Terminalde Claude Code konuşmasını dışa aktarma nedir?

Claude Code konuşmasını dışa aktarma, etkileşimli bir CLI oturumundaki /export komutudur. Anthropic’in belgeleri, mevcut konuşmayı kopyalamak veya düz metin dosyası olarak kaydetmek için bir menü anlatır; mesajlar ve araç çıktıları okunabilir metin olarak işlenir. Menüyü atlayıp doğrudan o dosyayı yazmak için bir dosya adı verin.

Bu, claude.ai’den alınan Markdown değildir, bu Chrome uzantısının JSON’u değildir ve bir PDF de değildir. Bir insanın okuması için işlenmiş bir dökümdür. Anthropic, diskteki JSONL günlüğünün farklı, dahili bir format olduğunu; sizin genel API’niz olarak değil, ürün için tasarlandığını söyler.

/export

Soruyu atlamak ve geçerli çalışma dizinine adlandırılmış bir dosya yazmak için:

/export my-session

Bayraklar ve dosya adları için esas kaynak Anthropic’in oturum belgeleridir; bunlar Claude Code sürümleri arasında değişir. Topluluk bloglarını ikincil kaynak sayın. /export penceresindeki metin gördüğünüzle eşleşmiyorsa CLI’niz farklı bir derlemedir — 2025’ten kalma bir ekran görüntüsünü değil, ürün içi yardımı kullanın.

Betikler için Anthropic başka arayüzleri gösterir: --output-format json veya stream-json ile claude -p, oturum kimliğiyle devam etme, transcript_path alan hook’lar veya Agent SDK. Bunlar Claude Code geliştirici arayüzleridir. Bu web sitesinin Chrome uzantısı değildirler.

Okunabilir ve yapılandırılmış. /export insan için dökümdür. projects klasörü altındaki JSONL ise günlüktür. Chrome uzantısının JSON’u yalnızca bir claude.ai sayfasından oluşturulan üçüncü bir yapıdır. Üçü için tek bir ayrıştırıcı yazmayın.

Bir Claude Code konuşması diskten nasıl indirilir?

Bir Claude Code konuşmasını diskten indirmek için oturumun JSONL dosyasını projects dizininden kopyalayın ya da okunabilir bir döküm için /export çalıştırın. macOS ve Linux’ta varsayılan yol ~/.claude/projects/ altındadır. Windows’ta %USERPROFILE%\.claude\projects olur. Dosya adları oturum kimlikleridir.

Proje klasörünün adı, alfanümerik olmayan karakterleri kısa çizgiyle değiştirilmiş çalışma dizinidir. Anthropic, dizinin dosya sistemi sınırları içinde kalması için çok uzun dönüştürülmüş adları kısaltır ve sonuna bir hash ekler. Klasörü bulamıyorsanız Claude Code’u sandığınızdan farklı bir çalışma dizininden (cwd) başlatmışsınızdır.

Her JSONL satırı bir mesaj, araç kullanımı veya meta veri için bir JSON nesnesidir. Anthropic bu kayıt formatının dahili olduğunu ve sürümler arasında değiştiğini belirtir. Bu dosyaları ayrıştıran betikler bir Claude Code sürümüyle bozulabilir. Kararlı bir şeye ihtiyacınız olduğunda /export komutunu veya belgelenmiş betik arayüzlerini tercih edin.

Depolama yeri değişebilir. CLAUDE_CONFIG_DIR, yapılandırma ağacını ~/.claude dışına taşır. CLAUDE_CODE_PROJECT_DIR_NAME, o yapılandırma diziniyle birlikte kullanıldığında proje dizinini adlandırır (Anthropic’e göre Claude Code v2.1.234 veya sonrası). settings.json içindeki cleanupPeriodDays varsayılan saklama süresini değiştirir. Bu ayarların hiçbiri Download Claude conversations’ın özelliği değildir.

Dolayısıyla Claude Code konuşma dosyalarını yedek için indirmenin yolu şudur: klasörü kopyalayın ya da dökümleri düzenli aralıklarla /export ile dışa aktarın. Bu site bir “JSONL içe aktar” düğmesi eklemeyecek. Ana dizininizi okumayız.

Claude Code dışa aktarma bu uzantıyla çalışır mı?

Hayır, terminal oturumları için çalışmaz. Download Claude conversations yerel Claude Code oturumlarını okumaz. Chrome uzantısı claude.ai’ye eklenir. Terminali göremez, /export çalıştıramaz ve JSONL açamaz. İstisna, claude.ai/code adresindeki web’deki Claude Code’dur: bu bir claude.ai sayfasıdır, dolayısıyla her sohbet gibi dışa aktarılır. CLI’den bir Claude Code konuşmasının nasıl indirileceğini aradıysanız bu sayfadaki CLI adımlarında kalın.

İnsanlar buraya, Google “Claude” ve “dışa aktarma” sözcüklerini birlikte grupladığı için gelir. Web Store kaydı yine yalnızca claude.ai içindir. Uzantıyı yüklemek iTerm, Ghostty, VS Code terminali veya Claude Code’un masaüstü sarmalayıcısında turuncu bir düğme göstermez.

Aynı kodlama işi için claude.ai’de paralel bir sohbet de tutuyorsanız o tarayıcı sohbeti uzantıyla kaydedilebilir. İki kayıt birleştirilmez. Yalnızca CLI’de gerçekleşen araç çağrıları, oraya yapıştırmadıysanız web dışa aktarmasında görünmez.

Her hafta aynı destek e-postasını alıyoruz: biri Chrome uzantısını yüklemiş ve /export’un görünmesini beklemiş. Biz yalnızca claude.ai’yi ayrıştırıyoruz. Claude Code zaten /export ve JSONL ile geliyor. CLI’yi sarmalamak farklı bir ürün olurdu ve böyle bir ürün yayımlamadık.

Bunların hiçbiri /export kullanımını saymaz.

Web’deki Claude Code oturumlarını dışa aktarabilir miyim?

Evet. Web’deki Claude Code claude.ai/code adresinde çalışır; bu yüzden Download Claude conversations bu oturumları her claude.ai sohbeti gibi dışa aktarır. Oturumu Chrome’da açın, turuncu düğmeye tıklayın, bir format seçin ve “Export” (Dışa aktar) düğmesine tıklayın. Uzantının kapsadığı tek Claude Code ortamı budur.

Formatlar her sohbetteki yedi formatla aynıdır: PDF, Markdown, Plain Text (düz metin), JSON, XML, CSV ve PNG. Markdown, metin, JSON, XML, CSV ve PNG sınırsızdır ve hesap gerektirmez. PDF, Google ile giriş ister ve Pro’da değilseniz ücretsiz planın günlük 3 hakkını toplu ZIP ile paylaşır. Kod blokları dil etiketlerini korur. Genişletilmiş düşünme paneldeki “Thinking” (Düşünme) onay kutusudur; araç / MCP adımları ve web arama kaynakları Ayarlar’daki isteğe bağlı anahtarlardır.

Web dışa aktarması, claude.ai/code’un tarayıcıda gösterdiği şeydir. Yerel bir CLI çalıştırmasının JSONL günlüğü değildir ve yalnızca terminalinizde çalışmış oturumlara ulaşmaz. Anthropic’e göre web’deki Claude Code kendi oturum geçmişini, CLI’nin ~/.claude/projects ağacından ayrı tutar. Bir terminal oturumu için yol hâlâ /export komutudur.

Claude Code konuşma geçmişini nerede saklar?

Claude Code konuşma geçmişini, yapılandırma dizinindeki projects klasörü altında JSONL dökümleri olarak saklar. macOS ve Linux’ta varsayılan: ~/.claude/projects/<encoded-cwd>/<session-id>.jsonl. Windows %USERPROFILE%\.claude\projects kullanır. Anthropic bu düzeni değiştirebilir; diskte bir yol eksikse güncel oturum belgelerine bakın.

Devam etmek, dışa aktarmaktan farklı bir eylemdir. claude --continue ve claude --resume bir oturumu yeniden yükler, böylece çalışmaya devam edebilirsiniz. /export ise git’te bırakabileceğiniz veya e-postayla gönderebileceğiniz bir kopya yazar. Biri bağlamı geri getirir. Diğeri yanınızda bir kayıt götürmenizi sağlar. Anthropic’in oturum sayfası devam ederken izin modunu, sıkıştırma/özeti ve seçici davranışını anlatır — bunların hiçbiri bu uzantıyla ilgili değildir.

Anthropic’e göre masaüstü uygulaması, web’deki Claude Code ve VS Code uzantısının her biri kendi oturum geçmişini tutar. Bu rehberdeki yollar CLI’ye aittir. Web oturumları claude.ai/code’da kalır ve uzantı onları orada dışa aktarabilir. Bir Desktop Cowork dökümünün terminalden kullandığınız aynı JSONL ağacında durduğunu varsaymayın.

JSONL’yi genel bir şema gibi görmeyin. Anthropic satır formatının değiştiğini söyler. Yine de ayrıştıracaksanız bir Claude Code sürümüne sabitleyin ve bozulmaları bekleyin. İnsanın okuyabileceği bir Claude Code konuşması almanın kararlı yolu /export komutudur.

CLAUDE_CODE_SKIP_PROMPT_HISTORY gibi ortam bayrakları döküm yazımını engelleyebilir. projects klasörü boşsa kalıcılığı devre dışı bırakıp bırakmadığınızı, CLAUDE_CONFIG_DIR ayarını başka bir yere yönlendirip yönlendirmediğinizi veya o dizinde hiç etkileşimli oturum çalıştırıp çalıştırmadığınızı kontrol edin.

Bunun yerine claude.ai’de bir Claude sohbeti nasıl indirilir?

claude.ai’de bir Claude sohbeti şöyle indirilir: Download Claude conversations’ı yükleyin, sohbeti Chrome’da açın, turuncu düğmeye tıklayın, PDF, Markdown, Plain Text, JSON, XML, CSV veya PNG’yi seçin. Bu tarayıcı ürünüdür ve claude.ai/code oturumlarını da kapsar. Terminaldeki Claude Code dışa aktarması değildir. Adım adım: Claude sohbeti nasıl indirilir.

claude.ai geçmişinin tamamını ayrı dosyalar olarak almak /export ile değil, Dashboard’daki “Export All” (Tümünü dışa aktar) ile yapılır. Ücretsiz planda ZIP içindeki her sohbet günlük 3 hakka sayılır (PDF ile paylaşılır, gece yarısı UTC’de sıfırlanır); Pro sınırı kaldırır. Rehber: toplu “Export All”. Formatlar: formatlar.

Tek sohbetlik Markdown, metin, JSON, XML, CSV veya PNG için hesap gerekmez — bu dışa aktarmalar sınırsızdır. Google ile giriş yalnızca PDF, toplu ZIP ve Pro için çıkar; böylece günlük kotayı sayabilir ve Pro’yu geri yükleyebiliriz. Dosyalar, PDF dahil, yerel olarak oluşturulur. Paddle, Pro’yu ayda 3,99 $ veya yılda 26,99 $ olarak faturalandırır. Bunların hiçbiri terminaldeki /export için geçerli değildir.

İşiniz Claude Code’da başladıysa ve claude.ai’ye bir özet yapıştırdıysanız, notlar için web sohbetini indirin, gerçek CLI günlüğü için ise /export komutunu kullanın. İki dosya, karışık tek bir dosyadan iyidir.

Claude Code dışa aktarma mı, Anthropic’in resmî Export data özelliği mi?

Claude Code dışa aktarması (/export veya JSONL) tek bir terminal oturumudur. Resmî Export data ise claude.ai’deki Settings → Privacy → Export data yoludur (claude.ai Türkçe ayarlıysa etiketler çevrilmiş görünebilir): Anthropic hesabının gecikmeli bir JSON ZIP’i. Aynı arşiv değildirler. ZIP, /export komutunun yerini tutmaz.

Belirli bir Claude Code oturumunun hesap ZIP’inde görünüp görünmemesi bu uzantıya değil, Anthropic’in o ürünü nasıl sakladığına bağlıdır. Anthropic’in güncel gizlilik belgeleri aksini söylemedikçe ZIP’i bir web hesabı yedeği olarak görün. CLI oturumlarını o ZIP’e biz eklemeyiz.

Web sitesinden bir Claude sohbetinin nasıl dışa aktarılacağı, o ZIP ile uzantının karşılaştırması dahil, burada anlatılıyor: Claude sohbeti nasıl dışa aktarılır. Uzantının PDF dışa aktarması da bir terminal arayüzü için geçerli değildir. Claude sohbetini PDF olarak indirme rehberine yalnızca konuşma claude.ai’de (claude.ai/code dahil) olduğunda bakın.

Claude Code, Desktop ve claude.ai dışa aktarma farkı nedir?

Claude Code, Claude Desktop ve claude.ai üç ayrı ortamdır. Claude Code dışa aktarması /export ve JSONL kullanır. Desktop, bu uzantının turuncu düğmesi olmayan bir uygulamadır. Download Claude conversations’ın çalıştığı tek yer Chrome’daki claude.ai’dir — claude.ai/code adresindeki web’deki Claude Code dahil. Adları karıştırmak, dışa aktarmaların sessizce başarısız olmasının nedenidir.

Claude Desktop: sohbet aynı Anthropic hesabına senkronize olduysa onu claude.ai’de açın ve orada dışa aktarın. Yalnızca Desktop penceresinde duruyorsa kopyala-yapıştır yapın veya resmî Export data’yı bekleyin. Rehber: bir Claude Desktop sohbetini dışa aktarma.

VS Code’daki Claude Code paneli claude.ai’den çok CLI’ye yakındır. İçerik betiğimizin o webview’e eklenmesini beklemeyin. Mesajları gerçekten tutan oturumdan /export kullanın.

Bağımsız bir Chrome uzantısıdır, Anthropic, PBC ile bağlantılı değildir. Claude, Anthropic’in ticari markasıdır. Onların Hizmet Şartları’na uyun. Tescilli kod içeren araç çıktılarını kopyalama konusunda hukuki tavsiye veremeyiz; bu sizinle, işvereninizle ve Anthropic arasındadır.

SSS: Claude Code dışa aktarma

Bir Claude Code konuşmasını nasıl dışa aktarırım?

Claude Code terminalinde, işlenmiş bir dökümü kaydetmek için /export yazın (isteğe bağlı olarak bir dosya adıyla) ya da JSONL dosyasını macOS/Linux’ta ~/.claude/projects, Windows’ta %USERPROFILE%\.claude\projects klasöründen kopyalayın. Güncel pencereyi Anthropic’in oturum belgeleri anlatır.

Bu Chrome uzantısı Claude Code sohbetlerini indirir mi?

Terminalden hayır. Download Claude conversations yalnızca Chrome’daki claude.ai’de çalışır. Yerel terminal oturumlarını, JSONL dökümlerini veya /export komutunu okuyamaz. claude.ai/code adresindeki web’deki Claude Code oturumları ise her sohbet gibi dışa aktarılır.

Web’deki Claude Code’u (claude.ai/code) dışa aktarabilir miyim?

Evet. Oturumu Chrome’da claude.ai/code adresinde açın ve turuncu düğmeyi kullanın. PDF, Markdown, Plain Text, JSON, XML, CSV ve PNG’nin hepsi çalışır. PDF dışındaki altı format hesapsız ve sınırsızdır; PDF, Google ile giriş gerektirir ve günlük 3 ücretsiz hakka sayılır.

Claude Code konuşma geçmişini nerede saklar?

Oturum dökümleri, ~/.claude/projects/<encoded-working-directory>/ altında oturum kimliğiyle adlandırılmış JSONL dosyalarıdır. Tam düzen değişebilir. JSONL ayrıştırmak yerine okunabilir bir dosya istediğinizde /export kullanın. CLAUDE_CONFIG_DIR bu ağacı taşıyabilir.

Bir Claude Code konuşması Markdown olarak nasıl indirilir?

Claude Code’un /export komutu düz metin bir dökümdür, bu uzantının Markdown’u değildir. Özellikle Markdown gerekiyorsa bir claude.ai/code oturumunu veya işin claude.ai’deki bir kopyasını Download Claude conversations ile dışa aktarın ya da /export metnini kendiniz dönüştürün. JSONL’yi Markdown’a dönüştürmüyoruz.

Bunun yerine bir claude.ai konuşmasını nasıl indiririm?

Ücretsiz Chrome uzantısını yükleyin, sohbeti claude.ai’de açın ve turuncu düğmeyi kullanın — geçmiş için de “Export All”u. Bkz. Claude sohbeti nasıl indirilir. Markdown, metin, JSON, XML, CSV ve PNG hesapsız ve sınırsızdır; PDF ve toplu ZIP, Google ile girişle günde 3 adede kadar ücretsizdir; Pro ayda 3,99 $ veya yılda 26,99 $’dır.

/export resmî Export data ile aynı şey mi?

Hayır. /export mevcut Claude Code oturumudur. Settings → Privacy → Export data ise Anthropic hesabının JSON ZIP’ini e-postayla gönderir. Farklı ürün ortamları, farklı dosyalar, farklı bekleme süreleri.

Claude Code JSONL’sini jq ile ayrıştırabilir miyim?

Ayrıştırabilirsiniz, ancak Anthropic’in yayımladığı uyarıyla: satır şeması dahilidir ve değişebilir. Bir sözleşmeye ihtiyacınız olduğunda /export veya claude -p --output-format json tercih edin. Yine de JSONL ayrıştıracaksanız CLI sürümünüzü sabitleyin.

Claude Code dışa aktarma Windows’ta çalışır mı?

Evet. /export bir CLI komutudur. CLAUDE_CONFIG_DIR ayarlamadıysanız diskteki dökümler %USERPROFILE%\.claude\projects altında durur. Bu Chrome uzantısı yine de o terminalin içinde çalışmaz.

Claude Code, Claude Desktop ile aynı şey mi?

Hayır. Claude Code terminaldeki kodlama ajanıdır. Claude Desktop sohbet uygulamasıdır. claude.ai web sitesidir. Bu uzantı yalnızca web sitesinde, claude.ai/code dahil, çalışır. Desktop dışa aktarma notları: Claude Desktop.

Bu uzantı bir gün /export’u sarmalayacak mı?

1.16.2 sürümünde hayır. Ürünün kapsamı, web’deki Claude Code dahil claude.ai’dir: yedi format, yerel dosyalar, yalnızca PDF, toplu dışa aktarma ve Pro için Google ile giriş. Bu kapsam değişirse bu sayfa bunu belirtecek. O zamana kadar terminaldeki Claude Code dışa aktarması için Anthropic’in CLI’sini kullanın.

/export araç çıktılarını içerir mi?

Anthropic, /export çıktısını okunabilir metin olarak işlenmiş mesajlar ve araç çıktıları olarak tanımlar. Bu onların dökümüdür, bizim ayrıştırıcımız değil. Güncel içeriği tam olarak görmek için kendi derlemenizde /export çalıştırın ve dosyayı okuyun — belgeler bir sürümün gerisinde kalabilir.

Claude Code oturumlarını toplu dışa aktarabilir miyim?

Yerel CLI oturumlarını hayır. Dashboard’daki “Export All” yalnızca claude.ai içindir. Çok sayıda CLI oturumu için projects klasörünü kopyalayın veya her oturum için /export çalıştırın. JSONL için turuncu düğmeyle toplu dışa aktarma yoktur.
