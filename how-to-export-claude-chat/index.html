How to export a Claude chat with the extension?

How to export a Claude chat as a readable file is the orange button on claude.ai. Install Download Claude conversations, open the thread, pick Markdown, JSON, text, XML, or PNG, then click Export. The file is built in your browser and saved locally. Google sign-in counts the 3 free exports.

The extension is a content script on the page you already loaded. It does not open a second Anthropic session and it does not upload the conversation to generate the file. That is why the button only appears on a conversation URL, after the thread exists in the DOM.

  1. Install the extension from the Chrome Web Store.
  2. Open the conversation on claude.ai. Reload the tab if it was open during install.
  3. Click the orange download button beside the message box.
  4. Pick Markdown, JSON, plain text, XML, or PNG.
  5. Set thinking, metadata, sender, and artifact layout if you need them. Click Export.

For more than one thread, open View and Download All Conversations in the popup. Search, filter by Project or already exported, then Export All. Every file in that batch counts against the same 3 free exports. Walkthrough: bulk Export All.

Team and Enterprise chats export the same way if you can open them in Chrome. The parser does not check Anthropic plan names. If an org blocks extensions, that is an IT policy, not a missing Pro toggle on our side.

Quota vs Anthropic usage. Exporting with this extension does not spend Claude message credits. It reads the page. The 3-export cap is our quota, billed separately via Paddle if you buy Pro at $3.99/mo or $26.99/yr.

How to export chat from Claude with official ZIP?

How to export chat from Claude at account scale is Settings → Privacy → Export data. Anthropic emails a link that expires. The ZIP is JSON for the whole account, not a pretty file for one conversation. Use it as a backup.

The official ZIP is the right tool when you are leaving a workspace, archiving everything, or satisfying a “give me all my data” request. It is the wrong tool when you have one design review open and need a file in the next minute.

There is no filter in that flow for a single conversation ID. You wait, you download the archive, you unpack it, you find the thread. The JSON shape is account-level. It is not the per-chat JSON this extension writes from the open page.

If you need both, run Export data once for the backup and use Download Claude conversations whenever you need a working file. Those jobs do not replace each other. The ZIP will not become Markdown. The orange button will not email you every forgotten chat from 2024.

Official Export data also is not print-to-PDF. Print captures the webpage. The ZIP is structured account data. Comparison of print vs files: download Claude chat as PDF.

How do I export a Claude chat to Markdown or JSON?

How to export a Claude chat to Markdown or JSON: choose that format in the dropdown before Export. Markdown is for notes and git. JSON is the message tree for scripts. Plain text strips markup. PNG is an image, not a PDF.

Markdown keeps headings, fenced code with language tags, and tables. Artifact layout can be Original, Inline, Nested, or Flat. Thinking blocks are optional. That file is what most people mean by a readable export. Hub: formats.

JSON from the extension is per conversation (or per bulk selection). It is not Anthropic’s account ZIP renamed. If you are writing a parser, use this JSON for one thread and the official ZIP only when you truly need every conversation Anthropic stored.

Can I export a Claude chat without paying?

Yes. You can export a Claude chat without paying for the first 3 files on any account, any of the five formats. After that, Pro is $3.99 per month or $26.99 per year. Google sign-in stops a reinstall from resetting the free count.

Bulk Export All is not a separate free bucket. One file from Export All is one export, same as the orange button. Selecting twenty conversations on a free account stops after the third file. Plan the selection.

Print and Anthropic Export data do not use our quota. They also do not give you Markdown of one chat. Free-as-in-no-extension still has costs in time and cleanup.

Google sign-in is not optional. The first Export click asks Google to verify an email. Canceling looks like a broken export. Complete sign-in, then click Export again. No credit card is required for the 3 free files.

Pro restore follows that Google email if you move machines or reinstall. It does not follow the Anthropic password. Sign in with the same Google account you used when you paid.

We keep the official ZIP and our export as two different jobs on purpose. Account JSON by email is Anthropic’s backup. Per-chat Markdown and JSON are what we build in the browser from the thread you have open. Mixing those two in one button would make both worse.

How to export a Claude chat vs copy-paste?

Copy-paste can export a Claude chat only in the weakest sense: you selected text and moved it. Code loses indentation. Tables collapse. A long thread has no message boundaries. How to export a Claude chat as a structured file is still the extension, print, or the official ZIP.

A middle path is select-all into Google Docs or Word, then fix formatting by hand. That is a one-off client deliverable, not a weekly archive. Every new turn means another cleanup. The extension exists so that cleanup does not start from a paste.

Copy-paste also misses collapsed thinking and artifacts that were not expanded. Print has the same gap: collapsed UI is absent from the PDF. The extension’s toggles can include thinking and artifacts when they are in the loaded page data, which is a different layer than “what pixels are visible.”

If you only need one paragraph for Slack, copy-paste is honest and faster. If you need the whole review with code fences, spend one of the 3 free exports on Markdown.

How to export Claude Code vs claude.ai chats?

How to export a Claude chat on claude.ai is this Chrome extension. How to export a Claude Code conversation is /export in the terminal, or JSONL under ~/.claude/projects. Claude Desktop is a third window and does not get the orange button.

Claude Code’s /export writes a rendered plain-text transcript (clipboard or file). Anthropic documents that JSONL on disk is an internal format that can change. Prefer /export or their script interfaces for anything you will keep. Steps: Claude Code export.

Claude Desktop: open the same chat on claude.ai if it synced, then export there. Otherwise copy-paste from Desktop, or rely on Settings → Privacy → Export data for account-level JSON. Guide: export a Claude Desktop chat.

Searching “claude code export” on this site is a disambiguation page, not a feature of the Web Store listing. The listing is claude.ai only. That limit is the product, not a missing checkbox.

What does a Claude chat export keep and drop?

A Claude chat export from this extension keeps the message tree the page has loaded: senders, text, code fences, tables, and — if toggled — thinking, metadata, and artifacts. It drops anything not rendered yet and CSS chrome such as the composer.

Print keeps pixels. It drops a clean code layout more often than not. Official ZIP keeps whatever Anthropic put in the account archive. It drops a human-readable per-chat document. Copy-paste keeps selected characters and drops structure.

Sender filter: all messages, human only, or assistant only. Useful when you want prompts without answers, or the reverse. Metadata toggle adds titles, timestamps, and model when you need a bibliography line in the file.

Files stay on disk. Our worker sees subscription state. Google sees the OAuth consent you approved. claude.ai already had the conversation. That is the full list of parties. We are not Anthropic. Claude is a trademark of Anthropic, PBC.

If the export looks short, load more of the thread and export again. On the free tier that second try is another of the 3 exports. Confirm the stream finished and older turns are on screen before you click.

FAQ: how to export a Claude chat

How do I export chat from Claude for one thread?

Use Download Claude conversations on the open claude.ai conversation. The official Export data flow is account-wide and slower than you need for a single thread. Print is a visual PDF, not Markdown.

How do I export Claude chat to PDF?

Neither claude.ai nor this extension writes a native PDF. Print (Ctrl/Cmd+P → Save as PDF) for a snapshot. Or export Markdown and convert it in Word, Google Docs, or a Markdown app. Guide: download Claude chat as PDF.

Does the official export cover artifacts and thinking?

The ZIP includes whatever Anthropic stored in the account JSON. It is not formatted as per-chat Markdown with a chosen artifact layout. The extension’s export is built to keep those readable when the toggles are on and the page has loaded them.

Will a Chrome extension risk my Anthropic account?

The extension uses your existing logged-in claude.ai session the same way the website does. It does not automate account actions or call Anthropic with its own credentials. We are not Anthropic. You are still bound by their Terms of Service.

Can I export a Claude chat from Team workspaces?
