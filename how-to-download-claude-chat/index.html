How to download a Claude chat

There is no native "Download chat" control on Claude.ai. To download a Claude chat you either print the page, request Anthropic's account export, or use a Chrome extension to save that conversation as Markdown, JSON, text, XML, or PNG. Use print for a one-off screenshot-like copy; use Anthropic's export for a full-account JSON ZIP; use Download Claude conversations when you want a clean file of this thread in seconds.

Method 1 — Chrome extension (this product)

If you only need one answer to how to download a Claude chat, this is it. Download Claude conversations puts an orange button next to the message box on every claude.ai conversation, and it exports the actual message structure — code blocks, tables, artifacts — instead of a picture of the page.

  1. Install the extension from the Chrome Web Store.
  2. Open a conversation on claude.ai.
  3. Click the orange download button to the right of the message box.
  4. Choose Markdown, JSON, plain text, XML, or PNG.
  5. Click Export — the file downloads immediately.

The difference between this and printing the page shows up the moment you open the file afterward: a printed PDF keeps the sidebar and composer chrome and often breaks a long code block across pages, while a Claude Conversation Downloader export keeps only the conversation, formatted as a real Markdown, JSON, or text file you can search, diff, or paste elsewhere without cleanup.

If you need to download your whole Claude chat history instead of one thread, don't repeat these steps one chat at a time. Open View and Download All Conversations from the extension popup — the same Claude Conversation Downloader, in a browse view that lists every conversation, lets you search and filter, and exports many chats in one Export All pass. Free accounts should know that bulk exports count against the same 3-export quota as single chats — it's not a separate allowance.

Method 2 — Anthropic Export data

Yes: Settings → Privacy → Export data on claude.ai. Anthropic emails you a link (it expires) to a ZIP of your entire account as JSON. That covers every conversation you've ever had, but the output is a raw account archive, not a per-chat file you'd hand to a client or drop into notes — there's no Markdown, no PNG, and no way to grab just one thread. It's the right choice when you want a full backup of your account, not when you want to download a Claude conversation you're currently reading. Expect to wait for the email and to dig through the ZIP structure yourself once it arrives — there's no browsing UI, just files.

Method 3 — Copy-paste

For one short message, sure — select the text, paste it into a document. But this loses code indentation, tables collapse, and a multi-turn thread turns into an unstructured wall of text you have to clean up manually. It doesn't scale past a message or two, and it's the slowest way to download a Claude chat of any real length. If you find yourself doing this more than once, that's usually the signal to switch to Method 1 instead.

Whichever row matches what you actually need, that's how to download a Claude chat today — there isn't a single universal answer, because "download claude conversation" covers four different jobs depending on whether you want one thread, everything, or just a quick look. Most people land on the extension once they realize the official export is built for backups, not for a readable file of one conversation.

Troubleshooting

  • Button missing: you're not on a conversation URL (the button only appears once a chat is open), the page needs a reload after install, or the extension icon needs pinning to the toolbar.
  • Sign-in gate: expected behavior. Download Claude conversations requires Google sign-in before the first export — no credit card for the free tier, just an account so we can enforce the 3-export limit and let you restore Pro later.
  • Hit the 3-export limit: upgrade to Pro, or wait until you actually need the next export. We won't pretend the free tier is unlimited — it isn't.
  • Export looks incomplete: confirm the whole conversation has finished loading in claude.ai before exporting — a very long thread that hasn't fully scrolled/loaded in the page can export only what's currently rendered.
  • Wrong file downloaded: double-check the format dropdown before clicking Export — Download Claude conversations remembers your last-used format, so it's easy to click through without noticing it's still set to JSON when you wanted Markdown.

FAQ

How do I download Claude chat history?

For one conversation, use the orange button (Method 1). For your entire chat history at once, use Export All on the browse page — that's bulk, not the official account export, which is a separate, slower ZIP.

Can I download Claude chats without an extension?

Yes: print to PDF, or request Anthropic's Export data. Both work, and both lose something an extension doesn't — see the comparison table above.

Will this get my Anthropic account banned?

We can't give legal advice, but the extension uses your logged-in claude.ai session the same way the site itself does — it doesn't touch Anthropic's servers directly or automate your account. We are not Anthropic; follow their Terms of Service.

Is claude download chat the same task as download claude chat?

Yes, same task, different word order. Both land on the same orange button.

Do I need to pay to download a Claude conversation?

No — 3 exports are free on every account. Pro removes the limit if you need more.

Does Download Claude conversations work on mobile?

No — it's a Chrome extension, so it needs desktop Chrome (or a Chromium browser) on claude.ai. There's no mobile app version today.

Is Claude Conversation Downloader the same extension people call "Claude Exporter"?

Yes — same product, different name used in different places (legal pages currently say Claude Exporter, the Chrome Web Store listing and this site say Download Claude conversations). Either name points at the same orange button.
