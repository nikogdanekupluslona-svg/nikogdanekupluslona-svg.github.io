Hvordan eksporterer jeg Claude-chat til Markdown?

Åpne samtalen på claude.ai i Chrome, klikk den oransje knappen ved siden av meldingsfeltet, velg Markdown og klikk «Export». Download Claude conversations skriver en .md-fil lokalt. Slik eksporterer du en Claude-chat til Markdown i versjon 1.16.2.

  1. Installer Download Claude conversations fra Chrome Web Store.
  2. Last inn claude.ai på nytt og åpne en ekte samtale-URL, ikke den tomme startsiden med skrivefeltet.
  3. Klikk den oransje nedlastingsknappen til høyre for meldingsfeltet.
  4. Velg Markdown. Utvidelsen husker formatet du brukte sist. Med «Select» (velg) krysser du av bare meldingene du vil ha med.
  5. Klikk «Export». Chrome laster ned .md-filen via nettleserens nedlastings-API. Eller klikk «Copy» (Kopier) for å legge Markdown-teksten på utklippstavlen.

Du trenger ingen pålogging for å eksportere Claude-chat til Markdown. Markdown-eksport av én chat er ubegrenset, anonym og sender ingenting til serverne våre. Google-pålogging kreves bare for PDF og masseeksport med «Export All» (Eksporter alle). Slik virker det: slik fungerer det.

Mangler den oransje knappen, er du ikke på en samtale-URL, fanen må lastes inn på nytt etter installasjonen, eller utvidelsen er fortsatt skjult i puslebrikkemenyen i Chrome. Fest Download Claude conversations og last claude.ai på nytt. Innholdsskriptet legges aldri inn i Claude Desktop eller i Claude Code i terminalen.

Én chat eller mange. Den oransje knappen eksporterer den åpne samtalen som Markdown. For mange .md-filer åpner du «View and Download All Conversations» (Se og last ned alle samtaler) og kjører Export All med Markdown valgt: én ZIP-fil, 3 chatter om dagen på gratisplanen – se masseeksport med Export All.

Hvorfor eksportere Claude-chat til Markdown for notater?

Velg Markdown når du skal lese filen i Obsidian, en GitHub-wiki eller en editor som viser overskrifter og kodeblokker. .md-filen er fortsatt ren tekst du kan søke i og sammenligne med diff. JSON passer bedre for parsere; PNG er et bilde du ikke kan søke i med grep.

Kopier og lim inn fra claude.ai mister som regel innrykk og gjør tabeller flate. Utskrift (Ctrl/Cmd+P) tar med sidefeltet og deler ofte en lang kodeblokk over flere sider. Når du eksporterer til Markdown, blir språkmerkene på kodeblokkene stående, og tabeller forblir tabeller. Derfor velger skribenter dette formatet først.

Vi behandler Markdown som standardfilen for mennesker: overskrifter, kodeblokker med språkmerker og tabeller fra claude.ai-samtalen. Trenger du sider i stedet, velger du PDF i samme panel. Den settes opp i nettleseren, med sidestørrelse, marger og innholdsfortegnelse.

Hva beholder Markdown-eksporten?

Når du eksporterer Claude-chat til Markdown, beholder Download Claude conversations overskrifter, kodeblokker med språkmerker og innrykk, tabeller og lenker. Tenkeblokker, kilder fra nettsøk og verktøy-/MCP-trinn tar du med etter eget valg: «Thinking» (tenkning) er en avkrysningsboks i eksportpanelet, og de to andre slår du på i innstillingene. Metadata (tittel, tidsstempler, modell) kan følge med. Avsenderfilteret kan begrense .md-filen til alle meldinger, bare menneske eller bare assistent («All / Human / Assistant»).

Oppsett for artefakter er en ekte bryter i versjon 1.16.2: «Original», «Inline» (innebygd), «Nested» (nestet) eller «Flat» (flatt). En Markdown-eksport kan speile artefaktstrukturen på skjermen, gjøre den om til ett lineært dokument eller legge artefaktene i en egen mappe i en ZIP-fil. I innstillingene kan du bygge inn bilder i .md-filen. Hele listen: funksjoner i Chrome-utvidelsen. Markdown beholder ikke fargene på meldingsboblene; bruk PNG for et visuelt øyeblikksbilde eller PDF for sider.

Er samtalen svært lang, blar du til claude.ai har lastet inn de tidligere meldingene før du eksporterer. Utvidelsen kan bare skrive det siden har vist. En halvveis innlastet samtale gir en halvveis .md-fil. Det ser ut som en feil, men skyldes som regel en DOM du ikke har bladd gjennom.

Kan jeg eksportere Claude-chat til Markdown i bulk?

Ja. Åpne «View and Download All Conversations», sett «Chat format» (chatformat) til Markdown, filtrer listen og klikk Export All. Chrome lagrer én ZIP-fil med én .md-fil per chat. På gratisplanen er det 3 chatter om dagen med Google-pålogging, delt med PDF. Pro til 3,99 $ i måneden eller 26,99 $ i året fjerner grensen for Markdown i bulk.

Oversiktssiden (Dashboard) viser claude.ai-historikken med søk på navn, filtrene «All conversations», «New», «Updated» og «Previously exported» (alle samtaler, nye, oppdaterte, eksportert tidligere), fanene Chat og Cowork og prosjektsøk. New betyr ikke eksportert ennå med Download Claude conversations. Previously exported holder styr på chatter du allerede har lagret, slik at neste Export All kan hoppe over dem.

Den daglige grensen gjelder per konto. Tre chatter om dagen på gratisplanen, delt med PDF. Velger du 40 samtaler og har 3 igjen, blokkeres hele kjøringen – den kuttes ikke av. Velg færre, eller bruk Pro. Enkeltvise .md-eksporter fra den oransje knappen er fortsatt ubegrenset.

Markdown i bulk bruker avkrysningsboksene på oversiktssiden – «Chats», «Thinking», «Metadata», «Tools» og «Sources» (chatter, tenkning, metadata, verktøy, kilder) – pluss formatet for artefakter. Export All er ikke Anthropics forsinkede ZIP-fil. Det er én ZIP-fil med .md-filer, én per chat. Ville du ha ett arkiv med hele kontoen, er det Settings → Privacy → Export data (etikettene kan være oversatt hvis claude.ai er satt til norsk), og det er JSON, ikke Markdown.

Markdown eller JSON når jeg eksporterer en Claude-chat?

Velg Markdown når et menneske skal lese filen. Velg JSON når et skript skal lese meldingstreet. Download Claude conversations har begge i samme nedtrekksliste, pluss PDF, ren tekst, XML, CSV og PNG. Formatoversikt: eksportformater for Claude-chat.

Ren tekst Ingen markup, arkiv du kan lime inn hvor som helst
XML Et system som krever XML
CSV Regneark, én rad per melding
PDF Lesing, utskrift, sending – PDF-guide
PNG Et bilde av samtalen, ikke søkbar tekst

Anthropics Export data er også JSON, men det er en ZIP-fil for kontoen på e-post, ikke en .md-fil per chat. Du kan ikke velge Markdown i den forespørselen. Utskrift fra nettleseren er et øyeblikksbilde av nettsiden. Ingen av dem erstatter Markdown-eksporten fra den oransje knappen.

Utvidelsen kjører bare på claude.ai i Chrome. Claude Desktop og Claude Code i terminalen får ingen Markdown-knapp. Claude Code på nettet (claude.ai/code) kjører på claude.ai, så det eksporteres som en hvilken som helst chat. Finnes en samtale også på claude.ai, åpner du den der og eksporterer til Markdown. /export i Claude Code i terminalen er en annen produktvei.

Koster det ekstra å eksportere Claude-chat til Markdown?

Nei. Markdown-eksport av én chat er gratis og ubegrenset, uten konto og uten teller – akkurat som JSON, tekst, XML, CSV og PNG. Bare PDF og masseeksport med Export All har en grense på gratisplanen: 3 om dagen med Google-pålogging. Pro koster 3,99 $ i måneden eller 26,99 $ i året via Paddle. Download Claude conversations tar ikke tillegg for Markdown.

Det er Markdown i bulk som møter grensen. Hver chat i en ZIP-fil fra Export All bruker én av de 3 om dagen, og tellingen nullstilles ved midnatt UTC. Pro fjerner grensen og gjenopprettes på en ny datamaskin med samme Google-konto. Paddle er selger (merchant of record); teamet vårt ser aldri kortnumre.

Du trenger ikke et betalt claude.ai-abonnement fra Anthropic. Du trenger en innlogging som kan laste inn samtalen i Chrome. Team og Enterprise fungerer som Free med den oransje knappen. Versjon 1.16.2 fra september 2026 skriver fortsatt ikke Word eller Notion.

Mister jeg kode når jeg eksporterer Claude-chat til Markdown?

Nei. Kodeblokker beholder språkmerke og innrykk, i motsetning til vanlig kopier og lim inn fra claude.ai. Tabeller forblir Markdown-tabeller. Det er hovedgrunnen til å eksportere til Markdown i stedet for å markere tekst for hånd.

Kan jeg eksportere Claude-chat til Markdown i bulk?

Ja. Export All på oversiktssiden støtter Markdown og lagrer én ZIP-fil med .md-filer. På gratisplanen dekker den 3 chatter om dagen med Google-pålogging; med Pro er det ubegrenset.

Er Markdown det samme som Anthropics Export data?

Nei. Anthropics offisielle eksport er en JSON-ZIP for hele kontoen, sendt på e-post etter en ventetid. Markdown-eksporten er en .md-fil per chat (eller per utvalg) fra Download Claude conversations.

Koster Markdown mer enn andre formater?

Nei. Markdown-eksport av én chat er ubegrenset og krever ingen konto, akkurat som JSON, tekst, XML, CSV og PNG. Bare PDF og ZIP-masseeksport har en gratisgrense på 3 om dagen. Pro koster 3,99 $ i måneden eller 26,99 $ i året.

Kan jeg eksportere Claude-chat til Markdown i Desktop?

Nei. Download Claude conversations legges bare inn på claude.ai i Chrome. Claude Desktop viser aldri nedtrekkslisten for Markdown. Åpne samme samtale på claude.ai hvis den finnes der.

Lager Markdown-eksporten en PDF?

Nei. Markdown er en .md-tekstfil. Vil du ha sider, velger du PDF i samme panel i stedet: den bygges i nettleseren med sidestørrelse, marger og innholdsfortegnelse. PDF krever Google-pålogging og teller mot 3 om dagen på gratisplanen.

Trenger jeg Pro for å eksportere til Markdown én gang?

Nei. Du trenger ingen konto i det hele tatt. Markdown-eksport av enkeltchatter er ubegrenset på gratisplanen. Pro til 3,99 $ i måneden eller 26,99 $ i året fjerner bare grensen på 3 om dagen for masseeksport med Export All og PDF.
