Hvordan eksporterer jeg Claude-chat til Markdown?

Åpne samtalen på claude.ai i Chrome, klikk den oransje knappen ved siden av meldingsfeltet, velg Markdown og klikk «Export». Download Claude conversations skriver en .md-fil lokalt. Slik eksporterer du en Claude-chat til Markdown i versjon 1.13.0.

  1. Installer Download Claude conversations fra Chrome Web Store (oppføringen er vurdert til 5.0).
  2. Last inn claude.ai på nytt og åpne en ekte samtale-URL, ikke den tomme startsiden med skrivefeltet.
  3. Klikk den oransje nedlastingsknappen til høyre for meldingsfeltet.
  4. Velg Markdown. Utvidelsen husker formatet du brukte sist.
  5. Klikk «Export». Chrome laster ned .md-filen via nettleserens nedlastings-API.

Google-pålogging kreves før første Markdown-eksport. Download Claude conversations lagrer den verifiserte e-postadressen for å telle de 3 gratis eksportene og gjenopprette Pro etter en ny installasjon. Chatteksten lastes ikke opp for påloggingen. Slik virker det: slik fungerer det.

Mangler den oransje knappen, er du ikke på en samtale-URL, fanen må lastes inn på nytt etter installasjonen, eller utvidelsen er fortsatt skjult i puslebrikkemenyen i Chrome. Fest Download Claude conversations og last claude.ai på nytt. Innholdsskriptet legges aldri inn i Claude Desktop eller Claude Code.

Én chat eller mange. Den oransje knappen eksporterer den åpne samtalen som Markdown. For mange .md-filer åpner du «View and Download All Conversations» (Se og last ned alle samtaler) og kjører «Export All» (Eksporter alle) med Markdown valgt – se masseeksport med Export All.

Hvorfor eksportere Claude-chat til Markdown for notater?

Velg Markdown når du skal lese filen i Obsidian, en GitHub-wiki eller en editor som viser overskrifter og kodeblokker. .md-filen er fortsatt ren tekst du kan søke i og sammenligne med diff. JSON passer bedre for parsere; PNG er et bilde du ikke kan søke i med grep.

Kopier og lim inn fra claude.ai mister som regel innrykk og gjør tabeller flate. Utskrift (Ctrl/Cmd+P) tar med sidefeltet og deler ofte en lang kodeblokk over flere sider. Når du eksporterer til Markdown, blir språkmerkene på kodeblokkene stående, og tabeller forblir tabeller. Derfor velger skribenter dette formatet først.

Vi behandler Markdown som standardfilen for mennesker: overskrifter, kodeblokker med språkmerker og tabeller fra claude.ai-samtalen. Vi finner fortsatt ikke opp et PDF-format – trenger du en utskriftsvennlig side, bruker du utskriftsdialogen i Chrome etter Markdown-eksporten eller i stedet for den.

Hva beholder Markdown-eksporten?

Når du eksporterer Claude-chat til Markdown, beholder Download Claude conversations overskrifter, kodeblokker med språkmerker og innrykk, tabeller og lenker. Tenkeblokker er valgfrie. Metadata (tittel, tidsstempler, modell) kan følge med. Avsenderfilteret kan begrense .md-filen til alle meldinger, bare menneske eller bare assistent («all / human only / assistant only»).

Oppsett for artefakter er en ekte bryter i versjon 1.13.0: «Original», «Inline» (innebygd), «Nested» (nestet) eller «Flat» (flatt). En Markdown-eksport kan speile artefaktstrukturen på skjermen eller gjøre den om til ett lineært dokument. Hele listen med brytere: funksjoner i Chrome-utvidelsen. Markdown beholder ikke fargene på meldingsboblene; bruk PNG hvis du trenger et visuelt øyeblikksbilde.

Er samtalen svært lang, blar du til claude.ai har lastet inn de tidligere meldingene før du eksporterer. Utvidelsen kan bare skrive det siden har vist. En halvveis innlastet samtale gir en halvveis .md-fil. Det ser ut som en feil, men skyldes som regel en DOM du ikke har bladd gjennom.

Kan jeg eksportere Claude-chat til Markdown i bulk?

Ja. Åpne «View and Download All Conversations», sett formatet til Markdown, filtrer tabellen og klikk Export All. Hver ferdige .md-fil er én eksport av de samme 3 gratis eksportene som en kjøring med den oransje knappen. Pro til 3,99 $/mnd. eller 26,99 $/år fjerner grensen for Markdown i bulk.

Tabellen viser claude.ai-historikken med søk på navn og filtrene «All», «New», «Exported» og «Project» (Alle, Nye, Eksportert, Prosjekt). New betyr ikke eksportert ennå med Download Claude conversations. Exported holder styr på chatter du allerede har lagret, slik at neste Export All kan hoppe over dem. Project følger måten du grupperer chatter på i claude.ai.

Kvoten gjelder hele kontoen. Tre gratis eksporter totalt – ikke tre Markdown-filer per dag. Velger du 40 samtaler, bruker du 40 eksporter hvis alle .md-filene fullføres. Planlegg utvalget før du klikker Export All.

Markdown i bulk bruker de samme bryterne for tenkning, metadata, avsender og artefakter som én samtale. Export All er ikke Anthropics forsinkede ZIP-fil. Det er mange .md-filer, én per chat. Ville du ha ett arkiv med hele kontoen, er det Settings → Privacy → Export data (etikettene kan være oversatt hvis claude.ai er satt til norsk), og det er JSON, ikke Markdown.

Markdown eller JSON når jeg eksporterer en Claude-chat?

Velg Markdown når et menneske skal lese filen. Velg JSON når et skript skal lese meldingstreet. Download Claude conversations har begge i samme nedtrekksliste, pluss ren tekst, XML og PNG. Det finnes fortsatt ingen PDF. Formatoversikt: eksportformater for Claude-chat.

Markdown sammenlignet med de andre eksportfilene fra claude.ai
Format Velg det når
Markdown Notater, Obsidian, GitHub, wikier
JSON Diff, pipelines, verktøy – JSON-guide
Ren tekst Ingen markup, arkiv du kan lime inn hvor som helst
XML Et system som krever XML
PNG Et bilde av samtalen, ikke søkbar tekst

Anthropics Export data er også JSON, men det er en ZIP-fil for kontoen på e-post, ikke en .md-fil per chat. Du kan ikke velge Markdown i den forespørselen. Skriv ut → Lagre som PDF er et øyeblikksbilde av nettsiden. Ingen av dem erstatter Markdown-eksporten fra den oransje knappen.

Utvidelsen kjører bare på claude.ai i Chrome. Claude Desktop og Claude Code får ingen Markdown-knapp. Finnes samtalen også på claude.ai, åpner du den der og eksporterer til Markdown. /export i Claude Code er en annen produktvei.

Koster det ekstra å eksportere Claude-chat til Markdown?

Nei. Markdown er med i de 3 gratis eksportene hver konto som er logget på med Google får, akkurat som JSON, tekst, XML og PNG. Etter de tre filene koster Pro 3,99 $ per måned eller 26,99 $ per år via Paddle. Download Claude conversations tar ikke tillegg for Markdown.

De 3 gratis eksportene nullstilles ikke når du installerer utvidelsen på nytt. Derfor kreves Google-pålogging første gang du eksporterer til Markdown. Pro gjenopprettes på en ny datamaskin med samme Google-konto. Paddle er selger (merchant of record); teamet vårt ser aldri kortnumre.

Du trenger ikke et betalt claude.ai-abonnement fra Anthropic. Du trenger en innlogging som kan laste inn samtalen i Chrome. Team og Enterprise fungerer som Free med den oransje knappen. Versjon 1.13.0 fra september 2026 skriver fortsatt ikke Word, Notion eller PDF.

Vanlige spørsmål: eksportere Claude-chat til Markdown

Disse spørsmålene dekker Markdown-eksport i Download Claude conversations 1.13.0: kodeblokker, masseeksport med Export All, Anthropics ZIP-fil, kvote og Desktop. Hvert svar er et produktfaktum. FAQPage-JSON-LD i sidehodet samsvarer med denne listen.

Mister jeg kode når jeg eksporterer Claude-chat til Markdown?

Nei. Kodeblokker beholder språkmerke og innrykk, i motsetning til vanlig kopier og lim inn fra claude.ai. Tabeller forblir Markdown-tabeller. Det er hovedgrunnen til å eksportere til Markdown i stedet for å markere tekst for hånd.

Kan jeg eksportere Claude-chat til Markdown i bulk?

Ja. Export All på oversiktssiden støtter Markdown på samme måte som eksport av én chat. Hver ferdige .md-fil teller som én av de 3 gratis eksportene, med mindre du har Pro.

Er Markdown det samme som Anthropics Export data?

Nei. Anthropics offisielle eksport er en JSON-ZIP for hele kontoen, sendt på e-post etter en ventetid. Markdown-eksporten er en .md-fil per chat (eller per utvalg) fra Download Claude conversations.

Koster Markdown mer enn andre formater?

Nei. Markdown er med i de 3 gratis eksportene på alle kontoer som er logget på med Google, akkurat som JSON, tekst, XML og PNG. Deretter koster Pro 3,99 $/mnd. eller 26,99 $/år for ubegrenset antall filer.

Kan jeg eksportere Claude-chat til Markdown i Desktop?

Nei. Download Claude conversations legges bare inn på claude.ai i Chrome. Claude Desktop viser aldri nedtrekkslisten for Markdown. Åpne samme samtale på claude.ai hvis den finnes der.

Lager Markdown-eksporten en PDF?

Nei. Markdown er en .md-tekstfil. Produktet leverer ikke PDF. For en utskriftsvennlig side bruker du utskriftsdialogen i Chrome. PNG er et bilde, heller ikke PDF.

Trenger jeg Pro for å eksportere til Markdown én gang?

Nei. De første 3 eksportene er gratis, i valgfritt format, også Markdown. Pro til 3,99 $/mnd. eller 26,99 $/år fjerner grensen for flere .md-filer, enkeltvis eller i bulk.
