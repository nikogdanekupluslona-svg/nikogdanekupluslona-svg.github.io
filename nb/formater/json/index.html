Hvordan eksporterer jeg en Claude-samtale som JSON?

Åpne samtalen på claude.ai i Chrome, klikk den oransje knappen ved siden av meldingsfeltet, velg JSON og klikk «Export». Download Claude conversations skriver filen lokalt. Slik eksporterer du en Claude-samtale som JSON i versjon 1.16.2. claude.ai har ingen egen knapp for å lagre én chat som JSON per september 2026.

  1. Installer Download Claude conversations fra Chrome Web Store.
  2. Last inn claude.ai på nytt og åpne en ekte samtale-URL, ikke den tomme startsiden med skrivefeltet.
  3. Klikk den oransje nedlastingsknappen til høyre for meldingsfeltet.
  4. Velg JSON. Sist brukte format huskes. Med «Select» (velg) krysser du av bare meldingene du vil ha med.
  5. Klikk «Export». Chrome laster ned JSON-filen via nettleserens nedlastings-API. Eller klikk «Copy» (Kopier) for å legge JSON-teksten på utklippstavlen.

Du trenger ingen pålogging for å eksportere en Claude-samtale som JSON. JSON-eksport av én chat er ubegrenset, anonym og sender ingenting til serverne våre. Google-pålogging kreves bare for PDF og masseeksport med «Export All» (Eksporter alle). Slik virker det: slik fungerer det.

Mangler den oransje knappen, er du ikke på en samtale-URL, fanen må lastes inn på nytt, eller utvidelsen er skjult i puslebrikkemenyen i Chrome. Fest Download Claude conversations og last claude.ai på nytt. Innholdsskriptet legges aldri inn i Claude Desktop eller i Claude Code i terminalen.

Én samtale eller mange filer. Den oransje knappen eksporterer den åpne chatten som JSON. For mange JSON-filer åpner du «View and Download All Conversations» (Se og last ned alle samtaler) og kjører Export All med JSON valgt: én ZIP-fil, 3 chatter om dagen på gratisplanen – se masseeksport med Export All.

Når bør jeg eksportere en Claude-samtale som JSON?

Velg JSON når et skript, en indekserer eller et diff-verktøy skal lese filen. JSON-filen er bygd for meldingstreet, ikke for lesing i Obsidian. Vil du ha overskrifter og kodeblokker for mennesker, velger du heller Markdown. Til et regneark velger du CSV: én rad per melding.

Kopier og lim inn fra claude.ai mister strukturen for hvem som sa hva. Utskrift tar med nettsidens grensesnitt. Når du eksporterer som JSON, beholder Download Claude conversations replikker, avsendere og valgfri tenkning som data, ikke som ett flatt avsnitt. Derfor velger utviklere JSON fremfor ren tekst.

Vi skriver JSON fra claude.ai-treet som allerede ligger på siden – avsender, innholdsblokker, tidsstempler, modellmetadata – uten å laste opp samtalen. Denne JSON-filen er ikke Anthropics ZIP-fil for kontoen. I versjon 1.16.2 er den ett av sju formater, ved siden av PDF og CSV, og den er gratis uten konto.

Hva inneholder en JSON-eksport av en Claude-samtale?

En JSON-eksport av en Claude-samtale speiler meldingstreet på claude.ai: avsender, innholdsblokker, tidsstempler og modellmetadata. Tenkeblokker, kilder fra nettsøk, verktøy-/MCP-trinn og artefakter tas med når de valgene er på: «Thinking» (tenkning) er en avkrysningsboks i eksportpanelet, og verktøy og kilder slår du på i innstillingene. Avsenderfilteret kan begrense filen til alle meldinger, bare menneske eller bare assistent («All / Human / Assistant»). Ingenting gjøres om til Markdown først.

Oppsettet for artefakter i versjon 1.16.2 er «Original», «Inline» (innebygd), «Nested» (nestet) eller «Flat» (flatt). Oppsettene styrer hvordan artefaktinnholdet nestes i JSON – de samme fire valgene som for Markdown og XML. Hele listen: funksjoner i Chrome-utvidelsen. Vil du ha sider i stedet for data, eksporterer du PDF.

JSON-eksport av Claude-samtale eller Anthropics Export data?

Begge er JSON, men med ulik form og omfang. Anthropic Settings → Privacy → Export data (etikettene kan være oversatt hvis claude.ai er satt til norsk) sender deg én ZIP-fil med hele kontoen på e-post etter en ventetid. Når du eksporterer en Claude-samtale som JSON her, får du én samtale med en gang i Chrome. Bruk ZIP-filen som sikkerhetskopi.

Du kan ikke velge Markdown i Anthropics ZIP-forespørsel. Du kan heller ikke bruke JSON fra denne utvidelsen som direkte erstatning for ZIP-skjemaet. Formatoversikt: eksportformater for Claude-chat. PDF er for lesing, ikke en JSON-eksport.

Download Claude conversations er ikke tilknyttet Anthropic, PBC. Innholdsskriptet bruker økten du allerede har åpnet på claude.ai. Det logger ikke inn hos Anthropic med egne påloggingsdetaljer. Følg Anthropics regler for kontoen din.

Kan jeg eksportere Claude-samtaler som JSON i bulk?

Ja. Åpne «View and Download All Conversations», sett «Chat format» (chatformat) til JSON, filtrer listen og klikk Export All. Chrome lagrer én ZIP-fil med én JSON-fil per chat. På gratisplanen er det 3 chatter om dagen med Google-pålogging, delt med PDF. Pro til 3,99 $ i måneden eller 26,99 $ i året fjerner grensen for JSON i bulk.

Oversiktssiden (Dashboard) viser claude.ai-historikken med søk på navn, filtrene «All conversations», «New», «Updated» og «Previously exported» (alle samtaler, nye, oppdaterte, eksportert tidligere), fanene Chat og Cowork og prosjektsøk. New betyr ikke eksportert ennå med Download Claude conversations. Previously exported holder styr på chatter du allerede har lagret. Export All gir én ZIP-fil med JSON-filer per chat, ikke et arkiv med blandede formater.

Den daglige grensen gjelder per konto. Tre chatter om dagen på gratisplanen, delt med PDF. Velger du 40 samtaler og har 3 igjen, blokkeres hele kjøringen – den kuttes ikke av. Velg færre, eller bruk Pro. Enkeltvise JSON-eksporter fra den oransje knappen er fortsatt ubegrenset.

Du kan sammenligne to JSON-eksporter av samme claude.ai-samtale tatt på ulike tidspunkter, slik du ville sammenlignet hvilken som helst JSON-fil med diff. Hver eksport er selvstendig. En ny Export All av de samme chattene teller hver chat på nytt.

Krever JSON-eksport av Claude-samtaler Pro?

Nei. JSON-eksport av én chat er gratis og ubegrenset, uten konto og uten teller – akkurat som Markdown, tekst, XML, CSV og PNG. Bare PDF og masseeksport med Export All har en grense på gratisplanen: 3 om dagen med Google-pålogging. Pro koster 3,99 $ i måneden eller 26,99 $ i året via Paddle. Download Claude conversations tar ikke ekstra betalt for JSON-eksport.

Det er JSON i bulk som møter grensen. Hver chat i en ZIP-fil fra Export All bruker én av de 3 om dagen, og tellingen nullstilles ved midnatt UTC. Pro fjerner grensen og gjenopprettes på en ny datamaskin med samme Google-konto. Paddle er selger (merchant of record); teamet vårt ser aldri kortnumre.

Utvidelsen kjører bare på claude.ai i Chrome. Claude Desktop og Claude Code i terminalen får ingen JSON-knapp; Claude Code på nettet (claude.ai/code) kjører på claude.ai, så det eksporteres som en hvilken som helst chat. /export i Claude Code i terminalen eller JSONL på disken er en annen vei. Versjon 1.16.2 fra september 2026 skriver fortsatt ikke Word eller Notion.

Vanlige spørsmål: eksportere Claude-samtale som JSON

Disse spørsmålene dekker JSON-eksport i Download Claude conversations 1.16.2: masseeksport med Export All, skjema, pris, diff, Anthropics ZIP-fil, PDF og Desktop. Hvert svar er et produktfaktum. FAQPage-JSON-LD i sidehodet samsvarer med denne listen.

Kan jeg eksportere Claude-samtaler som JSON i bulk?

Ja. Export All på oversiktssiden støtter JSON og lagrer én ZIP-fil med én JSON-fil per chat. På gratisplanen dekker den 3 chatter om dagen med Google-pålogging; Pro til 3,99 $ i måneden eller 26,99 $ i året er ubegrenset.

Er JSON-strukturen dokumentert?

Den speiler claude.ai sitt eget meldingstre: avsender, innholdsblokker, tidsstempler og modellmetadata, med artefakter, tenkeblokker, kilder fra nettsøk og verktøy-/MCP-trinn når du slår på de valgene. Det er ikke skjemaet i Anthropics ZIP-fil for kontoen.

Trenger jeg Pro for å eksportere en Claude-samtale som JSON?

Nei. JSON-eksport av én chat er ubegrenset og krever ingen konto, akkurat som alle andre formater unntatt PDF. Pro til 3,99 $ i måneden eller 26,99 $ i året fjerner bare grensen på 3 om dagen for PDF og masseeksport med Export All.

Kan jeg sammenligne to JSON-eksporter av én chat?

Ja. Hver gang du eksporterer en Claude-samtale som JSON, får du en selvstendig fil bygd på samme måte. Å sammenligne to eksporter av samme samtale fra ulike tidspunkter fungerer som diff av hvilken som helst annen JSON-fil.

Er denne JSON-filen det samme som Anthropics Export data?

Nei. Anthropics Export data er en forsinket ZIP-fil med hele kontoen. Download Claude conversations skriver en JSON-fil per chat (eller per utvalg) med en gang i Chrome. Begge kan være JSON, men de kan ikke byttes ut med hverandre.

Lager JSON-eksporten en PDF?

Nei. JSON er strukturerte data. Vil du ha sider, velger du PDF i samme panel; de sju formatene er PDF, Markdown, JSON, ren tekst, XML, CSV og PNG. PDF krever Google-pålogging og teller mot 3 om dagen på gratisplanen.

Fungerer JSON-eksport i Claude Desktop?

Nei. Chrome-utvidelsen legges bare inn på claude.ai. Claude Desktop viser aldri JSON-valget. Åpne samme samtale på claude.ai i Chrome hvis den finnes der.
