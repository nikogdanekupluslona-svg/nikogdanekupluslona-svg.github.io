Hvordan eksporterer jeg en Claude-samtale som JSON?

Åpne samtalen på claude.ai i Chrome, klikk den oransje knappen ved siden av meldingsfeltet, velg JSON og klikk «Export». Download Claude conversations skriver filen lokalt. Slik eksporterer du en Claude-samtale som JSON i versjon 1.13.0. claude.ai har ingen egen knapp for å lagre én chat som JSON per september 2026.

  1. Installer Download Claude conversations fra Chrome Web Store (oppføringen er vurdert til 5.0).
  2. Last inn claude.ai på nytt og åpne en ekte samtale-URL, ikke den tomme startsiden med skrivefeltet.
  3. Klikk den oransje nedlastingsknappen til høyre for meldingsfeltet.
  4. Velg JSON. Sist brukte format huskes.
  5. Klikk «Export». Chrome laster ned JSON-filen via nettleserens nedlastings-API.

Google-pålogging kreves før første JSON-eksport. Download Claude conversations lagrer den verifiserte e-postadressen for å telle de 3 gratis eksportene og gjenopprette Pro etter en ny installasjon. Selve chatteksten er ikke en del av påloggingen. Slik virker det: slik fungerer det.

Mangler den oransje knappen, er du ikke på en samtale-URL, fanen må lastes inn på nytt, eller utvidelsen er skjult i puslebrikkemenyen i Chrome. Fest Download Claude conversations og last claude.ai på nytt. Innholdsskriptet legges aldri inn i Claude Desktop eller Claude Code.

Én samtale eller mange filer. Den oransje knappen eksporterer den åpne chatten som JSON. For mange JSON-filer åpner du «View and Download All Conversations» (Se og last ned alle samtaler) og kjører «Export All» (Eksporter alle) med JSON valgt – se masseeksport med Export All.

Når bør jeg eksportere en Claude-samtale som JSON?

Velg JSON når et skript, en indekserer eller et diff-verktøy skal lese filen. JSON-filen er bygd for meldingstreet, ikke for lesing i Obsidian. Vil du ha overskrifter og kodeblokker for mennesker, velger du heller Markdown.

Kopier og lim inn fra claude.ai mister strukturen for hvem som sa hva. Utskrift tar med nettsidens grensesnitt. Når du eksporterer som JSON, beholder Download Claude conversations replikker, avsendere og valgfri tenkning som data, ikke som ett flatt avsnitt. Derfor velger utviklere JSON fremfor ren tekst.

Vi skriver JSON fra claude.ai-treet som allerede ligger på siden – avsender, innholdsblokker, tidsstempler, modellmetadata – uten å laste opp samtalen. Denne JSON-filen er ikke Anthropics ZIP-fil for kontoen, og den er ikke PDF. Versjon 1.13.0 leverer fortsatt bare fem formater.

Hva inneholder en JSON-eksport av en Claude-samtale?

En JSON-eksport av en Claude-samtale speiler meldingstreet på claude.ai: avsender, innholdsblokker, tidsstempler og modellmetadata. Tenkeblokker og artefakter tas med når de bryterne er på. Avsenderfilteret kan begrense filen til alle meldinger, bare menneske eller bare assistent («all / human only / assistant only»). Ingenting gjøres om til Markdown først.

Oppsettet for artefakter i versjon 1.13.0 er «Original», «Inline» (innebygd), «Nested» (nestet) eller «Flat» (flatt). Oppsettene styrer hvordan artefaktinnholdet nestes i JSON – de samme fire valgene som for Markdown og XML. Hele listen med brytere: funksjoner i Chrome-utvidelsen. JSON blir fortsatt ikke til PDF.

JSON-eksport av Claude-samtale eller Anthropics Export data?

Begge er JSON, men med ulik form og omfang. Anthropic Settings → Privacy → Export data (etikettene kan være oversatt hvis claude.ai er satt til norsk) sender deg én ZIP-fil med hele kontoen på e-post etter en ventetid. Når du eksporterer en Claude-samtale som JSON her, får du én samtale med en gang i Chrome. Bruk ZIP-filen som sikkerhetskopi.

Du kan ikke velge Markdown i Anthropics ZIP-forespørsel. Du kan heller ikke bruke JSON fra denne utvidelsen som direkte erstatning for ZIP-skjemaet. Formatoversikt: eksportformater for Claude-chat. Utskrift er en visuell nødløsning, ikke en JSON-eksport.

Download Claude conversations er ikke tilknyttet Anthropic, PBC. Innholdsskriptet bruker økten du allerede har åpnet på claude.ai. Det logger ikke inn hos Anthropic med egne påloggingsdetaljer. Følg Anthropics regler for kontoen din.

Kan jeg eksportere Claude-samtaler som JSON i bulk?

Ja. Åpne «View and Download All Conversations», sett formatet til JSON, filtrer tabellen og klikk Export All. Hver ferdige fil er én av de 3 gratis eksportene. Pro til 3,99 $/mnd. eller 26,99 $/år fjerner grensen for JSON i bulk.

Tabellen viser claude.ai-historikken med søk på navn og filtrene «All», «New», «Exported» og «Project» (Alle, Nye, Eksportert, Prosjekt). New betyr ikke eksportert ennå med Download Claude conversations. Exported holder styr på chatter du allerede har lagret. Project følger måten du grupperer chatter på i claude.ai. Export All gir mange JSON-filer, ikke én blandet ZIP-fil.

Kvoten gjelder hele kontoen. Tre gratis eksporter totalt – ikke tre JSON-filer per masseeksport. Velger du 40 samtaler, bruker du 40 eksporter hvis alle filene fullføres. Planlegg utvalget, eller bruk Pro.

Du kan sammenligne to JSON-eksporter av samme claude.ai-samtale tatt på ulike tidspunkter, slik du ville sammenlignet hvilken som helst JSON-fil med diff. Hver eksport er selvstendig. En ny Export All av de samme chattene bruker fortsatt kvote, med mindre filene ikke fullføres.

Krever JSON-eksport av Claude-samtaler Pro?

Nei. JSON er med i de 3 gratis eksportene hver konto som er logget på med Google får, akkurat som Markdown, tekst, XML og PNG. Etter de tre filene koster Pro 3,99 $ per måned eller 26,99 $ per år via Paddle. Download Claude conversations tar ikke ekstra betalt for JSON-eksport.

De 3 gratis eksportene nullstilles ikke når du installerer utvidelsen på nytt. Derfor kreves Google-pålogging ved første klikk på Export. Pro gjenopprettes på en ny datamaskin med samme Google-konto. Paddle er selger (merchant of record); teamet vårt ser aldri kortnumre.

Utvidelsen kjører bare på claude.ai i Chrome. Claude Desktop og Claude Code får ingen JSON-knapp. /export i Claude Code eller JSONL på disken er en annen vei. Versjon 1.13.0 fra september 2026 skriver fortsatt ikke PDF, Word eller Notion.

Vanlige spørsmål: eksportere Claude-samtale som JSON

Disse spørsmålene dekker JSON-eksport i Download Claude conversations 1.13.0: masseeksport med Export All, skjema, kvote, diff, Anthropics ZIP-fil og Desktop. Hvert svar er et produktfaktum. FAQPage-JSON-LD i sidehodet samsvarer med denne listen.

Kan jeg eksportere Claude-samtaler som JSON i bulk?

Ja. Export All på oversiktssiden støtter JSON på samme måte som en enkelteksport. Hver ferdige fil teller som én av de 3 gratis eksportene, med mindre du har Pro til 3,99 $/mnd. eller 26,99 $/år.

Er JSON-strukturen dokumentert?

Den speiler claude.ai sitt eget meldingstre: avsender, innholdsblokker, tidsstempler og modellmetadata, med artefakter og tenkeblokker når du slår på de bryterne. Det er ikke skjemaet i Anthropics ZIP-fil for kontoen.

Trenger jeg Pro for å eksportere en Claude-samtale som JSON?

Nei. JSON er med i de 3 gratis eksportene hver konto som er logget på med Google får, akkurat som alle andre formater. Etter de tre filene koster Pro 3,99 $/mnd. eller 26,99 $/år.

Kan jeg sammenligne to JSON-eksporter av én chat?

Ja. Hver gang du eksporterer en Claude-samtale som JSON, får du en selvstendig fil bygd på samme måte. Å sammenligne to eksporter av samme samtale fra ulike tidspunkter fungerer som diff av hvilken som helst annen JSON-fil.

Er denne JSON-filen det samme som Anthropics Export data?

Nei. Anthropics Export data er en forsinket ZIP-fil med hele kontoen. Download Claude conversations skriver en JSON-fil per chat (eller per utvalg) med en gang i Chrome. Begge kan være JSON, men de kan ikke byttes ut med hverandre.

Lager JSON-eksporten en PDF?

Nei. JSON er strukturerte data. Produktets formater er Markdown, JSON, ren tekst, XML og PNG. For en utskriftsvennlig side bruker du utskriftsdialogen i Chrome, ikke denne nedtrekkslisten.

Fungerer JSON-eksport i Claude Desktop?

Nei. Chrome-utvidelsen legges bare inn på claude.ai. Claude Desktop viser aldri JSON-valget. Åpne samme samtale på claude.ai i Chrome hvis den finnes der.
