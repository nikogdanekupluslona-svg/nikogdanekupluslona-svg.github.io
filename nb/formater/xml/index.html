Hvordan eksporterer jeg en Claude-chat til XML?

Åpne samtalen på claude.ai i Chrome, klikk den oransje knappen ved siden av meldingsfeltet, velg XML og klikk «Export». Download Claude conversations skriver filen lokalt. Slik eksporterer du en Claude-chat til XML i versjon 1.16.2. claude.ai har ingen innebygd knapp for å lagre som XML per september 2026.

  1. Installer Download Claude conversations fra Chrome Web Store.
  2. Last inn claude.ai på nytt og åpne en ekte samtale-URL, ikke den tomme startsiden med skrivefeltet.
  3. Klikk den oransje nedlastingsknappen til høyre for meldingsfeltet.
  4. Velg XML. Sist brukte format huskes. Med «Select» (velg) krysser du av bare meldingene du vil ha med.
  5. Klikk «Export». Chrome laster ned XML-filen via nettleserens nedlastings-API. Eller klikk «Copy» (Kopier) for å legge XML-teksten på utklippstavlen.

Du trenger ingen pålogging for å eksportere en Claude-chat til XML. XML-eksport av én chat er ubegrenset, anonym og sender ingenting til serverne våre. Google-pålogging kreves bare for PDF og masseeksport med «Export All» (Eksporter alle). Slik virker det: slik fungerer det.

Mangler den oransje knappen, er du ikke på en samtale-URL, fanen må lastes inn på nytt, eller utvidelsen er skjult i puslebrikkemenyen i Chrome. Fest Download Claude conversations og last claude.ai på nytt. XML-eksport dukker aldri opp i Claude Desktop eller i Claude Code i terminalen.

Én fil eller mange. Den oransje knappen eksporterer den åpne samtalen som XML. For mange XML-filer åpner du «View and Download All Conversations» (Se og last ned alle samtaler) og kjører Export All med XML valgt: én ZIP-fil, 3 chatter om dagen på gratisplanen – se masseeksport med Export All.

Når bør jeg eksportere en Claude-chat til XML?

Velg XML når mottakersystemet, pipelinen eller et eldre verktøy krever XML for strukturert datautveksling. De fleste utviklere bør heller velge JSON. Markdown er for notater til mennesker. CSV er for regneark. PNG er et bilde. XML står i nedtrekkslisten fordi noen verktøy fortsatt leser XML og ikke godtar JSON.

Ikke velg XML som en «mer offisiell» JSON. Download Claude conversations leser samtalen på samme måte uansett. Forskjellen er filens form, ikke ekstra felt som plutselig dukker opp. Krever ingenting du bruker XML, hopper du over formatet og bruker JSON.

Vi leverer XML fordi noen pipelines fortsatt krever det, ikke fordi vi mener det slår JSON for alle eksporter fra claude.ai. Lesingen er den samme: meldinger, avsender, valgfri tenkning og artefakter. Versjon 1.16.2 har XML som ett av sju formater, gratis uten konto, ikke som et betalt tillegg.

Hva beholder XML-eksporten av en Claude-chat?

Når du eksporterer en Claude-chat til XML, skriver Download Claude conversations samtalestrukturen – meldinger, avsender og tilgjengelige metadata – som XML-markup. Tenkeblokker, kilder fra nettsøk, verktøy-/MCP-trinn og artefakter følger de samme valgene som i Markdown og JSON: «Thinking» (tenkning) er en avkrysningsboks i eksportpanelet, og verktøy og kilder slår du på i innstillingene. XML er ikke en nedstrippet slektning av disse formatene.

Oppsettet for artefakter er «Original», «Inline» (innebygd), «Nested» (nestet) eller «Flat» (flatt) i versjon 1.16.2. Avsenderfilteret kan begrense XML-filen til alle meldinger, bare menneske eller bare assistent («All / Human / Assistant»). Metadata (tittel, tidsstempler, modell) kan følge med. Hele listen med brytere: funksjoner i Chrome-utvidelsen.

XML eller JSON når jeg eksporterer en Claude-chat?

JSON er det vanlige valget for utviklere. Eksporter til XML bare når et system lenger ned i kjeden krever XML. Download Claude conversations gjør ikke XML «mer komplett» enn JSON. Begge kan ta med tenkning og artefakter. Ingen av dem er Anthropics ZIP-fil for kontoen. Formatoversikt: eksportformater for Claude-chat.

XML sammenlignet med de andre eksportfilene fra claude.ai
Format Velg det når
XML Et verktøy eller skjema krever XML
JSON Skript, diff, de fleste moderne pipelines
Markdown Notater som mennesker skal lese
Ren tekst Ingen markup
CSV Regneark, én rad per melding
PDF Lesing, utskrift, sending – PDF-guide
PNG Et bilde av samtalen

Anthropic Settings → Privacy → Export data (etikettene kan være oversatt hvis claude.ai er satt til norsk) er JSON (i en ZIP-fil), ikke XML. PDF fra samme panel er sider for mennesker, ikke markup. Ingen av dem erstatter XML-eksporten fra den oransje knappen. Ikke forvent at denne XML-filen følger et upublisert skjema fra Anthropic.

Utvidelsen kjører bare på claude.ai i Chrome. Claude Desktop og Claude Code i terminalen får ingen XML-knapp. Claude Code på nettet (claude.ai/code) kjører på claude.ai, så det eksporteres som en hvilken som helst chat. Finnes en samtale også på claude.ai, åpner du den der og eksporterer til XML. /export i Claude Code i terminalen er en annen produktvei.

Kan jeg eksportere Claude-chatter til XML i bulk?

Ja. Åpne «View and Download All Conversations», sett «Chat format» (chatformat) til XML, filtrer listen og klikk Export All. Chrome lagrer én ZIP-fil med én XML-fil per chat. På gratisplanen er det 3 chatter om dagen med Google-pålogging, delt med PDF. Pro til 3,99 $ i måneden eller 26,99 $ i året fjerner grensen for XML i bulk.

Oversiktssiden (Dashboard) viser claude.ai-historikken med søk på navn, filtrene «All conversations», «New», «Updated» og «Previously exported» (alle samtaler, nye, oppdaterte, eksportert tidligere), fanene Chat og Cowork og prosjektsøk. New betyr ikke eksportert ennå med Download Claude conversations. Previously exported holder styr på chatter du allerede har lagret. Export All gir én ZIP-fil med XML-filer per chat, ikke et arkiv med blandede formater.

Den daglige grensen gjelder per konto. Tre chatter om dagen på gratisplanen, delt med PDF. Velger du 40 samtaler og har 3 igjen, blokkeres hele kjøringen – den kuttes ikke av. Velg færre, eller bruk Pro. Enkeltvise XML-eksporter fra den oransje knappen er fortsatt ubegrenset.

Du kan ikke blande XML og JSON i ett klikk på Export All. Velg XML for den kjøringen. Kjør Export All på nytt med JSON hvis du trenger samme claude.ai-samtale i begge former; den andre kjøringen teller hver chat på nytt.

Krever XML-eksport av Claude-chatter Pro?

Nei. XML-eksport av én chat er gratis og ubegrenset, uten konto og uten teller – akkurat som Markdown, JSON, tekst, CSV og PNG. Bare PDF og masseeksport med Export All har en grense på gratisplanen: 3 om dagen med Google-pålogging. Pro koster 3,99 $ i måneden eller 26,99 $ i året via Paddle. Download Claude conversations behandler ikke XML som et format bare for betalende.

Det er XML i bulk som møter grensen. Hver chat i en ZIP-fil fra Export All bruker én av de 3 om dagen, og tellingen nullstilles ved midnatt UTC. Pro fjerner grensen og gjenopprettes på en ny datamaskin med samme Google-konto. Paddle er selger (merchant of record); teamet vårt ser aldri kortnumre.

Du trenger ikke et betalt claude.ai-abonnement fra Anthropic. Du trenger en innlogging som kan laste inn samtalen i Chrome. Versjon 1.16.2 fra september 2026 skriver fortsatt ikke Word eller Notion. Endres listen, oppdateres denne siden samme dag.

Vanlige spørsmål: eksportere Claude-chat til XML

Disse spørsmålene dekker XML-eksport i Download Claude conversations 1.16.2: sammenligning med JSON, masseeksport med Export All, pris, Desktop, PDF og Pro. Hvert svar er et produktfaktum. FAQPage-JSON-LD i sidehodet samsvarer med denne listen.

Er XML bedre enn JSON for eksport av Claude-chatter?

Ikke generelt. JSON er det vanligste valget for utviklere. Eksporter til XML når systemet ditt lenger ned i kjeden krever XML for strukturert datautveksling. Lesingen fra claude.ai er den samme; filens form er forskjellig.

Kan jeg masseeksportere Claude-chatter til XML?

Ja. Den samme Export All-flyten på oversiktssiden støtter XML og lagrer én ZIP-fil med én XML-fil per chat. På gratisplanen dekker den 3 chatter om dagen med Google-pålogging; Pro til 3,99 $ i måneden eller 26,99 $ i året er ubegrenset.

Er XML bare for betalende?

Nei. XML-eksport av enkeltchatter er ubegrenset og krever ingen konto, akkurat som Markdown, tekst, JSON, CSV og PNG. Bare PDF og masseeksport med Export All har en gratisgrense på 3 om dagen. Pro koster 3,99 $ i måneden eller 26,99 $ i året.

Samsvarer XML-eksporten med Anthropics ZIP-fil?

Nei. Anthropics Export data er en forsinket JSON-ZIP for hele kontoen. Download Claude conversations skriver en XML-fil per chat (eller per utvalg) med en gang i Chrome. De har ikke samme skjema.

Lager XML-eksporten en PDF?

Nei. XML er markup. Vil du ha sider, velger du PDF i samme panel; de sju formatene er PDF, Markdown, JSON, ren tekst, XML, CSV og PNG. PDF krever Google-pålogging og teller mot 3 om dagen på gratisplanen.

Kan jeg eksportere Claude-chat til XML i Desktop?

Nei. Chrome-utvidelsen legges bare inn på claude.ai. Claude Desktop viser aldri nedtrekkslisten for XML. Åpne samme samtale på claude.ai i Chrome hvis den finnes der.

Trenger jeg Pro for å eksportere til XML én gang?

Nei. Du trenger ingen konto i det hele tatt. XML-eksport av enkeltchatter er ubegrenset på gratisplanen. Pro til 3,99 $ i måneden eller 26,99 $ i året fjerner bare grensen på 3 om dagen for masseeksport med Export All og PDF.
