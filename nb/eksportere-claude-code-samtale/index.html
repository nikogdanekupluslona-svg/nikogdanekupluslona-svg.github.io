Hva er eksport fra Claude Code i terminalen?

Eksport fra Claude Code er kommandoen /export i en interaktiv CLI-økt. Anthropics dokumentasjon beskriver en meny for å kopiere den gjeldende samtalen eller lagre en ren tekstfil, der meldinger og verktøyutdata vises som lesbar tekst. Oppgir du et filnavn, hopper du over menyen og skriver rett til den filen.

Dette er ikke Markdown fra claude.ai, ikke JSON fra denne Chrome-utvidelsen og ikke PDF. Det er en ferdig gjengitt transkripsjon som et menneske skal lese. Anthropic sier at JSONL-loggen på disken er et annet, internt format beregnet på produktet, ikke et offentlig API for deg.

/export

Slik hopper du over spørsmålet og skriver en navngitt fil i gjeldende arbeidsmappe:

/export my-session

Anthropics dokumentasjon om økter er fasiten for flagg og filnavn; de endres mellom versjoner av Claude Code. Behandle blogger fra brukermiljøet som sekundærkilder. Samsvarer ikke teksten i dialogen for /export med det du ser, har du en annen versjon av CLI-en – bruk hjelpen i produktet, ikke et skjermbilde fra 2025.

For skript peker Anthropic på andre grensesnitt: claude -p med --output-format json eller stream-json, gjenopptak med økt-ID, hooks som mottar en transcript_path, eller Agent SDK. Det er utviklerflater i Claude Code. De er ikke Chrome-utvidelsen på dette nettstedet.

Lesbart eller strukturert. /export er transkripsjonen for mennesker. JSONL under prosjektmappen er loggen. JSON fra Chrome-utvidelsen er en tredje form, bygd bare fra en claude.ai-side. Ikke skriv én parser for alle tre.

Hvordan henter jeg en Claude Code-samtale fra disken?

Slik henter du en Claude Code-samtale fra disken: kopier JSONL-filen for økten fra prosjektmappen, eller kjør /export for en lesbar transkripsjon. Standardstien på macOS og Linux ligger under ~/.claude/projects/. På Windows er den %USERPROFILE%\.claude\projects. Filnavnene er økt-ID-er.

Navnet på prosjektmappen er arbeidsmappen der tegn som ikke er bokstaver eller tall, er byttet ut med bindestreker. Anthropic kutter svært lange konverterte navn og legger til en hash, slik at mappen holder seg innenfor filsystemets grenser. Finner du ikke mappen, startet du Claude Code fra en annen arbeidsmappe enn du tror.

Hver JSONL-linje er et JSON-objekt for en melding, et verktøykall eller metadata. Anthropic sier at dette formatet er internt og endres mellom versjoner. Skript som leser disse filene, kan slutte å virke ved en ny versjon av Claude Code. Foretrekk /export eller de dokumenterte skriptgrensesnittene når du trenger noe stabilt.

Lagringsstedet kan flyttes. CLAUDE_CONFIG_DIR flytter konfigurasjonstreet bort fra ~/.claude. CLAUDE_CODE_PROJECT_DIR_NAME gir prosjektmappen navn når den brukes sammen med den konfigurasjonsmappen (Claude Code v2.1.234 eller nyere, ifølge Anthropic). cleanupPeriodDays i settings.json endrer standard oppbevaringstid. Ingen av disse innstillingene er funksjoner i Download Claude conversations.

For å ta sikkerhetskopi av Claude Code-samtaler kopierer du altså mappen, eller eksporterer transkripsjoner med /export jevnlig. Dette nettstedet kommer ikke til å legge til en knapp for å «importere JSONL». Vi leser ikke hjemmemappen din.

Fungerer eksport fra Claude Code med denne utvidelsen?

Nei. Eksport av Claude Code-samtaler fungerer ikke med Download Claude conversations. Chrome-utvidelsen legges inn i claude.ai. Den ser ikke terminalen, kan ikke kjøre /export og kan ikke åpne JSONL. Søkte du etter hvordan du laster ned en Claude Code-samtale, holder du deg til CLI-trinnene på denne siden.

Folk havner her fordi Google grupperer «Claude» og «eksport». Oppføringen i Web Store gjelder fortsatt bare claude.ai. Å installere utvidelsen gir ingen oransje knapp i iTerm, Ghostty, terminalen i VS Code eller skrivebordsinnpakningen til Claude Code.

Har du også en parallell samtale på claude.ai for den samme kodejobben, kan den nettleserchatten lagres med utvidelsen. De to sporene slås ikke sammen. Verktøykall som bare skjedde i CLI-en, dukker ikke opp i eksporten fra nettet med mindre du limte dem inn der.

Vi får den samme supporthenvendelsen hver uke: noen har installert Chrome-utvidelsen og ventet at /export skulle dukke opp. Vi leser bare claude.ai. Claude Code har allerede /export og JSONL. Å pakke inn CLI-en ville vært et annet produkt, og det har vi ikke lansert.

Hvor lagrer Claude Code samtalehistorikken?

Claude Code lagrer samtalehistorikken som JSONL-transkripsjoner i prosjektmappen under konfigurasjonsmappen. Standard på macOS og Linux: ~/.claude/projects/<encoded-cwd>/<session-id>.jsonl. Windows bruker %USERPROFILE%\.claude\projects. Anthropic kan endre oppsettet; sjekk den gjeldende dokumentasjonen om økter hvis en sti mangler på disken.

Å gjenoppta er noe annet enn å eksportere. claude --continue og claude --resume laster inn en økt på nytt, så du kan jobbe videre. /export skriver en kopi du kan legge i git eller sende på e-post. Det ene gjenoppretter konteksten. Det andre gir deg et dokument å ta med. Anthropics side om økter dekker tillatelsesmodus ved gjenopptak, komprimering/oppsummering og velgeren – ingenting av det gjelder denne utvidelsen.

Skrivebordsappen, Claude Code på nettet og VS Code-utvidelsen har hver sin økthistorikk, ifølge Anthropic. Stiene i denne guiden gjelder CLI-en. Ikke gå ut fra at en Cowork-transkripsjon fra Desktop ligger i det samme JSONL-treet som du bruker fra terminalen.

Ikke behandle JSONL som et offentlig skjema. Anthropic sier at linjeformatet endres. Leser du det likevel, lås versjonen av Claude Code og regn med at det brekker. /export er den stabile måten å få en lesbar Claude Code-samtale på.

Miljøvariabler som CLAUDE_CODE_SKIP_PROMPT_HISTORY kan hindre at transkripsjoner skrives. Er prosjektmappen tom, sjekker du om du har slått av lagring, pekt CLAUDE_CONFIG_DIR et annet sted, eller aldri har kjørt en interaktiv økt i den mappen.

Hvordan laster jeg ned en Claude-chat på claude.ai i stedet?

Slik laster du ned en Claude-chat på claude.ai: installer Download Claude conversations, åpne samtalen i Chrome, klikk den oransje knappen og velg Markdown, JSON, tekst, XML eller PNG. Det er nettleserproduktet. Det er ikke eksport fra Claude Code. Trinn for trinn: slik laster du ned en Claude-chat.

Hele claude.ai-historikken som separate filer får du med «Export All» (Eksporter alle) på oversiktssiden, ikke med /export. Hver fil teller mot 3 gratis eksporter, med mindre du har Pro. Guide: masseeksport med Export All. Formater: formater.

Google-pålogging kreves ved første eksport fra claude.ai, slik at vi kan telle kvoten og gjenopprette Pro. Filene bygges lokalt. Paddle fakturerer Pro til 3,99 $/mnd. eller 26,99 $/år. Ingenting av dette gjelder /export i terminalen.

Begynte arbeidet i Claude Code og du limte et sammendrag inn i claude.ai, laster du ned nettsamtalen som notater og beholder /export som den ekte CLI-loggen. To filer er bedre enn én forvirret fil.

Eksport fra Claude Code eller Anthropics offisielle Export data?

Eksport fra Claude Code (/export eller JSONL) er én terminaløkt. Den offisielle Export data er Settings → Privacy → Export data på claude.ai (etikettene kan være oversatt hvis claude.ai er satt til norsk): en forsinket JSON-ZIP med Anthropic-kontoen. Det er ikke det samme arkivet. ZIP-filen erstatter ikke /export.

Om en bestemt Claude Code-økt havner i ZIP-filen for kontoen, avhenger av hvordan Anthropic lagrer det produktet, ikke av denne utvidelsen. Behandle ZIP-filen som en sikkerhetskopi av nettkontoen, med mindre Anthropics gjeldende personverndokumentasjon sier noe annet. Vi legger ikke CLI-økter inn i den ZIP-filen.

Hvordan du eksporterer en Claude-chat fra nettstedet, inkludert ZIP-filen sammenlignet med utvidelsen, står her: slik eksporterer du en Claude-chat. Utskrift til PDF av en nettside gjelder ikke et terminalgrensesnitt. Se utskrift / PDF bare når samtalen er i nettleseren.

Claude Code, Desktop eller claude.ai – hvilken eksport?

Claude Code, Claude Desktop og claude.ai er tre ulike flater. Eksport fra Claude Code bruker /export og JSONL. Desktop er en app uten den oransje knappen fra denne utvidelsen. claude.ai i Chrome er det eneste stedet Download Claude conversations kjører. Blander du navnene, feiler eksporten i det stille.

Claude Desktop: er chatten synkronisert til samme Anthropic-konto, åpner du den på claude.ai og eksporterer der. Finnes den bare i Desktop-vinduet, kopierer og limer du inn eller venter på den offisielle Export data. Guide: eksportere en Claude Desktop-chat.

Claude Code-panelet i VS Code ligger nærmere CLI-en enn claude.ai. Ikke forvent at innholdsskriptet vårt legges inn i den webvisningen. Bruk /export fra økten som faktisk inneholder meldingene.

Uavhengig Chrome-utvidelse, ikke tilknyttet Anthropic, PBC. Claude er et varemerke for Anthropic. Følg bruksvilkårene deres. Vi kan ikke gi juridiske råd om kopiering av verktøyutdata som inneholder proprietær kode; det er mellom deg, arbeidsgiveren din og Anthropic.

Vanlige spørsmål: eksportere Claude Code-samtale

Hvordan eksporterer jeg en Claude Code-samtale?

I terminalen i Claude Code skriver du /export (eventuelt med et filnavn) for å lagre en gjengitt transkripsjon, eller kopierer JSONL-filen fra ~/.claude/projects på macOS/Linux eller %USERPROFILE%\.claude\projects på Windows. Anthropics dokumentasjon om økter beskriver den gjeldende dialogen.

Laster denne Chrome-utvidelsen ned Claude Code-chatter?

Nei. Download Claude conversations fungerer bare på claude.ai i Chrome. Den kan ikke lese terminaløkter, JSONL-transkripsjoner eller kommandoen /export. Eksport fra Claude Code skjer i CLI-en.

Hvor lagrer Claude Code samtalehistorikken?

Transkripsjonene av øktene er JSONL-filer under ~/.claude/projects/<encoded-working-directory>/, navngitt etter økt-ID. Det nøyaktige oppsettet kan endres. Bruk /export når du vil ha en lesbar fil i stedet for å lese JSONL. CLAUDE_CONFIG_DIR kan flytte treet.

Hvordan laster jeg ned en Claude Code-samtale som Markdown?

/export i Claude Code gir en ren teksttranskripsjon, ikke Markdown fra denne utvidelsen. Trenger du spesifikt Markdown, eksporterer du fra en claude.ai-kopi av arbeidet med Download Claude conversations, eller konverterer /export-teksten selv. Vi konverterer ikke JSONL til Markdown.

Hvordan laster jeg ned en claude.ai-samtale i stedet?

Installer den gratis Chrome-utvidelsen, åpne chatten på claude.ai og bruk den oransje knappen – eller Export All for historikken. Se slik laster du ned en Claude-chat. 3 gratis eksporter; Pro koster 3,99 $/mnd. eller 26,99 $/år.

Er /export det samme som den offisielle Export data?

Nei. /export gjelder den gjeldende Claude Code-økten. Settings → Privacy → Export data sender deg en JSON-ZIP med Anthropic-kontoen på e-post. Ulike produktflater, ulike filer, ulik ventetid.

Kan jeg lese JSONL fra Claude Code med jq?

Ja, med forbeholdet Anthropic selv oppgir: linjeskjemaet er internt og kan endres. Foretrekk /export eller claude -p --output-format json når du trenger en fast kontrakt. Lås CLI-versjonen hvis du leser JSONL likevel.

Fungerer eksport fra Claude Code på Windows?

Ja. /export er en CLI-kommando. Transkripsjonene på disken ligger under %USERPROFILE%\.claude\projects med mindre du setter CLAUDE_CONFIG_DIR. Denne Chrome-utvidelsen kjører fortsatt ikke i den terminalen.

Er Claude Code det samme som Claude Desktop?

Nei. Claude Code er kodeagenten i terminalen. Claude Desktop er chatteappen. claude.ai er nettstedet. Bare nettstedet får denne utvidelsen. Om eksport fra Desktop: Claude Desktop.

Kommer utvidelsen noen gang til å pakke inn /export?

Ikke i versjon 1.13.0. Produktets omfang er claude.ai: fem formater, lokale filer, Google-pålogging for kvoten. Endres omfanget, står det på denne siden. Frem til da bruker du Anthropics CLI for å eksportere fra Claude Code.

Tar /export med verktøyutdata?

Anthropic beskriver /export som meldinger og verktøyutdata gjengitt som lesbar tekst. Det er deres transkripsjon, ikke vår parser. For det nøyaktige innholdet i dag kjører du /export på din versjon og leser filen – dokumentasjonen kan henge etter en ny versjon.

Kan jeg masseeksportere Claude Code-økter?

Ikke med Export All i denne utvidelsen. Masseeksport på oversiktssiden vår gjelder bare claude.ai. For mange CLI-økter kopierer du prosjektmappen eller kjører /export per økt. Det finnes ingen masseeksport med oransje knapp for JSONL.
