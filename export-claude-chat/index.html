Export Claude chat from claude.ai

To export a Claude chat, open the conversation in Chrome, use Download Claude conversations, pick a format, and click Export. That's the fastest way to export Claude AI chat text without copy-paste. Developers usually pick JSON; writers pick Markdown; a PNG is a picture of the thread, not a PDF.

Export Claude chat (one conversation)

Every claude.ai conversation gets an orange export button next to the message box once Download Claude conversations is installed. Open the thread, click the button, choose a format, and the file saves to your computer immediately — no dialog boxes beyond the format picker, no account setup beyond the one-time Google sign-in. This is what most people mean by "export claude chat": one thread, one click, one file, and nothing sent to a server in between.

Export many chats

Claude export chat requests rarely stop at one thread once people realize how much history they've built up. The extension's browse page lists every conversation in your account, with search and project filters, and a single Export All turns your selection into a batch of files. Each file in that batch still counts toward your 3 free exports; Pro removes the cap for bulk the same way it does for single chats. Details on the bulk download page.

Format chooser

Markdown, JSON, plain text, XML, or PNG — pick from the same dropdown either way. Markdown suits notes and Obsidian; JSON suits developers who want the full message tree; plain text is the simplest archive; XML suits structured interchange; PNG gives a visual snapshot instead of a text file. Full breakdown of each on the formats hub.

Artifacts and thinking

A claude ai export chat action from this extension keeps what a copy-paste would drop. Artifacts export in your choice of layout — Original, Inline, Nested, or Flat — and extended thinking blocks are optional, so you can include or skip Claude's visible reasoning per export. Code blocks keep their language tag and indentation; tables stay tables. This level of structure is the main reason Claude Conversation Downloader exists instead of people just relying on copy-paste.

Export vs download

No — same user job, different word people reach for. Whether you search export claude chat or download claude chat, you land on the same orange button and the same five formats. We use both words on this site on purpose, because search engines and people don't agree on which one is "correct," and Download Claude conversations answers to either.

FAQ

What does "claude export chat" mean here?

The same thing as "export claude chat" — saving a claude.ai conversation as a file with this extension, one click on the orange button.

Is "claude ai export chat" different from Anthropic's own export?

Yes. Anthropic's own tool is Settings → Privacy → Export data — a full-account JSON ZIP by email. This extension exports the chat you're viewing (or a bulk selection) as a readable file right away.

Can I export a Claude chat as PDF?

Not with this extension — current formats are Markdown, JSON, plain text, XML, and PNG. See how to export a Claude chat for print and official-export alternatives.

Do I need Pro to export claude chat once?

No. The first 3 exports on any account are free.

Does Download Claude conversations work on any claude.ai plan?

Yes — free, Pro, Team, or Enterprise claude.ai plans all work the same way, as long as you can open the conversation in your browser.
