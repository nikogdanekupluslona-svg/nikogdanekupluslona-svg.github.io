How do I export Claude chat from claude.ai?

Open the conversation on claude.ai in Chrome, click the orange button beside the message box, choose Markdown, JSON, plain text, XML, or PNG, then click Export. Download Claude conversations writes that file locally. There is no native Export this chat control on claude.ai itself in September 2026.

  1. Install Download Claude conversations from the Chrome Web Store (listing rated 5.0).
  2. Reload claude.ai and open a real conversation URL, not the empty composer home.
  3. Click the orange download button to the right of the message box.
  4. Pick a format. The Claude export extension remembers the last format you used.
  5. Click Export. Chrome saves the file immediately through the browser download API.

Google sign-in is required before the first export Claude chat action. Download Claude conversations stores the verified email to count the 3 free exports and to restore Pro after a reinstall. Chat text is not part of that sign-in. Mechanics: how it works.

If the orange button is missing, you are not on a conversation URL, the tab needs a reload after install, or the extension icon is still hidden in the Chrome puzzle menu. Pin Download Claude conversations, then refresh claude.ai. The Claude export extension only injects on claude.ai, never on other sites.

What does a Claude export extension actually do?

A Claude export extension reads the conversation already rendered in your logged-in claude.ai tab and writes a structured file on disk. Download Claude conversations is that Chrome content script: sender, message tree, code fences, tables, optional thinking, and artifact layout — not a screenshot of the chrome around the chat.

Copy-paste from claude.ai drops indentation and collapses tables. Print (Ctrl/Cmd+P) keeps the sidebar and often splits a long code block across pages. The Claude export extension keeps language tags on fences and leaves tables as tables in Markdown, JSON, and XML. PNG is the visual snapshot option; it is still not a PDF.

Artifact layout is a real toggle in version 1.13.0: Original, Inline, Nested, or Flat. Thinking blocks are optional. Metadata (title, timestamps, model) can ride along. Sender filter can limit the file to all messages, human only, or assistant only. Full list: features.

We built the orange button to write a real file from the chat already on claude.ai — Markdown, JSON, text, XML, or PNG — without uploading the thread to our servers. Version 1.13.0 still does not emit PDF.

Can I export Claude chat in bulk with Export All?

Yes. Open View and Download All Conversations, filter the table, then click Export All. Each completed file is one export Claude chat against the same 3 free exports as the orange button. Pro removes the cap for bulk the same way it does for a single thread.

The browse table lists claude.ai history with search by name and filters All, New, Exported, and Project. New means not yet exported with Download Claude conversations. Exported tracks chats you already saved so a second Export All can skip them. Project matches how you group chats on claude.ai.

Bulk uses the same toggles as one conversation: Chats, Thinking, Metadata, artifact layout (Original, Inline, Nested, Flat), and the same five formats. Export All is not a stripped ZIP. It is many per-chat files. If you wanted one delayed archive of the whole account, that is Anthropic Export data, compared in the next section and on the bulk page.

Quota is account-wide. Three free exports total — not three per bulk run. Selecting 40 conversations on the browse page will consume 40 exports if every file completes. Plan the selection before you click Export All, or use Pro at $3.99/mo or $26.99/yr.

Does export Claude chat work on Desktop or Code?

No. This Claude export extension runs only on claude.ai inside Chrome (or another Chromium browser that can load the listing). Claude Desktop is a separate Mac/Windows app. Claude Code is the terminal agent. The orange button never appears in those windows.

If the thread also exists on your claude.ai account, open it in Chrome and export Claude chat there with Download Claude conversations. If the chat lives only in Desktop, copy-paste from the app or request Settings → Privacy → Export data on the web. Step-by-step contrast: export Claude Desktop chat.

Claude Code uses /export or JSONL transcripts on disk. That is not Markdown from this Chrome extension. Do not install Download Claude conversations expecting a terminal hook. Guide: Claude Code export. Searching export Claude chat for a CLI session is a different product path.

Mobile claude.ai in a phone browser is also out of scope. The Claude export extension needs desktop Chrome. There is no iOS or Android app from this team in 2026. Open the conversation on a computer, then export Claude chat from the orange button or Export All.
