How do I export Claude chat from claude.ai?

Open the conversation on claude.ai in Chrome, click the orange button beside the message box, choose PDF, Markdown, JSON, plain text, XML, CSV, or PNG, then click Export. Download Claude conversations writes that file locally. There is no native Export this chat control on claude.ai itself in September 2026.

  1. Install Download Claude conversations from the Chrome Web Store.
  2. Reload claude.ai and open a real conversation URL, not the empty composer home.
  3. Click the round orange download button to the right of the message box.
  4. In the panel, set Messages to All, Human, or Assistant, then pick a format. Tick Thinking to include extended thinking, or use Select to tick individual messages. The Claude export extension remembers the last format you used.
  5. Click Export. Chrome saves the file immediately through the browser download API. Copy puts Markdown, text, JSON, XML, or CSV on the clipboard instead.

No account is needed to export Claude chat as Markdown, text, JSON, XML, CSV, or PNG. Those single-chat exports are unlimited, and the extension sends nothing to our servers for them. Google sign-in appears only when you pick PDF or run bulk Export All: the free plan allows 3 of those a day, combined, reset at midnight UTC. Chat text is never part of that sign-in. One thread vs the whole account. The orange button exports the open chat. For many files, open the extension popup → View and Download All Conversations and run Export All — see bulk Export All. Anthropic Settings → Privacy → Export data is a delayed account ZIP, not this flow.

What does a Claude export extension actually do?

A Claude export extension reads the conversation already rendered in your logged-in claude.ai tab and writes a structured file on disk. Download Claude conversations is that Chrome content script: sender, message tree, code fences, tables, optional thinking, and artifact layout — not a screenshot of the chrome around the chat. It works on regular chats, Projects, Cowork sessions, and Claude Code on the web.

Copy-paste from claude.ai drops indentation and collapses tables. Print (Ctrl/Cmd+P) keeps the sidebar and often splits a long code block across pages. The Claude export extension keeps language tags on fences and leaves tables as tables in Markdown, JSON, and XML. PNG is the visual snapshot option. PDF is the paginated one, built in the browser with no print dialog.

Artifact layout is a real toggle in version 1.16.2: Original, Inline, Nested, or Flat, set on the Dashboard. Extended thinking is a checkbox in the export panel; web search sources and tool / MCP steps are opt-in in Settings. Metadata (title, timestamps, model) can ride along. The Messages filter limits the file to all messages, human only, or assistant only, and Select ticks individual messages. Full list: features.

We built the orange button to write a real file from the chat already on claude.ai — PDF, Markdown, JSON, text, XML, CSV, or PNG — without uploading the thread to our servers. Version 1.16.2 builds the PDF in the browser too.

Can I export Claude chat in bulk with Export All?

Yes. Open the extension popup → View and Download All Conversations, filter the table, then click Export All for a ZIP. Bulk export asks for Google sign-in. On the free plan it shares 3 a day with PDF, and each conversation in the ZIP uses one. Pro removes the cap for the whole history.

The Dashboard lists claude.ai history with search by name, filters (All conversations, New, Updated, Previously exported), Chat and Cowork tabs, and project search. New means not yet exported with Download Claude conversations. Previously exported tracks chats you already saved so a second Export All can skip them. Project search matches how you group chats on claude.ai.

Bulk has a Chat format picker with all seven formats, PDF included, checkboxes for Chats, Thinking, Metadata, Tools, and Sources, and artifact layout (Original, Inline, Nested, Flat). Export All is not a stripped archive. It is one ZIP with one file per chat in the chosen format. If you wanted one delayed archive of the whole account, that is Anthropic Export data, compared in the next section and on the bulk page.

Bulk counts per chat. On the free plan, Export All and PDF share 3 a day, and every conversation in the ZIP uses one. Select 40 conversations with 3 left and the whole batch is blocked, not cut short. Pick fewer, wait for the midnight UTC reset, or use Pro at $3.99 a month or $26.99 a year.

Does export Claude chat work on Desktop or Code?

Not in the Desktop app or the Claude Code terminal. This Claude export extension runs only on claude.ai inside Chrome (or another Chromium browser that can load the listing). Claude Desktop is a separate Mac/Windows app, and the orange button never appears there or in a terminal. Claude Code on the web (claude.ai/code) is the exception: those sessions open on claude.ai and export like any chat.

If the thread also exists on your claude.ai account, open it in Chrome and export Claude chat there with Download Claude conversations. If the chat lives only in Desktop, copy-paste from the app or request Settings → Privacy → Export data on the web. Step-by-step contrast: export Claude Desktop chat.

Claude Code in the terminal uses /export or JSONL transcripts on disk. This Chrome extension does not read those local sessions. Do not install Download Claude conversations expecting a terminal hook. Guide: Claude Code export. Searching export Claude chat for a CLI session is a different product path.

Mobile claude.ai in a phone browser is also out of scope. The Claude export extension needs desktop Chrome. There is no iOS or Android app from this team in 2026. Open the conversation on a computer, then export Claude chat from the orange button or Export All.
