How do I download Claude chat as PNG?

Open the conversation on claude.ai in Chrome, click the orange button beside the message box, choose PNG, then click Export. Download Claude conversations renders the image in the tab. That is how you download Claude chat as PNG in version 1.16.2 — free, unlimited, no account.

  1. Install Download Claude conversations from the Chrome Web Store.
  2. Reload claude.ai and open a real conversation URL, not the empty composer home.
  3. Click the round orange download button to the right of the message box.
  4. Select PNG. The last format you used is remembered.
  5. Click Export. Chrome downloads the PNG immediately.

No Google sign-in is needed to download Claude chat as PNG. Single-chat PNG exports are unlimited and anonymous: no counter, and nothing about the chat leaves the browser. Sign-in appears only if you pick PDF, run Export All, or buy Pro. Mechanics: how it works.

If the orange button is missing, you are not on a conversation URL, the tab needs a reload after install, or the extension is hidden in the Chrome puzzle menu. PNG export never appears in the Claude Desktop app or in local Claude Code terminal sessions.

One image vs many. The orange button writes one PNG of the open thread. For many images, open View and Download All Conversations and run Export All with PNG selected. Bulk writes a ZIP and uses the daily bulk allowance — see bulk Export All.

What does a Claude chat PNG export include?

A Claude chat PNG export is a single image of the conversation content Download Claude conversations rendered. Unlike Markdown or JSON, the PNG does not carry a message tree you can parse. Code and tables are pixels. Thinking and artifacts are drawn, not stored as text.

The Messages filter limits what is drawn to all messages, human only, or assistant only, the Thinking checkbox adds or drops extended thinking, and Select lets you tick individual messages. Metadata and artifact layout (Original, Inline, Nested, Flat) are Dashboard options for Export All. Metadata does not become selectable text on the PNG the way it does in JSON. Copy does not work for PNG; it is always a file.

If the thread is very long, scroll until claude.ai has loaded earlier messages before you download Claude chat as PNG. The extension can only render what the page has loaded. A half-loaded thread produces a truncated image. Full toggle list: Chrome extension features.

Can I bulk download Claude chat as PNG?

Yes. Open View and Download All Conversations, set Chat format to PNG, filter the list, then click Export All. You get one ZIP with one PNG per selected conversation. Bulk needs Google sign-in; on the free plan each chat in the ZIP uses one of 3 daily PDF or bulk exports. Pro at $3.99 a month or $26.99 a year removes that cap.

The Dashboard lists claude.ai history with search by name, project search, Chat and Cowork tabs, and filters All conversations, New, Updated, and Previously exported. New means not yet exported with Download Claude conversations. Export All produces one PNG per selected conversation inside the ZIP, not a contact-sheet collage and not a PDF binder.

The bulk cap resets at midnight UTC. On the free plan, a selection larger than what is left today is blocked as a whole, not cut short: pick fewer chats or use Pro. Single-chat PNG from the orange button stays unlimited. Anthropic Settings → Privacy → Export data is still a delayed JSON ZIP, not a folder of images.
