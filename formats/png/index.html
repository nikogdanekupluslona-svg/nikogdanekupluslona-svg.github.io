How do I download Claude chat as PNG?

Open the conversation on claude.ai in Chrome, click the orange button beside the message box, choose PNG, then click Export. Download Claude conversations renders the image in the tab. That is how you download Claude chat as PNG in version 1.13.0.

  1. Install Download Claude conversations from the Chrome Web Store (listing rated 5.0).
  2. Reload claude.ai and open a real conversation URL, not the empty composer home.
  3. Click the orange download button to the right of the message box.
  4. Select PNG. The last format you used is remembered.
  5. Click Export. Chrome downloads the PNG immediately.

Google sign-in is required before the first time you download Claude chat as PNG. Download Claude conversations stores the verified email to count the 3 free exports and to restore Pro after a reinstall. Chat pixels are not uploaded for that sign-in. Mechanics: how it works.

If the orange button is missing, you are not on a conversation URL, the tab needs a reload after install, or the extension is hidden in the Chrome puzzle menu. Pin Download Claude conversations, then refresh claude.ai. PNG export never appears in Claude Desktop or Claude Code.

One image vs many. The orange button writes one PNG of the open thread. For many images, open View and Download All Conversations and run Export All with PNG selected — see bulk Export All.

When should I download Claude chat as PNG?

Download Claude chat as PNG when you need a picture for a slide, a chat app, or a ticket — somewhere an image is easier to drop than a .md file. Do not pick PNG if you need to search or copy code later. Use Markdown for that.

A claude.ai screenshot you take by hand often includes the sidebar and composer. Download Claude conversations builds a PNG from the conversation content it already parsed, not from a random OS screenshot. It is still an image: no message tree, no fenced-code language tags you can copy as text.

We added PNG so you can save a visual snapshot of a claude.ai thread. We did not add PDF. If you download Claude chat as PNG you get an image file; if you need a printable page, use Chrome’s print dialog, which is a browser feature, not a sixth product format.

Is download Claude chat as PNG the same as PDF?

No. PNG is an image format. PDF is a paginated document format. Download Claude conversations exports PNG, not PDF. If you actually need a PDF-like page, print the claude.ai tab in Chrome (Ctrl/Cmd+P → Save as PDF). Walkthrough: print a Claude conversation.

What does a Claude chat PNG export include?

A Claude chat PNG export is a single image of the conversation content Download Claude conversations rendered. Unlike Markdown or JSON, the PNG does not carry a message tree you can parse. Code and tables are pixels. Thinking and artifacts are drawn, not stored as text.

Artifact layout (Original, Inline, Nested, Flat) still changes how artifacts appear in the image, the same four options as other formats. Sender filter can limit what is drawn to all messages, human only, or assistant only. Metadata does not become selectable text on the PNG the way it does in JSON.

If the thread is very long, scroll until claude.ai has loaded earlier messages before you download Claude chat as PNG. The extension can only render what the page has loaded. A half-loaded thread produces a truncated image. Full toggle list: Chrome extension features.

Keep a text copy if you care about the words. PNG is a snapshot. If you later need to grep a function name, that search will fail. Export Markdown or JSON as a second file; that second file also counts against the 3 free exports.

Can I bulk download Claude chat as PNG?

Yes. Open View and Download All Conversations, set the format to PNG, filter the table, then click Export All. Each completed image is one export against the same 3 free exports as a single orange-button PNG. Pro at $3.99/mo or $26.99/yr removes that cap for bulk PNG.

The browse table lists claude.ai history with search by name and filters All, New, Exported, and Project. New means not yet exported with Download Claude conversations. Export All produces one PNG per selected conversation, not a contact-sheet collage and not a PDF binder.

Quota is account-wide. Selecting 40 conversations consumes 40 exports if every PNG completes. Plan the selection before you click Export All. Anthropic Settings → Privacy → Export data is still a delayed JSON ZIP, not a folder of images.

Does Download Claude conversations export PDF?

No. Current formats are Markdown, JSON, plain text, XML, and PNG. PNG is the closest to a visual copy, but it is an image, not a PDF. Print the claude.ai page in Chrome if you need a PDF-like file.

Can I download Claude chat as PNG for all history?

Yes. Export All on the bulk page supports PNG the same as a single export, producing one image per selected conversation. Each image counts as one of the 3 free exports unless you are on Pro.

Is PNG free, or Pro only?

Free. Every format, including PNG, is part of the 3 free exports on any Google-signed account. Pro is $3.99/mo or $26.99/yr after those three files.

Can I copy code from a Claude chat PNG?

Not cleanly. Download Claude chat as PNG stores pixels. Export Markdown or JSON if you need fenced code with language tags. Keep both files if you need a picture and searchable text.

Is download Claude chat as PNG a screenshot of Chrome?

No. Download Claude conversations renders a PNG from the conversation it parsed on claude.ai. It is still an image, not a Markdown file. An OS screenshot of the whole window is a different file you take yourself.

Does PNG work on Claude Desktop?

No. The Chrome extension injects only on claude.ai. Claude Desktop never shows the PNG option. Open the same thread on claude.ai in Chrome if it exists there.

Does a PNG export use the same quota as Markdown?

Yes. One completed PNG is one export, same as one .md or JSON file. The 3 free exports are not three per format. Pro removes the cap for every format including PNG.
