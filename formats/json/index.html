How do I export Claude conversation as JSON?

Open the conversation on claude.ai in Chrome, click the orange button beside the message box, choose JSON, then click Export. Download Claude conversations writes the file locally. That is how you export Claude conversation as JSON in version 1.16.2. claude.ai has no per-chat Save as JSON control in September 2026.

  1. Install Download Claude conversations from the Chrome Web Store.
  2. Reload claude.ai and open a real conversation URL, not the empty composer home.
  3. Click the orange download button to the right of the message box.
  4. Select JSON. The last format you used is remembered. Use Select to tick only the messages you want.
  5. Click Export. Chrome downloads the JSON through the browser download API. Or click Copy to put the JSON on the clipboard.

No sign-in is needed to export Claude conversation as JSON. Single-chat JSON exports are unlimited, anonymous, and send nothing to our servers. Google sign-in is asked only for PDF and bulk Export All. Mechanics: how it works.

If the orange button is missing, you are not on a conversation URL, the tab needs a reload, or the extension is hidden in the Chrome puzzle menu. Pin Download Claude conversations, then refresh claude.ai. The content script never injects in Claude Desktop or the Claude Code terminal.

One thread vs many files. The orange button exports the open chat as JSON. For many JSON files, open View and Download All Conversations and run Export All with JSON selected: one ZIP, 3 chats a day on the free plan — see bulk Export All.

When should I export Claude conversation as JSON?

Export Claude conversation as JSON when a script, indexer, or diff tool will read the file. The JSON is built for the message tree, not for reading in Obsidian. If you want headings and fenced code for humans, pick Markdown instead. For a spreadsheet, pick CSV: one row per message.

Copy-paste from claude.ai loses sender structure. Print keeps webpage chrome. When you export Claude conversation as JSON, Download Claude conversations keeps turns, senders, and optional thinking as data, not as a flattened paragraph. That is why developers pick JSON over plain text.

We write JSON from the claude.ai tree already on the page — sender, content blocks, timestamps, model metadata — without uploading the thread. That JSON is not Anthropic’s account ZIP. In version 1.16.2 it is one of seven formats, next to PDF and CSV, and it is free with no account.

What is in a Claude conversation JSON export?

A Claude conversation JSON export mirrors the message tree on claude.ai: sender, content blocks, timestamps, and model metadata. Thinking blocks, web search sources, tool / MCP steps, and artifacts are included when those options are on: Thinking is a checkbox in the export panel, and tools and sources are switched on in Settings. Sender filter can limit the file to all messages, human only, or assistant only. Nothing is flattened into Markdown first.

Artifact layout in version 1.16.2 is Original, Inline, Nested, or Flat. Those layouts change how artifact content is nested in the JSON, the same four options used for Markdown and XML. Full list: Chrome extension features. For pages instead of data, export PDF.

If the thread is long, scroll until claude.ai has loaded earlier messages before you export Claude conversation as JSON. The extension can only serialize what the page has rendered. A half-loaded DOM produces a truncated JSON file.

Claude conversation JSON vs Anthropic Export data?

Both are JSON, but not the same shape or scope. Anthropic Settings → Privacy → Export data emails one ZIP of the whole account after a wait. When you export Claude conversation as JSON, you get one thread immediately in Chrome. Use the ZIP for backup.

Can I bulk export Claude conversation as JSON?

Yes. Open View and Download All Conversations, set Chat format to JSON, filter the table, then click Export All. Chrome saves one ZIP with one JSON file per chat. On the free plan that is 3 chats a day with Google sign-in, shared with PDF. Pro at $3.99 a month or $26.99 a year removes that cap for bulk JSON.

The Dashboard lists claude.ai history with search by name, filters All conversations, New, Updated, and Previously exported, Chat and Cowork tabs, and project search. New means not yet exported with Download Claude conversations. Previously exported tracks chats you already saved. Export All is one ZIP of per-chat JSON files, not a mixed-format archive.

The daily limit is per account. Three chats a day on the free plan, shared with PDF. If you select 40 conversations with 3 left, the whole batch is blocked, not cut short. Select fewer or use Pro. Single JSON exports from the orange button stay unlimited.

You can diff two JSON exports of the same claude.ai thread taken at different times the way you would diff any JSON file. Each export is self-contained. A second Export All of the same chats counts every chat again.

Does JSON Claude conversation export need Pro?

No. Single-chat JSON export is free and unlimited, with no account and no counter — same as Markdown, text, XML, CSV, and PNG. Only PDF and bulk Export All have a free limit: 3 a day with Google sign-in. Pro is $3.99 a month or $26.99 a year through Paddle. Download Claude conversations does not charge extra to export Claude conversation as JSON.

Bulk JSON is where the limit shows up. Each chat in an Export All ZIP uses one of the 3 a day, and the count resets at midnight UTC. Pro removes it and restores on a new computer from the same Google account. Paddle is merchant of record; this team never sees card numbers.

The extension runs only on claude.ai in Chrome. Claude Desktop and the Claude Code terminal do not get a JSON button; Claude Code on the web (claude.ai/code) runs on claude.ai, so it exports like any chat. Terminal Claude Code’s /export or JSONL on disk is a different path. Version 1.16.2, September 2026, still does not write Word or Notion.

FAQ: export Claude conversation as JSON

These FAQ items cover export Claude conversation as JSON in Download Claude conversations 1.16.2: bulk Export All, schema, cost, diffs, Anthropic’s ZIP, PDF, and Desktop. Each answer is a product fact. The FAQPage JSON-LD in the page head matches this list.

Can I export Claude conversation as JSON in bulk?

Yes. Export All on the Dashboard supports JSON and saves one ZIP with a JSON file per chat. On the free plan it covers 3 chats a day with Google sign-in; Pro at $3.99 a month or $26.99 a year is unlimited.

Is the JSON structure documented?

It mirrors claude.ai’s own message tree: sender, content blocks, timestamps, and model metadata, with artifacts, thinking blocks, web search sources, and tool / MCP steps included when you enable those options. It is not Anthropic’s account ZIP schema.

Do I need Pro to export Claude conversation as JSON?

No. Single-chat JSON exports are unlimited and need no account, same as every format except PDF. Pro at $3.99 a month or $26.99 a year only lifts the 3-a-day limit on PDF and bulk Export All.

Can I diff two JSON exports of one chat?

Yes. Each time you export Claude conversation as JSON, you get a self-contained file built the same way. Comparing two exports of the same thread taken at different times works like diffing any other JSON file.

Is this JSON the same as Anthropic Export data?

No. Anthropic Export data is a delayed full-account ZIP. Download Claude conversations writes a per-chat (or per-selection) JSON file immediately in Chrome. Both may be JSON; they are not interchangeable.

Does export Claude conversation as JSON create a PDF?

No. JSON is structured data. For pages, pick PDF in the same panel; the seven formats are PDF, Markdown, JSON, plain text, XML, CSV, and PNG. PDF needs Google sign-in and counts toward 3 a day on the free plan.

Does JSON export work on Claude Desktop?

No. The Chrome extension injects only on claude.ai. Claude Desktop never shows the JSON option. Open the same thread on claude.ai in Chrome if it exists there.
