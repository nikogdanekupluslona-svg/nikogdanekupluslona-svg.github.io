How do I export Claude conversation as JSON?

Open the conversation on claude.ai in Chrome, click the orange button beside the message box, choose JSON, then click Export. Download Claude conversations writes the file locally. That is how you export Claude conversation as JSON in version 1.13.0. claude.ai has no per-chat Save as JSON control in September 2026.

  1. Install Download Claude conversations from the Chrome Web Store (listing rated 5.0).
  2. Reload claude.ai and open a real conversation URL, not the empty composer home.
  3. Click the orange download button to the right of the message box.
  4. Select JSON. The last format you used is remembered.
  5. Click Export. Chrome downloads the JSON through the browser download API.

Google sign-in is required before the first time you export Claude conversation as JSON. Download Claude conversations stores the verified email to count the 3 free exports and to restore Pro after a reinstall. Chat bodies are not part of that sign-in. Mechanics: how it works.

If the orange button is missing, you are not on a conversation URL, the tab needs a reload, or the extension is hidden in the Chrome puzzle menu. Pin Download Claude conversations, then refresh claude.ai. The content script never injects on Claude Desktop or Claude Code.

One thread vs many files. The orange button exports the open chat as JSON. For many JSON files, open View and Download All Conversations and run Export All with JSON selected — see bulk Export All.

When should I export Claude conversation as JSON?

Export Claude conversation as JSON when a script, indexer, or diff tool will read the file. The JSON is built for the message tree, not for reading in Obsidian. If you want headings and fenced code for humans, pick Markdown instead.

Copy-paste from claude.ai loses sender structure. Print keeps webpage chrome. When you export Claude conversation as JSON, Download Claude conversations keeps turns, senders, and optional thinking as data, not as a flattened paragraph. That is why developers pick JSON over plain text.

We write JSON from the claude.ai tree already on the page — sender, content blocks, timestamps, model metadata — without uploading the thread. That JSON is not Anthropic’s account ZIP, and it is not PDF. Version 1.13.0 still ships five formats only.

What is in a Claude conversation JSON export?

A Claude conversation JSON export mirrors the message tree on claude.ai: sender, content blocks, timestamps, and model metadata. Thinking blocks and artifacts are included when those toggles are on. Sender filter can limit the file to all messages, human only, or assistant only. Nothing is flattened into Markdown first.

Artifact layout in version 1.13.0 is Original, Inline, Nested, or Flat. Those layouts change how artifact content is nested in the JSON, the same four options used for Markdown and XML. Full toggle list: Chrome extension features. JSON still does not become a PDF.

If the thread is long, scroll until claude.ai has loaded earlier messages before you export Claude conversation as JSON. The extension can only serialize what the page has rendered. A half-loaded DOM produces a truncated JSON file.

Claude conversation JSON vs Anthropic Export data?

Both are JSON, but not the same shape or scope. Anthropic Settings → Privacy → Export data emails one ZIP of the whole account after a wait. When you export Claude conversation as JSON, you get one thread immediately in Chrome. Use the ZIP for backup.

Can I bulk export Claude conversation as JSON?

Yes. Open View and Download All Conversations, set the format to JSON, filter the table, then click Export All. Each completed file is one of the 3 free exports. Pro at $3.99/mo or $26.99/yr removes that cap for bulk JSON.

The browse table lists claude.ai history with search by name and filters All, New, Exported, and Project. New means not yet exported with Download Claude conversations. Exported tracks chats you already saved. Project matches how you group chats on claude.ai. Export All is many JSON files, not one mixed ZIP.

Quota is account-wide. Three free exports total — not three JSON files per bulk run. Selecting 40 conversations consumes 40 exports if every file completes. Plan the selection, or use Pro.

You can diff two JSON exports of the same claude.ai thread taken at different times the way you would diff any JSON file. Each export is self-contained. A second Export All of the same chats still consumes quota unless those files fail to complete.

Does JSON Claude conversation export need Pro?

No. JSON is included in the 3 free exports every Google-signed account gets, same as Markdown, text, XML, and PNG. After those three files, Pro is $3.99 per month or $26.99 per year through Paddle. Download Claude conversations does not charge extra to export Claude conversation as JSON.

The 3 free exports do not reset when you reinstall the Chrome listing. That is why Google sign-in is required on the first Export click. Pro restores on a new computer from the same Google account. Paddle is merchant of record; this team never sees card numbers.

The extension runs only on claude.ai in Chrome. Claude Desktop and Claude Code do not get a JSON button. Claude Code’s /export or JSONL on disk is a different path. Version 1.13.0, September 2026, still does not write PDF, Word, or Notion.

FAQ: export Claude conversation as JSON

These FAQ items cover export Claude conversation as JSON in Download Claude conversations 1.13.0: bulk Export All, schema, quota, diffs, Anthropic’s ZIP, and Desktop. Each answer is a product fact. The FAQPage JSON-LD in the page head matches this list.

Can I export Claude conversation as JSON in bulk?

Yes. Export All on the browse page supports JSON the same as a single export. Each completed file counts as one of the 3 free exports unless you are on Pro at $3.99/mo or $26.99/yr.

Is the JSON structure documented?

It mirrors claude.ai’s own message tree: sender, content blocks, timestamps, and model metadata, with artifacts and thinking blocks included when you enable those toggles. It is not Anthropic’s account ZIP schema.

Do I need Pro to export Claude conversation as JSON?

No. JSON is included in the 3 free exports every Google-signed account gets, same as every other format. Pro is $3.99/mo or $26.99/yr after those three files.

Can I diff two JSON exports of one chat?

Yes. Each time you export Claude conversation as JSON, you get a self-contained file built the same way. Comparing two exports of the same thread taken at different times works like diffing any other JSON file.

Is this JSON the same as Anthropic Export data?

No. Anthropic Export data is a delayed full-account ZIP. Download Claude conversations writes a per-chat (or per-selection) JSON file immediately in Chrome. Both may be JSON; they are not interchangeable.

Does export Claude conversation as JSON create a PDF?

No. JSON is structured data. The product formats are Markdown, JSON, plain text, XML, and PNG. For a printable page, use Chrome’s print dialog, not this dropdown.

Does JSON export work on Claude Desktop?

No. The Chrome extension injects only on claude.ai. Claude Desktop never shows the JSON option. Open the same thread on claude.ai in Chrome if it exists there.
