How do I export Claude chat to XML?

Open the conversation on claude.ai in Chrome, click the orange button beside the message box, choose XML, then click Export. Download Claude conversations writes the file locally. That is how you export Claude chat to XML in version 1.13.0. claude.ai has no native Save as XML control in September 2026.

  1. Install Download Claude conversations from the Chrome Web Store (listing rated 5.0).
  2. Reload claude.ai and open a real conversation URL, not the empty composer home.
  3. Click the orange download button to the right of the message box.
  4. Select XML. The last format you used is remembered.
  5. Click Export. Chrome downloads the XML through the browser download API.

Google sign-in is required before the first time you export Claude chat to XML. Download Claude conversations stores the verified email to count the 3 free exports and to restore Pro after a reinstall. Chat text is not part of that sign-in. Mechanics: how it works.

If the orange button is missing, you are not on a conversation URL, the tab needs a reload, or the extension is hidden in the Chrome puzzle menu. Pin Download Claude conversations, then refresh claude.ai. XML export never appears in Claude Desktop or Claude Code.

One file vs many. The orange button exports the open thread as XML. For many XML files, open View and Download All Conversations and run Export All with XML selected — see bulk Export All.

When should I export Claude chat to XML?

Export Claude chat to XML when the receiving system, pipeline, or legacy tool requires XML for structured interchange. Most developers should pick JSON instead. Markdown is for human notes. PNG is a picture. XML exists in the dropdown because some tools still ingest XML and will not accept JSON.

Do not export Claude chat to XML as a “more official” JSON. Download Claude conversations applies the same parse either way. The difference is the file shape, not extra fields magically appearing. If nothing you use requires XML, skip this format and use JSON.

We ship XML because some pipelines still require it, not because we think it beats JSON for every claude.ai export. The parse is the same: messages, sender, optional thinking and artifacts. We still do not emit PDF. Version 1.13.0 keeps XML as one of five formats, not a paid add-on.

What does export Claude chat to XML keep?

When you export Claude chat to XML, Download Claude conversations writes the conversation structure — messages, sender, and available metadata — as XML markup. Thinking blocks and artifacts follow the same toggles as Markdown and JSON. XML is not a stripped-down cousin of those formats.

Artifact layout is Original, Inline, Nested, or Flat in version 1.13.0. Sender filter can limit the XML to all messages, human only, or assistant only. Metadata (title, timestamps, model) can ride along. Full toggle list: Chrome extension features.

If the thread is long, scroll until claude.ai has loaded earlier messages before you export Claude chat to XML. The extension can only serialize what the page has rendered. A half-loaded DOM produces truncated XML.

XML vs JSON if I export Claude chat?

JSON is the common developer pick. Export Claude chat to XML only when a downstream system requires XML. Download Claude conversations does not make XML “more complete” than JSON. Both can include thinking and artifacts. Neither is Anthropic’s account ZIP. Format hub: Claude chat export formats.

XML versus the other claude.ai export files

Anthropic Settings → Privacy → Export data is JSON (a ZIP), not XML. Print → Save as PDF is a webpage snapshot. Neither replaces export Claude chat to XML from the orange button. Do not expect this XML to match an unpublished Anthropic schema.

The extension runs only on claude.ai in Chrome. Claude Desktop and Claude Code do not get an XML button. If the thread also exists on claude.ai, open it there and export Claude chat to XML. Claude Code’s /export is a different product path.

Can I export Claude chat to XML in bulk?

Yes. Open View and Download All Conversations, set the format to XML, filter the table, then click Export All. Each completed file is one of the 3 free exports. Pro at $3.99/mo or $26.99/yr removes that cap for bulk XML.

The browse table lists claude.ai history with search by name and filters All, New, Exported, and Project. New means not yet exported with Download Claude conversations. Exported tracks chats you already saved. Project matches how you group chats on claude.ai. Export All is many XML files, not one mixed ZIP.

Quota is account-wide. Three free exports total — not three XML files per bulk run. Selecting 40 conversations consumes 40 exports if every file completes. Plan the selection, or use Pro.

You cannot mix XML and JSON in one Export All click. Pick XML for that run. Run Export All again with JSON if you need both shapes of the same claude.ai thread; the second run also consumes quota.

Is XML better than JSON for Claude chat exports?

Not generally. JSON is the more common choice for developers. Export Claude chat to XML when your downstream system requires XML for structured interchange. The parse from claude.ai is the same; the file shape differs.

Can I bulk-export Claude chat to XML?

Yes. The same Export All flow on the browse page supports XML. Each completed file counts as one of the 3 free exports unless you are on Pro at $3.99/mo or $26.99/yr.

Is XML a paid-only format?

No. All five formats, XML included, are covered by the 3 free exports every Google-signed account gets. Pro is $3.99/mo or $26.99/yr after those three files.

Does export Claude chat to XML match Anthropic’s ZIP?

No. Anthropic Export data is a delayed account JSON ZIP. Download Claude conversations writes a per-chat (or per-selection) XML file immediately in Chrome. They are not the same schema.

Does export Claude chat to XML create a PDF?

No. XML is markup. Product formats are Markdown, JSON, plain text, XML, and PNG. For a printable page, use Chrome’s print dialog. PNG is an image, also not a PDF.

Can I export Claude chat to XML on Desktop?

No. The Chrome extension injects only on claude.ai. Claude Desktop never shows the XML dropdown. Open the same thread on claude.ai in Chrome if it exists there.

Do I need Pro to export Claude chat to XML once?

No. The first 3 exports are free, any format including XML. Pro at $3.99/mo or $26.99/yr removes the limit for more single or bulk XML files.
