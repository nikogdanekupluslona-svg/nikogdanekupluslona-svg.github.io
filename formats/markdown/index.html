How do I export Claude chat to Markdown?

Open the conversation on claude.ai in Chrome, click the orange button beside the message box, choose Markdown, then click Export. Download Claude conversations writes a .md file locally. That is how you export Claude chat to Markdown in version 1.16.2.

  1. Install Download Claude conversations from the Chrome Web Store.
  2. Reload claude.ai and open a real conversation URL, not the empty composer home.
  3. Click the orange download button to the right of the message box.
  4. Select Markdown. The extension remembers the last format you used. Use Select to tick only the messages you want.
  5. Click Export. Chrome downloads the .md file through the browser download API. Or click Copy to put the Markdown on the clipboard.

No sign-in is needed to export Claude chat to Markdown. Single-chat Markdown exports are unlimited, anonymous, and send nothing to our servers. Google sign-in is asked only for PDF and bulk Export All. Mechanics: how it works.

If the orange button is missing, you are not on a conversation URL, the tab needs a reload after install, or the extension is still hidden in the Chrome puzzle menu. Pin Download Claude conversations, then refresh claude.ai. The content script never injects in Claude Desktop or the Claude Code terminal.

One chat vs many. The orange button exports the open thread as Markdown. For many .md files, open View and Download All Conversations and run Export All with Markdown selected: one ZIP, 3 chats a day on the free plan — see bulk Export All.

Why export Claude chat to Markdown for notes?

Export Claude chat to Markdown when you will read the file in Obsidian, a GitHub wiki, or any editor that renders headings and fences. The .md file is still plain text you can search and diff. JSON is better for parsers; PNG is a picture you cannot grep.

Copy-paste from claude.ai usually drops indentation and flattens tables. Print (Ctrl/Cmd+P) keeps the sidebar and often splits a long code block across pages. When you export Claude chat to Markdown, language tags stay on fences and tables stay tables. That is the reason writers pick this format first.

We treat Markdown as the default human-readable file: headings, fenced code with language tags, and tables from the claude.ai thread. When you need pages instead, pick PDF in the same panel. It is laid out in the browser, with page size, margins, and a table of contents.

What does export Claude chat to Markdown keep?

When you export Claude chat to Markdown, Download Claude conversations keeps headings, fenced code with language tags and indentation, tables, and links. Thinking blocks, web search sources, and tool / MCP steps are each opt-in: Thinking is a checkbox in the export panel, and the other two are switched on in Settings. Metadata (title, timestamps, model) can ride along. Sender filter can limit the .md file to all messages, human only, or assistant only.

Artifact layout is a real toggle in version 1.16.2: Original, Inline, Nested, or Flat. A Markdown export can mirror the on-screen artifact structure, flatten it into one linear document, or pull artifacts into their own folder inside a ZIP. Settings can embed images in the .md file. Full list: Chrome extension features. Markdown does not keep message-bubble colors; use PNG for a visual snapshot or PDF for pages.

If the thread is very long, scroll until claude.ai has loaded earlier messages before you export Claude chat to Markdown. The extension can only write what the page has rendered. A half-loaded thread produces a half-loaded .md file, which looks like a bug and is usually an un-scrolled DOM.

Can I export Claude chat to Markdown in bulk?

Yes. Open View and Download All Conversations, set Chat format to Markdown, filter the table, then click Export All. Chrome saves one ZIP with one .md file per chat. On the free plan that is 3 chats a day with Google sign-in, shared with PDF. Pro at $3.99 a month or $26.99 a year removes that cap for bulk Markdown.

The Dashboard lists claude.ai history with search by name, filters All conversations, New, Updated, and Previously exported, Chat and Cowork tabs, and project search. New means not yet exported with Download Claude conversations. Previously exported tracks chats you already saved so a second Export All can skip them.

The daily limit is per account. Three chats a day on the free plan, shared with PDF. If you select 40 conversations with 3 left, the whole batch is blocked, not cut short. Select fewer or use Pro. Single .md exports from the orange button stay unlimited.

Bulk Markdown uses the Dashboard checkboxes Chats, Thinking, Metadata, Tools, and Sources, plus the artifact format. Export All is not Anthropic’s delayed ZIP. It is one ZIP of per-chat .md files. If you wanted one archive of the whole account, that is Settings → Privacy → Export data, which is JSON, not Markdown.

Markdown vs JSON when I export Claude chat?

Export Claude chat to Markdown when a human will read the file. Export as JSON when a script will parse the message tree. Download Claude conversations offers both in one dropdown, plus PDF, plain text, XML, CSV, and PNG. Format hub: Claude chat export formats.

The extension runs only on claude.ai in Chrome. Claude Desktop and the Claude Code terminal do not get a Markdown button. Claude Code on the web (claude.ai/code) runs on claude.ai, so it exports like any chat. If a thread also exists on claude.ai, open it there and export Claude chat to Markdown. FAQ: export Claude chat to Markdown

These FAQ items cover export Claude chat to Markdown in Download Claude conversations 1.16.2: code fences, bulk Export All, Anthropic’s ZIP, cost, PDF, and Desktop. Each answer is a product fact. The FAQPage JSON-LD in the page head matches this list.

Does export Claude chat to Markdown lose code?

No. Code blocks keep their language tag and indentation, unlike a plain copy-paste from claude.ai. Tables stay Markdown tables. That is the main reason to export Claude chat to Markdown instead of selecting text by hand.

Can I export Claude chat to Markdown in bulk?

Yes. Export All on the Dashboard supports Markdown and saves one ZIP of .md files. On the free plan it covers 3 chats a day with Google sign-in; Pro is unlimited.

Is Markdown the same as Anthropic Export data?

No. Anthropic’s official export is a JSON ZIP for your whole account, emailed after a wait. Export Claude chat to Markdown is a per-chat (or per-selection) .md file from Download Claude conversations.

Does Markdown cost extra versus other formats?

No. Single-chat Markdown exports are unlimited and need no account, same as JSON, text, XML, CSV, and PNG. Only PDF and bulk ZIP have a free limit of 3 a day. Pro is $3.99 a month or $26.99 a year.

Can I export Claude chat to Markdown on Desktop?

No. Download Claude conversations injects only on claude.ai in Chrome. Claude Desktop never shows the Markdown dropdown. Open the same thread on claude.ai if it exists there.

Does export Claude chat to Markdown create a PDF?

No. Markdown is a .md text file. For pages, pick PDF in the same panel instead: it is built in the browser with page size, margins, and a table of contents. PDF needs Google sign-in and counts toward 3 a day on the free plan.

Do I need Pro to export Claude chat to Markdown once?

No. You need no account at all. Markdown exports of single chats are unlimited on the free plan. Pro at $3.99 a month or $26.99 a year only lifts the 3-a-day limit on bulk Export All and PDF.
