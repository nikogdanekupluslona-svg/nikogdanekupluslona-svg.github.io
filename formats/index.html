How do I choose Claude chat export formats?

Open a conversation URL on claude.ai in Chrome, click the orange button beside the message box, pick one of the Claude chat export formats, then click Export. Download Claude conversations assembles the file in the tab. claude.ai has no native Export this chat control in September 2026.

  1. Install Download Claude conversations from the Chrome Web Store.
  2. Reload claude.ai and open a real conversation URL, not the empty composer home.
  3. Click the round orange download button to the right of the message box.
  4. Choose PDF, Markdown, Plain Text, JSON, XML, CSV, or PNG. The last format sticks.
  5. Click Export. Chrome saves the file immediately. For PDF, set the options in the PDF dialog; the first PDF asks for Google sign-in.

No sign-in for Markdown, text, JSON, XML, CSV or PNG: those exports are unlimited, anonymous, and send nothing. Google sign-in appears only for PDF, Export All, or Pro. The extension then sends only the Google email, to check the daily limit and to restore Pro after a reinstall. Chat text is never uploaded. Mechanics: how it works.

The export panel also sets Messages (All, Human, Assistant), a Thinking checkbox, and Select, which ticks individual messages. Copy puts Markdown, text, JSON, XML or CSV on the clipboard instead of a file; it is unlimited, and not available for PDF or PNG. Tool / MCP steps and web search sources are switched on in Settings. Metadata and artifact layout (Original, Inline, Nested, Flat) are Dashboard options; the layout decides whether artifacts sit inside the file or in their own folder in the ZIP.

Do Claude chat export formats work in Export All?

Yes. Open the extension popup → View and Download All Conversations, filter the list, tick the chats, pick any of the seven formats as Chat format, then click Export All. You get one ZIP with one file per chat. Bulk needs Google sign-in; on the free plan every chat in the ZIP uses one of 3 daily PDF or bulk exports. Pro at $3.99 a month or $26.99 a year removes that cap.

The Dashboard lists claude.ai history with search by name, project search, Chat and Cowork tabs, and filters All conversations, New, Updated, and Previously exported. New means not yet exported with Download Claude conversations. Previously exported tracks chats you already saved. Export All is not a delayed account ZIP.

The bulk cap is daily. On the free plan, PDF and bulk share 3 exports a day, reset at midnight UTC. Each chat in a ZIP counts as one. If you select more than what is left today, the whole batch is blocked, not cut short. Pick fewer chats, or use Pro.

Bulk has its own include checkboxes — Chats, Thinking, Metadata, Tools, Sources — plus the artifact layout. You do not get a mixed bundle of Markdown plus JSON in one click. You pick one of the Claude chat export formats in the Chat format picker for that run. Run Export All again with a different format if you need two shapes of the same thread; on the free plan that second run counts again.
