Hoe exporteer ik een Claude-chat naar XML?

Open het gesprek op claude.ai in Chrome, klik op de oranje knop naast het berichtvak, kies XML en klik op „Export”. Download Claude conversations schrijft het bestand lokaal. Zo werkt het in versie 1.13.0. claude.ai heeft in september 2026 geen eigen knop om als XML op te slaan.

  1. Installeer Download Claude conversations uit de Chrome Web Store (vermelding beoordeeld met 5,0).
  2. Laad claude.ai opnieuw en open een echte gespreks-URL, niet de lege startpagina met het invoerveld.
  3. Klik op de oranje downloadknop rechts van het berichtvak.
  4. Selecteer XML. Het laatst gebruikte formaat wordt onthouden.
  5. Klik op „Export”. Chrome downloadt de XML via de download-API van de browser.

Voordat je voor het eerst naar XML exporteert, moet je je aanmelden met Google. Download Claude conversations bewaart het geverifieerde e-mailadres om de 3 gratis exports te tellen en Pro na een herinstallatie te herstellen. Chattekst hoort niet bij die aanmelding. Zo werkt het: hoe het werkt.

Zie je de oranje knop niet, dan sta je niet op een gespreks-URL, moet het tabblad opnieuw worden geladen of zit de extensie verstopt in het puzzelstukmenu van Chrome. Zet Download Claude conversations vast en vernieuw claude.ai. XML-export verschijnt nooit in Claude Desktop of Claude Code.

Eén bestand of veel. De oranje knop exporteert het geopende gesprek als XML. Voor veel XML-bestanden open je „View and Download All Conversations” (alle gesprekken bekijken en downloaden) en start je „Export All” met XML geselecteerd — zie bulkexport met Export All.

Wanneer exporteer je een Claude-chat naar XML?

Kies XML als het ontvangende systeem, de pipeline of een oudere tool XML vereist voor gestructureerde uitwisseling. De meeste ontwikkelaars kunnen beter JSON kiezen. Markdown is voor notities, PNG is een afbeelding. XML staat in het keuzemenu omdat sommige tools nog steeds XML inlezen en geen JSON accepteren.

Zie XML niet als een „officiëlere” JSON. Download Claude conversations verwerkt het gesprek in beide gevallen op dezelfde manier. Het verschil zit in de vorm van het bestand; er verschijnen niet ineens extra velden. Vereist niets wat je gebruikt XML, sla dit formaat dan over en kies JSON.

We leveren XML omdat sommige pipelines het nog vereisen, niet omdat we vinden dat het voor elke claude.ai-export beter is dan JSON. De verwerking is hetzelfde: berichten, afzender, optioneel denkstappen en artifacts. PDF maken we nog steeds niet. In versie 1.13.0 is XML een van de vijf formaten, geen betaalde uitbreiding.

Wat blijft behouden bij een export naar XML?

Bij een export naar XML schrijft Download Claude conversations de structuur van het gesprek — berichten, afzender en beschikbare metadata — als XML-opmaak. Denkblokken en artifacts volgen dezelfde schakelaars als bij Markdown en JSON. XML is geen uitgeklede variant van die formaten.

De artifact-indeling is „Original”, „Inline”, „Nested” of „Flat” (origineel, ingevoegd, genest of plat) in versie 1.13.0. Met het afzenderfilter beperk je de XML tot alle berichten, alleen mens of alleen assistent („all / human only / assistant only”). Metadata (titel, tijdstempels, model) kan mee. XML of JSON als ik een Claude-chat exporteer?

JSON is de gebruikelijke keuze voor ontwikkelaars. Kies XML alleen als een systeem verderop in de keten XML vereist. Download Claude conversations maakt XML niet „vollediger” dan JSON. Beide kunnen denkstappen en artifacts bevatten. Geen van beide is de account-ZIP van Anthropic. Overzicht van alle formaten: exportformaten voor Claude-chats.

Settings → Privacy → Export data van Anthropic (de labels kunnen vertaald zijn als claude.ai in het Nederlands staat) levert JSON (in een ZIP), geen XML. Afdrukken → Opslaan als PDF is een momentopname van de webpagina. Geen van beide vervangt de XML-export via de oranje knop. Verwacht niet dat deze XML overeenkomt met een ongepubliceerd schema van Anthropic.

De extensie werkt alleen op claude.ai in Chrome. Claude Desktop en Claude Code krijgen geen XML-knop. Bestaat het gesprek ook op claude.ai, open het daar en exporteer het naar XML. /export van Claude Code is een andere route binnen een ander product.

Kan ik Claude-chats in bulk naar XML exporteren?

Ja. Open „View and Download All Conversations”, zet het formaat op XML, filter de tabel en klik op „Export All” (alles exporteren). Elk voltooid bestand is een van de 3 gratis exports. Pro voor 3,99 $/maand of 26,99 $/jaar heft die limiet op voor XML in bulk.

De overzichtstabel toont je claude.ai-geschiedenis, met zoeken op naam en de filters All, New, Exported en Project. New betekent: nog niet geëxporteerd met Download Claude conversations. Exported houdt bij welke chats je al hebt opgeslagen. Project volgt de manier waarop je chats op claude.ai groepeert. „Export All” levert veel XML-bestanden op, geen gemengde ZIP.

Het quotum geldt per account. Drie gratis exports in totaal — niet drie XML-bestanden per bulkronde. Selecteer je 40 gesprekken, dan kost dat 40 exports als elk bestand voltooid wordt. Plan je selectie, of neem Pro.

XML en JSON mengen in één klik op „Export All” kan niet. Kies voor die ronde XML. Heb je hetzelfde claude.ai-gesprek in beide vormen nodig, draai „Export All” dan nog een keer met JSON; ook die tweede ronde telt mee voor het quotum.

Heb je Pro nodig om een Claude-chat naar XML te exporteren?

Nee. XML valt onder de 3 gratis exports die elk met Google aangemeld account krijgt, net als Markdown, JSON, tekst en PNG. Na die drie bestanden kost Pro 3,99 $ per maand of 26,99 $ per jaar via Paddle. Download Claude conversations behandelt XML niet als betaald formaat.

De 3 gratis exports worden niet opnieuw ingesteld als je de extensie opnieuw installeert. Daarom is aanmelden met Google verplicht bij je eerste export naar XML. Op een nieuwe computer wordt Pro hersteld via hetzelfde Google-account. Paddle is de merchant of record; ons team ziet nooit kaartnummers.

Je hebt geen betaald claude.ai-abonnement van Anthropic nodig, alleen een login waarmee het gesprek in Chrome laadt. Versie 1.13.0, september 2026, schrijft nog steeds geen PDF, Word of Notion. Verandert die lijst, dan wordt deze pagina dezelfde dag bijgewerkt.

FAQ: Claude-chat exporteren naar XML

Deze vragen gaan over exporteren naar XML met Download Claude conversations 1.13.0: de vergelijking met JSON, bulkexport met „Export All”, het quotum, Desktop, PDF en Pro. Elk antwoord is een productfeit. De FAQPage-JSON-LD in de head van de pagina komt overeen met deze lijst.

Is XML beter dan JSON voor exports van Claude-chats?

Niet in het algemeen. JSON is voor ontwikkelaars de gangbaardere keuze. Kies XML als je systeem verderop in de keten XML vereist voor gestructureerde uitwisseling. De verwerking vanuit claude.ai is hetzelfde; alleen de vorm van het bestand verschilt.

Kan ik Claude-chats in bulk naar XML exporteren?

Ja. Dezelfde „Export All”-werkwijze op de overzichtspagina ondersteunt XML. Elk voltooid bestand telt als een van de 3 gratis exports, tenzij je Pro hebt voor 3,99 $/maand of 26,99 $/jaar.

Is XML alleen voor betalende gebruikers?

Nee. Alle vijf formaten, ook XML, vallen onder de 3 gratis exports die elk met Google aangemeld account krijgt. Na die drie bestanden kost Pro 3,99 $/maand of 26,99 $/jaar.

Komt een XML-export overeen met de ZIP van Anthropic?

Nee. Export data van Anthropic is een vertraagde JSON-ZIP van het account. Download Claude conversations schrijft direct in Chrome een XML-bestand per chat (of per selectie). Het schema is niet hetzelfde.

Maakt een export naar XML een PDF?

Nee. XML is opmaakcode. De productformaten zijn Markdown, JSON, platte tekst, XML en PNG. Gebruik voor een afdrukbare pagina het afdrukvenster van Chrome. PNG is een afbeelding, ook geen PDF.

Kan ik in Claude Desktop naar XML exporteren?

Nee. De Chrome-extensie wordt alleen op claude.ai geladen. Claude Desktop toont het XML-menu nooit. Open hetzelfde gesprek op claude.ai in Chrome als het daar bestaat.

Heb ik Pro nodig om één keer naar XML te exporteren?

Nee. De eerste 3 exports zijn gratis, in elk formaat, dus ook XML. Pro voor 3,99 $/maand of 26,99 $/jaar heft de limiet op voor meer losse of bulk-XML-bestanden.
