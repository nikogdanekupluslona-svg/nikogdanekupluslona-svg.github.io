Hoe exporteer ik een Claude-chat naar XML?

Open het gesprek op claude.ai in Chrome, klik op de oranje knop naast het berichtvak, kies XML en klik op „Export”. Download Claude conversations schrijft het bestand lokaal. Zo werkt het in versie 1.16.2. claude.ai heeft in september 2026 geen eigen knop om als XML op te slaan.

  1. Installeer Download Claude conversations uit de Chrome Web Store.
  2. Laad claude.ai opnieuw en open een echte gespreks-URL, niet de lege startpagina met het invoerveld.
  3. Klik op de oranje downloadknop rechts van het berichtvak.
  4. Kies XML. Het laatst gebruikte formaat wordt onthouden. Met „Select” (selecteren) vink je alleen de berichten aan die je wilt.
  5. Klik op „Export”. Chrome downloadt de XML via de download-API van de browser. Of klik op „Copy” (kopiëren) om de XML op het klembord te zetten.

Om een Claude-chat naar XML te exporteren hoef je je niet aan te melden. Losse chats exporteren als XML is onbeperkt en anoniem, en er gaat niets naar onze servers. Om een Google-aanmelding wordt alleen gevraagd bij PDF en bij bulkexport met „Export All”. Zo werkt het: hoe het werkt.

Zie je de oranje knop niet, dan sta je niet op een gespreks-URL, moet het tabblad opnieuw worden geladen of zit de extensie verstopt in het puzzelstukmenu van Chrome. Zet Download Claude conversations vast en vernieuw claude.ai. XML-export verschijnt nooit in Claude Desktop of in de terminal van Claude Code.

Eén bestand of veel. De oranje knop exporteert het geopende gesprek als XML. Voor veel XML-bestanden open je „View and Download All Conversations” (alle gesprekken bekijken en downloaden) en start je „Export All” met XML geselecteerd: één ZIP, 3 chats per dag in de gratis versie — zie bulkexport met Export All.

Wanneer exporteer je een Claude-chat naar XML?

Kies XML als het ontvangende systeem, de pipeline of een oudere tool XML vereist voor gestructureerde uitwisseling. De meeste ontwikkelaars kunnen beter JSON kiezen. Markdown is voor notities, CSV voor spreadsheets, PNG is een afbeelding. XML staat in het keuzemenu omdat sommige tools nog steeds XML inlezen en geen JSON accepteren.

Zie XML niet als een „officiëlere” JSON. Download Claude conversations verwerkt het gesprek in beide gevallen op dezelfde manier. Het verschil zit in de vorm van het bestand; er verschijnen niet ineens extra velden. Vereist niets wat je gebruikt XML, sla dit formaat dan over en kies JSON.

We leveren XML omdat sommige pipelines het nog vereisen, niet omdat we vinden dat het voor elke claude.ai-export beter is dan JSON. De verwerking is hetzelfde: berichten, afzender, optioneel denkstappen en artifacts. In versie 1.16.2 is XML een van de zeven formaten, gratis en zonder account, geen betaalde uitbreiding.

Wat blijft behouden bij een export naar XML?

Bij een export naar XML schrijft Download Claude conversations de structuur van het gesprek — berichten, afzender en beschikbare metadata — als XML-opmaak. Denkblokken, bronnen van webzoekopdrachten, tool-/MCP-stappen en artifacts volgen dezelfde opties als bij Markdown en JSON: „Thinking” (denkstappen) is een vakje in het exportpaneel, tools en bronnen zet je aan in de instellingen. XML is geen uitgeklede variant van die formaten.

De artifact-indeling is „Original”, „Inline”, „Nested” of „Flat” (origineel, ingevoegd, genest of plat) in versie 1.16.2. Met het afzenderfilter beperk je de XML tot alle berichten, alleen mens of alleen assistent („all / human only / assistant only”). Metadata (titel, tijdstempels, model) kan mee. XML of JSON als ik een Claude-chat exporteer?

JSON is de gebruikelijke keuze voor ontwikkelaars. Kies XML alleen als een systeem verderop in de keten XML vereist. Download Claude conversations maakt XML niet „vollediger” dan JSON. Beide kunnen denkstappen en artifacts bevatten. Geen van beide is de account-ZIP van Anthropic. Overzicht van alle formaten: exportformaten voor Claude-chats.

Settings → Privacy → Export data van Anthropic (de labels kunnen vertaald zijn als claude.ai in het Nederlands staat) levert JSON (in een ZIP), geen XML. PDF uit hetzelfde paneel levert pagina's voor mensen, geen opmaakcode. Geen van beide vervangt de XML-export via de oranje knop. Verwacht niet dat deze XML overeenkomt met een ongepubliceerd schema van Anthropic.

De extensie werkt alleen op claude.ai in Chrome. Claude Desktop en de terminal van Claude Code krijgen geen XML-knop. Claude Code op het web (claude.ai/code) draait op claude.ai, dus dat exporteer je zoals elke chat. Bestaat een gesprek ook op claude.ai, open het daar en exporteer het naar XML. /export van Claude Code in de terminal is een andere route binnen een ander product.

Kan ik Claude-chats in bulk naar XML exporteren?

Ja. Open „View and Download All Conversations”, zet „Chat format” (chatformaat) op XML, filter de tabel en klik op „Export All” (alles exporteren). Chrome slaat één ZIP op met één XML-bestand per chat. In de gratis versie zijn dat 3 chats per dag met een Google-aanmelding, gedeeld met PDF. Pro voor 3,99 $ per maand of 26,99 $ per jaar heft die limiet op voor XML in bulk.

Het Dashboard toont je claude.ai-geschiedenis, met zoeken op naam, de filters All conversations, New, Updated en Previously exported (alle gesprekken, nieuw, bijgewerkt, eerder geëxporteerd), de tabbladen Chat en Cowork en zoeken op project. New betekent: nog niet geëxporteerd met Download Claude conversations. Previously exported houdt bij welke chats je al hebt opgeslagen. „Export All” levert één ZIP met XML-bestanden per chat op, geen archief met gemengde formaten.

De daglimiet geldt per account. Drie chats per dag in de gratis versie, gedeeld met PDF. Selecteer je 40 gesprekken terwijl je er nog 3 over hebt, dan wordt de hele batch geblokkeerd, niet ingekort. Selecteer er minder of neem Pro. Losse XML-exports via de oranje knop blijven onbeperkt.

XML en JSON mengen in één klik op „Export All” kan niet. Kies voor die ronde XML. Heb je hetzelfde claude.ai-gesprek in beide vormen nodig, draai „Export All” dan nog een keer met JSON; in die tweede ronde telt elke chat opnieuw mee.

Heb je Pro nodig om een Claude-chat naar XML te exporteren?

Nee. Eén chat exporteren naar XML is gratis en onbeperkt, zonder account en zonder teller — net als Markdown, JSON, tekst, CSV en PNG. Alleen PDF en bulkexport met „Export All” hebben een gratis limiet: 3 per dag met een Google-aanmelding. Pro kost 3,99 $ per maand of 26,99 $ per jaar via Paddle. Download Claude conversations behandelt XML niet als betaald formaat.

Bij XML in bulk merk je de limiet wel. Elke chat in een ZIP van „Export All” gebruikt een van de 3 per dag, en de telling begint opnieuw om middernacht UTC. Pro heft de limiet op en wordt op een nieuwe computer hersteld via hetzelfde Google-account. Paddle is de merchant of record; ons team ziet nooit kaartnummers.

Je hebt geen betaald claude.ai-abonnement van Anthropic nodig, alleen een login waarmee het gesprek in Chrome laadt. Versie 1.16.2, september 2026, schrijft nog steeds geen Word of Notion. Verandert die lijst, dan wordt deze pagina dezelfde dag bijgewerkt.

FAQ: Claude-chat exporteren naar XML

Deze vragen gaan over exporteren naar XML met Download Claude conversations 1.16.2: de vergelijking met JSON, bulkexport met „Export All”, kosten, Desktop, PDF en Pro. Elk antwoord is een productfeit. De FAQPage-JSON-LD in de head van de pagina komt overeen met deze lijst.

Is XML beter dan JSON voor exports van Claude-chats?

Niet in het algemeen. JSON is voor ontwikkelaars de gangbaardere keuze. Kies XML als je systeem verderop in de keten XML vereist voor gestructureerde uitwisseling. De verwerking vanuit claude.ai is hetzelfde; alleen de vorm van het bestand verschilt.

Kan ik Claude-chats in bulk naar XML exporteren?

Ja. Dezelfde „Export All”-werkwijze op het Dashboard ondersteunt XML en slaat één ZIP op met een XML-bestand per chat. In de gratis versie gaat dat om 3 chats per dag met een Google-aanmelding; Pro voor 3,99 $ per maand of 26,99 $ per jaar is onbeperkt.

Is XML alleen voor betalende gebruikers?

Nee. Losse chats exporteren als XML is onbeperkt en vraagt geen account, net als Markdown, tekst, JSON, CSV en PNG. Alleen PDF en bulkexport met „Export All” hebben een gratis limiet van 3 per dag. Pro kost 3,99 $ per maand of 26,99 $ per jaar.

Komt een XML-export overeen met de ZIP van Anthropic?

Nee. Export data van Anthropic is een vertraagde JSON-ZIP van het account. Download Claude conversations schrijft direct in Chrome een XML-bestand per chat (of per selectie). Het schema is niet hetzelfde.

Maakt een export naar XML een PDF?

Nee. XML is opmaakcode. Wil je pagina's, kies dan PDF in hetzelfde paneel; de zeven formaten zijn PDF, Markdown, JSON, platte tekst, XML, CSV en PNG. Voor PDF meld je je aan met Google, en in de gratis versie telt het mee voor de 3 per dag.

Kan ik in Claude Desktop naar XML exporteren?

Nee. De Chrome-extensie wordt alleen op claude.ai geladen. Claude Desktop toont het XML-menu nooit. Open hetzelfde gesprek op claude.ai in Chrome als het daar bestaat.

Heb ik Pro nodig om één keer naar XML te exporteren?

Nee. Je hebt helemaal geen account nodig. Losse chats exporteren als XML is onbeperkt in de gratis versie. Pro voor 3,99 $ per maand of 26,99 $ per jaar heft alleen de limiet van 3 per dag op voor bulkexport met „Export All” en voor PDF.
