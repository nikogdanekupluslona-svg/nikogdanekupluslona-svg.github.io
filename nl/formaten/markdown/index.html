Hoe exporteer ik een Claude-chat naar Markdown?

Open het gesprek op claude.ai in Chrome, klik op de oranje knop naast het berichtvak, kies Markdown en klik op „Export”. Download Claude conversations schrijft lokaal een .md-bestand. Zo werkt het in versie 1.16.2.

  1. Installeer Download Claude conversations uit de Chrome Web Store.
  2. Laad claude.ai opnieuw en open een echte gespreks-URL, niet de lege startpagina met het invoerveld.
  3. Klik op de oranje downloadknop rechts van het berichtvak.
  4. Kies Markdown. De extensie onthoudt het laatst gebruikte formaat. Met „Select” (selecteren) vink je alleen de berichten aan die je wilt.
  5. Klik op „Export”. Chrome downloadt het .md-bestand via de download-API van de browser. Of klik op „Copy” (kopiëren) om de Markdown op het klembord te zetten.

Om een Claude-chat naar Markdown te exporteren hoef je je niet aan te melden. Losse chats exporteren als Markdown is onbeperkt en anoniem, en er gaat niets naar onze servers. Om een Google-aanmelding wordt alleen gevraagd bij PDF en bij bulkexport met „Export All”. Zo werkt het: hoe het werkt.

Zie je de oranje knop niet, dan sta je niet op een gespreks-URL, moet het tabblad na de installatie opnieuw worden geladen of zit de extensie nog verstopt in het puzzelstukmenu van Chrome. Zet Download Claude conversations vast en vernieuw claude.ai. Het contentscript wordt nooit geladen in Claude Desktop of in de terminal van Claude Code.

Eén chat of veel. De oranje knop exporteert het geopende gesprek als Markdown. Voor veel .md-bestanden open je „View and Download All Conversations” (alle gesprekken bekijken en downloaden) en start je „Export All” met Markdown geselecteerd: één ZIP, 3 chats per dag in de gratis versie — zie bulkexport met Export All.

Waarom een Claude-chat naar Markdown exporteren voor notities?

Kies Markdown als je het bestand leest in Obsidian, een GitHub-wiki of een editor die koppen en codeblokken weergeeft. Het .md-bestand blijft platte tekst waarin je kunt zoeken en die je kunt vergelijken. JSON is beter voor parsers; PNG is een afbeelding waarin grep niets vindt.

Kopiëren en plakken vanuit claude.ai laat meestal de inspringing wegvallen en maakt tabellen plat. Afdrukken (Ctrl/Cmd+P) neemt de zijbalk mee en breekt een lang codeblok vaak over meerdere pagina's. Bij een export naar Markdown blijven taallabels op de codeblokken staan en blijven tabellen tabellen. Daarom kiezen schrijvers dit formaat als eerste.

We zien Markdown als het standaardbestand voor mensen: koppen, codeblokken met taallabels en tabellen uit het claude.ai-gesprek. Heb je liever pagina's, kies dan PDF in hetzelfde paneel. Die wordt in de browser opgemaakt, met paginaformaat, marges en een inhoudsopgave.

Wat blijft behouden bij een export naar Markdown?

Bij een export naar Markdown behoudt Download Claude conversations koppen, codeblokken met taallabel en inspringing, tabellen en links. Denkblokken, bronnen van webzoekopdrachten en tool-/MCP-stappen zijn elk optioneel: „Thinking” (denkstappen) is een vakje in het exportpaneel, de andere twee zet je aan in de instellingen. Metadata (titel, tijdstempels, model) kan mee. Met het afzenderfilter beperk je het .md-bestand tot alle berichten, alleen mens of alleen assistent („all / human only / assistant only”).

De artifact-indeling is een echte schakelaar in versie 1.16.2: „Original”, „Inline”, „Nested” of „Flat” (origineel, ingevoegd, genest of plat). Een Markdown-export kan de artifact-structuur op het scherm spiegelen, alles plat maken tot één doorlopend document, of artifacts in een eigen map in een ZIP zetten. In de instellingen kun je afbeeldingen in het .md-bestand insluiten. Volledige lijst: functies van de Chrome-extensie. Markdown bewaart geen kleuren van berichtballonnen; gebruik PNG voor een visuele momentopname of PDF voor pagina's.

Een half geladen gesprek levert een half gevuld .md-bestand op. Dat lijkt op een bug, maar meestal is er gewoon niet ver genoeg gescrold.

Kan ik Claude-chats in bulk naar Markdown exporteren?

Ja. Open „View and Download All Conversations”, zet „Chat format” (chatformaat) op Markdown, filter de tabel en klik op „Export All”. Chrome slaat één ZIP op met één .md-bestand per chat. In de gratis versie zijn dat 3 chats per dag met een Google-aanmelding, gedeeld met PDF. Pro voor 3,99 $ per maand of 26,99 $ per jaar heft die limiet op voor Markdown in bulk.

Het Dashboard toont je claude.ai-geschiedenis, met zoeken op naam, de filters All conversations, New, Updated en Previously exported (alle gesprekken, nieuw, bijgewerkt, eerder geëxporteerd), de tabbladen Chat en Cowork en zoeken op project. New betekent: nog niet geëxporteerd met Download Claude conversations. Previously exported houdt bij welke chats je al hebt opgeslagen, zodat een tweede „Export All” ze kan overslaan.

De daglimiet geldt per account. Drie chats per dag in de gratis versie, gedeeld met PDF. Selecteer je 40 gesprekken terwijl je er nog 3 over hebt, dan wordt de hele batch geblokkeerd, niet ingekort. Selecteer er minder of neem Pro. Losse .md-exports via de oranje knop blijven onbeperkt.

Markdown in bulk gebruikt de vakjes „Chats”, „Thinking”, „Metadata”, „Tools” en „Sources” (chats, denkstappen, metadata, tools en bronnen) op het Dashboard, plus het artifact-formaat. „Export All” is niet de vertraagde ZIP van Anthropic, maar één ZIP met .md-bestanden per chat. Wil je één archief van het hele account, dan is dat Settings → Privacy → Export data (de labels kunnen vertaald zijn als claude.ai in het Nederlands staat) — en dat is JSON, geen Markdown.

Markdown of JSON als ik een Claude-chat exporteer?

Kies Markdown als een mens het bestand gaat lezen. Kies JSON als een script de berichtenboom gaat verwerken. Download Claude conversations biedt beide in één keuzemenu, plus PDF, platte tekst, XML, CSV en PNG. Overzicht van alle formaten: exportformaten voor Claude-chats.

Export data van Anthropic is ook JSON, maar dat is een account-ZIP per e-mail, geen .md-bestand per chat. In dat verzoek kun je geen Markdown kiezen. Afdrukken via de browser is een momentopname van de webpagina. Geen van beide vervangt de Markdown-export via de oranje knop.

De extensie werkt alleen op claude.ai in Chrome. Claude Desktop en de terminal van Claude Code krijgen geen Markdown-knop. Claude Code op het web (claude.ai/code) draait op claude.ai, dus dat exporteer je zoals elke chat. Bestaat een gesprek ook op claude.ai, open het daar en exporteer het naar Markdown. /export van Claude Code in de terminal is een andere route binnen een ander product.

Kost exporteren naar Markdown extra?

Nee. Eén chat exporteren naar Markdown is gratis en onbeperkt, zonder account en zonder teller — net als JSON, tekst, XML, CSV en PNG. Alleen PDF en bulkexport met „Export All” hebben een gratis limiet: 3 per dag met een Google-aanmelding. Pro kost 3,99 $ per maand of 26,99 $ per jaar via Paddle. Download Claude conversations rekent geen toeslag voor Markdown.

Bij Markdown in bulk merk je de limiet wel. Elke chat in een ZIP van „Export All” gebruikt een van de 3 per dag, en de telling begint opnieuw om middernacht UTC. Pro heft de limiet op en wordt op een nieuwe computer hersteld via hetzelfde Google-account. Paddle is de merchant of record; ons team ziet nooit kaartnummers.

Je hebt geen betaald claude.ai-abonnement van Anthropic nodig, alleen een login waarmee het gesprek in Chrome laadt. Team en Enterprise werken met de oranje knop net zo als Free. Versie 1.16.2, september 2026, schrijft nog steeds geen Word of Notion.

FAQ: Claude-chat exporteren naar Markdown

Deze vragen gaan over exporteren naar Markdown met Download Claude conversations 1.16.2: codeblokken, bulkexport met „Export All”, de ZIP van Anthropic, kosten, PDF en Desktop. Elk antwoord is een productfeit. De FAQPage-JSON-LD in de head van de pagina komt overeen met deze lijst.

Gaat er code verloren bij een export naar Markdown?

Nee. Codeblokken behouden hun taallabel en inspringing, anders dan bij gewoon kopiëren en plakken vanuit claude.ai. Tabellen blijven Markdown-tabellen. Dat is de belangrijkste reden om naar Markdown te exporteren in plaats van tekst met de hand te selecteren.

Kan ik Claude-chats in bulk naar Markdown exporteren?

Ja. „Export All” op het Dashboard ondersteunt Markdown en slaat één ZIP met .md-bestanden op. In de gratis versie gaat dat om 3 chats per dag met een Google-aanmelding; met Pro is het onbeperkt.

Is Markdown hetzelfde als Export data van Anthropic?

Nee. De officiële export van Anthropic is een JSON-ZIP van je hele account, die je na een wachttijd per e-mail krijgt. Een export naar Markdown is een .md-bestand per chat (of per selectie) van Download Claude conversations.

Kost Markdown meer dan andere formaten?

Nee. Losse chats exporteren als Markdown is onbeperkt en vraagt geen account, net als JSON, tekst, XML, CSV en PNG. Alleen PDF en bulk-ZIP hebben een gratis limiet van 3 per dag. Pro kost 3,99 $ per maand of 26,99 $ per jaar.

Kan ik in Claude Desktop naar Markdown exporteren?

Nee. Download Claude conversations wordt alleen op claude.ai in Chrome geladen. Claude Desktop toont het Markdown-menu nooit. Open hetzelfde gesprek op claude.ai als het daar bestaat.

Maakt een export naar Markdown een PDF?

Nee. Markdown is een .md-tekstbestand. Wil je pagina's, kies dan PDF in hetzelfde paneel: dat wordt in de browser gemaakt, met paginaformaat, marges en een inhoudsopgave. Voor PDF meld je je aan met Google, en in de gratis versie telt het mee voor de 3 per dag.

Heb ik Pro nodig om één keer naar Markdown te exporteren?

Nee. Je hebt helemaal geen account nodig. Losse chats exporteren als Markdown is onbeperkt in de gratis versie. Pro voor 3,99 $ per maand of 26,99 $ per jaar heft alleen de limiet van 3 per dag op voor bulkexport met „Export All” en voor PDF.
