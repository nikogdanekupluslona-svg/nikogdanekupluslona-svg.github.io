Hoe exporteer ik een Claude-chat naar Markdown?

Open het gesprek op claude.ai in Chrome, klik op de oranje knop naast het berichtvak, kies Markdown en klik op „Export”. Download Claude conversations schrijft lokaal een .md-bestand. Zo werkt het in versie 1.13.0.

  1. Installeer Download Claude conversations uit de Chrome Web Store (vermelding beoordeeld met 5,0).
  2. Laad claude.ai opnieuw en open een echte gespreks-URL, niet de lege startpagina met het invoerveld.
  3. Klik op de oranje downloadknop rechts van het berichtvak.
  4. Selecteer Markdown. De extensie onthoudt het laatst gebruikte formaat.
  5. Klik op „Export”. Chrome downloadt het .md-bestand via de download-API van de browser.

Voordat je voor het eerst naar Markdown exporteert, moet je je aanmelden met Google. Download Claude conversations bewaart het geverifieerde e-mailadres om de 3 gratis exports te tellen en Pro na een herinstallatie te herstellen. Voor die aanmelding wordt geen chattekst geüpload. Zo werkt het: hoe het werkt.

Zie je de oranje knop niet, dan sta je niet op een gespreks-URL, moet het tabblad na de installatie opnieuw worden geladen of zit de extensie nog verstopt in het puzzelstukmenu van Chrome. Zet Download Claude conversations vast en vernieuw claude.ai. Het contentscript wordt nooit geladen in Claude Desktop of Claude Code.

Eén chat of veel. De oranje knop exporteert het geopende gesprek als Markdown. Voor veel .md-bestanden open je „View and Download All Conversations” (alle gesprekken bekijken en downloaden) en start je „Export All” met Markdown geselecteerd — zie bulkexport met Export All.

Waarom een Claude-chat naar Markdown exporteren voor notities?

Kies Markdown als je het bestand leest in Obsidian, een GitHub-wiki of een editor die koppen en codeblokken weergeeft. Het .md-bestand blijft platte tekst waarin je kunt zoeken en die je kunt vergelijken. JSON is beter voor parsers; PNG is een afbeelding waarin grep niets vindt.

Kopiëren en plakken vanuit claude.ai laat meestal de inspringing wegvallen en maakt tabellen plat. Afdrukken (Ctrl/Cmd+P) neemt de zijbalk mee en breekt een lang codeblok vaak over meerdere pagina's. Bij een export naar Markdown blijven taallabels op de codeblokken staan en blijven tabellen tabellen. Daarom kiezen schrijvers dit formaat als eerste.

We zien Markdown als het standaardbestand voor mensen: koppen, codeblokken met taallabels en tabellen uit het claude.ai-gesprek. We verzinnen nog steeds geen PDF-formaat — heb je een afdrukbare pagina nodig, gebruik dan het afdrukvenster van Chrome, na de export naar Markdown of in plaats daarvan.

Wat blijft behouden bij een export naar Markdown?

Bij een export naar Markdown behoudt Download Claude conversations koppen, codeblokken met taallabel en inspringing, tabellen en links. Denkblokken zijn optioneel. Metadata (titel, tijdstempels, model) kan mee. Met het afzenderfilter beperk je het .md-bestand tot alle berichten, alleen mens of alleen assistent („all / human only / assistant only”).

De artifact-indeling is een echte schakelaar in versie 1.13.0: „Original”, „Inline”, „Nested” of „Flat” (origineel, ingevoegd, genest of plat). Een Markdown-export kan de artifact-structuur op het scherm spiegelen of alles plat maken tot één doorlopend document. Alle schakelaars: functies van de Chrome-extensie. Markdown bewaart geen kleuren van berichtballonnen; gebruik PNG als je een visuele momentopname nodig hebt.

Is het gesprek erg lang, scrol dan tot claude.ai de eerdere berichten heeft geladen voordat je naar Markdown exporteert. De extensie kan alleen schrijven wat de pagina heeft weergegeven. Een half geladen gesprek levert een half gevuld .md-bestand op. Dat lijkt op een bug, maar meestal is er gewoon niet ver genoeg gescrold.

Kan ik Claude-chats in bulk naar Markdown exporteren?

Ja. Open „View and Download All Conversations”, zet het formaat op Markdown, filter de tabel en klik op „Export All”. Elk voltooid .md-bestand telt als één export van dezelfde 3 gratis exports als een losse export met de oranje knop. Pro voor 3,99 $/maand of 26,99 $/jaar heft die limiet op voor Markdown in bulk.

De overzichtstabel toont je claude.ai-geschiedenis, met zoeken op naam en de filters All, New, Exported en Project. New betekent: nog niet geëxporteerd met Download Claude conversations. Exported houdt bij welke chats je al hebt opgeslagen, zodat een tweede „Export All” ze kan overslaan. Project volgt de manier waarop je chats op claude.ai groepeert.

Het quotum geldt per account. Drie gratis exports in totaal — niet drie Markdown-bestanden per dag. Selecteer je 40 gesprekken, dan kost dat 40 exports als elk .md-bestand voltooid wordt. Plan je selectie voordat je op „Export All” klikt.

Markdown in bulk gebruikt dezelfde schakelaars voor denkstappen, metadata, afzender en artifacts als één gesprek. „Export All” is niet de vertraagde ZIP van Anthropic, maar levert veel losse .md-bestanden per chat op. Wil je één archief van het hele account, dan is dat Settings → Privacy → Export data (de labels kunnen vertaald zijn als claude.ai in het Nederlands staat) — en dat is JSON, geen Markdown.

Markdown of JSON als ik een Claude-chat exporteer?

Kies Markdown als een mens het bestand gaat lezen. Kies JSON als een script de berichtenboom gaat verwerken. Download Claude conversations biedt beide in één keuzemenu, plus platte tekst, XML en PNG. PDF is er nog steeds niet. Overzicht van alle formaten: exportformaten voor Claude-chats.

Export data van Anthropic is ook JSON, maar dat is een account-ZIP per e-mail, geen .md-bestand per chat. In dat verzoek kun je geen Markdown kiezen. Afdrukken → Opslaan als PDF is een momentopname van de webpagina. Geen van beide vervangt de Markdown-export via de oranje knop.

De extensie werkt alleen op claude.ai in Chrome. Claude Desktop en Claude Code krijgen geen Markdown-knop. Bestaat het gesprek ook op claude.ai, open het daar en exporteer het naar Markdown. /export van Claude Code is een andere route binnen een ander product.

Kost exporteren naar Markdown extra?

Nee. Markdown valt onder de 3 gratis exports die elk met Google aangemeld account krijgt, net als JSON, tekst, XML en PNG. Na die drie bestanden kost Pro 3,99 $ per maand of 26,99 $ per jaar via Paddle. Download Claude conversations rekent geen toeslag voor Markdown.

De 3 gratis exports worden niet opnieuw ingesteld als je de extensie opnieuw installeert. Daarom is aanmelden met Google verplicht bij je eerste export naar Markdown. Op een nieuwe computer wordt Pro hersteld via hetzelfde Google-account. Paddle is de merchant of record; ons team ziet nooit kaartnummers.

Je hebt geen betaald claude.ai-abonnement van Anthropic nodig, alleen een login waarmee het gesprek in Chrome laadt. Team en Enterprise werken met de oranje knop net zo als Free. Versie 1.13.0, september 2026, schrijft nog steeds geen Word, Notion of PDF.

FAQ: Claude-chat exporteren naar Markdown

Deze vragen gaan over exporteren naar Markdown met Download Claude conversations 1.13.0: codeblokken, bulkexport met „Export All”, de ZIP van Anthropic, het quotum en Desktop. Elk antwoord is een productfeit. De FAQPage-JSON-LD in de head van de pagina komt overeen met deze lijst.

Gaat er code verloren bij een export naar Markdown?

Nee. Codeblokken behouden hun taallabel en inspringing, anders dan bij gewoon kopiëren en plakken vanuit claude.ai. Tabellen blijven Markdown-tabellen. Dat is de belangrijkste reden om naar Markdown te exporteren in plaats van tekst met de hand te selecteren.

Kan ik Claude-chats in bulk naar Markdown exporteren?

Ja. „Export All” op de overzichtspagina ondersteunt Markdown net als een export van één chat. Elk voltooid .md-bestand telt als een van de 3 gratis exports, tenzij je Pro hebt.

Is Markdown hetzelfde als Export data van Anthropic?

Nee. De officiële export van Anthropic is een JSON-ZIP van je hele account, die je na een wachttijd per e-mail krijgt. Een export naar Markdown is een .md-bestand per chat (of per selectie) van Download Claude conversations.

Kost Markdown meer dan andere formaten?

Nee. Markdown valt onder de 3 gratis exports op elk met Google aangemeld account, net als JSON, tekst, XML en PNG. Daarna kost Pro 3,99 $/maand of 26,99 $/jaar voor onbeperkt veel bestanden.

Kan ik in Claude Desktop naar Markdown exporteren?

Nee. Download Claude conversations wordt alleen op claude.ai in Chrome geladen. Claude Desktop toont het Markdown-menu nooit. Open hetzelfde gesprek op claude.ai als het daar bestaat.

Maakt een export naar Markdown een PDF?

Nee. Markdown is een .md-tekstbestand. Het product levert geen PDF. Gebruik voor een afdrukbare pagina het afdrukvenster van Chrome. PNG is een afbeelding, ook geen PDF.

Heb ik Pro nodig om één keer naar Markdown te exporteren?

Nee. De eerste 3 exports zijn gratis, in elk formaat, dus ook Markdown. Pro voor 3,99 $/maand of 26,99 $/jaar heft de limiet op voor meer losse of bulk-.md-bestanden.
