Hoe exporteer ik een Claude-gesprek als JSON?

Open het gesprek op claude.ai in Chrome, klik op de oranje knop naast het berichtvak, kies JSON en klik op „Export”. Download Claude conversations schrijft het bestand lokaal. Zo werkt het in versie 1.13.0. claude.ai heeft in september 2026 geen eigen knop om één chat als JSON op te slaan.

  1. Installeer Download Claude conversations uit de Chrome Web Store (vermelding beoordeeld met 5,0).
  2. Laad claude.ai opnieuw en open een echte gespreks-URL, niet de lege startpagina met het invoerveld.
  3. Klik op de oranje downloadknop rechts van het berichtvak.
  4. Selecteer JSON. Het laatst gebruikte formaat wordt onthouden.
  5. Klik op „Export”. Chrome downloadt de JSON via de download-API van de browser.

Voordat je voor het eerst als JSON exporteert, moet je je aanmelden met Google. Download Claude conversations bewaart het geverifieerde e-mailadres om de 3 gratis exports te tellen en Pro na een herinstallatie te herstellen. De inhoud van chats hoort niet bij die aanmelding. Zo werkt het: hoe het werkt.

Zie je de oranje knop niet, dan sta je niet op een gespreks-URL, moet het tabblad opnieuw worden geladen of zit de extensie verstopt in het puzzelstukmenu van Chrome. Zet Download Claude conversations vast en vernieuw claude.ai. Het contentscript wordt nooit geladen in Claude Desktop of Claude Code.

Eén gesprek of veel bestanden. De oranje knop exporteert de geopende chat als JSON. Voor veel JSON-bestanden open je „View and Download All Conversations” (alle gesprekken bekijken en downloaden) en start je „Export All” met JSON geselecteerd — zie bulkexport met Export All.

Wanneer exporteer je een Claude-gesprek als JSON?

Kies JSON als een script, indexeerder of diff-tool het bestand gaat lezen. De JSON is gebouwd rond de berichtenboom, niet om in Obsidian te lezen. Wil je koppen en codeblokken voor mensen, kies dan Markdown.

Kopiëren en plakken vanuit claude.ai verliest wie wat zei. Afdrukken neemt de opmaak van de webpagina mee. Bij een JSON-export houdt Download Claude conversations beurten, afzenders en optionele denkstappen vast als data, niet als één platgeslagen alinea. Daarom kiezen ontwikkelaars JSON boven platte tekst.

We schrijven JSON op basis van de claude.ai-boom die al op de pagina staat — afzender, contentblokken, tijdstempels, modelmetadata — zonder het gesprek te uploaden. Die JSON is niet de account-ZIP van Anthropic, en ook geen PDF. Versie 1.13.0 levert nog steeds precies vijf formaten.

Het team van Download Claude conversations

Mensen zoeken dezelfde extensie ook als Claude Chat Downloader en Claude Conversation Downloader. Exporteren als JSON gaat via die oranje knop, niet via een tweede product. Op juridische pagina's staat soms nog Claude Exporter.

Wat zit er in een JSON-export van een Claude-gesprek?

Een JSON-export volgt de berichtenboom op claude.ai: afzender, contentblokken, tijdstempels en modelmetadata. Denkblokken en artifacts komen erin als die schakelaars aan staan. Met het afzenderfilter beperk je het bestand tot alle berichten, alleen mens of alleen assistent („all / human only / assistant only”). Niets wordt eerst naar Markdown platgeslagen.

De artifact-indeling in versie 1.13.0 is „Original”, „Inline”, „Nested” of „Flat” (origineel, ingevoegd, genest of plat). Die indelingen bepalen hoe artifact-inhoud in de JSON is genest — dezelfde vier opties als bij Markdown en XML. Alle schakelaars: functies van de Chrome-extensie. JSON wordt nog steeds geen PDF.

JSON van een Claude-gesprek of Export data van Anthropic?

Beide zijn JSON, maar met een andere vorm en reikwijdte. Via Settings → Privacy → Export data (de labels kunnen vertaald zijn als claude.ai in het Nederlands staat) mailt Anthropic na een wachttijd één ZIP van het hele account. Met deze extensie krijg je meteen één gesprek in Chrome. Gebruik de ZIP als back-up.

In het ZIP-verzoek van Anthropic kun je geen Markdown kiezen. Je kunt de JSON van deze extensie ook niet gebruiken als directe vervanging voor het schema van die ZIP. Overzicht van alle formaten: exportformaten voor Claude-chats. Afdrukken is een visuele noodoplossing, geen JSON-export.

Download Claude conversations is niet verbonden aan Anthropic, PBC. Het contentscript gebruikt de sessie die je al op claude.ai hebt geopend en logt niet met aparte inloggegevens in bij Anthropic. Houd je aan de regels van Anthropic voor je account.

Kan ik Claude-gesprekken in bulk als JSON exporteren?

Ja. Open „View and Download All Conversations”, zet het formaat op JSON, filter de tabel en klik op „Export All” (alles exporteren). Elk voltooid bestand is een van de 3 gratis exports. Pro voor 3,99 $/maand of 26,99 $/jaar heft die limiet op voor JSON in bulk.

De overzichtstabel toont je claude.ai-geschiedenis, met zoeken op naam en de filters All, New, Exported en Project. New betekent: nog niet geëxporteerd met Download Claude conversations. Exported houdt bij welke chats je al hebt opgeslagen. Project volgt de manier waarop je chats op claude.ai groepeert. „Export All” levert veel JSON-bestanden op, geen gemengde ZIP.

Het quotum geldt per account. Drie gratis exports in totaal — niet drie JSON-bestanden per bulkronde. Selecteer je 40 gesprekken, dan kost dat 40 exports als elk bestand voltooid wordt. Plan je selectie, of neem Pro.

Twee JSON-exports van hetzelfde claude.ai-gesprek, gemaakt op verschillende momenten, kun je vergelijken zoals je elk JSON-bestand vergelijkt. Elke export staat op zichzelf. Een tweede „Export All” van dezelfde chats kost opnieuw quotum, tenzij die bestanden niet voltooid worden.

Heb je Pro nodig om een Claude-gesprek als JSON te exporteren?

Nee. JSON valt onder de 3 gratis exports die elk met Google aangemeld account krijgt, net als Markdown, tekst, XML en PNG. Na die drie bestanden kost Pro 3,99 $ per maand of 26,99 $ per jaar via Paddle. Download Claude conversations rekent niets extra voor JSON.

De 3 gratis exports worden niet opnieuw ingesteld als je de extensie opnieuw installeert. Daarom is aanmelden met Google verplicht bij de eerste klik op „Export”. Op een nieuwe computer wordt Pro hersteld via hetzelfde Google-account. Paddle is de merchant of record; ons team ziet nooit kaartnummers.

De extensie werkt alleen op claude.ai in Chrome. Claude Desktop en Claude Code krijgen geen JSON-knop. /export van Claude Code of JSONL op schijf is een andere route. Versie 1.13.0, september 2026, schrijft nog steeds geen PDF, Word of Notion.

FAQ: Claude-gesprek exporteren als JSON

Deze vragen gaan over exporteren als JSON met Download Claude conversations 1.13.0: bulkexport met „Export All”, het schema, het quotum, diffs, de ZIP van Anthropic en Desktop. Elk antwoord is een productfeit. De FAQPage-JSON-LD in de head van de pagina komt overeen met deze lijst.

Kan ik Claude-gesprekken in bulk als JSON exporteren?

Ja. „Export All” op de overzichtspagina ondersteunt JSON net als een losse export. Elk voltooid bestand telt als een van de 3 gratis exports, tenzij je Pro hebt voor 3,99 $/maand of 26,99 $/jaar.

Is de JSON-structuur gedocumenteerd?

Ze volgt de eigen berichtenboom van claude.ai: afzender, contentblokken, tijdstempels en modelmetadata, met artifacts en denkblokken erbij als je die schakelaars aanzet. Het is niet het schema van de account-ZIP van Anthropic.

Heb ik Pro nodig om een Claude-gesprek als JSON te exporteren?

Nee. JSON valt onder de 3 gratis exports die elk met Google aangemeld account krijgt, net als elk ander formaat. Na die drie bestanden kost Pro 3,99 $/maand of 26,99 $/jaar.

Kan ik twee JSON-exports van één chat vergelijken?

Ja. Elke JSON-export is een zelfstandig bestand dat op dezelfde manier is opgebouwd. Twee exports van hetzelfde gesprek op verschillende momenten vergelijk je net als elk ander JSON-bestand.

Is deze JSON hetzelfde als Export data van Anthropic?

Nee. Export data van Anthropic is een vertraagde ZIP van het hele account. Download Claude conversations schrijft direct in Chrome een JSON-bestand per chat (of per selectie). Beide kunnen JSON zijn; uitwisselbaar zijn ze niet.

Maakt een JSON-export een PDF?

Nee. JSON is gestructureerde data. De productformaten zijn Markdown, JSON, platte tekst, XML en PNG. Gebruik voor een afdrukbare pagina het afdrukvenster van Chrome, niet dit keuzemenu.

Werkt de JSON-export in Claude Desktop?

Nee. De Chrome-extensie wordt alleen op claude.ai geladen. Claude Desktop toont de JSON-optie nooit. Open hetzelfde gesprek op claude.ai in Chrome als het daar bestaat.
