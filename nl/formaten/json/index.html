Hoe exporteer ik een Claude-gesprek als JSON?

Open het gesprek op claude.ai in Chrome, klik op de oranje knop naast het berichtvak, kies JSON en klik op „Export”. Download Claude conversations schrijft het bestand lokaal. Zo werkt het in versie 1.16.2. claude.ai heeft in september 2026 geen eigen knop om één chat als JSON op te slaan.

  1. Installeer Download Claude conversations uit de Chrome Web Store.
  2. Laad claude.ai opnieuw en open een echte gespreks-URL, niet de lege startpagina met het invoerveld.
  3. Klik op de oranje downloadknop rechts van het berichtvak.
  4. Kies JSON. Het laatst gebruikte formaat wordt onthouden. Met „Select” (selecteren) vink je alleen de berichten aan die je wilt.
  5. Klik op „Export”. Chrome downloadt de JSON via de download-API van de browser. Of klik op „Copy” (kopiëren) om de JSON op het klembord te zetten.

Om een Claude-gesprek als JSON te exporteren hoef je je niet aan te melden. Losse chats exporteren als JSON is onbeperkt en anoniem, en er gaat niets naar onze servers. Om een Google-aanmelding wordt alleen gevraagd bij PDF en bij bulkexport met „Export All”. Zo werkt het: hoe het werkt.

Zie je de oranje knop niet, dan sta je niet op een gespreks-URL, moet het tabblad opnieuw worden geladen of zit de extensie verstopt in het puzzelstukmenu van Chrome. Zet Download Claude conversations vast en vernieuw claude.ai. Het contentscript wordt nooit geladen in Claude Desktop of in de terminal van Claude Code.

Eén gesprek of veel bestanden. De oranje knop exporteert de geopende chat als JSON. Voor veel JSON-bestanden open je „View and Download All Conversations” (alle gesprekken bekijken en downloaden) en start je „Export All” met JSON geselecteerd: één ZIP, 3 chats per dag in de gratis versie — zie bulkexport met Export All.

Wanneer exporteer je een Claude-gesprek als JSON?

Kies JSON als een script, indexeerder of diff-tool het bestand gaat lezen. De JSON is gebouwd rond de berichtenboom, niet om in Obsidian te lezen. Wil je koppen en codeblokken voor mensen, kies dan Markdown. Voor een spreadsheet kies je CSV: één rij per bericht.

Kopiëren en plakken vanuit claude.ai verliest wie wat zei. Afdrukken neemt de opmaak van de webpagina mee. Bij een JSON-export houdt Download Claude conversations beurten, afzenders en optionele denkstappen vast als data, niet als één platgeslagen alinea. Daarom kiezen ontwikkelaars JSON boven platte tekst.

We schrijven JSON op basis van de claude.ai-boom die al op de pagina staat — afzender, contentblokken, tijdstempels, modelmetadata — zonder het gesprek te uploaden. Die JSON is niet de account-ZIP van Anthropic. In versie 1.16.2 is het een van zeven formaten, naast PDF en CSV, en het is gratis, zonder account.

Wat zit er in een JSON-export van een Claude-gesprek?

Een JSON-export volgt de berichtenboom op claude.ai: afzender, contentblokken, tijdstempels en modelmetadata. Denkblokken, bronnen van webzoekopdrachten, tool-/MCP-stappen en artifacts komen erin als die opties aan staan: „Thinking” (denkstappen) is een vakje in het exportpaneel, tools en bronnen zet je aan in de instellingen. Met het afzenderfilter beperk je het bestand tot alle berichten, alleen mens of alleen assistent („all / human only / assistant only”). Niets wordt eerst naar Markdown platgeslagen.

De artifact-indeling in versie 1.16.2 is „Original”, „Inline”, „Nested” of „Flat” (origineel, ingevoegd, genest of plat). Die indelingen bepalen hoe artifact-inhoud in de JSON is genest — dezelfde vier opties als bij Markdown en XML. Volledige lijst: functies van de Chrome-extensie. Wil je pagina's in plaats van data, exporteer dan PDF.

JSON van een Claude-gesprek of Export data van Anthropic?

Beide zijn JSON, maar met een andere vorm en reikwijdte. Via Settings → Privacy → Export data (de labels kunnen vertaald zijn als claude.ai in het Nederlands staat) mailt Anthropic na een wachttijd één ZIP van het hele account. Met deze extensie krijg je meteen één gesprek in Chrome. Gebruik de ZIP als back-up.

Settings → Privacy → Export data Het hele account E-mail met een link die verloopt

In het ZIP-verzoek van Anthropic kun je geen Markdown kiezen. Je kunt de JSON van deze extensie ook niet gebruiken als directe vervanging voor het schema van die ZIP. Overzicht van alle formaten: exportformaten voor Claude-chats. PDF is om te lezen, geen JSON-export.

Download Claude conversations is niet verbonden aan Anthropic, PBC. Het contentscript gebruikt de sessie die je al op claude.ai hebt geopend en logt niet met aparte inloggegevens in bij Anthropic. Houd je aan de regels van Anthropic voor je account.

Kan ik Claude-gesprekken in bulk als JSON exporteren?

Ja. Open „View and Download All Conversations”, zet „Chat format” (chatformaat) op JSON, filter de tabel en klik op „Export All” (alles exporteren). Chrome slaat één ZIP op met één JSON-bestand per chat. In de gratis versie zijn dat 3 chats per dag met een Google-aanmelding, gedeeld met PDF. Pro voor 3,99 $ per maand of 26,99 $ per jaar heft die limiet op voor JSON in bulk.

Het Dashboard toont je claude.ai-geschiedenis, met zoeken op naam, de filters All conversations, New, Updated en Previously exported (alle gesprekken, nieuw, bijgewerkt, eerder geëxporteerd), de tabbladen Chat en Cowork en zoeken op project. New betekent: nog niet geëxporteerd met Download Claude conversations. Previously exported houdt bij welke chats je al hebt opgeslagen. „Export All” levert één ZIP met JSON-bestanden per chat op, geen archief met gemengde formaten.

De daglimiet geldt per account. Drie chats per dag in de gratis versie, gedeeld met PDF. Selecteer je 40 gesprekken terwijl je er nog 3 over hebt, dan wordt de hele batch geblokkeerd, niet ingekort. Selecteer er minder of neem Pro. Losse JSON-exports via de oranje knop blijven onbeperkt.

Twee JSON-exports van hetzelfde claude.ai-gesprek, gemaakt op verschillende momenten, kun je vergelijken zoals je elk JSON-bestand vergelijkt. Elke export staat op zichzelf. Bij een tweede „Export All” van dezelfde chats telt elke chat opnieuw mee.

Heb je Pro nodig om een Claude-gesprek als JSON te exporteren?

Nee. Eén chat exporteren als JSON is gratis en onbeperkt, zonder account en zonder teller — net als Markdown, tekst, XML, CSV en PNG. Alleen PDF en bulkexport met „Export All” hebben een gratis limiet: 3 per dag met een Google-aanmelding. Pro kost 3,99 $ per maand of 26,99 $ per jaar via Paddle. Download Claude conversations rekent niets extra om een Claude-gesprek als JSON te exporteren.

Bij JSON in bulk merk je de limiet wel. Elke chat in een ZIP van „Export All” gebruikt een van de 3 per dag, en de telling begint opnieuw om middernacht UTC. Pro heft de limiet op en wordt op een nieuwe computer hersteld via hetzelfde Google-account. Paddle is de merchant of record; ons team ziet nooit kaartnummers.

De extensie werkt alleen op claude.ai in Chrome. Claude Desktop en de terminal van Claude Code krijgen geen JSON-knop; Claude Code op het web (claude.ai/code) draait op claude.ai, dus dat exporteer je zoals elke chat. /export van Claude Code in de terminal of JSONL op schijf is een andere route. Versie 1.16.2, september 2026, schrijft nog steeds geen Word of Notion.

FAQ: Claude-gesprek exporteren als JSON

Deze vragen gaan over exporteren als JSON met Download Claude conversations 1.16.2: bulkexport met „Export All”, het schema, kosten, diffs, de ZIP van Anthropic, PDF en Desktop. Elk antwoord is een productfeit. De FAQPage-JSON-LD in de head van de pagina komt overeen met deze lijst.

Kan ik Claude-gesprekken in bulk als JSON exporteren?

Ja. „Export All” op het Dashboard ondersteunt JSON en slaat één ZIP op met één JSON-bestand per chat. In de gratis versie gaat dat om 3 chats per dag met een Google-aanmelding; Pro voor 3,99 $ per maand of 26,99 $ per jaar is onbeperkt.

Is de JSON-structuur gedocumenteerd?

Ze volgt de eigen berichtenboom van claude.ai: afzender, contentblokken, tijdstempels en modelmetadata, met artifacts, denkblokken, bronnen van webzoekopdrachten en tool-/MCP-stappen erbij als je die opties aanzet. Het is niet het schema van de account-ZIP van Anthropic.

Heb ik Pro nodig om een Claude-gesprek als JSON te exporteren?

Nee. Losse chats exporteren als JSON is onbeperkt en vraagt geen account, net als elk ander formaat behalve PDF. Pro voor 3,99 $ per maand of 26,99 $ per jaar heft alleen de limiet van 3 per dag op voor PDF en bulkexport met „Export All”.

Kan ik twee JSON-exports van één chat vergelijken?

Ja. Elke JSON-export is een zelfstandig bestand dat op dezelfde manier is opgebouwd. Twee exports van hetzelfde gesprek op verschillende momenten vergelijk je net als elk ander JSON-bestand.

Is deze JSON hetzelfde als Export data van Anthropic?

Nee. Export data van Anthropic is een vertraagde ZIP van het hele account. Download Claude conversations schrijft direct in Chrome een JSON-bestand per chat (of per selectie). Beide kunnen JSON zijn; uitwisselbaar zijn ze niet.

Maakt een JSON-export een PDF?

Nee. JSON is gestructureerde data. Wil je pagina's, kies dan PDF in hetzelfde paneel; de zeven formaten zijn PDF, Markdown, JSON, platte tekst, XML, CSV en PNG. Voor PDF meld je je aan met Google, en in de gratis versie telt het mee voor de 3 per dag.

Werkt de JSON-export in Claude Desktop?

Nee. De Chrome-extensie wordt alleen op claude.ai geladen. Claude Desktop toont de JSON-optie nooit. Open hetzelfde gesprek op claude.ai in Chrome als het daar bestaat.
