Een Claude Code-gesprek exporteren doe je in de terminal. Typ /export in de sessie, of kopieer de JSONL uit ~/.claude/projects. Hoe exporteer je een Claude Code-gesprek in de terminal?

Met het commando /export in een interactieve CLI-sessie. De documentatie van Anthropic beschrijft een menu waarmee je het huidige gesprek kopieert of als platte tekst opslaat, met berichten en tooluitvoer als leesbare tekst. Geef een bestandsnaam mee om het menu over te slaan en direct dat bestand te schrijven.

Dit is geen Markdown van claude.ai, geen JSON van deze Chrome-extensie en geen PDF. Het is een leesbaar transcript voor mensen. Volgens Anthropic is het JSONL-logboek op schijf een ander, intern formaat voor het product zelf, niet bedoeld als publieke API.

/export

Om de vraag over te slaan en een bestand met een naam in de huidige werkmap te schrijven:

/export my-session

De sessiedocumentatie van Anthropic is de bron voor opties en bestandsnamen; die veranderen tussen versies van Claude Code. Zie blogs uit de community als secundair. Komt de tekst in het dialoogvenster van /export niet overeen met wat jij ziet, dan heb je een andere build van de CLI — gebruik de hulp in het product, niet een schermafbeelding uit 2025.

Voor scripts wijst Anthropic naar andere interfaces: claude -p met --output-format json of stream-json, hervatten via een sessie-ID, hooks die een transcript_path ontvangen, of de Agent SDK. Dat zijn ontwikkelaarsingangen van Claude Code, niet de Chrome-extensie van deze website.

Leesbaar of gestructureerd. /export is het transcript voor mensen. JSONL in de map projects is het logboek. De JSON van de Chrome-extensie is een derde vorm, alleen gemaakt vanaf een claude.ai-pagina. Schrijf niet één parser voor alle drie.

Hoe download je een Claude Code-gesprek van schijf?

Kopieer het JSONL-bestand van de sessie uit de map projects, of voer /export uit voor een leesbaar transcript. Het standaardpad op macOS en Linux ligt onder ~/.claude/projects/. Op Windows is het %USERPROFILE%\.claude\projects. De bestandsnamen zijn sessie-ID's.

De naam van de projectmap is de werkmap waarin tekens die geen letter of cijfer zijn, door koppeltekens zijn vervangen. Anthropic kort heel lange omgezette namen in en voegt een hash toe, zodat de map binnen de limieten van het bestandssysteem blijft. Vind je de map niet, dan heb je Claude Code vanuit een andere werkmap gestart dan je denkt.

Elke JSONL-regel is een JSON-object voor een bericht, een toolaanroep of metadata. Anthropic geeft aan dat dit formaat intern is en tussen versies verandert. Scripts die deze bestanden verwerken, kunnen breken bij een nieuwe release van Claude Code. Kies /export of de gedocumenteerde scriptinterfaces als je iets stabiels nodig hebt.

De opslag kan verhuizen. CLAUDE_CONFIG_DIR verplaatst de configuratiemap weg van ~/.claude. CLAUDE_CODE_PROJECT_DIR_NAME bepaalt de naam van de projectmap in combinatie met die configuratiemap (Claude Code v2.1.234 of later, volgens Anthropic). cleanupPeriodDays in settings.json wijzigt de standaard bewaartermijn. Geen van die instellingen is een functie van Download Claude conversations.

Claude Code-gesprekken downloaden als back-up komt dus neer op: de map kopiëren, of volgens een vast schema transcripten exporteren met /export. Deze site krijgt geen knop om JSONL te importeren. We lezen je thuismap niet.

Kun je een Claude Code-gesprek exporteren met deze extensie?

Nee. Download Claude conversations werkt niet voor Claude Code. De Chrome-extensie wordt in claude.ai geladen. Ze kan de terminal niet zien, /export niet uitvoeren en geen JSONL openen. Zocht je hoe je een Claude Code-gesprek downloadt, houd je dan aan de CLI-stappen op deze pagina.

Mensen komen hier terecht omdat Google „Claude” en „exporteren” bij elkaar zet. De vermelding in de Web Store blijft alleen voor claude.ai. De extensie installeren zet geen oranje knop in iTerm, Ghostty, de terminal van VS Code of de desktopomgeving van Claude Code.

Houd je voor dezelfde programmeerklus ook een parallel gesprek bij op claude.ai, dan kun je die browserchat wel met de extensie opslaan. De twee verslagen worden niet samengevoegd. Toolaanroepen die alleen in de CLI gebeurden, verschijnen niet in de webexport, tenzij je ze daar hebt geplakt.

Elke week krijgen we dezelfde supportmail: iemand heeft de Chrome-extensie geïnstalleerd en verwachtte dat /export zou verschijnen. Wij verwerken alleen claude.ai. Claude Code heeft /export en JSONL al ingebouwd. Een schil om de CLI zou een ander product zijn, en dat hebben we niet uitgebracht.

Waar bewaart Claude Code de gespreksgeschiedenis?

Claude Code bewaart de gespreksgeschiedenis als JSONL-transcripten in de map projects van de configuratiemap. Standaard op macOS en Linux: ~/.claude/projects/<encoded-cwd>/<session-id>.jsonl. Windows gebruikt %USERPROFILE%\.claude\projects. Anthropic kan die indeling wijzigen; kijk in de actuele sessiedocumentatie als een pad op schijf ontbreekt.

Hervatten is iets anders dan exporteren. claude --continue en claude --resume laden een sessie opnieuw, zodat je verder kunt werken. /export schrijft een kopie die je in git kunt zetten of kunt mailen. Het ene herstelt de context, het andere geeft je een verslag om mee te nemen. De sessiepagina van Anthropic behandelt de rechtenmodus bij hervatten, compact/samenvatting en de sessiekiezer — niets daarvan hoort bij deze extensie.

Volgens Anthropic houden de desktop-app, Claude Code op het web en de VS Code-extensie elk hun eigen sessiegeschiedenis bij. De paden in deze gids gelden voor de CLI. Ga er niet van uit dat een Cowork-transcript uit Desktop in dezelfde JSONL-map staat die je vanuit de terminal gebruikt.

Behandel JSONL niet als publiek schema. Anthropic zegt dat het regelformaat verandert. Verwerk je het toch, zet dan een vaste versie van Claude Code vast en reken op breuk. /export is de stabiele manier om een leesbaar Claude Code-gesprek te krijgen.

Omgevingsvariabelen zoals CLAUDE_CODE_SKIP_PROMPT_HISTORY kunnen het schrijven van transcripten onderdrukken. Is de map projects leeg, controleer dan of je het opslaan hebt uitgeschakeld, CLAUDE_CONFIG_DIR ergens anders naartoe laat wijzen, of in die map nooit een interactieve sessie hebt gedraaid.

Hoe download je in plaats daarvan een Claude-chat op claude.ai?

Installeer Download Claude conversations, open het gesprek in Chrome, klik op de oranje knop en kies Markdown, JSON, tekst, XML of PNG. Dat is het browserproduct, geen export van Claude Code. Stap voor stap: een Claude-chat downloaden.

Je hele claude.ai-geschiedenis als losse bestanden gaat via „Export All” (alles exporteren) op de overzichtspagina, niet via /export. Elk bestand telt mee voor de 3 gratis exports, tenzij je Pro hebt. Gids: bulkexport met Export All. Formaten: formaten.

Bij de eerste export op claude.ai moet je je aanmelden met Google, zodat we het quotum kunnen tellen en Pro kunnen herstellen. Bestanden worden lokaal gemaakt. Paddle rekent Pro af voor 3,99 $/maand of 26,99 $/jaar. Niets daarvan geldt voor /export in de terminal.

Begon je werk in Claude Code en heb je een samenvatting in claude.ai geplakt, download dan het webgesprek voor je notities en bewaar /export voor het echte CLI-logboek. Twee bestanden zijn beter dan één verwarrend bestand.

Claude Code-export of de officiële Export data van Anthropic?

Een Claude Code-export (/export of JSONL) is één terminalsessie. De officiële Export data is Settings → Privacy → Export data op claude.ai (de labels kunnen vertaald zijn als claude.ai in het Nederlands staat): een vertraagde JSON-ZIP van het Anthropic-account. Dat zijn verschillende archieven. De ZIP vervangt /export niet.

Of een bepaalde Claude Code-sessie in de account-ZIP terechtkomt, hangt af van hoe Anthropic dat product opslaat, niet van deze extensie. Behandel de ZIP als back-up van je webaccount, tenzij de actuele privacydocumentatie van Anthropic iets anders zegt. Wij voegen geen CLI-sessies aan die ZIP toe.

Hoe je een Claude-chat van de website exporteert, inclusief die ZIP tegenover de extensie, staat hier: hoe exporteer je een Claude-chat. Een webpagina afdrukken als PDF werkt niet voor een terminalinterface. Kijk alleen bij afdrukken / PDF als het gesprek in de browser staat.

Exporteren uit Claude Code, Desktop of claude.ai?

Claude Code, Claude Desktop en claude.ai zijn drie verschillende omgevingen. Een Claude Code-gesprek exporteer je met /export en JSONL. Desktop is een app zonder de oranje knop van deze extensie. claude.ai in Chrome is de enige plek waar Download Claude conversations draait. Wie de namen door elkaar haalt, ziet exports ongemerkt mislukken.

Claude Desktop: is de chat met hetzelfde Anthropic-account gesynchroniseerd, open hem dan op claude.ai en exporteer daar. Bestaat hij alleen in het Desktop-venster, kopieer en plak dan, of wacht op de officiële Export data. Gids: een Claude Desktop-chat exporteren.

Het Claude Code-paneel in VS Code staat dichter bij de CLI dan bij claude.ai. Verwacht niet dat ons contentscript in die webview wordt geladen. Gebruik /export in de sessie die de berichten echt bevat.

We kunnen geen juridisch advies geven over het kopiëren van tooluitvoer met bedrijfseigen code; dat is een zaak tussen jou, je werkgever en Anthropic.

FAQ: Claude Code-gesprek exporteren

Hoe exporteer ik een Claude Code-gesprek?

Typ in de terminal van Claude Code /export (eventueel met een bestandsnaam) om een leesbaar transcript op te slaan, of kopieer het JSONL-bestand uit ~/.claude/projects op macOS/Linux of %USERPROFILE%\.claude\projects op Windows. De sessiedocumentatie van Anthropic beschrijft het huidige dialoogvenster.

Downloadt deze Chrome-extensie Claude Code-chats?

Nee. Download Claude conversations werkt alleen op claude.ai in Chrome. De extensie kan geen terminalsessies, JSONL-transcripten of het commando /export lezen. Een Claude Code-export blijft in de CLI.

Waar bewaart Claude Code de gespreksgeschiedenis?

Sessietranscripten zijn JSONL-bestanden onder ~/.claude/projects/<encoded-working-directory>/, genoemd naar het sessie-ID. De precieze indeling kan veranderen. Gebruik /export als je een leesbaar bestand wilt in plaats van JSONL te verwerken. CLAUDE_CONFIG_DIR kan de map verplaatsen.

Hoe download ik een Claude Code-gesprek als Markdown?

/export van Claude Code levert een transcript in platte tekst, niet de Markdown van deze extensie. Heb je echt Markdown nodig, exporteer dan een claude.ai-kopie van het werk met Download Claude conversations, of zet de tekst van /export zelf om. Wij zetten JSONL niet om naar Markdown.

Hoe download ik in plaats daarvan een claude.ai-gesprek?

Installeer de gratis Chrome-extensie, open de chat op claude.ai en gebruik de oranje knop — of „Export All” voor je geschiedenis. Zie een Claude-chat downloaden. 3 gratis exports; Pro kost 3,99 $/maand of 26,99 $/jaar.

Is /export hetzelfde als de officiële Export data?

Nee. /export gaat over de huidige Claude Code-sessie. Settings → Privacy → Export data mailt een JSON-ZIP van het Anthropic-account. Andere productomgevingen, andere bestanden, andere wachttijden.

Kan ik Claude Code-JSONL verwerken met jq?

Dat kan, met het voorbehoud dat Anthropic zelf noemt: het regelschema is intern en kan veranderen. Kies /export of claude -p --output-format json als je vaste afspraken nodig hebt. Zet je CLI-versie vast als je JSONL toch verwerkt.

Werkt een Claude Code-export op Windows?

Ja. /export is een CLI-commando. Transcripten op schijf staan onder %USERPROFILE%\.claude\projects, tenzij je CLAUDE_CONFIG_DIR instelt. Deze Chrome-extensie draait ook dan niet in die terminal.

Is Claude Code hetzelfde als Claude Desktop?

Nee. Claude Code is de programmeeragent in de terminal. Claude Desktop is de chat-app. claude.ai is de website. Alleen de website krijgt deze extensie. Notities over exporteren uit Desktop: Claude Desktop.

Komt deze extensie ooit met een schil om /export?

Niet in versie 1.13.0. De scope van het product is claude.ai: vijf formaten, lokale bestanden, Google-aanmelding voor het quotum. Verandert die scope, dan staat dat op deze pagina. Gebruik tot die tijd de CLI van Anthropic om Claude Code-gesprekken te exporteren.

Bevat /export ook tooluitvoer?

Anthropic beschrijft /export als berichten en tooluitvoer, weergegeven als leesbare tekst. Dat is hun transcript, niet onze parser. Voor de precieze actuele inhoud voer je /export uit op jouw build en lees je het bestand — documentatie kan een release achterlopen.

Kan ik Claude Code-sessies in bulk exporteren?

Niet met „Export All” van deze extensie. Bulk op onze overzichtspagina is alleen voor claude.ai. Voor veel CLI-sessies kopieer je de map projects of voer je per sessie /export uit. Er is geen bulkknop voor JSONL.
