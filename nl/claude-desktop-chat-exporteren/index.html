Waarom kan ik hier geen Claude Desktop-chat exporteren?

Download Claude conversations is een contentscript voor claude.ai in Chrome. Claude Desktop is een losse app voor Mac en Windows. Dat venster heeft geen werkbalk voor extensies, dus de oranje knop verschijnt er nooit. De extensie in Chrome installeren terwijl Desktop open staat, doet niets met Desktop.

Chrome-extensies draaien op pagina's die bij hun hostrechten passen. Deze extensie past bij gesprekspagina's van claude.ai. Claude Desktop is geen claude.ai-tabblad. Binnen de Desktop-app kun je niets „toevoegen aan Chrome”. Versie 1.13.0 (september 2026) heeft nog steeds geen Desktop-plug-in, geen hulpje in de menubalk en geen lezer voor de installatiemap van Desktop.

Harde grens. Met deze Chrome-extensie kun je vanuit Desktop geen Claude Desktop-chat exporteren. Wil je Markdown, JSON, tekst, XML of PNG uit onze knop, verlaat Desktop dan, open https://claude.ai in Chrome en open het gesprek daar.

Mensen zoeken op „Claude Desktop-chat exporteren” (of in het Engels op „export Claude Desktop chat”) omdat de producten dezelfde merknaam delen. Zoekresultaten halen Desktop, claude.ai en Claude Code door elkaar. De bestanden zijn niet uitwisselbaar. Een schermafbeelding van Desktop is geen Markdown-export. Een JSONL-logboek van Code is geen claude.ai-gesprek. Deze pagina bestaat om dat verschil duidelijk te maken.

Claude Desktop-chat exporteren of claude.ai en Code?

Claude Desktop is de chat-app. claude.ai is het browserproduct. Claude Code is de terminalagent. Alleen claude.ai in Chrome krijgt Download Claude conversations. Een Desktop-chat exporteren vraagt dus om een omweg, niet om een oranje knop in de app.

Hoe exporteer ik een Claude Desktop-chat via claude.ai?

Veel Desktop-sessies gebruiken hetzelfde Claude-account als het web. Staat het gesprek in je claude.ai-geschiedenis, open het dan in Chrome en gebruik Download Claude conversations. Alleen zo helpt deze extensie je bij een Desktop-chat: het gesprek moet eerst op claude.ai laden.

  1. Stop met zoeken in Desktop. Open https://claude.ai in Chrome en meld je aan met hetzelfde account.
  2. Zoek het gesprek in je webgeschiedenis. Ontbreekt het, ga dan door naar kopiëren en plakken of Export data — we kunnen geen chat ophalen die Chrome nooit heeft geladen.
  3. Klik op de oranje knop. Kies Markdown, JSON, platte tekst, XML of PNG. Klik op „Export” (exporteren).
  4. Voor veel gesynchroniseerde gesprekken open je „View and Download All Conversations” (alle gesprekken bekijken en downloaden) en start je „Export All” (alles exporteren).
  5. Heb je een pagina in PDF-stijl nodig van wat je op het web ziet, druk dan af vanuit Chrome — wij leveren geen PDF. Gids: afdrukken / PDF.

De Google-aanmelding bij de eerste webexport telt de 3 gratis exports en herstelt Pro voor 3,99 $/maand of 26,99 $/jaar. Dat quotum geldt alleen voor claude.ai-bestanden. Kopiëren en plakken in Desktop kost geen quotum, omdat de extensie er niet aan te pas komt. Paddle rekent Pro af; wij zien nooit kaartnummers.

Synchronisatie is gedrag van Anthropic, niet van ons. Toont Desktop een chat die claude.ai niet toont, dan kan deze Chrome-extensie hem niet verzinnen. Wacht, vernieuw claude.ai, of gebruik kopiëren en plakken of de officiële ZIP. We lezen de lokale database van Desktop niet. Hoe de webexport werkt zodra het tabblad bestaat: hoe het werkt.

Formaten zodra je op claude.ai bent. Markdown voor notities, JSON voor tools, tekst voor een kaal archief, XML voor uitwisseling, PNG voor een afbeelding. Dezelfde vijf als in elke andere gids. Overzicht: formaten. Geen van die formaten verschijnt via deze extensie in de Desktop-app.

Kan ik een Claude Desktop-chat exporteren door te kopiëren en plakken?

Ja. Selecteer tekst in Claude Desktop en plak die in een document. Dat is de eerlijke noodoplossing als het gesprek niet op claude.ai verschijnt. Je verliest nette codeblokken, artifact-indelingen, de schakelaar voor denkstappen en bulkexport met „Export All”. Prima voor een kort antwoord; pijnlijk voor een lang programmeergesprek.

Kopiëren en plakken uit Desktop is precies waarom de Chrome-extensie op claude.ai bestaat: de webknop behoudt taallabels, tabellen en artifacts in de indelingen „Original”, „Inline”, „Nested” of „Flat” (origineel, ingevoegd, genest, plat). Desktop krijgt van ons geen van die exportopties. Kun je hetzelfde gesprek naar claude.ai halen, stop dan met kopiëren en plakken en gebruik daar Download Claude conversations.

Schermafbeeldingen van Claude Desktop zijn een andere noodoplossing. Het zijn afbeeldingen, geen Markdown. Ze tellen niet als een Desktop-chat exporteren in de zin van een herbruikbaar bestand. De PNG van onze extensie is ook een afbeelding, maar die wordt pas gemaakt als de chat op claude.ai open staat. Verwacht die PNG niet uit het Desktop-venster.

Bevat Export data ook Claude Desktop-chats?

Settings → Privacy → Export data van Anthropic (de labels kunnen vertaald zijn als claude.ai in het Nederlands staat) mailt een JSON-ZIP die aan het Claude-account hangt, niet aan het venster waarin je typte. Is een Desktop-gesprek in dat account opgeslagen, dan kan het erin staan. Zie de ZIP als back-up, niet als Markdown van deze extensie.

De ZIP is traag, de link verloopt en je kunt geen formaat kiezen voor Markdown, tekst, XML of PNG. Toch is het de officiële manier om je account mee te nemen als je je Claude Desktop-geschiedenis in één geheel wilt exporteren. Vergelijking met afdrukken en de Chrome-knop: hoe exporteer je een Claude-chat.

Verwar die ZIP niet met „Export All” op onze overzichtspagina. „Export All” schrijft meteen losse bestanden die je op claude.ai selecteert, in het formaat dat je kiest, en elk bestand kost een van de 3 gratis exports (of valt onder Pro). De officiële Export data gebruikt ons quotum niet. Desktop-chats die nooit zijn gesynchroniseerd, kunnen in beide ontbreken.

Is Claude Desktop hetzelfde als Claude Code?

Nee. Claude Desktop is de chat-app. Claude Code is de programmeeragent in de terminal, met /export en JSONL-transcripten. Wie een Desktop-chat wil exporteren maar eigenlijk een terminal in een IDE bedoelt, zit bij het verkeerde product. Deze Chrome-extensie draait in geen van beide.

Bedoelde je met „desktop” VS Code of een terminal op je computer, volg dan Claude Code-gesprek exporteren. Bedoelde je de chat-app Claude Desktop van Anthropic, blijf dan op deze pagina. Wie de twee door elkaar haalt, verliest tijd: JSONL op schijf is geen oranje knop, en kopiëren en plakken in Desktop is geen /export.

Download Claude conversations krijgt geen koppeling met Code alleen omdat Desktop en Code allebei „niet de browser” zijn. Het product is bewust smal: claude.ai in Chrome, vijf formaten, 3 gratis exports, Pro 3,99 $/maand of 26,99 $/jaar. Scope van de functies: functies. Dezelfde webknop, maar vanuit het idee „extraheren”: Claude-gesprekken extraheren.

Wat we niet doen om een Claude Desktop-chat te exporteren

We leveren geen Claude Desktop-plug-in, geen menubalk-app en geen schakelaar „exporteren uit Desktop”. We lezen geen bestanden uit je Claude Desktop-installatie op Mac of Windows. We vervangen /export van Claude Code niet. Die zinnen vormen de productgrens voor Desktop-chats in 1.13.0.

We noemen ook geen andere Chrome-exporttools. Officiële onderdelen van Anthropic — claude.ai, Claude Desktop, Claude Code, Settings → Privacy → Export data — noemen we hier ter vergelijking. Download Claude conversations blijft onafhankelijk, niet verbonden aan Anthropic, PBC. De beoordeling van 5,0 in de Chrome Web Store op deze pagina geldt voor de webextensie, niet voor een Desktop-product dat niet bestaat.

Werk je alleen in Desktop, gebruik dan kopiëren en plakken en de officiële ZIP, totdat Anthropic in de app een export per chat uitbrengt. Gebruik je ook claude.ai, installeer dan de extensie en exporteer vanuit de browser. Dat is ons hele eerlijke aanbod. Mobiele Claude-apps vallen evengoed buiten deze extensie.

Quotum op de webroute. Zodra je een gesynchroniseerde chat op claude.ai opent, zijn 3 exports gratis; daarna kost Pro 3,99 $/maand of 26,99 $/jaar. Kopiëren en plakken in Desktop verhoogt die teller nooit. Aanmelden met Google is alleen nodig als je de Chrome-knop echt gebruikt.

Problemen oplossen: extensie geïnstalleerd maar geen knop in Desktop — dat klopt. Knop ontbreekt op claude.ai — laad opnieuw, zet het pictogram vast, open een gespreks-URL. Chat staat in Desktop maar niet op het web — geen bug van de extensie. Verkeerd product (Code of Desktop) — kijk of je in een terminal zit. Heb je op het web toch een visuele kopie in PDF-stijl nodig — druk af, en wacht niet op een PDF-formaat dat we niet leveren.

FAQ: Claude Desktop-chat exporteren

Deze vragen gaan over het exporteren van een Claude Desktop-chat: waarom de oranje knop ontbreekt, hoe je claude.ai gebruikt als het gesprek synchroniseert, kopiëren en plakken, de officiële Export data en Claude Code. De antwoorden gelden voor versie 1.13.0. Het FAQPage-schema in de head komt overeen met deze lijst.

Kan ik een Claude Desktop-chat exporteren met deze extensie?

Nee. Download Claude conversations draait op claude.ai in Chrome. De oranje knop verschijnt nooit in het venster van Claude Desktop. Versie 1.13.0 heeft geen Desktop-plug-in.

Hoe exporteer ik een Claude Desktop-gesprek?

Open dezelfde chat op claude.ai in Chrome als hij synchroniseert en gebruik daar de extensie of druk af. Anders kopieer en plak je vanuit Desktop, of gebruik je Settings → Privacy → Export data voor een JSON-ZIP van het hele account.

Is Claude Desktop hetzelfde als Claude Code?

Nee. Desktop is de chat-app. Claude Code is de terminalagent met /export en JSONL-transcripten. Deze Chrome-extensie draait in geen van beide.

Bevat de officiële Export data ook Desktop-chats?

De account-ZIP hangt aan je Claude-account. Is een Desktop-gesprek daar opgeslagen, dan kan het erin staan. Het blijft een back-up-ZIP, geen Markdown per chat van deze extensie.

Werkt het exporteren van een Desktop-chat als ik claude.ai open?

Ja, voor gesprekken die op claude.ai laden. Dan kan Download Claude conversations Markdown, JSON, tekst, XML of PNG schrijven. Chats die nooit synchroniseren, blijven aangewezen op kopiëren en plakken of de ZIP.

Kan deze extensie mijn installatiemap van Claude Desktop lezen?

Nee. We doorzoeken geen Desktop-bestanden op Mac of Windows. Het contentscript ziet alleen een claude.ai-pagina die Chrome al heeft weergegeven.

Heb ik Pro nodig om een Desktop-chat op het web te exporteren?

Niet voor de eerste 3 webexports. Daarna kost Pro 3,99 $/maand of 26,99 $/jaar. Kopiëren en plakken in Desktop gebruikt ons quotum niet.

Kan ik met deze tool een Claude Desktop-chat als PDF exporteren?

Nee. Ook op claude.ai leveren we geen PDF. Druk af vanuit Chrome zodra de chat op het web staat, of neem genoegen met PNG als afbeelding. Voor Desktop hebben we geen afdrukroute.

Exporteert „Toevoegen aan Chrome” een Claude Desktop-chat?

Nee. Download Claude conversations installeren heeft alleen effect op Chrome op claude.ai. Desktop blijft ongewijzigd. Zet de extensie vast en werk in het browsertabblad.

Kan ik een Claude Desktop-chat op mobiel exporteren?

Niet met deze extensie. Die heeft Chrome op de desktop met claude.ai nodig. Mobiele browsers en de Desktop-app worden allebei niet ondersteund door de oranje knop.

Welke formaten werken zodra een Desktop-chat op claude.ai staat?

Markdown, JSON, platte tekst, XML en PNG — dezelfde vijf als in elke andere gids van Download Claude conversations. Artifact-indelingen en de schakelaar voor denkstappen gelden alleen in die webknop.
