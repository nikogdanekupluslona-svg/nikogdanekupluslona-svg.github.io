Over ons

Download Claude conversations is een onafhankelijke Chrome-extensie (sitenaam: Chat Downloader). Zoekmachines en gebruikers noemen haar ook Claude Chat Downloader en Claude Conversation Downloader. Ze is niet gemaakt door, verbonden aan of goedgekeurd door Anthropic, PBC — Claude is een handelsmerk van Anthropic. We hebben de extensie gebouwd om een gat in claude.ai zelf te dichten: er is geen ingebouwde manier om één gesprek als bestand te downloaden.

De extensie voegt een exportknop toe aan claude.ai en een Dashboard voor bulkexports, en schrijft PDF-, Markdown-, platte tekst-, JSON-, XML-, CSV- of PNG-bestanden lokaal in je browser. Losse chats exporteren als Markdown, tekst, JSON, XML, CSV of PNG is onbeperkt en kan zonder account. Voor PDF en bulk-ZIP log je in met Google; die zijn gratis tot 3 per dag, en Pro (3,99 $ per maand of 26,99 $ per jaar) heft die limiet op. De extensie werkt met gewone chats, Projects, Cowork-sessies en Claude Code op het web (claude.ai/code). Details lees je bij hoe het werkt. Terminalsessies van Claude Code exporteert de extensie niet.

Vermelding in de Chrome Web Store (synchroon houden)

Gebruik deze tekst in de Chrome Web Store, zodat het fragment in de Store aansluit bij hoe mensen zoeken (de Store-vermelding is Engelstalig en blijft daarom letterlijk in het Engels):

  • Naam (≤75 tekens): Claude Chat Downloader
  • Korte beschrijving (≤132 tekens): Free Chrome extension to save claude.ai chats as PDF, Markdown, text, JSON, XML, CSV or PNG — one chat or bulk Export All.
