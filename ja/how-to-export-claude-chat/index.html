拡張機能でClaudeのチャットをエクスポートする方法は？

Claudeのチャットを読みやすいファイルとしてエクスポートする方法は、claude.aiのオレンジ色のボタンです。この拡張機能をインストールし、スレッドを開いて、Markdown、JSON、テキスト、XML、PNGから選び、「Export」（エクスポート）をクリックします。ファイルはブラウザ内で作られ、ローカルに保存されます。3回の無料エクスポートはGoogleサインインで数えます。

この拡張機能は、すでに読み込まれたページ上で動くコンテンツスクリプトです。Anthropicに2つ目のセッションを開くことはなく、ファイルを作るために会話をアップロードすることもありません。そのため、ボタンは会話のURLで、スレッドがページ上に存在してからでないと表示されません。

  1. Chrome Web Storeから拡張機能をインストールします。
  2. claude.aiで会話を開きます。インストール時に開いていたタブは再読み込みします。
  3. メッセージ入力欄の横にあるオレンジ色のダウンロードボタンをクリックします。
  4. Markdown、JSON、プレーンテキスト、XML、PNGから選びます。
  5. 必要に応じて、思考、メタデータ、送信者、アーティファクトの配置を設定します。「Export」をクリックします。

複数のスレッドなら、ポップアップから「View and Download All Conversations」（すべての会話を表示・ダウンロード）を開きます。検索し、プロジェクトやエクスポート済みかどうかで絞り込んでから、「Export All」（すべてエクスポート）を実行します。そのバッチのファイルはすべて同じ3回の無料枠に含まれます。手順：一括の「Export All」。

TeamやEnterpriseのチャットも、Chromeで開ければ同じ方法でエクスポートできます。パーサーはAnthropicのプラン名を確認しません。組織が拡張機能をブロックしている場合、それはIT部門のポリシーであり、当方のProの設定が足りないわけではありません。

無料枠とAnthropicの利用量は別。この拡張機能でエクスポートしても、Claudeのメッセージ枠は消費しません。ページを読み取るだけです。3回の上限は当方の無料枠で、Pro（月額$3.99または年額$26.99）を購入する場合はPaddle経由で別途請求されます。

「エクスポート」ではなく「ダウンロード」で探していた方向けの1件ずつの手順：Claudeのチャットをダウンロードする方法。製品もオレンジ色のボタンも同じで、探すときの言葉が違うだけです。

公式のZIPでClaudeのチャットをエクスポートするには？

アカウント単位でClaudeのチャットをエクスポートする方法は、Settings → Privacy → Export dataです。Anthropicから有効期限付きのリンクがメールで届きます。ZIPはアカウント全体のJSONで、1件の会話を見やすくしたファイルではありません。バックアップとして使ってください。

公式のZIPが適しているのは、ワークスペースを離れるとき、すべてをアーカイブするとき、「自分のデータをすべて出してほしい」という要求に応えるときです。設計レビューを1件開いていて、1分以内にファイルが欲しいときには向きません。

この流れには、1件の会話IDで絞り込む機能がありません。待って、アーカイブをダウンロードし、展開して、スレッドを探すことになります。JSONの構造はアカウント単位です。この拡張機能が開いているページから書き出すチャットごとのJSONとは違います。

両方が必要なら、バックアップのために「Export data」を一度実行し、作業用のファイルが必要なときはいつでもこの拡張機能を使ってください。この2つは互いの代わりにはなりません。ZIPがMarkdownになることはありませんし、オレンジ色のボタンが2024年の忘れていたチャットまですべてメールで送ってくれることもありません。

公式の「Export data」は、PDFへの印刷とも違います。印刷はWebページを写すもので、ZIPは構造化されたアカウントデータです。印刷とファイルの比較：ClaudeのチャットをPDFで保存する方法。

ClaudeのチャットをMarkdownやJSONでエクスポートするには？

ClaudeのチャットをMarkdownやJSONでエクスポートするには、「Export」の前にドロップダウンでその形式を選びます。Markdownはメモやgit向け、JSONはスクリプト向けのメッセージツリーです。プレーンテキストはマークアップを取り除きます。PNGは画像で、PDFではありません。

Markdownは見出し、言語タグ付きのコードブロック、表を保持します。アーティファクトの配置は「Original」「Inline」「Nested」「Flat」（元の配置／インライン／入れ子／フラット）から選べます。思考ブロックは任意です。多くの人が「読みやすいエクスポート」と言うときに指すのが、このファイルです。一覧：形式。

拡張機能のJSONは、会話ごと（または一括で選んだものごと）のファイルです。AnthropicのアカウントZIPの名前を変えたものではありません。パーサーを書くなら、1件のスレッドにはこのJSONを使い、公式のZIPはAnthropicが保存したすべての会話が本当に必要なときだけ使ってください。

お金をかけずにClaudeのチャットをエクスポートできますか？

はい。どのアカウントでも、最初の3ファイルは5つの形式のどれでも無料でClaudeのチャットをエクスポートできます。それ以降はProが月額$3.99または年額$26.99です。Googleサインインにより、再インストールで無料回数がリセットされることはありません。

一括の「Export All」に別の無料枠はありません。「Export All」の1ファイルは、オレンジ色のボタンと同じく1回のエクスポートです。無料アカウントで20件の会話を選んでも、3件目のファイルで止まります。選ぶ会話を計画してください。

印刷やAnthropicの「Export data」は当方の無料枠を使いません。その代わり、1件のチャットのMarkdownも得られません。拡張機能を使わない「無料」の方法にも、時間と手直しのコストがかかります。

Googleサインインは省略できません。最初に「Export」をクリックすると、Googleにメールアドレスの確認を求められます。キャンセルすると、エクスポートが壊れているように見えます。サインインを完了してから、もう一度「Export」をクリックしてください。3回の無料ファイルにクレジットカードは不要です。

パソコンを替えたり再インストールしたりしても、ProはそのGoogleメールアドレスに従って復元されます。Anthropicのパスワードとは関係ありません。支払いに使ったのと同じGoogleアカウントでサインインしてください。

私たちは、公式のZIPと当方のエクスポートをあえて別の仕事として扱っています。メールで届くアカウントのJSONはAnthropicのバックアップです。チャットごとのMarkdownやJSONは、あなたが開いているスレッドから私たちがブラウザ内で作るものです。この2つを1つのボタンに混ぜれば、どちらも使いにくくなります。

エクスポートとコピー＆ペーストの違いは？

コピー＆ペーストでClaudeのチャットをエクスポートできるのは、ごく弱い意味でだけです。テキストを選んで移しただけだからです。コードのインデントは失われ、表は崩れ、長いスレッドにはメッセージの区切りがなくなります。Claudeのチャットを構造化されたファイルとしてエクスポートする方法は、やはり拡張機能、印刷、公式のZIPです。

中間的な方法として、すべて選択してGoogleドキュメントやWordに貼り、書式を手で直すこともできます。これは単発の納品物向けで、毎週のアーカイブには向きません。やり取りが増えるたびに、また手直しが必要になります。この拡張機能は、貼り付けから手直しを始めなくて済むようにするためのものです。

コピー＆ペーストでは、折りたたまれた思考や展開していないアーティファクトも抜け落ちます。印刷にも同じ欠点があり、折りたたまれた部分はPDFに入りません。拡張機能の切り替えを使えば、読み込まれたページのデータにある思考やアーティファクトを含められます。これは「画面に見えているピクセル」とは別の層の話です。

Slack用に段落が1つ欲しいだけなら、コピー＆ペーストのほうが素直で速い方法です。コードブロックを含むレビュー全体が必要なら、3回の無料エクスポートのうち1回をMarkdownに使ってください。

Claude Codeとclaude.aiでエクスポート方法はどう違う？

claude.aiでClaudeのチャットをエクスポートする方法は、このChrome拡張機能です。Claude Codeの会話をエクスポートする方法は、ターミナルでの/exportか、~/.claude/projectsにあるJSONLです。Claude Desktopは3つ目の別のウィンドウで、オレンジ色のボタンは表示されません。

Claude Codeの/exportは、表示用に整えたプレーンテキストのトランスクリプトを（クリップボードかファイルに）書き出します。Anthropicは、ディスク上のJSONLは変更される可能性のある内部形式だと説明しています。残しておくものには、/exportかスクリプト用のインターフェースを使ってください。手順：Claude Codeのエクスポート。

Claude Desktop：同期されていればclaude.aiで同じチャットを開き、そこでエクスポートします。そうでなければDesktopからコピー＆ペーストするか、アカウント単位のJSONならSettings → Privacy → Export dataを使います。ガイド：Claude Desktopのチャットをエクスポートする。

当サイトで「Claude Code エクスポート」を探して見つかるのは、違いを整理するページであり、Chrome Web Storeの拡張機能の機能ではありません。この拡張機能はclaude.ai専用です。この制限は製品の仕様であって、チェックボックスが足りないわけではありません。

Claudeのチャットのエクスポートで残るもの・失われるものは？

この拡張機能でClaudeのチャットをエクスポートすると、ページに読み込まれたメッセージツリーが残ります。送信者、テキスト、コードブロック、表、そして切り替えをオンにしていれば思考、メタデータ、アーティファクトです。まだ表示されていない部分や、入力欄などの画面要素は含まれません。

印刷はピクセルを残しますが、整ったコードのレイアウトはたいてい失われます。公式のZIPは、Anthropicがアカウントのアーカイブに入れたものを残しますが、人が読めるチャットごとの文書にはなりません。コピー＆ペーストは選択した文字を残しますが、構造は失われます。

送信者フィルター：すべてのメッセージ、ユーザーのみ、アシスタントのみ。回答なしでプロンプトだけ欲しいとき、またはその逆のときに便利です。メタデータの切り替えをオンにすると、ファイルに出典情報として残したいタイトル、タイムスタンプ、モデルが加わります。

ファイルはディスクに残ります。当方のWorkerが見るのはサブスクリプションの状態です。Googleが見るのは、あなたが承認したOAuthの同意です。claude.aiはもともと会話を持っています。関係者はこれですべてです。当方はAnthropicではありません。ClaudeはAnthropic, PBCの商標です。

エクスポートしたファイルが短いと感じたら、スレッドをさらに読み込んでからもう一度エクスポートしてください。無料プランでは、その2回目も3回のうちの1回になります。クリックする前に、生成が終わり、古いやり取りも画面に表示されていることを確認してください。

よくある質問：Claudeのチャットをエクスポートする方法

Claudeのチャットを1件だけエクスポートするには？

開いているclaude.aiの会話で、Download Claude conversationsを使います。公式の「Export data」はアカウント全体が対象で、1件のスレッドには手間がかかりすぎます。印刷は見た目のPDFで、Markdownではありません。

ClaudeのチャットをPDFにエクスポートするには？

claude.aiにもこの拡張機能にも、ネイティブなPDF出力はありません。スナップショットなら印刷（Ctrl/Cmd+P →「PDFに保存」）を使います。または、Markdownでエクスポートし、Word、Googleドキュメント、Markdownアプリで変換してください。ガイド：ClaudeのチャットをPDFで保存する方法。

公式のエクスポートにアーティファクトや思考は含まれますか？

ZIPには、AnthropicがアカウントのJSONに保存したものがそのまま入ります。アーティファクトの配置を選んだチャットごとのMarkdownにはなっていません。この拡張機能のエクスポートは、切り替えをオンにしていて、ページにそれらが読み込まれていれば、読みやすい形で残すように作られています。

Chrome拡張機能でAnthropicのアカウントに影響はありますか？

この拡張機能は、ログイン済みのclaude.aiセッションをWebサイトと同じように使います。アカウント操作を自動化したり、独自の認証情報でAnthropicにアクセスしたりはしません。当方はAnthropicではありません。引き続きAnthropicの利用規約が適用されます。

Claudeのチャットを無料でエクスポートする方法はありますか？

はい。どのアカウントでも、Markdown、JSON、テキスト、XML、PNGのいずれかで3回まで無料でエクスポートできます。それ以降はProが月額$3.99または年額$26.99です。印刷や公式の「Export data」はこの無料枠を使いません。

Teamのワークスペースからもチャットをエクスポートできますか？

はい。Chromeでclaude.aiの会話を開ければ使えます。拡張機能はページをもとに動き、個人向けプラン専用ではありません。会社の拡張機能の許可リストは引き続き適用されます。

エクスポートするとAnthropicアカウントの利用上限を使いますか？

いいえ。この拡張機能は、すでに読み込まれたページを読み取るだけです。Claudeに追加の生成リクエストを送ることはなく、Anthropicのメッセージ数や利用上限にも影響しません。

最初の一括エクスポートは無料ですか？

アカウントの最初の3ファイルは、1件のチャットからでも、3件のチャットからでも、少数の一括選択からでも無料です。「Export All」に別の無料枠はありません。

Claude Codeの会話をエクスポートするには？

ターミナルで/exportを実行するか、~/.claude/projectsからJSONLをコピーします。このChrome拡張機能はClaude Codeのチャットをエクスポートしません。詳しい手順：Claude Codeのエクスポート。

Claudeのチャットをエクスポートするのに、Googleサインインは必要ですか？

はい、最初のエクスポートから必要です。無料枠の管理とProの復元に使います。サインインの際にチャットの本文がアップロードされることはありません。確認済みのメールアドレスは、無料枠とサブスクリプションの状態の管理のために保存します。

Claudeのチャットはどの形式でエクスポートできますか？

Markdown、JSON、プレーンテキスト、XML、PNGです。PDFはありません。PNGは画像です。どれを選ぶべきかは形式をご覧ください。

Claude Conversation Downloaderは同じ拡張機能ですか？

はい。Download Claude conversations、Claude Chat Downloader、Claude Conversation Downloaderは同じChrome拡張機能を指します。claude.aiのオレンジ色のボタン、5つの形式、3回の無料エクスポート、Pro（月額$3.99または年額$26.99）です。
