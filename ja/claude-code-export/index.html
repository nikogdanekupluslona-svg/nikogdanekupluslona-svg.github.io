Claude Codeの会話エクスポートとclaude.ai：正しい方法を選ぶ

ターミナルでのClaude Codeエクスポートとは？

Claude Codeのエクスポートとは、対話型CLIセッションで使う /export コマンドのことです。Anthropicのドキュメントによると、現在の会話をコピーするか、プレーンテキストのファイルとして保存するかを選ぶメニューが表示され、メッセージとツールの出力は読みやすいテキストとして書き出されます。ファイル名を渡せばメニューを飛ばして、そのファイルに直接書き込みます。

これはclaude.aiのMarkdownでも、このChrome拡張機能のJSONでも、PDFでもありません。人が読むためにレンダリングされたトランスクリプトです。Anthropicは、ディスク上のJSONLログは製品内部向けの別フォーマットであり、公開APIとして扱うものではないと説明しています。

/export

確認を飛ばして、現在の作業ディレクトリに名前付きファイルを書き出す場合：

/export my-session

フラグやファイル名については、Anthropicのセッションに関するドキュメントが正式な情報源です。これらはClaude Codeのバージョンによって変わります。コミュニティのブログは二次情報として扱ってください。/export のダイアログの文言が手元の表示と違う場合は、CLIのビルドが異なります。2025年のスクリーンショットではなく、製品内のヘルプを参照してください。

スクリプトから使う場合、Anthropicは別のインターフェースを案内しています。--output-format json または stream-json を付けた claude -p、セッションIDによる再開、transcript_path を受け取るフック、Agent SDKです。これらはClaude Codeの開発者向けの仕組みであり、このサイトのChrome拡張機能ではありません。

読みやすさか、構造か。/export は人が読むためのトランスクリプトです。projectsフォルダ内のJSONLはログです。Chrome拡張機能のJSONは3つ目の形式で、claude.aiのページからのみ作られます。3つすべてを1つのパーサーで扱おうとしないでください。

Claude Codeの会話をディスクから取り出すには？

Claude Codeの会話をディスクから取り出すには、projectsディレクトリにあるセッションのJSONLファイルをコピーするか、読みやすいトランスクリプトが必要なら /export を実行します。macOSとLinuxのデフォルトの場所は ~/.claude/projects/ 以下、Windowsでは %USERPROFILE%\.claude\projects です。ファイル名はセッションIDです。

プロジェクトのフォルダ名は、作業ディレクトリのパスの英数字以外の文字をハイフンに置き換えたものです。変換後の名前が長すぎる場合、Anthropicは名前を切り詰めてハッシュを付け、ファイルシステムの制限内に収めます。フォルダが見つからないときは、思っているのとは別のカレントディレクトリからClaude Codeを起動しています。

JSONLの各行は、メッセージ、ツールの使用、またはメタデータを表すJSONオブジェクトです。Anthropicは、この形式は内部仕様でありバージョンごとに変わると明言しています。これらのファイルを解析するスクリプトは、Claude Codeのリリースで動かなくなる可能性があります。安定した出力が必要なら、/export かドキュメント化されたスクリプト用インターフェースを使ってください。

保存場所は変更できます。CLAUDE_CONFIG_DIR は設定ディレクトリを ~/.claude 以外に移します。CLAUDE_CODE_PROJECT_DIR_NAME は、その設定ディレクトリと組み合わせてプロジェクトディレクトリ名を指定します（Anthropicによれば Claude Code v2.1.234 以降）。settings.json の cleanupPeriodDays はデフォルトの保持期間を変更します。いずれもDownload Claude conversationsの機能ではありません。

つまり、バックアップのためにClaude Codeの会話ファイルを保存するには、フォルダをコピーするか、定期的に /export でトランスクリプトを書き出します。このサイトの拡張機能に「JSONLをインポート」ボタンが追加されることはありません。私たちはあなたのホームディレクトリを読み取りません。

Claude Codeのエクスポートにこの拡張機能は使える？

いいえ。Claude Codeのエクスポートは、Download Claude conversationsでは行えません。このChrome拡張機能はclaude.aiのページに組み込まれて動きます。ターミナルを見ることも、/export を実行することも、JSONLを開くこともできません。Claude Codeの会話を保存したい場合は、このページのCLI手順に従ってください。

「Claude」と「エクスポート」で検索すると、両方の話題がまとめて表示されるため、このページにたどり着く方がいます。それでもChrome Web Storeの掲載内容はclaude.ai専用です。拡張機能をインストールしても、iTerm、Ghostty、VS Codeのターミナル、Claude Codeのデスクトップラッパーにオレンジ色のボタンが表示されることはありません。

同じコーディング作業について、claude.aiでも並行してスレッドを進めている場合、そのブラウザ上のチャットは拡張機能で保存できます。2つの記録が統合されることはありません。CLIの中だけで実行されたツール呼び出しは、claude.aiに貼り付けていない限り、Webのエクスポートには含まれません。

毎週のように同じ問い合わせが届きます。Chrome拡張機能をインストールしたら /export が使えるようになると思った、というものです。私たちが解析するのはclaude.aiだけです。Claude Codeには、すでに /export とJSONLがあります。CLIをラップするのは別の製品になりますし、そのような製品は出していません。

Claude Codeの会話履歴はどこに保存される？

Claude Codeの会話履歴は、設定ディレクトリ内のprojectsフォルダにJSONLトランスクリプトとして保存されます。macOSとLinuxのデフォルトは ~/.claude/projects/<encoded-cwd>/<session-id>.jsonl、Windowsは %USERPROFILE%\.claude\projects です。この構成はAnthropicが変更する可能性があります。ディスク上にパスが見当たらない場合は、最新のセッションに関するドキュメントを確認してください。

再開（resume）とエクスポートは別の操作です。claude --continue と claude --resume は、作業を続けるためにセッションを読み込み直します。/export は、gitに残したりメールで送ったりできるコピーを書き出します。前者はコンテキストを復元し、後者は記録を持ち出します。再開時の権限モード、compact／要約、選択画面の動作はAnthropicのセッションのページに説明があり、いずれもこの拡張機能とは関係ありません。

Anthropicによると、デスクトップアプリ、Web版Claude Code、VS Code拡張機能は、それぞれ独自にセッション履歴を管理しています。このガイドのパスはCLIのものです。DesktopのCoworkのトランスクリプトが、ターミナルで使うのと同じJSONLのフォルダにあるとは考えないでください。

JSONLを公開スキーマとして扱わないでください。Anthropicは行の形式が変わると明言しています。それでも解析する場合は、Claude Codeのバージョンを固定し、動かなくなることを前提にしてください。Claude Codeの会話を読みやすい形で得る安定した方法は /export です。

CLAUDE_CODE_SKIP_PROMPT_HISTORY などの環境変数を設定すると、トランスクリプトが書き込まれなくなることがあります。projectsフォルダが空の場合は、保存を無効にしていないか、CLAUDE_CONFIG_DIR を別の場所に向けていないか、そのディレクトリで対話型セッションを一度も実行していないのではないかを確認してください。

claude.aiのチャットをダウンロードするには？

claude.aiのチャットをダウンロードするには、Download Claude conversationsをインストールし、Chromeでスレッドを開いて、オレンジ色のボタンをクリックし、Markdown、JSON、テキスト、XML、PNGのいずれかを選びます。これはブラウザ向けの製品で、Claude Codeのエクスポートではありません。詳しい手順はClaudeのチャットをダウンロードする方法をご覧ください。

claude.aiの履歴全体を個別のファイルとして保存するには、/export ではなく、一覧ページの「Export All」（すべてエクスポート）を使います。Proでない場合、各ファイルが無料エクスポート3回の枠に数えられます。ガイド：「Export All」で一括エクスポート。形式について：対応形式。

claude.aiで初めてエクスポートするときは、回数の管理とProの復元のためにGoogleログインが必要です。ファイルはローカルで作成されます。ProはPaddleで課金され、月額$3.99または年額$26.99です。これらはいずれも、ターミナルの /export には関係しません。

Claude Codeで始めた作業の要約をclaude.aiに貼り付けた場合は、メモとしてWeb上のスレッドをダウンロードし、本来のCLIログとしては /export を残してください。混乱した1つのファイルより、2つのファイルのほうが役に立ちます。

Claude CodeのエクスポートとAnthropic公式のデータエクスポートの違いは？

Claude Codeのエクスポート（/export またはJSONL）は、1つのターミナルセッションが対象です。公式のデータエクスポートは、claude.aiの Settings → Privacy → Export data（claude.aiを日本語で表示している場合、ラベルは翻訳されていることがあります）から行うもので、Anthropicアカウント全体のJSONをZIPで、時間をおいて受け取ります。この2つは同じアーカイブではありません。ZIPが /export の代わりになることはありません。

特定のClaude CodeセッションがアカウントのZIPに含まれるかどうかは、この拡張機能ではなく、Anthropicがその製品のデータをどう保存しているかによります。Anthropicの最新のプライバシー関連ドキュメントに別の記載がない限り、ZIPはWebアカウントのバックアップと考えてください。私たちがCLIのセッションをそのZIPに追加することはありません。

Webサイトからclaude.aiのチャットをエクスポートする方法（そのZIPと拡張機能の違いを含む）は、Claudeのチャットをエクスポートする方法で説明しています。Webページの「PDFとして印刷」は、ターミナルの画面には使えません。印刷／PDFは、会話がブラウザ上にある場合にだけ参照してください。

Claude Code・Desktop・claude.aiのエクスポートの違いは？

Claude Code、Claude Desktop、claude.aiは3つの別々の環境です。Claude Codeのエクスポートには /export とJSONLを使います。Desktopはアプリで、この拡張機能のオレンジ色のボタンは表示されません。Download Claude conversationsが動くのは、Chromeで開いたclaude.aiだけです。名前を混同すると、エクスポートが気づかないうちに失敗します。

Claude Desktopの場合：チャットが同じAnthropicアカウントに同期されていれば、claude.aiで開いてそこからエクスポートします。Desktopのウィンドウの中にしか存在しない場合は、コピー＆ペーストするか、公式のデータエクスポートを待ちます。ガイド：Claude Desktopのチャットをエクスポートする。

VS CodeのClaude Codeパネルは、claude.aiよりもCLIに近いものです。そのWebビューに私たちのコンテンツスクリプトが組み込まれることは期待しないでください。実際にメッセージを持っているセッションから /export を実行してください。

この拡張機能は独立したChrome拡張機能であり、Anthropic, PBCとは提携していません。ClaudeはAnthropicの商標です。Anthropicの利用規約に従ってください。独自のコードを含むツール出力のコピーについて、法的な助言はできません。それはあなたと雇用主、Anthropicの間の問題です。

よくある質問：Claude Codeの会話エクスポート

Claude Codeの会話をエクスポートするには？

Claude Codeのターミナルで /export（必要ならファイル名を付けて）と入力すると、レンダリングされたトランスクリプトを保存できます。または、macOS／Linuxでは ~/.claude/projects、Windowsでは %USERPROFILE%\.claude\projects からJSONLファイルをコピーします。現在のダイアログについてはAnthropicのセッションのドキュメントに説明があります。

このChrome拡張機能でClaude Codeのチャットをダウンロードできますか？

いいえ。Download Claude conversationsが動作するのは、Chromeで開いたclaude.aiだけです。ターミナルのセッション、JSONLのトランスクリプト、/export コマンドは読み取れません。Claude CodeのエクスポートはCLIで行います。

Claude Codeの会話履歴はどこに保存されますか？

セッションのトランスクリプトは、~/.claude/projects/<encoded-working-directory>/ 以下に、セッションIDを名前にしたJSONLファイルとして保存されます。正確な構成は変わる可能性があります。JSONLを解析せずに読みやすいファイルが欲しい場合は /export を使ってください。CLAUDE_CONFIG_DIR で保存先を移動できます。

Claude Codeの会話をMarkdownで保存するには？

Claude Codeの /export はプレーンテキストのトランスクリプトで、この拡張機能のMarkdownではありません。どうしてもMarkdownが必要な場合は、作業内容をclaude.aiにコピーしてDownload Claude conversationsでエクスポートするか、/export のテキストをご自身で変換してください。私たちはJSONLをMarkdownに変換しません。

代わりにclaude.aiの会話をダウンロードするには？

無料のChrome拡張機能をインストールし、claude.aiでチャットを開いてオレンジ色のボタンを使います。履歴全体なら「Export All」を使います。Claudeのチャットをダウンロードする方法をご覧ください。無料エクスポートは3回、Proは月額$3.99または年額$26.99です。

/export は公式のデータエクスポートと同じですか？

いいえ。/export は現在のClaude Codeセッションが対象です。Settings → Privacy → Export data は、AnthropicアカウントのJSONをZIPにしてメールで送ります。製品も、ファイルも、待ち時間も異なります。

Claude CodeのJSONLはjqで解析できますか？

できます。ただし、Anthropicが示している注意点があります。行のスキーマは内部仕様で、変わる可能性があります。決まった仕様が必要なら、/export か claude -p --output-format json を使ってください。それでもJSONLを解析する場合は、CLIのバージョンを固定してください。

Claude CodeのエクスポートはWindowsでも使えますか？

はい。/export はCLIのコマンドです。ディスク上のトランスクリプトは、CLAUDE_CONFIG_DIR を設定していない限り %USERPROFILE%\.claude\projects にあります。ただし、このChrome拡張機能はそのターミナル内では動きません。

Claude CodeとClaude Desktopは同じものですか？

いいえ。Claude Codeはターミナルで動くコーディングエージェント、Claude Desktopはチャットアプリ、claude.aiはWebサイトです。この拡張機能が使えるのはWebサイトだけです。Desktopのエクスポートについて：Claude Desktop。

この拡張機能が /export をラップする予定はありますか？

バージョン1.13.0ではありません。製品の対象範囲はclaude.aiです。5つの形式、ローカルのファイル、回数管理のためのGoogleログイン。範囲が変わる場合は、このページでお知らせします。それまでは、Claude CodeのエクスポートにはAnthropicのCLIを使ってください。

/export にはツールの出力も含まれますか？

Anthropicは、/export はメッセージとツールの出力を読みやすいテキストとして書き出すと説明しています。これはAnthropicのトランスクリプトで、私たちのパーサーではありません。現時点での正確な内容は、お使いのビルドで /export を実行してファイルを確認してください。ドキュメントはリリースより遅れることがあります。

Claude Codeのセッションを一括エクスポートできますか？

この拡張機能の「Export All」ではできません。一覧ページでの一括エクスポートはclaude.ai専用です。多数のCLIセッションを保存するには、projectsフォルダをコピーするか、セッションごとに /export を実行します。JSONLをオレンジ色のボタンで一括保存する方法はありません。
