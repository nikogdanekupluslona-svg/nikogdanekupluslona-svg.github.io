Claudeの会話抽出ツールとは何ですか？

Claudeの会話抽出ツールは、claude.aiに表示されたスレッドを解析し、実際のファイルを書き出します。この拡張機能がそのChromeツールです。スクリーンショットツールでも、Anthropicのアカウント全体のZIPでもありません。「抽出」「エクスポート」「ダウンロード」と言い方は違っても、claude.aiの同じオレンジ色のボタンを指しています。

開発者や研究者が「会話抽出ツール」を探すのは、「抽出」という言葉に構造のイメージがあるからです。送信者、コンテンツブロック、コードブロック、表、アーティファクト。この拡張機能は、すでに開いているタブの中でその解析を行います。レビューではClaude Conversation DownloaderやClaude Exporterと呼ばれることもありますが、どれもChrome Web Storeで評価5.0のこの拡張機能のことです。

この抽出ツールは、Claude Desktopのプラグインでも、Claude CodeのCLIでもありません。ターミナルの履歴が目的なら/exportを使ってください。ガイド：Claude Codeのエクスポート。Mac/Windowsアプリが目的ならClaude Desktopのチャットをエクスポートするをご覧ください。このページはChromeのclaude.aiだけを扱います。

ボタンは同じ、言葉が違うだけ。「Claudeのチャットを抽出」「Claudeのチャットをエクスポート」「Claudeのチャットをダウンロード」は、どれもこの拡張機能にたどり着きます。製品としてのエクスポートの解説はClaudeのチャットをエクスポートにあります。このガイドでは、抽出ツールが何を読み取り、何を省くかに絞って説明します。

claude.aiでClaudeのチャットを抽出するには？

この拡張機能をインストールし、claude.aiで会話のURLを開き、メッセージ入力欄の横にあるオレンジ色のボタンをクリックして形式を選び、「Export」をクリックします。会話抽出ツールは、Chromeのダウンロード機能を通じてファイルをローカルに書き出します。3回の無料エクスポートを数えるため、最初の抽出の前に一度だけGoogleサインインを行います。

  1. Chrome Web Storeから拡張機能を追加します（Download Claude conversations、2026年9月時点でバージョン1.13.0）。
  2. claude.aiを再読み込みしてスレッドを開きます。抽出ツールには、何も入力していないホーム画面ではなく会話のURLが必要です。
  3. メッセージ入力欄の右側にあるオレンジ色のボタンをクリックします。
  4. Markdown、JSON、プレーンテキスト、XML、PNGから選びます。
  5. 「Export」をクリックします。会話抽出ツールがチャットの本文を当方のサーバーにアップロードすることはありません。

オレンジ色のボタンが表示されない場合は、拡張機能を固定してタブを再読み込みし、URLが実際のチャットであることを確認してください。会話抽出ツールが読み込まれるのはclaude.aiだけです。Claude Desktop、Claude Code、他のWebサイトには表示されません。ファイルが不完全なのは、たいてい長いスレッドの表示が終わっていなかったためです。スクロールするか少し待ってから、もう一度抽出してください。

抽出ツールは最後に使った形式を記憶します。MarkdownのつもりがJSONで保存された場合は、「Export」の前にドロップダウンを確認してください。3回の上限に達すると、Pro（月額$3.99または年額$26.99）の案内が表示されます。これは想定どおりの動作で、解析の失敗ではありません。再インストールで無料回数がリセットされないよう、最初にチャットを抽出するときにGoogleサインインが必要です。

印刷やZIPという代替手段も含めた手順が知りたい場合はClaudeのチャットをダウンロードする方法を、印刷 →「PDFに保存」を含めた方法の比較ならClaudeのチャットをエクスポートする方法をご覧ください。この抽出ツールのページは、開いているスレッドを構造化されたファイルにしたい方向けです。

Claudeの会話抽出ツールは何を取り出しますか？

Claudeの会話抽出ツールは、claude.aiがすでに描画したメッセージツリーを読み取ります。ユーザーとアシスタントのやり取り、言語タグ付きのコードブロック、表、リンク、任意で思考です。アーティファクトの配置は「Original」「Inline」「Nested」「Flat」（元の配置／インライン／入れ子／フラット）から選べます。同じページからコピー＆ペーストするとこの構造は失われますが、抽出ツールならMarkdown、JSON、XMLに残ります。

思考ブロックは切り替えられます。抽出したファイルにClaudeの表示された推論を残したいならオンに、最終的な回答だけが欲しいならオフのままにします。メタデータにはタイトル、タイムスタンプ、モデルを含められます。送信者フィルターで、すべてのメッセージ、ユーザーのみ、アシスタントのみを残せます。これらの設定は、形式と同じウィジェットにあります。機能の一覧：機能。

抽出ツールは、claude.aiのタブにすでに表示されている会話を読み取ります。コードブロック、表、アーティファクトの配置（Original、Inline、Nested、Flat）はそこで解析され、ファイルはローカルで作られます。PDFは提供していません。

Chromeで一度も読み込まれていないチャットは抽出できません。シークレットモード、ログアウトしたタブ、Claude Desktopにしかない会話からはファイルを作れません。サインインした状態でclaude.aiのスレッドを開いてから、会話抽出ツールを実行してください。オフラインでのエクスポートは、そのページが読み込まれた後でのみ可能です。ファイルの生成にサーバーとのやり取りは発生しません。

Claudeのチャット抽出ツールはどの形式で書き出せますか？

Markdown、JSON、プレーンテキスト、XML、PNGです。Claudeのチャットを1件抽出する場合も、「Export All」を実行する場合も同じ5形式です。1.13.0では、Word、Notion、ネイティブなPDFはありません。形式を選んでも3回の無料枠は変わらず、完成したファイルはそれぞれ1回の抽出として数えます。

Claudeの会話を一括で抽出できますか？

はい。「View and Download All Conversations」を開いて絞り込み、「Export All」をクリックします。会話抽出ツールは、選んだチャットごとに1ファイルを書き出します。アカウントがPro（月額$3.99または年額$26.99）でない限り、各ファイルが3回の無料エクスポートのうち1回を使います。

一覧ページの絞り込みは、All（すべて）、New（新規）、Exported（エクスポート済み）、Project（プロジェクト）です。Newは、抽出ツールでまだ保存していないチャットです。Exportedは抽出済みの履歴を示し、後の一括実行で飛ばせます。Projectはclaude.aiのプロジェクト分けに対応しています。「Export All」を実行する前に、名前で会話を検索することもできます。

一括でも解析の質は落ちません。Thinking、Metadata、アーティファクトの配置、送信者のオプションは、1件用のウィジェットと同じです。無料枠の注意点を含む手順：一括の「Export All」。アカウント全体を1つのZIPでメールで受け取りたいなら、それはこの抽出ツールではなくSettings → Privacy → Export data（claude.aiを日本語表示にしている場合、メニュー名は日本語で表示されることがあります）です。

無料の抽出は合計3回です。「Export All」に別枠はありません。25件のチャットを選ぶと、すべてのファイルが完成すれば25回分を使います。大量に抽出する前に、NewやProjectで絞り込むか、Pro（月額$3.99または年額$26.99）にアップグレードしてください。

会話抽出ツールとコピー＆ペーストの違いは？

コピー＆ペーストはClaudeの短い回答1つなら十分ですが、コードや表では失敗します。Anthropicの「Export data」はアカウント全体のバックアップZIPです。会話抽出ツールはその中間で、このスレッドまたは一括で選んだ会話を、構造化されたファイルとして、Chromeのclaude.aiからすぐに書き出します。

Claudeの会話抽出ツールは安全に使えますか？

この会話抽出ツールは、既存のclaude.aiセッションをWebサイトと同じように使います。アカウントの操作を自動化したり、チャットの本文を当方のAPIに送ったりはしません。Googleサインインは3回の無料エクスポートを数え、Proを復元するためのものです。支払いはPaddleが処理します。当方はAnthropicではなく、Anthropicの利用規約が引き続き適用されます。

Cloudflare Workerが見るのはサブスクリプションの状態、つまり無料エクスポートの回数とProかどうかだけです。抽出したMarkdown、JSON、テキスト、XML、PNGを受け取ることはありません。ファイルがブラウザの外に出るのは、Chromeのダウンロードフォルダーに保存されるときだけです。境界の詳細：仕組み。「Claudeのチャット抽出ツールは安全か」と気になる方は、この分担を見てください。課金はWorkerに、チャットはタブの中に。

「通信がまったくない」とは約束できません。claude.ai、Google、Workerはどれも存在します。お約束できるのは、チャットの本文が当方にアップロードされないということです。Anthropicの利用規約に従ってください。この拡張機能は独立したChrome拡張機能であり、Anthropicの公式製品ではありません。サポートのメールアドレスはサイトのフッターにあります。

モバイルブラウザとClaude Desktopには対応していません。Chromeのコンテンツスクリプトである会話抽出ツールは、そこでは動きません。2026年9月時点で、このページからSafari版やFirefox版を提供する予定はありません。デスクトップ版Chromeのclaude.aiを使ってください。拡張機能をブロックするチームのポリシーがあれば、この抽出ツールもブロックされます。

Claudeのチャットの「抽出」と「エクスポート」は違いますか？

いいえ。やることは同じで、言葉が違うだけです。「抽出」「エクスポート」「ダウンロード」のどれも、claude.aiの同じオレンジ色のボタンと同じ5つの形式にたどり着きます。このページでは、パーサーが何を残すかに重点を置いています。

何もインストールせずにClaudeのチャットを抽出できますか？

できるのは、コードブロックや表が崩れるコピー＆ペーストか、アカウント全体のZIPであるAnthropicの「Export data」だけです。構造を保った会話抽出にはページを読み取る必要があり、それを行うのがこのChrome拡張機能です。

会話の一括抽出に対応していますか？

はい。「View and Download All Conversations」（すべての会話を表示・ダウンロード）を開き、「Export All」（すべてエクスポート）を実行します。各ファイルは3回の無料エクスポートに含まれます。Pro（月額$3.99または年額$26.99）にすると上限がなくなります。絞り込み：All、New、Exported、Project。

Claudeのチャット抽出ツールは安全に使えますか？

このツールは、ログイン済みのclaude.aiセッションを読み取り、ファイルをローカルで作成します。会話の本文が当方のサーバーに送られることはありません。当方はAnthropicではなく、引き続きAnthropicの利用規約が適用されます。

チャットを抽出するのにClaude Proは必要ですか？

いいえ。Chromeでスレッドを開けるclaude.aiのプランなら、どれでも使えます。会話抽出ツールでの最初の3ファイルは当方側で無料です。Anthropicの有料プランは、当方の3回の無料枠とは関係ありません。

Claudeの会話抽出ツールはDesktopで動きますか？

いいえ。Claude Desktopにオレンジ色のボタンが表示されることはありません。同期されていればclaude.aiで同じチャットを開くか、コピー＆ペーストまたは公式のZIPを使ってください。この抽出ツールはclaude.ai用のChrome専用です。

Claudeの会話抽出ツールでPDFを書き出せますか？

いいえ。形式はMarkdown、JSON、プレーンテキスト、XML、PNGです。PDFのようなスナップショットが必要なら、claude.aiのページを印刷してください。PNGは画像で、PDFではありません。

Claude Codeでもチャットを抽出できますか？

いいえ。Claude Codeでは/exportかディスク上のJSONLを使います。この会話抽出ツールはclaude.ai用のChromeのコンテンツスクリプトで、ターミナルに組み込むものではありません。

抽出ツールは何回まで無料ですか？

Googleでサインインしたアカウントごとに3回で、「Export All」と共通です。再インストールしても回数はリセットされません。Proは同じGoogleアカウントで復元され、請求はPaddleが行います。

Claudeの会話抽出ツールが省くものは？

ページの画面要素、入力欄、会話の中に表示されていないものです。Chromeで一度も読み込まれていないチャットも対象外です。Claude Desktopにしかないスレッドや、Claude CodeのJSONLも範囲外です。
