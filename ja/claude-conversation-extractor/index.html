Claudeの会話抽出ツールとは何ですか？

Claudeの会話抽出ツールは、claude.aiに表示されたスレッドを解析し、実際のファイルを書き出します。Download Claude conversationsがそのChromeツールです。スクリーンショットツールでも、Anthropicのアカウント全体のZIPでもありません。「抽出」「エクスポート」「ダウンロード」と言い方は違っても、claude.aiの同じオレンジ色のボタンを指しています。

開発者や研究者が「会話抽出ツール」を探すのは、「抽出」という言葉に構造のイメージがあるからです。送信者、コンテンツブロック、コードブロック、表、アーティファクト。この拡張機能は、すでに開いているタブの中でその解析を行います。レビューではClaude Conversation DownloaderやClaude Exporterと呼ばれることもありますが、どれもChrome Web StoreにあるDownload Claude conversations 1.16.2のことです。

この抽出ツールは、Claude Desktopのプラグインでも、Claude CodeのCLIでもありません。ターミナルの履歴が目的なら/exportを使ってください。ガイド：Claude Codeのエクスポート。Mac/Windowsアプリが目的ならClaude Desktopのチャットをエクスポートするをご覧ください。Claude Code on the web（claude.ai/code）とCoworkのセッションはclaude.ai上で開くので、抽出できます。このページはChromeのclaude.aiだけを扱います。

ボタンは同じ、言葉が違うだけ。「Claudeのチャットを抽出」「Claudeのチャットをエクスポート」「Claudeのチャットをダウンロード」は、どれもこの拡張機能にたどり着きます。製品としてのエクスポートの解説はClaudeのチャットをエクスポートにあります。このガイドでは、抽出ツールが何を読み取り、何を省くかに絞って説明します。

claude.aiでClaudeのチャットを抽出するには？

この拡張機能をインストールし、claude.aiで会話のURLを開き、メッセージ入力欄の横にあるオレンジ色のボタンをクリックして形式を選び、「Export」をクリックします。会話抽出ツールは、Chromeのダウンロード機能を通じてファイルをローカルに書き出します。Markdown、テキスト、JSON、XML、CSV、PNGならアカウントは不要で、Googleサインインが求められるのはPDFと一括エクスポートのときだけです。

  1. Chrome Web Storeから拡張機能を追加します（Download Claude conversations、2026年9月時点でバージョン1.16.2）。
  2. claude.aiを再読み込みしてスレッドを開きます。抽出ツールには、何も入力していないホーム画面ではなく会話のURLが必要です。
  3. メッセージ入力欄の右側にあるオレンジ色のボタンをクリックします。
  4. 「Messages」（メッセージ）を「All」「Human」「Assistant」（すべて／ユーザー／アシスタント）から選び、必要なら「Thinking」（思考）にチェックを入れます。個々のメッセージだけを残すなら「Select」（選択）を使います。形式はPDF、Markdown、JSON、プレーンテキスト、XML、CSV、PNGから選びます。
  5. 「Export」をクリックします。「Copy」（コピー）を使えば、Markdown、テキスト、JSON、XML、CSVをクリップボードに入れられます。会話抽出ツールがチャットの本文を当方のサーバーにアップロードすることはありません。

オレンジ色のボタンが表示されない場合は、拡張機能を固定してタブを再読み込みし、URLが実際のチャットであることを確認してください。会話抽出ツールが読み込まれるのはclaude.aiだけです。Claude Desktop、Claude Codeのターミナル、他のWebサイトには表示されません。ファイルが不完全なのは、たいてい長いスレッドの表示が終わっていなかったためです。スクロールするか少し待ってから、もう一度抽出してください。

抽出ツールは最後に使った形式を記憶します。MarkdownのつもりがJSONで保存された場合は、「Export」の前にドロップダウンを確認してください。PDFを選ぶとGoogleサインインが求められます。無料プランで1日にPDFと一括エクスポートを合わせて3回使うと、Pro（月額$3.99または年額$26.99）の案内が表示されます。これは想定どおりの動作で、解析の失敗ではありません。回数はUTCの午前0時にリセットされます。

印刷やZIPという代替手段も含めた手順が知りたい場合はClaudeのチャットをダウンロードする方法を、印刷 →「PDFに保存」を含めた方法の比較ならClaudeのチャットをエクスポートする方法をご覧ください。この抽出ツールのページは、開いているスレッドを構造化されたファイルにしたい方向けです。

Claudeの会話抽出ツールは何を取り出しますか？

Claudeの会話抽出ツールは、claude.aiがすでに描画したメッセージツリーを読み取ります。ユーザーとアシスタントのやり取り、言語タグ付きのコードブロック、表、リンク、任意で思考です。アーティファクトの配置は「Original」「Inline」「Nested」「Flat」（元の配置／インライン／入れ子／フラット）から選べます。同じページからコピー＆ペーストするとこの構造は失われますが、抽出ツールならMarkdown、JSON、XMLに残ります。

思考はチェックボックスで切り替えます。抽出したファイルにClaudeの表示された推論を残したいならオンに、最終的な回答だけが欲しいならオフのままにします。メタデータにはタイトル、タイムスタンプ、モデルを含められます。「Messages」フィルター（All、Human、Assistant）、「Thinking」、「Select」は、エクスポートパネルの形式の横にあります。ツール／MCPのステップとWeb検索の出典は、設定でオンにします。機能の一覧：機能。

抽出ツールは、claude.aiのタブにすでに表示されている会話を読み取ります。コードブロック、表、アーティファクトの配置（Original、Inline、Nested、Flat）はそこで解析され、ファイルはローカルで作られます。PDFも同じです。

Claudeのチャット抽出ツールはどの形式で書き出せますか？

PDF、Markdown、JSON、プレーンテキスト、XML、CSV、PNGの7つです。Claudeのチャットを1件抽出する場合も、「Export All」を実行する場合も同じ7形式です。1.16.2では、Word、Notion、Googleドキュメントはありません。上限がかかるかどうかは形式で決まります。6つの形式はアカウント不要で無制限で、PDFは無料プランでは1件ごとに1日3回の枠を1回使います。

Claudeの会話を一括で抽出できますか？

はい。拡張機能のポップアップ →「View and Download All Conversations」（すべての会話を表示・ダウンロード）を開いて絞り込み、「Export All」（すべてエクスポート）をクリックします。会話抽出ツールは、選んだ形式で、選んだチャットごとに1ファイルが入った1つのZIPを書き出します。一括エクスポートにはGoogleサインインが必要です。アカウントがPro（月額$3.99または年額$26.99）でない限り、無料プランではZIPに入るチャット1件ごとに、PDFと共通の1日3回の枠を1回使います。

ダッシュボードの絞り込みは、「All conversations」「New」「Updated」「Previously exported」（すべての会話／新規／更新あり／エクスポート済み）です。ほかに「Chat」と「Cowork」のタブ、プロジェクト検索もあります。「New」は、抽出ツールでまだ保存していないチャットです。「Previously exported」は抽出済みの履歴を示し、後の一括実行で飛ばせます。プロジェクト検索はclaude.aiのプロジェクト分けに対応しています。「Export All」を実行する前に、名前で会話を検索することもできます。

一括でも解析の質は落ちません。ダッシュボードのチェックボックス「Chats」「Thinking」「Metadata」「Tools」「Sources」（チャット、思考、メタデータ、ツール、出典）とアーティファクトの配置で各ファイルの中身が決まり、「Chat format」（チャット形式）ではPDFを含む7つの形式すべてを選べます。利用上限の注意点を含む手順：一括の「Export All」。アカウント全体を1つのZIPでメールで受け取りたいなら、それはこの抽出ツールではなくSettings → Privacy → Export data（claude.aiを日本語表示にしている場合、メニュー名は日本語で表示されることがあります）です。

一括ではチャットごとに数えます。無料プランでは「Export All」とPDFで1日3回を共有し、ZIPに入るチャット1件ごとに1回を使います。残りが3回のときに25件のチャットを選ぶと、途中で打ち切られるのではなく、一括実行全体がブロックされます。大量に抽出する前に、「New」で絞り込んで件数を減らすか、UTCの午前0時のリセットを待つか、Pro（月額$3.99または年額$26.99）にアップグレードしてください。

会話抽出ツールとコピー＆ペーストの違いは？

コピー＆ペーストはClaudeの短い回答1つなら十分ですが、コードや表では失敗します。Anthropicの「Export data」はアカウント全体のバックアップZIPです。会話抽出ツールはその中間で、このスレッドまたは一括で選んだ会話を、構造化されたファイルとして、Chromeのclaude.aiからすぐに書き出します。

Claudeの会話抽出ツールは安全に使えますか？

この会話抽出ツールは、既存のclaude.aiセッションをWebサイトと同じように使います。アカウントの操作を自動化したり、チャットの本文を当方のAPIに送ったりはしません。Googleサインインが求められるのはPDF、一括エクスポート、Proのときだけで、1日の利用回数を数え、Proを復元するためのものです。支払いはPaddleが処理します。当方はAnthropicではなく、Anthropicの利用規約が引き続き適用されます。

PDF、一括エクスポート、Proのためにサインインすると、Cloudflare WorkerはGoogleのメールアドレス、その日のPDFと一括エクスポートの回数、Proかどうかを確認します。1件ずつのMarkdown、JSON、テキスト、XML、CSV、PNGのエクスポートでは、Workerには何も送られません。抽出したファイルを受け取ることも、PDFを含めて一切ありません。ファイルがブラウザの外に出るのは、Chromeのダウンロードフォルダーに保存されるときだけです。境界の詳細：仕組み。「Claudeのチャット抽出ツールは安全か」と気になる方は、この分担を見てください。課金はWorkerに、チャットはタブの中に。

「通信がまったくない」とは約束できません。claude.ai、Google、Workerはどれも存在します。お約束できるのは、チャットの本文が当方にアップロードされないということです。Anthropicの利用規約に従ってください。この拡張機能は独立したChrome拡張機能であり、Anthropicの公式製品ではありません。サポートのメールアドレスはサイトのフッターにあります。

モバイルブラウザとClaude Desktopには対応していません。Chromeのコンテンツスクリプトである会話抽出ツールは、そこでは動きません。2026年9月時点で、このページからSafari版やFirefox版を提供する予定はありません。デスクトップ版Chromeのclaude.aiを使ってください。拡張機能をブロックするチームのポリシーがあれば、この抽出ツールもブロックされます。
