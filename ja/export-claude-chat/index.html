claude.aiからClaudeのチャットをエクスポートするには？

Chromeでclaude.aiの会話を開き、メッセージ入力欄の横にあるオレンジ色のボタンをクリックし、PDF、Markdown、JSON、プレーンテキスト、XML、CSV、PNGから選んで「Export」をクリックします。Download Claude conversationsがファイルをローカルに書き出します。2026年9月時点で、claude.ai自体に「このチャットをエクスポート」という標準の機能はありません。

  1. Chrome Web StoreからDownload Claude conversationsをインストールします。
  2. claude.aiを再読み込みし、何も入力していないホーム画面ではなく、実際の会話のURLを開きます。
  3. メッセージ入力欄の右側にあるオレンジ色のダウンロードボタンをクリックします。
  4. パネルで「Messages」（メッセージ）を「All」「Human」「Assistant」（すべて／ユーザー／アシスタント）から選び、形式を選びます。拡張思考も残すなら「Thinking」（思考）にチェックを入れ、特定のメッセージだけを残すなら「Select」（選択）で1件ずつチェックを入れます。エクスポート用拡張機能は、最後に使った形式を記憶しています。
  5. 「Export」をクリックします。Chromeがブラウザのダウンロード機能を通じて、すぐにファイルを保存します。「Copy」（コピー）を使うと、ファイルの代わりにMarkdown、テキスト、JSON、XML、CSVをクリップボードに入れられます。

Markdown、テキスト、JSON、XML、CSV、PNGでClaudeのチャットをエクスポートするのに、アカウントは必要ありません。これらの単体エクスポートは無制限で、拡張機能が当方のサーバーに何かを送ることもありません。Googleサインインが求められるのは、PDFを選んだときと、一括の「Export All」（すべてエクスポート）を実行したときだけです。無料プランではこの2つを合わせて1日3回まで使え、回数はUTCの午前0時にリセットされます。このサインインにチャットの本文が含まれることはありません。仕組みの詳細：仕組み。

オレンジ色のボタンが表示されない場合は、会話のURLを開いていない、インストール後にタブを再読み込みしていない、または拡張機能のアイコンがChromeのパズルピースのメニューに隠れたままになっています。拡張機能を固定してから、claude.aiを再読み込みしてください。このエクスポート用拡張機能が動作するのはclaude.aiだけで、他のサイトに読み込まれることはありません。

1件のスレッドか、アカウント全体か。オレンジ色のボタンは、開いているチャットをエクスポートします。多数のファイルが必要なら、拡張機能のポップアップ →「View and Download All Conversations」（すべての会話を表示・ダウンロード）を開いて「Export All」を実行します。詳しくは一括の「Export All」をご覧ください。AnthropicのSettings → Privacy → Export data（claude.aiを日本語表示にしている場合、メニュー名は日本語で表示されることがあります）は後から届くアカウント全体のZIPで、この流れとは別物です。

Claudeのエクスポート用拡張機能は実際に何をするのですか？

Claudeのエクスポート用拡張機能は、ログイン済みのclaude.aiのタブにすでに表示されている会話を読み取り、構造化されたファイルをディスクに書き出します。この拡張機能は、そのためのChromeのコンテンツスクリプトです。送信者、メッセージツリー、コードブロック、表、任意で思考、アーティファクトの配置を扱います。チャットの周りの画面をスクリーンショットするものではありません。通常のチャット、プロジェクト、Coworkのセッション、Claude Code on the webで動作します。

claude.aiからコピー＆ペーストすると、インデントが失われ、表が崩れます。印刷（Ctrl/Cmd+P）ではサイドバーが残り、長いコードブロックがページの途中で分かれることがよくあります。エクスポート用拡張機能なら、Markdown、JSON、XMLでコードブロックの言語タグが保たれ、表は表のまま残ります。PNGは見た目を残すスナップショットの選択肢です。PDFはページ分けされた文書で、印刷ダイアログを使わずにブラウザ内で作成されます。

バージョン1.16.2では、アーティファクトの配置を「Original」「Inline」「Nested」「Flat」（元の配置／インライン／入れ子／フラット）から実際に切り替えられます。設定はダッシュボードで行います。拡張思考はエクスポートパネルのチェックボックスで含められ、Web検索の出典とツール／MCPのステップは設定でオンにできます。メタデータ（タイトル、タイムスタンプ、モデル）も含められます。「Messages」フィルターで、すべてのメッセージ、ユーザーのみ、アシスタントのみに絞れ、「Select」では個々のメッセージを選べます。機能の一覧：機能。

私たちがオレンジ色のボタンを作ったのは、claude.aiにあるチャットから、スレッドを当方のサーバーにアップロードせずに、PDF、Markdown、JSON、テキスト、XML、CSV、PNGの実際のファイルを書き出すためです。バージョン1.16.2では、PDFもブラウザ内で作成します。

「Export All」でClaudeのチャットを一括エクスポートできますか？

はい。拡張機能のポップアップ →「View and Download All Conversations」を開き、一覧を絞り込んでから「Export All」をクリックすると、ZIPができます。一括エクスポートにはGoogleサインインが必要です。無料プランではPDFと合わせて1日3回までで、ZIPに入る会話1件ごとに1回を使います。Proにすると、履歴全体でも上限がなくなります。

ダッシュボードには、claude.aiの会話履歴が一覧で表示されます。名前での検索、絞り込み（「All conversations」「New」「Updated」「Previously exported」＝すべての会話／新規／更新あり／エクスポート済み）、「Chat」と「Cowork」のタブ、プロジェクト検索を使えます。「New」は、Download Claude conversationsでまだエクスポートしていないチャットです。「Previously exported」は保存済みのチャットを記録しており、2回目の「Export All」で飛ばせます。プロジェクト検索は、claude.aiでのチャットのまとめ方に対応しています。

一括エクスポートでは、PDFを含む7つの形式すべてを選べる「Chat format」（チャット形式）、「Chats」「Thinking」「Metadata」「Tools」「Sources」（チャット、思考、メタデータ、ツール、出典）のチェックボックス、アーティファクトの配置（「Original」「Inline」「Nested」「Flat」）を使えます。「Export All」は中身を削ったアーカイブではありません。選んだ形式で、チャットごとに1ファイルが入った1つのZIPです。アカウント全体を1つのアーカイブにして後から受け取りたいなら、それはAnthropicの「Export data」です。次のセクションと一括エクスポートのページで比較しています。

一括ではチャットごとに数えます。無料プランでは「Export All」とPDFで1日3回を共有し、ZIPに入る会話1件ごとに1回を使います。残りが3回のときに40件の会話を選ぶと、途中で打ち切られるのではなく、一括実行全体がブロックされます。選ぶ件数を減らすか、UTCの午前0時のリセットを待つか、Pro（月額$3.99または年額$26.99）をお使いください。

DesktopやCodeでもチャットをエクスポートできますか？

Desktopアプリや、ターミナルのClaude Codeでは使えません。このエクスポート用拡張機能が動作するのは、Chrome（またはこの拡張機能を読み込めるChromium系ブラウザ）のclaude.aiだけです。Claude DesktopはMac/Windows用の別アプリで、そこやターミナルにオレンジ色のボタンが表示されることはありません。例外はClaude Code on the web（claude.ai/code）です。これらのセッションはclaude.ai上で開くので、通常のチャットと同じようにエクスポートできます。

同じスレッドがclaude.aiのアカウントにもあるなら、Chromeで開いてこの拡張機能でエクスポートしてください。チャットがDesktopにしかない場合は、アプリからコピー＆ペーストするか、WebでSettings → Privacy → Export dataを申請します。手順の違い：Claude Desktopのチャットをエクスポートする。

ターミナルのClaude Codeでは/exportか、ディスク上のJSONLのトランスクリプトを使います。このChrome拡張機能は、そうしたローカルのセッションを読み取りません。ターミナル向けの機能を期待してDownload Claude conversationsをインストールしないでください。ガイド：Claude Codeのエクスポート。CLIのセッションをエクスポートしたいなら、別の製品の手順になります。

スマートフォンのブラウザで使うclaude.aiも対象外です。このエクスポート用拡張機能にはデスクトップ版Chromeが必要です。2026年時点で、当チームのiOSやAndroidのアプリはありません。パソコンで会話を開き、オレンジ色のボタンか「Export All」でエクスポートしてください。

チャットのエクスポートとAnthropicの「Export data」の違いは？

Anthropicの「Export data」は、しばらく待った後にアカウント全体のJSON ZIPをメールで届けます。この拡張機能でのチャットのエクスポートは、開いているスレッドをすぐにPDF、Markdown、JSON、テキスト、XML、CSV、PNGで保存します。ZIPはバックアップに、エクスポート用拡張機能は今すぐ読めるファイルに使ってください。

Claudeのエクスポート用拡張機能の料金は？

Markdown、テキスト、JSON、XML、CSV、PNGのエクスポートは、アカウント不要で無料・無制限です。PDFと一括の「Export All」は、Googleサインインで1日3回まで無料です。ProはPaddle経由で月額$3.99または年額$26.99で、PDFと一括エクスポートが無制限になります。形式ごとの料金はありません。Chromeでチャットを開ければ、claude.aiのどのプランでも使えます。

PDFと一括エクスポートの1日の回数は、UTCの午前0時にリセットされます。Proは、新しいパソコンでも同じGoogleアカウントでサインインすれば復元できます。解約は、拡張機能のオプションページかPaddleからいつでもできます。販売元（Merchant of Record）はPaddleで、当チームがカード番号を見ることはありません。初回のお支払いには14日間の返金保証があり、返金ポリシーのページのとおりPaddle経由で対応します。

このエクスポート用拡張機能を使うのに、Anthropicの有料claude.aiプランは必要ありません。必要なのは、会話を開けるclaude.aiのログインとChromeだけです。オレンジ色のボタンは、TeamやEnterpriseでもFreeと同じように動きます。ワークスペースの管理者が拡張機能をブロックしている場合、この拡張機能は読み込まれません。これはブラウザのポリシーによるもので、形式の制限ではありません。

同じ作業、違う言い方。「Claudeのチャットをエクスポート」「Claudeのチャットをダウンロード」「Claudeの会話を抽出」は、どれも「このスレッドをファイルとして保存する」という意味です。印刷やZIPという代替手段も含めた手順ガイドはClaudeのチャットをダウンロードする方法です。このページは、エクスポート用拡張機能という製品の観点からの解説です。

チャットのエクスポートに失敗したときは、長いスレッドがclaude.aiで読み込まれるまで待ち、形式のドロップダウン（最後に使った形式が残ります）を確認し、PDFや一括エクスポートなら、今日の3回のうち何回残っているかを確かめてください。Chromeがダウンロードをブロックした場合は、claude.aiからのダウンロードを許可します。ファイルが不完全なのは、たいていページがまだメッセージツリー全体を表示していなかったためです。

ClaudeのチャットをPDFでエクスポートできますか？

はい。形式の一覧でPDFを選び、「Export」をクリックします。このエクスポート用拡張機能は、印刷ダイアログを使わずにブラウザ内でPDFを作成します。PDFにはGoogleサインインが必要で、1日3回まで無料です。Proなら無制限です。ガイド：ClaudeのチャットをPDFでダウンロード。

Claudeのチャットを1回エクスポートするのにProは必要ですか？

いいえ。Markdown、テキスト、JSON、XML、CSV、PNGのエクスポートは、アカウント不要で無料・無制限です。PDFと一括の「Export All」は、Googleサインインで1日3回まで無料です。Pro（月額$3.99または年額$26.99）にすると、この上限がなくなります。

はい。Chromeで会話を開ければ、claude.aiのFree、Pro、Team、Enterpriseのどのプランでも使えます。このエクスポート用拡張機能にAnthropicの有料プランは必要ありません。

このエクスポート用拡張機能はClaude Code向けですか？

Claude Desktopからチャットをエクスポートできますか？

このエクスポート用拡張機能は何回まで無料ですか？

Markdown、テキスト、JSON、XML、CSV、PNGは、アカウント不要で無制限です。PDFと一括の「Export All」は、無料プランでは合わせて1日3回までで、Googleサインインが必要です。一括ZIPでは、チャット1件ごとに1回として数えます。回数はUTCの午前0時にリセットされます。Proにすると上限がなくなり、Googleサインインで復元できます。

Claudeのチャットをエクスポートするオレンジ色のボタンはどこにありますか？

Download Claude conversationsをインストールして再読み込みすると、claude.aiの会話URLでメッセージ入力欄の右側に表示されます。何も入力していないホーム画面やDesktopには表示されません。

チャットをエクスポートすると会話がアップロードされますか？

いいえ。PDFを含むすべての形式はブラウザ内で作られ、Chromeのダウンロード機能に渡されます。Markdown、テキスト、JSON、XML、CSV、PNGのエクスポートでは、当方に何も送信されません。PDF、一括エクスポート、Proのためにサインインした後も、当方のワーカーが見るのは利用回数やサブスクリプションの状態とGoogleのメールアドレスだけで、チャットの本文を見ることはありません。詳しくは「仕組み」のページをご覧ください。

このエクスポート用拡張機能はどの形式で書き出せますか？

PDF、Markdown、プレーンテキスト、JSON、XML、CSV、PNGの7つです。1件のチャットでも「Export All」でも同じ7形式です。バージョン1.16.2では、Word、Notion、Googleドキュメントへのエクスポートはありません。
