claude.aiからClaudeのチャットをエクスポートするには？

Chromeでclaude.aiの会話を開き、メッセージ入力欄の横にあるオレンジ色のボタンをクリックし、Markdown、JSON、プレーンテキスト、XML、PNGから選んで「Export」をクリックします。この拡張機能がファイルをローカルに書き出します。2026年9月時点で、claude.ai自体に「このチャットをエクスポート」という標準の機能はありません。

  1. Chrome Web StoreからDownload Claude conversationsをインストールします（ストアでの評価は5.0）。
  2. claude.aiを再読み込みし、何も入力していないホーム画面ではなく、実際の会話のURLを開きます。
  3. メッセージ入力欄の右側にあるオレンジ色のダウンロードボタンをクリックします。
  4. 形式を選びます。エクスポート用拡張機能は、最後に使った形式を記憶しています。
  5. 「Export」をクリックします。Chromeがブラウザのダウンロード機能を通じて、すぐにファイルを保存します。

最初にClaudeのチャットをエクスポートする前に、Googleサインインが必要です。この拡張機能は、3回の無料エクスポートを数え、再インストール後にProを復元するために、確認済みのメールアドレスを保存します。このサインインにチャットの本文は含まれません。仕組みの詳細：仕組み。

オレンジ色のボタンが表示されない場合は、会話のURLを開いていない、インストール後にタブを再読み込みしていない、または拡張機能のアイコンがChromeのパズルピースのメニューに隠れたままになっています。拡張機能を固定してから、claude.aiを再読み込みしてください。このエクスポート用拡張機能が動作するのはclaude.aiだけで、他のサイトに読み込まれることはありません。

1件のスレッドか、アカウント全体か。オレンジ色のボタンは、開いているチャットをエクスポートします。多数のファイルが必要なら「View and Download All Conversations」（すべての会話を表示・ダウンロード）を開いて「Export All」（すべてエクスポート）を実行します。詳しくは一括の「Export All」をご覧ください。AnthropicのSettings → Privacy → Export data（claude.aiを日本語表示にしている場合、メニュー名は日本語で表示されることがあります）は後から届くアカウント全体のZIPで、この流れとは別物です。

Claudeのエクスポート用拡張機能は実際に何をするのですか？

Claudeのエクスポート用拡張機能は、ログイン済みのclaude.aiのタブにすでに表示されている会話を読み取り、構造化されたファイルをディスクに書き出します。この拡張機能は、そのためのChromeのコンテンツスクリプトです。送信者、メッセージツリー、コードブロック、表、任意で思考、アーティファクトの配置を扱います。チャットの周りの画面をスクリーンショットするものではありません。

claude.aiからコピー＆ペーストすると、インデントが失われ、表が崩れます。印刷（Ctrl/Cmd+P）ではサイドバーが残り、長いコードブロックがページの途中で分かれることがよくあります。エクスポート用拡張機能なら、Markdown、JSON、XMLでコードブロックの言語タグが保たれ、表は表のまま残ります。PNGは見た目を残すスナップショットの選択肢ですが、PDFではありません。

バージョン1.13.0では、アーティファクトの配置を「Original」「Inline」「Nested」「Flat」（元の配置／インライン／入れ子／フラット）から実際に切り替えられます。思考ブロックは任意です。メタデータ（タイトル、タイムスタンプ、モデル）も含められます。送信者フィルターで、すべてのメッセージ、ユーザーのみ、アシスタントのみに絞れます。機能の一覧：機能。

私たちがオレンジ色のボタンを作ったのは、claude.aiにあるチャットから、スレッドを当方のサーバーにアップロードせずに、Markdown、JSON、テキスト、XML、PNGの実際のファイルを書き出すためです。バージョン1.13.0でもPDFは出力しません。

同じChromeの拡張機能を、Claude Chat DownloaderやClaude Conversation Downloaderという名前で探す人もいます。法的情報のページにはClaude Exporterという表記が残っている場合があります。どの名前もDownload Claude conversationsのことで、別の製品ではありません。「エクスポート」ではなく「抽出」で探しても同じボタンにたどり着きます。その観点での解説はClaudeの会話抽出ツールのガイドにあります。

Claudeのチャットはどの形式でエクスポートすべき？

Claudeのチャットは、メモならMarkdown、スクリプトならJSON、飾りのないアーカイブならプレーンテキスト、データ交換ならXML、スレッドの画像ならPNGでエクスポートします。この拡張機能では、この5つを1つのドロップダウンから選べます。PDF形式はありません。

文章を書く人はたいていClaudeのチャットをMarkdownでエクスポートし、開発者はJSONを選びます。PDFのようなページがどうしても必要なら、提供していない形式を待つのではなく、Chromeから印刷してください。手順：Claudeの会話を印刷する。エクスポート用拡張機能で作るPNGは画像ファイルで、ページ分けされた文書ではありません。

形式を選んでも、3回の無料枠は変わりません。Markdown、JSON、テキスト、XML、PNGのどれでも、ファイルが完成した時点で1回として数えます。Pro（月額$3.99または年額$26.99）にすると、すべての形式で上限がなくなります。1.13.0では、Notion、Word、Googleドキュメントへの書き出しはありません。

「Export All」でClaudeのチャットを一括エクスポートできますか？

はい。「View and Download All Conversations」を開き、一覧を絞り込んでから「Export All」をクリックします。完成したファイルはそれぞれ、オレンジ色のボタンと同じ3回の無料枠のうち1回として数えます。Proにすると、1件のスレッドと同じように一括でも上限がなくなります。

一覧には、名前での検索と、All（すべて）、New（新規）、Exported（エクスポート済み）、Project（プロジェクト）の絞り込みを備えたclaude.aiの会話履歴が表示されます。Newは、この拡張機能でまだエクスポートしていないチャットです。Exportedは保存済みのチャットを記録しており、2回目の「Export All」で飛ばせます。Projectは、claude.aiでのチャットのまとめ方に対応しています。

一括でも、1件の会話と同じ切り替え（Chats、Thinking、Metadata、アーティファクトの配置「Original」「Inline」「Nested」「Flat」）と、同じ5つの形式が使えます。「Export All」は中身を削ったZIPではなく、チャットごとの多数のファイルです。アカウント全体を1つのアーカイブにして後から受け取りたいなら、それはAnthropicの「Export data」です。次のセクションと一括エクスポートのページで比較しています。

無料枠はアカウント全体で共通です。無料エクスポートは合計3回で、一括実行ごとに3回ではありません。一覧で40件の会話を選ぶと、すべてのファイルが完成すれば40回分を使います。「Export All」をクリックする前に選ぶ会話を計画するか、Pro（月額$3.99または年額$26.99）を使ってください。

DesktopやCodeでもチャットをエクスポートできますか？

いいえ。このエクスポート用拡張機能が動作するのは、Chrome（またはこの拡張機能を読み込めるChromium系ブラウザ）のclaude.aiだけです。Claude DesktopはMac/Windows用の別アプリで、Claude Codeはターミナルのエージェントです。これらのウィンドウにオレンジ色のボタンが表示されることはありません。

同じスレッドがclaude.aiのアカウントにもあるなら、Chromeで開いてこの拡張機能でエクスポートしてください。チャットがDesktopにしかない場合は、アプリからコピー＆ペーストするか、WebでSettings → Privacy → Export dataを申請します。手順の違い：Claude Desktopのチャットをエクスポートする。

Claude Codeでは/exportか、ディスク上のJSONLのトランスクリプトを使います。これはこのChrome拡張機能のMarkdownではありません。ターミナル向けの機能を期待してDownload Claude conversationsをインストールしないでください。ガイド：Claude Codeのエクスポート。CLIのセッションをエクスポートしたいなら、別の製品の手順になります。

スマートフォンのブラウザで使うclaude.aiも対象外です。このエクスポート用拡張機能にはデスクトップ版Chromeが必要です。2026年時点で、当チームのiOSやAndroidのアプリはありません。パソコンで会話を開き、オレンジ色のボタンか「Export All」でエクスポートしてください。

チャットのエクスポートとAnthropicの「Export data」の違いは？

Anthropicの「Export data」は、しばらく待った後にアカウント全体のJSON ZIPをメールで届けます。この拡張機能でのチャットのエクスポートは、開いているスレッドをすぐにMarkdown、JSON、テキスト、XML、PNGで保存します。ZIPはバックアップに、エクスポート用拡張機能は今すぐ読めるファイルに使ってください。

Claudeのエクスポート用拡張機能の料金は？

Googleでサインインしたアカウントごとに、3回まで無料でエクスポートできます。それ以降は、Paddle経由でProが月額$3.99または年額$26.99です。この料金にはオレンジ色のボタンと「Export All」の両方が含まれます。形式ごとの料金はありません。Chromeでチャットを開ければ、claude.aiのどのプランでも使えます。

3回の無料エクスポートは、Chromeの拡張機能を再インストールしてもリセットされません。そのため、最初にチャットをエクスポートするときにGoogleサインインが必要です。Proは同じGoogleアカウントで新しいパソコンでも復元できます。販売元（Merchant of Record）はPaddleで、当チームがカード番号を見ることはありません。返金は返金ポリシーのページのとおりPaddle経由で行います。

このエクスポート用拡張機能を使うのに、Anthropicの有料claude.aiプランは必要ありません。必要なのは、会話を開けるclaude.aiのログインとChromeだけです。オレンジ色のボタンは、TeamやEnterpriseでもFreeと同じように動きます。ワークスペースの管理者が拡張機能をブロックしている場合、この拡張機能は読み込まれません。これはブラウザのポリシーによるもので、形式の制限ではありません。

同じ作業、違う言い方。「Claudeのチャットをエクスポート」「Claudeのチャットをダウンロード」「Claudeの会話を抽出」は、どれも「このスレッドをファイルとして保存する」という意味です。印刷やZIPという代替手段も含めた手順ガイドはClaudeのチャットをダウンロードする方法です。このページは、エクスポート用拡張機能という製品の観点からの解説です。

チャットのエクスポートに失敗したときは、長いスレッドがclaude.aiで読み込まれるまで待ち、形式のドロップダウン（最後に使った形式が残ります）を確認し、3回の無料枠に達していないか確かめてください。Chromeがダウンロードをブロックした場合は、claude.aiからのダウンロードを許可します。ファイルが不完全なのは、たいていページがまだメッセージツリー全体を表示していなかったためです。

このページの内容はバージョン1.13.0（2026年9月）時点のものです。形式は引き続きMarkdown、JSON、プレーンテキスト、XML、PNGです。この一覧が変われば、このガイドも同じ日に更新します。それまでは、このエクスポート用拡張機能にWord、Notion、ネイティブなPDFは期待しないでください。

よくある質問：Claudeのチャットをエクスポートする方法

ここでは、Claudeのチャットのエクスポートとエクスポート用拡張機能について、形式、無料枠、Desktop、Claude Code、AnthropicのZIP、オレンジ色のボタンの場所をまとめています。どの回答もバージョン1.13.0の事実に基づいています。ページのheadにあるFAQPageのJSON-LDも、この一覧と同じ内容です。

当サイトでいう「Claudeのチャットをエクスポート」とは？

Download Claude conversationsを使って、claude.aiの会話をファイルとして保存することです。オレンジ色のボタン、形式の選択、「Export」の3ステップです。英語で「claude export chat」と検索されるのと同じ作業です。Anthropicからメールで届くZIPでも、Claude Codeの/exportでもありません。

Claudeのエクスポート用拡張機能は「Export data」と同じですか？

いいえ。Settings → Privacy → Export dataは、アカウント全体のJSON ZIPをメールで届けるものです。Claudeのエクスポート用拡張機能は、開いているチャットや「Export All」で選んだチャットを、ChromeですぐにMarkdown、JSON、テキスト、XML、PNGとして書き出します。

ClaudeのチャットをPDFでエクスポートできますか？

このエクスポート用拡張機能ではできません。形式はMarkdown、JSON、プレーンテキスト、XML、PNGです。PDFのようなスナップショットが必要なら、Chromeでclaude.aiのページを印刷してください。PNGは画像で、PDFではありません。

Claudeのチャットを1回エクスポートするのにProは必要ですか？

いいえ。Googleでサインインしたアカウントなら、最初の3回はどの形式でも無料です。Pro（月額$3.99または年額$26.99）にすると、1件ずつでも一括でも上限がなくなります。

claude.aiのどのプランでもチャットをエクスポートできますか？

はい。Chromeで会話を開ければ、claude.aiのFree、Pro、Team、Enterpriseのどのプランでも使えます。このエクスポート用拡張機能にAnthropicの有料プランは必要ありません。

このエクスポート用拡張機能はClaude Code向けですか？

いいえ。Download Claude conversationsはChromeのclaude.aiで動作します。Claude Codeでは/exportかディスク上のJSONLを使います。Claude Codeのエクスポートのガイドをご覧ください。

Claude Desktopからチャットをエクスポートできますか？

このChrome拡張機能ではできません。同期されていればclaude.aiで同じスレッドを開くか、コピー＆ペーストするか、公式の「Export data」を使ってください。Desktopにオレンジ色のボタンが表示されることはありません。

このエクスポート用拡張機能は何回まで無料ですか？

アカウントごとに3回で、オレンジ色のボタンと「Export All」の合計です。再インストールしても回数はリセットされません。ProはGoogleサインインで復元されます。

Claudeのチャットをエクスポートするオレンジ色のボタンはどこにありますか？

Download Claude conversationsをインストールして再読み込みすると、claude.aiの会話URLでメッセージ入力欄の右側に表示されます。何も入力していないホーム画面やDesktopには表示されません。

チャットをエクスポートすると会話がアップロードされますか？

いいえ。ファイルはブラウザ内で作られ、Chromeのダウンロード機能に渡されます。当方のサーバーが見るのはサブスクリプションの状態とGoogleで確認されたメールアドレスだけで、チャットの本文ではありません。詳しくは「仕組み」のページをご覧ください。

このエクスポート用拡張機能はどの形式で書き出せますか？

Markdown、JSON、プレーンテキスト、XML、PNGです。1件のチャットでも「Export All」でも同じ5形式です。バージョン1.13.0では、PDF、Word、Notion、Googleドキュメントへのエクスポートはありません。
