Claudeの会話履歴をすべて一括エクスポートする

claude.aiの会話履歴をすべて一括エクスポートするには、「View and Download All Conversations」（すべての会話を表示してダウンロード）を開き、絞り込んでから「Export All」（すべてエクスポート）をクリックします。拡張機能がMarkdown、JSON、テキスト、XML、PNGをローカルで書き出します。Pro（月額$3.99または年額$26.99）でない場合、各ファイルが無料エクスポート3回のうち1回を使います。これはClaude Desktop、Claude Code、Anthropicからメールで届くZIPとは別の方法です。

Claudeの会話履歴をすべてエクスポートするには？

拡張機能のアイコンをクリックし、すべての会話の一覧ページを開いて、「Export All」をクリックします。この一覧ページにはclaude.aiの履歴が並ぶので、Claudeの会話履歴を個別のファイルとしてまとめて保存できます。スレッドごとのオレンジ色のボタンがもう一つの入り口で、一括エクスポートはこの一覧表から行います。

  1. Chrome Web Storeから拡張機能（評価5.0）をインストールし、固定します。このガイドのバージョンは1.13.0（2026年9月）です。
  2. Chromeでclaude.aiにログインします。一括エクスポートは、サイトと同じセッションを読み取ります。
  3. ポップアップを開き、「View and Download All Conversations」をクリックします。
  4. 検索や絞り込みをして、本当に必要なチャットを選びます。
  5. Markdown、JSON、プレーンテキスト、XML、PNGのいずれかを選び、「Export All」をクリックします。

検索と「Export All」を備えた、Claudeの会話の一覧ページ

最初のファイルの前に（最初の一括エクスポートも含む）、Googleログインが必要です。拡張機能は、無料エクスポート3回の管理とProの復元のために、確認済みのメールアドレスを保存します。チャットの本文はブラウザ内にとどまります。処理の流れ：仕組み。1つのタブだけで足りる場合の手順：Claudeのチャットをダウンロードする方法。

「履歴すべて」とは、1つのZIPではなく多数のファイルのことです。「Export All」は、選択したclaude.aiの会話1件につき1ファイルを書き出します。MarkdownやJSONのフォルダではなく、1つのバックアップのまとまりが欲しいなら、Anthropicの Settings → Privacy → Export data（claude.aiを日本語で表示している場合、ラベルは翻訳されていることがあります）で、時間をおいて届くアカウントのZIPを使います。

「Export All」の前にClaudeのチャットを絞り込むには？

検索では会話を名前で探せます。フィルターは「All」「New」「Exported」「Project」（すべて／未エクスポート／エクスポート済み／プロジェクト）です。Claudeの会話をまとめてエクスポートする前にこれらを使えば、すでに持っているファイルに回数を使わずに済みます。「New」はこの拡張機能でまだエクスポートしていないもの、「Exported」はすでに保存したチャットです。

「Project」は、claude.aiでスレッドをまとめているプロジェクトに対応します。よくある一括エクスポートは「このプロジェクト」や「Newだけ」で、「アカウント作成以来のすべて」ではありません。行を選び、「Export All」を一度だけ実行します。何十ものURLでオレンジ色のボタンを繰り返すのは時間のかかるやり方で、この一覧表はそれを置き換えるためにあります。

「Exported」フィルターは、この拡張機能の中だけの記録です。Anthropicのバックアップの概念とは関係ありません。以前に公式のデータエクスポートを使っていても、この拡張機能でファイルを書き出すまで、それらのチャットはここで「New」と表示されることがあります。それで正常です。一覧表の機能の概要：機能。

実行する前に選択を確認してください。「Export All」は、選択したすべての行についてファイルを書き出そうとします。無料プランの上限は3回なので、40行を選ぶならPro（月額$3.99または年額$26.99）向けの作業であり、無料プランで試すものではありません。まず「New」や1つのプロジェクトに絞り込んでください。

一括エクスポートの各ファイルには何が含まれる？

一括エクスポートでも、1つのチャットを保存するときと同じ設定を使います。チャット、思考プロセス、メタデータ、アーティファクトのレイアウト（「Original」「Inline」「Nested」「Flat」）です。Claudeの会話の一括エクスポートは、品質を落としたZIPではありません。各ファイルに、コードブロック、表、必要に応じて推論を残せます。送信者フィルターでは、すべて、人間のみ、アシスタントのみ（「all / human only / assistant only」）を選べます。

思考プロセスは、ページに表示されていた場合のClaudeの拡張思考（extended reasoning）です。メタデータには、タイトル、タイムスタンプ、モデルを含められます。アーティファクトのレイアウトは、Markdown、JSON、XMLの中でアーティファクトをどう配置するかを決めます。PNGはあくまでスレッドの画像です。どの設定でもPDFは追加されません。印刷はブラウザの別の操作です：印刷／PDF。

「Export All」でも、1つのチャットを保存するときと同じく、各ファイルが無料エクスポート3回の枠に数えられます。Pro（月額$3.99または年額$26.99）は、どちらの方法にも共通のライセンスです。一括エクスポートは、単体のエクスポートをまとめて実行するもので、別の製品ではありません。

一括エクスポートのファイルが不完全な場合、たいていは非常に長い会話が最後まで表示されていなかったのが原因です。「Export All」も、開いた各チャットについてclaude.aiが読み込んだ内容に依存します。ファイルが短いと感じたら、その会話を開いて待ち、その行をもう一度エクスポートしてください。ダウンロードが成功すると、一覧表の「Exported」の状態が更新されます。

一括エクスポートで無料エクスポートを何回使う？

書き出しが完了したファイル1つが1回のエクスポートで、オレンジ色のボタンと同じです。どのアカウントも、単体と一括を合わせて合計3回まで無料でエクスポートできます。一括専用の枠はありません。Pro（月額$3.99または年額$26.99）なら、どちらも上限がなくなります。ProはPaddleが課金し、私たちがカード情報を見ることはありません。

Chromeを再インストールしても、3回のカウントはリセットされません。そのため、Claudeの会話履歴を保存する最初のファイルの前にGoogleログインが必要です。Proは、同じGoogleアカウントであれば新しいパソコンでも復元されます。claude.aiのFree、Pro、Team、Enterpriseのどのプランでも、セッションで会話の一覧を表示できれば使えます。Anthropicのプランは、私たちの回数管理とは関係ありません。

選択は計画的に。「New」の3件をMarkdownで書き出すのは、無料プランでも有効な一括エクスポートです。30件ならProです。形式を混ぜても回数が倍になるわけではなく、書き出したPNGやJSONはそれぞれ1回と数えます。Proにアップグレードした後で考えが変わった場合の返金は、返金ページのとおりPaddleを通じて行います。

一括エクスポートとバックアップ用ZIPの違いは？

「Claudeのチャットをバックアップする」というと、ふつうはAnthropicの Settings → Privacy → Export data を指します。アカウント全体のJSONのZIPが、時間をおいて1つ届きます。「Export All」による一括エクスポートは、選んだファイルを、すぐに、Markdown、JSON、テキスト、XML、PNGで書き出します。アカウントのバックアップにはZIPを、文書が必要ならこのページの方法を使ってください。

公式のZIPは、チャットごとのMarkdownではなく、「New」や「Exported」のフィルターもありません。一方、「Export All」は、一覧表に表示されない忘れられたスレッドまですべて取り出す、法務やコンプライアンス向けのデータ出力ではありません。一覧ページに表示されない会話を、この拡張機能が作り出すことはできません。印刷も含めた方法の比較：Claudeのチャットをエクスポートする方法。

「Claude チャット履歴 保存」や「Claude 会話履歴 エクスポート」で検索する方も、同じ分かれ道に立っています。目的がClaudeのチャットのバックアップなら、Anthropicのデータエクスポートから始めてください。目的がメモのフォルダなら、「Export All」を使ってください。どちらの方法もClaude Desktop向けではなく、Claude Codeの /export でもありません。

一括エクスポートはDesktopやCodeで使える？

いいえ。この拡張機能でClaudeの会話履歴をまとめて保存するには、Chromeで開いたclaude.aiが必要です。Claude Desktopにこの一覧ページは表示されません。Claude Codeでは /export やディスク上のJSONLを使います。拡張機能をインストールしても、それらの製品に一括エクスポートは追加されません。

Desktopのスレッドが同じアカウントに同期されていれば、claude.aiに存在する時点で一覧表に表示されます。一度も同期されていなければ、一括エクスポートからは見えません。Desktopでの代替手段：Claude Desktopのチャットをエクスポートする。ターミナルのセッション：Claude Codeのエクスポート。リポジトリのJSONLが出てくると期待して「Export All」を実行しないでください。

モバイル版のChromeにも対応していません。一覧ページは、パソコン用の拡張機能の画面です。2026年時点で、私たちのiOS向けの一括ダウンローダーはありません。パソコンでclaude.aiを開いてください。拡張機能を禁止するチームのポリシーがある場合、一括エクスポートも使えません。

一括エクスポートにはどの形式を使うべき？

「Export All」の1回の実行につき、1つの形式を選びます。ノート管理ならMarkdown、処理の自動化ならJSON、装飾なしの保存ならプレーンテキスト、データ交換ならXML、画像ならPNGです。Claudeの会話の一括エクスポートでも、オレンジ色のボタンと同じ5つの形式が使えます。一覧：対応形式。1.13.0にPDFはありません。

文章を書く人はたいていMarkdownで一括保存します — Markdownガイド。開発者はたいていJSONで一括保存します — JSONガイド。XML：XML。PNG：PNG。「Export All」のJSONも、ページから作るチャットごとのファイルであり、AnthropicのアカウントZIPとは構造が違います。1つのスクリプトでこの2つのスキーマを混ぜないでください。

形式を選んでも料金は変わりません。PNGの一括エクスポートでも、画像1枚につき1回を使います。1回目にMarkdown、2回目にJSONで書き出すと、チャットごとに2回分を使います。重複を避けるには「Exported」フィルターを使ってください。同じファイルを「抽出」という観点で説明したページ：Claude会話エクストラクター。製品としての単体エクスポート：Claudeのチャットをエクスポートする。

ほかのエクスポーターの名前は挙げません。Anthropic公式のデータエクスポートは、バックアップ用ZIPとの比較のために名前を挙げています。Download Claude conversations（Claude Chat Downloader／Claude Conversation Downloaderとも呼ばれます）は、Chromeで一括エクスポートするための拡張機能です。独立した拡張機能であり、Anthropic, PBCとは提携していません。Chrome Web Storeで評価5.0です。

「Export All」が止まる場合は、claude.aiに対するChromeのダウンロードの許可を確認し、3回の上限に達していないか（またはProか）を確かめて、「New」だけで再試行してください。一覧表が空の場合は、ログアウトしているか、コンテンツスクリプトが読み取れるclaude.aiのセッションではありません。claude.aiを再読み込みしてから、一覧ページを開き直してください。

よくある質問：Claudeの会話履歴を一括エクスポート

ここでは、Claudeの会話履歴のエクスポート、「Export All」による一括エクスポート、Claudeのチャットのバックアップについての質問に答えます。回数制限、プロジェクトのフィルター、Desktop、Claude Code、PDF、AnthropicのZIPについてです。回答はclaude.aiで使う拡張機能1.13.0に基づいています。ページのheadにあるFAQPageのJSON-LDはこの一覧と一致しています。

Claudeのチャットを一括でダウンロードするには？

拡張機能の一覧ページを開き、行を選ぶか絞り込んで、形式を選び、「Export All」をクリックします。各ファイルはMarkdown、JSON、テキスト、XML、PNGのいずれかです。これが、Claudeの会話履歴を個別の文書としてすべて保存する方法です。

一括エクスポートは単体のエクスポートより多く回数を使いますか？

いいえ。数え方は同じで、オレンジ色のボタンと「Export All」を合わせて合計3回まで無料です。Pro（月額$3.99または年額$26.99）はどちらにも使えます。一括エクスポートのファイル1つは、1つのチャットを保存するのと同じく1回分です。

1つのプロジェクトのClaudeの会話履歴だけをダウンロードできますか？

はい。一覧ページで「Project」で絞り込み、「Export All」を実行します。アカウント内のすべてのスレッドを取らずに、Claudeの会話をまとめてエクスポートする一般的な方法です。

一括エクスポートはAnthropicの公式エクスポートと同じですか？

いいえ。公式のデータエクスポートは、アカウント全体のJSONのZIPがメールで1つ届くもの（Claudeのチャットのバックアップ）です。「Export All」による一括エクスポートは、選んだファイルを、すぐに、選んだ形式で書き出します。

拡張機能はエクスポート済みのチャットを覚えていますか？

はい。「Exported」フィルターで、この拡張機能がすでにダウンロードしたものを管理できるので、次に使うときは「New」だけを対象に「Export All」を実行できます。

これがClaudeの会話履歴をすべて保存する方法ですか？

はい。一覧ページの「Export All」が、Claudeの会話履歴を個別のファイルとしてすべて保存する方法です。Anthropicのデータエクスポートは、代わりにアカウントのZIPが時間をおいて1つ届きます。

一括エクスポートはClaude Desktopで使えますか？

いいえ。このChrome拡張機能はClaude Desktopでは動きません。先にチャットをclaude.aiに同期するか、コピー＆ペースト／公式のZIPを使ってください。

「Export All」でClaudeのチャットをバックアップできますか？

「Export All」で得られるのは読みやすいファイルのフォルダで、Anthropicのバックアップ用ZIPではありません。アカウント単位でClaudeのチャットをバックアップするなら、Settings → Privacy → Export data を使ってください。文書とアーカイブの両方が欲しいなら、両方使いましょう。

一括エクスポートでPDFファイルを書き出せますか？

いいえ。形式はMarkdown、JSON、プレーンテキスト、XML、PNGです。PDFのようなページが必要ならChromeから印刷してください。PNGの一括エクスポートでは、チャット1件につき1枚の画像ができます。

Claudeの会話履歴の一括エクスポートはClaude Codeにも使えますか？

いいえ。Claude Codeでは /export やディスク上のJSONLを使います。一括エクスポートの一覧に表示されるのは、Chromeで開いたclaude.aiの会話だけです。

「Export All」が3ファイルで止まったら？

無料エクスポート3回を使い切っています。Pro（月額$3.99または年額$26.99）にアップグレードするか、必要になるまで待ってください。再インストールしても、Googleアカウントに紐づいたカウントはリセットされません。

一括エクスポートにAnthropicの有料プランは必要ですか？

いいえ。Chromeで履歴を読み込めるclaude.aiのプランなら、どれでも使えます。私たちの無料／Proの回数管理は別物です。ただし、Teamの管理者がブラウザで拡張機能をブロックしている場合は使えません。
