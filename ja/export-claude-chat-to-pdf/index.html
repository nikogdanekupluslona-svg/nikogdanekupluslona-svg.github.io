ClaudeのチャットをPDFにエクスポートする方法 — ワンクリックと最適な設定で

ClaudeのチャットをPDFにエクスポートするには、Download Claude conversationsをインストールし、claude.aiでチャットを開いてオレンジ色のボタンをクリックし、PDFを選んで「Export」（エクスポート）をクリックします。拡張機能はブラウザの中でPDFを作成し、用紙サイズ、余白、ダークモードまたはライトモード、目次を好みどおりに設定できます。PDFは1日3回まで無料です。

ClaudeのチャットをPDFにエクスポートする手順は？

ClaudeのチャットをPDFにエクスポートするには、パソコンのChromeと無料のDownload Claude conversations拡張機能が必要です。操作は5回のクリックで終わります。チャットを開き、オレンジ色のボタンをクリックし、PDFを選び、「Export」をクリックして、PDFダイアログで確定します。最初のPDFでは、Googleでのサインインを求められます。

  1. Chrome Web StoreからDownload Claude conversationsをインストールし、開いているclaude.aiのタブを再読み込みします。
  2. claude.aiで会話を開き、最後の回答の生成が終わるまで待ちます。
  3. メッセージ入力欄の右にある、丸いオレンジ色のダウンロードボタンをクリックします。エクスポートパネルが開きます。
  4. 「Format」（形式）でPDFを選びます。「Messages」（メッセージ）は「All」（すべて）のままにするか、片方の発言だけを残すなら「Human」（ユーザー）または「Assistant」（アシスタント）を選びます。
  5. 「Export」をクリックします。初回はGoogleでサインインし、PDFのオプションを設定してファイルを保存します。

同じ5つの手順は、通常のチャット、プロジェクト、Coworkのセッション、Claude Code on the web（claude.ai/code）でも使えます。Chromeのclaude.aiで開けるものなら、何でもPDFにエクスポートできます。拡張機能はClaude Desktopアプリやスマートフォンでは動きません。その場合は、パソコンのChromeで同じチャットを開いてください。

拡張思考は、エクスポートパネルの「Thinking」（思考）チェックボックスで選びます。ツール／MCPのステップとWeb検索の出典は、拡張機能の設定でオンにします。PDFに入るのはチェックを入れたものだけなので、長い推論のあるチャットでも、紙の上では短くまとめられます。

無料プランでのPDFの上限。PDFのエクスポートにはGoogleサインインが必要で、一括ZIPのエクスポートと合わせて1日3回まで無料です。回数はUTCの午前0時（日本時間の午前9時）にリセットされます。Pro（月額$3.99または年額$26.99）なら、PDFは無制限になります。Markdown、テキスト、JSON、XML、CSV、PNGは、引き続きアカウント不要で無制限です。

Claudeのチャットが文書としてどう見えるかは、PDFダイアログで決まります。用紙サイズ、余白、フォントは読みやすさを左右します。ページ番号、目次、タイムスタンプがあれば、長いチャットでも目的の箇所を探しやすくなります。プロンプトごとの改ページを使うと、質問ごとに新しいページから始まります。

PDFはブラウザの中で作成するので、設定は書いてあるとおりに効きます。用紙サイズ、余白、ダークモード、ページ番号、目次、プロンプトごとの改ページです。印刷で得られるのはWebページだけです。共有する前にテキストを編集したいなら、代わりにMarkdownでエクスポートしてください。

拡張機能なしでClaudeのチャットをPDFに保存するには？

何もインストールせずにClaudeのチャットをPDFに保存するには、Chromeの印刷ダイアログを使います。チャットを開き、WindowsならCtrl+P、MacならCmd+Pを押し、送信先を「PDF に保存」にして保存します。できるファイルはWebページのスナップショットで、エクスポートした文書ではありません。Claude向けの設定もありません。

  1. claude.aiで会話を開き、すべてのやり取りが読み込まれるよう、いちばん最初のメッセージまでスクロールします。
  2. サイドバーを折りたたみ、紙に載せたくないアーティファクトのパネルを閉じます。
  3. Ctrl+PまたはCmd+Pを押します。「送信先」で「PDF に保存」を選びます。
  4. 「詳細設定」を開いて用紙サイズと余白を選び、ページが薄く見える場合は「背景のグラフィック」にチェックを入れます。
  5. 「保存」をクリックします。

Google自身のChromeヘルプも、同じ手順を次の一行で締めくくっています。「[PDF に保存] をクリックします。」印刷でできるのはそこまでです。プロンプトごとの改ページも、目次も、ダークモードも付きません。

各ページに何が載るかを決めるのは、あなたではなくclaude.aiの印刷用スタイルシートです。MDNはCSSのページメディアを、「分割されたコンテンツを収めるために、ページ単位の表示でページをどのように生成し、レイアウトするか」を指定するルールだと説明しています。このルールがコードブロックを分割すれば、PDFでも分割されたままです。

先にスレッド全体を読み込んでください。Claudeの長いチャットでは、上にスクロールするまで古いメッセージが読み込まれません。その前に印刷やエクスポートをすると、冒頭が欠けたPDFになります。最初までスクロールし、少し待ってから印刷またはエクスポートしてください。

印刷は、1回だけ手早く済ませるなら十分です。印刷と本物のPDFファイルの詳しい比較（スマートフォンの場合を含む）は、ClaudeのチャットをPDFで保存をご覧ください。

Claudeのチャットを1つのPDFにするには？

「Export」を1回クリックすると、最初のプロンプトから最後の回答まで、Claudeのチャット全体が入った1つのPDFファイルができます。ClaudeのチャットをPDFとしてクリップボードにコピーすることはできません。「Copy」（コピー）が使えるのはMarkdown、テキスト、JSON、XML、CSVです。ただ、エクスポートしたファイルがそのまま1つのPDFです。

チャットの一部だけを1つのPDFにするには、「Select」（選択）を使います。エクスポートパネルで「Select」をクリックし、必要なメッセージにチェックを入れ、PDFを選んで「Export」をクリックします。PDFには、そのメッセージだけが順番どおりに入ります。「Messages」のフィルターは、片方の発言について同じことをします。「Assistant」ならClaudeの回答だけ、「Human」なら自分のプロンプトだけが残ります。

欲しいもの やること 得られるもの
チャット全体 Format：PDF → Export 全メッセージ入りのPDF 1つ
いくつかのメッセージ Select → メッセージにチェック → PDF → Export 選んだメッセージだけのPDF 1つ
Claudeの回答だけ Messages：Assistant → PDF → Export 自分のプロンプトを除いたPDF 1つ
どこかに貼り付けるテキスト Format：Markdownまたはプレーンテキスト → Copy クリップボードのテキスト。PDFではない

複数のチャットが1つのPDFに結合されることはありません。一括エクスポートでは、ZIPの中にチャットごとに1つのPDFが作られます。1つにまとめた文書が必要なら、チャットをエクスポートしてからPDF編集ソフトで結合するか、Markdownでエクスポートして1つのファイルに貼り合わせてから変換してください。

MarkdownからClaudeのチャットをPDFに変換するには？

先にテキストを編集したいときは、MarkdownからClaudeのチャットをPDFに変換します。チャットをMarkdownでエクスポートし（無制限、アカウント不要）、.md ファイルをVS Code、Obsidian、Typoraなどのエディターで開いて手を加え、そのエディターの印刷またはPDFエクスポートの機能を使います。

  1. claude.aiでオレンジ色のボタンをクリックし、Markdownを選んで「Export」をクリックします。サインインも回数のカウントもありません。
  2. エディターでファイルを開きます。メッセージを削る、見出しを整える、自分のメモを加えるといった編集をします。
  3. エディターの「PDFとしてエクスポート」や「印刷 → PDF に保存」を使い、自分のテンプレートとフォントで出力します。

Markdownが中間形式として使えるのは、プレーンテキストのままでも読みやすいからです。Markdownの考案者であるJohn Gruberは、「Markdownは、できる限り読みやすく、書きやすいことを目指している。」と書いています。マークアップに煩わされずにClaudeのチャットをMarkdownで編集し、最後に一度だけ組版できます。

欠点は、1つではなく2つのツールを使うことです。編集が不要なら、拡張機能のPDFのほうが速く、ページ番号も目次もすでに付けられます。また、MarkdownはPDFの1日の上限をまったく使わないので、無料プランでは助かります。形式の詳細：Markdownのエクスポート。

Anthropicのアカウントのエクスポートは、変換の出発点には向きません。アカウント全体のJSONをまとめたZIPなので、まず1つの会話を取り出し、JSONを読めるテキストに直す必要があります。開いているチャットからMarkdownでエクスポートすれば、その手間はすべて省けます。

複数のチャットをまとめてPDFにエクスポートできる？

はい。拡張機能のダッシュボードなら、Claudeの複数のチャットを1回でPDFにエクスポートできます。「Chat format」（チャット形式）をPDFにし、会話にチェックを入れて「Export All」（すべてエクスポート）をクリックします。チャットごとに1つのPDFが入ったZIPが1つできます。無料プランでは、ZIP内のチャット1件ごとに1日3回の枠を1回使います。

  1. Chromeで拡張機能のアイコンをクリックし、「View and Download All Conversations」（すべての会話を表示してダウンロード）を選びます。
  2. 一覧を絞り込むか検索し、必要なチャットにチェックを入れます。
  3. 「Chat format」をPDFにします。思考、メタデータ、ツール、出典を含めるかどうかを選びます。
  4. 「Export All」をクリックし、ZIPを保存します。

今日の無料枠より多くのチャットにチェックを入れると、途中で切られるのではなく、全体がブロックされます。チャットを減らすか、アップグレードしてください。Proなら、PDFと一括エクスポートの両方で上限がなくなります。フィルターやアーティファクトのオプションを含む一括エクスポートの全手順は、一括エクスポートのガイドにあります。

1日のPDF枠は大事なものに取っておきましょう。大量に保管するなら、まずMarkdownかJSONで一括エクスポートし（どちらも無制限）、実際に送ったり印刷したりするチャットだけをPDFにエクスポートしてください。

PDFエクスポートの結果がおかしいのはなぜ？

ClaudeのチャットのPDFがおかしくなる原因は、主に4つです。スレッドが最後まで読み込まれていなかった、「Format」のドロップダウンが前回の形式のままだった、無料の1日の上限に達していた、エクスポートではなく印刷を使った、のいずれかです。どれもすぐに直せます。対処法は下の表のとおりです。

ClaudeのチャットのPDFエクスポートで起きる問題と対処法
症状 原因 対処法
最初のメッセージが欠けている 古いやり取りが読み込まれていなかった チャットの最初までスクロールし、待ってから再度エクスポート
PDFではなく .md ファイルができた パネルが前回の形式を記憶している 「Export」をクリックする前にFormatをPDFにする
エクスポートでアップグレードを求められる 今日の無料のPDF／一括エクスポート3回を使い切った UTCの午前0時まで待つ、Markdownでエクスポートする、またはProにする

推論が入っていない 「Thinking」のチェックが外れていた エクスポートパネルで「Thinking」にチェックを入れる
Webの出典やツールのステップが入っていない 初期設定ではオフ 拡張機能の設定でオンにする

無料プランでは、間違えて作ったPDFも回数に数えられます。「Export」をクリックする前に「Format」のドロップダウンを確認してください。オレンジ色のボタンが見当たらない場合は、インストール後にclaude.aiを再読み込みしてください。ボタンは、すべてのチャットページでメッセージ入力欄の横に表示されます。

PDFにするなら拡張機能・印刷・公式エクスポートのどれ？

Claudeのチャットをファイルにする方法は3つありますが、1つのチャットの本物のPDFを作れるのは1つだけです。拡張機能は、ページ構成のPDFを数秒でエクスポートします。印刷はWebページのスナップショットです。AnthropicのExport dataはアカウント全体のZIPをメールで送る方法で、PDFではありません。

公式の方法は、claude.aiの Settings → Privacy → Export data（claude.aiを日本語で表示している場合、ラベルは翻訳されていることがあります）にあります。Claudeヘルプセンターの説明はこうです。「エクスポートの処理が完了すると、ダウンロードリンクがメールで届きます。」同じページには、「ダウンロードリンクは送信から24時間後に有効期限が切れます」ともあります。

印刷 → PDF に保存 Webページのスナップショット 数秒 不要

送る、保管する、印刷するための1つの会話なら、拡張機能でClaudeのチャットをPDFにエクスポートしてください。何もインストールできないときは印刷、先に編集したいときはMarkdown、完全なバックアップには公式のZIPを使います。ほかの形式や方法については、Claudeのチャットをエクスポートする方法をご覧ください。

ターミナルのClaude Codeは別です。ローカルのセッションはWebページではないので、そこでは /export を使います。Claude Codeのエクスポートをご覧ください。Download Claude conversationsは独立したChrome拡張機能であり、Anthropic, PBCとは提携していません。PDFはすべてローカルで作成され、会話のテキストがアップロード、保存、分析されることはありません。

よくある質問：ClaudeのチャットをPDFにエクスポート

ClaudeのチャットをPDFにエクスポートするには？

Download Claude conversationsをインストールし、claude.aiでチャットを開いて、メッセージ入力欄の横にあるオレンジ色のボタンをクリックし、PDFを選んで「Export」をクリックします。初回はGoogleでサインインし、用紙サイズなどのオプションを設定して保存します。PDFはブラウザの中で作成されます。

ClaudeのチャットをPDFに無料で保存するには？

拡張機能のPDFエクスポートは、Googleサインインで1日3回まで無料です。Chromeの印刷ダイアログ（Ctrl+PまたはCmd+P → PDF に保存）は無料で回数の制限もありませんが、できるのはWebページのスナップショットです。Markdownでエクスポートしてエディターで変換する方法も、無料で無制限です。

ClaudeのチャットをPDFでダウンロードするには？

ここではダウンロードとエクスポートは同じ作業です。エクスポートパネルでPDFを選べば、Chromeがほかのダウンロードと同じようにファイルを保存します。印刷とエクスポートしたファイルの比較は、ClaudeのチャットをPDFで保存をご覧ください。

Claudeのチャットを1つのPDFとしてコピーできますか？

クリップボードにはコピーできません。「Copy」が対応しているのはMarkdown、テキスト、JSON、XML、CSVで、PDFは対象外です。代わりに「Export」をクリックしてください。1回のエクスポートで、チャット全体が入ったPDFファイルが1つできます。一部のメッセージだけにするなら、エクスポートの前に「Select」を使います。

Claudeの回答だけをPDFにエクスポートできますか？

はい。エクスポートパネルで「Messages」を「Assistant」にし、PDFを選んで「Export」をクリックします。PDFには、自分のプロンプトを除いたClaudeの回答だけが入ります。「Human」はその逆です。

ClaudeのチャットのPDFでコードブロックや表は保たれますか？

はい、エクスポートなら保たれます。コードブロックは言語と書式が保たれ、表やリストもそのまま残ります。弱いのは印刷のほうで、コードブロックは折り返されたりページをまたいで分割されたりし、幅の広い表は切れてしまいます。

ClaudeのチャットをダークモードのPDFにエクスポートできますか？

はい。PDFダイアログにはライトモードとダークモードがあります。画面で読むならダーク、紙に印刷するならライトが向いています。

スマートフォンでClaudeのチャットをPDFに変換できますか？

拡張機能ではできません。拡張機能はパソコンのChromeとChromium系ブラウザでしか動かないためです。スマートフォンのブラウザでも、印刷や共有でページをPDFにはできますが、レイアウトは窮屈になります。きれいなPDFが欲しい場合は、パソコンのChromeで同じチャットを開いてください。

Claude CodeのセッションをPDFにエクスポートできますか？

Claude Code on the web（claude.ai/code）はclaude.aiで開くので、ふつうのチャットと同じように拡張機能でPDFにエクスポートできます。ターミナルのセッションはWebページではありません。そこでは /export を使い、テキストファイルをエディターから印刷してください。

PDFにエクスポートすると、Claudeのチャットはアップロードされますか？

いいえ。PDFは、ほかのすべての形式と同じく、ブラウザの中で作成されます。サインイン後に送信されるのは、1日の上限やProを確認するためのGoogleアカウントのメールアドレスだけです。

ClaudeのチャットのPDFではなくMarkdownファイルができたのはなぜですか？

エクスポートパネルは、最後に使った形式を記憶しています。「Export」をクリックする前に「Format」をPDFにしてください。無料プランではPDFが1つ作られるたびに1日3回の枠を使うので、先に確認しましょう。
