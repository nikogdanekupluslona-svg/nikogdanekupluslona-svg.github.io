ClaudeのチャットをPDFで保存する — 印刷ではなく本物のファイルで

ClaudeのチャットをPDFで直接ダウンロードできる？

claude.ai単体ではできません。「PDFでダウンロード」のボタンがないためです。Download Claude conversationsを使えばできます。エクスポートパネルでPDFを選び、「Export」をクリックするだけです。バージョン1.16.2は、印刷ダイアログを使わずにタブの中で .pdf を作成します。何もアップロードされません。

  1. Chrome Web StoreからDownload Claude conversationsをインストールし、claude.aiを再読み込みします。
  2. 会話を開きます。通常のチャット、プロジェクト、Coworkのセッション、Claude Code on the web（claude.ai/code）のどれでも使えます。
  3. メッセージ入力欄の右にある、丸いオレンジ色のダウンロードボタンをクリックします。
  4. 「Format」（形式）でPDFを選びます。「Messages」（メッセージ）は「All」（すべて）のままにするか、「Human」（ユーザー）または「Assistant」（アシスタント）を選びます。「Select」（選択）を使えば、必要なメッセージだけにチェックを入れられます。
  5. 「Export」をクリックします。初回はGoogleでサインインし、PDFのオプションを設定して保存します。

PDFダイアログでは、印刷ではできなかった次の設定ができます。

  • ファイル名、用紙サイズ、余白
  • ライトモードまたはダークモード
  • フォントとフォントサイズ
  • ページ番号と目次
  • タイムスタンプ
  • 各プロンプトの前での改ページ

コードブロックは言語と書式が保たれます。表やリストもそのまま残ります。拡張思考は、エクスポートパネルの「Thinking」（思考）チェックボックスで含めるかどうかを選べます。ツール／MCPのステップとWeb検索の出典は、拡張機能の設定でオンにします。PDFに入るのは、選んだものだけです。

無料プランでのPDFの上限。PDFは初回からGoogleサインインが必要です。無料アカウントでは、PDFと一括ZIPのエクスポートを合わせて1日3回まで使えます。日付はUTCの午前0時（日本時間の午前9時）にリセットされます。Pro（月額$3.99または年額$26.99）なら上限はなくなります。Markdown、テキスト、JSON、XML、CSV、PNGは、引き続きアカウント不要で無制限です。

Anthropicの Settings → Privacy → Export data（claude.aiを日本語で表示している場合、ラベルは翻訳されていることがあります）もPDFではありません。時間をおいて届く、アカウント全体のJSONのZIPです。ZIPを展開しても、整った体裁の会話は出てきません。開いているスレッドのPDFが欲しいだけなら、メールを待つ必要はありません。

パソコンでClaudeの会話を印刷するには？

パソコンでClaudeの会話を印刷するには、claude.aiでスレッドを開き、できればサイドバーを閉じてから、Ctrl+PまたはCmd+Pを押し、「PDFとして保存」を選んで印刷します。会話が読み込まれるまで待ってください。スクロールしていない長いチャットは、読み込まれている部分（DOM）しか印刷されません。印刷は、拡張機能をインストールできないときや、1回だけ手早く済ませたいときに使います。

  1. Chromeなどのデスクトップブラウザでclaude.aiの会話を開きます。回答の生成が終わるまで待ちます。
  2. サイドバーを折りたたみ、会話がページを広く使えるようにします。紙に載せたくないアーティファクトやプロジェクトのパネルは閉じておきます。
  3. WindowsやLinuxではCtrl+P、MacではCmd+Pを押します。
  4. 送信先を「PDFとして保存」（Chrome）または「Microsoft Print to PDF」などに設定します。紙に印刷する場合はプリンターを選びます。
  5. 詳細設定で、ページが薄く見える場合は「背景のグラフィック」を試します。サイドバーがまだ場所を取っている場合は余白を小さくします。保存または印刷します。

Claudeの会話を印刷する手順はこれだけです。印刷では、ページ番号、目次、プロンプトごとの改ページは付きません。得られるのは、サイトが印刷モードで適用するCSSのとおりの結果で、たいていは「Webページをページ分けしたもの」です。

もっときれいなレイアウトでClaudeのチャットを印刷できるか？ 印刷ダイアログではできません。印刷ダイアログが組版ソフトになることはないからです。代わりに拡張機能でPDFを選んでください。用紙サイズ、余白、フォント、ページ番号、目次は、CSS任せではなく、そこで設定できる項目です。

先にスレッドを読み込んでください。長いチャットでは、スクロールするまで古いやり取りが読み込まれません。半分しか読み込まれていないページを印刷やPNGにすると、途中で切れたPDFのようになります。最初までスクロールし、待ってから印刷してください。拡張機能のエクスポートにも同じ制約があります。

印刷したClaudeのチャットPDFには何が残る？

印刷したClaudeのチャットPDFに残るのはレイアウトのスナップショットで、メッセージの構造をエクスポートしたものではありません。表示されているテキストと、印刷用CSSが削らなかった部分はたいてい残ります。一方で、崩れていないコードブロック、幅の広い表、折りたたまれたアーティファクト、入力欄などの画面要素がないきれいなページは失われがちです。

  • コードブロックは折り返されるか、ページをまたいで分割されます。インデントが保たれるのは、印刷用スタイルシートが pre の折り返しをきちんと制御している場合だけで、多くの場合そうなっていません。
  • 表が用紙の幅からはみ出します。幅の広い比較表は読めなくなります。
  • 入力欄、モデルの選択、サイドバーなどのアプリの画面要素は、事前に隠さないと全ページに入ることがあります。
  • アーティファクトや思考プロセスは、画面上で展開されている場合にだけ印刷されます。折りたたまれた部分はPDFに入りません。
  • そのPDFをObsidianでMarkdownとして扱ったり、gitで差分を取ったりはできません。

Claudeの画面どおりに見える添付ファイルを1回だけ作るなら、印刷で十分です。送信する、保管する、紙で読むためのPDFなら、拡張機能のPDFのほうが良いファイルになります。編集、引用、差分に使う作業用の文書なら、拡張機能のMarkdownかJSONを使ってください。Claudeのチャットをエクスポートする方法をご覧ください。

背景のグラフィックや用紙サイズで、スナップショットは変わります。A4かレターかで、コードが改ページされる位置も変わります。ただし、どの設定でも、画面幅より広かった表は元に戻りません。表が重要なら、拡張機能からPDFかMarkdownでエクスポートしてください。

スマートフォンからClaudeのチャットを印刷できる？

場合によります。モバイルブラウザに「共有 → PDF」や「印刷」があれば、スマートフォンからClaudeのチャットを印刷できます。ただしclaude.aiのモバイル表示は、大きな入力欄の付いた細い1列のレイアウトなので、PDFはたいていパソコンより見劣りします。画面要素が多く、行が短く、改ページも増えます。

このChrome拡張機能はiOSやAndroidでは動きません。Download Claude conversationsのアプリ版はありません。SafariではこのChrome Web Storeのアイテムを読み込めません。きれいなPDFが欲しい場合は、パソコンのChromeで同じ会話を開き、拡張機能でPDFを選んでください。

チャットがスマートフォンのセッションにしかなく、パソコンで開けない場合は、スマートフォンから印刷してレイアウトは妥協するか、ノートパソコンが使えるまで待ちましょう。Settingsからの公式のデータエクスポートも、Web上のアカウントが必要で、やはりPDFではありません。

デスクトップ拡張機能を禁止するチームのポリシーがあっても、モバイルでの印刷がきれいになるわけではありません。残る手段が印刷と公式のZIPになるだけです。この2つは、私たちのソフトウェアがなくても使えます。

Markdown経由でClaudeのチャットをPDFにするには？

Markdown経由でClaudeのチャットをPDFにするには、Download Claude conversationsでMarkdownをエクスポートし、.md ファイルをエディターで開いて、そのアプリの「印刷」や「PDFとしてエクスポート」を使います。先にテキストを編集したいときや、自分のテンプレートを適用したいときの方法です。Markdownのエクスポートは無制限でアカウントも不要なので、PDFの1日の上限にはまったく影響しません。

  1. claude.aiでチャットを開き、オレンジ色のボタンをクリックしてMarkdownを選び、「Export」をクリックします。サインインも回数のカウントもありません。
  2. VS Code、Obsidian、Typora、Googleドキュメント、Word（貼り付け）などでファイルを開きます。
  3. そのアプリの「印刷」／「PDFとしてエクスポート」を使います。用紙サイズや見出しは、claude.aiではなくそこで設定します。

欠点は、1つではなく2つのツールを使うことです。拡張機能のPDFなら、用紙サイズ、余白、フォント、目次はすでに設定できます。Markdownから始めるのは、PDFに手を加えたいとき、社内指定のフォントを使いたいとき、ダイアログにないテンプレートが必要なときだけで十分です。PNGも代わりにはなりません。ビットマップ画像なので、スライドの1枚には使えても、40ページの設計レビューには使えません。

PDFを含むすべてのファイルは、ブラウザの中でローカルに作成されます。会話のテキストがアップロード、保存、分析されることはありません。形式の一覧：対応形式。

PDFは、ほかのすべての形式と同じくブラウザの中で作成されます。印刷ダイアログもサーバーも使いません。ダイアログでは、印刷ではできなかったこと、つまり用紙サイズ、余白、ダークモード、ページ番号、目次、プロンプトごとの改ページを設定できます。共有する前にテキストを編集したいなら、代わりにMarkdownでエクスポートしてください。

PDFをまとめて作りたい場合は、ダッシュボードを開き、「Chat format」（チャット形式）をPDFにして、チャットにチェックを入れ、「Export All」（すべてエクスポート）をクリックします。チャットごとに1つのPDFが入ったZIPが1つできます。Googleサインインが必要で、無料プランではZIP内のチャット1件ごとに、同じ1日3回の枠を1回使います。今日の残り回数より多く選ぶと、途中で切られるのではなく、全体がブロックされます。Proなら上限はなくなります。ガイド：一括エクスポート。

ClaudeのチャットはPNG・PDF・Markdownのどれがいい？

PNG、PDF、Markdownは、3つのまったく別のものです。この拡張機能のPDFは、ページ構成の文書です。PNGはスレッド全体を写した1枚の画像です。Markdownは構造を持ったテキストです。印刷で作るPDFは、Webページのスナップショットです。名前を混同すると、間違ったファイルを送ってしまいます。

PDF（この拡張機能） ブラウザの中で作成される、ページ構成の文書 読む、共有する、添付する 1日3回、Googleサインイン
印刷 → PDFとして保存 claude.aiのブラウザ上のスナップショット 手早い共有、「Claudeの画面どおり」 ブラウザの機能、上限なし

Markdown 構造を持ったテキスト メモ、git、後からのPDF作成 無制限、アカウント不要
JSON メッセージのツリー スクリプト向け。人やプリンター向けではない 無制限、アカウント不要

プレーンテキスト、XML、CSVもあります。どれもPDFではありません。プレーンテキストを印刷すると行がびっしり並ぶだけで、XMLを印刷するとタグがそのまま出ます。CSVはメッセージ1件につき1行で、紙ではなくスプレッドシート向けです。納品物がPDFなら、PDFを選んでください。

最後に使った形式は記憶されます。PDFが欲しかったのにMarkdownが届いたなら、ドロップダウンがMarkdownのままだったということです。「Export」をクリックする前に確認してください。無料プランでは、意図せず作ったPDFでも今日の3回のうち1回を使います。

印刷・公式エクスポート・このChrome拡張機能の違いは？

印刷、公式のデータエクスポート、このChrome拡張機能は、どれも「エクスポート」と呼ばれがちですが、3つの別の作業です。印刷 → PDFとして保存は、1つの会話を、見た目どおりに、今すぐ保存します。公式のZIPは、アカウント全体をJSONで、後からメールで届けます。拡張機能は、PDFを含む7つの形式でローカルに書き出します。そのうち6つはアカウント不要で、PDFと一括エクスポートにはGoogleサインインが必要です。

ターミナルのClaude Codeのことなら、印刷は役に立ちません。ローカルのセッションはWebページではないからです。/export を使ってください。Claude Code on the web（claude.ai/code）は別で、claude.aiで開くため、ふつうのチャットと同じように拡張機能でPDFにエクスポートできます。Claude Desktopアプリのことなら、拡張機能はそこでは動きません。Claude Desktopのチャットをエクスポートするをご覧ください。

ZIPを使う方法とオレンジ色のボタンを使う方法でClaudeのチャットをエクスポートする手順は、エクスポートのガイドで説明しています。ウィジェットを使ってClaudeのチャットをダウンロードする手順は、ダウンロードのガイドにあります。このページはPDFと印刷に絞り、3つのページの役割を分けています。

1日の上限は印刷には適用されません。ブラウザでの印刷は、拡張機能とは関係ありません。無料プランの上限（PDFと一括ZIPのエクスポートを合わせて1日3回、UTCの午前0時にリセット）が適用されるのは、拡張機能のPDFと「Export All」だけです。Markdown、テキスト、JSON、XML、CSV、PNGは無制限です。Pro（月額$3.99または年額$26.99）なら上限はなくなります。支払いはPaddleが処理します。

この拡張機能は独立したChrome拡張機能であり、Anthropic, PBCとは提携していません。Anthropicの利用規約に従ってください。Anthropicが管理する印刷用スタイルシートについて、私たちは何も約束できません。ClaudeのUI変更で印刷が崩れた場合、それはAnthropic側のCSSの問題です。代わりに拡張機能からPDFでエクスポートしてください。

ClaudeのチャットをPDFでダウンロードできますか？

はい、Download Claude conversationsを使えばできます。claude.aiでチャットを開き、オレンジ色のボタンをクリックしてPDFを選び、「Export」をクリックします。ファイルはブラウザの中で作成され、印刷ダイアログは開きません。claude.ai自体にはPDFボタンがありません。インストール不要の代替手段は印刷（Ctrl/Cmd+P → PDFとして保存）です。

ClaudeのチャットをPDFで保存するのにアカウントは必要ですか？

はい。最初のPDFからGoogleサインインが必要です。無料プランの1日3回（PDFと一括エクスポートの合計）を数えるためと、Proを購入した場合にアカウントに紐づけるためです。Markdown、テキスト、JSON、XML、CSV、PNGにはアカウントは要りません。

Claudeの会話を印刷するには？

claude.aiでチャットを開き、できればサイドバーを閉じて、WindowsならCtrl+P、MacならCmd+Pを押し、「PDFとして保存」かプリンターを選んで印刷します。長いスレッドでは、コードブロックがページをまたいで分割されがちです。先にスクロールして古いやり取りを読み込んでください。

スマートフォンからClaudeのチャットを印刷できますか？

モバイルブラウザでも印刷やPDFへの共有はできますが、レイアウトはパソコンより見劣りします。拡張機能はモバイルでは動きません。きれいなPDFが欲しい場合は、パソコンのChromeで同じチャットを開き、PDFでエクスポートしてください。

Download Claude conversationsはPDFでエクスポートできますか？

はい。バージョン1.16.2は、Markdown、プレーンテキスト、JSON、XML、CSV、PNGに加えてPDFでもエクスポートできます。PDFダイアログでは、ファイル名、用紙サイズ、余白、ライトモードまたはダークモード、フォントとサイズ、ページ番号、目次、タイムスタンプ、プロンプトごとの改ページを設定できます。

コードを読みやすい形でClaudeのチャットをPDFにするには？

拡張機能でPDFを選んでください。コードブロックは言語と書式が保たれ、用紙サイズと余白も設定できます。コードにとって印刷は不向きな方法で、ブロックが折り返されたり、ページをまたいで分割されたりします。自分で組版したいなら、Markdownでエクスポートしてエディターから印刷してください。

PNGはPDFの代わりになりますか？

いいえ。PNGは会話全体を写した1枚の画像です。拡張機能のPDFは、ページ番号や目次を付けられるページ構成の文書です。印刷で作ったPDFは、claude.aiをページ分けしたスナップショットです。どれも、編集や差分の用途ではMarkdownの代わりになりません。

印刷するとPDFの1日の上限を使いますか？

いいえ。印刷はブラウザの機能で、拡張機能ではありません。無料プランの1日3回の上限は、拡張機能のPDFと一括ZIPにだけ適用されます。claude.aiの印刷にサインインは不要で、Markdown、テキスト、JSON、XML、CSV、PNGのエクスポートは無制限です。

Claudeのチャットを一括でPDFとしてダウンロードできますか？

はい。ダッシュボードで「Chat format」（チャット形式）をPDFにし、チャットにチェックを入れて「Export All」（すべてエクスポート）をクリックすると、チャットごとに1つのPDFが入ったZIPが1つできます。先にGoogleでサインインしてください。無料プランでは1日3件までで、ZIP内のチャット1件が1回に数えられます。Proは無制限です。「Export All」で一括エクスポートをご覧ください。

Claude CodeのセッションをPDFで保存できますか？

Webならできます。Claude Code on the web（claude.ai/code）はclaude.aiで開くので、ふつうのチャットと同じように拡張機能でPDFにエクスポートできます。ローカルのターミナルのセッションはWebページではありません。そこでは /export を使い、テキストファイルをエディターから印刷してください。ガイド：Claude Codeのエクスポート。

TeamやEnterpriseプランならPDFエクスポートは変わりますか？

いいえ。PDFはClaudeのプランではなく、拡張機能の機能です。Chromeのclaude.aiでチャットを開ければ、PDFを含む7つの形式のどれでもエクスポートできます。無料の1日3回の上限もProも、どのClaudeのプランでも同じです。

ClaudeのチャットのPDFはサーバーで作成されますか？

いいえ。PDFは、ほかのすべての形式と同じく、ブラウザの中で作成されます。会話のテキストがアップロード、保存、分析されることはありません。サインイン後に送信されるのは、1日の上限やProを確認するためのGoogleのメールアドレスだけです。
