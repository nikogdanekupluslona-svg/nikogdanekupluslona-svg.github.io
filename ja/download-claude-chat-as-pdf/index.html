ClaudeのチャットをPDFで直接ダウンロードできる？

いいえ。claude.ai自体の機能でClaudeのチャットをPDFとしてダウンロードすることはできず、この拡張機能もPDFには出力しません。見た目どおりのPDFが欲しければ会話を印刷し、そうでなければMarkdownでエクスポートしてその文書を印刷します。バージョン1.13.0には .pdf の書き出し機能はありません。

現在の形式はMarkdown、JSON、プレーンテキスト、XML、PNGです。これが製品の対応範囲です。.pdf の書き出しに対応した日には、このページでお知らせします。それまでは、ブラウザの印刷ダイアログがPDFを作る手段です。

Anthropicの Settings → Privacy → Export data（claude.aiを日本語で表示している場合、ラベルは翻訳されていることがあります）もPDFではありません。時間をおいて届く、アカウント全体のJSONのZIPです。ZIPを展開しても、整った体裁の会話は出てきません。開いているスレッドを印刷できる形で欲しいだけなら、メールを待つ必要はありません。

パソコンでClaudeの会話を印刷するには？

パソコンでClaudeの会話を印刷するには、claude.aiでスレッドを開き、できればサイドバーを閉じてから、Ctrl+PまたはCmd+Pを押し、「PDFとして保存」を選んで印刷します。会話が読み込まれるまで待ってください。スクロールしていない長いチャットは、読み込まれている部分（DOM）しか印刷されません。

  1. Chromeなどのデスクトップブラウザでclaude.aiの会話を開きます。回答の生成が終わるまで待ちます。
  2. サイドバーを折りたたみ、会話がページを広く使えるようにします。紙に載せたくないアーティファクトやプロジェクトのパネルは閉じておきます。
  3. WindowsやLinuxではCtrl+P、MacではCmd+Pを押します。
  4. 送信先を「PDFとして保存」（Chrome）または「Microsoft Print to PDF」などに設定します。紙に印刷する場合はプリンターを選びます。
  5. 詳細設定で、ページが薄く見える場合は「背景のグラフィック」を試します。サイドバーがまだ場所を取っている場合は余白を小さくします。保存または印刷します。

Claudeの会話を印刷する手順はこれだけです。Claudeはヘッダー、ページ番号、目次を付けません。得られるのは、サイトが印刷モードで適用するCSSのとおりの結果で、たいていは「Webページをページ分けしたもの」です。

もっときれいなレイアウトでClaudeのチャットを印刷できるか？ それにはチャット画面から離れるしかありません。拡張機能でMarkdownをエクスポートし、文書アプリから印刷します。claude.aiの印刷ダイアログが組版ソフトになることはありません。

先にスレッドを読み込んでください。長いチャットでは、スクロールするまで古いやり取りが読み込まれません。半分しか読み込まれていないページを印刷やPNGにすると、途中で切れたPDFのようになります。最初までスクロールし、待ってから印刷してください。拡張機能のエクスポートにも同じ制約があります。

印刷したClaudeのチャットPDFには何が残る？

印刷したClaudeのチャットPDFに残るのはレイアウトのスナップショットで、メッセージの構造をエクスポートしたものではありません。表示されているテキストと、印刷用CSSが削らなかった部分はたいてい残ります。一方で、崩れていないコードブロック、幅の広い表、折りたたまれたアーティファクト、入力欄などの画面要素がないきれいなページは失われがちです。

  • コードブロックは折り返されるか、ページをまたいで分割されます。インデントが保たれるのは、印刷用スタイルシートが pre の折り返しをきちんと制御している場合だけで、多くの場合そうなっていません。
  • 表が用紙の幅からはみ出します。幅の広い比較表は読めなくなります。
  • 入力欄、モデルの選択、サイドバーなどのアプリの画面要素は、事前に隠さないと全ページに入ることがあります。
  • アーティファクトや思考プロセスは、画面上で展開されている場合にだけ印刷されます。折りたたまれた部分はPDFに入りません。
  • PDF内の検索はいまひとつです。ObsidianでMarkdownとして扱ったり、gitで差分を取ったりはできません。

印刷は、Claudeの画面どおりに見える添付ファイルを1回だけ作りたいときには適した方法です。スレッドを作業用の文書として編集、引用、保管するなら適していません。その場合は拡張機能のMarkdownかJSONを使ってください。Claudeのチャットをエクスポートする方法をご覧ください。

背景のグラフィックや用紙サイズで、スナップショットは変わります。A4かレターかで、コードが改ページされる位置も変わります。ただし、どの設定でも、画面幅より広かった表は元に戻りません。表が重要なら、Markdownでエクスポートしてください。

スマートフォンからClaudeのチャットを印刷できる？

場合によります。モバイルブラウザに「共有 → PDF」や「印刷」があれば、スマートフォンからClaudeのチャットを印刷できます。ただしclaude.aiのモバイル表示は、大きな入力欄の付いた細い1列のレイアウトなので、PDFはたいていパソコンより見劣りします。画面要素が多く、行が短く、改ページも増えます。

このChrome拡張機能はiOSやAndroidでは動きません。Download Claude conversationsのアプリ版はありません。SafariではこのChrome Web Storeのアイテムを読み込めません。再利用するファイルが欲しい場合は、パソコンのChromeで同じ会話を開き、そこで印刷するかMarkdownでエクスポートしてください。

チャットがスマートフォンのセッションにしかなく、パソコンで開けない場合は、スマートフォンから印刷してレイアウトは妥協するか、ノートパソコンが使えるまで待ちましょう。Settingsからの公式のデータエクスポートも、Web上のアカウントが必要で、やはりPDFではありません。

デスクトップ拡張機能を禁止するチームのポリシーがあっても、モバイルでの印刷がきれいになるわけではありません。残る手段が印刷と公式のZIPになるだけです。この2つは、私たちのソフトウェアがなくても使えます。

Markdown経由でClaudeのチャットをPDFにするには？

表示中のページを印刷せずにClaudeのチャットをPDFで保存するには、Download Claude conversationsでMarkdownをエクスポートし、.md ファイルをエディターで開いて、そのアプリの「印刷」や「PDFとしてエクスポート」を使います。チャット画面ではなく文書として、フォント、余白、改ページを自分で調整できます。

  1. 拡張機能をインストールし、claude.aiでチャットを開いてMarkdownでエクスポートします。初回のエクスポートにはGoogleログインが必要です。無料エクスポートは3回、Proは月額$3.99または年額$26.99です。
  2. VS Code、Obsidian、Typora、Googleドキュメント、Word（貼り付け）などでファイルを開きます。
  3. そのアプリの「印刷」／「PDFとしてエクスポート」を使います。用紙サイズや見出しは、claude.aiではなくそこで設定します。

PDFを読みやすいものにする必要があるなら、ほとんどの人にとってこの2段階の方法が、ClaudeのチャットをPDFで保存する最適な手順です。1段階目は構造を保ったエクスポート、2段階目は本物の組版ソフトです。PNGは代わりになりません。ビットマップ画像なので、スライドの1枚には使えても、40ページの設計レビューには使えません。

ファイルはローカルで作成されます。MarkdownからPDFへの変換をサーバーで行うこともありません。PDFへの対応は、ドロップダウンに新しい形式を追加することを意味しますが、1.13.0にはありません。形式の一覧：対応形式。

PDFに対応してほしいという要望は毎週届きます。それでも .pdf は書き出していません。チャット画面は組版に向いていないからです。今すぐスナップショットが必要ならページを印刷してください。文書が必要ならMarkdownでエクスポートしてください。PDFボタンがあるふりをすれば問い合わせは1件減るかもしれませんが、できあがるファイルは質の悪いものになります。

ClaudeのチャットはPNG・PDF・Markdownのどれがいい？

PNG、PDF、Markdownは、3つのまったく別のものです。ClaudeのチャットをPDFで保存するとは、印刷するか、Markdownファイルを変換することです。この拡張機能のPNGはスレッドの画像です。Markdownは構造を持ったテキストです。名前を混同すると、間違ったファイルを送ってしまいます。

Claudeのチャットを画面の外に保存したいときのPNG・PDF・Markdownの比較
形式 中身 向いている用途
印刷 → PDFとして保存 claude.aiのブラウザ上のスナップショット 手早い共有、「Claudeの画面どおり」
PNG（この拡張機能） エクスポートしたスレッドの画像 スライドの図。文書ではない
Markdown 構造を持ったテキスト メモ、git、後からのPDF変換
JSON メッセージのツリー スクリプト向け。人やプリンター向けではない

XMLとプレーンテキストもあります。どちらもPDFではありません。プレーンテキストを印刷すると行がびっしり並ぶだけで、XMLを印刷するとタグがそのまま出ます。納品物がPDFなら、JSONではなく、印刷かMarkdownから始めてください。

最後に使った形式は記憶されます。スライド用にPNGが欲しかったのにMarkdownが届いたなら、ドロップダウンがMarkdownのままだったということです。無料エクスポートを使う前に確認してください。

印刷・公式エクスポート・このChrome拡張機能の違いは？

印刷、公式のデータエクスポート、このChrome拡張機能は、どれも「エクスポート」と呼ばれがちですが、3つの別の作業です。印刷 → PDFとして保存は、1つの会話を、見た目どおりに、今すぐ保存します。公式のZIPは、アカウント全体をJSONで、後からメールで届けます。拡張機能は5つの形式でローカルに書き出し、回数管理のためにGoogleログインを使います。

ターミナルのClaude Codeのことなら、印刷は役に立ちません。Webページではないからです。/export を使ってください。Claude Desktopアプリのことなら、それもこの拡張機能の対象外です。Claude Desktopのチャットをエクスポートするをご覧ください。

ZIPを使う方法とオレンジ色のボタンを使う方法でClaudeのチャットをエクスポートする手順は、エクスポートのガイドで説明しています。ウィジェットを使ってClaudeのチャットをダウンロードする手順は、ダウンロードのガイドにあります。このページはPDFと印刷に絞り、3つのページの役割を分けています。

印刷には回数制限がかかりません。ブラウザでの印刷は、私たちの3回までのエクスポート上限とは関係ありません。上限は、拡張機能がMarkdown、JSON、テキスト、XML、PNGを書き出すときに適用されます。Pro（月額$3.99または年額$26.99）なら上限はなくなります。支払いはPaddleが処理します。

この拡張機能は独立したChrome拡張機能であり、Anthropic, PBCとは提携していません。Anthropicの利用規約に従ってください。Anthropicが管理する印刷用スタイルシートについて、私たちは何も約束できません。ClaudeのUI変更で印刷が崩れた場合、それはAnthropic側のCSSの問題です。代わりにMarkdownでエクスポートしてください。

よくある質問：ClaudeのチャットをPDFで保存

ClaudeのチャットをPDFでダウンロードできますか？

claude.ai自体の機能では、この拡張機能でもできません。見た目どおりのPDFが欲しければ会話を印刷（Ctrl/Cmd+P → PDFとして保存）し、よりきれいな文書が必要ならMarkdownでエクスポートしてそのファイルを変換してください。

claude.aiでチャットを開き、できればサイドバーを閉じて、WindowsならCtrl+P、MacならCmd+Pを押し、「PDFとして保存」かプリンターを選んで印刷します。長いスレッドでは、コードブロックがページをまたいで分割されがちです。先にスクロールして古いやり取りを読み込んでください。

スマートフォンからClaudeのチャットを印刷できますか？

モバイルブラウザでも印刷やPDFへの共有はできますが、レイアウトはパソコンより見劣りします。再利用できるファイルが欲しい場合は、パソコンのChromeで同じチャットを開き、Markdownでエクスポートしてください。拡張機能はモバイルでは動きません。

Download Claude conversationsはPDFでエクスポートできますか？

いいえ。現在の形式はMarkdown、JSON、プレーンテキスト、XML、PNGです。PNGはスレッドの画像で、PDFではありません。PDFへの印刷は引き続きブラウザの役割です。バージョン1.13.0には .pdf の書き出し機能はありません。

印刷したPDFはAnthropicのデータエクスポートと同じですか？

いいえ。印刷は、表示しているページをそのまま写し取ります。Anthropicの Settings → Privacy → Export data は、アカウント全体のJSONをZIPにしてメールで送ります。どちらも、オレンジ色のボタンで得られるチャットごとのMarkdownファイルではありません。

コードを読みやすい形でClaudeのチャットをPDFにするには？

コードが重要なら、印刷から始めないでください。Markdownでエクスポートし、エディターで開いてから、その文書を印刷します。改ページはチャット画面ではなくファイルに対して行われます。Proでない場合、無料エクスポート3回のうち1回を使います。

PNGはPDFの代わりになりますか？

いいえ。PNGはビットマップ画像です。印刷で作ったPDFは、claude.aiをページ分けしたスナップショットです。どちらもチャットの画像のように見えますが、実際にPDFなのは印刷で作ったものだけです。どちらも、検索や差分の用途ではMarkdownの代わりになりません。

印刷すると無料エクスポート3回分を使いますか？

いいえ。印刷はブラウザの機能です。回数制限は拡張機能のファイルにだけ適用されます。claude.aiを印刷するのにGoogleログインは不要です。この拡張機能でMarkdown、JSON、テキスト、XML、PNGをエクスポートするときには必要です。

Claudeのチャットを一括でPDFとしてダウンロードできますか？

PDFとして直接はできません。「Export All」で多数のMarkdownファイルやPNGファイルを書き出せるので、PDFが必要ならMarkdownを後から変換してください。一括でも、各ファイルが無料エクスポート3回の枠に数えられます。「Export All」で一括エクスポートをご覧ください。

Claude CodeのセッションをPDFとして印刷できますか？

claude.aiの印刷ではできません。Claude Codeはターミナルです。/export を使い、紙が必要ならテキストファイルをエディターから印刷してください。ガイド：Claude Codeのエクスポート。

TeamやEnterpriseプランならPDFエクスポートは変わりますか？

それらのプランでもPDFボタンは追加されません。Chromeでチャットを開ければ印刷でき、拡張機能の5つの形式も使えます。プランによって私たちのドロップダウンに .pdf が加わることはありません。

対応形式にPDFを追加する予定はありますか？

1.13.0ではありません。追加した場合は、その日のうちにこのページでお知らせします。それまでは、印刷するかMarkdownを変換してください。存在しない「PDFでダウンロード」機能をでっち上げるより、足りない点をはっきり伝えるほうを選びます。
