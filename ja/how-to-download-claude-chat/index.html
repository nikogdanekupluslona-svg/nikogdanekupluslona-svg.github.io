ChromeでClaudeのチャットをダウンロードする方法は？

Claudeのチャットをダウンロードする方法への直接の答えは、この拡張機能がclaude.aiのメッセージ入力欄の横に追加するオレンジ色のボタンです。会話を開き、PDF、Markdown、JSON、テキスト、XML、CSV、PNGから選んで「Export」（エクスポート）をクリックします。ファイルはブラウザ内で組み立てられ、ディスクに保存されます。

この拡張機能はChromeのコンテンツスクリプトです。ログイン済みのclaude.aiセッションにすでに読み込まれている会話を読み取ります。独自の認証情報で別のAnthropic APIを呼び出すことはなく、ファイルを作るためにスレッドを当方のサーバーへアップロードすることもありません。

  1. Chrome Web StoreからDownload Claude conversationsをインストールします（Chrome拡張機能を読み込めるChromium系ブラウザでも動作します）。
  2. インストール時にclaude.aiを開いていた場合は、ページを再読み込みします。
  3. 保存したい会話のURLを開きます。オレンジ色のボタンは実際のスレッドにだけ表示され、何も入力していないホーム画面には表示されません。
  4. メッセージ入力欄の右側にある丸いオレンジ色のダウンロードボタンをクリックします。パネルが開き、「Messages」（メッセージ：「All / Human / Assistant」）、「Format」（形式）、「Thinking」（思考）、「Select」（選択）、「Copy」（コピー）、「Export」が表示されます。
  5. PDF、Markdown、プレーンテキスト、JSON、XML、CSV、PNGから選び、「Export」をクリックします。Chromeがすぐにファイルをダウンロードします。

Markdown、プレーンテキスト、JSON、XML、CSV、PNGならアカウントは不要です。これらの1件ずつのエクスポートは無料で無制限で、サインインも回数のカウントもありません。Googleサインインを求められるのは、PDFを選んだときと一括の「Export All」を実行したときだけです。チャットを読むためのログインではありません。会話の本文はお使いのパソコンから出ません。

PDFと一括ZIPは、合わせて1日3回まで無料です。回数はUTCの午前0時（日本時間の午前9時）にリセットされます。一括ZIPに含まれるチャットは、1件ごとに1回と数えます。Proは月額$3.99または年額$26.99で、この上限がなくなります。PDFのオプションと手順：ClaudeのチャットをPDFでダウンロードする。

ファイルはローカルで作成。PDFを含むすべての形式がブラウザ内で作られ、Chromeのダウンロード機能に渡されます。チャットの本文がアップロードされることはありません。送信されるのは、PDFと一括エクスポートのときの回数確認（Googleのメールアドレス付き）だけです。

同じパネルでは送信者で絞り込めます（「All」「Human」「Assistant」＝すべて／ユーザー／アシスタント）。「Thinking」のチェックボックスで、拡張思考を含めるかどうかを選べます。「Select」を使えば個々のメッセージにチェックを入れ、そのやり取りだけをファイルに残せます。「Copy」は、ファイルをダウンロードする代わりにMarkdown、テキスト、JSON、XML、CSVをクリップボードに入れます。ツール／MCPのステップとWeb検索の出典は、設定（Settings）でオンにする任意の項目です。メタデータとアーティファクトの配置（「Original」「Inline」「Nested」「Flat」＝元の配置／インライン／入れ子／フラット）は、ダッシュボードで設定します。

スレッドがとても長い場合は、claude.aiが前半のメッセージを読み込むまでスクロールしてください。拡張機能がエクスポートできるのは、ページに表示済みの内容だけです。途中までしか読み込まれていないスレッドからは途中までのファイルができます。不具合に見えますが、たいていはスクロールが足りていないだけです。

私たちは、あなたがすでに開いているclaude.aiのページ上でメッセージツリーを解析します。コードブロックは言語タグとインデントを保ち、表は表のまま残ります。PDFも同じツリーからブラウザ内で作られ、印刷ダイアログは使いません。印刷できるファイルが、もうWebページのスクリーンショットを意味することはありません。

拡張機能なしでClaudeのチャットをダウンロードできますか？

はい。ページを印刷するか、Anthropicのアカウントエクスポートを申請すれば、拡張機能なしでもClaudeのチャットを持ち出せます。印刷はWebページの見た目をPDFにしたものです。「Export data」は、アカウント全体のJSON ZIPが後から届く仕組みです。どちらもチャットごとのMarkdownファイルは作りません。

印刷の手順：claude.aiで会話を開き、可能ならサイドバーを隠してから、Ctrl+P（Windows/Linux）またはCmd+P（Mac）を押し、送信先を「PDFに保存」にして保存します。コードブロックはページの途中で分かれることが多く、入力欄などの画面要素が毎ページに入ることもあります。拡張機能のPDFエクスポートなら、このダイアログを通りません。2つの方法の比較はClaudeのチャットをPDFで保存する方法にまとめています。

公式の手順：claude.aiでSettings → Privacy → Export data（claude.aiを日本語表示にしている場合、メニュー名は日本語で表示されることがあります）。Anthropicから有効期限付きのリンクがメールで届きます。ZIPはアカウント単位のJSONアーカイブで、読んでいたチャットの名前が付いたファイルではありません。バックアップとして使い、何千もの会話から1件だけ取り出したい場合は自分で展開してください。

拡張機能を使わない3つ目の方法がコピー＆ペーストです。テキストを選択して、Googleドキュメントやメモアプリに貼り付けます。コードのインデントはたいてい崩れ、表は一続きの行になり、何往復もあるスレッドは構造のない文字の塊になります。短い回答1つなら十分ですが、後で検索するコードレビューには向きません。拡張機能の「Copy」ボタンなら、整ったMarkdownをクリップボードに入れられます。

Claudeのチャット履歴を一括でダウンロードするには？

Claudeのチャット履歴を複数のファイルでダウンロードするなら、タブごとにオレンジ色のボタンを押す必要はありません。拡張機能のポップアップから「View and Download All Conversations」（すべての会話を表示・ダウンロード）を開き、一覧を絞り込んでから「Export All」（すべてエクスポート）をクリックします。「Export All」にはGoogleサインインが必要です。無料プランでは、ZIPに含まれるチャット1件ごとに、PDFと共通の1日3回の枠を1回使います。Proなら上限はありません。

ダッシュボードには、ログイン中のclaude.aiアカウントの会話が表示されます。名前で検索でき、All conversations（すべての会話）、New（新規）、Updated（更新あり）、Previously exported（エクスポート済み）で絞り込めます。ChatタブとCoworkタブを切り替えられるほか、claude.aiでプロジェクトごとにチャットを分けていればプロジェクト名でも検索できます。古い下書きまで全部フォルダーに入れたくないときは、一部だけを選択してください。

一括エクスポートでは、チャットごとに1ファイルを収めたZIPが1つ作られます。形式は「Chat format」（チャット形式）で選び、PDFを含む7つの形式のどれでも使えます。パーサーは1件のエクスポートと同じです。含める内容はチェックボックス「Chats」「Thinking」「Metadata」「Tools」「Sources」（チャット、思考、メタデータ、ツール、出典）とアーティファクトの配置で決めます。「Export All」は簡易版の処理ではなく、同じパーサーを多数の会話IDにまとめて適用するものです。詳細とスクリーンショット：一括の「Export All」。

Anthropicの「Export data」は、引き続きアカウントのバックアップとして役立ちます。ZIPが1つ、メールが1通、すべてがJSONで、忘れていたチャットも含まれます。一括の「Export All」はその逆で、スレッドを選び、形式を選べば、ZIPがすぐに保存されます。記録保管用のアーカイブと、読みやすいメモのフォルダーの両方が欲しいなら、両方を使ってください。

無料枠は共通で、1日ごとです。無料プランでは、PDFのエクスポートと一括エクスポートのチャットを合わせて1日3回までで、UTCの午前0時にリセットされます。40件の会話を選ぶと、途中で切られるのではなく、一括エクスポート全体がブロックされます。選ぶ会話を減らすか、Pro（月額$3.99または年額$26.99）にアップグレードしてください。

ダッシュボードはエクスポート済みの会話も記録しているため、次に開いたときはNew（新規）やUpdated（更新あり）だけに絞り込めます。こうすれば、毎週Claudeのチャット履歴をダウンロードする習慣も、先月のMarkdownを重複させずに差分だけで続けられます。

ClaudeのチャットをMarkdownやJSONでダウンロードするには？

ClaudeのチャットをMarkdownやJSONでダウンロードするには、オレンジ色のボタンを開いて形式を選び、「Export」をクリックします。Markdownはメモ用のファイル、JSONはスクリプト向けのメッセージツリーです。プレーンテキストにはマークアップがありません。CSVはメッセージ1件につき1行です。PDFはページ分けされた文書、PNGは画像です。

Markdownは見出し、言語タグ付きのコードブロック、表を保持します。Obsidian、GitHub、社内Wikiに入れるならまずこれです。JSONはパーサーが組み立てたツリーをそのまま残し、切り替えをオンにしていればアーティファクトや思考も含みます。AnthropicのアカウントZIPとは構造が異なります。形式の解説：すべての形式。

保存先がどのみちマークアップを取り除く場合は、プレーンテキストが適しています。チケット管理ツールの入力欄への貼り付け、メール本文、生の文字列を扱う検索インデックスなどです。XMLはデータ交換用の特殊な選択肢です。CSVはExcel、Googleスプレッドシート、Numbersで開けます。PNGはスライドやバグ報告に貼るスレッドの図に向いており、後でgrepする40往復の設計レビューには向きません。

PDFはバージョン1.16.2に組み込まれています。PDFを選ぶとダイアログが開き、ファイル名、用紙サイズ、余白、ライトモードかダークモードか、フォントと文字サイズ、ページ番号、目次、タイムスタンプ、プロンプトごとの改ページを設定できます。PDFにはGoogleサインインが必要で、無料プランでは1日3回までです。Proなら無制限です。詳細：ClaudeのチャットをPDFで。

最後に使った形式は記憶されます。MarkdownのつもりがJSONで保存された場合は、前回のエクスポートの設定がJSONのままだったということです。目的が変わるたびに、形式の選択を確認してください。

Claudeの会話の保存と、印刷やZIPとの違いは？

claude.aiでは、「保存」「ダウンロード」「エクスポート」はどれも同じ作業、つまりスレッドをページの外に持ち出すことです。Claudeの会話を使えるファイル（PDFを含む）として保存する方法が、この拡張機能です。印刷はスナップショット、Anthropicの「Export data」はアカウント全体のZIPです。

チームの中でも言葉はまちまちです。研究者は「保存」、開発者は「エクスポート」、マネージャーは「ダウンロード」と言います。当サイトでは、Chromeでclaude.aiを使っている限り、この3つの言葉はすべて同じオレンジ色のボタンを指します。関連ガイドClaudeのチャットをエクスポートする方法では、公式ZIPとJSONの構造をさらに詳しく説明しています。

印刷にも出番はあります。claude.aiの画面とまったく同じ見た目で添付したい単発の資料です。公式の「Export data」にも出番があります。退職時、訴訟に備えた保全、念のための二重バックアップです。ただし、どちらも来週編集するMarkdownファイルの代わりにはなりません。

Claude Desktopは別のウィンドウです。Chrome拡張機能はDesktopアプリには組み込まれません。同じチャットがclaude.aiにもあるなら、そちらで開いてダウンロードしてください。Desktopにしかない場合は、コピー＆ペーストするか、アカウントのZIPを待ちます。手順：Claude Desktopのチャットをエクスポートする。

Proの支払いはPaddleが処理し、当方がカード番号を見ることはありません。Googleサインインを使うのはPDF、一括エクスポート、Proのときだけで、それによって会話へのアクセス権が当方に渡ることもありません。利用回数とProの状態を確認するCloudflare Workerが受け取るのはGoogleのメールアドレスで、メッセージの本文ではありません。それ以外の1件ずつのエクスポートでは何も送信されません。この境界線がプライバシーのすべてです。課金はサーバーに、チャットはディスクに。

Claudeのチャットのダウンロードボタンが表示されないのはなぜ？

Claudeのチャットのダウンロードボタンが表示されないのは、会話のURLを開いていない、インストール後にタブを再読み込みしていない、または拡張機能が無効になっている場合です。アイコンを固定して再読み込みし、Desktopアプリやスマートフォン、Claude Codeのターミナルではなく、デスクトップ版Chromeのclaude.aiにいることを確認してください。

インストール後、すでに開いていたタブにChromeがコンテンツスクリプトを読み込むとは限りません。claude.aiのタブを閉じるか、強制的に再読み込みしてください。複数のプロファイルを使っている場合は、Anthropicにログインしているプロファイルに拡張機能をインストールする必要があります。

TeamやEnterpriseのワークスペースでも、ブラウザで会話を開ければ使えます。拡張機能が読むのはページで、プランの種類ではありません。組織がChrome拡張機能をブロックしている場合は、IT部門にこの拡張機能を許可してもらう必要があります。当サイトからそのポリシーを回避することはできません。

サインインの確認が出るのは、PDFと「Export All」のときだけで、想定どおりの動作です。Markdown、テキスト、JSON、XML、CSV、PNGはアカウントなしでエクスポートできます。最初にPDFまたは一括エクスポートを実行すると、Googleのサインインを求められます。これをキャンセルすると、ダウンロードに失敗したように見えます。サインインを完了してから、もう一度「Export」をクリックしてください。無料プランにクレジットカードは不要です。

ファイルが不完全な場合：会話の生成がまだ終わっていなかったか、古いやり取りが画面外にあって読み込まれていませんでした。アシスタントの回答が終わるまで待ち、長いスレッドの冒頭に向かってスクロールしてclaude.aiに読み込ませてから、もう一度エクスポートします。MarkdownやJSONのエクスポートは、何度やり直しても回数を消費しません。PDFをやり直すと、無料プランでは1日3回の枠をもう1回使うので、先にスレッドがすべて読み込まれているか確認するのがおすすめです。

形式が違う場合：前回使った形式が選ばれたままでした。アカウントが違う場合：Proを契約しているのとは別のアドレスでGoogleにサインインしています。Proの復元はそのGoogleメールアドレスに紐付いており、Anthropicのログインや、Chromeのプロファイル名とは関係ありません。

モバイルブラウザではこの拡張機能は動きません。iOSやAndroidのアプリもありません。スマートフォンのSafariでは印刷はできますが、オレンジ色のボタンは表示されません。再利用できるファイルが必要なら、デスクトップ版Chromeで同じチャットを開いてください。

Claude Codeのチャットもダウンロードできますか？

Claude Code on the webからならダウンロードできます。claude.ai/codeのセッションはChromeで開くので、Download Claude conversationsはほかのチャットと同じようにエクスポートできます。ローカルのClaude Codeのターミナルセッションは別物です。ターミナルのセッションをエクスポートする方法は/exportか、~/.claude/projectsにあるJSONLファイルです。環境が違えば、ファイルも違います。

Claude Codeのセッション中に/exportと入力すると、AnthropicのCLIがメニューを開き、トランスクリプトをコピーするか、プレーンテキストのファイルとして保存するかを選べます。ファイル名を指定すればメニューは省略されます。このトランスクリプトは人が読むためのテキストで、この拡張機能のMarkdown、JSON、PDFとは別物です。パスの詳細：Claude Codeのエクスポート。

ディスク上のJSONLは内部ログです。スキーマはClaude Codeのバージョンによって変わることがあります。Anthropic自身のドキュメントでも、JSONLを解析するより/exportやスクリプト用のインターフェースを使うよう勧めています。当方はそのCLIをラップしておらず、~/.claudeを読み取ることもありません。

同じ作業についてclaude.aiでも並行してスレッドを使っているなら、そのブラウザのチャットはオレンジ色のボタンでダウンロードしてください。ターミナルのログとWebのチャットが自動的に同じ文書になることはありません。一方をもう一方に貼り付けていない限り、別々の記録として扱ってください。

よくある質問：Claudeのチャットをダウンロードする方法

ChromeでClaudeのチャットをダウンロードするには？

Download Claude conversationsをインストールし、claude.aiでスレッドを開き、メッセージ入力欄の右側にあるオレンジ色のボタンをクリックします。PDF、Markdown、JSON、テキスト、XML、CSV、PNGから形式を選び、「Export」（エクスポート）をクリックすれば、ファイルが手元に保存されます。アカウントは不要です。ただしPDFだけはGoogleサインインを求められます。

拡張機能なしでClaudeのチャットをダウンロードできますか？

はい。見た目を残すならページを印刷（Ctrl/Cmd+P →「PDFに保存」）し、アカウント全体のJSON ZIPが欲しいならSettings → Privacy → Export dataを使います（届くまで時間がかかります）。短い回答ならコピー＆ペーストでも十分です。ただし、どの方法もChrome拡張機能のようにチャットごとの構造化されたMarkdownファイルは作れません。

Claudeのチャット履歴をダウンロードするには？

1件の会話ならオレンジ色のボタンを使います。複数のファイルが必要なら、拡張機能のポップアップから「View and Download All Conversations」（すべての会話を表示・ダウンロード）を開き、「Export All」（すべてエクスポート）をクリックします。一括エクスポートにはGoogleサインインが必要で、無料プランでは1日3回の枠に数えられます。この一括ダウンロードはAnthropicの「Export data」のZIPとは別物です。公式の「Export data」は、アカウント全体をひとつのアーカイブにして後からメールで届けるものです。詳しくは一括ダウンロードをご覧ください。

Claudeのチャットをダウンロードするのにお金はかかりますか？

いいえ。Markdown、プレーンテキスト、JSON、XML、CSV、PNGのエクスポートは、アカウント不要・無料で無制限です。PDFと一括ZIPは、Googleサインインをすれば1日3回まで無料で、一括ZIPではチャット1件を1回と数えます。Proは月額$3.99または年額$26.99で、この上限がなくなります。支払いはPaddleが処理します。

Download Claude conversationsはスマートフォンで使えますか？

いいえ。デスクトップ版Chrome（またはChrome Web Storeの拡張機能をインストールできる他のChromium系ブラウザ）用のChrome拡張機能です。iOSやAndroidのアプリはありません。モバイルブラウザでもClaudeのチャットを印刷することはできますが、この拡張機能は動きません。

これを使うとAnthropicのアカウントが停止されますか？

法的な助言はできません。この拡張機能は、ご自身のセッションですでに読み込まれているclaude.aiのページを読み取ります。別の認証情報でAnthropicにアクセスしたり、アカウント上のクリック操作を自動化したりはしません。当方はAnthropicではありません。Anthropicの利用規約と勤務先のルールに従ってください。

Claudeの会話をファイルとして保存するには？

開いているチャットをきれいなファイル（PDFを含む）にするならChrome拡張機能を使います。Webページのスナップショットなら印刷、アカウント全体のZIPならAnthropicの「Export data」です。claude.aiでスレッドを画面の外に持ち出したいとき、「保存」「ダウンロード」「エクスポート」はどれも同じ作業を指します。

Claude Codeのセッションにも使えますか？

Webの場合だけ使えます。claude.ai/codeのClaude Codeのセッションは、ほかのclaude.aiのチャットと同じようにエクスポートできます。ローカルのターミナルのセッションは対象外なので、/exportを使うか、~/.claude/projects（Windowsでは%USERPROFILE%\.claude\projects）からJSONLをコピーしてください。このChrome拡張機能はclaude.aiでのみ動作します。ガイド：Claude Codeのエクスポート。

Claudeのチャットをダウンロードするのに、Googleサインインは必要ですか？

Markdown、プレーンテキスト、JSON、XML、CSV、PNGなら不要です。Googleサインインが必要なのはPDF、一括の「Export All」、Proだけで、1日3回の上限を適用し、再インストール後にProを復元するために使います。このサインインで会話の内容が送られることはありません。確認済みのメールアドレスは、無料枠とProの状態の管理にだけ保存します。

Claudeのチャットはどの形式でダウンロードできますか？

拡張機能1.16.2では、PDF、Markdown、JSON、プレーンテキスト、XML、CSV、PNGの7つです。PDFは印刷ダイアログを使わずにブラウザ内で作られます。CSVはメッセージ1件につき1行です。PNGはスレッドの画像です。形式の一覧：形式。

TeamやEnterpriseのワークスペースからもエクスポートできますか？

はい。Chromeでclaude.aiの会話を開ける状態なら使えます。拡張機能は表示されたページをもとに動き、個人向けプラン専用のAPIには依存しません。会社のポリシーで拡張機能がブロックされている場合、それはIT部門の判断であり、当方の設定でプランを切り替えて解決するものではありません。

Claude Chat Downloaderはこの製品と同じですか？

はい。Download Claude conversationsはChrome Web Storeでの名称です。Claude Chat DownloaderやClaude Conversation Downloaderという名前で探す人もいます。オレンジ色のボタンも、7つの形式も、無料プランも同じです。
