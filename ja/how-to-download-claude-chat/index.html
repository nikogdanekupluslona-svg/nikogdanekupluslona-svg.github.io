ChromeでClaudeのチャットをダウンロードする方法は？

Claudeのチャットをダウンロードする方法への直接の答えは、この拡張機能がclaude.aiのメッセージ入力欄の横に追加するオレンジ色のボタンです。会話を開き、Markdown、JSON、テキスト、XML、PNGから選んで「Export」（エクスポート）をクリックします。ファイルはブラウザ内で組み立てられ、ディスクに保存されます。

この拡張機能はChromeのコンテンツスクリプトです。ログイン済みのclaude.aiセッションにすでに読み込まれている会話を読み取ります。独自の認証情報で別のAnthropic APIを呼び出すことはなく、ファイルを作るためにスレッドを当方のサーバーへアップロードすることもありません。

  1. Chrome Web StoreからDownload Claude conversationsをインストールします（Chrome拡張機能を読み込めるChromium系ブラウザでも動作します）。
  2. インストール時にclaude.aiを開いていた場合は、ページを再読み込みします。
  3. 保存したい会話のURLを開きます。オレンジ色のボタンは実際のスレッドにだけ表示され、何も入力していないホーム画面には表示されません。
  4. メッセージ入力欄の右側にあるオレンジ色のダウンロードボタンをクリックします。
  5. Markdown、JSON、プレーンテキスト、XML、PNGから選び、「Export」をクリックします。Chromeがすぐにファイルをダウンロードします。

最初のエクスポートの前にGoogleサインインが必要です。これはアカウントごとに3回の無料エクスポートを数え、後でProを復元するためのものです。チャットを読むためのログインではありません。保存するのは無料枠とサブスクリプションの状態を管理するための、Googleで確認されたメールアドレスだけです。会話の本文はお使いのパソコンから出ません。

完成したファイルは、MarkdownでもPNGでも1件につき1回のエクスポートとして数えます。無料アカウントは合計3回までです。Proは月額$3.99または年額$26.99で、1件ずつのチャットにも一括の「Export All」にも上限がなくなります。

ファイルはローカルで作成。Markdown、JSON、テキスト、XML、PNGはブラウザ内で作られ、Chromeのダウンロード機能に渡されます。当方のサーバーに届くのは利用回数の確認だけで、チャットの本文は送られません。

同じウィジェットには任意の切り替えもあります。拡張思考を含めるかどうか、メタデータ（タイトル、タイムスタンプ、モデル）を含めるかどうか、送信者での絞り込み（「all / human only / assistant only」＝すべて／ユーザーのみ／アシスタントのみ）、アーティファクトの配置（「Original」「Inline」「Nested」「Flat」＝元の配置／インライン／入れ子／フラット）です。これらの設定は、一括の一覧ページと同じようにこの1件のチャットにも適用されます。

スレッドがとても長い場合は、claude.aiが前半のメッセージを読み込むまでスクロールしてください。拡張機能がエクスポートできるのは、ページに表示済みの内容だけです。途中までしか読み込まれていないスレッドからは途中までのファイルができます。不具合に見えますが、たいていはスクロールが足りていないだけです。

私たちは、あなたがすでに開いているclaude.aiのページ上でメッセージツリーを解析します。コードブロックは言語タグとインデントを保ち、表は表のまま残ります。PDF形式をでっち上げることはしません。印刷用のページが必要なら、偽の「PDFでエクスポート」ボタンではなく、ブラウザの印刷ダイアログを使ってください。

拡張機能なしでClaudeのチャットをダウンロードできますか？

はい。ページを印刷するか、Anthropicのアカウントエクスポートを申請すれば、拡張機能なしでもClaudeのチャットを持ち出せます。印刷はWebページの見た目をPDFにしたものです。「Export data」は、アカウント全体のJSON ZIPが後から届く仕組みです。どちらもチャットごとのMarkdownファイルは作りません。

印刷の手順：claude.aiで会話を開き、可能ならサイドバーを隠してから、Ctrl+P（Windows/Linux）またはCmd+P（Mac）を押し、送信先を「PDFに保存」にして保存します。コードブロックはページの途中で分かれることが多く、入力欄などの画面要素が毎ページに入ることもあります。印刷の詳しい注意点はClaudeのチャットをPDFで保存する方法にまとめています。

公式の手順：claude.aiでSettings → Privacy → Export data（claude.aiを日本語表示にしている場合、メニュー名は日本語で表示されることがあります）。Anthropicから有効期限付きのリンクがメールで届きます。ZIPはアカウント単位のJSONアーカイブで、読んでいたチャットの名前が付いたファイルではありません。バックアップとして使い、何千もの会話から1件だけ取り出したい場合は自分で展開してください。

拡張機能を使わない3つ目の方法がコピー＆ペーストです。テキストを選択して、Googleドキュメントやメモアプリに貼り付けます。コードのインデントはたいてい崩れ、表は一続きの行になり、何往復もあるスレッドは構造のない文字の塊になります。短い回答1つなら十分ですが、後で検索するコードレビューには向きません。

Claudeのチャット履歴を一括でダウンロードするには？

Claudeのチャット履歴を複数のファイルでダウンロードするなら、タブごとにオレンジ色のボタンを押す必要はありません。拡張機能のポップアップから「View and Download All Conversations」（すべての会話を表示・ダウンロード）を開き、一覧を絞り込んでから「Export All」（すべてエクスポート）をクリックします。Proでない場合、完成したファイルはそれぞれ同じ3回の無料枠に含まれます。

一覧ページには、ログイン中のclaude.aiアカウントの会話が表示されます。名前で検索でき、All（すべて）、New（未エクスポート）、Exported（エクスポート済み）で絞り込めるほか、claude.aiでプロジェクトごとにチャットを分けていればProjectでも絞り込めます。古い下書きまで全部フォルダーに入れたくないときは、一部だけを選択してください。

一括エクスポートでも、1件のエクスポートと同じ5つの形式と同じ切り替え（思考、メタデータ、送信者フィルター、アーティファクトの配置）が使えます。「Export All」は簡易版の処理ではなく、同じパーサーを多数の会話IDにまとめて適用するものです。詳細とスクリーンショット：一括の「Export All」。

Anthropicの「Export data」は、引き続きアカウントのバックアップとして役立ちます。ZIPが1つ、メールが1通、すべてがJSONで、忘れていたチャットも含まれます。一括の「Export All」はその逆で、スレッドを選び、MarkdownかJSONかを選べば、ファイルがすぐに保存されます。記録保管用のアーカイブと、読みやすいメモのフォルダーの両方が欲しいなら、両方を使ってください。

無料枠は共通です。3回の無料エクスポートは、1件ずつのチャットと一括のファイルを合わせた回数です。無料アカウントで40件の会話を選んでも、3件目のファイルで止まります。選ぶ会話を計画するか、Pro（月額$3.99または年額$26.99）にアップグレードしてください。

一覧はエクスポート済みの会話も記録しているため、次に開いたときはNew（未エクスポート）だけに絞り込めます。こうすれば、毎週Claudeのチャット履歴をダウンロードする習慣も、先月のMarkdownを重複させずに差分だけで続けられます。

ClaudeのチャットをMarkdownやJSONでダウンロードするには？

ClaudeのチャットをMarkdownやJSONでダウンロードするには、オレンジ色のボタンを開いて形式を選び、「Export」をクリックします。Markdownはメモ用のファイル、JSONはスクリプト向けのメッセージツリーです。プレーンテキストにはマークアップがありません。PNGは画像で、PDFではありません。

Markdownは見出し、言語タグ付きのコードブロック、表を保持します。Obsidian、GitHub、社内Wikiに入れるならまずこれです。JSONはパーサーが組み立てたツリーをそのまま残し、切り替えをオンにしていればアーティファクトや思考も含みます。AnthropicのアカウントZIPとは構造が異なります。形式の解説：すべての形式。

保存先がどのみちマークアップを取り除く場合は、プレーンテキストが適しています。チケット管理ツールの入力欄への貼り付け、メール本文、生の文字列を扱う検索インデックスなどです。XMLはデータ交換用の特殊な選択肢です。PNGはスライドやバグ報告に貼るスレッドの図に向いており、後でgrepする40往復の設計レビューには向きません。

バージョン1.13.0にネイティブのPDF出力はありません。取引先にPDFを求められたら、Markdownでエクスポートし、そのファイルをWord、Googleドキュメント、VS Code、Obsidianから印刷してください。claude.aiそのものを印刷する方法もあります。この拡張機能にない.pdfオプションを待つ必要はありません。変換手順：印刷とPDF。

最後に使った形式は記憶されます。MarkdownのつもりがJSONで保存された場合は、前回のエクスポートの設定がJSONのままだったということです。目的が変わるたびに、形式の選択を確認してください。

Claudeの会話の保存と、印刷やZIPとの違いは？

claude.aiでは、「保存」「ダウンロード」「エクスポート」はどれも同じ作業、つまりスレッドをページの外に持ち出すことです。Claudeの会話を使えるファイルとして保存する方法が、この拡張機能です。印刷はスナップショット、Anthropicの「Export data」はアカウント全体のZIPです。

チームの中でも言葉はまちまちです。研究者は「保存」、開発者は「エクスポート」、マネージャーは「ダウンロード」と言います。当サイトでは、Chromeでclaude.aiを使っている限り、この3つの言葉はすべて同じオレンジ色のボタンを指します。関連ガイドClaudeのチャットをエクスポートする方法では、公式ZIPとJSONの構造をさらに詳しく説明しています。

印刷にも出番はあります。製品の画面どおりの見た目で添付したい単発の資料です。公式の「Export data」にも出番があります。退職時、訴訟に備えた保全、念のための二重バックアップです。ただし、どちらも来週編集するMarkdownファイルの代わりにはなりません。

Claude Desktopは別のウィンドウです。Chrome拡張機能はDesktopアプリには組み込まれません。同じチャットがclaude.aiにもあるなら、そちらで開いてダウンロードしてください。Desktopにしかない場合は、コピー＆ペーストするか、アカウントのZIPを待ちます。手順：Claude Desktopのチャットをエクスポートする。

Proの支払いはPaddleが処理し、当方がカード番号を見ることはありません。Googleサインインで会話へのアクセス権が当方に渡ることもありません。Proの状態を確認するCloudflare Workerが受け取るのはライセンスの状態で、メッセージの本文ではありません。この境界線がプライバシーのすべてです。課金はサーバーに、チャットはディスクに。

Claudeのチャットのダウンロードボタンが表示されないのはなぜ？

Claudeのチャットのダウンロードボタンが表示されないのは、会話のURLを開いていない、インストール後にタブを再読み込みしていない、または拡張機能が無効になっている場合です。アイコンを固定して再読み込みし、Desktopアプリやスマートフォン、Claude Codeではなく、デスクトップ版Chromeのclaude.aiにいることを確認してください。

インストール後、すでに開いていたタブにChromeがコンテンツスクリプトを読み込むとは限りません。claude.aiのタブを閉じるか、強制的に再読み込みしてください。複数のプロファイルを使っている場合は、Anthropicにログインしているプロファイルに拡張機能をインストールする必要があります。

TeamやEnterpriseのワークスペースでも、ブラウザで会話を開ければ使えます。拡張機能が読むのはページで、プランの種類ではありません。組織がChrome拡張機能をブロックしている場合は、IT部門にこの拡張機能を許可してもらう必要があります。当サイトからそのポリシーを回避することはできません。

サインインの確認は想定どおりの動作です。最初に「Export」をクリックするとGoogleのサインインを求められます。これをキャンセルすると、ダウンロードに失敗したように見えます。サインインを完了してから、もう一度「Export」をクリックしてください。3回の無料エクスポートにクレジットカードは不要です。

ファイルが不完全な場合：会話の生成がまだ終わっていなかったか、古いやり取りが画面外にあって読み込まれていませんでした。アシスタントの回答が終わるまで待ち、長いスレッドの冒頭に向かってスクロールしてclaude.aiに読み込ませてから、もう一度エクスポートします。無料プランではこれも1回分として数えられるので、先にスレッドがすべて読み込まれているか確認するのがおすすめです。

形式が違う場合：前回使った形式が選ばれたままでした。アカウントが違う場合：Proを契約しているのとは別のアドレスでGoogleにサインインしています。Proの復元はそのGoogleメールアドレスに紐付いており、Anthropicのログインや、Chromeのプロファイル名とは関係ありません。

モバイルブラウザではこの拡張機能は動きません。iOSやAndroidのアプリもありません。スマートフォンのSafariでは印刷はできますが、オレンジ色のボタンは表示されません。再利用できるファイルが必要なら、デスクトップ版Chromeで同じチャットを開いてください。

Claude Codeのチャットもダウンロードできますか？

いいえ。この拡張機能ではClaude Codeの会話はダウンロードできません。Claude Codeはターミナルで動くエージェントです。claude.aiでClaudeのチャットをダウンロードする方法がこのChrome拡張機能で、ターミナルのセッションをエクスポートする方法は/exportか、~/.claude/projectsにあるJSONLファイルです。製品が違えば、ファイルも違います。

Claude Codeのセッション中に/exportと入力すると、AnthropicのCLIがメニューを開き、トランスクリプトをコピーするか、プレーンテキストのファイルとして保存するかを選べます。ファイル名を指定すればメニューは省略されます。このトランスクリプトは人が読むためのテキストで、この拡張機能のMarkdown/JSON/PNGとは別物です。パスの詳細：Claude Codeのエクスポート。

ディスク上のJSONLは内部ログです。スキーマはClaude Codeのバージョンによって変わることがあります。Anthropic自身のドキュメントでも、JSONLを解析するより/exportやスクリプト用のインターフェースを使うよう勧めています。当方はそのCLIをラップしておらず、~/.claudeを読み取ることもありません。

同じ作業についてclaude.aiでも並行してスレッドを使っているなら、そのブラウザのチャットはオレンジ色のボタンでダウンロードしてください。ターミナルのログとWebのチャットが自動的に同じ文書になることはありません。一方をもう一方に貼り付けていない限り、別々の記録として扱ってください。

よくある質問：Claudeのチャットをダウンロードする方法

ChromeでClaudeのチャットをダウンロードするには？

Download Claude conversationsをインストールし、claude.aiでスレッドを開き、メッセージ入力欄の横にあるオレンジ色のボタンをクリックします。Markdown、JSON、テキスト、XML、PNGから形式を選び、「Export」（エクスポート）をクリックすれば、ファイルが手元に保存されます。無料の3回を数えるため、最初のエクスポートの前にGoogleサインインが必要です。

拡張機能なしでClaudeのチャットをダウンロードできますか？

はい。見た目を残すならページを印刷（Ctrl/Cmd+P →「PDFに保存」）し、アカウント全体のJSON ZIPが欲しいならSettings → Privacy → Export dataを使います（届くまで時間がかかります）。短い回答ならコピー＆ペーストでも十分です。ただし、どの方法もChrome拡張機能のようにチャットごとの構造化されたMarkdownファイルは作れません。

Claudeのチャット履歴をダウンロードするには？

1件の会話ならオレンジ色のボタンを使います。複数のファイルが必要なら「View and Download All Conversations」（すべての会話を表示・ダウンロード）を開き、「Export All」（すべてエクスポート）をクリックします。この一括ダウンロードはAnthropicの「Export data」のZIPとは別物です。公式の「Export data」は、アカウント全体をひとつのアーカイブにして後からメールで届けるものです。詳しくは一括ダウンロードをご覧ください。

Claudeのチャットをダウンロードするのにお金はかかりますか？

いいえ。どのアカウントでも、5つの形式のいずれかで3回まで無料でエクスポートできます。それ以降はProが月額$3.99または年額$26.99です。支払いはPaddleが処理します。無料枠は無制限ではなく、一括で作成したファイルも同じ3回に含まれます。

Download Claude conversationsはスマートフォンで使えますか？

いいえ。デスクトップ版Chrome（またはChrome Web Storeの拡張機能をインストールできる他のChromium系ブラウザ）用のChrome拡張機能です。iOSやAndroidのアプリはありません。モバイルブラウザでもClaudeのチャットを印刷することはできますが、この拡張機能は動きません。

これを使うとAnthropicのアカウントが停止されますか？

法的な助言はできません。この拡張機能は、ご自身のセッションですでに読み込まれているclaude.aiのページを読み取ります。別の認証情報でAnthropicにアクセスしたり、アカウント上のクリック操作を自動化したりはしません。当方はAnthropicではありません。Anthropicの利用規約と勤務先のルールに従ってください。

Claudeの会話をファイルとして保存するには？

開いているチャットをきれいなファイルにするならChrome拡張機能を使います。PDFのようなスナップショットなら印刷、アカウント全体のZIPならAnthropicの「Export data」です。claude.aiでスレッドを画面の外に持ち出したいとき、「保存」「ダウンロード」「エクスポート」はどれも同じ作業を指します。

Claude Codeのセッションにも使えますか？

いいえ。Claude Codeはターミナルで動きます。/exportを使うか、~/.claude/projects（Windowsでは%USERPROFILE%\.claude\projects）からJSONLをコピーしてください。このChrome拡張機能はclaude.aiでのみ動作します。ガイド：Claude Codeのエクスポート。

Claudeのチャットをダウンロードするのに、Googleサインインは必要ですか？

はい、最初のエクスポートから必要です。選んだアカウントをGoogleが確認することで、3回の無料枠を管理し、再インストール後にProを復元できます。このサインインで会話の内容が送られることはありません。確認済みのメールアドレスは、無料枠とProの状態の管理にだけ保存します。

Claudeのチャットはどの形式でダウンロードできますか？

Markdown、JSON、プレーンテキスト、XML、PNGです。拡張機能1.13.0にPDFエクスポートはありません。PDFが必要ならclaude.aiを印刷するか、Markdownファイルを別のアプリで変換してください。PNGはスレッドの画像で、PDFではありません。形式の一覧：形式。

TeamやEnterpriseのワークスペースからもエクスポートできますか？

はい。Chromeでclaude.aiの会話を開ける状態なら使えます。拡張機能は表示されたページをもとに動き、個人向けプラン専用のAPIには依存しません。会社のポリシーで拡張機能がブロックされている場合、それはIT部門の判断であり、当方の設定でプランを切り替えて解決するものではありません。

Claude Chat Downloaderはこの製品と同じですか？

はい。Download Claude conversationsはChrome Web Storeでの名称です。Claude Chat DownloaderやClaude Conversation Downloaderという名前で探す人もいます。オレンジ色のボタンも、5つの形式も、3回の無料エクスポートも同じです。
