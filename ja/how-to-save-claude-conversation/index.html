Claudeの会話は履歴に自動で保存されていますか？

はい。claude.aiは、サインイン中のスレッドをAnthropicアカウントの履歴にすでに保存しています。タブを閉じても会話は消えません。それでも、ディスクにファイルを書き出す保存ボタンはありません。会話をMarkdownやJSONとして保存することは、履歴とは別の作業です。

履歴とは、claude.aiの左側に並ぶチャットの一覧です。各行は、そのログインに対してAnthropicが保存した会話です。後で行を開けば、同じやり取りが表示されます。これはアカウント上の保存であり、パソコンのダウンロードフォルダーではありません。

「Claude 会話 保存」と検索する人の多くは、「ページを離れたら消えてしまうのでは？」と心配しています。通常のサインイン中のセッションなら、答えは「消えません」です。claude.aiでは、スレッドをアカウントに残すために保存をクリックする必要はありません。足りないのはファイルを書き出す機能であって、会話を残すためのスイッチではありません。

履歴はMarkdownファイルでも、grepできるJSONツリーでも、スライドに貼れるPNGでもありません。履歴はAnthropicのログインの向こう側にあります。サインインできなければ、そのチャットは開けません。ローカルのファイルなら、パスワードがわからなくなっても開けます。

2種類の「保存」。履歴＝Anthropicがチャットをアカウントに残すこと。ファイル＝Markdown、JSON、テキスト、XML、PNGを自分のディスクに書き出すこと。claude.aiにあるのは前者だけで、後者のためのボタンはありません。

claude.aiのプロジェクトや最近のチャットも、履歴の一部です。チャットをプロジェクトにまとめてもファイルはできません。会話の名前を変えてもファイルはできません。画面にスターやピン留めの機能があっても、それでMarkdownが書き出されるわけではありません。

TeamやEnterpriseのワークスペースでも同じです。claude.aiで会話を開けるなら、Anthropicはその会話をワークスペースにすでに保存しています。ただし、会社の保持ルールによって、自分では管理できないスケジュールでチャットが削除されたり非表示になったりすることがあります。そのとき手元に残るのは、エクスポートしたファイルです。

シークレットモードや別のChromeプロファイルとは履歴を共有しません。スレッドは、そのセッションで使ったAnthropicアカウントに紐付いています。別のAnthropicログインでサインインすれば、別の履歴が表示されます。アカウントをまたいで「保存」するならファイルを使います。履歴が統合されることはありません。

Claudeの会話をファイルとして保存する方法は？

Claudeの会話をファイルとして保存するには、ディスクに書き出す方法を選びます。ChromeのDownload Claude conversations、印刷 →「PDFに保存」、またはSettings → Privacy → Export dataです。claude.aiの履歴はアカウント上の保存であり、Markdown、JSON、テキスト、XML、PNGのファイルではありません。

Chrome拡張機能は、チャットを1件ずつ保存する方法です。会話のURLを開き、メッセージ入力欄の横にあるオレンジ色のボタンをクリックし、形式を選んで「Export」をクリックします。Chromeのダウンロード機能がファイルをローカルに書き出します。無料枠の管理にはGoogleサインインを使い、チャットの本文はパソコンから出ません。

印刷は見た目を残す方法です。Ctrl+PまたはCmd+Pを押し、送信先を「PDFに保存」にします。結果はclaude.aiのページそのままの見た目で、印刷用スタイルで隠れなかった画面要素も含まれます。コードブロックはページの途中で分かれることがよくあります。メモ用のファイルではなく、スナップショットを求められたときに使ってください。

公式の「Export data」はアカウント全体を保存する方法です。claude.aiのSettings → Privacy → Export dataから申請すると、Anthropicから有効期限付きのリンクがメールで届きます。ZIPはアカウント全体のJSONで、画面上のチャットの名前が付いたファイル1つではありません。待ち時間は、完全なバックアップを得るための代償です。

目的に合う行を選んでください。Claudeのチャットを保存する方法を探す人の多くが求めているのは2行目、つまりObsidian、VS Code、社内Wikiで開けるファイルです。1行目は履歴がすでに担っています。印刷と「Export data」も有効ですが、解決する目的が違います。

ファイルが役立つのは、退職や異動の前、パソコンの初期化の前、研究資料のアーカイブを作る前、コードレビューをgitに貼る前です。同じAnthropicログインで明日また同じスレッドを開くだけなら、履歴で十分です。

コピー＆ペーストは5つ目の方法ですが、ファイルとしては弱い方法です。claude.aiでテキストを選択し、Googleドキュメントに貼り付けます。コードブロックは崩れ、表は一続きの行になり、メッセージの区切りも消えます。段落1つなら十分ですが、40往復の設計レビューを保存する唯一の記録としては不十分です。

Chrome拡張機能でClaudeのチャットを保存するには？

Download Claude conversationsでClaudeのチャットを保存するには、Chrome拡張機能をインストールし、claude.aiでスレッドを開き、メッセージ入力欄の横にあるオレンジ色のボタンをクリックして、Markdown、JSON、テキスト、XML、PNGから選び、「Export」を押します。3回の無料エクスポートはGoogleサインインで数えます。

  1. Chrome Web StoreからDownload Claude conversationsをインストールします（Chrome拡張機能を読み込めるChromium系ブラウザでも動作します）。
  2. インストール時にclaude.aiを開いていた場合は、ページを再読み込みします。古いタブにChromeがコンテンツスクリプトを読み込むとは限りません。
  3. 履歴から実際の会話のURLを開きます。オレンジ色のボタンはスレッドに表示され、何も入力していないホーム画面には表示されません。
  4. メッセージ入力欄の右側にあるオレンジ色のダウンロードボタンをクリックします。
  5. Markdown、JSON、プレーンテキスト、XML、PNGから選び、「Export」をクリックします。Chromeがすぐにファイルをダウンロードします。

この拡張機能は、claude.aiでのみ動くChromeのコンテンツスクリプトです。パーサーは、ログイン済みのセッションにすでに読み込まれている会話を読み取ります。独自の認証情報で別のAnthropic APIを呼び出すことはなく、ファイルを作るためにスレッドを当方のサーバーへアップロードすることもありません。

最初のエクスポートの前にGoogleサインインが必要です。これはアカウントごとに3回の無料エクスポートを数え、後でProを復元するためのものです。Googleサインインはチャットを読むためのログインではありません。保存するのは無料枠とサブスクリプションの状態を管理するための、Googleで確認されたメールアドレスだけです。会話の本文はお使いのパソコンから出ません。

完成したファイルは、MarkdownでもPNGでも1件につき1回のエクスポートとして数えます。無料アカウントは合計3回までです。Proは月額$3.99または年額$26.99で、1件ずつのチャットにも一括の「Export All」にも上限がなくなります。Proの支払いはPaddleが処理し、当方がカード番号を見ることはありません。

ファイルはローカルで作成。Markdown、JSON、テキスト、XML、PNGはブラウザ内で作られ、Chromeのダウンロード機能に渡されます。当方のサーバーに届くのは利用回数の確認だけで、チャットの本文は送られません。バージョン1.13.0はChrome Web Storeで評価5.0です。

同じウィジェットには任意の切り替えもあります。拡張思考を含めるかどうか、メタデータ（タイトル、タイムスタンプ、モデル）を含めるかどうか、送信者での絞り込み（「all / human only / assistant only」＝すべて／ユーザーのみ／アシスタントのみ）、アーティファクトの配置（「Original」「Inline」「Nested」「Flat」＝元の配置／インライン／入れ子／フラット）です。これらの設定は、一括の一覧ページと同じようにこの1件のチャットにも適用されます。

スレッドがとても長い場合は、claude.aiが前半のメッセージを読み込むまでスクロールしてください。拡張機能がエクスポートできるのは、ページに表示済みの内容だけです。途中までしか読み込まれていないスレッドからは途中までのファイルができます。不具合に見えますが、たいていはスクロールが足りていないだけです。

「Export」の前に、アシスタントの回答が最後まで生成されるのを待ってください。生成の途中で保存すると、最後の回答が途切れたファイルになります。無料プランでは2回目も1回分として数えられるので、先にスレッドが完成しているか確認してください。

最後に使った形式は記憶されます。MarkdownのつもりがJSONで保存された場合は、前回のエクスポートの設定がJSONのままだったということです。目的が変わるたびに、形式の選択を確認してください。同じオレンジ色のボタンの手順をスクリーンショット付きで説明したページ：Claudeのチャットをダウンロードする方法。

同じ勘違いを毎週のように耳にします。履歴は消えてしまう下書きだと思って、保存ボタンを探してしまうのです。claude.aiはすでにスレッドを保存しています。私たちのオレンジ色のボタンは、あなたが開いたページからMarkdown、JSON、テキスト、XML、PNGのローカルファイルを書き出すだけです。PDF形式をでっち上げることはしません。

拡張機能なしでClaudeの会話を保存するには？

拡張機能なしでClaudeの会話を保存するには、claude.aiのページを印刷するか、Anthropicの「Export data」のZIPを申請します。印刷はWebページの見た目をPDFにしたものです。「Export data」は、アカウント全体のJSONアーカイブが後から届く仕組みです。どちらもチャットごとのMarkdownファイルは作りません。

印刷の手順：claude.aiで会話を開き、可能ならサイドバーを隠してから、Ctrl+P（Windows/Linux）またはCmd+P（Mac）を押し、送信先を「PDFに保存」にして保存します。入力欄などの画面要素が毎ページに入ることがあります。印刷の詳しい注意点はClaudeのチャットをPDFで保存する方法にまとめています。

公式の手順：claude.aiでSettings → Privacy → Export dataを開きます。Anthropicから有効期限付きのリンクがメールで届きます。何千もの会話から1件だけ必要なら、ZIPを自分で展開してください。このアーカイブは記録保管用のバックアップであり、明日の朝会で使うメモではありません。

コピー＆ペーストなら、何もインストールせずに使えます。claude.aiでやり取りを選択し、メモアプリに貼り付けます。コードのインデントはたいてい崩れ、何往復もあるスレッドは構造のない文字の塊になります。コピー＆ペーストは短い抜粋1つに使い、会話を保存する唯一の手段にはしないでください。

タブを閉じた後も履歴に会話は残りますか？

はい。サインイン中に作った会話であれば、タブを閉じても、claude.aiを再読み込みしても、パソコンを閉じても、履歴に残ります。タブを閉じることは削除ではありません。スレッドをアカウントの画面から消すのは、履歴からの削除です。

claude.aiからログアウトすると、ページには何も表示されなくなります。同じAnthropicアカウントにログインし直せば、履歴にチャットが戻ってきます。ログアウトは一覧を隠すだけで、それ自体でアカウントに保存された内容が消えるわけではありません。別のAnthropicログインでは別の履歴が表示されます。

実際に会話が消えるのは、履歴から削除したときです。claude.aiの画面で会話を削除すると、そのスレッドはサイドバーから消えます。オレンジ色のボタンですでにエクスポートしたMarkdownファイルはディスクに残ります。チャットを整理する予定があるなら、先にエクスポートしてください。

削除は「閉じる」とは違います。claude.aiのタブを閉じても履歴はそのままです。履歴から会話を削除すると、チャットはアカウントの画面から消えます。Anthropicがそのスレッドをもう含めていなければ、削除後に公式の「Export data」を使っても取り戻せません。整理する前にファイルを書き出してください。

シークレットモードはウィンドウを閉じると終わります。継続的なログインなしにプライベートウィンドウでclaude.aiを使った場合、履歴に作業が残っているとは限りません。通常のChromeプロファイルでサインインするか、シークレットのセッションが終わる前にファイルをエクスポートしてください。

TeamやEnterpriseでは、ワークスペースの管理者がチャットを保持したり制限したりできます。自分が設定していないポリシーによって、後からスレッドが見えなくなることもあります。会社の履歴は借り物の保管場所と考え、エクスポートしたMarkdownやJSONのファイルをポリシーの外にある自分側のコピーとして扱ってください。

スマートフォンからパソコンに切り替えるときも、両方で同じAnthropicアカウントを使っていれば、特別な保存操作は不要です。パソコンで履歴を開いてください。チャットが見当たらない場合は、「保存されていない」のではなく、別のログインや別のワークスペースを使っているか、スレッドが削除されています。

Claude Desktopも、同じAnthropicユーザーでログインしていれば、同じアカウントのチャットを表示することがあります。同期はAnthropic側の仕組みです。Chrome拡張機能がDesktopに組み込まれることはありません。スレッドがclaude.aiにあるなら、Chromeでclaude.aiを開いてファイルを書き出してください。

Claudeの会話をMarkdownやJSONで保存するには？

Claudeの会話をMarkdownやJSONで保存するには、claude.aiでオレンジ色のボタンを開いて形式を選び、「Export」をクリックします。Markdownはメモ用のファイル、JSONはスクリプト向けのメッセージツリーです。プレーンテキストにはマークアップがありません。PNGは画像で、PDFではありません。

Markdownは見出し、言語タグ付きのコードブロック、表を保持します。Obsidian、GitHub、社内Wikiに入れるならまずMarkdownです。この形式のレイアウトについて：Markdownエクスポート。JSONはパーサーが組み立てたツリーをそのまま残し、切り替えをオンにしていればアーティファクトや思考も含みます。

この拡張機能のJSONは、AnthropicのアカウントZIPとは構造が異なります。拡張機能のJSONは、ページに表示されたとおりの1件の会話です。「Export data」のJSONは、Anthropicが後からメールで届けるアカウント全体のデータです。キーを確認せずに、2つのスキーマを1つのスクリプトで混ぜて扱わないでください。

保存先がマークアップを取り除く場合は、プレーンテキストが適しています。チケット管理ツールの入力欄、メール本文、生の文字列を扱う検索インデックスなどです。XMLはデータ交換用の特殊な選択肢です。PNGはスライドやバグ報告に貼るスレッドの図に向いており、後でgrepする40往復のレビューには向きません。

思考、メタデータ、送信者フィルター、アーティファクトの配置によって、MarkdownやJSONに入る内容が変わります。拡張思考の推論もアーカイブに残したいなら思考をオンに、最終的な回答だけを読み手に見せたいならオフにします。メモのファイルに見出し情報を付けたいときは、メタデータでタイトル、タイムスタンプ、モデルを追加できます。

送信者フィルターの「human only」（ユーザーのみ）はあなたのプロンプトを、「assistant only」（アシスタントのみ）はClaudeの返答を書き出します。「all」（すべて）は既定のスレッド全体です。アーティファクトの配置「Original / Inline / Nested / Flat」（元の配置／インライン／入れ子／フラット）で、Markdown内でのアーティファクトの置き方が変わります。配置を一度決めて使い続ければ、保存したチャットのフォルダーの体裁がそろいます。

Claudeのチャット履歴を一括で保存するには？

Claudeのチャット履歴を複数のファイルで保存するなら、タブごとにオレンジ色のボタンを押す必要はありません。拡張機能のポップアップから「View and Download All Conversations」を開き、一覧を絞り込んでから「Export All」をクリックします。Proでない場合、完成したファイルはそれぞれ同じ3回の無料枠に含まれます。

一覧ページには、ログイン中のclaude.aiアカウントの会話が表示されます。すでにある履歴が、絞り込みのできる表になったものです。名前で検索でき、All（すべて）、New（未エクスポート）、Exported（エクスポート済み）で絞り込めるほか、claude.aiでプロジェクトごとにチャットを分けていればProjectでも絞り込めます。

一括エクスポートでも、1件のエクスポートと同じ5つの形式と同じ切り替え（思考、メタデータ、送信者フィルター、アーティファクトの配置）が使えます。「Export All」は簡易版の処理ではなく、同じパーサーを多数の会話IDにまとめて適用するものです。詳細：一括の「Export All」。

Anthropicの「Export data」は、引き続きアカウントのバックアップとして役立ちます。ZIPが1つ、メールが1通、すべてがJSONで、忘れていたチャットも含まれます。一括の「Export All」はその逆で、履歴のどの行かを選び、MarkdownかJSONかを選べば、ファイルがすぐに保存されます。記録保管用のアーカイブと、読みやすいメモのフォルダーの両方が欲しいなら、両方を使ってください。

無料枠は共通です。3回の無料エクスポートは、1件ずつのチャットと一括のファイルを合わせた回数です。無料アカウントで40件の会話を選んでも、3件目のファイルで止まります。選ぶ会話を計画するか、Paddle経由でPro（月額$3.99または年額$26.99）にアップグレードしてください。

一覧はエクスポート済みの会話も記録しているため、次に開いたときはNew（未エクスポート）だけに絞り込めます。こうすれば、毎週Claudeのチャットを保存する習慣も、先月のMarkdownを重複させずに差分だけで続けられます。拡張機能を再インストールしても3回の回数はリセットされません。回数はGoogleでサインインしたアカウントに紐付いています。

履歴が1行だけの下書きでいっぱいなら、一部だけを選択してください。「Export All」だからといって、すべての行を書き出す必要はありません。しっかり絞り込んでMarkdownで書き出せば、「こんにちは」だけの200件のスレッドより整った研究用フォルダーになります。

「エクスポート」という言葉で探している場合も、使うのは同じオレンジ色のボタンと同じ「Export All」の一覧です。「保存」ではなく「エクスポート」で探してたどり着いた方には、隣のページClaudeのチャットをエクスポートでこれらの操作を整理しています。

Claude DesktopやClaude Codeの会話も保存できますか？

いいえ。Download Claude conversationsでは、Claude DesktopやClaude Codeの会話は保存できません。このChrome拡張機能が動作するのはデスクトップ版Chromeのclaude.aiだけです。Claude Desktopは別のアプリで、Claude Codeは/exportとディスク上のJSONLを持つターミナルのエージェントです。

Desktopのチャットがclaude.aiにもあるなら、そのURLをChromeで開いてオレンジ色のボタンを使ってください。スレッドがDesktopにしかない場合は、コピー＆ペーストするか、Settings → Privacy → Export dataを待ちます。拡張機能がDesktopのウィンドウに組み込まれることはありません。

Claude Codeのセッション中に/exportと入力すると、AnthropicのCLIがメニューを開き、トランスクリプトをコピーするか、プレーンテキストのファイルとして保存するかを選べます。ファイル名を指定すればメニューは省略されます。このトランスクリプトは人が読むためのテキストで、この拡張機能のMarkdown/JSON/PNGとは別物です。パスの詳細：Claude Codeのエクスポート。

ディスク上のJSONLは、~/.claude/projects（Windowsでは%USERPROFILE%\.claude\projects）にある内部ログです。スキーマはClaude Codeのバージョンによって変わることがあります。Anthropic自身のドキュメントでも、JSONLを解析するより/exportを使うよう勧めています。当方はそのCLIをラップしておらず、~/.claudeを読み取ることもありません。

TeamやEnterpriseのワークスペースでも、Chromeでclaude.aiの会話を開ければこの拡張機能を使えます。パーサーは表示されたページを読み取り、個人向けプラン専用のAPIには依存しません。会社のポリシーで拡張機能がブロックされている場合、それはIT部門の判断であり、当方の設定でプランを切り替えて解決するものではありません。

Anthropic, PBCとは提携していない独立したChrome拡張機能です。ClaudeはAnthropicの商標です。Anthropicの利用規約に従ってください。特定のエクスポートが勤務先で許可されているかどうかについて法的な助言はできません。この拡張機能はWebサイトと同じように既存のセッションを使い、アカウント操作を自動化しません。

Proの請求はPaddleが行います。Googleサインインで会話へのアクセス権が当方に渡ることはありません。Proの状態を確認するCloudflare Workerが受け取るのはライセンスの状態で、メッセージの本文ではありません。課金はサーバーに、チャットはディスクに。この境界線が、この製品で保存するすべての会話ファイルに共通するプライバシーの考え方です。

よくある質問：Claudeの会話を保存する方法

Claudeの会話をファイルとして保存するには？

Download Claude conversationsをインストールし、claude.aiでスレッドを開き、メッセージ入力欄の横にあるオレンジ色のボタンをクリックします。Markdown、JSON、テキスト、XML、PNGから選び、「Export」（エクスポート）をクリックすれば、ファイルが手元に保存されます。チャット自体はすでにAnthropicアカウントの履歴に残っており、オレンジ色のボタンはそのコピーをディスクに書き出すものです。

claude.aiでClaudeのチャットを保存するには？

スレッドをアカウントに残すだけなら、保存ボタンは必要ありません。サインインして使ったチャットは、claude.aiの履歴にすでに並んでいます。チャットをファイルとして保存したい場合は、Chrome拡張機能、印刷 →「PDFに保存」、またはSettings → Privacy → Export data（アカウント全体のJSON ZIPが後から届きます）を使います。

拡張機能なしでClaudeの会話を保存するには？

見た目を残すならclaude.aiのページを印刷（Ctrl/Cmd+P →「PDFに保存」）し、アカウント全体のJSON ZIPをメールで受け取るならSettings → Privacy → Export dataを使います。短い回答ならコピー＆ペーストでも十分です。ただし、どの方法もChrome拡張機能のようにチャットごとの構造化されたMarkdownファイルは作れません。

Claudeの会話は履歴に自動で保存されていますか？

はい。claude.aiでサインインして使ったチャットは、Anthropicアカウントの履歴に残ります。タブを閉じても、再読み込みしても、同じログインで別の端末を開いても、スレッドは消えません。ただし履歴は、ディスク上のMarkdown、JSON、テキスト、XML、PNGのファイルではありません。

タブを閉じるとClaudeの会話は消えますか？

いいえ。claude.aiのタブを閉じても、会話が履歴から削除されることはありません。履歴からチャットを削除すると、アカウントの画面からは消えます。Download Claude conversationsですでにエクスポートしたファイルは、削除後もディスクに残ります。

Claudeの会話をPDFで保存できますか？

Download Claude conversations 1.13.0ではできません。形式はMarkdown、JSON、プレーンテキスト、XML、PNGです。PDFのようなスナップショットが必要なら、claude.aiのページを印刷してください。PNGはスレッドの画像で、PDFではありません。

Claudeの会話は何ファイルまで無料で保存できますか？

Googleでサインインしたアカウントごとに、5つの形式のいずれかで3回まで無料でエクスポートできます。それ以降はProが月額$3.99または年額$26.99です。支払いはPaddleが処理します。一括の「Export All」で作成したファイルも同じ3回に含まれます。

スマートフォンでもClaudeの会話を保存できますか？

Chrome拡張機能は使えません。動作するのはデスクトップ版Chrome（またはChrome Web Storeの拡張機能をインストールできる他のChromium系ブラウザ）です。iOSやAndroidのアプリはありません。モバイルブラウザでも履歴を開いてClaudeのチャットを印刷することはできますが、オレンジ色のボタンは表示されません。

履歴にあるClaudeのチャットを一括で保存できますか？

はい。拡張機能のポップアップから「View and Download All Conversations」（すべての会話を表示・ダウンロード）を開き、一覧を絞り込んでから「Export All」（すべてエクスポート）をクリックします。この一括保存はAnthropicの「Export data」のZIPとは別物です。公式の「Export data」は、アカウント全体をひとつのアーカイブにして後からメールで届けるものです。詳しくは一括ダウンロードをご覧ください。

Claude Codeの会話も保存できますか？

いいえ。Claude Codeはターミナルで動きます。/exportを使うか、~/.claude/projects（Windowsでは%USERPROFILE%\.claude\projects）からJSONLをコピーしてください。このChrome拡張機能はclaude.aiでのみ動作します。ガイド：Claude Codeのエクスポート。

Claudeのチャットを保存するのにGoogleサインインは必要ですか？

はい、最初のエクスポートから必要です。選んだアカウントをGoogleが確認することで、3回の無料枠を管理し、再インストール後にProを復元できます。このサインインで会話の内容が送られることはありません。確認済みのメールアドレスは、無料枠とProの状態の管理にだけ保存します。

Claudeのチャットを保存する公式の「Export data」はどこにありますか？

claude.aiのSettings → Privacy → Export dataです（claude.aiを日本語表示にしている場合、メニュー名は日本語で表示されることがあります）。Anthropicから有効期限付きのリンクがメールで届きます。ZIPはアカウント単位のJSONアーカイブで、読んでいたチャットの名前が付いたMarkdownファイルではありません。「Export data」はバックアップとして使い、読みやすいファイルを今すぐ1つ作るならオレンジ色のボタンを使ってください。
