Claudeの会話をMarkdown、JSON、テキスト、XML、PNGで保存

Claude.aiには、チャットを1件ずつダウンロードする標準のボタンがありません。Download Claude conversations（Claude Chat DownloaderやClaude Conversation Downloaderとも呼ばれる無料のChrome拡張機能）を使えば、開いているチャットや会話履歴の全体をMarkdown、JSON、プレーンテキスト、XML、PNGでエクスポートできます。ファイルはブラウザ内で作成されます。詳しくはClaudeのチャットをダウンロードする方法をご覧ください。ターミナルを使っている場合は、この拡張機能ではなくClaude Codeのエクスポートが該当します。

Claudeのチャットをダウンロードする6つの主要機能

01

Markdown、JSON、XML、テキスト、PNGでエクスポート

Claudeのチャットを、ページのスクリーンショットではなく実際のファイルとしてダウンロードします。メモにはMarkdown、開発にはJSON、最もシンプルな保管にはプレーンテキスト、データ交換にはXML、見た目を残すならPNGが便利です。

02

Claudeのチャットを一括ダウンロード

View and Download All Conversations（すべての会話を表示・ダウンロード）を開くと会話履歴が一覧表示され、名前で検索したりプロジェクトで絞り込んだりしてからExport All（すべてエクスポート）をクリックできます。タブを1つずつ開く必要はありません。

03

コード、表、アーティファクトをそのまま保持

エクスポートエンジンがメッセージツリーを解析するため、コードブロックのインデントは保たれ、表は表のまま残ります。アーティファクトは「Original」「Inline」「Nested」「Flat」（元の配置／インライン／入れ子／フラット）から選べます。

04

思考ブロックとメタデータは任意

記録として残したいときはClaudeの拡張思考を含め、不要なら省けます。タイトル、タイムスタンプ、モデルのメタデータも同じファイルに含められます。

05

エクスポート前に検索・絞り込み

一覧を新しいチャット、エクスポート済みのチャット、Claudeのプロジェクトで絞り込み、選んだものだけをエクスポートできます。

06

ブラウザ内でローカルに作成

会話の内容はお使いの端末上で組み立てられ、ディスクにダウンロードされます。Googleサインインは無料エクスポート回数の管理に使うもので、チャットの本文を当方のサーバーへアップロードするためのものではありません。

よくある質問

claude.aiからClaudeの会話をダウンロードできますか？

標準のボタンではできません。Chrome Web StoreからDownload Claude conversationsをインストールし、チャットを開いてファイルをエクスポートします。

Claude公式の「Export data」と同じものですか？

いいえ。Anthropic公式のSettings → Privacy → Export dataは、アカウント全体のZIP（JSON）をメールで送る機能です。この拡張機能は、開いているチャットや一括で選んだチャットを、読みやすいファイルとしてすぐにダウンロードします。

Claudeのチャットは保存されますか？

エクスポートはブラウザ内で実行され、会話の内容を当方が受け取ることはありません。保存するのはGoogleで確認されたメールアドレスだけで、無料エクスポート回数の管理とProサブスクリプションの紐付けに使います。

「Claude チャット ダウンロード」と「Claude 会話 ダウンロード」の違いは何ですか？

やりたいことは同じで、言い方が違うだけです。どちらの場合も、claude.aiのオレンジ色のボタンを使います。

PDFでエクスポートできますか？

いいえ。現在の形式はMarkdown、JSON、プレーンテキスト、XML、PNGです。見た目どおりのPDFがすぐに必要ならページを印刷（Ctrl/Cmd+P →「PDFに保存」）するか、Markdownでエクスポートしてから変換してください。詳しい手順はClaudeのチャットをPDFで保存する方法にあります。

Claude Pro / Teamでも使えますか？

はい。claude.aiの会話をブラウザで開ける状態であれば使えます。当方はAnthropicではありません。

Claudeの会話を保存するにはどうすればよいですか？

無料のChrome拡張機能をインストールし、claude.aiでチャットを開いて、オレンジ色のボタンをクリックし、形式を選びます。これがClaudeの会話を実際のファイルとして保存する方法です。ほかにはPDFとして印刷する方法と、Anthropicのアカウント全体のZIPを使う方法があります。比較はClaudeのチャットをダウンロードする方法をご覧ください。

Claude Codeの会話もダウンロードできますか？

いいえ。この拡張機能はChrome上のclaude.aiでのみ動作します。Claude Codeのセッションは/exportか、ディスク上のJSONLファイルを使います。詳しくはClaude Codeのエクスポートをご覧ください。

Download Claude conversationsはAnthropicと提携していますか？

いいえ。ClaudeはAnthropic, PBCの商標です。これは独立したChrome拡張機能であり、Anthropicの公式製品ではありません。
