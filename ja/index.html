Claudeのチャットを3ステップでダウンロードする方法

    拡張機能を追加する

    Chrome Web StoreからDownload Claude conversationsをインストールして、ツールバーに固定します。10秒ほどで終わります。

  2. 2

    claude.aiでチャットを開く

    メッセージ入力欄の右に、オレンジ色のダウンロードボタンが表示されます。多くのチャットをまとめて保存するなら、View and Download All Conversations（すべての会話を表示・ダウンロード）を開きます。

  3. 3

    形式を選んでエクスポートする

    PDF、Markdown、JSON、テキスト、CSV、XML、PNGから選び、Export（エクスポート）をクリックします。アカウントは不要です。Googleサインインを求められるのは、PDFと一括エクスポートのときだけです。

Claudeのチャットをダウンロードする6つの主要機能

01

PDF、Markdown、JSON、CSVなどでエクスポート

Claudeのチャットを、ページのスクリーンショットではなく実際のファイルとしてダウンロードします。読んだり共有したりするにはPDF、メモにはMarkdown、開発にはJSON、表計算にはCSV、最もシンプルな保管にはプレーンテキスト、データ交換にはXML、見た目を残すならPNGが便利です。Copy（コピー）を押せば、結果をクリップボードに入れることもできます。

02

Claudeのチャットを一括ダウンロード

View and Download All Conversationsを開くと会話履歴が一覧表示され、名前で検索したり、プロジェクトやCoworkで絞り込んだりしてからExport All（すべてエクスポート）をクリックできます。タブを1つずつ開く代わりに、1つのZIPにまとまります。無料プランでは1日3チャットまで、Proなら無制限です。

03

コード、表、アーティファクトをそのまま保持

エクスポートエンジンがメッセージツリーを解析するため、コードブロックのインデントは保たれ、表は表のまま残ります。アーティファクトは「Original」「Inline」「Nested」「Flat」（元の配置／インライン／入れ子／フラット）から選べます。

04

ファイルに含める内容を選べる

スレッド全体、自分のプロンプトだけ、Claudeの回答だけ、またはSelect（選択）でチェックしたメッセージだけをエクスポートできます。記録として残したいときは拡張思考を含め、不要なら省けます。タイトル、タイムスタンプ、モデルのメタデータも同じファイルに含められます。

05

エクスポート前に検索・絞り込み

一覧を新しいチャット、エクスポート済みのチャット、Claudeのプロジェクトで絞り込み、選んだものだけをエクスポートできます。

06

ブラウザ内でローカルに作成

PDFを含むすべてのファイルは、お使いの端末上で組み立てられ、ディスクにダウンロードされます。ほとんどのエクスポートにアカウントは要りません。Googleサインインは、PDFと一括エクスポートの回数を数え、Proサブスクリプションを紐付けるためだけのもので、チャットの本文を当方のサーバーへアップロードすることはありません。

よくある質問

claude.aiからClaudeの会話をダウンロードできますか？

標準のボタンではできません。Chrome Web StoreからDownload Claude conversationsをインストールし、チャットを開いてファイルをエクスポートします。

Claudeのチャットは無料でダウンロードできますか？

はい。Markdown、プレーンテキスト、JSON、XML、CSV、PNGのエクスポートは回数無制限で、アカウントも要りません。PDFと一括ZIPのエクスポートはGoogleサインインが必要で、1日3回まで無料です。Pro（月額$3.99または年額$26.99）なら、この上限がなくなります。

どのブラウザで使えますか？

パソコン版のChromeと、Chrome Web Storeから拡張機能をインストールできるChromiumベースのブラウザで使えます。モバイルアプリはなく、Claude Desktopの中では動作しません。

Proはどうやって解約できますか？返金は受けられますか？

拡張機能のオプションページ（「Cancel subscription」＝サブスクリプションを解約）またはPaddleから、いつでも解約できます。初回のお支払いには14日間の返金保証があり、理由は問いません。

Claude公式の「Export data」と同じものですか？

いいえ。Anthropic公式のSettings → Privacy → Export dataは、アカウント全体のZIP（JSON）をメールで送る機能です。この拡張機能は、開いているチャットや一括で選んだチャットを、読みやすいファイルとしてすぐにダウンロードします。

Claudeのチャットは保存されますか？

いいえ。PDFを含むすべての形式はブラウザ内で作成され、会話のテキストが当方のサーバーに届くことはありません。PDF、一括エクスポート、ProのためにGoogleでサインインした場合は、そのメールアドレスを、1日の回数の管理とサブスクリプションの紐付けのためだけに保存します。

「Claude チャット ダウンロード」と「Claude 会話 ダウンロード」の違いは何ですか？

やりたいことは同じで、言い方が違うだけです。どちらの場合も、claude.aiのオレンジ色のボタンを使います。

PDFでエクスポートできますか？

はい。エクスポートパネルでPDFを選び、用紙サイズ、余白、ライト／ダークモード、フォント、ページ番号、目次を設定します。PDFにはGoogleサインインが必要です。無料プランではPDFまたは一括エクスポートが1日3回まで、Proなら無制限です。詳しい手順はClaudeのチャットをPDFで保存する方法にあります。

Claude Pro / Teamでも使えますか？

はい。claude.aiの会話をブラウザで開ける状態であれば使えます。当方はAnthropicではありません。

Claudeの会話を保存するにはどうすればよいですか？

無料のChrome拡張機能をインストールし、claude.aiでチャットを開いて、オレンジ色のボタンをクリックし、形式を選んでExportをクリックします。Markdown、テキスト、JSON、XML、CSV、PNGならアカウントは要りません。これがClaudeの会話を実際のファイルとして保存する方法です。ほかにはページを印刷する方法と、Anthropicのアカウント全体のZIPを使う方法があります。比較はClaudeのチャットをダウンロードする方法をご覧ください。

Claude Codeの会話もダウンロードできますか？

claude.ai上のものだけです。Claude Code on the web（claude.ai/code）とCoworkのセッションは、ほかのチャットと同じようにエクスポートできます。ローカルのターミナルのセッションは拡張機能では読み取りません。/exportか、ディスク上のJSONLファイルを使います。詳しくはClaude Codeのエクスポートをご覧ください。

Download Claude conversationsはAnthropicと提携していますか？

いいえ。ClaudeはAnthropic, PBCの商標です。これは独立したChrome拡張機能であり、Anthropicの公式製品ではありません。
