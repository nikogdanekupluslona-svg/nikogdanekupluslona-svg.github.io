ClaudeのチャットをMarkdownでエクスポートするには？

Chromeでclaude.aiの会話を開き、メッセージ入力欄の横にあるオレンジ色のボタンをクリックして、Markdownを選び、「Export」をクリックします。Download Claude conversationsが .md ファイルをローカルで書き出します。これが、バージョン1.16.2でClaudeのチャットをMarkdownで出力する方法です。

  1. Chrome Web StoreからDownload Claude conversationsをインストールします。
  2. claude.aiを再読み込みし、空の入力画面のホームではなく、実際の会話のURLを開きます。
  3. メッセージ入力欄の右にあるオレンジ色のダウンロードボタンをクリックします。
  4. Markdownを選びます。拡張機能は最後に使った形式を記憶します。必要なメッセージだけにチェックを入れるなら、「Select」（選択）を使います。
  5. 「Export」をクリックします。Chromeがブラウザのダウンロード機能で .md ファイルを保存します。「Copy」（コピー）をクリックすれば、Markdownをクリップボードに入れることもできます。

ClaudeのチャットをMarkdownでエクスポートするのに、ログインは不要です。1つのチャットのMarkdownエクスポートは無制限・匿名で、私たちのサーバーには何も送りません。Googleログインを求められるのは、PDFと一括の「Export All」（すべてエクスポート）だけです。仕組み：仕組み。

オレンジ色のボタンが見当たらない場合は、会話のURLを開いていないか、インストール後にタブの再読み込みが必要か、拡張機能がまだChromeのパズルのメニューに隠れています。Download Claude conversationsを固定してから、claude.aiを再読み込みしてください。コンテンツスクリプトがClaude DesktopやClaude Codeのターミナルに組み込まれることはありません。

1つのチャットか、たくさんか。オレンジ色のボタンは、開いているスレッドをMarkdownでエクスポートします。多数の .md ファイルが必要なら、「View and Download All Conversations」（すべての会話を表示してダウンロード）を開き、Markdownを選んで「Export All」を実行します。ZIPは1つで、無料プランでは1日3チャットまでです。「Export All」で一括エクスポートをご覧ください。

メモ用にMarkdownでエクスポートする理由は？

Obsidian、GitHubのWiki、見出しやコードブロックを表示できるエディターでファイルを読むなら、Markdownでエクスポートしましょう。.md ファイルはプレーンテキストでもあるので、検索も差分も取れます。パーサーで処理するならJSONのほうが向いています。PNGは画像なので、grepで検索できません。

claude.aiからコピー＆ペーストすると、たいていインデントが消え、表が崩れます。印刷（Ctrl/Cmd+P）ではサイドバーが残り、長いコードブロックがページをまたいで分割されがちです。Markdownでエクスポートすれば、コードブロックの言語タグは残り、表は表のままです。文章を書く人がまずこの形式を選ぶのはそのためです。

私たちはMarkdownを、人が読むための標準のファイルと考えています。claude.aiのスレッドの見出し、言語タグ付きのコードブロック、表をそのまま残します。ページ形式が必要なら、同じパネルでPDFを選んでください。ページサイズ、余白、目次を指定して、ブラウザの中でレイアウトされます。

Markdownのエクスポートで何が残る？

ClaudeのチャットをMarkdownでエクスポートすると、Download Claude conversationsは、見出し、言語タグとインデントを保ったコードブロック、表、リンクを残します。思考プロセス、Web検索のソース、ツール／MCPのステップは、それぞれ任意です。思考プロセスはエクスポートパネルの「Thinking」（思考）のチェックボックスで、残りの2つは設定（Settings）でオンにします。メタデータ（タイトル、タイムスタンプ、モデル）も含められます。送信者フィルターで、.md ファイルの中身をすべてのメッセージ、人間のみ、アシスタントのみ（「All」「Human」「Assistant」）に絞れます。

バージョン1.16.2では、アーティファクトのレイアウトを実際に切り替えられます。「Original」「Inline」「Nested」「Flat」（元のまま／インライン／入れ子／フラット）です。Markdownのエクスポートで、画面上のアーティファクトの構造をそのまま再現することも、1つの直線的な文書に平らにすることも、アーティファクトをZIPの中の専用フォルダーに分けることもできます。設定で、画像を .md ファイルに埋め込むこともできます。一覧：Chrome拡張機能の機能。Markdownではメッセージの吹き出しの色は残りません。見た目のスナップショットならPNGを、ページ形式ならPDFを使ってください。

ClaudeのチャットをMarkdownで一括エクスポートできる？

はい。「View and Download All Conversations」を開き、「Chat format」（チャット形式）をMarkdownにして、一覧を絞り込み、「Export All」をクリックします。Chromeが、チャットごとに1つの .md ファイルが入ったZIPを1つ保存します。無料プランではGoogleログインで1日3チャットまでで、この枠はPDFと共通です。Pro（月額$3.99または年額$26.99）なら、Markdownの一括エクスポートにも上限はありません。

ダッシュボードにはclaude.aiの履歴が表示され、名前での検索、「All conversations」「New」「Updated」「Previously exported」（すべての会話／新規／更新あり／エクスポート済み）のフィルター、「Chat」と「Cowork」のタブ、プロジェクトの検索が使えます。「New」はDownload Claude conversationsでまだエクスポートしていないもの。「Previously exported」は保存済みのチャットを記録し、2回目の「Export All」でそれらを飛ばせるようにします。

1日の上限はアカウント単位です。無料プランでは1日3チャットまでで、この枠はPDFと共通です。残りが3回のときに40件の会話を選ぶと、途中で切られるのではなく、全体がブロックされます。選ぶ数を減らすか、Proを使ってください。オレンジ色のボタンからの .md ファイル単体のエクスポートは、引き続き無制限です。

Markdownの一括エクスポートでは、ダッシュボードのチェックボックス「Chats」「Thinking」「Metadata」「Tools」「Sources」（チャット、思考、メタデータ、ツール、出典）と、アーティファクトの形式を使います。「Export All」は、Anthropicから時間をおいて届くZIPではありません。チャットごとの .md ファイルを収めた1つのZIPです。アカウント全体を1つのアーカイブにしたいなら、それは Settings → Privacy → Export data（claude.aiを日本語で表示している場合、ラベルは翻訳されていることがあります）で、中身はMarkdownではなくJSONです。

Claudeのチャットのエクスポート、MarkdownとJSONのどちらがいい？

人が読むファイルならMarkdownでエクスポートします。スクリプトでメッセージのツリーを解析するならJSONでエクスポートします。Download Claude conversationsでは、1つのドロップダウンで両方に加え、PDF、プレーンテキスト、XML、CSV、PNGも選べます。形式の一覧：Claudeのチャットのエクスポート形式。

PNG スレッドの画像。検索できるテキストではない

AnthropicのデータエクスポートもJSONですが、メールで届くアカウントのZIPであり、チャットごとの .md ファイルではありません。そのリクエストでMarkdownを選ぶことはできません。ブラウザの印刷は、Webページのスナップショットです。どちらも、オレンジ色のボタンでMarkdownにエクスポートする代わりにはなりません。

拡張機能が動くのは、Chromeで開いたclaude.aiだけです。Claude DesktopやClaude CodeのターミナルにMarkdownのボタンはありません。Claude Code on the web（claude.ai/code）はclaude.ai上で動くので、ほかのチャットと同じようにエクスポートできます。スレッドがclaude.aiにもあれば、そこで開いてMarkdownでエクスポートしてください。ターミナルのClaude Codeの /export は別の製品の機能です。

Markdownでのエクスポートに追加料金はかかる？

いいえ。1つのチャットのMarkdownエクスポートは、JSON、テキスト、XML、CSV、PNGと同じく無料・無制限で、アカウントも回数のカウントもありません。無料の上限があるのはPDFと一括の「Export All」だけで、Googleログインで1日3回までです。Paddle経由のProは月額$3.99または年額$26.99です。Markdownだけの追加料金はありません。

上限が関係するのは、Markdownの一括エクスポートです。「Export All」のZIPに入るチャット1件ごとに1日3回の枠を1回使い、回数はUTCの午前0時にリセットされます。Proならこの上限はなくなり、同じGoogleアカウントなら新しいパソコンでも復元されます。Paddleが販売者（Merchant of Record）であり、私たちがカード番号を見ることはありません。

Anthropicのclaude.aiの有料プランは必要ありません。Chromeで会話を読み込めるログインがあれば十分です。オレンジ色のボタンは、TeamやEnterpriseでもFreeと同じように使えます。バージョン1.16.2（2026年9月）でも、WordやNotionには出力しません。

Markdownでエクスポートするとコードは失われますか？

いいえ。claude.aiから単純にコピー＆ペーストする場合と違い、コードブロックは言語タグとインデントを保ちます。表もMarkdownの表のままです。手作業でテキストを選択するのではなく、ClaudeのチャットをMarkdownでエクスポートする一番の理由です。

ClaudeのチャットをMarkdownで一括エクスポートできますか？

はい。ダッシュボードの「Export All」はMarkdownに対応していて、.md ファイルを1つのZIPにまとめて保存します。無料プランではGoogleログインで1日3チャットまで、Proなら無制限です。

MarkdownはAnthropicのデータエクスポートと同じですか？

いいえ。Anthropicの公式エクスポートは、アカウント全体のJSONのZIPで、しばらく待った後にメールで届きます。Markdownでのエクスポートは、Download Claude conversationsによるチャットごと（または選択範囲ごと）の .md ファイルです。

Markdownはほかの形式より料金が高いですか？

いいえ。1つのチャットのMarkdownエクスポートは、JSON、テキスト、XML、CSV、PNGと同じく無制限で、アカウントも要りません。無料の上限（1日3回）があるのはPDFと一括ZIPだけです。Proは月額$3.99または年額$26.99です。

DesktopでClaudeのチャットをMarkdownでエクスポートできますか？

いいえ。Download Claude conversationsが組み込まれるのは、Chromeで開いたclaude.aiだけです。Claude DesktopにMarkdownのドロップダウンは表示されません。同じスレッドがclaude.aiにあれば、そこで開いてください。

MarkdownでエクスポートするとPDFができますか？

いいえ。Markdownは .md のテキストファイルです。ページ形式が必要なら、同じパネルでPDFを選んでください。ページサイズ、余白、目次を指定して、ブラウザの中で作成されます。PDFにはGoogleログインが必要で、無料プランでは1日3回の枠に数えられます。

1回だけMarkdownでエクスポートするのにProは必要ですか？

いいえ。アカウントもまったく要りません。無料プランでも、1つのチャットのMarkdownエクスポートは無制限です。Pro（月額$3.99または年額$26.99）が外すのは、一括の「Export All」とPDFの1日3回の上限だけです。
