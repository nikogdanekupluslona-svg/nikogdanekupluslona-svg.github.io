ClaudeのチャットをMarkdownでエクスポートするには？

Chromeでclaude.aiの会話を開き、メッセージ入力欄の横にあるオレンジ色のボタンをクリックして、Markdownを選び、「Export」をクリックします。拡張機能が .md ファイルをローカルで書き出します。これが、バージョン1.13.0でClaudeのチャットをMarkdownで出力する方法です。

  1. Chrome Web Storeから拡張機能をインストールします（評価5.0）。
  2. claude.aiを再読み込みし、空の入力画面のホームではなく、実際の会話のURLを開きます。
  3. メッセージ入力欄の右にあるオレンジ色のダウンロードボタンをクリックします。
  4. Markdownを選びます。拡張機能は最後に使った形式を記憶します。
  5. 「Export」をクリックします。Chromeがブラウザのダウンロード機能で .md ファイルを保存します。

初めてMarkdownでエクスポートする前に、Googleログインが必要です。拡張機能は、無料エクスポート3回を数え、再インストール後にProを復元するために、確認済みのメールアドレスを保存します。このログインのためにチャットの本文がアップロードされることはありません。仕組み：仕組み。

オレンジ色のボタンが見当たらない場合は、会話のURLを開いていないか、インストール後にタブの再読み込みが必要か、拡張機能がまだChromeのパズルのメニューに隠れています。拡張機能を固定してから、claude.aiを再読み込みしてください。コンテンツスクリプトがClaude DesktopやClaude Codeに組み込まれることはありません。

1つのチャットか、たくさんか。オレンジ色のボタンは、開いているスレッドをMarkdownでエクスポートします。多数の .md ファイルが必要なら、「View and Download All Conversations」（すべての会話を表示してダウンロード）を開き、Markdownを選んで「Export All」（すべてエクスポート）を実行します。「Export All」で一括エクスポートをご覧ください。

メモ用にMarkdownでエクスポートする理由は？

Obsidian、GitHubのWiki、見出しやコードブロックを表示できるエディターでファイルを読むなら、Markdownでエクスポートしましょう。.md ファイルはプレーンテキストでもあるので、検索も差分も取れます。パーサーで処理するならJSONのほうが向いています。PNGは画像なので、grepで検索できません。

claude.aiからコピー＆ペーストすると、たいていインデントが消え、表が崩れます。印刷（Ctrl/Cmd+P）ではサイドバーが残り、長いコードブロックがページをまたいで分割されがちです。Markdownでエクスポートすれば、コードブロックの言語タグは残り、表は表のままです。文章を書く人がまずこの形式を選ぶのはそのためです。

私たちはMarkdownを、人が読むための標準のファイルと考えています。claude.aiのスレッドの見出し、言語タグ付きのコードブロック、表をそのまま残します。それでもPDF形式を作るつもりはありません。印刷できるページが必要なら、ClaudeのチャットをMarkdownでエクスポートした後に、あるいはその代わりに、Chromeの印刷ダイアログを使ってください。

Markdownのエクスポートで何が残る？

ClaudeのチャットをMarkdownでエクスポートすると、見出し、言語タグとインデントを保ったコードブロック、表、リンクが残ります。思考プロセスは任意です。メタデータ（タイトル、タイムスタンプ、モデル）も含められます。送信者フィルターで、.md ファイルの中身をすべてのメッセージ、人間のみ、アシスタントのみ（「all / human only / assistant only」）に絞れます。

バージョン1.13.0では、アーティファクトのレイアウトを実際に切り替えられます。「Original」「Inline」「Nested」「Flat」（元のまま／インライン／入れ子／フラット）です。Markdownのエクスポートで、画面上のアーティファクトの構造をそのまま再現することも、1つの直線的な文書に平らにすることもできます。設定の一覧：Chrome拡張機能の機能。Markdownではメッセージの吹き出しの色は残りません。見た目のスナップショットが必要ならPNGを使ってください。

スレッドがとても長い場合は、Markdownでエクスポートする前に、claude.aiが前のメッセージを読み込むまでスクロールしてください。拡張機能が書き出せるのは、ページに表示された内容だけです。半分しか読み込まれていないスレッドからは、半分だけの .md ファイルができます。不具合のように見えますが、たいていはスクロールしていないDOMが原因です。

ClaudeのチャットをMarkdownで一括エクスポートできる？

はい。すべての会話の一覧ページを開き、形式をMarkdownにして、一覧表を絞り込み、「Export All」をクリックします。書き出しが完了した .md ファイル1つが、オレンジ色のボタンで1回実行するのと同じく、無料エクスポート3回のうち1回になります。Pro（月額$3.99または年額$26.99）なら、Markdownの一括エクスポートにも上限はありません。

一覧表にはclaude.aiの履歴が表示され、名前で検索したり、「All」「New」「Exported」「Project」（すべて／未エクスポート／エクスポート済み／プロジェクト）で絞り込んだりできます。「New」はこの拡張機能でまだエクスポートしていないもの。「Exported」は保存済みのチャットを記録し、2回目の「Export All」でそれらを飛ばせるようにします。「Project」はclaude.aiでのチャットのまとめ方に対応します。

回数はアカウント全体で数えます。無料エクスポートは合計3回で、1日にMarkdownファイル3つではありません。40件の会話を選んですべての .md ファイルが完了すれば、40回分を使います。「Export All」をクリックする前に選択を計画してください。

Markdownの一括エクスポートでも、1つの会話と同じ思考プロセス、メタデータ、送信者、アーティファクトの設定を使います。「Export All」は、Anthropicから時間をおいて届くZIPではなく、チャットごとの多数の .md ファイルです。アカウント全体を1つのアーカイブにしたいなら、それは Settings → Privacy → Export data（claude.aiを日本語で表示している場合、ラベルは翻訳されていることがあります）で、中身はMarkdownではなくJSONです。

Claudeのチャットのエクスポート、MarkdownとJSONのどちらがいい？

人が読むファイルならMarkdownでエクスポートします。スクリプトでメッセージのツリーを解析するならJSONでエクスポートします。拡張機能では、1つのドロップダウンで両方に加え、プレーンテキスト、XML、PNGも選べます。PDFは引き続きありません。形式の一覧：Claudeのチャットのエクスポート形式。

AnthropicのデータエクスポートもJSONですが、メールで届くアカウントのZIPであり、チャットごとの .md ファイルではありません。そのリクエストでMarkdownを選ぶことはできません。印刷 → PDFとして保存は、Webページのスナップショットです。どちらも、オレンジ色のボタンでMarkdownにエクスポートする代わりにはなりません。

拡張機能が動くのは、Chromeで開いたclaude.aiだけです。Claude DesktopやClaude CodeにMarkdownのボタンはありません。スレッドがclaude.aiにもあれば、そこで開いてMarkdownでエクスポートしてください。Claude Codeの /export は別の製品の機能です。

Markdownでのエクスポートに追加料金はかかる？

いいえ。Markdownは、JSON、テキスト、XML、PNGと同じく、Googleでログインしたどのアカウントにもある無料エクスポート3回に含まれます。3ファイルを超えたら、Paddle経由でProが月額$3.99または年額$26.99です。Markdownだけの追加料金はありません。

拡張機能を再インストールしても、無料エクスポート3回はリセットされません。そのため、初めてMarkdownでエクスポートするときにGoogleログインが必要です。Proは、同じGoogleアカウントなら新しいパソコンでも復元されます。Paddleが販売者（Merchant of Record）であり、私たちがカード番号を見ることはありません。

Anthropicのclaude.aiの有料プランは必要ありません。Chromeで会話を読み込めるログインがあれば十分です。オレンジ色のボタンは、TeamやEnterpriseでもFreeと同じように使えます。バージョン1.13.0（2026年9月）でも、Word、Notion、PDFには出力しません。

よくある質問：ClaudeのチャットをMarkdownでエクスポート

ここでは、拡張機能1.13.0でClaudeのチャットをMarkdownでエクスポートすることについての質問に答えます。コードブロック、「Export All」による一括エクスポート、AnthropicのZIP、回数制限、Desktopについてです。どの回答も製品の事実に基づいています。ページのheadにあるFAQPageのJSON-LDはこの一覧と一致しています。

Markdownでエクスポートするとコードは失われますか？

いいえ。claude.aiから単純にコピー＆ペーストする場合と違い、コードブロックは言語タグとインデントを保ちます。表もMarkdownの表のままです。手作業でテキストを選択するのではなく、ClaudeのチャットをMarkdownでエクスポートする一番の理由です。

ClaudeのチャットをMarkdownで一括エクスポートできますか？

はい。一覧ページの「Export All」は、単体のエクスポートと同じくMarkdownに対応しています。Proでない場合、完了した .md ファイル1つが無料エクスポート3回のうち1回になります。

MarkdownはAnthropicのデータエクスポートと同じですか？

いいえ。Anthropicの公式エクスポートは、アカウント全体のJSONのZIPで、しばらく待った後にメールで届きます。Markdownでのエクスポートは、拡張機能によるチャットごと（または選択範囲ごと）の .md ファイルです。

Markdownはほかの形式より料金が高いですか？

いいえ。Markdownは、JSON、テキスト、XML、PNGと同じく、Googleでログインしたどのアカウントにもある無料エクスポート3回に含まれます。その後、無制限にファイルを作るならPro（月額$3.99または年額$26.99）です。

DesktopでClaudeのチャットをMarkdownでエクスポートできますか？

いいえ。この拡張機能が組み込まれるのは、Chromeで開いたclaude.aiだけです。Claude Desktopに形式のドロップダウンは表示されません。同じスレッドがclaude.aiにあれば、そこで開いてください。

MarkdownでエクスポートするとPDFができますか？

いいえ。Markdownは .md のテキストファイルです。この製品はPDFを提供していません。印刷できるページが必要なら、Chromeの印刷ダイアログを使ってください。PNGは画像で、これもPDFではありません。

1回だけMarkdownでエクスポートするのにProは必要ですか？

いいえ。最初の3回は、Markdownを含むどの形式でも無料です。Pro（月額$3.99または年額$26.99）なら、単体や一括でさらに多くの .md ファイルを作れます。
