Claudeの会話をJSONでエクスポートするには？

Chromeでclaude.aiの会話を開き、メッセージ入力欄の横にあるオレンジ色のボタンをクリックして、JSONを選び、「Export」をクリックします。拡張機能がファイルをローカルで書き出します。これが、バージョン1.13.0でClaudeの会話をJSONでエクスポートする方法です。2026年9月時点で、claude.aiにはチャットごとに「JSONとして保存」する機能はありません。

  1. Chrome Web Storeから拡張機能をインストールします（評価5.0）。
  2. claude.aiを再読み込みし、空の入力画面のホームではなく、実際の会話のURLを開きます。
  3. メッセージ入力欄の右にあるオレンジ色のダウンロードボタンをクリックします。
  4. JSONを選びます。最後に使った形式が記憶されます。
  5. 「Export」をクリックします。Chromeがブラウザのダウンロード機能でJSONを保存します。

初めてJSONでエクスポートする前に、Googleログインが必要です。拡張機能は、無料エクスポート3回を数え、再インストール後にProを復元するために、確認済みのメールアドレスを保存します。チャットの本文はこのログインに含まれません。仕組み：仕組み。

オレンジ色のボタンが見当たらない場合は、会話のURLを開いていないか、タブの再読み込みが必要か、拡張機能がChromeのパズルのメニューに隠れています。拡張機能を固定してから、claude.aiを再読み込みしてください。コンテンツスクリプトがClaude DesktopやClaude Codeに組み込まれることはありません。

1つのスレッドか、多数のファイルか。オレンジ色のボタンは、開いているチャットをJSONでエクスポートします。多数のJSONファイルが必要なら、「View and Download All Conversations」（すべての会話を表示してダウンロード）を開き、JSONを選んで「Export All」（すべてエクスポート）を実行します。「Export All」で一括エクスポートをご覧ください。

JSONでエクスポートすべきなのはどんなとき？

スクリプト、インデクサー、差分ツールでファイルを読み込むなら、Claudeの会話をJSONでエクスポートしましょう。このJSONはメッセージのツリーを表すためのもので、Obsidianで読むためのものではありません。人が読むために見出しやコードブロックが欲しいなら、代わりにMarkdownを選んでください。

claude.aiからコピー＆ペーストすると、送信者の構造が失われます。印刷ではWebページの画面要素が残ります。JSONでエクスポートすれば、やり取り、送信者、任意で思考プロセスが、平たい段落ではなくデータとして残ります。開発者がプレーンテキストよりJSONを選ぶのはそのためです。

私たちは、ページにすでにあるclaude.aiのツリー（送信者、コンテンツブロック、タイムスタンプ、モデルのメタデータ）からJSONを書き出し、スレッドをアップロードすることはありません。このJSONはAnthropicのアカウントZIPではなく、PDFでもありません。バージョン1.13.0でも、提供する形式は5つだけです。

「Claude Chat Downloader」や「Claude Conversation Downloader」という名前で検索される方もいますが、どちらもこの拡張機能のことです。JSONでのエクスポートはそのオレンジ色のボタンで行い、別の製品ではありません。法的なページでは「Claude Exporter」と書かれている場合もあります。

Claudeの会話のJSONには何が入っている？

Claudeの会話のJSONは、claude.aiのメッセージのツリー（送信者、コンテンツブロック、タイムスタンプ、モデルのメタデータ）をそのまま反映します。思考プロセスとアーティファクトは、それぞれの設定がオンのときに含まれます。送信者フィルターで、ファイルの中身をすべてのメッセージ、人間のみ、アシスタントのみ（「all / human only / assistant only」）に絞れます。先にMarkdownに平らにしてから変換することはありません。

バージョン1.13.0のアーティファクトのレイアウトは、「Original」「Inline」「Nested」「Flat」（元のまま／インライン／入れ子／フラット）です。レイアウトによって、JSONの中でのアーティファクトの入れ子の仕方が変わります。MarkdownやXMLと同じ4つの選択肢です。設定の一覧：Chrome拡張機能の機能。JSONがPDFになることはありません。

Claudeの会話のJSONとAnthropicのデータエクスポートの違いは？

どちらもJSONですが、構造も範囲も同じではありません。Anthropicの Settings → Privacy → Export data（claude.aiを日本語で表示している場合、ラベルは翻訳されていることがあります）は、しばらく待った後に、アカウント全体のZIPを1つメールで送ります。Claudeの会話をJSONでエクスポートすれば、1つのスレッドがChromeですぐに手に入ります。バックアップにはZIPを使ってください。

AnthropicのZIPのリクエストでMarkdownを選ぶことはできません。また、この拡張機能のJSONを、そのZIPのスキーマの代わりにそのまま使うこともできません。形式の一覧：Claudeのチャットのエクスポート形式。印刷は見た目のための回避策で、JSONのエクスポートではありません。

Claudeの会話をJSONで一括エクスポートできる？

はい。すべての会話の一覧ページを開き、形式をJSONにして、一覧表を絞り込み、「Export All」をクリックします。書き出しが完了した各ファイルが、無料エクスポート3回のうち1回になります。Pro（月額$3.99または年額$26.99）なら、JSONの一括エクスポートにも上限はありません。

一覧表にはclaude.aiの履歴が表示され、名前で検索したり、「All」「New」「Exported」「Project」（すべて／未エクスポート／エクスポート済み／プロジェクト）で絞り込んだりできます。「New」はこの拡張機能でまだエクスポートしていないもの、「Exported」は保存済みのチャットです。「Project」はclaude.aiでのチャットのまとめ方に対応します。「Export All」でできるのは多数のJSONファイルで、形式が混ざった1つのZIPではありません。

回数はアカウント全体で数えます。無料エクスポートは合計3回で、一括エクスポート1回ごとにJSONファイル3つではありません。40件の会話を選んですべてのファイルが完了すれば、40回分を使います。選択を計画するか、Proを使ってください。

claude.aiの同じスレッドを別々のタイミングでJSONエクスポートした2つのファイルは、ほかのJSONファイルと同じように差分を取れます。各エクスポートはそれだけで完結しています。同じチャットでもう一度「Export All」を実行すると、ファイルの書き出しに失敗しない限り、やはり回数を消費します。

JSONでのエクスポートにProは必要？

いいえ。JSONは、Markdown、テキスト、XML、PNGと同じく、Googleでログインしたどのアカウントにもある無料エクスポート3回に含まれます。3ファイルを超えたら、Paddle経由でProが月額$3.99または年額$26.99です。Claudeの会話をJSONでエクスポートするための追加料金はありません。

拡張機能を再インストールしても、無料エクスポート3回はリセットされません。そのため、最初に「Export」をクリックするときにGoogleログインが必要です。Proは、同じGoogleアカウントなら新しいパソコンでも復元されます。Paddleが販売者（Merchant of Record）であり、私たちがカード番号を見ることはありません。

拡張機能が動くのは、Chromeで開いたclaude.aiだけです。Claude DesktopやClaude CodeにJSONのボタンはありません。Claude Codeの /export やディスク上のJSONLは別の方法です。バージョン1.13.0（2026年9月）でも、PDF、Word、Notionには出力しません。

よくある質問：Claudeの会話をJSONでエクスポート

ここでは、拡張機能1.13.0でClaudeの会話をJSONでエクスポートすることについての質問に答えます。「Export All」による一括エクスポート、スキーマ、回数制限、差分、AnthropicのZIP、Desktopについてです。どの回答も製品の事実に基づいています。ページのheadにあるFAQPageのJSON-LDはこの一覧と一致しています。

Claudeの会話をJSONで一括エクスポートできますか？

はい。一覧ページの「Export All」は、単体のエクスポートと同じくJSONに対応しています。Pro（月額$3.99または年額$26.99）でない場合、完了したファイル1つが無料エクスポート3回のうち1回になります。

JSONの構造はドキュメント化されていますか？

claude.ai自体のメッセージのツリー（送信者、コンテンツブロック、タイムスタンプ、モデルのメタデータ）をそのまま反映しており、設定をオンにすればアーティファクトと思考プロセスも含まれます。AnthropicのアカウントZIPのスキーマではありません。

Claudeの会話をJSONでエクスポートするのにProは必要ですか？

いいえ。JSONは、ほかのすべての形式と同じく、Googleでログインしたどのアカウントにもある無料エクスポート3回に含まれます。3ファイルを超えたら、Pro（月額$3.99または年額$26.99）です。

1つのチャットの2つのJSONエクスポートの差分を取れますか？

はい。Claudeの会話をJSONでエクスポートするたびに、同じ方法で作られた完結したファイルができます。同じスレッドを別々のタイミングでエクスポートした2つのファイルの比較は、ほかのJSONファイルの差分と同じように行えます。

このJSONはAnthropicのデータエクスポートと同じですか？

いいえ。Anthropicのデータエクスポートは、時間をおいて届くアカウント全体のZIPです。この拡張機能は、チャットごと（または選択範囲ごと）のJSONファイルを、Chromeの中ですぐに書き出します。どちらもJSONかもしれませんが、互換性はありません。

JSONでエクスポートするとPDFができますか？

いいえ。JSONは構造化データです。製品の形式はMarkdown、JSON、プレーンテキスト、XML、PNGです。印刷できるページが必要なら、このドロップダウンではなく、Chromeの印刷ダイアログを使ってください。

JSONでのエクスポートはClaude Desktopで使えますか？

いいえ。このChrome拡張機能が組み込まれるのはclaude.aiだけです。Claude DesktopにJSONの選択肢が表示されることはありません。同じスレッドがclaude.aiにあれば、Chromeでそこを開いてください。
