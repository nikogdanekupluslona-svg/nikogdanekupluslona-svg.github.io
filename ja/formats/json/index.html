Claudeの会話をJSONでエクスポートするには？

Chromeでclaude.aiの会話を開き、メッセージ入力欄の横にあるオレンジ色のボタンをクリックして、JSONを選び、「Export」をクリックします。Download Claude conversationsがファイルをローカルで書き出します。これが、バージョン1.16.2でClaudeの会話をJSONでエクスポートする方法です。2026年9月時点で、claude.aiにはチャットごとに「JSONとして保存」する機能はありません。

  1. Chrome Web StoreからDownload Claude conversationsをインストールします。
  2. claude.aiを再読み込みし、空の入力画面のホームではなく、実際の会話のURLを開きます。
  3. メッセージ入力欄の右にあるオレンジ色のダウンロードボタンをクリックします。
  4. JSONを選びます。最後に使った形式が記憶されます。必要なメッセージだけにチェックを入れるなら、「Select」（選択）を使います。
  5. 「Export」をクリックします。Chromeがブラウザのダウンロード機能でJSONを保存します。「Copy」（コピー）をクリックすれば、JSONをクリップボードに入れることもできます。

Claudeの会話をJSONでエクスポートするのに、ログインは不要です。1つのチャットのJSONエクスポートは無制限・匿名で、私たちのサーバーには何も送りません。Googleログインを求められるのは、PDFと一括の「Export All」（すべてエクスポート）だけです。仕組み：仕組み。

オレンジ色のボタンが見当たらない場合は、会話のURLを開いていないか、タブの再読み込みが必要か、拡張機能がChromeのパズルのメニューに隠れています。Download Claude conversationsを固定してから、claude.aiを再読み込みしてください。コンテンツスクリプトがClaude DesktopやClaude Codeのターミナルに組み込まれることはありません。

1つのスレッドか、多数のファイルか。オレンジ色のボタンは、開いているチャットをJSONでエクスポートします。多数のJSONファイルが必要なら、「View and Download All Conversations」（すべての会話を表示してダウンロード）を開き、JSONを選んで「Export All」を実行します。ZIPは1つで、無料プランでは1日3チャットまでです。「Export All」で一括エクスポートをご覧ください。

JSONでエクスポートすべきなのはどんなとき？

スクリプト、インデクサー、差分ツールでファイルを読み込むなら、Claudeの会話をJSONでエクスポートしましょう。このJSONはメッセージのツリーを表すためのもので、Obsidianで読むためのものではありません。人が読むために見出しやコードブロックが欲しいなら、代わりにMarkdownを選んでください。表計算で使うなら、1メッセージが1行になるCSVを選びます。

claude.aiからコピー＆ペーストすると、送信者の構造が失われます。印刷ではWebページの画面要素が残ります。JSONでエクスポートすれば、Download Claude conversationsは、やり取り、送信者、任意で思考プロセスを、平たい段落ではなくデータとして残します。開発者がプレーンテキストよりJSONを選ぶのはそのためです。

私たちは、ページにすでにあるclaude.aiのツリー（送信者、コンテンツブロック、タイムスタンプ、モデルのメタデータ）からJSONを書き出し、スレッドをアップロードすることはありません。このJSONはAnthropicのアカウントZIPではありません。バージョン1.16.2では、PDFやCSVと並ぶ7つの形式の1つで、アカウント不要・無料で使えます。

Claudeの会話のJSONには何が入っている？

Claudeの会話のJSONは、claude.aiのメッセージのツリー（送信者、コンテンツブロック、タイムスタンプ、モデルのメタデータ）をそのまま反映します。思考プロセス、Web検索のソース、ツール／MCPのステップ、アーティファクトは、それぞれのオプションがオンのときに含まれます。思考プロセスはエクスポートパネルの「Thinking」（思考）のチェックボックスで、ツールとソースは設定（Settings）でオンにします。送信者フィルターで、ファイルの中身をすべてのメッセージ、人間のみ、アシスタントのみ（「All」「Human」「Assistant」）に絞れます。先にMarkdownに平らにしてから変換することはありません。

バージョン1.16.2のアーティファクトのレイアウトは、「Original」「Inline」「Nested」「Flat」（元のまま／インライン／入れ子／フラット）です。レイアウトによって、JSONの中でのアーティファクトの入れ子の仕方が変わります。MarkdownやXMLと同じ4つの選択肢です。一覧：Chrome拡張機能の機能。データではなくページ形式が必要なら、PDFでエクスポートしてください。

Claudeの会話のJSONとAnthropicのデータエクスポートの違いは？

どちらもJSONですが、構造も範囲も同じではありません。Anthropicの Settings → Privacy → Export data（claude.aiを日本語で表示している場合、ラベルは翻訳されていることがあります）は、しばらく待った後に、アカウント全体のZIPを1つメールで送ります。Claudeの会話をJSONでエクスポートすれば、1つのスレッドがChromeですぐに手に入ります。バックアップにはZIPを使ってください。

Claudeの会話をJSONで一括エクスポートできる？

はい。「View and Download All Conversations」を開き、「Chat format」（チャット形式）をJSONにして、一覧を絞り込み、「Export All」をクリックします。Chromeが、チャットごとに1つのJSONファイルが入ったZIPを1つ保存します。無料プランではGoogleログインで1日3チャットまでで、この枠はPDFと共通です。Pro（月額$3.99または年額$26.99）なら、JSONの一括エクスポートにも上限はありません。

ダッシュボードにはclaude.aiの履歴が表示され、名前での検索、「All conversations」「New」「Updated」「Previously exported」（すべての会話／新規／更新あり／エクスポート済み）のフィルター、「Chat」と「Cowork」のタブ、プロジェクトの検索が使えます。「New」はDownload Claude conversationsでまだエクスポートしていないもの、「Previously exported」は保存済みのチャットです。「Export All」でできるのは、チャットごとのJSONファイルを収めた1つのZIPで、形式が混ざったアーカイブではありません。

1日の上限はアカウント単位です。無料プランでは1日3チャットまでで、この枠はPDFと共通です。残りが3回のときに40件の会話を選ぶと、途中で切られるのではなく、全体がブロックされます。選ぶ数を減らすか、Proを使ってください。オレンジ色のボタンからのJSON単体のエクスポートは、引き続き無制限です。

claude.aiの同じスレッドを別々のタイミングでJSONエクスポートした2つのファイルは、ほかのJSONファイルと同じように差分を取れます。各エクスポートはそれだけで完結しています。同じチャットでもう一度「Export All」を実行すると、すべてのチャットがもう一度回数に数えられます。

JSONでのエクスポートにProは必要？

いいえ。1つのチャットのJSONエクスポートは、Markdown、テキスト、XML、CSV、PNGと同じく無料・無制限で、アカウントも回数のカウントもありません。無料の上限があるのはPDFと一括の「Export All」だけで、Googleログインで1日3回までです。Paddle経由のProは月額$3.99または年額$26.99です。Claudeの会話をJSONでエクスポートするための追加料金はありません。

上限が関係するのは、JSONの一括エクスポートです。「Export All」のZIPに入るチャット1件ごとに1日3回の枠を1回使い、回数はUTCの午前0時にリセットされます。Proならこの上限はなくなり、同じGoogleアカウントなら新しいパソコンでも復元されます。Paddleが販売者（Merchant of Record）であり、私たちがカード番号を見ることはありません。

拡張機能が動くのは、Chromeで開いたclaude.aiだけです。Claude DesktopやClaude CodeのターミナルにJSONのボタンはありません。Claude Code on the web（claude.ai/code）はclaude.ai上で動くので、ほかのチャットと同じようにエクスポートできます。ターミナルのClaude Codeの /export やディスク上のJSONLは別の方法です。バージョン1.16.2（2026年9月）でも、WordやNotionには出力しません。

Claudeの会話をJSONで一括エクスポートできますか？

はい。ダッシュボードの「Export All」はJSONに対応していて、チャットごとに1つのJSONファイルが入ったZIPを1つ保存します。無料プランではGoogleログインで1日3チャットまで、Pro（月額$3.99または年額$26.99）なら無制限です。

JSONの構造はドキュメント化されていますか？

claude.ai自体のメッセージのツリー（送信者、コンテンツブロック、タイムスタンプ、モデルのメタデータ）をそのまま反映しており、オプションをオンにすれば、アーティファクト、思考プロセス、Web検索のソース、ツール／MCPのステップも含まれます。AnthropicのアカウントZIPのスキーマではありません。

Claudeの会話をJSONでエクスポートするのにProは必要ですか？

いいえ。1つのチャットのJSONエクスポートは、PDF以外のすべての形式と同じく無制限で、アカウントも要りません。Pro（月額$3.99または年額$26.99）が外すのは、PDFと一括の「Export All」の1日3回の上限だけです。

1つのチャットの2つのJSONエクスポートの差分を取れますか？

はい。Claudeの会話をJSONでエクスポートするたびに、同じ方法で作られた完結したファイルができます。同じスレッドを別々のタイミングでエクスポートした2つのファイルの比較は、ほかのJSONファイルの差分と同じように行えます。

このJSONはAnthropicのデータエクスポートと同じですか？

いいえ。Anthropicのデータエクスポートは、時間をおいて届くアカウント全体のZIPです。Download Claude conversationsは、チャットごと（または選択範囲ごと）のJSONファイルを、Chromeの中ですぐに書き出します。どちらもJSONかもしれませんが、互換性はありません。

JSONでエクスポートするとPDFができますか？

いいえ。JSONは構造化データです。ページ形式が必要なら、同じパネルでPDFを選んでください。7つの形式は、PDF、Markdown、JSON、プレーンテキスト、XML、CSV、PNGです。PDFにはGoogleログインが必要で、無料プランでは1日3回の枠に数えられます。

JSONでのエクスポートはClaude Desktopで使えますか？

いいえ。このChrome拡張機能が組み込まれるのはclaude.aiだけです。Claude DesktopにJSONの選択肢が表示されることはありません。同じスレッドがclaude.aiにあれば、Chromeでそこを開いてください。
