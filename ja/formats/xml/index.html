データ連携のためにClaudeのチャットをXMLでエクスポートする

ClaudeのチャットをXMLでエクスポートするには、Download Claude conversationsをインストールし、claude.aiでスレッドを開いて、オレンジ色のボタンをクリックし、XMLを選んで「Export」（エクスポート）をクリックします。Chromeが、JSONではなくXMLを必要とするシステム向けの構造化マークアップを保存します。XMLのエクスポートは無制限・無料で、アカウントも要りません。ページ形式が必要なら、同じドロップダウンにPDFもあります。

ClaudeのチャットをXMLでエクスポートするには？

Chromeでclaude.aiの会話を開き、メッセージ入力欄の横にあるオレンジ色のボタンをクリックして、XMLを選び、「Export」をクリックします。Download Claude conversationsがファイルをローカルで書き出します。これが、バージョン1.16.2でClaudeのチャットをXMLでエクスポートする方法です。2026年9月時点で、claude.aiには「XMLとして保存」する標準機能はありません。

  1. Chrome Web StoreからDownload Claude conversationsをインストールします。
  2. claude.aiを再読み込みし、空の入力画面のホームではなく、実際の会話のURLを開きます。
  3. メッセージ入力欄の右にあるオレンジ色のダウンロードボタンをクリックします。
  4. XMLを選びます。最後に使った形式が記憶されます。必要なメッセージだけにチェックを入れるなら、「Select」（選択）を使います。
  5. 「Export」をクリックします。Chromeがブラウザのダウンロード機能でXMLを保存します。「Copy」（コピー）をクリックすれば、XMLをクリップボードに入れることもできます。

ClaudeのチャットをXMLでエクスポートするのに、ログインは不要です。1つのチャットのXMLエクスポートは無制限・匿名で、私たちのサーバーには何も送りません。Googleログインを求められるのは、PDFと一括の「Export All」（すべてエクスポート）だけです。仕組み：仕組み。

オレンジ色のボタンが見当たらない場合は、会話のURLを開いていないか、タブの再読み込みが必要か、拡張機能がChromeのパズルのメニューに隠れています。Download Claude conversationsを固定してから、claude.aiを再読み込みしてください。XMLでのエクスポートがClaude DesktopやClaude Codeのターミナルに表示されることはありません。

1ファイルか、たくさんか。オレンジ色のボタンは、開いているスレッドをXMLでエクスポートします。多数のXMLファイルが必要なら、「View and Download All Conversations」（すべての会話を表示してダウンロード）を開き、XMLを選んで「Export All」を実行します。ZIPは1つで、無料プランでは1日3チャットまでです。「Export All」で一括エクスポートをご覧ください。

XMLでエクスポートすべきなのはどんなとき？

受け取り側のシステム、パイプライン、古いツールが、構造化データのやり取りにXMLを必要とするときは、ClaudeのチャットをXMLでエクスポートしましょう。ほとんどの開発者は、代わりにJSONを選ぶべきです。Markdownは人が読むメモ用、CSVは表計算用、PNGは画像です。ドロップダウンにXMLがあるのは、今もXMLしか受け付けず、JSONを読み込まないツールがあるからです。

XMLを「より正式な」JSONだと思ってエクスポートしないでください。Download Claude conversationsはどちらでも同じ解析を行います。違いはファイルの形で、XMLにすると特別な項目が魔法のように増えるわけではありません。使っているものにXMLが必要ないなら、この形式は飛ばしてJSONを使ってください。

XMLを提供しているのは、今もXMLを必要とするパイプラインがあるからで、claude.aiのあらゆるエクスポートでJSONより優れていると考えているからではありません。解析内容は同じで、メッセージ、送信者、任意で思考プロセスとアーティファクトです。バージョン1.16.2でも、XMLは7つの形式の1つで、アカウント不要・無料で使えます。有料のオプションではありません。

「Claude Chat Downloader」や「Claude Conversation Downloader」という名前で検索される方もいますが、どちらもこの拡張機能のことです。XMLでのエクスポートはそのオレンジ色のボタンで行います。法的なページでは「Claude Exporter」と書かれている場合もあります。これらの名前はすべてこの製品のことです。

XMLのエクスポートで何が残る？

ClaudeのチャットをXMLでエクスポートすると、Download Claude conversationsは、会話の構造（メッセージ、送信者、利用できるメタデータ）をXMLのマークアップとして書き出します。思考プロセス、Web検索のソース、ツール／MCPのステップ、アーティファクトは、MarkdownやJSONと同じオプションに従います。思考プロセスはエクスポートパネルの「Thinking」（思考）のチェックボックスで、ツールとソースは設定（Settings）でオンにします。XMLは、それらの形式を簡略化したものではありません。

バージョン1.16.2のアーティファクトのレイアウトは、「Original」「Inline」「Nested」「Flat」（元のまま／インライン／入れ子／フラット）です。送信者フィルターで、XMLの中身をすべてのメッセージ、人間のみ、アシスタントのみ（「All」「Human」「Assistant」）に絞れます。メタデータ（タイトル、タイムスタンプ、モデル）も含められます。設定の一覧：Chrome拡張機能の機能。

スレッドが長い場合は、XMLでエクスポートする前に、claude.aiが前のメッセージを読み込むまでスクロールしてください。拡張機能がシリアライズできるのは、ページに表示された内容だけです。半分しか読み込まれていないDOMからは、途中で切れたXMLができます。

Claudeのチャットのエクスポート、XMLとJSONのどちらがいい？

開発者によく選ばれるのはJSONです。XMLでエクスポートするのは、後段のシステムがXMLを必要とする場合だけにしましょう。Download Claude conversationsでは、XMLだからといってJSONより「完全」になるわけではありません。どちらも思考プロセスとアーティファクトを含められます。どちらもAnthropicのアカウントZIPではありません。形式の一覧：Claudeのチャットのエクスポート形式。

Anthropicの Settings → Privacy → Export data（claude.aiを日本語で表示している場合、ラベルは翻訳されていることがあります）はJSON（ZIP）で、XMLではありません。同じパネルのPDFは人が読むためのページで、マークアップではありません。どちらも、オレンジ色のボタンでXMLにエクスポートする代わりにはなりません。このXMLが、公開されていないAnthropicのスキーマと一致することは期待しないでください。

拡張機能が動くのは、Chromeで開いたclaude.aiだけです。Claude DesktopやClaude CodeのターミナルにXMLのボタンはありません。Claude Code on the web（claude.ai/code）はclaude.ai上で動くので、ほかのチャットと同じようにエクスポートできます。スレッドがclaude.aiにもあれば、そこで開いてXMLでエクスポートしてください。ターミナルのClaude Codeの /export は別の製品の機能です。

ClaudeのチャットをXMLで一括エクスポートできる？

はい。「View and Download All Conversations」を開き、「Chat format」（チャット形式）をXMLにして、一覧を絞り込み、「Export All」をクリックします。Chromeが、チャットごとに1つのXMLファイルが入ったZIPを1つ保存します。無料プランではGoogleログインで1日3チャットまでで、この枠はPDFと共通です。Pro（月額$3.99または年額$26.99）なら、XMLの一括エクスポートにも上限はありません。

ダッシュボードにはclaude.aiの履歴が表示され、名前での検索、「All conversations」「New」「Updated」「Previously exported」（すべての会話／新規／更新あり／エクスポート済み）のフィルター、「Chat」と「Cowork」のタブ、プロジェクトの検索が使えます。「New」はDownload Claude conversationsでまだエクスポートしていないもの、「Previously exported」は保存済みのチャットです。「Export All」でできるのは、チャットごとのXMLファイルを収めた1つのZIPで、形式が混ざったアーカイブではありません。

1日の上限はアカウント単位です。無料プランでは1日3チャットまでで、この枠はPDFと共通です。残りが3回のときに40件の会話を選ぶと、途中で切られるのではなく、全体がブロックされます。選ぶ数を減らすか、Proを使ってください。オレンジ色のボタンからのXML単体のエクスポートは、引き続き無制限です。

1回の「Export All」でXMLとJSONを混ぜることはできません。その実行ではXMLを選びます。claude.aiの同じスレッドを両方の形で欲しい場合は、JSONでもう一度「Export All」を実行してください。その2回目では、すべてのチャットがもう一度回数に数えられます。

XMLでのエクスポートにProは必要？

いいえ。1つのチャットのXMLエクスポートは、Markdown、JSON、テキスト、CSV、PNGと同じく無料・無制限で、アカウントも回数のカウントもありません。無料の上限があるのはPDFと一括の「Export All」だけで、Googleログインで1日3回までです。Paddle経由のProは月額$3.99または年額$26.99です。XMLを有料限定の形式として扱うことはありません。

上限が関係するのは、XMLの一括エクスポートです。「Export All」のZIPに入るチャット1件ごとに1日3回の枠を1回使い、回数はUTCの午前0時にリセットされます。Proならこの上限はなくなり、同じGoogleアカウントなら新しいパソコンでも復元されます。Paddleが販売者（Merchant of Record）であり、私たちがカード番号を見ることはありません。

Anthropicのclaude.aiの有料プランは必要ありません。Chromeで会話を読み込めるログインがあれば十分です。バージョン1.16.2（2026年9月）でも、WordやNotionには出力しません。この一覧が変わる場合は、その日のうちにこのページも更新します。

よくある質問：ClaudeのチャットをXMLでエクスポート

ここでは、Download Claude conversations 1.16.2でClaudeのチャットをXMLでエクスポートすることについての質問に答えます。JSONとの比較、「Export All」による一括エクスポート、料金、Desktop、PDF、Proについてです。どの回答も製品の事実に基づいています。ページのheadにあるFAQPageのJSON-LDはこの一覧と一致しています。

Claudeのチャットのエクスポートでは、XMLのほうがJSONより優れていますか？

一般的にはそうではありません。開発者によく選ばれるのはJSONです。後段のシステムが構造化データのやり取りにXMLを必要とする場合に、ClaudeのチャットをXMLでエクスポートしてください。claude.aiからの解析内容は同じで、ファイルの形が違うだけです。

ClaudeのチャットをXMLで一括エクスポートできますか？

はい。ダッシュボードの同じ「Export All」の流れでXMLに対応していて、チャットごとに1つのXMLファイルが入ったZIPを1つ保存します。無料プランではGoogleログインで1日3チャットまで、Pro（月額$3.99または年額$26.99）なら無制限です。

XMLは有料限定の形式ですか？

いいえ。1つのチャットのXMLエクスポートは、Markdown、テキスト、JSON、CSV、PNGと同じく無制限で、アカウントも要りません。無料の上限（1日3回）があるのはPDFと一括の「Export All」だけです。Proは月額$3.99または年額$26.99です。

XMLのエクスポートはAnthropicのZIPと一致しますか？

いいえ。Anthropicのデータエクスポートは、時間をおいて届くアカウントのJSONのZIPです。Download Claude conversationsは、チャットごと（または選択範囲ごと）のXMLファイルを、Chromeの中ですぐに書き出します。スキーマは同じではありません。

XMLでエクスポートするとPDFができますか？

いいえ。XMLはマークアップです。ページ形式が必要なら、同じパネルでPDFを選んでください。7つの形式は、PDF、Markdown、JSON、プレーンテキスト、XML、CSV、PNGです。PDFにはGoogleログインが必要で、無料プランでは1日3回の枠に数えられます。

DesktopでClaudeのチャットをXMLでエクスポートできますか？

いいえ。このChrome拡張機能が組み込まれるのはclaude.aiだけです。Claude DesktopにXMLのドロップダウンは表示されません。同じスレッドがclaude.aiにあれば、Chromeでそこを開いてください。

1回だけXMLでエクスポートするのにProは必要ですか？

いいえ。アカウントもまったく要りません。無料プランでも、1つのチャットのXMLエクスポートは無制限です。Pro（月額$3.99または年額$26.99）が外すのは、一括の「Export All」とPDFの1日3回の上限だけです。
