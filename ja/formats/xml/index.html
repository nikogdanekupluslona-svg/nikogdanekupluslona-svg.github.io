ClaudeのチャットをXMLでエクスポートするには？

Chromeでclaude.aiの会話を開き、メッセージ入力欄の横にあるオレンジ色のボタンをクリックして、XMLを選び、「Export」をクリックします。拡張機能がファイルをローカルで書き出します。これが、バージョン1.13.0でClaudeのチャットをXMLでエクスポートする方法です。2026年9月時点で、claude.aiには「XMLとして保存」する標準機能はありません。

  1. Chrome Web Storeから拡張機能をインストールします（評価5.0）。
  2. claude.aiを再読み込みし、空の入力画面のホームではなく、実際の会話のURLを開きます。
  3. メッセージ入力欄の右にあるオレンジ色のダウンロードボタンをクリックします。
  4. XMLを選びます。最後に使った形式が記憶されます。
  5. 「Export」をクリックします。Chromeがブラウザのダウンロード機能でXMLを保存します。

初めてXMLでエクスポートする前に、Googleログインが必要です。拡張機能は、無料エクスポート3回を数え、再インストール後にProを復元するために、確認済みのメールアドレスを保存します。チャットの本文はこのログインに含まれません。仕組み：仕組み。

オレンジ色のボタンが見当たらない場合は、会話のURLを開いていないか、タブの再読み込みが必要か、拡張機能がChromeのパズルのメニューに隠れています。拡張機能を固定してから、claude.aiを再読み込みしてください。XMLでのエクスポートがClaude DesktopやClaude Codeに表示されることはありません。

1ファイルか、たくさんか。オレンジ色のボタンは、開いているスレッドをXMLでエクスポートします。多数のXMLファイルが必要なら、「View and Download All Conversations」（すべての会話を表示してダウンロード）を開き、XMLを選んで「Export All」（すべてエクスポート）を実行します。「Export All」で一括エクスポートをご覧ください。

XMLでエクスポートすべきなのはどんなとき？

受け取り側のシステム、パイプライン、古いツールが、構造化データのやり取りにXMLを必要とするときは、ClaudeのチャットをXMLでエクスポートしましょう。ほとんどの開発者は、代わりにJSONを選ぶべきです。Markdownは人が読むメモ用、PNGは画像です。ドロップダウンにXMLがあるのは、今もXMLしか受け付けず、JSONを読み込まないツールがあるからです。

XMLを「より正式な」JSONだと思ってエクスポートしないでください。拡張機能はどちらでも同じ解析を行います。違いはファイルの形で、XMLにすると特別な項目が魔法のように増えるわけではありません。使っているものにXMLが必要ないなら、この形式は飛ばしてJSONを使ってください。

XMLを提供しているのは、今もXMLを必要とするパイプラインがあるからで、claude.aiのあらゆるエクスポートでJSONより優れていると考えているからではありません。解析内容は同じで、メッセージ、送信者、任意で思考プロセスとアーティファクトです。今もPDFは出力していません。バージョン1.13.0でも、XMLは5つの形式の1つであり、有料のオプションではありません。

「Claude Chat Downloader」や「Claude Conversation Downloader」という名前で検索される方もいますが、どちらもこの拡張機能のことです。XMLでのエクスポートはそのオレンジ色のボタンで行います。法的なページでは「Claude Exporter」と書かれている場合もあります。これらの名前はすべてこの製品のことです。

XMLのエクスポートで何が残る？

ClaudeのチャットをXMLでエクスポートすると、会話の構造（メッセージ、送信者、利用できるメタデータ）がXMLのマークアップとして書き出されます。思考プロセスとアーティファクトは、MarkdownやJSONと同じ設定に従います。XMLは、それらの形式を簡略化したものではありません。

バージョン1.13.0のアーティファクトのレイアウトは、「Original」「Inline」「Nested」「Flat」（元のまま／インライン／入れ子／フラット）です。送信者フィルターで、XMLの中身をすべてのメッセージ、人間のみ、アシスタントのみ（「all / human only / assistant only」）に絞れます。メタデータ（タイトル、タイムスタンプ、モデル）も含められます。設定の一覧：Chrome拡張機能の機能。

スレッドが長い場合は、XMLでエクスポートする前に、claude.aiが前のメッセージを読み込むまでスクロールしてください。拡張機能がシリアライズできるのは、ページに表示された内容だけです。半分しか読み込まれていないDOMからは、途中で切れたXMLができます。

Claudeのチャットのエクスポート、XMLとJSONのどちらがいい？

開発者によく選ばれるのはJSONです。XMLでエクスポートするのは、後段のシステムがXMLを必要とする場合だけにしましょう。拡張機能では、XMLだからといってJSONより「完全」になるわけではありません。どちらも思考プロセスとアーティファクトを含められます。どちらもAnthropicのアカウントZIPではありません。形式の一覧：Claudeのチャットのエクスポート形式。

Anthropicの Settings → Privacy → Export data（claude.aiを日本語で表示している場合、ラベルは翻訳されていることがあります）はJSON（ZIP）で、XMLではありません。印刷 → PDFとして保存は、Webページのスナップショットです。どちらも、オレンジ色のボタンでXMLにエクスポートする代わりにはなりません。このXMLが、公開されていないAnthropicのスキーマと一致することは期待しないでください。

拡張機能が動くのは、Chromeで開いたclaude.aiだけです。Claude DesktopやClaude CodeにXMLのボタンはありません。スレッドがclaude.aiにもあれば、そこで開いてXMLでエクスポートしてください。Claude Codeの /export は別の製品の機能です。

ClaudeのチャットをXMLで一括エクスポートできる？

はい。すべての会話の一覧ページを開き、形式をXMLにして、一覧表を絞り込み、「Export All」をクリックします。書き出しが完了した各ファイルが、無料エクスポート3回のうち1回になります。Pro（月額$3.99または年額$26.99）なら、XMLの一括エクスポートにも上限はありません。

一覧表にはclaude.aiの履歴が表示され、名前で検索したり、「All」「New」「Exported」「Project」（すべて／未エクスポート／エクスポート済み／プロジェクト）で絞り込んだりできます。「New」はこの拡張機能でまだエクスポートしていないもの、「Exported」は保存済みのチャットです。「Project」はclaude.aiでのチャットのまとめ方に対応します。「Export All」でできるのは多数のXMLファイルで、形式が混ざった1つのZIPではありません。

回数はアカウント全体で数えます。無料エクスポートは合計3回で、一括エクスポート1回ごとにXMLファイル3つではありません。40件の会話を選んですべてのファイルが完了すれば、40回分を使います。選択を計画するか、Proを使ってください。

1回の「Export All」でXMLとJSONを混ぜることはできません。その実行ではXMLを選びます。claude.aiの同じスレッドを両方の形で欲しい場合は、JSONでもう一度「Export All」を実行してください。その2回目も回数を消費します。

XMLでのエクスポートにProは必要？

いいえ。XMLは、Markdown、JSON、テキスト、PNGと同じく、Googleでログインしたどのアカウントにもある無料エクスポート3回に含まれます。3ファイルを超えたら、Paddle経由でProが月額$3.99または年額$26.99です。XMLを有料限定の形式として扱うことはありません。

拡張機能を再インストールしても、無料エクスポート3回はリセットされません。そのため、初めてXMLでエクスポートするときにGoogleログインが必要です。Proは、同じGoogleアカウントなら新しいパソコンでも復元されます。Paddleが販売者（Merchant of Record）であり、私たちがカード番号を見ることはありません。

Anthropicのclaude.aiの有料プランは必要ありません。Chromeで会話を読み込めるログインがあれば十分です。バージョン1.13.0（2026年9月）でも、PDF、Word、Notionには出力しません。この一覧が変わる場合は、その日のうちにこのページも更新します。

よくある質問：ClaudeのチャットをXMLでエクスポート

ここでは、拡張機能1.13.0でClaudeのチャットをXMLでエクスポートすることについての質問に答えます。JSONとの比較、「Export All」による一括エクスポート、回数制限、Desktop、PDF、Proについてです。どの回答も製品の事実に基づいています。ページのheadにあるFAQPageのJSON-LDはこの一覧と一致しています。

Claudeのチャットのエクスポートでは、XMLのほうがJSONより優れていますか？

一般的にはそうではありません。開発者によく選ばれるのはJSONです。後段のシステムが構造化データのやり取りにXMLを必要とする場合に、ClaudeのチャットをXMLでエクスポートしてください。claude.aiからの解析内容は同じで、ファイルの形が違うだけです。

ClaudeのチャットをXMLで一括エクスポートできますか？

はい。一覧ページの同じ「Export All」の流れでXMLに対応しています。Pro（月額$3.99または年額$26.99）でない場合、完了したファイル1つが無料エクスポート3回のうち1回になります。

XMLは有料限定の形式ですか？

いいえ。XMLを含む5つの形式すべてが、Googleでログインしたどのアカウントにもある無料エクスポート3回の対象です。3ファイルを超えたら、Pro（月額$3.99または年額$26.99）です。

XMLのエクスポートはAnthropicのZIPと一致しますか？

いいえ。Anthropicのデータエクスポートは、時間をおいて届くアカウントのJSONのZIPです。この拡張機能は、チャットごと（または選択範囲ごと）のXMLファイルを、Chromeの中ですぐに書き出します。スキーマは同じではありません。

XMLでエクスポートするとPDFができますか？

いいえ。XMLはマークアップです。製品の形式はMarkdown、JSON、プレーンテキスト、XML、PNGです。印刷できるページが必要なら、Chromeの印刷ダイアログを使ってください。PNGは画像で、これもPDFではありません。

DesktopでClaudeのチャットをXMLでエクスポートできますか？

いいえ。このChrome拡張機能が組み込まれるのはclaude.aiだけです。Claude Desktopに形式のドロップダウンは表示されません。同じスレッドがclaude.aiにあれば、Chromeでそこを開いてください。

1回だけXMLでエクスポートするのにProは必要ですか？

いいえ。最初の3回は、XMLを含むどの形式でも無料です。Pro（月額$3.99または年額$26.99）なら、単体や一括でさらに多くのXMLファイルを作れます。
