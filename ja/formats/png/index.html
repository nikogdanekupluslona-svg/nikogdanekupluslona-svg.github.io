ClaudeのチャットをPNGでダウンロードするには？

Chromeでclaude.aiの会話を開き、メッセージ入力欄の横にあるオレンジ色のボタンをクリックして、PNGを選び、「Export」をクリックします。Download Claude conversationsがタブの中で画像を描画します。これが、バージョン1.16.2でClaudeのチャットをPNGでダウンロードする方法です。無料・無制限で、アカウントも要りません。

  1. Chrome Web StoreからDownload Claude conversationsをインストールします。
  2. claude.aiを再読み込みし、空の入力画面のホームではなく、実際の会話のURLを開きます。
  3. メッセージ入力欄の右にある丸いオレンジ色のダウンロードボタンをクリックします。
  4. PNGを選びます。最後に使った形式が記憶されます。
  5. 「Export」をクリックします。ChromeがすぐにPNGをダウンロードします。

ClaudeのチャットをPNGでダウンロードするのに、Googleログインは不要です。1つのチャットのPNGエクスポートは無制限・匿名で、回数のカウントもなく、チャットについての情報がブラウザの外に出ることもありません。ログインが表示されるのは、PDFを選んだとき、「Export All」（すべてエクスポート）を実行したとき、Proを購入したときだけです。仕組み：仕組み。

オレンジ色のボタンが見当たらない場合は、会話のURLを開いていないか、インストール後にタブの再読み込みが必要か、拡張機能がChromeのパズルのメニューに隠れています。Download Claude conversationsを固定してから、claude.aiを再読み込みしてください。プロジェクト、Coworkのセッション、Claude Code on the web（claude.ai/code）も、ほかのチャットと同じようにエクスポートできます。Claude Desktopアプリや、ローカルのClaude Codeのターミナルセッションに、PNGでのエクスポートが表示されることはありません。

1枚か、たくさんか。オレンジ色のボタンは、開いているスレッドのPNGを1枚書き出します。多数の画像が必要なら、「View and Download All Conversations」（すべての会話を表示してダウンロード）を開き、PNGを選んで「Export All」を実行します。一括エクスポートはZIPで保存され、1日の一括エクスポートの枠を使います。「Export All」で一括エクスポートをご覧ください。

ClaudeのチャットのPNGには何が含まれる？

ClaudeのチャットのPNGは、Download Claude conversationsが描画した会話の内容の1枚の画像です。MarkdownやJSONと違い、PNGには解析できるメッセージのツリーはありません。コードや表はピクセルです。思考プロセスやアーティファクトは、テキストとして保存されるのではなく描画されます。

「Messages」のフィルターで、描画する内容をすべてのメッセージ、人間のみ、アシスタントのみ（「All」「Human」「Assistant」）に絞れます。「Thinking」（思考）のチェックボックスで拡張思考を含めるかどうかを決め、「Select」（選択）で個々のメッセージにチェックを入れられます。メタデータとアーティファクトのレイアウト（「Original」「Inline」「Nested」「Flat」＝元のまま／インライン／入れ子／フラット）は、「Export All」用のダッシュボードのオプションです。メタデータは、JSONのようにPNG上で選択できるテキストにはなりません。PNGでは「Copy」（コピー）は使えず、必ずファイルになります。

スレッドがとても長い場合は、PNGでダウンロードする前に、claude.aiが前のメッセージを読み込むまでスクロールしてください。拡張機能が描画できるのは、ページに読み込まれた内容だけです。半分しか読み込まれていないスレッドからは、途中で切れた画像ができます。設定の一覧：Chrome拡張機能の機能。

文章が大事なら、テキストのコピーも残しましょう。PNGはスナップショットです。後で関数名をgrepで探そうとしても見つかりません。2つ目のファイルとしてMarkdownかJSONもエクスポートしてください。PNGと同じく、無制限・無料です。

ClaudeのチャットをPNGで一括ダウンロードできる？

はい。「View and Download All Conversations」を開き、「Chat format」（チャット形式）をPNGにして、一覧を絞り込み、「Export All」をクリックします。選んだ会話1件につき1枚のPNGが入ったZIPが1つ保存されます。一括エクスポートにはGoogleログインが必要です。無料プランでは、ZIP内のチャット1件ごとに、PDFと共通の1日3回の枠を1回使います。Pro（月額$3.99または年額$26.99）なら、この上限はなくなります。

ダッシュボードにはclaude.aiの履歴が表示され、名前での検索、プロジェクトの検索、「Chat」と「Cowork」のタブ、「All conversations」「New」「Updated」「Previously exported」（すべての会話／新規／更新あり／エクスポート済み）のフィルターが使えます。「New」はDownload Claude conversationsでまだエクスポートしていないものです。「Export All」は、ZIPの中に、選んだ会話1件につき1枚のPNGを作ります。サムネイルを並べた1枚のまとめ画像でも、PDFの冊子でもありません。

一括エクスポートの枠は、UTCの午前0時（日本時間の午前9時）にリセットされます。無料プランでは、今日の残りより多く選ぶと、途中で切られるのではなく、全体がブロックされます。選ぶチャットを減らすか、Proを使ってください。オレンジ色のボタンからの1つのチャットのPNGは、引き続き無制限です。Anthropicの Settings → Privacy → Export data（claude.aiを日本語で表示している場合、ラベルは翻訳されていることがあります）は、引き続き時間をおいて届くJSONのZIPで、画像のフォルダーではありません。

PNGでのダウンロードに追加料金はかかる？

いいえ。PNGは、Markdown、JSON、テキスト、XML、CSVと同じく、無料・無制限です。Googleアカウントも回数のカウントもありません。Pro（Paddle経由で月額$3.99または年額$26.99）は、PDFと一括ZIPを無制限にするためのもので、PNGのためではありません。ClaudeのチャットをPNGでダウンロードするための追加料金はありません。

ログインが必要になるのは、PDFや「Export All」を使いたいときだけです。無料プランでは、この2つで1日3回のエクスポートを共有します。Proは、同じGoogleアカウントでログインすれば新しいパソコンでも復元されます。Paddleが販売者（Merchant of Record）であり、私たちがカード番号を見ることはありません。

拡張機能は、Chromeで開いたclaude.aiで動きます。通常のチャット、プロジェクト、Coworkのセッション、Claude Code on the web（claude.ai/code）です。Claude Desktopアプリや、ローカルのClaude Codeのターミナルセッションには、PNGのボタンはありません。2026年時点で、私たちのiOSやAndroidのアプリはありません。バージョン1.16.2はPDFに出力できますが、WordやNotionには出力しません。

Download Claude conversationsはPDFでエクスポートできますか？

はい。ページ番号や目次を付けられる、ページ分けされた文書が必要なら、エクスポートパネルでPDFを選びます。PNGはスレッドの1枚の画像です。PDFはGoogleログインが必要で1日3回まで無料、PNGはアカウント不要で無制限です。

履歴すべてをPNGでダウンロードできますか？

はい。ダッシュボードの「Export All」はPNGに対応していて、選んだ会話1件につき1枚の画像が入ったZIPを1つ作ります。一括エクスポートにはGoogleログインが必要で、無料プランではZIP内のチャット1件ごとに、PDFと共通の1日3回の枠を1回使います。Proなら無制限です。

PNGは無料ですか、それともPro限定ですか？

無料で、無制限です。1つのチャットのPNGエクスポートはアカウント不要で、回数のカウントもありません。Pro（月額$3.99または年額$26.99）は、PDFと一括ZIPを無制限にするためのものです。

ClaudeのチャットのPNGからコードをコピーできますか？

きれいにはできません。PNGで保存されるのはピクセルです。言語タグ付きのコードブロックが必要なら、MarkdownかJSONでエクスポートしてください。画像と検索できるテキストの両方が必要なら、両方のファイルを残しましょう。

PNGでのダウンロードはChromeのスクリーンショットですか？

いいえ。Download Claude conversationsは、claude.aiで解析した会話からPNGを描画します。それでも画像であり、Markdownファイルではありません。ウィンドウ全体のOSのスクリーンショットは、ご自身で撮る別のファイルです。

PNGのエクスポートの回数の数え方はMarkdownと同じですか？

はい。どちらも回数に数えられません。1つのチャットのPNGとMarkdownのエクスポートは、どちらも無制限・匿名です。上限は、無料プランでのPDFまたは一括ZIPの1日3回だけで、Proならそれもなくなります。
