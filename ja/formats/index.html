ここで使えるClaudeチャットのエクスポート形式は？

このサイトで紹介しているClaudeチャットのエクスポート形式は、Download Claude conversationsがclaude.aiのスレッドから書き出す7種類のファイル、PDF、Markdown、プレーンテキスト、JSON、XML、CSV、PNGです。バージョン1.16.2は、そのすべてをブラウザの中で作成します。6つはアカウント不要で無制限です。PDFはGoogleログインが必要で、1日3回まで無料です。

拡張機能は、Chromeでclaude.aiを開いたスレッドならどこでも使えます。通常のチャット、プロジェクト、Coworkのセッション、Claude Code on the web（claude.ai/code）です。Claude Desktopアプリや、ローカルのClaude Codeのターミナルセッションには、オレンジ色のボタンは表示されません。同じスレッドがclaude.aiのアカウントにあれば、ChromeでそのURLを開き、そこで形式を選んでください。ドロップダウンは最後に選んだ形式を記憶します。

「Claude Chat Downloader」や「Claude Conversation Downloader」という名前で検索される方もいますが、どちらもこの製品のことで、別のエクスポーターではありません。法的なページでは「Claude Exporter」と書かれている場合もあります。得られるファイルは同じ7つの形式です。

形式の一覧は1つ、入り口は2つ。オレンジ色のボタンは、開いているチャットをエクスポートします。ダッシュボードの「Export All」は、多数のチャットを1つのZIPにまとめます。チャットごとに1ファイルで、形式は「Chat format」（チャット形式）で選んだ7つのうちの1つです。PDFも選べます。詳しくは「Export All」で一括エクスポートをご覧ください。

どのエクスポート形式を選ぶべき？

読む・共有するならPDF、メモならMarkdown、スクリプトならJSON、表計算ならCSV、どこにでも貼れる保存用ならプレーンテキスト、システムがXMLを必要とするならXML、スレッドの画像が欲しいならPNGを選びます。Download Claude conversationsは、どれが一番とは決めていません。各形式の違いは中身の構造で、無料プランで1日の上限があるのはPDFだけです。

エクスポート形式はどうやって選ぶ？

Chromeでclaude.aiの会話のURLを開き、メッセージ入力欄の横にあるオレンジ色のボタンをクリックして、エクスポート形式を1つ選び、「Export」（エクスポート）をクリックします。Download Claude conversationsがタブの中でファイルを組み立てます。2026年9月時点で、claude.aiには「このチャットをエクスポート」のような標準機能はありません。

  1. Chrome Web StoreからDownload Claude conversationsをインストールします。
  2. claude.aiを再読み込みし、空の入力画面のホームではなく、実際の会話のURLを開きます。
  3. メッセージ入力欄の右にある丸いオレンジ色のダウンロードボタンをクリックします。
  4. PDF、Markdown、プレーンテキスト、JSON、XML、CSV、PNGから選びます。最後に選んだ形式が残ります。
  5. 「Export」をクリックします。Chromeがすぐにファイルを保存します。PDFの場合は、PDFダイアログでオプションを設定します。最初のPDFではGoogleログインを求められます。

Markdown、テキスト、JSON、XML、CSV、PNGにログインは不要です。これらのエクスポートは無制限・匿名で、何も送信しません。Googleログインが表示されるのは、PDF、「Export All」、Proのときだけです。そのとき拡張機能が送るのは、1日の上限の確認と、再インストール後のProの復元に使うGoogleのメールアドレスだけです。チャットの本文がアップロードされることはありません。仕組み：仕組み。

エクスポートパネルでは、「Messages」（「All」「Human」「Assistant」＝すべて／人間／アシスタント）、「Thinking」（思考）のチェックボックス、個々のメッセージにチェックを入れる「Select」（選択）も設定できます。「Copy」は、ファイルの代わりにMarkdown、テキスト、JSON、XML、CSVをクリップボードに送ります。回数は無制限で、PDFとPNGでは使えません。ツール／MCPのステップとWeb検索のソースは、設定（Settings）でオンにします。メタデータとアーティファクトのレイアウト（「Original」「Inline」「Nested」「Flat」＝元のまま／インライン／入れ子／フラット）はダッシュボードのオプションです。レイアウトによって、アーティファクトをファイルの中に入れるか、ZIPの中の専用フォルダーに分けるかが決まります。

エクスポート形式は「Export All」でも使える？

はい。拡張機能のポップアップから「View and Download All Conversations」（すべての会話を表示してダウンロード）を開き、一覧を絞り込んでチャットにチェックを入れ、「Chat format」で7つの形式のどれかを選んで、「Export All」をクリックします。チャットごとに1ファイルが入ったZIPが1つ保存されます。一括エクスポートにはGoogleログインが必要です。無料プランでは、ZIP内のチャット1件ごとに、PDFと共通の1日3回の枠を1回使います。Pro（月額$3.99または年額$26.99）なら、この上限はなくなります。

ダッシュボードにはclaude.aiの履歴が表示され、名前での検索、プロジェクトの検索、「Chat」と「Cowork」のタブ、「All conversations」「New」「Updated」「Previously exported」（すべての会話／新規／更新あり／エクスポート済み）のフィルターが使えます。「New」はDownload Claude conversationsでまだエクスポートしていないチャット、「Previously exported」は保存済みのチャットです。「Export All」は、時間をおいて届くアカウントのZIPではありません。

一括の上限は1日単位です。無料プランでは、PDFと一括エクスポートで1日3回を共有し、UTCの午前0時（日本時間の午前9時）にリセットされます。ZIP内のチャット1件が1回です。今日の残りより多く選ぶと、途中で切られるのではなく、全体がブロックされます。選ぶチャットを減らすか、Proを使ってください。

一括エクスポートには専用のチェックボックス「Chats」「Thinking」「Metadata」「Tools」「Sources」（チャット、思考、メタデータ、ツール、出典）と、アーティファクトのレイアウトがあります。1回のクリックでMarkdownとJSONを混ぜた束が得られるわけではありません。その実行で使うエクスポート形式を「Chat format」で1つ選びます。同じスレッドを2つの形式で欲しい場合は、別の形式でもう一度「Export All」を実行してください。無料プランでは、その2回目も回数に数えられます。

エクスポート形式とAnthropicのZIPの違いは？

Anthropicの Settings → Privacy → Export data（claude.aiを日本語で表示している場合、ラベルは翻訳されていることがあります）は、しばらく待った後に、アカウント全体のJSONのZIPをメールで送ります。Download Claude conversationsのエクスポート形式なら、開いているスレッドをすぐにPDF、Markdown、テキスト、JSON、XML、CSV、PNGで保存できます。バックアップにはZIPを、今すぐ必要なときはこの拡張機能を使ってください。

公式のZIPは、これらのエクスポート形式の見栄えを良くしたものではありません。そのリクエストでMarkdownやPDFを選ぶことはできません。一方、忘れていたスレッドまですべて1つのアーカイブに入れたい場合、Download Claude conversationsはそのZIPの代わりになりません。印刷は見た目のための回避策で、拡張機能自身のPDFのほうがきれいなファイルになります。

Download Claude conversationsはAnthropic, PBCとは提携していません。拡張機能を使っても、Anthropicの利用規約は変わりません。コンテンツスクリプトは、あなたがclaude.aiですでに開いているセッションを使います。ご自身のアカウントについてはAnthropicのルールに従ってください。

エクスポート形式の料金は？

6つのエクスポート形式は無料で、アカウントも要りません。Markdown、プレーンテキスト、JSON、XML、CSV、PNGは無制限です。PDFと一括ZIPは、Googleログインで合わせて1日3回まで無料です。Paddle経由のPro（月額$3.99または年額$26.99）なら、PDFと一括エクスポートが無制限になります。どの形式にも追加料金はかかりません。

1日の回数はUTCの午前0時にリセットされ、Googleアカウントごとに数えます。そのため、PDFと一括エクスポートではログインが必要です。Proは、同じGoogleアカウントでログインすれば新しいパソコンでも復元されます。Paddleが販売者（Merchant of Record）であり、私たちがカード番号を見ることはありません。解約はオプションページからいつでもでき、初回のお支払いには14日間の返金保証があります。

よくある質問：Claudeチャットのエクスポート形式

ここでは、Download Claude conversations 1.16.2のエクスポート形式についての質問に答えます。7つの形式の一覧、PDF、CSV、回数制限、「Export All」、AnthropicのZIP、DesktopとCode、Proについてです。どの回答も製品の事実に基づいています。ページのheadにあるFAQPageのJSON-LDはこの一覧と一致しています。

Claudeのチャットはどの形式でダウンロードできますか？

7つです。PDF、Markdown、プレーンテキスト、JSON、XML、CSV、PNGです。Markdown、テキスト、JSON、XML、CSV、PNGは無制限で、アカウントも要りません。PDFはGoogleログインが必要で、1日3回まで無料です。

エクスポート形式にPDFはありますか？

はい。エクスポートパネルでPDFを選びます。PDFダイアログでは、ファイル名、ページサイズ、余白、ライト／ダークモード、フォントとサイズ、ページ番号、目次、タイムスタンプ、各プロンプトの前の改ページを設定できます。PDFはブラウザの中で作成され、印刷ダイアログは使いません。

CSVエクスポートは何に使いますか？

表計算です。CSVは1メッセージを1行として書き出し、Excel、Googleスプレッドシート、Numbersで開けます。無制限でアカウントも要らず、ダウンロードの代わりにクリップボードへコピーすることもできます。

エクスポート形式に1日の上限はありますか？

PDFと一括エクスポートだけです。1つのチャットをMarkdown、テキスト、JSON、XML、CSV、PNGでエクスポートするのは無制限・無料です。無料プランでは、PDFと一括ZIPで1日3回を共有し、UTCの午前0時にリセットされます。Pro（月額$3.99または年額$26.99）なら上限はなくなります。

「Export All」で形式を混ぜられますか？

いいえ。1回の「Export All」で使える形式は1つで、書き出されるZIPも1つです。claude.aiの同じチャットについて2つのファイルが必要なら、別の形式でもう一度実行してください。無料プランでは、どのZIPでもチャット1件ごとに、PDFと一括エクスポートで共通の1日3回の枠を1回使います。

エクスポート形式はデータエクスポートと同じですか？

いいえ。Anthropicのデータエクスポートは、時間をおいて届くアカウントのJSONのZIPです。Download Claude conversationsのエクスポート形式は、チャットごと（または選択範囲ごと）のファイルを、Chromeの中ですぐに書き出します。

エクスポート形式はDesktopやCodeでも使えますか？

Webなら使えます。チャット、プロジェクト、Coworkのセッション、Claude Code on the web（claude.ai/code）では、Chromeですべての形式を使えます。Claude Desktopアプリと、ローカルのClaude Codeのターミナルセッションには、形式のドロップダウンは表示されません。同じスレッドがclaude.aiにあれば、Chromeでそこを開いてください。

エクスポート形式を試すのにProは必要ですか？

いいえ。無料プランでは、6つの形式がアカウント不要で無制限です。PDFはGoogleログインで1日3回まで無料で、この枠は一括ZIPと共通です。PDFや一括エクスポートを無制限に使いたいときは、Pro（月額$3.99または年額$26.99）をご利用ください。
