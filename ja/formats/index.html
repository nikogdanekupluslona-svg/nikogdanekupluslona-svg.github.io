ここで使えるClaudeチャットのエクスポート形式は？

このサイトで紹介しているClaudeチャットのエクスポート形式は、拡張機能がclaude.aiのスレッドから書き出す5種類のファイル、Markdown、JSON、プレーンテキスト、XML、PNGです。バージョン1.13.0にPDFの書き出し機能はありません。書き出しが完了したファイル1つが、無料エクスポート3回のうち1回になります。

この拡張機能が組み込まれるのはclaude.aiだけです。Claude DesktopやClaude Codeにオレンジ色のボタンは表示されません。同じスレッドがclaude.aiのアカウントにあれば、ChromeでそのURLを開き、そこで形式を選んでください。ドロップダウンは最後に選んだ形式を記憶します。

「Claude Chat Downloader」や「Claude Conversation Downloader」という名前で検索される方もいますが、どちらもこの製品のことで、別のエクスポーターではありません。法的なページでは「Claude Exporter」と書かれている場合もあります。得られるファイルは同じく、Markdown、JSON、テキスト、XML、PNGです。

形式の一覧は1つ、入り口は2つ。オレンジ色のボタンと「Export All」では、同じエクスポート形式を使います。一括エクスポートはチャットごとの多数のファイルで、形式が混ざった1つのZIPではありません。詳しくは「Export All」で一括エクスポートをご覧ください。

どのエクスポート形式を選ぶべき？

メモならMarkdown、スクリプトならJSON、どこにでも貼れる保存用ならプレーンテキスト、システムがXMLを必要とするならXML、スレッドの画像が欲しいならPNGを選びます。拡張機能はどれが一番とは決めていません。各形式の違いは中身の構造で、回数の消費は同じです。

拡張機能1.13.0のエクスポート形式
形式 向いている用途 ファイルの中身
Markdown Obsidian、GitHub、Wiki 見出し、コードブロック、表 — Markdownガイド

文章を書く人はたいていMarkdownに落ち着きます。開発者はたいていJSONに落ち着きます。PNGは5つの形式の中で唯一の画像で、後から検索したり、コードをきれいにコピーしたりはできません。印刷できるページが必要なら、Chromeの印刷ダイアログを使ってください。それはブラウザのスナップショットで、6つ目の形式ではありません。

私たちが提供するClaudeチャットのエクスポート形式は、Markdown、JSON、テキスト、XML、PNGの5つで、今もPDFは出力していません。オレンジ色のボタンと「Export All」のドロップダウンは同じなので、一括エクスポートで別の種類のファイルができることはありません。

エクスポート形式はどうやって選ぶ？

Chromeでclaude.aiの会話のURLを開き、メッセージ入力欄の横にあるオレンジ色のボタンをクリックして、エクスポート形式を1つ選び、「Export」（エクスポート）をクリックします。拡張機能がタブの中でファイルを組み立てます。2026年9月時点で、claude.aiには「このチャットをエクスポート」のような標準機能はありません。

  1. Chrome Web Storeから拡張機能をインストールします（評価5.0）。
  2. claude.aiを再読み込みし、空の入力画面のホームではなく、実際の会話のURLを開きます。
  3. メッセージ入力欄の右にあるオレンジ色のダウンロードボタンをクリックします。
  4. Markdown、JSON、プレーンテキスト、XML、PNGから選びます。最後に選んだ形式が残ります。
  5. 「Export」をクリックします。Chromeがすぐにファイルを保存します。

最初のエクスポートの前にGoogleログインが必要です。拡張機能は、無料エクスポート3回を数え、再インストール後にProを復元するために、確認済みのメールアドレスを保存します。チャットの本文はこのログインに含まれません。仕組み：仕組み。

同じウィジェットの設定は、どの形式にも適用されます。思考プロセスのオン／オフ、メタデータ（タイトル、タイムスタンプ、モデル）、送信者フィルター（すべて、人間のみ、アシスタントのみ）、アーティファクトのレイアウト（「Original」「Inline」「Nested」「Flat」＝元のまま／インライン／入れ子／フラット）です。PNGは画像として描画し、ほかの4つはテキストか構造化されたマークアップを書き出します。

エクスポート形式は「Export All」でも使える？

はい。「View and Download All Conversations」（すべての会話を表示してダウンロード）を開き、一覧表を絞り込んで、同じエクスポート形式のドロップダウンから選び、「Export All」をクリックします。書き出しが完了した各ファイルが無料エクスポート3回のうち1回になります。Pro（月額$3.99または年額$26.99）なら、一括でも単体でも上限はなくなります。

一覧表にはclaude.aiの履歴が表示され、名前で検索したり、「All」「New」「Exported」「Project」（すべて／未エクスポート／エクスポート済み／プロジェクト）で絞り込んだりできます。「New」はこの拡張機能でまだエクスポートしていないもの、「Exported」は保存済みのチャットです。「Project」はclaude.aiでのチャットのまとめ方に対応します。「Export All」は、時間をおいて届くアカウントのZIPではありません。

回数はアカウント全体で数えます。無料エクスポートは合計3回で、形式ごとに3回でも、一括エクスポート1回ごとに3回でもありません。40件の会話を選んですべてのファイルが完了すれば、40回分を使います。選択を計画するか、Proを使ってください。

一括エクスポートでも、1つの会話と同じ思考プロセス、メタデータ、送信者、アーティファクトの設定を使います。1回のクリックでMarkdownとJSONを混ぜた束が得られるわけではありません。その実行で使う形式を1つ選びます。同じスレッドを2つの形式で欲しい場合は、別の形式でもう一度「Export All」を実行してください。その2回目も回数を消費します。

エクスポート形式とAnthropicのZIPの違いは？

Anthropicの Settings → Privacy → Export data（claude.aiを日本語で表示している場合、ラベルは翻訳されていることがあります）は、しばらく待った後に、アカウント全体のJSONのZIPをメールで送ります。拡張機能のエクスポート形式なら、開いているスレッドをすぐにMarkdown、JSON、テキスト、XML、PNGで保存できます。バックアップにはZIPを、今すぐ必要なときはこの拡張機能を使ってください。

claude.aiからClaudeの会話を取り出す方法
方法 得られるもの 待ち時間
Download Claude conversations MD / JSON / TXT / XML / PNG なし — Chromeがファイルをダウンロード
Settings → Privacy → Export data メールで届くアカウントのJSONのZIP あり — リンクに有効期限あり。チャットごとのMarkdownはなし
印刷 → PDFとして保存 WebページのPDF なし。ただしコードやサイドバーが崩れがち
コピー＆ペースト 選択した部分だけ 長いスレッドでは構造が残らない

公式のZIPは、これらのエクスポート形式の見栄えを良くしたものではありません。そのリクエストでMarkdownを選ぶことはできません。一方、忘れていたスレッドまですべて1つのアーカイブに入れたい場合、拡張機能はそのZIPの代わりになりません。印刷は見た目のための回避策で、私たちが提供する形式ではありません。

この拡張機能はAnthropic, PBCとは提携していません。拡張機能を使っても、Anthropicの利用規約は変わりません。コンテンツスクリプトは、あなたがclaude.aiですでに開いているセッションを使います。ご自身のアカウントについてはAnthropicのルールに従ってください。

エクスポート形式ごとの料金は？

Googleでログインしたどのアカウントでも、3回まで無料でエクスポートできます。その後は、Paddle経由でProが月額$3.99または年額$26.99です。この料金で、すべてのエクスポート形式が使えます。JSONやPNGに追加料金はかかりません。

拡張機能を再インストールしても、無料エクスポート3回はリセットされません。そのため、最初に「Export」をクリックするときにGoogleログインが必要です。Proは、同じGoogleアカウントなら新しいパソコンでも復元されます。Paddleが販売者（Merchant of Record）であり、私たちがカード番号を見ることはありません。

このページの情報はバージョン1.13.0、2026年9月時点のものです。Claudeチャットのエクスポート形式は、引き続きMarkdown、JSON、プレーンテキスト、XML、PNGです。Notion、Word、PDFの直接出力はまだありません。この一覧が変わる場合は、その日のうちにこのページも更新します。

よくある質問：Claudeチャットのエクスポート形式

ここでは、拡張機能1.13.0のエクスポート形式についての質問に答えます。5種類のファイル、回数制限、「Export All」、AnthropicのZIP、Desktop、Proについてです。どの回答も製品の事実に基づいています。ページのheadにあるFAQPageのJSON-LDはこの一覧と一致しています。

Claudeのチャットはどの形式でダウンロードできますか？

Markdown、JSON、プレーンテキスト、XML、PNGです。この拡張機能はPDFを書き出しません。PNGはclaude.aiのスレッドの画像で、ページ分けされた文書ではありません。

エクスポート形式にPDFはありますか？

いいえ。製品のドロップダウンにPDFが表示されることはありません。PDFのようなページが必要なら、Chromeでclaude.aiのタブを印刷してください。そのファイルはブラウザのスナップショットで、この拡張機能によるエクスポートではありません。

どの形式でも無料エクスポート3回を共有しますか？

はい。Markdown、JSON、テキスト、XML、PNGは、ファイルが完成した時点でそれぞれ1回と数えます。Pro（月額$3.99または年額$26.99）なら、すべての形式で上限がなくなります。

「Export All」で形式を混ぜられますか？

いいえ。1回の「Export All」で使える形式は1つです。claude.aiの同じチャットについて2つのファイルが必要なら、別の形式でもう一度実行してください。完了した各ファイルは、やはり回数に数えられます。

エクスポート形式はデータエクスポートと同じですか？

いいえ。Anthropicのデータエクスポートは、時間をおいて届くアカウントのJSONのZIPです。拡張機能のエクスポート形式は、チャットごと（または選択範囲ごと）のファイルを、Chromeの中ですぐに書き出します。

エクスポート形式はDesktopやCodeでも使えますか？

いいえ。このChrome拡張機能が組み込まれるのはclaude.aiだけです。Claude DesktopやClaude Codeに形式のドロップダウンは表示されません。同じスレッドがclaude.aiにあれば、Chromeでそこを開いてください。

エクスポート形式を試すのにProは必要ですか？

いいえ。Googleでログインしたどのアカウントでも、最初の3回は形式を問わず無料です。単体や一括でそれ以上のファイルが必要になったら、Pro（月額$3.99または年額$26.99）をご利用ください。
