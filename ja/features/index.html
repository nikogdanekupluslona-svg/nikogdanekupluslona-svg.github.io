claude.aiをエクスポートするChrome拡張機能の機能一覧

Chrome拡張機能「Download Claude conversations」の機能は、claude.aiのスレッドに表示されるオレンジ色のボタン、「Export All」による一括エクスポート、PDFとCSVを含む7つの形式、「Select」（選択）と「Copy」（コピー）、アーティファクトのレイアウト、思考プロセス、そして設定です。ファイルはあなたのパソコンの中で作成されます。Markdown、テキスト、JSON、XML、CSV、PNGはアカウント不要で無制限です。PDFと一括ZIPは1日3回まで無料で、Pro（月額$3.99または年額$26.99）なら無制限です。

1つのチャットをエクスポートする機能は？

1つのスレッドを保存するための中心的な機能は、拡張機能がclaude.aiのメッセージ入力欄の横に追加するオレンジ色のボタンです。会話のURLを開き、形式を選んで、「Export」（エクスポート）または「Copy」をクリックします。ファイルはすぐにダウンロードされます。ログインが必要なのはPDFだけで、ほかの6つの形式にアカウントは要りません。

  1. Chrome Web Storeから拡張機能をインストールします。
  2. claude.aiを再読み込みし、実際の会話のURLを開きます。通常のチャット、プロジェクト内のチャット、Coworkのセッション、Claude Code on the webのいずれでもかまいません。
  3. メッセージ入力欄の右にあるオレンジ色のダウンロードボタンをクリックします。
  4. 「Messages」で「All」「Human」「Assistant」（すべて／人間／アシスタント）のいずれかを選び、形式と「Thinking」（思考プロセス）のチェックボックスを設定します。個別のメッセージだけを書き出すなら、「Select」をクリックしてチェックを入れます。最後に使った形式は記憶されます。
  5. 「Export」をクリックするとファイルがダウンロードされ、「Copy」をクリックするとクリップボードにコピーされます。「Copy」はMarkdown、テキスト、JSON、XML、CSVで使えます。

オレンジ色のボタンは、読み込まれた会話にだけ表示されます。空の入力画面のホームには、解析するものがありません。ボタンが見当たらない場合は、Chromeのパズルのメニューで拡張機能を固定し、claude.aiを再読み込みしてください。これらの機能がClaude DesktopやClaude Codeのターミナルに組み込まれることはありません。PDFを選ぶとダイアログが開き、ファイル名、用紙サイズ、余白、ライト／ダークモード、フォントと文字サイズ、ページ番号、目次、タイムスタンプ、プロンプトごとの改ページを設定できます。詳しくはClaudeのチャットをPDFで保存をご覧ください。

ローカルのファイル。PDF、Markdown、JSON、テキスト、XML、CSV、PNGは、タブの中で作成されます。PDF以外の形式で1つのチャットをエクスポートするときは、私たちのサーバーに何も送られません。PDFと一括エクスポートで送られるのは、1日の回数を数えるためのGoogleのメールアドレスだけです。チャットの本文が外に出ることはありません。仕組み：仕組み。

「Export All」に関する機能は？

一括エクスポートの機能は、ダッシュボード（「View and Download All Conversations」＝すべての会話を表示してダウンロード）にあります。検索、「All conversations / New / Updated / Previously exported」（すべての会話／新規／更新あり／エクスポート済み）のフィルター、「Chat」と「Cowork」のタブ、プロジェクトの検索、そして「Export All」（すべてエクスポート）です。「Export All」は1つのZIPとして保存されます。無料プランではGoogleログインで1日3チャットまで、Pro（月額$3.99または年額$26.99）なら上限はなくなります。

「New」は、この拡張機能でまだエクスポートしていないもの。「Previously exported」は保存済みのチャットを記録し、2回目の「Export All」でそれらを飛ばせるようにします。「Cowork」タブには、通常のチャットと並んでCoworkのセッションが表示されます。プロジェクトの検索では、claude.aiの1つのプロジェクトに入っているチャットを見つけられます。検索は会話の名前で行います。全体の流れ：「Export All」で一括エクスポート。

1日の上限はアカウントごとです。無料プランでは1日3チャットまでで、この枠はPDFと共通です。一括エクスポート1回ごとに3件ではありません。残りが3回のときに40件の会話を選ぶと、途中で切れるのではなく、一括エクスポート全体がブロックされます。「Export All」をクリックする前に選択を計画するか、Proを使ってください。

「Export All」では、ダッシュボードの「Chat format」（チャットの形式）ピッカー（PDFを含む7形式すべて）、「Chats」「Thinking」「Metadata」「Tools」「Sources」（チャット／思考プロセス／メタデータ／ツール／ソース）のチェックボックス、アーティファクトの形式を使います。できあがるのはチャットごとに1ファイルが入った1つのZIPで、Anthropicから時間をおいて届くアカウントのZIPではありません。1回の実行で選べる形式は1つです。1回のクリックでMarkdownとJSONを混ぜて書き出すことはできません。ダッシュボードにはバックアップと復元の機能もあります。

どの形式で書き出せる？

書き出せる形式は、PDF、Markdown、プレーンテキスト、JSON、XML、CSV、PNGの7つです。Markdown、テキスト、JSON、XML、CSV、PNGはアカウント不要で無制限です。PDFはブラウザの中で作成され、Googleログインが必要で、無料プランでは1日3回の枠に数えられます。オレンジ色のボタンでも、ダッシュボードの「Chat format」ピッカーでも一覧は同じです。形式ごとのページ：Claudeのチャットのエクスポート形式。

アーティファクトは保持される？

はい。アーティファクトのレイアウトとして「Original」「Inline」「Nested」「Flat」（元のまま／インライン／入れ子／フラット）を選べます。思考プロセスのブロック、ツール／MCPのステップ、Web検索のソースは、それぞれ任意で含められます。思考プロセスはエクスポートパネルのチェックボックスで、ツールとソースは設定でオンにします。ダッシュボードには3つすべてのチェックボックスがあります。メタデータでは、タイトル、タイムスタンプ、モデルを追加できます。送信者フィルターでは、ファイルの中身をすべて、人間のみ、アシスタントのみに絞れます。「Select」を使えば、個別のメッセージを選べます。

アーティファクトはclaude.aiのスレッドの一部です。レイアウトによって、Markdown、JSON、XML、テキストのファイルの中に入れるか、ZIPの中の専用フォルダーに分けるかが決まります。アーティファクトのZIPは無料で無制限です。プロジェクトのファイルのZIPも同じで、プロジェクトのページで「Project files」→「Download ZIP」（プロジェクトのファイル → ZIPをダウンロード）をクリックします。PNGでは、アーティファクトはマークアップとして保存されるのではなく、描画されます。思考プロセスをオフにすると、claude.aiの画面に拡張思考が表示されていてもエクスポートには含まれません。

スレッドが長い場合は、claude.aiが前のメッセージを読み込むまでスクロールしてください。この拡張機能がエクスポートできるのは、ページに表示された内容だけです。半分しか読み込まれていないDOMからは途中で切れたファイルができ、アーティファクトが欠けた不具合のように見えますが、たいていは会話をスクロールしていないことが原因です。

設定ページにある機能は？

設定は、拡張機能のオプションページです。ファイル名のテンプレート、「Copy instead of download」（ダウンロードせずにコピー）、Markdownへの画像の埋め込み、ツール／MCPのステップ、Web検索のソース、日付と時刻の形式、バックアップと復元、サブスクリプションが含まれます。拡張機能の画面は英語のみです。

ログインはどう扱われる？

ほとんどの機能にログインは要りません。Markdown、プレーンテキスト、JSON、XML、CSV、PNGでの1つのチャットのエクスポートは、回数無制限で匿名のまま使えます。「Copy」、「Select」、アーティファクトのZIP、プロジェクトのファイルのZIPも同じです。Googleログインを求められるのは、PDF、一括の「Export All」、Proのときだけです。会話の内容がこの流れに含まれることはありません。

PDFと一括ZIPは、無料プランで合わせて1日3回までです。回数はGoogleのメールアドレスごとに私たちのサーバーで数えます。1日の区切りはUTCの午前0時で、再インストールしてもリセットされません。ProはPaddle経由で月額$3.99または年額$26.99です。Paddleが販売者（Merchant of Record）であり、私たちがカード番号を見ることはありません。Proは、新しいパソコンでも同じGoogleアカウントでログインすれば復元されます。

Anthropicのclaude.aiの有料プランは必要ありません。Chromeでチャットを開ければ、claude.aiのFree、Pro、Team、Enterpriseのどのプランでも使えます。ワークスペースの管理者が拡張機能をブロックしている場合、拡張機能は組み込まれません。それはブラウザのポリシーによるもので、このページで説明している機能が欠けているわけではありません。

1.16.2にない機能は？

1.16.2にない機能は、Notionへのエクスポート、Wordへのエクスポート、Googleドキュメントへの送信、Claude Desktopとの連携、ローカルのClaude Codeのターミナルのセッション（/export、~/.claude/projects）です。この拡張機能はclaude.ai用のChromeのコンテンツスクリプトであり、別の名前を持つ2つ目のアプリではありません。PDFはもうこの一覧に入っていません。標準で搭載されています。

Claude DesktopはMac／Windowsのアプリ、ターミナルのClaude Codeはローカルのエージェントです。どちらにもオレンジ色のボタンは表示されません。Claude Code on the web（claude.ai/code）とCoworkのセッションはclaude.aiで開くので、ほかのチャットと同じようにエクスポートできます。Desktopのスレッドがclaude.aiにもあるなら、Chromeで開いてそこで拡張機能の機能を使ってください。Desktopとの違い：Claude Desktopのチャットをエクスポートする。Codeとの違い：Claude Codeのエクスポート。

スマートフォンのブラウザで開いたモバイル版claude.aiは対象外です。2026年時点で、私たちのiOSやAndroidのアプリはありません。「Copy」はPDFとPNGでは使えません。このページの情報は2026年9月時点のものです。形式を追加した場合は、その日のうちにこのページを更新します。

よくある質問：Chrome拡張機能の機能

ここでは、拡張機能1.16.2の機能についての質問に答えます。オレンジ色のボタン、「Export All」、形式、アーティファクト、無料プラン、Desktop、Proについてです。どの回答も製品の事実に基づいています。ページのheadにあるFAQPageのJSON-LDは、このページの一覧と一致しています。

1つのチャットをエクスポートする機能は？

claude.aiの会話のURLで、メッセージ入力欄の横に表示されるオレンジ色のボタンです。PDF、Markdown、JSON、テキスト、XML、CSV、PNGのいずれかを選び、「Export」または「Copy」をクリックします。1つのスレッドを保存する最も速い方法で、ログインが必要なのはPDFだけです。

「Export All」による一括エクスポートも含まれますか？

はい。ダッシュボード（「View and Download All Conversations」）に、claude.aiの履歴が「All conversations」「New」「Updated」「Previously exported」のフィルター、「Chat」と「Cowork」のタブ、プロジェクトの検索とともに表示されます。「Export All」は1つのZIPとして保存されます。無料プランではGoogleログインで1日3チャットまで、Proなら無制限です。

どの形式に対応していますか？

PDF、Markdown、プレーンテキスト、JSON、XML、CSV、PNGの7つです。PDFは専用のダイアログを使い、ブラウザの中で作成されます。CSVは1メッセージが1行です。PNGは会話全体を1枚にした画像です。

アーティファクトや思考プロセスもエクスポートできますか？

はい。アーティファクトのレイアウトは「Original」「Inline」「Nested」「Flat」から選べ、アーティファクトをZIPの中の専用フォルダーに分けることもできます。思考プロセス、ツール／MCPのステップ、Web検索のソースは、それぞれ任意で含められます。メタデータ、送信者フィルター、「Select」も任意です。

無料で試せますか？

はい。Markdown、テキスト、JSON、XML、CSV、PNGのエクスポートは回数無制限で、アカウントも要りません。PDFと一括ZIPは、Googleログインで1日3回までです。Paddle経由のPro（月額$3.99または年額$26.99）なら、この上限がなくなります。

DesktopやCodeでも使えますか？

Claude DesktopとClaude Codeのターミナルでは使えません。コンテンツスクリプトが組み込まれるのは、Chromeで開いたclaude.aiだけです。Claude Code on the web（claude.ai/code）とCoworkのセッションはclaude.aiで動くので、エクスポートできます。Desktopのスレッドがclaude.aiにもあれば、そこで開いてください。

チャットがアップロードされることはありますか？

いいえ。PDFを含むすべてのファイルは、ブラウザの中で作成されます。PDF以外の形式で1つのチャットをエクスポートするときは、何も送られません。PDF、一括エクスポート、Proでは、1日の回数とサブスクリプションの確認のために、Googleのメールアドレスだけが送られます。境界については「仕組み」のページをご覧ください。
