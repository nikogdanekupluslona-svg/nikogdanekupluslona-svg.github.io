claude.aiをエクスポートするChrome拡張機能の機能一覧

Chrome拡張機能「Download Claude conversations」の機能は、claude.aiのスレッドに表示されるオレンジ色のボタン、「Export All」による一括エクスポート、5つの形式、アーティファクトのレイアウト、思考プロセス、送信者フィルター、そして回数管理のためのGoogleログインです。ファイルはあなたのパソコンから出ません。3回まで無料でエクスポートでき、Proは月額$3.99または年額$26.99です。1.13.0にPDFの書き出し機能はありません。

1つのチャットをエクスポートする機能は？

1つのスレッドを保存するための中心的な機能は、拡張機能がclaude.aiのメッセージ入力欄の横に追加するオレンジ色のボタンです。会話のURLを開き、Markdown、JSON、テキスト、XML、PNGのいずれかを選んで、「Export」（エクスポート）をクリックします。ファイルはすぐにダウンロードされます。

  1. Chrome Web Storeから拡張機能をインストールします（評価5.0）。
  2. claude.aiを再読み込みし、空の入力画面のホームではなく、実際の会話のURLを開きます。
  3. メッセージ入力欄の右にあるオレンジ色のダウンロードボタンをクリックします。
  4. 形式を選びます。最後に使った形式が記憶されます。
  5. 「Export」をクリックします。Chromeがブラウザのダウンロード機能でファイルを保存します。

オレンジ色のボタンは、読み込まれた会話にだけ表示されます。空の入力画面のホームには、解析するものがありません。ボタンが見当たらない場合は、Chromeのパズルのメニューで拡張機能を固定し、claude.aiを再読み込みしてください。これらの機能がClaude DesktopやClaude Codeに組み込まれることはありません。

ローカルのファイル。Markdown、JSON、テキスト、XML、PNGは、タブの中で作成されます。回数の確認は私たちのサーバー（worker）に送られますが、チャットの本文は送られません。仕組み：仕組み。

「Export All」に関する機能は？

一括エクスポートの機能は「View and Download All Conversations」（すべての会話を表示してダウンロード）画面にあります。claude.aiの履歴を検索できる一覧表、「All / New / Exported / Project」（すべて／未エクスポート／エクスポート済み／プロジェクト）のフィルター、そして「Export All」（すべてエクスポート）です。書き出しが完了した各ファイルが、無料エクスポート3回のうち1回になります。Pro（月額$3.99または年額$26.99）なら上限はなくなります。

「New」は、この拡張機能でまだエクスポートしていないもの。「Exported」は保存済みのチャットを記録し、2回目の「Export All」でそれらを飛ばせるようにします。「Project」はclaude.aiでのチャットのまとめ方に対応します。検索は会話の名前で行います。全体の流れ：「Export All」で一括エクスポート。

回数はアカウント全体で数えます。無料エクスポートは合計3回で、一括エクスポート1回ごとに3回ではありません。40件の会話を選んですべてのファイルが完了すれば、40回分を使います。「Export All」をクリックする前に選択を計画するか、Proを使ってください。

「Export All」でも、1つの会話と同じ思考プロセス、メタデータ、送信者、アーティファクトの設定を使います。できあがるのはチャットごとの多数のファイルで、Anthropicから時間をおいて届くアカウントのZIPではありません。1回の実行で選べる形式は1つです。1回のクリックでMarkdownとJSONを混ぜて書き出すことはできません。

どの形式で書き出せる？

書き出せる形式は、Markdown、JSON、プレーンテキスト、XML、PNGの5つです。オレンジ色のボタンでも「Export All」でも一覧は同じです。バージョン1.13.0にPDFはありません。書き出しが完了したファイル1つが1回のエクスポートです。形式ごとのページ：Claudeのチャットのエクスポート形式。

この拡張機能の機能は、あえて絞り込んでいます。ページに表示されているclaude.aiのスレッドから5種類のファイルを作ること、それに一括の「Export All」と、ファイルの中身を変える設定だけです。今もPDF、Notion、Wordには対応していません。変わるときは、その日のうちにこのページも更新します。

アーティファクトは保持される？

はい。アーティファクトのレイアウトとして「Original」「Inline」「Nested」「Flat」（元のまま／インライン／入れ子／フラット）を選べます。思考プロセスは、調査の経緯を残したいときのためのオプションです（「include thinking」）。メタデータ（「include metadata」）では、タイトル、タイムスタンプ、モデルを追加できます。送信者フィルターでは、ファイルの中身をすべて、人間のみ、アシスタントのみ（「all / human only / assistant only」）に絞れます。

アーティファクトはclaude.aiのスレッドの一部で、別のダウンロードではありません。レイアウトによって、Markdown、JSON、XML、テキストの中での配置が変わります。PNGでは、マークアップとして保存されるのではなく、描画されます。思考プロセスをオフにすると、claude.aiの画面に拡張思考が表示されていてもエクスポートには含まれません。

スレッドが長い場合は、claude.aiが前のメッセージを読み込むまでスクロールしてください。この拡張機能がエクスポートできるのは、ページに表示された内容だけです。半分しか読み込まれていないDOMからは途中で切れたファイルができ、アーティファクトが欠けた不具合のように見えますが、たいていは会話をスクロールしていないことが原因です。

ログインはどう扱われる？

最初のエクスポートからGoogleログインが必要です。このログインは、アカウントごとの無料エクスポート3回を数えることと、再インストール後にProを復元することに使われます。会話の内容がこの流れに含まれることはありません。拡張機能は、回数とサブスクリプションの状態を管理するために、Googleで確認されたメールアドレスを保存します。

拡張機能を再インストールしても、無料エクスポート3回はリセットされません。それがログインの目的です。ProはPaddle経由で月額$3.99または年額$26.99です。Paddleが販売者（Merchant of Record）であり、私たちがカード番号を見ることはありません。Proは、同じGoogleアカウントなら新しいパソコンでも復元されます。

Anthropicのclaude.aiの有料プランは必要ありません。Chromeでチャットを開ければ、claude.aiのFree、Pro、Team、Enterpriseのどのプランでも使えます。ワークスペースの管理者が拡張機能をブロックしている場合、拡張機能は組み込まれません。それはブラウザのポリシーによるもので、このページで説明している機能が欠けているわけではありません。

1.13.0にない機能は？

1.13.0にない機能は、PDFの直接出力、Notionへのエクスポート、Wordへのエクスポート、Googleドキュメントへの送信、Claude Desktopとの連携、Claude Codeの /export です。この拡張機能はclaude.ai用のChromeのコンテンツスクリプトであり、別の名前を持つ2つ目のアプリではありません。

Claude DesktopはMac／Windowsのアプリ、Claude Codeはターミナルのエージェントです。どちらにもオレンジ色のボタンは表示されません。スレッドがclaude.aiにもあるなら、Chromeで開いてそこで拡張機能の機能を使ってください。Desktopとの違い：Claude Desktopのチャットをエクスポートする。Codeとの違い：Claude Codeのエクスポート。

スマートフォンのブラウザで開いたモバイル版claude.aiは対象外です。2026年時点で、私たちのiOSやAndroidのアプリはありません。このページの情報は2026年9月時点のものです。形式を追加した場合は、その日のうちにこのページを更新します。それまでは、ドロップダウンにPDFが出てくることは期待しないでください。

よくある質問：Chrome拡張機能の機能

ここでは、拡張機能1.13.0の機能についての質問に答えます。オレンジ色のボタン、「Export All」、形式、アーティファクト、回数制限、Desktop、Proについてです。どの回答も製品の事実に基づいています。ページのheadにあるFAQPageのJSON-LDは、このページの一覧と一致しています。

1つのチャットをエクスポートする機能は？

claude.aiの会話のURLで、メッセージ入力欄の横に表示されるオレンジ色のボタンです。Markdown、JSON、テキスト、XML、PNGのいずれかを選び、「Export」をクリックします。1つのスレッドを保存する最も速い方法です。

「Export All」による一括エクスポートも含まれますか？

はい。すべての会話の一覧画面に、claude.aiの履歴が「All」「New」「Exported」「Project」のフィルター付きで表示されます。「Export All」は、選んだチャット1件につき1ファイルを書き出します。Proでない場合、各ファイルが無料エクスポート3回のうち1回になります。

どの形式に対応していますか？

Markdown、JSON、プレーンテキスト、XML、PNGです。PDFはありません。PNGは画像です。PDFのようなページが必要なら、Chromeでclaude.aiのタブを印刷してください。

アーティファクトや思考プロセスもエクスポートできますか？

はい。アーティファクトのレイアウトは「Original」「Inline」「Nested」「Flat」から選べます。思考プロセスはオン／オフを切り替えられます。メタデータと送信者フィルターは任意です。同じ設定が「Export All」にも適用されます。

無料で試せますか？

はい。Googleでログインしたどのアカウントでも、形式を問わず3回まで無料でエクスポートできます。単体や一括でそれ以上のファイルが必要なら、Paddle経由のPro（月額$3.99または年額$26.99）をご利用ください。

DesktopやCodeでも使えますか？

いいえ。コンテンツスクリプトが組み込まれるのは、Chromeで開いたclaude.aiだけです。Claude DesktopやClaude Codeにオレンジ色のボタンは表示されません。同じスレッドがclaude.aiにあれば、そこで開いてください。

チャットがアップロードされることはありますか？

いいえ。ファイルはブラウザの中で作成されます。Googleログインでは、回数管理とProの復元のために確認済みのメールアドレスを保存します。チャットの本文が私たちのサーバーに送られることはありません。境界については「仕組み」のページをご覧ください。
