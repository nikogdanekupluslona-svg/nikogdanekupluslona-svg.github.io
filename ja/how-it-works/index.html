claude.aiで拡張機能はどう動く？

claude.aiでの仕組みはこうです。拡張機能は、あなたがすでに開いているページに、すでにログインしているセッションを使ってコンテンツスクリプトを組み込みます。読み取るのは表示された会話で、Anthropicの別のAPIではありません。オレンジ色のボタンは、実際の会話のURLにだけ表示されます。通常のチャット、プロジェクト内のチャット、Coworkのセッション、Claude Code on the webが対象です。

  1. Chrome Web Storeから拡張機能をインストールします。
  2. インストール中にタブを開いていた場合は、claude.aiを再読み込みします。
  3. 会話のURLを開きます。オレンジ色のボタンはメッセージ入力欄の右にあります。
  4. PDF、Markdown、JSON、プレーンテキスト、XML、CSV、PNGのいずれかを選び、「Export」（エクスポート）をクリックします。クリップボードに入れる場合は「Copy」（コピー）をクリックします。
  5. Chromeがファイルをダウンロードします。PDF以外の形式なら、ブラウザ側の処理はこれですべてです。ログインも、私たちのサーバーへの通信もありません。

空の入力画面のホームにはメッセージのツリーがないため、ボタンは表示されません。アイコンが隠れている場合は、Chromeのパズルのメニューで拡張機能を固定してから、claude.aiを再読み込みしてください。この仕組みはclaude.aiで完結しており、Claude DesktopやClaude Codeのターミナルにこのスクリプトが組み込まれることはありません。機能の一覧：Chrome拡張機能の機能。

同じセッション、同じページ。コンテンツスクリプトに見えるのは、ログイン済みのclaude.aiのタブにすでに表示されている内容です。別のパスワードでAnthropicにログインすることはありません。ご自身のアカウントについてはAnthropicのルールに従ってください。

ファイルはローカルで作られる？

はい。PDFを含むすべての形式がブラウザの中で組み立てられ、Chromeのダウンロード機能に渡されます。会話のテキストがあなたの端末を離れて私たちのインフラに届くことはありません。オレンジ色のボタンで1件エクスポートする場合も、一括エクスポートのページで「Export All」（すべてエクスポート）を使う場合も同じです。

claude.aiがスレッドを読み込んでしまえば、ファイルの生成に私たちのサーバーを待つことはありません。PDFと一括エクスポートでは、先に回数の確認が別に行われます。ほかの形式で1つのチャットをエクスポートする場合、この確認はありません。Chromeがclaude.aiからのダウンロードをブロックしている場合は許可してください。それはブラウザの設定で、解析の失敗ではありません。長いスレッドを途中までしかスクロールしていないと、DOMが不完全なので、やはり途中までのファイルになります。

私たちはこの拡張機能の仕組みを、はっきりした線引きのもとに作りました。チャットの本文はタブの中にとどまります。サーバー（worker）が答えるのは「今日のPDFと一括エクスポートはあと何回か」と「このGoogleアカウントはProか」だけです。PDFもブラウザの中でレイアウトされ、印刷ダイアログもアップロードもありません。

PNGは画像としてローカルで描画されます。PDFもローカルでレイアウトされます。JSON、XML、CSVは、同じツリーからローカルでシリアライズされます。これらのファイルを私たちがメールで送ることはありません。Anthropicの Settings → Privacy → Export data（claude.aiを日本語で表示している場合、ラベルは翻訳されていることがあります）は、Anthropicから時間をおいて届く別のZIPで、このローカルの処理とは関係ありません。

回数管理にGoogleログインを使うのはなぜ？

Googleログインが必要なのは、PDF、一括の「Export All」、Proのときだけです。Markdown、プレーンテキスト、JSON、XML、CSV、PNGで1つのチャットをエクスポートする場合は、ログインを求められることも、何かが送られることもありません。初めてPDFを選んだとき、または初めて「Export All」を実行したときに、ログインを求められます。私たちが保存するのは確認済みのメールアドレスで、チャットのテキストは保存しません。

メールアドレスは、サーバー側の1日の回数カウンターに紐づけられます。無料プランでは、PDFと一括エクスポートを合わせて1日3回までで、UTCの午前0時にリセットされます。一括ZIPでは、チャット1件が1回に数えられます。一括エクスポートで選んだ件数がその日の残りより多い場合、途中で切れるのではなく、一括エクスポート全体がブロックされます。カウンターは私たちのworkerにあるため、拡張機能を削除して入れ直してもリセットされません。Pro（月額$3.99または年額$26.99）は、同じGoogleアカウントなら新しいパソコンでも復元されます。

Googleログインはclaude.aiへのログインではありません。Webサイトでは引き続きAnthropicのセッションを使います。拡張機能がGoogleを必要とするのは、1日の回数とProを紐づけるためだけです。「Claude Chat Downloader」という名前で検索される方もいますが、同じ拡張機能なので、ログインのルールも同じです。

1日の上限はアカウントごとです。無料プランでは、PDFと一括エクスポートを合わせて1日3回までです。残りが3回のときに40件の会話を選ぶと、最初の3件だけがエクスポートされるのではなく、一括エクスポート全体がブロックされます。ログインは、このカウンターを再インストール後も保つための仕組みです。

PaddleとProの支払いの仕組みは？

Paddle.com Market Limitedが決済代行業者であり、販売者（Merchant of Record）です。支払いの仕組みはこうです。Paddleがカード情報と税金を処理し、私たちが支払い情報を見ることはありません。Proは月額$3.99または年額$26.99です。解約はいつでも、拡張機能のオプションページ（「Cancel subscription」＝サブスクリプションを解約）またはPaddleからできます。初回のお支払いには14日間の返金保証があります。

Proでは、PDFと「Export All」の1日3回の上限がなくなります。それ以外の機能は、無料プランですでに無制限です。ProでNotionやWordが追加されるわけではありません。形式は、PDF、Markdown、JSON、テキスト、XML、CSV、PNGの同じ7つです。Anthropicのclaude.aiの有料プランは必要ありません。Chromeでスレッドを読み込めるclaude.aiのログインがあれば十分です。

エクスポート中、サーバーには何が見える？

Cloudflare Workerが、サブスクリプションと回数の状態、つまりGoogleでログインしたアカウントがProかどうかと、今日PDFや一括エクスポートを何回使ったかを確認します。受け取るのはアカウントのメールアドレスだけで、それもPDF、一括エクスポート、Proのためにログインした後に限られます。このworkerが会話の内容を受け取ることはありません。ほかの形式での1つのチャットのエクスポートが、workerに届くことはありません。

再インストールしても1日の回数がリセットされないのは、このworkerがあるからです。Proが復元されるのもそのためです。チャットのバックアップではありません。claude.aiの履歴は引き続きAnthropic側にあり、私たちが2つ目のコピーを持つことはありません。保存するメールアドレスについては、このサイトのプライバシーポリシーに記載しています。

バージョン1.16.2、2026年9月時点の情報です。workerに接続できない場合、状態を確認できるまでPDFや一括エクスポートを始められないことがあります。それはライセンスの確認のためで、スレッドのアップロードが必要なわけではありません。確認が成功すれば、ファイルはローカルで組み立てられます。ほかの形式での1つのチャットのエクスポートは、この確認を待ちません。

このClaudeチャットエクスポーターは安全？

すべての経路で「通信はゼロ」とは言いません。Markdown、テキスト、JSON、XML、CSV、PNGで1つのチャットをエクスポートする場合、私たちへの通信はありません。PDF、一括エクスポート、ProではGoogleと私たちのworkerと、ProではさらにPaddleと通信します。チャットの本文は私たちのAPIに送られませんが、アカウントのメールアドレスと回数の状態は送られます。スクリプトが、あなたのAnthropicアカウントで余計な操作を自動で行うことはありません。

拡張機能は私のチャットを保存しますか？

いいえ。PDFを含むすべてのエクスポートはローカルで作られ、アップロードされることはありません。PDF、一括エクスポート、ProのためにGoogleでログインした場合、私たちはそのメールアドレスを、1日の回数を数えてProを紐づけるためだけに保存します。チャットの本文は、claude.aiのタブと、Chromeがダウンロードしたファイルの中にとどまります。

Googleログインは必須ですか、任意ですか？

必要なのは、PDF、一括の「Export All」、Proのときだけです。Markdown、テキスト、JSON、XML、CSV、PNGで1つのチャットをエクスポートする場合、アカウントは要りません。PDFと一括エクスポートでは、再インストールで1日3回のカウンターがリセットされないよう、初回からログインを求めます。チャットを読むためのログインではありません。

Proの支払いは誰が処理しますか？

Paddleです。私たちがカード情報を見ることはありません。Proは月額$3.99または年額$26.99です。Paddleが販売者（Merchant of Record）です。返金はPaddleを通じて行います。

Anthropicと提携していますか？

いいえ。独立したChrome拡張機能であり、Anthropic, PBCとは提携していません。ClaudeはAnthropicの商標です。この拡張機能は既存のclaude.aiのセッションを使うもので、Anthropicの製品に代わるものではありません。

PDF形式はありますか？

はい。PDFは、ほかの6つの形式（Markdown、JSON、プレーンテキスト、XML、CSV、PNG）と同じようにブラウザの中で作られます。印刷ダイアログは使いません。PDFにはGoogleログインが必要で、無料プランでは1日3回の枠に数えられます。

エクスポート時、workerには何が見えますか？

PDF、一括エクスポート、Proのためにログインした後に限り、アカウントのメールアドレス、Proかどうか、今日PDFや一括エクスポートを何回使ったかが見えます。workerが会話の内容を受け取ることはありません。エクスポートの処理はブラウザの中にとどまります。

使うのにProは必要ですか？

いいえ。Markdown、テキスト、JSON、XML、CSV、PNGで1つのチャットをエクスポートするのは、回数無制限で無料、アカウントも要りません。PDFと一括ZIPは、Googleログインで1日3回まで無料です。Pro（月額$3.99または年額$26.99）なら、この上限がなくなります。ローカルでファイルを作る仕組みは、無料でもProでも同じです。
