ChromeでのClaudeの会話エクスポートの仕組みは？

Chromeでclaude.aiの会話URLを開き、メッセージ入力欄の右側にあるオレンジ色のボタンをクリックし、PDF、Markdown、JSON、テキスト、XML、CSV、PNGから選んで「Export」を押します。Download Claude conversationsが会話のファイルをローカルに書き出します。インストール後はclaude.aiを再読み込みしてください。claude.aiには、スレッドごとにエクスポートする機能はありません。

  1. Chrome Web StoreからDownload Claude conversationsをインストールします（バージョン1.16.2）。
  2. コンテンツスクリプトが会話URLに読み込まれるよう、claude.aiのタブを再読み込みします。
  3. claude.aiの何も入力していないホーム画面ではなく、実際の会話を開きます。
  4. メッセージ入力欄の右側にあるオレンジ色のダウンロードボタンをクリックします。
  5. 「Messages」（メッセージ）を「All」「Human」「Assistant」（すべて／ユーザー／アシスタント）から選び、必要なら「Thinking」（思考）にチェックを入れます。PDF、Markdown、JSON、プレーンテキスト、XML、CSV、PNGから形式を選び、「Export」をクリックします。

Markdown、テキスト、JSON、XML、CSV、PNGで会話をエクスポートするのに、アカウントは必要ありません。これらの単体エクスポートは無制限で、当方のサーバーには何も送信されません。Googleサインインが求められるのは、PDFと一括の「Export All」（すべてエクスポート）だけで、無料プランではこの2つを合わせて1日3回まで使えます。このGoogleサインインに会話の本文が含まれることはありません。仕組みの詳細：仕組み。

オレンジ色のボタンが表示されない場合は、タブがclaude.aiの会話URLを開いていない、インストール後にページを再読み込みしていない、または拡張機能がChromeのパズルピースのメニューに隠れています。拡張機能を固定してから再読み込みしてください。オレンジ色のボタンが他のWebサイトに表示されることはありません。

形式の選択は、前回選んだものが記憶されます。「Select」（選択）では個々のメッセージにチェックを入れられ、「Copy」（コピー）ではファイルの代わりにMarkdown、テキスト、JSON、XML、CSVをクリップボードに入れられます。ファイルが不完全なのは、たいていclaude.aiの長いスレッドがまだメッセージツリーを表示し終えていなかったためです。少し待ってから、もう一度「Export」をクリックしてください。

1件の会話か、アカウント全体か。オレンジ色のボタンは、開いているスレッドの会話をエクスポートします。多数のファイルが必要なら、拡張機能のポップアップ →「View and Download All Conversations」（すべての会話を表示・ダウンロード）を開いて「Export All」を実行します。AnthropicのSettings → Privacy → Export data（claude.aiを日本語表示にしている場合、メニュー名は日本語で表示されることがあります）は後から届くアカウント全体のJSON ZIPで、このChromeでの流れとは別物です。

Claudeの会話エクスポートでファイルに残るものは？

この拡張機能でエクスポートした会話ファイルには、claude.aiにすでに表示されているメッセージツリーが残ります。送信者、コードブロック、表、任意で思考、メタデータ、アーティファクトの配置です。サイドバーのスクリーンショットではありません。画像が欲しいときはPNG、ページ分けされた文書ならPDFを選びます。バージョン1.16.2では、PDFもブラウザ内で作成します。

claude.aiからコピー＆ペーストすると、インデントが失われ、表が崩れます。印刷（Ctrl/Cmd+P）ではclaude.aiの画面要素が残り、長いコードブロックがページの途中で分かれることがよくあります。この拡張機能なら、Markdown、JSON、XMLでコードブロックの言語タグが保たれ、表は表のまま残ります。PNGはスレッドの画像で、ページ分けされたPDFではありません。

バージョン1.16.2では、拡張思考はエクスポートパネルのチェックボックスで含められ、Web検索の出典とツール／MCPのステップは設定でオンにできます。メタデータにはタイトル、タイムスタンプ、モデルを含められます。「Messages」フィルターで、会話ファイルをすべてのメッセージ、ユーザーのみ、アシスタントのみに絞れ、「Select」では個々のメッセージを選べます。「Export All」でのアーティファクトの配置（「Original」「Inline」「Nested」「Flat」＝元の配置／インライン／入れ子／フラット）は、ダッシュボードで設定します。

私たちはClaudeの会話エクスポートを、claude.aiのオレンジ色のボタンを中心に作りました。画面に表示されている会話から、スレッドをアップロードせずにPDF、Markdown、JSON、テキスト、XML、CSV、PNGを書き出します。バージョン1.16.2では、PDFもブラウザ内で作成します。

Claudeの会話をMarkdownでエクスポートするには？

Claudeの会話をMarkdownでエクスポートするのは、文章を書く人向けの使い方です。オレンジ色のボタンを開き、ドロップダウンでMarkdownを選んで「Export」を押します。Download Claude conversationsでは、同じclaude.aiのスレッドからPDF、JSON、プレーンテキスト、XML、CSV、PNGも書き出せます。Markdownは無制限で、アカウントも必要ありません。

会話をメモとしてエクスポートするなら、文章を書く人はたいていMarkdownを選びます。機械で読める会話ファイルが必要な開発者は、たいていJSONを選びます。プレーンテキストはマークアップなしのアーカイブ、XMLはタグが必要なデータ交換用、CSVは表計算用に1メッセージを1行にしたもの、PNGはスクリーンショットのようなファイル、PDFはページ分けされた文書です。1.16.2では、Word、Notion、Googleドキュメントへの書き出しはありません。

ページ分けされた文書が必要なら、同じドロップダウンでPDFを選んでください。PDFはブラウザ内で作られ、用紙サイズ、余白、ライト／ダークモード、ページ番号、目次を設定できます。手順：ClaudeのチャットをPDFでダウンロード。この拡張機能で作るPNGは画像ファイル1枚です。エクスポートしたMarkdownは、後からWord、Googleドキュメント、Markdownアプリで変換することもできます。

Markdown、JSON、テキスト、XML、CSV、PNGのダウンロードは無制限で、アカウントも必要ありません。同じclaude.aiの会話を別の形式でもう一度エクスポートしても、費用はかかりません。PDFはGoogleサインインが必要で、無料プランでは1件ごとに1日3回の枠を1回使います。Pro（月額$3.99または年額$26.99）にすると、この上限がなくなります。

「Export All」でClaudeの会話履歴をエクスポートできますか？

はい。拡張機能のポップアップ →「View and Download All Conversations」を開いて絞り込み、「Export All」をクリックすれば、Claudeの会話履歴をスレッドごとのファイルを入れたZIPとしてエクスポートできます。一括エクスポートにはGoogleサインインが必要です。無料プランでは、ZIPに入る会話1件ごとに、PDFと共通の1日3回の枠を1回使います。Pro（月額$3.99または年額$26.99）にすると、一括の上限がなくなります。

ダッシュボードには、claude.aiの会話履歴が一覧で表示されます。名前での検索、絞り込み（「All conversations」「New」「Updated」「Previously exported」＝すべての会話／新規／更新あり／エクスポート済み）、「Chat」と「Cowork」のタブ、プロジェクト検索を使えます。「New」は、Download Claude conversationsでまだ保存していない会話です。「Previously exported」はディスクに書き出し済みの会話を記録しており、2回目の「Export All」で飛ばせます。プロジェクト検索は、claude.aiでのスレッドのまとめ方に対応しています。

一括エクスポートでは、PDFを含む7つの形式すべてを選べる「Chat format」（チャット形式）、「Chats」「Thinking」「Metadata」「Tools」「Sources」（チャット、思考、メタデータ、ツール、出典）のチェックボックス、アーティファクトの配置（「Original」「Inline」「Nested」「Flat」）を使えます。「Export All」はアカウント全体を削ったZIPではありません。選んだ形式で、会話ごとに1ファイルが入った1つのZIPです。Anthropicの「Export data」は、引き続き後から届くアカウント全体のJSON ZIPです。

一括では会話ごとに数えます。無料プランでは「Export All」とPDFで1日3回を共有し、ZIPに入る会話1件ごとに1回を使います。残りが3回のときに40件の会話を選ぶと、途中で打ち切られるのではなく、一括実行全体がブロックされます。選ぶ件数を減らすか、UTCの午前0時のリセットを待つか、Pro（月額$3.99または年額$26.99）をお使いください。共通の上限の詳細：一括の「Export All」。

「Export All」が1日の枠を共有するのはPDFだけです。オレンジ色のボタンからのMarkdown、テキスト、JSON、XML、CSV、PNGはこの枠を使わないので、これらの形式での会話エクスポートは常に無料です。枠はUTCの午前0時にリセットされます。Proは同じGoogleアカウントを使えば、Paddle経由で新しいパソコンでも復元されます。

DesktopやCodeでもClaudeのセッションをエクスポートできますか？

Desktopアプリや、ターミナルのClaude Codeではできません。claude.aiでいうセッションとは、開いている会話のURLのことで、そこでClaudeのセッションをエクスポートするとは、Chromeのオレンジ色のボタンを使うことです。CoworkのセッションとClaude Code on the web（claude.ai/code）もclaude.ai上で開くので、同じ方法でエクスポートできます。Claude Desktopにオレンジ色のボタンが表示されることはありません。ターミナルのClaude Codeでは/exportか、~/.claude/projectsにあるJSONLを使います。

同じスレッドがclaude.aiのアカウントにもあるなら、Chromeでその会話を開いてこの拡張機能でエクスポートしてください。チャットがClaude Desktopにしかない場合は、アプリからコピー＆ペーストするか、WebでSettings → Privacy → Export dataを申請します。違いの比較：Claude Desktopのチャットをエクスポートする。

ターミナルのClaude Codeは別の製品の手順です。ターミナルで/exportを実行するか、~/.claude/projectsからJSONLのトランスクリプトをコピーします。この拡張機能はそれらのファイルを読み取らず、CLIに組み込まれることもありません。ターミナルのエージェントのセッションをエクスポートしたいなら、ディスク上のファイルを使う方法です。ガイド：Claude Codeのエクスポート。

スマートフォンのブラウザで使うclaude.aiも対象外です。この拡張機能には、デスクトップ版Chrome（またはChrome Web Storeの拡張機能を読み込めるChromium系ブラウザ）が必要です。2026年時点で、当チームのiOSやAndroidのアプリはありません。パソコンで会話を開き、オレンジ色のボタンか「Export All」を使ってください。

claude.aiのTeamやEnterpriseのワークスペースでも、Chromeでは同じ会話URLを使います。ワークスペースの管理者が拡張機能をブロックしている場合、この拡張機能は読み込まれません。これはブラウザのポリシーによるもので、形式が足りないわけではありません。オレンジ色のボタンは、開く権限のある会話URLで再読み込みした後にだけ表示されます。

Claudeの会話エクスポートとAnthropicの「Export data」の違いは？

Anthropicの「Export data」は、しばらく待った後にアカウント全体のJSON ZIPをメールで届けます。この拡張機能での会話エクスポートは、開いているスレッドをすぐにPDF、Markdown、JSON、テキスト、XML、CSV、PNGで保存します。ZIPはバックアップに、Chrome拡張機能はclaude.aiから今すぐ読めるファイルを得るために使ってください。

claude.aiからClaudeの会話を持ち出す方法
方法 向いている用途 得られるもの 待ち時間
Download Claude conversations この会話、または一括で選んだ会話 PDF / MD / JSON / TXT / XML / CSV / PNG なし — Chromeでファイルがダウンロードされる
Settings → Privacy → Export data アカウント全体のバックアップ メールで届くJSON ZIP あり — リンクに有効期限、チャットごとのMarkdownなし
印刷 →「PDFに保存」 大まかな見た目のコピー WebページのPDF なし、ただしレイアウトやコードが崩れやすい
コピー＆ペースト 短い回答1つ 選択した部分だけ 長いスレッドでは構造が残らない

公式のZIPは、会話エクスポートをきれいにしたものではありません。アカウント単位のJSONです。そのリクエストの中で、claude.aiの会話を1件選んだりMarkdownを選んだりはできません。一方で、忘れていたスレッドまで1つのアーカイブに収めたいなら、この拡張機能はそのZIPの代わりにはなりません。方法の比較：Claudeのチャットをエクスポートする方法。

この拡張機能はAnthropic, PBCとは提携していません。会話をエクスポートしても、Anthropicの利用規約が変わるわけではありません。コンテンツスクリプトは、claude.aiですでに開いているセッションを使い、別の認証情報でAnthropicにログインすることはありません。ご自身のアカウントについてはAnthropicのルールに従ってください。同じ製品を「チャット」という言葉で説明したページ：Claudeのチャットをエクスポート。

Claudeの会話エクスポートの料金は？

Markdown、テキスト、JSON、XML、CSV、PNGのエクスポートは、アカウント不要で無料・無制限です。PDFと一括の「Export All」は、Googleサインインで1日3回まで無料です。ProはPaddle経由で月額$3.99または年額$26.99で、PDFと一括エクスポートが無制限になります。形式ごとの料金はありません。Chromeで会話を開ければ、claude.aiのどのプランでも使えます。

PDFと一括エクスポートの1日の回数は、UTCの午前0時にリセットされます。Proは、新しいパソコンでも同じGoogleアカウントでサインインすれば復元できます。解約は、拡張機能のオプションページかPaddleからいつでもできます。販売元（Merchant of Record）はPaddleで、当チームがカード番号を見ることはありません。初回のお支払いには14日間の返金保証があり、返金ポリシーのページのとおりPaddle経由で対応します。

会話をエクスポートするのに、Anthropicの有料claude.aiプランは必要ありません。必要なのは、会話を開けるclaude.aiのログインとChromeだけです。オレンジ色のボタンは、TeamやEnterpriseでもFreeと同じように動きます。Chromeがダウンロードをブロックした場合は、claude.aiからのダウンロードを許可してから、もう一度「Export」をクリックしてください。

同じ作業、違う言い方。「Claude 会話 エクスポート」「Claude 会話履歴 エクスポート」、英語の「Claude export conversation」は、どれも「このスレッドをファイルとして保存する」という意味です。このページは「会話」「セッション」という言葉での説明です。「チャット」という言葉での製品ページは姉妹ページで、別の拡張機能ではありません。

会話のエクスポートに失敗したときは、長いスレッドがclaude.aiで読み込まれるまで待ち、形式のドロップダウン（最後に使った形式が残ります）を確認し、PDFなら今日の3回のうち何回残っているかを確かめてください。PNGやMarkdownのファイルが不完全なのは、たいていメッセージツリーがまだ生成中だったためです。会話をスクロールし、アシスタントの最後の回答が画面に表示されてから「Export」を押してください。

このページの内容はバージョン1.16.2（2026年9月）時点のものです。形式はPDF、Markdown、プレーンテキスト、JSON、XML、CSV、PNGです。この一覧が変われば、このガイドも同じ日に更新します。それまでは、claude.aiでこの拡張機能にWord、Notion、Googleドキュメントへのエクスポートは期待しないでください。

言い方が違っても同じChrome拡張機能ですか？

はい。「Claude 会話 エクスポート」「Claude チャット エクスポート」、英語の「Claude export conversation」など、言い方が違ってもやりたいことは同じで、claude.aiの会話をファイルとして保存することです。Download Claude conversationsがそのためのChrome拡張機能です。オレンジ色のボタン、7つの形式、そのうち6つは無料・無制限でエクスポートできます。法的情報のページには、この拡張機能についてClaude Exporterという表記が残っている場合があります。

「会話履歴をエクスポート」「会話をまとめてエクスポート」といった言い方も同じです。claude.aiの会話URLでのオレンジ色のボタン、または「View and Download All Conversations」からの「Export All」を指します。自分で公式の手順を選ばない限り、Claude Codeの/exportやAnthropicからメールで届くZIPのことではありません。

拡張機能なしでClaudeの会話をエクスポートする方法は、コピー＆ペースト、印刷、Settings → Privacy → Export dataの3つです。コピー＆ペーストでは表が崩れます。印刷ではclaude.aiの画面要素が残ります。ZIPは後から届くアカウント全体のJSONです。この拡張機能は、claude.aiだけで使える、PDF／Markdown／JSON／テキスト／XML／CSV／PNGをすぐに書き出す方法です。

この拡張機能がClaude DesktopやClaude Codeのターミナルに表示されることはありません。これらの環境にオレンジ色のボタンは出ません。CLIのオプションを期待して会話のエクスポートを調べていたなら、/exportかディスク上のJSONLを使ってください。Macアプリのボタンを期待していたなら、同期されたスレッドをChromeのclaude.aiで開いてください。

当サイトでいう「Claudeの会話エクスポート」とは？

Download Claude conversationsを使って、claude.aiの会話をファイルとして保存することです。オレンジ色のボタン、形式の選択、「Export」の3ステップです。「Claude 会話 エクスポート」と検索するときの目的と同じです。Anthropicからメールで届くZIPでも、Claude Codeの/exportでもありません。

Claudeの会話エクスポートは「Export data」と同じですか？

いいえ。Settings → Privacy → Export dataは、アカウント全体のJSON ZIPをメールで届けるものです。この拡張機能での会話エクスポートは、開いているスレッドをPDF、Markdown、JSON、テキスト、XML、CSV、PNGとして、または「Export All」で選んだ会話をZIPとして、Chromeですぐに書き出します。

Claudeの会話をPDFでエクスポートできますか？

はい。形式の一覧でPDFを選び、「Export」をクリックします。Download Claude conversationsは、印刷ダイアログを使わずにブラウザ内でPDFを作成します。PDFにはGoogleサインインが必要で、1日3回まで無料です。Proなら無制限です。ガイド：ClaudeのチャットをPDFでダウンロード。

Claudeの会話を1回エクスポートするのにProは必要ですか？

いいえ。Markdown、テキスト、JSON、XML、CSV、PNGのエクスポートは、アカウント不要で無料・無制限です。PDFと一括の「Export All」は、Googleサインインで1日3回まで無料です。Pro（月額$3.99または年額$26.99）にすると、この上限がなくなります。

claude.aiのどのプランでも会話をエクスポートできますか？

はい。Chromeで会話を開ければ、claude.aiのFree、Pro、Team、Enterpriseのどのプランでも使えます。この拡張機能にAnthropicの有料プランは必要ありません。

Claudeの会話エクスポートはClaude Code向けですか？

対象はClaude Code on the webだけです。claude.ai/codeのセッションはclaude.ai上で開くので、ほかの会話と同じようにエクスポートできます。ターミナルのClaude Codeでは/exportか、~/.claude/projectsにあるJSONLを使い、この拡張機能はそうしたローカルのセッションを読み取りません。

Claude DesktopからClaudeのセッションをエクスポートできますか？

このChrome拡張機能ではできません。同期されていればclaude.aiで同じ会話を開くか、コピー＆ペーストするか、公式の「Export data」を使ってください。Claude Desktopにオレンジ色のボタンが表示されることはありません。

Claudeの会話エクスポートは何ファイルまで無料ですか？

Markdown、テキスト、JSON、XML、CSV、PNGは、アカウント不要で無制限です。PDFと一括の「Export All」は、無料プランでは合わせて1日3回までで、Googleサインインが必要です。一括ZIPでは、会話1件ごとに1回として数えます。回数はUTCの午前0時にリセットされます。Proにすると上限がなくなり、Googleサインインで復元できます。

Claudeの会話をエクスポートするオレンジ色のボタンはどこにありますか？

この拡張機能をインストールして再読み込みすると、claude.aiの会話URLでメッセージ入力欄の右側に表示されます。何も入力していないホーム画面やClaude Desktopには表示されません。

Claudeの会話エクスポートでチャットがアップロードされますか？

いいえ。PDFを含むすべての形式はブラウザ内で作られ、Chromeのダウンロード機能に渡されます。Markdown、テキスト、JSON、XML、CSV、PNGのエクスポートでは、当方に何も送信されません。PDF、一括エクスポート、Proのためにサインインした後も、当方のワーカーが見るのは利用回数やサブスクリプションの状態とGoogleのメールアドレスだけで、会話の本文を見ることはありません。

Claudeの会話エクスポートではどの形式で書き出せますか？

PDF、Markdown、プレーンテキスト、JSON、XML、CSV、PNGの7つです。1件の会話でも「Export All」でも同じ7形式です。バージョン1.16.2では、Word、Notion、Googleドキュメントへのエクスポートはありません。
