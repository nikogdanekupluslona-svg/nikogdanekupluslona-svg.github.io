ChromeでのClaudeの会話エクスポートの仕組みは？

Chromeでclaude.aiの会話URLを開き、メッセージ入力欄の右側にあるオレンジ色のボタンをクリックし、Markdown、JSON、テキスト、XML、PNGから選んで「Export」を押します。この拡張機能が会話のファイルをローカルに書き出します。インストール後はclaude.aiを再読み込みしてください。claude.aiには、スレッドごとにエクスポートする機能はありません。

  1. Chrome Web StoreからDownload Claude conversationsをインストールします（ストアでの評価は5.0、バージョン1.13.0）。
  2. コンテンツスクリプトが会話URLに読み込まれるよう、claude.aiのタブを再読み込みします。
  3. claude.aiの何も入力していないホーム画面ではなく、実際の会話を開きます。
  4. メッセージ入力欄の右側にあるオレンジ色のダウンロードボタンをクリックします。
  5. Markdown、JSON、プレーンテキスト、XML、PNGから選び、「Export」をクリックします。

最初に会話をエクスポートする前に、Googleサインインが必要です。この拡張機能は、再インストール後も3回の無料枠とProを復元できるよう、確認済みのメールアドレスを保存します。このGoogleサインインに会話の本文は含まれません。仕組みの詳細：仕組み。

オレンジ色のボタンが表示されない場合は、タブがclaude.aiの会話URLを開いていない、インストール後にページを再読み込みしていない、または拡張機能がChromeのパズルピースのメニューに隠れています。拡張機能を固定してから再読み込みしてください。オレンジ色のボタンが他のWebサイトに表示されることはありません。

形式の選択は、前回選んだものが記憶されます。Markdown、JSON、プレーンテキスト、XML、PNGのどれも、Chromeのダウンロードが完了した時点で1回として数えます。ファイルが不完全なのは、たいていclaude.aiの長いスレッドがまだメッセージツリーを表示し終えていなかったためです。少し待ってから、もう一度「Export」をクリックしてください。

1件の会話か、アカウント全体か。オレンジ色のボタンは、開いているスレッドの会話をエクスポートします。多数のファイルが必要なら「View and Download All Conversations」（すべての会話を表示・ダウンロード）を開いて「Export All」（すべてエクスポート）を実行します。AnthropicのSettings → Privacy → Export data（claude.aiを日本語表示にしている場合、メニュー名は日本語で表示されることがあります）は後から届くアカウント全体のJSON ZIPで、このChromeでの流れとは別物です。

Claudeの会話エクスポートでファイルに残るものは？

この拡張機能でエクスポートした会話ファイルには、claude.aiにすでに表示されているメッセージツリーが残ります。送信者、コードブロック、表、任意で思考、メタデータ、アーティファクトの配置です。サイドバーのスクリーンショットではありません。画像が欲しいときはPNGを選びます。バージョン1.13.0でもPDFは出力しません。

claude.aiからコピー＆ペーストすると、インデントが失われ、表が崩れます。印刷（Ctrl/Cmd+P）ではclaude.aiの画面要素が残り、長いコードブロックがページの途中で分かれることがよくあります。この拡張機能なら、Markdown、JSON、XMLでコードブロックの言語タグが保たれ、表は表のまま残ります。PNGはスレッドの画像で、ページ分けされたPDFではありません。

バージョン1.13.0では、思考ブロックを切り替えられます。メタデータにはタイトル、タイムスタンプ、モデルを含められます。送信者フィルターで、会話ファイルをすべてのメッセージ、ユーザーのみ、アシスタントのみに絞れます。アーティファクトの配置は「Original」「Inline」「Nested」「Flat」（元の配置／インライン／入れ子／フラット）です。これらの設定は、開いているスレッドにも「Export All」にも適用されます。

私たちはClaudeの会話エクスポートを、claude.aiのオレンジ色のボタンを中心に作りました。画面に表示されている会話から、スレッドをアップロードせずにMarkdown、JSON、テキスト、XML、PNGを書き出します。バージョン1.13.0でもPDFは出力しません。

Claudeの会話をMarkdownでエクスポートするには？

Claudeの会話をMarkdownでエクスポートするのは、文章を書く人向けの使い方です。オレンジ色のボタンを開き、ドロップダウンでMarkdownを選んで「Export」を押します。同じclaude.aiのスレッドから、JSON、プレーンテキスト、XML、PNGも書き出せます。バージョン1.13.0にPDF形式はありません。形式を選んでも3回の無料枠は変わりません。

会話をメモとしてエクスポートするなら、文章を書く人はたいていMarkdownを選びます。機械で読める会話ファイルが必要な開発者は、たいていJSONを選びます。プレーンテキストはマークアップなしのアーカイブ、XMLはタグが必要なデータ交換用、PNGはスクリーンショットのようなファイルです。1.13.0では、Word、Notion、Googleドキュメントへの書き出しはありません。

PDFのようなページがどうしても必要なら、提供していない形式を待つのではなく、Chromeからclaude.aiの会話を印刷してください。この拡張機能で作るPNGは画像ファイルです。ページ分けされた文書が必要なら、エクスポートしたMarkdownを後でWord、Googleドキュメント、Markdownアプリで変換できます。

Markdown、JSON、テキスト、XML、PNGのダウンロードが完了するたびに、Googleでサインインしたアカウントの3回の無料枠のうち1回として数えます。Pro（月額$3.99または年額$26.99）にすると、すべての形式で上限がなくなります。同じclaude.aiの会話を別の形式でもう一度エクスポートすると、Proでない限りもう1回分を使います。

「Export All」でClaudeの会話履歴をエクスポートできますか？

はい。「View and Download All Conversations」を開いて絞り込み、「Export All」をクリックすれば、Claudeの会話履歴をスレッドごとのファイルとしてエクスポートできます。完成したファイルはそれぞれ、オレンジ色のボタンと同じ3回の無料枠を使います。Pro（月額$3.99または年額$26.99）にすると、1件のスレッドと同じように一括でも上限がなくなります。

一覧には、名前での検索と、All（すべて）、New（新規）、Exported（エクスポート済み）、Project（プロジェクト）の絞り込みを備えたclaude.aiの会話履歴が表示されます。Newは、この拡張機能でまだ保存していない会話です。Exportedはディスクに書き出し済みの会話を記録しており、2回目の「Export All」で飛ばせます。Projectは、claude.aiでのスレッドのまとめ方に対応しています。

一括でも、1件の会話エクスポートと同じ切り替え（Chats、Thinking、Metadata、アーティファクトの配置「Original」「Inline」「Nested」「Flat」）と、同じ5つの形式が使えます。「Export All」はアカウント全体を削ったZIPではなく、会話ごとの多数のファイルです。Anthropicの「Export data」は、引き続き後から届くアカウント全体のJSON ZIPです。

無料枠はアカウント全体で共通です。無料エクスポートは合計3回で、一括実行ごとに3回ではありません。一覧で40件の会話を選ぶと、すべてのファイルが完成すれば40回分を使います。「Export All」をクリックする前に選ぶ会話を計画するか、Pro（月額$3.99または年額$26.99）を使ってください。無料枠の詳細：一括の「Export All」。

「Export All」とオレンジ色のボタンは、Googleでサインインしたアカウントの無料枠を共有しています。オレンジ色のボタンで3件、「Export All」でさらに3件を無料で書き出すことはできません。拡張機能を再インストールしても回数はリセットされません。Proは同じGoogleアカウントを使えば、Paddle経由で新しいパソコンでも復元されます。

DesktopやCodeでもClaudeのセッションをエクスポートできますか？

claude.aiでいうセッションとは、開いている会話のURLのことです。そこでClaudeのセッションをエクスポートするとは、Chromeのオレンジ色のボタンを使うことで、Desktopやターミナルに組み込む機能ではありません。この拡張機能が動作するのはclaude.aiだけです。Claude Desktopにオレンジ色のボタンが表示されることはありません。Claude Codeでは/exportか、~/.claude/projectsにあるJSONLを使います。

同じスレッドがclaude.aiのアカウントにもあるなら、Chromeでその会話を開いてこの拡張機能でエクスポートしてください。チャットがClaude Desktopにしかない場合は、アプリからコピー＆ペーストするか、WebでSettings → Privacy → Export dataを申請します。違いの比較：Claude Desktopのチャットをエクスポートする。

Claude Codeは別の製品の手順です。ターミナルで/exportを実行するか、~/.claude/projectsからJSONLのトランスクリプトをコピーします。この拡張機能はそれらのファイルを読み取らず、CLIに組み込まれることもありません。ターミナルのエージェントのセッションをエクスポートしたいなら、ディスク上のファイルを使う方法です。ガイド：Claude Codeのエクスポート。

スマートフォンのブラウザで使うclaude.aiも対象外です。この拡張機能には、デスクトップ版Chrome（またはChrome Web Storeの拡張機能を読み込めるChromium系ブラウザ）が必要です。2026年時点で、当チームのiOSやAndroidのアプリはありません。パソコンで会話を開き、オレンジ色のボタンか「Export All」を使ってください。

claude.aiのTeamやEnterpriseのワークスペースでも、Chromeでは同じ会話URLを使います。ワークスペースの管理者が拡張機能をブロックしている場合、この拡張機能は読み込まれません。これはブラウザのポリシーによるもので、形式が足りないわけではありません。オレンジ色のボタンは、開く権限のある会話URLで再読み込みした後にだけ表示されます。

Claudeの会話エクスポートとAnthropicの「Export data」の違いは？

Anthropicの「Export data」は、しばらく待った後にアカウント全体のJSON ZIPをメールで届けます。この拡張機能での会話エクスポートは、開いているスレッドをすぐにMarkdown、JSON、テキスト、XML、PNGで保存します。ZIPはバックアップに、Chrome拡張機能はclaude.aiから今すぐ読めるファイルを得るために使ってください。

claude.aiからClaudeの会話を持ち出す方法
方法 向いている用途 得られるもの 待ち時間
Download Claude conversations この会話、または一括で選んだ会話 MD / JSON / TXT / XML / PNG なし — Chromeでファイルがダウンロードされる
Settings → Privacy → Export data アカウント全体のバックアップ メールで届くJSON ZIP あり — リンクに有効期限、チャットごとのMarkdownなし
印刷 →「PDFに保存」 大まかな見た目のコピー WebページのPDF なし、ただしレイアウトやコードが崩れやすい
コピー＆ペースト 短い回答1つ 選択した部分だけ 長いスレッドでは構造が残らない

公式のZIPは、会話エクスポートをきれいにしたものではありません。アカウント単位のJSONです。そのリクエストの中で、claude.aiの会話を1件選んだりMarkdownを選んだりはできません。一方で、忘れていたスレッドまで1つのアーカイブに収めたいなら、この拡張機能はそのZIPの代わりにはなりません。方法の比較：Claudeのチャットをエクスポートする方法。

この拡張機能はAnthropic, PBCとは提携していません。会話をエクスポートしても、Anthropicの利用規約が変わるわけではありません。コンテンツスクリプトは、claude.aiですでに開いているセッションを使い、別の認証情報でAnthropicにログインすることはありません。ご自身のアカウントについてはAnthropicのルールに従ってください。同じ製品を「チャット」という言葉で説明したページ：Claudeのチャットをエクスポート。

Claudeの会話エクスポートの料金は？

Googleでサインインしたアカウントごとに、3回まで無料でエクスポートできます。それ以降は、Paddle経由でProが月額$3.99または年額$26.99です。この料金にはオレンジ色のボタンと「Export All」の両方が含まれます。形式ごとの料金はありません。Chromeで会話を開ければ、claude.aiのどのプランでも使えます。

3回の無料エクスポートは、Chromeの拡張機能を再インストールしてもリセットされません。そのため、最初に会話をエクスポートするときにGoogleサインインが必要です。Proは同じGoogleアカウントで新しいパソコンでも復元できます。販売元（Merchant of Record）はPaddleで、当チームがカード番号を見ることはありません。返金は返金ポリシーのページのとおりPaddle経由で行います。

会話をエクスポートするのに、Anthropicの有料claude.aiプランは必要ありません。必要なのは、会話を開けるclaude.aiのログインとChromeだけです。オレンジ色のボタンは、TeamやEnterpriseでもFreeと同じように動きます。Chromeがダウンロードをブロックした場合は、claude.aiからのダウンロードを許可してから、もう一度「Export」をクリックしてください。

同じ作業、違う言い方。「Claude 会話 エクスポート」「Claude 会話履歴 エクスポート」、英語の「Claude export conversation」は、どれも「このスレッドをファイルとして保存する」という意味です。このページは「会話」「セッション」という言葉での説明です。「チャット」という言葉での製品ページは姉妹ページで、別の拡張機能ではありません。

会話のエクスポートに失敗したときは、長いスレッドがclaude.aiで読み込まれるまで待ち、形式のドロップダウン（最後に使った形式が残ります）を確認し、3回の無料枠に達していないか確かめてください。PNGやMarkdownのファイルが不完全なのは、たいていメッセージツリーがまだ生成中だったためです。会話をスクロールし、アシスタントの最後の回答が画面に表示されてから「Export」を押してください。

このページの内容はバージョン1.13.0（2026年9月）時点のものです。形式は引き続きMarkdown、JSON、プレーンテキスト、XML、PNGです。この一覧が変われば、このガイドも同じ日に更新します。それまでは、claude.aiでこの拡張機能にWord、Notion、ネイティブなPDFは期待しないでください。

言い方が違っても同じChrome拡張機能ですか？

はい。「Claude 会話 エクスポート」「Claude チャット エクスポート」、英語の「Claude export conversation」など、言い方が違ってもやりたいことは同じで、claude.aiの会話をファイルとして保存することです。Download Claude conversationsがそのためのChrome拡張機能です。オレンジ色のボタン、5つの形式、3回の無料エクスポート。法的情報のページには、この拡張機能についてClaude Exporterという表記が残っている場合があります。

「会話履歴をエクスポート」「会話をまとめてエクスポート」といった言い方も同じです。claude.aiの会話URLでのオレンジ色のボタン、または「View and Download All Conversations」からの「Export All」を指します。自分で公式の手順を選ばない限り、Claude Codeの/exportやAnthropicからメールで届くZIPのことではありません。

拡張機能なしでClaudeの会話をエクスポートする方法は、コピー＆ペースト、印刷、Settings → Privacy → Export dataの3つです。コピー＆ペーストでは表が崩れます。印刷ではclaude.aiの画面要素が残ります。ZIPは後から届くアカウント全体のJSONです。この拡張機能は、claude.aiだけで使える、Markdown／JSON／テキスト／XML／PNGをすぐに書き出す方法です。

この拡張機能がClaude DesktopやClaude Codeのターミナルに表示されることはありません。これらの環境にオレンジ色のボタンは出ません。CLIのオプションを期待して会話のエクスポートを調べていたなら、/exportかディスク上のJSONLを使ってください。Macアプリのボタンを期待していたなら、同期されたスレッドをChromeのclaude.aiで開いてください。

ここでは、Claudeの会話エクスポートについて、形式、無料枠、Claude Desktop、Claude Code、AnthropicのZIP、claude.aiのオレンジ色のボタンをまとめています。どの回答もDownload Claude conversations 1.13.0の事実に基づいています。ページのheadにあるFAQPageのJSON-LDも、この一覧と同じ内容です。

当サイトでいう「Claudeの会話エクスポート」とは？

Download Claude conversationsを使って、claude.aiの会話をファイルとして保存することです。オレンジ色のボタン、形式の選択、「Export」の3ステップです。「Claude 会話 エクスポート」と検索するときの目的と同じです。Anthropicからメールで届くZIPでも、Claude Codeの/exportでもありません。

Claudeの会話エクスポートは「Export data」と同じですか？

いいえ。Settings → Privacy → Export dataは、アカウント全体のJSON ZIPをメールで届けるものです。この拡張機能での会話エクスポートは、開いているスレッドや「Export All」で選んだ会話を、ChromeですぐにMarkdown、JSON、テキスト、XML、PNGとして書き出します。

Claudeの会話をPDFでエクスポートできますか？

この拡張機能ではできません。形式はMarkdown、JSON、プレーンテキスト、XML、PNGです。PDFのようなスナップショットが必要なら、Chromeでclaude.aiのページを印刷してください。PNGは画像で、PDFではありません。

Claudeの会話を1回エクスポートするのにProは必要ですか？

いいえ。Googleでサインインしたアカウントなら、最初の3回はどの形式でも無料です。Pro（月額$3.99または年額$26.99）にすると、1件ずつでも一括でも上限がなくなります。

claude.aiのどのプランでも会話をエクスポートできますか？

はい。Chromeで会話を開ければ、claude.aiのFree、Pro、Team、Enterpriseのどのプランでも使えます。この拡張機能にAnthropicの有料プランは必要ありません。

Claudeの会話エクスポートはClaude Code向けですか？

いいえ。この拡張機能はChromeのclaude.aiで動作します。Claude Codeでは/exportか、~/.claude/projectsにあるJSONLを使います。この拡張機能はClaude Codeのセッションを読み取りません。

Claude DesktopからClaudeのセッションをエクスポートできますか？

このChrome拡張機能ではできません。同期されていればclaude.aiで同じ会話を開くか、コピー＆ペーストするか、公式の「Export data」を使ってください。Claude Desktopにオレンジ色のボタンが表示されることはありません。

Claudeの会話エクスポートは何ファイルまで無料ですか？

Googleでサインインしたアカウントごとに3回で、オレンジ色のボタンと「Export All」の合計です。再インストールしても回数はリセットされません。ProはGoogleサインインで復元されます。

Claudeの会話をエクスポートするオレンジ色のボタンはどこにありますか？

この拡張機能をインストールして再読み込みすると、claude.aiの会話URLでメッセージ入力欄の右側に表示されます。何も入力していないホーム画面やClaude Desktopには表示されません。

Claudeの会話エクスポートでチャットがアップロードされますか？

いいえ。ファイルはブラウザ内で作られ、Chromeのダウンロード機能に渡されます。当方のサーバーが見るのはサブスクリプションの状態とGoogleで確認されたメールアドレスだけで、会話の本文ではありません。

Claudeの会話エクスポートではどの形式で書き出せますか？

Markdown、JSON、プレーンテキスト、XML、PNGです。1件の会話でも「Export All」でも同じ5形式です。バージョン1.13.0では、PDF、Word、Notion、Googleドキュメントへのエクスポートはありません。
