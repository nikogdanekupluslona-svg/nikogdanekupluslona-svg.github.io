¿Claude ya guarda la conversación en el historial?

Sí. Claude.ai ya almacena el hilo con sesión iniciada en el historial de la cuenta de Anthropic. Cerrar la pestaña no borra la conversación. Aun así, no hay ningún control Guardar que cree un archivo en el disco. Guardar la conversación como Markdown o JSON es una tarea distinta del historial.

El historial es la lista de chats de la izquierda en claude.ai. Cada fila es una conversación que Anthropic guardó para ese usuario. Abre una fila más tarde y vuelven los mismos turnos. Eso es almacenamiento en la cuenta, no una carpeta de descargas en tu portátil.

Quien busca cómo guardar una conversación en Claude suele querer decir «¿desaparecerá cuando me vaya?». En una sesión normal con la cuenta iniciada, la respuesta es no. Claude.ai no necesita un clic en Guardar para conservar el hilo en la cuenta. Lo que falta es un exportador de archivos, no un interruptor para mantener el chat.

El historial no es un archivo Markdown, ni un árbol JSON en el que buscar con grep, ni un PNG para una diapositiva. El historial vive detrás del acceso de Anthropic. Si no puedes iniciar sesión, no puedes abrir esos chats. Un archivo local se sigue abriendo aunque ya no tengas la contraseña.

Dos «guardados» distintos. Historial = Anthropic conserva el chat en la cuenta. Archivo = tú escribes PDF, Markdown, JSON, texto, XML, CSV o PNG en el disco. Claude.ai tiene lo primero. Para lo segundo, claude.ai no tiene botón.

Projects y Recents en claude.ai siguen siendo historial. Agrupar un chat en un proyecto no crea un archivo. Cambiar el nombre de la conversación no crea un archivo. Marcarla con estrella o fijarla, si la interfaz lo ofrece, tampoco escribe Markdown. Download Claude conversations exporta los chats de un proyecto como cualquier otro, y en la página de un proyecto «Project files» → «Download ZIP» (archivos del proyecto → descargar ZIP) guarda los archivos del proyecto.

Los espacios de trabajo Team y Enterprise siguen la misma división. Si puedes abrir la conversación en claude.ai, Anthropic ya la guardó para el espacio de trabajo. Aun así, las reglas de retención de la empresa pueden borrar u ocultar chats según un calendario que tú no controlas. Entonces, el archivo que exportaste es la copia que conservas.

El modo incógnito y un segundo perfil de Chrome no comparten historial. El hilo va ligado a la cuenta de Anthropic usada en esa sesión. Si inicias sesión con otra cuenta de Anthropic, verás otro historial. «Guardar» entre cuentas significa un archivo, no fusionar historiales.

¿Cómo guardar una conversación de Claude como archivo?

Para guardar una conversación de Claude como archivo, elige un método que escriba en el disco: Download Claude conversations en Chrome, Imprimir → Guardar como PDF, o Settings → Privacy → Export data. El historial de claude.ai es almacenamiento en la cuenta, no un archivo PDF, Markdown, JSON, texto, XML, CSV o PNG.

La extensión de Chrome es la vía chat por chat. Abre la URL de la conversación, haz clic en el botón naranja junto al cuadro de mensaje, elige un formato y pulsa «Export» (Exportar). La API de descargas de Chrome escribe el archivo en local. Markdown, texto, JSON, XML, CSV y PNG no necesitan cuenta; solo el PDF pide iniciar sesión con Google. El contenido de los chats se queda en tu equipo.

Imprimir es la vía visual. Ctrl+P o Cmd+P, destino Guardar como PDF. El resultado se ve como la página de claude.ai, incluidos los elementos de la interfaz que los estilos de impresión no ocultan. Los bloques de código suelen partirse entre hojas. Imprime cuando alguien quiera una captura para revisar, no un archivo de notas. Para un PDF construido a partir de los mensajes y no de la pantalla, elige PDF en la extensión.

Export data oficial es la vía de la cuenta. Settings → Privacy → Export data en claude.ai. Anthropic envía por correo un enlace que caduca. El ZIP es JSON de toda la cuenta, no un archivo con nombre para el chat que tienes en pantalla. La espera es el precio de una copia de seguridad completa.

Un archivo es lo adecuado antes de dejar una empresa, antes de formatear el portátil, antes de montar un archivo de investigación o antes de pegar una revisión de código en git. El historial basta cuando solo necesitas volver a abrir el mismo hilo mañana con la misma cuenta de Anthropic.

Copiar y pegar es un quinto método, y un archivo pobre. Seleccionas el texto en claude.ai y lo pegas en Docs. Los bloques de código se deshacen. Las tablas se convierten en líneas corridas. Los límites entre mensajes desaparecen. Vale para un párrafo. No sirve como único registro de una revisión de diseño de 40 turnos. ¿Cómo guardar un chat de Claude con la extensión de Chrome?

Para guardar un chat de Claude con Download Claude conversations: instala la extensión de Chrome, abre el hilo en claude.ai, haz clic en el botón naranja junto al cuadro de mensaje, elige PDF, Markdown, JSON, texto, XML, CSV o PNG y pulsa «Export». No necesitas cuenta, salvo para el PDF.

  1. Instala Download Claude conversations desde la Chrome Web Store (también funcionan los navegadores Chromium que cargan extensiones de Chrome).
  2. Recarga claude.ai si la página ya estaba abierta durante la instalación. Chrome no siempre inyecta el content script en pestañas antiguas.
  3. Abre desde el historial la URL de una conversación real: el botón naranja aparece en un hilo, no en la pantalla de inicio vacía.
  4. Haz clic en el botón redondo naranja de descarga, a la derecha del cuadro de mensaje. Se abre un panel con Messages (All / Human / Assistant; todos, humano, asistente), Format, «Thinking», «Select» (Seleccionar), «Copy» y «Export».
  5. Elige PDF, Markdown, texto plano, JSON, XML, CSV o PNG. Haz clic en «Export». Chrome descarga el archivo al instante.

¿Cómo guardar una conversación en Claude sin extensión?

Para guardar una conversación en Claude sin extensión, imprime la página de claude.ai o solicita el ZIP de Export data de Anthropic. Imprimir da un PDF visual de la página web. Export data es un archivo en JSON de toda la cuenta que llega con retraso. Ninguno de los dos crea un archivo Markdown por chat.

Imprimir: abre la conversación en claude.ai, oculta la barra lateral si la interfaz lo permite, pulsa Ctrl+P (Windows/Linux) o Cmd+P (Mac), elige Guardar como PDF como destino y guarda. Los elementos del cuadro de mensaje pueden repetirse en cada hoja. Las notas completas sobre la impresión están en descargar un chat de Claude en PDF.

Vía oficial: Settings → Privacy → Export data en claude.ai. Anthropic envía por correo un enlace que caduca. Descomprime el ZIP tú mismo si necesitas una conversación entre miles. Ese archivo es la copia de seguridad de tipo legal, no un archivo de notas para la reunión de mañana.

Copiar y pegar sigue disponible sin instalar nada. Seleccionas turnos en claude.ai y los pegas en una app de notas. La sangría del código suele perderse. Un hilo de varios turnos queda como un muro sin estructura. Usa copiar y pegar para un fragmento suelto, no como tu único plan para guardar conversaciones.

¿El historial sigue guardando la conversación al cerrar?

Sí. El historial sigue guardando la conversación de Claude después de cerrar la pestaña, recargar claude.ai o apagar el portátil, siempre que el chat se creara con la sesión iniciada. Cerrar una pestaña no es borrar. Eliminar del historial es la acción que quita el hilo de la interfaz de la cuenta.

Cierra sesión en claude.ai y la página se queda en blanco. Vuelve a entrar con la misma cuenta de Anthropic y el historial recupera esos chats. Cerrar sesión oculta la lista; por sí solo no borra lo que guarda la cuenta. Otra cuenta de Anthropic muestra otro historial.

Eliminar del historial es el caso real en el que un chat desaparece. Quita una conversación en la interfaz de claude.ai y ese hilo desaparece de la barra lateral. Un archivo Markdown que ya exportaste con el botón naranja se queda en el disco. Exporta primero si vas a limpiar el chat.

Borrar no es cerrar. Cerrar una pestaña de claude.ai deja el historial intacto. Eliminar la conversación del historial la quita de la interfaz de la cuenta. Export data oficial no te ayudará tras un borrado si Anthropic ya no incluye ese hilo. Escribe el archivo antes de hacer limpieza.

El modo incógnito termina al cerrar la ventana. Si usaste claude.ai en una ventana privada sin una sesión duradera, no des por hecho que el historial conservó el trabajo. Inicia sesión en un perfil normal de Chrome o exporta un archivo antes de que termine la sesión de incógnito.

Los administradores de los espacios Team y Enterprise pueden retener o restringir chats. Una política que tú no fijaste puede ocultar un hilo más adelante. Trata el historial de la empresa como almacenamiento prestado. Trata un archivo Markdown o JSON exportado como la copia que queda de tu lado de la política.

Pasar del teléfono al portátil no requiere ningún clic especial para guardar la conversación si ambos dispositivos usan la misma cuenta de Anthropic. Abre el historial en el portátil. Si falta el chat, estás en otra cuenta, en otro espacio de trabajo o el hilo se borró; no es que esté «sin guardar».

Claude Desktop puede mostrar los chats de la misma cuenta cuando esa app tiene la sesión iniciada con el mismo usuario de Anthropic. La sincronización es cosa de Anthropic. La extensión de Chrome nunca se inyecta en Desktop. Si el hilo existe en claude.ai, abre claude.ai en Chrome para crear un archivo.

¿Cómo guardar la conversación en Markdown o JSON?

Para guardar la conversación de Claude en Markdown o JSON, abre el botón naranja en claude.ai, elige el formato y pulsa «Export». Markdown es el archivo de notas. JSON es el árbol de mensajes para scripts. El texto plano no lleva marcado. CSV es una fila por mensaje. PDF es un documento paginado. PNG es una imagen.

Markdown conserva los encabezados, el código delimitado con etiquetas de lenguaje y las tablas. Markdown es la opción habitual para Obsidian, GitHub o una wiki. Notas sobre la estructura de ese formato: exportación a Markdown. JSON conserva el árbol que ya construyó el analizador, incluidos los artefactos y el razonamiento cuando esas opciones están activadas.

El JSON de Download Claude conversations no tiene la misma estructura que el ZIP de la cuenta de Anthropic. El JSON de la extensión es una conversación tal como la mostró la página. El JSON de Export data es un volcado de la cuenta que Anthropic envía más tarde por correo. No mezcles los dos esquemas en un mismo script sin revisar las claves.

El texto plano es la opción correcta cuando el destino elimina el marcado: un campo de un sistema de tickets, el cuerpo de un correo o un índice de búsqueda que quiere texto sin formato. XML es la opción de nicho para intercambio de datos. CSV se abre en Excel, Google Sheets o Numbers. PNG sirve para una diapositiva o una figura del hilo en un informe de error, no para una revisión de 40 turnos en la que vas a buscar con grep.

¿Cómo guardar el historial de chats de Claude en bloque?

Para guardar el historial de chats de Claude en muchos archivos, no repitas el botón naranja pestaña por pestaña. Abre «View and Download All Conversations» (ver y descargar todas las conversaciones) desde la ventana de la extensión, filtra la tabla y haz clic en «Export All». «Export All» pide iniciar sesión con Google. En el plan gratuito, cada chat del ZIP gasta una de las 3 cuotas diarias compartidas con el PDF. Pro elimina el límite.

El Dashboard muestra las conversaciones de la cuenta de claude.ai con la que has iniciado sesión: el mismo historial que ya tienes, convertido en una tabla que puedes filtrar. Busca por nombre. Filtra por All conversations, New, Updated o Previously exported (todas, nuevas, actualizadas o ya exportadas). Cambia entre las pestañas Chat y Cowork, y busca por proyecto si agrupas chats así en claude.ai.

La exportación masiva crea un ZIP con un archivo por chat, en el formato que elijas en el selector «Chat format»: cualquiera de los siete, PDF incluido. Usa el mismo analizador que la exportación de un solo chat. Las casillas «Chats», «Thinking», «Metadata», «Tools» y «Sources» deciden qué se incluye (chats, razonamiento, metadatos, herramientas, fuentes), además de una disposición de artefactos. «Export All» no es un proceso de segunda: es el mismo analizador aplicado a muchas conversaciones de una sola pasada. Detalles: exportación masiva con Export All.

Export data de Anthropic sigue siendo la copia de seguridad de la cuenta. Un ZIP, un correo, JSON para todo, incluidos chats que habías olvidado. «Export All» hace lo contrario: tú eliges qué filas del historial, tú eliges el formato y el ZIP llega al momento. Usa los dos si quieres un archivo completo para fines legales y una carpeta de notas legibles.

La cuota es diaria y compartida. En el plan gratuito, las exportaciones en PDF y los chats de una exportación masiva comparten 3 al día, que se reinician a medianoche UTC. Si seleccionas 40 conversaciones, se bloquea todo el lote, no se recorta. Elige menos o pásate a Pro por 3,99 US$ al mes o 26,99 US$ al año a través de Paddle.

El Dashboard recuerda lo que ya exportaste, así que en una visita posterior puedes filtrar solo por New o Updated. Así, la costumbre de guardar cada semana tus chats de Claude se mantiene incremental en vez de duplicar el Markdown del mes pasado. El contador de 3 al día va con la cuenta de Google, no con la instalación, y se reinicia a medianoche UTC.

Selecciona un subconjunto cuando el historial esté lleno de borradores de una línea. «Export All» no te obliga a llevarte todas las filas. Un filtro ajustado y Markdown dan una carpeta de investigación más limpia que 200 hilos vacíos de «hola».

Exportar un chat de Claude, como verbo del producto, es el mismo botón naranja y la misma tabla de «Export All». La página vecina exportar chat de Claude explica esos controles si llegaste buscando «exportar» en lugar de «guardar».

¿Puedo guardar la conversación en Desktop o en Code?

En Desktop, no. En Code, solo en la web. Download Claude conversations no puede guardar conversaciones de Claude Desktop ni de una terminal local de Claude Code. Las sesiones de claude.ai/code se abren en Chrome de escritorio, así que se guardan como cualquier chat. Claude Desktop es una app aparte. Claude Code en local es el agente de terminal con /export y JSONL en el disco.

Si el chat de Desktop también existe en claude.ai, abre esa URL en Chrome y usa el botón naranja. Si el hilo solo está en Desktop, copia y pega o espera a Settings → Privacy → Export data. La extensión nunca se inyecta en la ventana de Desktop.

Dentro de una sesión activa de Claude Code, escribe /export. La CLI de Anthropic abre un menú para copiar la transcripción o guardarla en un archivo de texto plano. Pasa un nombre de archivo para saltarte el menú. Esa transcripción es texto formateado para que lo lea una persona, no el Markdown, JSON o PDF de esta extensión. Rutas completas: exportación de Claude Code.

El JSONL del disco es el registro interno, en ~/.claude/projects (Windows: %USERPROFILE%\.claude\projects). Su esquema puede cambiar entre versiones de Claude Code. La propia documentación de Anthropic recomienda usar /export en lugar de analizar el JSONL. No envolvemos esa CLI. No leemos ~/.claude.

Preguntas frecuentes: cómo guardar una conversación de Claude

¿Cómo guardo una conversación de Claude como archivo?

Instala Download Claude conversations, abre el hilo en claude.ai, haz clic en el botón naranja a la derecha del cuadro de mensaje, elige PDF, Markdown, JSON, texto, XML, CSV o PNG y pulsa «Export». El archivo se descarga en local, sin cuenta salvo para el PDF. El historial ya guardó el chat en la cuenta de Anthropic; el botón naranja escribe una copia en el disco.

¿Cómo guardar un chat de Claude en claude.ai?

No necesitas un botón Guardar para conservar el hilo en la cuenta. El historial de claude.ai ya muestra los chats con sesión iniciada. Para guardar un chat de Claude como archivo, usa la extensión de Chrome, Imprimir → Guardar como PDF, o Settings → Privacy → Export data para un ZIP en JSON de la cuenta que llega con retraso.

¿Cómo guardar una conversación en Claude sin extensión?

Imprime la página de claude.ai (Ctrl/Cmd+P → Guardar como PDF) para una copia visual, o usa Settings → Privacy → Export data para recibir por correo un ZIP en JSON de toda la cuenta. Copiar y pegar sirve para una respuesta corta. Ninguno de esos métodos crea un archivo Markdown estructurado por chat como hace la extensión de Chrome.

¿Claude ya guarda la conversación en el historial?

Sí. Los chats con sesión iniciada en claude.ai se quedan en el historial de la cuenta de Anthropic. Cerrar la pestaña, recargar o abrir otro dispositivo con la misma cuenta no borra el hilo. El historial no es un PDF, un Markdown, un JSON ni ningún otro archivo en tu disco.

¿Desaparece una conversación de Claude si cierro la pestaña?

No. Cerrar una pestaña de claude.ai no borra la conversación del historial. Eliminar el chat del historial sí lo quita de la interfaz de la cuenta. Un archivo que ya exportaste con Download Claude conversations se queda en el disco incluso después de ese borrado.

¿Puedo guardar una conversación de Claude en PDF?

Sí. Download Claude conversations 1.16.2 exporta directamente a PDF: elige PDF en el panel del botón naranja y pulsa «Export». El archivo se genera en el navegador, sin diálogo de impresión. El PDF requiere iniciar sesión con Google y es gratis hasta 3 al día; Pro no tiene límite. Guía: chat de Claude en PDF.

¿Cuántos archivos gratis puedo guardar?

Ilimitados en Markdown, texto plano, JSON, XML, CSV y PNG, sin cuenta. El PDF y el ZIP masivo comparten 3 al día en el plan gratuito, con inicio de sesión de Google; cada chat de un ZIP masivo cuenta como uno, y el día se reinicia a medianoche UTC. Pro cuesta 3,99 US$ al mes o 26,99 US$ al año y elimina el límite. Paddle procesa el pago.

¿Puedo guardar conversaciones de Claude desde el móvil?

Con la extensión de Chrome, no. Funciona en Chrome de escritorio (u otro navegador Chromium que pueda instalar elementos de la Chrome Web Store). No hay app para iOS ni Android. Los navegadores móviles pueden abrir el historial e imprimir un chat de Claude, pero no pueden mostrar el botón naranja.

¿Puedo guardar chats de Claude del historial en bloque?

Sí. Abre «View and Download All Conversations» desde la ventana de la extensión, filtra la tabla y haz clic en «Export All». La exportación masiva requiere iniciar sesión con Google y cuenta para las 3 diarias del plan gratuito. No es el ZIP de Export data de Anthropic. El Export data oficial es un único archivo de toda la cuenta que llega más tarde por correo. Consulta la descarga masiva.

¿Sirve para guardar conversaciones de Claude Code?

Solo en la web. Las sesiones de Claude Code en claude.ai/code se guardan como cualquier chat de claude.ai. Las sesiones locales de la terminal no: usa /export o copia el JSONL de ~/.claude/projects (Windows: %USERPROFILE%\.claude\projects). Esta extensión de Chrome solo funciona en claude.ai. Guía: exportación de Claude Code.

¿Hace falta iniciar sesión con Google para guardar un chat de Claude?

No para Markdown, texto plano, JSON, XML, CSV o PNG. El inicio de sesión con Google solo se exige para PDF, «Export All» y Pro, para aplicar el límite de 3 al día y restaurar Pro tras reinstalar. El contenido de las conversaciones no se envía con ese inicio de sesión. Guardamos el correo verificado solo para la cuota y el estado Pro.

¿Dónde está Export data oficial para guardar chats de Claude?

En claude.ai: Settings → Privacy → Export data. Anthropic envía por correo un enlace que caduca. El ZIP es un archivo en JSON de toda la cuenta, no un archivo Markdown con nombre para el chat que estabas leyendo. Usa Export data como copia de seguridad; usa el botón naranja para obtener ahora un archivo legible.
