¿Cómo exporto un chat de Claude a Markdown?

Abre la conversación en claude.ai en Chrome, haz clic en el botón naranja junto al cuadro de mensaje, elige Markdown y pulsa «Export». Download Claude conversations genera un archivo .md en tu equipo. Así funciona en la versión 1.16.2.

  1. Instala Download Claude conversations desde Chrome Web Store.
  2. Recarga claude.ai y abre la URL de una conversación real, no la página de inicio con el cuadro de texto vacío.
  3. Haz clic en el botón naranja de descarga, a la derecha del cuadro de mensaje.
  4. Selecciona Markdown. La extensión recuerda el último formato que usaste. Usa «Select» (Seleccionar) para marcar solo los mensajes que quieras.
  5. Pulsa «Export». Chrome descarga el archivo .md mediante la API de descargas del navegador. O pulsa «Copy» (Copiar) para llevar el Markdown al portapapeles.

No hace falta iniciar sesión. Las exportaciones de un solo chat a Markdown son ilimitadas, anónimas y no envían nada a nuestros servidores. El inicio de sesión con Google solo se pide para PDF y para «Export All» (Exportar todo). Detalles técnicos: cómo funciona.

Si no ves el botón naranja, no estás en la URL de una conversación, la pestaña necesita recargarse tras la instalación o la extensión sigue oculta en el menú de extensiones de Chrome (el icono de la pieza de puzle). Fija Download Claude conversations y actualiza claude.ai. El script de contenido nunca se inyecta en Claude Desktop ni en la terminal de Claude Code.

Un chat o muchos. El botón naranja exporta el hilo abierto en Markdown. Para obtener muchos archivos .md, abre «View and Download All Conversations» (ver y descargar todas las conversaciones) y ejecuta «Export All» con Markdown seleccionado: un ZIP, 3 chats al día en el plan gratuito. Consulta la exportación masiva con Export All.

¿Por qué elegir Markdown para tus notas?

Elige Markdown cuando vayas a leer el archivo en Obsidian, en una wiki de GitHub o en cualquier editor que muestre encabezados y bloques de código. El .md sigue siendo texto plano que puedes buscar y comparar. JSON es mejor para programas que lo procesan; PNG es una imagen en la que no puedes buscar texto.

Copiar y pegar desde claude.ai suele perder la sangría y aplanar las tablas. Imprimir (Ctrl/Cmd+P) incluye la barra lateral y a menudo parte un bloque de código largo entre páginas. Al exportar a Markdown, los bloques de código mantienen su etiqueta de lenguaje y las tablas siguen siendo tablas. Por eso quien escribe suele elegir este formato primero.

Tratamos Markdown como el archivo legible por defecto: encabezados, código delimitado con etiqueta de lenguaje y tablas del hilo de claude.ai. Si lo que necesitas son páginas, elige PDF en el mismo panel. Se maqueta en el navegador, con tamaño de página, márgenes y tabla de contenido.

El equipo de Download Claude conversations

Mucha gente busca en inglés «claude export chat» o «Claude Chat Downloader» y llega a la misma ficha. Exportar un chat de Claude a Markdown es el mismo botón naranja, no un segundo producto. Las páginas legales pueden seguir diciendo Claude Exporter. Todos esos nombres se refieren a Download Claude conversations.

¿Qué conserva la exportación a Markdown?

Al exportar a Markdown, Download Claude conversations conserva encabezados, código delimitado con etiqueta de lenguaje y sangría, tablas y enlaces. Los bloques de razonamiento, las fuentes de búsqueda web y los pasos de herramientas / MCP son opcionales: «Thinking» (razonamiento) es una casilla del panel de exportación, y los otros dos se activan en Settings (Ajustes). Los metadatos (título, fechas y horas, modelo) pueden ir incluidos. El filtro de remitente limita el .md a todos los mensajes, solo los humanos o solo los del asistente.

La disposición de artefactos es una opción real en la versión 1.16.2: «Original», «Inline», «Nested» o «Flat» (original, en línea, anidada o plana). Una exportación a Markdown puede reflejar la estructura de artefactos que ves en pantalla, aplanarla en un único documento lineal o sacar los artefactos a su propia carpeta dentro de un ZIP. En Settings puedes incrustar imágenes en el .md. Lista completa: funciones de la extensión de Chrome. Markdown no conserva los colores de las burbujas de mensaje; usa PNG para una captura visual o PDF para páginas.

Si el hilo es muy largo, desplázate hasta que claude.ai cargue los mensajes anteriores antes de exportar. La extensión solo puede escribir lo que la página ya ha mostrado. Un hilo cargado a medias produce un .md a medias, algo que parece un error y casi siempre es un DOM sin desplazar.

¿Puedo exportar muchos chats a Markdown a la vez?

Sí. Abre «View and Download All Conversations», elige Markdown en «Chat format» (formato del chat), filtra la tabla y pulsa «Export All». Chrome guarda un ZIP con un archivo .md por chat. En el plan gratuito son 3 chats al día con inicio de sesión de Google, un límite compartido con PDF. Pro, por 3,99 US$ al mes o 26,99 US$ al año, elimina ese límite para la exportación masiva a Markdown.

El panel (Dashboard) muestra el historial de claude.ai con búsqueda por nombre, los filtros «All conversations», «New», «Updated» y «Previously exported» (todas, nuevas, actualizadas y ya exportadas), las pestañas Chat y Cowork y búsqueda por proyecto. «New» significa que aún no se ha exportado con Download Claude conversations. «Previously exported» registra los chats que ya guardaste, para que un segundo «Export All» pueda omitirlos.

El límite diario es por cuenta. Tres chats al día en el plan gratuito, compartidos con PDF. Si seleccionas 40 conversaciones y te quedan 3, se bloquea todo el lote, no se recorta. Selecciona menos o usa Pro. Las exportaciones sueltas a .md desde el botón naranja siguen siendo ilimitadas.

La exportación masiva a Markdown usa las casillas del Dashboard «Chats», «Thinking», «Metadata», «Tools» y «Sources» (chats, razonamiento, metadatos, herramientas y fuentes), además del formato de artefactos. «Export All» no es el ZIP diferido de Anthropic. Es un ZIP con archivos .md por chat. Si querías un único archivo de toda la cuenta, eso es Settings → Privacy → Export data (las etiquetas pueden aparecer traducidas si claude.ai está en español), que entrega JSON, no Markdown.

¿Markdown o JSON al exportar un chat de Claude?

Elige Markdown cuando el archivo lo vaya a leer una persona. Elige JSON cuando un script vaya a procesar el árbol de mensajes. Download Claude conversations ofrece ambos en un mismo menú, además de PDF, texto plano, XML, CSV y PNG. Todos los formatos: formatos de exportación de chats de Claude.

La exportación de datos de Anthropic también es JSON, pero es un ZIP de toda la cuenta que llega por correo, no un .md por chat. En esa solicitud no puedes elegir Markdown. Imprimir desde el navegador es una captura de la página web. Ninguna de las dos opciones sustituye la exportación a Markdown desde el botón naranja.

La extensión solo funciona en claude.ai en Chrome. Claude Desktop y la terminal de Claude Code no tienen botón de Markdown. Claude Code en la web (claude.ai/code) funciona dentro de claude.ai, así que se exporta como cualquier chat. Si un hilo también existe en claude.ai, ábrelo ahí y expórtalo a Markdown. El comando /export de Claude Code en la terminal es otra vía, de otro producto.

¿Exportar a Markdown cuesta algo extra?

No. Exportar un chat a Markdown es gratis e ilimitado, sin cuenta ni contador, igual que JSON, texto, XML, CSV y PNG. Solo PDF y «Export All» tienen un límite gratuito: 3 al día con inicio de sesión de Google. Pro cuesta 3,99 US$ al mes o 26,99 US$ al año a través de Paddle. Download Claude conversations no cobra ningún recargo por Markdown.

El límite aparece en la exportación masiva a Markdown. Cada chat de un ZIP de «Export All» consume uno de los 3 diarios, y el contador se reinicia a medianoche UTC. Pro lo elimina y se restaura en otro equipo con la misma cuenta de Google. Paddle es el comerciante registrado (merchant of record); este equipo nunca ve los números de tarjeta.

No necesitas un plan de pago de claude.ai de Anthropic. Solo necesitas una sesión que cargue la conversación en Chrome. Los planes Team y Enterprise funcionan igual que Free con el botón naranja. La versión 1.16.2, de septiembre de 2026, sigue sin generar Word ni Notion.

Preguntas frecuentes: exportar un chat de Claude a Markdown

Estas preguntas cubren la exportación a Markdown en Download Claude conversations 1.16.2: bloques de código, «Export All», el ZIP de Anthropic, el coste, PDF y Desktop. Cada respuesta es un dato del producto. El JSON-LD FAQPage del encabezado de la página coincide con esta lista.

¿Se pierde el código al exportar a Markdown?

No. Los bloques de código conservan su etiqueta de lenguaje y su sangría, a diferencia de copiar y pegar desde claude.ai. Las tablas siguen siendo tablas Markdown. Esa es la razón principal para exportar a Markdown en lugar de seleccionar el texto a mano.

¿Puedo exportar chats de Claude a Markdown de forma masiva?

Sí. «Export All» en el Dashboard admite Markdown y guarda un ZIP de archivos .md. En el plan gratuito cubre 3 chats al día con inicio de sesión de Google; con Pro es ilimitado.

¿Markdown es lo mismo que Export data de Anthropic?

No. La exportación oficial de Anthropic es un ZIP en JSON de toda tu cuenta que llega por correo tras una espera. Exportar a Markdown con Download Claude conversations te da un archivo .md por chat (o por selección).

¿Markdown cuesta más que otros formatos?

No. Las exportaciones de un solo chat a Markdown son ilimitadas y no requieren cuenta, igual que JSON, texto, XML, CSV y PNG. Solo PDF y el ZIP masivo tienen un límite gratuito de 3 al día. Pro cuesta 3,99 US$ al mes o 26,99 US$ al año.

¿Puedo exportar a Markdown desde Claude Desktop?

No. Download Claude conversations solo se inyecta en claude.ai en Chrome. Claude Desktop nunca muestra el menú de Markdown. Abre el mismo hilo en claude.ai si existe allí.

¿Exportar a Markdown crea un PDF?

No. Markdown es un archivo de texto .md. Si quieres páginas, elige PDF en el mismo panel: se genera en el navegador con tamaño de página, márgenes y tabla de contenido. PDF requiere iniciar sesión con Google y cuenta para el límite de 3 al día del plan gratuito.

¿Necesito Pro para exportar un chat a Markdown una vez?

No. No necesitas ninguna cuenta. Las exportaciones de chats sueltos a Markdown son ilimitadas en el plan gratuito. Pro, por 3,99 US$ al mes o 26,99 US$ al año, solo elimina el límite de 3 al día de «Export All» y PDF.
