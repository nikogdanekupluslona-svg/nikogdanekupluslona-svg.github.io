¿Cómo descargo un chat de Claude como PNG?

Abre la conversación en claude.ai en Chrome, haz clic en el botón naranja junto al cuadro de mensaje, elige PNG y pulsa «Export». Download Claude conversations genera la imagen en la pestaña. Así funciona en la versión 1.16.2: gratis, ilimitado y sin cuenta.

  1. Instala Download Claude conversations desde Chrome Web Store.
  2. Recarga claude.ai y abre la URL de una conversación real, no la página de inicio con el cuadro de texto vacío.
  3. Haz clic en el botón naranja redondo de descarga, a la derecha del cuadro de mensaje.
  4. Selecciona PNG. Se recuerda el último formato que usaste.
  5. Pulsa «Export». Chrome descarga el PNG al instante.

No hace falta iniciar sesión con Google. Las exportaciones de un solo chat a PNG son ilimitadas y anónimas: sin contador, y nada del chat sale del navegador. El inicio de sesión solo aparece si eliges PDF, ejecutas «Export All» (Exportar todo) o compras Pro. Detalles técnicos: cómo funciona.

Si no ves el botón naranja, no estás en la URL de una conversación, la pestaña necesita recargarse tras la instalación o la extensión está oculta en el menú de extensiones de Chrome (el icono de la pieza de puzle). Fija Download Claude conversations y actualiza claude.ai. Los proyectos, las sesiones de Cowork y Claude Code en la web (claude.ai/code) se exportan como cualquier chat. La exportación a PNG nunca aparece en la aplicación Claude Desktop ni en las sesiones locales de Claude Code en la terminal.

Una imagen o muchas. El botón naranja genera un PNG del hilo abierto. Para obtener muchas imágenes, abre «View and Download All Conversations» (ver y descargar todas las conversaciones) y ejecuta «Export All» con PNG seleccionado. La exportación masiva genera un ZIP y consume el cupo diario de exportación masiva. Consulta la exportación masiva con Export All.

¿Cuándo conviene una imagen PNG?

Descarga el chat como PNG cuando necesites una imagen para una diapositiva, una app de mensajería o un ticket: sitios donde es más fácil soltar una imagen que un archivo .md. No elijas PNG si más adelante vas a buscar texto o copiar código. Para eso usa Markdown, o PDF si necesitas páginas.

Una captura de claude.ai hecha a mano suele incluir la barra lateral y el cuadro de texto. Download Claude conversations crea el PNG a partir del contenido de la conversación que ya ha analizado, no de una captura cualquiera del sistema. Aun así es una imagen: no hay árbol de mensajes ni etiquetas de lenguaje en bloques de código que puedas copiar como texto.

Añadimos PNG para que puedas guardar una captura visual de un hilo de claude.ai en un solo archivo. Si prefieres páginas a una imagen larga, elige PDF: la extensión lo genera directamente, con números de página y tabla de contenido. PNG sigue siendo ilimitado y sin cuenta.

¿Un PNG es lo mismo que un PDF?

No. PNG es un formato de imagen. PDF es un formato de documento con páginas. Download Claude conversations exporta ambos: PNG para una sola imagen, PDF para páginas. PNG es ilimitado y sin cuenta; PDF requiere iniciar sesión con Google y es gratis hasta 3 al día. Paso a paso: descargar un chat de Claude como PDF.

¿Qué incluye una exportación a PNG?

Una exportación a PNG es una sola imagen del contenido de la conversación que Download Claude conversations ha generado. A diferencia de Markdown o JSON, el PNG no contiene un árbol de mensajes que se pueda procesar. El código y las tablas son píxeles. El razonamiento y los artefactos se dibujan, no se guardan como texto.

El filtro «Messages» (mensajes) limita lo que se dibuja a todos los mensajes, solo los humanos o solo los del asistente; la casilla «Thinking» (razonamiento) añade o quita el razonamiento extendido, y «Select» (Seleccionar) te permite marcar mensajes concretos. Los metadatos y la disposición de artefactos («Original», «Inline», «Nested», «Flat») son opciones del Dashboard para «Export All». Los metadatos no se convierten en texto seleccionable en el PNG como ocurre en JSON. «Copy» (Copiar) no funciona con PNG; siempre es un archivo.

Si el hilo es muy largo, desplázate hasta que claude.ai cargue los mensajes anteriores antes de exportar a PNG. La extensión solo puede dibujar lo que la página ya ha cargado. Un hilo cargado a medias produce una imagen recortada. Lista completa de opciones: funciones de la extensión de Chrome.

Guarda una copia en texto si te importan las palabras. PNG es una captura. Si más adelante necesitas buscar el nombre de una función, esa búsqueda fallará. Exporta también Markdown o JSON como segundo archivo; es ilimitado y gratis, igual que el PNG.

¿Puedo descargar muchos chats como PNG a la vez?

Sí. Abre «View and Download All Conversations», elige PNG en «Chat format» (formato del chat), filtra la lista y pulsa «Export All». Obtienes un ZIP con un PNG por conversación seleccionada. La exportación masiva requiere iniciar sesión con Google; en el plan gratuito, cada chat del ZIP consume una de las 3 exportaciones diarias de PDF o masivas. Pro, por 3,99 US$ al mes o 26,99 US$ al año, elimina ese límite.

El panel (Dashboard) muestra el historial de claude.ai con búsqueda por nombre, búsqueda por proyecto, las pestañas Chat y Cowork y los filtros «All conversations», «New», «Updated» y «Previously exported» (todas, nuevas, actualizadas y ya exportadas). «New» significa que aún no se ha exportado con Download Claude conversations. «Export All» genera un PNG por conversación seleccionada dentro del ZIP, no un collage de miniaturas ni un PDF encuadernado.

El límite masivo se reinicia a medianoche UTC. En el plan gratuito, una selección mayor que lo que te queda hoy se bloquea entera, no se recorta: elige menos chats o usa Pro. El PNG de un solo chat desde el botón naranja sigue siendo ilimitado. Settings → Privacy → Export data de Anthropic (las etiquetas pueden aparecer traducidas si claude.ai está en español) sigue siendo un ZIP en JSON diferido, no una carpeta de imágenes.

¿Descargar como PNG cuesta algo extra?

No. PNG es gratis e ilimitado, igual que Markdown, JSON, texto, XML y CSV. Sin cuenta de Google y sin contador. Pro (3,99 US$ al mes o 26,99 US$ al año a través de Paddle) sirve para PDF y ZIP masivo ilimitados, no para PNG. Download Claude conversations no cobra nada extra por descargar un chat de Claude como PNG.

El inicio de sesión solo entra en juego si quieres PDF o «Export All»: ambos comparten 3 exportaciones al día en el plan gratuito. Pro se restaura en otro equipo cuando inicias sesión con la misma cuenta de Google. Paddle es el comerciante registrado (merchant of record); este equipo nunca ve los números de tarjeta.

La extensión funciona en claude.ai en Chrome: chats, proyectos, sesiones de Cowork y Claude Code en la web (claude.ai/code). La aplicación Claude Desktop y las sesiones locales de Claude Code en la terminal no tienen botón de PNG. Este equipo no tiene app para iOS ni Android en 2026. La versión 1.16.2 genera PDF, pero no Word ni Notion.

Preguntas frecuentes: descargar un chat de Claude como PNG

Estas preguntas cubren la descarga como PNG en Download Claude conversations 1.16.2: PDF, «Export All», límites y qué contiene la imagen. Cada respuesta es un dato del producto. El JSON-LD FAQPage del encabezado de la página coincide con esta lista.

¿Download Claude conversations exporta PDF?

Sí. Elige PDF en el panel de exportación para obtener un documento paginado con números de página y tabla de contenido opcionales. PNG es una sola imagen del hilo. PDF requiere iniciar sesión con Google y es gratis hasta 3 al día; PNG es ilimitado y sin cuenta.

¿Puedo descargar todo el historial como PNG?

Sí. «Export All» en el Dashboard admite PNG y genera un ZIP con una imagen por conversación seleccionada. La exportación masiva requiere iniciar sesión con Google; en el plan gratuito, cada chat del ZIP consume una de las 3 exportaciones diarias de PDF o masivas. Con Pro es ilimitado.

¿PNG es gratis o solo para Pro?

Gratis e ilimitado. Las exportaciones de un solo chat a PNG no requieren cuenta y no tienen contador. Pro, por 3,99 US$ al mes o 26,99 US$ al año, es para PDF y ZIP masivo ilimitados.

¿Puedo copiar código de un PNG de un chat de Claude?

No de forma limpia. Un PNG guarda píxeles. Exporta Markdown o JSON si necesitas bloques de código con etiqueta de lenguaje. Guarda ambos archivos si necesitas una imagen y texto en el que buscar.

¿El PNG es una captura de pantalla de Chrome?

No. Download Claude conversations genera el PNG a partir de la conversación que ha analizado en claude.ai. Sigue siendo una imagen, no un archivo Markdown. Una captura de toda la ventana hecha con el sistema es otro archivo que haces tú.

¿PNG funciona en Claude Desktop?

No. La extensión de Chrome funciona en claude.ai en Chrome, no en la aplicación Claude Desktop. Claude Desktop nunca muestra la opción PNG. Abre el mismo hilo en claude.ai en Chrome si existe allí.

¿Una exportación a PNG usa el mismo cupo que Markdown?

Sí: ninguno de los dos tiene cupo. Las exportaciones de un solo chat a PNG y a Markdown son ilimitadas y anónimas. El único límite es de 3 exportaciones de PDF o ZIP masivo al día en el plan gratuito; Pro lo elimina.
