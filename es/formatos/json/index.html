Exportar conversación de Claude a JSON para scripts

Para exportar una conversación de Claude a JSON, instala Download Claude conversations, abre el hilo en claude.ai, haz clic en el botón naranja, elige JSON y pulsa «Export» (Exportar). Chrome guarda un archivo por chat con el árbol de mensajes. Ese archivo no es el ZIP de cuenta de Anthropic. La exportación a JSON es ilimitada y gratuita, sin cuenta; Pro (3,99 US$ al mes o 26,99 US$ al año) solo importa para la exportación masiva y PDF.

¿Cómo exporto una conversación de Claude a JSON?

Abre la conversación en claude.ai en Chrome, haz clic en el botón naranja junto al cuadro de mensaje, elige JSON y pulsa «Export». Download Claude conversations genera el archivo en tu equipo. Así funciona en la versión 1.16.2. En septiembre de 2026, claude.ai no tiene ninguna opción propia para guardar un chat como JSON.

  1. Instala Download Claude conversations desde Chrome Web Store.
  2. Recarga claude.ai y abre la URL de una conversación real, no la página de inicio con el cuadro de texto vacío.
  3. Haz clic en el botón naranja de descarga, a la derecha del cuadro de mensaje.
  4. Selecciona JSON. Se recuerda el último formato que usaste. Usa «Select» (Seleccionar) para marcar solo los mensajes que quieras.
  5. Pulsa «Export». Chrome descarga el JSON mediante la API de descargas del navegador. O pulsa «Copy» (Copiar) para llevar el JSON al portapapeles.

No hace falta iniciar sesión. Las exportaciones de un solo chat a JSON son ilimitadas, anónimas y no envían nada a nuestros servidores. El inicio de sesión con Google solo se pide para PDF y para «Export All» (Exportar todo). Detalles técnicos: cómo funciona.

Si no ves el botón naranja, no estás en la URL de una conversación, la pestaña necesita recargarse o la extensión está oculta en el menú de extensiones de Chrome (el icono de la pieza de puzle). Fija Download Claude conversations y actualiza claude.ai. El script de contenido nunca se inyecta en Claude Desktop ni en la terminal de Claude Code.

Un hilo o muchos archivos. El botón naranja exporta el chat abierto en JSON. Para obtener muchos archivos JSON, abre «View and Download All Conversations» (ver y descargar todas las conversaciones) y ejecuta «Export All» con JSON seleccionado: un ZIP, 3 chats al día en el plan gratuito. Consulta la exportación masiva con Export All.

¿Cuándo conviene elegir JSON?

Exporta a JSON cuando un script, un indexador o una herramienta de comparación vaya a leer el archivo. El JSON refleja el árbol de mensajes; no está pensado para leerse en Obsidian. Si quieres encabezados y bloques de código para personas, elige Markdown. Para una hoja de cálculo, elige CSV: una fila por mensaje.

Copiar y pegar desde claude.ai pierde la estructura de quién dice qué. Imprimir incluye los elementos de la página web. Con JSON, Download Claude conversations conserva los turnos, los remitentes y, si quieres, el razonamiento como datos, no como un párrafo aplanado. Por eso los desarrolladores prefieren JSON al texto plano.

Generamos el JSON a partir del árbol de claude.ai que ya está en la página (remitente, bloques de contenido, fechas y horas, metadatos del modelo) sin subir el hilo. Ese JSON no es el ZIP de cuenta de Anthropic. En la versión 1.16.2 es uno de los siete formatos, junto a PDF y CSV, y es gratis sin cuenta.

El equipo de Download Claude conversations

Mucha gente busca en inglés «claude export chat», «Claude Chat Downloader» o «Claude Conversation Downloader» y llega a la misma ficha. Exportar una conversación de Claude a JSON es ese botón naranja, no un segundo producto. Las páginas legales pueden seguir diciendo Claude Exporter.

¿Qué contiene una exportación a JSON?

Una exportación a JSON refleja el árbol de mensajes de claude.ai: remitente, bloques de contenido, fechas y horas, y metadatos del modelo. Los bloques de razonamiento, las fuentes de búsqueda web, los pasos de herramientas / MCP y los artefactos se incluyen cuando esas opciones están activadas: «Thinking» (razonamiento) es una casilla del panel de exportación, y las herramientas y las fuentes se activan en Settings (Ajustes). El filtro de remitente limita el archivo a todos los mensajes, solo los humanos o solo los del asistente. Nada se convierte antes a Markdown.

La disposición de artefactos en la versión 1.16.2 es «Original», «Inline», «Nested» o «Flat» (original, en línea, anidada o plana). Esas disposiciones cambian cómo se anida el contenido de los artefactos en el JSON; son las mismas cuatro opciones que en Markdown y XML. Lista completa: funciones de la extensión de Chrome. Si quieres páginas en lugar de datos, exporta a PDF.

¿JSON de la extensión o Export data de Anthropic?

Ambos son JSON, pero no tienen la misma forma ni el mismo alcance. En Anthropic, Settings → Privacy → Export data (las etiquetas pueden aparecer traducidas si claude.ai está en español) envía por correo un ZIP de toda la cuenta tras una espera. Al exportar una conversación de Claude a JSON con la extensión, obtienes un hilo al instante en Chrome. Usa el ZIP como copia de seguridad.

En la solicitud de ZIP de Anthropic no puedes elegir Markdown. Tampoco puedes usar el JSON de esta extensión como sustituto directo del esquema de ese ZIP. Todos los formatos: formatos de exportación de chats de Claude. PDF es para leer, no una exportación JSON.

Download Claude conversations no está afiliada a Anthropic, PBC. El script de contenido usa la sesión que ya tienes abierta en claude.ai. No inicia sesión en Anthropic con credenciales aparte. Sigue las normas de Anthropic para tu cuenta.

¿Puedo exportar muchas conversaciones a JSON a la vez?

Sí. Abre «View and Download All Conversations», elige JSON en «Chat format» (formato del chat), filtra la tabla y pulsa «Export All». Chrome guarda un ZIP con un archivo JSON por chat. En el plan gratuito son 3 chats al día con inicio de sesión de Google, un límite compartido con PDF. Pro, por 3,99 US$ al mes o 26,99 US$ al año, elimina ese límite para la exportación masiva a JSON.

El panel (Dashboard) muestra el historial de claude.ai con búsqueda por nombre, los filtros «All conversations», «New», «Updated» y «Previously exported» (todas, nuevas, actualizadas y ya exportadas), las pestañas Chat y Cowork y búsqueda por proyecto. «New» significa que aún no se ha exportado con Download Claude conversations. «Previously exported» registra los chats que ya guardaste. «Export All» genera un ZIP con archivos JSON por chat, no un archivo con formatos mezclados.

El límite diario es por cuenta. Tres chats al día en el plan gratuito, compartidos con PDF. Si seleccionas 40 conversaciones y te quedan 3, se bloquea todo el lote, no se recorta. Selecciona menos o usa Pro. Las exportaciones sueltas a JSON desde el botón naranja siguen siendo ilimitadas.

Puedes comparar dos exportaciones JSON del mismo hilo de claude.ai hechas en momentos distintos, como compararías cualquier archivo JSON. Cada exportación es independiente. Un segundo «Export All» de los mismos chats vuelve a contar cada chat.

¿La exportación a JSON requiere Pro?

No. Exportar un chat a JSON es gratis e ilimitado, sin cuenta ni contador, igual que Markdown, texto, XML, CSV y PNG. Solo PDF y «Export All» tienen un límite gratuito: 3 al día con inicio de sesión de Google. Pro cuesta 3,99 US$ al mes o 26,99 US$ al año a través de Paddle. Download Claude conversations no cobra nada extra por el JSON.

El límite aparece en la exportación masiva a JSON. Cada chat de un ZIP de «Export All» consume uno de los 3 diarios, y el contador se reinicia a medianoche UTC. Pro lo elimina y se restaura en otro equipo con la misma cuenta de Google. Paddle es el comerciante registrado (merchant of record); este equipo nunca ve los números de tarjeta.

La extensión solo funciona en claude.ai en Chrome. Claude Desktop y la terminal de Claude Code no tienen botón de JSON; Claude Code en la web (claude.ai/code) funciona dentro de claude.ai, así que se exporta como cualquier chat. El comando /export de Claude Code en la terminal o los archivos JSONL en disco son otra vía. La versión 1.16.2, de septiembre de 2026, sigue sin generar Word ni Notion.

Preguntas frecuentes: exportar una conversación de Claude a JSON

Estas preguntas cubren la exportación a JSON en Download Claude conversations 1.16.2: «Export All», el esquema, el coste, las comparaciones, el ZIP de Anthropic, PDF y Desktop. Cada respuesta es un dato del producto. El JSON-LD FAQPage del encabezado de la página coincide con esta lista.

¿Puedo exportar conversaciones de Claude a JSON de forma masiva?

Sí. «Export All» en el Dashboard admite JSON y guarda un ZIP con un archivo JSON por chat. En el plan gratuito cubre 3 chats al día con inicio de sesión de Google; Pro, por 3,99 US$ al mes o 26,99 US$ al año, es ilimitado.

¿Está documentada la estructura del JSON?

Refleja el propio árbol de mensajes de claude.ai: remitente, bloques de contenido, fechas y horas, y metadatos del modelo, con artefactos, bloques de razonamiento, fuentes de búsqueda web y pasos de herramientas / MCP cuando activas esas opciones. No es el esquema del ZIP de cuenta de Anthropic.

¿Necesito Pro para exportar una conversación de Claude a JSON?

No. Las exportaciones de un solo chat a JSON son ilimitadas y no requieren cuenta, como todos los formatos salvo PDF. Pro, por 3,99 US$ al mes o 26,99 US$ al año, solo elimina el límite de 3 al día de PDF y «Export All».

¿Puedo comparar dos exportaciones JSON de un mismo chat?

Sí. Cada vez que exportas a JSON obtienes un archivo independiente generado de la misma manera. Comparar dos exportaciones del mismo hilo hechas en momentos distintos funciona como con cualquier otro archivo JSON.

¿Este JSON es lo mismo que Export data de Anthropic?

No. Export data de Anthropic es un ZIP diferido de toda la cuenta. Download Claude conversations genera al instante en Chrome un archivo JSON por chat (o por selección). Ambos pueden ser JSON, pero no son intercambiables.

¿Exportar a JSON crea un PDF?

No. JSON son datos estructurados. Si quieres páginas, elige PDF en el mismo panel; los siete formatos son PDF, Markdown, JSON, texto plano, XML, CSV y PNG. PDF requiere iniciar sesión con Google y cuenta para el límite de 3 al día del plan gratuito.

¿La exportación a JSON funciona en Claude Desktop?

No. La extensión de Chrome solo se inyecta en claude.ai. Claude Desktop nunca muestra la opción JSON. Abre el mismo hilo en claude.ai en Chrome si existe allí.
