Exportar conversación de Claude Code o de claude.ai: elige la ruta correcta

Exportar una conversación de Claude Code es una tarea de terminal. Escribe /export en la sesión o copia el JSONL de ~/.claude/projects. Descargar una conversación de Claude Code desde la terminal no se hace con el botón naranja de este sitio. Download Claude conversations guarda los chats que abres en claude.ai con Chrome, incluidas las sesiones de Claude Code on the web en claude.ai/code. Las sesiones locales de la terminal y Desktop son cosa aparte.

¿Qué es exportar desde Claude Code en la terminal?

Exportar desde Claude Code es usar el comando /export dentro de una sesión interactiva de la CLI. La documentación de Anthropic describe un menú para copiar la conversación actual o guardar un archivo de texto plano, con los mensajes y las salidas de herramientas convertidos en texto legible. Si le pasas un nombre de archivo, se salta el menú y escribe ese archivo.

No es Markdown de claude.ai, ni JSON de esta extensión de Chrome, ni un PDF. Es una transcripción pensada para que la lea una persona. Anthropic indica que el registro JSONL en disco es un formato distinto e interno, pensado para el producto, no como tu API pública.

/export

Para saltarte la pregunta y escribir un archivo con nombre en el directorio de trabajo actual:

/export my-session

La documentación de sesiones de Anthropic es la referencia para opciones y nombres de archivo; cambian entre versiones de Claude Code. Toma los blogs de la comunidad como fuente secundaria. Si el texto del diálogo de /export no coincide con lo que ves, tu CLI es otra compilación: usa la ayuda integrada, no una captura de 2025.

Para scripts, Anthropic remite a otras interfaces: claude -p con --output-format json o stream-json, reanudar por ID de sesión, hooks que reciben un transcript_path o el Agent SDK. Son superficies de desarrollo de Claude Code. No son la extensión de Chrome de este sitio.

Legible frente a estructurado. /export es la transcripción para personas. El JSONL de la carpeta de proyectos es el registro. El JSON de la extensión de Chrome es una tercera forma, generada solo a partir de una página de claude.ai. No escribas un único analizador para las tres.

¿Cómo descargar una conversación de Claude Code desde el disco?

Para descargar una conversación de Claude Code desde el disco, copia el archivo JSONL de la sesión desde el directorio de proyectos, o ejecuta /export para obtener una transcripción legible. La ruta predeterminada en macOS y Linux está en ~/.claude/projects/. En Windows es %USERPROFILE%\.claude\projects. Los nombres de archivo son los ID de sesión.

El nombre de la carpeta del proyecto es el directorio de trabajo con los caracteres no alfanuméricos sustituidos por guiones. Anthropic recorta los nombres convertidos muy largos y añade un hash para que el directorio no supere los límites del sistema de archivos. Si no encuentras la carpeta, iniciaste Claude Code desde un directorio de trabajo distinto del que crees.

Cada línea del JSONL es un objeto JSON de un mensaje, un uso de herramienta o metadatos. Anthropic indica que este formato de entradas es interno y cambia entre versiones. Los scripts que analizan estos archivos pueden romperse con una nueva versión de Claude Code. Si necesitas algo estable, mejor /export o las interfaces de scripts documentadas.

La ubicación puede cambiar. CLAUDE_CONFIG_DIR saca el árbol de configuración de ~/.claude. CLAUDE_CODE_PROJECT_DIR_NAME da nombre al directorio del proyecto cuando se usa con ese directorio de configuración (Claude Code v2.1.234 o posterior, según Anthropic). cleanupPeriodDays en settings.json cambia la retención predeterminada. Ninguno de esos ajustes es una función de Download Claude conversations.

Por tanto, para descargar los archivos de conversaciones de Claude Code como copia de seguridad: copia la carpeta o exporta transcripciones con /export de forma periódica. Este sitio no añadirá un botón para «importar JSONL». No leemos tu carpeta personal.

¿Exportar desde Claude Code funciona con esta extensión?

No, no para las sesiones de terminal. Download Claude conversations no lee las sesiones locales de Claude Code. La extensión de Chrome se carga en claude.ai. No puede ver la terminal, no puede ejecutar /export y no puede abrir JSONL. Claude Code on the web en claude.ai/code es la excepción: es una página de claude.ai, así que se exporta como cualquier chat. Si buscabas cómo descargar una conversación de Claude Code desde la CLI, sigue los pasos de CLI de esta página.

La gente llega aquí porque Google agrupa «Claude» y «exportar». La ficha de la Web Store sigue siendo solo para claude.ai. Instalar la extensión no pondrá un botón naranja en iTerm, Ghostty, la terminal de VS Code ni el contenedor de escritorio de Claude Code.

Si además mantienes una conversación paralela en claude.ai para el mismo trabajo de programación, ese chat del navegador se puede guardar con la extensión. Los dos registros no se fusionan. Las llamadas a herramientas que solo ocurrieron en la CLI no aparecerán en la exportación web, salvo que las hayas pegado allí.

Cada semana recibimos el mismo correo de soporte: alguien instaló la extensión de Chrome y esperaba que apareciera /export. Solo analizamos claude.ai. Claude Code ya incluye /export y JSONL. Envolver la CLI sería otro producto, y no lo hemos lanzado.

La extensión es una herramienta para claude.ai, no un complemento de Claude Code. Sus límites solo se aplican cuando exportas desde claude.ai: Markdown, texto, JSON, XML, CSV y PNG son ilimitados y sin cuenta; el PDF y el ZIP en bloque son 3 al día gratis iniciando sesión con Google; Pro, por 3,99 US$ al mes o 26,99 US$ al año, elimina el tope. Nada de eso limita /export.

¿Puedo exportar las sesiones de Claude Code on the web?

Sí. Claude Code on the web funciona en claude.ai/code, así que Download Claude conversations exporta esas sesiones como cualquier chat de claude.ai. Abre la sesión en Chrome, haz clic en el botón naranja, elige un formato y pulsa «Export» (Exportar). Es la única superficie de Claude Code que cubre la extensión.

Los formatos son los mismos siete que para cualquier chat: PDF, Markdown, texto plano, JSON, XML, CSV y PNG. Markdown, texto, JSON, XML, CSV y PNG son ilimitados y no necesitan cuenta. PDF pide iniciar sesión con Google y comparte las 3 diarias del plan gratuito con el ZIP en bloque, salvo que tengas Pro. Los bloques de código conservan su etiqueta de lenguaje. El razonamiento extendido es la casilla «Thinking» (razonamiento) del panel; los pasos de herramientas / MCP y las fuentes de búsqueda web se activan en Settings (ajustes).

La exportación web es lo que claude.ai/code muestra en el navegador. No es el registro JSONL de una ejecución local de la CLI y no llega a las sesiones que solo se ejecutaron en tu terminal. Según Anthropic, Claude Code on the web mantiene su propio historial de sesiones, separado del árbol ~/.claude/projects de la CLI. Para una sesión de terminal, la vía sigue siendo /export.

¿Dónde guarda Claude Code el historial de conversaciones?

Claude Code guarda el historial de conversaciones como transcripciones JSONL en la carpeta de proyectos del directorio de configuración. Por defecto en macOS y Linux: ~/.claude/projects/<encoded-cwd>/<session-id>.jsonl. Windows usa %USERPROFILE%\.claude\projects. Anthropic puede cambiar esa estructura; consulta la documentación actual de sesiones si falta una ruta en el disco.

Reanudar no es lo mismo que exportar. claude --continue y claude --resume recargan una sesión para que sigas trabajando. /export escribe una copia que puedes dejar en git o enviar por correo. Una cosa restaura el contexto; la otra te da un registro para llevar contigo. La página de sesiones de Anthropic explica el modo de permisos al reanudar, la compactación / resumen y el selector de sesiones; nada de eso es esta extensión.

La app de escritorio, Claude Code on the web y la extensión de VS Code mantienen cada una su propio historial de sesiones, según Anthropic. Las rutas de esta guía son las de la CLI. Las sesiones web se quedan en claude.ai/code, donde la extensión puede exportarlas. No des por hecho que una transcripción de Cowork en Desktop está en el mismo árbol JSONL que usas desde la terminal.

No trates el JSONL como un esquema público. Anthropic indica que el formato de las líneas cambia. Si aun así lo analizas, fija una versión de Claude Code y cuenta con que algo se rompa. /export es la forma estable de obtener una conversación de Claude Code legible.

Variables de entorno como CLAUDE_CODE_SKIP_PROMPT_HISTORY pueden impedir que se escriban transcripciones. Si la carpeta de proyectos está vacía, comprueba si desactivaste la persistencia, si apuntaste CLAUDE_CONFIG_DIR a otro sitio o si nunca ejecutaste una sesión interactiva en ese directorio.

¿Cómo descargar un chat de Claude en claude.ai?

Para descargar un chat de Claude en claude.ai: instala Download Claude conversations, abre la conversación en Chrome, haz clic en el botón naranja y elige PDF, Markdown, texto plano, JSON, XML, CSV o PNG. Ese es el producto para el navegador, y también cubre las sesiones de claude.ai/code. No es exportar desde Claude Code en la terminal. Paso a paso: cómo descargar un chat de Claude.

Todo el historial de claude.ai en archivos separados se exporta con «Export All» (Exportar todo) en el Dashboard (panel), no con /export. En el plan gratuito, cada chat del ZIP cuenta para las 3 diarias (compartidas con el PDF, con reinicio a medianoche UTC); Pro elimina el tope. Guía: exportación en bloque con «Export All». No necesitas cuenta para exportar un solo chat en Markdown, texto, JSON, XML, CSV o PNG: esas exportaciones son ilimitadas. El inicio de sesión con Google solo aparece para PDF, ZIP en bloque y Pro, para que podamos contar la cuota diaria y restaurar Pro. Los archivos se generan en local, PDF incluido. Paddle factura Pro a 3,99 US$ al mes o 26,99 US$ al año. Nada de eso se aplica a /export en la terminal.

Si tu trabajo empezó en Claude Code y pegaste un resumen en claude.ai, descarga la conversación web para tus notas y guarda /export para el registro real de la CLI. Dos archivos son mejores que uno confuso.

¿Exportar desde Claude Code o el Export data oficial de Anthropic?

Exportar desde Claude Code (/export o JSONL) cubre una sesión de terminal. El Export data oficial es Settings → Privacy → Export data en claude.ai (los nombres pueden aparecer traducidos si claude.ai está en español): un ZIP diferido en JSON de la cuenta de Anthropic. No son el mismo archivo. El ZIP no sustituye a /export.

Que una sesión concreta de Claude Code aparezca en el ZIP de la cuenta depende de cómo Anthropic almacena ese producto, no de esta extensión. Trata el ZIP como una copia de seguridad de la cuenta web, salvo que la documentación de privacidad actual de Anthropic diga otra cosa. Nosotros no añadimos sesiones de la CLI a ese ZIP.

Cómo exportar un chat de Claude desde el sitio web, incluida la comparación entre ese ZIP y la extensión, está aquí: cómo exportar un chat de Claude. La exportación a PDF de la extensión tampoco sirve para una interfaz de terminal. Consulta descargar un chat de Claude en PDF solo cuando la conversación esté en claude.ai, claude.ai/code incluido.

¿Exportar desde Claude Code, Desktop o claude.ai?

Claude Code, Claude Desktop y claude.ai son tres superficies distintas. Exportar desde Claude Code usa /export y JSONL. Desktop es una app sin el botón naranja de esta extensión. claude.ai en Chrome es el único sitio donde funciona Download Claude conversations, Claude Code on the web en claude.ai/code incluido. Mezclar los nombres es la forma en que las exportaciones fallan sin avisar.

Claude Desktop: si el chat se sincronizó con la misma cuenta de Anthropic, ábrelo en claude.ai y expórtalo allí. Si solo existe en la ventana de Desktop, copia y pega o espera al Export data oficial. Guía: exportar un chat de Claude Desktop.

El panel de Claude Code en VS Code se parece más a la CLI que a claude.ai. No esperes que nuestro script de contenido se cargue en esa vista web. Usa /export desde la sesión que realmente contiene los mensajes.

Extensión independiente de Chrome, no afiliada a Anthropic, PBC. Claude es una marca registrada de Anthropic. Sigue sus Términos de servicio. No podemos dar asesoramiento legal sobre copiar salidas de herramientas que incluyan código propietario; eso queda entre tú, tu empresa y Anthropic.

Preguntas frecuentes: exportar conversación de Claude Code

¿Cómo exporto una conversación de Claude Code?

En la terminal de Claude Code, escribe /export (con un nombre de archivo si quieres) para guardar una transcripción legible, o copia el archivo JSONL de ~/.claude/projects en macOS/Linux o de %USERPROFILE%\.claude\projects en Windows. La documentación de sesiones de Anthropic describe el diálogo actual.

¿Esta extensión de Chrome descarga chats de Claude Code?

No desde la terminal. Download Claude conversations solo funciona en claude.ai con Chrome. No puede leer sesiones locales de terminal, transcripciones JSONL ni el comando /export. Las sesiones de Claude Code on the web en claude.ai/code sí se exportan, como cualquier chat.

¿Puedo exportar Claude Code on the web (claude.ai/code)?

Sí. Abre la sesión en claude.ai/code con Chrome y usa el botón naranja. Funcionan PDF, Markdown, texto plano, JSON, XML, CSV y PNG. Los seis formatos que no son PDF son ilimitados y sin cuenta; PDF necesita iniciar sesión con Google y cuenta para las 3 gratis al día.

¿Dónde guarda Claude Code el historial de conversaciones?

Las transcripciones de sesión son archivos JSONL en ~/.claude/projects/<encoded-working-directory>/, con el ID de sesión como nombre. La estructura exacta puede cambiar. Usa /export cuando quieras un archivo legible en lugar de analizar JSONL. CLAUDE_CONFIG_DIR puede mover el árbol.

¿Cómo descargar una conversación de Claude Code en Markdown?

El /export de Claude Code es una transcripción en texto plano, no el Markdown de esta extensión. Si necesitas Markdown en concreto, exporta una sesión de claude.ai/code o una copia del trabajo en claude.ai con Download Claude conversations, o convierte tú mismo el texto de /export. No convertimos JSONL a Markdown.

¿Cómo descargo una conversación de claude.ai?

Instala la extensión gratuita de Chrome, abre el chat en claude.ai y usa el botón naranja, o «Export All» para el historial. Consulta cómo descargar un chat de Claude. Markdown, texto, JSON, XML, CSV y PNG son ilimitados y sin cuenta; el PDF y el ZIP en bloque son 3 al día gratis iniciando sesión con Google; Pro cuesta 3,99 US$ al mes o 26,99 US$ al año.

¿/export es lo mismo que el Export data oficial?

No. /export es la sesión actual de Claude Code. Settings → Privacy → Export data envía por correo un ZIP en JSON de la cuenta de Anthropic. Son superficies de producto distintas, archivos distintos y esperas distintas.

¿Puedo analizar el JSONL de Claude Code con jq?

Puedes, con la advertencia que publica Anthropic: el esquema de las líneas es interno y puede cambiar. Si necesitas un contrato, mejor /export o claude -p --output-format json. Si aun así analizas JSONL, fija la versión de tu CLI.

¿Exportar desde Claude Code funciona en Windows?

Sí. /export es un comando de la CLI. Las transcripciones en disco están en %USERPROFILE%\.claude\projects, salvo que definas CLAUDE_CONFIG_DIR. Esta extensión de Chrome sigue sin funcionar dentro de esa terminal.

¿Claude Code es lo mismo que Claude Desktop?

No. Claude Code es el agente de programación para la terminal. Claude Desktop es la app de chat. claude.ai es el sitio web. Solo el sitio web, claude.ai/code incluido, tiene esta extensión. Notas sobre exportar desde Desktop: Claude Desktop.

¿Esta extensión llegará a envolver /export?

No en la versión 1.16.2. El alcance del producto es claude.ai, Claude Code on the web incluido: siete formatos, archivos locales e inicio de sesión con Google solo para PDF, exportación en bloque y Pro. Si ese alcance cambia, esta página lo dirá. Hasta entonces, usa la CLI de Anthropic para exportar desde Claude Code en la terminal.

¿/export incluye las salidas de herramientas?

Anthropic describe /export como mensajes y salidas de herramientas convertidos en texto legible. Es su transcripción, no nuestro analizador. Para saber el contenido exacto actual, ejecuta /export en tu versión y lee el archivo: la documentación puede ir por detrás de una versión.

¿Puedo exportar sesiones de Claude Code en bloque?

No las sesiones locales de la CLI. «Export All» en el Dashboard es solo para claude.ai. Para muchas sesiones de la CLI, copia la carpeta de proyectos o ejecuta /export en cada sesión. No hay exportación en bloque con el botón naranja para JSONL.
