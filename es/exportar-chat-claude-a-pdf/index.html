Cómo exportar un chat de Claude a PDF en un clic, con los ajustes correctos

Cómo exportar un chat de Claude a PDF: instala Download Claude conversations, abre el chat en claude.ai, pulsa el botón naranja, elige PDF y haz clic en «Export» (Exportar). La extensión genera el PDF en tu navegador, con el tamaño de página, los márgenes, el modo claro u oscuro y el índice que elijas. Es gratis hasta 3 PDF al día.

claude.ai no tiene botón de PDF, y Ctrl+P te da la página web paginada, con barra lateral, bloques de código partidos y todo. Esta guía explica cómo pasar un chat de Claude a PDF como un documento limpio: los cinco pasos, qué hace cada ajuste del PDF, cómo obtener un solo PDF con los mensajes seleccionados y qué hacer si el archivo sale mal. Cada paso está comprobado con la versión 1.16.2 de la extensión. Mucha gente lo busca también en inglés, como «claude export chat to pdf»; es la misma tarea.

¿Cómo exportar un chat de Claude a PDF, paso a paso?

Para exportar un chat de Claude a PDF necesitas Chrome de escritorio y la extensión gratuita Download Claude conversations. Son cinco clics: abre el chat, pulsa el botón naranja, elige PDF, pulsa «Export» y confirma el cuadro de diálogo del PDF. El primer PDF te pide iniciar sesión con Google.

  1. Instala Download Claude conversations desde Chrome Web Store y recarga las pestañas de claude.ai que tengas abiertas.
  2. Abre la conversación en claude.ai y deja que la última respuesta termine de generarse.
  3. Pulsa el botón redondo naranja de descarga, a la derecha del cuadro de mensaje. Se abre el panel de exportación.
  4. En «Format» (Formato), elige PDF. Deja «Messages» (Mensajes) en «All» (Todos) o elige «Human» (Humano) o «Assistant» (Asistente) para quedarte con una sola parte del chat.
  5. Pulsa «Export». La primera vez, inicia sesión con Google, ajusta las opciones del PDF y guarda el archivo.

Los mismos cinco pasos sirven para chats normales, Projects, sesiones de Cowork y Claude Code en la web (claude.ai/code). Todo lo que se abre en claude.ai en Chrome se puede exportar a PDF. La extensión no funciona en la aplicación Claude Desktop ni en el móvil; abre el mismo chat en Chrome de escritorio.

El razonamiento extendido es una casilla del panel de exportación: «Thinking» (Razonamiento). Los pasos de herramientas y MCP y las fuentes de búsqueda web se activan en «Settings» (Ajustes) de la extensión. El PDF solo lleva lo que marcaste, así que un chat con mucho razonamiento puede quedar corto en papel.

Límite del PDF en el plan gratuito. La exportación a PDF pide iniciar sesión con Google y es gratis hasta 3 al día, compartidas con las exportaciones masivas en ZIP; el contador se reinicia a medianoche UTC. Pro, por 3,99 US$ al mes o 26,99 US$ al año, hace el PDF ilimitado. Markdown, texto, JSON, XML, CSV y PNG siguen siendo ilimitados y sin cuenta.

¿Qué ajustes importan al exportar un chat de Claude a PDF?

El cuadro de diálogo del PDF decide cómo se ve un chat de Claude como documento. El tamaño de página, los márgenes y la fuente marcan la legibilidad. Los números de página, el índice y las marcas de tiempo facilitan moverse por un chat largo. Un salto de página antes de cada prompt empieza cada pregunta en una página nueva.

Nombre del archivo
Defínelo antes de guardar si archivas los PDF por proyecto o por fecha.
Tamaño de página
A4 o Carta para imprimir; usa el papel que tengan tus lectores.
Márgenes
Los márgenes estrechos dan cabida a código y tablas anchas; los normales se leen mejor en papel.
Modo claro u oscuro
Claro para imprimir, oscuro para leer el PDF en pantalla.
Fuente y tamaño de fuente
Un tamaño mayor ayuda en tabletas; uno menor deja las respuestas largas en menos páginas.
Números de página
Útiles en cuanto alguien diga «mira la página 12».
Índice
Añade una página de contenidos, así un chat de 40 mensajes es fácil de recorrer.
Marcas de tiempo
Añaden cuándo se envió cada mensaje: prácticas para registros y revisiones.
Salto de página antes de cada prompt
Empieza cada pregunta en una página nueva, así ninguna respuesta arranca a mitad de página.

Los bloques de código conservan su lenguaje y su formato en el PDF, y las tablas y las listas siguen siendo tablas y listas. Es la razón principal para exportar el chat a PDF en lugar de imprimirlo: la impresión parte el código donde se acaba el papel.

¿Por qué un PDF? Adobe, que creó el formato, describe el PDF como «una forma fácil y fiable de presentar e intercambiar documentos, sea cual sea el software, el hardware o el sistema operativo que se utilice». Un chat de Claude exportado a PDF se abre igual en el portátil de un colega, en el móvil de un cliente o en una impresora.

Generamos el PDF en tu navegador, así que los ajustes hacen lo que dicen: tamaño de página, márgenes, modo oscuro, números de página, índice y un salto de página antes de cada prompt. La impresión solo puede darte la página web. Si necesitas editar el texto antes de compartirlo, exporta Markdown.

¿Cómo guardar un chat de Claude como PDF sin extensión?

Para guardar un chat de Claude como PDF sin instalar nada, usa el cuadro de impresión de Chrome: abre el chat, pulsa Ctrl+P en Windows o Cmd+P en Mac, elige como destino Guardar como PDF y guarda. El archivo es una captura de la página web, no un documento exportado, y no tiene ajustes propios de Claude.

  1. Abre la conversación en claude.ai y desplázate hasta el primer mensaje para que se carguen todos los turnos.
  2. Contrae la barra lateral y cierra los paneles de artefactos que no quieras en papel.
  3. Pulsa Ctrl+P o Cmd+P. En «Destino», elige «Guardar como PDF».
  4. Abre «Más ajustes», elige el tamaño del papel y los márgenes, y marca «Gráficos de fondo» si la página se ve pálida.
  5. Pulsa «Guardar».

La propia Ayuda de Google Chrome cierra el mismo procedimiento con una línea: «Haz clic en Guardar como PDF.» Eso es todo lo que puede hacer la impresión. No añade números de página por prompt, ni índice, ni modo oscuro.

Lo que acaba en cada página lo decide la hoja de estilos de impresión de claude.ai, no tú. MDN describe los medios paginados de CSS como las reglas que especifican «cómo se generan y se maquetan las páginas para contener contenido fragmentado en una presentación paginada». Cuando esas reglas parten un bloque de código, el PDF conserva el corte.

Carga primero todo el hilo. Los chats largos de Claude cargan los mensajes antiguos solo cuando te desplazas hacia arriba. Una impresión o exportación hecha antes parece un PDF al que le falta el principio. Desplázate hasta arriba, espera un segundo y luego imprime o exporta.

Imprimir sirve para algo rápido y puntual. Para una comparación detallada entre la impresión y un archivo PDF real, móvil incluido, consulta descargar un chat de Claude en PDF.

¿Cómo obtener un chat de Claude en un solo PDF?

Un clic en «Export» da un solo archivo PDF con todo el chat de Claude, del primer prompt a la última respuesta. No puedes copiar un chat de Claude como PDF al portapapeles, porque «Copy» (Copiar) funciona con Markdown, texto, JSON, XML y CSV, pero el archivo exportado ya es un único PDF.

Para meter solo una parte del chat en un PDF, usa «Select» (Seleccionar). Pulsa «Select» en el panel de exportación, marca los mensajes que quieras, elige PDF y pulsa «Export». El PDF contiene solo esos mensajes, en orden. El filtro «Messages» hace lo mismo con un lado de la conversación: «Assistant» deja solo las respuestas de Claude y «Human», solo tus prompts.

Varios chats nunca se fusionan en un PDF. La exportación masiva genera un PDF por chat dentro de un ZIP. Si necesitas un único documento combinado, exporta los chats y une los PDF con cualquier editor de PDF, o exporta Markdown y pega los chats en un solo archivo antes de convertirlo.

¿Cómo convertir un chat de Claude a PDF desde Markdown?

Convierte un chat de Claude a PDF desde Markdown cuando quieras editar antes el texto. Exporta el chat en Markdown (ilimitado y sin cuenta), abre el archivo .md en un editor como VS Code, Obsidian o Typora, ajústalo y usa el comando de imprimir o exportar a PDF de ese editor.

  1. En claude.ai, pulsa el botón naranja, elige Markdown y pulsa «Export». Sin iniciar sesión, sin contador.
  2. Abre el archivo en tu editor. Recorta mensajes, arregla los encabezados y añade tus notas.
  3. Usa Exportar como PDF o Imprimir → Guardar como PDF del editor, con tu propia plantilla y tus fuentes.

Markdown funciona como paso intermedio porque sigue siendo legible como texto plano. John Gruber, creador de Markdown, escribió que «Markdown pretende ser tan fácil de leer y de escribir como sea posible.» Puedes editar un chat de Claude en Markdown sin pelearte con el marcado y luego maquetarlo una sola vez.

La contrapartida es usar dos herramientas en lugar de una. Si no necesitas editar, el PDF propio de la extensión es más rápido y ya trae números de página e índice. Además, Markdown nunca toca el límite diario de PDF, lo que ayuda en el plan gratuito. Más sobre el formato: exportación a Markdown.

La exportación de cuenta de Anthropic es un mal punto de partida para convertir. Es un ZIP en JSON de toda la cuenta, así que primero tendrías que extraer una conversación y convertir el JSON en texto legible. Exportar Markdown desde el chat abierto se salta todo eso.

¿Se pueden exportar muchos chats de Claude a PDF a la vez?

Sí. El Dashboard (panel) de la extensión exporta muchos chats de Claude a PDF de una sola vez: pon «Chat format» (Formato del chat) en PDF, marca las conversaciones y pulsa «Export All» (Exportar todo). Obtienes un ZIP con un PDF por chat. En el plan gratuito, cada chat del ZIP cuenta para las 3 exportaciones diarias.

  1. Haz clic en el icono de la extensión en Chrome y elige «View and Download All Conversations» (Ver y descargar todas las conversaciones).
  2. Filtra o busca en la lista y marca los chats que necesites.
  3. Pon «Chat format» en PDF. Decide si marcar «Thinking», «Metadata» (Metadatos), «Tools» (Herramientas) y «Sources» (Fuentes).
  4. Pulsa «Export All» y guarda el ZIP.

Si marcas más chats de los que te quedan gratis hoy, se bloquea el lote entero en lugar de recortarse: elige menos chats o pásate a Pro. Pro elimina el límite tanto del PDF como de la exportación masiva. El flujo completo, con filtros y opciones de artefactos, está en la guía de exportación masiva.

Reserva los PDF diarios para lo importante. Para un archivo grande, exporta primero en masa en Markdown o JSON (ambos ilimitados) y exporta a PDF solo los chats que de verdad vayas a enviar o imprimir.

¿Por qué sale mal el PDF exportado de un chat de Claude?

La mayoría de los PDF de chats de Claude que salen mal tienen una de cuatro causas: el hilo no estaba cargado del todo, el desplegable «Format» seguía en el último formato usado, se alcanzó el límite diario gratuito o se usó la impresión en lugar de la exportación. Cada causa tiene un arreglo rápido, recogido en la tabla siguiente.

Un PDF equivocado también cuenta en el plan gratuito, así que revisa el desplegable «Format» antes de pulsar «Export». Si no ves el botón naranja, recarga claude.ai después de instalar: el botón aparece junto al cuadro de mensaje en cada página de chat.

¿PDF con la extensión, impresión o exportación oficial?

Hay tres métodos para convertir un chat de Claude en un archivo, y solo uno genera un PDF real de un chat. La extensión exporta un PDF paginado en segundos. La impresión da una captura de la página web. Export data de Anthropic envía por correo un ZIP de toda la cuenta, y no es un PDF.

La vía oficial está en claude.ai, en Settings → Privacy → Export data (los nombres pueden aparecer traducidos si claude.ai está en español). El Centro de ayuda de Claude explica: «Una vez procesada la exportación, recibirás un enlace de descarga por correo electrónico.» La misma página añade que «el enlace de descarga caducará 24 horas después de la entrega».

Preguntas frecuentes: exportar un chat de Claude a PDF

¿Cómo exporto un chat de Claude a PDF?

Instala Download Claude conversations, abre el chat en claude.ai, pulsa el botón naranja junto al cuadro de mensaje, elige PDF y pulsa «Export». La primera vez, inicia sesión con Google, ajusta el tamaño de página y las demás opciones, y guarda. El PDF se genera en tu navegador.

¿Cómo guardo un chat de Claude como PDF gratis?

La exportación a PDF de la extensión es gratis hasta 3 PDF al día con inicio de sesión de Google. El cuadro de impresión de Chrome (Ctrl+P o Cmd+P → Guardar como PDF) es gratis y sin límite, pero da una captura de la página web. Exportar Markdown y convertirlo en un editor también es gratis e ilimitado.

¿Cómo descargo un chat de Claude en PDF?

Aquí descargar y exportar son lo mismo: elige PDF en el panel de exportación y Chrome guarda el archivo como cualquier otra descarga. Para comparar la impresión con el archivo exportado, consulta descargar un chat de Claude en PDF.

¿Puedo copiar un chat de Claude como un solo PDF?

Al portapapeles, no: «Copy» admite Markdown, texto, JSON, XML y CSV, no PDF. Pulsa «Export»: una exportación es un archivo PDF con todo el chat. Para incluir solo algunos mensajes, usa «Select» antes de exportar.

¿Puedo exportar a PDF solo las respuestas de Claude?

Sí. Pon «Messages» en «Assistant» en el panel de exportación, elige PDF y pulsa «Export». El PDF contendrá las respuestas de Claude sin tus prompts. «Human» hace lo contrario.

¿El PDF de un chat de Claude conserva los bloques de código y las tablas?

Sí, cuando exportas. Los bloques de código conservan su lenguaje y su formato, y las tablas y las listas se mantienen. La impresión es el camino débil: los bloques de código se ajustan o se parten entre páginas, y las tablas anchas se cortan.

¿Puedo exportar un chat de Claude a PDF en modo oscuro?

Sí. El cuadro de diálogo del PDF tiene modo claro y modo oscuro. El oscuro va bien para leer en pantalla; el claro es mejor para imprimir en papel.

¿Puedo convertir un chat de Claude a PDF desde el móvil?

Con la extensión no, porque solo funciona en Chrome de escritorio y en navegadores Chromium. Un navegador móvil puede imprimir o compartir la página en PDF, pero el diseño queda apretado. Para un PDF limpio, abre el mismo chat en Chrome de escritorio.

¿Puedo exportar una sesión de Claude Code a PDF?

Claude Code en la web (claude.ai/code) se abre en claude.ai, así que la extensión la exporta a PDF como cualquier chat. Una sesión de terminal no es una página web: usa ahí /export e imprime el archivo de texto desde un editor.

¿Se sube mi chat de Claude al exportarlo a PDF?

No. El PDF se genera en tu navegador, como todos los demás formatos. Tras iniciar sesión, solo se envía el correo de tu cuenta de Google, para comprobar el límite diario o Pro.

¿Por qué obtuve un archivo Markdown en lugar del PDF del chat de Claude?

El panel de exportación recuerda el último formato que usaste. Pon «Format» en PDF antes de pulsar «Export». En el plan gratuito, revísalo primero, porque cada PDF cuenta para los 3 del día.
