Cómo exportar un chat de Claude como archivo estructurado

Claude.ai no tiene un control para exportar una sola conversación. ¿Cómo exportar un chat de Claude con la extensión?

La forma de exportar un chat de Claude como archivo legible es el botón naranja de claude.ai. Instala Download Claude conversations, abre la conversación, elige PDF, Markdown, JSON, texto, XML, CSV o PNG y pulsa «Export» (Exportar). El archivo se genera en tu navegador y se guarda en local. No necesitas cuenta, salvo para PDF y la exportación en bloque.

La extensión es un script de contenido en la página que ya cargaste. No abre una segunda sesión de Anthropic ni sube la conversación para generar el archivo. Por eso el botón solo aparece en la URL de una conversación, cuando la conversación ya está en el DOM.

  1. Instala la extensión desde la Chrome Web Store.
  2. Abre la conversación en claude.ai. Recarga la pestaña si estaba abierta durante la instalación.
  3. Haz clic en el botón redondo naranja de descarga, junto al cuadro de mensaje.
  4. Pon Messages (Mensajes) en «All», «Human» o «Assistant» (todos, humano o asistente) y elige PDF, Markdown, JSON, texto plano, XML, CSV o PNG.
  5. Marca «Thinking» (razonamiento) para incluir el razonamiento extendido. Usa «Select» (Seleccionar) para marcar mensajes sueltos si solo necesitas parte de la conversación. Pulsa «Export», o «Copy» (Copiar) para poner Markdown, texto, JSON, XML o CSV en el portapapeles.

Para más de una conversación, abre «View and Download All Conversations» (ver y descargar todas las conversaciones) en la ventana emergente. Busca, filtra por «New», «Updated» o «Previously exported» (nuevas, actualizadas o ya exportadas), busca proyectos, elige un «Chat format» y pulsa «Export All» (Exportar todo) para obtener un ZIP con un archivo por chat. La exportación en bloque pide iniciar sesión con Google; en el plan gratuito, cada chat de ese ZIP consume una de las 3 diarias, compartidas con el PDF. Paso a paso: exportación en bloque con «Export All».

Los chats de Team y Enterprise se exportan igual si puedes abrirlos en Chrome. El analizador no comprueba el nombre del plan de Anthropic. Si tu organización bloquea las extensiones, es una política de TI, no una opción de Pro que falte por nuestra parte.

Nuestra cuota frente al uso de Anthropic. Exportar con esta extensión no gasta créditos de mensajes de Claude: solo lee la página. El tope de 3 al día para PDF y exportación en bloque es nuestra cuota; Pro, por 3,99 US$ al mes o 26,99 US$ al año, facturado aparte a través de Paddle, lo elimina.

¿Cómo exportar chats de Claude con el ZIP oficial?

Para exportar chats de Claude a escala de cuenta, usa Settings → Privacy → Export data. Anthropic envía por correo un enlace que caduca. El ZIP es JSON de toda la cuenta, no un archivo bonito de una conversación. Úsalo como copia de seguridad.

El ZIP oficial es la herramienta adecuada cuando dejas un espacio de trabajo, archivas todo o respondes a una solicitud de «dame todos mis datos». No lo es cuando tienes abierta una revisión de diseño y necesitas un archivo en el próximo minuto.

En ese flujo no hay filtro para el ID de una sola conversación. Esperas, descargas el archivo, lo descomprimes y buscas la conversación. La estructura del JSON es de cuenta. No es el JSON por chat que esta extensión escribe desde la página abierta.

Si necesitas ambas cosas, ejecuta Export data una vez para la copia de seguridad y usa Download Claude conversations cuando necesites un archivo de trabajo. Una tarea no sustituye a la otra. El ZIP no se convertirá en Markdown. El botón naranja no te enviará por correo todos los chats olvidados de 2024.

El Export data oficial tampoco es imprimir a PDF. Imprimir captura la página web. El ZIP son datos estructurados de la cuenta. Comparación entre imprimir y el PDF integrado de la extensión: descargar un chat de Claude en PDF.

¿Cómo exporto un chat de Claude a Markdown o JSON?

Para exportar un chat de Claude a Markdown o JSON, elige ese formato en el desplegable antes de pulsar «Export». Markdown sirve para notas y git. JSON es el árbol de mensajes para scripts. El texto plano elimina el marcado. CSV pone un mensaje por fila. PNG es una imagen; PDF es el documento paginado.

Markdown conserva encabezados, bloques de código con etiqueta de lenguaje y tablas. La disposición de artefactos puede ser «Original», «Inline», «Nested» o «Flat» (original, en línea, anidada o plana). Los bloques de razonamiento son opcionales. Ese archivo es lo que la mayoría entiende por una exportación legible. Página central: formatos.

El JSON de la extensión es por conversación (o por selección en bloque). No es el ZIP de cuenta de Anthropic con otro nombre. Si escribes un analizador, usa este JSON para una conversación y el ZIP oficial solo cuando de verdad necesites todas las conversaciones que Anthropic guarda.

PNG no es un PDF. Si un cliente exige PDF, elige PDF en la lista de formatos. Se genera en el navegador, con tamaño de página, márgenes, números de página e índice, y pide iniciar sesión con Google. Guía: descargar un chat de Claude en PDF.

El desplegable recuerda el último formato. Exportar JSON por accidente después de una sesión de scripts es el aviso de «archivo equivocado» más habitual. Mira el desplegable antes de hacer clic, sobre todo antes de un PDF, que consume una de las 3 diarias del plan gratuito.

¿Puedo exportar un chat de Claude sin pagar?

Sí. Puedes exportar un chat de Claude sin pagar en Markdown, texto, JSON, XML, CSV o PNG tantas veces como quieras, sin cuenta. El PDF y «Export All» en bloque son gratis hasta 3 al día iniciando sesión con Google. Pro, por 3,99 US$ al mes o 26,99 US$ al año, los hace ilimitados.

La exportación en bloque con «Export All» y el PDF comparten esas 3 diarias. Cada conversación de un ZIP en bloque consume una. Si seleccionas veinte en una cuenta gratuita, se bloquea todo el lote; no se recorta: elige menos, espera al reinicio de medianoche UTC o pásate a Pro. Planifica la selección.

Imprimir y el Export data de Anthropic no consumen nuestra cuota. Tampoco te dan el Markdown de un chat. Lo gratis sin extensión también cuesta tiempo y limpieza.

El inicio de sesión con Google solo es para PDF y exportación en bloque. La primera exportación en PDF o el primer «Export All» piden a Google que verifique un correo. Si lo cancelas, parece que la exportación falló. Completa el inicio de sesión y vuelve a pulsar «Export». El plan gratuito no pide tarjeta, y Markdown, texto, JSON, XML, CSV y PNG nunca piden iniciar sesión.

Pro se restaura con ese correo de Google si cambias de equipo o reinstalas. No depende de la contraseña de Anthropic. Inicia sesión con la misma cuenta de Google que usaste al pagar.

Mantenemos a propósito el ZIP oficial y nuestra exportación como dos tareas distintas. El JSON de cuenta por correo es la copia de seguridad de Anthropic. El Markdown y el JSON por chat son lo que generamos en el navegador a partir de la conversación que tienes abierta. Mezclar ambas cosas en un solo botón empeoraría las dos.

¿Exportar un chat de Claude o copiar y pegar?

Copiar y pegar solo exporta un chat de Claude en el sentido más débil: seleccionaste texto y lo moviste. El código pierde la sangría. Las tablas se deshacen. Una conversación larga no tiene límites entre mensajes. Para exportar un chat de Claude como archivo estructurado, las opciones siguen siendo la extensión, imprimir o el ZIP oficial.

Un término medio es seleccionar todo, pegarlo en Google Docs o Word y arreglar el formato a mano. Sirve para una entrega puntual a un cliente, no para un archivo semanal. Cada turno nuevo implica otra limpieza. La extensión existe para que esa limpieza no empiece desde un pegado.

Copiar y pegar también pierde el razonamiento contraído y los artefactos que no estaban desplegados. Imprimir tiene el mismo problema: lo que está contraído en la interfaz no aparece en el PDF. Las opciones de la extensión pueden incluir el razonamiento y los artefactos cuando están en los datos cargados de la página, que es otra capa distinta de «los píxeles visibles».

Si solo necesitas un párrafo para Slack, copiar y pegar es honesto y más rápido. Si necesitas toda la revisión con los bloques de código, expórtala a Markdown (gratis, ilimitado y sin cuenta) o usa el botón «Copy» del panel para poner ese Markdown en el portapapeles.

¿Cómo exportar Claude Code frente a los chats de claude.ai?

Para exportar un chat de Claude en claude.ai se usa esta extensión de Chrome, y eso incluye las sesiones de Claude Code on the web en claude.ai/code. Para exportar una conversación local de Claude Code en la terminal se usa /export en la terminal, o el JSONL de ~/.claude/projects. Claude Desktop es una tercera ventana y no tiene el botón naranja.

El /export de Claude Code escribe una transcripción en texto plano (al portapapeles o a un archivo). Anthropic documenta que el JSONL en disco es un formato interno que puede cambiar. Para lo que vayas a conservar, mejor /export o sus interfaces de scripts. Pasos: exportar desde Claude Code.

Claude Desktop: abre el mismo chat en claude.ai si se sincronizó y expórtalo allí. Si no, copia y pega desde Desktop o recurre a Settings → Privacy → Export data para obtener el JSON de la cuenta. Guía: exportar un chat de Claude Desktop.

Buscar «claude code export» en este sitio lleva a una página que aclara las dos rutas, no a una función de la ficha de la Web Store. La extensión solo funciona en claude.ai: Claude Code on the web está incluido, la terminal no. Ese límite es el producto, no una casilla que falte.

¿Qué conserva y qué pierde una exportación de Claude?

Una exportación de un chat de Claude con esta extensión conserva el árbol de mensajes que la página ha cargado: remitentes, texto, bloques de código, tablas y, si lo activas, razonamiento, metadatos y artefactos. Deja fuera lo que aún no se ha mostrado y la interfaz, como el cuadro de mensaje.

Imprimir conserva píxeles. Casi siempre pierde una disposición limpia del código. El ZIP oficial conserva lo que Anthropic incluyó en el archivo de la cuenta. Pierde un documento legible por chat. Copiar y pegar conserva los caracteres seleccionados y pierde la estructura.

Filtro de remitente: todos los mensajes, solo los humanos o solo los del asistente. Útil cuando quieres las preguntas sin respuestas, o al revés. La opción de metadatos añade títulos, marcas de tiempo y modelo cuando necesitas una referencia bibliográfica en el archivo.

Los archivos se quedan en el disco. Nuestro servidor solo ve el estado de la cuota y de la suscripción después de que inicias sesión para PDF, exportación en bloque o Pro, y Google ve el consentimiento OAuth que aprobaste entonces. claude.ai ya tenía la conversación. Esa es la lista completa de partes. No somos Anthropic. Claude es una marca registrada de Anthropic, PBC.

Si la exportación parece corta, carga más de la conversación y vuelve a exportar. En Markdown, texto, JSON, XML, CSV o PNG, ese segundo intento es gratis; un segundo PDF consume otra de las 3 diarias. Comprueba que la respuesta terminó de generarse y que los turnos anteriores están en pantalla antes de hacer clic.

Preguntas frecuentes: cómo exportar un chat de Claude

¿Cómo exporto una sola conversación de Claude?

Usa Download Claude conversations en la conversación abierta de claude.ai. El flujo oficial Export data abarca toda la cuenta y es más lento de lo que necesitas para una sola conversación. Imprimir da un PDF visual, no Markdown.

¿Cómo exporto un chat de Claude a PDF?

Elige PDF en la lista de formatos de la extensión y pulsa «Export». El PDF se genera en el navegador, sin diálogo de impresión; pide iniciar sesión con Google y es gratis hasta 3 al día, ilimitado con Pro. Imprimir (Ctrl/Cmd+P → Guardar como PDF) sigue sirviendo para una instantánea aproximada de la página web. Guía: descargar un chat de Claude en PDF.

¿La exportación oficial incluye artefactos y razonamiento?

El ZIP incluye lo que Anthropic guardó en el JSON de la cuenta. No tiene formato de Markdown por chat con la disposición de artefactos que elijas. La exportación de la extensión está pensada para que eso sea legible cuando las opciones están activadas y la página lo ha cargado.

¿Una extensión de Chrome pone en riesgo mi cuenta de Anthropic?

La extensión usa tu sesión de claude.ai ya iniciada, igual que el sitio web. No automatiza acciones de la cuenta ni llama a Anthropic con credenciales propias. No somos Anthropic. Sigues sujeto a sus Términos de servicio.

¿Hay una forma gratis de exportar un chat de Claude?

Sí. Las exportaciones en Markdown, JSON, texto, XML, CSV y PNG son gratis e ilimitadas, sin cuenta. El PDF y la exportación en bloque son gratis hasta 3 al día; Pro cuesta 3,99 US$ al mes o 26,99 US$ al año. Imprimir y el Export data oficial no consumen esta cuota.

¿Puedo exportar un chat de Claude desde espacios de trabajo Team?

Sí, si puedes abrir la conversación en claude.ai con Chrome. La extensión trabaja sobre la página, no sobre un plan solo para particulares. Las listas de extensiones permitidas de tu empresa siguen aplicándose.

¿Exportar consume los límites de mi cuenta de Anthropic?

No. Download Claude conversations lee la página que ya cargaste. No envía solicitudes de generación adicionales a Claude y no cuenta para los límites de mensajes o de uso de Anthropic.

¿La primera exportación en bloque es gratis?

Sí, hasta 3 conversaciones al día en el plan gratuito, compartidas con el PDF, tras iniciar sesión con Google. Cada chat del ZIP cuenta como una. Una selección mayor se bloquea entera, no se recorta; Pro elimina el tope.

¿Cómo exporto una conversación de Claude Code?

Las sesiones de Claude Code on the web en claude.ai/code se exportan con el botón naranja como cualquier chat. En la terminal, ejecuta /export o copia el JSONL de ~/.claude/projects; esta extensión de Chrome no lee sesiones locales. Todos los pasos: exportar desde Claude Code.

¿Hace falta iniciar sesión con Google para exportar un chat de Claude?

Solo para PDF, «Export All» en bloque y Pro. Las exportaciones en Markdown, texto, JSON, XML, CSV y PNG no necesitan cuenta. El inicio de sesión aplica el límite de 3 al día para PDF y exportación en bloque y restaura Pro. El contenido de los chats no se sube al iniciar sesión. Guardamos el correo verificado para el estado de la cuota y de la suscripción.

¿A qué formatos puedo exportar un chat de Claude?

PDF, Markdown, JSON, texto plano, XML, CSV y PNG. PNG es una imagen; PDF es un documento paginado. Consulta formatos para saber cuándo elegir cada uno.

¿Claude Conversation Downloader es la misma extensión?

Sí. Download Claude conversations, Claude Chat Downloader y Claude Conversation Downloader se refieren a la misma extensión de Chrome: botón naranja en claude.ai, siete formatos, exportaciones gratis e ilimitadas en seis de ellos, PDF y exportación en bloque gratis hasta 3 al día, y Pro por 3,99 US$ al mes o 26,99 US$ al año.
