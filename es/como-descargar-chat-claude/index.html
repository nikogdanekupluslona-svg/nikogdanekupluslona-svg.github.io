¿Cómo descargar un chat de Claude con Chrome?

La respuesta directa es el botón naranja que Download Claude conversations añade junto al cuadro de mensaje en claude.ai. Abre la conversación, elige PDF, Markdown, JSON, texto, XML, CSV o PNG y haz clic en «Export» (Exportar). El archivo se genera en tu navegador y se guarda en el disco.

La extensión es un content script de Chrome. Lee la conversación que ya está cargada en tu sesión de claude.ai. No llama a ninguna API aparte de Anthropic con credenciales propias ni sube el hilo a nuestros servidores para generar el archivo.

  1. Instala Download Claude conversations desde la Chrome Web Store (también funcionan los navegadores Chromium que cargan extensiones de Chrome).
  2. Recarga claude.ai si la página ya estaba abierta durante la instalación.
  3. Abre la URL de la conversación que quieres: el botón naranja solo aparece en un hilo real, no en la pantalla de inicio vacía.
  4. Haz clic en el botón redondo naranja de descarga, a la derecha del cuadro de mensaje. Se abre un panel con Messages (All / Human / Assistant; todos, humano, asistente), Format, «Thinking», «Select» (Seleccionar), «Copy» (Copiar) y «Export».
  5. Elige PDF, Markdown, texto plano, JSON, XML, CSV o PNG. Haz clic en «Export». Chrome descarga el archivo al instante.

Para Markdown, texto plano, JSON, XML, CSV o PNG no necesitas cuenta. Esas exportaciones de un solo chat son ilimitadas y gratuitas: sin inicio de sesión ni contador. El inicio de sesión con Google solo aparece al elegir PDF o lanzar una exportación masiva con «Export All» (Exportar todo). No es un acceso para leer tus chats. El contenido de las conversaciones se queda en tu equipo.

El PDF y el ZIP masivo comparten una cuota gratuita de 3 al día, que se reinicia a medianoche UTC. Cada chat dentro de un ZIP masivo cuenta como uno. Pro cuesta 3,99 US$ al mes o 26,99 US$ al año y elimina ese límite. Opciones y pasos del PDF: descargar un chat de Claude en PDF.

Archivos locales. Todos los formatos, PDF incluido, se generan en el navegador y se entregan a la API de descargas de Chrome. El texto del chat nunca se sube. Solo las exportaciones en PDF y masivas envían una comprobación de cuota con tu correo de Google.

El mismo panel filtra por remitente: All, Human o Assistant (todos, humano o asistente). La casilla «Thinking» incluye u omite el razonamiento extendido. «Select» te deja marcar mensajes sueltos para que el archivo contenga solo esos turnos. «Copy» lleva Markdown, texto, JSON, XML o CSV al portapapeles en lugar de descargar un archivo. Los pasos de herramientas / MCP y las fuentes de búsqueda web se activan en Settings (Configuración). Los metadatos y la disposición de los artefactos («Original», «Inline», «Nested» o «Flat») se eligen en el Dashboard (panel).

Si el hilo es muy largo, desplázate hasta que claude.ai haya cargado los mensajes anteriores. La extensión solo puede exportar lo que la página ha mostrado. Un hilo cargado a medias produce un archivo a medias, que parece un error y casi siempre es solo un DOM sin desplazar.

Analizamos el árbol de mensajes de la página de claude.ai que ya tienes abierta. Los bloques de código conservan las etiquetas de lenguaje y la sangría; las tablas siguen siendo tablas. El PDF se construye a partir de ese mismo árbol dentro del navegador, sin diálogo de impresión, así que un archivo imprimible ya no significa una captura de la página web.

¿Puedo descargar un chat de Claude sin extensión?

Sí. Puedes descargar un chat de Claude sin extensión imprimiendo la página o pidiendo la exportación de la cuenta a Anthropic. Imprimir da un PDF visual de la página web. Export data es un ZIP en JSON de toda la cuenta que llega con retraso. Ninguno de los dos crea un archivo Markdown por chat.

Imprimir: abre la conversación en claude.ai, oculta la barra lateral si la interfaz lo permite, pulsa Ctrl+P (Windows/Linux) o Cmd+P (Mac), elige Guardar como PDF como destino y guarda. Los bloques de código suelen partirse entre páginas. Los elementos del cuadro de mensaje pueden aparecer en cada hoja. La exportación a PDF de la propia extensión se salta ese diálogo. Las dos vías se comparan en descargar un chat de Claude en PDF.

Vía oficial: Settings → Privacy → Export data en claude.ai (las etiquetas pueden aparecer traducidas si claude.ai está en español). Anthropic envía por correo un enlace que caduca. El ZIP es un archivo en JSON de toda la cuenta, no un archivo con nombre para el chat que estabas leyendo. Úsalo como copia de seguridad y descomprímelo tú si necesitas sacar una conversación entre miles.

Copiar y pegar es un tercer método sin extensión. Seleccionas el texto y lo pegas en Docs o en una app de notas. La sangría del código suele perderse. Las tablas se convierten en líneas corridas. Un hilo de varios turnos queda como un muro sin estructura. Vale para una respuesta corta. No sirve para una revisión de código que querrás buscar más adelante. El botón «Copy» de la extensión, en cambio, lleva Markdown limpio al portapapeles.

¿Cómo descargo el historial de chats de Claude en bloque?

Para descargar el historial de chats de Claude en muchos archivos, no repitas el botón naranja pestaña por pestaña. Abre «View and Download All Conversations» (ver y descargar todas las conversaciones) desde la ventana de la extensión, filtra la tabla y haz clic en «Export All». «Export All» pide iniciar sesión con Google. En el plan gratuito, cada chat del ZIP gasta una de las 3 cuotas diarias compartidas con el PDF. Pro elimina el límite.

El Dashboard muestra las conversaciones de la cuenta de claude.ai con la que has iniciado sesión. Busca por nombre. Filtra por All conversations, New, Updated o Previously exported (todas, nuevas, actualizadas o ya exportadas). Cambia entre las pestañas Chat y Cowork, y busca por proyecto si agrupas chats así en claude.ai. Selecciona un subconjunto cuando no quieras todos los borradores antiguos en la carpeta.

La exportación masiva crea un ZIP con un archivo por chat, en el formato que elijas en el selector «Chat format»: cualquiera de los siete, PDF incluido. Usa el mismo analizador que la exportación de un solo chat. Las casillas «Chats», «Thinking», «Metadata», «Tools» y «Sources» deciden qué se incluye (chats, razonamiento, metadatos, herramientas, fuentes), además de una disposición de artefactos. «Export All» no es un proceso de segunda: es el mismo analizador aplicado a muchas conversaciones de una sola pasada. Detalles y capturas: exportación masiva con Export All.

Export data de Anthropic sigue siendo la copia de seguridad de la cuenta. Un ZIP, un correo, JSON para todo, incluidos chats que habías olvidado. «Export All» hace lo contrario: tú eliges los hilos, tú eliges el formato y el ZIP llega al momento. Usa los dos si quieres un archivo completo para fines legales y una carpeta de notas legibles.

La cuota es diaria y compartida. En el plan gratuito, las exportaciones en PDF y los chats de una exportación masiva comparten 3 al día, que se reinician a medianoche UTC. Si seleccionas 40 conversaciones, se bloquea todo el lote, no se recorta. Elige menos o pásate a Pro por 3,99 US$ al mes o 26,99 US$ al año.

El Dashboard también recuerda lo que ya exportaste, así que en una visita posterior puedes filtrar solo por New o Updated. Así, la costumbre de descargar cada semana el historial de chats de Claude se mantiene incremental en vez de duplicar el Markdown del mes pasado.

¿Cómo descargar un chat de Claude en Markdown o JSON?

Para descargar un chat de Claude en Markdown o JSON, abre el botón naranja, elige el formato y pulsa «Export». Markdown es el archivo de notas. JSON es el árbol de mensajes para scripts. El texto plano no lleva marcado. CSV es una fila por mensaje. PDF es un documento paginado. PNG es una imagen.

Markdown conserva los encabezados, el código delimitado con etiquetas de lenguaje y las tablas. Es la opción habitual para Obsidian, GitHub o una wiki. JSON conserva el árbol que ya construyó el analizador, incluidos los artefactos y el razonamiento cuando esas opciones están activadas. No tiene la misma estructura que el ZIP de la cuenta de Anthropic. Notas sobre cada formato: todos los formatos.

El texto plano es la opción correcta cuando el destino elimina el marcado de todos modos: un campo de un sistema de tickets, el cuerpo de un correo o un índice de búsqueda que quiere texto sin formato. XML es la opción de nicho para intercambio de datos. CSV se abre en Excel, Google Sheets o Numbers. PNG sirve para una diapositiva o una captura del hilo en un informe de error, no para una revisión de diseño de 40 turnos en la que vas a buscar con grep.

¿Guardar una conversación de Claude, imprimirla o pedir el ZIP?

Guardar, descargar y exportar son la misma tarea en claude.ai: sacar el hilo de la página. Para guardar una conversación de Claude como archivo útil, PDF incluido, la respuesta es la extensión. Imprimir es una captura. Export data de Anthropic es un ZIP de la cuenta.

Los equipos suelen mezclar los verbos. Quien investiga dice guardar. Quien programa dice exportar. Quien dirige dice descargar. En este sitio, los tres verbos llevan al mismo botón naranja cuando trabajas en claude.ai con Chrome. La guía vecina cómo exportar un chat de Claude explica con más detalle el ZIP oficial y las estructuras JSON.

Imprimir sigue teniendo su sitio: un adjunto puntual que debe verse exactamente como la pantalla de claude.ai. Export data oficial también: dejar una empresa, una retención legal o una copia de seguridad extra por si acaso. Ninguno sustituye a un archivo Markdown que vas a editar la semana que viene.

Claude Desktop es otra ventana. La extensión de Chrome no se inyecta en la app de escritorio. Si el mismo chat existe en claude.ai, ábrelo allí y descárgalo. Si solo está en Desktop, copia y pega o espera al ZIP de la cuenta. Pasos: exportar un chat de Claude Desktop.

Paddle procesa los pagos de Pro. No vemos los números de tarjeta. El inicio de sesión con Google, que solo se usa para PDF, exportación masiva y Pro, no nos da acceso a la conversación. El worker de Cloudflare que comprueba la cuota y el estado Pro recibe tu correo de Google, no el texto de los mensajes. Las demás exportaciones de un solo chat no envían nada. Ese límite resume toda la privacidad: la facturación en el servidor, el chat en tu disco.

¿Por qué no aparece el botón para descargar el chat de Claude?

El botón para descargar el chat de Claude no aparece cuando no estás en la URL de una conversación, cuando no recargaste la pestaña tras instalar o cuando la extensión está desactivada. Fija el icono, recarga y comprueba que estás en Chrome de escritorio en claude.ai, no en Desktop, en un teléfono ni en una terminal de Claude Code.

Tras la instalación, Chrome no siempre inyecta el content script en las pestañas que ya estaban abiertas. Cierra la pestaña de claude.ai o recárgala por completo. Si usas varios perfiles, la extensión debe estar instalada en el perfil que tiene la sesión de Anthropic iniciada.

Los espacios de trabajo Team y Enterprise funcionan si puedes abrir la conversación en el navegador. La extensión lee la página, no el nivel del plan. Si tu organización bloquea las extensiones de Chrome, TI tiene que permitir esta; desde el sitio web no podemos saltarnos esa política.

Solicitud de inicio de sesión: solo es esperable para PDF y «Export All». Markdown, texto, JSON, XML, CSV y PNG se exportan sin cuenta. La primera exportación en PDF o masiva pide Google. Cancelar esa ventana parece una descarga fallida. Completa el inicio de sesión y vuelve a hacer clic en «Export». El plan gratuito no pide tarjeta de crédito.

Archivo incompleto: la conversación no había terminado de generarse o los turnos antiguos seguían virtualizados fuera de la pantalla. Espera a que el asistente termine. Desplázate hacia el principio de un hilo largo para que claude.ai cargue esos nodos y vuelve a exportar. Repetir una exportación en Markdown o JSON no cuesta nada. Repetir un PDF gasta otra de las 3 cuotas diarias del plan gratuito: otra razón para comprobar antes que el hilo esté cargado del todo.

Tipo de archivo equivocado: seguía seleccionado el último formato usado. Cuenta equivocada: iniciaste sesión en Google con una dirección distinta de la que tiene Pro. La restauración de Pro va ligada a ese correo de Google, no al acceso de Anthropic ni al nombre del perfil de Chrome.

Los navegadores móviles no ejecutan esta extensión. No hay app para iOS ni Android. Safari en un teléfono puede imprimir, pero no puede mostrar el botón naranja. Para un archivo reutilizable, abre el mismo chat en Chrome de escritorio.

¿Sirve para descargar un chat de Claude Code?

Solo de Claude Code en la web. Las sesiones de claude.ai/code se abren en Chrome, así que Download Claude conversations las exporta como cualquier chat. Una sesión local de Claude Code en la terminal es otra cosa. Para exportarla se usa /export o el archivo JSONL de ~/.claude/projects. Superficies distintas, archivos distintos.

Dentro de una sesión activa de Claude Code, escribe /export. La CLI de Anthropic abre un menú para copiar la transcripción o guardarla en un archivo de texto plano. Pasa un nombre de archivo para saltarte el menú. Esa transcripción es texto formateado para que lo lea una persona, no el Markdown, JSON o PDF de esta extensión. Rutas completas: exportación de Claude Code.

El JSONL del disco es el registro interno. Su esquema puede cambiar entre versiones de Claude Code. La propia documentación de Anthropic recomienda usar /export o las interfaces para scripts en lugar de analizar el JSONL. No envolvemos esa CLI. No leemos ~/.claude.

Si mantienes un hilo paralelo en claude.ai para el mismo trabajo, descarga ese chat del navegador con el botón naranja. El registro de la terminal y el chat web no son automáticamente el mismo documento. Trátalos como dos registros, salvo que hayas pegado uno en el otro.
