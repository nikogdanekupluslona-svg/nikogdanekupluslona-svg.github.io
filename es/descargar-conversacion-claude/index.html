¿En qué formato descargar la conversación?

Para elegir el formato de la conversación, abre el botón naranja, elige PDF, Markdown, JSON, texto, XML, CSV o PNG y pulsa «Export». Markdown es el archivo de notas. JSON es el árbol de mensajes para scripts. El texto plano no lleva marcado. XML sirve para intercambio de datos. CSV es una fila por mensaje. PDF es un documento paginado. PNG es una imagen.

Markdown conserva los encabezados, el código delimitado con etiquetas de lenguaje y las tablas. Es la opción habitual para Obsidian, GitHub o una wiki. JSON conserva el árbol que ya construyó el analizador, incluidos los artefactos y el razonamiento cuando esas opciones están activadas. No tiene la misma estructura que el ZIP de la cuenta de Anthropic. Notas sobre cada formato: todos los formatos.

El texto plano es la opción correcta cuando el destino elimina el marcado de todos modos: un campo de un sistema de tickets, el cuerpo de un correo o un índice de búsqueda que quiere texto sin formato. XML es la opción de nicho para intercambio de datos. CSV se abre en Excel, Google Sheets o Numbers. PNG sirve para una diapositiva o una captura del hilo en un informe de error, no para una revisión de diseño de 40 turnos en la que vas a buscar con grep.

Instala Download Claude conversations, abre el hilo en claude.ai, haz clic en el botón naranja a la derecha del cuadro de mensaje, elige PDF, Markdown, JSON, texto, XML, CSV o PNG y pulsa «Export». Chrome guarda un archivo local. Ese archivo es una conversación. No necesitas cuenta, salvo para el PDF, que pide iniciar sesión con Google.

¿«Descargar conversación de Claude» es la ficha de la Store?

El título en la Store es Download Claude conversations, en plural, porque «Export All» crea muchos archivos. Búsquedas como «descargar conversación claude», «descargar claude chat» o, en inglés, «download claude conversation» apuntan a esa misma ficha. Una exportación con el botón naranja sigue siendo una conversación, un archivo.

¿Puedo descargar una conversación de Claude sin extensión?

Sí. Imprime la página de claude.ai (Ctrl/Cmd+P → Guardar como PDF) para una captura visual, o usa Settings → Privacy → Export data para un ZIP en JSON de la cuenta que llega con retraso. Copiar y pegar sirve para una respuesta corta. Ninguno de esos métodos crea un archivo Markdown estructurado por conversación como hace la extensión de Chrome.

¿Un archivo equivale a una conversación descargada?

Sí. El botón naranja crea un archivo del hilo abierto en claude.ai. «Export All» crea un ZIP con un archivo por cada fila seleccionada. El ZIP de Export data de Anthropic tiene la forma contraria: un archivo de toda la cuenta, enviado más tarde por correo, no un archivo con nombre para la conversación que estabas leyendo.

¿Puedo descargar una conversación de Claude en PDF?

Sí. Elige PDF en el panel del botón naranja y pulsa «Export». La versión 1.16.2 genera el PDF en el navegador sin diálogo de impresión; tú eliges el tamaño de página, los márgenes, el modo claro u oscuro, la fuente, la numeración de páginas y un índice. El PDF requiere iniciar sesión con Google y es gratis hasta 3 al día; Pro no tiene límite. Guía: chat de Claude en PDF.

¿Hace falta iniciar sesión con Google para descargar una conversación de Claude?

Solo para PDF y «Export All». Markdown, texto plano, JSON, XML, CSV y PNG no necesitan cuenta. Para PDF y exportación masiva, Google verifica qué cuenta elegiste para que podamos aplicar el límite de 3 al día y restaurar Pro tras reinstalar. El contenido de las conversaciones no se envía con ese inicio de sesión. Guardamos el correo verificado solo para la cuota y el estado Pro.

¿Funciona la descarga de conversaciones en Desktop?

No. Download Claude conversations solo se inyecta en claude.ai en Chrome de escritorio. Claude Desktop nunca muestra el botón naranja. Abre el mismo hilo en claude.ai si se sincroniza, o copia y pega / usa Export data oficial. No hay app para iOS ni Android.

¿Cuántos archivos gratis puedo descargar?

Ilimitados en Markdown, texto plano, JSON, XML, CSV y PNG, sin cuenta. El PDF y el ZIP masivo comparten 3 al día en el plan gratuito, con inicio de sesión de Google; cada conversación de un ZIP masivo cuenta como una, y el día se reinicia a medianoche UTC. Pro cuesta 3,99 US$ al mes o 26,99 US$ al año y elimina el límite. Paddle procesa el pago.

¿Sirve para descargar conversaciones de Claude Code?

Solo en la web. Las sesiones de Claude Code en claude.ai/code se exportan como cualquier conversación de claude.ai. Las sesiones locales de la terminal no: usa /export o copia el JSONL de ~/.claude/projects (Windows: %USERPROFILE%\.claude\projects). Esta extensión de Chrome solo funciona en claude.ai. Guía: exportación de Claude Code.

¿En qué formatos se puede descargar la conversación?

En siete: PDF, Markdown, JSON, texto plano, XML, CSV y PNG, en la extensión 1.16.2. El PDF se genera en el navegador sin diálogo de impresión. CSV es una fila por mensaje. PNG es una imagen del hilo. Página de formatos: formatos.
