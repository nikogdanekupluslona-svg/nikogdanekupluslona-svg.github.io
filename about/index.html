About

Download Claude conversations is an independent Chrome extension (site name: Chat Downloader). Search engines and users also call it Claude Chat Downloader and Claude Conversation Downloader. It is not made by, affiliated with, or endorsed by Anthropic, PBC — Claude is Anthropic's trademark, and we built this to fill a gap in claude.ai itself: there's no built-in way to download a single conversation as a file.

The extension adds an export button to claude.ai and a browse page for bulk exports, writing Markdown, JSON, plain text, XML, or PNG files locally in your browser. Every account gets 3 free exports; Pro removes the limit. Details on how it works. It does not export Claude Code terminal sessions.
