About

Download Claude conversations is an independent Chrome extension (site name: Chat Downloader). Search engines and users also call it Claude Chat Downloader and Claude Conversation Downloader. It is not made by, affiliated with, or endorsed by Anthropic, PBC — Claude is Anthropic's trademark, and we built this to fill a gap in claude.ai itself: there's no built-in way to download a single conversation as a file.

The extension adds an export button to claude.ai and a Dashboard for bulk exports, writing PDF, Markdown, plain text, JSON, XML, CSV, or PNG files locally in your browser. Single-chat Markdown, text, JSON, XML, CSV, and PNG exports are unlimited and need no account. PDF and bulk ZIP ask for Google sign-in and are free up to 3 a day; Pro ($3.99/mo or $26.99/yr) removes that cap. It works with regular chats, Projects, Cowork sessions, and Claude Code on the web (claude.ai/code). Details on how it works. It does not export Claude Code terminal sessions.
