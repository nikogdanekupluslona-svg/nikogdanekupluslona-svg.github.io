Jak funguje export konverzace Claude v Chromu?

Otevřete adresu konverzace na claude.ai v Chromu, klikněte na oranžové tlačítko vpravo od pole pro zprávu, zvolte PDF, Markdown, JSON, text, XML, CSV nebo PNG a klikněte na „Export“. Download Claude conversations zapíše soubor s konverzací lokálně. Po instalaci claude.ai znovu načtěte. Samotné claude.ai nemá volbu pro export jednotlivého vlákna.

  1. Nainstalujte Download Claude conversations z Chrome Web Store (verze 1.16.2).
  2. Znovu načtěte kartu claude.ai, aby se obsahový skript mohl vložit do adresy konverzace.
  3. Otevřete skutečnou konverzaci, ne prázdnou úvodní stránku claude.ai se zadávacím polem.
  4. Klikněte na kulaté oranžové tlačítko pro stažení vpravo od pole pro zprávu.
  5. Nastavte Messages na „All / Human / Assistant“ (vše / uživatel / asistent), podle potřeby zaškrtněte „Thinking“ (uvažování), zvolte PDF, Markdown, JSON, prostý text, XML, CSV nebo PNG a klikněte na „Export“.

Mohu exportovat relaci Claude z Claude Desktop?

S tímto rozšířením pro Chrome ne. Pokud se konverzace synchronizuje, otevřete ji na claude.ai, nebo ji zkopírujte či použijte oficiální Export data. Claude Desktop oranžové tlačítko nikdy nezobrazí.

Kolik souborů s konverzacemi Claude mohu exportovat zdarma?

Neomezeně v Markdownu, textu, JSON, XML, CSV a PNG, bez účtu. PDF a hromadný „Export All“ sdílejí v bezplatném tarifu 3 exporty denně s přihlášením přes Google; každá konverzace v hromadném ZIPu se počítá jako jedna. Počet se obnovuje o půlnoci UTC. Pro limit ruší a na novém počítači ho obnovíte přihlášením přes Google.

Kde je oranžové tlačítko pro export konverzace Claude?

Vpravo od pole pro zprávu na adrese konverzace na claude.ai, jakmile nainstalujete Download Claude conversations a stránku znovu načtete. Na prázdné úvodní stránce se zadávacím polem ani v Claude Desktop se nezobrazí.

Nahrává export konverzace Claude moje chaty?

Ne. Každý formát včetně PDF se sestaví v prohlížeči a předá rozhraní Chromu pro stahování. Exporty do Markdownu, textu, JSON, XML, CSV a PNG nám nic neposílají. Po přihlášení kvůli PDF, hromadnému exportu nebo Pro vidí náš server stav limitu nebo předplatného a váš e-mail Google, nikdy obsah konverzací.

Do jakých formátů export konverzace Claude zapisuje?

Do sedmi: PDF, Markdown, prostý text, JSON, XML, CSV a PNG — stejných sedm pro jednu konverzaci i pro „Export All“. Export do Wordu, Notionu ani Google Docs verze 1.16.2 nenabízí.
