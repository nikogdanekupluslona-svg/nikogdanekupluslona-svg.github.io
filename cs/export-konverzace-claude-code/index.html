Export konverzace Claude Code, nebo claude.ai: zvolte správnou cestu

Export konverzace Claude Code (anglicky „claude code export“) je úkol pro terminál. V relaci zadejte /export, nebo zkopírujte JSONL z ~/.claude/projects. Stažení konverzace Claude Code z terminálu neobstará oranžové tlačítko z tohoto webu. Download Claude conversations ukládá chaty, které otevřete na claude.ai v Chromu — včetně relací Claude Code on the web na claude.ai/code. Místní relace v terminálu a Desktop jsou samostatná věc.

Co je export konverzace Claude Code v terminálu?

Export konverzace Claude Code je příkaz /export v interaktivní relaci CLI. Dokumentace Anthropicu popisuje nabídku, která aktuální konverzaci zkopíruje nebo uloží jako soubor s prostým textem, přičemž zprávy a výstupy nástrojů se vykreslí jako čitelný text. Když zadáte název souboru, nabídka se přeskočí a soubor se rovnou zapíše.

Nejde o Markdown z claude.ai, o JSON z tohoto rozšíření pro Chrome ani o PDF. Je to vykreslený přepis určený ke čtení člověkem. Anthropic uvádí, že log JSONL na disku je jiný, interní formát určený pro produkt, ne jako vaše veřejné API.

/export

Chcete-li přeskočit dotaz a zapsat pojmenovaný soubor do aktuálního pracovního adresáře:

/export my-session

Zdrojem pravdy pro přepínače a názvy souborů je dokumentace relací od Anthropicu; mezi verzemi Claude Code se mění. Komunitní blogy berte jako druhotný zdroj. Pokud texty v dialogu /export neodpovídají tomu, co vidíte, máte jiné sestavení CLI — řiďte se nápovědou v produktu, ne snímkem obrazovky z roku 2025.

Pro skripty Anthropic odkazuje na jiná rozhraní: claude -p s --output-format json nebo stream-json, obnovení podle ID relace, hooky, které dostanou transcript_path, nebo Agent SDK. To jsou vývojářská rozhraní Claude Code. Nejsou to funkce rozšíření pro Chrome z tohoto webu.

Čitelné, nebo strukturované. /export je přepis pro člověka. JSONL ve složce projektů je log. JSON z rozšíření pro Chrome je třetí struktura, vytvořená jen ze stránky na claude.ai. Nepište jeden parser pro všechny tři.

Jak stáhnout konverzaci Claude Code z disku?

Jak stáhnout konverzaci Claude Code z disku: zkopírujte soubor JSONL dané relace z adresáře projektů, nebo spusťte /export pro čitelný přepis. Výchozí cesta v macOS a Linuxu je pod ~/.claude/projects/. Ve Windows je to %USERPROFILE%\.claude\projects. Názvy souborů jsou ID relací.

Název složky projektu je pracovní adresář, v němž jsou nealfanumerické znaky nahrazené pomlčkami. Velmi dlouhé převedené názvy Anthropic zkracuje a přidává k nim hash, aby adresář zůstal v limitech souborového systému. Pokud složku nemůžete najít, spustili jste Claude Code z jiného pracovního adresáře, než si myslíte.

Každý řádek JSONL je objekt JSON pro zprávu, použití nástroje nebo metadata. Anthropic uvádí, že formát těchto záznamů je interní a mezi verzemi se mění. Skripty, které tyto soubory zpracovávají, se mohou s novou verzí Claude Code rozbít. Když potřebujete něco stabilního, dejte přednost /export nebo zdokumentovaným skriptovacím rozhraním.

Úložiště se může přesunout. CLAUDE_CONFIG_DIR přesune konfigurační strom mimo ~/.claude. CLAUDE_CODE_PROJECT_DIR_NAME pojmenuje adresář projektu při použití s tímto konfiguračním adresářem (podle Anthropicu Claude Code v2.1.234 nebo novější). cleanupPeriodDays v settings.json mění výchozí dobu uchování. Žádné z těchto nastavení není funkcí Download Claude conversations.

Stažení souborů konverzací Claude Code kvůli záloze tedy znamená: zkopírovat složku, nebo pravidelně exportovat přepisy přes /export. Tento web nepřidá tlačítko pro import JSONL. Váš domovský adresář nečteme.

Funguje export z Claude Code s tímto rozšířením?

Pro relace v terminálu ne. Download Claude conversations nečte místní relace Claude Code. Rozšíření pro Chrome se vkládá do claude.ai. Nevidí terminál, nemůže spustit /export a neotevře JSONL. Výjimkou je Claude Code on the web na claude.ai/code: je to stránka claude.ai, takže se exportuje jako jakýkoli chat. Pokud jste hledali, jak stáhnout konverzaci Claude Code z CLI, držte se postupů pro CLI na této stránce.

Lidé sem přicházejí, protože Google spojuje slova „Claude“ a „export“. Rozšíření z Chrome Web Store je ale stále jen pro claude.ai. Jeho instalace nepřidá oranžové tlačítko do iTerm, Ghostty, terminálu ve VS Code ani do desktopového obalu Claude Code.

Pokud ke stejné programátorské práci vedete i paralelní vlákno na claude.ai, tento chat v prohlížeči můžete rozšířením uložit. Oba záznamy se nesloučí. Volání nástrojů, která proběhla jen v CLI, se ve webovém exportu neobjeví, pokud jste je tam nevložili.

Každý týden dostáváme stejný dotaz na podporu: někdo nainstaloval rozšíření pro Chrome a čekal, že se objeví /export. Zpracováváme jen claude.ai. Claude Code už /export i JSONL obsahuje. Obal pro CLI by byl jiný produkt a ten jsme nevydali.

Mohu exportovat relace Claude Code on the web?

Ano. Claude Code on the web běží na claude.ai/code, takže Download Claude conversations tyto relace exportuje jako jakýkoli chat na claude.ai. Otevřete relaci v Chromu, klikněte na oranžové tlačítko, zvolte formát a klikněte na „Export“ (Exportovat). Je to jediné rozhraní Claude Code, které rozšíření pokrývá.

Formáty jsou stejných sedm jako u každého chatu: PDF, Markdown, prostý text, JSON, XML, CSV a PNG. Markdown, text, JSON, XML, CSV a PNG jsou neomezené a nevyžadují účet. PDF vyžaduje přihlášení přes Google a v bezplatném tarifu sdílí 3 exporty denně s hromadným ZIPem, pokud nemáte Pro. Bloky kódu si zachovají označení jazyka. Rozšířené uvažování je zaškrtávací políčko „Thinking“ (uvažování) v panelu; kroky nástrojů / MCP a zdroje z webového vyhledávání se zapínají v nastavení.

Webový export obsahuje to, co claude.ai/code zobrazuje v prohlížeči. Není to log JSONL z místního běhu CLI a nedosáhne na relace, které běžely jen ve vašem terminálu. Podle Anthropicu si Claude Code on the web vede vlastní historii relací, oddělenou od stromu ~/.claude/projects v CLI. Pro relaci v terminálu zůstává cestou /export.

Kde Claude Code ukládá historii konverzací?

Claude Code ukládá historii konverzací jako přepisy JSONL ve složce projektů v konfiguračním adresáři. Výchozí cesta v macOS a Linuxu: ~/.claude/projects/<encoded-cwd>/<session-id>.jsonl. Windows používají %USERPROFILE%\.claude\projects. Anthropic může toto uspořádání změnit; pokud cesta na disku chybí, podívejte se do aktuální dokumentace relací.

Obnovení je jiné sloveso než export. claude --continue a claude --resume načtou relaci znovu, abyste mohli pokračovat v práci. /export zapíše kopii, kterou můžete nechat v gitu nebo poslat e-mailem. Jedno obnovuje kontext. Druhé vám dá záznam s sebou. Stránka Anthropicu o relacích popisuje režim oprávnění při obnovení, compact/summary a chování výběru — nic z toho se tohoto rozšíření netýká.

Desktopová aplikace, Claude Code on the web i rozšíření pro VS Code si podle Anthropicu vedou každé vlastní historii relací. Cesty v tomto průvodci platí pro CLI. Webové relace zůstávají na claude.ai/code, kde je rozšíření umí exportovat. Nepředpokládejte, že přepis z Cowork v Desktopu leží ve stejném stromu JSONL, který používáte z terminálu.

Nepovažujte JSONL za veřejné schéma. Anthropic uvádí, že formát řádků se mění. Pokud ho přesto zpracováváte, zafixujte verzi Claude Code a počítejte s tím, že se něco rozbije. /export je stabilní způsob, jak získat konverzaci Claude Code v čitelné podobě.

Proměnné prostředí, jako je CLAUDE_CODE_SKIP_PROMPT_HISTORY, mohou zápis přepisů potlačit. Pokud je složka projektů prázdná, zkontrolujte, zda jste neukládání nevypnuli, zda CLAUDE_CONFIG_DIR nesměřuje jinam, nebo zda jste v tom adresáři vůbec spustili interaktivní relaci.

Jak místo toho stáhnout chat Claude na claude.ai?

Jak stáhnout chat Claude na claude.ai: nainstalujte Download Claude conversations, otevřete vlákno v Chromu, klikněte na oranžové tlačítko a zvolte PDF, Markdown, prostý text, JSON, XML, CSV nebo PNG. To je produkt pro prohlížeč a pokrývá i relace na claude.ai/code. Není to export z Claude Code v terminálu. Postup krok za krokem: jak stáhnout chat Claude.

Celou historii claude.ai jako samostatné soubory získáte přes „Export All“ (Exportovat vše) na Dashboardu, ne přes /export. V bezplatném tarifu se každý chat v ZIPu počítá do 3 exportů denně (sdílených s PDF, s obnovou o půlnoci UTC); Pro limit ruší. Průvodce: hromadný export přes Export All. Formáty: formáty.

Pro Markdown, text, JSON, XML, CSV nebo PNG z jednoho chatu nepotřebujete účet — tyto exporty jsou neomezené. Přihlášení přes Google se objeví jen u PDF, hromadného ZIPu a Pro, abychom mohli počítat denní limit a obnovit Pro. Soubory se sestavují lokálně, včetně PDF. Paddle účtuje Pro za 3,99 USD měsíčně nebo 26,99 USD ročně. Nic z toho se netýká /export v terminálu.

Pokud práce začala v Claude Code a shrnutí jste vložili do claude.ai, stáhněte webové vlákno jako poznámky a /export si nechte pro skutečný log z CLI. Dva soubory jsou lepší než jeden zmatený.

Export z Claude Code, nebo oficiální Export data od Anthropicu?

Export z Claude Code (/export nebo JSONL) je jedna relace v terminálu. Oficiální Export data je Settings → Privacy → Export data na claude.ai (pokud máte claude.ai v češtině, mohou být popisky přeložené): opožděný ZIP s JSON účtu u Anthropicu. Nejde o stejný archiv. ZIP /export nenahradí.

Zda se daná relace Claude Code objeví v ZIPu účtu, závisí na tom, jak Anthropic daný produkt ukládá, ne na tomto rozšíření. Pokud aktuální dokumentace Anthropicu k ochraně soukromí neříká jinak, berte ZIP jako zálohu webového účtu. Relace z CLI do toho ZIPu nepřidáváme.

Jak exportovat chat Claude z webu, včetně srovnání ZIPu a rozšíření, popisuje stránka jak exportovat chat Claude. Export do PDF z rozšíření se na rozhraní terminálu také nevztahuje. Stránku stáhnout chat Claude jako PDF použijte jen tehdy, když je konverzace na claude.ai, včetně claude.ai/code.

Export z Claude Code, z Desktopu, nebo z claude.ai?

Claude Code, Claude Desktop a claude.ai jsou tři různá rozhraní. Export z Claude Code používá /export a JSONL. Desktop je aplikace bez oranžového tlačítka tohoto rozšíření. claude.ai v Chromu je jediné místo, kde Download Claude conversations běží — včetně Claude Code on the web na claude.ai/code. Právě záměna těchto názvů je důvod, proč exporty potichu selhávají.

Claude Desktop: pokud se chat synchronizoval do stejného účtu u Anthropicu, otevřete ho na claude.ai a exportujte tam. Pokud existuje jen v okně Desktopu, zkopírujte ho, nebo počkejte na oficiální Export data. Průvodce: export chatu z Claude Desktop.

Panel Claude Code ve VS Code má blíž k CLI než ke claude.ai. Nečekejte, že se náš obsahový skript vloží do tohoto webview. Použijte /export z relace, která zprávy skutečně obsahuje.

Nezávislé rozšíření pro Chrome, nijak nespojené se společností Anthropic, PBC. Claude je ochranná známka společnosti Anthropic. Dodržujte jejich podmínky služby. Nemůžeme poskytovat právní rady ke kopírování výstupů nástrojů, které obsahují proprietární kód; to je věc mezi vámi, vaším zaměstnavatelem a Anthropicem.

Časté dotazy: export z Claude Code

Jak exportovat konverzaci z Claude Code?

V terminálu Claude Code zadejte /export (volitelně s názvem souboru) a uložte vykreslený přepis, nebo zkopírujte soubor JSONL z ~/.claude/projects v macOS/Linuxu či z %USERPROFILE%\.claude\projects ve Windows. Aktuální podobu dialogu popisuje dokumentace relací od Anthropicu.

Stahuje toto rozšíření pro Chrome chaty z Claude Code?

Z terminálu ne. Download Claude conversations funguje jen na claude.ai v Chromu. Neumí číst místní relace v terminálu, přepisy JSONL ani příkaz /export. Relace Claude Code on the web na claude.ai/code se exportují jako jakýkoli chat.

Mohu exportovat Claude Code on the web (claude.ai/code)?

Ano. Otevřete relaci na claude.ai/code v Chromu a použijte oranžové tlačítko. Funguje PDF, Markdown, prostý text, JSON, XML, CSV i PNG. Šest formátů kromě PDF je neomezených a bez účtu; PDF vyžaduje přihlášení přes Google a počítá se do 3 bezplatných exportů denně.

Kde Claude Code ukládá historii konverzací?

Přepisy relací jsou soubory JSONL pod ~/.claude/projects/<encoded-working-directory>/, pojmenované podle ID relace. Přesné uspořádání se může změnit. Když chcete místo zpracování JSONL čitelný soubor, použijte /export. CLAUDE_CONFIG_DIR může strom přesunout.

Jak stáhnout konverzaci Claude Code jako Markdown?

/export v Claude Code je přepis v prostém textu, ne Markdown z tohoto rozšíření. Pokud potřebujete právě Markdown, exportujte relaci z claude.ai/code nebo kopii práce na claude.ai pomocí Download Claude conversations, případně text z /export převeďte sami. JSONL do Markdownu nepřevádíme.

Jak místo toho stáhnout konverzaci z claude.ai?

Nainstalujte bezplatné rozšíření pro Chrome, otevřete chat na claude.ai a použijte oranžové tlačítko — nebo pro historii „Export All“. Viz jak stáhnout chat Claude. Markdown, text, JSON, XML, CSV a PNG jsou neomezené a bez účtu; PDF a hromadný ZIP jsou zdarma 3× denně s přihlášením přes Google; Pro stojí 3,99 USD měsíčně nebo 26,99 USD ročně.

Je /export totéž co oficiální Export data?

Ne. /export se týká aktuální relace Claude Code. Settings → Privacy → Export data pošle e-mailem ZIP s JSON účtu u Anthropicu. Jiná rozhraní produktu, jiné soubory, jiné čekání.

Mohu JSONL z Claude Code zpracovat pomocí jq?

Můžete, s výhradou, kterou Anthropic zveřejňuje: schéma řádků je interní a může se změnit. Když potřebujete pevný kontrakt, dejte přednost /export nebo claude -p --output-format json. Pokud JSONL přesto zpracováváte, zafixujte verzi CLI.

Funguje export z Claude Code ve Windows?

Ano. /export je příkaz CLI. Přepisy na disku jsou pod %USERPROFILE%\.claude\projects, pokud nenastavíte CLAUDE_CONFIG_DIR. Toto rozšíření pro Chrome v tomto terminálu stále neběží.

Je Claude Code totéž co Claude Desktop?

Ne. Claude Code je programátorský agent v terminálu. Claude Desktop je chatovací aplikace. claude.ai je web. Toto rozšíření funguje jen na webu, včetně claude.ai/code. Poznámky k exportu z Desktopu: Claude Desktop.

Bude toto rozšíření někdy obalovat /export?

Ve verzi 1.16.2 ne. Rozsah produktu je claude.ai včetně Claude Code on the web: sedm formátů, místní soubory, přihlášení přes Google jen pro PDF, hromadný export a Pro. Pokud se rozsah změní, tato stránka to uvede. Do té doby používejte pro export z Claude Code v terminálu CLI od Anthropicu.

Obsahuje /export výstupy nástrojů?

Anthropic popisuje /export jako zprávy a výstupy nástrojů vykreslené jako čitelný text. Je to jejich přepis, ne náš parser. Přesný aktuální obsah zjistíte, když /export spustíte ve svém sestavení a soubor si přečtete — dokumentace může za vydáním zaostávat.

Mohu relace Claude Code exportovat hromadně?

Místní relace z CLI ne. „Export All“ na Dashboardu je jen pro claude.ai. Pro mnoho relací z CLI zkopírujte složku projektů nebo spusťte /export pro každou relaci zvlášť. Hromadný export oranžovým tlačítkem pro JSONL neexistuje.
