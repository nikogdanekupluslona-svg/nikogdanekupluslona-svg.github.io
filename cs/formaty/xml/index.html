Jak exportovat chat Claude do XML?

Otevřete konverzaci na claude.ai v Chromu, klikněte na oranžové tlačítko vedle pole pro zprávu, zvolte XML a klikněte na „Export“. Download Claude conversations zapíše soubor lokálně. Přesně tak funguje export do XML ve verzi 1.16.2. Samotné claude.ai v září 2026 nemá vestavěnou volbu pro uložení do XML.

  1. Nainstalujte Download Claude conversations z Chrome Web Store.
  2. Znovu načtěte claude.ai a otevřete skutečnou adresu konverzace, ne prázdnou úvodní stránku se zadávacím polem.
  3. Klikněte na oranžové tlačítko pro stažení vpravo od pole pro zprávu.
  4. Vyberte XML. Naposledy použitý formát si rozšíření pamatuje. Pomocí „Select“ (Vybrat) označíte jen zprávy, které chcete.
  5. Klikněte na „Export“. Chrome stáhne XML přes rozhraní prohlížeče pro stahování. Nebo klikněte na „Copy“ (Kopírovat) a XML se vloží do schránky.

K exportu do XML se nemusíte přihlašovat. Exporty jednotlivých chatů do XML jsou neomezené, anonymní a na naše servery nic neposílají. Přihlášení přes Google se objeví jen u PDF a hromadného „Export All“ (Exportovat vše). Podrobnosti: jak to funguje.

Pokud oranžové tlačítko chybí, nejste na adrese konverzace, kartu je potřeba znovu načíst, nebo je rozšíření skryté v nabídce rozšíření (ikona dílku skládačky) v Chromu. Připněte Download Claude conversations a obnovte claude.ai. Export do XML se nikdy neobjeví v Claude Desktop ani v terminálu Claude Code.

Jeden soubor, nebo mnoho. Oranžové tlačítko exportuje otevřenou konverzaci do XML. Pro mnoho souborů XML otevřete „View and Download All Conversations“ (Zobrazit a stáhnout všechny konverzace) a spusťte „Export All“ se zvoleným XML: jeden ZIP, 3 chaty denně v bezplatném tarifu — viz hromadný export přes Export All.

Kdy zvolit XML?

XML zvolte, když přijímající systém, datový tok nebo starší nástroj vyžaduje pro strukturovanou výměnu dat XML. Většina vývojářů by měla zvolit raději JSON. Markdown je na poznámky pro lidi. CSV je pro tabulky. PNG je obrázek. XML je v rozbalovacím seznamu proto, že některé nástroje stále načítají XML a JSON nepřijmou.

Neexportujte chat Claude do XML jako „oficiálnější“ JSON. Download Claude conversations v obou případech zpracuje konverzaci stejně. Rozdíl je ve tvaru souboru, žádná další pole se zázračně neobjeví. Pokud nic, co používáte, XML nevyžaduje, tento formát přeskočte a použijte JSON.

XML nabízíme, protože ho některé datové toky stále vyžadují, ne proto, že bychom si mysleli, že u každého exportu z claude.ai překoná JSON. Zpracování je stejné: zprávy, odesílatel, volitelné uvažování a artefakty. Verze 1.16.2 ponechává XML jako jeden ze sedmi formátů, zdarma a bez účtu, ne jako placený doplněk.

Co export chatu Claude do XML zachová?

Při exportu do XML Download Claude conversations zapíše strukturu konverzace — zprávy, odesílatele a dostupná metadata — jako značkování XML. Bloky uvažování, zdroje z webového vyhledávání, kroky nástrojů / MCP a artefakty se řídí stejnými volbami jako u Markdownu a JSON: „Thinking“ (uvažování) je zaškrtávací políčko v panelu exportu, nástroje a zdroje se zapínají v nastavení. XML není ořezaná varianta těchto formátů.

Rozložení artefaktů je ve verzi 1.16.2 „Original“, „Inline“, „Nested“ nebo „Flat“ (původní, vložené, vnořené, ploché). Filtr odesílatele omezí XML na všechny zprávy, jen na uživatele, nebo jen na asistenta. Přidat lze i metadata (název, časová razítka, model). Úplný přehled přepínačů: funkce rozšíření pro Chrome.

XML, nebo JSON při exportu chatu Claude?

JSON je běžná volba vývojářů. Do XML exportujte jen tehdy, když ho vyžaduje navazující systém. Download Claude conversations nedělá XML „úplnějším“ než JSON. Obojí může obsahovat uvažování i artefakty. Ani jedno není ZIP účtu od Anthropicu. Přehled formátů: formáty exportu chatu Claude.

Settings → Privacy → Export data od Anthropicu (pokud máte claude.ai v češtině, mohou být popisky přeložené) je JSON (ZIP), ne XML. PDF ze stejného panelu jsou stránky pro lidi, ne značkování. Ani jedno nenahradí export do XML z oranžového tlačítka. Nečekejte, že toto XML bude odpovídat nezveřejněnému schématu Anthropicu.

Rozšíření funguje jen na claude.ai v Chromu. Claude Desktop a terminál Claude Code tlačítko pro XML nemají. Claude Code on the web (claude.ai/code) běží na claude.ai, takže se exportuje jako každý jiný chat. Pokud konverzace existuje i na claude.ai, otevřete ji tam a exportujte do XML. Příkaz /export v terminálovém Claude Code je jiná cesta.

Lze chaty Claude exportovat do XML hromadně?

Ano. Otevřete „View and Download All Conversations“, v poli „Chat format“ (formát chatu) nastavte XML, vyfiltrujte tabulku a klikněte na „Export All“. Chrome uloží jeden ZIP s jedním souborem XML na každý chat. V bezplatném tarifu jsou to 3 chaty denně s přihlášením přes Google, společně s PDF. Pro za 3,99 USD měsíčně nebo 26,99 USD ročně tento limit pro hromadné XML ruší.

Dashboard zobrazuje historii z claude.ai s vyhledáváním podle názvu, filtry „All conversations“, „New“, „Updated“ a „Previously exported“ (všechny konverzace, nové, aktualizované, dříve exportované), záložkami Chat a Cowork a vyhledáváním v projektech. „New“ znamená dosud neexportované přes Download Claude conversations. „Previously exported“ sleduje chaty, které jste už uložili. „Export All“ je jeden ZIP se samostatnými soubory XML pro každý chat, ne archiv smíšených formátů.

Denní limit platí pro celý účet. Tři chaty denně v bezplatném tarifu, společně s PDF. Když vyberete 40 konverzací a zbývají vám 3, zablokuje se celá dávka — nezkrátí se. Vyberte méně chatů, nebo použijte Pro. Jednotlivé exporty do XML z oranžového tlačítka zůstávají neomezené.

V jednom kliknutí na „Export All“ nelze kombinovat XML a JSON. Pro daný běh zvolte XML. Pokud potřebujete obě podoby stejné konverzace z claude.ai, spusťte „Export All“ znovu s JSON; druhý běh započítá každý chat znovu.

Potřebuje export do XML tarif Pro?

Ne. Export jednoho chatu do XML je zdarma a neomezený, bez účtu a bez počítadla — stejně jako Markdown, JSON, text, CSV a PNG. Bezplatný limit mají jen PDF a hromadný „Export All“: 3 denně s přihlášením přes Google. Pro stojí 3,99 USD měsíčně nebo 26,99 USD ročně přes Paddle. Download Claude conversations nebere XML jako formát jen pro platící.

Limit se projeví až u hromadného XML. Každý chat v ZIPu z „Export All“ spotřebuje jeden ze 3 denních exportů a počítadlo se nuluje o půlnoci UTC. Pro limit ruší a na novém počítači ho obnovíte přihlášením stejným účtem Google. Obchodníkem je Paddle; náš tým čísla karet nikdy nevidí.

Placený tarif claude.ai od Anthropicu nepotřebujete. Stačí přihlášení, se kterým se konverzace v Chromu načte. Verze 1.16.2 (září 2026) stále nevytváří soubory Word ani Notion. Pokud se tento seznam změní, změní se tato stránka ještě týž den.

Je XML pro export chatů Claude lepší než JSON?

Obecně ne. JSON je u vývojářů běžnější volba. Chat Claude exportujte do XML, když ho navazující systém vyžaduje pro strukturovanou výměnu dat. Zpracování z claude.ai je stejné; liší se tvar souboru.

Mohu chaty Claude exportovat do XML hromadně?

Ano. Stejný postup „Export All“ na Dashboardu podporuje XML a uloží jeden ZIP se souborem XML pro každý chat. V bezplatném tarifu pokryje 3 chaty denně s přihlášením přes Google; Pro za 3,99 USD měsíčně nebo 26,99 USD ročně je neomezený.

Je XML formát jen pro platící?

Ne. Exporty jednotlivých chatů do XML jsou neomezené a bez účtu, stejně jako Markdown, text, JSON, CSV a PNG. Bezplatný limit 3 denně mají jen PDF a hromadný „Export All“. Pro stojí 3,99 USD měsíčně nebo 26,99 USD ročně.

Odpovídá export chatu Claude do XML ZIPu od Anthropicu?

Ne. Export data od Anthropicu je opožděný ZIP účtu s JSON. Download Claude conversations zapíše soubor XML pro jeden chat (nebo výběr) hned v Chromu. Nejde o stejné schéma.

Vytvoří export chatu Claude do XML PDF?

Ne. XML je značkování. Pro stránky zvolte ve stejném panelu PDF; sedm formátů je PDF, Markdown, JSON, prostý text, XML, CSV a PNG. PDF vyžaduje přihlášení přes Google a v bezplatném tarifu se počítá do 3 denních exportů.

Mohu chat Claude exportovat do XML v aplikaci Desktop?

Ne. Rozšíření pro Chrome se vkládá jen do claude.ai. Claude Desktop rozbalovací seznam s XML nikdy nezobrazí. Otevřete stejnou konverzaci na claude.ai v Chromu, pokud tam existuje.

Potřebuji Pro pro jednorázový export do XML?

Ne. Nepotřebujete vůbec žádný účet. Exporty jednotlivých chatů do XML jsou v bezplatném tarifu neomezené. Pro za 3,99 USD měsíčně nebo 26,99 USD ročně ruší jen limit 3 denně u hromadného „Export All“ a PDF.
