Přehled (Dashboard) zobrazuje konverzace z účtu claude.ai, ke kterému jste přihlášeni – stejnou historii, kterou už máte, jen jako tabulku, kterou lze filtrovat. Hledejte podle názvu. Filtrujte podle All conversations, New, Updated nebo Previously exported (všechny, nové, aktualizované, dříve exportované). Přepínejte mezi kartami Chat a Cowork a hledejte podle projektu, pokud chaty na claude.ai takto seskupujete.

Hromadný export vytvoří jeden ZIP s jedním souborem na chat ve formátu, který zvolíte ve výběru „Chat format“ – kterýkoli ze sedmi, včetně PDF. Používá stejný parser jako export jednoho chatu. Zaškrtávací políčka určují obsah – „Chats“, „Thinking“, „Metadata“, „Tools“, „Sources“ (chaty, uvažování, metadata, nástroje, zdroje) – a k tomu rozložení artefaktů. Export All není ořezaná verze. Export All je stejný parser použitý na mnoho ID konverzací najednou. Podrobnosti: hromadný Export All.

Export data od Anthropicu zůstává zálohou účtu. Jeden ZIP, jeden e-mail, JSON pro všechno, včetně chatů, na které jste zapomněli. Hromadný Export All řeší opačný úkol: vy vybíráte řádky historie, vy volíte formát a ZIP dorazí okamžitě. Použijte obojí, pokud chcete archiv pro právní účely i složku čitelných poznámek.

Limit je sdílený a denní. V bezplatném plánu sdílejí exporty PDF a hromadně exportované chaty limit 3 denně, který se obnovuje o půlnoci UTC. Vyberete-li 40 konverzací, zablokuje se celá dávka – nezkrátí se. Vyberte méně, nebo přejděte na Pro za 3,99 USD měsíčně či 26,99 USD ročně přes Paddle.

Přehled si pamatuje, co jste už exportovali, takže při další návštěvě můžete filtrovat jen New nebo Updated. Díky tomu zůstane pravidelné týdenní ukládání chatů přírůstkové a neduplikuje Markdown z minulého měsíce. Počítadlo 3 denně se váže na účet Google, ne na instalaci, a obnovuje se o půlnoci UTC.

Když je historie plná jednořádkových konceptů, vyberte jen část. Export All neznamená, že musíte vzít každý řádek. Přesný filtr a Markdown dají čistší výzkumnou složku než 200 prázdných vláken s „ahoj“.

Export chatu Claude jako produktové sloveso znamená stejné oranžové tlačítko a stejnou tabulku Export All. Související stránka export chatu Claude tyto ovládací prvky popisuje, pokud jste přišli z dotazu na „export“ místo „uložit“.

Lze uložit konverzaci v Desktopu nebo v Claude Code?

V Desktopu ne. V Claude Code jen na webu. Download Claude conversations neuloží konverzaci Claude z Claude Desktop ani z lokálního terminálu Claude Code. Relace na claude.ai/code se otevírají v desktopovém Chrome, takže se ukládají jako jakýkoli chat. Claude Desktop je samostatná aplikace. Lokální Claude Code je terminálový agent s příkazem /export a soubory JSONL na disku.

Pokud chat z Desktopu existuje i na claude.ai, otevřete tuto URL v Chrome a použijte oranžové tlačítko. Pokud vlákno existuje jen v Desktopu, zkopírujte ho, nebo počkejte na Settings → Privacy → Export data. Rozšíření se do okna Desktopu nikdy nevkládá.

V aktivní relaci Claude Code napište /export. CLI od Anthropicu otevře nabídku, kde přepis zkopírujete nebo uložíte jako soubor s prostým textem. Když zadáte název souboru, nabídka se přeskočí. Tento přepis je vykreslený text ke čtení pro člověka, ne Markdown, JSON ani PDF z tohoto rozšíření. Všechny cesty: export z Claude Code.

JSONL na disku je interní log v ~/.claude/projects (Windows: %USERPROFILE%\.claude\projects). Jeho schéma se může mezi verzemi Claude Code měnit. Vlastní dokumentace Anthropicu doporučuje místo parsování JSONL používat /export. Toto CLI neobalujeme. Složku ~/.claude nečteme.

FAQ: jak uložit konverzaci Claude

Jak uložím konverzaci Claude jako soubor?

Nainstalujte Download Claude conversations, otevřete vlákno na claude.ai, klikněte na oranžové tlačítko vpravo od pole pro zprávu, zvolte PDF, Markdown, JSON, text, XML, CSV nebo PNG a klikněte na Export. Soubor se stáhne lokálně, bez účtu, kromě PDF. Historie už chat v účtu Anthropic uložila; oranžové tlačítko zapíše kopii na disk.

Jak uložit chat Claude na claude.ai?

Aby vlákno zůstalo v účtu, tlačítko Uložit nepotřebujete. Historie na claude.ai už chaty z přihlášené relace zobrazuje. Chcete-li chat Claude uložit jako soubor, použijte rozšíření pro Chrome, Tisk → Uložit jako PDF, nebo Settings → Privacy → Export data pro ZIP účtu v JSON, který přijde se zpožděním.

Jak uložit konverzaci v Claude bez rozšíření?

Vytiskněte stránku claude.ai (Ctrl/Cmd+P → Uložit jako PDF) pro vizuální kopii, nebo použijte Settings → Privacy → Export data pro ZIP celého účtu v JSON, zaslaný e-mailem. Pro krátkou odpověď stačí kopírovat a vložit. Žádná z těchto metod nevytvoří strukturovaný soubor Markdown pro jednotlivý chat tak jako rozšíření pro Chrome.

Ukládá Claude konverzace už sám do historie?

Ano. Chaty z přihlášené relace na claude.ai zůstávají v historii v účtu Anthropic. Zavření karty, obnovení stránky ani otevření jiného zařízení se stejným přihlášením vlákno nesmaže. Historie ale není PDF, Markdown, JSON ani jiný soubor na vašem disku.

Zmizí konverzace Claude, když zavřu kartu?

Ne. Zavřením karty claude.ai se konverzace z historie nesmaže. Smazání chatu z historie ho z rozhraní účtu odstraní. Soubor, který jste už exportovali přes Download Claude conversations, zůstane na disku i po tomto smazání.

Mohu konverzaci Claude uložit jako PDF?

Ano. Download Claude conversations 1.16.2 exportuje PDF přímo: v panelu oranžového tlačítka zvolte PDF a klikněte na Export. Soubor vzniká v prohlížeči bez dialogu tisku. PDF vyžaduje přihlášení přes Google a je zdarma až 3 denně; s Pro bez omezení. Návod: chat Claude jako PDF.

Kolik souborů mohu uložit zdarma?

Markdown, prostý text, JSON, XML, CSV a PNG neomezeně, bez účtu. PDF a hromadný ZIP sdílejí v bezplatném plánu limit 3 denně s přihlášením přes Google; každý chat v hromadném ZIP se počítá jako jeden a den se obnovuje o půlnoci UTC. Pro stojí 3,99 USD měsíčně nebo 26,99 USD ročně a limit ruší. Platbu zpracovává Paddle.

Funguje ukládání konverzací na mobilu?

Rozšíření pro Chrome ne. Běží v desktopovém Chrome (nebo jiném prohlížeči založeném na Chromiu, který umí instalovat položky z Chrome Web Store). Aplikace pro iOS ani Android neexistuje. Mobilní prohlížeče umí otevřít historii a chat Claude vytisknout, oranžové tlačítko ale nezobrazí.

Mohu chaty Claude z historie uložit hromadně?

Ano. V okně rozšíření otevřete View and Download All Conversations, vyfiltrujte tabulku a klikněte na Export All. Hromadný export vyžaduje přihlášení přes Google a v bezplatném plánu se započítává do limitu 3 denně. Tato hromadná cesta není ZIP z Export data od Anthropicu. Oficiální Export data je jeden archiv celého účtu, poslaný později e-mailem. Viz hromadné stahování.

Uloží to konverzaci Claude i z Claude Code?

Jen na webu. Relace Claude Code na claude.ai/code se ukládají jako jakýkoli chat na claude.ai. Lokální relace z terminálu ne: použijte /export nebo zkopírujte JSONL z ~/.claude/projects (Windows: %USERPROFILE%\.claude\projects). Toto rozšíření pro Chrome běží jen na claude.ai. Návod: export z Claude Code.

Je k uložení chatu Claude nutné přihlášení přes Google?

Pro Markdown, prostý text, JSON, XML, CSV ani PNG ne. Přihlášení přes Google je nutné jen pro PDF, hromadný Export All a Pro, abychom mohli uplatnit limit 3 denně a obnovit Pro po přeinstalaci. Obsah konverzací se s tímto přihlášením neodesílá. Ověřený e-mail ukládáme jen kvůli limitu a stavu Pro.

Kde najdu oficiální Export data pro uložení chatů Claude?

Na claude.ai: Settings → Privacy → Export data. Anthropic vám e-mailem pošle odkaz s omezenou platností. ZIP je archiv celého účtu v JSON, ne pojmenovaný soubor Markdown s chatem, který jste četli. Export data používejte jako zálohu; oranžové tlačítko pro jeden čitelný soubor hned.
