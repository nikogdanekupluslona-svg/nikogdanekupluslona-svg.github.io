Proč tu nejde exportovat chat z Claude Desktop?

Download Claude conversations je obsahový skript Chromu pro claude.ai. Claude Desktop je samostatná aplikace pro Mac a Windows. V jejím okně není lišta rozšíření, takže se oranžové tlačítko nikdy neobjeví. Instalace z Chrome Web Store při otevřeném Desktopu s Desktopem nic neudělá.

Rozšíření pro Chrome běží na stránkách, které odpovídají jejich oprávněním k webům. Tato položka odpovídá stránkám konverzací na claude.ai. Claude Desktop není karta claude.ai. V aplikaci Desktop nemůžete kliknout na „Add to Chrome“ (Přidat do Chromu). Verze 1.16.2 (září 2026) stále nemá plugin pro Desktop, pomocníka v liště nabídek ani čtečku souborů z instalační složky Desktopu.

Pevná hranice. Z Desktopu chat Claude tímto rozšířením pro Chrome neexportujete. Pokud z našeho widgetu potřebujete PDF, Markdown, JSON, text, XML, CSV nebo PNG, opusťte Desktop, otevřete https://claude.ai v Chromu a konverzaci otevřete tam.

Lidé hledají „export chatu Claude Desktop“, česky i anglicky („claude desktop export chat“), protože produkty sdílejí značku. Výsledky vyhledávání míchají Desktop, claude.ai a Claude Code. Soubory ale zaměnitelné nejsou. Snímek obrazovky z Desktopu není export do Markdownu. Log JSONL z Code není vlákno z claude.ai. Tato stránka existuje proto, aby byl ten nesoulad jasně pojmenovaný.

Jak exportovat chat z Claude Desktop přes claude.ai?

Mnoho relací v Desktopu používá stejný účet Claude jako web. Pokud je vlákno v historii na claude.ai, otevřete ho v Chromu a použijte Download Claude conversations. Jen tak vám toto rozšíření s exportem chatu z Claude Desktop pomůže: chat se musí nejdřív načíst na claude.ai.

  1. Přestaňte hádat v Desktopu. Otevřete https://claude.ai v Chromu a přihlaste se stejným účtem.
  2. Najděte konverzaci v historii na webu. Pokud chybí, přejděte ke kopírování nebo k Export data — chat, který Chrome nikdy nenačetl, stáhnout nedokážeme.
  3. Klikněte na oranžové tlačítko. Zvolte PDF, Markdown, prostý text, JSON, XML, CSV nebo PNG. Klikněte na „Export“ (Exportovat).
  4. U mnoha synchronizovaných vláken otevřete „View and Download All Conversations“ (Zobrazit a stáhnout všechny konverzace) a spusťte „Export All“ (Exportovat vše). Dashboard (přehled) má karty Chat a Cowork. V bezplatném tarifu se každý chat v ZIPu počítá do 3 denně.
  5. Pokud potřebujete PDF, zvolte PDF ve stejném panelu — soubor se sestaví v prohlížeči, bez tiskového dialogu. Průvodce: chat Claude do PDF.

Exporty do Markdownu, textu, JSON, XML, CSV a PNG na webu jsou neomezené a nevyžadují účet. Přihlášení přes Google se objeví jen u PDF a hromadného ZIPu, které sdílejí 3 bezplatné exporty denně (obnova o půlnoci UTC), a kvůli obnovení Pro za 3,99 USD měsíčně nebo 26,99 USD ročně. Tento limit platí jen pro soubory z claude.ai. Kopírování z Desktopu náš limit nečerpá, protože se rozšíření vůbec nedotkne. Pro účtuje Paddle; čísla karet nikdy nevidíme.

Synchronizace je chování Anthropicu, ne naše. Pokud Desktop ukazuje chat, který na claude.ai není, toto rozšíření pro Chrome si ho nevymyslí. Počkejte, obnovte claude.ai, nebo použijte kopírování / oficiální ZIP. Lokální databázi Desktopu nečteme. Jak webový exportér funguje, jakmile karta existuje: jak to funguje.

Formáty, jakmile se dostanete na claude.ai. PDF ke sdílení nebo tisku, Markdown pro poznámky, JSON pro nástroje, text pro holý archiv, XML pro výměnu dat, CSV pro tabulku, PNG pro obrázek. Stejných sedm jako v každém jiném průvodci. Přehled: formáty. Žádný z těchto formátů se přes tuto položku v aplikaci Desktop neobjeví.

Lze chat z Claude Desktop exportovat kopírováním?

Ano. Označte text v Claude Desktop a vložte ho do dokumentu. To je poctivá záložní cesta, když se vlákno na claude.ai nezobrazuje. Přijdete o věrné bloky kódu, rozvržení artefaktů, přepínače uvažování i hromadný „Export All“. Na krátkou odpověď to stačí; u dlouhého programátorského vlákna je to utrpení.

Kopírování z Desktopu je důvod, proč rozšíření pro Chrome na claude.ai existuje: webový widget zachová označení jazyka, tabulky i artefakty v rozvržení „Original“, „Inline“, „Nested“ a „Flat“ (původní, vložené, vnořené, ploché). Desktop od nás žádné takové ovládání exportu nemá. Pokud můžete stejnou konverzaci otevřít na claude.ai, přestaňte kopírovat a použijte tam Download Claude conversations.

Další záložní možností jsou snímky obrazovky z Claude Desktop. Jsou to obrázky, ne Markdown. Za export chatu Claude Desktop ve smyslu znovu použitelného souboru se nepočítají. PNG z našeho rozšíření je také obrázek, ale vznikne až poté, co je chat otevřený na claude.ai. Nečekejte, že takové PNG dostanete z okna Desktopu.

Zahrnuje Export data i chaty z Claude Desktop?

Settings → Privacy → Export data od Anthropicu (pokud máte claude.ai v češtině, mohou být popisky přeložené) pošle e-mailem ZIP s JSON navázaný na účet Claude, ne na okno, ve kterém jste psali. Pokud je konverzace z Desktopu uložená v tomto účtu, může se v něm objevit. Berte ZIP jako zálohu, ne jako Markdown z tohoto rozšíření.

ZIP přichází pomalu, odkaz vyprší a nemá výběr formátu pro PDF, Markdown, text, XML, CSV ani PNG. Přesto je to oficiální cesta, jak si vzít účet s sebou, když potřebujete exportovat historii chatů z Claude Desktop jako jeden balík. Srovnání s tiskem a widgetem pro Chrome: jak exportovat chat Claude.

Nepleťte si tento ZIP s hromadným „Export All“ v našem Dashboardu. „Export All“ zapíše jeden ZIP s jedním souborem na každý chat, který vyberete na claude.ai, okamžitě a ve zvoleném formátu. V bezplatném tarifu spotřebuje každý chat v ZIPu jeden ze 3 denních exportů (sdílených s PDF); Pro limit ruší. Oficiální Export data náš limit nečerpá. Chaty jen z Desktopu, které se nikdy nesynchronizovaly, mohou chybět v obou.

Je Claude Desktop totéž co Claude Code?

Ne. Claude Desktop je chatovací aplikace. Claude Code je programovací agent v terminálu s /export a přepisy v JSONL. Hledat export chatu Claude Desktop kvůli terminálu v IDE znamená hledat špatný produkt. Toto rozšíření pro Chrome neběží ani v jednom z nich. Výjimkou je Claude Code on the web na claude.ai/code: je to stránka claude.ai, takže se exportuje jako každý chat.

Pokud jste „desktopem“ mysleli VS Code nebo terminál na počítači, pokračujte na export z Claude Code. Pokud jste mysleli chatovací aplikaci Desktop od Anthropicu, zůstaňte na této stránce. Míchat obojí je ztráta času: JSONL na disku není oranžové tlačítko a kopírování z Desktopu není /export.

Download Claude conversations nezíská napojení na Code jen proto, že Desktop i Code „nejsou prohlížeč“. Produkt je záměrně úzký: claude.ai v Chromu, sedm formátů, neomezené exporty bez účtu kromě PDF a hromadného ZIPu (zdarma 3× denně), Pro za 3,99 USD měsíčně nebo 26,99 USD ročně. Nejmenujeme ani jiné exportéry pro Chrome. Oficiální produkty Anthropicu — claude.ai, Claude Desktop, Claude Code, Settings → Privacy → Export data — tu zmiňujeme pro srovnání. Pokud žijete jen v Desktopu, používejte kopírování a oficiální ZIP, dokud Anthropic v aplikaci nepřidá export jednotlivých chatů do souboru. Pokud používáte i claude.ai, nainstalujte rozšíření a exportujte z prohlížeče. To je celá poctivá nabídka. Mobilní aplikace Claude jsou pro tuto položku stejně mimo rozsah.

Řešení potíží: rozšíření je nainstalované, ale v Desktopu tlačítko není — to je očekávané. Tlačítko chybí na claude.ai — znovu načtěte stránku, připněte ikonu, otevřete adresu konverzace.
