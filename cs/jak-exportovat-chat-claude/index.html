Jak exportovat chat Claude pomocí rozšíření?

Chcete-li chat Claude exportovat jako čitelný soubor, použijte oranžové tlačítko na claude.ai. Nainstalujte Download Claude conversations, otevřete vlákno, zvolte PDF, Markdown, JSON, text, XML, CSV nebo PNG a klikněte na „Export“ (Exportovat). Soubor se sestaví ve vašem prohlížeči a uloží lokálně. Účet potřebujete jen pro PDF a hromadný export.

Rozšíření je obsahový skript na stránce, kterou už máte načtenou. Neotevírá druhou relaci u Anthropicu a k vytvoření souboru konverzaci nikam nenahrává. Proto se tlačítko objeví jen na adrese konverzace, až když vlákno existuje v DOM.

  1. Nainstalujte rozšíření z Chrome Web Store.
  2. Otevřete konverzaci na claude.ai. Pokud byla karta otevřená během instalace, načtěte ji znovu.
  3. Klikněte na kulaté oranžové tlačítko pro stažení vedle pole pro zprávu.
  4. Nastavte Messages na „All / Human / Assistant“ (vše / uživatel / asistent) a zvolte PDF, Markdown, JSON, prostý text, XML, CSV nebo PNG.
  5. Zaškrtnutím „Thinking“ (uvažování) přidáte rozšířené uvažování. Pomocí „Select“ (Vybrat) označíte jednotlivé zprávy, pokud potřebujete jen část vlákna. Klikněte na „Export“ — nebo na „Copy“ (Kopírovat), čímž vložíte Markdown, text, JSON, XML nebo CSV do schránky.

Pro více než jedno vlákno otevřete ve vyskakovacím okně „View and Download All Conversations“ (Zobrazit a stáhnout všechny konverzace). Vyhledávejte, filtrujte podle „New“, „Updated“ nebo „Previously exported“ (nové, aktualizované, dříve exportované), prohledávejte projekty, zvolte „Chat format“ a pak přes „Export All“ (Exportovat vše) získáte jeden ZIP s jedním souborem na chat. Hromadný export vyžaduje přihlášení přes Google; v bezplatném tarifu spotřebuje každý chat v ZIPu jeden ze 3 denních exportů, sdílených s PDF. Návod: hromadný export přes Export All.

Chaty z Team a Enterprise se exportují stejně, pokud je otevřete v Chromu. Zpracování nekontroluje názvy tarifů Anthropicu. Pokud organizace rozšíření blokuje, jde o zásadu IT, ne o chybějící přepínač Pro na naší straně.

Náš limit, nebo využití u Anthropicu. Export tímto rozšířením nespotřebovává kredity zpráv Claude. Jen čte stránku. Limit 3 denně pro PDF a hromadný export je náš; Pro za 3,99 USD měsíčně nebo 26,99 USD ročně, účtované zvlášť přes Paddle, ho ruší.

Jak exportovat chaty z Claude přes oficiální ZIP?

Export chatů z Claude v rozsahu celého účtu je Settings → Privacy → Export data. Anthropic pošle e-mailem odkaz, který vyprší. ZIP obsahuje JSON celého účtu, ne pěkný soubor pro jednu konverzaci. Používejte ho jako zálohu.

Oficiální ZIP je správný nástroj, když opouštíte pracovní prostor, archivujete vše nebo vyřizujete žádost typu „dejte mi všechna moje data“. Je to špatný nástroj, když máte otevřenou jednu revizi návrhu a soubor potřebujete během minuty.

V tomto postupu nelze filtrovat podle ID jedné konverzace. Čekáte, stáhnete archiv, rozbalíte ho a vlákno hledáte. Struktura JSON je na úrovni účtu. Není to JSON pro jednotlivý chat, který toto rozšíření zapisuje z otevřené stránky.

Pokud potřebujete obojí, spusťte jednou Export data kvůli záloze a Download Claude conversations používejte, kdykoli potřebujete pracovní soubor. Tyto úkoly se navzájem nenahrazují. Ze ZIPu se Markdown nestane. Oranžové tlačítko vám e-mailem nepošle každý zapomenutý chat z roku 2024.

Oficiální Export data také není tisk do PDF. Tisk zachytí webovou stránku. ZIP obsahuje strukturovaná data účtu. Srovnání tisku a vestavěného PDF v rozšíření: stáhnout chat Claude jako PDF.

Jak exportovat chat Claude do Markdownu nebo JSON?

Jak exportovat chat Claude do Markdownu nebo JSON: před kliknutím na „Export“ zvolte daný formát v rozbalovacím seznamu. Markdown je pro poznámky a git. JSON je strom zpráv pro skripty. Prostý text odstraní značky. CSV dá každou zprávu na jeden řádek. PNG je obrázek; PDF je stránkovaný dokument.

Markdown zachová nadpisy, bloky kódu s označením jazyka a tabulky. Rozložení artefaktů může být „Original“, „Inline“, „Nested“ nebo „Flat“ (původní, vložené, vnořené, ploché). Bloky uvažování jsou volitelné. Právě takový soubor většina lidí myslí čitelným exportem. Přehled: formáty.

JSON z rozšíření vzniká pro každou konverzaci (nebo pro hromadný výběr). Není to přejmenovaný ZIP účtu od Anthropicu. Pokud píšete parser, použijte tento JSON pro jedno vlákno a oficiální ZIP jen tehdy, když opravdu potřebujete každou konverzaci, kterou Anthropic uložil.
