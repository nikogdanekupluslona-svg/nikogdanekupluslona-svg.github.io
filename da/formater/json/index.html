Hvordan eksporterer jeg en Claude-samtale som JSON?

Åbn samtalen på claude.ai i Chrome, klik på den orange knap ved siden af beskedfeltet, vælg JSON, og klik på "Export". Download Claude conversations skriver filen lokalt. Sådan eksporterer du en Claude-samtale som JSON i version 1.13.0. claude.ai har i september 2026 ingen knap til at gemme en enkelt chat som JSON.

  1. Installér Download Claude conversations fra Chrome Web Store (bedømt 5.0).
  2. Genindlæs claude.ai, og åbn en rigtig samtale-URL – ikke den tomme startside med skrivefeltet.
  3. Klik på den orange downloadknap til højre for beskedfeltet.
  4. Vælg JSON. Det sidst brugte format huskes.
  5. Klik på "Export". Chrome downloader JSON-filen via browserens download-API.

Du skal logge ind med Google, før du eksporterer første gang. Download Claude conversations gemmer den verificerede e-mail for at tælle de 3 gratis eksporter og gendanne Pro efter en geninstallation. Chatindholdet indgår ikke i login. Mekanikken: sådan virker det.

Mangler den orange knap, er du ikke på en samtale-URL, fanen skal genindlæses, eller udvidelsen er skjult i Chromes puslespilsmenu. Fastgør Download Claude conversations, og genindlæs claude.ai. Content scriptet indlæses aldrig i Claude Desktop eller Claude Code.

Én tråd eller mange filer. Den orange knap eksporterer den åbne chat som JSON. Vil du have mange JSON-filer, så åbn "View and Download All Conversations" (se og download alle samtaler) og kør "Export All" (eksportér alle) med JSON valgt – se masseeksport med Export All.

Hvornår skal jeg eksportere en Claude-samtale som JSON?

Vælg JSON, når et script, en indekser eller et sammenligningsværktøj skal læse filen. JSON-filen er bygget til beskedtræet, ikke til læsning i Obsidian. Vil du have overskrifter og kodeblokke til mennesker, så vælg Markdown i stedet.

Kopiering fra claude.ai mister strukturen med afsendere. Udskrift tager webside-rammen med. Med JSON bevarer Download Claude conversations tur, afsender og valgfri thinking som data – ikke som ét fladt afsnit. Derfor vælger udviklere JSON frem for ren tekst.

Vi skriver JSON ud fra det claude.ai-træ, der allerede er på siden – afsender, indholdsblokke, tidsstempler, metadata om modellen – uden at uploade tråden. Den JSON er ikke Anthropics ZIP-fil for kontoen, og det er ikke PDF. Version 1.13.0 leverer stadig kun fem formater.

Hvad indeholder en JSON-eksport af en Claude-samtale?

En JSON-eksport spejler beskedtræet på claude.ai: afsender, indholdsblokke, tidsstempler og metadata om modellen. Thinking-blokke og artefakter kommer med, når de kontakter er slået til ("include thinking", "include metadata"). Afsenderfilteret kan begrænse filen til "all / human only / assistant only" (alle beskeder, kun mennesket eller kun assistenten). Intet bliver først gjort fladt til Markdown.

Layout for artefakter i version 1.13.0 er "Original", "Inline" (i teksten), "Nested" (indlejret) eller "Flat" (fladt). Layoutet ændrer, hvordan artefakternes indhold er indlejret i JSON – de samme fire muligheder som for Markdown og XML. Hele listen over kontakter: funktioner i Chrome-udvidelsen. JSON bliver stadig ikke til PDF.

JSON-eksport af en Claude-samtale vs. Anthropics Export data?

Begge er JSON, men ikke med samme form eller omfang. Anthropics Settings → Privacy → Export data (menunavnene kan være oversat, hvis claude.ai er sat til dansk) sender efter en ventetid én ZIP-fil med hele kontoen på mail. Med udvidelsen får du én tråd med det samme i Chrome. Brug ZIP-filen til backup.

Du kan ikke vælge Markdown i Anthropics ZIP-anmodning. Du kan heller ikke bruge udvidelsens JSON som direkte erstatning for ZIP-filens skema. Oversigt over formater: formater til eksport af Claude-chats. Udskrift er en visuel nødløsning, ikke en JSON-eksport.

Download Claude conversations er ikke tilknyttet Anthropic, PBC. Content scriptet bruger den session, du allerede har åbnet på claude.ai. Det logger ikke ind hos Anthropic med separate loginoplysninger. Følg Anthropics regler for din konto.

Kan jeg eksportere mange Claude-samtaler som JSON på én gang?

Ja. Åbn "View and Download All Conversations", sæt formatet til JSON, filtrér tabellen, og klik på Export All. Hver færdig fil er en af de 3 gratis eksporter. Pro til 3,99 $/md. eller 26,99 $/år fjerner loftet for masseeksport som JSON.

Oversigtstabellen viser din historik fra claude.ai med søgning på navn og filtrene All, New, Exported og Project (alle, nye, eksporterede, projekt). New betyder, at chatten endnu ikke er eksporteret med Download Claude conversations. Exported holder styr på chats, du allerede har gemt. Project svarer til, hvordan du grupperer chats på claude.ai. Export All giver mange JSON-filer, ikke én blandet ZIP-fil.

Kvoten gælder hele kontoen. Tre gratis eksporter i alt – ikke tre JSON-filer pr. masseeksport. Vælger du 40 samtaler, bruger du 40 eksporter, hvis alle filer bliver færdige. Planlæg udvalget, eller brug Pro.

Du kan sammenligne to JSON-eksporter af den samme claude.ai-tråd fra forskellige tidspunkter, ligesom du sammenligner enhver anden JSON-fil. Hver eksport er selvstændig. En ny Export All af de samme chats bruger stadig af kvoten, medmindre filerne ikke bliver færdige.

Kræver JSON-eksport af en Claude-samtale Pro?

Nej. JSON indgår i de 3 gratis eksporter, som hver konto med Google-login får, ligesom Markdown, tekst, XML og PNG. Efter de tre filer koster Pro 3,99 $ om måneden eller 26,99 $ om året via Paddle. Download Claude conversations tager ikke ekstra for at eksportere en Claude-samtale som JSON.

De 3 gratis eksporter nulstilles ikke, når du geninstallerer udvidelsen fra Chrome Web Store. Derfor kræves Google-login ved det første klik på Export. Pro gendannes på en ny computer fra den samme Google-konto. Paddle er forhandler (merchant of record); vi ser aldrig kortnumre.

Udvidelsen kører kun på claude.ai i Chrome. Claude Desktop og Claude Code får ingen JSON-knap. Claude Codes /export eller JSONL på disken er en helt anden vej. Version 1.13.0 fra september 2026 skriver stadig ikke PDF, Word eller Notion.

FAQ: eksportér Claude-samtale som JSON

Disse spørgsmål dækker JSON-eksport i Download Claude conversations 1.13.0: masseeksport med Export All, skema, kvote, sammenligninger, Anthropics ZIP-fil og Desktop. Hvert svar er et produktfaktum. FAQPage-JSON-LD i sidens head svarer til denne liste.

Kan jeg eksportere Claude-samtaler som JSON i én omgang?

Ja. Export All på oversigtssiden understøtter JSON på samme måde som en enkelt eksport. Hver færdig fil tæller som en af de 3 gratis eksporter, medmindre du har Pro til 3,99 $/md. eller 26,99 $/år.

Er JSON-strukturen dokumenteret?

Den spejler claude.ai's eget beskedtræ: afsender, indholdsblokke, tidsstempler og metadata om modellen, med artefakter og thinking-blokke, når du slår de kontakter til. Det er ikke skemaet fra Anthropics ZIP-fil for kontoen.

Skal jeg have Pro for at eksportere en Claude-samtale som JSON?

Nej. JSON indgår i de 3 gratis eksporter, som hver konto med Google-login får, ligesom alle andre formater. Pro koster 3,99 $/md. eller 26,99 $/år efter de tre filer.

Kan jeg sammenligne to JSON-eksporter af den samme chat?

Ja. Hver gang du eksporterer en Claude-samtale som JSON, får du en selvstændig fil, der er bygget på samme måde. To eksporter af samme tråd fra forskellige tidspunkter sammenlignes som enhver anden JSON-fil.

Er denne JSON det samme som Anthropics Export data?

Nej. Anthropics Export data er en forsinket ZIP-fil med hele kontoen. Download Claude conversations skriver med det samme en JSON-fil pr. chat (eller pr. udvalg) i Chrome. Begge kan være JSON, men de kan ikke bruges i stedet for hinanden.

Laver eksport som JSON en PDF?

Nej. JSON er strukturerede data. Produktets formater er Markdown, JSON, ren tekst, XML og PNG. Vil du have en side til udskrift, så brug Chromes udskriftsdialog, ikke denne menu.

Virker JSON-eksport i Claude Desktop?

Nej. Chrome-udvidelsen indlæses kun på claude.ai. Claude Desktop viser aldrig JSON-muligheden. Åbn den samme tråd på claude.ai i Chrome, hvis den findes der.
