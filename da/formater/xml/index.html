Hvordan eksporterer jeg en Claude-chat til XML?

Åbn samtalen på claude.ai i Chrome, klik på den orange knap ved siden af beskedfeltet, vælg XML, og klik på "Export". Download Claude conversations skriver filen lokalt. Sådan eksporterer du en Claude-chat til XML i version 1.16.2. claude.ai har i september 2026 ingen indbygget knap til at gemme som XML.

  1. Installér Download Claude conversations fra Chrome Web Store.
  2. Genindlæs claude.ai, og åbn en rigtig samtale-URL – ikke den tomme startside med skrivefeltet.
  3. Klik på den orange downloadknap til højre for beskedfeltet.
  4. Vælg XML. Det sidst brugte format huskes. Brug "Select" (vælg) til kun at markere de beskeder, du vil have med.
  5. Klik på "Export". Chrome downloader XML-filen via browserens download-API. Eller klik på "Copy" (kopiér) for at lægge XML-teksten i udklipsholderen.

Du behøver intet login for at eksportere en Claude-chat til XML. Eksport af enkelte chats til XML er ubegrænset og anonym og sender ingenting til vores servere. Google-login kræves kun til PDF og masseeksport med "Export All" (eksportér alle). Mekanikken: sådan virker det.

Mangler den orange knap, er du ikke på en samtale-URL, fanen skal genindlæses, eller udvidelsen er skjult i Chromes puslespilsmenu. Fastgør Download Claude conversations, og genindlæs claude.ai. XML-eksport vises aldrig i Claude Desktop eller Claude Code-terminalen.

Én fil eller mange. Den orange knap eksporterer den åbne tråd som XML. Vil du have mange XML-filer, så åbn "View and Download All Conversations" (se og download alle samtaler) og kør Export All med XML valgt: én ZIP-fil, 3 chats om dagen på gratisplanen – se masseeksport med Export All.

Hvornår skal jeg eksportere en Claude-chat til XML?

Vælg XML, når det modtagende system, en pipeline eller et ældre værktøj kræver XML til struktureret dataudveksling. De fleste udviklere bør vælge JSON i stedet. Markdown er til noter for mennesker. CSV er til regneark. PNG er et billede. XML findes i menuen, fordi nogle værktøjer stadig indlæser XML og ikke accepterer JSON.

Brug ikke XML som en "mere officiel" JSON. Download Claude conversations læser samtalen på samme måde uanset format. Forskellen er filens form – der dukker ikke ekstra felter op. Hvis intet af det, du bruger, kræver XML, så spring formatet over og brug JSON.

Vi leverer XML, fordi nogle pipelines stadig kræver det – ikke fordi vi mener, det slår JSON til enhver eksport fra claude.ai. Læsningen er den samme: beskeder, afsender, valgfri thinking og artefakter. Version 1.16.2 har XML som et af syv formater, gratis uden konto – ikke som et betalt tilvalg.

Hvad bevares, når du eksporterer en Claude-chat til XML?

Download Claude conversations skriver samtalens struktur – beskeder, afsender og tilgængelige metadata – som XML-markup. Thinking-blokke, kilder fra websøgning, værktøjs-/MCP-trin og artefakter følger de samme valg som i Markdown og JSON: "Thinking" (tænkning) er et afkrydsningsfelt i eksportpanelet, og værktøjer og kilder slår du til i indstillingerne ("Settings"). XML er ikke en nedbarberet udgave af de formater.

Layout for artefakter er "Original", "Inline" (i teksten), "Nested" (indlejret) eller "Flat" (fladt) i version 1.16.2. Afsenderfilteret kan begrænse XML-filen til "All", "Human" eller "Assistant" (alle beskeder, kun mennesket eller kun assistenten). Metadata (titel, tidsstempler, model) kan komme med. Hele listen over kontakter: funktioner i Chrome-udvidelsen.

XML eller JSON, når jeg eksporterer en Claude-chat?

JSON er det almindelige valg for udviklere. Eksportér kun til XML, når et system længere nede i kæden kræver XML. Download Claude conversations gør ikke XML "mere komplet" end JSON. Begge kan indeholde thinking og artefakter. Ingen af dem er Anthropics ZIP-fil for kontoen. Oversigt over formater: formater til eksport af Claude-chats.

Anthropics Settings → Privacy → Export data (menunavnene kan være oversat, hvis claude.ai er sat til dansk) er JSON (i en ZIP-fil), ikke XML. PDF fra samme panel er sider til mennesker, ikke markup. Ingen af dem erstatter XML-eksporten via den orange knap. Forvent ikke, at denne XML matcher et upubliceret skema fra Anthropic.

Udvidelsen kører kun på claude.ai i Chrome. Claude Desktop og Claude Code-terminalen får ingen XML-knap. Claude Code på nettet (claude.ai/code) kører på claude.ai, så den eksporteres som enhver anden chat. Findes en tråd også på claude.ai, så åbn den dér og eksportér den til XML. /export i Claude Code-terminalen er en helt anden vej i et andet produkt.

Kan jeg eksportere mange Claude-chats til XML på én gang?

Ja. Åbn "View and Download All Conversations", sæt "Chat format" (chatformat) til XML, filtrér tabellen, og klik på Export All. Chrome gemmer én ZIP-fil med én XML-fil pr. chat. På gratisplanen er det 3 chats om dagen med Google-login, delt med PDF. Pro til 3,99 $ om måneden eller 26,99 $ om året fjerner loftet for masseeksport til XML.

Dashboardet viser din historik fra claude.ai med søgning på navn, filtrene "All conversations", "New", "Updated" og "Previously exported" (alle samtaler, nye, opdaterede, tidligere eksporteret), fanerne Chat og Cowork samt projektsøgning. New betyder, at chatten endnu ikke er eksporteret med Download Claude conversations. Previously exported holder styr på chats, du allerede har gemt. Export All giver én ZIP-fil med XML-filer, én pr. chat – ikke et arkiv med blandede formater.

Den daglige grænse gælder pr. konto. Tre chats om dagen på gratisplanen, delt med PDF. Vælger du 40 samtaler med 3 tilbage, blokeres hele kørslen – den bliver ikke bare afkortet. Vælg færre, eller brug Pro. Enkelte XML-eksporter fra den orange knap er fortsat ubegrænsede.

Du kan ikke blande XML og JSON i ét klik på Export All. Vælg XML til den kørsel. Kør Export All igen med JSON, hvis du har brug for den samme claude.ai-tråd i begge former; den anden kørsel tæller hver chat med igen.

Kræver eksport af en Claude-chat til XML Pro?

Nej. Eksport af én chat til XML er gratis og ubegrænset, uden konto og uden tæller – ligesom Markdown, JSON, tekst, CSV og PNG. Kun PDF og masseeksport med Export All har en gratisgrænse: 3 om dagen med Google-login. Pro koster 3,99 $ om måneden eller 26,99 $ om året via Paddle. Download Claude conversations behandler ikke XML som et format kun for betalende.

Det er ved masseeksport til XML, at grænsen viser sig. Hver chat i en ZIP-fil fra Export All bruger en af de 3 om dagen, og tælleren nulstilles ved midnat UTC. Pro fjerner grænsen og gendannes på en ny computer fra den samme Google-konto. Paddle er forhandler (merchant of record); vi ser aldrig kortnumre.

Du behøver ikke et betalt abonnement på claude.ai hos Anthropic. Du skal bare have et login, der kan indlæse samtalen i Chrome. Version 1.16.2 fra september 2026 skriver stadig ikke Word eller Notion. Ændrer listen sig, opdateres denne side samme dag.

FAQ: eksportér Claude-chat til XML

Disse spørgsmål dækker XML-eksport i Download Claude conversations 1.16.2: sammenligning med JSON, masseeksport med Export All, pris, Desktop, PDF og Pro. Hvert svar er et produktfaktum. FAQPage-JSON-LD i sidens head svarer til denne liste.

Er XML bedre end JSON til eksport af Claude-chats?

Ikke generelt. JSON er det mest almindelige valg for udviklere. Eksportér til XML, når systemet, der modtager filen, kræver XML til struktureret dataudveksling. Læsningen af claude.ai er den samme; kun filens form er forskellig.

Kan jeg masseeksportere Claude-chats til XML?

Ja. Det samme Export All-forløb på dashboardet understøtter XML og gemmer én ZIP-fil med en XML-fil pr. chat. På gratisplanen dækker det 3 chats om dagen med Google-login; Pro til 3,99 $ om måneden eller 26,99 $ om året er ubegrænset.

Er XML kun for betalende brugere?

Nej. Eksport af enkelte chats til XML er ubegrænset og kræver ingen konto, ligesom Markdown, tekst, JSON, CSV og PNG. Kun PDF og masseeksport med Export All har en gratisgrænse på 3 om dagen. Pro koster 3,99 $ om måneden eller 26,99 $ om året.

Svarer eksport til XML til Anthropics ZIP-fil?

Nej. Anthropics Export data er en forsinket ZIP-fil med JSON for kontoen. Download Claude conversations skriver med det samme en XML-fil pr. chat (eller pr. udvalg) i Chrome. Det er ikke det samme skema.

Laver eksport til XML en PDF?

Nej. XML er markup. Vil du have sider, så vælg PDF i samme panel; de syv formater er PDF, Markdown, JSON, ren tekst, XML, CSV og PNG. PDF kræver Google-login og tæller med i de 3 om dagen på gratisplanen.

Kan jeg eksportere en Claude-chat til XML i Claude Desktop?

Nej. Chrome-udvidelsen indlæses kun på claude.ai. Claude Desktop viser aldrig XML-menuen. Åbn den samme tråd på claude.ai i Chrome, hvis den findes der.

Skal jeg have Pro for at eksportere en Claude-chat til XML én gang?

Nej. Du behøver slet ingen konto. Eksport af enkelte chats til XML er ubegrænset på gratisplanen. Pro til 3,99 $ om måneden eller 26,99 $ om året løfter kun grænsen på 3 om dagen for masseeksport med Export All og PDF.
