Hvordan eksporterer jeg en Claude-chat til XML?

Åbn samtalen på claude.ai i Chrome, klik på den orange knap ved siden af beskedfeltet, vælg XML, og klik på "Export". Download Claude conversations skriver filen lokalt. Sådan eksporterer du en Claude-chat til XML i version 1.13.0. claude.ai har i september 2026 ingen indbygget knap til at gemme som XML.

  1. Installér Download Claude conversations fra Chrome Web Store (bedømt 5.0).
  2. Genindlæs claude.ai, og åbn en rigtig samtale-URL – ikke den tomme startside med skrivefeltet.
  3. Klik på den orange downloadknap til højre for beskedfeltet.
  4. Vælg XML. Det sidst brugte format huskes.
  5. Klik på "Export". Chrome downloader XML-filen via browserens download-API.

Du skal logge ind med Google, før du eksporterer første gang. Download Claude conversations gemmer den verificerede e-mail for at tælle de 3 gratis eksporter og gendanne Pro efter en geninstallation. Chatteksten indgår ikke i login. Mekanikken: sådan virker det.

Mangler den orange knap, er du ikke på en samtale-URL, fanen skal genindlæses, eller udvidelsen er skjult i Chromes puslespilsmenu. Fastgør Download Claude conversations, og genindlæs claude.ai. XML-eksport vises aldrig i Claude Desktop eller Claude Code.

Én fil eller mange. Den orange knap eksporterer den åbne tråd som XML. Vil du have mange XML-filer, så åbn "View and Download All Conversations" (se og download alle samtaler) og kør "Export All" (eksportér alle) med XML valgt – se masseeksport med Export All.

Hvornår skal jeg eksportere en Claude-chat til XML?

Vælg XML, når det modtagende system, en pipeline eller et ældre værktøj kræver XML til struktureret dataudveksling. De fleste udviklere bør vælge JSON i stedet. Markdown er til noter for mennesker. PNG er et billede. XML findes i menuen, fordi nogle værktøjer stadig indlæser XML og ikke accepterer JSON.

Brug ikke XML som en "mere officiel" JSON. Download Claude conversations læser samtalen på samme måde uanset format. Forskellen er filens form – der dukker ikke ekstra felter op. Hvis intet af det, du bruger, kræver XML, så spring formatet over og brug JSON.

Vi leverer XML, fordi nogle pipelines stadig kræver det – ikke fordi vi mener, det slår JSON til enhver eksport fra claude.ai. Læsningen er den samme: beskeder, afsender, valgfri thinking og artefakter. Vi skriver stadig ikke PDF. Version 1.13.0 har XML som et af fem formater, ikke som et betalt tilvalg.

Hvad bevares, når du eksporterer en Claude-chat til XML?

Download Claude conversations skriver samtalens struktur – beskeder, afsender og tilgængelige metadata – som XML-markup. Thinking-blokke og artefakter følger de samme kontakter som i Markdown og JSON ("include thinking", "include metadata"). XML er ikke en nedbarberet udgave af de formater.

Layout for artefakter er "Original", "Inline" (i teksten), "Nested" (indlejret) eller "Flat" (fladt) i version 1.13.0. Afsenderfilteret kan begrænse XML-filen til "all / human only / assistant only" (alle beskeder, kun mennesket eller kun assistenten). Metadata (titel, tidsstempler, model) kan komme med. Hele listen over kontakter: funktioner i Chrome-udvidelsen.

XML eller JSON, når jeg eksporterer en Claude-chat?

JSON er det almindelige valg for udviklere. Eksportér kun til XML, når et system længere nede i kæden kræver XML. Download Claude conversations gør ikke XML "mere komplet" end JSON. Begge kan indeholde thinking og artefakter. Ingen af dem er Anthropics ZIP-fil for kontoen. Oversigt over formater: formater til eksport af Claude-chats.

Anthropics Settings → Privacy → Export data (menunavnene kan være oversat, hvis claude.ai er sat til dansk) er JSON (i en ZIP-fil), ikke XML. Udskriv → Gem som PDF er et øjebliksbillede af websiden. Ingen af dem erstatter XML-eksporten via den orange knap. Forvent ikke, at denne XML matcher et upubliceret skema fra Anthropic.

Udvidelsen kører kun på claude.ai i Chrome. Claude Desktop og Claude Code får ingen XML-knap. Findes tråden også på claude.ai, så åbn den dér og eksportér den til XML. Claude Codes /export er en helt anden vej i et andet produkt.

Kan jeg eksportere mange Claude-chats til XML på én gang?

Ja. Åbn "View and Download All Conversations", sæt formatet til XML, filtrér tabellen, og klik på Export All. Hver færdig fil er en af de 3 gratis eksporter. Pro til 3,99 $/md. eller 26,99 $/år fjerner loftet for masseeksport til XML.

Oversigtstabellen viser din historik fra claude.ai med søgning på navn og filtrene All, New, Exported og Project (alle, nye, eksporterede, projekt). New betyder, at chatten endnu ikke er eksporteret med Download Claude conversations. Exported holder styr på chats, du allerede har gemt. Project svarer til, hvordan du grupperer chats på claude.ai. Export All giver mange XML-filer, ikke én blandet ZIP-fil.

Kvoten gælder hele kontoen. Tre gratis eksporter i alt – ikke tre XML-filer pr. masseeksport. Vælger du 40 samtaler, bruger du 40 eksporter, hvis alle filer bliver færdige. Planlæg udvalget, eller brug Pro.

Du kan ikke blande XML og JSON i ét klik på Export All. Vælg XML til den kørsel. Kør Export All igen med JSON, hvis du har brug for den samme claude.ai-tråd i begge former; den anden kørsel bruger også af kvoten.

Kræver eksport af en Claude-chat til XML Pro?

Nej. XML indgår i de 3 gratis eksporter, som hver konto med Google-login får, ligesom Markdown, JSON, tekst og PNG. Efter de tre filer koster Pro 3,99 $ om måneden eller 26,99 $ om året via Paddle. Download Claude conversations behandler ikke XML som et format kun for betalende.

De 3 gratis eksporter nulstilles ikke, når du geninstallerer udvidelsen fra Chrome Web Store. Derfor kræves Google-login første gang, du eksporterer. Pro gendannes på en ny computer fra den samme Google-konto. Paddle er forhandler (merchant of record); vi ser aldrig kortnumre.

Du behøver ikke et betalt abonnement på claude.ai hos Anthropic. Du skal bare have et login, der kan indlæse samtalen i Chrome. Version 1.13.0 fra september 2026 skriver stadig ikke PDF, Word eller Notion. Ændrer listen sig, opdateres denne side samme dag.

FAQ: eksportér Claude-chat til XML

Disse spørgsmål dækker XML-eksport i Download Claude conversations 1.13.0: sammenligning med JSON, masseeksport med Export All, kvote, Desktop, PDF og Pro. Hvert svar er et produktfaktum. FAQPage-JSON-LD i sidens head svarer til denne liste.

Er XML bedre end JSON til eksport af Claude-chats?

Ikke generelt. JSON er det mest almindelige valg for udviklere. Eksportér til XML, når systemet, der modtager filen, kræver XML til struktureret dataudveksling. Læsningen af claude.ai er den samme; kun filens form er forskellig.

Kan jeg masseeksportere Claude-chats til XML?

Ja. Det samme Export All-forløb på oversigtssiden understøtter XML. Hver færdig fil tæller som en af de 3 gratis eksporter, medmindre du har Pro til 3,99 $/md. eller 26,99 $/år.

Er XML kun for betalende brugere?

Nej. Alle fem formater, også XML, er dækket af de 3 gratis eksporter, som hver konto med Google-login får. Pro koster 3,99 $/md. eller 26,99 $/år efter de tre filer.

Svarer eksport til XML til Anthropics ZIP-fil?

Nej. Anthropics Export data er en forsinket ZIP-fil med JSON for kontoen. Download Claude conversations skriver med det samme en XML-fil pr. chat (eller pr. udvalg) i Chrome. Det er ikke det samme skema.

Laver eksport til XML en PDF?

Nej. XML er markup. Produktets formater er Markdown, JSON, ren tekst, XML og PNG. Brug Chromes udskriftsdialog, hvis du vil have en side til udskrift. PNG er et billede og heller ikke en PDF.

Kan jeg eksportere en Claude-chat til XML i Claude Desktop?

Nej. Chrome-udvidelsen indlæses kun på claude.ai. Claude Desktop viser aldrig XML-menuen. Åbn den samme tråd på claude.ai i Chrome, hvis den findes der.

Skal jeg have Pro for at eksportere en Claude-chat til XML én gang?

Nej. De første 3 eksporter er gratis i alle formater, også XML. Pro til 3,99 $/md. eller 26,99 $/år fjerner grænsen for flere enkelte eller massevise XML-filer.
