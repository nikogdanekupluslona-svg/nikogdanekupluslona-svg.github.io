Om os

Download Claude conversations er en uafhængig Chrome-udvidelse (webstedets navn: Chat Downloader). Søgemaskiner og brugere kalder den også Claude Chat Downloader og Claude Conversation Downloader. Den er ikke lavet af, tilknyttet eller godkendt af Anthropic, PBC – Claude er Anthropics varemærke. Vi byggede udvidelsen for at udfylde et hul i selve claude.ai: der findes ingen indbygget måde at downloade en enkelt samtale som fil på.

Udvidelsen tilføjer en eksportknap på claude.ai og et dashboard til masseeksport og skriver filer i PDF, Markdown, ren tekst, JSON, XML, CSV eller PNG lokalt i din browser. Eksport af enkelte chats i Markdown, tekst, JSON, XML, CSV og PNG er ubegrænset og kræver ingen konto. PDF og masseeksport som ZIP kræver Google-login og er gratis op til 3 om dagen; Pro (3,99 $/md. eller 26,99 $/år) fjerner den grænse. Udvidelsen virker med almindelige chats, projekter, Cowork-sessioner og Claude Code på nettet (claude.ai/code). Læs mere om, hvordan det virker. Udvidelsen eksporterer ikke terminalsessioner fra Claude Code.

Opslaget i Chrome Web Store (skal holdes synkront)

Denne tekst bruges i Chrome Web Store, så butikkens uddrag matcher det, folk søger efter (teksten står på engelsk, som i butikken):

  • Navn (≤75 tegn): Claude Chat Downloader
  • Kort beskrivelse (≤132 tegn): Free Chrome extension to save claude.ai chats as PDF, Markdown, text, JSON, XML, CSV or PNG — one chat or bulk Export All.
