Hvad er eksport af en Claude Code-samtale i terminalen?

Eksport fra Claude Code er kommandoen /export i en interaktiv CLI-session. Anthropics dokumentation beskriver en menu, hvor du kan kopiere den aktuelle samtale eller gemme en fil i ren tekst, med beskeder og værktøjsoutput gengivet som læsbar tekst. Angiver du et filnavn, springer du menuen over og skriver direkte til filen.

Det er ikke Markdown fra claude.ai, ikke JSON fra denne Chrome-udvidelse og ikke PDF. Det er en gengivet udskrift, som et menneske kan læse. Ifølge Anthropic er JSONL-loggen på disken et andet, internt format til selve produktet – ikke dit offentlige API.

/export

For at springe spørgsmålet over og skrive en navngivet fil i den aktuelle arbejdsmappe:

/export my-session

Anthropics dokumentation om sessioner er kilden til flag og filnavne; de ændrer sig mellem versioner af Claude Code. Betragt blogindlæg fra fællesskabet som sekundære. Hvis teksten i dialogen for /export ikke svarer til det, du ser, kører du en anden version af CLI'en – brug hjælpen i produktet, ikke et skærmbillede fra 2025.

Til scripts henviser Anthropic til andre grænseflader: claude -p med --output-format json eller stream-json, genoptagelse via sessions-id, hooks, der modtager en transcript_path, eller Agent SDK. Det er udviklerflader i Claude Code. De er ikke dette websteds Chrome-udvidelse.

Læsbart vs. struktureret. /export er udskriften til mennesker. JSONL i projects-mappen er loggen. Chrome-udvidelsens JSON er en tredje form, som kun bygges fra en claude.ai-side. Skriv ikke én parser til alle tre.

Hvordan downloader jeg en Claude Code-samtale fra disken?

For at hente en Claude Code-samtale fra disken kopierer du sessionens JSONL-fil fra projects-mappen eller kører /export for en læsbar udskrift. Standardstien på macOS og Linux ligger under ~/.claude/projects/. På Windows er det %USERPROFILE%\.claude\projects. Filnavnene er sessions-id'er.

Projektmappens navn er arbejdsmappen, hvor tegn, der ikke er bogstaver eller tal, er erstattet med bindestreger. Anthropic afkorter meget lange konverterede navne og tilføjer en hash, så mappen holder sig inden for filsystemets grænser. Kan du ikke finde mappen, startede du Claude Code fra en anden arbejdsmappe, end du tror.

Hver JSONL-linje er et JSON-objekt for en besked, et værktøjskald eller metadata. Anthropic oplyser, at formatet er internt og ændrer sig mellem versioner. Scripts, der parser filerne, kan gå i stykker ved en ny udgivelse af Claude Code. Brug hellere /export eller de dokumenterede script-grænseflader, når du har brug for noget stabilt.

Placeringen kan flyttes. CLAUDE_CONFIG_DIR flytter konfigurationstræet væk fra ~/.claude. CLAUDE_CODE_PROJECT_DIR_NAME navngiver projektmappen, når den bruges sammen med den konfigurationsmappe (Claude Code v2.1.234 eller nyere ifølge Anthropic). cleanupPeriodDays i settings.json ændrer standardopbevaringen. Ingen af de indstillinger er funktioner i Download Claude conversations.

Vil du tage backup af Claude Code-samtaler, er vejen derfor: kopiér mappen, eller eksportér udskrifter med /export med faste mellemrum. Dette websted tilføjer ikke en knap til at "importere JSONL". Vi læser ikke din hjemmemappe.

Virker eksport af en Claude Code-samtale med denne udvidelse?

Nej. Eksport fra Claude Code virker ikke med Download Claude conversations. Chrome-udvidelsen indlæses på claude.ai. Den kan ikke se terminalen, ikke køre /export og ikke åbne JSONL. Søgte du efter, hvordan man downloader en Claude Code-samtale, så hold dig til CLI-trinnene på denne side.

Mange lander her, fordi søgemaskiner grupperer "Claude" og "eksport". Udvidelsen i Chrome Web Store gælder stadig kun claude.ai. Installationen placerer ingen orange knap i iTerm, Ghostty, terminalen i VS Code eller Claude Codes desktop-indpakning.

Har du også en parallel tråd på claude.ai om den samme kodeopgave, kan den browserchat gemmes med udvidelsen. De to optegnelser flettes ikke sammen. Værktøjskald, der kun skete i CLI'en, kommer ikke med i web-eksporten, medmindre du har indsat dem dér.

Vi får den samme supportmail hver uge: nogen har installeret Chrome-udvidelsen og forventede, at /export ville dukke op. Vi læser kun claude.ai. Claude Code har allerede /export og JSONL. At pakke CLI'en ind ville være et andet produkt, og det har vi ikke lavet.

Hvor gemmer Claude Code samtalehistorikken?

Claude Code gemmer samtalehistorik som JSONL-udskrifter i konfigurationsmappens projects-mappe. Standard på macOS og Linux: ~/.claude/projects/<encoded-cwd>/<session-id>.jsonl. Windows bruger %USERPROFILE%\.claude\projects. Anthropic kan ændre strukturen; tjek den aktuelle dokumentation om sessioner, hvis en sti mangler på disken.

At genoptage er noget andet end at eksportere. claude --continue og claude --resume genindlæser en session, så du kan arbejde videre. /export skriver en kopi, du kan lægge i git eller sende på mail. Det ene genskaber kontekst. Det andet giver dig en optegnelse at tage med. Anthropics side om sessioner dækker tilladelsestilstand ved genoptagelse, compact/opsummering og vælgerens adfærd – intet af det er denne udvidelse.

Desktop-appen, Claude Code på nettet og VS Code-udvidelsen har ifølge Anthropic hver deres sessionshistorik. Stierne i denne guide gælder CLI'en. Gå ikke ud fra, at en udskrift fra Desktop Cowork ligger i det samme JSONL-træ, som du bruger fra terminalen.

Behandl ikke JSONL som et offentligt skema. Anthropic siger, at linjeformatet ændrer sig. Parser du det alligevel, så lås en version af Claude Code, og forvent, at det går i stykker. /export er den stabile vej til en læsbar Claude Code-samtale.

Miljøvariabler som CLAUDE_CODE_SKIP_PROMPT_HISTORY kan forhindre, at udskrifter skrives. Er projects-mappen tom, så tjek, om du har slået lagring fra, peget CLAUDE_CONFIG_DIR et andet sted hen eller aldrig har kørt en interaktiv session i den mappe.

Hvordan downloader jeg i stedet en Claude-chat på claude.ai?

Sådan downloader du en Claude-chat på claude.ai: installér Download Claude conversations, åbn tråden i Chrome, klik på den orange knap, og vælg Markdown, JSON, tekst, XML eller PNG. Det er browserproduktet. Det er ikke eksport fra Claude Code. Trin for trin: sådan downloader du en Claude-chat.

Hele din historik fra claude.ai som separate filer kræver "Export All" (eksportér alle) på oversigtssiden, ikke /export. Hver fil tæller med i de 3 gratis eksporter, medmindre du har Pro. Guide: masseeksport med Export All. Formater: formater.

Google-login kræves ved den første eksport fra claude.ai, så vi kan tælle kvoten og gendanne Pro. Filerne bygges lokalt. Paddle fakturerer Pro til 3,99 $/md. eller 26,99 $/år. Intet af det gælder /export i terminalen.

Startede dit arbejde i Claude Code, og har du indsat et resumé i claude.ai, så download web-tråden til noter og behold /export som den egentlige CLI-log. To filer er bedre end én forvirret fil.

Eksport af en Claude Code-samtale vs. Anthropics officielle Export data?

Eksport fra Claude Code (/export eller JSONL) er én terminalsession. Den officielle Export data er Settings → Privacy → Export data på claude.ai (menunavnene kan være oversat, hvis claude.ai er sat til dansk): en forsinket ZIP-fil med JSON for Anthropic-kontoen. Det er ikke det samme arkiv. ZIP-filen erstatter ikke /export.

Om en given Claude Code-session kommer med i kontoens ZIP-fil, afhænger af, hvordan Anthropic gemmer det produkt – ikke af denne udvidelse. Betragt ZIP-filen som en backup af webkontoen, medmindre Anthropics aktuelle dokumentation om privatliv siger andet. Vi tilføjer ikke CLI-sessioner til den ZIP-fil.

Hvordan du eksporterer en Claude-chat fra webstedet, inklusive ZIP-filen sammenlignet med udvidelsen, er beskrevet her: sådan eksporterer du en Claude-chat. Udskrift til PDF af en webside gælder ikke en terminal. Se kun udskriv / PDF, når samtalen er i browseren.

Claude Code vs. Desktop vs. eksport fra claude.ai?

Claude Code, Claude Desktop og claude.ai er tre forskellige flader. Eksport fra Claude Code bruger /export og JSONL. Desktop er en app uden udvidelsens orange knap. claude.ai i Chrome er det eneste sted, Download Claude conversations kører. Når navnene blandes sammen, fejler eksporter i stilhed.

Claude Desktop: er chatten synkroniseret til den samme Anthropic-konto, så åbn den på claude.ai og eksportér dér. Findes den kun i Desktop-vinduet, så kopiér og indsæt, eller vent på den officielle Export data. Guide: eksportér en Claude Desktop-chat.

Claude Code-panelet i VS Code ligger tættere på CLI'en end på claude.ai. Forvent ikke, at vores content script indlæses i den webview. Brug /export fra den session, der faktisk indeholder beskederne.

Uafhængig Chrome-udvidelse, ikke tilknyttet Anthropic, PBC. Claude er et varemærke tilhørende Anthropic. Følg deres servicevilkår. Vi kan ikke give juridisk rådgivning om kopiering af værktøjsoutput med proprietær kode; det er et spørgsmål mellem dig, din arbejdsgiver og Anthropic.

FAQ: eksportér Claude Code-samtale

Hvordan eksporterer jeg en Claude Code-samtale?

Skriv /export i Claude Codes terminal (eventuelt med et filnavn) for at gemme en læsbar udskrift, eller kopiér JSONL-filen fra ~/.claude/projects på macOS/Linux eller %USERPROFILE%\.claude\projects på Windows. Anthropics dokumentation om sessioner beskriver den aktuelle dialog.

Downloader denne Chrome-udvidelse Claude Code-chats?

Nej. Download Claude conversations virker kun på claude.ai i Chrome. Den kan ikke læse terminalsessioner, JSONL-udskrifter eller kommandoen /export. Eksport fra Claude Code foregår i CLI'en.

Hvor gemmer Claude Code samtalehistorikken?

Sessionsudskrifter er JSONL-filer under ~/.claude/projects/<encoded-working-directory>/, navngivet efter sessions-id. Den præcise struktur kan ændre sig. Brug /export, når du vil have en læsbar fil i stedet for at parse JSONL. CLAUDE_CONFIG_DIR kan flytte hele mappetræet.

Hvordan downloader jeg en Claude Code-samtale som Markdown?

Claude Codes /export er en udskrift i ren tekst, ikke udvidelsens Markdown. Har du specifikt brug for Markdown, så eksportér en claude.ai-kopi af arbejdet med Download Claude conversations, eller konvertér selv teksten fra /export. Vi konverterer ikke JSONL til Markdown.

Hvordan downloader jeg i stedet en samtale fra claude.ai?

Installér den gratis Chrome-udvidelse, åbn chatten på claude.ai, og brug den orange knap – eller Export All til historikken. Se, hvordan du downloader en Claude-chat. 3 gratis eksporter; Pro koster 3,99 $/md. eller 26,99 $/år.

Er /export det samme som den officielle Export data?

Nej. /export er den aktuelle Claude Code-session. Settings → Privacy → Export data sender en ZIP-fil med JSON for Anthropic-kontoen på mail. Forskellige produkter, forskellige filer, forskellige ventetider.

Kan jeg parse Claude Codes JSONL med jq?

Ja, med det forbehold, Anthropic selv nævner: linjeskemaet er internt og kan ændre sig. Brug hellere /export eller claude -p --output-format json, når du har brug for en fast kontrakt. Lås din CLI-version, hvis du alligevel parser JSONL.

Virker eksport fra Claude Code på Windows?

Ja. /export er en CLI-kommando. Udskrifter på disken ligger under %USERPROFILE%\.claude\projects, medmindre du sætter CLAUDE_CONFIG_DIR. Chrome-udvidelsen kører stadig ikke i den terminal.

Er Claude Code det samme som Claude Desktop?

Nej. Claude Code er kodeagenten i terminalen. Claude Desktop er chat-appen. claude.ai er webstedet. Kun webstedet får denne udvidelse. Noter om eksport fra Desktop: Claude Desktop.

Vil udvidelsen nogensinde understøtte /export?

Ikke i version 1.13.0. Produktet dækker claude.ai: fem formater, lokale filer, Google-login til kvoten. Ændrer det sig, står det på denne side. Indtil da bruger du Anthropics CLI til eksport fra Claude Code.

Indeholder /export output fra værktøjer?

Anthropic beskriver /export som beskeder og værktøjsoutput gengivet som læsbar tekst. Det er deres udskrift, ikke vores parser. Vil du vide præcis, hvad den indeholder nu, så kør /export i din version og læs filen – dokumentationen kan halte en udgivelse bagefter.

Kan jeg masseeksportere Claude Code-sessioner?

Ikke med udvidelsens Export All. Masseeksport på vores oversigtsside gælder kun claude.ai. Til mange CLI-sessioner kopierer du projects-mappen eller kører /export for hver session. Der findes ingen masseeksport af JSONL med den orange knap.
