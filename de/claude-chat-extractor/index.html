Was ist ein Claude Chat Extractor?

Ein Claude Chat Extractor liest den angezeigten claude.ai-Chat aus und schreibt eine echte Datei. Download Claude conversations ist dieses Chrome-Werkzeug: kein Screenshot-Programm und nicht das Konto-ZIP von Anthropic. Ob extrahieren, exportieren oder herunterladen – alle meinen denselben orangefarbenen Button auf claude.ai.

Entwickler und Forschende suchen oft nach einem Extractor, weil „extrahieren“ Struktur verspricht: Absender, Inhaltsblöcke, Codeblöcke, Tabellen, Artefakte. Download Claude conversations liest diese Struktur in dem Tab aus, den Sie bereits geöffnet haben. In Rezensionen heißt das Produkt manchmal Claude Conversation Downloader oder Claude Exporter; gemeint ist trotzdem dieser Chrome-Eintrag: Download Claude conversations 1.16.2 im Chrome Web Store.

Der Extractor ist kein Plugin für Claude Desktop und kein CLI für Claude Code. Wenn Sie den Verlauf aus dem Terminal suchen, nutzen Sie /export – Anleitung: Claude Code Chat exportieren. Wenn Sie die App für Mac oder Windows meinen, siehe Claude Desktop Chat exportieren. Claude Code im Web (claude.ai/code) und Cowork-Sitzungen lassen sich dagegen extrahieren, weil sie sich auf claude.ai öffnen. Diese Seite betrifft nur claude.ai in Chrome.

Derselbe Button, verschiedene Verben. Claude Chat extrahieren, Claude Chat exportieren und Claude Chat herunterladen führen alle zu Download Claude conversations. Die produktbezogene Beschreibung des Exports finden Sie unter Claude Chat exportieren. Diese Anleitung bleibt dabei, was der Extractor liest und was er weglässt.

Wie extrahiere ich einen Claude Chat auf claude.ai?

Installieren Sie Download Claude conversations, öffnen Sie die Unterhaltung auf claude.ai, klicken Sie auf den orangefarbenen Button neben dem Nachrichtenfeld, wählen Sie ein Format und klicken Sie auf „Export“. Der Claude Chat Extractor schreibt die Datei lokal über die Download-Funktion von Chrome. Für Markdown, Text, JSON, XML, CSV oder PNG brauchen Sie kein Konto; die Google-Anmeldung erscheint nur bei PDF und beim Massenexport.

  1. Fügen Sie den Chrome-Eintrag hinzu (Download Claude conversations, Version 1.16.2, Stand September 2026).
  2. Laden Sie claude.ai neu und öffnen Sie den Chat – der Extractor braucht eine Unterhaltung, nicht die leere Startseite mit dem Eingabefeld.
  3. Klicken Sie auf den runden orangefarbenen Button rechts neben dem Nachrichtenfeld.
  4. Stellen Sie „Messages“ (Nachrichten) auf „All“, „Human“ oder „Assistant“ (alle, nur Ihre, nur Claudes), setzen Sie bei Bedarf das Häkchen „Thinking“ (Denkprozess) oder haken Sie mit „Select“ (Auswählen) einzelne Nachrichten an. Wählen Sie PDF, Markdown, JSON, Nur-Text, XML, CSV oder PNG.
  5. Klicken Sie auf „Export“ oder auf „Copy“ (Kopieren), um Markdown, Text, JSON, XML oder CSV in die Zwischenablage zu legen. Der Claude Chat Extractor lädt den Chatinhalt nicht auf unsere Server hoch.

Fehlt der orangefarbene Button, heften Sie die Erweiterung an, laden Sie den Tab neu und prüfen Sie, dass die Adresse ein echter Chat ist. Der Extractor wird nur auf claude.ai eingebunden. Er erscheint nicht in Claude Desktop, nicht im Terminal von Claude Code und nicht auf anderen Websites. Unvollständige Dateien bedeuten meist, dass der lange Chat noch nicht fertig angezeigt war; scrollen oder warten Sie und extrahieren Sie erneut.

Der Extractor merkt sich das zuletzt genutzte Format. Wenn Sie Markdown wollten und JSON bekommen haben, öffnen Sie das Auswahlmenü vor dem Export. Wenn Sie PDF wählen, fragt die Erweiterung nach einer Google-Anmeldung. Nach 3 PDF- oder Massenexporten an einem Tag zeigt der kostenlose Tarif einen Hinweis auf Pro für 3,99 $ im Monat oder 26,99 $ im Jahr – das ist so vorgesehen, kein fehlgeschlagenes Auslesen. Der Zähler beginnt um Mitternacht UTC neu.

Was liest ein Claude Chat Extractor aus?

Der Extractor liest den Nachrichtenbaum, den claude.ai bereits gezeichnet hat: Runden von Mensch und Assistent, Codeblöcke mit Sprachangabe, Tabellen, Links und optional das Denken. Das Artefakt-Layout ist „Original“, „Inline“, „Nested“ (verschachtelt) oder „Flat“ (flach). Beim Kopieren von derselben Seite geht diese Struktur verloren; der Extractor behält sie in Markdown, JSON und XML.

Das Denken ist ein Häkchen. Setzen Sie es, wenn Sie Claudes sichtbare Argumentation in der Datei brauchen; lassen Sie es weg, wenn Sie nur die endgültige Antwort wollen. Metadaten können Titel, Zeitstempel und Modell enthalten. Der Filter „Messages“ („All“, „Human“, „Assistant“), „Thinking“ und „Select“ sitzen im Export-Panel neben dem Format; Tool-/MCP-Schritte und Quellen der Websuche schalten Sie in den Einstellungen zu. Liste der Funktionen: Funktionen.

Der Extractor liest die Unterhaltung, die die Seite in Ihrem claude.ai-Tab bereits angezeigt hat. Codeblöcke, Tabellen und Artefakt-Layouts („Original“, „Inline“, „Nested“, „Flat“) werden dort ausgelesen, dann wird die Datei lokal erzeugt – auch das PDF.

PNG ist die Ausnahme: ein Bild des Chats, keine durchsuchbare Struktur. Nutzen Sie PNG, wenn Sie für ein Ticket oder eine Folie ein optisches Ergebnis brauchen. Nutzen Sie Markdown oder JSON, wenn Sie durchsuchbaren Text brauchen. Weder PNG noch Markdown ist ein PDF; wenn Sie Seiten brauchen, wählen Sie PDF – siehe Claude Chat als PDF.

Der Extractor kann keinen Chat auslesen, den Chrome nie geladen hat. Ein privates Fenster, ein abgemeldeter Tab oder eine Unterhaltung, die nur in Claude Desktop existiert, ergibt keine Datei. Öffnen Sie den Chat angemeldet auf claude.ai und starten Sie dann den Extractor. Ein Export ohne Netz funktioniert erst, nachdem die Seite geladen ist; für das Erzeugen der Datei gibt es trotzdem keinen Umweg über einen Server.

Welche Formate kann der Extractor schreiben?

Sieben: PDF, Markdown, JSON, Nur-Text, XML, CSV und PNG – dieselben sieben, ob Sie einen Claude Chat extrahieren oder Export All starten. Download Claude conversations bietet in 1.16.2 kein Word, kein Notion und kein Google Docs. Die Wahl des Formats entscheidet über die Grenze: Sechs Formate sind unbegrenzt und ohne Konto, jedes PDF verbraucht im kostenlosen Tarif einen von 3 pro Tag.

Kann ich Claude-Unterhaltungen gesammelt extrahieren?

Ja. Öffnen Sie im Pop-up der Erweiterung „View and Download All Conversations“ (alle Unterhaltungen anzeigen und herunterladen), filtern Sie und klicken Sie auf „Export All“ (alle exportieren). Der Extractor schreibt ein ZIP mit einer Datei pro ausgewähltem Chat im gewählten Format. Der Massenexport verlangt eine Google-Anmeldung. Im kostenlosen Tarif verbraucht jeder Chat im ZIP einen von 3 pro Tag, die er sich mit PDF teilt, sofern das Konto nicht Pro für 3,99 $ im Monat oder 26,99 $ im Jahr nutzt.

Filter im Dashboard: „All conversations“, „New“, „Updated“ und „Previously exported“ (alle, neu, aktualisiert, bereits exportiert), dazu die Tabs „Chat“ und „Cowork“ und eine Projektsuche. „New“ heißt: Der Extractor hat diesen Chat noch nicht gespeichert. „Previously exported“ markiert den Verlauf, den Sie bereits extrahiert haben, damit ein späterer Massenexport ihn überspringen kann. Die Projektsuche entspricht der Projektgruppierung auf claude.ai. Die Suche findet Unterhaltungen nach Namen, bevor Sie Export All starten.

Der Massenexport liest nicht schlechter aus. Die Häkchen im Dashboard – „Chats“, „Thinking“, „Metadata“, „Tools“, „Sources“ (Chats, Denkprozess, Metadaten, Tools, Quellen) – und das Artefakt-Layout bestimmen, was in jede Datei kommt, und die Auswahl „Chat format“ (Chat-Format) bietet alle sieben Formate, auch PDF. Anleitung mit Hinweisen zum Kontingent: Alle Claude Chats exportieren. Wenn Sie ein ZIP des gesamten Kontos per E-Mail wollten, ist das Settings → Privacy → Export data (die Bezeichnungen können übersetzt sein, wenn claude.ai auf Deutsch eingestellt ist), nicht dieser Extractor.

Der Massenexport zählt pro Chat. Im kostenlosen Tarif teilt sich Export All 3 pro Tag mit PDF, und jeder Chat im ZIP verbraucht einen davon. Wählen Sie 25 Chats aus, während noch 3 übrig sind, wird der ganze Stapel blockiert, nicht gekürzt. Wählen Sie mit dem Filter „New“ weniger aus, warten Sie auf den Neustart um Mitternacht UTC oder wechseln Sie vor einem großen Durchlauf des Extractors zu Pro (3,99 $ im Monat oder 26,99 $ im Jahr).

Extractor oder Kopieren und Einfügen?

Kopieren und Einfügen reicht für eine kurze Claude-Antwort und scheitert an Code und Tabellen. Export data von Anthropic ist das Konto-Backup als ZIP. Der Claude Chat Extractor liegt dazwischen: dieser Chat oder eine Auswahl vieler Chats, strukturierte Datei, sofort, auf claude.ai in Chrome.

Drucken ist kein Extractor. Es erfasst die Webseite, samt Bedienelementen, die Sie in einer Notizdatei nicht wollen. Der Claude Chat Extractor entfernt diese Elemente und behält die Struktur der Nachrichten. Wenn Sie ein PDF brauchen, wählen Sie PDF im selben Panel; die Erweiterung erzeugt es im Browser, ohne Druckdialog. Wenn Sie Text in der Zwischenablage brauchen, kopiert der Button „Copy“ im Panel Markdown, Text, JSON, XML oder CSV statt des rohen Seitentexts.

Ist ein Claude Chat Extractor sicher?

Dieser Extractor nutzt Ihre bestehende claude.ai-Sitzung genauso wie die Website. Er automatisiert das Konto nicht und sendet keine Chatinhalte an unsere API. Nach einer Google-Anmeldung fragt die Erweiterung nur bei PDF, Massenexport und Pro, um das Tageskontingent zu zählen und Pro wiederherzustellen. Paddle wickelt die Zahlung ab. Wir sind nicht Anthropic; deren Nutzungsbedingungen gelten weiterhin.

Nachdem Sie sich für PDF, Massenexport oder Pro angemeldet haben, sieht ein Cloudflare-Worker Ihre Google-E-Mail-Adresse, die heutige Zahl der PDF- und Massenexporte und ob Pro aktiv ist. Exporte einzelner Chats als Markdown, JSON, Text, XML, CSV und PNG senden ihm nichts, und eine extrahierte Datei erhält er nie, auch kein PDF. Die Dateien verlassen den Browser nur in Richtung Download-Ordner von Chrome. Die vollständige Abgrenzung: So funktioniert es. Wer fragt, ob ein Claude Chat Extractor sicher ist, sollte sich diese Trennung ansehen – Abrechnung im Worker, Chat im Tab.

„Kein Netzwerkverkehr“ können wir nicht versprechen. claude.ai, Google und der Worker gibt es alle. Wir können sagen, dass Chatinhalte nicht zu uns hochgeladen werden. Halten Sie sich an die Nutzungsbedingungen von Anthropic. Download Claude conversations ist eine unabhängige Chrome-Erweiterung, kein offizielles Anthropic-Produkt. Die Support-Adresse steht in der Fußzeile der Website.

Mobile Browser und Claude Desktop werden nicht unterstützt. Ein Extractor, der als Chrome-Content-Script läuft, kann dort nicht laufen. Erwarten Sie im September 2026 keinen Eintrag für Safari oder Firefox. Nutzen Sie Chrome am Desktop auf claude.ai. Was ist ein Claude Chat Extractor?

Ist „Claude Chat extrahieren“ etwas anderes als „Claude Chat exportieren“?

Kann ich einen Claude Chat ohne Installation extrahieren?

Nur durch Kopieren und Einfügen, wobei Codeblöcke und Tabellen verloren gehen, oder über Export data von Anthropic, ein ZIP des Kontos. Ein strukturierter Claude Chat Extractor muss die Seite lesen; das ist die Chrome-Erweiterung.

Brauche ich Claude Pro, um einen Chat zu extrahieren?

Nein. Jeder claude.ai-Tarif, der den Chat in Chrome öffnen kann, funktioniert. Läuft der Claude Chat Extractor in Desktop?

Nein. Claude Desktop bekommt den orangefarbenen Button nie. Öffnen Sie denselben Chat auf claude.ai, falls er synchronisiert ist, oder kopieren Sie ihn bzw. nutzen Sie das offizielle ZIP. Der Extractor läuft nur in Chrome auf claude.ai.

Nur im Web. Claude-Code-Sitzungen unter claude.ai/code öffnen sich auf claude.ai und lassen sich wie jeder Chat extrahieren.
