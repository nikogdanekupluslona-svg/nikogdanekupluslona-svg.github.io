Was ist ein Claude Chat Extractor?

Ein Claude Chat Extractor liest den angezeigten claude.ai-Chat aus und schreibt eine echte Datei. Download Claude conversations ist dieses Chrome-Werkzeug: kein Screenshot-Programm und nicht das Konto-ZIP von Anthropic. Ob extrahieren, exportieren oder herunterladen – alle meinen denselben orangefarbenen Button auf claude.ai.

Entwickler und Forschende suchen oft nach einem Extractor, weil „extrahieren“ Struktur verspricht: Absender, Inhaltsblöcke, Codeblöcke, Tabellen, Artefakte. Download Claude conversations liest diese Struktur in dem Tab aus, den Sie bereits geöffnet haben. In Rezensionen heißt das Produkt manchmal Claude Conversation Downloader oder Claude Exporter; gemeint ist trotzdem dieser Chrome-Eintrag, mit 5,0 im Chrome Web Store bewertet.

Der Extractor ist kein Plugin für Claude Desktop und kein CLI für Claude Code. Wenn Sie den Verlauf aus dem Terminal suchen, nutzen Sie /export – Anleitung: Claude Code Chat exportieren. Wenn Sie die App für Mac oder Windows meinen, siehe Claude Desktop Chat exportieren. Diese Seite betrifft nur claude.ai in Chrome.

Derselbe Button, verschiedene Verben. Claude Chat extrahieren, Claude Chat exportieren und Claude Chat herunterladen führen alle zu Download Claude conversations. Die produktbezogene Beschreibung des Exports finden Sie unter Claude Chat exportieren. Diese Anleitung bleibt dabei, was der Extractor liest und was er weglässt.

Wie extrahiere ich einen Claude Chat auf claude.ai?

Installieren Sie Download Claude conversations, öffnen Sie die Unterhaltung auf claude.ai, klicken Sie auf den orangefarbenen Button neben dem Nachrichtenfeld, wählen Sie ein Format und klicken Sie auf „Export“. Der Claude Chat Extractor schreibt die Datei lokal über die Download-Funktion von Chrome. Die Google-Anmeldung erfolgt einmal vor der ersten Extraktion, um die 3 kostenlosen Exporte zu zählen.

  1. Fügen Sie den Chrome-Eintrag hinzu (Download Claude conversations, Version 1.13.0, Stand September 2026).
  2. Laden Sie claude.ai neu und öffnen Sie den Chat – der Extractor braucht eine Unterhaltung, nicht die leere Startseite mit dem Eingabefeld.
  3. Klicken Sie auf den orangefarbenen Button rechts neben dem Nachrichtenfeld.
  4. Wählen Sie Markdown, JSON, Nur-Text, XML oder PNG.
  5. Klicken Sie auf „Export“. Der Claude Chat Extractor lädt den Chatinhalt nicht auf unsere Server hoch.

Fehlt der orangefarbene Button, heften Sie die Erweiterung an, laden Sie den Tab neu und prüfen Sie, dass die Adresse ein echter Chat ist. Der Extractor wird nur auf claude.ai eingebunden. Er erscheint nicht in Claude Desktop, nicht in Claude Code und nicht auf anderen Websites. Unvollständige Dateien bedeuten meist, dass der lange Chat noch nicht fertig angezeigt war; scrollen oder warten Sie und extrahieren Sie erneut.

Der Extractor merkt sich das zuletzt genutzte Format. Wenn Sie Markdown wollten und JSON bekommen haben, öffnen Sie das Auswahlmenü vor dem Export. Wenn die Grenze von 3 Exporten erreicht ist, erscheint ein Hinweis auf Pro für 3,99 $/Monat oder 26,99 $/Jahr – das ist so vorgesehen, kein fehlgeschlagenes Auslesen. Die Google-Anmeldung beim ersten Extrahieren ist nötig, damit eine Neuinstallation den kostenlosen Zähler nicht zurücksetzt.

Nutzen Sie Anleitung: Claude Chat exportieren. Diese Seite geht davon aus, dass Sie eine strukturierte Datei des geöffneten Chats wollen.

Was liest ein Claude Chat Extractor aus?

Der Extractor liest den Nachrichtenbaum, den claude.ai bereits gezeichnet hat: Runden von Mensch und Assistent, Codeblöcke mit Sprachangabe, Tabellen, Links und optional das Denken. Das Artefakt-Layout ist „Original“, „Inline“, „Nested“ (verschachtelt) oder „Flat“ (flach). Beim Kopieren von derselben Seite geht diese Struktur verloren; der Extractor behält sie in Markdown, JSON und XML.

Denkblöcke sind ein Schalter („include thinking“). Schalten Sie ihn ein, wenn Sie Claudes sichtbare Argumentation in der Datei brauchen; lassen Sie ihn aus, wenn Sie nur die endgültige Antwort wollen. Metadaten können Titel, Zeitstempel und Modell enthalten („include metadata“). Der Absenderfilter behält alle Nachrichten, nur Mensch oder nur Assistent („all / human only / assistant only“). Diese Optionen sitzen im selben Widget wie das Format. Liste der Funktionen: Funktionen.

Der Extractor liest die Unterhaltung, die die Seite in Ihrem claude.ai-Tab bereits angezeigt hat. Codeblöcke, Tabellen und Artefakt-Layouts („Original“, „Inline“, „Nested“, „Flat“) werden dort ausgelesen, dann wird die Datei lokal erzeugt. PDF bieten wir nicht an.

Das Team von Download Claude conversations

PNG ist die Ausnahme: ein Bild des Chats, keine durchsuchbare Struktur. Nutzen Sie PNG, wenn Sie für ein Ticket oder eine Folie ein optisches Ergebnis brauchen. Nutzen Sie Markdown oder JSON, wenn Sie durchsuchbaren Text brauchen. Weder PNG noch Markdown ist ein PDF; Drucken bleibt der PDF-ähnliche Umweg, siehe Drucken / PDF.

Der Extractor kann keinen Chat auslesen, den Chrome nie geladen hat. Ein privates Fenster, ein abgemeldeter Tab oder eine Unterhaltung, die nur in Claude Desktop existiert, ergibt keine Datei. Öffnen Sie den Chat angemeldet auf claude.ai und starten Sie dann den Extractor. Ein Export ohne Netz funktioniert erst, nachdem die Seite geladen ist; für das Erzeugen der Datei gibt es trotzdem keinen Umweg über einen Server.

Welche Formate kann der Extractor schreiben?

Markdown, JSON, Nur-Text, XML und PNG – dieselben fünf, ob Sie einen Claude Chat extrahieren oder Export All starten. Download Claude conversations bietet in 1.13.0 kein Word, kein Notion und kein natives PDF. Die Wahl des Formats ändert nichts am Kontingent von 3 Exporten; jede fertige Datei zählt als eine Extraktion.

Kann ich Claude-Unterhaltungen gesammelt extrahieren?

Ja. Öffnen Sie „View and Download All Conversations“ (alle Unterhaltungen anzeigen und herunterladen), filtern Sie und klicken Sie auf „Export All“ (alle exportieren). Der Extractor schreibt eine Datei pro ausgewähltem Chat. Jede Datei verbraucht einen der 3 kostenlosen Exporte, sofern das Konto nicht Pro für 3,99 $/Monat oder 26,99 $/Jahr nutzt.

Filter auf der Übersichtsseite: Alle, Neu, Exportiert und Projekt. Neu heißt: Der Extractor hat diesen Chat noch nicht gespeichert. Exportiert markiert den Verlauf, den Sie bereits extrahiert haben, damit ein späterer Massenexport ihn überspringen kann. Projekt entspricht der Projektgruppierung auf claude.ai. Die Suche findet Unterhaltungen nach Namen, bevor Sie Export All starten.

Der Massenexport liest nicht schlechter aus. Denken, Metadaten, Artefakt-Layout und Absenderoptionen entsprechen dem Widget für einzelne Chats. Anleitung mit Hinweisen zum Kontingent: Alle Claude Chats exportieren. Wenn Sie ein ZIP des gesamten Kontos per E-Mail wollten, ist das Settings → Privacy → Export data (die Bezeichnungen können übersetzt sein, wenn claude.ai auf Deutsch eingestellt ist), nicht dieser Extractor.

Insgesamt drei kostenlose Extraktionen. Export All bekommt kein eigenes Kontingent. Wenn Sie 25 Chats auswählen, verbrauchen Sie 25 Exporte, sofern jede Datei fertig wird. Nutzen Sie die Filter Neu/Projekt oder wechseln Sie vor einem großen Durchlauf des Extractors zu Pro (3,99 $/Monat oder 26,99 $/Jahr).

Extractor oder Kopieren und Einfügen?

Kopieren und Einfügen reicht für eine kurze Claude-Antwort und scheitert an Code und Tabellen. Export data von Anthropic ist das Konto-Backup als ZIP. Der Claude Chat Extractor liegt dazwischen: dieser Chat oder eine Auswahl vieler Chats, strukturierte Datei, sofort, auf claude.ai in Chrome.

Drucken ist kein Extractor. Es erfasst die Webseite, samt Bedienelementen, die Sie in einer Notizdatei nicht wollen. Der Claude Chat Extractor entfernt diese Elemente und behält die Struktur der Nachrichten. Wenn Sie nach dem Extrahieren von Markdown trotzdem ein PDF brauchen, konvertieren Sie die .md-Datei selbst; das Widget erzeugt kein PDF.

Ist ein Claude Chat Extractor sicher?

Dieser Extractor nutzt Ihre bestehende claude.ai-Sitzung genauso wie die Website. Er automatisiert das Konto nicht und sendet keine Chatinhalte an unsere API. Die Google-Anmeldung zählt die 3 kostenlosen Exporte und stellt Pro wieder her. Paddle wickelt die Zahlung ab. Wir sind nicht Anthropic; deren Nutzungsbedingungen gelten weiterhin.

Ein Cloudflare-Worker sieht den Abo-Status: Zahl der kostenlosen Exporte und ob Pro aktiv ist. Er erhält weder das extrahierte Markdown noch JSON, Text, XML oder PNG. Die Dateien verlassen den Browser nur in Richtung Download-Ordner von Chrome. Die vollständige Abgrenzung: So funktioniert es. Wer fragt, ob ein Claude Chat Extractor sicher ist, sollte sich diese Trennung ansehen – Abrechnung im Worker, Chat im Tab.

„Kein Netzwerkverkehr“ können wir nicht versprechen. claude.ai, Google und der Worker gibt es alle. Wir können sagen, dass Chatinhalte nicht zu uns hochgeladen werden. Halten Sie sich an die Nutzungsbedingungen von Anthropic. Download Claude conversations ist eine unabhängige Chrome-Erweiterung, kein offizielles Anthropic-Produkt. Die Support-Adresse steht in der Fußzeile der Website.

Mobile Browser und Claude Desktop werden nicht unterstützt. Ein Extractor, der als Chrome-Content-Script läuft, kann dort nicht laufen. Erwarten Sie im September 2026 keinen Eintrag für Safari oder Firefox. Nutzen Sie Chrome am Desktop auf claude.ai. Unternehmensrichtlinien, die Erweiterungen blockieren, blockieren auch diesen Extractor.

FAQ: Claude Chat Extractor

Diese Fragen behandeln den Claude Chat Extractor und das Extrahieren von Claude Chats: Massenexport mit Export All, Desktop, Claude Code, PDF, Google-Anmeldung und das Kontingent von 3 Exporten. Die Antworten beziehen sich auf Version 1.13.0 auf claude.ai. Das FAQPage-Schema im Kopf des Dokuments entspricht dieser Liste.

Was ist ein Claude Chat Extractor?

Ein Werkzeug, das eine geöffnete claude.ai-Unterhaltung liest und Markdown, JSON, Nur-Text, XML oder PNG schreibt. Download Claude conversations fügt den orangefarbenen Button hinzu, der dieses Auslesen lokal in Chrome erledigt.

Ist „Claude Chat extrahieren“ etwas anderes als „Claude Chat exportieren“?

Nein – dieselbe Aufgabe, anderes Verb. Extrahieren, exportieren und herunterladen führen alle zum selben orangefarbenen Button und denselben fünf Formaten auf claude.ai. Diese Seite betont, was der Parser erhält.

Kann ich einen Claude Chat ohne Installation extrahieren?

Nur durch Kopieren und Einfügen, wobei Codeblöcke und Tabellen verloren gehen, oder über Export data von Anthropic, ein ZIP des Kontos. Ein strukturierter Claude Chat Extractor muss die Seite lesen; das ist die Chrome-Erweiterung.

Kann der Extractor viele Unterhaltungen auf einmal extrahieren?

Ja. „View and Download All Conversations“ öffnen, dann „Export All“. Jede Datei zählt zu den 3 kostenlosen Exporten. Pro für 3,99 $/Monat oder 26,99 $/Jahr hebt die Grenze auf. Filter: Alle, Neu, Exportiert, Projekt.

Ist ein Claude Chat Extractor sicher?

Dieser liest die angemeldete claude.ai-Sitzung und erzeugt die Dateien lokal. Gesprächstext wird nicht an unsere Server gesendet. Wir sind nicht Anthropic; für Sie gelten weiterhin deren Nutzungsbedingungen.

Brauche ich Claude Pro, um einen Chat zu extrahieren?

Nein. Jeder claude.ai-Tarif, der den Chat in Chrome öffnen kann, funktioniert. Die ersten 3 Dateien aus dem Claude Chat Extractor sind bei uns kostenlos. Der kostenpflichtige Tarif von Anthropic hat mit unserem Kontingent von 3 Exporten nichts zu tun.

Läuft der Claude Chat Extractor in Desktop?

Nein. Claude Desktop bekommt den orangefarbenen Button nie. Öffnen Sie denselben Chat auf claude.ai, falls er synchronisiert ist, oder kopieren Sie ihn bzw. nutzen Sie das offizielle ZIP. Der Extractor läuft nur in Chrome auf claude.ai.

Kann ein Claude Chat Extractor PDF schreiben?

Nein. Die Formate sind Markdown, JSON, Nur-Text, XML und PNG. Drucken Sie die claude.ai-Seite, wenn Sie eine PDF-ähnliche Momentaufnahme brauchen. PNG ist ein Bild, kein PDF.

Funktioniert das Extrahieren in Claude Code?

Nein. Claude Code nutzt /export oder JSONL auf der Festplatte. Dieser Claude Chat Extractor ist ein Chrome-Content-Script für claude.ai, keine Anbindung an das Terminal.

Wie viele kostenlose Extraktionen erlaubt der Extractor?

Drei pro mit Google angemeldetem Konto, gemeinsam mit Export All. Eine Neuinstallation setzt den Zähler nicht zurück. Pro wird über dasselbe Google-Konto wiederhergestellt; abgerechnet wird über Paddle.

Was lässt der Claude Chat Extractor weg?

Bedienelemente der Seite, das Eingabefeld und alles, was in der Unterhaltung nicht angezeigt wird. Er überspringt auch Chats, die nie in Chrome geladen wurden. Chats, die nur in Claude Desktop existieren, und JSONL aus Claude Code gehören nicht dazu.
