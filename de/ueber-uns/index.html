Über uns

Download Claude conversations ist eine unabhängige Chrome-Erweiterung (Name der Website: Chat Downloader). Suchmaschinen und Nutzer nennen sie auch Claude Chat Downloader und Claude Conversation Downloader. Sie wird nicht von Anthropic, PBC entwickelt, ist nicht mit Anthropic verbunden und wird nicht von Anthropic unterstützt – Claude ist eine Marke von Anthropic. Wir haben sie gebaut, um eine Lücke in claude.ai zu schließen: Es gibt keinen eingebauten Weg, eine einzelne Unterhaltung als Datei herunterzuladen.

Die Erweiterung fügt claude.ai einen Export-Button und ein Dashboard für Massenexporte hinzu und schreibt PDF, Markdown, reinen Text, JSON, XML, CSV oder PNG lokal in Ihrem Browser. Exporte einzelner Chats als Markdown, Text, JSON, XML, CSV und PNG sind unbegrenzt und brauchen kein Konto. PDF- und ZIP-Massenexporte erfordern eine Google-Anmeldung und sind bis zu 3-mal pro Tag kostenlos; Pro (3,99 $/Monat oder 26,99 $/Jahr) hebt diese Grenze auf. Die Erweiterung funktioniert mit normalen Chats, Projekten, Cowork-Sitzungen und Claude Code im Web (claude.ai/code). Details unter So funktioniert es. Terminal-Sitzungen von Claude Code exportiert sie nicht.
