Wie exportiere ich einen Claude Chat als XML?

Öffnen Sie die Unterhaltung auf claude.ai in Chrome, klicken Sie auf den orangefarbenen Button neben dem Eingabefeld, wählen Sie XML und klicken Sie auf „Export“. Download Claude conversations schreibt die Datei lokal. So exportieren Sie in Version 1.16.2 einen Claude Chat als XML. Eine eingebaute Funktion „als XML speichern“ hat claude.ai im September 2026 nicht.

  1. Installieren Sie Download Claude conversations aus dem Chrome Web Store.
  2. Laden Sie claude.ai neu und öffnen Sie eine echte Unterhaltung, nicht die leere Startseite mit dem Eingabefeld.
  3. Klicken Sie auf den orangefarbenen Download-Button rechts neben dem Eingabefeld.
  4. Wählen Sie XML. Das zuletzt genutzte Format wird gespeichert. Mit „Select“ (Auswählen) haken Sie nur die Nachrichten an, die Sie brauchen.
  5. Klicken Sie auf „Export“. Chrome lädt das XML über die Download-Schnittstelle des Browsers herunter. Oder klicken Sie auf „Copy“ (Kopieren), um das XML in die Zwischenablage zu legen.

Um einen Claude Chat als XML zu exportieren, ist keine Anmeldung nötig. Einzelexporte als XML sind unbegrenzt, anonym und senden nichts an unsere Server. Eine Google-Anmeldung wird nur für PDF und den Massenexport mit Export All verlangt. Technik: So funktioniert es.

Wann lohnt sich XML?

Exportieren Sie einen Claude Chat als XML, wenn das empfangende System, die Pipeline oder ein älteres Werkzeug XML für den strukturierten Datenaustausch verlangt. Die meisten Entwickler sollten stattdessen JSON nehmen. Markdown ist für Notizen von Menschen, CSV für Tabellenkalkulationen, PNG ist ein Bild. XML steht im Menü, weil manche Werkzeuge weiterhin XML einlesen und JSON nicht akzeptieren.

Nehmen Sie XML nicht als „offizielleres“ JSON. Download Claude conversations liest den Chat in beiden Fällen gleich aus. Der Unterschied ist die Dateiform, nicht zusätzliche Felder, die plötzlich auftauchen. Verlangt keines Ihrer Werkzeuge XML, überspringen Sie dieses Format und nutzen JSON.

Wir liefern XML, weil manche Pipelines es noch verlangen – nicht, weil wir es für jeden claude.ai-Export besser als JSON halten. Das Auslesen ist dasselbe: Nachrichten, Absender, optional Denkschritte und Artefakte. In Version 1.16.2 bleibt XML eines von sieben Formaten, kostenlos und ohne Konto – keine kostenpflichtige Erweiterung.

Was bleibt beim XML-Export erhalten?

Wenn Sie einen Claude Chat als XML exportieren, schreibt Download Claude conversations die Struktur der Unterhaltung – Nachrichten, Absender und verfügbare Metadaten – als XML-Auszeichnung. Denkschritte, Quellen der Websuche, Tool-/MCP-Schritte und Artefakte folgen denselben Optionen wie bei Markdown und JSON: „Thinking“ (Denkprozess) ist ein Häkchen im Export-Panel, Tools und Quellen schalten Sie in den Einstellungen ein. XML ist keine abgespeckte Variante dieser Formate.

Das Artefakt-Layout ist in Version 1.16.2 „Original“, „Inline“, „Nested“ oder „Flat“ (original, eingebettet, verschachtelt, flach). Der Absenderfilter „all / human only / assistant only“ (alle / nur Mensch / nur Assistent) begrenzt das XML auf alle Nachrichten, nur Ihre oder nur Claudes. Metadaten (Titel, Zeitstempel, Modell) können mit hinein. Alle Schalter: Funktionen der Chrome-Erweiterung.

XML oder JSON beim Claude-Export?

JSON ist die übliche Wahl für Entwickler. Exportieren Sie einen Claude Chat nur dann als XML, wenn ein nachgelagertes System XML verlangt. Download Claude conversations macht XML nicht „vollständiger“ als JSON. Beide können Denkschritte und Artefakte enthalten. Keines ist das Konto-ZIP von Anthropic. Kann ich viele Chats auf einmal als XML exportieren?

Ja. Öffnen Sie „View and Download All Conversations“, stellen Sie „Chat format“ (Chat-Format) auf XML, filtern Sie die Tabelle und klicken Sie auf „Export All“. Chrome speichert ein ZIP mit einer XML-Datei pro Chat. Im kostenlosen Tarif sind das 3 Chats pro Tag mit Google-Anmeldung, gemeinsam mit PDF. Pro für 3,99 $ im Monat oder 26,99 $ im Jahr hebt diese Grenze für den Massenexport als XML auf.

Das Dashboard listet Ihren claude.ai-Verlauf mit Namenssuche, den Filtern „All conversations“, „New“, „Updated“ und „Previously exported“ (alle Unterhaltungen, neu, aktualisiert, bereits exportiert), den Tabs „Chat“ und „Cowork“ und einer Projektsuche. „New“ heißt: noch nicht mit Download Claude conversations exportiert. „Previously exported“ markiert bereits gespeicherte Chats. Export All ergibt ein ZIP mit einer XML-Datei pro Chat, kein Archiv mit gemischten Formaten.

Das Tageslimit gilt pro Konto. Drei Chats pro Tag im kostenlosen Tarif, gemeinsam mit PDF. Wählen Sie 40 Unterhaltungen aus, obwohl nur noch 3 übrig sind, wird der ganze Stapel blockiert, nicht gekürzt. Wählen Sie weniger aus oder nutzen Sie Pro. Einzelne XML-Exporte über den orangefarbenen Button bleiben unbegrenzt.

XML und JSON lassen sich in einem Klick auf „Export All“ nicht mischen. Wählen Sie für diesen Durchlauf XML. Brauchen Sie denselben claude.ai-Chat in beiden Formen, starten Sie Export All mit JSON erneut; der zweite Durchlauf zählt jeden Chat erneut.

Ist XML besser als JSON für den Export von Claude Chats?

Im Allgemeinen nicht. JSON ist unter Entwicklern die üblichere Wahl. Exportieren Sie einen Claude Chat als XML, wenn Ihr nachgelagertes System XML für den strukturierten Datenaustausch verlangt. Das Auslesen von claude.ai ist dasselbe; nur die Dateiform unterscheidet sich.

Kann ich viele Claude Chats auf einmal als XML exportieren?

Ja. Derselbe Ablauf mit Export All im Dashboard unterstützt XML und speichert ein ZIP mit einer XML-Datei pro Chat. Im kostenlosen Tarif deckt das 3 Chats pro Tag mit Google-Anmeldung ab; mit Pro für 3,99 $ im Monat oder 26,99 $ im Jahr ist es unbegrenzt.

Ist XML nur mit Pro verfügbar?

Nein. XML-Exporte einzelner Chats sind unbegrenzt und brauchen kein Konto, wie Markdown, Text, JSON, CSV und PNG. Nur PDF und der Massenexport mit Export All haben ein kostenloses Limit von 3 pro Tag. Pro kostet 3,99 $ im Monat oder 26,99 $ im Jahr.

Entspricht der XML-Export dem ZIP von Anthropic?

Nein. Der Datenexport von Anthropic ist ein verzögertes JSON-ZIP des Kontos. Download Claude conversations schreibt sofort in Chrome eine XML-Datei pro Chat (oder pro Auswahl). Das Schema ist nicht dasselbe.

Erzeugt der XML-Export ein PDF?

Nein. XML ist Auszeichnung. Für Seiten wählen Sie im selben Panel PDF; die sieben Formate sind PDF, Markdown, JSON, reiner Text, XML, CSV und PNG. PDF erfordert eine Google-Anmeldung und zählt im kostenlosen Tarif zu den 3 pro Tag.

Kann ich in Claude Desktop als XML exportieren?

Nein. Die Chrome-Erweiterung läuft nur auf claude.ai. Claude Desktop zeigt das XML-Menü nie. Öffnen Sie denselben Chat auf claude.ai in Chrome, falls er dort existiert.

Brauche ich Pro für einen einzelnen XML-Export?

Nein. Sie brauchen überhaupt kein Konto. XML-Exporte einzelner Chats sind im kostenlosen Tarif unbegrenzt. Pro für 3,99 $ im Monat oder 26,99 $ im Jahr hebt nur das Limit von 3 pro Tag für den Massenexport mit Export All und für PDF auf.
