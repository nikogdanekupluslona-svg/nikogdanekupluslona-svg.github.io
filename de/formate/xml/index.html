Wie exportiere ich einen Claude Chat als XML?

Öffnen Sie die Unterhaltung auf claude.ai in Chrome, klicken Sie auf den orangefarbenen Button neben dem Eingabefeld, wählen Sie XML und klicken Sie auf „Export“. Download Claude conversations schreibt die Datei lokal. So exportieren Sie in Version 1.13.0 einen Claude Chat als XML. Eine eingebaute Funktion „als XML speichern“ hat claude.ai im September 2026 nicht.

  1. Installieren Sie Download Claude conversations aus dem Chrome Web Store (Bewertung 5,0).
  2. Laden Sie claude.ai neu und öffnen Sie eine echte Unterhaltung, nicht die leere Startseite mit dem Eingabefeld.
  3. Klicken Sie auf den orangefarbenen Download-Button rechts neben dem Eingabefeld.
  4. Wählen Sie XML. Das zuletzt genutzte Format wird gespeichert.
  5. Klicken Sie auf „Export“. Chrome lädt das XML über die Download-Schnittstelle des Browsers herunter.

Vor dem ersten XML-Export ist eine Google-Anmeldung nötig. Download Claude conversations speichert die bestätigte E-Mail-Adresse, um die 3 kostenlosen Exporte zu zählen und Pro nach einer Neuinstallation wiederherzustellen. Chat-Text ist nicht Teil dieser Anmeldung. Technik: So funktioniert es.

Fehlt der orangefarbene Button, sind Sie nicht in einer Unterhaltung, der Tab braucht einen Neuladen, oder die Erweiterung steckt im Puzzle-Menü von Chrome. Pinnen Sie Download Claude conversations und laden Sie claude.ai neu. In Claude Desktop oder Claude Code erscheint der XML-Export nie.

Eine Datei oder viele. Der orangefarbene Button exportiert den offenen Chat als XML. Für viele XML-Dateien öffnen Sie „View and Download All Conversations“ (alle Unterhaltungen ansehen und herunterladen) und starten „Export All“ (alles exportieren) mit XML – siehe Massenexport mit Export All.

Wann lohnt sich XML?

Exportieren Sie einen Claude Chat als XML, wenn das empfangende System, die Pipeline oder ein älteres Werkzeug XML für den strukturierten Datenaustausch verlangt. Die meisten Entwickler sollten stattdessen JSON nehmen. Markdown ist für Notizen von Menschen, PNG ist ein Bild. XML steht im Menü, weil manche Werkzeuge weiterhin XML einlesen und JSON nicht akzeptieren.

Nehmen Sie XML nicht als „offizielleres“ JSON. Download Claude conversations liest den Chat in beiden Fällen gleich aus. Der Unterschied ist die Dateiform, nicht zusätzliche Felder, die plötzlich auftauchen. Verlangt keines Ihrer Werkzeuge XML, überspringen Sie dieses Format und nutzen JSON.

Wir liefern XML, weil manche Pipelines es noch verlangen – nicht, weil wir es für jeden claude.ai-Export besser als JSON halten. Das Auslesen ist dasselbe: Nachrichten, Absender, optional Denkschritte und Artefakte. PDF erzeugen wir weiterhin nicht. In Version 1.13.0 bleibt XML eines von fünf Formaten, keine kostenpflichtige Erweiterung.

Was bleibt beim XML-Export erhalten?

Wenn Sie einen Claude Chat als XML exportieren, schreibt Download Claude conversations die Struktur der Unterhaltung – Nachrichten, Absender und verfügbare Metadaten – als XML-Auszeichnung. Denkschritte und Artefakte folgen denselben Schaltern wie bei Markdown und JSON. XML ist keine abgespeckte Variante dieser Formate.

Das Artefakt-Layout ist in Version 1.13.0 „Original“, „Inline“, „Nested“ oder „Flat“ (original, eingebettet, verschachtelt, flach). Der Absenderfilter „all / human only / assistant only“ (alle / nur Mensch / nur Assistent) begrenzt das XML auf alle Nachrichten, nur Ihre oder nur Claudes. Metadaten (Titel, Zeitstempel, Modell) können mit hinein. Alle Schalter: Funktionen der Chrome-Erweiterung.

XML oder JSON beim Claude-Export?

JSON ist die übliche Wahl für Entwickler. Exportieren Sie einen Claude Chat nur dann als XML, wenn ein nachgelagertes System XML verlangt. Download Claude conversations macht XML nicht „vollständiger“ als JSON. Beide können Denkschritte und Artefakte enthalten. Keines ist das Konto-ZIP von Anthropic. Kann ich viele Chats auf einmal als XML exportieren?

Ja. Öffnen Sie „View and Download All Conversations“, stellen Sie das Format auf XML, filtern Sie die Tabelle und klicken Sie auf „Export All“. Jede fertige Datei ist einer der 3 kostenlosen Exporte. Pro für 3,99 $/Monat oder 26,99 $/Jahr hebt die Grenze für den Massenexport als XML auf.

Die Tabelle listet Ihren claude.ai-Verlauf mit Namenssuche und den Filtern „All“, „New“, „Exported“ und „Project“ (alle, neu, exportiert, Projekt). „New“ heißt: noch nicht mit Download Claude conversations exportiert. „Exported“ markiert bereits gespeicherte Chats. „Project“ entspricht Ihrer Gruppierung auf claude.ai. Export All ergibt viele XML-Dateien, kein gemischtes ZIP.

Das Kontingent gilt pro Konto. Insgesamt drei kostenlose Exporte – nicht drei XML-Dateien pro Durchlauf. Wählen Sie 40 Unterhaltungen aus, verbrauchen Sie 40 Exporte, wenn jede Datei fertig wird. Planen Sie die Auswahl oder nutzen Sie Pro.

XML und JSON lassen sich in einem Klick auf „Export All“ nicht mischen. Wählen Sie für diesen Durchlauf XML. Brauchen Sie denselben claude.ai-Chat in beiden Formen, starten Sie Export All mit JSON erneut; auch dieser zweite Durchlauf verbraucht Kontingent.

Ist XML besser als JSON für den Export von Claude Chats?

Im Allgemeinen nicht. JSON ist unter Entwicklern die üblichere Wahl. Exportieren Sie einen Claude Chat als XML, wenn Ihr nachgelagertes System XML für den strukturierten Datenaustausch verlangt. Das Auslesen von claude.ai ist dasselbe; nur die Dateiform unterscheidet sich.

Kann ich viele Claude Chats auf einmal als XML exportieren?

Ja. Derselbe Ablauf mit Export All auf der Übersichtsseite unterstützt XML. Jede fertige Datei zählt als einer der 3 kostenlosen Exporte, außer Sie haben Pro für 3,99 $/Monat oder 26,99 $/Jahr.

Ist XML nur mit Pro verfügbar?

Nein. Alle fünf Formate, auch XML, sind in den 3 kostenlosen Exporten jedes per Google angemeldeten Kontos enthalten. Nach diesen drei Dateien kostet Pro 3,99 $/Monat oder 26,99 $/Jahr.

Entspricht der XML-Export dem ZIP von Anthropic?

Nein. Der Datenexport von Anthropic ist ein verzögertes JSON-ZIP des Kontos. Download Claude conversations schreibt sofort in Chrome eine XML-Datei pro Chat (oder pro Auswahl). Das Schema ist nicht dasselbe.

Erzeugt der XML-Export ein PDF?

Nein. XML ist Auszeichnung. Die Formate des Produkts sind Markdown, JSON, reiner Text, XML und PNG. Für eine druckbare Seite nutzen Sie den Druckdialog von Chrome. PNG ist ein Bild, ebenfalls kein PDF.

Kann ich in Claude Desktop als XML exportieren?

Nein. Die Chrome-Erweiterung läuft nur auf claude.ai. Claude Desktop zeigt das XML-Menü nie. Öffnen Sie denselben Chat auf claude.ai in Chrome, falls er dort existiert.

Brauche ich Pro für einen einzelnen XML-Export?

Nein. Die ersten 3 Exporte sind kostenlos, in jedem Format einschließlich XML. Pro für 3,99 $/Monat oder 26,99 $/Jahr hebt die Grenze für weitere einzelne oder gesammelte XML-Dateien auf.
