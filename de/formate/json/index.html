Wie exportiere ich eine Claude Unterhaltung als JSON?

Öffnen Sie die Unterhaltung auf claude.ai in Chrome, klicken Sie auf den orangefarbenen Button neben dem Eingabefeld, wählen Sie JSON und klicken Sie auf „Export“. Download Claude conversations schreibt die Datei lokal. So exportieren Sie in Version 1.16.2 eine Claude Unterhaltung als JSON. Eine eingebaute Funktion „als JSON speichern“ pro Chat hat claude.ai im September 2026 nicht.

  1. Installieren Sie Download Claude conversations aus dem Chrome Web Store.
  2. Laden Sie claude.ai neu und öffnen Sie eine echte Unterhaltung, nicht die leere Startseite mit dem Eingabefeld.
  3. Klicken Sie auf den orangefarbenen Download-Button rechts neben dem Eingabefeld.
  4. Wählen Sie JSON. Das zuletzt genutzte Format wird gespeichert. Mit „Select“ (Auswählen) haken Sie nur die Nachrichten an, die Sie brauchen.
  5. Klicken Sie auf „Export“. Chrome lädt das JSON über die Download-Schnittstelle des Browsers herunter. Oder klicken Sie auf „Copy“ (Kopieren), um das JSON in die Zwischenablage zu legen.

Für den JSON-Export einer Claude Unterhaltung ist keine Anmeldung nötig. Einzelexporte als JSON sind unbegrenzt, anonym und senden nichts an unsere Server. Eine Google-Anmeldung wird nur für PDF und den Massenexport mit Export All verlangt. Technik: So funktioniert es.

Fehlt der orangefarbene Button, sind Sie nicht in einer Unterhaltung, der Tab braucht einen Neuladen, oder die Erweiterung steckt im Puzzle-Menü von Chrome. Pinnen Sie Download Claude conversations und laden Sie claude.ai neu. In Claude Desktop oder im Terminal von Claude Code wird das Content-Skript nie geladen.

Ein Chat oder viele Dateien. Der orangefarbene Button exportiert den offenen Chat als JSON. Für viele JSON-Dateien öffnen Sie „View and Download All Conversations“ (alle Unterhaltungen ansehen und herunterladen) und starten „Export All“ (alles exportieren) mit JSON: ein ZIP, 3 Chats pro Tag im kostenlosen Tarif – siehe Massenexport mit Export All.

Wann lohnt sich JSON?

Exportieren Sie eine Claude Unterhaltung als JSON, wenn ein Skript, ein Indexer oder ein Vergleichswerkzeug die Datei liest. Das JSON bildet den Nachrichtenbaum ab und ist nicht zum Lesen in Obsidian gedacht. Wollen Sie Überschriften und Codeblöcke für Menschen, wählen Sie Markdown. Für eine Tabelle wählen Sie CSV: eine Zeile pro Nachricht.

Kopieren aus claude.ai verliert die Absender-Struktur. Drucken behält die Bedienelemente der Webseite. Beim JSON-Export behält Download Claude conversations Nachrichten, Absender und optional die Denkschritte als Daten, nicht als plattgedrückten Absatz. Deshalb wählen Entwickler JSON statt reinem Text.

Wir schreiben JSON aus dem claude.ai-Baum, der schon auf der Seite ist – Absender, Inhaltsblöcke, Zeitstempel, Modell-Metadaten –, ohne den Chat hochzuladen. Dieses JSON ist nicht das Konto-ZIP von Anthropic. In Version 1.16.2 ist es eines von sieben Formaten, neben PDF und CSV, und es ist kostenlos und ohne Konto nutzbar.

Was steckt in einem JSON-Export?

Ein JSON-Export einer Claude Unterhaltung bildet den Nachrichtenbaum auf claude.ai ab: Absender, Inhaltsblöcke, Zeitstempel und Modell-Metadaten. Denkschritte, Quellen der Websuche, Tool-/MCP-Schritte und Artefakte sind enthalten, wenn diese Optionen an sind: „Thinking“ (Denkprozess) ist ein Häkchen im Export-Panel, Tools und Quellen schalten Sie in den Einstellungen ein. Der Absenderfilter „all / human only / assistant only“ (alle / nur Mensch / nur Assistent) begrenzt die Datei auf alle Nachrichten, nur Ihre oder nur Claudes. Nichts wird vorher zu Markdown plattgemacht.

Das Artefakt-Layout in Version 1.16.2 ist „Original“, „Inline“, „Nested“ oder „Flat“ (original, eingebettet, verschachtelt, flach). Diese Layouts ändern, wie Artefakt-Inhalte im JSON verschachtelt sind – dieselben vier Optionen wie bei Markdown und XML. Alle Optionen: Funktionen der Chrome-Erweiterung. Für Seiten statt Daten exportieren Sie PDF.

JSON-Export vs. Datenexport von Anthropic?

Beides ist JSON, aber weder Form noch Umfang stimmen überein. Settings → Privacy → Export data von Anthropic (die Beschriftungen können übersetzt sein, wenn claude.ai auf Deutsch eingestellt ist) schickt nach einer Wartezeit ein ZIP des ganzen Kontos per E-Mail. Beim JSON-Export einer Claude Unterhaltung erhalten Sie sofort einen Chat in Chrome. Das ZIP ist für die Sicherung.

Zwei verschiedene JSON-Wege aus claude.ai
Methode Umfang Wann die Datei kommt
JSON aus Download Claude conversations Dieser Chat oder eine Auswahl Sofort als Chrome-Download
Settings → Privacy → Export data Ganzes Konto E-Mail-Link, der abläuft
PDF aus Download Claude conversations Dieser Chat als Seiten Sofort, aber als PDF, nicht JSON

In der ZIP-Anfrage von Anthropic können Sie kein Markdown wählen. Umgekehrt ist das JSON dieser Erweiterung kein direkter Ersatz für das ZIP-Schema. Formatübersicht: Exportformate für Claude Chats. PDF ist zum Lesen da, kein JSON-Export.

Download Claude conversations ist nicht mit Anthropic, PBC verbunden. Das Content-Skript nutzt die Sitzung, die Sie auf claude.ai bereits geöffnet haben. Es meldet sich nicht mit eigenen Zugangsdaten bei Anthropic an. Halten Sie sich an die Regeln von Anthropic für Ihr Konto.

Kann ich viele Unterhaltungen auf einmal als JSON exportieren?

Ja. Öffnen Sie „View and Download All Conversations“, stellen Sie „Chat format“ (Chat-Format) auf JSON, filtern Sie die Tabelle und klicken Sie auf „Export All“. Chrome speichert ein ZIP mit einer JSON-Datei pro Chat. Im kostenlosen Tarif sind das 3 Chats pro Tag mit Google-Anmeldung, gemeinsam mit PDF. Pro für 3,99 $ im Monat oder 26,99 $ im Jahr hebt diese Grenze für den Massenexport als JSON auf.

Das Dashboard listet Ihren claude.ai-Verlauf mit Namenssuche, den Filtern „All conversations“, „New“, „Updated“ und „Previously exported“ (alle Unterhaltungen, neu, aktualisiert, bereits exportiert), den Tabs „Chat“ und „Cowork“ und einer Projektsuche. „New“ heißt: noch nicht mit Download Claude conversations exportiert. „Previously exported“ markiert bereits gespeicherte Chats. Export All ergibt ein ZIP mit einer JSON-Datei pro Chat, kein Archiv mit gemischten Formaten.

Das Tageslimit gilt pro Konto. Drei Chats pro Tag im kostenlosen Tarif, gemeinsam mit PDF. Wählen Sie 40 Unterhaltungen aus, obwohl nur noch 3 übrig sind, wird der ganze Stapel blockiert, nicht gekürzt. Wählen Sie weniger aus oder nutzen Sie Pro. Einzelne JSON-Exporte über den orangefarbenen Button bleiben unbegrenzt.

Zwei JSON-Exporte desselben claude.ai-Chats zu unterschiedlichen Zeitpunkten vergleichen Sie wie jede andere JSON-Datei. Jeder Export ist eigenständig. Ein zweiter Durchlauf von Export All mit denselben Chats zählt jeden Chat erneut.

Braucht der JSON-Export Pro?

Nein. Der JSON-Export eines Chats ist kostenlos und unbegrenzt, ohne Konto und ohne Zähler – genau wie Markdown, Text, XML, CSV und PNG. Nur PDF und der Massenexport mit Export All haben ein kostenloses Limit: 3 pro Tag mit Google-Anmeldung. Pro kostet 3,99 $ im Monat oder 26,99 $ im Jahr über Paddle. Für den JSON-Export einer Claude Unterhaltung verlangt Download Claude conversations keinen Aufpreis.

Das Limit zeigt sich erst beim Massenexport als JSON. Jeder Chat in einem ZIP von Export All belegt einen der 3 Plätze pro Tag, und der Zähler beginnt um Mitternacht UTC neu. Pro hebt das Limit auf und wird auf einem neuen Computer über dasselbe Google-Konto wiederhergestellt. Paddle ist Händler (Merchant of Record); dieses Team sieht nie Kartennummern.

Die Erweiterung läuft nur auf claude.ai in Chrome. Claude Desktop und das Terminal von Claude Code bekommen keinen JSON-Button; Claude Code im Web (claude.ai/code) läuft auf claude.ai und lässt sich deshalb wie jeder Chat exportieren. /export oder JSONL auf der Festplatte in Claude Code im Terminal ist ein anderer Weg. Version 1.16.2, September 2026, schreibt weiterhin kein Word oder Notion.

FAQ: Claude Unterhaltung als JSON exportieren

Diese Fragen behandeln den JSON-Export in Download Claude conversations 1.16.2: Export All, Schema, Kosten, Vergleiche, das ZIP von Anthropic, PDF und Desktop. Jede Antwort ist eine Produkt-Tatsache. Das FAQPage-JSON-LD im Kopf der Seite entspricht dieser Liste.

Kann ich viele Claude Unterhaltungen auf einmal als JSON exportieren?

Ja. Export All im Dashboard unterstützt JSON und speichert ein ZIP mit einer JSON-Datei pro Chat. Im kostenlosen Tarif deckt das 3 Chats pro Tag mit Google-Anmeldung ab; mit Pro für 3,99 $ im Monat oder 26,99 $ im Jahr ist es unbegrenzt.

Ist die JSON-Struktur dokumentiert?

Sie bildet den Nachrichtenbaum von claude.ai ab: Absender, Inhaltsblöcke, Zeitstempel und Modell-Metadaten, dazu Artefakte, Denkschritte, Quellen der Websuche und Tool-/MCP-Schritte, wenn Sie diese Optionen aktivieren. Es ist nicht das Schema des Konto-ZIPs von Anthropic.

Brauche ich Pro, um eine Claude Unterhaltung als JSON zu exportieren?

Nein. Einzelexporte als JSON sind unbegrenzt und brauchen kein Konto, wie jedes Format außer PDF. Pro für 3,99 $ im Monat oder 26,99 $ im Jahr hebt nur das Limit von 3 pro Tag für PDF und den Massenexport mit Export All auf.

Kann ich zwei JSON-Exporte desselben Chats vergleichen?

Ja. Jeder JSON-Export einer Claude Unterhaltung ergibt eine eigenständige Datei, die gleich aufgebaut ist. Zwei Exporte desselben Chats zu unterschiedlichen Zeitpunkten vergleichen Sie wie jede andere JSON-Datei.

Ist dieses JSON dasselbe wie der Datenexport von Anthropic?

Nein. Der Datenexport von Anthropic ist ein verzögertes ZIP des ganzen Kontos. Download Claude conversations schreibt sofort in Chrome eine JSON-Datei pro Chat (oder pro Auswahl). Beides kann JSON sein; austauschbar ist es nicht.

Erzeugt der JSON-Export ein PDF?

Nein. JSON sind strukturierte Daten. Für Seiten wählen Sie im selben Panel PDF; die sieben Formate sind PDF, Markdown, JSON, reiner Text, XML, CSV und PNG. PDF erfordert eine Google-Anmeldung und zählt im kostenlosen Tarif zu den 3 pro Tag.

Funktioniert der JSON-Export in Claude Desktop?

Nein. Die Chrome-Erweiterung läuft nur auf claude.ai. Claude Desktop zeigt die JSON-Option nie. Öffnen Sie denselben Chat auf claude.ai in Chrome, falls er dort existiert.
