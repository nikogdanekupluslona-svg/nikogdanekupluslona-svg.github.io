Wie lade ich einen Claude Chat als PNG herunter?

Öffnen Sie die Unterhaltung auf claude.ai in Chrome, klicken Sie auf den orangefarbenen Button neben dem Eingabefeld, wählen Sie PNG und klicken Sie auf „Export“. Download Claude conversations erzeugt das Bild im Tab. So laden Sie in Version 1.16.2 einen Claude Chat als PNG herunter – kostenlos, unbegrenzt, ohne Konto.

  1. Installieren Sie Download Claude conversations aus dem Chrome Web Store.
  2. Laden Sie claude.ai neu und öffnen Sie eine echte Unterhaltung, nicht die leere Startseite mit dem Eingabefeld.
  3. Klicken Sie auf den runden orangefarbenen Download-Button rechts neben dem Eingabefeld.
  4. Wählen Sie PNG. Das zuletzt genutzte Format wird gespeichert.
  5. Klicken Sie auf „Export“. Chrome lädt das PNG sofort herunter.

Um einen Claude Chat als PNG herunterzuladen, ist keine Google-Anmeldung nötig. Einzelexporte als PNG sind unbegrenzt und anonym: kein Zähler, und nichts über den Chat verlässt den Browser. Eine Anmeldung erscheint nur, wenn Sie PDF wählen, Export All starten oder Pro kaufen. Technik: So funktioniert es.

Fehlt der orangefarbene Button, sind Sie nicht in einer Unterhaltung, der Tab braucht nach der Installation einen Neuladen, oder die Erweiterung steckt im Puzzle-Menü von Chrome. Pinnen Sie Download Claude conversations und laden Sie claude.ai neu. Projekte, Cowork-Sitzungen und Claude Code im Web (claude.ai/code) exportieren Sie wie jeden Chat. In der Desktop-App Claude Desktop oder in lokalen Claude-Code-Sitzungen im Terminal erscheint der PNG-Export nie.

Ein Bild oder viele. Der orangefarbene Button schreibt ein PNG des offenen Chats. Für viele Bilder öffnen Sie „View and Download All Conversations“ (alle Unterhaltungen ansehen und herunterladen) und starten „Export All“ (alles exportieren) mit PNG. Der Massenexport schreibt ein ZIP und nutzt das tägliche Limit für Massenexporte – siehe Massenexport mit Export All.

Wann lohnt sich PNG?

Laden Sie einen Claude Chat als PNG herunter, wenn Sie ein Bild für eine Folie, einen Messenger oder ein Ticket brauchen – überall, wo sich ein Bild leichter einfügen lässt als eine .md-Datei. Wählen Sie PNG nicht, wenn Sie später suchen oder Code kopieren wollen. Dafür nehmen Sie Markdown – oder PDF, wenn Sie Seiten brauchen.

Ein Screenshot von claude.ai von Hand zeigt oft Seitenleiste und Eingabefeld. Es bleibt ein Bild: kein Nachrichtenbaum, keine Sprach-Tags an Codeblöcken, die Sie als Text kopieren könnten.

PNG haben wir eingeführt, damit Sie einen optischen Schnappschuss eines claude.ai-Chats in einer Datei speichern können. Ist ein PNG dasselbe wie ein PDF?

Nein. PNG ist ein Bildformat, PDF ein Dokumentformat mit Seiten. Download Claude conversations exportiert beides: PNG für ein Bild, PDF für Seiten. PNG ist unbegrenzt und ohne Konto nutzbar; PDF erfordert eine Google-Anmeldung und ist bis zu 3-mal pro Tag kostenlos. Anleitung: Claude Chat als PDF herunterladen.

Was enthält ein PNG-Export eines Claude Chats?

Ein PNG-Export eines Claude Chats ist ein einzelnes Bild des Unterhaltungsinhalts, den Download Claude conversations dargestellt hat. Anders als Markdown oder JSON enthält das PNG keinen auswertbaren Nachrichtenbaum. Code und Tabellen sind Pixel. Denkschritte und Artefakte werden gezeichnet, nicht als Text gespeichert.

Der Filter „Messages“ (Nachrichten: „All“ / „Human“ / „Assistant“ – alle, Mensch, Assistent) begrenzt, was gezeichnet wird, das Häkchen „Thinking“ (Denkprozess) nimmt erweitertes Denken auf oder lässt es weg, und mit „Select“ (Auswählen) haken Sie einzelne Nachrichten an. „Metadata“ (Metadaten) und das Artefakt-Layout „Original“, „Inline“, „Nested“ oder „Flat“ (original, eingebettet, verschachtelt, flach) sind Optionen im Dashboard für Export All. Metadaten werden im PNG nicht zu markierbarem Text wie im JSON. „Copy“ (Kopieren) funktioniert bei PNG nicht; es ist immer eine Datei.

Ist der Chat sehr lang, scrollen Sie vor dem PNG-Export, bis claude.ai frühere Nachrichten geladen hat. Die Erweiterung kann nur darstellen, was die Seite geladen hat. Ein halb geladener Chat ergibt ein abgeschnittenes Bild. Alle Schalter: Funktionen der Chrome-Erweiterung.

Behalten Sie eine Textkopie, wenn Ihnen die Worte wichtig sind. PNG ist ein Schnappschuss. Suchen Sie später nach einem Funktionsnamen, findet die Suche nichts. Exportieren Sie Markdown oder JSON als zweite Datei; das ist unbegrenzt und kostenlos, genau wie das PNG.

Kann ich viele Claude Chats auf einmal als PNG herunterladen?

Ja. Öffnen Sie „View and Download All Conversations“, stellen Sie „Chat format“ (Chat-Format) auf PNG, filtern Sie die Liste und klicken Sie auf „Export All“. Sie erhalten ein ZIP mit einem PNG pro ausgewählter Unterhaltung. Der Massenexport erfordert eine Google-Anmeldung; im kostenlosen Tarif belegt jeder Chat im ZIP einen der 3 täglichen PDF- oder Massenexporte. Pro für 3,99 $ im Monat oder 26,99 $ im Jahr hebt diese Grenze auf.

Das Dashboard listet Ihren claude.ai-Verlauf mit Namenssuche, Projektsuche, den Tabs „Chat“ und „Cowork“ und den Filtern „All conversations“, „New“, „Updated“ und „Previously exported“ (alle Unterhaltungen, neu, aktualisiert, bereits exportiert). „New“ heißt: noch nicht mit Download Claude conversations exportiert. Export All erzeugt im ZIP ein PNG pro ausgewählter Unterhaltung – keine Kontaktbogen-Collage und keine PDF-Mappe.

Die Grenze für den Massenexport beginnt um Mitternacht UTC neu. Im kostenlosen Tarif wird eine Auswahl, die größer ist als der heutige Rest, als Ganzes blockiert, nicht gekürzt: Wählen Sie weniger Chats oder nutzen Sie Pro. Einzelne PNGs über den orangefarbenen Button bleiben unbegrenzt. Settings → Privacy → Export data von Anthropic (die Beschriftungen können übersetzt sein, wenn claude.ai auf Deutsch eingestellt ist) bleibt ein verzögertes JSON-ZIP, kein Ordner mit Bildern.

FAQ: Claude Chat als PNG herunterladen

Diese Fragen behandeln den PNG-Export in Download Claude conversations 1.16.2: PDF, Export All, Limits und den Inhalt des Bildes. Jede Antwort ist eine Produkt-Tatsache. Das FAQPage-JSON-LD im Kopf der Seite entspricht dieser Liste.

Exportiert Download Claude conversations als PDF?

Ja. Wählen Sie PDF im Export-Panel für ein Dokument mit Seiten, optional mit Seitenzahlen und Inhaltsverzeichnis. PNG ist ein einzelnes Bild des Chats. PDF erfordert eine Google-Anmeldung und ist bis zu 3-mal pro Tag kostenlos; PNG ist unbegrenzt und ohne Konto nutzbar.

Kann ich den ganzen Verlauf als PNG herunterladen?

Ja. Export All im Dashboard unterstützt PNG und erzeugt ein ZIP mit einem Bild pro ausgewählter Unterhaltung. Der Massenexport erfordert eine Google-Anmeldung; im kostenlosen Tarif belegt jeder Chat im ZIP einen der 3 täglichen PDF- oder Massenexporte. Mit Pro ist es unbegrenzt.

Ist PNG kostenlos oder nur mit Pro?

Kostenlos und unbegrenzt. Einzelexporte als PNG brauchen kein Konto und haben keinen Zähler. Pro für 3,99 $ im Monat oder 26,99 $ im Jahr ist für unbegrenzte PDF- und ZIP-Massenexporte gedacht.

Kann ich Code aus einem PNG eines Claude Chats kopieren?

Nicht sauber. Ein PNG speichert Pixel. Exportieren Sie Markdown oder JSON, wenn Sie Codeblöcke mit Sprach-Tags brauchen. Behalten Sie beide Dateien, wenn Sie ein Bild und durchsuchbaren Text wollen.

Ist der PNG-Export ein Screenshot von Chrome?

Nein. Download Claude conversations erzeugt das PNG aus der Unterhaltung, die es auf claude.ai ausgelesen hat. Es bleibt ein Bild, keine Markdown-Datei. Ein Screenshot des ganzen Fensters mit dem Betriebssystem ist eine andere Datei, die Sie selbst aufnehmen.

Funktioniert PNG in Claude Desktop?

Nein. Die Chrome-Erweiterung läuft auf claude.ai in Chrome, nicht in der Desktop-App Claude Desktop. Claude Desktop zeigt die PNG-Option nie. Öffnen Sie denselben Chat auf claude.ai in Chrome, falls er dort existiert.

Verbraucht ein PNG-Export dasselbe Kontingent wie Markdown?

Ja – keines von beiden hat eines. Einzelexporte als PNG und als Markdown sind beide unbegrenzt und anonym. Die einzige Grenze sind 3 PDF- oder ZIP-Massenexporte pro Tag im kostenlosen Tarif; Pro hebt sie auf.
