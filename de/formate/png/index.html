Wie lade ich einen Claude Chat als PNG herunter?

Öffnen Sie die Unterhaltung auf claude.ai in Chrome, klicken Sie auf den orangefarbenen Button neben dem Eingabefeld, wählen Sie PNG und klicken Sie auf „Export“. Download Claude conversations erzeugt das Bild im Tab. So laden Sie in Version 1.13.0 einen Claude Chat als PNG herunter.

  1. Installieren Sie Download Claude conversations aus dem Chrome Web Store (Bewertung 5,0).
  2. Laden Sie claude.ai neu und öffnen Sie eine echte Unterhaltung, nicht die leere Startseite mit dem Eingabefeld.
  3. Klicken Sie auf den orangefarbenen Download-Button rechts neben dem Eingabefeld.
  4. Wählen Sie PNG. Das zuletzt genutzte Format wird gespeichert.
  5. Klicken Sie auf „Export“. Chrome lädt das PNG sofort herunter.

Vor dem ersten PNG-Export ist eine Google-Anmeldung nötig. Download Claude conversations speichert die bestätigte E-Mail-Adresse, um die 3 kostenlosen Exporte zu zählen und Pro nach einer Neuinstallation wiederherzustellen. Für diese Anmeldung werden keine Bilder des Chats hochgeladen. Technik: So funktioniert es.

Fehlt der orangefarbene Button, sind Sie nicht in einer Unterhaltung, der Tab braucht nach der Installation einen Neuladen, oder die Erweiterung steckt im Puzzle-Menü von Chrome. Pinnen Sie Download Claude conversations und laden Sie claude.ai neu. In Claude Desktop oder Claude Code erscheint der PNG-Export nie.

Ein Bild oder viele. Der orangefarbene Button schreibt ein PNG des offenen Chats. Für viele Bilder öffnen Sie „View and Download All Conversations“ (alle Unterhaltungen ansehen und herunterladen) und starten „Export All“ (alles exportieren) mit PNG – siehe Massenexport mit Export All.

Wann lohnt sich PNG?

Laden Sie einen Claude Chat als PNG herunter, wenn Sie ein Bild für eine Folie, einen Messenger oder ein Ticket brauchen – überall, wo sich ein Bild leichter einfügen lässt als eine .md-Datei. Wählen Sie PNG nicht, wenn Sie später suchen oder Code kopieren wollen. Dafür nehmen Sie Markdown.

Ein Screenshot von claude.ai von Hand zeigt oft Seitenleiste und Eingabefeld. Download Claude conversations baut das PNG aus dem Inhalt der Unterhaltung, den es bereits ausgelesen hat, nicht aus einem beliebigen Screenshot. Es bleibt ein Bild: kein Nachrichtenbaum, keine Sprach-Tags an Codeblöcken, die Sie als Text kopieren könnten.

PNG haben wir eingeführt, damit Sie einen optischen Schnappschuss eines claude.ai-Chats speichern können. PDF haben wir nicht eingeführt. Beim PNG-Export erhalten Sie eine Bilddatei; brauchen Sie eine druckbare Seite, nutzen Sie den Druckdialog von Chrome – eine Browserfunktion, kein sechstes Format unseres Produkts.

Ist ein PNG dasselbe wie ein PDF?

Nein. PNG ist ein Bildformat, PDF ein Dokumentformat mit Seiten. Download Claude conversations exportiert PNG, nicht PDF. Brauchen Sie tatsächlich eine PDF-ähnliche Seite, drucken Sie den claude.ai-Tab in Chrome (Ctrl/Cmd+P → „Als PDF speichern“). Anleitung: Claude Unterhaltung drucken.

Was enthält ein PNG-Export eines Claude Chats?

Ein PNG-Export eines Claude Chats ist ein einzelnes Bild des Unterhaltungsinhalts, den Download Claude conversations dargestellt hat. Anders als Markdown oder JSON enthält das PNG keinen auswertbaren Nachrichtenbaum. Code und Tabellen sind Pixel. Denkschritte und Artefakte werden gezeichnet, nicht als Text gespeichert.

Das Artefakt-Layout „Original“, „Inline“, „Nested“ oder „Flat“ (original, eingebettet, verschachtelt, flach) ändert auch hier, wie Artefakte im Bild erscheinen – dieselben vier Optionen wie bei den anderen Formaten. Der Absenderfilter „all / human only / assistant only“ (alle / nur Mensch / nur Assistent) begrenzt, was gezeichnet wird. Metadaten werden im PNG nicht zu markierbarem Text wie im JSON.

Ist der Chat sehr lang, scrollen Sie vor dem PNG-Export, bis claude.ai frühere Nachrichten geladen hat. Die Erweiterung kann nur darstellen, was die Seite geladen hat. Ein halb geladener Chat ergibt ein abgeschnittenes Bild. Alle Schalter: Funktionen der Chrome-Erweiterung.

Behalten Sie eine Textkopie, wenn Ihnen die Worte wichtig sind. PNG ist ein Schnappschuss. Suchen Sie später nach einem Funktionsnamen, findet die Suche nichts. Exportieren Sie Markdown oder JSON als zweite Datei; auch diese zweite Datei zählt zu den 3 kostenlosen Exporten.

Kann ich viele Claude Chats auf einmal als PNG herunterladen?

Ja. Öffnen Sie „View and Download All Conversations“, stellen Sie das Format auf PNG, filtern Sie die Tabelle und klicken Sie auf „Export All“. Jedes fertige Bild ist ein Export aus denselben 3 kostenlosen Exporten wie ein einzelnes PNG über den orangefarbenen Button. Pro für 3,99 $/Monat oder 26,99 $/Jahr hebt die Grenze für den Massenexport als PNG auf.

Die Tabelle listet Ihren claude.ai-Verlauf mit Namenssuche und den Filtern „All“, „New“, „Exported“ und „Project“ (alle, neu, exportiert, Projekt). „New“ heißt: noch nicht mit Download Claude conversations exportiert. Export All erzeugt ein PNG pro ausgewählter Unterhaltung – keine Kontaktbogen-Collage und keine PDF-Mappe.

Das Kontingent gilt pro Konto. Wählen Sie 40 Unterhaltungen aus, verbrauchen Sie 40 Exporte, wenn jedes PNG fertig wird. Planen Sie die Auswahl, bevor Sie auf „Export All“ klicken. Settings → Privacy → Export data von Anthropic (die Beschriftungen können übersetzt sein, wenn claude.ai auf Deutsch eingestellt ist) bleibt ein verzögertes JSON-ZIP, kein Ordner mit Bildern.

Nein. PNG ist in den 3 kostenlosen Exporten jedes per Google angemeldeten Kontos enthalten, genau wie Markdown, JSON, Text und XML. FAQ: Claude Chat als PNG herunterladen

Diese Fragen behandeln den PNG-Export in Download Claude conversations 1.13.0: PDF, Export All, Kontingent und den Inhalt des Bildes. Jede Antwort ist eine Produkt-Tatsache. Das FAQPage-JSON-LD im Kopf der Seite entspricht dieser Liste.

Exportiert Download Claude conversations als PDF?

Nein. Die aktuellen Formate sind Markdown, JSON, reiner Text, XML und PNG. PNG kommt einer optischen Kopie am nächsten, ist aber ein Bild, kein PDF. Drucken Sie die claude.ai-Seite in Chrome, wenn Sie eine PDF-ähnliche Datei brauchen.

Kann ich den ganzen Verlauf als PNG herunterladen?

Ja. Export All auf der Massenexport-Seite unterstützt PNG genauso wie der Einzelexport und erzeugt ein Bild pro ausgewählter Unterhaltung. Jedes Bild zählt als einer der 3 kostenlosen Exporte, außer Sie haben Pro.

Ist PNG kostenlos oder nur mit Pro?

Kostenlos. Jedes Format, auch PNG, gehört zu den 3 kostenlosen Exporten jedes per Google angemeldeten Kontos. Nach diesen drei Dateien kostet Pro 3,99 $/Monat oder 26,99 $/Jahr.

Kann ich Code aus einem PNG eines Claude Chats kopieren?

Nicht sauber. Ein PNG speichert Pixel. Exportieren Sie Markdown oder JSON, wenn Sie Codeblöcke mit Sprach-Tags brauchen. Behalten Sie beide Dateien, wenn Sie ein Bild und durchsuchbaren Text wollen.

Ist der PNG-Export ein Screenshot von Chrome?

Nein. Download Claude conversations erzeugt das PNG aus der Unterhaltung, die es auf claude.ai ausgelesen hat. Es bleibt ein Bild, keine Markdown-Datei. Ein Screenshot des ganzen Fensters mit dem Betriebssystem ist eine andere Datei, die Sie selbst aufnehmen.

Funktioniert PNG in Claude Desktop?

Nein. Die Chrome-Erweiterung läuft nur auf claude.ai. Claude Desktop zeigt die PNG-Option nie. Öffnen Sie denselben Chat auf claude.ai in Chrome, falls er dort existiert.

Verbraucht ein PNG-Export dasselbe Kontingent wie Markdown?

Ja. Ein fertiges PNG ist ein Export, genau wie eine .md- oder JSON-Datei. Die 3 kostenlosen Exporte gelten nicht pro Format. Pro hebt die Grenze für jedes Format auf, auch für PNG.
