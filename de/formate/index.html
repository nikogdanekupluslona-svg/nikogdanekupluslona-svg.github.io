Welche Exportformate für Claude Chats gibt es hier?

Die Exportformate für Claude Chats auf dieser Website sind die fünf Dateitypen, die Download Claude conversations aus einem claude.ai-Chat schreibt: Markdown, JSON, reiner Text, XML und PNG. Version 1.13.0 kann kein PDF schreiben. Jede fertige Datei zählt als einer der 3 kostenlosen Exporte.

Die Erweiterung läuft nur auf claude.ai. Claude Desktop und Claude Code zeigen den orangefarbenen Button nie. Existiert derselbe Chat in Ihrem claude.ai-Konto, öffnen Sie die URL in Chrome und wählen dort ein Format. Das Auswahlmenü merkt sich Ihre letzte Wahl.

Viele suchen dieselbe Erweiterung auch als Claude Chat Downloader oder Claude Conversation Downloader. Diese Namen meinen dieses Produkt, keinen zweiten Exporter. In den Rechtstexten kann noch Claude Exporter stehen. Sie erhalten trotzdem Markdown, JSON, Text, XML oder PNG.

Eine Liste, zwei Einstiege. Der orangefarbene Button und Export All nutzen dieselben Exportformate. Ein Massenexport ergibt viele Einzeldateien pro Chat, kein gemischtes ZIP. Details: Massenexport mit Export All.

Welches Exportformat sollte ich wählen?

Markdown für Notizen, JSON für Skripte, reinen Text für ein Archiv zum Einfügen überall, XML, wenn ein System XML verlangt, und PNG für ein Bild des Chats. Download Claude conversations erklärt keines zum besten. Die Formate unterscheiden sich in der Form, nicht im Kontingent.

Wie wähle ich das Exportformat aus?

Öffnen Sie eine Unterhaltung auf claude.ai in Chrome, klicken Sie auf den orangefarbenen Button neben dem Eingabefeld, wählen Sie ein Exportformat und klicken Sie auf „Export“ (Exportieren). Download Claude conversations baut die Datei im Tab. Eine eingebaute Funktion „diesen Chat exportieren“ hat claude.ai im September 2026 nicht.

  1. Installieren Sie Download Claude conversations aus dem Chrome Web Store (Bewertung 5,0).
  2. Laden Sie claude.ai neu und öffnen Sie eine echte Unterhaltung, nicht die leere Startseite mit dem Eingabefeld.
  3. Klicken Sie auf den orangefarbenen Download-Button rechts neben dem Eingabefeld.
  4. Wählen Sie Markdown, JSON, reinen Text, XML oder PNG. Das zuletzt gewählte Format bleibt eingestellt.
  5. Klicken Sie auf „Export“. Chrome speichert die Datei sofort.

Vor dem ersten Export ist eine Google-Anmeldung nötig. Download Claude conversations speichert die bestätigte E-Mail-Adresse, um die 3 kostenlosen Exporte zu zählen und Pro nach einer Neuinstallation wiederherzustellen. Chat-Text ist nicht Teil dieser Anmeldung. Technik: So funktioniert es.

Die Schalter im selben Widget gelten für jedes Format: „include thinking“ (Denkschritte einbeziehen), „include metadata“ (Metadaten: Titel, Zeitstempel, Modell), Absenderfilter „all / human only / assistant only“ (alle / nur Mensch / nur Assistent) und das Artefakt-Layout „Original“, „Inline“, „Nested“ oder „Flat“ (original, eingebettet, verschachtelt, flach). PNG zeichnet weiterhin ein Bild; die anderen vier schreiben Text oder strukturierte Auszeichnung.

Funktionieren die Exportformate in Export All?

Ja. Öffnen Sie „View and Download All Conversations“ (alle Unterhaltungen ansehen und herunterladen), filtern Sie die Tabelle, wählen Sie im selben Formatmenü und klicken Sie auf „Export All“. Jede fertige Datei ist einer der 3 kostenlosen Exporte. Pro für 3,99 $/Monat oder 26,99 $/Jahr hebt die Grenze für Massen- und Einzelexporte auf.

Die Tabelle listet Ihren claude.ai-Verlauf mit Namenssuche und den Filtern „All“, „New“, „Exported“ und „Project“ (alle, neu, exportiert, Projekt). „New“ heißt: noch nicht mit Download Claude conversations exportiert. „Exported“ markiert bereits gespeicherte Chats. „Project“ entspricht Ihrer Gruppierung auf claude.ai. Export All ist kein verzögertes Konto-ZIP.

Das Kontingent gilt pro Konto. Insgesamt drei kostenlose Exporte – nicht drei pro Format und nicht drei pro Durchlauf. Wählen Sie 40 Unterhaltungen aus, verbrauchen Sie 40 Exporte, wenn jede Datei fertig wird. Planen Sie die Auswahl oder nutzen Sie Pro.

Der Massenexport nutzt dieselben Schalter für Denkschritte, Metadaten, Absender und Artefakte wie eine einzelne Unterhaltung. Ein gemischtes Paket aus Markdown und JSON in einem Klick gibt es nicht. Sie wählen pro Durchlauf ein Exportformat. Brauchen Sie denselben Chat in zwei Formen, starten Sie Export All mit einem anderen Format erneut; auch dieser zweite Durchlauf verbraucht Kontingent.

Exportformate vs. ZIP von Anthropic?

Settings → Privacy → Export data von Anthropic (die Beschriftungen können übersetzt sein, wenn claude.ai auf Deutsch eingestellt ist) schickt nach einer Wartezeit ein JSON-ZIP des ganzen Kontos per E-Mail. Die Exportformate von Download Claude conversations speichern den offenen Chat sofort als Markdown, JSON, Text, XML oder PNG. Das ZIP ist für die Sicherung, diese Erweiterung für jetzt.

Jedes per Google angemeldete Konto bekommt 3 kostenlose Exporte. Danach kostet Pro 3,99 $ im Monat oder 26,99 $ im Jahr über Paddle. Dieser Preis gilt für alle Exportformate. Download Claude conversations verlangt für JSON oder PNG keinen Aufpreis.

In welchen Exportformaten kann ich Claude Chats herunterladen?

Markdown, JSON, reiner Text, XML und PNG. Download Claude conversations schreibt kein PDF. PNG ist ein Bild des claude.ai-Chats, kein Dokument mit Seiten.

Ist PDF eines der Exportformate?

Nein. Das Auswahlmenü enthält nie PDF. Für eine PDF-ähnliche Seite drucken Sie den claude.ai-Tab in Chrome. Diese Datei ist ein Browser-Schnappschuss, kein Export dieser Erweiterung.

Teilen sich alle Exportformate die 3 kostenlosen Exporte?

Ja. Markdown, JSON, Text, XML und PNG zählen jeweils als ein Export, sobald die Datei fertig ist. Pro für 3,99 $/Monat oder 26,99 $/Jahr hebt die Grenze für jedes Format auf.

Kann ich Exportformate in Export All mischen?

Nein. Ein Durchlauf von Export All nutzt ein Format. Starten Sie ihn mit einem anderen Format erneut, wenn Sie zwei Dateien desselben claude.ai-Chats brauchen. Jede fertige Datei zählt trotzdem zum Kontingent.

Sind die Exportformate dasselbe wie der Datenexport?

Nein. Der Datenexport von Anthropic ist ein verzögertes JSON-ZIP des Kontos. Die Exportformate von Download Claude conversations sind Dateien pro Chat (oder pro Auswahl), die sofort in Chrome geschrieben werden.

Funktionieren die Exportformate in Desktop oder Code?

Nein. Die Chrome-Erweiterung läuft nur auf claude.ai. Claude Desktop und Claude Code zeigen das Formatmenü nie. Öffnen Sie denselben Chat auf claude.ai in Chrome, falls er dort existiert.

Brauche ich Pro, um die Exportformate auszuprobieren?

Nein. Die ersten 3 Exporte jedes per Google angemeldeten Kontos sind kostenlos, in jedem Format. Pro kostet 3,99 $/Monat oder 26,99 $/Jahr, wenn Sie mehr Einzel- oder Massenexporte brauchen.
