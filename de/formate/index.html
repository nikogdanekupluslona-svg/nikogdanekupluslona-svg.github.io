Wie wähle ich das Exportformat aus?

Öffnen Sie eine Unterhaltung auf claude.ai in Chrome, klicken Sie auf den orangefarbenen Button neben dem Eingabefeld, wählen Sie ein Exportformat und klicken Sie auf „Export“ (Exportieren). Download Claude conversations baut die Datei im Tab. Eine eingebaute Funktion „diesen Chat exportieren“ hat claude.ai im September 2026 nicht.

  1. Installieren Sie Download Claude conversations aus dem Chrome Web Store.
  2. Laden Sie claude.ai neu und öffnen Sie eine echte Unterhaltung, nicht die leere Startseite mit dem Eingabefeld.
  3. Klicken Sie auf den runden orangefarbenen Download-Button rechts neben dem Eingabefeld.
  4. Wählen Sie PDF, Markdown, reinen Text, JSON, XML, CSV oder PNG. Das zuletzt gewählte Format bleibt eingestellt.
  5. Klicken Sie auf „Export“. Chrome speichert die Datei sofort. Für PDF legen Sie die Optionen im PDF-Dialog fest; beim ersten PDF werden Sie um eine Google-Anmeldung gebeten.

Für Markdown, Text, JSON, XML, CSV oder PNG ist keine Anmeldung nötig: Diese Exporte sind unbegrenzt, anonym und senden nichts. Die Google-Anmeldung erscheint nur bei PDF, Export All oder Pro. Die Erweiterung sendet dann nur die Google-E-Mail-Adresse, um das Tageslimit zu prüfen und Pro nach einer Neuinstallation wiederherzustellen. Chat-Text wird nie hochgeladen. Technik: So funktioniert es.

Im Export-Panel legen Sie außerdem „Messages“ (Nachrichten: „All“ / „Human“ / „Assistant“ – alle, Mensch, Assistent) fest, dazu das Häkchen „Thinking“ (Denkprozess) und „Select“ (Auswählen), mit dem Sie einzelne Nachrichten anhaken. „Copy“ legt Markdown, Text, JSON, XML oder CSV statt einer Datei in die Zwischenablage; das ist unbegrenzt, für PDF und PNG aber nicht verfügbar. Tool-/MCP-Schritte und Quellen der Websuche schalten Sie in den Einstellungen der Erweiterung ein. „Metadata“ (Metadaten) und das Artefakt-Layout „Original“, „Inline“, „Nested“ oder „Flat“ (original, eingebettet, verschachtelt, flach) sind Optionen im Dashboard; das Layout entscheidet, ob Artefakte in der Datei stehen oder in einem eigenen Ordner im ZIP.

Funktionieren die Exportformate in Export All?

Ja. Öffnen Sie im Pop-up der Erweiterung „View and Download All Conversations“ (alle Unterhaltungen ansehen und herunterladen), filtern Sie die Liste, haken Sie die Chats an, wählen Sie unter „Chat format“ eines der sieben Formate und klicken Sie auf „Export All“. Sie erhalten ein ZIP mit einer Datei pro Chat. Der Massenexport erfordert eine Google-Anmeldung; im kostenlosen Tarif belegt jeder Chat im ZIP einen der 3 täglichen PDF- oder Massenexporte. Pro für 3,99 $ im Monat oder 26,99 $ im Jahr hebt diese Grenze auf.

Das Dashboard listet Ihren claude.ai-Verlauf mit Namenssuche, Projektsuche, den Tabs „Chat“ und „Cowork“ und den Filtern „All conversations“, „New“, „Updated“ und „Previously exported“ (alle Unterhaltungen, neu, aktualisiert, bereits exportiert). „New“ heißt: noch nicht mit Download Claude conversations exportiert. „Previously exported“ markiert bereits gespeicherte Chats. Export All ist kein verzögertes Konto-ZIP.

Die Grenze für den Massenexport gilt pro Tag. Im kostenlosen Tarif teilen sich PDF und Massenexport 3 Exporte pro Tag, zurückgesetzt um Mitternacht UTC. Jeder Chat in einem ZIP zählt als einer. Wählen Sie mehr aus, als heute noch übrig ist, wird der ganze Stapel blockiert, nicht gekürzt. Wählen Sie weniger Chats oder nutzen Sie Pro.

Der Massenexport hat eigene Häkchen dafür, was hineinkommt – „Chats“, „Thinking“, „Metadata“, „Tools“ (Werkzeuge) und „Sources“ (Quellen) –, dazu das Artefakt-Layout. Ein gemischtes Paket aus Markdown und JSON in einem Klick gibt es nicht. Sie wählen pro Durchlauf unter „Chat format“ ein Exportformat. Brauchen Sie denselben Chat in zwei Formen, starten Sie Export All mit einem anderen Format erneut; im kostenlosen Tarif zählt dieser zweite Durchlauf erneut.

FAQ: Exportformate für Claude Chats

Diese Fragen behandeln die Exportformate in Download Claude conversations 1.16.2: die Liste der sieben Formate, PDF, CSV, Limits, Export All, das ZIP von Anthropic, Desktop und Code sowie Pro. Jede Antwort ist eine Produkt-Tatsache. Das FAQPage-JSON-LD im Kopf der Seite entspricht dieser Liste.

In welchen Exportformaten kann ich Claude Chats herunterladen?

In sieben: PDF, Markdown, reiner Text, JSON, XML, CSV und PNG. Markdown, Text, JSON, XML, CSV und PNG sind unbegrenzt und brauchen kein Konto. PDF erfordert eine Google-Anmeldung und ist bis zu 3-mal pro Tag kostenlos.

Ist PDF eines der Exportformate?

Ja. Wählen Sie PDF im Export-Panel. Im PDF-Dialog legen Sie Dateiname, Seitengröße, Ränder, hellen oder dunklen Modus, Schriftart und -größe, Seitenzahlen, ein Inhaltsverzeichnis, Zeitstempel und einen Seitenumbruch vor jedem Prompt fest. Das PDF entsteht im Browser, ganz ohne Druckdialog.

Wofür ist der CSV-Export gedacht?

Für Tabellenkalkulationen. CSV schreibt eine Zeile pro Nachricht und öffnet sich in Excel, Google Sheets und Numbers. Der Export ist unbegrenzt, braucht kein Konto und lässt sich statt als Download auch in die Zwischenablage kopieren.

Haben die Exportformate ein Tageslimit?

Nur PDF und Massenexport. Einzelexporte als Markdown, Text, JSON, XML, CSV und PNG sind unbegrenzt und kostenlos. PDF und Massenexport als ZIP teilen sich im kostenlosen Tarif 3 pro Tag, zurückgesetzt um Mitternacht UTC. Pro für 3,99 $ im Monat oder 26,99 $ im Jahr hebt die Grenze auf.

Kann ich Exportformate in Export All mischen?

Nein. Ein Durchlauf von Export All nutzt ein Format und schreibt ein ZIP. Starten Sie ihn mit einem anderen Format erneut, wenn Sie zwei Dateien desselben claude.ai-Chats brauchen. Im kostenlosen Tarif zählt jeder Chat in jedem ZIP zu den 3 täglichen PDF- oder Massenexporten.

Sind die Exportformate dasselbe wie der Datenexport?

Nein. Der Datenexport von Anthropic ist ein verzögertes JSON-ZIP des Kontos. Die Exportformate von Download Claude conversations sind Dateien pro Chat (oder pro Auswahl), die sofort in Chrome geschrieben werden.

Funktionieren die Exportformate in Desktop oder Code?

Im Web ja. Chats, Projekte, Cowork-Sitzungen und Claude Code im Web (claude.ai/code) bekommen in Chrome jedes Format. Die Desktop-App Claude Desktop und lokale Claude-Code-Sitzungen im Terminal zeigen das Formatmenü nie. Öffnen Sie denselben Chat auf claude.ai in Chrome, falls er dort existiert.

Brauche ich Pro, um die Exportformate auszuprobieren?

Nein. Sechs Formate sind im kostenlosen Tarif unbegrenzt und ohne Konto nutzbar. PDF ist mit Google-Anmeldung bis zu 3-mal pro Tag kostenlos, gemeinsam mit dem Massenexport als ZIP. Pro kostet 3,99 $ im Monat oder 26,99 $ im Jahr, wenn Sie PDF oder Massenexporte unbegrenzt brauchen.
