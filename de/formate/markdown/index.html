Wie exportiere ich einen Claude Chat als Markdown?

Öffnen Sie die Unterhaltung auf claude.ai in Chrome, klicken Sie auf den orangefarbenen Button neben dem Eingabefeld, wählen Sie Markdown und klicken Sie auf „Export“. Download Claude conversations schreibt die .md-Datei lokal. So exportieren Sie in Version 1.13.0 einen Claude Chat als Markdown.

  1. Installieren Sie Download Claude conversations aus dem Chrome Web Store (Bewertung 5,0).
  2. Laden Sie claude.ai neu und öffnen Sie eine echte Unterhaltung, nicht die leere Startseite mit dem Eingabefeld.
  3. Klicken Sie auf den orangefarbenen Download-Button rechts neben dem Eingabefeld.
  4. Wählen Sie Markdown. Die Erweiterung merkt sich das zuletzt genutzte Format.
  5. Klicken Sie auf „Export“. Chrome lädt die .md-Datei über die Download-Schnittstelle des Browsers herunter.

Vor dem ersten Markdown-Export ist eine Google-Anmeldung nötig. Download Claude conversations speichert die bestätigte E-Mail-Adresse, um die 3 kostenlosen Exporte zu zählen und Pro nach einer Neuinstallation wiederherzustellen. Für diese Anmeldung wird kein Chat-Text hochgeladen. Technik: So funktioniert es.

Fehlt der orangefarbene Button, sind Sie nicht in einer Unterhaltung, der Tab braucht nach der Installation einen Neuladen, oder die Erweiterung steckt noch im Puzzle-Menü von Chrome. Pinnen Sie Download Claude conversations und laden Sie claude.ai neu. In Claude Desktop oder Claude Code wird das Content-Skript nie geladen.

Ein Chat oder viele. Der orangefarbene Button exportiert den offenen Chat als Markdown. Für viele .md-Dateien öffnen Sie „View and Download All Conversations“ (alle Unterhaltungen ansehen und herunterladen) und starten „Export All“ (alles exportieren) mit Markdown – siehe Massenexport mit Export All.

Warum Markdown für Notizen?

Exportieren Sie einen Claude Chat als Markdown, wenn Sie die Datei in Obsidian, einem GitHub-Wiki oder einem Editor lesen, der Überschriften und Codeblöcke darstellt. Die .md-Datei bleibt reiner Text, den Sie durchsuchen und vergleichen können. JSON eignet sich besser für Parser; PNG ist ein Bild, in dem Sie nicht suchen können.

Kopieren aus claude.ai verliert meist Einrückungen und macht Tabellen platt. Drucken (Ctrl/Cmd+P) behält die Seitenleiste und teilt lange Codeblöcke oft über Seiten. Beim Markdown-Export bleiben Sprach-Tags an den Codeblöcken und Tabellen bleiben Tabellen. Deshalb wählen Schreibende dieses Format zuerst.

Markdown ist für uns die lesbare Standarddatei: Überschriften, Codeblöcke mit Sprach-Tags und Tabellen aus dem claude.ai-Chat. Ein PDF-Format erfinden wir trotzdem nicht – brauchen Sie eine druckbare Seite, nutzen Sie den Druckdialog von Chrome, nach dem Markdown-Export oder stattdessen.

Was bleibt beim Markdown-Export erhalten?

Wenn Sie einen Claude Chat als Markdown exportieren, behält Download Claude conversations Überschriften, Codeblöcke mit Sprach-Tags und Einrückung, Tabellen und Links. Denkschritte sind optional. Metadaten (Titel, Zeitstempel, Modell) können mit hinein. Der Absenderfilter „all / human only / assistant only“ (alle / nur Mensch / nur Assistent) begrenzt die .md-Datei auf alle Nachrichten, nur Ihre oder nur Claudes.

Das Artefakt-Layout ist in Version 1.13.0 ein echter Schalter: „Original“, „Inline“, „Nested“ oder „Flat“ (original, eingebettet, verschachtelt, flach). Ein Markdown-Export kann die Artefakt-Struktur vom Bildschirm übernehmen oder alles zu einem linearen Dokument glätten. Alle Schalter: Funktionen der Chrome-Erweiterung. Die Farben der Nachrichtenblasen behält Markdown nicht; für einen optischen Schnappschuss nehmen Sie PNG.

Kann ich viele Chats auf einmal als Markdown exportieren?

Ja. Öffnen Sie „View and Download All Conversations“, stellen Sie das Format auf Markdown, filtern Sie die Tabelle und klicken Sie auf „Export All“. Jede fertige .md-Datei ist ein Export aus denselben 3 kostenlosen Exporten wie beim orangefarbenen Button. Pro für 3,99 $/Monat oder 26,99 $/Jahr hebt die Grenze für den Massenexport als Markdown auf.

Die Tabelle listet Ihren claude.ai-Verlauf mit Namenssuche und den Filtern „All“, „New“, „Exported“ und „Project“ (alle, neu, exportiert, Projekt). „New“ heißt: noch nicht mit Download Claude conversations exportiert. „Exported“ markiert bereits gespeicherte Chats, damit ein zweiter Durchlauf sie überspringen kann. „Project“ entspricht Ihrer Gruppierung auf claude.ai.

Das Kontingent gilt pro Konto. Insgesamt drei kostenlose Exporte – nicht drei Markdown-Dateien pro Tag. Wählen Sie 40 Unterhaltungen aus, verbrauchen Sie 40 Exporte, wenn jede .md-Datei fertig wird. Planen Sie die Auswahl, bevor Sie auf „Export All“ klicken.

Der Massenexport als Markdown nutzt dieselben Schalter für Denkschritte, Metadaten, Absender und Artefakte wie eine einzelne Unterhaltung. Export All ist nicht das verzögerte ZIP von Anthropic, sondern viele .md-Dateien pro Chat. Wollten Sie ein Archiv des ganzen Kontos, ist das Settings → Privacy → Export data (die Beschriftungen können übersetzt sein, wenn claude.ai auf Deutsch eingestellt ist) – und das ist JSON, nicht Markdown.

FAQ: Claude Chat als Markdown exportieren

Diese Fragen behandeln den Markdown-Export in Download Claude conversations 1.13.0: Codeblöcke, Export All, das ZIP von Anthropic, Kontingent und Desktop. Jede Antwort ist eine Produkt-Tatsache. Das FAQPage-JSON-LD im Kopf der Seite entspricht dieser Liste.

Geht beim Export als Markdown Code verloren?

Nein. Codeblöcke behalten Sprach-Tag und Einrückung, anders als beim einfachen Kopieren aus claude.ai. Tabellen bleiben Markdown-Tabellen. Das ist der Hauptgrund, einen Claude Chat als Markdown zu exportieren, statt Text von Hand zu markieren.

Kann ich viele Claude Chats auf einmal als Markdown exportieren?

Ja. Export All auf der Übersichtsseite unterstützt Markdown genauso wie der Einzelexport. Jede fertige .md-Datei zählt als einer der 3 kostenlosen Exporte, außer Sie haben Pro.

Ist Markdown dasselbe wie der Datenexport von Anthropic?

Nein. Der offizielle Export von Anthropic ist ein JSON-ZIP des ganzen Kontos, das nach einer Wartezeit per E-Mail kommt. Der Markdown-Export ist eine .md-Datei pro Chat (oder pro Auswahl) aus Download Claude conversations.

Kostet Markdown mehr als andere Formate?

Nein. Markdown ist in den 3 kostenlosen Exporten jedes per Google angemeldeten Kontos enthalten, genau wie JSON, Text, XML und PNG. Danach kostet Pro 3,99 $/Monat oder 26,99 $/Jahr für unbegrenzte Dateien.

Kann ich in Claude Desktop als Markdown exportieren?

Nein. Download Claude conversations läuft nur auf claude.ai in Chrome. Claude Desktop zeigt das Markdown-Menü nie. Öffnen Sie denselben Chat auf claude.ai, falls er dort existiert.

Erzeugt der Markdown-Export ein PDF?

Nein. Markdown ist eine .md-Textdatei. Das Produkt liefert kein PDF. Für eine druckbare Seite nutzen Sie den Druckdialog von Chrome. PNG ist ein Bild, ebenfalls kein PDF.

Brauche ich Pro für einen einzelnen Markdown-Export?

Nein. Die ersten 3 Exporte sind kostenlos, in jedem Format einschließlich Markdown. Pro für 3,99 $/Monat oder 26,99 $/Jahr hebt die Grenze für weitere einzelne oder gesammelte .md-Dateien auf.
