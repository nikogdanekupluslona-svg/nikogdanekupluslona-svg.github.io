Wie exportiere ich einen Claude Chat als Markdown?

Öffnen Sie die Unterhaltung auf claude.ai in Chrome, klicken Sie auf den orangefarbenen Button neben dem Eingabefeld, wählen Sie Markdown und klicken Sie auf „Export“. Download Claude conversations schreibt die .md-Datei lokal. So exportieren Sie in Version 1.16.2 einen Claude Chat als Markdown.

  1. Installieren Sie Download Claude conversations aus dem Chrome Web Store.
  2. Laden Sie claude.ai neu und öffnen Sie eine echte Unterhaltung, nicht die leere Startseite mit dem Eingabefeld.
  3. Klicken Sie auf den orangefarbenen Download-Button rechts neben dem Eingabefeld.
  4. Wählen Sie Markdown. Die Erweiterung merkt sich das zuletzt genutzte Format. Mit „Select“ (Auswählen) haken Sie nur die Nachrichten an, die Sie brauchen.
  5. Klicken Sie auf „Export“. Chrome lädt die .md-Datei über die Download-Schnittstelle des Browsers herunter. Oder klicken Sie auf „Copy“ (Kopieren), um das Markdown in die Zwischenablage zu legen.

Für den Markdown-Export eines Claude Chats ist keine Anmeldung nötig. Einzelexporte als Markdown sind unbegrenzt, anonym und senden nichts an unsere Server. Eine Google-Anmeldung wird nur für PDF und den Massenexport mit Export All verlangt. Technik: So funktioniert es.

Fehlt der orangefarbene Button, sind Sie nicht in einer Unterhaltung, der Tab braucht nach der Installation einen Neuladen, oder die Erweiterung steckt noch im Puzzle-Menü von Chrome. Pinnen Sie Download Claude conversations und laden Sie claude.ai neu. In Claude Desktop oder im Terminal von Claude Code wird das Content-Skript nie geladen.

Ein Chat oder viele. Der orangefarbene Button exportiert den offenen Chat als Markdown. Für viele .md-Dateien öffnen Sie „View and Download All Conversations“ (alle Unterhaltungen ansehen und herunterladen) und starten „Export All“ (alles exportieren) mit Markdown: ein ZIP, 3 Chats pro Tag im kostenlosen Tarif – siehe Massenexport mit Export All.

Warum Markdown für Notizen?

Exportieren Sie einen Claude Chat als Markdown, wenn Sie die Datei in Obsidian, einem GitHub-Wiki oder einem Editor lesen, der Überschriften und Codeblöcke darstellt. Die .md-Datei bleibt reiner Text, den Sie durchsuchen und vergleichen können. JSON eignet sich besser für Parser; PNG ist ein Bild, in dem Sie nicht suchen können.

Kopieren aus claude.ai verliert meist Einrückungen und macht Tabellen platt. Drucken (Ctrl/Cmd+P) behält die Seitenleiste und teilt lange Codeblöcke oft über Seiten. Beim Markdown-Export bleiben Sprach-Tags an den Codeblöcken und Tabellen bleiben Tabellen. Deshalb wählen Schreibende dieses Format zuerst.

Markdown ist für uns die lesbare Standarddatei: Überschriften, Codeblöcke mit Sprach-Tags und Tabellen aus dem claude.ai-Chat. Brauchen Sie stattdessen Seiten, wählen Sie im selben Panel PDF. Das PDF wird im Browser gesetzt, mit Seitengröße, Rändern und Inhaltsverzeichnis.

Was bleibt beim Markdown-Export erhalten?

Wenn Sie einen Claude Chat als Markdown exportieren, behält Download Claude conversations Überschriften, Codeblöcke mit Sprach-Tags und Einrückung, Tabellen und Links. Denkschritte, Quellen der Websuche und Tool-/MCP-Schritte sind jeweils optional: „Thinking“ (Denkprozess) ist ein Häkchen im Export-Panel, die anderen beiden schalten Sie in den Einstellungen ein. Metadaten (Titel, Zeitstempel, Modell) können mit hinein. Der Absenderfilter „all / human only / assistant only“ (alle / nur Mensch / nur Assistent) begrenzt die .md-Datei auf alle Nachrichten, nur Ihre oder nur Claudes.

Das Artefakt-Layout ist in Version 1.16.2 ein echter Schalter: „Original“, „Inline“, „Nested“ oder „Flat“ (original, eingebettet, verschachtelt, flach). Ein Markdown-Export kann die Artefakt-Struktur vom Bildschirm übernehmen, alles zu einem linearen Dokument glätten oder die Artefakte in einen eigenen Ordner im ZIP legen. In den Einstellungen können Sie Bilder in die .md-Datei einbetten. Alle Optionen: Funktionen der Chrome-Erweiterung. Die Farben der Nachrichtenblasen behält Markdown nicht; für einen optischen Schnappschuss nehmen Sie PNG, für Seiten PDF.

Kann ich viele Chats auf einmal als Markdown exportieren?

Ja. Öffnen Sie „View and Download All Conversations“, stellen Sie „Chat format“ (Chat-Format) auf Markdown, filtern Sie die Tabelle und klicken Sie auf „Export All“. Chrome speichert ein ZIP mit einer .md-Datei pro Chat. Im kostenlosen Tarif sind das 3 Chats pro Tag mit Google-Anmeldung, gemeinsam mit PDF. Pro für 3,99 $ im Monat oder 26,99 $ im Jahr hebt diese Grenze für den Massenexport als Markdown auf.

Das Dashboard listet Ihren claude.ai-Verlauf mit Namenssuche, den Filtern „All conversations“, „New“, „Updated“ und „Previously exported“ (alle Unterhaltungen, neu, aktualisiert, bereits exportiert), den Tabs „Chat“ und „Cowork“ und einer Projektsuche. „New“ heißt: noch nicht mit Download Claude conversations exportiert. „Previously exported“ markiert bereits gespeicherte Chats, damit ein zweiter Durchlauf sie überspringen kann.

Das Tageslimit gilt pro Konto. Drei Chats pro Tag im kostenlosen Tarif, gemeinsam mit PDF. Wählen Sie 40 Unterhaltungen aus, obwohl nur noch 3 übrig sind, wird der ganze Stapel blockiert, nicht gekürzt. Wählen Sie weniger aus oder nutzen Sie Pro. Einzelne .md-Exporte über den orangefarbenen Button bleiben unbegrenzt.

Der Massenexport als Markdown nutzt die Häkchen im Dashboard – „Chats“, „Thinking“, „Metadata“ (Metadaten), „Tools“ (Werkzeuge) und „Sources“ (Quellen) – plus das Artefakt-Format. Export All ist nicht das verzögerte ZIP von Anthropic, sondern ein ZIP mit einer .md-Datei pro Chat. Wollten Sie ein Archiv des ganzen Kontos, ist das Settings → Privacy → Export data (die Beschriftungen können übersetzt sein, wenn claude.ai auf Deutsch eingestellt ist) – und das ist JSON, nicht Markdown.

Markdown oder JSON beim Claude-Export?

Exportieren Sie einen Claude Chat als Markdown, wenn ein Mensch die Datei liest. Nehmen Sie JSON, wenn ein Skript den Nachrichtenbaum auswertet. Download Claude conversations bietet beides im selben Menü, dazu PDF, reinen Text, XML, CSV und PNG. Formatübersicht: Exportformate für Claude Chats.

Kostet der Markdown-Export extra?

Nein. Der Markdown-Export eines Chats ist kostenlos und unbegrenzt, ohne Konto und ohne Zähler – genau wie JSON, Text, XML, CSV und PNG. Nur PDF und der Massenexport mit Export All haben ein kostenloses Limit: 3 pro Tag mit Google-Anmeldung. Pro kostet 3,99 $ im Monat oder 26,99 $ im Jahr über Paddle. Download Claude conversations verlangt keinen Markdown-Aufpreis.

Das Limit zeigt sich erst beim Massenexport als Markdown. Jeder Chat in einem ZIP von Export All belegt einen der 3 Plätze pro Tag, und der Zähler beginnt um Mitternacht UTC neu. Pro hebt das Limit auf und wird auf einem neuen Computer über dasselbe Google-Konto wiederhergestellt. Paddle ist Händler (Merchant of Record); dieses Team sieht nie Kartennummern.

FAQ: Claude Chat als Markdown exportieren

Diese Fragen behandeln den Markdown-Export in Download Claude conversations 1.16.2: Codeblöcke, Export All, das ZIP von Anthropic, Kosten, PDF und Desktop. Jede Antwort ist eine Produkt-Tatsache. Das FAQPage-JSON-LD im Kopf der Seite entspricht dieser Liste.

Geht beim Export als Markdown Code verloren?

Nein. Codeblöcke behalten Sprach-Tag und Einrückung, anders als beim einfachen Kopieren aus claude.ai. Tabellen bleiben Markdown-Tabellen. Das ist der Hauptgrund, einen Claude Chat als Markdown zu exportieren, statt Text von Hand zu markieren.

Kann ich viele Claude Chats auf einmal als Markdown exportieren?

Ja. Export All im Dashboard unterstützt Markdown und speichert ein ZIP mit .md-Dateien. Im kostenlosen Tarif deckt das 3 Chats pro Tag mit Google-Anmeldung ab; mit Pro ist es unbegrenzt.

Ist Markdown dasselbe wie der Datenexport von Anthropic?

Nein. Der offizielle Export von Anthropic ist ein JSON-ZIP des ganzen Kontos, das nach einer Wartezeit per E-Mail kommt. Der Markdown-Export ist eine .md-Datei pro Chat (oder pro Auswahl) aus Download Claude conversations.

Kostet Markdown mehr als andere Formate?

Nein. Einzelexporte als Markdown sind unbegrenzt und brauchen kein Konto, genau wie JSON, Text, XML, CSV und PNG. Nur PDF und der Massenexport als ZIP haben ein kostenloses Limit von 3 pro Tag. Pro kostet 3,99 $ im Monat oder 26,99 $ im Jahr.

Kann ich in Claude Desktop als Markdown exportieren?

Nein. Download Claude conversations läuft nur auf claude.ai in Chrome. Claude Desktop zeigt das Markdown-Menü nie. Öffnen Sie denselben Chat auf claude.ai, falls er dort existiert.

Erzeugt der Markdown-Export ein PDF?

Nein. Markdown ist eine .md-Textdatei. Für Seiten wählen Sie stattdessen im selben Panel PDF: Es entsteht im Browser, mit Seitengröße, Rändern und Inhaltsverzeichnis. PDF erfordert eine Google-Anmeldung und zählt im kostenlosen Tarif zu den 3 pro Tag.

Brauche ich Pro für einen einzelnen Markdown-Export?

Nein. Sie brauchen überhaupt kein Konto. Markdown-Exporte einzelner Chats sind im kostenlosen Tarif unbegrenzt. Pro für 3,99 $ im Monat oder 26,99 $ im Jahr hebt nur das Limit von 3 pro Tag für den Massenexport mit Export All und für PDF auf.
