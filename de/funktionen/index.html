Welche Funktion exportiert einen einzelnen Chat?

Die zentrale Funktion für einen einzelnen Chat ist der orangefarbene Button, den Download Claude conversations neben dem Eingabefeld auf claude.ai einfügt. Öffnen Sie eine Unterhaltung, wählen Sie ein Format und klicken Sie auf „Export“ (Exportieren) oder „Copy“. Die Datei wird sofort heruntergeladen. Nur PDF verlangt eine Anmeldung; die anderen sechs Formate brauchen kein Konto.

  1. Installieren Sie Download Claude conversations aus dem Chrome Web Store.
  2. Laden Sie claude.ai neu und öffnen Sie eine echte Unterhaltung – einen Chat, einen Chat in einem Projekt, eine Cowork-Sitzung oder Claude Code im Web.
  3. Klicken Sie auf den orangefarbenen Download-Button rechts neben dem Eingabefeld.
  4. Wählen Sie unter „Messages“ (Nachrichten) „All“, „Human“ oder „Assistant“ (alle, Mensch, Assistent), dann ein Format und das Kontrollkästchen „Thinking“ (Denkschritte) – oder klicken Sie auf „Select“, um einzelne Nachrichten anzuhaken. Die Erweiterung merkt sich das zuletzt genutzte Format.
  5. Klicken Sie auf „Export“, um die Datei herunterzuladen, oder auf „Copy“, um sie in die Zwischenablage zu legen. „Copy“ funktioniert für Markdown, Text, JSON, XML und CSV.

Der orangefarbene Button erscheint nur in einer geladenen Unterhaltung. Auf der leeren Startseite gibt es nichts auszulesen. Fehlt der Button, pinnen Sie die Erweiterung im Puzzle-Menü von Chrome und laden Sie claude.ai neu. In Claude Desktop oder im Terminal von Claude Code erscheinen diese Funktionen nie. Wählen Sie PDF, öffnet sich ein Dialog für Dateiname, Seitenformat, Ränder, hellen oder dunklen Modus, Schriftart und Schriftgröße, Seitenzahlen, Inhaltsverzeichnis, Zeitstempel und einen Seitenumbruch vor jedem Prompt: Claude Chat als PDF.

Lokale Datei. PDF, Markdown, JSON, Text, XML, CSV und PNG entstehen im Tab. Einzelne Chats in den Formaten außer PDF senden nichts an unsere Server. PDF und Massenexport senden nur Ihre Google-E-Mail-Adresse für die Tageszählung. Chat-Text verlässt den Browser nie. Technik: So funktioniert es.

Welche Funktionen gehören zu Export All?

Die Funktionen für den Massenexport liegen im Dashboard „View and Download All Conversations“ (alle Unterhaltungen ansehen und herunterladen): Suche, die Filter „All conversations / New / Updated / Previously exported“ (alle Unterhaltungen / neu / aktualisiert / bereits exportiert), die Tabs „Chat“ und „Cowork“, die Projektsuche und „Export All“. Export All speichert ein ZIP. Der kostenlose Tarif umfasst 3 Chats pro Tag mit Google-Anmeldung; Pro für 3,99 $ im Monat oder 26,99 $ im Jahr hebt diese Grenze auf.

„New“ heißt: noch nicht mit Download Claude conversations exportiert. „Previously exported“ markiert bereits gespeicherte Chats, damit ein zweiter Durchlauf von Export All sie überspringen kann. Der Tab „Cowork“ listet Cowork-Sitzungen neben normalen Chats. Die Projektsuche findet die Chats innerhalb eines claude.ai-Projekts. Gesucht wird nach dem Namen der Unterhaltung. Ganzer Ablauf: Massenexport mit Export All.

Das Tageslimit gilt pro Konto. Drei Chats pro Tag im kostenlosen Tarif, gemeinsam mit PDF – nicht drei pro Durchlauf. Wählen Sie 40 Unterhaltungen aus, obwohl nur noch 3 übrig sind, wird der ganze Durchlauf blockiert, nicht gekürzt. Planen Sie die Auswahl, bevor Sie auf „Export All“ klicken, oder nutzen Sie Pro.

Export All nutzt die Formatauswahl „Chat format“ (Chat-Format) im Dashboard (alle sieben Formate, auch PDF), die Kontrollkästchen „Chats“, „Thinking“, „Metadata“, „Tools“ und „Sources“ (Chats, Denkschritte, Metadaten, Tools, Quellen) sowie das Artefakt-Format. Es entsteht ein ZIP mit einer Datei pro Chat, nicht das verzögerte Konto-ZIP von Anthropic. Pro Durchlauf wählen Sie ein Format. Markdown und JSON in einem Klick zu mischen ist nicht vorgesehen. Das Dashboard bietet außerdem Sicherung und Wiederherstellung.

Welche Formate schreibt die Chrome-Erweiterung?

Die Chrome-Erweiterung schreibt sieben Formate: PDF, Markdown, reinen Text, JSON, XML, CSV und PNG. Markdown, Text, JSON, XML, CSV und PNG sind unbegrenzt und ohne Konto nutzbar. PDF entsteht im Browser, erfordert eine Google-Anmeldung und zählt im kostenlosen Tarif zu den 3 pro Tag. Die Liste ist beim orangefarbenen Button und in der Formatauswahl „Chat format“ im Dashboard gleich. Formatseiten: Exportformate für Claude Chats.

Behält die Erweiterung Artefakte?

Ja. Zu den Funktionen gehört das Artefakt-Layout: „Original“, „Inline“, „Nested“ oder „Flat“ (original, eingebettet, verschachtelt, flach). Denkschritte, Tool-/MCP-Schritte und Websuche-Quellen sind jeweils optional: „Thinking“ ist ein Kontrollkästchen im Export-Panel, Tools und Quellen schalten Sie in den Einstellungen ein, und das Dashboard hat Kontrollkästchen für alle drei. Metadaten ergänzen Titel, Zeitstempel und Modell. Der Absenderfilter begrenzt die Datei auf alle Nachrichten, nur Ihre oder nur Claudes, und „Select“ hakt einzelne Nachrichten an.

Artefakte sind Teil des claude.ai-Chats. Das Layout entscheidet, ob sie in der Markdown-, JSON-, XML- oder Textdatei stehen oder in einem eigenen Ordner innerhalb eines ZIPs landen. Artefakt-ZIPs sind unbegrenzt und kostenlos, ebenso das ZIP mit Projektdateien: Klicken Sie auf einer Projektseite auf „Project files“ → „Download ZIP“ (Projektdateien → ZIP herunterladen). Im PNG werden Artefakte gezeichnet, nicht als Auszeichnung gespeichert. Sind die Denkschritte abgeschaltet, fehlt das erweiterte Nachdenken im Export, auch wenn claude.ai es angezeigt hat.

Ist der Chat lang, scrollen Sie, bis claude.ai frühere Nachrichten geladen hat. Die Erweiterung kann nur exportieren, was die Seite dargestellt hat. Ein halb geladenes DOM ergibt eine abgeschnittene Datei. Das sieht aus wie ein Fehler mit fehlenden Artefakten, ist aber meist eine nicht gescrollte Unterhaltung.

Dort finden Sie die Dateinamen-Vorlage, „Copy instead of download“ (kopieren statt herunterladen), eingebettete Bilder in Markdown, Tool-/MCP-Schritte, Websuche-Quellen, das Datums- und Zeitformat, Sicherung und Wiederherstellung sowie Ihr Abo. Wie funktioniert die Anmeldung?

Die meisten Funktionen brauchen keine Anmeldung. Exporte einzelner Chats als Markdown, reiner Text, JSON, XML, CSV und PNG sind unbegrenzt und anonym, ebenso „Copy“, „Select“, Artefakt-ZIPs und das ZIP mit Projektdateien. Eine Google-Anmeldung wird nur für PDF, den Massenexport mit Export All und Pro abgefragt. Unterhaltungsinhalte sind nie Teil dieses Ablaufs.

PDF und ZIP-Massenexport teilen sich im kostenlosen Tarif 3 pro Tag, gezählt auf unserem Server anhand Ihrer Google-E-Mail-Adresse. Der Tag beginnt um Mitternacht UTC neu, und eine Neuinstallation setzt den Zähler nicht zurück. Pro kostet 3,99 $ im Monat oder 26,99 $ im Jahr über Paddle. Paddle ist Händler (Merchant of Record); dieses Team sieht nie Kartennummern. Pro wird auf einem neuen Computer wiederhergestellt, wenn Sie sich mit demselben Google-Konto anmelden.

Einen bezahlten claude.ai-Tarif von Anthropic brauchen Sie nicht. Free, Pro, Team und Enterprise funktionieren, wenn Chrome den Chat öffnen kann. Sperrt ein Workspace-Admin Erweiterungen, wird Download Claude conversations nicht geladen – das ist eine Browser-Richtlinie, keine fehlende Funktion.

Welche Funktionen fehlen in 1.16.2?

Diese Funktionen gibt es in 1.16.2 nicht: Export nach Notion, Export nach Word, Übertragung zu Google Docs, Anbindung an Claude Desktop und lokale Terminal-Sitzungen von Claude Code (/export, ~/.claude/projects). Download Claude conversations ist ein Content-Skript für claude.ai in Chrome, keine zweite App unter anderem Namen. PDF steht nicht mehr auf dieser Liste – es ist eingebaut.

Claude Desktop ist eine App für Mac und Windows. Claude Code im Terminal ist ein lokaler Agent. Keines von beiden bekommt den orangefarbenen Button. Claude Code im Web (claude.ai/code) und Cowork-Sitzungen öffnen sich auf claude.ai und lassen sich daher wie jeder Chat exportieren. Existiert ein Desktop-Chat auch auf claude.ai, öffnen Sie ihn in Chrome und nutzen Sie dort die Erweiterung. Abgrenzung zu Desktop: Claude Desktop Chat exportieren. FAQ: Funktionen der Chrome-Erweiterung

Diese Fragen behandeln die Funktionen von Download Claude conversations 1.16.2: orangefarbener Button, Export All, Formate, Artefakte, kostenloser Tarif, Desktop und Pro. Jede Antwort ist eine Produkt-Tatsache. Das FAQPage-JSON-LD im Kopf der Seite entspricht dieser Liste.

Welche Funktion der Chrome-Erweiterung exportiert einen einzelnen Chat?

Der orangefarbene Button neben dem Eingabefeld auf einer claude.ai-Unterhaltung. Wählen Sie PDF, Markdown, JSON, Text, XML, CSV oder PNG und klicken Sie auf „Export“ oder „Copy“. Das ist der schnellste Weg für einen einzelnen Chat, und nur PDF erfordert eine Anmeldung.

Gehört der Massenexport Export All zu den Funktionen?

Ja. Das Dashboard („View and Download All Conversations“) listet den claude.ai-Verlauf mit den Filtern „All conversations“, „New“, „Updated“ und „Previously exported“, den Tabs „Chat“ und „Cowork“ und einer Projektsuche. Export All speichert ein ZIP. Der kostenlose Tarif umfasst 3 Chats pro Tag mit Google-Anmeldung; Pro ist unbegrenzt.

Welche Formate unterstützt die Chrome-Erweiterung?

Sieben: PDF, Markdown, reiner Text, JSON, XML, CSV und PNG. PDF entsteht im Browser, mit eigenem Dialog. CSV enthält eine Zeile pro Nachricht. PNG ist ein Bild der Unterhaltung.

Exportiert die Erweiterung Artefakte und Denkschritte?

Ja. Das Artefakt-Layout ist „Original“, „Inline“, „Nested“ oder „Flat“, und Artefakte können in einen eigenen Ordner innerhalb eines ZIPs wandern. Denkschritte, Tool-/MCP-Schritte und Websuche-Quellen sind jeweils optional. Metadaten, Absenderfilter und „Select“ ebenfalls.

Kann ich die Funktionen kostenlos ausprobieren?

Ja. Exporte als Markdown, Text, JSON, XML, CSV und PNG sind unbegrenzt und brauchen kein Konto. PDF und ZIP-Massenexport sind mit Google-Anmeldung 3-mal pro Tag möglich. Pro für 3,99 $ im Monat oder 26,99 $ im Jahr über Paddle hebt diese Grenze auf.

Funktioniert die Erweiterung in Desktop oder Code?

Nicht in Claude Desktop und nicht im Terminal von Claude Code. Das Content-Skript läuft nur auf claude.ai in Chrome. Claude Code im Web (claude.ai/code) und Cowork-Sitzungen laufen dort, also lassen sie sich exportieren. Öffnen Sie einen Desktop-Chat auf claude.ai, falls er dort existiert.

Lädt die Erweiterung meine Chats hoch?

Nein. Jede Datei, auch PDF, entsteht im Browser. Einzelne Chats in den anderen Formaten senden nichts. Für PDF, Massenexport oder Pro wird nur Ihre Google-E-Mail-Adresse übermittelt – für die Tageszählung und das Abo. Die Grenze erklärt „So funktioniert es“.
