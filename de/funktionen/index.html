Welche Funktion exportiert einen einzelnen Chat?

Die zentrale Funktion für einen einzelnen Chat ist der orangefarbene Button, den Download Claude conversations neben dem Eingabefeld auf claude.ai einfügt. Öffnen Sie eine Unterhaltung, wählen Sie Markdown, JSON, Text, XML oder PNG und klicken Sie auf „Export“ (Exportieren). Die Datei wird sofort heruntergeladen.

  1. Installieren Sie Download Claude conversations aus dem Chrome Web Store (Bewertung 5,0).
  2. Laden Sie claude.ai neu und öffnen Sie eine echte Unterhaltung, nicht die leere Startseite mit dem Eingabefeld.
  3. Klicken Sie auf den orangefarbenen Download-Button rechts neben dem Eingabefeld.
  4. Wählen Sie ein Format. Die Erweiterung merkt sich das zuletzt genutzte Format.
  5. Klicken Sie auf „Export“. Chrome speichert die Datei über die Download-Schnittstelle des Browsers.

Der orangefarbene Button erscheint nur in einer geladenen Unterhaltung. Auf der leeren Startseite gibt es nichts auszulesen. Fehlt der Button, pinnen Sie die Erweiterung im Puzzle-Menü von Chrome und laden Sie claude.ai neu. In Claude Desktop oder Claude Code erscheinen diese Funktionen nie.

Lokale Datei. Markdown, JSON, Text, XML und PNG entstehen im Tab. Kontingent-Prüfungen gehen an unseren Worker, Chat-Text nicht. Technik: So funktioniert es.

Welche Funktionen gehören zu Export All?

Die Funktionen für den Massenexport liegen auf „View and Download All Conversations“ (alle Unterhaltungen ansehen und herunterladen): eine durchsuchbare Tabelle Ihres claude.ai-Verlaufs, die Filter „All / New / Exported / Project“ (alle / neu / exportiert / Projekt) und „Export All“. Jede fertige Datei ist einer der 3 kostenlosen Exporte. Pro für 3,99 $/Monat oder 26,99 $/Jahr hebt die Grenze auf.

„New“ heißt: noch nicht mit Download Claude conversations exportiert. „Exported“ markiert bereits gespeicherte Chats, damit ein zweiter Durchlauf sie überspringen kann. „Project“ entspricht Ihrer Gruppierung auf claude.ai. Gesucht wird nach dem Namen der Unterhaltung. Ganzer Ablauf: Massenexport mit Export All.

Das Kontingent gilt pro Konto. Insgesamt drei kostenlose Exporte – nicht drei pro Durchlauf. Wählen Sie 40 Unterhaltungen aus, verbrauchen Sie 40 Exporte, wenn jede Datei fertig wird. Planen Sie die Auswahl, bevor Sie auf „Export All“ klicken, oder nutzen Sie Pro.

Export All nutzt dieselben Schalter für Denkschritte, Metadaten, Absender und Artefakte wie eine einzelne Unterhaltung. Es entstehen viele Einzeldateien pro Chat, nicht das verzögerte Konto-ZIP von Anthropic. Pro Durchlauf wählen Sie ein Format. Markdown und JSON in einem Klick zu mischen ist nicht vorgesehen.

Welche Formate schreibt die Chrome-Erweiterung?

Die Chrome-Erweiterung schreibt fünf Formate: Markdown, JSON, reinen Text, XML und PNG. Die Liste ist beim orangefarbenen Button und bei Export All gleich. In Version 1.13.0 gibt es kein PDF. Jede fertige Datei zählt als ein Export. Formatseiten: Exportformate für Claude Chats.

PDF, Notion oder Word liefern wir weiterhin nicht. Ändert sich das, ändert sich diese Seite am selben Tag.

Wer schreibt, nimmt meist Markdown. Wer entwickelt, meist JSON. PNG ist ein Bild; darin können Sie nicht suchen. Drucken Sie in Chrome, wenn Sie eine PDF-ähnliche Seite brauchen. Dieser Druck ist eine Browserfunktion, keine Funktion dieser Erweiterung.

Behält die Erweiterung Artefakte?

Ja. Zu den Funktionen gehört das Artefakt-Layout: „Original“, „Inline“, „Nested“ oder „Flat“ (original, eingebettet, verschachtelt, flach). Denkschritte lassen sich per „include thinking“ (Denkschritte einbeziehen) mitnehmen, etwa für Recherche-Verläufe. „include metadata“ (Metadaten einbeziehen) ergänzt Titel, Zeitstempel und Modell. Der Absenderfilter „all / human only / assistant only“ (alle / nur Mensch / nur Assistent) begrenzt die Datei auf alle Nachrichten, nur Ihre oder nur Claudes.

Artefakte sind Teil des claude.ai-Chats, kein separater Download. Das Layout bestimmt, wie sie in Markdown, JSON, XML und Text stehen. Im PNG werden sie gezeichnet, nicht als Auszeichnung gespeichert. Sind die Denkschritte abgeschaltet, fehlt das erweiterte Nachdenken im Export, auch wenn claude.ai es angezeigt hat.

Ist der Chat lang, scrollen Sie, bis claude.ai frühere Nachrichten geladen hat. Die Erweiterung kann nur exportieren, was die Seite dargestellt hat. Ein halb geladenes DOM ergibt eine abgeschnittene Datei. Das sieht aus wie ein Fehler mit fehlenden Artefakten, ist aber meist eine nicht gescrollte Unterhaltung.

Wie funktioniert die Anmeldung?

Ab dem ersten Export ist eine Google-Anmeldung nötig. Die Erweiterung nutzt sie, um die 3 kostenlosen Exporte pro Konto zu zählen und Pro nach einer Neuinstallation wiederherzustellen. Unterhaltungsinhalte sind nie Teil dieses Ablaufs. Download Claude conversations speichert eine von Google bestätigte E-Mail-Adresse für Kontingent und Abo-Status.

Die 3 kostenlosen Exporte setzen sich bei einer Neuinstallation nicht zurück. Genau dafür ist die Anmeldung da. Pro kostet 3,99 $ im Monat oder 26,99 $ im Jahr über Paddle. Paddle ist Händler (Merchant of Record); dieses Team sieht nie Kartennummern. Pro wird auf einem neuen Computer über dasselbe Google-Konto wiederhergestellt.

Einen bezahlten claude.ai-Tarif von Anthropic brauchen Sie nicht. Free, Pro, Team und Enterprise funktionieren, wenn Chrome den Chat öffnen kann. Sperrt ein Workspace-Admin Erweiterungen, wird Download Claude conversations nicht geladen – das ist eine Browser-Richtlinie, keine fehlende Funktion.

Welche Funktionen fehlen in 1.13.0?

Diese Funktionen gibt es in 1.13.0 nicht: natives PDF, Export nach Notion, Export nach Word, Übertragung zu Google Docs, Anbindung an Claude Desktop und /export von Claude Code. Download Claude conversations ist ein Content-Skript für claude.ai in Chrome, keine zweite App unter anderem Namen.

Claude Desktop ist eine App für Mac und Windows. Claude Code ist der Agent im Terminal. Keines von beiden bekommt den orangefarbenen Button. Existiert der Chat auch auf claude.ai, öffnen Sie ihn in Chrome und nutzen Sie dort die Erweiterung. Abgrenzung zu Desktop: Claude Desktop Chat exportieren. Abgrenzung zu Code: Claude Code Export.

claude.ai im Handy-Browser gehört nicht dazu. Eine App für iOS oder Android gibt es von diesem Team 2026 nicht. Stand: September 2026. Kommt ein Format hinzu, wird diese Seite am selben Tag aktualisiert. Bis dahin erwarten Sie kein PDF im Auswahlmenü.

FAQ: Funktionen der Chrome-Erweiterung

Diese Fragen behandeln die Funktionen von Download Claude conversations 1.13.0: orangefarbener Button, Export All, Formate, Artefakte, Kontingent, Desktop und Pro. Jede Antwort ist eine Produkt-Tatsache. Das FAQPage-JSON-LD im Kopf der Seite entspricht dieser Liste.

Welche Funktion der Chrome-Erweiterung exportiert einen einzelnen Chat?

Der orangefarbene Button neben dem Eingabefeld auf einer claude.ai-Unterhaltung. Wählen Sie Markdown, JSON, Text, XML oder PNG und klicken Sie auf „Export“. Das ist der schnellste Weg für einen einzelnen Chat.

Gehört der Massenexport Export All zu den Funktionen?

Ja. „View and Download All Conversations“ listet den claude.ai-Verlauf mit den Filtern „All“, „New“, „Exported“ und „Project“. Export All schreibt eine Datei pro ausgewähltem Chat. Jede Datei zählt als einer der 3 kostenlosen Exporte, außer Sie haben Pro.

Welche Formate unterstützt die Chrome-Erweiterung?

Markdown, JSON, reiner Text, XML und PNG. PDF gibt es nicht. PNG ist ein Bild. Drucken Sie den claude.ai-Tab in Chrome, wenn Sie eine PDF-ähnliche Seite brauchen.

Exportiert die Erweiterung Artefakte und Denkschritte?

Ja. Das Artefakt-Layout ist „Original“, „Inline“, „Nested“ oder „Flat“. Denkschritte sind ein Schalter. Metadaten und Absenderfilter sind optional. Dieselben Schalter gelten für Export All.

Kann ich die Funktionen kostenlos ausprobieren?

Ja. Jedes per Google angemeldete Konto bekommt 3 kostenlose Exporte in beliebigem Format. Pro kostet 3,99 $/Monat oder 26,99 $/Jahr über Paddle für weitere Einzel- oder Massenexporte.

Funktioniert die Erweiterung in Desktop oder Code?

Nein. Das Content-Skript läuft nur auf claude.ai in Chrome. Claude Desktop und Claude Code zeigen den orangefarbenen Button nie. Öffnen Sie denselben Chat auf claude.ai, falls er dort existiert.

Lädt die Erweiterung meine Chats hoch?

Nein. Die Dateien entstehen im Browser. Die Google-Anmeldung speichert eine bestätigte E-Mail-Adresse für Kontingent und Pro-Wiederherstellung. Chat-Inhalte werden nicht an unseren Worker geschickt. Die Grenze erklärt „So funktioniert es“.
