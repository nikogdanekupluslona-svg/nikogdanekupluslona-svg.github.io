Wie exportiere ich einen Claude Chat von claude.ai?

Öffnen Sie die Unterhaltung auf claude.ai in Chrome, klicken Sie auf den orangefarbenen Button neben dem Nachrichtenfeld, wählen Sie PDF, Markdown, JSON, Nur-Text, XML, CSV oder PNG und klicken Sie auf „Export“. Download Claude conversations schreibt diese Datei lokal. Eine eigene Funktion „diesen Chat exportieren“ hat claude.ai selbst im September 2026 nicht.

  1. Installieren Sie Download Claude conversations aus dem Chrome Web Store.
  2. Laden Sie claude.ai neu und öffnen Sie eine echte Unterhaltung, nicht die leere Startseite mit dem Eingabefeld.
  3. Klicken Sie auf den runden orangefarbenen Download-Button rechts neben dem Nachrichtenfeld.
  4. Stellen Sie im Panel „Messages“ (Nachrichten) auf „All“, „Human“ oder „Assistant“ (alle, nur Ihre, nur Claudes) und wählen Sie dann ein Format. Setzen Sie das Häkchen bei „Thinking“ (Denkprozess), um erweitertes Denken aufzunehmen, oder haken Sie mit „Select“ (Auswählen) einzelne Nachrichten an. Die Claude-Export-Erweiterung merkt sich das zuletzt genutzte Format.
  5. Klicken Sie auf „Export“. Chrome speichert die Datei sofort über die Download-Funktion des Browsers. „Copy“ (Kopieren) legt Markdown, Text, JSON, XML oder CSV stattdessen in die Zwischenablage.

Um einen Claude Chat als Markdown, Text, JSON, XML, CSV oder PNG zu exportieren, brauchen Sie kein Konto. Diese Exporte einzelner Chats sind unbegrenzt, und die Erweiterung sendet dafür nichts an unsere Server. Heften Sie Download Claude conversations an und laden Sie claude.ai neu. Die Claude-Export-Erweiterung wird nur auf claude.ai eingebunden, nie auf anderen Websites.

Was macht eine Claude-Export-Erweiterung genau?

Eine Claude-Export-Erweiterung liest die Unterhaltung, die in Ihrem angemeldeten claude.ai-Tab bereits angezeigt wird, und schreibt eine strukturierte Datei auf die Festplatte. Download Claude conversations ist dieses Chrome-Content-Script: Absender, Nachrichtenbaum, Codeblöcke, Tabellen, optional das Denken und das Artefakt-Layout – kein Screenshot der Oberfläche rund um den Chat. Sie funktioniert in normalen Chats, in Projekten, in Cowork-Sitzungen und in Claude Code im Web.

Beim Kopieren aus claude.ai geht die Einrückung verloren und Tabellen fallen zusammen. Drucken (Ctrl/Cmd+P) behält die Seitenleiste und trennt lange Codeblöcke oft über Seiten hinweg. Die Claude-Export-Erweiterung behält Sprachangaben an Codeblöcken und lässt Tabellen in Markdown, JSON und XML als Tabellen stehen. PNG ist die Option für eine optische Momentaufnahme. PDF ist die Variante mit Seiten, direkt im Browser erzeugt, ohne Druckdialog.

Das Artefakt-Layout ist in Version 1.16.2 ein echter Schalter: „Original“, „Inline“, „Nested“ (verschachtelt) oder „Flat“ (flach), einzustellen im Dashboard. Erweitertes Denken ist ein Häkchen im Export-Panel; Quellen der Websuche und Tool-/MCP-Schritte schalten Sie in den Einstellungen zu. Metadaten (Titel, Zeitstempel, Modell) können mitkommen. Der Filter „Messages“ beschränkt die Datei auf alle Nachrichten, nur Mensch oder nur Assistent, und mit „Select“ haken Sie einzelne Nachrichten an. Vollständige Liste: Funktionen.

Funktioniert der Export in Desktop oder Claude Code?

Claude Desktop ist eine eigene App für Mac und Windows, und der orangefarbene Button erscheint weder dort noch in einem Terminal.
