Wie exportiere ich einen Claude Chat von claude.ai?

Öffnen Sie die Unterhaltung auf claude.ai in Chrome, klicken Sie auf den orangefarbenen Button neben dem Nachrichtenfeld, wählen Sie Markdown, JSON, Nur-Text, XML oder PNG und klicken Sie auf „Export“. Download Claude conversations schreibt diese Datei lokal. Eine eigene Funktion „diesen Chat exportieren“ hat claude.ai selbst im September 2026 nicht.

  1. Installieren Sie Download Claude conversations aus dem Chrome Web Store (Eintrag mit 5,0 bewertet).
  2. Laden Sie claude.ai neu und öffnen Sie eine echte Unterhaltung, nicht die leere Startseite mit dem Eingabefeld.
  3. Klicken Sie auf den orangefarbenen Download-Button rechts neben dem Nachrichtenfeld.
  4. Wählen Sie ein Format. Die Claude-Export-Erweiterung merkt sich das zuletzt genutzte Format.
  5. Klicken Sie auf „Export“. Chrome speichert die Datei sofort über die Download-Funktion des Browsers.

Vor dem ersten Export ist eine Google-Anmeldung nötig. Download Claude conversations speichert die bestätigte E-Mail-Adresse, um die 3 kostenlosen Exporte zu zählen und Pro nach einer Neuinstallation wiederherzustellen. Der Chattext gehört nicht zu dieser Anmeldung. Technik: So funktioniert es.

Heften Sie Download Claude conversations an und laden Sie claude.ai neu. Die Claude-Export-Erweiterung wird nur auf claude.ai eingebunden, nie auf anderen Websites.

Was macht eine Claude-Export-Erweiterung genau?

Eine Claude-Export-Erweiterung liest die Unterhaltung, die in Ihrem angemeldeten claude.ai-Tab bereits angezeigt wird, und schreibt eine strukturierte Datei auf die Festplatte. Download Claude conversations ist dieses Chrome-Content-Script: Absender, Nachrichtenbaum, Codeblöcke, Tabellen, optional das Denken und das Artefakt-Layout – kein Screenshot der Oberfläche rund um den Chat.

Beim Kopieren aus claude.ai geht die Einrückung verloren und Tabellen fallen zusammen. Drucken (Ctrl/Cmd+P) behält die Seitenleiste und trennt lange Codeblöcke oft über Seiten hinweg. Die Claude-Export-Erweiterung behält Sprachangaben an Codeblöcken und lässt Tabellen in Markdown, JSON und XML als Tabellen stehen. PNG ist die Option für eine optische Momentaufnahme; auch das ist kein PDF.

Das Artefakt-Layout ist in Version 1.13.0 ein echter Schalter: „Original“, „Inline“, „Nested“ (verschachtelt) oder „Flat“ (flach). Denkblöcke sind optional („include thinking“). Metadaten (Titel, Zeitstempel, Modell) können mitkommen („include metadata“). Der Absenderfilter kann die Datei auf alle Nachrichten, nur Mensch oder nur Assistent beschränken („all / human only / assistant only“). Vollständige Liste: Funktionen.

Wir haben den orangefarbenen Button gebaut, um aus dem Chat, der bereits auf claude.ai offen ist, eine echte Datei zu schreiben – Markdown, JSON, Text, XML oder PNG –, ohne den Chat auf unsere Server hochzuladen. Auch Version 1.13.0 erzeugt kein PDF.

Kann ich Claude Chats mit Export All gesammelt exportieren?

Die Übersichtstabelle listet Ihren claude.ai-Verlauf mit Suche nach Namen und den Filtern Alle, Neu, Exportiert und Projekt. Neu heißt: noch nicht mit Download Claude conversations exportiert. Exportiert erfasst Chats, die Sie bereits gespeichert haben, damit ein zweiter Durchlauf von Export All sie überspringen kann. Projekt entspricht der Gruppierung Ihrer Chats auf claude.ai.

Der Massenexport nutzt dieselben Schalter wie eine einzelne Unterhaltung: Chats, Denken, Metadaten, Artefakt-Layout („Original“, „Inline“, „Nested“, „Flat“) und dieselben fünf Formate. Export All ist kein abgespecktes ZIP. Es sind viele Dateien, eine pro Chat. Wenn Sie ein verzögertes Archiv des ganzen Kontos wollten, ist das Export data von Anthropic – verglichen im nächsten Abschnitt und auf der Seite Alle Claude Chats exportieren.

Das Kontingent gilt für das ganze Konto. Insgesamt drei kostenlose Exporte – nicht drei pro Massenexport. Was bedeutet „Claude Chat exportieren“ auf dieser Website?

Eine claude.ai-Unterhaltung mit Download Claude conversations als Datei speichern: orangefarbener Button, Formatauswahl, „Export“. Dieselbe Aufgabe wie das englische „claude export chat“. Nicht das ZIP von Anthropic per E-Mail und nicht /export in Claude Code.

Ist eine Claude-Export-Erweiterung dasselbe wie Export data?

Nein. Settings → Privacy → Export data ist ein JSON-ZIP des ganzen Kontos per E-Mail. Die Claude-Export-Erweiterung schreibt den geöffneten Chat oder eine Auswahl über Export All sofort in Chrome als Markdown, JSON, Text, XML oder PNG.

Kann ich einen Claude Chat als PDF exportieren?

Nicht mit dieser Claude-Export-Erweiterung. Die Formate sind Markdown, JSON, Nur-Text, XML und PNG. Für eine PDF-ähnliche Momentaufnahme drucken Sie die claude.ai-Seite in Chrome. PNG ist ein Bild, kein PDF.

Brauche ich Pro, um einen Claude Chat einmal zu exportieren?

Nein. Die ersten 3 Exporte sind für jedes mit Google angemeldete Konto kostenlos, in jedem Format. Pro für 3,99 $/Monat oder 26,99 $/Jahr hebt die Grenze für weitere Einzel- oder Massenexporte auf.

Funktioniert der Export mit jedem claude.ai-Tarif?

Ja. Die claude.ai-Tarife Free, Pro, Team und Enterprise funktionieren, wenn Sie die Unterhaltung in Chrome öffnen können. Die Claude-Export-Erweiterung setzt keinen kostenpflichtigen Tarif von Anthropic voraus.

Ist diese Claude-Export-Erweiterung für Claude Code?

Nein. Download Claude conversations läuft auf claude.ai in Chrome. Claude Code nutzt /export oder JSONL auf der Festplatte. Siehe die Anleitung Claude Code Chat exportieren.

Kann ich einen Claude Chat aus Claude Desktop exportieren?

Wie viele kostenlose Exporte bietet die Claude-Export-Erweiterung?

Drei pro Konto, gemeinsam für den orangefarbenen Button und Export All. Eine Neuinstallation setzt den Zähler nicht zurück. Pro wird über die Google-Anmeldung wiederhergestellt.

Wo ist der orangefarbene Button zum Exportieren?

Rechts neben dem Nachrichtenfeld in einer claude.ai-Unterhaltung, nachdem Sie Download Claude conversations installiert und die Seite neu geladen haben. Auf der leeren Startseite mit dem Eingabefeld und in Desktop erscheint er nicht.

Lädt der Export meine Unterhaltungen hoch?
