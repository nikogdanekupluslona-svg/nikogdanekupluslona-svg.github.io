Speichert Claude die Unterhaltung nicht schon im Verlauf?

Ja. Claude.ai legt den Chat einer angemeldeten Sitzung bereits im Verlauf des Anthropic-Kontos ab. Das Schließen des Tabs löscht die Unterhaltung nicht. Trotzdem gibt es keine Speichern-Funktion, die eine Datei auf die Festplatte schreibt. Eine Unterhaltung als Markdown oder JSON zu sichern, ist eine eigene Aufgabe neben dem Verlauf.

Der Verlauf ist die Liste der Chats links auf claude.ai. Jede Zeile ist eine Unterhaltung, die Anthropic für diesen Login gespeichert hat. Öffnen Sie eine Zeile später, kommen dieselben Runden zurück. Das ist Speicher im Konto, kein Download-Ordner auf Ihrem Laptop.

Wer fragt, wie man eine Unterhaltung in Claude speichert, meint oft: „Ist das weg, wenn ich die Seite verlasse?“ Bei einer normalen angemeldeten Sitzung lautet die Antwort nein. Claude.ai braucht keinen Klick auf „Speichern“, um den Chat im Konto zu behalten. Was fehlt, ist ein Exporter für Dateien, kein Schalter zum Aufbewahren.

Der Verlauf ist keine Markdown-Datei, kein durchsuchbarer JSON-Baum und kein PNG für eine Folie. Er liegt hinter dem Anthropic-Login. Wenn Sie sich nicht anmelden können, können Sie diese Chats nicht öffnen. Eine lokale Datei lässt sich auch ohne Passwort noch öffnen.

Zwei Arten von „Speichern“. Verlauf = Anthropic behält den Chat im Konto. Datei = Sie schreiben PDF, Markdown, JSON, Text, XML, CSV oder PNG auf die Festplatte. Claude.ai bietet das Erste. Für das Zweite hat claude.ai keinen Button.

„Projects“ und „Recents“ auf claude.ai gehören ebenfalls zum Verlauf. Einen Chat einem Projekt zuzuordnen, erzeugt keine Datei. Die Unterhaltung umzubenennen, erzeugt keine Datei. Markieren oder Anheften, falls die Oberfläche das anbietet, schreibt ebenfalls kein Markdown. Download Claude conversations exportiert Chats in einem Projekt wie jeden anderen, und auf einer Projektseite speichert „Project files“ → „Download ZIP“ (Projektdateien → ZIP herunterladen) die Dateien des Projekts.

Für Team- und Enterprise-Workspaces gilt dieselbe Trennung. Wenn Sie die Unterhaltung auf claude.ai öffnen können, hat Anthropic sie für den Workspace bereits gespeichert. Aufbewahrungsregeln des Unternehmens können Chats trotzdem nach einem Zeitplan löschen oder ausblenden, den Sie nicht steuern. Eine exportierte Datei ist dann die Kopie, die Ihnen bleibt.

Inkognito-Fenster und ein zweites Chrome-Profil teilen keinen Verlauf. Der Chat hängt an dem Anthropic-Konto, das in dieser Sitzung genutzt wurde. Ein anderer Anthropic-Login zeigt einen anderen Verlauf. „Speichern“ über Konten hinweg ist eine Datei, keine Zusammenführung von Verläufen.

Die Chrome-Erweiterung ist der Weg pro Chat. Drucken ist der optische Weg. Ctrl+P oder Cmd+P, Ziel „Als PDF speichern“. Das Ergebnis sieht aus wie die claude.ai-Seite, einschließlich Bedienelementen, die die Druckansicht nicht ausblendet. Das ZIP enthält JSON für das ganze Konto, keine benannte Datei für den Chat auf dem Bildschirm. Die Wartezeit ist der Preis für ein vollständiges Backup.

Wie speichere ich eine Unterhaltung als Markdown oder JSON?

Öffnen Sie den orangefarbenen Button auf claude.ai, wählen Sie das Format und klicken Sie auf „Export“. Markdown ist die Notizdatei. JSON ist der Nachrichtenbaum für Skripte. Nur-Text hat kein Markup. CSV ist eine Zeile pro Nachricht. PDF ist ein Dokument mit Seiten. PNG ist ein Bild.

Markdown behält Überschriften, Codeblöcke mit Sprachangabe und Tabellen. Markdown ist die übliche Wahl für Obsidian, GitHub oder ein Wiki. Hinweise zum Layout dieses Formats: Markdown-Export. JSON bewahrt den Baum, den der Parser bereits aufgebaut hat, einschließlich Artefakten und Denkblöcken, wenn diese Schalter aktiv sind.

JSON aus Download Claude conversations hat nicht dieselbe Struktur wie das Konto-ZIP von Anthropic. Das JSON der Erweiterung ist eine Unterhaltung, so wie die Seite sie angezeigt hat. Das JSON aus Export data ist ein Konto-Dump, den Anthropic später per E-Mail schickt. Mischen Sie die beiden Schemas nicht in einem Skript, ohne die Schlüssel zu prüfen.

Nur-Text ist richtig, wenn das Ziel Markup entfernt – ein Feld in einem Ticketsystem, der Text einer E-Mail, ein Suchindex, der reine Zeichenketten erwartet. XML ist die Nischenwahl für den Datenaustausch. CSV öffnet sich in Excel, Google Sheets oder Numbers. PNG ist für eine Folie oder eine Abbildung des Chats in einem Fehlerbericht gedacht, nicht für ein Review mit 40 Runden, das Sie später durchsuchen.

FAQ: Claude Chat speichern

Wie speichere ich eine Claude-Unterhaltung als Datei?

Installieren Sie Download Claude conversations, öffnen Sie den Chat auf claude.ai, klicken Sie auf den orangefarbenen Button rechts neben dem Nachrichtenfeld, wählen Sie PDF, Markdown, JSON, Text, XML, CSV oder PNG und klicken Sie auf „Export“. Die Datei wird lokal heruntergeladen, ohne Konto – außer bei PDF. Der Verlauf hat den Chat bereits im Anthropic-Konto gespeichert; der orangefarbene Button schreibt eine Kopie auf die Festplatte.

Wie speichere ich einen Claude Chat auf claude.ai?

Um den Chat im Konto zu behalten, brauchen Sie keinen Speichern-Button. Der Verlauf auf claude.ai listet angemeldete Chats bereits auf. Um einen Claude Chat als Datei zu speichern, nutzen Sie die Chrome-Erweiterung, Drucken → Als PDF speichern oder Settings → Privacy → Export data für ein verzögertes JSON-ZIP des Kontos.

Wie speichere ich eine Unterhaltung in Claude ohne Erweiterung?

Drucken Sie die claude.ai-Seite (Ctrl/Cmd+P → Als PDF speichern) für eine optische Kopie, oder nutzen Sie Settings → Privacy → Export data für ein JSON-ZIP des ganzen Kontos per E-Mail. Kopieren und Einfügen reicht für eine kurze Antwort. Keine dieser Methoden erzeugt eine strukturierte Markdown-Datei pro Chat, wie es die Chrome-Erweiterung tut.

Speichert Claude die Unterhaltung nicht schon im Verlauf?

Ja. Angemeldete Chats auf claude.ai bleiben im Verlauf des Anthropic-Kontos. Tab schließen, neu laden oder ein anderes Gerät mit demselben Login öffnen löscht den Chat nicht. Der Verlauf ist aber keine PDF-, Markdown-, JSON- oder sonstige Datei auf Ihrer Festplatte.

Verschwindet eine Claude-Unterhaltung, wenn ich den Tab schließe?

Nein. Das Schließen eines claude.ai-Tabs löscht die Unterhaltung nicht aus dem Verlauf. Das Löschen des Chats im Verlauf entfernt ihn dagegen aus der Oberfläche des Kontos. Eine Datei, die Sie bereits mit Download Claude conversations exportiert haben, bleibt auch danach auf der Festplatte.

Kann ich eine Claude-Unterhaltung als PDF speichern?

Ja. Download Claude conversations 1.16.2 exportiert PDF direkt: Wählen Sie im Panel des orangefarbenen Buttons PDF und klicken Sie auf „Export“. Die Datei entsteht im Browser, ganz ohne Druckdialog. PDF erfordert eine Google-Anmeldung und ist bis zu 3-mal pro Tag kostenlos; mit Pro unbegrenzt. Anleitung: Claude Chat als PDF.

Wie viele Dateien kann ich kostenlos speichern?

Unbegrenzt viele als Markdown, Nur-Text, JSON, XML, CSV und PNG, ganz ohne Konto. PDF und Massenexport als ZIP teilen sich im kostenlosen Tarif 3 pro Tag, mit Google-Anmeldung; jeder Chat in einem ZIP-Massenexport zählt als einer, und der Tag beginnt um Mitternacht UTC neu. Pro kostet 3,99 $ pro Monat oder 26,99 $ pro Jahr und hebt die Grenze auf. Die Zahlung wickelt Paddle ab.

Funktioniert das Speichern auf dem Smartphone?

Die Chrome-Erweiterung nicht. Sie läuft in Chrome am Desktop (oder einem anderen Chromium-Browser, der Erweiterungen aus dem Chrome Web Store installieren kann). Es gibt keine iOS- oder Android-App. Mobile Browser können den Verlauf öffnen und einen Claude Chat drucken, zeigen aber den orangefarbenen Button nicht an.

Kann ich Claude Chats aus dem Verlauf gesammelt speichern?

Ja. Öffnen Sie im Popup der Erweiterung „View and Download All Conversations“, filtern Sie die Tabelle und klicken Sie auf „Export All“. Der Massenexport erfordert eine Google-Anmeldung und zählt im kostenlosen Tarif zu den 3 pro Tag. Dieser Massenexport ist nicht das Export-data-ZIP von Anthropic. Der offizielle Datenexport ist ein Archiv des gesamten Kontos, das später per E-Mail kommt. Siehe Alle Claude Chats exportieren.

Speichert die Erweiterung Unterhaltungen aus Claude Code?

Nur im Web. Sitzungen aus Claude Code im Web (claude.ai/code) speichern Sie wie jeden anderen claude.ai-Chat. Lokale Terminal-Sitzungen nicht: Nutzen Sie dafür /export oder kopieren Sie JSONL aus ~/.claude/projects (Windows: %USERPROFILE%\.claude\projects). Diese Chrome-Erweiterung läuft nur auf claude.ai. Anleitung: Claude Code Chat exportieren.

Ist eine Google-Anmeldung nötig, um einen Claude Chat zu speichern?

Nein, nicht für Markdown, Nur-Text, JSON, XML, CSV oder PNG. Eine Google-Anmeldung ist nur für PDF, den Massenexport mit „Export All“ und Pro nötig, damit wir die Grenze von 3 pro Tag anwenden und Pro nach einer Neuinstallation wiederherstellen können. Mit dieser Anmeldung werden keine Gesprächsinhalte übertragen. Wir speichern die bestätigte E-Mail-Adresse nur für Kontingent und Pro-Status.

Wo finde ich den offiziellen Datenexport für Claude Chats?

Auf claude.ai: Settings → Privacy → Export data. Anthropic schickt einen Link per E-Mail, der abläuft. Das ZIP ist ein JSON-Archiv auf Kontoebene, keine benannte Markdown-Datei für den Chat, den Sie gerade gelesen haben. Nutzen Sie Export data als Backup und den orangefarbenen Button für eine sofort lesbare Datei.
