Wie funktioniert die Erweiterung auf claude.ai?

So funktioniert die Erweiterung auf claude.ai: Sie fügt ein Content-Skript in die Seite ein, die Sie bereits geöffnet haben, und nutzt die Sitzung, mit der Sie schon angemeldet sind. Sie liest die dargestellte Unterhaltung, keine separate Schnittstelle von Anthropic. Der orangefarbene Button erscheint nur in einer echten Unterhaltung.

  1. Installieren Sie Download Claude conversations aus dem Chrome Web Store (Bewertung 5,0).
  2. Laden Sie claude.ai neu, falls der Tab während der Installation offen war.
  3. Öffnen Sie eine Unterhaltung. Der orangefarbene Button sitzt rechts neben dem Eingabefeld.
  4. Wählen Sie Markdown, JSON, reinen Text, XML oder PNG. Klicken Sie auf „Export“ (Exportieren).
  5. Chrome lädt die Datei herunter. Das ist der gesamte Ablauf im Browser.

Die leere Startseite mit dem Eingabefeld hat keinen Nachrichtenbaum, daher erscheint dort kein Button. Ist das Symbol versteckt, pinnen Sie die Erweiterung im Puzzle-Menü von Chrome und laden claude.ai neu. Die Erweiterung endet an der Grenze von claude.ai: Claude Desktop und Claude Code bekommen dieses Skript nie. Funktionsliste: Funktionen der Chrome-Erweiterung.

Dieselbe Sitzung, dieselbe Seite. Das Content-Skript sieht, was Ihr angemeldeter claude.ai-Tab ohnehin zeigt. Es meldet sich nicht mit einem zweiten Passwort bei Anthropic an. Halten Sie sich an die Regeln von Anthropic für Ihr Konto.

Entstehen die Dateien lokal?

Ja. Markdown, JSON, reiner Text, XML und PNG werden in Ihrem Browser zusammengesetzt und an die Download-Schnittstelle von Chrome übergeben. Unterhaltungstext verlässt Ihr Gerät nie in Richtung unserer Infrastruktur. Das gilt für einen einzelnen Export über den orangefarbenen Button ebenso wie für „Export All“ (alles exportieren) auf der Massenexport-Seite.

Hat claude.ai den Chat geladen, wartet die Erzeugung der Datei nicht auf unseren Server. Kontingent- und Lizenzprüfungen sind eine eigene Anfrage. Blockiert Chrome Downloads von claude.ai, erlauben Sie sie; das ist eine Browser-Einstellung, kein fehlgeschlagenes Auslesen. Ein langer, nur halb gescrollter Chat ergibt trotzdem eine halbe Datei, weil das DOM unvollständig war.

Wir haben die Erweiterung um eine harte Grenze gebaut: Chat-Inhalte bleiben im Tab; unser Worker beantwortet nur „wie viele kostenlose Exporte sind übrig“ und „hat dieses Google-Konto Pro“. Wir laden weiterhin keine Chats hoch, um Markdown, JSON, Text, XML oder PNG zu erzeugen, und wir erzeugen weiterhin kein PDF.

PNG wird lokal als Bild erzeugt. JSON und XML werden lokal aus demselben Baum serialisiert. Keine dieser Dateien verschicken wir per E-Mail. Warum braucht das Kontingent eine Google-Anmeldung?

Die Google-Anmeldung gibt es, damit die Erweiterung 3 kostenlose Exporte pro Konto zählen und Pro nach einer Neuinstallation wiederherstellen kann. Sie ist ab dem ersten Klick auf „Export“ nötig. Wir speichern die bestätigte E-Mail-Adresse, keinen Chat-Text.

Die 3 kostenlosen Exporte setzen sich nicht zurück, wenn Sie die Erweiterung entfernen und neu hinzufügen. Deshalb ist die Anmeldung nicht optional. Ohne sie würde jede Neuinstallation still drei neue Dateien freischalten. Pro für 3,99 $/Monat oder 26,99 $/Jahr wird auf einem neuen Computer über dasselbe Google-Konto wiederhergestellt.

Die Google-Anmeldung ist kein Login bei claude.ai. Auf der Website nutzen Sie weiterhin Ihre Sitzung bei Anthropic. Die Erweiterung braucht Google nur als Schlüssel für das Kontingent. Viele suchen dieselbe Erweiterung auch als Claude Chat Downloader; die Regel zur Anmeldung ist dieselbe.

Das Kontingent gilt pro Konto. Insgesamt drei kostenlose Exporte, jedes Format, einschließlich Export All. Wählen Sie 40 Unterhaltungen aus, verbrauchen Sie 40 Exporte, wenn jede Datei fertig wird. Die Anmeldung sorgt dafür, dass dieser Zähler eine Neuinstallation übersteht.

Wie funktioniert die Zahlung mit Paddle und Pro?

Paddle.com Market Limited ist Zahlungsabwickler und Händler (Merchant of Record). Für die Abrechnung heißt das: Paddle erfasst Kartendaten und Steuern. Wir sehen nie Zahlungsdaten. Pro kostet 3,99 $ im Monat oder 26,99 $ im Jahr. Erstattungen laufen über Paddle.

Pro hebt die Grenze von 3 Exporten für den orangefarbenen Button und für Export All auf. PDF, Notion oder Word kommen dadurch nicht hinzu. Die Formate bleiben Markdown, JSON, Text, XML und PNG. Einen bezahlten claude.ai-Tarif von Anthropic brauchen Sie nicht. Jedes claude.ai-Login, das den Chat in Chrome lädt, genügt.

Was sieht der Worker beim Export?

Ein Cloudflare Worker prüft den Abo-Status: ob das per Google angemeldete Konto Pro hat und wie viele kostenlose Exporte es verbraucht hat. Unterhaltungsinhalte erhält dieser Worker nicht. Export und Lizenzprüfung sind zwei getrennte Wege. Nur die Lizenzprüfung erreicht unsere Server.

Der Worker ist der Grund, warum eine Neuinstallation die 3 kostenlosen Exporte nicht zurücksetzt – und warum Pro wiederhergestellt wird. Er ist keine Chat-Sicherung. Ihren claude.ai-Verlauf hält weiterhin Anthropic. Eine zweite Kopie behalten wir nicht. Die Datenschutzerklärung dieser Website beschreibt die gespeicherte E-Mail-Adresse.

Version 1.13.0, September 2026. Ist der Worker nicht erreichbar, kann ein Export blockiert sein, bis der Status geprüft ist. Das ist eine Lizenzsperre, keine Pflicht, den Chat hochzuladen. Nach erfolgreicher Prüfung entstehen die Dateien weiterhin lokal.

„Null Netzwerkverkehr“ versprechen wir nicht. Die Erweiterung spricht weiterhin mit Google, Paddle, claude.ai und unserem Worker. Chat-Inhalte gehen nicht an unsere Schnittstelle, Lizenz- und Anmeldestatus schon. Das Skript führt keine zusätzlichen Aktionen in Ihrem Anthropic-Konto aus.

Speichert Download Claude conversations meine Chats?

Nein. Exporte entstehen lokal und werden nie hochgeladen. Wir speichern nur eine von Google bestätigte E-Mail-Adresse, um die kostenlosen Exporte und den Pro-Status zu verfolgen. Chat-Inhalte bleiben im claude.ai-Tab und in der Datei, die Chrome herunterlädt.

Ist die Google-Anmeldung Pflicht oder optional?

Pflicht, ab dem ersten Export. So setzen wir die 3 kostenlosen Exporte durch, ohne dass eine Neuinstallation den Zähler zurücksetzt. Es ist kein Login, um Ihre Chats zu lesen.

Wer wickelt die Zahlung für Pro ab?

Paddle. Ihre Kartendaten sehen wir nie. Pro kostet 3,99 $/Monat oder 26,99 $/Jahr. Paddle ist Händler (Merchant of Record). Erstattungen laufen über Paddle.

Ist das mit Anthropic verbunden?

Nein. Unabhängige Chrome-Erweiterung, nicht mit Anthropic, PBC verbunden. Claude ist eine Marke von Anthropic. Die Erweiterung nutzt Ihre bestehende claude.ai-Sitzung; sie ersetzt keine Produkte von Anthropic.

Gibt es ein PDF-Format?

Nein. Die Dateien sind Markdown, JSON, reiner Text, XML oder PNG, alle lokal erzeugt. Für eine PDF-ähnliche Seite drucken Sie den claude.ai-Tab in Chrome. PNG ist ein Bild, kein PDF.

Was sieht der Worker bei einem Export?

Den Abo-Status: ob Pro aktiv ist und wie viele kostenlose Exporte das per Google angemeldete Konto verbraucht hat. Unterhaltungsinhalte erhält der Worker nicht. Der Export selbst bleibt im Browser.

Brauche ich Pro, damit die Erweiterung funktioniert?

Nein. Die ersten 3 Exporte sind auf jedem per Google angemeldeten Konto kostenlos. Pro für 3,99 $/Monat oder 26,99 $/Jahr hebt die Grenze für weitere Einzel- oder Massenexporte auf. Der lokale Ablauf ist bei Gratis und Pro derselbe.
