Wie lade ich einen Claude Chat mit Chrome herunter?

Die direkte Antwort ist der orangefarbene Button, den Download Claude conversations neben dem Nachrichtenfeld auf claude.ai einfügt. Öffnen Sie die Unterhaltung, wählen Sie Markdown, JSON, Text, XML oder PNG und klicken Sie auf „Export“ (Exportieren). Die Datei wird in Ihrem Browser zusammengesetzt und auf der Festplatte gespeichert.

Die Erweiterung ist ein Chrome-Content-Script. Sie liest die Unterhaltung, die in Ihrer angemeldeten claude.ai-Sitzung bereits geladen ist. Sie ruft keine separate Anthropic-API mit eigenen Zugangsdaten auf und lädt den Chat nicht auf unsere Server hoch, um die Datei zu erzeugen.

  1. Installieren Sie Download Claude conversations aus dem Chrome Web Store (Chromium-Browser, die Chrome-Erweiterungen laden, funktionieren ebenfalls).
  2. Laden Sie claude.ai neu, falls die Seite während der Installation schon geöffnet war.
  3. Öffnen Sie die gewünschte Unterhaltung – der orangefarbene Button erscheint nur in einem echten Chat, nicht auf der leeren Startseite mit dem Eingabefeld.
  4. Klicken Sie auf den orangefarbenen Download-Button rechts neben dem Nachrichtenfeld.
  5. Wählen Sie Markdown, JSON, Nur-Text, XML oder PNG. Klicken Sie auf „Export“. Chrome lädt die Datei sofort herunter.

Vor dem ersten Export ist eine Google-Anmeldung nötig. Sie dient dazu, die 3 kostenlosen Exporte pro Konto zu zählen und Pro später wiederherzustellen. Sie ist kein Login, um Ihre Chats zu lesen. Wir speichern eine von Google bestätigte E-Mail-Adresse für Kontingent und Abo-Status. Die Gesprächsinhalte bleiben auf Ihrem Rechner.

Jede fertige Datei zählt als ein Export, ob Markdown oder PNG. Kostenlose Konten haben insgesamt 3 Exporte. Pro kostet 3,99 $ pro Monat oder 26,99 $ pro Jahr und hebt diese Grenze auf – für einzelne Chats und für den Massenexport mit Export All.

Lokale Dateien. Markdown, JSON, Text, XML und PNG werden im Browser erzeugt und an die Download-Funktion von Chrome übergeben. Die Kontingentprüfung läuft über unseren Worker. Der Chattext nicht.

Optionale Schalter im selben Widget: erweitertes Denken aufnehmen oder weglassen („include thinking“), Metadaten mitnehmen („include metadata“: Titel, Zeitstempel, Modell), nach Absender filtern („all / human only / assistant only“ – alle, nur Mensch, nur Assistent) und ein Artefakt-Layout wählen – „Original“, „Inline“, „Nested“ (verschachtelt) oder „Flat“ (flach). Diese Schalter wirken auf diesen einen Chat genauso wie auf der Übersichtsseite für den Massenexport.

Bei sehr langen Chats scrollen Sie, bis claude.ai auch die früheren Nachrichten geladen hat. Die Erweiterung kann nur exportieren, was die Seite angezeigt hat. Ein halb geladener Chat ergibt eine halbe Datei – das wirkt wie ein Fehler, ist aber meist nur ein nicht gescrolltes DOM.

Wir lesen den Nachrichtenbaum auf der claude.ai-Seite aus, die Sie bereits geöffnet haben. Codeblöcke behalten Sprachangabe und Einrückung, Tabellen bleiben Tabellen. Wir erfinden kein PDF-Format – wenn Sie eine druckbare Seite brauchen, nutzen Sie den Druckdialog des Browsers, keinen vorgetäuschten „Als PDF exportieren“-Schalter.

Kann ich einen Claude Chat ohne Erweiterung herunterladen?

Ja. Ohne Erweiterung können Sie die Seite drucken oder den Kontoexport von Anthropic anfordern. Drucken ergibt ein optisches PDF der Webseite. Export data ist ein verzögertes JSON-ZIP des gesamten Kontos. Keiner der beiden Wege erzeugt eine Markdown-Datei pro Chat.

Drucken: Öffnen Sie die Unterhaltung auf claude.ai, blenden Sie die Seitenleiste aus, falls die Oberfläche das erlaubt, drücken Sie Ctrl+P (Windows/Linux) oder Cmd+P (Mac), wählen Sie als Ziel „Als PDF speichern“ und speichern Sie. Codeblöcke werden oft über Seiten hinweg getrennt. Das Eingabefeld kann auf jedem Blatt erscheinen. Alle Hinweise zum Drucken finden Sie unter Claude Chat als PDF speichern.

Offizieller Weg: Settings → Privacy → Export data auf claude.ai (die Bezeichnungen können übersetzt sein, wenn claude.ai auf Deutsch eingestellt ist). Anthropic schickt einen Link per E-Mail, der abläuft. Das ZIP ist ein JSON-Archiv auf Kontoebene, keine benannte Datei für den Chat, den Sie gerade gelesen haben. Nutzen Sie es als Backup und entpacken Sie es selbst, wenn Sie eine Unterhaltung aus Tausenden brauchen.

Kopieren und Einfügen ist der dritte Weg ohne Erweiterung. Text markieren, in Docs oder eine Notiz-App einfügen. Die Einrückung von Code geht meist verloren. Tabellen werden zu Fließtext. Ein Chat mit vielen Runden wird zu einer unstrukturierten Textwand. Für eine kurze Antwort reicht das. Für ein Code-Review, das Sie später durchsuchen wollen, nicht.

Wie lade ich den Claude-Verlauf komplett herunter?

Wenn Sie Ihren Claude-Verlauf als viele Dateien herunterladen wollen, klicken Sie nicht in jedem Tab einzeln auf den orangefarbenen Button. Öffnen Sie im Popup der Erweiterung „View and Download All Conversations“ (alle Unterhaltungen anzeigen und herunterladen), filtern Sie die Tabelle und klicken Sie auf „Export All“ (alle exportieren). Jede fertige Datei zählt weiterhin zu denselben 3 kostenlosen Exporten, sofern Sie nicht Pro nutzen.

Die Übersichtsseite listet die Unterhaltungen des claude.ai-Kontos, in dem Sie angemeldet sind. Suchen Sie nach Namen. Filtern Sie nach Alle, Neu (noch nicht exportiert), Exportiert und nach Projekt, wenn Sie Chats auf claude.ai so gruppieren. Wählen Sie eine Teilmenge aus, wenn nicht jeder alte Entwurf im Ordner landen soll.

Der Massenexport nutzt dieselben fünf Formate und dieselben Schalter wie der Export eines einzelnen Chats: Denken, Metadaten, Absenderfilter, Artefakt-Layout. Export All ist keine abgespeckte Variante. Es ist derselbe Parser, angewendet auf viele Unterhaltungs-IDs in einem Durchgang. Details und Screenshots: Alle Claude Chats exportieren.

Export data von Anthropic bleibt das Konto-Backup. Ein ZIP, eine E-Mail, JSON für alles – auch für Chats, die Sie vergessen haben. Export All ist die umgekehrte Aufgabe: Sie wählen die Chats, Sie wählen Markdown oder JSON, die Dateien kommen sofort. Nutzen Sie beides, wenn Sie ein lückenloses Archiv und einen Ordner mit lesbaren Notizen wollen.

Das Kontingent ist gemeinsam. Drei kostenlose Exporte gelten für einzelne Chats und Dateien aus dem Massenexport zusammen. Wenn Sie in einem kostenlosen Konto 40 Unterhaltungen auswählen, stoppt der Export nach der dritten Datei. Planen Sie die Auswahl oder wechseln Sie zu Pro für 3,99 $/Monat oder 26,99 $/Jahr.

Die Tabelle merkt sich außerdem, was Sie bereits exportiert haben. Beim nächsten Besuch können Sie also nur nach „Neu“ filtern. So bleibt ein wöchentlicher Download Ihres Claude-Verlaufs inkrementell, statt die Markdown-Dateien vom letzten Monat zu duplizieren.

Wie lade ich einen Claude Chat als Markdown oder JSON herunter?

Öffnen Sie den orangefarbenen Button, wählen Sie das Format und klicken Sie auf „Export“. Markdown ist die Notizdatei. JSON ist der Nachrichtenbaum für Skripte. Nur-Text hat kein Markup. PNG ist ein Bild, kein PDF.

Markdown behält Überschriften, Codeblöcke mit Sprachangabe und Tabellen. Es ist die übliche Wahl für Obsidian, GitHub oder ein Wiki. JSON bewahrt den Baum, den der Parser bereits aufgebaut hat, einschließlich Artefakten und Denkblöcken, wenn diese Schalter aktiv sind. Die Struktur ist nicht dieselbe wie im Konto-ZIP von Anthropic. Hinweise zu den Formaten: alle Formate.

Nur-Text ist richtig, wenn das Ziel Markup ohnehin entfernt – ein Feld in einem Ticketsystem, der Text einer E-Mail, ein Suchindex, der reine Zeichenketten erwartet. XML ist die Nischenwahl für den Datenaustausch. PNG ist für eine Folie oder einen Screenshot des Chats in einem Fehlerbericht gedacht, nicht für ein Design-Review mit 40 Runden, das Sie später durchsuchen.

Version 1.13.0 hat kein natives PDF. Wenn ein Kunde ein PDF verlangt, exportieren Sie Markdown und drucken diese Datei aus Word, Google Docs, VS Code oder Obsidian. Oder drucken Sie claude.ai selbst. Warten Sie nicht auf eine .pdf-Option, die diese Erweiterung nicht anbietet. Schritte zur Konvertierung: Drucken und PDF.

Das zuletzt genutzte Format wird gespeichert. Wenn Sie Markdown wollten und JSON bekommen haben, stand das Auswahlmenü noch von vorher auf JSON. Prüfen Sie das Menü jedes Mal, wenn Sie die Aufgabe wechseln.

Claude-Unterhaltung speichern, drucken oder als ZIP?

Speichern, herunterladen und exportieren sind auf claude.ai dieselbe Aufgabe: den Chat von der Seite holen. Wer eine Claude-Unterhaltung als Arbeitsdatei speichern will, nutzt die Erweiterung. Drucken ist eine Momentaufnahme. Export data von Anthropic ist ein Konto-ZIP.

In Teams werden die Begriffe oft gemischt. Eine Forscherin sagt speichern. Ein Entwickler sagt exportieren. Eine Managerin sagt herunterladen. Auf dieser Website führen alle drei Verben zum selben orangefarbenen Button, wenn Sie claude.ai in Chrome nutzen. Die Anleitung Claude Chat exportieren geht ausführlicher auf das offizielle ZIP und die JSON-Strukturen ein.

Drucken hat trotzdem seinen Platz: ein einmaliger Anhang, der wie das Produkt aussehen soll. Auch Export data hat seinen Platz: beim Verlassen einer Firma, bei einer rechtlichen Aufbewahrungspflicht oder als doppelte Absicherung. Keins von beiden ersetzt eine Markdown-Datei, die Sie nächste Woche bearbeiten.

Claude Desktop ist ein anderes Fenster. Die Chrome-Erweiterung wird nicht in die Desktop-App eingebunden. Wenn derselbe Chat auf claude.ai existiert, öffnen Sie ihn dort und laden ihn herunter. Wenn er nur in Desktop existiert, kopieren Sie ihn oder warten auf das Konto-ZIP. Schritte: Claude Desktop Chat exportieren.

Paddle wickelt Pro-Zahlungen ab. Wir sehen keine Kartennummern. Die Google-Anmeldung gibt uns keinen Zugriff auf die Unterhaltung. Der Cloudflare-Worker, der den Pro-Status prüft, erhält den Lizenzstatus, keinen Nachrichtentext. Diese Grenze ist die ganze Datenschutz-Geschichte: Abrechnung auf dem Server, Chat auf der Festplatte.

Warum fehlt der Button zum Herunterladen?

Der Button fehlt, wenn Sie nicht in einer Unterhaltung sind, der Tab nach der Installation nicht neu geladen wurde oder die Erweiterung deaktiviert ist. Heften Sie das Symbol an, laden Sie neu und prüfen Sie, dass Sie in Chrome am Desktop auf claude.ai sind – nicht in Desktop, auf dem Smartphone oder in Claude Code.

Nach der Installation fügt Chrome ein Content-Script nicht immer in bereits geöffnete Tabs ein. Schließen Sie den claude.ai-Tab oder laden Sie ihn hart neu. Wenn Sie mehrere Profile nutzen, muss die Erweiterung in dem Profil installiert sein, das bei Anthropic angemeldet ist.

Team- und Enterprise-Workspaces funktionieren, wenn Sie die Unterhaltung im Browser öffnen können. Die Erweiterung liest die Seite, nicht den Tarif. Wenn Ihre Organisation Chrome-Erweiterungen blockiert, muss die IT diese freigeben; von der Website aus können wir diese Richtlinie nicht umgehen.

Anmeldeabfrage: erwartet. Beim ersten Klick auf „Export“ fragt Google nach. Wenn Sie die Abfrage abbrechen, sieht das wie ein fehlgeschlagener Download aus. Schließen Sie die Anmeldung ab und klicken Sie erneut auf „Export“. Für die 3 kostenlosen Exporte ist keine Kreditkarte nötig.

Unvollständige Datei: Die Antwort wurde noch gestreamt, oder ältere Runden waren noch nicht gerendert. Warten Sie, bis der Assistent fertig ist. Scrollen Sie in einem langen Chat zum Anfang, damit claude.ai diese Nachrichten lädt, und exportieren Sie erneut. In der kostenlosen Stufe kostet das einen weiteren Export – ein Grund, vorher zu prüfen, ob der Chat vollständig geladen ist.

Falscher Dateityp: Das zuletzt genutzte Format war noch ausgewählt. Falsches Konto: Sie haben sich bei Google mit einer anderen Adresse angemeldet als der, zu der Pro gehört. Die Wiederherstellung von Pro hängt an dieser Google-E-Mail, nicht am Anthropic-Login und nicht am Namen des Chrome-Profils.

Mobile Browser führen diese Erweiterung nicht aus. Es gibt keine iOS- oder Android-App. Safari auf dem Smartphone kann drucken, zeigt aber den orangefarbenen Button nicht an. Für eine wiederverwendbare Datei öffnen Sie denselben Chat in Chrome am Desktop.

Lädt die Erweiterung Chats aus Claude Code herunter?

Nein. Download Claude conversations lädt keine Claude-Code-Unterhaltung herunter. Claude Code ist der Agent im Terminal. Für Chats auf claude.ai ist diese Chrome-Erweiterung zuständig. Die Terminal-Sitzung exportieren Sie mit /export oder über die JSONL-Datei unter ~/.claude/projects. Verschiedene Produkte, verschiedene Dateien.

Geben Sie in einer laufenden Claude-Code-Sitzung /export ein. Das CLI von Anthropic öffnet ein Menü, um das Transkript zu kopieren oder als Textdatei zu speichern. Mit einem Dateinamen überspringen Sie das Menü. Dieses Transkript ist gerenderter Text zum Lesen, nicht das Markdown/JSON/PNG dieser Erweiterung. Alle Pfade: Claude Code Chat exportieren.

JSONL auf der Festplatte ist das interne Protokoll. Das Schema kann sich zwischen Claude-Code-Versionen ändern. Die Dokumentation von Anthropic empfiehlt selbst, /export oder Skript-Schnittstellen zu nutzen, statt JSONL zu parsen. Wir kapseln dieses CLI nicht. Wir lesen ~/.claude nicht.

Wenn Sie für dieselbe Arbeit parallel einen Chat auf claude.ai führen, laden Sie diesen Browser-Chat mit dem orangefarbenen Button herunter. Das Terminal-Protokoll und der Web-Chat sind nicht automatisch dasselbe Dokument. Behandeln Sie sie als zwei Aufzeichnungen, es sei denn, Sie haben das eine in das andere kopiert.

FAQ: Claude Chat herunterladen

Wie lade ich einen Claude Chat in Chrome herunter?

Installieren Sie Download Claude conversations, öffnen Sie den Chat auf claude.ai, klicken Sie auf den orangefarbenen Button neben dem Nachrichtenfeld, wählen Sie Markdown, JSON, Text, XML oder PNG und klicken Sie auf „Export“. Die Datei wird lokal heruntergeladen. Vor dem ersten Export ist eine Google-Anmeldung nötig, damit wir die 3 kostenlosen Exporte zählen können.

Kann ich Claude Chats ohne Erweiterung herunterladen?

Ja. Drucken Sie die Seite (Ctrl/Cmd+P → Als PDF speichern) für eine optische Kopie, oder nutzen Sie Settings → Privacy → Export data für ein verzögertes JSON-ZIP des Kontos. Kopieren und Einfügen reicht für eine kurze Antwort. Keine dieser Methoden erzeugt eine strukturierte Markdown-Datei pro Chat, wie es die Chrome-Erweiterung tut.

Wie lade ich meinen Claude-Verlauf herunter?

Für eine einzelne Unterhaltung nutzen Sie den orangefarbenen Button. Für viele Dateien öffnen Sie „View and Download All Conversations“ und klicken auf „Export All“. Dieser Massenexport ist nicht das Export-data-ZIP von Anthropic. Der offizielle Datenexport ist ein Archiv des gesamten Kontos, das später per E-Mail kommt. Siehe Alle Claude Chats exportieren.

Muss ich bezahlen, um einen Claude Chat herunterzuladen?

Nein. Jedes Konto erhält 3 kostenlose Exporte in jedem der fünf Formate. Danach kostet Pro 3,99 $ pro Monat oder 26,99 $ pro Jahr. Die Zahlung wickelt Paddle ab. Die kostenlose Stufe ist nicht unbegrenzt, und Dateien aus dem Massenexport zählen zu denselben 3.

Funktioniert Download Claude conversations auf dem Smartphone?

Nein. Es ist eine Chrome-Erweiterung für Chrome am Desktop (oder einen anderen Chromium-Browser, der Erweiterungen aus dem Chrome Web Store installieren kann). Es gibt keine iOS- oder Android-App. Mobile Browser können einen Claude Chat drucken, diese Erweiterung aber nicht ausführen.

Wird mein Anthropic-Konto deswegen gesperrt?

Wir können keine Rechtsberatung geben. Die Erweiterung liest die claude.ai-Seite, die Sie in Ihrer eigenen Sitzung bereits geladen haben. Sie ruft Anthropic nicht mit eigenen Zugangsdaten auf und automatisiert keine Klicks in Ihrem Konto. Wir sind nicht Anthropic. Halten Sie sich an deren Nutzungsbedingungen und an die Regeln Ihres Arbeitgebers.

Wie speichere ich eine Claude-Unterhaltung als Datei?

Nutzen Sie die Chrome-Erweiterung für eine saubere Datei des geöffneten Chats. Drucken Sie für eine PDF-ähnliche Momentaufnahme. Nutzen Sie Export data von Anthropic für ein ZIP des ganzen Kontos. Speichern, herunterladen und exportieren meinen auf claude.ai dasselbe, wenn der Chat vom Bildschirm in eine Datei soll.

Funktioniert das für Claude-Code-Sitzungen?

Nein. Claude Code läuft im Terminal. Nutzen Sie /export oder kopieren Sie JSONL aus ~/.claude/projects (Windows: %USERPROFILE%\.claude\projects). Diese Chrome-Erweiterung läuft nur auf claude.ai. Anleitung: Claude Code Chat exportieren.

Ist eine Google-Anmeldung nötig, um einen Claude Chat herunterzuladen?

Ja, ab dem ersten Export. Google bestätigt, welches Konto Sie gewählt haben, damit wir das Kontingent von 3 Exporten durchsetzen und Pro nach einer Neuinstallation wiederherstellen können. Mit dieser Anmeldung werden keine Gesprächsinhalte übertragen. Wir speichern die bestätigte E-Mail-Adresse nur für Kontingent und Pro-Status.

In welchen Formaten kann ich einen Claude Chat herunterladen?

Markdown, JSON, Nur-Text, XML und PNG. In Version 1.13.0 der Erweiterung gibt es keinen PDF-Export. Für ein PDF drucken Sie claude.ai oder konvertieren eine Markdown-Datei in einer anderen App. PNG ist ein Bild des Chats, kein PDF. Übersicht: Formate.

Kann ich aus Team- oder Enterprise-Workspaces exportieren?

Ja, sofern Sie die Unterhaltung auf claude.ai in Chrome öffnen können. Die Erweiterung arbeitet mit der angezeigten Seite, nicht mit einer API nur für Privatkonten. Wenn eine Unternehmensrichtlinie Erweiterungen blockiert, ist das eine Entscheidung der IT, kein Tarif-Schalter in unseren Einstellungen.

Ist Claude Chat Downloader dasselbe Produkt?

Ja. Download Claude conversations ist der Name im Chrome Web Store. Viele suchen auch nach Claude Chat Downloader oder Claude Conversation Downloader. Derselbe orangefarbene Button, dieselben fünf Formate, dieselben 3 kostenlosen Exporte.
