Wie lade ich einen Claude Chat mit Chrome herunter?

Die direkte Antwort ist der orangefarbene Button, den Download Claude conversations neben dem Nachrichtenfeld auf claude.ai einfügt. Öffnen Sie die Unterhaltung, wählen Sie PDF, Markdown, JSON, Text, XML, CSV oder PNG und klicken Sie auf „Export“ (Exportieren). Die Datei wird in Ihrem Browser zusammengesetzt und auf der Festplatte gespeichert.

Die Erweiterung ist ein Chrome-Content-Script. Sie liest die Unterhaltung, die in Ihrer angemeldeten claude.ai-Sitzung bereits geladen ist. Sie ruft keine separate Anthropic-API mit eigenen Zugangsdaten auf und lädt den Chat nicht auf unsere Server hoch, um die Datei zu erzeugen.

  1. Installieren Sie Download Claude conversations aus dem Chrome Web Store (Chromium-Browser, die Chrome-Erweiterungen laden, funktionieren ebenfalls).
  2. Laden Sie claude.ai neu, falls die Seite während der Installation schon geöffnet war.
  3. Öffnen Sie die gewünschte Unterhaltung – der orangefarbene Button erscheint nur in einem echten Chat, nicht auf der leeren Startseite mit dem Eingabefeld.
  4. Klicken Sie auf den runden orangefarbenen Download-Button rechts neben dem Nachrichtenfeld. Es öffnet sich ein Panel mit „Messages“ (Nachrichten: „All“ / „Human“ / „Assistant“), „Format“, „Thinking“ (Denkprozess), „Select“ (Auswählen), „Copy“ (Kopieren) und „Export“.
  5. Wählen Sie PDF, Markdown, Nur-Text, JSON, XML, CSV oder PNG. Klicken Sie auf „Export“. Chrome lädt die Datei sofort herunter.

Für Markdown, Nur-Text, JSON, XML, CSV oder PNG brauchen Sie kein Konto. Diese Exporte einzelner Chats sind unbegrenzt und kostenlos: keine Anmeldung, kein Zähler. Die Google-Anmeldung erscheint nur, wenn Sie PDF wählen oder einen Massenexport mit „Export All“ starten. Sie ist kein Login, um Ihre Chats zu lesen. Die Gesprächsinhalte bleiben auf Ihrem Rechner.

PDF und Massenexport als ZIP teilen sich ein kostenloses Kontingent von 3 pro Tag, das um Mitternacht UTC neu beginnt. Jeder Chat in einem ZIP-Massenexport zählt als einer. Dasselbe Panel filtert nach Absender – „All“ (alle), „Human“ (nur Ihre Nachrichten) oder „Assistant“ (nur Claude). Das Häkchen „Thinking“ nimmt erweitertes Denken auf oder lässt es weg. Mit „Select“ haken Sie einzelne Nachrichten an, sodass die Datei nur diese Runden enthält. „Copy“ legt Markdown, Text, JSON, XML oder CSV in die Zwischenablage, statt eine Datei herunterzuladen. Tool-/MCP-Schritte und Quellen der Websuche schalten Sie in den Einstellungen zu. Metadaten und das Artefakt-Layout – „Original“, „Inline“, „Nested“ (verschachtelt) oder „Flat“ (flach) – legen Sie im Dashboard fest.

Bei sehr langen Chats scrollen Sie, bis claude.ai auch die früheren Nachrichten geladen hat. Die Erweiterung kann nur exportieren, was die Seite angezeigt hat. Ein halb geladener Chat ergibt eine halbe Datei – das wirkt wie ein Fehler, ist aber meist nur ein nicht gescrolltes DOM.

Kann ich einen Claude Chat ohne Erweiterung herunterladen?

Ja. Ohne Erweiterung können Sie die Seite drucken oder den Kontoexport von Anthropic anfordern. Drucken ergibt ein optisches PDF der Webseite. Export data ist ein verzögertes JSON-ZIP des gesamten Kontos. Keiner der beiden Wege erzeugt eine Markdown-Datei pro Chat.

Drucken: Öffnen Sie die Unterhaltung auf claude.ai, blenden Sie die Seitenleiste aus, falls die Oberfläche das erlaubt, drücken Sie Ctrl+P (Windows/Linux) oder Cmd+P (Mac), wählen Sie als Ziel „Als PDF speichern“ und speichern Sie. Codeblöcke werden oft über Seiten hinweg getrennt. Das Eingabefeld kann auf jedem Blatt erscheinen. Der eigene PDF-Export der Erweiterung überspringt diesen Dialog. Beide Wege vergleicht die Seite Claude Chat als PDF speichern.

Offizieller Weg: Settings → Privacy → Export data auf claude.ai (die Bezeichnungen können übersetzt sein, wenn claude.ai auf Deutsch eingestellt ist). Anthropic schickt einen Link per E-Mail, der abläuft. Das ZIP ist ein JSON-Archiv auf Kontoebene, keine benannte Datei für den Chat, den Sie gerade gelesen haben. Nutzen Sie es als Backup und entpacken Sie es selbst, wenn Sie eine Unterhaltung aus Tausenden brauchen.

Kopieren und Einfügen ist der dritte Weg ohne Erweiterung. Text markieren, in Docs oder eine Notiz-App einfügen. Die Einrückung von Code geht meist verloren. Tabellen werden zu Fließtext. Ein Chat mit vielen Runden wird zu einer unstrukturierten Textwand. Für eine kurze Antwort reicht das. Für ein Code-Review, das Sie später durchsuchen wollen, nicht. Der Button „Copy“ der Erweiterung legt stattdessen sauberes Markdown in die Zwischenablage.

Im kostenlosen Tarif belegt jeder Chat im ZIP einen von 3 täglichen Plätzen, die sich der Massenexport mit PDF teilt. Pro hebt die Grenze auf.

Wählen Sie eine Teilmenge aus, wenn nicht jeder alte Entwurf im Ordner landen soll.

Wie lade ich einen Claude Chat als Markdown oder JSON herunter?

Öffnen Sie den orangefarbenen Button, wählen Sie das Format und klicken Sie auf „Export“. Markdown ist die Notizdatei. JSON ist der Nachrichtenbaum für Skripte. Nur-Text hat kein Markup. CSV ist eine Zeile pro Nachricht. PDF ist ein Dokument mit Seiten. PNG ist ein Bild.

Markdown behält Überschriften, Codeblöcke mit Sprachangabe und Tabellen. Es ist die übliche Wahl für Obsidian, GitHub oder ein Wiki. JSON bewahrt den Baum, den der Parser bereits aufgebaut hat, einschließlich Artefakten und Denkblöcken, wenn diese Schalter aktiv sind. Die Struktur ist nicht dieselbe wie im Konto-ZIP von Anthropic. Hinweise zu den Formaten: alle Formate.

Nur-Text ist richtig, wenn das Ziel Markup ohnehin entfernt – ein Feld in einem Ticketsystem, der Text einer E-Mail, ein Suchindex, der reine Zeichenketten erwartet. XML ist die Nischenwahl für den Datenaustausch. CSV öffnet sich in Excel, Google Sheets oder Numbers. PNG ist für eine Folie oder einen Screenshot des Chats in einem Fehlerbericht gedacht, nicht für ein Design-Review mit 40 Runden, das Sie später durchsuchen.

Claude-Unterhaltung speichern, drucken oder als ZIP?

Speichern, herunterladen und exportieren sind auf claude.ai dieselbe Aufgabe: den Chat von der Seite holen. Wer eine Claude-Unterhaltung als Arbeitsdatei speichern will, auch als PDF, nutzt die Erweiterung. Drucken ist eine Momentaufnahme. Export data von Anthropic ist ein Konto-ZIP.

In Teams werden die Begriffe oft gemischt. Eine Forscherin sagt speichern. Ein Entwickler sagt exportieren. Eine Managerin sagt herunterladen. Auf dieser Website führen alle drei Verben zum selben orangefarbenen Button, wenn Sie claude.ai in Chrome nutzen. Die Anleitung Claude Chat exportieren geht ausführlicher auf das offizielle ZIP und die JSON-Strukturen ein.

Drucken hat trotzdem seinen Platz: ein einmaliger Anhang, der genau wie die Ansicht auf claude.ai aussehen soll. Auch Export data hat seinen Platz: beim Verlassen einer Firma, bei einer rechtlichen Aufbewahrungspflicht oder als doppelte Absicherung. Keins von beiden ersetzt eine Markdown-Datei, die Sie nächste Woche bearbeiten.

Claude Desktop ist ein anderes Fenster. Die Chrome-Erweiterung wird nicht in die Desktop-App eingebunden. Wenn derselbe Chat auf claude.ai existiert, öffnen Sie ihn dort und laden ihn herunter. Wenn er nur in Desktop existiert, kopieren Sie ihn oder warten auf das Konto-ZIP. Schritte: Claude Desktop Chat exportieren.

Paddle wickelt Pro-Zahlungen ab. Wir sehen keine Kartennummern. Die Google-Anmeldung, die nur für PDF, Massenexport und Pro dient, gibt uns keinen Zugriff auf die Unterhaltung. Der Cloudflare-Worker, der Kontingent und Pro-Status prüft, erhält Ihre Google-E-Mail-Adresse, keinen Nachrichtentext. Andere Exporte einzelner Chats senden gar nichts. Diese Grenze ist die ganze Datenschutz-Geschichte: Abrechnung auf dem Server, Chat auf der Festplatte.

Warum fehlt der Button zum Herunterladen?

Der Button fehlt, wenn Sie nicht in einer Unterhaltung sind, der Tab nach der Installation nicht neu geladen wurde oder die Erweiterung deaktiviert ist. Heften Sie das Symbol an, laden Sie neu und prüfen Sie, dass Sie in Chrome am Desktop auf claude.ai sind – nicht in Desktop, auf dem Smartphone oder in einem Claude-Code-Terminal.

Nach der Installation fügt Chrome ein Content-Script nicht immer in bereits geöffnete Tabs ein. Schließen Sie den claude.ai-Tab oder laden Sie ihn hart neu. Wenn Sie mehrere Profile nutzen, muss die Erweiterung in dem Profil installiert sein, das bei Anthropic angemeldet ist.

Team- und Enterprise-Workspaces funktionieren, wenn Sie die Unterhaltung im Browser öffnen können. Die Erweiterung liest die Seite, nicht den Tarif. Wenn Ihre Organisation Chrome-Erweiterungen blockiert, muss die IT diese freigeben; von der Website aus können wir diese Richtlinie nicht umgehen.

Anmeldeabfrage: nur bei PDF und „Export All“ zu erwarten. Markdown, Text, JSON, XML, CSV und PNG exportieren Sie ohne Konto. Beim ersten PDF- oder Massenexport fragt Google nach. Wenn Sie die Abfrage abbrechen, sieht das wie ein fehlgeschlagener Download aus. Schließen Sie die Anmeldung ab und klicken Sie erneut auf „Export“. Im kostenlosen Tarif ist keine Kreditkarte nötig.

Unvollständige Datei: Die Antwort wurde noch gestreamt, oder ältere Runden waren noch nicht gerendert. Warten Sie, bis der Assistent fertig ist. Scrollen Sie in einem langen Chat zum Anfang, damit claude.ai diese Nachrichten lädt, und exportieren Sie erneut. Ein wiederholter Export als Markdown oder JSON kostet nichts. Ein wiederholtes PDF belegt im kostenlosen Tarif einen weiteren der 3 täglichen Plätze – ein Grund, vorher zu prüfen, ob der Chat vollständig geladen ist.

Falscher Dateityp: Das zuletzt genutzte Format war noch ausgewählt. Falsches Konto: Sie haben sich bei Google mit einer anderen Adresse angemeldet als der, zu der Pro gehört. Die Wiederherstellung von Pro hängt an dieser Google-E-Mail, nicht am Anthropic-Login und nicht am Namen des Chrome-Profils.

Mobile Browser führen diese Erweiterung nicht aus. Es gibt keine iOS- oder Android-App. Safari auf dem Smartphone kann drucken, zeigt aber den orangefarbenen Button nicht an. Für eine wiederverwendbare Datei öffnen Sie denselben Chat in Chrome am Desktop.

Lädt die Erweiterung Chats aus Claude Code herunter?

Nur aus Claude Code im Web. Sitzungen unter claude.ai/code öffnen sich in Chrome, daher exportiert Download Claude conversations sie wie jeden anderen Chat. Eine lokale Claude-Code-Sitzung im Terminal ist etwas anderes. Die Terminal-Sitzung exportieren Sie mit /export oder über die JSONL-Datei unter ~/.claude/projects. Verschiedene Oberflächen, verschiedene Dateien.

Geben Sie in einer laufenden Claude-Code-Sitzung /export ein. Das CLI von Anthropic öffnet ein Menü, um das Transkript zu kopieren oder als Textdatei zu speichern. Mit einem Dateinamen überspringen Sie das Menü. Dieses Transkript ist gerenderter Text zum Lesen, nicht das Markdown, JSON oder PDF dieser Erweiterung. Alle Pfade: Claude Code Chat exportieren.

JSONL auf der Festplatte ist das interne Protokoll. Das Schema kann sich zwischen Claude-Code-Versionen ändern. Die Dokumentation von Anthropic empfiehlt selbst, /export oder Skript-Schnittstellen zu nutzen, statt JSONL zu parsen. Wir kapseln dieses CLI nicht. Wir lesen ~/.claude nicht.

Wenn Sie für dieselbe Arbeit parallel einen Chat auf claude.ai führen, laden Sie diesen Browser-Chat mit dem orangefarbenen Button herunter. Das Terminal-Protokoll und der Web-Chat sind nicht automatisch dasselbe Dokument. Behandeln Sie sie als zwei Aufzeichnungen, es sei denn, Sie haben das eine in das andere kopiert.

FAQ: Claude Chat herunterladen

Wie lade ich einen Claude Chat in Chrome herunter?

Installieren Sie Download Claude conversations, öffnen Sie den Chat auf claude.ai, klicken Sie auf den orangefarbenen Button rechts neben dem Nachrichtenfeld, wählen Sie PDF, Markdown, JSON, Text, XML, CSV oder PNG und klicken Sie auf „Export“. Die Datei wird lokal heruntergeladen. Ein Konto ist nicht nötig – außer für PDF, dafür fragt die Erweiterung nach einer Google-Anmeldung.

Kann ich Claude Chats ohne Erweiterung herunterladen?

Ja. Drucken Sie die Seite (Ctrl/Cmd+P → Als PDF speichern) für eine optische Kopie, oder nutzen Sie Settings → Privacy → Export data für ein verzögertes JSON-ZIP des Kontos. Kopieren und Einfügen reicht für eine kurze Antwort. Keine dieser Methoden erzeugt eine strukturierte Markdown-Datei pro Chat, wie es die Chrome-Erweiterung tut.

Wie lade ich meinen Claude-Verlauf herunter?

Für eine einzelne Unterhaltung nutzen Sie den orangefarbenen Button. Für viele Dateien öffnen Sie im Popup der Erweiterung „View and Download All Conversations“ und klicken auf „Export All“. Der Massenexport erfordert eine Google-Anmeldung und zählt im kostenlosen Tarif zu den 3 pro Tag. Dieser Massenexport ist nicht das Export-data-ZIP von Anthropic. Der offizielle Datenexport ist ein Archiv des gesamten Kontos, das später per E-Mail kommt. Siehe Alle Claude Chats exportieren.

Muss ich bezahlen, um einen Claude Chat herunterzuladen?

Nein. Exporte als Markdown, Nur-Text, JSON, XML, CSV und PNG sind unbegrenzt und kostenlos, ganz ohne Konto. PDF und Massenexport als ZIP sind mit Google-Anmeldung bis zu 3-mal pro Tag kostenlos; jeder Chat in einem ZIP-Massenexport zählt als einer. Pro kostet 3,99 $ pro Monat oder 26,99 $ pro Jahr und hebt diese Grenze auf. Die Zahlung wickelt Paddle ab.

Funktioniert Download Claude conversations auf dem Smartphone?

Nein. Es ist eine Chrome-Erweiterung für Chrome am Desktop (oder einen anderen Chromium-Browser, der Erweiterungen aus dem Chrome Web Store installieren kann). Es gibt keine iOS- oder Android-App. Mobile Browser können einen Claude Chat drucken, diese Erweiterung aber nicht ausführen.

Wird mein Anthropic-Konto deswegen gesperrt?

Wir können keine Rechtsberatung geben. Die Erweiterung liest die claude.ai-Seite, die Sie in Ihrer eigenen Sitzung bereits geladen haben. Sie ruft Anthropic nicht mit eigenen Zugangsdaten auf und automatisiert keine Klicks in Ihrem Konto. Wir sind nicht Anthropic. Halten Sie sich an deren Nutzungsbedingungen und an die Regeln Ihres Arbeitgebers.

Wie speichere ich eine Claude-Unterhaltung als Datei?

Nutzen Sie die Chrome-Erweiterung für eine saubere Datei des geöffneten Chats, auch als PDF. Drucken Sie für eine Momentaufnahme der Webseite. Nutzen Sie Export data von Anthropic für ein ZIP des ganzen Kontos. Speichern, herunterladen und exportieren meinen auf claude.ai dasselbe, wenn der Chat vom Bildschirm in eine Datei soll.

Funktioniert das für Claude-Code-Sitzungen?

Nur im Web. Sitzungen aus Claude Code im Web (claude.ai/code) exportieren Sie wie jeden anderen claude.ai-Chat. Lokale Terminal-Sitzungen nicht: Nutzen Sie dafür /export oder kopieren Sie JSONL aus ~/.claude/projects (Windows: %USERPROFILE%\.claude\projects). Diese Chrome-Erweiterung läuft nur auf claude.ai. Anleitung: Claude Code Chat exportieren.

Ist eine Google-Anmeldung nötig, um einen Claude Chat herunterzuladen?

Nein, nicht für Markdown, Nur-Text, JSON, XML, CSV oder PNG. Eine Google-Anmeldung ist nur für PDF, den Massenexport mit „Export All“ und Pro nötig, damit wir die Grenze von 3 pro Tag anwenden und Pro nach einer Neuinstallation wiederherstellen können. Mit dieser Anmeldung werden keine Gesprächsinhalte übertragen. Wir speichern die bestätigte E-Mail-Adresse nur für Kontingent und Pro-Status.

In welchen Formaten kann ich einen Claude Chat herunterladen?

In sieben: PDF, Markdown, JSON, Nur-Text, XML, CSV und PNG, in Version 1.16.2 der Erweiterung. PDF entsteht im Browser, ganz ohne Druckdialog. CSV ist eine Zeile pro Nachricht. PNG ist ein Bild des Chats. Übersicht: Formate.

Kann ich aus Team- oder Enterprise-Workspaces exportieren?

Ja, sofern Sie die Unterhaltung auf claude.ai in Chrome öffnen können. Die Erweiterung arbeitet mit der angezeigten Seite, nicht mit einer API nur für Privatkonten. Wenn eine Unternehmensrichtlinie Erweiterungen blockiert, ist das eine Entscheidung der IT, kein Tarif-Schalter in unseren Einstellungen.
