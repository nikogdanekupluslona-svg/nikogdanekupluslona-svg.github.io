In welchem Format soll ich die Unterhaltung herunterladen?

Öffnen Sie den orangefarbenen Button, wählen Sie PDF, Markdown, JSON, Text, XML, CSV oder PNG und klicken Sie auf „Export“. Markdown ist die Notizdatei. JSON ist der Nachrichtenbaum für Skripte. Nur-Text hat kein Markup. XML dient dem Datenaustausch. CSV ist eine Zeile pro Nachricht. PDF ist ein Dokument mit Seiten. PNG ist ein Bild.

Markdown behält Überschriften, Codeblöcke mit Sprachangabe und Tabellen. Es ist die übliche Wahl für Obsidian, GitHub oder ein Wiki. JSON bewahrt den Baum, den der Parser bereits aufgebaut hat, einschließlich Artefakten und Denkblöcken, wenn diese Schalter aktiv sind. Die Struktur ist nicht dieselbe wie im Konto-ZIP von Anthropic. Hinweise zu den Formaten: alle Formate.

Nur-Text ist richtig, wenn das Ziel Markup ohnehin entfernt – ein Feld in einem Ticketsystem, der Text einer E-Mail, ein Suchindex, der reine Zeichenketten erwartet. XML ist die Nischenwahl für den Datenaustausch. CSV öffnet sich in Excel, Google Sheets oder Numbers. PNG ist für eine Folie oder einen Screenshot des Chats in einem Fehlerbericht gedacht, nicht für ein Design-Review mit 40 Runden, das Sie später durchsuchen.

Warum ist der Download-Button verschwunden?

Der Button fehlt, wenn Sie nicht in einer Unterhaltung sind, der Tab nach der Installation nicht neu geladen wurde oder die Erweiterung deaktiviert ist. Heften Sie das Symbol an, laden Sie neu und prüfen Sie, dass Sie in Chrome am Desktop auf claude.ai sind – nicht in Desktop, auf dem Smartphone oder in einem Claude-Code-Terminal.

Nach der Installation fügt Chrome ein Content-Script nicht immer in bereits geöffnete Tabs ein. Schließen Sie den claude.ai-Tab oder laden Sie ihn hart neu. Wenn Sie mehrere Profile nutzen, muss Download Claude conversations in dem Profil installiert sein, das bei Anthropic angemeldet ist.

Team- und Enterprise-Workspaces funktionieren, wenn Sie die Unterhaltung im Browser öffnen können. Die Erweiterung liest die Seite, nicht den Tarif. Wenn Ihre Organisation Chrome-Erweiterungen blockiert, muss die IT diesen Eintrag freigeben; von chat-downloader.com aus können wir diese Richtlinie nicht umgehen.

Anmeldeabfrage: nur bei PDF und „Export All“ zu erwarten. Markdown, Text, JSON, XML, CSV und PNG exportieren Sie ohne Konto. Beim ersten PDF- oder Massenexport fragt Google nach. Wenn Sie die Abfrage abbrechen, sieht das wie ein fehlgeschlagener Download aus. Schließen Sie die Anmeldung ab und klicken Sie erneut auf „Export“. Im kostenlosen Tarif ist keine Kreditkarte nötig. Paddle erscheint nur, wenn Sie Pro kaufen.

Unvollständige Datei: Die Antwort wurde noch gestreamt, oder ältere Runden waren noch nicht gerendert. Warten Sie, bis der Assistent fertig ist. Scrollen Sie in einem langen Chat zum Anfang, damit claude.ai diese Nachrichten lädt, und exportieren Sie erneut. Ein wiederholter Export als Markdown oder JSON kostet nichts. Ein wiederholtes PDF belegt im kostenlosen Tarif einen weiteren der 3 täglichen Plätze – prüfen Sie also vorher, ob der Chat vollständig geladen ist.

Falscher Dateityp: Das zuletzt genutzte Format war noch ausgewählt. Falsches Konto: Sie haben sich bei Google mit einer anderen Adresse angemeldet als der, zu der Pro gehört. Die Wiederherstellung von Pro hängt an dieser Google-E-Mail, nicht am Anthropic-Login und nicht am Namen des Chrome-Profils.

Mobile Browser führen diese Erweiterung nicht aus. Es gibt keine iOS- oder Android-App. Safari auf dem Smartphone kann claude.ai drucken, zeigt aber den orangefarbenen Button nicht an. Wie lade ich eine Claude-Unterhaltung von claude.ai herunter?

Installieren Sie Download Claude conversations, öffnen Sie den Chat auf claude.ai, klicken Sie auf den orangefarbenen Button rechts neben dem Nachrichtenfeld, wählen Sie PDF, Markdown, JSON, Text, XML, CSV oder PNG und klicken Sie auf „Export“. Chrome speichert eine lokale Datei. Diese Datei ist eine Unterhaltung. Ein Konto ist nicht nötig – außer für PDF, dafür fragt die Erweiterung nach einer Google-Anmeldung.

Ist „Claude Unterhaltung herunterladen“ der Name im Store?

Der Titel im Store lautet Download Claude conversations, im Plural, weil Export All viele Dateien erzeugt. Suchanfragen wie „Claude Unterhaltung herunterladen“, „Claude Chat herunterladen“ oder das englische „claude download conversation“ führen alle zu diesem Eintrag. Ein Export über den orangefarbenen Button bleibt eine Unterhaltung, eine Datei.

Kann ich eine Claude-Unterhaltung ohne Erweiterung herunterladen?

Ja. Drucken Sie die claude.ai-Seite (Ctrl/Cmd+P → Als PDF speichern) für eine optische Momentaufnahme, oder nutzen Sie Settings → Privacy → Export data für ein verzögertes JSON-ZIP des Kontos. Kopieren und Einfügen reicht für eine kurze Antwort. Keine dieser Methoden erzeugt eine strukturierte Markdown-Datei pro Unterhaltung, wie es die Chrome-Erweiterung tut.

Ist eine Datei gleich eine heruntergeladene Unterhaltung?

Ja. Der orangefarbene Button erzeugt eine Datei für den geöffneten claude.ai-Chat. Export All erzeugt ein ZIP mit einer Datei pro ausgewählter Zeile. Das Export-data-ZIP von Anthropic ist das Gegenteil: ein Archiv für das ganze Konto, später per E-Mail, keine benannte Datei für die Unterhaltung, die Sie gerade gelesen haben.

Kann ich eine Claude-Unterhaltung als PDF herunterladen?

Ja. Wählen Sie im Panel des orangefarbenen Buttons PDF und klicken Sie auf „Export“. Version 1.16.2 erstellt das PDF im Browser, ganz ohne Druckdialog; Sie legen Seitenformat, Ränder, hellen oder dunklen Modus, Schriftart, Seitenzahlen und ein Inhaltsverzeichnis fest. PDF erfordert eine Google-Anmeldung und ist bis zu 3-mal pro Tag kostenlos; mit Pro unbegrenzt. Anleitung: Claude Chat als PDF.

Ist eine Google-Anmeldung nötig, um eine Claude-Unterhaltung herunterzuladen?

Nur für PDF und den Massenexport mit „Export All“. Markdown, Nur-Text, JSON, XML, CSV und PNG brauchen kein Konto. Bei PDF und Massenexport bestätigt Google, welches Konto Sie gewählt haben, damit wir die Grenze von 3 pro Tag anwenden und Pro nach einer Neuinstallation wiederherstellen können. Mit dieser Anmeldung werden keine Gesprächsinhalte übertragen. Wir speichern die bestätigte E-Mail-Adresse nur für Kontingent und Pro-Status.

Funktioniert der Download in Claude Desktop?

Nein. Download Claude conversations wird nur auf claude.ai in Chrome am Desktop eingebunden. Claude Desktop zeigt den orangefarbenen Button nie an. Öffnen Sie denselben Chat auf claude.ai, falls er synchronisiert ist, oder kopieren Sie ihn bzw. nutzen Sie den offiziellen Datenexport. Es gibt keine iOS- oder Android-App.

Wie viele Dateien sind kostenlos?

Unbegrenzt für Markdown, Nur-Text, JSON, XML, CSV und PNG, ganz ohne Konto. PDF und Massenexport als ZIP teilen sich im kostenlosen Tarif 3 pro Tag, mit Google-Anmeldung; jede Unterhaltung in einem ZIP-Massenexport zählt als eine, und der Tag beginnt um Mitternacht UTC neu. Pro kostet 3,99 $ pro Monat oder 26,99 $ pro Jahr und hebt die Grenze auf. Die Zahlung wickelt Paddle ab.

Lädt die Erweiterung Unterhaltungen aus Claude Code herunter?

Nur im Web. Sitzungen aus Claude Code im Web (claude.ai/code) exportieren Sie wie jede andere claude.ai-Unterhaltung. Lokale Terminal-Sitzungen nicht: Nutzen Sie dafür /export oder kopieren Sie JSONL aus ~/.claude/projects (Windows: %USERPROFILE%\.claude\projects). Diese Chrome-Erweiterung läuft nur auf claude.ai. Anleitung: Claude Code Chat exportieren.
