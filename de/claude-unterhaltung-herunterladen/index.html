In welchem Format soll ich die Unterhaltung herunterladen?

Öffnen Sie den orangefarbenen Button, wählen Sie Markdown, JSON, Text, XML oder PNG und klicken Sie auf „Export“. Markdown ist die Notizdatei. JSON ist der Nachrichtenbaum für Skripte. Nur-Text hat kein Markup. XML dient dem Datenaustausch. PNG ist ein Bild, kein PDF.

Markdown behält Überschriften, Codeblöcke mit Sprachangabe und Tabellen. Es ist die übliche Wahl für Obsidian, GitHub oder ein Wiki. JSON bewahrt den Baum, den der Parser bereits aufgebaut hat, einschließlich Artefakten und Denkblöcken, wenn diese Schalter aktiv sind. Die Struktur ist nicht dieselbe wie im Konto-ZIP von Anthropic. Hinweise zu den Formaten: alle Formate.

Nur-Text ist richtig, wenn das Ziel Markup ohnehin entfernt – ein Feld in einem Ticketsystem, der Text einer E-Mail, ein Suchindex, der reine Zeichenketten erwartet. XML ist die Nischenwahl für den Datenaustausch. PNG ist für eine Folie oder einen Screenshot des Chats in einem Fehlerbericht gedacht, nicht für ein Design-Review mit 40 Runden, das Sie später durchsuchen.

Kann ich eine Claude-Unterhaltung als PDF herunterladen?

Nein. Version 1.13.0 erzeugt nur Markdown, JSON, Nur-Text, XML und PNG. Es gibt keinen PDF-Export. Drucken Sie den claude.ai-Tab oder konvertieren Sie eine Markdown-Datei in einer anderen App. PNG ist ein Bild des Chats, kein PDF.

Ist eine Google-Anmeldung nötig, um eine Claude-Unterhaltung herunterzuladen?

Ja, ab dem ersten Klick auf „Export“. Google bestätigt, welches Konto Sie gewählt haben, damit wir das Kontingent von 3 Exporten durchsetzen und Pro nach einer Neuinstallation wiederherstellen können. Mit dieser Anmeldung werden keine Gesprächsinhalte übertragen. Wir speichern die bestätigte E-Mail-Adresse nur für Kontingent und Pro-Status.

Funktioniert der Download in Claude Desktop?

Nein. Download Claude conversations wird nur auf claude.ai in Chrome am Desktop eingebunden. Claude Desktop zeigt den orangefarbenen Button nie an. Öffnen Sie denselben Chat auf claude.ai, falls er synchronisiert ist, oder kopieren Sie ihn bzw. nutzen Sie den offiziellen Datenexport. Es gibt keine iOS- oder Android-App.

Wie viele Dateien sind kostenlos?

Jedes mit Google angemeldete Konto erhält 3 kostenlose Exporte in jedem der fünf Formate. Danach kostet Pro 3,99 $ pro Monat oder 26,99 $ pro Jahr. Die Zahlung wickelt Paddle ab. Dateien aus Export All zählen zu denselben 3. Eine Neuinstallation setzt den Zähler nicht zurück.

Lädt die Erweiterung Unterhaltungen aus Claude Code herunter?

Nein. Claude Code läuft im Terminal. Nutzen Sie /export oder kopieren Sie JSONL aus ~/.claude/projects (Windows: %USERPROFILE%\.claude\projects). Diese Chrome-Erweiterung läuft nur auf claude.ai. Anleitung: Claude Code Chat exportieren.
