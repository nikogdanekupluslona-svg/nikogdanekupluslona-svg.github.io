6 zentrale Funktionen, um Claude Chats zu exportieren

01

Export als Markdown, JSON, XML, Text & PNG

Laden Sie einen Claude Chat als echte Datei herunter – nicht als Screenshot der Webseite. Markdown für Notizen, JSON für Entwickler, Nur-Text für das einfachste Archiv, XML für den Datenaustausch, PNG für eine optische Momentaufnahme.

02

Alle Claude Chats auf einmal herunterladen

Öffnen Sie View and Download All Conversations (alle Unterhaltungen anzeigen und herunterladen), um Ihren Verlauf aufzulisten, nach Namen zu suchen, nach Projekt zu filtern und auf Export All (alle exportieren) zu klicken. Ein Durchgang statt Tab für Tab.

03

Code, Tabellen und Artefakte bleiben erhalten

Die Export-Engine liest den Nachrichtenbaum aus: Codeblöcke behalten ihre Einrückung, Tabellen bleiben Tabellen, und Artefakte lassen sich als „Original“, „Inline“, „Nested“ (verschachtelt) oder „Flat“ (flach) ausgeben.

04

Denkblöcke und Metadaten optional

Nehmen Sie Claudes erweitertes Denken (Extended Thinking) auf, wenn Sie eine nachvollziehbare Dokumentation brauchen, oder lassen Sie es weg. Titel, Zeitstempel und Modell-Metadaten können in derselben Datei mitkommen.

05

Vor dem Export suchen und filtern

Grenzen Sie die Bibliothek auf neue Chats, bereits exportierte Chats oder ein Claude-Projekt ein und exportieren Sie nur, was Sie ausgewählt haben.

06

Lokal in Ihrem Browser erstellt

Der Gesprächsinhalt wird auf Ihrem Gerät zusammengesetzt und auf die Festplatte heruntergeladen. Die Google-Anmeldung dient nur dem Kontingent für kostenlose Exporte – nicht dem Hochladen des Chattextes auf unsere Server.

Häufig gestellte Fragen

Kann ich eine Claude-Unterhaltung von claude.ai herunterladen?

Nicht mit einem eingebauten Button. Installieren Sie Download Claude conversations aus dem Chrome Web Store, öffnen Sie den Chat und exportieren Sie eine Datei.

Ist das dasselbe wie „Export data“ von Claude?

Nein. Anthropics Settings → Privacy → Export data (die Bezeichnungen können übersetzt sein, wenn claude.ai auf Deutsch eingestellt ist) schickt Ihnen per E-Mail ein ZIP Ihres Kontos (JSON). Diese Erweiterung lädt den aktuellen Chat – oder eine Auswahl vieler Chats – sofort als lesbare Dateien herunter.

Speichern Sie meine Claude-Chats?

Der Export läuft im Browser. Wir erhalten keine Gesprächsinhalte. Wir speichern nur eine von Google bestätigte E-Mail-Adresse, um kostenlose Exporte zu zählen und ein Pro-Abo zuzuordnen.

Was ist der Unterschied zwischen „Claude Chat exportieren“ und „Claude Chat herunterladen“?

Dieselbe Aufgabe, zwei Arten, sie zu suchen – manche tippen auch einfach „claude export chat“. In jedem Fall nutzen Sie den orangefarbenen Button auf claude.ai.

Exportiert die Erweiterung PDF?

Nein. Die aktuellen Formate sind Markdown, JSON, Nur-Text, XML und PNG. Drucken Sie die Seite (Ctrl/Cmd+P → Als PDF speichern), wenn Sie schnell ein optisches PDF brauchen, oder exportieren Sie Markdown und konvertieren Sie es. Vollständige Anleitung: Claude Chat als PDF speichern.

Funktioniert es mit Claude Pro / Team?

Ja, sofern Sie die Unterhaltung im Browser auf claude.ai öffnen können. Wir sind nicht Anthropic.

Wie speichere ich eine Claude-Unterhaltung?

Installieren Sie die kostenlose Chrome-Erweiterung, öffnen Sie den Chat auf claude.ai, klicken Sie auf den orangefarbenen Button und wählen Sie ein Format. So speichern Sie eine Claude-Unterhaltung als echte Datei. Drucken als PDF und das Konto-ZIP von Anthropic sind die beiden anderen Wege – den Vergleich finden Sie unter Claude Chat herunterladen.

Lädt die Erweiterung Claude-Code-Unterhaltungen herunter?

Nein. Die Erweiterung funktioniert nur auf claude.ai in Chrome. Claude-Code-Sitzungen nutzen /export oder JSONL-Dateien auf der Festplatte – siehe Claude Code Chat exportieren.

Ist Download Claude conversations mit Anthropic verbunden?

Nein. Claude ist eine Marke von Anthropic, PBC. Dies ist eine unabhängige Chrome-Erweiterung, kein offizielles Anthropic-Produkt.
