6 zentrale Funktionen, um Claude Chats zu exportieren

01

Export als PDF, Markdown, JSON, CSV & mehr

Laden Sie einen Claude Chat als echte Datei herunter – nicht als Screenshot der Webseite. PDF zum Lesen und Weitergeben, Markdown für Notizen, JSON für Entwickler, CSV für Tabellenkalkulationen, Nur-Text für das einfachste Archiv, XML für den Datenaustausch, PNG für eine optische Momentaufnahme. Oder klicken Sie auf Copy (kopieren), um das Ergebnis in die Zwischenablage zu legen.

02

Alle Claude Chats auf einmal herunterladen

Öffnen Sie View and Download All Conversations, um Ihren Verlauf aufzulisten, nach Namen zu suchen, nach Projekt oder Cowork zu filtern und auf Export All (alle exportieren) zu klicken. Ein ZIP statt Tab für Tab – 3 Chats pro Tag im kostenlosen Tarif, unbegrenzt mit Pro.

03

Code, Tabellen und Artefakte bleiben erhalten

Die Export-Engine liest den Nachrichtenbaum aus: Codeblöcke behalten ihre Einrückung, Tabellen bleiben Tabellen, und Artefakte lassen sich als „Original“, „Inline“, „Nested“ (verschachtelt) oder „Flat“ (flach) ausgeben.

04

Bestimmen Sie, was in die Datei kommt

Exportieren Sie den ganzen Chat, nur Ihre Prompts, nur Claudes Antworten oder nur die Nachrichten, die Sie mit Select (auswählen) markieren. Nehmen Sie Claudes erweitertes Denken (Extended Thinking) auf, wenn Sie eine nachvollziehbare Dokumentation brauchen, oder lassen Sie es weg. Titel, Zeitstempel und Modell-Metadaten können in derselben Datei mitkommen.

05

Vor dem Export suchen und filtern

Grenzen Sie die Bibliothek auf neue Chats, bereits exportierte Chats oder ein Claude-Projekt ein und exportieren Sie nur, was Sie ausgewählt haben.

06

Lokal in Ihrem Browser erstellt

Jede Datei, auch das PDF, wird auf Ihrem Gerät zusammengesetzt und auf die Festplatte heruntergeladen. Die meisten Exporte brauchen kein Konto. Die Google-Anmeldung zählt nur PDF- und Massenexporte und verknüpft ein Pro-Abo – Chattexte werden dabei nie auf unsere Server hochgeladen.

Häufig gestellte Fragen

Kann ich eine Claude-Unterhaltung von claude.ai herunterladen?

Nicht mit einem eingebauten Button. Installieren Sie Download Claude conversations aus dem Chrome Web Store, öffnen Sie den Chat und exportieren Sie eine Datei.

Ist es kostenlos, Claude Chats herunterzuladen?

Ja. Exporte als Markdown, Nur-Text, JSON, XML, CSV und PNG sind unbegrenzt und brauchen kein Konto. PDF- und ZIP-Massenexporte erfordern eine Google-Anmeldung und sind bis zu 3-mal pro Tag kostenlos. Pro für 3,99 $ im Monat oder 26,99 $ im Jahr hebt diese Grenze auf.

In welchen Browsern funktioniert es?

In Chrome am Desktop und in Chromium-basierten Browsern, die Erweiterungen aus dem Chrome Web Store installieren. Es gibt keine mobile App, und die Erweiterung läuft nicht in Claude Desktop.

Wie kündige ich Pro, und bekomme ich mein Geld zurück?

Sie können jederzeit kündigen – auf der Optionsseite der Erweiterung („Cancel subscription“, Abo kündigen) oder über Paddle. Für Ihre erste Zahlung gilt eine 14-tägige Geld-zurück-Garantie, ohne Rückfragen.

Ist das dasselbe wie „Export data“ von Claude?

Nein. Anthropics Settings → Privacy → Export data (die Bezeichnungen können übersetzt sein, wenn claude.ai auf Deutsch eingestellt ist) schickt Ihnen per E-Mail ein ZIP Ihres Kontos (JSON). Diese Erweiterung lädt den aktuellen Chat – oder eine Auswahl vieler Chats – sofort als lesbare Dateien herunter.

Speichern Sie meine Claude-Chats?

Nein. Jedes Format, auch PDF, wird in Ihrem Browser erstellt, und der Gesprächstext erreicht nie unsere Server. Wenn Sie sich für PDF, Massenexport oder Pro mit Google anmelden, speichern wir diese E-Mail-Adresse nur, um das Tageskontingent zu zählen und Ihr Abo zuzuordnen.

Was ist der Unterschied zwischen „Claude Chat exportieren“ und „Claude Chat herunterladen“?

Dieselbe Aufgabe, zwei Arten, sie zu suchen – manche tippen auch einfach „claude export chat“. In jedem Fall nutzen Sie den orangefarbenen Button auf claude.ai.

Exportiert die Erweiterung PDF?

Ja. Wählen Sie im Export-Panel PDF und legen Sie Seitenformat, Ränder, hellen oder dunklen Modus, Schriftart, Seitenzahlen und ein Inhaltsverzeichnis fest. PDF erfordert eine Google-Anmeldung; der kostenlose Tarif umfasst 3 PDF- oder Massenexporte pro Tag, mit Pro ist es unbegrenzt. Vollständige Anleitung: Claude Chat als PDF speichern.

Funktioniert es mit Claude Pro / Team?

Ja, sofern Sie die Unterhaltung im Browser auf claude.ai öffnen können. Wir sind nicht Anthropic.

Wie speichere ich eine Claude-Unterhaltung?

Installieren Sie die kostenlose Chrome-Erweiterung, öffnen Sie den Chat auf claude.ai, klicken Sie auf den orangefarbenen Button, wählen Sie ein Format und klicken Sie auf Export. Für Markdown, Text, JSON, XML, CSV oder PNG brauchen Sie kein Konto. So speichern Sie eine Claude-Unterhaltung als echte Datei. Die Seite drucken und das Konto-ZIP von Anthropic sind die beiden anderen Wege – den Vergleich finden Sie unter Claude Chat herunterladen.

Lädt die Erweiterung Claude-Code-Unterhaltungen herunter?

Nur die auf claude.ai. Sitzungen aus Claude Code im Web (claude.ai/code) und Cowork-Sitzungen exportieren Sie wie jeden anderen Chat. Lokale Terminal-Sitzungen liest die Erweiterung nicht; dafür gibt es /export oder JSONL-Dateien auf der Festplatte – siehe Claude Code Chat exportieren.

Ist Download Claude conversations mit Anthropic verbunden?

Nein. Claude ist eine Marke von Anthropic, PBC. Dies ist eine unabhängige Chrome-Erweiterung, kein offizielles Anthropic-Produkt.
