Wie exportiere ich einen Claude Chat mit der Erweiterung?

Der Weg zur lesbaren Datei ist der orangefarbene Button auf claude.ai. Installieren Sie Download Claude conversations, öffnen Sie den Chat, wählen Sie Markdown, JSON, Text, XML oder PNG und klicken Sie auf „Export“ (Exportieren). Die Datei wird in Ihrem Browser erzeugt und lokal gespeichert. Die Google-Anmeldung zählt die 3 kostenlosen Exporte.

Die Erweiterung ist ein Content-Script auf der Seite, die Sie bereits geladen haben. Sie öffnet keine zweite Anthropic-Sitzung und lädt die Unterhaltung nicht hoch, um die Datei zu erzeugen. Deshalb erscheint der Button nur in einer Unterhaltung, sobald der Chat im DOM vorhanden ist.

  1. Installieren Sie die Erweiterung aus dem Chrome Web Store.
  2. Öffnen Sie die Unterhaltung auf claude.ai. Laden Sie den Tab neu, falls er während der Installation geöffnet war.
  3. Klicken Sie auf den orangefarbenen Download-Button neben dem Nachrichtenfeld.
  4. Wählen Sie Markdown, JSON, Nur-Text, XML oder PNG.
  5. Stellen Sie bei Bedarf Denken („include thinking“), Metadaten („include metadata“), Absender („all / human only / assistant only“) und Artefakt-Layout („Original“, „Inline“, „Nested“, „Flat“) ein. Klicken Sie auf „Export“.

Für mehr als einen Chat öffnen Sie im Popup „View and Download All Conversations“ (alle Unterhaltungen anzeigen und herunterladen). Suchen Sie, filtern Sie nach Projekt oder nach bereits exportierten Chats und klicken Sie dann auf „Export All“ (alle exportieren). Jede Datei in diesem Durchlauf zählt zu denselben 3 kostenlosen Exporten. Anleitung: Alle Claude Chats exportieren.

Chats aus Team und Enterprise exportieren Sie genauso, wenn Sie sie in Chrome öffnen können. Der Parser prüft keine Tarifnamen von Anthropic. Wenn eine Organisation Erweiterungen blockiert, ist das eine Richtlinie der IT, kein fehlender Pro-Schalter bei uns.

Kontingent und Nutzung bei Anthropic. Der Export mit dieser Erweiterung verbraucht keine Claude-Nachrichten. Er liest die Seite. Die Grenze von 3 Exporten ist unser Kontingent, das separat über Paddle abgerechnet wird, wenn Sie Pro für 3,99 $/Monat oder 26,99 $/Jahr kaufen.

Schritte für einen einzelnen Chat für alle, die nach „herunterladen“ statt „exportieren“ gesucht haben: Claude Chat herunterladen. Dasselbe Produkt, derselbe orangefarbene Button, andere Suchbegriffe.

Wie exportiere ich Chats aus Claude mit dem offiziellen ZIP?

Für das ganze Konto nutzen Sie Settings → Privacy → Export data. Anthropic schickt einen Link per E-Mail, der abläuft. Das ZIP enthält JSON für das ganze Konto, keine schöne Datei für eine einzelne Unterhaltung. Nutzen Sie es als Backup.

Das offizielle ZIP ist das richtige Werkzeug, wenn Sie einen Workspace verlassen, alles archivieren oder eine Anfrage nach „allen meinen Daten“ erfüllen. Es ist das falsche Werkzeug, wenn Sie ein Design-Review geöffnet haben und in der nächsten Minute eine Datei brauchen.

In diesem Ablauf gibt es keinen Filter für eine einzelne Unterhaltung. Sie warten, laden das Archiv herunter, entpacken es und suchen den Chat. Die JSON-Struktur gilt für das Konto. Sie ist nicht das JSON pro Chat, das diese Erweiterung aus der geöffneten Seite schreibt.

Wenn Sie beides brauchen, führen Sie den Datenexport einmal als Backup aus und nutzen Download Claude conversations, wann immer Sie eine Arbeitsdatei brauchen. Diese Aufgaben ersetzen einander nicht. Aus dem ZIP wird kein Markdown. Der orangefarbene Button schickt Ihnen nicht jeden vergessenen Chat aus 2024 per E-Mail.

Der offizielle Datenexport ist auch kein Drucken als PDF. Drucken erfasst die Webseite. Das ZIP enthält strukturierte Kontodaten. Vergleich von Drucken und Dateien: Claude Chat als PDF speichern.

Wie exportiere ich einen Claude Chat als Markdown oder JSON?

Wählen Sie das Format vor dem Export im Auswahlmenü. Markdown ist für Notizen und Git. JSON ist der Nachrichtenbaum für Skripte. Nur-Text entfernt das Markup. PNG ist ein Bild, kein PDF.

Markdown behält Überschriften, Codeblöcke mit Sprachangabe und Tabellen. Das Artefakt-Layout kann „Original“, „Inline“, „Nested“ (verschachtelt) oder „Flat“ (flach) sein. Denkblöcke sind optional. Diese Datei meinen die meisten, wenn sie von einem lesbaren Export sprechen. Übersicht: Formate.

JSON aus der Erweiterung gilt pro Unterhaltung (oder pro Auswahl im Massenexport). Es ist nicht das umbenannte Konto-ZIP von Anthropic. Wenn Sie einen Parser schreiben, nutzen Sie dieses JSON für einen einzelnen Chat und das offizielle ZIP nur, wenn Sie wirklich jede Unterhaltung brauchen, die Anthropic gespeichert hat.

Kann ich einen Claude Chat kostenlos exportieren?

Ja. Kann man Claude Chats kostenlos exportieren? Die ersten 3 Dateien sind für jedes Konto kostenlos, in jedem der fünf Formate. Danach kostet Pro 3,99 $ pro Monat oder 26,99 $ pro Jahr. Die Google-Anmeldung verhindert, dass eine Neuinstallation den kostenlosen Zähler zurücksetzt.

Der Massenexport mit Export All hat kein eigenes kostenloses Kontingent. Eine Datei aus Export All ist ein Export, genau wie beim orangefarbenen Button. Wenn Sie in einem kostenlosen Konto zwanzig Unterhaltungen auswählen, stoppt der Export nach der dritten Datei. Planen Sie die Auswahl.

Drucken und Export data von Anthropic nutzen unser Kontingent nicht. Sie liefern aber auch kein Markdown eines einzelnen Chats. „Kostenlos ohne Erweiterung“ kostet trotzdem Zeit und Nacharbeit.

Die Google-Anmeldung ist nicht optional. Beim ersten Klick auf „Export“ bittet Google darum, eine E-Mail-Adresse zu bestätigen. Wenn Sie abbrechen, sieht das wie ein kaputter Export aus. Schließen Sie die Anmeldung ab und klicken Sie erneut auf „Export“. Für die 3 kostenlosen Dateien ist keine Kreditkarte nötig.

Die Wiederherstellung von Pro folgt dieser Google-Adresse, wenn Sie den Rechner wechseln oder neu installieren. Sie folgt nicht dem Anthropic-Passwort. Melden Sie sich mit demselben Google-Konto an, mit dem Sie bezahlt haben.

Wir halten das offizielle ZIP und unseren Export bewusst als zwei verschiedene Aufgaben getrennt. Konto-JSON per E-Mail ist das Backup von Anthropic. Markdown und JSON pro Chat erzeugen wir im Browser aus dem Chat, den Sie geöffnet haben. Beides in einem Button zu mischen, würde beides schlechter machen.

Exportieren oder Kopieren und Einfügen?

Kopieren und Einfügen exportiert einen Claude Chat nur im schwächsten Sinn: Sie haben Text markiert und verschoben. Code verliert die Einrückung. Tabellen fallen zusammen. Ein langer Chat hat keine Grenzen zwischen Nachrichten. Für eine strukturierte Datei bleiben die Erweiterung, Drucken oder das offizielle ZIP.

Ein Mittelweg ist, alles zu markieren, in Google Docs oder Word einzufügen und die Formatierung von Hand zu reparieren. Das taugt für ein einmaliges Dokument für einen Kunden, nicht für ein wöchentliches Archiv. Jede neue Runde bedeutet neue Nacharbeit. Die Erweiterung gibt es, damit diese Nacharbeit nicht bei einer eingefügten Textwand beginnt.

Beim Kopieren fehlen außerdem eingeklapptes Denken und Artefakte, die nicht aufgeklappt waren. Drucken hat dieselbe Lücke: Eingeklappte Oberfläche fehlt im PDF. Die Schalter der Erweiterung können Denken und Artefakte aufnehmen, wenn sie in den geladenen Seitendaten enthalten sind – eine andere Ebene als „welche Pixel sichtbar sind“.

Wenn Sie nur einen Absatz für Slack brauchen, ist Kopieren ehrlich und schneller. Wenn Sie das ganze Review mit Codeblöcken brauchen, investieren Sie einen der 3 kostenlosen Exporte in Markdown.

Claude Code oder claude.ai: Wie exportiere ich was?

Einen Chat auf claude.ai exportieren Sie mit dieser Chrome-Erweiterung. Eine Unterhaltung aus Claude Code exportieren Sie mit /export im Terminal oder über JSONL unter ~/.claude/projects. Claude Desktop ist ein drittes Fenster und bekommt den orangefarbenen Button nicht.

/export in Claude Code schreibt ein gerendertes Transkript als Nur-Text (Zwischenablage oder Datei). Anthropic dokumentiert, dass JSONL auf der Festplatte ein internes Format ist, das sich ändern kann. Nutzen Sie für alles, was Sie behalten wollen, lieber /export oder die Skript-Schnittstellen von Anthropic. Schritte: Claude Code Chat exportieren.

Claude Desktop: Öffnen Sie denselben Chat auf claude.ai, falls er synchronisiert wurde, und exportieren Sie ihn dort. Andernfalls kopieren Sie aus Desktop oder verlassen sich auf Settings → Privacy → Export data für JSON auf Kontoebene. Anleitung: Claude Desktop Chat exportieren.

Wer auf dieser Website nach „Claude Code Chat exportieren“ sucht, landet auf einer Seite zur Abgrenzung, nicht bei einer Funktion des Web-Store-Eintrags. Der Eintrag gilt nur für claude.ai. Diese Grenze ist das Produkt, kein fehlendes Häkchen.

Was behält ein Export eines Claude Chats, was nicht?

Ein Export mit dieser Erweiterung behält den Nachrichtenbaum, den die Seite geladen hat: Absender, Text, Codeblöcke, Tabellen und – wenn eingeschaltet – Denken, Metadaten und Artefakte. Er lässt alles weg, was noch nicht angezeigt wurde, sowie Bedienelemente wie das Eingabefeld.

Drucken behält Pixel. Ein sauberes Code-Layout geht dabei meist verloren. Das offizielle ZIP behält, was Anthropic ins Kontoarchiv gelegt hat. Ein lesbares Dokument pro Chat fehlt. Kopieren behält die markierten Zeichen und verliert die Struktur.

Absenderfilter: alle Nachrichten, nur Mensch oder nur Assistent. Nützlich, wenn Sie die Prompts ohne Antworten wollen oder umgekehrt. Der Metadaten-Schalter fügt Titel, Zeitstempel und Modell hinzu, wenn Sie eine Quellenangabe in der Datei brauchen.

Die Dateien bleiben auf der Festplatte. Unser Worker sieht den Abo-Status. Google sieht die OAuth-Zustimmung, die Sie erteilt haben. claude.ai hatte die Unterhaltung ohnehin. Das ist die vollständige Liste der Beteiligten. Wir sind nicht Anthropic. Claude ist eine Marke von Anthropic, PBC.

Wirkt der Export zu kurz, laden Sie mehr vom Chat und exportieren Sie erneut. In der kostenlosen Stufe ist dieser zweite Versuch ein weiterer der 3 Exporte. Prüfen Sie vor dem Klick, dass die Antwort fertig gestreamt ist und ältere Runden auf dem Bildschirm sind.

FAQ: Wie exportiere ich einen Claude Chat?

Wie exportiere ich einen einzelnen Chat aus Claude?

Nutzen Sie Download Claude conversations in der geöffneten claude.ai-Unterhaltung. Der offizielle Datenexport gilt für das ganze Konto und ist für einen einzelnen Chat langsamer als nötig. Drucken ergibt ein optisches PDF, kein Markdown.

Wie exportiere ich einen Claude Chat als PDF?

Weder claude.ai noch diese Erweiterung schreibt ein natives PDF. Drucken Sie (Ctrl/Cmd+P → Als PDF speichern) für eine Momentaufnahme. Oder exportieren Sie Markdown und konvertieren Sie es in Word, Google Docs oder einer Markdown-App. Anleitung: Claude Chat als PDF speichern.

Enthält der offizielle Export Artefakte und Denken?

Das ZIP enthält, was Anthropic im JSON des Kontos gespeichert hat. Es ist nicht als Markdown pro Chat mit gewähltem Artefakt-Layout formatiert. Der Export der Erweiterung ist darauf ausgelegt, diese Teile lesbar zu halten, wenn die Schalter aktiv sind und die Seite sie geladen hat.

Gefährdet eine Chrome-Erweiterung mein Anthropic-Konto?

Die Erweiterung nutzt Ihre bestehende angemeldete claude.ai-Sitzung genauso wie die Website. Sie automatisiert keine Aktionen im Konto und ruft Anthropic nicht mit eigenen Zugangsdaten auf. Wir sind nicht Anthropic. Für Sie gelten weiterhin deren Nutzungsbedingungen.

Kann man Claude Chats kostenlos exportieren?

Ja. 3 kostenlose Exporte pro Konto, in Markdown, JSON, Text, XML oder PNG. Danach kostet Pro 3,99 $/Monat oder 26,99 $/Jahr. Drucken und der offizielle Datenexport nutzen dieses Kontingent nicht.

Kann ich einen Claude Chat aus Team-Workspaces exportieren?

Ja, sofern Sie die Unterhaltung auf claude.ai in Chrome öffnen können. Die Erweiterung arbeitet mit der Seite, nicht mit einem Tarif nur für Privatkonten. Freigabelisten Ihres Unternehmens für Erweiterungen gelten weiterhin.

Verbraucht der Export Limits meines Anthropic-Kontos?

Nein. Download Claude conversations liest die Seite, die Sie bereits geladen haben. Die Erweiterung sendet keine zusätzlichen Anfragen an Claude und zählt nicht gegen Nachrichten- oder Nutzungslimits von Anthropic.

Ist der erste Massenexport kostenlos?

Die ersten 3 Dateien eines Kontos sind kostenlos, egal ob sie aus einem Chat, drei Chats oder einer kleinen Auswahl im Massenexport stammen. Export All bekommt kein eigenes kostenloses Kontingent.

Wie exportiere ich eine Unterhaltung aus Claude Code?

Führen Sie im Terminal /export aus oder kopieren Sie JSONL aus ~/.claude/projects. Diese Chrome-Erweiterung exportiert keine Claude-Code-Chats. Alle Schritte: Claude Code Chat exportieren.

Ist eine Google-Anmeldung nötig, um einen Claude Chat zu exportieren?

Ja, ab dem ersten Export. Sie setzt das kostenlose Kontingent durch und stellt Pro wieder her. Bei der Anmeldung werden keine Chatinhalte hochgeladen. Wir speichern die bestätigte E-Mail-Adresse für Kontingent und Abo-Status.

In welche Formate kann ich einen Claude Chat exportieren?

Markdown, JSON, Nur-Text, XML und PNG. Kein PDF. PNG ist ein Bild. Unter Formate steht, wann Sie welches wählen.
