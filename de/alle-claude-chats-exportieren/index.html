Wie exportiere ich den kompletten Claude-Verlauf?

Klicken Sie auf das Symbol von Download Claude conversations, wählen Sie „View and Download All Conversations“ und dann „Export All“. Diese Übersichtsseite listet Ihren claude.ai-Verlauf, sodass Sie alle Claude Chats als einzelne Dateien exportieren können. Der orangefarbene Button in einem einzelnen Chat ist der andere Einstieg; der Massenexport ist diese Tabelle.

  1. Installieren Sie die Erweiterung aus dem Chrome Web Store (Bewertung 5,0) und pinnen Sie sie. Diese Anleitung gilt für Version 1.13.0, September 2026.
  2. Melden Sie sich in Chrome bei claude.ai an. Export All nutzt dieselbe Sitzung wie die Website.
  3. Öffnen Sie das Popup und klicken Sie auf „View and Download All Conversations“.
  4. Suchen oder filtern Sie und wählen Sie die Chats aus, die Sie wirklich brauchen.
  5. Wählen Sie Markdown, JSON, reinen Text, XML oder PNG und klicken Sie auf „Export All“.

Wie filtere ich Claude Chats vor Export All?

Die Suche findet Unterhaltungen nach Namen. Die Filter heißen „All“, „New“, „Exported“ und „Project“ (alle, neu, exportiert, Projekt). Nutzen Sie sie, bevor Sie Ihren kompletten Chat-Verlauf exportieren, damit Sie kein Kontingent für Dateien verbrauchen, die Sie schon haben. „New“ bedeutet: noch nicht mit dieser Erweiterung exportiert. „Exported“ markiert bereits gespeicherte Chats.

„Project“ entspricht der Gruppierung Ihrer Chats auf claude.ai. Ein typischer Massenexport lautet „dieses Projekt“ oder „nur neue“, nicht „alles seit Kontoeröffnung“. Markieren Sie die Zeilen und starten Sie Export All einmal. Den orangefarbenen Button auf Dutzenden URLs zu wiederholen ist der langsame Weg, den diese Tabelle ersetzt.

Der Filter „Exported“ gilt nur lokal für Download Claude conversations. Mit einer Sicherung im Sinne von Anthropic hat er nichts zu tun. Haben Sie früher den offiziellen Datenexport genutzt, können diese Chats hier trotzdem als „New“ erscheinen, bis diese Erweiterung Dateien geschrieben hat. Das ist so gewollt. Überblick über die Tabelle: Funktionen.

Erst auswählen, dann starten. Export All versucht, für jede ausgewählte Zeile eine Datei zu schreiben. Bei einer Grenze von 3 kostenlosen Exporten ist eine Auswahl von 40 Zeilen ein Fall für Pro (3,99 $/Monat oder 26,99 $/Jahr), kein Experiment im Gratis-Tarif. Filtern Sie vorher auf „New“ oder ein Projekt.

Was enthält jede Datei beim Massenexport?

Der Massenexport nutzt dieselben Schalter wie ein einzelner Chat: „Chats“, „Thinking“ (Denkschritte), „Metadata“ (Metadaten) und das Artefakt-Layout „Original“, „Inline“, „Nested“ oder „Flat“ (original, eingebettet, verschachtelt, flach). Wer alle Claude Chats exportiert, bekommt kein ZIP mit geringerer Qualität. Jede Datei kann Codeblöcke, Tabellen und optional die Denkschritte behalten. Der Absenderfilter „all / human only / assistant only“ (alle / nur Mensch / nur Assistent) behält alles, nur Ihre Nachrichten oder nur die Antworten.

„Thinking“ ist Claudes erweitertes Nachdenken, sofern die Seite es angezeigt hat. Metadaten können Titel, Zeitstempel und Modell enthalten. Das Artefakt-Layout steuert, wie Artefakte in Markdown, JSON oder XML landen. PNG bleibt ein Bild des Chats. Keiner dieser Schalter fügt PDF hinzu. Drucken bleibt eine eigene Browser-Aktion: Drucken / PDF.

Export All zählt jede Datei gegen dieselben 3 kostenlosen Exporte wie ein einzelner Chat. Pro für 3,99 $ im Monat oder 26,99 $ im Jahr ist dieselbe Lizenz für beide Wege. Der Massenexport ist der Einzelexport in großem Maßstab, kein anderes Produkt.

Das Team von Download Claude conversations

Unvollständige Dateien im Massenexport bedeuten meist, dass eine sehr lange Unterhaltung nicht vollständig geladen war. Export All hängt davon ab, was claude.ai für jeden geöffneten Chat geladen hat. Wirkt eine Datei zu kurz, öffnen Sie die Unterhaltung, warten Sie und exportieren Sie diese Zeile erneut. Der Status „Exported“ in der Tabelle aktualisiert sich nach einem erfolgreichen Download.

Wie viele kostenlose Exporte verbraucht Export All?

Eine fertige Datei ist ein Export, genau wie beim orangefarbenen Button. Jedes Konto hat insgesamt 3 kostenlose Exporte für Einzel- und Massenexport zusammen. Ein eigenes Kontingent für den Massenexport gibt es nicht. Pro für 3,99 $/Monat oder 26,99 $/Jahr hebt die Grenze für beides auf. Pro rechnet Paddle ab; Kartendaten sehen wir nie.

Eine Neuinstallation von Chrome setzt den Zähler nicht zurück. Deshalb ist bei der ersten Datei eine Google-Anmeldung nötig. Pro wird auf einem neuen Rechner über dasselbe Google-Konto wiederhergestellt. claude.ai Free, Pro, Team und Enterprise funktionieren alle, solange die Sitzung Unterhaltungen auflisten kann; der Tarif bei Anthropic ist nicht unser Zähler.

Planen Sie die Auswahl. Drei neue Chats als Markdown sind ein gültiger Massenexport im Gratis-Tarif. Dreißig Chats sind ein Fall für Pro. Verschiedene Formate vervielfachen das Kontingent nicht; jede fertige PNG- oder JSON-Datei zählt als eins. Erstattungen nach einem Upgrade laufen über Paddle, wie auf der Erstattungsseite beschrieben.

Export All vs. Sicherungs-ZIP für Claude Chats?

Claude Chats sichern heißt meist Settings → Privacy → Export data von Anthropic: ein verzögertes JSON-ZIP für das Konto. Export All heißt: Dateien, die Sie auswählen, sofort, als Markdown, JSON, Text, XML oder PNG. Das ZIP nutzen Sie zur Sicherung des Kontos, diese Seite für Dokumente.

Das offizielle ZIP enthält kein Markdown pro Chat und keine Filter für neu/exportiert. Export All ist kein Rechts- oder Compliance-Abzug jedes vergessenen Chats, den Sie in der Tabelle nicht sehen. Steht eine Unterhaltung nicht auf der Übersichtsseite, kann diese Erweiterung sie nicht erfinden. Alle Methoden inklusive Drucken: Anleitung: Claude Chat exportieren.

Wer nach „Claude Verlauf exportieren“ sucht, steht vor derselben Weggabelung. Geht es um eine Sicherung, beginnen Sie mit dem Datenexport von Anthropic. Geht es um einen Ordner mit Notizen, bleiben Sie bei Export All. Keiner der beiden Wege ist Claude Desktop, keiner ist /export von Claude Code.

Läuft Export All in Desktop oder Code?

Nein. Um mit dieser Erweiterung alle Claude Chats zu exportieren, brauchen Sie claude.ai in Chrome. Claude Desktop zeigt „View and Download All Conversations“ nie an. Claude Code nutzt /export oder JSONL auf der Festplatte. Die Installation fügt diesen Produkten keinen Massenexport hinzu.

Wurden Desktop-Chats mit demselben Konto synchronisiert, erscheinen sie in der Tabelle, sobald sie auf claude.ai existieren. Wurden sie nie synchronisiert, sieht der Massenexport sie nicht. Umwege für Desktop: Claude Desktop Chat exportieren. Terminal-Sitzungen: Claude Code Export. Erwarten Sie von Export All kein JSONL aus einem Repository.

Chrome auf dem Handy wird ebenfalls nicht unterstützt. Die Übersichtsseite ist eine Oberfläche der Desktop-Erweiterung. Einen Massenexport für iOS gibt es von diesem Team 2026 nicht. Öffnen Sie claude.ai am Computer. Team-Richtlinien, die Erweiterungen sperren, sperren auch Export All.

Welches Format eignet sich für Export All?

Wählen Sie ein Format für den ganzen Durchlauf. Markdown für Notiz-Sammlungen, JSON für Datenpipelines, reinen Text für Archive ohne Auszeichnung, XML für den Datenaustausch, PNG für Bilder. Der Massenexport nutzt dieselben fünf Formate wie der orangefarbene Button. Übersicht: Formate. Kein PDF in 1.13.0.

Wer schreibt, exportiert meist in Markdown – Markdown-Anleitung. Wer entwickelt, meist in JSON – JSON-Anleitung. XML: XML. PNG: PNG. JSON aus Export All sind weiterhin Einzeldateien pro Chat aus der Seite, nicht die Struktur des Konto-ZIPs von Anthropic. Mischen Sie diese Schemas nicht in einem Skript.

Das Format ändert den Preis nicht. Auch PNG im Massenexport verbraucht einen Export pro Bild. Wechseln Sie beim zweiten Durchlauf von Markdown zu JSON, kostet das einen weiteren Export pro Chat. Nutzen Sie den Filter „Exported“, um Doppelungen zu vermeiden. Wer dieselben Dateien eher als „Extraktion“ sucht: Claude Chat Extractor. Einzelexport als Produkt: Claude Chat exportieren.

Andere Exporter nennen wir nicht. Den offiziellen Datenexport von Anthropic nennen wir als Gegenstück zum Sicherungs-ZIP. FAQ: alle Claude Chats exportieren

Diese Fragen behandeln den Export aller Claude Chats, Export All und die Sicherung von Claude Chats: Kontingent, Projektfilter, Desktop, Claude Code, PDF und das ZIP von Anthropic. Die Antworten gelten für Erweiterung 1.13.0 auf claude.ai. Das FAQPage-JSON-LD im Kopf der Seite entspricht dieser Liste.

Wie lade ich Claude Chats gesammelt herunter?

Öffnen Sie „View and Download All Conversations“, wählen oder filtern Sie Zeilen, wählen Sie ein Format und klicken Sie auf „Export All“. Jede Datei ist Markdown, JSON, Text, XML oder PNG. So exportieren Sie den ganzen Claude-Verlauf als einzelne Dokumente.

Kostet der Massenexport mehr als ein einzelner Export?

Nein. Derselbe Zähler: insgesamt 3 kostenlose Exporte über orangefarbenen Button und Export All hinweg. Pro kostet 3,99 $/Monat oder 26,99 $/Jahr für beides. Eine Datei aus dem Massenexport kostet einen Export, genau wie ein einzelner Chat.

Kann ich den Verlauf eines einzelnen Projekts exportieren?

Ja. Filtern Sie auf der Übersichtsseite nach „Project“ und klicken Sie dann auf „Export All“. So exportieren Sie meist ganze Chat-Gruppen, ohne jeden Chat des Kontos mitzunehmen.

Ist der Massenexport dasselbe wie der offizielle Export von Anthropic?

Nein. Der offizielle Datenexport ist ein JSON-ZIP des ganzen Kontos per E-Mail (Sicherung der Claude Chats). Export All liefert sofort Dateien, die Sie auswählen, im gewählten Format.

Merkt sich Download Claude conversations bereits exportierte Chats?

Ja. Der Filter „Exported“ zeigt, was diese Erweiterung schon heruntergeladen hat, sodass Sie beim nächsten Besuch Export All nur auf „New“ anwenden können.

Exportiert man so den kompletten Claude-Verlauf?

Ja – mit Export All auf der Übersichtsseite exportieren Sie den ganzen Claude-Verlauf als einzelne Dateien. Der Datenexport von Anthropic ist stattdessen ein verzögertes ZIP des Kontos.

Funktioniert Export All in Claude Desktop?

Nein. Diese Chrome-Erweiterung läuft nicht in Claude Desktop. Synchronisieren Sie die Chats zuerst mit claude.ai, oder kopieren Sie den Text bzw. nutzen Sie das offizielle ZIP.

Kann ich Claude Chats mit Export All sichern?

Export All liefert einen Ordner lesbarer Dateien, nicht das Sicherungs-ZIP von Anthropic. Für eine Sicherung auf Kontoebene nutzen Sie Settings → Privacy → Export data. Nutzen Sie beides, wenn Sie Dokumente und ein Archiv wollen.

Schreibt Export All eine PDF-Datei?

Nein. Die Formate sind Markdown, JSON, reiner Text, XML und PNG. Drucken Sie aus Chrome, wenn Sie eine PDF-ähnliche Seite brauchen. PNG im Massenexport ergibt Bilder, eines pro Chat.

Kann ich so auch alle Claude Code Chats exportieren?

Nein. Claude Code nutzt /export oder JSONL auf der Festplatte. Export All listet nur claude.ai-Unterhaltungen in Chrome.

Was, wenn Export All nach drei Dateien stoppt?

Dann sind die 3 kostenlosen Exporte verbraucht. Wechseln Sie zu Pro (3,99 $/Monat oder 26,99 $/Jahr) oder warten Sie, bis Sie mehr brauchen. Eine Neuinstallation setzt den an Google gebundenen Zähler nicht zurück.

Brauche ich einen bezahlten Anthropic-Tarif für Export All?

Nein. Jeder claude.ai-Tarif, der den Verlauf in Chrome laden kann, funktioniert. Unser Kostenlos/Pro-Zähler ist davon getrennt. Team-Admins können die Erweiterung im Browser trotzdem sperren.
