Was ist der Claude Code Export im Terminal?

Der Claude Code Export ist der Befehl /export in einer interaktiven CLI-Sitzung. Laut Dokumentation von Anthropic öffnet er ein Menü: Sie kopieren die aktuelle Unterhaltung oder speichern sie als Textdatei. Nachrichten und Tool-Ausgaben erscheinen dabei als lesbarer Text. Geben Sie einen Dateinamen mit, entfällt das Menü und die Datei wird direkt geschrieben.

Das ist kein Markdown von claude.ai, kein JSON aus dieser Chrome-Erweiterung und kein PDF. Es ist ein aufbereitetes Transkript zum Lesen. Das JSONL-Protokoll auf der Festplatte ist laut Anthropic ein anderes, internes Format für das Produkt selbst – keine öffentliche Schnittstelle für Sie.

/export

Ohne Rückfrage eine benannte Datei im aktuellen Arbeitsverzeichnis schreiben:

/export my-session

Maßgeblich für Optionen und Dateinamen ist die Sitzungsdokumentation von Anthropic; beides ändert sich zwischen Claude Code Versionen. Community-Blogs sind zweitrangig. Sieht der Dialog von /export bei Ihnen anders aus, haben Sie eine andere Version – nutzen Sie die Hilfe im Produkt, keinen Screenshot von 2025.

Für Skripte verweist Anthropic auf andere Schnittstellen: claude -p mit --output-format json oder stream-json, Fortsetzen per Sitzungs-ID, Hooks mit transcript_path oder das Agent SDK. Das sind Entwicklerwerkzeuge von Claude Code. Mit der Chrome-Erweiterung dieser Website haben sie nichts zu tun.

Lesbar vs. strukturiert. /export ist das Transkript für Menschen. Das JSONL im projects-Ordner ist das Protokoll. Das JSON der Chrome-Erweiterung ist eine dritte Form, erzeugt nur aus einer claude.ai-Seite. Schreiben Sie keinen gemeinsamen Parser für alle drei.

Wie lädt man eine Claude Code Unterhaltung von der Festplatte?

Eine Claude Code Unterhaltung holen Sie von der Festplatte, indem Sie die JSONL-Datei der Sitzung aus dem projects-Verzeichnis kopieren – oder Sie führen /export aus und erhalten ein lesbares Transkript. Unter macOS und Linux liegt der Standardpfad unter ~/.claude/projects/. Unter Windows ist es %USERPROFILE%\.claude\projects. Die Dateinamen sind Sitzungs-IDs.

Der Projektordner heißt wie das Arbeitsverzeichnis, wobei alle nicht alphanumerischen Zeichen durch Bindestriche ersetzt werden. Sehr lange Namen kürzt Anthropic und hängt einen Hash an, damit das Verzeichnis im Rahmen des Dateisystems bleibt. Finden Sie den Ordner nicht, haben Sie Claude Code wahrscheinlich aus einem anderen Arbeitsverzeichnis gestartet, als Sie denken.

Jede JSONL-Zeile ist ein JSON-Objekt für eine Nachricht, einen Tool-Aufruf oder Metadaten. Laut Anthropic ist dieses Format intern und ändert sich zwischen Versionen. Skripte, die diese Dateien auswerten, können mit einem Claude Code Release brechen. Brauchen Sie etwas Stabiles, nehmen Sie /export oder die dokumentierten Skript-Schnittstellen.

Der Speicherort kann sich verschieben. CLAUDE_CONFIG_DIR verlegt den Konfigurationsordner weg von ~/.claude. CLAUDE_CODE_PROJECT_DIR_NAME benennt zusammen mit diesem Ordner das Projektverzeichnis (laut Anthropic ab Claude Code v2.1.234). cleanupPeriodDays in settings.json ändert die Standard-Aufbewahrungsdauer. Keine dieser Einstellungen gehört zu Download Claude conversations.

Wer Claude Code Unterhaltungen sichern will, kopiert also den Ordner oder exportiert Transkripte regelmäßig mit /export. Diese Website bekommt keinen Button „JSONL importieren“. Wir lesen Ihr Home-Verzeichnis nicht.

Wo speichert Claude Code den Verlauf?

Claude Code speichert den Verlauf als JSONL-Transkripte im projects-Ordner des Konfigurationsverzeichnisses. Standard unter macOS und Linux: ~/.claude/projects/<encoded-cwd>/<session-id>.jsonl. Windows nutzt %USERPROFILE%\.claude\projects. Anthropic kann diese Struktur ändern; fehlt ein Pfad, prüfen Sie die aktuelle Sitzungsdokumentation.

Fortsetzen ist etwas anderes als Exportieren. claude --continue und claude --resume laden eine Sitzung neu, damit Sie weiterarbeiten können. /export schreibt eine Kopie, die Sie in Git ablegen oder per E-Mail verschicken. Das eine stellt Kontext wieder her, das andere nimmt eine Aufzeichnung mit. Die Sitzungsseite von Anthropic erklärt Berechtigungsmodus beim Fortsetzen, Kompaktierung/Zusammenfassung und die Sitzungsauswahl – nichts davon betrifft diese Erweiterung.

Die Desktop-App, Claude Code im Web und die VS Code Erweiterung führen laut Anthropic jeweils einen eigenen Sitzungsverlauf. Die Pfade in dieser Anleitung gelten für die CLI. Gehen Sie nicht davon aus, dass ein Cowork-Transkript aus Desktop im selben JSONL-Ordner liegt wie Ihre Terminal-Sitzungen.

JSONL ist kein öffentliches Schema. Laut Anthropic ändert sich das Zeilenformat. Wer es trotzdem auswertet, sollte eine Claude Code Version fixieren und mit Brüchen rechnen. /export ist der stabile Weg zu einer lesbaren Claude Code Unterhaltung.

Umgebungsvariablen wie CLAUDE_CODE_SKIP_PROMPT_HISTORY können das Schreiben von Transkripten verhindern. Ist der projects-Ordner leer, prüfen Sie, ob Sie die Speicherung abgeschaltet, CLAUDE_CONFIG_DIR umgeleitet oder in diesem Verzeichnis nie eine interaktive Sitzung gestartet haben.

Claude Code Export vs. offizieller Datenexport von Anthropic?

Der Claude Code Export (/export oder JSONL) umfasst eine Terminal-Sitzung. Der offizielle Datenexport ist Settings → Privacy → Export data auf claude.ai (die Beschriftungen können übersetzt sein, wenn claude.ai auf Deutsch eingestellt ist): ein verzögertes JSON-ZIP des Anthropic-Kontos. Das sind unterschiedliche Archive. Das ZIP ersetzt /export nicht.

Ob eine bestimmte Claude Code Sitzung im Konto-ZIP landet, hängt davon ab, wie Anthropic dieses Produkt speichert – nicht von dieser Erweiterung. Betrachten Sie das ZIP als Sicherung des Web-Kontos, solange die aktuelle Datenschutz-Dokumentation von Anthropic nichts anderes sagt. Wir fügen diesem ZIP keine CLI-Sitzungen hinzu.

Claude Code vs. Desktop vs. claude.ai – wie exportieren?

Claude Code, Claude Desktop und claude.ai sind drei getrennte Oberflächen. Der Claude Code Export nutzt /export und JSONL. Desktop ist eine App ohne den orangefarbenen Button dieser Erweiterung. claude.ai in Chrome ist der einzige Ort, an dem Download Claude conversations läuft. Wer die Namen verwechselt, bekommt Exporte, die still scheitern.

Claude Desktop: Ist der Chat mit demselben Anthropic-Konto synchronisiert, öffnen Sie ihn auf claude.ai und exportieren ihn dort. Existiert er nur im Desktop-Fenster, bleibt Kopieren und Einfügen oder das Warten auf den offiziellen Datenexport. Anleitung: Claude Desktop Chat exportieren.

Das Claude Code Panel in VS Code ist näher an der CLI als an claude.ai. Unser Content-Skript wird sich nicht in diese Webview einklinken. Nutzen Sie /export in der Sitzung, die die Nachrichten tatsächlich enthält.

Unabhängige Chrome-Erweiterung, nicht mit Anthropic, PBC verbunden. Claude ist eine Marke von Anthropic. Halten Sie sich an deren Nutzungsbedingungen. Zum Kopieren von Tool-Ausgaben mit proprietärem Code können wir keine Rechtsberatung geben; das klären Sie mit Ihrem Arbeitgeber und Anthropic.

FAQ: Claude Code Chat exportieren

Wie exportiere ich eine Claude Code Unterhaltung?

Tippen Sie im Claude Code Terminal /export (optional mit Dateinamen), um ein lesbares Transkript zu speichern, oder kopieren Sie die JSONL-Datei aus ~/.claude/projects unter macOS/Linux bzw. %USERPROFILE%\.claude\projects unter Windows. Den aktuellen Dialog beschreibt die Sitzungsdokumentation von Anthropic.

Lädt diese Chrome-Erweiterung Claude Code Chats herunter?

Nein. Download Claude conversations funktioniert nur auf claude.ai in Chrome. Terminal-Sitzungen, JSONL-Transkripte oder den Befehl /export kann sie nicht lesen. Der Claude Code Export bleibt in der CLI.

Wo speichert Claude Code den Verlauf?

Sitzungstranskripte sind JSONL-Dateien unter ~/.claude/projects/<encoded-working-directory>/, benannt nach der Sitzungs-ID. Die genaue Struktur kann sich ändern. Nutzen Sie /export, wenn Sie eine lesbare Datei statt JSONL wollen. CLAUDE_CONFIG_DIR kann den Ordner verschieben.

Wie lade ich eine Claude Code Unterhaltung als Markdown herunter?

/export in Claude Code erzeugt ein Transkript als reinen Text, nicht das Markdown dieser Erweiterung. Brauchen Sie Markdown, exportieren Sie eine claude.ai-Kopie der Arbeit mit Download Claude conversations oder wandeln Sie den /export-Text selbst um. Wir konvertieren kein JSONL in Markdown.

Wie lade ich stattdessen eine claude.ai-Unterhaltung herunter?

Installieren Sie die kostenlose Chrome-Erweiterung, öffnen Sie den Chat auf claude.ai und nutzen Sie den orangefarbenen Button – oder Export All für den ganzen Verlauf. Siehe Claude Chat herunterladen. 3 kostenlose Exporte; Pro kostet 3,99 $/Monat oder 26,99 $/Jahr.

Ist /export dasselbe wie der offizielle Datenexport?

Nein. /export betrifft die aktuelle Claude Code Sitzung. Settings → Privacy → Export data schickt per E-Mail ein JSON-ZIP des Anthropic-Kontos. Verschiedene Produkte, verschiedene Dateien, verschiedene Wartezeiten.

Kann ich Claude Code JSONL mit jq auswerten?

Ja, mit dem Vorbehalt, den Anthropic selbst nennt: Das Zeilenformat ist intern und kann sich ändern. Nehmen Sie lieber /export oder claude -p --output-format json, wenn Sie ein verlässliches Format brauchen. Wer trotzdem JSONL parst, sollte die CLI-Version fixieren.

Funktioniert der Claude Code Export unter Windows?

Ja. /export ist ein CLI-Befehl. Transkripte liegen unter %USERPROFILE%\.claude\projects, sofern Sie CLAUDE_CONFIG_DIR nicht setzen. Diese Chrome-Erweiterung läuft trotzdem nicht in diesem Terminal.

Ist Claude Code dasselbe wie Claude Desktop?

Nein. Claude Code ist der Coding-Agent im Terminal. Claude Desktop ist die Chat-App. claude.ai ist die Website. Nur die Website bekommt diese Erweiterung. Hinweise zum Desktop-Export: Claude Desktop.

Wird die Erweiterung irgendwann /export einbinden?

Nicht in Version 1.13.0. Der Produktumfang ist claude.ai: fünf Formate, lokale Dateien, Google-Anmeldung für das Kontingent. Ändert sich das, steht es auf dieser Seite. Bis dahin nutzen Sie die CLI von Anthropic für den Claude Code Export.

Enthält /export auch Tool-Ausgaben?

Laut Anthropic enthält /export Nachrichten und Tool-Ausgaben als lesbaren Text. Das ist deren Transkript, nicht unser Parser. Für den genauen aktuellen Inhalt führen Sie /export in Ihrer Version aus und lesen die Datei – die Dokumentation hinkt Releases manchmal hinterher.

Kann ich mehrere Claude Code Sitzungen auf einmal exportieren?

Nicht mit Export All dieser Erweiterung. Der Massenexport auf unserer Übersichtsseite gilt nur für claude.ai. Für viele CLI-Sitzungen kopieren Sie den projects-Ordner oder führen /export pro Sitzung aus. Einen Massenexport per orangefarbenem Button gibt es für JSONL nicht.
