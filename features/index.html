Everything in Download Claude conversations

Download Claude conversations is a Chrome extension with two entry points on claude.ai: an orange export button on every conversation, and a separate browse page for exporting many conversations at once. Both write Markdown, JSON, plain text, XML, or PNG files, locally in your browser.

The in-page widget

Open any conversation on claude.ai and Download Claude conversations adds a button next to the message box. Click it, pick a format, click Export — the file downloads immediately. No page reload, no separate tab, no account dashboard to navigate first. This is the fastest path for a single chat, and it's the same button whether you're using the free tier or Pro.

The browse table

The extension's browse page lists every conversation in your account in a searchable table, with filters for All, New, Exported, and by Project. Select any combination and click Export All to turn a bulk selection into files in one pass — full detail on the bulk page.

Formats

Five formats, same list whether you're exporting one chat or many: Markdown, JSON, plain text, XML, PNG. No native PDF yet — see the formats hub for what each one is good for.

Thinking blocks

When Claude shows extended thinking, this Claude Conversation Downloader can include it in the export as an optional toggle — on for research and audit trails, off when you only want the final answer.

Artifact layouts

Artifacts export in your choice of four layouts — Original, Inline, Nested, or Flat — so the structure matches how you actually want to read the file afterward, whether that's close to the on-screen layout or flattened into one linear document.

Sender filter

Yes. Filter by sender — all messages, human only, or assistant only — before exporting, useful when you only need your own prompts or only Claude's responses.

Google sign-in and Pro restore

Google sign-in is required from your first export. It's how Download Claude conversations enforces the 3-export free quota per account and lets you restore Pro if you reinstall the extension or move to a new machine — your conversation content is never part of that sign-in flow. Full mechanics on how it works.

What we don't do

No native PDF, no Notion export, no Word export, no direct Google Docs push. Download Claude conversations is deliberately narrow: five formats, done well, rather than a long list of half-supported ones. The honest list today is Markdown, JSON, plain text, XML, PNG — if that changes, this page changes with it, the same day.
