What Chrome extension features export one chat?

The core Chrome extension features for one thread are the orange button Download Claude conversations adds next to the message box on claude.ai. Open a conversation URL, pick a format, then click Export or Copy. The file downloads immediately. Only PDF asks for sign-in; the other six formats need no account.

  1. Install Download Claude conversations from the Chrome Web Store.
  2. Reload claude.ai and open a real conversation URL — a chat, a Project chat, a Cowork session, or Claude Code on the web.
  3. Click the orange download button to the right of the message box.
  4. Choose Messages (All, Human, or Assistant), a format, and the Thinking checkbox, or click Select to tick individual messages. Chrome extension features remember the last format you used.
  5. Click Export to download the file, or Copy to put it on the clipboard. Copy works for Markdown, text, JSON, XML, and CSV.

The orange button only appears on a loaded conversation. The empty composer home has nothing to parse. If the button is missing, pin the extension in the Chrome puzzle menu and refresh claude.ai. These Chrome extension features never inject in Claude Desktop or the Claude Code terminal. Picking PDF opens a dialog for file name, page size, margins, light or dark mode, font and font size, page numbers, a table of contents, timestamps, and a page break before every prompt: Claude chat as PDF.

Local file. PDF, Markdown, JSON, text, XML, CSV, and PNG are built in the tab. Single-chat exports in the non-PDF formats send nothing to our servers. PDF and bulk send only your Google email for the daily count. Chat text never leaves. Mechanics: how it works.

Which Chrome extension features cover Export All?

Bulk Chrome extension features live on the Dashboard, View and Download All Conversations: search, filters All conversations / New / Updated / Previously exported, Chat and Cowork tabs, project search, and Export All. Export All saves one ZIP. The free plan covers 3 chats a day with Google sign-in; Pro at $3.99 a month or $26.99 a year removes that cap.

New means not yet exported with Download Claude conversations. Previously exported tracks chats you already saved so a second Export All can skip them. The Cowork tab lists Cowork sessions next to regular chats. Project search finds the chats inside one claude.ai Project. Search is by conversation name. Full flow: bulk Export All.

The daily limit is per account. Three chats a day on the free plan, shared with PDF — not three per bulk run. If you select 40 conversations with 3 left, the whole batch is blocked, not cut short. Plan the selection before you click Export All, or use Pro.

Export All uses the Dashboard’s Chat format picker (all seven formats, PDF included), the checkboxes Chats, Thinking, Metadata, Tools, and Sources, and the artifact format. It is one ZIP with one file per chat, not Anthropic’s delayed account ZIP. You pick one format per run. Chrome extension features do not mix Markdown and JSON in a single click. The Dashboard also has backup and restore.

Do Chrome extension features keep artifacts?

Yes. Chrome extension features include artifact layout: Original, Inline, Nested, or Flat. Thinking blocks, tool / MCP steps, and web search sources are each opt-in: Thinking is a checkbox in the export panel, tools and sources are switched on in Settings, and the Dashboard has checkboxes for all three. Metadata can add title, timestamps, and model. Sender filter limits the file to all, human only, or assistant only, and Select ticks individual messages.

Artifacts are part of the claude.ai thread. Layout decides whether they sit inside the Markdown, JSON, XML, or text file or go into their own folder inside a ZIP. Artifact ZIPs are unlimited and free, and so is the project files ZIP: on a Project page, click Project files → Download ZIP. On PNG artifacts are drawn, not stored as markup. If thinking is off, the export omits extended thinking even when claude.ai showed it on screen.

If the thread is long, scroll until claude.ai has loaded earlier messages. Chrome extension features can only export what the page has rendered. A half-loaded DOM produces a truncated file, which looks like a missing-artifact bug and is usually an un-scrolled conversation.

Which Chrome extension features are in Settings?

Settings is the extension’s Options page. It holds the filename template, “Copy instead of download,” embedded images in Markdown, tool / MCP steps, web search sources, date and time format, backup and restore, and your subscription. The extension UI is English only.

How do Chrome extension features handle sign-in?

Most Chrome extension features need no sign-in. Single-chat exports in Markdown, Plain Text, JSON, XML, CSV, and PNG are unlimited and anonymous, and so are Copy, Select, artifact ZIPs, and the project files ZIP. Google sign-in is asked only for PDF, bulk Export All, and Pro. Conversation content is never part of that flow.

PDF and bulk ZIP share 3 a day on the free plan, counted on our server against your Google email. The day resets at midnight UTC, and a reinstall does not reset it. Pro is $3.99 a month or $26.99 a year through Paddle. Paddle is merchant of record; this team never sees card numbers. Pro restores on a new computer when you sign in with the same Google account.

You do not need Anthropic’s paid claude.ai plan. Free, Pro, Team, and Enterprise claude.ai plans work if Chrome can open the chat. If a workspace admin blocks extensions, Download Claude conversations will not inject — that is browser policy, not a missing feature on this page.

What Chrome extension features are not in 1.16.2?

Chrome extension features that are not in 1.16.2: Notion export, Word export, Google Docs push, Claude Desktop hooks, and local Claude Code terminal sessions (/export, ~/.claude/projects). Download Claude conversations is a claude.ai Chrome content script, not a second app under another name. PDF is no longer on this list; it is built in.

Claude Desktop is a Mac/Windows app. Claude Code in the terminal is a local agent. Neither gets the orange button. Claude Code on the web (claude.ai/code) and Cowork sessions open on claude.ai, so they export like any chat. If a Desktop thread also exists on claude.ai, open it in Chrome and use the Chrome extension features there. Desktop contrast: export Claude Desktop chat. Code contrast: Claude Code export.

Mobile claude.ai in a phone browser is out of scope. There is no iOS or Android app from this team in 2026. Copy is not available for PDF or PNG. Version dated September 2026. If we add a format, this page updates the same day.

FAQ: Chrome extension features

These FAQ items cover Chrome extension features in Download Claude conversations 1.16.2: the orange button, Export All, formats, artifacts, the free plan, Desktop, and Pro. Each answer is a product fact. The FAQPage JSON-LD in the page head matches this on-page list.

What Chrome extension features export a single chat?

The orange button next to the message box on a claude.ai conversation URL. Pick PDF, Markdown, JSON, text, XML, CSV, or PNG, then click Export or Copy. That is the fastest Chrome extension features path for one thread, and only PDF needs sign-in.

Do Chrome extension features include bulk Export All?

Yes. The Dashboard (View and Download All Conversations) lists claude.ai history with All conversations, New, Updated, and Previously exported filters, Chat and Cowork tabs, and project search. Export All saves one ZIP. The free plan covers 3 chats a day with Google sign-in; Pro is unlimited.

Which formats do Chrome extension features support?

Seven: PDF, Markdown, Plain Text, JSON, XML, CSV, and PNG. PDF is built in the browser with its own dialog. CSV is one row per message. PNG is one image of the conversation.

Do Chrome extension features export artifacts and thinking?

Yes. Artifact layout is Original, Inline, Nested, or Flat, and artifacts can go into their own folder inside a ZIP. Thinking, tool / MCP steps, and web search sources are each opt-in. Metadata, sender filter, and Select are optional.

Are Chrome extension features free to try?

Yes. Markdown, text, JSON, XML, CSV, and PNG exports are unlimited and need no account. PDF and bulk ZIP are 3 a day with Google sign-in. Pro at $3.99 a month or $26.99 a year through Paddle removes that cap.

Do Chrome extension features work on Desktop or Code?

Not in Claude Desktop or the Claude Code terminal. The content script injects only on claude.ai in Chrome. Claude Code on the web (claude.ai/code) and Cowork sessions run there, so they export. Open a Desktop thread on claude.ai if it exists there.

Do Chrome extension features upload my chats?

No. Every file, PDF included, is built in the browser. Single-chat exports in the other formats send nothing. For PDF, bulk, or Pro, only your Google email is sent, for the daily count and subscription. See how it works for the boundary.
