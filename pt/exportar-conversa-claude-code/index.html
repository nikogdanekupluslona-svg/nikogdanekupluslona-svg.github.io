O que é exportar conversa do Claude Code no terminal?

Exportar do Claude Code é usar o comando /export dentro de uma sessão interativa da linha de comando. A documentação da Anthropic descreve um menu para copiar a conversa atual ou salvar um arquivo de texto simples, com mensagens e saídas de ferramentas renderizadas como texto legível. Passe um nome de arquivo para pular o menu e gravar esse arquivo.

Isso não é o Markdown do claude.ai, não é o JSON desta extensão do Chrome e não é um PDF. É uma transcrição renderizada para uma pessoa ler. A Anthropic diz que o log JSONL no disco é um formato diferente e interno, pensado para o produto, não como uma API pública para você.

/export

Para pular a pergunta e gravar um arquivo com nome no diretório de trabalho atual:

/export my-session

A documentação de sessões da Anthropic é a fonte oficial para opções e nomes de arquivo; eles mudam entre versões do Claude Code. Trate blogs da comunidade como fonte secundária. Se o texto da janela do /export não bate com o que você vê, a sua linha de comando é de outra versão — use a ajuda do próprio produto, não uma captura de tela de 2025.

Para scripts, a Anthropic indica outras interfaces: claude -p com --output-format json ou stream-json, retomada por ID de sessão, hooks que recebem um transcript_path ou o Agent SDK. Essas são interfaces de desenvolvedor do Claude Code. Não são a extensão do Chrome deste site.

Legível ou estruturado. O /export é a transcrição para pessoas. O JSONL na pasta de projetos é o log. O JSON da extensão do Chrome é um terceiro formato, gerado apenas a partir de uma página do claude.ai. Não escreva um único parser para os três.

Como baixar uma conversa do Claude Code a partir do disco?

Para baixar uma conversa do Claude Code a partir do disco, copie o arquivo JSONL da sessão no diretório de projetos ou rode /export para ter uma transcrição legível. O caminho padrão no macOS e no Linux fica em ~/.claude/projects/. No Windows, é %USERPROFILE%\.claude\projects. Os nomes dos arquivos são IDs de sessão.

O nome da pasta do projeto é o diretório de trabalho com os caracteres não alfanuméricos trocados por hífens. A Anthropic corta nomes convertidos muito longos e acrescenta um hash para que o diretório respeite os limites do sistema de arquivos. Se você não encontra a pasta, abriu o Claude Code a partir de um diretório diferente do que imagina.

Cada linha do JSONL é um objeto JSON de uma mensagem, de um uso de ferramenta ou de metadados. A Anthropic afirma que esse formato de entrada é interno e muda entre versões. Scripts que processam esses arquivos podem quebrar com uma nova versão do Claude Code. Prefira o /export ou as interfaces de script documentadas quando precisar de algo estável.

O local de armazenamento pode mudar. CLAUDE_CONFIG_DIR move a árvore de configuração para fora de ~/.claude. CLAUDE_CODE_PROJECT_DIR_NAME define o nome do diretório do projeto quando usado com esse diretório de configuração (Claude Code v2.1.234 ou posterior, segundo a Anthropic). cleanupPeriodDays no settings.json muda o período padrão de retenção. Nenhuma dessas opções é recurso do Download Claude conversations.

Para baixar conversas do Claude Code como backup, portanto: copie a pasta ou exporte transcrições com /export regularmente. Este site não vai adicionar um botão “importar JSONL”. Não lemos a sua pasta pessoal.

A exportação do Claude Code funciona com esta extensão?

Não para sessões do terminal. O Download Claude conversations não lê sessões locais do Claude Code. A extensão do Chrome atua no claude.ai. Ela não enxerga o terminal, não consegue rodar /export e não abre JSONL. O Claude Code on the web em claude.ai/code é a exceção: é uma página do claude.ai, então é exportado como qualquer chat. Se você pesquisou como baixar uma conversa do Claude Code pela linha de comando, siga os passos de terminal desta página.

Muita gente chega aqui porque o Google junta “Claude” e “exportar” — em português ou em inglês, como “claude code export”. A extensão na Chrome Web Store continua sendo só para o claude.ai. Instalá-la não coloca um botão laranja no iTerm, no Ghostty, no terminal do VS Code nem no aplicativo de desktop que envolve o Claude Code.

Se você também mantém uma conversa paralela no claude.ai para o mesmo trabalho de programação, esse chat do navegador pode ser salvo com a extensão. Os dois registros não são unidos. Chamadas de ferramentas que aconteceram só na linha de comando não aparecem na exportação web, a menos que você as tenha colado lá.

Recebemos o mesmo e-mail de suporte toda semana: alguém instalou a extensão do Chrome e esperava que o /export aparecesse. Nós só lemos o claude.ai. O Claude Code já traz o /export e o JSONL. Envolver a linha de comando seria outro produto, e não o lançamos.

Dá para exportar sessões do Claude Code on the web?

Sim. O Claude Code on the web roda em claude.ai/code, então o Download Claude conversations exporta essas sessões como qualquer chat do claude.ai. Abra a sessão no Chrome, clique no botão laranja, escolha um formato e clique em "Export" (Exportar). Esta é a única interface do Claude Code que a extensão cobre.

Os formatos são os mesmos sete de todo chat: PDF, Markdown, texto simples, JSON, XML, CSV e PNG. Markdown, texto, JSON, XML, CSV e PNG são ilimitados e não precisam de conta. O PDF pede login com Google e divide as 3 por dia do plano grátis com o ZIP em lote, a menos que você esteja no Pro. Os blocos de código mantêm a linguagem. O raciocínio estendido é a caixa "Thinking" (raciocínio) no painel; as etapas de ferramentas / MCP e as fontes de pesquisa na web são opções nas configurações.

A exportação web é o que o claude.ai/code mostra no navegador. Não é o log JSONL de uma execução local na linha de comando e não alcança sessões que rodaram só no seu terminal. Segundo a Anthropic, o Claude Code on the web mantém o próprio histórico de sessões, separado da árvore ~/.claude/projects da linha de comando. Para uma sessão de terminal, o caminho continua sendo o /export.

Onde o Claude Code guarda o histórico de conversas?

O Claude Code guarda o histórico de conversas como transcrições JSONL na pasta de projetos do diretório de configuração. Padrão no macOS e no Linux: ~/.claude/projects/<encoded-cwd>/<session-id>.jsonl. O Windows usa %USERPROFILE%\.claude\projects. A Anthropic pode mudar essa estrutura; consulte a documentação atual de sessões se um caminho não existir no disco.

Retomar é diferente de exportar. claude --continue e claude --resume recarregam uma sessão para você continuar trabalhando. O /export grava uma cópia que você pode deixar no git ou mandar por e-mail. Um restaura o contexto. O outro leva um registro com você. A página de sessões da Anthropic explica o modo de permissão ao retomar, o resumo/compactação e o seletor de sessões — nada disso é desta extensão.

O aplicativo de desktop, o Claude Code on the web e a extensão do VS Code mantêm cada um o próprio histórico de sessões, segundo a Anthropic. Os caminhos deste guia são os da linha de comando. As sessões web ficam em claude.ai/code, onde a extensão pode exportá-las. Não suponha que uma transcrição do Cowork no Desktop esteja na mesma árvore JSONL que você usa no terminal.

Não trate o JSONL como um esquema público. A Anthropic diz que o formato das linhas muda. Se mesmo assim você processar esses arquivos, fixe uma versão do Claude Code e espere quebras. O /export é a forma estável de obter uma conversa do Claude Code legível.

Variáveis de ambiente como CLAUDE_CODE_SKIP_PROMPT_HISTORY podem impedir a gravação das transcrições. Se a pasta de projetos está vazia, verifique se você desativou a persistência, apontou CLAUDE_CONFIG_DIR para outro lugar ou nunca rodou uma sessão interativa naquele diretório.

Como baixar um chat do Claude no claude.ai?

Para baixar um chat do Claude no claude.ai: instale o Download Claude conversations, abra a conversa no Chrome, clique no botão laranja e escolha PDF, Markdown, texto simples, JSON, XML, CSV ou PNG. Esse é o produto para o navegador, e ele cobre também as sessões de claude.ai/code. Não é a exportação do Claude Code no terminal. Passo a passo: como baixar conversa do Claude.

Todo o histórico do claude.ai em arquivos separados usa o "Export All" (Exportar tudo) no Dashboard, não o /export. No plano grátis, cada chat no ZIP conta para as 3 por dia (divididas com o PDF, com reinício à meia-noite UTC); o Pro remove o limite. Guia: exportação em lote com Export All. Formatos: formatos.

Nenhuma conta é necessária para exportar um chat em Markdown, texto, JSON, XML, CSV ou PNG — essas exportações são ilimitadas. O login com Google só aparece para PDF, ZIP em lote e Pro, para contarmos a cota diária e restaurarmos o Pro. Os arquivos são gerados localmente, PDF incluído. A Paddle cobra o Pro por US$ 3,99 por mês ou US$ 26,99 por ano. Nada disso se aplica ao /export no terminal.

Se o seu trabalho começou no Claude Code e você colou um resumo no claude.ai, baixe a conversa web para as suas notas e guarde o /export para o log real da linha de comando. Dois arquivos valem mais do que um arquivo confuso.

Exportar do Claude Code ou o Export data oficial da Anthropic?

Exportar do Claude Code (/export ou JSONL) cobre uma sessão de terminal. O Export data oficial é Settings → Privacy → Export data no claude.ai (os rótulos podem aparecer traduzidos se o claude.ai estiver em português): um ZIP em JSON da conta da Anthropic, entregue com atraso. Não são o mesmo arquivo. O ZIP não substitui o /export.

Se uma sessão do Claude Code aparece ou não no ZIP da conta depende de como a Anthropic armazena esse produto, não desta extensão. Trate o ZIP como backup da conta web, a menos que a documentação de privacidade atual da Anthropic diga outra coisa. Não adicionamos sessões da linha de comando a esse ZIP.

Como exportar um chat do Claude pelo site, incluindo a comparação entre esse ZIP e a extensão, está documentado aqui: como exportar conversa do Claude. A exportação em PDF da extensão também não se aplica a uma interface de terminal. Veja baixar chat do Claude em PDF só quando a conversa estiver no claude.ai, incluindo claude.ai/code.

Exportar no Claude Code, no Desktop ou no claude.ai?

Claude Code, Claude Desktop e claude.ai são três interfaces diferentes. A exportação do Claude Code usa /export e JSONL. O Desktop é um aplicativo sem o botão laranja desta extensão. O claude.ai no Chrome é o único lugar onde o Download Claude conversations roda — incluindo o Claude Code on the web em claude.ai/code. Misturar esses nomes é como as exportações falham sem aviso.

Claude Desktop: se o chat foi sincronizado com a mesma conta da Anthropic, abra-o no claude.ai e exporte ali. Se ele só existe na janela do Desktop, copie e cole ou espere pelo Export data oficial. Guia: exportar chat do Claude Desktop.

O painel do Claude Code no VS Code está mais perto da linha de comando do que do claude.ai. Não espere que o nosso script de conteúdo atue nessa webview. Use o /export na sessão que realmente contém as mensagens.

Extensão independente do Chrome, sem vínculo com a Anthropic, PBC. Claude é uma marca registrada da Anthropic. Siga os Termos de Serviço dela. Não podemos dar orientação jurídica sobre copiar saídas de ferramentas que incluem código proprietário; isso é entre você, o seu empregador e a Anthropic.

Perguntas frequentes: exportar conversa do Claude Code

Como exportar uma conversa do Claude Code?

No terminal do Claude Code, digite /export (com um nome de arquivo, se quiser) para salvar uma transcrição renderizada, ou copie o arquivo JSONL de ~/.claude/projects no macOS/Linux ou de %USERPROFILE%\.claude\projects no Windows. A documentação de sessões da Anthropic descreve a janela atual.

Esta extensão do Chrome baixa chats do Claude Code?

Não a partir do terminal. O Download Claude conversations só funciona no claude.ai pelo Chrome. Ele não lê sessões locais do terminal, transcrições JSONL nem o comando /export. As sessões do Claude Code on the web em claude.ai/code são exportadas, como qualquer chat.

Posso exportar o Claude Code on the web (claude.ai/code)?

Sim. Abra a sessão em claude.ai/code no Chrome e use o botão laranja. PDF, Markdown, texto simples, JSON, XML, CSV e PNG funcionam. Os seis formatos que não são PDF são ilimitados, sem conta; o PDF precisa de login com Google e conta para as 3 grátis por dia.

Onde o Claude Code guarda o histórico de conversas?

As transcrições das sessões são arquivos JSONL em ~/.claude/projects/<encoded-working-directory>/, com o ID da sessão como nome. A estrutura exata pode mudar. Use o /export quando quiser um arquivo legível em vez de processar JSONL. CLAUDE_CONFIG_DIR pode mover a árvore.

Como baixar uma conversa do Claude Code em Markdown?

O /export do Claude Code gera uma transcrição em texto simples, não o Markdown desta extensão. Se você precisa especificamente de Markdown, exporte uma sessão de claude.ai/code ou uma cópia do trabalho no claude.ai com o Download Claude conversations, ou converta você mesmo o texto do /export. Não convertemos JSONL para Markdown.

E como baixar uma conversa do claude.ai?

Instale a extensão grátis do Chrome, abra o chat no claude.ai e use o botão laranja — ou o "Export All" para o histórico. Veja como baixar conversa do Claude. Markdown, texto, JSON, XML, CSV e PNG são ilimitados, sem conta; PDF e ZIP em lote são 3 por dia grátis com login no Google; o Pro custa US$ 3,99 por mês ou US$ 26,99 por ano.

O /export é o mesmo que o Export data oficial?

Não. O /export cobre a sessão atual do Claude Code. Settings → Privacy → Export data envia por e-mail um ZIP em JSON da conta da Anthropic. Interfaces diferentes, arquivos diferentes, esperas diferentes.

Posso processar o JSONL do Claude Code com jq?

Pode, com a ressalva que a Anthropic publica: o esquema das linhas é interno e pode mudar. Prefira o /export ou claude -p --output-format json quando precisar de um formato garantido. Fixe a versão da linha de comando se mesmo assim processar o JSONL.

Exportar do Claude Code funciona no Windows?

Sim. O /export é um comando da linha de comando. As transcrições no disco ficam em %USERPROFILE%\.claude\projects, a menos que você defina CLAUDE_CONFIG_DIR. Esta extensão do Chrome continua não rodando dentro desse terminal.

O Claude Code é o mesmo que o Claude Desktop?

Não. O Claude Code é o agente de programação no terminal. O Claude Desktop é o aplicativo de chat. O claude.ai é o site. Só o site, incluindo claude.ai/code, recebe esta extensão. Notas sobre exportar do Desktop: Claude Desktop.

Esta extensão vai algum dia envolver o /export?

Não na versão 1.16.2. O escopo do produto é o claude.ai, incluindo o Claude Code on the web: sete formatos, arquivos locais, login com Google só para PDF, lote e Pro. Se esse escopo mudar, esta página vai dizer. Até lá, use a linha de comando da Anthropic para exportar do Claude Code no terminal.

O /export inclui as saídas das ferramentas?

A Anthropic descreve o /export como mensagens e saídas de ferramentas renderizadas como texto legível. É a transcrição deles, não o nosso parser. Para saber o conteúdo exato atual, rode o /export na sua versão e leia o arquivo — a documentação pode ficar atrás de uma nova versão.

Posso exportar sessões do Claude Code em lote?

Não as sessões locais da linha de comando. O "Export All" no Dashboard é só para o claude.ai. Para muitas sessões da linha de comando, copie a pasta de projetos ou rode /export em cada sessão. Não existe exportação em lote pelo botão laranja para JSONL.
