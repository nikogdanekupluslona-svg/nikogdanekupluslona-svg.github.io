Como exportar conversa do Claude em um arquivo estruturado

O claude.ai não tem um controle para exportar uma única conversa. Como exportar conversa do Claude em um arquivo: use o Download Claude conversations para PDF, Markdown, JSON, texto, XML, CSV ou PNG; Settings → Privacy → Export data (os rótulos podem aparecer traduzidos se o claude.ai estiver em português) para um ZIP da conta, entregue com atraso; ou a impressão para um PDF aproximado da página web.

Como exportar conversa do Claude com a extensão?

Para exportar uma conversa do Claude em um arquivo legível, use o botão laranja no claude.ai. Instale o Download Claude conversations, abra a conversa, escolha PDF, Markdown, JSON, texto, XML, CSV ou PNG e clique em "Export" (Exportar). O arquivo é gerado no seu navegador e salvo localmente. Nenhuma conta é necessária, exceto para PDF e exportação em lote.

A extensão é um script de conteúdo na página que você já carregou. Ela não abre uma segunda sessão na Anthropic e não envia a conversa a lugar nenhum para gerar o arquivo. É por isso que o botão só aparece no endereço de uma conversa, depois que ela já existe no DOM.

  1. Instale a extensão pela Chrome Web Store.
  2. Abra a conversa no claude.ai. Recarregue a aba se ela estava aberta durante a instalação.
  3. Clique no botão redondo laranja de download, ao lado da caixa de mensagem.
  4. Defina Messages como "All", "Human" ou "Assistant" (todas, humano ou assistente) e escolha PDF, Markdown, JSON, texto simples, XML, CSV ou PNG.
  5. Marque "Thinking" (raciocínio) para incluir o raciocínio estendido. Use "Select" (Selecionar) para marcar mensagens específicas se precisar só de parte da conversa. Clique em "Export" — ou em "Copy" (Copiar) para colocar Markdown, texto, JSON, XML ou CSV na área de transferência.

Para mais de uma conversa, abra "View and Download All Conversations" (ver e baixar todas as conversas) no pop-up. Busque, filtre por "New", "Updated" ou "Previously exported" (novas, atualizadas, já exportadas), busque projetos, escolha um "Chat format" e use o "Export All" (Exportar tudo) para gerar um ZIP com um arquivo por chat. O lote pede login com Google; no plano grátis, cada chat nesse ZIP usa uma das 3 por dia, divididas com o PDF. Passo a passo: exportação em lote com Export All.

Chats de Team e Enterprise são exportados do mesmo jeito, desde que você consiga abri-los no Chrome. A extensão não verifica o nome do plano da Anthropic. Se a empresa bloqueia extensões, é uma política de TI, não uma opção Pro que falta do nosso lado.

Nossa cota ou o uso da Anthropic. Exportar com esta extensão não gasta créditos de mensagens do Claude. Ela só lê a página. O limite de 3 por dia para PDF e lote é a nossa cota; o Pro, por US$ 3,99 por mês ou US$ 26,99 por ano, cobrado à parte pela Paddle, remove esse limite.

Passos para uma conversa, para quem pesquisou “baixar” em vez de “exportar”: como baixar conversa do Claude. Mesmo produto, mesmo botão laranja, outra palavra na busca — vale também para quem digita em inglês, como “claude export chat”.

Como exportar conversas do Claude pelo ZIP oficial?

Para exportar conversas do Claude no nível da conta, use Settings → Privacy → Export data. A Anthropic envia por e-mail um link que expira. O ZIP é JSON da conta inteira, não um arquivo bonito de uma conversa. Use-o como backup.

O ZIP oficial é a ferramenta certa quando você está saindo de um espaço de trabalho, arquivando tudo ou atendendo a um pedido do tipo “quero todos os meus dados”. É a ferramenta errada quando você tem uma revisão de design aberta e precisa de um arquivo no próximo minuto.

Nesse fluxo não há filtro para o ID de uma única conversa. Você espera, baixa o arquivo, descompacta e procura a conversa. O formato do JSON é o da conta. Não é o JSON por chat que esta extensão grava a partir da página aberta.

Se você precisa dos dois, rode o Export data uma vez para o backup e use o Download Claude conversations sempre que precisar de um arquivo de trabalho. Uma tarefa não substitui a outra. O ZIP não vira Markdown. O botão laranja não vai mandar por e-mail todas as conversas esquecidas de 2024.

O Export data oficial também não é impressão em PDF. A impressão captura a página web. O ZIP é um conjunto de dados estruturados da conta. Comparação entre a impressão e o PDF gerado pela extensão: baixar chat do Claude em PDF.

Como exportar uma conversa do Claude em Markdown ou JSON?

Para exportar uma conversa do Claude em Markdown ou JSON, escolha esse formato na lista antes de clicar em "Export". O Markdown serve para notas e git. O JSON é a árvore de mensagens para scripts. O texto simples remove a marcação. O CSV coloca uma mensagem por linha. O PNG é uma imagem; o PDF é o documento paginado.

O Markdown mantém títulos, blocos de código com a linguagem e tabelas. O layout dos artefatos pode ser "Original", "Inline", "Nested" ou "Flat" (original, embutido, aninhado ou plano). Os blocos de raciocínio são opcionais. Esse arquivo é o que a maioria das pessoas chama de exportação legível. Visão geral: formatos.

O JSON da extensão é por conversa (ou por seleção em lote). Não é o ZIP da conta da Anthropic com outro nome. Se você está escrevendo um parser, use este JSON para uma conversa e o ZIP oficial só quando realmente precisar de todas as conversas que a Anthropic guardou.

PNG não é PDF. Se um cliente exige PDF, escolha PDF na lista de formatos. Ele é gerado no navegador, com tamanho da página, margens, números de página e sumário, e pede login com Google. Guia: baixar chat do Claude em PDF.

A lista lembra o último formato. Exportar JSON sem querer depois de uma sessão de scripts é a reclamação de “arquivo errado” mais comum. Olhe a lista antes de clicar, principalmente antes de um PDF, que usa uma das 3 por dia do plano grátis.

Dá para exportar uma conversa do Claude sem pagar?

Sim. Você pode exportar uma conversa do Claude sem pagar em Markdown, texto, JSON, XML, CSV ou PNG, quantas vezes quiser, sem conta. PDF e "Export All" em lote são grátis até 3 por dia com login no Google. O Pro, por US$ 3,99 por mês ou US$ 26,99 por ano, deixa esses dois ilimitados.

O "Export All" em lote e o PDF dividem essas 3 por dia. Cada conversa em um ZIP em lote usa uma. Selecione vinte em uma conta grátis e o lote inteiro é bloqueado, não cortado: escolha menos, espere o reinício à meia-noite UTC ou faça o upgrade. Planeje a seleção.

A impressão e o Export data da Anthropic não usam a nossa cota. Mas também não entregam o Markdown de uma conversa. Fazer tudo de graça, sem extensão, ainda custa tempo e limpeza.

O login com Google é só para PDF e lote. O primeiro PDF ou "Export All" pede que o Google confirme um e-mail. Cancelar parece uma exportação quebrada. Conclua o login e clique em "Export" de novo. O plano grátis não pede cartão de crédito, e Markdown, texto, JSON, XML, CSV e PNG nunca pedem login.

A restauração do Pro acompanha esse e-mail do Google se você trocar de computador ou reinstalar. Ela não depende da senha da Anthropic. Entre com a mesma conta Google que você usou para pagar.

Mantemos o ZIP oficial e a nossa exportação como duas tarefas diferentes, de propósito. JSON da conta por e-mail é o backup da Anthropic. Markdown e JSON por conversa são o que geramos no navegador a partir da conversa que você tem aberta. Misturar os dois em um só botão deixaria ambos piores.

Exportar conversa do Claude ou copiar e colar?

Copiar e colar só exporta uma conversa do Claude no sentido mais fraco: você selecionou um texto e o moveu. O código perde a indentação. As tabelas se desmontam. Uma conversa longa fica sem separação entre mensagens. Para ter um arquivo estruturado, as opções continuam sendo a extensão, a impressão ou o ZIP oficial.

Um meio-termo é selecionar tudo, colar no Google Docs ou no Word e corrigir a formatação à mão. Isso serve para uma entrega pontual a um cliente, não para um arquivo semanal. Cada nova mensagem significa outra limpeza. A extensão existe para que essa limpeza não comece de uma colagem.

Copiar e colar também perde o raciocínio recolhido e os artefatos que não foram expandidos. A impressão tem a mesma lacuna: o que está recolhido na interface não aparece no PDF. As opções da extensão podem incluir raciocínio e artefatos quando eles estão nos dados da página carregada, o que é outra camada, diferente de “quais pixels estão visíveis”.

Se você só precisa de um parágrafo para o Slack, copiar e colar é honesto e mais rápido. Se precisa da revisão inteira com os blocos de código, exporte em Markdown — grátis, ilimitado, sem conta — ou use o botão "Copy" do painel para colocar esse Markdown na área de transferência.

Como exportar o Claude Code e os chats do claude.ai?

Para exportar um chat do Claude no claude.ai, use esta extensão do Chrome, e isso inclui as sessões do Claude Code on the web em claude.ai/code. Para exportar uma conversa local do Claude Code no terminal, use /export no terminal ou os arquivos JSONL em ~/.claude/projects. O Claude Desktop é uma terceira janela e não recebe o botão laranja.

O /export do Claude Code grava uma transcrição em texto simples (na área de transferência ou em arquivo). A Anthropic documenta que o JSONL no disco é um formato interno que pode mudar. Prefira o /export ou as interfaces de script oficiais para tudo o que você for guardar. Passos: exportar conversa do Claude Code.

Claude Desktop: abra o mesmo chat no claude.ai, se ele foi sincronizado, e exporte ali. Caso contrário, copie e cole a partir do Desktop ou use Settings → Privacy → Export data para o JSON da conta. Guia: exportar chat do Claude Desktop.

Quem busca “exportar conversa claude code” neste site chega a uma página que separa os dois casos, não a um recurso da extensão. A extensão funciona só no claude.ai: o Claude Code on the web está coberto, o terminal não. Esse limite faz parte do produto, não é uma opção que falta.

O que a exportação de um chat do Claude mantém e descarta?

A exportação de um chat do Claude com esta extensão mantém a árvore de mensagens que a página carregou: remetentes, texto, blocos de código, tabelas e — se ativados — raciocínio, metadados e artefatos. Ela descarta tudo o que ainda não foi renderizado e a interface em volta, como a caixa de mensagem.

A impressão mantém os pixels. Na maioria das vezes, perde um layout de código limpo. O ZIP oficial mantém o que a Anthropic colocou no arquivo da conta. Ele não traz um documento legível por conversa. Copiar e colar mantém os caracteres selecionados e perde a estrutura.

Filtro de remetente: todas as mensagens, só as humanas ou só as do assistente. Útil quando você quer os prompts sem as respostas, ou o contrário. A opção de metadados adiciona títulos, datas e horários e modelo quando você precisa de uma linha de referência no arquivo.

Os arquivos ficam no disco. Nosso servidor vê o estado da cota e da assinatura só depois que você entra para PDF, lote ou Pro, e o Google vê o consentimento OAuth que você aprovou nesse momento. O claude.ai já tinha a conversa. Essa é a lista completa de participantes. Não somos a Anthropic. Claude é uma marca registrada da Anthropic, PBC.

Se a exportação parece curta, carregue mais da conversa e exporte de novo. Em Markdown, texto, JSON, XML, CSV ou PNG, essa segunda tentativa é grátis; um segundo PDF usa outra das 3 por dia. Confirme que a resposta terminou de carregar e que as mensagens mais antigas estão na tela antes de clicar.

Perguntas frequentes: como exportar conversa do Claude

Como exportar uma única conversa do Claude?

Use o Download Claude conversations na conversa aberta no claude.ai. O fluxo oficial de Export data vale para a conta inteira e é mais lento do que você precisa para uma conversa. A impressão gera um PDF visual, não Markdown.

Como exportar um chat do Claude em PDF?

Escolha PDF na lista de formatos da extensão e clique em "Export". O PDF é gerado no navegador, sem caixa de impressão; ele pede login com Google e é grátis até 3 por dia, ilimitado no Pro. A impressão (Ctrl/Cmd+P → Salvar como PDF) ainda serve para uma cópia aproximada da página web. Guia: baixar chat do Claude em PDF.

A exportação oficial inclui artefatos e raciocínio?

O ZIP inclui o que a Anthropic guardou no JSON da conta. Ele não vem formatado como Markdown por conversa, com um layout de artefatos escolhido. A exportação da extensão foi feita para manter esses elementos legíveis quando as opções estão ativadas e a página já os carregou.

Uma extensão do Chrome coloca minha conta da Anthropic em risco?

A extensão usa a sua sessão logada do claude.ai do mesmo jeito que o site. Ela não automatiza ações na conta nem acessa a Anthropic com credenciais próprias. Não somos a Anthropic. Você continua sujeito aos Termos de Serviço dela.

Tem como exportar conversa do Claude de graça?

Sim. As exportações em Markdown, JSON, texto, XML, CSV e PNG são grátis e ilimitadas, sem conta. PDF e lote são grátis até 3 por dia; o Pro custa US$ 3,99 por mês ou US$ 26,99 por ano. A impressão e o Export data oficial não usam esta cota.

Posso exportar um chat do Claude de espaços de trabalho Team?

Sim, desde que você consiga abrir a conversa no claude.ai pelo Chrome. A extensão trabalha a partir da página, não de um plano só para consumidores. As listas de extensões permitidas pela empresa continuam valendo.

Exportar consome os limites da conta da Anthropic?

Não. O Download Claude conversations lê a página que você já carregou. Ele não envia pedidos extras de geração ao Claude e não conta para os limites de mensagens ou de uso da Anthropic.

A primeira exportação em lote é grátis?

Sim, até 3 conversas por dia no plano grátis, divididas com o PDF, depois do login com Google. Cada chat no ZIP conta como uma. Uma seleção maior é bloqueada por inteiro, não cortada; o Pro remove o limite.

Como exportar uma conversa do Claude Code?

As sessões do Claude Code on the web em claude.ai/code são exportadas pelo botão laranja como qualquer chat. No terminal, rode /export ou copie o JSONL de ~/.claude/projects; esta extensão do Chrome não lê sessões locais. Passos completos: exportar conversa do Claude Code.

É preciso login com Google para exportar um chat do Claude?

Só para PDF, "Export All" em lote e Pro. As exportações em Markdown, texto, JSON, XML, CSV e PNG não precisam de conta. O login controla o limite de 3 por dia para PDF e lote e restaura o Pro. O conteúdo dos chats não é enviado como parte do login. Guardamos o e-mail verificado para o status da cota e da assinatura.

Em quais formatos posso exportar um chat do Claude?

PDF, Markdown, JSON, texto simples, XML, CSV e PNG. O PNG é uma imagem; o PDF é um documento paginado. Veja formatos para saber quando escolher cada um.

O Claude Conversation Downloader é a mesma extensão?

Sim. Download Claude conversations, Claude Chat Downloader e Claude Conversation Downloader são a mesma extensão do Chrome: botão laranja no claude.ai, sete formatos, exportações grátis ilimitadas em seis deles, PDF e lote 3 por dia grátis, Pro por US$ 3,99 por mês ou US$ 26,99 por ano.
