Como salvar uma conversa do Claude como arquivo que fica com você

Como salvar uma conversa do Claude? O claude.ai já guarda no histórico todo chat feito com login, mas não tem um botão “Salvar” que gere um arquivo. Para ter a conversa em PDF, Markdown, JSON, texto, XML, CSV ou PNG, use a Download Claude conversations no Chrome, imprima a página ou peça o Settings → Privacy → Export data (os nomes dos menus podem aparecer em português se o claude.ai estiver configurado nesse idioma). Fechar a aba não apaga a conversa.

O Claude já salva a conversa no histórico?

Sim. O claude.ai já guarda a conversa feita com login no histórico da conta da Anthropic. Fechar a aba não apaga a conversa. Mesmo assim, não existe um controle “Salvar” que grave um arquivo no disco. Salvar a conversa em Markdown ou JSON é uma tarefa separada do histórico.

O histórico é a lista de chats à esquerda no claude.ai. Cada linha é uma conversa que a Anthropic guardou para aquele login. Abra a linha depois e os mesmos turnos voltam. Isso é armazenamento na conta, não uma pasta de downloads no seu notebook.

Quem pesquisa “como salvar conversa no Claude” muitas vezes quer saber: “isso vai sumir quando eu sair?”. Numa sessão normal, com login, a resposta é não. O claude.ai não exige um clique em “Salvar” para manter a conversa na conta. O que falta é um exportador de arquivos, não um botão para manter a conversa viva.

O histórico não é um arquivo Markdown, não é uma árvore JSON que você pesquisa com grep e não é um PNG para colocar num slide. O histórico fica atrás do login da Anthropic. Se você não consegue entrar, não consegue abrir esses chats. Um arquivo local continua abrindo mesmo sem a senha.

Dois tipos de “salvar”. Histórico = a Anthropic mantém o chat na conta. Arquivo = você grava PDF, Markdown, JSON, texto, XML, CSV ou PNG no disco. O claude.ai tem o primeiro. O claude.ai não tem botão para o segundo.

Projects e Recents (projetos e recentes) no claude.ai continuam sendo histórico. Colocar um chat num projeto não cria um arquivo. Renomear a conversa não cria um arquivo. Marcar com estrela ou fixar, se a interface oferecer, também não grava Markdown. A Download Claude conversations exporta chats de dentro de um projeto como qualquer outro, e na página de um projeto “Project files” → “Download ZIP” (arquivos do projeto → baixar ZIP) salva os arquivos do projeto.

Workspaces Team e Enterprise seguem a mesma divisão. Se você consegue abrir a conversa no claude.ai, a Anthropic já guardou essa conversa para o workspace. Regras de retenção da empresa ainda podem apagar ou esconder chats num prazo que você não controla. Um arquivo que você exportou passa a ser a cópia que fica com você.

A janela anônima e um segundo perfil do Chrome não compartilham o histórico. A conversa está ligada à conta da Anthropic usada naquela sessão. Entrar com outro login da Anthropic mostra outra lista de histórico. “Salvar” entre contas diferentes é um arquivo, não uma fusão de históricos.

Como salvar uma conversa do Claude como arquivo?

Escolha um método que grave no disco: a Download Claude conversations no Chrome, Imprimir → Salvar como PDF, ou Settings → Privacy → Export data. O histórico do claude.ai é armazenamento na conta, não um arquivo PDF, Markdown, JSON, texto, XML, CSV ou PNG.

A extensão do Chrome é o caminho por conversa. Abra o endereço da conversa, clique no botão laranja ao lado da caixa de mensagem, escolha um formato e clique em “Export” (Exportar). A API de downloads do Chrome grava o arquivo localmente. Markdown, texto, JSON, XML, CSV e PNG não exigem conta; só o PDF pede login com o Google. O conteúdo dos chats fica na máquina.

A impressão é o caminho visual. Ctrl+P ou Cmd+P, destino “Salvar como PDF”. O resultado se parece com a página do claude.ai, inclusive com elementos da interface que os estilos de impressão não esconderam. Blocos de código costumam se partir entre folhas. Use a impressão quando alguém quer um retrato da tela, não um arquivo de notas. Para um PDF gerado a partir das mensagens, e não da tela, escolha PDF na extensão.

O Export data oficial é o caminho da conta. Settings → Privacy → Export data no claude.ai. A Anthropic envia por e-mail um link que expira. O ZIP é JSON da conta inteira, não um arquivo com o nome do chat que está na tela. A espera é o preço de um backup completo.

O histórico já resolveu a primeira. A impressão e o Export data continuam válidos; esses métodos resolvem outras tarefas.

Um arquivo é a escolha certa antes de sair da empresa, antes de formatar o notebook, antes de montar um arquivo de pesquisa ou antes de colocar uma revisão de código no git. O histórico basta quando você só precisa reabrir a mesma conversa amanhã, com o mesmo login da Anthropic.

Copiar e colar é um quinto método e gera um arquivo fraco. Selecione o texto no claude.ai e cole no Docs. Os blocos de código se desfazem. As tabelas viram linhas corridas. A divisão entre mensagens desaparece. Serve para um parágrafo. É ruim como único registro de uma revisão de design de 40 turnos. O botão “Copy” (Copiar) da extensão, por outro lado, coloca Markdown limpo na área de transferência.

Como salvar um chat do Claude com a extensão do Chrome?

Com a Download Claude conversations: instale a extensão do Chrome, abra a conversa no claude.ai, clique no botão laranja ao lado da caixa de mensagem, escolha PDF, Markdown, JSON, texto, XML, CSV ou PNG e clique em “Export”. Não é preciso conta, exceto para o PDF.

  1. Instale a Download Claude conversations pela Chrome Web Store (navegadores Chromium que carregam extensões do Chrome também funcionam).
  2. Recarregue o claude.ai se a página já estava aberta durante a instalação. O Chrome nem sempre injeta o content script em abas antigas.
  3. Abra uma conversa de verdade a partir do histórico — o botão laranja aparece numa conversa, não na tela inicial vazia.
  4. Clique no botão redondo e laranja de download, à direita da caixa de mensagem. Abre-se um painel com Messages (All / Human / Assistant — todas, só as suas, só as do Claude), Format (formato), “Thinking” (raciocínio), “Select” (Selecionar), “Copy” e “Export”.
  5. Escolha PDF, Markdown, texto simples, JSON, XML, CSV ou PNG. Clique em “Export”. O Chrome baixa o arquivo na hora.

A extensão é um content script do Chrome que roda só no claude.ai. O parser lê a conversa que já está carregada na sessão logada. A Download Claude conversations não chama uma API separada da Anthropic com credenciais próprias e não envia a conversa aos nossos servidores para gerar o arquivo.

Não é preciso conta para Markdown, texto simples, JSON, XML, CSV ou PNG. Essas exportações de um chat são ilimitadas e grátis: sem login, sem contador. O login com o Google só aparece quando você escolhe PDF ou roda um “Export All” (Exportar tudo) em lote. O login com o Google não é um login para ler chats. O conteúdo das conversas fica na sua máquina.

PDF e ZIP em lote dividem uma cota grátis de 3 por dia, que zera à meia-noite UTC. Cada conversa dentro de um ZIP em lote conta como uma. O Pro custa US$ 3,99 por mês ou US$ 26,99 por ano e remove esse limite. A Paddle processa o pagamento do Pro. Não vemos números de cartão. Passos do PDF: salvar uma conversa do Claude em PDF.

Arquivos locais. Todos os formatos, inclusive o PDF, são gerados no navegador e entregues à API de downloads do Chrome. O texto da conversa nunca é enviado. Só as exportações em PDF e em lote mandam uma verificação de cota com o seu e-mail do Google. Versão 1.16.2, setembro de 2026.

O mesmo painel filtra por remetente — All, Human ou Assistant. A caixa “Thinking” inclui ou deixa de fora o raciocínio estendido. “Select” permite marcar mensagens específicas, para que o arquivo tenha só aqueles turnos. “Copy” coloca Markdown, texto, JSON, XML ou CSV na área de transferência em vez de baixar um arquivo. Etapas de ferramentas / MCP e fontes da busca na web são opções que você liga nas configurações. Metadados e o layout dos artefatos — “Original”, “Inline”, “Nested” ou “Flat” (original, no texto, aninhado ou em pasta separada) — são definidos no Dashboard.

Se a conversa for muito longa, role a página até o claude.ai carregar as mensagens mais antigas. A extensão só consegue exportar o que a página já renderizou. Uma conversa carregada pela metade gera um arquivo pela metade. Parece bug, mas quase sempre é só um DOM que não foi rolado.

Espere o assistente terminar de responder antes de clicar em “Export”. Um arquivo salvo no meio da resposta corta a última mensagem. Uma segunda tentativa em Markdown ou JSON não custa nada. Um segundo PDF usa mais uma das 3 vagas diárias do plano grátis — um motivo para confirmar antes que a conversa está completa.

O último formato usado fica memorizado. Se você queria Markdown e recebeu JSON, o menu ainda estava em JSON desde a exportação anterior. Confira o menu sempre que mudar de tarefa. Capturas de tela passo a passo do mesmo botão laranja estão em como baixar uma conversa do Claude.

Como salvar uma conversa no Claude sem extensão?

Sem extensão, imprima a página do claude.ai ou peça o ZIP do Export data da Anthropic. A impressão é um PDF visual da página. O Export data é um arquivo JSON da conta inteira, que chega depois. Nenhum dos dois gera um arquivo Markdown por conversa.

Pela impressão: abra a conversa no claude.ai, esconda a barra lateral se a interface permitir, pressione Ctrl+P (Windows/Linux) ou Cmd+P (Mac), escolha “Salvar como PDF” como destino e salve. A caixa de mensagem e outros elementos da interface podem se repetir em todas as folhas. Notas completas sobre impressão em conversa do Claude em PDF.

Pelo caminho oficial: Settings → Privacy → Export data no claude.ai. A Anthropic envia por e-mail um link que expira. Descompacte o ZIP você mesmo se precisar de uma conversa entre milhares. Esse arquivo é o backup formal, não um arquivo de notas para a reunião de amanhã.

Copiar e colar continua disponível, sem instalar nada. Selecione os turnos no claude.ai e cole num app de notas. O recuo do código costuma se perder. Uma conversa com vários turnos vira um bloco sem estrutura. Use copiar e colar para um trecho, não como único plano para guardar a conversa.

A conversa continua salva no histórico depois de fechar?

Sim. O histórico continua guardando a conversa depois que você fecha a aba, atualiza o claude.ai ou desliga o notebook — desde que o chat tenha sido criado com login. Fechar a aba não é apagar. Excluir do histórico é a ação que remove a conversa da interface da conta.

Saia da conta no claude.ai e a página fica em branco. Entre de novo na mesma conta da Anthropic e o histórico traz esses chats de volta. Sair esconde a lista; sair, por si só, não apaga o que a conta guarda. Outro login da Anthropic mostra outro histórico.

Excluir do histórico é o caso em que as coisas de fato somem. Remova uma conversa na interface do claude.ai e ela sai da barra lateral. Um arquivo Markdown que você já exportou com o botão laranja continua no disco. Exporte antes se o chat estiver prestes a ser limpo.

Excluir não é fechar. Fechar uma aba do claude.ai mantém o histórico intacto. Excluir a conversa do histórico remove o chat da interface da conta. O Export data oficial não vai ajudar depois de uma exclusão se a Anthropic não incluir mais essa conversa. Grave o arquivo antes de fazer a limpeza.

A janela anônima termina quando é fechada. Se você usou o claude.ai numa janela privada sem um login duradouro, não conte com o histórico para guardar o trabalho. Entre num perfil normal do Chrome ou exporte um arquivo antes que a sessão anônima acabe.

Administradores de workspaces Team e Enterprise podem reter ou restringir chats. Uma política que você não definiu pode esconder uma conversa mais tarde. Trate o histórico da empresa como um armazenamento emprestado. Trate um arquivo Markdown ou JSON exportado como a cópia que fica do seu lado da política.

Passar do celular para o notebook não exige nenhum clique especial para salvar a conversa quando os dois aparelhos usam a mesma conta da Anthropic. Abra o histórico no notebook. Se o chat não estiver lá, você está em outro login, em outro workspace, ou a conversa foi excluída — não “deixou de ser salva”.

O Claude Desktop pode mostrar os chats da mesma conta quando o app está logado no mesmo usuário da Anthropic. A sincronização é trabalho da Anthropic. A extensão do Chrome nunca é injetada no Desktop. Se a conversa existe no claude.ai, abra o claude.ai no Chrome para gravar um arquivo.

Como salvar a conversa em Markdown ou JSON?

Abra o botão laranja no claude.ai, escolha o formato e clique em “Export”. Markdown é o arquivo de notas. JSON é a árvore de mensagens para scripts. Texto simples não tem marcação. CSV é uma linha por mensagem. PDF é um documento paginado. PNG é uma imagem.

O Markdown mantém títulos, blocos de código cercados com a tag de linguagem e tabelas. O Markdown é a escolha comum para Obsidian, GitHub ou uma wiki. Notas de layout desse formato: exportação em Markdown. O JSON preserva a árvore que o parser já montou, incluindo artefatos e raciocínio quando essas opções estão ligadas.

O JSON da Download Claude conversations não tem o mesmo formato do ZIP da conta da Anthropic. O JSON da extensão é uma conversa, do jeito que a página a renderizou. O JSON do Export data é um despejo da conta que a Anthropic envia depois por e-mail. Não misture os dois esquemas num script sem conferir as chaves.

Texto simples é a escolha certa quando o destino remove a marcação — um campo de chamado, o corpo de um e-mail, um índice de busca que quer texto puro. XML é a opção de nicho para troca de dados. CSV abre no Excel, no Google Sheets ou no Numbers. PNG serve para um slide ou para ilustrar um relatório de bug com a conversa, não para uma revisão de 40 turnos que você vai pesquisar com grep.

Como salvar o histórico de chats do Claude em lote?

Para salvar o histórico de chats do Claude em vários arquivos, não repita o botão laranja aba por aba. Abra “View and Download All Conversations” (ver e baixar todas as conversas) no pop-up da extensão, filtre a tabela e clique em “Export All”. O “Export All” pede login com o Google. No plano grátis, cada chat do ZIP usa uma das 3 vagas diárias, divididas com o PDF. O Pro remove o limite.

O Dashboard lista as conversas da conta do claude.ai em que você está logado — o mesmo histórico que você já tem, transformado numa tabela que dá para filtrar. Busque pelo nome. Filtre por All conversations, New, Updated ou Previously exported (todas, novas, atualizadas, já exportadas). Alterne entre as abas Chat e Cowork e busque por projeto, se você organiza os chats assim no claude.ai.

O lote gera um ZIP com um arquivo por chat, no formato escolhido no seletor “Chat format” — qualquer um dos sete, inclusive PDF. Usa o mesmo parser da exportação de um chat. Caixas de seleção definem o que entra — “Chats”, “Thinking”, “Metadata”, “Tools”, “Sources” (conversas, raciocínio, metadados, ferramentas, fontes) — além do layout dos artefatos. O “Export All” não é um processo inferior. O “Export All” é o mesmo parser aplicado a vários IDs de conversa de uma vez. Detalhes: exportar todas as conversas com o Export All.

O Export data da Anthropic continua sendo o backup da conta. Um ZIP, um e-mail, JSON para tudo, inclusive chats que você nem lembrava. O “Export All” é a tarefa oposta: você escolhe quais linhas do histórico, escolhe o formato, e o ZIP chega na hora. Use os dois se quiser um arquivo completo para fins formais e uma pasta de notas legíveis.

A cota é compartilhada e diária. No plano grátis, exportações em PDF e chats em lote dividem 3 por dia, que zeram à meia-noite UTC. Selecione 40 conversas e o lote inteiro é bloqueado, não cortado. Escolha menos ou passe para o Pro por US$ 3,99 por mês ou US$ 26,99 por ano, pela Paddle.

O Dashboard lembra o que você já exportou, então numa próxima visita dá para filtrar só New ou Updated. É assim que o hábito de salvar os chats toda semana fica incremental, em vez de duplicar o Markdown do mês passado. A contagem de 3 por dia acompanha a conta Google, não a instalação, e zera à meia-noite UTC.

Selecione só uma parte quando o histórico estiver cheio de rascunhos de uma linha. “Export All” não significa que você precisa levar todas as linhas. Um filtro bem feito com Markdown gera uma pasta de pesquisa mais limpa do que 200 conversas vazias de “oi”.

Exportar um chat do Claude, dito com o verbo do produto, é o mesmo botão laranja e a mesma tabela do “Export All”. A página vizinha exportar chat do Claude explica esses controles, caso você tenha chegado buscando “exportar” em vez de “salvar”.

Dá para salvar a conversa no Desktop ou no Claude Code?

No Desktop, não. No Claude Code, só na web. A Download Claude conversations não salva conversas do Claude Desktop nem de um terminal local do Claude Code. As sessões em claude.ai/code abrem no Chrome para computador, então são salvas como qualquer chat. O Claude Desktop é um app separado. O Claude Code local é o agente de terminal, com /export e JSONL no disco.

Se o chat do Desktop também existe no claude.ai, abra esse endereço no Chrome e use o botão laranja. Se a conversa só existe no Desktop, copie e cole ou espere o Settings → Privacy → Export data. A extensão nunca é injetada na janela do Desktop.

Dentro de uma sessão ativa do Claude Code, digite /export. A CLI da Anthropic abre um menu para copiar a transcrição ou salvar um arquivo de texto simples. Passe um nome de arquivo para pular o menu. Essa transcrição é texto renderizado para uma pessoa ler, não o Markdown, JSON ou PDF desta extensão. Caminhos completos: exportar conversas do Claude Code.

O JSONL no disco é o log interno, em ~/.claude/projects (Windows: %USERPROFILE%\.claude\projects). O esquema pode mudar entre versões do Claude Code. A própria documentação da Anthropic recomenda preferir o /export em vez de analisar o JSONL. Não embrulhamos essa CLI. Não lemos ~/.claude.

O worker da Cloudflare que verifica a cota e o status do Pro recebe o seu e-mail do Google, não o texto das mensagens. As outras exportações de um chat não enviam nada. Cobrança no servidor, conversa no disco — essa fronteira é a história da privacidade de cada arquivo que este produto grava.

Perguntas frequentes: como salvar uma conversa do Claude

Como salvo uma conversa do Claude como arquivo?

Instale a Download Claude conversations, abra a conversa no claude.ai, clique no botão laranja à direita da caixa de mensagem, escolha PDF, Markdown, JSON, texto, XML, CSV ou PNG e clique em “Export”. O arquivo é baixado localmente, sem conta, exceto para o PDF. O histórico já guardou o chat na conta da Anthropic; o botão laranja grava uma cópia no disco.

Como salvar um chat do Claude no claude.ai?

Você não precisa de um botão “Salvar” para manter a conversa na conta. O histórico do claude.ai já lista os chats feitos com login. Para salvar o chat como arquivo, use a extensão do Chrome, Imprimir → Salvar como PDF, ou Settings → Privacy → Export data para um ZIP em JSON da conta, que chega depois.

Como salvar uma conversa no Claude sem extensão?

Imprima a página do claude.ai (Ctrl/Cmd+P → Salvar como PDF) para uma cópia visual, ou use Settings → Privacy → Export data para um ZIP em JSON da conta inteira, enviado por e-mail. Copiar e colar funciona para uma resposta curta. Nenhum desses métodos gera um arquivo Markdown estruturado por conversa como a extensão do Chrome.

O Claude já salva a conversa no histórico?

Sim. Os chats feitos com login no claude.ai ficam no histórico da conta da Anthropic. Fechar a aba, atualizar a página ou abrir outro aparelho com o mesmo login não apaga a conversa. O histórico não é um PDF, Markdown, JSON nem qualquer outro arquivo no seu disco.

Uma conversa do Claude some se eu fechar a aba?

Não. Fechar uma aba do claude.ai não exclui a conversa do histórico. Excluir o chat do histórico, sim, o remove da interface da conta. Um arquivo que você já exportou com a Download Claude conversations continua no disco mesmo depois dessa exclusão.

Posso salvar uma conversa do Claude em PDF?

Sim. A Download Claude conversations 1.16.2 exporta PDF diretamente: escolha PDF no painel do botão laranja e clique em “Export”. O arquivo é gerado no navegador, sem janela de impressão. O PDF exige login com o Google e é grátis até 3 por dia; no Pro é ilimitado. Guia: conversa do Claude em PDF.

Quantos arquivos grátis posso salvar?

Ilimitados em Markdown, texto simples, JSON, XML, CSV e PNG, sem conta. PDF e ZIP em lote dividem 3 por dia no plano grátis, com login no Google; cada chat num ZIP em lote conta como um, e o dia zera à meia-noite UTC. O Pro custa US$ 3,99 por mês ou US$ 26,99 por ano e remove o limite. A Paddle processa o pagamento.

Dá para salvar a conversa pelo celular?

Com a extensão do Chrome, não. Ela roda no Chrome para computador (ou outro navegador Chromium que instale itens da Chrome Web Store). Não há app para iOS ou Android. Navegadores de celular ainda conseguem abrir o histórico e imprimir uma conversa do Claude; não conseguem mostrar o botão laranja.

Posso salvar chats do histórico do Claude em lote?

Sim. Abra “View and Download All Conversations” no pop-up da extensão, filtre a tabela e clique em “Export All”. O lote exige login com o Google e conta para o limite de 3 por dia no plano grátis. Esse caminho em lote não é o ZIP do Export data da Anthropic. O Export data oficial é um único arquivo da conta inteira, enviado por e-mail depois. Veja download em lote.

A extensão salva conversas do Claude Code?

Só na web. As sessões do Claude Code em claude.ai/code são salvas como qualquer chat do claude.ai. As sessões locais do terminal não: use /export ou copie o JSONL de ~/.claude/projects (Windows: %USERPROFILE%\.claude\projects). Esta extensão do Chrome só roda no claude.ai. Guia: exportar conversas do Claude Code.

O login com o Google é obrigatório para salvar um chat do Claude?

Não para Markdown, texto simples, JSON, XML, CSV ou PNG. O login com o Google só é exigido para PDF, “Export All” em lote e Pro, para que possamos aplicar o limite de 3 por dia e restaurar o Pro depois de uma reinstalação. O conteúdo das conversas não é enviado com esse login. Guardamos o e-mail verificado apenas para a cota e o status do Pro.

Onde fica o Export data oficial para salvar chats do Claude?

No claude.ai: Settings → Privacy → Export data. A Anthropic envia por e-mail um link que expira. O ZIP é um arquivo JSON da conta, não um arquivo Markdown com o nome do chat que você estava lendo. Use o Export data como backup; use o botão laranja para um arquivo legível agora.
