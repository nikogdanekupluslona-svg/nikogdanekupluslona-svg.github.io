Como baixar uma conversa do Claude no Chrome?

No claude.ai, o caminho é o botão laranja que a Download Claude conversations coloca ao lado da caixa de mensagem. Abra a conversa, escolha PDF, Markdown, JSON, texto, XML, CSV ou PNG e clique em “Export”. O Chrome salva um arquivo local. Esse arquivo é uma conversa, não um ZIP da conta.

A Download Claude conversations é um content script do Chrome. Ela lê a conversa que já está carregada na sua sessão logada do claude.ai. Não chama uma API separada da Anthropic com credenciais próprias e não envia a conversa aos nossos servidores para gerar nenhum formato, inclusive o PDF.

  1. Instale a Download Claude conversations pela Chrome Web Store (navegadores Chromium que carregam extensões do Chrome também funcionam).
  2. Recarregue o claude.ai se a página já estava aberta durante a instalação. O Chrome não injeta a extensão numa aba antiga.
  3. Abra o endereço da conversa que você quer — o botão laranja só aparece numa conversa de verdade, não na tela inicial vazia.
  4. Clique no botão redondo e laranja de download, à direita da caixa de mensagem. Abre-se um painel com Messages (All / Human / Assistant — todas, só as suas, só as do Claude), Format (formato), “Thinking” (raciocínio), “Select” (Selecionar), “Copy” (Copiar) e “Export”.
  5. Escolha PDF, Markdown, texto simples, JSON, XML, CSV ou PNG. Clique em “Export”. O Chrome baixa um arquivo na hora.

Não é preciso conta para Markdown, texto simples, JSON, XML, CSV ou PNG. Essas exportações de uma conversa são ilimitadas e grátis: sem login, sem contador. O login com o Google só aparece quando você escolhe PDF ou roda um “Export All” (Exportar tudo) em lote. Não é um login para ler seus chats do claude.ai. O conteúdo das conversas fica na sua máquina.

Baixar a conversa ou usar o Export data oficial?

Baixar a conversa pelo botão laranja gera um arquivo com nome da conversa aberta no claude.ai, na hora, localmente, inclusive em PDF. O Settings → Privacy → Export data da Anthropic (os nomes dos menus podem aparecer em português se o claude.ai estiver configurado nesse idioma) é um ZIP em JSON da conta, enviado depois por e-mail. A impressão é um PDF visual da página. Copiar e colar dá texto sem estrutura. Escolha a linha que corresponde à tarefa.

O Export data oficial é um backup da conta inteira da Anthropic, não o download de uma conversa. A Anthropic envia por e-mail um link que expira. O ZIP mistura chats que você esqueceu com chats que queria guardar. Depois, você mesmo descompacta o JSON se precisar de uma conversa entre milhares. Esse não é o caminho do botão laranja.

Pela impressão: abra a conversa no claude.ai, esconda a barra lateral se a interface permitir, pressione Ctrl+P (Windows/Linux) ou Cmd+P (Mac), escolha “Salvar como PDF” como destino e salve. Blocos de código costumam se partir entre páginas. A caixa de mensagem e outros elementos da interface podem aparecer em todas as folhas. A impressão é um retrato da tela, não Markdown. A exportação em PDF da própria extensão dispensa essa janela: conversa do Claude em PDF.

Copiar e colar é o terceiro método sem extensão. Selecione o texto no claude.ai e cole no Docs ou num app de notas. O recuo do código costuma se perder. As tabelas viram linhas corridas. Uma conversa com vários turnos vira um bloco sem estrutura. Serve para uma resposta curta. É ruim para uma revisão de código que você vai pesquisar depois.

Em qual formato baixar a conversa?

Abra o botão laranja, escolha PDF, Markdown, JSON, texto, XML, CSV ou PNG e clique em “Export”. Markdown é o arquivo de notas. JSON é a árvore de mensagens para scripts. Texto simples não tem marcação. XML serve para troca de dados. CSV é uma linha por mensagem. PDF é um documento paginado. PNG é uma imagem.

O Markdown mantém títulos, blocos de código cercados com a tag de linguagem e tabelas. É a escolha comum para Obsidian, GitHub ou uma wiki. O JSON preserva a árvore que o parser já montou, incluindo artefatos e raciocínio quando essas opções estão ligadas. Não tem o mesmo formato do ZIP da conta da Anthropic. Notas sobre formatos: todos os formatos.

Texto simples é a escolha certa quando o destino remove a marcação de qualquer jeito — um campo de chamado, o corpo de um e-mail, um índice de busca que quer texto puro. XML é a opção de nicho para troca de dados. CSV abre no Excel, no Google Sheets ou no Numbers. PNG serve para um slide ou para a captura de uma conversa num relatório de bug, não para uma revisão de design de 40 turnos que você vai pesquisar com grep.

Dá para baixar várias conversas do Claude de uma vez?

Sim. Para baixar o histórico de conversas do Claude em vários arquivos, não repita o botão laranja aba por aba. Abra “View and Download All Conversations” (ver e baixar todas as conversas) no pop-up da extensão, filtre a tabela e clique em “Export All”. O “Export All” pede login com o Google. No plano grátis, cada conversa do ZIP usa uma das 3 vagas diárias, divididas com o PDF. O Pro remove o limite.

O Dashboard lista as conversas da conta do claude.ai em que você está logado. Busque pelo nome. Filtre por All conversations, New, Updated ou Previously exported (todas, novas, atualizadas, já exportadas). Alterne entre as abas Chat e Cowork e busque por projeto, se você organiza as conversas assim no claude.ai. Selecione só uma parte quando não quiser todos os rascunhos antigos na pasta.

O lote gera um ZIP com um arquivo por conversa, no formato escolhido no seletor “Chat format” — qualquer um dos sete, inclusive PDF. Usa o mesmo parser da exportação de uma conversa. Caixas de seleção definem o que entra — “Chats”, “Thinking”, “Metadata”, “Tools”, “Sources” (conversas, raciocínio, metadados, ferramentas, fontes) — além do layout dos artefatos. Por que o botão de baixar a conversa sumiu?

O botão de download some quando você não está no endereço de uma conversa, a aba não foi recarregada depois da instalação ou a extensão está desativada. Fixe o ícone, recarregue e confirme que você está no Chrome para computador, no claude.ai — não no Desktop, no celular ou num terminal do Claude Code.

Depois da instalação, o Chrome nem sempre injeta o content script em abas que já estavam abertas. Feche a aba do claude.ai ou force o recarregamento. Se você usa vários perfis, a Download Claude conversations precisa estar instalada no perfil que está logado na Anthropic.

Workspaces Team e Enterprise funcionam se você consegue abrir a conversa no navegador. A extensão lê a página, não o tipo de plano. Se a organização bloqueia extensões do Chrome, a TI precisa liberar esta; não conseguimos contornar essa política pelo chat-downloader.com.

Pedido de login: esperado só para PDF e “Export All”. Markdown, texto, JSON, XML, CSV e PNG exportam sem conta. A primeira exportação em PDF ou em lote pede o Google. Cancelar esse pedido parece um download que falhou. Conclua o login e clique em “Export” de novo. Não é preciso cartão de crédito no plano grátis. A Paddle só aparece se você comprar o Pro.

Arquivo incompleto: a resposta ainda não tinha terminado de ser gerada, ou turnos antigos ainda estavam virtualizados fora da tela. Espere o assistente terminar. Role até o início de uma conversa longa para o claude.ai carregar essas partes e exporte de novo. Repetir uma exportação em Markdown ou JSON não custa nada. Repetir um PDF usa mais uma das 3 vagas diárias do plano grátis — confirme antes que a conversa carregou por completo.

Tipo de arquivo errado: o último formato usado ainda estava selecionado. Conta errada: você entrou no Google com um endereço diferente daquele que tem o Pro. A restauração do Pro está ligada a esse e-mail do Google, não ao login da Anthropic nem ao nome do perfil do Chrome.

Navegadores de celular não rodam esta extensão. Não há app para iOS ou Android. O Safari no celular consegue imprimir o claude.ai; não consegue mostrar o botão laranja. Para um arquivo reutilizável, abra a mesma conversa no Chrome para computador e baixe por lá.

A tela inicial vazia não tem botão. A página inicial do claude.ai, com a caixa de mensagem vazia, não é o endereço de uma conversa. Comece ou abra uma conversa primeiro. O botão laranja fica à direita da caixa de mensagem dessa conversa, depois de recarregar a página após a instalação.

O Claude Desktop permite baixar a conversa?

Não. No Claude Desktop, esta extensão não baixa a conversa. A Download Claude conversations só é injetada no claude.ai, no Chrome. Um terminal local do Claude Code é outro ambiente; o Claude Code na web, em claude.ai/code, é exportado normalmente. Abra a mesma conversa no claude.ai, se ela existir lá, e use o botão laranja.

O Claude Desktop é uma janela separada. O content script do Chrome nunca é injetado nesse app. Se a mesma conversa existe no claude.ai, abra lá e baixe. Se ela só existe no Desktop, copie e cole ou espere o ZIP da conta em Settings → Privacy → Export data.

O Claude Code local fica no terminal. Dentro de uma sessão ativa, digite /export. A CLI da Anthropic abre um menu para copiar a transcrição ou salvar um arquivo de texto simples. Passe um nome de arquivo para pular o menu. Essa transcrição é texto renderizado para uma pessoa ler, não o Markdown, JSON ou PDF desta extensão. Caminhos: exportar conversas do Claude Code.

A própria documentação da Anthropic recomenda preferir o /export ou as interfaces de script em vez de analisar o JSONL. Não embrulhamos essa CLI. Não lemos ~/.claude. Caminho no Windows: %USERPROFILE%\.claude\projects.

O Claude Code na web é a exceção. As sessões em claude.ai/code abrem no Chrome, então a Download Claude conversations as exporta como qualquer conversa. Se você mantém uma conversa paralela no claude.ai para o mesmo trabalho, baixe essa conversa do navegador com o botão laranja. O log do terminal e o chat da web não são automaticamente o mesmo documento. Trate-os como dois registros, a menos que você tenha colado um no outro.

“Baixar conversa do Claude” é o nome da extensão na loja?

O título na loja é Download Claude conversations, no plural, porque o “Export All” gera vários arquivos. Buscas como “baixar conversa claude”, “baixar claude chat” ou, em inglês, “download claude conversation” levam todas a essa mesma extensão. Uma exportação pelo botão laranja continua sendo uma conversa, um arquivo.

Dá para baixar uma conversa do Claude sem extensão?

Sim. Imprima a página do claude.ai (Ctrl/Cmd+P → Salvar como PDF) para um retrato visual, ou use Settings → Privacy → Export data para um ZIP em JSON da conta, que chega depois. Copiar e colar funciona para uma resposta curta. Nenhum desses métodos gera um arquivo Markdown estruturado por conversa como a extensão do Chrome.

Um arquivo equivale a uma conversa baixada?

Sim. O botão laranja gera um arquivo da conversa aberta no claude.ai. O “Export All” gera um ZIP com um arquivo por linha selecionada. O ZIP do Export data da Anthropic tem o formato oposto: um único arquivo da conta inteira, enviado depois por e-mail, e não um arquivo com o nome da conversa que você estava lendo.

Posso baixar uma conversa do Claude em PDF?

Sim. Escolha PDF no painel do botão laranja e clique em “Export”. A versão 1.16.2 gera o PDF no navegador, sem janela de impressão; você define tamanho da página, margens, modo claro ou escuro, fonte, números de página e sumário. O PDF exige login com o Google e é grátis até 3 por dia; no Pro é ilimitado. Guia: conversa do Claude em PDF.

O login com o Google é obrigatório para baixar uma conversa?

Só para PDF e “Export All” em lote. Markdown, texto simples, JSON, XML, CSV e PNG não exigem conta. Para PDF e lote, o Google confirma qual conta você escolheu, para que possamos aplicar o limite de 3 por dia e restaurar o Pro depois de uma reinstalação. O conteúdo das conversas não é enviado com esse login. Guardamos o e-mail verificado apenas para a cota e o status do Pro.

Dá para baixar a conversa no Claude Desktop?

Não. A Download Claude conversations só é injetada no claude.ai, no Chrome para computador. O Claude Desktop nunca mostra o botão laranja. Abra a mesma conversa no claude.ai, se ela estiver sincronizada, ou copie e cole / use o Export data oficial. Não há app para iOS ou Android.

Quantos arquivos grátis posso baixar?

Ilimitados em Markdown, texto simples, JSON, XML, CSV e PNG, sem conta. PDF e ZIP em lote dividem 3 por dia no plano grátis, com login no Google; cada conversa num ZIP em lote conta como uma, e o dia zera à meia-noite UTC. O Pro custa US$ 3,99 por mês ou US$ 26,99 por ano e remove o limite. A Paddle processa o pagamento.

A extensão baixa conversas do Claude Code?

Só na web. As sessões do Claude Code em claude.ai/code exportam como qualquer conversa do claude.ai. As sessões locais do terminal não: use /export ou copie o JSONL de ~/.claude/projects (Windows: %USERPROFILE%\.claude\projects). Esta extensão do Chrome só roda no claude.ai. Guia: exportar conversas do Claude Code.

Em quais formatos posso baixar a conversa?

Sete: PDF, Markdown, JSON, texto simples, XML, CSV e PNG, na extensão 1.16.2. O PDF é gerado no navegador, sem janela de impressão. O CSV tem uma linha por mensagem. O PNG é uma imagem da conversa. Central de formatos: formatos.
