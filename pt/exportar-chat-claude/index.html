Como exportar chat do Claude no claude.ai?

Abra a conversa no claude.ai pelo Chrome, clique no botão laranja ao lado da caixa de mensagem, escolha PDF, Markdown, JSON, texto simples, XML, CSV ou PNG e clique em "Export" (Exportar). O Download Claude conversations grava esse arquivo localmente. Em setembro de 2026, o próprio claude.ai não tem nenhum controle nativo para exportar uma conversa.

  1. Instale o Download Claude conversations pela Chrome Web Store.
  2. Recarregue o claude.ai e abra o endereço de uma conversa real, não a tela inicial vazia.
  3. Clique no botão redondo laranja de download, à direita da caixa de mensagem.
  4. No painel, defina Messages como "All", "Human" ou "Assistant" (todas, humano ou assistente) e escolha um formato. Marque "Thinking" (raciocínio) para incluir o raciocínio estendido, ou use "Select" (Selecionar) para marcar mensagens específicas. A extensão lembra o último formato usado.
  5. Clique em "Export". O Chrome salva o arquivo na hora pela API de downloads do navegador. "Copy" (Copiar) coloca Markdown, texto, JSON, XML ou CSV na área de transferência em vez disso.

Nenhuma conta é necessária para exportar chat do Claude em Markdown, texto, JSON, XML, CSV ou PNG. Essas exportações de uma conversa são ilimitadas, e a extensão não envia nada aos nossos servidores. O login com Google só aparece quando você escolhe PDF ou roda o "Export All" em lote: o plano grátis permite 3 dessas operações por dia, somadas, com reinício à meia-noite UTC. O texto das conversas nunca faz parte desse login. Detalhes: como funciona.

Se o botão laranja não aparece, você não está no endereço de uma conversa, a aba precisa ser recarregada depois da instalação ou o ícone da extensão ainda está escondido no menu de quebra-cabeça do Chrome. Fixe o Download Claude conversations e atualize o claude.ai. A extensão só atua no claude.ai, nunca em outros sites.

Uma conversa ou a conta inteira. O botão laranja exporta o chat aberto. Para muitos arquivos, abra o pop-up da extensão → "View and Download All Conversations" (ver e baixar todas as conversas) e rode o "Export All" (Exportar tudo) — veja exportação em lote com Export All. O caminho da Anthropic, Settings → Privacy → Export data (os rótulos podem aparecer traduzidos se o claude.ai estiver em português), gera um ZIP da conta com atraso; não é este fluxo.

O que uma extensão de exportação do Claude faz de verdade?

Uma extensão de exportação do Claude lê a conversa já exibida na sua aba logada do claude.ai e grava um arquivo estruturado no disco. O Download Claude conversations é esse script de conteúdo do Chrome: remetente, árvore de mensagens, blocos de código, tabelas, raciocínio opcional e layout dos artefatos — não uma captura de tela da interface em volta do chat. Funciona em chats comuns, Projects, sessões do Cowork e no Claude Code on the web.

Copiar e colar do claude.ai perde a indentação e desmonta as tabelas. Imprimir (Ctrl/Cmd+P) mantém a barra lateral e muitas vezes quebra um bloco de código longo entre páginas. A extensão mantém a linguagem nos blocos de código e deixa as tabelas como tabelas em Markdown, JSON e XML. O PNG é a opção de imagem. O PDF é a opção paginada, gerada no navegador sem caixa de impressão.

O layout dos artefatos é uma opção real na versão 1.16.2: "Original", "Inline", "Nested" ou "Flat" (original, embutido, aninhado ou plano), definido no Dashboard. O raciocínio estendido é uma caixa de seleção no painel de exportação; as fontes de pesquisa na web e as etapas de ferramentas / MCP são opcionais nas configurações. Os metadados (título, datas e horários, modelo) podem ir junto. O filtro Messages limita o arquivo a todas as mensagens, só as humanas ou só as do assistente, e o "Select" marca mensagens específicas. Lista completa: recursos.

Criamos o botão laranja para gravar um arquivo de verdade a partir do chat que já está no claude.ai — PDF, Markdown, JSON, texto, XML, CSV ou PNG — sem enviar a conversa aos nossos servidores. A versão 1.16.2 também gera o PDF no navegador.

O Download Claude conversations não exporta para Notion, Word ou Google Docs na versão 1.16.2.

Dá para exportar chats do Claude em lote com o "Export All"?

Sim. Abra o pop-up da extensão → "View and Download All Conversations", filtre a tabela e clique em "Export All" para gerar um ZIP. A exportação em lote pede login com Google. No plano grátis, ela divide as 3 por dia com o PDF, e cada conversa no ZIP usa uma. O Pro remove o limite para todo o histórico.

O Dashboard lista o histórico do claude.ai com busca por nome, filtros ("All conversations", "New", "Updated", "Previously exported" — todas, novas, atualizadas, já exportadas), abas "Chat" e "Cowork" e busca por projeto. "New" indica conversas ainda não exportadas com o Download Claude conversations. "Previously exported" marca as que você já salvou, para que um segundo "Export All" possa pulá-las. A busca por projeto segue a forma como você agrupa os chats no claude.ai.

O lote tem o seletor "Chat format" com os sete formatos, PDF incluído, as caixas "Chats", "Thinking", "Metadata", "Tools" e "Sources" (chats, raciocínio, metadados, ferramentas e fontes) e o layout dos artefatos ("Original", "Inline", "Nested", "Flat"). O "Export All" não é um arquivo pela metade. É um ZIP com um arquivo por chat no formato escolhido. Se você queria um único arquivo da conta inteira, entregue com atraso, isso é o Export data da Anthropic, comparado na próxima seção e na página de exportação em lote.

O lote conta por conversa. No plano grátis, o "Export All" e o PDF dividem 3 por dia, e cada conversa no ZIP usa uma. Selecione 40 conversas com 3 restantes e o lote inteiro é bloqueado, não cortado. Escolha menos, espere o reinício à meia-noite UTC ou use o Pro por US$ 3,99 por mês ou US$ 26,99 por ano.

Exportar chat do Claude funciona no Desktop ou no Code?

Não no aplicativo Desktop nem no terminal do Claude Code. Esta extensão roda apenas no claude.ai dentro do Chrome (ou de outro navegador Chromium que instale pela Chrome Web Store). O Claude Desktop é um aplicativo separado para Mac/Windows, e o botão laranja nunca aparece nele nem em um terminal. O Claude Code on the web (claude.ai/code) é a exceção: essas sessões abrem no claude.ai e são exportadas como qualquer chat.

Se a conversa também existe na sua conta do claude.ai, abra-a no Chrome e exporte o chat do Claude ali com o Download Claude conversations. Se o chat existe só no Desktop, copie e cole a partir do aplicativo ou peça o Settings → Privacy → Export data na versão web. Comparação passo a passo: exportar chat do Claude Desktop.

O Claude Code no terminal usa /export ou transcrições JSONL no disco. Esta extensão do Chrome não lê essas sessões locais. Não instale o Download Claude conversations esperando uma integração com o terminal. Guia: exportar conversa do Claude Code. Procurar como exportar chat do Claude para uma sessão de linha de comando leva a outro caminho.

O claude.ai no navegador do celular também fica de fora. A extensão precisa do Chrome no computador. Esta equipe não tem aplicativo para iOS ou Android em 2026. Abra a conversa em um computador e exporte pelo botão laranja ou pelo "Export All".

Exportar chat do Claude ou usar o Export data da Anthropic?

O Export data da Anthropic envia por e-mail, depois de uma espera, um ZIP em JSON com a conta inteira. Exportar chat do Claude com o Download Claude conversations salva na hora a conversa aberta em PDF, Markdown, JSON, texto, XML, CSV ou PNG. Use o ZIP para backup; use a extensão para ter um arquivo legível agora.

Perguntas frequentes: como exportar chat do Claude

Estas perguntas cobrem como exportar chat do Claude com a extensão: formatos, limites, Desktop, Claude Code, o ZIP da Anthropic e onde fica o botão laranja. Cada resposta é um fato da versão 1.16.2. O JSON-LD FAQPage no cabeçalho da página corresponde a esta lista.

O que significa exportar chat do Claude neste site?

Salvar uma conversa do claude.ai em um arquivo com o Download Claude conversations: botão laranja, escolha do formato, "Export". É o que muita gente busca em inglês como “claude export chat”. Não é o ZIP da Anthropic enviado por e-mail nem o /export do Claude Code.

Uma extensão de exportação do Claude é o mesmo que o Export data?

Não. Settings → Privacy → Export data gera um ZIP em JSON da conta inteira, enviado por e-mail. A extensão grava na hora, no Chrome, o chat aberto em PDF, Markdown, JSON, texto, XML, CSV ou PNG, ou uma seleção do "Export All" em ZIP.

Posso exportar chat do Claude em PDF?

Sim. Escolha PDF na lista de formatos e clique em "Export". A extensão gera o PDF no navegador, sem caixa de impressão. O PDF pede login com Google e é grátis até 3 por dia; o Pro deixa ilimitado. Guia: baixar chat do Claude em PDF.

Preciso do Pro para exportar um chat do Claude uma vez?

Não. As exportações em Markdown, texto, JSON, XML, CSV e PNG são grátis e ilimitadas, sem conta. PDF e "Export All" em lote são grátis até 3 por dia com login no Google. O Pro, por US$ 3,99 por mês ou US$ 26,99 por ano, remove esse limite.

Exportar chat do Claude funciona em qualquer plano do claude.ai?

Sim. Os planos Free, Pro, Team e Enterprise do claude.ai funcionam, desde que você consiga abrir a conversa no Chrome. A extensão não exige o plano pago da Anthropic.

Esta extensão de exportação serve para o Claude Code?

Só para o Claude Code on the web. As sessões em claude.ai/code abrem no claude.ai e são exportadas como qualquer chat. O Claude Code no terminal usa /export ou JSONL no disco, e o Download Claude conversations não lê esses arquivos. Veja o guia de exportação do Claude Code.

Posso exportar chat do Claude a partir do Claude Desktop?

Não com esta extensão do Chrome. Abra a mesma conversa no claude.ai, se ela estiver sincronizada, ou copie e cole / use o Export data oficial. O Desktop nunca mostra o botão laranja.

Quantas exportações grátis a extensão oferece?

Ilimitadas em Markdown, texto, JSON, XML, CSV e PNG, sem conta. PDF e "Export All" em lote dividem 3 por dia no plano grátis, com login no Google; cada chat em um ZIP em lote conta como uma. A contagem reinicia à meia-noite UTC. O Pro remove o limite e é restaurado com o login no Google.

Onde fica o botão laranja para exportar chat do Claude?

À direita da caixa de mensagem, no endereço de uma conversa do claude.ai, depois que você instala o Download Claude conversations e recarrega a página. Ele não aparece na tela inicial vazia nem no Desktop.

Exportar chat do Claude envia minhas conversas para algum servidor?

Não. Todos os formatos, PDF incluído, são gerados no navegador e entregues à API de downloads do Chrome. As exportações em Markdown, texto, JSON, XML, CSV e PNG não nos enviam nada. Depois que você entra com o Google para PDF, lote ou Pro, nosso servidor vê o status da cota ou da assinatura e o seu e-mail do Google, nunca o conteúdo dos chats. Detalhes em Como funciona.

Em quais formatos a extensão exporta?

Sete: PDF, Markdown, texto simples, JSON, XML, CSV e PNG — os mesmos sete para um chat e para o "Export All". Não há exportação para Word, Notion ou Google Docs na versão 1.16.2.
