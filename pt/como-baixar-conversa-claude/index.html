Como baixar uma conversa do Claude pelo Chrome?

A resposta direta é o botão laranja que a Download Claude conversations coloca ao lado da caixa de mensagem no claude.ai. Abra a conversa, escolha PDF, Markdown, JSON, texto, XML, CSV ou PNG e clique em “Export” (Exportar). O arquivo é montado no seu navegador e salvo no disco.

A extensão é um content script do Chrome. Ela lê a conversa que já está carregada na sua sessão logada do claude.ai. Não chama uma API separada da Anthropic com credenciais próprias e não envia a conversa aos nossos servidores para gerar o arquivo.

  1. Instale a Download Claude conversations pela Chrome Web Store (navegadores Chromium que carregam extensões do Chrome também funcionam).
  2. Recarregue o claude.ai se a página já estava aberta durante a instalação.
  3. Abra o endereço da conversa que você quer — o botão laranja só aparece numa conversa de verdade, não na tela inicial vazia.
  4. Clique no botão redondo e laranja de download, à direita da caixa de mensagem. Abre-se um painel com Messages (All / Human / Assistant — todas, só as suas, só as do Claude), Format (formato), “Thinking” (raciocínio), “Select” (Selecionar), “Copy” (Copiar) e “Export”.
  5. Escolha PDF, Markdown, texto simples, JSON, XML, CSV ou PNG. Clique em “Export”. O Chrome baixa o arquivo na hora.

Não é preciso conta para Markdown, texto simples, JSON, XML, CSV ou PNG. Essas exportações de um chat são ilimitadas e grátis: sem login, sem contador. O login com o Google só aparece quando você escolhe PDF ou roda um “Export All” (Exportar tudo) em lote. Não é um login para ler suas conversas. O conteúdo das conversas fica na sua máquina.

PDF e ZIP em lote dividem uma cota grátis de 3 por dia, que zera à meia-noite UTC. Cada conversa dentro de um ZIP em lote conta como uma. O Pro custa US$ 3,99 por mês ou US$ 26,99 por ano e remove esse limite. Opções e passos do PDF: salvar uma conversa do Claude em PDF.

Arquivos locais. Todos os formatos, inclusive o PDF, são gerados no navegador e entregues à API de downloads do Chrome. O texto da conversa nunca é enviado. Só as exportações em PDF e em lote mandam uma verificação de cota com o seu e-mail do Google.

O mesmo painel filtra por remetente — All, Human ou Assistant. A caixa “Thinking” inclui ou deixa de fora o raciocínio estendido. “Select” permite marcar mensagens específicas, para que o arquivo tenha só aqueles turnos. “Copy” coloca Markdown, texto, JSON, XML ou CSV na área de transferência em vez de baixar um arquivo. Etapas de ferramentas / MCP e fontes da busca na web são opções que você liga nas configurações. Metadados e o layout dos artefatos — “Original”, “Inline”, “Nested” ou “Flat” (original, no texto, aninhado ou em pasta separada) — são definidos no Dashboard.

Se a conversa for muito longa, role a página até o claude.ai carregar as mensagens mais antigas. A extensão só consegue exportar o que a página já renderizou. Uma conversa carregada pela metade gera um arquivo pela metade — parece bug, mas quase sempre é só um DOM que não foi rolado.

Lemos a árvore de mensagens na página do claude.ai que você já abriu. Os blocos de código mantêm a tag de linguagem e o recuo; as tabelas continuam tabelas. O PDF é gerado a partir dessa mesma árvore, dentro do navegador, sem janela de impressão — então um arquivo para imprimir já não significa uma captura de tela da página.

Dá para baixar uma conversa do Claude sem extensão?

Sim. Sem extensão, você pode imprimir a página ou pedir a exportação da conta da Anthropic. A impressão é um PDF visual da página. O Export data é um ZIP em JSON da conta inteira, que chega depois. Nenhum dos dois gera um arquivo Markdown por conversa.

Pela impressão: abra a conversa no claude.ai, esconda a barra lateral se a interface permitir, pressione Ctrl+P (Windows/Linux) ou Cmd+P (Mac), escolha “Salvar como PDF” como destino e salve. Blocos de código costumam se partir entre páginas. A caixa de mensagem e outros elementos da interface podem aparecer em todas as folhas. A exportação em PDF da própria extensão dispensa essa janela. As duas opções são comparadas em conversa do Claude em PDF.

Pelo caminho oficial: Settings → Privacy → Export data no claude.ai (os nomes dos menus podem aparecer em português se o claude.ai estiver configurado nesse idioma). A Anthropic envia por e-mail um link que expira. O ZIP é um arquivo JSON da conta, não um arquivo com o nome da conversa que você estava lendo. Use-o como backup e descompacte você mesmo se precisar de uma conversa entre milhares.

Copiar e colar é o terceiro método sem extensão. Selecione o texto e cole no Docs ou num app de notas. O recuo do código costuma se perder. As tabelas viram linhas corridas. Uma conversa com vários turnos vira um bloco sem estrutura. Serve para uma resposta curta. É ruim para uma revisão de código que você vai pesquisar depois. O botão “Copy” da extensão, por outro lado, coloca Markdown limpo na área de transferência.

A linha que corresponde à sua tarefa é o método certo. Quem procura como baixar uma conversa do Claude quase sempre quer a primeira linha: uma conversa, um arquivo que abre, sem esperar e-mail, sem conta para a maioria dos formatos. Os outros três métodos existem; só resolvem tarefas diferentes.

Como baixar o histórico de conversas do Claude em lote?

Para baixar o histórico de conversas do Claude em vários arquivos, não repita o botão laranja aba por aba. Abra “View and Download All Conversations” (ver e baixar todas as conversas) no pop-up da extensão, filtre a tabela e clique em “Export All”. O “Export All” pede login com o Google. No plano grátis, cada conversa do ZIP usa uma das 3 vagas diárias, divididas com o PDF. O Pro remove o limite.

O Dashboard lista as conversas da conta do claude.ai em que você está logado. Busque pelo nome. Filtre por All conversations, New, Updated ou Previously exported (todas, novas, atualizadas, já exportadas). Alterne entre as abas Chat e Cowork e busque por projeto, se você organiza as conversas assim no claude.ai. Selecione só uma parte quando não quiser todos os rascunhos antigos na pasta.

O lote gera um ZIP com um arquivo por conversa, no formato escolhido no seletor “Chat format” — qualquer um dos sete, inclusive PDF. Usa o mesmo parser da exportação de um chat. Caixas de seleção definem o que entra — “Chats”, “Thinking”, “Metadata”, “Tools”, “Sources” (conversas, raciocínio, metadados, ferramentas, fontes) — além do layout dos artefatos. O “Export All” não é um processo inferior. É o mesmo parser aplicado a vários IDs de conversa de uma vez. Detalhes e capturas de tela: exportar todas as conversas com o Export All.

O Export data da Anthropic continua sendo o backup da conta. Um ZIP, um e-mail, JSON para tudo, inclusive conversas que você nem lembrava. O “Export All” é a tarefa oposta: você escolhe as conversas, escolhe o formato, e o ZIP chega na hora. Use os dois se quiser um arquivo completo para fins formais e uma pasta de notas legíveis.

A cota é compartilhada e diária. No plano grátis, exportações em PDF e conversas em lote dividem 3 por dia, que zeram à meia-noite UTC. Selecione 40 conversas e o lote inteiro é bloqueado, não cortado. Escolha menos ou passe para o Pro por US$ 3,99 por mês ou US$ 26,99 por ano.

O Dashboard também lembra o que você já exportou, então numa próxima visita dá para filtrar só New ou Updated. É assim que o hábito de baixar o histórico toda semana fica incremental, em vez de duplicar o Markdown do mês passado.

Como baixar uma conversa do Claude em Markdown ou JSON?

Abra o botão laranja, escolha o formato e clique em “Export”. Markdown é o arquivo de notas. JSON é a árvore de mensagens para scripts. Texto simples não tem marcação. CSV é uma linha por mensagem. PDF é um documento paginado. PNG é uma imagem.

O Markdown mantém títulos, blocos de código cercados com a tag de linguagem e tabelas. É a escolha comum para Obsidian, GitHub ou uma wiki. O JSON preserva a árvore que o parser já montou, incluindo artefatos e raciocínio quando essas opções estão ligadas. Não tem o mesmo formato do ZIP da conta da Anthropic. Notas sobre formatos: todos os formatos.

Texto simples é a escolha certa quando o destino remove a marcação de qualquer jeito — um campo de chamado, o corpo de um e-mail, um índice de busca que quer texto puro. XML é a opção de nicho para troca de dados. CSV abre no Excel, no Google Sheets ou no Numbers. PNG serve para um slide ou para a captura de uma conversa num relatório de bug, não para uma revisão de design de 40 turnos que você vai pesquisar com grep.

O PDF exige login com o Google e é limitado a 3 por dia no plano grátis. No Pro é ilimitado. Detalhes: conversa do Claude em PDF.

O último formato usado fica memorizado. Se você queria Markdown e recebeu JSON, o menu ainda estava em JSON desde a exportação anterior. Confira o menu sempre que mudar de tarefa.

Salvar a conversa, imprimir ou pedir o ZIP: qual usar?

Salvar, baixar e exportar são a mesma tarefa no claude.ai: tirar a conversa da página. Para salvar uma conversa do Claude como arquivo útil, inclusive em PDF, use a extensão. A impressão é um retrato. O Export data da Anthropic é um ZIP da conta.

Equipes costumam misturar as palavras. Quem pesquisa diz salvar. Quem desenvolve diz exportar. Quem gerencia diz baixar. Neste site, os três verbos levam ao mesmo botão laranja quando o ambiente é o claude.ai no Chrome. O guia vizinho como exportar uma conversa do Claude explica com mais detalhe o ZIP oficial e o formato do JSON.

A impressão ainda tem seu lugar: um anexo avulso que precisa ficar idêntico à tela do claude.ai. O Export data oficial também: saída de uma empresa, retenção por motivos legais ou um backup extra por precaução. Nenhum dos dois substitui um arquivo Markdown que você vai editar na semana que vem.

O Claude Desktop é outra janela. A extensão do Chrome não é injetada no app Desktop. Se a mesma conversa existe no claude.ai, abra lá e baixe. Se ela só existe no Desktop, copie e cole ou espere o ZIP da conta. Passos: exportar um chat do Claude Desktop.

A Paddle processa os pagamentos do Pro. Não vemos números de cartão. O login com o Google, usado só para PDF, lote e Pro, não nos dá acesso à conversa. O worker da Cloudflare que verifica a cota e o status do Pro recebe o seu e-mail do Google, não o texto das mensagens. As outras exportações de um chat não enviam nada. Essa fronteira é toda a história da privacidade: cobrança no servidor, conversa no disco.

Por que o botão para baixar a conversa não aparece?

O botão de download some quando você não está no endereço de uma conversa, a aba não foi recarregada depois da instalação ou a extensão está desativada. Fixe o ícone, recarregue e confirme que você está no Chrome para computador, no claude.ai — não no Desktop, no celular ou num terminal do Claude Code.

Depois da instalação, o Chrome nem sempre injeta o content script em abas que já estavam abertas. Feche a aba do claude.ai ou force o recarregamento. Se você usa vários perfis, a extensão precisa estar instalada no perfil que está logado na Anthropic.

Workspaces Team e Enterprise funcionam se você consegue abrir a conversa no navegador. A extensão lê a página, não o tipo de plano. Se a organização bloqueia extensões do Chrome, a TI precisa liberar esta; não conseguimos contornar essa política pelo site.

Pedido de login: esperado só para PDF e “Export All”. Markdown, texto, JSON, XML, CSV e PNG exportam sem conta. A primeira exportação em PDF ou em lote pede o Google. Cancelar esse pedido parece um download que falhou. Conclua o login e clique em “Export” de novo. Não é preciso cartão de crédito no plano grátis.

Arquivo incompleto: a resposta ainda não tinha terminado de ser gerada, ou turnos antigos ainda estavam virtualizados fora da tela. Espere o assistente terminar. Role até o início de uma conversa longa para o claude.ai carregar essas partes e exporte de novo. Repetir uma exportação em Markdown ou JSON não custa nada. Repetir um PDF usa mais uma das 3 vagas diárias do plano grátis — um motivo para confirmar antes que a conversa carregou por completo.

Tipo de arquivo errado: o último formato usado ainda estava selecionado. Conta errada: você entrou no Google com um endereço diferente daquele que tem o Pro. A restauração do Pro está ligada a esse e-mail do Google, não ao login da Anthropic nem ao nome do perfil do Chrome.

Navegadores de celular não rodam esta extensão. Não há app para iOS ou Android. O Safari no celular consegue imprimir; não consegue mostrar o botão laranja. Para um arquivo reutilizável, abra a mesma conversa no Chrome para computador.

A extensão baixa conversas do Claude Code?

Só do Claude Code na web. As sessões em claude.ai/code abrem no Chrome, então a Download Claude conversations as exporta como qualquer chat. Uma sessão local do Claude Code no terminal é outra coisa. Para exportar a sessão do terminal existe o /export ou o arquivo JSONL em ~/.claude/projects. Ambientes diferentes, arquivos diferentes.

Dentro de uma sessão ativa do Claude Code, digite /export. A CLI da Anthropic abre um menu para copiar a transcrição ou salvar um arquivo de texto simples. Passe um nome de arquivo para pular o menu. Essa transcrição é texto renderizado para uma pessoa ler, não o Markdown, JSON ou PDF desta extensão. Caminhos completos: exportar conversas do Claude Code.

O JSONL no disco é o log interno. O esquema pode mudar entre versões do Claude Code. A própria documentação da Anthropic recomenda preferir o /export ou as interfaces de script em vez de analisar o JSONL. Não embrulhamos essa CLI. Não lemos ~/.claude.

Se você mantém uma conversa paralela no claude.ai para o mesmo trabalho, baixe esse chat do navegador com o botão laranja. O log do terminal e o chat da web não são automaticamente o mesmo documento. Trate-os como dois registros, a menos que você tenha colado um no outro.

Perguntas frequentes: como baixar uma conversa do Claude

Como baixo uma conversa do Claude no Chrome?

Instale a Download Claude conversations, abra a conversa no claude.ai, clique no botão laranja à direita da caixa de mensagem, escolha PDF, Markdown, JSON, texto, XML, CSV ou PNG e clique em “Export”. O arquivo é baixado localmente. Não é preciso conta, exceto para o PDF, que pede login com o Google.

Dá para baixar conversas do Claude sem extensão?

Sim. Imprima a página (Ctrl/Cmd+P → Salvar como PDF) para uma cópia visual, ou use Settings → Privacy → Export data para um ZIP em JSON da conta, que chega depois. Copiar e colar funciona para uma resposta curta. Nenhum desses métodos gera um arquivo Markdown estruturado por conversa como a extensão do Chrome.

Como baixo o histórico de conversas do Claude?

Para uma conversa, use o botão laranja. Para muitos arquivos, abra “View and Download All Conversations” no pop-up da extensão e clique em “Export All”. O lote exige login com o Google e conta para o limite de 3 por dia no plano grátis. Esse caminho em lote não é o ZIP do Export data da Anthropic. O Export data oficial é um único arquivo da conta inteira, enviado por e-mail depois. Veja download em lote.

Preciso pagar para baixar uma conversa do Claude?

Não. As exportações em Markdown, texto simples, JSON, XML, CSV e PNG são ilimitadas e grátis, sem conta. PDF e ZIP em lote são grátis até 3 por dia com login no Google; cada conversa num ZIP em lote conta como uma. O Pro custa US$ 3,99 por mês ou US$ 26,99 por ano e remove esse limite. A Paddle processa o pagamento.

A Download Claude conversations funciona no celular?

Não. É uma extensão para o Chrome de computador (ou outro navegador Chromium que instale itens da Chrome Web Store). Não há app para iOS ou Android. Navegadores de celular ainda conseguem imprimir uma conversa do Claude; não conseguem rodar esta extensão.

Isso pode fazer minha conta da Anthropic ser banida?

Não podemos dar orientação jurídica. A extensão lê a página do claude.ai que você já carregou na sua própria sessão. Não chama a Anthropic com credenciais separadas nem automatiza cliques na sua conta. Não somos a Anthropic. Siga os Termos de Serviço deles e as regras do seu empregador.

Como salvo uma conversa do Claude como arquivo?

Use a extensão do Chrome para um arquivo limpo do chat aberto, inclusive em PDF. Imprima para um retrato da página. Use o Export data da Anthropic para um ZIP da conta inteira. Salvar, baixar e exportar são a mesma tarefa no claude.ai quando você quer tirar a conversa da tela.

Funciona com sessões do Claude Code?

Só na web. As sessões do Claude Code em claude.ai/code exportam como qualquer chat do claude.ai. As sessões locais do terminal não: use /export ou copie o JSONL de ~/.claude/projects (Windows: %USERPROFILE%\.claude\projects). Esta extensão do Chrome só roda no claude.ai. Guia: exportar conversas do Claude Code.

O login com o Google é obrigatório para baixar uma conversa do Claude?

Não para Markdown, texto simples, JSON, XML, CSV ou PNG. O login com o Google só é exigido para PDF, “Export All” em lote e Pro, para que possamos aplicar o limite de 3 por dia e restaurar o Pro depois de uma reinstalação. O conteúdo das conversas não é enviado com esse login. Guardamos o e-mail verificado apenas para a cota e o status do Pro.

Em quais formatos posso baixar uma conversa do Claude?

Sete: PDF, Markdown, JSON, texto simples, XML, CSV e PNG, na extensão 1.16.2. O PDF é gerado no navegador, sem janela de impressão. O CSV tem uma linha por mensagem. O PNG é uma imagem da conversa. Central de formatos: formatos.

Posso exportar de workspaces Team ou Enterprise?

Sim, se você consegue abrir a conversa no claude.ai pelo Chrome. A extensão trabalha a partir da página renderizada, não de uma API exclusiva para contas pessoais. Se uma política da empresa bloqueia extensões, essa é uma decisão da TI, não uma opção de plano nas nossas configurações.

O Claude Chat Downloader é este mesmo produto?

Sim. Download Claude conversations é o nome na Chrome Web Store. As pessoas também buscam Claude Chat Downloader e Claude Conversation Downloader. Mesmo botão laranja, mesmos sete formatos, mesmo plano grátis.
