Como exportar um chat do Claude para Markdown?

Abra a conversa no claude.ai pelo Chrome, clique no botão laranja ao lado da caixa de mensagem, escolha Markdown e clique em “Export”. O Download Claude conversations grava um arquivo .md localmente. É assim que funciona na versão 1.16.2.

  1. Instale o Download Claude conversations pela Chrome Web Store.
  2. Recarregue o claude.ai e abra o endereço de uma conversa de verdade, não a tela inicial com a caixa de mensagem vazia.
  3. Clique no botão laranja de download, à direita da caixa de mensagem.
  4. Escolha Markdown. A extensão lembra o último formato usado. Use “Select” (Selecionar) para marcar só as mensagens que você quer.
  5. Clique em “Export”. O Chrome baixa o arquivo .md pela API de downloads do navegador. Ou clique em “Copy” (Copiar) para colocar o Markdown na área de transferência.

Não é preciso fazer login para gerar o arquivo Markdown. As exportações de um único chat em Markdown são ilimitadas, anônimas e não enviam nada aos nossos servidores. O login com Google só é pedido para PDF e para a exportação em lote com “Export All” (Exportar tudo). Detalhes técnicos: como funciona.

Se o botão laranja não aparecer, você não está no endereço de uma conversa, a aba precisa ser recarregada depois da instalação ou a extensão ainda está escondida no menu de extensões do Chrome (o ícone de peça de quebra-cabeça). Fixe o Download Claude conversations e atualize o claude.ai. O script de conteúdo nunca é injetado no Claude Desktop nem no terminal do Claude Code.

Um chat ou vários. O botão laranja exporta a conversa aberta em Markdown. Para vários arquivos .md, abra “View and Download All Conversations” (Ver e baixar todas as conversas) e execute “Export All” com Markdown selecionado: um único ZIP, 3 chats por dia no plano gratuito — veja a exportação em lote com Export All.

Por que exportar chat do Claude para Markdown e usar nas notas?

Escolha Markdown quando for ler o arquivo no Obsidian, numa wiki do GitHub ou em qualquer editor que exiba títulos e blocos de código. O .md continua sendo texto puro, que dá para pesquisar e comparar. JSON é melhor para scripts; PNG é uma imagem em que não dá para buscar texto.

Copiar e colar do claude.ai costuma perder a indentação e achatar as tabelas. Imprimir (Ctrl/Cmd+P) mantém a barra lateral e muitas vezes quebra um bloco de código longo entre páginas. Na exportação em Markdown, as tags de linguagem continuam nos blocos de código e as tabelas continuam sendo tabelas. É por isso que quem escreve escolhe este formato primeiro.

Tratamos o Markdown como o arquivo padrão para leitura humana: títulos, blocos de código com tag de linguagem e tabelas da conversa no claude.ai. Quando você precisa de páginas, escolha PDF no mesmo painel. Ele é montado no navegador, com tamanho de página, margens e sumário.

Equipe do Download Claude conversations

Muita gente também procura pelo nome Claude Chat Downloader ou digita em inglês “claude export chat” para achar a mesma extensão. A exportação em Markdown é o mesmo botão laranja, não um segundo produto. As páginas jurídicas ainda podem dizer Claude Exporter. Todos esses nomes se referem ao Download Claude conversations.

O que a exportação de um chat do Claude em Markdown mantém?

Ao gerar o .md, o Download Claude conversations mantém títulos, blocos de código com tag de linguagem e indentação, tabelas e links. Blocos de raciocínio, fontes da pesquisa na web e etapas de ferramentas / MCP são opcionais: “Thinking” (Raciocínio) é uma caixa de seleção no painel de exportação, e os outros dois são ativados nas configurações da extensão (Settings). Os metadados (título, data e hora, modelo) podem ir junto. O filtro de remetente limita o arquivo .md a todas as mensagens, só as humanas ou só as do assistente.

O layout de artefatos é uma opção real na versão 1.16.2: “Original”, “Inline” (em linha), “Nested” (aninhado) ou “Flat” (plano). Uma exportação em Markdown pode espelhar a estrutura de artefatos da tela, achatá-la num documento linear ou separar os artefatos numa pasta própria dentro de um ZIP. Nas configurações, é possível incorporar imagens no arquivo .md. Lista completa: recursos da extensão do Chrome. O Markdown não guarda as cores dos balões de mensagem; use PNG para um registro visual ou PDF para páginas.

Se a conversa for muito longa, role a página até o claude.ai carregar as mensagens mais antigas antes de exportar. A extensão só consegue gravar o que a página já exibiu. Uma conversa carregada pela metade gera um arquivo .md pela metade — parece um bug, mas quase sempre é um DOM que não foi rolado.

Dá para exportar chats do Claude para Markdown em lote?

Sim. Abra “View and Download All Conversations”, defina “Chat format” (formato do chat) como Markdown, filtre a tabela e clique em “Export All”. O Chrome salva um ZIP com um arquivo .md por chat. No plano gratuito são 3 chats por dia com login do Google, limite compartilhado com o PDF. O Pro, por US$ 3,99 por mês ou US$ 26,99 por ano, remove esse limite para Markdown em lote.

O Dashboard (painel da extensão) lista o histórico do claude.ai com busca por nome, os filtros “All conversations” (Todas as conversas), “New” (Novas), “Updated” (Atualizadas) e “Previously exported” (Já exportadas), as abas “Chat” e “Cowork” e a busca por projeto. “New” são as conversas ainda não exportadas com o Download Claude conversations. “Previously exported” marca os chats que você já salvou, para que um segundo “Export All” possa pulá-los.

O limite diário é por conta. Três chats por dia no plano gratuito, compartilhados com o PDF. Se você selecionar 40 conversas e restarem 3, o lote inteiro é bloqueado, e não cortado. Selecione menos ou use o Pro. As exportações individuais em .md pelo botão laranja continuam ilimitadas.

O Markdown em lote usa as caixas de seleção do Dashboard “Chats”, “Thinking”, “Metadata” (Metadados), “Tools” (Ferramentas) e “Sources” (Fontes), além do formato dos artefatos. O “Export All” não é o ZIP demorado da Anthropic. É um ZIP com um arquivo .md por chat. Se você queria um arquivo único com a conta inteira, o caminho é Settings → Privacy → Export data (os rótulos podem aparecer traduzidos se o claude.ai estiver em português), que gera JSON, não Markdown.

Markdown ou JSON ao exportar um chat do Claude?

Use Markdown quando uma pessoa for ler o arquivo. Use JSON quando um script for processar a árvore de mensagens. O Download Claude conversations oferece os dois na mesma lista, além de PDF, texto simples, XML, CSV e PNG. Visão geral: formatos de exportação de chats do Claude.

Markdown comparado aos outros arquivos de exportação do claude.ai
Formato Escolha quando
Markdown Notas, Obsidian, GitHub, wikis
JSON Comparações, pipelines, ferramentas — guia de JSON
Texto simples Nenhuma marcação, arquivo para colar em qualquer lugar
XML Um sistema que exige XML
CSV Planilhas, uma linha por mensagem
PDF Ler, imprimir, enviar — guia de PDF
PNG Uma imagem da conversa, sem texto pesquisável

O Export data da Anthropic também é JSON, mas é um ZIP da conta inteira enviado por e-mail, não um arquivo .md por chat. Não dá para escolher Markdown nesse pedido. A impressão do navegador é só uma cópia da página. Nenhum dos dois substitui a exportação em Markdown pelo botão laranja.

A extensão funciona só no claude.ai pelo Chrome. O Claude Desktop e o terminal do Claude Code não ganham um botão de Markdown. O Claude Code on the web (claude.ai/code) roda no claude.ai, então exporta como qualquer chat. Se a conversa também existir no claude.ai, abra-a lá e exporte para Markdown. O /export do Claude Code no terminal é outro caminho, de outro produto.

A exportação de um chat do Claude para Markdown custa algo a mais?

Não. Exportar um chat em Markdown é gratuito e ilimitado, sem conta e sem contador — igual a JSON, texto, XML, CSV e PNG. Só o PDF e o “Export All” em lote têm limite gratuito: 3 por dia com login do Google. O Pro custa US$ 3,99 por mês ou US$ 26,99 por ano, pelo Paddle. O Download Claude conversations não cobra nada a mais pelo Markdown.

O limite só aparece no Markdown em lote. Cada chat de um ZIP do “Export All” usa uma das 3 exportações do dia, e a contagem zera à meia-noite UTC. O Pro remove o limite e é restaurado num computador novo com a mesma conta Google. O Paddle é o revendedor oficial (merchant of record); nossa equipe nunca vê números de cartão.

Você não precisa do plano pago do claude.ai da Anthropic. Basta um login que consiga abrir a conversa no Chrome. Os planos Team e Enterprise funcionam igual ao Free no botão laranja. A versão 1.16.2, de setembro de 2026, ainda não gera arquivos do Word nem do Notion.

Perguntas frequentes: exportar chat do Claude para Markdown

Estas perguntas tratam da exportação em Markdown no Download Claude conversations 1.16.2: blocos de código, “Export All” em lote, o ZIP da Anthropic, custo, PDF e Claude Desktop. Cada resposta é um fato do produto. O JSON-LD FAQPage no cabeçalho da página corresponde a esta lista.

Exportar um chat do Claude para Markdown faz perder código?

Não. Os blocos de código mantêm a tag de linguagem e a indentação, ao contrário de um simples copiar e colar do claude.ai. As tabelas continuam sendo tabelas Markdown. Esse é o principal motivo para exportar em Markdown em vez de selecionar o texto à mão.

Dá para exportar chats do Claude para Markdown em lote?

Sim. O “Export All” no Dashboard aceita Markdown e salva um ZIP com arquivos .md. No plano gratuito, cobre 3 chats por dia com login do Google; o Pro é ilimitado.

O Markdown é a mesma coisa que o Export data da Anthropic?

Não. A exportação oficial da Anthropic é um ZIP em JSON da conta inteira, enviado por e-mail depois de um tempo. A exportação em Markdown é um arquivo .md por chat (ou por seleção), gerado pelo Download Claude conversations.

O Markdown custa mais que os outros formatos?

Não. As exportações de um chat em Markdown são ilimitadas e não exigem conta, assim como JSON, texto, XML, CSV e PNG. Só o PDF e o ZIP em lote têm limite gratuito de 3 por dia. O Pro custa US$ 3,99 por mês ou US$ 26,99 por ano.

Dá para exportar um chat do Claude para Markdown no Claude Desktop?

Não. O Download Claude conversations só é injetado no claude.ai pelo Chrome. O Claude Desktop nunca mostra a lista com Markdown. Abra a mesma conversa no claude.ai, se ela existir lá.

A exportação em Markdown gera um PDF?

Não. Markdown é um arquivo de texto .md. Para páginas, escolha PDF no mesmo painel: ele é montado no navegador, com tamanho de página, margens e sumário. O PDF exige login do Google e conta para o limite de 3 por dia no plano gratuito.

Preciso do Pro para exportar um chat para Markdown uma vez?

Não. Você não precisa de conta nenhuma. As exportações de um chat em Markdown são ilimitadas no plano gratuito. O Pro, por US$ 3,99 por mês ou US$ 26,99 por ano, só remove o limite de 3 por dia do “Export All” em lote e do PDF.
