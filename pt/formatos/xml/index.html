Como exportar um chat do Claude para XML?

Abra a conversa no claude.ai pelo Chrome, clique no botão laranja ao lado da caixa de mensagem, escolha XML e clique em “Export”. O Download Claude conversations grava o arquivo localmente. É assim que funciona na versão 1.16.2. Em setembro de 2026, o claude.ai não tem nenhum controle próprio para salvar em XML.

  1. Instale o Download Claude conversations pela Chrome Web Store.
  2. Recarregue o claude.ai e abra o endereço de uma conversa de verdade, não a tela inicial com a caixa de mensagem vazia.
  3. Clique no botão laranja de download, à direita da caixa de mensagem.
  4. Escolha XML. O último formato usado fica memorizado. Use “Select” (Selecionar) para marcar só as mensagens que você quer.
  5. Clique em “Export”. O Chrome baixa o XML pela API de downloads do navegador. Ou clique em “Copy” (Copiar) para colocar o XML na área de transferência.

Não é preciso fazer login para gerar o XML. As exportações de um único chat em XML são ilimitadas, anônimas e não enviam nada aos nossos servidores. O login com Google só é pedido para PDF e para a exportação em lote com “Export All” (Exportar tudo). Detalhes técnicos: como funciona.

Se o botão laranja não aparecer, você não está no endereço de uma conversa, a aba precisa ser recarregada ou a extensão está escondida no menu de extensões do Chrome (o ícone de peça de quebra-cabeça). Fixe o Download Claude conversations e atualize o claude.ai. A exportação em XML nunca aparece no Claude Desktop nem no terminal do Claude Code.

Um arquivo ou vários. O botão laranja exporta a conversa aberta em XML. Para vários arquivos XML, abra “View and Download All Conversations” (Ver e baixar todas as conversas) e execute “Export All” com XML selecionado: um único ZIP, 3 chats por dia no plano gratuito — veja a exportação em lote com Export All.

Quando exportar chat do Claude para XML?

Use XML quando o sistema de destino, o pipeline ou uma ferramenta antiga exigir XML para troca de dados estruturados. A maioria dos desenvolvedores deve escolher JSON. Markdown é para notas de leitura humana. CSV é para planilhas. PNG é uma imagem. O XML está na lista porque algumas ferramentas ainda só aceitam XML e recusam JSON.

Não use XML achando que é um JSON “mais oficial”. O Download Claude conversations faz a mesma leitura da conversa nos dois casos. A diferença está no formato do arquivo, e não em campos extras que aparecem do nada. Se nada do que você usa exige XML, pule este formato e use JSON.

Oferecemos XML porque alguns pipelines ainda exigem esse formato, não porque achamos que ele é melhor que JSON para toda exportação do claude.ai. A leitura é a mesma: mensagens, remetente, raciocínio e artefatos opcionais. A versão 1.16.2 mantém o XML como um dos sete formatos, gratuito e sem conta, não como um complemento pago.

Equipe do Download Claude conversations

Muita gente também procura pelos nomes Claude Chat Downloader e Claude Conversation Downloader, ou digita em inglês “claude export chat”, para achar a mesma extensão. A exportação em XML é esse botão laranja. As páginas jurídicas ainda podem dizer Claude Exporter. Esses nomes são este produto.

O que a exportação de um chat do Claude para XML mantém?

Ao gerar o XML, o Download Claude conversations grava a estrutura da conversa — mensagens, remetente e os metadados disponíveis — como marcação XML. Blocos de raciocínio, fontes da pesquisa na web, etapas de ferramentas / MCP e artefatos seguem as mesmas opções de Markdown e JSON: “Thinking” (Raciocínio) é uma caixa de seleção no painel de exportação, e ferramentas e fontes são ativadas nas configurações da extensão (Settings). O XML não é uma versão reduzida desses formatos.

O layout de artefatos é “Original”, “Inline” (em linha), “Nested” (aninhado) ou “Flat” (plano) na versão 1.16.2. O filtro de remetente limita o XML a todas as mensagens, só as humanas ou só as do assistente. Os metadados (título, data e hora, modelo) podem ir junto. XML ou JSON ao exportar um chat do Claude?

JSON é a escolha comum entre desenvolvedores. Use XML só quando um sistema de destino exigir. O Download Claude conversations não torna o XML “mais completo” que o JSON. Os dois podem incluir raciocínio e artefatos. Nenhum dos dois é o ZIP da conta da Anthropic. Visão geral: formatos de exportação de chats do Claude.

XML comparado aos outros arquivos de exportação do claude.ai

Na Anthropic, Settings → Privacy → Export data (os rótulos podem aparecer traduzidos se o claude.ai estiver em português) gera JSON (um ZIP), não XML. O PDF do mesmo painel são páginas para pessoas, não marcação. Nenhum dos dois substitui a exportação em XML pelo botão laranja. Não espere que este XML siga algum esquema não publicado da Anthropic.

A extensão funciona só no claude.ai pelo Chrome. O Claude Desktop e o terminal do Claude Code não ganham um botão de XML. O Claude Code on the web (claude.ai/code) roda no claude.ai, então exporta como qualquer chat. Se a conversa também existir no claude.ai, abra-a lá e exporte para XML. O /export do Claude Code no terminal é outro caminho, de outro produto.

Dá para exportar chats do Claude para XML em lote?

Sim. Abra “View and Download All Conversations”, defina “Chat format” (formato do chat) como XML, filtre a tabela e clique em “Export All”. O Chrome salva um ZIP com um arquivo XML por chat. No plano gratuito são 3 chats por dia com login do Google, limite compartilhado com o PDF. O Pro, por US$ 3,99 por mês ou US$ 26,99 por ano, remove esse limite para XML em lote.

O Dashboard (painel da extensão) lista o histórico do claude.ai com busca por nome, os filtros “All conversations” (Todas as conversas), “New” (Novas), “Updated” (Atualizadas) e “Previously exported” (Já exportadas), as abas “Chat” e “Cowork” e a busca por projeto. “New” são as conversas ainda não exportadas com o Download Claude conversations. “Previously exported” marca os chats que você já salvou. O “Export All” gera um ZIP com um XML por chat, não um arquivo com formatos misturados.

O limite diário é por conta. Três chats por dia no plano gratuito, compartilhados com o PDF. Se você selecionar 40 conversas e restarem 3, o lote inteiro é bloqueado, e não cortado. Selecione menos ou use o Pro. As exportações individuais em XML pelo botão laranja continuam ilimitadas.

Não dá para misturar XML e JSON num único clique em “Export All”. Escolha XML nessa execução. Rode o “Export All” de novo com JSON se precisar dos dois formatos da mesma conversa do claude.ai; a segunda execução conta todos os chats de novo.

Exportar um chat do Claude para XML exige o Pro?

Não. Exportar um chat em XML é gratuito e ilimitado, sem conta e sem contador — igual a Markdown, JSON, texto, CSV e PNG. Só o PDF e o “Export All” em lote têm limite gratuito: 3 por dia com login do Google. O Pro custa US$ 3,99 por mês ou US$ 26,99 por ano, pelo Paddle. O Download Claude conversations não trata o XML como formato pago.

O limite só aparece no XML em lote. Cada chat de um ZIP do “Export All” usa uma das 3 exportações do dia, e a contagem zera à meia-noite UTC. O Pro remove o limite e é restaurado num computador novo com a mesma conta Google. O Paddle é o revendedor oficial (merchant of record); nossa equipe nunca vê números de cartão.

Você não precisa do plano pago do claude.ai da Anthropic. Basta um login que consiga abrir a conversa no Chrome. A versão 1.16.2, de setembro de 2026, ainda não gera arquivos do Word nem do Notion. Se essa lista mudar, esta página muda no mesmo dia.

Perguntas frequentes: exportar chat do Claude para XML

Estas perguntas tratam da exportação em XML no Download Claude conversations 1.16.2: comparação com JSON, “Export All” em lote, custo, Claude Desktop, PDF e Pro. Cada resposta é um fato do produto. O JSON-LD FAQPage no cabeçalho da página corresponde a esta lista.

XML é melhor que JSON para exportar chats do Claude?

Em geral, não. JSON é a escolha mais comum entre desenvolvedores. Use XML quando o sistema de destino exigir XML para troca de dados estruturados. A leitura do claude.ai é a mesma; o que muda é o formato do arquivo.

Dá para exportar chats do Claude para XML em lote?

Sim. O mesmo fluxo do “Export All” no Dashboard aceita XML e salva um ZIP com um arquivo XML por chat. No plano gratuito, cobre 3 chats por dia com login do Google; o Pro, por US$ 3,99 por mês ou US$ 26,99 por ano, é ilimitado.

O XML é um formato só para assinantes?

Não. As exportações de um chat em XML são ilimitadas e não exigem conta, como Markdown, texto, JSON, CSV e PNG. Só o PDF e o “Export All” em lote têm limite gratuito de 3 por dia. O Pro custa US$ 3,99 por mês ou US$ 26,99 por ano.

A exportação em XML corresponde ao ZIP da Anthropic?

Não. O Export data da Anthropic é um ZIP em JSON da conta, entregue depois de um tempo. O Download Claude conversations grava na hora, no Chrome, um arquivo XML por chat (ou por seleção). Não é o mesmo esquema.

A exportação em XML gera um PDF?

Não. XML é marcação. Para páginas, escolha PDF no mesmo painel; os sete formatos são PDF, Markdown, JSON, texto simples, XML, CSV e PNG. O PDF exige login do Google e conta para o limite de 3 por dia no plano gratuito.

Dá para exportar um chat do Claude para XML no Claude Desktop?

Não. A extensão do Chrome só é injetada no claude.ai. O Claude Desktop nunca mostra a lista com XML. Abra a mesma conversa no claude.ai pelo Chrome, se ela existir lá.

Preciso do Pro para exportar um chat para XML uma vez?

Não. Você não precisa de conta nenhuma. As exportações de um chat em XML são ilimitadas no plano gratuito. O Pro, por US$ 3,99 por mês ou US$ 26,99 por ano, só remove o limite de 3 por dia do “Export All” em lote e do PDF.
