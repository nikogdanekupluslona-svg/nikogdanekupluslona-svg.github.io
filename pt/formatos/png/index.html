Como baixar um chat do Claude em PNG?

Abra a conversa no claude.ai pelo Chrome, clique no botão laranja ao lado da caixa de mensagem, escolha PNG e clique em “Export”. O Download Claude conversations gera a imagem na própria aba. É assim que funciona na versão 1.16.2 — grátis, ilimitado, sem conta.

  1. Instale o Download Claude conversations pela Chrome Web Store.
  2. Recarregue o claude.ai e abra o endereço de uma conversa de verdade, não a tela inicial com a caixa de mensagem vazia.
  3. Clique no botão laranja redondo de download, à direita da caixa de mensagem.
  4. Escolha PNG. O último formato usado fica memorizado.
  5. Clique em “Export”. O Chrome baixa o PNG na hora.

Não é preciso login do Google para gerar o PNG. As exportações de um único chat em PNG são ilimitadas e anônimas: sem contador, e nada da conversa sai do navegador. O login só aparece se você escolher PDF, usar o “Export All” (Exportar tudo) ou assinar o Pro. Detalhes técnicos: como funciona.

Se o botão laranja não aparecer, você não está no endereço de uma conversa, a aba precisa ser recarregada depois da instalação ou a extensão está escondida no menu de extensões do Chrome (o ícone de peça de quebra-cabeça). Fixe o Download Claude conversations e atualize o claude.ai. Projetos, sessões do Cowork e o Claude Code on the web (claude.ai/code) exportam como qualquer chat. A exportação em PNG nunca aparece no aplicativo Claude Desktop nem nas sessões locais do Claude Code no terminal.

Uma imagem ou várias. O botão laranja gera um PNG da conversa aberta. Para várias imagens, abra “View and Download All Conversations” (Ver e baixar todas as conversas) e execute “Export All” com PNG selecionado. A exportação em lote gera um ZIP e usa a cota diária de lote — veja a exportação em lote com Export All.

Quando baixar chat do Claude em PNG?

Escolha PNG quando precisar de uma imagem para um slide, um aplicativo de mensagens ou um chamado de suporte — lugares onde é mais fácil soltar uma imagem do que um arquivo .md. Não escolha PNG se for precisar buscar ou copiar código depois. Para isso, use Markdown, ou PDF se precisar de páginas.

Uma captura de tela do claude.ai feita à mão costuma incluir a barra lateral e a caixa de mensagem. O Download Claude conversations monta o PNG a partir do conteúdo da conversa que ele já leu, e não de uma captura qualquer do sistema. Mesmo assim, continua sendo uma imagem: sem árvore de mensagens, sem tags de linguagem nos blocos de código para copiar como texto.

Adicionamos o PNG para você guardar um registro visual de uma conversa do claude.ai num único arquivo. Se precisar de páginas em vez de uma imagem longa, escolha PDF: a extensão o monta diretamente, com números de página e sumário. O PNG continua ilimitado e sem conta.

Equipe do Download Claude conversations

Muita gente também procura pelo nome Claude Chat Downloader ou digita em inglês “claude export chat” para achar a mesma extensão. O PNG sai desse botão laranja. As páginas jurídicas ainda podem dizer Claude Exporter. Esses nomes são este produto, não um segundo exportador.

Baixar um chat do Claude em PNG é o mesmo que PDF?

Não. PNG é um formato de imagem. PDF é um formato de documento com páginas. O Download Claude conversations exporta os dois: PNG para uma imagem, PDF para páginas. O PNG é ilimitado e sem conta; o PDF exige login do Google e é grátis até 3 por dia. Passo a passo: baixar um chat do Claude em PDF.

O que uma exportação em PNG de um chat do Claude inclui?

A exportação em PNG é uma única imagem do conteúdo da conversa que o Download Claude conversations renderizou. Ao contrário de Markdown ou JSON, o PNG não traz uma árvore de mensagens que dê para processar. Código e tabelas viram pixels. Raciocínio e artefatos são desenhados, não guardados como texto.

O filtro “Messages” (Mensagens) limita o que é desenhado a todas as mensagens, só as humanas ou só as do assistente; a caixa “Thinking” (Raciocínio) inclui ou tira o raciocínio estendido; e “Select” (Selecionar) permite marcar mensagens individuais. Metadados e layout de artefatos (“Original”, “Inline”, “Nested”, “Flat”) são opções do Dashboard para o “Export All”. Os metadados não viram texto selecionável no PNG como acontece no JSON. “Copy” (Copiar) não funciona para PNG; ele é sempre um arquivo.

Se a conversa for muito longa, role a página até o claude.ai carregar as mensagens mais antigas antes de exportar. A extensão só consegue renderizar o que a página já carregou. Uma conversa carregada pela metade gera uma imagem incompleta. Lista completa de opções: recursos da extensão do Chrome.

Guarde uma cópia em texto se as palavras importam. O PNG é um registro visual. Se depois você precisar procurar o nome de uma função, a busca não vai funcionar. Exporte também em Markdown ou JSON; é ilimitado e grátis, como o PNG.

Dá para baixar chats do Claude em PNG em lote?

Sim. Abra “View and Download All Conversations”, defina “Chat format” (formato do chat) como PNG, filtre a lista e clique em “Export All”. Você recebe um ZIP com um PNG por conversa selecionada. A exportação em lote exige login do Google; no plano gratuito, cada chat do ZIP usa uma das 3 exportações diárias de PDF ou em lote. O Pro, por US$ 3,99 por mês ou US$ 26,99 por ano, remove esse limite.

O Dashboard (painel da extensão) lista o histórico do claude.ai com busca por nome, busca por projeto, as abas “Chat” e “Cowork” e os filtros “All conversations” (Todas as conversas), “New” (Novas), “Updated” (Atualizadas) e “Previously exported” (Já exportadas). “New” são as conversas ainda não exportadas com o Download Claude conversations. O “Export All” gera um PNG por conversa selecionada dentro do ZIP — não uma folha de miniaturas nem um PDF encadernado.

O limite do lote zera à meia-noite UTC. No plano gratuito, uma seleção maior do que o que resta no dia é bloqueada por inteiro, e não cortada: escolha menos chats ou use o Pro. O PNG de um chat pelo botão laranja continua ilimitado. Na Anthropic, Settings → Privacy → Export data (os rótulos podem aparecer traduzidos se o claude.ai estiver em português) continua sendo um ZIP em JSON entregue depois de um tempo, não uma pasta de imagens.

Baixar chat do Claude em PNG custa algo a mais?

Não. O PNG é gratuito e ilimitado, igual a Markdown, JSON, texto, XML e CSV. Sem conta Google, sem contador. O Pro — US$ 3,99 por mês ou US$ 26,99 por ano, pelo Paddle — serve para PDF e ZIP em lote ilimitados, não para PNG. O Download Claude conversations não cobra nada a mais pelo PNG.

O login só entra se você quiser PDF ou “Export All”: os dois compartilham 3 exportações por dia no plano gratuito. O Pro é restaurado num computador novo quando você entra com a mesma conta Google. O Paddle é o revendedor oficial (merchant of record); nossa equipe nunca vê números de cartão.

A extensão funciona no claude.ai pelo Chrome: chats, Projetos, sessões do Cowork e Claude Code on the web (claude.ai/code). O aplicativo Claude Desktop e as sessões locais do Claude Code no terminal não ganham um botão de PNG. Esta equipe não tem aplicativo para iOS ou Android em 2026. A versão 1.16.2 gera PDF, mas não Word nem Notion.

Perguntas frequentes: baixar chat do Claude em PNG

Estas perguntas tratam da exportação em PNG no Download Claude conversations 1.16.2: PDF, “Export All” em lote, limites e o que a imagem contém. Cada resposta é um fato do produto. O JSON-LD FAQPage no cabeçalho da página corresponde a esta lista.

O Download Claude conversations exporta PDF?

Sim. Escolha PDF no painel de exportação para ter um documento com páginas, números de página e sumário opcionais. O PNG é uma única imagem da conversa. O PDF exige login do Google e é grátis até 3 por dia; o PNG é ilimitado e sem conta.

Dá para baixar todo o histórico do Claude em PNG?

Sim. O “Export All” no Dashboard aceita PNG e gera um ZIP com uma imagem por conversa selecionada. A exportação em lote exige login do Google; no plano gratuito, cada chat do ZIP usa uma das 3 exportações diárias de PDF ou em lote. O Pro é ilimitado.

O PNG é grátis ou só no Pro?

Grátis e ilimitado. As exportações de um chat em PNG não exigem conta e não têm contador. O Pro, por US$ 3,99 por mês ou US$ 26,99 por ano, serve para PDF e ZIP em lote ilimitados.

Dá para copiar código de um PNG de chat do Claude?

Não de um jeito limpo. O PNG guarda pixels. Exporte em Markdown ou JSON se precisar dos blocos de código com tag de linguagem. Guarde os dois arquivos se precisar de uma imagem e de texto pesquisável.

O PNG é uma captura de tela do Chrome?

Não. O Download Claude conversations gera o PNG a partir da conversa que ele leu no claude.ai. Continua sendo uma imagem, não um arquivo Markdown. Uma captura de tela da janela inteira feita pelo sistema é outro arquivo, que você mesmo tira.

O PNG funciona no Claude Desktop?

Não. A extensão do Chrome funciona no claude.ai pelo Chrome, não no aplicativo Claude Desktop. O Claude Desktop nunca mostra a opção PNG. Abra a mesma conversa no claude.ai pelo Chrome, se ela existir lá.

A exportação em PNG usa a mesma cota que o Markdown?

Sim — nenhum dos dois tem cota. As exportações de um chat em PNG e em Markdown são ilimitadas e anônimas. O único limite é de 3 exportações de PDF ou ZIP em lote por dia no plano gratuito; o Pro remove esse limite.
