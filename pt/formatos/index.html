Quais são os formatos de exportação aqui?

Os formatos de exportação deste site são os sete arquivos que a Download Claude conversations gera a partir de uma conversa do claude.ai: PDF, Markdown, texto simples, JSON, XML, CSV e PNG. A versão 1.16.2 gera todos eles no seu navegador. Seis são ilimitados e sem conta. O PDF pede login com o Google e é grátis até 3 por dia.

A extensão funciona onde quer que uma conversa abra no claude.ai, no Chrome: chats, Projects, sessões do Cowork e Claude Code na web (claude.ai/code). O app Claude Desktop e as sessões locais do Claude Code no terminal nunca mostram o botão laranja. Se a mesma conversa existir na sua conta do claude.ai, abra essa URL no Chrome e escolha o formato lá. A lista suspensa lembra o último formato de exportação que você usou.

Muita gente também pesquisa em inglês por Claude Chat Downloader e Claude Conversation Downloader para chegar a esta mesma extensão. Esses nomes são este produto, não um segundo exportador. As páginas jurídicas ainda podem dizer Claude Exporter. Os arquivos que você recebe são os mesmos sete formatos.

Uma lista, duas portas de entrada. O botão laranja exporta o chat aberto. O “Export All” no Dashboard exporta muitos chats em um ZIP, um arquivo por chat, em qualquer um dos sete formatos que você escolher como “Chat format” (formato do chat) — inclusive PDF. Detalhes: “Export All” em lote.

Qual formato escolher para exportar a conversa?

Escolha PDF para ler e compartilhar, Markdown para notas, JSON para scripts, CSV para planilhas, texto simples para um arquivo que se cola em qualquer lugar, XML quando um sistema exige XML e PNG para uma imagem da conversa. A Download Claude conversations não elege um como o melhor. Os formatos para exportar conversas do Claude diferem na forma; só o PDF tem limite diário no plano grátis.

Quem escreve costuma ficar com o Markdown. Desenvolvedores costumam ficar com o JSON. O PNG é a única imagem entre os formatos de exportação; depois não dá para pesquisar nele nem copiar código direito. Se você precisa de uma página para imprimir, escolha PDF: a extensão gera o arquivo diretamente, com tamanho da página, margens, modo claro ou escuro e sumário. A janela de impressão do Chrome é só uma alternativa.

O CSV grava uma linha por mensagem, então a conversa vira uma planilha que você pode ordenar e filtrar. Abre no Excel, no Google Sheets e no Numbers. Não há um guia separado para o CSV; esta página central cobre o formato. Assim como Markdown, JSON, XML e texto simples, o CSV também pode ir para a área de transferência com o “Copy” (copiar), em vez de ser baixado.

Como escolher o formato na hora de exportar?

Abra a URL de uma conversa no claude.ai, no Chrome, clique no botão laranja ao lado da caixa de mensagem, escolha um dos formatos de exportação e clique em “Export” (exportar). A Download Claude conversations monta o arquivo na aba. Em setembro de 2026, o claude.ai não tem um controle nativo para exportar a conversa.

  1. Instale a Download Claude conversations pela Chrome Web Store.
  2. Recarregue o claude.ai e abra a URL de uma conversa de verdade, não a tela inicial com a caixa de mensagem vazia.
  3. Clique no botão laranja redondo de download, à direita da caixa de mensagem.
  4. Escolha PDF, Markdown, texto simples, JSON, XML, CSV ou PNG. O último formato fica salvo.
  5. Clique em “Export”. O Chrome salva o arquivo na hora. Para PDF, ajuste as opções na janela do PDF; o primeiro PDF pede login com o Google.

Sem login para Markdown, texto, JSON, XML, CSV ou PNG: essas exportações são ilimitadas, anônimas e não enviam nada. O login com o Google só aparece para PDF, “Export All” ou Pro. Nesse caso, a extensão envia só o e-mail do Google, para verificar o limite diário e restaurar o Pro depois de uma reinstalação. O texto do chat nunca é enviado. Detalhes: como funciona.

O painel de exportação também define as mensagens (“All”, “Human”, “Assistant” — todas, usuário, assistente), uma caixa “Thinking” (raciocínio) e o “Select” (selecionar), que marca mensagens individuais. O “Copy” coloca Markdown, texto, JSON, XML ou CSV na área de transferência em vez de gerar um arquivo; é ilimitado e não está disponível para PDF nem PNG. Etapas de ferramentas / MCP e fontes da pesquisa na web são ativadas nas configurações. Metadados e layout dos artefatos (“Original”, “Inline”, “Nested”, “Flat” — original, embutido, aninhado, plano) são opções do Dashboard; o layout define se os artefatos ficam dentro do arquivo ou em uma pasta própria no ZIP.

Os formatos funcionam no “Export All”?

Sim. Abra o pop-up da extensão → “View and Download All Conversations” (ver e baixar todas as conversas), filtre a lista, marque os chats, escolha qualquer um dos sete formatos como “Chat format” e clique em “Export All”. Você recebe um ZIP com um arquivo por chat. O lote exige login com o Google; no plano grátis, cada chat do ZIP usa uma das 3 exportações diárias em PDF ou em lote. O Pro, por US$ 3,99 por mês ou US$ 26,99 por ano, remove esse limite.

O Dashboard lista o histórico do claude.ai com pesquisa por nome, pesquisa por projeto, abas Chat e Cowork e os filtros “All conversations”, “New”, “Updated” e “Previously exported” (todas, novas, atualizadas, já exportadas). “New” são os chats ainda não exportados com a Download Claude conversations. “Previously exported” registra os chats que você já salvou. O “Export All” não é um ZIP da conta que chega depois.

O limite do lote é diário. No plano grátis, PDF e lote dividem 3 exportações por dia, que zeram à meia-noite UTC. Cada chat de um ZIP conta como uma. Se você selecionar mais do que resta no dia, o lote inteiro é bloqueado, não cortado. Escolha menos chats ou use o Pro.

O lote tem as próprias caixas de inclusão — “Chats”, “Thinking”, “Metadata”, “Tools”, “Sources” (conversas, raciocínio, metadados, ferramentas, fontes) — além do layout dos artefatos. Você não recebe um pacote misto de Markdown e JSON em um clique. Você escolhe um dos formatos de exportação no seletor “Chat format” para aquela execução. Rode o “Export All” de novo com outro formato se precisar de duas versões da mesma conversa; no plano grátis, essa segunda execução conta de novo.

Formatos da extensão ou ZIP da Anthropic?

O Settings → Privacy → Export data da Anthropic (os nomes dos menus podem aparecer em português se o claude.ai estiver configurado nesse idioma) envia por e-mail, depois de uma espera, um ZIP em JSON da conta inteira. Os formatos para exportar conversas do Claude da Download Claude conversations salvam a conversa aberta na hora, em PDF, Markdown, texto, JSON, XML, CSV ou PNG. Use o ZIP para backup; use esta extensão para ter o arquivo agora.

O ZIP oficial não é uma versão mais bonita dos formatos de exportação. Não dá para escolher Markdown ou PDF nesse pedido. A Download Claude conversations não substitui esse ZIP se você precisa de todas as conversas esquecidas em um único arquivo. A impressão é um improviso visual; o PDF da própria extensão é o arquivo mais limpo.

A Download Claude conversations não tem vínculo com a Anthropic, PBC. Usar a extensão não muda os Termos de Serviço da Anthropic. O script de conteúdo usa a sessão que você já abriu no claude.ai. Siga as regras da Anthropic para a sua conta.

Quanto custam os formatos de exportação?

Seis formatos de exportação não custam nada e não exigem conta: Markdown, texto simples, JSON, XML, CSV e PNG são ilimitados. PDF e ZIP em lote são grátis até 3 por dia, somados, com login do Google. O Pro custa US$ 3,99 por mês ou US$ 26,99 por ano pela Paddle e deixa PDF e lote ilimitados. A Download Claude conversations não cobra a mais por nenhum formato específico.

A contagem diária zera à meia-noite UTC e fica ligada à sua conta do Google, por isso PDF e lote pedem login. O Pro é restaurado em outro computador quando você entra com a mesma conta do Google. A Paddle é a revendedora oficial (merchant of record); esta equipe nunca vê números de cartão. Cancele quando quiser na página de opções; o primeiro pagamento tem garantia de reembolso de 14 dias.

Perguntas frequentes: formatos para exportar conversas do Claude

Estas perguntas tratam dos formatos para exportar conversas do Claude na Download Claude conversations 1.16.2: a lista de sete formatos, PDF, CSV, limites, “Export All”, o ZIP da Anthropic, Desktop e Claude Code, e o Pro. Cada resposta é um fato do produto. O JSON-LD FAQPage no head da página corresponde a esta lista.

Em quais formatos posso baixar as conversas do Claude?

Sete: PDF, Markdown, texto simples, JSON, XML, CSV e PNG. Markdown, texto, JSON, XML, CSV e PNG são ilimitados e não exigem conta. O PDF exige login com o Google e é grátis até 3 por dia.

O PDF é um dos formatos de exportação?

Sim. Escolha PDF no painel de exportação. A janela do PDF define nome do arquivo, tamanho da página, margens, modo claro ou escuro, fonte e tamanho, números de página, sumário, data e hora e uma quebra de página antes de cada prompt. O arquivo é gerado no navegador, sem janela de impressão.

Para que serve a exportação em CSV?

Para planilhas. O CSV grava uma linha por mensagem e abre no Excel, no Google Sheets e no Numbers. É ilimitado, não exige conta e pode ser copiado para a área de transferência em vez de baixado.

Os formatos de exportação têm limite diário?

Só PDF e lote. Exportações de um chat em Markdown, texto, JSON, XML, CSV e PNG são ilimitadas e grátis. PDF e ZIP em lote dividem 3 por dia no plano grátis, que zeram à meia-noite UTC. O Pro, por US$ 3,99 por mês ou US$ 26,99 por ano, remove o limite.

Dá para misturar formatos no “Export All”?

Não. Cada execução do “Export All” usa um formato e gera um ZIP. Rode de novo com outro formato se precisar de dois arquivos do mesmo chat do claude.ai. No plano grátis, cada chat de cada ZIP conta no limite de 3 exportações diárias em PDF ou em lote.

Os formatos de exportação são a mesma coisa que o Export data?

Não. O Export data da Anthropic é um ZIP em JSON da conta, que chega depois. Os formatos para exportar conversas do Claude são arquivos por chat (ou por seleção) gerados na hora no Chrome pela Download Claude conversations.

Os formatos funcionam no Desktop ou no Claude Code?

Na web, sim. Chats, Projects, sessões do Cowork e o Claude Code na web (claude.ai/code) têm todos os formatos no Chrome. O app Claude Desktop e as sessões locais do Claude Code no terminal nunca mostram a lista de formatos. Abra a mesma conversa no claude.ai, no Chrome, se ela existir lá.

Preciso do Pro para experimentar os formatos de exportação?

Não. Seis formatos são ilimitados no plano grátis, sem conta. O PDF é grátis até 3 por dia com login do Google, dividido com o ZIP em lote. O Pro custa US$ 3,99 por mês ou US$ 26,99 por ano, para quando você precisar de PDF ou lote ilimitados.
