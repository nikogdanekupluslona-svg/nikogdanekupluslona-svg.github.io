Exportar conversa do Claude em JSON para scripts

Para exportar uma conversa do Claude em JSON, instale o Download Claude conversations, abra a conversa no claude.ai, clique no botão laranja, escolha JSON e clique em “Export” (Exportar). O Chrome salva um arquivo por chat com a árvore de mensagens. Esse arquivo não é o ZIP da conta da Anthropic. A exportação em JSON é ilimitada e gratuita, sem conta; o Pro (US$ 3,99 por mês ou US$ 26,99 por ano) só faz diferença para exportação em lote e PDF.

Como exportar uma conversa do Claude em JSON?

Abra a conversa no claude.ai pelo Chrome, clique no botão laranja ao lado da caixa de mensagem, escolha JSON e clique em “Export”. O Download Claude conversations grava o arquivo localmente. É assim que funciona na versão 1.16.2. Em setembro de 2026, o claude.ai não tem nenhum controle próprio para salvar um chat como JSON.

  1. Instale o Download Claude conversations pela Chrome Web Store.
  2. Recarregue o claude.ai e abra o endereço de uma conversa de verdade, não a tela inicial com a caixa de mensagem vazia.
  3. Clique no botão laranja de download, à direita da caixa de mensagem.
  4. Escolha JSON. O último formato usado fica memorizado. Use “Select” (Selecionar) para marcar só as mensagens que você quer.
  5. Clique em “Export”. O Chrome baixa o JSON pela API de downloads do navegador. Ou clique em “Copy” (Copiar) para colocar o JSON na área de transferência.

Não é preciso fazer login para gerar o JSON. As exportações de um único chat em JSON são ilimitadas, anônimas e não enviam nada aos nossos servidores. O login com Google só é pedido para PDF e para a exportação em lote com “Export All” (Exportar tudo). Detalhes técnicos: como funciona.

Se o botão laranja não aparecer, você não está no endereço de uma conversa, a aba precisa ser recarregada ou a extensão está escondida no menu de extensões do Chrome (o ícone de peça de quebra-cabeça). Fixe o Download Claude conversations e atualize o claude.ai. O script de conteúdo nunca é injetado no Claude Desktop nem no terminal do Claude Code.

Uma conversa ou vários arquivos. O botão laranja exporta o chat aberto em JSON. Para vários arquivos JSON, abra “View and Download All Conversations” (Ver e baixar todas as conversas) e execute “Export All” com JSON selecionado: um único ZIP, 3 chats por dia no plano gratuito — veja a exportação em lote com Export All.

Quando exportar conversa do Claude em JSON?

Use JSON quando um script, um indexador ou uma ferramenta de comparação for ler o arquivo. O JSON foi feito para a árvore de mensagens, não para leitura no Obsidian. Se você quer títulos e blocos de código para pessoas, escolha Markdown. Para planilhas, escolha CSV: uma linha por mensagem.

Copiar e colar do claude.ai perde a estrutura de remetentes. A impressão mantém a interface da página. No JSON, o Download Claude conversations mantém turnos, remetentes e o raciocínio opcional como dados, e não como um parágrafo achatado. É por isso que desenvolvedores preferem JSON a texto simples.

Geramos o JSON a partir da árvore do claude.ai que já está na página — remetente, blocos de conteúdo, data e hora, metadados do modelo — sem enviar a conversa para lugar nenhum. Esse JSON não é o ZIP da conta da Anthropic. Na versão 1.16.2, é um dos sete formatos, ao lado de PDF e CSV, e é gratuito, sem conta.

Equipe do Download Claude conversations

Muita gente também procura pelos nomes Claude Chat Downloader e Claude Conversation Downloader, ou digita em inglês “claude export chat”, para achar a mesma extensão. A exportação em JSON é esse botão laranja, não um segundo produto. As páginas jurídicas ainda podem dizer Claude Exporter.

O que vem num JSON de conversa do Claude?

O JSON de uma conversa do Claude reproduz a árvore de mensagens do claude.ai: remetente, blocos de conteúdo, data e hora e metadados do modelo. Blocos de raciocínio, fontes da pesquisa na web, etapas de ferramentas / MCP e artefatos entram quando essas opções estão ativadas: “Thinking” (Raciocínio) é uma caixa de seleção no painel de exportação, e ferramentas e fontes são ativadas nas configurações da extensão (Settings). O filtro de remetente limita o arquivo a todas as mensagens, só as humanas ou só as do assistente. Nada é convertido em Markdown antes.

O layout de artefatos na versão 1.16.2 é “Original”, “Inline” (em linha), “Nested” (aninhado) ou “Flat” (plano). Esses layouts mudam como o conteúdo dos artefatos fica aninhado no JSON — as mesmas quatro opções usadas em Markdown e XML. Lista completa: recursos da extensão do Chrome. Para páginas em vez de dados, exporte em PDF.

JSON da conversa do Claude ou Export data da Anthropic?

Os dois são JSON, mas com formato e alcance diferentes. Na Anthropic, Settings → Privacy → Export data (os rótulos podem aparecer traduzidos se o claude.ai estiver em português) envia por e-mail um ZIP da conta inteira, depois de um tempo. Com a extensão, você recebe uma conversa na hora, no Chrome. Use o ZIP para backup.

Não dá para escolher Markdown no pedido de ZIP da Anthropic. Também não dá para usar o JSON desta extensão como substituto direto do esquema desse ZIP. Visão geral: formatos de exportação de chats do Claude. O PDF serve para leitura, não é uma exportação em JSON.

O Download Claude conversations não tem vínculo com a Anthropic, PBC. O script de conteúdo usa a sessão que você já abriu no claude.ai. Ele não faz login na Anthropic com credenciais separadas. Siga as regras da Anthropic para a sua conta.

Dá para exportar conversas do Claude em JSON em lote?

Sim. Abra “View and Download All Conversations”, defina “Chat format” (formato do chat) como JSON, filtre a tabela e clique em “Export All”. O Chrome salva um ZIP com um arquivo JSON por chat. No plano gratuito são 3 chats por dia com login do Google, limite compartilhado com o PDF. O Pro, por US$ 3,99 por mês ou US$ 26,99 por ano, remove esse limite para JSON em lote.

O Dashboard (painel da extensão) lista o histórico do claude.ai com busca por nome, os filtros “All conversations” (Todas as conversas), “New” (Novas), “Updated” (Atualizadas) e “Previously exported” (Já exportadas), as abas “Chat” e “Cowork” e a busca por projeto. “New” são as conversas ainda não exportadas com o Download Claude conversations. “Previously exported” marca os chats que você já salvou. O “Export All” gera um ZIP com um JSON por chat, não um arquivo com formatos misturados.

O limite diário é por conta. Três chats por dia no plano gratuito, compartilhados com o PDF. Se você selecionar 40 conversas e restarem 3, o lote inteiro é bloqueado, e não cortado. Selecione menos ou use o Pro. As exportações individuais em JSON pelo botão laranja continuam ilimitadas.

Você pode comparar duas exportações em JSON da mesma conversa do claude.ai, feitas em momentos diferentes, como compararia qualquer arquivo JSON. Cada exportação é independente. Um segundo “Export All” dos mesmos chats conta todos eles de novo.

Exportar uma conversa do Claude em JSON exige o Pro?

Não. Exportar um chat em JSON é gratuito e ilimitado, sem conta e sem contador — igual a Markdown, texto, XML, CSV e PNG. Só o PDF e o “Export All” em lote têm limite gratuito: 3 por dia com login do Google. O Pro custa US$ 3,99 por mês ou US$ 26,99 por ano, pelo Paddle. O Download Claude conversations não cobra nada a mais pelo JSON.

O limite só aparece no JSON em lote. Cada chat de um ZIP do “Export All” usa uma das 3 exportações do dia, e a contagem zera à meia-noite UTC. O Pro remove o limite e é restaurado num computador novo com a mesma conta Google. O Paddle é o revendedor oficial (merchant of record); nossa equipe nunca vê números de cartão.

A extensão funciona só no claude.ai pelo Chrome. O Claude Desktop e o terminal do Claude Code não ganham um botão de JSON; o Claude Code on the web (claude.ai/code) roda no claude.ai, então exporta como qualquer chat. O /export do Claude Code no terminal ou os arquivos JSONL no disco são outro caminho. A versão 1.16.2, de setembro de 2026, ainda não gera arquivos do Word nem do Notion.

Perguntas frequentes: exportar conversa do Claude em JSON

Estas perguntas tratam da exportação em JSON no Download Claude conversations 1.16.2: “Export All” em lote, estrutura, custo, comparações, o ZIP da Anthropic, PDF e Claude Desktop. Cada resposta é um fato do produto. O JSON-LD FAQPage no cabeçalho da página corresponde a esta lista.

Dá para exportar conversas do Claude em JSON em lote?

Sim. O “Export All” no Dashboard aceita JSON e salva um ZIP com um arquivo JSON por chat. No plano gratuito, cobre 3 chats por dia com login do Google; o Pro, por US$ 3,99 por mês ou US$ 26,99 por ano, é ilimitado.

A estrutura do JSON é documentada?

Ela reproduz a própria árvore de mensagens do claude.ai: remetente, blocos de conteúdo, data e hora e metadados do modelo, com artefatos, blocos de raciocínio, fontes da pesquisa na web e etapas de ferramentas / MCP incluídos quando você ativa essas opções. Não é o esquema do ZIP da conta da Anthropic.

Preciso do Pro para exportar uma conversa do Claude em JSON?

Não. As exportações de um chat em JSON são ilimitadas e não exigem conta, como todos os formatos exceto o PDF. O Pro, por US$ 3,99 por mês ou US$ 26,99 por ano, só remove o limite de 3 por dia do PDF e do “Export All” em lote.

Dá para comparar dois JSON do mesmo chat?

Sim. Cada exportação em JSON gera um arquivo independente, montado do mesmo jeito. Comparar duas exportações da mesma conversa feitas em momentos diferentes funciona como comparar qualquer outro arquivo JSON.

Este JSON é o mesmo que o Export data da Anthropic?

Não. O Export data da Anthropic é um ZIP da conta inteira, entregue depois de um tempo. O Download Claude conversations grava na hora, no Chrome, um arquivo JSON por chat (ou por seleção). Os dois podem ser JSON, mas não são intercambiáveis.

A exportação em JSON gera um PDF?

Não. JSON são dados estruturados. Para páginas, escolha PDF no mesmo painel; os sete formatos são PDF, Markdown, JSON, texto simples, XML, CSV e PNG. O PDF exige login do Google e conta para o limite de 3 por dia no plano gratuito.

A exportação em JSON funciona no Claude Desktop?

Não. A extensão do Chrome só é injetada no claude.ai. O Claude Desktop nunca mostra a opção JSON. Abra a mesma conversa no claude.ai pelo Chrome, se ela existir lá.
