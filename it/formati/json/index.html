Come si esporta una conversazione Claude in JSON?

Apri la conversazione su claude.ai in Chrome, clicca il pulsante arancione accanto alla casella dei messaggi, scegli JSON e poi clicca “Export”. Download Claude conversations scrive il file in locale. Nella versione 1.16.2 funziona così. A settembre 2026 claude.ai non ha un comando per salvare la singola chat in JSON.

  1. Installa Download Claude conversations dal Chrome Web Store.
  2. Ricarica claude.ai e apri l’URL di una conversazione vera, non la home con la casella vuota.
  3. Clicca il pulsante arancione di download a destra della casella dei messaggi.
  4. Seleziona JSON. L’ultimo formato usato viene ricordato. Con “Select” (Seleziona) puoi spuntare solo i messaggi che ti interessano.
  5. Clicca “Export”. Chrome scarica il JSON tramite l’API di download del browser. In alternativa clicca “Copy” (Copia) per mettere il JSON negli appunti.

Per il JSON non serve alcun accesso. Le esportazioni in JSON della singola chat sono illimitate, anonime e non inviano nulla ai nostri server. L’accesso con Google viene chiesto solo per il PDF e per l’esportazione in blocco con “Export All” (esporta tutto). Il meccanismo: come funziona.

Se il pulsante arancione non c’è, non sei sull’URL di una conversazione, la scheda va ricaricata, oppure l’estensione è nascosta nel menu a forma di puzzle di Chrome. Fissa Download Claude conversations e aggiorna claude.ai. Lo script dell’estensione non si attiva mai in Claude Desktop né nel terminale di Claude Code.

Una conversazione o tanti file. Il pulsante arancione esporta in JSON la chat aperta. Per molti file JSON apri “View and Download All Conversations” (visualizza e scarica tutte le conversazioni) ed esegui “Export All” con JSON selezionato: un unico ZIP, 3 chat al giorno con il piano gratuito — vedi esportazione in blocco con Export All.

Quando conviene il formato JSON?

Esporta la conversazione in JSON quando il file lo leggerà uno script, un indicizzatore o uno strumento di confronto. Il JSON è pensato per l’albero dei messaggi, non per la lettura in Obsidian. Se vuoi titoli e blocchi di codice per le persone, scegli invece Markdown. Per un foglio di calcolo scegli CSV: una riga per messaggio.

Il copia e incolla da claude.ai perde la struttura dei mittenti. La stampa mantiene l’interfaccia della pagina web. Con il JSON, Download Claude conversations conserva turni, mittenti e ragionamento facoltativo come dati, non come un paragrafo appiattito. Per questo gli sviluppatori preferiscono il JSON al testo semplice.

Scriviamo il JSON partendo dall’albero di claude.ai già presente nella pagina — mittente, blocchi di contenuto, orari, metadati del modello — senza caricare la conversazione. Quel JSON non è lo ZIP dell’account di Anthropic. Nella versione 1.16.2 è uno dei sette formati, accanto a PDF e CSV, ed è gratuito senza account.

Cosa contiene l’esportazione JSON di una conversazione Claude?

L’esportazione JSON di una conversazione Claude rispecchia l’albero dei messaggi di claude.ai: mittente, blocchi di contenuto, orari e metadati del modello. Blocchi di ragionamento, fonti della ricerca web, passaggi tool / MCP e artifact vengono inclusi quando le relative opzioni sono attive: “Thinking” (ragionamento) è una casella nel pannello di esportazione, mentre strumenti e fonti si attivano nelle impostazioni. Il filtro dei mittenti limita il file a tutti i messaggi, solo ai tuoi o solo a quelli dell’assistente. Niente viene prima appiattito in Markdown.

Nella versione 1.16.2 la disposizione degli artifact può essere “Original”, “Inline”, “Nested” o “Flat” (originale, in linea, annidata, piatta). Queste disposizioni cambiano il modo in cui il contenuto degli artifact viene annidato nel JSON: sono le stesse quattro opzioni usate per Markdown e XML. Elenco completo: funzionalità dell’estensione Chrome. Se ti servono pagine invece di dati, esporta in PDF.

JSON della conversazione o Export data di Anthropic?

Sono entrambi JSON, ma con struttura e portata diverse. Settings → Privacy → Export data di Anthropic (le etichette possono essere tradotte se claude.ai è impostato in italiano) invia per email, dopo un’attesa, un unico ZIP dell’intero account. Esportando la conversazione in JSON ottieni subito una singola chat in Chrome. Usa lo ZIP per il backup.

Nella richiesta ZIP di Anthropic non puoi scegliere Markdown. E il JSON di questa estensione non può sostituire direttamente lo schema di quello ZIP. Panoramica: formati di esportazione delle chat Claude. Il PDF serve per la lettura, non è un’esportazione JSON.

Download Claude conversations non è affiliata ad Anthropic, PBC. Lo script dell’estensione usa la sessione che hai già aperto su claude.ai. Non accede ad Anthropic con credenziali separate. Rispetta le regole di Anthropic per il tuo account.

Posso esportare le conversazioni Claude in JSON in blocco?

Sì. Apri “View and Download All Conversations”, imposta “Chat format” (formato della chat) su JSON, filtra la tabella e poi clicca “Export All”. Chrome salva un unico ZIP con un file JSON per ogni chat. Con il piano gratuito sono 3 chat al giorno con accesso Google, in condivisione con il PDF. Pro, a 3,99 $ al mese o 26,99 $ all’anno, elimina questo limite per il JSON in blocco.

La Dashboard elenca la cronologia di claude.ai con ricerca per nome, i filtri “All conversations”, “New”, “Updated” e “Previously exported” (tutte, nuove, aggiornate, già esportate), le schede Chat e Cowork e la ricerca per progetto. “New” indica le chat non ancora esportate con Download Claude conversations. “Previously exported” tiene traccia delle chat già salvate. “Export All” produce un unico ZIP di file JSON, uno per chat, non un archivio con formati misti.

Il limite giornaliero vale per account. Tre chat al giorno con il piano gratuito, in condivisione con il PDF. Se selezioni 40 conversazioni e te ne restano 3, l’intero lotto viene bloccato, non troncato. Selezionane meno oppure passa a Pro. Le singole esportazioni JSON dal pulsante arancione restano illimitate.

Puoi confrontare due esportazioni JSON della stessa conversazione di claude.ai fatte in momenti diversi, come faresti con qualsiasi file JSON. Ogni esportazione è autonoma. Un secondo “Export All” delle stesse chat conta di nuovo ogni chat.

Per il JSON serve Pro?

No. L’esportazione in JSON della singola chat è gratuita e illimitata, senza account e senza contatore — come Markdown, testo, XML, CSV e PNG. Solo il PDF e “Export All” in blocco hanno un limite gratuito: 3 al giorno con accesso Google. Pro costa 3,99 $ al mese o 26,99 $ all’anno tramite Paddle. Download Claude conversations non fa pagare nulla in più per esportare una conversazione Claude in JSON.

Il limite si fa sentire con il JSON in blocco. Ogni chat in uno ZIP di “Export All” consuma una delle 3 esportazioni giornaliere, e il conteggio si azzera a mezzanotte UTC. Pro lo elimina e si ripristina su un nuovo computer con lo stesso account Google. Paddle è il merchant of record: questo team non vede mai i numeri delle carte.

L’estensione funziona solo su claude.ai in Chrome. Claude Desktop e il terminale di Claude Code non hanno un pulsante JSON; Claude Code on the web (claude.ai/code) gira su claude.ai, quindi si esporta come qualsiasi chat. Il comando /export di Claude Code nel terminale, o i file JSONL sul disco, sono un’altra strada. La versione 1.16.2, settembre 2026, non scrive ancora file Word o Notion.

FAQ: esportare conversazione Claude in JSON

Queste domande riguardano l’esportazione in JSON con Download Claude conversations 1.16.2: “Export All” in blocco, struttura, costi, confronti, lo ZIP di Anthropic, PDF e Desktop. Ogni risposta è un dato di prodotto. Il JSON-LD FAQPage nell’intestazione della pagina corrisponde a questo elenco.

Posso esportare le conversazioni Claude in JSON in blocco?

Sì. “Export All” nella Dashboard supporta JSON e salva un unico ZIP con un file JSON per chat. Con il piano gratuito copre 3 chat al giorno con accesso Google; Pro, a 3,99 $ al mese o 26,99 $ all’anno, è illimitato.

La struttura del JSON è documentata?

Rispecchia l’albero dei messaggi di claude.ai: mittente, blocchi di contenuto, orari e metadati del modello, con artifact, blocchi di ragionamento, fonti della ricerca web e passaggi tool / MCP inclusi quando attivi quelle opzioni. Non è lo schema dello ZIP dell’account di Anthropic.

Mi serve Pro per esportare una conversazione Claude in JSON?

No. Le esportazioni in JSON della singola chat sono illimitate e non richiedono account, come tutti i formati tranne il PDF. Pro, a 3,99 $ al mese o 26,99 $ all’anno, elimina solo il limite di 3 al giorno per il PDF e per “Export All” in blocco.

Posso confrontare due esportazioni JSON della stessa chat?

Sì. Ogni volta che esporti la conversazione in JSON ottieni un file autonomo, costruito sempre allo stesso modo. Confrontare due esportazioni della stessa conversazione fatte in momenti diversi funziona come con qualsiasi altro file JSON.

Questo JSON è lo stesso di Export data di Anthropic?

No. Export data di Anthropic è uno ZIP differito dell’intero account. Download Claude conversations scrive subito in Chrome un file JSON per singola chat (o per singola selezione). Possono essere entrambi JSON, ma non sono intercambiabili.

Esportare in JSON crea anche un PDF?

No. JSON è un formato di dati strutturati. Per le pagine scegli il PDF nello stesso pannello; i sette formati sono PDF, Markdown, JSON, testo semplice, XML, CSV e PNG. Il PDF richiede l’accesso con Google e rientra nelle 3 esportazioni al giorno del piano gratuito.

L’esportazione in JSON funziona su Claude Desktop?

No. L’estensione Chrome si attiva solo su claude.ai. Claude Desktop non mostra mai l’opzione JSON. Apri la stessa conversazione su claude.ai in Chrome, se esiste anche lì.
