Come si esporta una chat Claude in Markdown?

Apri la conversazione su claude.ai in Chrome, clicca il pulsante arancione accanto alla casella dei messaggi, scegli Markdown e poi clicca “Export”. Download Claude conversations scrive un file .md in locale. Nella versione 1.16.2 funziona così.

  1. Installa Download Claude conversations dal Chrome Web Store.
  2. Ricarica claude.ai e apri l’URL di una conversazione vera, non la home con la casella vuota.
  3. Clicca il pulsante arancione di download a destra della casella dei messaggi.
  4. Seleziona Markdown. L’estensione ricorda l’ultimo formato usato. Con “Select” (Seleziona) puoi spuntare solo i messaggi che ti interessano.
  5. Clicca “Export”. Chrome scarica il file .md tramite l’API di download del browser. In alternativa clicca “Copy” (Copia) per mettere il Markdown negli appunti.

Per il Markdown non serve alcun accesso. Le esportazioni in Markdown della singola chat sono illimitate, anonime e non inviano nulla ai nostri server. L’accesso con Google viene chiesto solo per il PDF e per l’esportazione in blocco con “Export All” (esporta tutto). Il meccanismo: come funziona.

Se il pulsante arancione non c’è, non sei sull’URL di una conversazione, la scheda va ricaricata dopo l’installazione, oppure l’estensione è ancora nascosta nel menu a forma di puzzle di Chrome. Fissa Download Claude conversations e aggiorna claude.ai. Lo script dell’estensione non si attiva mai in Claude Desktop né nel terminale di Claude Code.

Una chat o tante. Il pulsante arancione esporta in Markdown la conversazione aperta. Per molti file .md apri “View and Download All Conversations” (visualizza e scarica tutte le conversazioni) ed esegui “Export All” con Markdown selezionato: un unico ZIP, 3 chat al giorno con il piano gratuito — vedi esportazione in blocco con Export All.

Perché scegliere Markdown per gli appunti?

Scegli Markdown quando leggerai il file in Obsidian, in una wiki di GitHub o in qualsiasi editor che visualizza titoli e blocchi di codice. Il file .md resta testo semplice: puoi cercarci dentro e confrontare le versioni. JSON è più adatto ai parser; PNG è un’immagine in cui non puoi cercare testo.

Il copia e incolla da claude.ai di solito perde il rientro e appiattisce le tabelle. La stampa (Ctrl/Cmd+P) mantiene la barra laterale e spesso spezza un lungo blocco di codice su più pagine. Quando esporti la chat in Markdown, i blocchi di codice conservano l’indicazione del linguaggio e le tabelle restano tabelle. Per questo chi scrive sceglie questo formato per primo.

Consideriamo Markdown il file leggibile di riferimento: titoli, blocchi di codice con l’indicazione del linguaggio e tabelle della conversazione su claude.ai. Se ti servono pagine, scegli il PDF nello stesso pannello. Viene impaginato nel browser, con formato della pagina, margini e indice.

Cosa conserva il file Markdown?

Nel file Markdown Download Claude conversations conserva titoli, blocchi di codice con indicazione del linguaggio e rientro, tabelle e link. Blocchi di ragionamento, fonti della ricerca web e passaggi tool / MCP sono tutti facoltativi: “Thinking” (ragionamento) è una casella nel pannello di esportazione, gli altri due si attivano nelle impostazioni. I metadati (titolo, orari, modello) possono essere inclusi. Il filtro dei mittenti limita il file .md a tutti i messaggi, solo ai tuoi o solo a quelli dell’assistente.

La disposizione degli artifact è una vera opzione nella versione 1.16.2: “Original”, “Inline”, “Nested” o “Flat” (originale, in linea, annidata, piatta). Un’esportazione in Markdown può rispecchiare la struttura degli artifact sullo schermo, appiattirla in un unico documento lineare oppure spostare gli artifact in una cartella a parte dentro uno ZIP. Dalle impostazioni puoi incorporare le immagini nel file .md. Elenco completo: funzionalità dell’estensione Chrome. Markdown non conserva i colori dei fumetti dei messaggi; per un’istantanea visiva usa PNG, per le pagine il PDF.

Se la conversazione è molto lunga, scorri finché claude.ai non ha caricato i messaggi precedenti, poi esporta. L’estensione può scrivere solo ciò che la pagina ha visualizzato. Una conversazione caricata a metà produce un file .md a metà: sembra un bug, ma di solito è solo una pagina non scorsa fino in fondo.

Posso esportare le chat Claude in Markdown in blocco?

Sì. Apri “View and Download All Conversations”, imposta “Chat format” (formato della chat) su Markdown, filtra la tabella e poi clicca “Export All”. Chrome salva un unico ZIP con un file .md per ogni chat. Con il piano gratuito sono 3 chat al giorno con accesso Google, in condivisione con il PDF. Pro, a 3,99 $ al mese o 26,99 $ all’anno, elimina questo limite per il Markdown in blocco.

La Dashboard elenca la cronologia di claude.ai con ricerca per nome, i filtri “All conversations”, “New”, “Updated” e “Previously exported” (tutte, nuove, aggiornate, già esportate), le schede Chat e Cowork e la ricerca per progetto. “New” indica le chat non ancora esportate con Download Claude conversations. “Previously exported” tiene traccia delle chat già salvate, così un secondo “Export All” può saltarle.

Il limite giornaliero vale per account. Tre chat al giorno con il piano gratuito, in condivisione con il PDF. Se selezioni 40 conversazioni e te ne restano 3, l’intero lotto viene bloccato, non troncato. Selezionane meno oppure passa a Pro. Le singole esportazioni .md dal pulsante arancione restano illimitate.

Il Markdown in blocco usa le caselle della Dashboard “Chats”, “Thinking”, “Metadata”, “Tools” e “Sources” (chat, ragionamento, metadati, strumenti, fonti), più il formato degli artifact. “Export All” non è lo ZIP differito di Anthropic: è un unico ZIP di file .md, uno per chat. Se volevi un archivio dell’intero account, quello è Settings → Privacy → Export data (le etichette possono essere tradotte se claude.ai è impostato in italiano), che è JSON, non Markdown.

Markdown o JSON quando esporto una chat Claude?

Scegli Markdown quando il file lo leggerà una persona. Esporta in JSON quando uno script dovrà analizzare l’albero dei messaggi. Download Claude conversations offre entrambi nello stesso menu a tendina, insieme a PDF, testo semplice, XML, CSV e PNG. Panoramica: formati di esportazione delle chat Claude.

Markdown rispetto agli altri file di esportazione di claude.ai

Markdown Appunti, Obsidian, GitHub, wiki
JSON Confronti, pipeline, strumenti — guida a JSON
Testo semplice Archivio senza markup, da incollare ovunque
XML Un sistema che richiede XML
CSV Fogli di calcolo, una riga per messaggio

PNG Un’immagine della conversazione, non testo ricercabile

Anche Export data di Anthropic è JSON, ma è uno ZIP dell’account inviato via email, non un file .md per singola chat. In quella richiesta non puoi scegliere Markdown. La stampa del browser è un’istantanea della pagina web. Nessuna delle due sostituisce l’esportazione in Markdown dal pulsante arancione.

L’estensione funziona solo su claude.ai in Chrome. Claude Desktop e il terminale di Claude Code non hanno un pulsante Markdown. Claude Code on the web (claude.ai/code) gira su claude.ai, quindi si esporta come qualsiasi chat. Se una conversazione esiste anche su claude.ai, aprila lì ed esportala in Markdown. Il comando /export di Claude Code nel terminale è tutt’altra cosa.

L’esportazione in Markdown costa di più?

No. L’esportazione in Markdown di una chat è gratuita e illimitata, senza account e senza contatore — come JSON, testo, XML, CSV e PNG. Solo il PDF e “Export All” in blocco hanno un limite gratuito: 3 al giorno con accesso Google. Pro costa 3,99 $ al mese o 26,99 $ all’anno tramite Paddle. Download Claude conversations non applica alcun sovrapprezzo al Markdown.

Il limite si fa sentire con il Markdown in blocco. Ogni chat in uno ZIP di “Export All” consuma una delle 3 esportazioni giornaliere, e il conteggio si azzera a mezzanotte UTC. Pro lo elimina e si ripristina su un nuovo computer con lo stesso account Google. Paddle è il merchant of record: questo team non vede mai i numeri delle carte.

Non ti serve il piano a pagamento di claude.ai di Anthropic. Ti basta un accesso che carichi la conversazione in Chrome. Con Team ed Enterprise il pulsante arancione funziona come con Free. La versione 1.16.2, settembre 2026, non scrive ancora file Word o Notion.

FAQ: esportare chat Claude in Markdown

Queste domande riguardano l’esportazione in Markdown con Download Claude conversations 1.16.2: blocchi di codice, “Export All” in blocco, lo ZIP di Anthropic, costi, PDF e Desktop. Ogni risposta è un dato di prodotto. Il JSON-LD FAQPage nell’intestazione della pagina corrisponde a questo elenco.

Esportando la chat Claude in Markdown si perde il codice?

No. I blocchi di codice conservano l’indicazione del linguaggio e il rientro, a differenza di un semplice copia e incolla da claude.ai. Le tabelle restano tabelle Markdown. È il motivo principale per esportare in Markdown invece di selezionare il testo a mano.

Posso esportare le chat Claude in Markdown in blocco?

Sì. “Export All” nella Dashboard supporta Markdown e salva un unico ZIP di file .md. Con il piano gratuito copre 3 chat al giorno con accesso Google; Pro è illimitato.

Il Markdown è la stessa cosa di Export data di Anthropic?

No. L’esportazione ufficiale di Anthropic è uno ZIP JSON dell’intero account, inviato via email dopo un’attesa. Il Markdown di Download Claude conversations è un file .md per singola chat (o per singola selezione).

Il Markdown costa di più rispetto agli altri formati?

No. Le esportazioni in Markdown della singola chat sono illimitate e non richiedono account, come JSON, testo, XML, CSV e PNG. Solo PDF e ZIP in blocco hanno un limite gratuito di 3 al giorno. Pro costa 3,99 $ al mese o 26,99 $ all’anno.

Posso esportare una chat Claude in Markdown da Desktop?

No. Download Claude conversations si attiva solo su claude.ai in Chrome. Claude Desktop non mostra mai il menu a tendina con Markdown. Apri la stessa conversazione su claude.ai, se esiste anche lì.

Esportare in Markdown crea anche un PDF?

No. Markdown è un file di testo .md. Per le pagine scegli invece il PDF nello stesso pannello: viene generato nel browser con formato della pagina, margini e indice. Il PDF richiede l’accesso con Google e rientra nelle 3 esportazioni al giorno del piano gratuito.

Mi serve Pro per esportare una chat Claude in Markdown una volta?

No. Non ti serve nemmeno un account. Le esportazioni in Markdown della singola chat sono illimitate con il piano gratuito. Pro, a 3,99 $ al mese o 26,99 $ all’anno, elimina solo il limite di 3 al giorno per “Export All” in blocco e per il PDF.
