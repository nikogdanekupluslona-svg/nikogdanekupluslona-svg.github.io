Come si esporta una chat Claude in XML?

Apri la conversazione su claude.ai in Chrome, clicca il pulsante arancione accanto alla casella dei messaggi, scegli XML e poi clicca “Export”. Download Claude conversations scrive il file in locale. Nella versione 1.16.2 funziona così. A settembre 2026 claude.ai non ha un comando nativo per salvare in XML.

  1. Installa Download Claude conversations dal Chrome Web Store.
  2. Ricarica claude.ai e apri l’URL di una conversazione vera, non la home con la casella vuota.
  3. Clicca il pulsante arancione di download a destra della casella dei messaggi.
  4. Seleziona XML. L’ultimo formato usato viene ricordato. Con “Select” (Seleziona) puoi spuntare solo i messaggi che ti interessano.
  5. Clicca “Export”. Chrome scarica l’XML tramite l’API di download del browser. In alternativa clicca “Copy” (Copia) per mettere l’XML negli appunti.

Per l’XML non serve alcun accesso. Le esportazioni in XML della singola chat sono illimitate, anonime e non inviano nulla ai nostri server. L’accesso con Google viene chiesto solo per il PDF e per l’esportazione in blocco con “Export All” (esporta tutto). Il meccanismo: come funziona.

Se il pulsante arancione non c’è, non sei sull’URL di una conversazione, la scheda va ricaricata, oppure l’estensione è nascosta nel menu a forma di puzzle di Chrome. Fissa Download Claude conversations e aggiorna claude.ai. L’esportazione in XML non compare mai in Claude Desktop né nel terminale di Claude Code.

Un file o tanti. Il pulsante arancione esporta in XML la conversazione aperta. Per molti file XML apri “View and Download All Conversations” (visualizza e scarica tutte le conversazioni) ed esegui “Export All” con XML selezionato: un unico ZIP, 3 chat al giorno con il piano gratuito — vedi esportazione in blocco con Export All.

Quando conviene il formato XML?

Esporta la chat in XML quando il sistema di destinazione, la pipeline o uno strumento datato richiede XML per lo scambio di dati strutturati. La maggior parte degli sviluppatori dovrebbe scegliere invece JSON. Markdown serve per gli appunti leggibili. CSV per i fogli di calcolo. PNG è un’immagine. L’XML è nel menu a tendina perché alcuni strumenti accettano ancora XML e non JSON.

Non esportare in XML pensando di ottenere un JSON “più ufficiale”. Download Claude conversations analizza la conversazione nello stesso modo in entrambi i casi. Cambia la forma del file, non compaiono per magia campi in più. Se nessuno dei tuoi strumenti richiede XML, salta questo formato e usa JSON.

Offriamo XML perché alcune pipeline lo richiedono ancora, non perché pensiamo che batta JSON per ogni esportazione da claude.ai. L’analisi è la stessa: messaggi, mittente, ragionamento e artifact facoltativi. La versione 1.16.2 mantiene XML come uno dei sette formati, gratuito senza account, non un componente aggiuntivo a pagamento.

Cosa conserva il file XML?

Quando esporti la chat in XML, Download Claude conversations scrive la struttura della conversazione — messaggi, mittente e metadati disponibili — come markup XML. Blocchi di ragionamento, fonti della ricerca web, passaggi tool / MCP e artifact seguono le stesse opzioni di Markdown e JSON: “Thinking” (ragionamento) è una casella nel pannello di esportazione, mentre strumenti e fonti si attivano nelle impostazioni. L’XML non è una versione ridotta di quei formati.

Nella versione 1.16.2 la disposizione degli artifact può essere “Original”, “Inline”, “Nested” o “Flat” (originale, in linea, annidata, piatta). Il filtro dei mittenti limita l’XML a tutti i messaggi, solo ai tuoi o solo a quelli dell’assistente. I metadati (titolo, orari, modello) possono essere inclusi. Elenco completo delle opzioni: funzionalità dell’estensione Chrome.

XML o JSON quando esporto una chat Claude?

JSON è la scelta più comune tra gli sviluppatori. Esporta la chat in XML solo quando un sistema a valle lo richiede. Download Claude conversations non rende l’XML “più completo” del JSON. Entrambi possono includere ragionamento e artifact. Nessuno dei due è lo ZIP dell’account di Anthropic. Panoramica: formati di esportazione delle chat Claude.

XML rispetto agli altri file di esportazione di claude.ai
Formato Sceglilo quando
XML Uno strumento o uno schema che richiede XML
JSON Script, confronti, la maggior parte delle pipeline moderne

Testo semplice Nessun markup
CSV Fogli di calcolo, una riga per messaggio

Settings → Privacy → Export data di Anthropic (le etichette possono essere tradotte se claude.ai è impostato in italiano) produce JSON (uno ZIP), non XML. Il PDF dello stesso pannello sono pagine per le persone, non markup. Nessuno dei due sostituisce l’esportazione in XML dal pulsante arancione. Non aspettarti che questo XML corrisponda a uno schema di Anthropic non pubblicato.

L’estensione funziona solo su claude.ai in Chrome. Claude Desktop e il terminale di Claude Code non hanno un pulsante XML. Claude Code on the web (claude.ai/code) gira su claude.ai, quindi si esporta come qualsiasi chat. Se una conversazione esiste anche su claude.ai, aprila lì ed esportala in XML. Il comando /export di Claude Code nel terminale è tutt’altra cosa.

Posso esportare le chat Claude in XML in blocco?

Sì. Apri “View and Download All Conversations”, imposta “Chat format” (formato della chat) su XML, filtra la tabella e poi clicca “Export All”. Chrome salva un unico ZIP con un file XML per ogni chat. Con il piano gratuito sono 3 chat al giorno con accesso Google, in condivisione con il PDF. Pro, a 3,99 $ al mese o 26,99 $ all’anno, elimina questo limite per l’XML in blocco.

La Dashboard elenca la cronologia di claude.ai con ricerca per nome, i filtri “All conversations”, “New”, “Updated” e “Previously exported” (tutte, nuove, aggiornate, già esportate), le schede Chat e Cowork e la ricerca per progetto. “New” indica le chat non ancora esportate con Download Claude conversations. “Previously exported” tiene traccia delle chat già salvate. “Export All” produce un unico ZIP di file XML, uno per chat, non un archivio con formati misti.

Il limite giornaliero vale per account. Tre chat al giorno con il piano gratuito, in condivisione con il PDF. Se selezioni 40 conversazioni e te ne restano 3, l’intero lotto viene bloccato, non troncato. Selezionane meno oppure passa a Pro. Le singole esportazioni XML dal pulsante arancione restano illimitate.

Non puoi combinare XML e JSON in un solo clic su “Export All”. Per quell’esecuzione scegli XML. Esegui di nuovo “Export All” con JSON se ti servono entrambe le forme della stessa conversazione di claude.ai; la seconda esecuzione conta di nuovo ogni chat.

Per l’XML serve Pro?

No. L’esportazione in XML della singola chat è gratuita e illimitata, senza account e senza contatore — come Markdown, JSON, testo, CSV e PNG. Solo il PDF e “Export All” in blocco hanno un limite gratuito: 3 al giorno con accesso Google. Pro costa 3,99 $ al mese o 26,99 $ all’anno tramite Paddle. Download Claude conversations non considera l’XML un formato a pagamento.

Il limite si fa sentire con l’XML in blocco. Ogni chat in uno ZIP di “Export All” consuma una delle 3 esportazioni giornaliere, e il conteggio si azzera a mezzanotte UTC. Pro lo elimina e si ripristina su un nuovo computer con lo stesso account Google. Paddle è il merchant of record: questo team non vede mai i numeri delle carte.

Non ti serve il piano a pagamento di claude.ai di Anthropic. Ti basta un accesso che carichi la conversazione in Chrome. La versione 1.16.2, settembre 2026, non scrive ancora file Word o Notion. Se questo elenco cambia, questa pagina viene aggiornata lo stesso giorno.

FAQ: esportare chat Claude in XML

Queste domande riguardano l’esportazione in XML con Download Claude conversations 1.16.2: confronto con JSON, “Export All” in blocco, costi, Desktop, PDF e Pro. Ogni risposta è un dato di prodotto. Il JSON-LD FAQPage nell’intestazione della pagina corrisponde a questo elenco.

L’XML è meglio del JSON per esportare le chat Claude?

In generale no. JSON è la scelta più comune tra gli sviluppatori. Esporta la chat in XML quando il sistema a valle richiede XML per lo scambio di dati strutturati. L’analisi di claude.ai è la stessa; cambia la forma del file.

Posso esportare le chat Claude in XML in blocco?

Sì. Lo stesso flusso “Export All” della Dashboard supporta l’XML e salva un unico ZIP con un file XML per chat. Con il piano gratuito copre 3 chat al giorno con accesso Google; Pro, a 3,99 $ al mese o 26,99 $ all’anno, è illimitato.

L’XML è un formato solo a pagamento?

No. Le esportazioni in XML della singola chat sono illimitate e non richiedono account, come Markdown, testo, JSON, CSV e PNG. Solo PDF e “Export All” in blocco hanno un limite gratuito di 3 al giorno. Pro costa 3,99 $ al mese o 26,99 $ all’anno.

L’XML corrisponde allo ZIP di Anthropic?

No. Export data di Anthropic è uno ZIP JSON differito dell’intero account. Download Claude conversations scrive subito in Chrome un file XML per singola chat (o per singola selezione). Non hanno lo stesso schema.

Esportare in XML crea anche un PDF?

No. L’XML è markup. Per le pagine scegli il PDF nello stesso pannello; i sette formati sono PDF, Markdown, JSON, testo semplice, XML, CSV e PNG. Il PDF richiede l’accesso con Google e rientra nelle 3 esportazioni al giorno del piano gratuito.

Posso esportare una chat Claude in XML da Desktop?

No. L’estensione Chrome si attiva solo su claude.ai. Claude Desktop non mostra mai il menu a tendina con XML. Apri la stessa conversazione su claude.ai in Chrome, se esiste anche lì.

Mi serve Pro per esportare una chat Claude in XML una volta?

No. Non ti serve nemmeno un account. Le esportazioni in XML della singola chat sono illimitate con il piano gratuito. Pro, a 3,99 $ al mese o 26,99 $ all’anno, elimina solo il limite di 3 al giorno per “Export All” in blocco e per il PDF.
