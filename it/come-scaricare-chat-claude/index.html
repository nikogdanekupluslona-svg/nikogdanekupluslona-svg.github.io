Come scaricare una chat Claude con Chrome?

La risposta diretta è il pulsante arancione che Download Claude conversations aggiunge accanto alla casella dei messaggi su claude.ai. Apri la conversazione, scegli PDF, Markdown, JSON, testo, XML, CSV o PNG, poi fai clic su «Export» (Esporta). Il file viene assemblato nel tuo browser e salvato sul disco.

L’estensione è uno script di contenuto di Chrome. Legge la conversazione già caricata nella tua sessione di claude.ai, con il tuo accesso. Non chiama un’API separata di Anthropic con credenziali proprie e non carica la conversazione sui nostri server per generare il file.

  1. Installa Download Claude conversations dal Chrome Web Store (funzionano anche i browser Chromium che caricano le estensioni di Chrome).
  2. Ricarica claude.ai se la pagina era già aperta durante l’installazione.
  3. Apri l’URL della conversazione che ti serve: il pulsante arancione compare solo in una conversazione vera, non nella pagina iniziale con la casella vuota.
  4. Fai clic sul pulsante rotondo arancione a destra della casella dei messaggi. Si apre un pannello con Messages («All» / «Human» / «Assistant», cioè tutti / tuoi / di Claude), Format, «Thinking» (ragionamento), «Select» (Seleziona), «Copy» (Copia) ed «Export».
  5. Scegli PDF, Markdown, testo semplice, JSON, XML, CSV o PNG. Fai clic su «Export». Chrome scarica subito il file.

Per Markdown, testo semplice, JSON, XML, CSV o PNG non serve alcun account. Queste esportazioni di una singola chat sono illimitate e gratuite: nessun accesso, nessun contatore. L’accesso con Google compare solo quando scegli PDF o avvii un «Export All» (Esporta tutto) in blocco. Non è un login per leggere le tue chat. Il contenuto delle conversazioni resta sul tuo computer.

PDF e ZIP in blocco condividono una quota gratuita di 3 al giorno, che si azzera a mezzanotte UTC. Ogni chat dentro uno ZIP in blocco conta come una. Pro costa 3,99 $ al mese o 26,99 $ all’anno ed elimina il limite. Opzioni e passaggi del PDF: scaricare una chat Claude in PDF.

File locali. Ogni formato, PDF compreso, viene creato nel browser e passato all’API di download di Chrome. Il testo delle chat non viene mai caricato. Solo le esportazioni PDF e in blocco inviano un controllo della quota con la tua email Google.

Lo stesso pannello filtra per mittente: «All», «Human» o «Assistant». La casella «Thinking» include o esclude il ragionamento esteso. «Select» ti permette di spuntare singoli messaggi, così il file contiene solo quei turni. «Copy» mette Markdown, testo, JSON, XML o CSV negli appunti invece di scaricare un file. I passaggi degli strumenti / MCP e le fonti della ricerca web si attivano a scelta nelle impostazioni. I metadati e la disposizione degli artifact, «Original», «Inline», «Nested» o «Flat», si impostano nella Dashboard.

Se la conversazione è molto lunga, scorri finché claude.ai non ha caricato i messaggi precedenti. L’estensione può esportare solo ciò che la pagina ha mostrato. Una conversazione caricata a metà produce un file a metà: sembra un bug, ma di solito è solo una pagina che non hai fatto scorrere.

Analizziamo l’albero dei messaggi sulla pagina di claude.ai che hai già aperto. I blocchi di codice mantengono il tag del linguaggio e l’indentazione; le tabelle restano tabelle. Il PDF viene creato da quello stesso albero dentro il browser, senza finestra di stampa: un file stampabile non è più uno screenshot della pagina web.

Posso scaricare una chat Claude senza estensione?

Sì. Puoi scaricare una chat Claude senza estensione stampando la pagina o richiedendo l’esportazione dell’account ad Anthropic. La stampa è un PDF visivo della pagina web. Export data è uno ZIP JSON di tutto l’account, che arriva più tardi. Nessuno dei due crea un file Markdown per singola chat.

Con la stampa: apri la conversazione su claude.ai, nascondi la barra laterale se l’interfaccia lo consente, premi Ctrl+P (Windows/Linux) o Cmd+P (Mac), imposta la destinazione su «Salva come PDF» e salva. I blocchi di codice spesso si spezzano tra una pagina e l’altra. Gli elementi dell’interfaccia intorno alla casella di scrittura possono comparire su ogni foglio. L’esportazione PDF dell’estensione salta questa finestra. I due metodi sono messi a confronto in scaricare una chat Claude in PDF.

Con il metodo ufficiale: Settings → Privacy → Export data su claude.ai (le voci possono essere tradotte se claude.ai è impostato in italiano). Anthropic ti invia per email un link che scade. Lo ZIP è un archivio JSON a livello di account, non un file con il nome della chat che stavi leggendo. Usalo come backup, poi estrailo da solo se ti serve una conversazione tra migliaia.

Il copia e incolla è un terzo metodo senza estensione. Selezioni il testo e lo incolli in Docs o in un’app per appunti. L’indentazione del codice di solito si perde. Le tabelle diventano righe continue. Una conversazione a più turni diventa un muro di testo senza struttura. Va bene per una risposta breve. Non va bene per una revisione del codice che vorrai cercare più avanti. Il pulsante «Copy» dell’estensione mette invece negli appunti un Markdown pulito.

Come scarico in blocco la cronologia delle chat Claude?

Per scaricare la cronologia delle chat Claude in tanti file, non ripetere il pulsante arancione scheda per scheda. Apri «View and Download All Conversations» (vedi e scarica tutte le conversazioni) dal popup dell’estensione, filtra la tabella e fai clic su «Export All». «Export All» chiede l’accesso con Google. Con il piano gratuito ogni chat nello ZIP usa uno dei 3 slot giornalieri condivisi con il PDF. Pro elimina il limite.

La Dashboard elenca le conversazioni dell’account claude.ai con cui hai effettuato l’accesso. Cerca per nome. Filtra per All conversations, New, Updated o Previously exported (tutte, nuove, aggiornate, già esportate). Passa dalla scheda Chat alla scheda Cowork e cerca per progetto se su claude.ai raggruppi le chat così. Seleziona solo una parte quando non vuoi ogni vecchia bozza nella cartella.

L’esportazione in blocco crea un unico ZIP con un file per chat, nel formato che scegli nel selettore «Chat format»: uno qualsiasi dei sette, PDF compreso. Usa lo stesso parser dell’esportazione di una singola chat. Le caselle decidono cosa entra nel file, «Chats», «Thinking», «Metadata», «Tools», «Sources» (chat, ragionamento, metadati, strumenti, fonti), più una disposizione degli artifact. «Export All» non è una versione ridotta: è lo stesso parser applicato a molte conversazioni in un solo passaggio. Dettagli e screenshot: «Export All» in blocco.

Export data di Anthropic resta il backup dell’account. Un ZIP, un’email, JSON per tutto, comprese le chat che avevi dimenticato. «Export All» fa l’opposto: scegli tu le conversazioni, scegli tu il formato, lo ZIP arriva subito. Usali entrambi se vuoi un archivio completo a fini legali e una cartella di appunti leggibili.

La quota è condivisa e giornaliera. Con il piano gratuito, le esportazioni PDF e le chat in blocco condividono 3 slot al giorno, che si azzerano a mezzanotte UTC. Se selezioni 40 conversazioni, l’intero lotto viene bloccato, non tagliato. Scegline meno, oppure passa a Pro a 3,99 $ al mese o 26,99 $ all’anno.

La Dashboard ricorda anche cosa hai già esportato, così alla visita successiva puoi filtrare solo New o Updated. In questo modo l’abitudine di scaricare ogni settimana la cronologia delle chat Claude resta incrementale, senza duplicare il Markdown del mese scorso.

Come scaricare una chat Claude in Markdown o JSON?

Per avere Markdown o JSON: apri il pulsante arancione, scegli il formato, poi «Export». Markdown è il file per gli appunti. JSON è l’albero dei messaggi per gli script. Il testo semplice non ha markup. CSV è una riga per messaggio. PDF è un documento impaginato. PNG è un’immagine.

Markdown mantiene titoli, blocchi di codice delimitati con il tag del linguaggio e tabelle. È la scelta abituale per Obsidian, GitHub o un wiki. JSON conserva l’albero che il parser ha già costruito, compresi artifact e ragionamento quando quelle opzioni sono attive. Non ha la stessa struttura dello ZIP dell’account di Anthropic. Note sui formati: tutti i formati.

Il testo semplice è la scelta giusta quando la destinazione elimina comunque il markup: un campo di un sistema di ticket, il corpo di un’email, un indice di ricerca che vuole stringhe grezze. XML è la scelta di nicchia per lo scambio di dati. CSV si apre in Excel, Google Sheets o Numbers. PNG serve per una slide o per lo screenshot della conversazione in una segnalazione di bug, non per una revisione di design di 40 turni in cui vorrai cercare con grep.

Salvare una conversazione Claude, stamparla o usare lo ZIP?

Salvare, scaricare ed esportare sono la stessa operazione su claude.ai: portare la conversazione fuori dalla pagina. Per salvare una conversazione Claude come file utilizzabile, PDF compreso, c’è l’estensione. La stampa è un’istantanea. Export data di Anthropic è uno ZIP dell’account.

Nei team le parole si mescolano. Chi fa ricerca dice salvare. Uno sviluppatore dice esportare. Un manager dice scaricare. Su questo sito i tre verbi portano allo stesso pulsante arancione quando lavori su claude.ai in Chrome. La guida collegata come esportare una chat Claude approfondisce lo ZIP ufficiale e le strutture JSON.

La stampa ha ancora senso: un allegato occasionale che deve sembrare esattamente la schermata di claude.ai. Anche Export data ufficiale ha senso: quando lasci un’azienda, per una conservazione a fini legali o per un backup in più. Nessuno dei due sostituisce un file Markdown che modificherai la settimana prossima.

Claude Desktop è un’altra finestra. L’estensione di Chrome non si inserisce nell’app Desktop. Se la stessa chat esiste su claude.ai, aprila lì e scaricala. Se esiste solo in Desktop, usa il copia e incolla o aspetta lo ZIP dell’account. Passaggi: esportare una chat di Claude Desktop.

Paddle gestisce i pagamenti di Pro. Non vediamo i numeri delle carte. L’accesso con Google, usato solo per PDF, esportazione in blocco e Pro, non ci dà accesso alle conversazioni. Il worker Cloudflare che controlla quota e stato Pro riceve la tua email Google, non il testo dei messaggi. Le altre esportazioni di una singola chat non inviano nulla. Questo confine è tutta la storia della privacy: la fatturazione sul server, la chat sul disco.

Perché non vedo il pulsante per scaricare la chat Claude?

Il pulsante per scaricare la chat Claude manca quando non sei nell’URL di una conversazione, quando la scheda non è stata ricaricata dopo l’installazione o quando l’estensione è disattivata. Fissa l’icona, ricarica e verifica di essere in Chrome per computer su claude.ai, non in Desktop, su un telefono o in un terminale di Claude Code.

Dopo l’installazione, Chrome non inserisce sempre lo script di contenuto nelle schede già aperte. Chiudi la scheda di claude.ai o ricaricala completamente. Se usi più profili, l’estensione deve essere installata nel profilo con cui hai effettuato l’accesso ad Anthropic.

Gli spazi di lavoro Team ed Enterprise funzionano se riesci ad aprire la conversazione nel browser. L’estensione legge la pagina, non il livello del piano. Se l’organizzazione blocca le estensioni di Chrome, l’IT deve consentire questa; dal sito non possiamo aggirare quella policy.

Richiesta di accesso: prevista solo per PDF ed «Export All». Markdown, testo, JSON, XML, CSV e PNG si esportano senza account. La prima esportazione PDF o in blocco chiede Google. Se annulli quella richiesta, sembra un download fallito. Completa l’accesso, poi fai di nuovo clic su «Export». Il piano gratuito non richiede alcuna carta di credito.

File incompleto: la conversazione non aveva finito di generarsi, oppure i turni più vecchi erano ancora fuori schermo e non caricati. Aspetta che l’assistente finisca. Scorri verso l’inizio di una conversazione lunga, così claude.ai carica quegli elementi, poi esporta di nuovo. Ripetere un’esportazione Markdown o JSON non costa nulla. Ripetere un PDF usa un altro dei 3 slot giornalieri del piano gratuito: un motivo in più per verificare prima che la conversazione sia caricata del tutto.

Tipo di file sbagliato: era ancora selezionato l’ultimo formato usato. Account sbagliato: hai effettuato l’accesso a Google con un indirizzo diverso da quello che ha Pro. Il ripristino di Pro è legato a quell’email Google, non al login di Anthropic e nemmeno al nome del profilo di Chrome.

I browser per dispositivi mobili non eseguono questa estensione. Non esiste un’app per iOS o Android. Safari sul telefono può stampare, ma non può mostrare il pulsante arancione. Per un file riutilizzabile, apri la stessa chat in Chrome sul computer.

Scarica anche le chat di Claude Code?

Solo da Claude Code sul web. Le sessioni su claude.ai/code si aprono in Chrome, quindi Download Claude conversations le esporta come qualsiasi chat. Una sessione locale di Claude Code nel terminale è un’altra cosa. Per esportare la sessione del terminale si usa /export oppure il file JSONL in ~/.claude/projects. Ambienti diversi, file diversi.

In una sessione attiva di Claude Code, digita /export. La CLI di Anthropic apre un menu per copiare la trascrizione o salvarla in un file di testo semplice. Passa un nome di file per saltare il menu. Quella trascrizione è testo da leggere per una persona, non il Markdown, il JSON o il PDF di questa estensione. Tutti i percorsi: esportare da Claude Code.

Il JSONL sul disco è il log interno. Lo schema può cambiare da una versione di Claude Code all’altra. La documentazione di Anthropic stessa consiglia di preferire /export o le interfacce per script rispetto all’analisi del JSONL. Non integriamo quella CLI. Non leggiamo ~/.claude.

Se tieni una conversazione parallela su claude.ai per lo stesso lavoro, scarica quella chat del browser con il pulsante arancione. Il log del terminale e la chat web non sono automaticamente lo stesso documento. Trattali come due registri distinti, a meno che tu non abbia incollato l’uno nell’altro.
