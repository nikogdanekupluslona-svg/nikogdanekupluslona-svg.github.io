Che cos’è l’esportazione di Claude Code nel terminale?

Esportare da Claude Code significa usare il comando /export dentro una sessione interattiva della CLI. La documentazione di Anthropic descrive un menu per copiare la conversazione corrente o salvarla in un file di testo semplice, con messaggi e output degli strumenti resi come testo leggibile. Se passi un nome di file, il menu viene saltato e il file viene scritto direttamente.

Non è il Markdown di claude.ai, non è il JSON di questa estensione Chrome e non è un PDF. È una trascrizione pensata per essere letta da una persona. Anthropic precisa che il log JSONL sul disco è un formato diverso e interno, pensato per il prodotto e non come API pubblica per te.

/export

Per saltare la domanda e scrivere un file con un nome nella cartella di lavoro corrente:

/export my-session

La documentazione di Anthropic sulle sessioni è la fonte di riferimento per opzioni e nomi di file, che cambiano tra le versioni di Claude Code. Considera i blog della community come fonti secondarie. Se i testi della finestra di /export non corrispondono a ciò che vedi, la tua CLI è una build diversa: usa la guida interna del prodotto, non uno screenshot del 2025.

Per gli script Anthropic indica altre interfacce: claude -p con --output-format json o stream-json, la ripresa tramite ID di sessione, gli hook che ricevono un transcript_path oppure l’Agent SDK. Sono strumenti per sviluppatori di Claude Code, non l’estensione Chrome di questo sito.

Leggibile contro strutturato. /export è la trascrizione per le persone. Il JSONL nella cartella dei progetti è il log. Il JSON dell’estensione Chrome è una terza struttura, generata solo da una pagina di claude.ai. Non scrivere un unico parser per tutti e tre.

Come scaricare una conversazione Claude Code dal disco?

Per scaricare una conversazione Claude Code dal disco, copia il file JSONL della sessione dalla cartella dei progetti, oppure esegui /export per ottenere una trascrizione leggibile. Il percorso predefinito su macOS e Linux è sotto ~/.claude/projects/. Su Windows è %USERPROFILE%\.claude\projects. I nomi dei file sono gli ID di sessione.

Il nome della cartella del progetto è la cartella di lavoro con i caratteri non alfanumerici sostituiti da trattini. Anthropic tronca i nomi convertiti molto lunghi e aggiunge un hash, così la cartella resta entro i limiti del file system. Se non trovi la cartella, hai avviato Claude Code da una cartella di lavoro diversa da quella che pensi.

Ogni riga del JSONL è un oggetto JSON per un messaggio, un uso di strumento o dei metadati. Anthropic dichiara che questo formato è interno e cambia tra le versioni. Gli script che analizzano questi file possono rompersi con un nuovo rilascio di Claude Code. Quando ti serve qualcosa di stabile, preferisci /export o le interfacce di scripting documentate.

La posizione dei file può cambiare. CLAUDE_CONFIG_DIR sposta la configurazione fuori da ~/.claude. CLAUDE_CODE_PROJECT_DIR_NAME assegna il nome alla cartella del progetto quando è usata insieme a quella cartella di configurazione (Claude Code v2.1.234 o successiva, secondo Anthropic). cleanupPeriodDays in settings.json modifica la conservazione predefinita. Nessuna di queste opzioni è una funzione di Download Claude conversations.

Per scaricare le conversazioni di Claude Code come backup, quindi, copia la cartella oppure esporta periodicamente le trascrizioni con /export. Questo sito non aggiungerà un pulsante “importa JSONL”. Non leggiamo la tua cartella home.

L’esportazione di Claude Code funziona con questa estensione?

No, non per le sessioni nel terminale. Download Claude conversations non legge le sessioni locali di Claude Code. L’estensione Chrome agisce su claude.ai: non vede il terminale, non può eseguire /export e non può aprire file JSONL. Claude Code on the web su claude.ai/code è l’eccezione: è una pagina di claude.ai, quindi si esporta come qualsiasi chat. Se cercavi come scaricare una conversazione Claude Code dalla CLI, segui i passaggi per la CLI di questa pagina.

Molti arrivano qui perché Google raggruppa “Claude” ed “esportare”. La scheda del Web Store riguarda comunque solo claude.ai. Installare l’estensione non aggiunge un pulsante arancione in iTerm, Ghostty, nel terminale di VS Code o nell’involucro desktop di Claude Code.

Se per lo stesso lavoro di programmazione tieni anche una conversazione parallela su claude.ai, quella chat nel browser si può salvare con l’estensione. I due registri non vengono uniti. Le chiamate agli strumenti avvenute solo nella CLI non compaiono nell’esportazione web, a meno che tu non le abbia incollate lì.

Posso esportare le sessioni di Claude Code on the web?

Sì. Claude Code on the web funziona su claude.ai/code, quindi Download Claude conversations esporta quelle sessioni come qualsiasi chat di claude.ai. Apri la sessione in Chrome, clicca il pulsante arancione, scegli un formato e clicca “Export” (Esporta). È l’unico ambiente di Claude Code coperto dall’estensione.

I formati sono gli stessi sette di ogni chat: PDF, Markdown, testo semplice, JSON, XML, CSV e PNG. Markdown, testo, JSON, XML, CSV e PNG sono illimitati e senza account. Il PDF chiede l’accesso con Google e condivide con lo ZIP in blocco le 3 esportazioni giornaliere del piano gratuito, a meno che tu non abbia Pro. I blocchi di codice conservano il linguaggio indicato. L’extended thinking è la casella “Thinking” (ragionamento) nel pannello; passaggi tool / MCP e fonti della ricerca web si attivano nelle impostazioni.

L’esportazione web è ciò che claude.ai/code mostra nel browser. Non è il log JSONL di un’esecuzione locale della CLI e non raggiunge le sessioni avvenute solo nel terminale. Secondo Anthropic, Claude Code on the web ha una propria cronologia delle sessioni, separata dalla cartella ~/.claude/projects della CLI. Per una sessione nel terminale la strada resta /export.

Dove salva Claude Code la cronologia delle conversazioni?

Claude Code salva la cronologia delle conversazioni come trascrizioni JSONL nella cartella dei progetti della cartella di configurazione. Percorso predefinito su macOS e Linux: ~/.claude/projects/<encoded-cwd>/<session-id>.jsonl. Windows usa %USERPROFILE%\.claude\projects. Anthropic può cambiare questa struttura; se un percorso manca sul disco, consulta la documentazione aggiornata sulle sessioni.

Riprendere non è esportare. claude --continue e claude --resume ricaricano una sessione per continuare a lavorare. /export scrive una copia che puoi tenere in git o inviare per email. Uno ripristina il contesto, l’altro ti fa portare via un registro. La pagina di Anthropic sulle sessioni descrive la modalità dei permessi alla ripresa, compattazione/riepilogo e il comportamento del selettore: niente di tutto questo riguarda l’estensione.

Secondo Anthropic, l’app desktop, Claude Code on the web e l’estensione per VS Code hanno ciascuna la propria cronologia delle sessioni. I percorsi di questa guida riguardano la CLI. Le sessioni web restano su claude.ai/code, dove l’estensione può esportarle. Non dare per scontato che una trascrizione Cowork di Desktop si trovi nella stessa cartella JSONL che usi dal terminale.

Non trattare il JSONL come uno schema pubblico. Anthropic dice che il formato delle righe cambia. Se lo analizzi comunque, fissa una versione di Claude Code e mettiti in conto che qualcosa si romperà. /export è il modo stabile per ottenere una conversazione di Claude Code leggibile.

Variabili d’ambiente come CLAUDE_CODE_SKIP_PROMPT_HISTORY possono impedire la scrittura delle trascrizioni. Se la cartella dei progetti è vuota, verifica di non aver disattivato la persistenza, di non aver puntato CLAUDE_CONFIG_DIR altrove o di aver effettivamente avviato una sessione interattiva in quella cartella.

Esportare da Claude Code o Export data ufficiale di Anthropic?

L’esportazione di Claude Code (/export o JSONL) riguarda una sessione nel terminale. L’Export data ufficiale è Settings → Privacy → Export data su claude.ai (le etichette possono essere tradotte se claude.ai è impostato in italiano): uno ZIP in JSON dell’account Anthropic che arriva più tardi. Non sono lo stesso archivio. Lo ZIP non sostituisce /export.

Se una determinata sessione di Claude Code compaia nello ZIP dell’account dipende da come Anthropic memorizza quel prodotto, non da questa estensione. Considera lo ZIP un backup dell’account web, a meno che la documentazione aggiornata di Anthropic sulla privacy non dica altrimenti. Noi non aggiungiamo sessioni della CLI a quello ZIP.

Esportare da Claude Code, Desktop o claude.ai?

Claude Code, Claude Desktop e claude.ai sono tre ambienti diversi. L’esportazione di Claude Code usa /export e JSONL. Desktop è un’app senza il pulsante arancione di questa estensione. claude.ai in Chrome è l’unico posto in cui funziona Download Claude conversations, Claude Code on the web su claude.ai/code compreso. Confondere i nomi è il modo in cui le esportazioni falliscono senza avvisi.

Claude Desktop: se la chat è sincronizzata con lo stesso account Anthropic, aprila su claude.ai ed esportala da lì. Se esiste solo nella finestra di Desktop, usa il copia e incolla oppure aspetta l’Export data ufficiale. Guida: esportare una chat di Claude Desktop.

Il pannello di Claude Code in VS Code è più vicino alla CLI che a claude.ai. Non aspettarti che il nostro script si attivi in quella webview. Usa /export dalla sessione che contiene davvero i messaggi.

FAQ: esportare conversazione Claude Code

Come esporto una conversazione di Claude Code?

Nel terminale di Claude Code digita /export (eventualmente con un nome di file) per salvare una trascrizione leggibile, oppure copia il file JSONL da ~/.claude/projects su macOS/Linux o da %USERPROFILE%\.claude\projects su Windows. La documentazione di Anthropic sulle sessioni descrive la finestra attuale.

Questa estensione Chrome scarica le chat di Claude Code?

Non dal terminale. Download Claude conversations funziona solo su claude.ai in Chrome. Non può leggere le sessioni locali del terminale, le trascrizioni JSONL o il comando /export. Le sessioni di Claude Code on the web su claude.ai/code invece si esportano, come qualsiasi chat.

Posso esportare Claude Code on the web (claude.ai/code)?

Sì. Apri la sessione su claude.ai/code in Chrome e usa il pulsante arancione. PDF, Markdown, testo semplice, JSON, XML, CSV e PNG funzionano tutti. I sei formati diversi dal PDF sono illimitati e senza account; il PDF richiede l’accesso con Google e rientra nelle 3 esportazioni gratuite al giorno.

Dove salva Claude Code la cronologia delle conversazioni?

Le trascrizioni delle sessioni sono file JSONL sotto ~/.claude/projects/<encoded-working-directory>/, con l’ID di sessione come nome. La struttura esatta può cambiare. Usa /export quando vuoi un file leggibile invece di analizzare il JSONL. CLAUDE_CONFIG_DIR può spostare la cartella.

Come scaricare una conversazione di Claude Code in Markdown?

Il comando /export di Claude Code produce una trascrizione in testo semplice, non il Markdown di questa estensione. Se ti serve proprio il Markdown, esporta con Download Claude conversations una sessione di claude.ai/code o una copia del lavoro su claude.ai, oppure converti tu stesso il testo di /export. Noi non convertiamo il JSONL in Markdown.

Come scarico invece una conversazione di claude.ai?

Installa l’estensione Chrome gratuita, apri la chat su claude.ai e usa il pulsante arancione, oppure Export All per la cronologia. Vedi come scaricare una chat Claude. Markdown, testo, JSON, XML, CSV e PNG sono illimitati e senza account; PDF e ZIP in blocco sono gratuiti fino a 3 al giorno con accesso Google; Pro costa 3,99 $/mese o 26,99 $/anno.

/export è la stessa cosa dell’Export data ufficiale?

No. /export riguarda la sessione corrente di Claude Code. Settings → Privacy → Export data invia per email uno ZIP in JSON dell’account Anthropic. Ambienti diversi, file diversi, attese diverse.

Posso analizzare il JSONL di Claude Code con jq?

Sì, con l’avvertenza pubblicata da Anthropic: lo schema delle righe è interno e può cambiare. Quando ti serve un formato garantito, preferisci /export o claude -p --output-format json. Se analizzi comunque il JSONL, fissa la versione della CLI.

L’esportazione di Claude Code funziona su Windows?

Sì. /export è un comando della CLI. Le trascrizioni sul disco si trovano sotto %USERPROFILE%\.claude\projects, a meno che tu non imposti CLAUDE_CONFIG_DIR. Questa estensione Chrome comunque non funziona dentro quel terminale.

Claude Code è la stessa cosa di Claude Desktop?

No. Claude Code è l’agente di programmazione nel terminale. Claude Desktop è l’app di chat. claude.ai è il sito web. Solo il sito, claude.ai/code compreso, riceve questa estensione. Note sull’esportazione da Desktop: Claude Desktop.

Questa estensione integrerà mai /export?

Non nella versione 1.16.2. Il perimetro del prodotto è claude.ai, Claude Code on the web compreso: sette formati, file locali, accesso con Google solo per PDF, esportazione in blocco e Pro. Se il perimetro cambia, questa pagina lo dirà. Fino ad allora, per esportare da Claude Code nel terminale usa la CLI di Anthropic.

/export include gli output degli strumenti?

Anthropic descrive /export come messaggi e output degli strumenti resi come testo leggibile. È la loro trascrizione, non il nostro parser. Per sapere esattamente cosa contiene oggi, esegui /export sulla tua build e leggi il file: la documentazione può essere in ritardo rispetto a un rilascio.

Posso esportare in blocco le sessioni di Claude Code?

Non le sessioni locali della CLI. Export All nella Dashboard riguarda solo claude.ai. Per molte sessioni della CLI, copia la cartella dei progetti o esegui /export in ogni sessione. Non esiste un’esportazione in blocco del JSONL con il pulsante arancione.
