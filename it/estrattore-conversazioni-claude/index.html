Che cos’è un estrattore di conversazioni Claude?

Un estrattore di conversazioni Claude analizza la conversazione visualizzata su claude.ai e scrive un vero file. Download Claude conversations è questo strumento per Chrome: non è un programma per screenshot e non è lo ZIP dell’account di Anthropic. C’è chi scrive “estrarre”, chi “esportare” e chi “scaricare”, ma il pulsante arancione su claude.ai è lo stesso.

Sviluppatori e ricercatori cercano spesso un estrattore di conversazioni Claude perché “estrarre” fa pensare a una struttura: mittente, blocchi di contenuto, blocchi di codice, tabelle, artifact. Download Claude conversations fa questa analisi nella scheda che hai già aperto. Nelle recensioni può comparire Claude Conversation Downloader o Claude Exporter: sono sempre questa scheda, Download Claude conversations 1.16.2 sul Chrome Web Store.

L’estrattore non è un plugin di Claude Desktop né una CLI di Claude Code. Se cercavi la cronologia del terminale, usa /export — guida: esportare da Claude Code. Se cercavi l’app per Mac/Windows, vedi esportare una chat di Claude Desktop. Claude Code on the web (claude.ai/code) e le sessioni Cowork si estraggono, perché si aprono su claude.ai. Questa pagina riguarda solo claude.ai in Chrome.

Stesso pulsante, verbi diversi. “Estrarre chat Claude”, “esportare chat Claude” e “scaricare una chat Claude” portano tutti a Download Claude conversations; molti lo cercano anche in inglese, come “claude exporter”. La pagina dedicata al prodotto è esportare chat Claude. Questa guida si concentra su cosa legge l’estrattore e cosa tralascia.

Come estraggo una chat Claude su claude.ai?

Installa Download Claude conversations, apri l’URL della conversazione su claude.ai, clicca il pulsante arancione accanto alla casella dei messaggi, scegli un formato e clicca “Export”. L’estrattore di conversazioni Claude salva il file in locale tramite l’API di download di Chrome. Per Markdown, testo, JSON, XML, CSV o PNG non serve alcun account; l’accesso con Google compare solo per il PDF e l’esportazione in blocco.

  1. Aggiungi la scheda del Chrome Web Store (Download Claude conversations, versione 1.16.2 a settembre 2026).
  2. Ricarica claude.ai e apri la conversazione: all’estrattore serve l’URL di una conversazione, non la home con la casella vuota.
  3. Clicca il pulsante rotondo arancione a destra della casella dei messaggi.
  4. Imposta Messages su “All”, “Human” o “Assistant” (tutti, solo tuoi, solo di Claude), spunta “Thinking” (ragionamento) se ti serve, oppure usa “Select” (Seleziona) per spuntare singoli messaggi. Scegli PDF, Markdown, JSON, testo semplice, XML, CSV o PNG.
  5. Clicca “Export”, oppure “Copy” (Copia) per mettere Markdown, testo, JSON, XML o CSV negli appunti. L’estrattore di conversazioni Claude non carica il contenuto della chat sui nostri server.

Se il pulsante arancione non c’è, fissa l’estensione, aggiorna la scheda e verifica che l’URL sia quello di una chat vera. L’estrattore di conversazioni Claude si attiva solo su claude.ai. Non compare in Claude Desktop, nel terminale di Claude Code né su altri siti. I file incompleti di solito significano che la conversazione lunga non era ancora completamente caricata: scorri o aspetta, poi estrai di nuovo.

L’estrattore ricorda l’ultimo formato usato. Se volevi Markdown e hai ottenuto JSON, apri il menu dei formati prima di “Export”. Scegliere PDF richiede l’accesso con Google. Dopo 3 esportazioni PDF o in blocco nello stesso giorno, il piano gratuito mostra l’invito a Pro a 3,99 $ al mese o 26,99 $ all’anno: è normale, non un errore di estrazione. Il conteggio si azzera a mezzanotte UTC.

Che cosa estrae un estrattore di conversazioni Claude?

L’estrattore di conversazioni Claude legge l’albero dei messaggi che claude.ai ha già disegnato: turni dell’utente e dell’assistente, blocchi di codice con il linguaggio indicato, tabelle, link e ragionamento facoltativo. La disposizione degli artifact è “Original”, “Inline”, “Nested” o “Flat” (originale, in linea, annidata, piatta). Il copia e incolla dalla stessa pagina perde questa struttura; l’estrattore la conserva in Markdown, JSON e XML.

Il ragionamento è una casella. Attivala quando ti serve nel file il ragionamento visibile di Claude; lasciala spenta quando vuoi solo la risposta finale. I metadati possono includere titoli, orari e modello. Il filtro Messages (“All”, “Human”, “Assistant”), “Thinking” e “Select” si trovano nel pannello di esportazione accanto al formato; passaggi tool / MCP e fonti della ricerca web si attivano nelle impostazioni. Elenco delle funzioni: funzionalità.

L’estrattore legge la conversazione che la pagina ha già visualizzato nella tua scheda claude.ai. Blocchi di codice, tabelle e disposizioni degli artifact (“Original”, “Inline”, “Nested”, “Flat”) vengono analizzati lì, poi il file viene generato in locale — PDF compreso.

L’esportazione offline funziona solo dopo che la pagina è stata caricata; in ogni caso non c’è alcun passaggio da un server per generare il file.

In quali formati scrive l’estrattore di chat Claude?

Sette: PDF, Markdown, JSON, testo semplice, XML, CSV e PNG — gli stessi sette sia che tu estragga una sola chat Claude, sia che esegua Export All. Download Claude conversations non aggiunge Word, Notion o Google Docs nella versione 1.16.2. È il formato a decidere il limite: sei formati sono illimitati e senza account, mentre ogni PDF consuma una delle 3 esportazioni giornaliere del piano gratuito.

Posso estrarre le conversazioni Claude in blocco?

Sì. Apri il popup dell’estensione → “View and Download All Conversations” (visualizza e scarica tutte le conversazioni), applica i filtri e clicca Export All. L’estrattore di conversazioni Claude scrive un unico ZIP con un file per ogni chat selezionata, nel formato scelto. L’esportazione in blocco chiede l’accesso con Google. Nel piano gratuito ogni chat nello ZIP consuma una delle 3 esportazioni giornaliere, condivise con il PDF, a meno che l’account non sia Pro a 3,99 $ al mese o 26,99 $ all’anno.

Filtri nella Dashboard: All conversations, New, Updated e Previously exported (tutte, nuove, aggiornate, già esportate), più le schede Chat e Cowork e la ricerca per progetto. New indica che l’estrattore non ha ancora salvato quella chat. Previously exported segna la cronologia già estratta, così un’esportazione in blocco successiva può saltarla. La ricerca per progetto rispecchia i progetti di claude.ai. La ricerca per nome trova le conversazioni prima di avviare Export All.

L’esportazione in blocco non è un’estrazione ridotta. Le caselle della Dashboard — “Chats”, “Thinking”, “Metadata”, “Tools”, “Sources” (chat, ragionamento, metadati, strumenti, fonti) — insieme alla disposizione degli artifact decidono cosa entra in ogni file, e il selettore “Chat format” offre tutti e sette i formati, PDF compreso. Procedura con gli avvisi sulla quota: esportazione in blocco con Export All. Se volevi un unico ZIP dell’intero account via email, quello è Settings → Privacy → Export data (le etichette possono essere tradotte se claude.ai è impostato in italiano), non questo estrattore.

L’esportazione in blocco conta ogni chat. Nel piano gratuito Export All condivide con il PDF 3 esportazioni al giorno, e ogni chat nello ZIP ne consuma una. Se selezioni 25 chat e te ne restano 3, l’intero lotto viene bloccato, non troncato. Usa il filtro New per sceglierne meno, aspetta l’azzeramento a mezzanotte UTC oppure passa a Pro (3,99 $ al mese o 26,99 $ all’anno) prima di un’estrazione di grandi dimensioni.

Estrattore di conversazioni Claude o copia e incolla?

Il copia e incolla va bene per una breve risposta di Claude e fallisce con codice e tabelle. Export data di Anthropic è lo ZIP di backup dell’account. L’estrattore di conversazioni Claude sta nel mezzo: questa conversazione o una selezione in blocco, in un file strutturato, subito, su claude.ai in Chrome.

Un estrattore di conversazioni Claude è sicuro?

Questo estrattore di conversazioni Claude usa la tua sessione claude.ai esistente, come fa il sito stesso. Non automatizza l’account e non invia il contenuto delle chat alla nostra API. L’accesso con Google viene chiesto solo per PDF, esportazione in blocco e Pro, per contare il limite giornaliero e ripristinare Pro. Il pagamento è gestito da Paddle. Non siamo Anthropic; i suoi Termini restano validi.

Dopo l’accesso per PDF, esportazione in blocco o Pro, un Cloudflare Worker vede la tua email Google, il conteggio di PDF ed esportazioni in blocco di oggi e se hai Pro o no. Le esportazioni della singola chat in Markdown, JSON, testo, XML, CSV e PNG non gli inviano nulla, e il worker non riceve mai un file estratto, PDF compreso. I file non lasciano mai il browser, se non verso la cartella dei download di Chrome. Il confine completo: come funziona. Chi si chiede se un estrattore di chat Claude sia sicuro dovrebbe guardare questa divisione: fatturazione sul worker, chat nella scheda.

Non possiamo promettere “zero rete”: claude.ai, Google e il worker esistono. Possiamo dire che il contenuto delle chat non viene caricato da noi. Rispetta i Termini di servizio di Anthropic. Download Claude conversations è un’estensione Chrome indipendente, non un prodotto ufficiale di Anthropic. L’email di supporto è nel piè di pagina del sito.

Browser mobili e Claude Desktop non sono supportati. Un estrattore di conversazioni Claude che è uno script di Chrome non può funzionare lì. Che cos’è un estrattore di conversazioni Claude?

Estrarre una chat Claude è diverso da esportarla?

No: stesso lavoro, verbo diverso. Estrarre, esportare e scaricare portano allo stesso pulsante arancione e agli stessi sette formati su claude.ai. Questa pagina mette in evidenza cosa conserva l’analisi.

Posso estrarre una chat Claude senza installare nulla?

Solo con il copia e incolla, che perde blocchi di codice e tabelle, oppure con Export data di Anthropic, che è uno ZIP dell’account. Un estrattore strutturato deve leggere la pagina: è l’estensione Chrome.

L’estrattore supporta l’estrazione in blocco delle conversazioni?

Sì. Apri “View and Download All Conversations” dal popup dell’estensione, poi Export All per ottenere uno ZIP. L’estrattore di conversazioni Claude funziona in Desktop?

No. Claude Desktop non riceve mai il pulsante arancione. Apri la stessa chat su claude.ai se è sincronizzata, oppure usa copia e incolla o lo ZIP ufficiale. L’estrattore funziona solo in Chrome su claude.ai.

Un estrattore di conversazioni Claude può creare un PDF?

Sì. Scegli PDF nel pannello di esportazione e clicca “Export”. Il PDF viene generato nel browser, senza finestra di stampa. Richiede l’accesso con Google ed è gratuito fino a 3 al giorno; con Pro è illimitato.

Estrarre una chat Claude funziona in Claude Code?

Solo sul web. Le sessioni di Claude Code su claude.ai/code si aprono su claude.ai e si estraggono come qualsiasi chat. Claude Code nel terminale usa /export o i file JSONL sul disco; questo estrattore è uno script di Chrome per claude.ai, non un aggancio al terminale.

Quante estrazioni gratuite consente l’estrattore?

Illimitate in Markdown, testo, JSON, XML, CSV e PNG, senza account. PDF ed Export All condividono 3 esportazioni al giorno per account Google nel piano gratuito, con azzeramento a mezzanotte UTC. Pro elimina il limite e si ripristina dallo stesso account Google, con fatturazione tramite Paddle.

Che cosa tralascia l’estrattore di conversazioni Claude?

L’interfaccia della pagina, la casella di scrittura e tutto ciò che non è visualizzato nella conversazione. Tralascia anche le chat mai caricate in Chrome. Le conversazioni presenti solo in Claude Desktop e i file JSONL locali di Claude Code sono esclusi.
