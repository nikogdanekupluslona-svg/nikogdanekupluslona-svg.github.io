Perché qui non posso esportare una chat di Claude Desktop?

Download Claude conversations è uno script di contenuto di Chrome per claude.ai. Claude Desktop è un’app autonoma per Mac e Windows. In quella finestra non c’è la barra delle estensioni, quindi il pulsante arancione non compare mai. Installare l’estensione dal Chrome Web Store mentre Desktop è aperto non cambia nulla in Desktop.

Le estensioni Chrome agiscono solo sulle pagine previste dai loro permessi. Questa estensione riguarda le pagine di conversazione di claude.ai. Claude Desktop non è una scheda di claude.ai. Non puoi fare “Aggiungi a Chrome” dentro l’app Desktop. La versione 1.16.2 (settembre 2026) non ha ancora un plugin per Desktop, né un’utility nella barra dei menu, né un lettore di file per la cartella di installazione di Desktop.

Limite invalicabile. Non puoi esportare una chat di Claude Desktop con questa estensione Chrome dall’interno di Desktop. Se ti servono PDF, Markdown, JSON, testo, XML, CSV o PNG dal nostro pulsante, esci da Desktop, apri https://claude.ai in Chrome e apri lì la conversazione.

Si cerca “esportare chat Claude Desktop” — o, in inglese, “export Claude Desktop chat” — perché i prodotti condividono lo stesso marchio. I risultati di ricerca mescolano Desktop, claude.ai e Claude Code. I file non sono intercambiabili. Uno screenshot di Desktop non è un’esportazione in Markdown. Un log JSONL di Code non è una conversazione di claude.ai. Questa pagina esiste per rendere esplicita la differenza.

Come esporto una chat di Claude Desktop passando da claude.ai?

Molte sessioni di Desktop usano lo stesso account Claude del web. Se la conversazione è nella tua cronologia di claude.ai, aprila in Chrome e usa Download Claude conversations. È l’unico modo in cui questa estensione ti aiuta a esportare una chat di Claude Desktop: la chat deve prima caricarsi su claude.ai.

  1. Smetti di cercare in Desktop. Apri https://claude.ai in Chrome e accedi con lo stesso account.
  2. Trova la conversazione nella cronologia web. Se manca, passa al copia e incolla o a Export data — non possiamo recuperare una chat che Chrome non ha mai caricato.
  3. Clicca il pulsante arancione. Scegli PDF, Markdown, testo semplice, JSON, XML, CSV o PNG. Clicca “Export” (Esporta).
  4. Per molte conversazioni sincronizzate, apri “View and Download All Conversations” (visualizza e scarica tutte le conversazioni) ed esegui “Export All”. La Dashboard ha le schede Chat e Cowork. Nel piano gratuito ogni chat nello ZIP conta per il limite di 3 al giorno.
  5. Se ti serve un PDF, scegli PDF nello stesso pannello — il file viene generato nel browser, senza finestra di stampa. Guida: salvare una chat Claude in PDF.

Le esportazioni sul web in Markdown, testo, JSON, XML, CSV e PNG sono illimitate e non richiedono account. L’accesso con Google compare solo per PDF e ZIP in blocco, che condividono 3 esportazioni gratuite al giorno (azzerate a mezzanotte UTC), e per ripristinare Pro a 3,99 $ al mese o 26,99 $ all’anno. Quel limite riguarda solo i file di claude.ai. Il copia e incolla da Desktop non consuma il nostro limite, perché non passa mai per l’estensione. Pro è fatturato da Paddle; non vediamo mai i numeri di carta.

La sincronizzazione dipende da Anthropic, non da noi. Se Desktop mostra una chat che su claude.ai non c’è, questa estensione Chrome non può inventarla. Aspetta, ricarica claude.ai oppure usa il copia e incolla o lo ZIP ufficiale. Non leggiamo il database locale di Desktop. Come funziona l’esportazione web quando la scheda esiste: come funziona.

I formati una volta arrivato su claude.ai. PDF per condividere o stampare, Markdown per gli appunti, JSON per gli strumenti, testo per un archivio essenziale, XML per lo scambio di dati, CSV per un foglio di calcolo, PNG per un’immagine. Posso esportare una chat di Claude Desktop con il copia e incolla?

Sì. Seleziona il testo in Claude Desktop e incollalo in un documento. È il ripiego onesto quando la conversazione non compare su claude.ai. Perdi la fedeltà dei blocchi di codice, la disposizione degli artifact, le opzioni per il ragionamento e l’esportazione in blocco con “Export All”. Va bene per una risposta breve; è faticoso per una lunga conversazione di programmazione.

Proprio i limiti del copia e incolla spiegano perché l’estensione Chrome esiste su claude.ai: il pulsante web conserva le etichette del linguaggio, le tabelle e gli artifact nelle disposizioni “Original”, “Inline”, “Nested” e “Flat” (originale, in linea, annidata, piatta). In Desktop non offriamo nessuno di questi controlli di esportazione. Se puoi aprire la stessa conversazione su claude.ai, smetti di copiare e incollare e usa lì Download Claude conversations.

Gli screenshot di Claude Desktop sono un altro ripiego. Sono immagini, non Markdown. Non valgono come esportazione di una chat di Claude Desktop nel senso di un file riutilizzabile. Anche il PNG della nostra estensione è un’immagine, ma viene generato solo dopo che la chat è aperta su claude.ai. Non aspettarti quel PNG dalla finestra di Desktop.

Se una conversazione di Desktop è salvata in quell’account, può comparire. Considera lo ZIP un backup, non un Markdown generato da questa estensione.

Lo ZIP arriva lentamente, il link scade e non c’è un selettore di formato per PDF, Markdown, testo, XML, CSV o PNG. Se per “desktop” intendevi VS Code o un terminale sul computer, segui esportare da Claude Code. Se intendevi l’app di chat Desktop di Anthropic, resta su questa pagina. Confondere le due cose fa perdere tempo: un JSONL su disco non è un pulsante arancione, e il copia e incolla da Desktop non è /export.
