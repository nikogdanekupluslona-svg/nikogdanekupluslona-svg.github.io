Come esporto una chat Claude da claude.ai?

Apri la conversazione su claude.ai in Chrome, clicca il pulsante arancione accanto alla casella dei messaggi, scegli PDF, Markdown, JSON, testo semplice, XML, CSV o PNG e poi clicca “Export”. Download Claude conversations salva il file in locale. A settembre 2026 claude.ai non ha un comando nativo per esportare la singola chat.

  1. Installa Download Claude conversations dal Chrome Web Store.
  2. Ricarica claude.ai e apri l’URL di una conversazione vera, non la home con la casella vuota.
  3. Clicca il pulsante rotondo arancione di download a destra della casella dei messaggi.
  4. Nel pannello imposta Messages su “All”, “Human” o “Assistant” (tutti, solo tuoi, solo di Claude), poi scegli un formato. Spunta “Thinking” (ragionamento) per includere l’extended thinking, oppure usa “Select” (Seleziona) per spuntare singoli messaggi. L’estensione ricorda l’ultimo formato usato.
  5. Clicca “Export”. Chrome salva subito il file tramite l’API di download del browser. “Copy” (Copia) mette invece Markdown, testo, JSON, XML o CSV negli appunti.

Per esportare una chat Claude in Markdown, testo, JSON, XML, CSV o PNG non serve alcun account. Queste esportazioni della singola chat sono illimitate e l’estensione non invia nulla ai nostri server. L’accesso con Google compare solo quando scegli PDF o avvii l’esportazione in blocco con Export All: il piano gratuito ne consente 3 al giorno in totale, con azzeramento a mezzanotte UTC. Fissa Download Claude conversations e aggiorna claude.ai. L’estensione si attiva solo su claude.ai, mai su altri siti.

Che cosa fa davvero un’estensione per esportare Claude?

Un’estensione per esportare Claude legge la conversazione già visualizzata nella tua scheda claude.ai, dove hai effettuato l’accesso, e scrive un file strutturato sul disco. Download Claude conversations è proprio questo script di Chrome: mittente, albero dei messaggi, blocchi di codice, tabelle, ragionamento facoltativo e disposizione degli artifact — non uno screenshot dell’interfaccia intorno alla chat. Funziona con chat normali, Projects, sessioni Cowork e Claude Code on the web.

Il copia e incolla da claude.ai perde il rientro e appiattisce le tabelle. La stampa (Ctrl/Cmd+P) mantiene la barra laterale e spesso spezza un lungo blocco di codice su più pagine. L’estensione conserva il linguaggio dei blocchi di codice e lascia le tabelle come tabelle in Markdown, JSON e XML. PNG è l’opzione dell’istantanea visiva. PDF è quella impaginata, generata nel browser senza finestra di stampa.

La disposizione degli artifact è una vera opzione nella versione 1.16.2: “Original”, “Inline”, “Nested” o “Flat” (originale, in linea, annidata, piatta), da impostare nella Dashboard. L’extended thinking è una casella nel pannello di esportazione; fonti della ricerca web e passaggi tool / MCP si attivano nelle impostazioni. I metadati (titolo, orari, modello) possono essere inclusi. Il filtro Messages limita il file a tutti i messaggi, solo ai tuoi o solo a quelli dell’assistente, e “Select” spunta singoli messaggi. Elenco completo: funzionalità.

Abbiamo creato il pulsante arancione per scrivere un vero file a partire dalla chat già aperta su claude.ai — PDF, Markdown, JSON, testo, XML, CSV o PNG — senza caricare la conversazione sui nostri server. Dalla versione 1.16.2 anche il PDF viene generato nel browser.

Posso esportare le chat Claude in blocco con Export All?

Sì. Apri il popup dell’estensione → “View and Download All Conversations”, filtra la tabella e clicca Export All per ottenere uno ZIP. L’esportazione in blocco chiede l’accesso con Google. Nel piano gratuito condivide con il PDF il limite di 3 al giorno, e ogni conversazione nello ZIP ne consuma una. Pro elimina il limite per tutta la cronologia.

La Dashboard elenca la cronologia di claude.ai con ricerca per nome, filtri (All conversations, New, Updated, Previously exported — tutte, nuove, aggiornate, già esportate), schede Chat e Cowork e ricerca per progetto. New indica le chat non ancora esportate con Download Claude conversations. Previously exported tiene traccia delle chat già salvate, così un secondo Export All può saltarle. La ricerca per progetto rispecchia il modo in cui raggruppi le chat su claude.ai.

L’esportazione in blocco ha un selettore “Chat format” con tutti e sette i formati, PDF compreso, le caselle “Chats”, “Thinking”, “Metadata”, “Tools” e “Sources” (chat, ragionamento, metadati, strumenti, fonti) e la disposizione degli artifact (“Original”, “Inline”, “Nested”, “Flat”). Export All non è un archivio ridotto: è un unico ZIP con un file per chat nel formato scelto. L’esportazione in blocco conta ogni chat. Nel piano gratuito Export All e PDF condividono 3 esportazioni al giorno, e ogni conversazione nello ZIP ne consuma una. L’esportazione funziona su Desktop o in Claude Code?

Non nell’app Desktop né nel terminale di Claude Code. Questa estensione funziona solo su claude.ai dentro Chrome (o un altro browser Chromium che installa dal Chrome Web Store). Claude Desktop è un’app separata per Mac/Windows e il pulsante arancione non compare mai lì né in un terminale. Claude Code on the web (claude.ai/code) è l’eccezione: quelle sessioni si aprono su claude.ai e si esportano come qualsiasi chat.

Se la conversazione esiste anche nel tuo account claude.ai, aprila in Chrome ed esporta lì la chat Claude con Download Claude conversations. Se la chat esiste solo in Desktop, copia e incolla dall’app oppure richiedi Settings → Privacy → Export data sul web. Confronto passo passo: esportare una chat di Claude Desktop.

Claude Code nel terminale usa /export o le trascrizioni JSONL sul disco. Questa estensione Chrome non legge quelle sessioni locali. Non installare Download Claude conversations aspettandoti un aggancio al terminale. Guida: esportare da Claude Code. Se cerchi come esportare una chat Claude per una sessione da riga di comando, la strada è un’altra.

Anche claude.ai nel browser del telefono è escluso. L’estensione richiede Chrome su desktop. Nel 2026 questo team non offre app per iOS o Android. Apri la conversazione su un computer, poi esporta la chat Claude dal pulsante arancione o con Export All.

FAQ: come esportare chat Claude

Queste domande riguardano l’esportazione delle chat Claude e l’estensione: formati, limiti, Desktop, Claude Code, lo ZIP di Anthropic e la posizione del pulsante arancione. Ogni risposta si basa sulla versione 1.16.2. Il JSON-LD FAQPage nell’intestazione della pagina corrisponde a questo elenco.

Che cosa significa esportare chat Claude su questo sito?

Salvare una conversazione di claude.ai come file con Download Claude conversations: pulsante arancione, scelta del formato, “Export”. È ciò che molti cercano come “esportare chat Claude” o, in inglese, “claude export chat”. Non è lo ZIP inviato per email da Anthropic e non è /export di Claude Code.

Un’estensione per esportare Claude è la stessa cosa di Export data?

No. Settings → Privacy → Export data è uno ZIP in JSON dell’intero account, inviato per email. L’estensione salva subito in Chrome la chat aperta in PDF, Markdown, JSON, testo, XML, CSV o PNG, oppure una selezione di Export All come ZIP.

Posso esportare una chat Claude in PDF?

Sì. Scegli PDF nell’elenco dei formati e clicca “Export”. L’estensione genera il PDF nel browser, senza finestra di stampa. Il PDF chiede l’accesso con Google ed è gratuito fino a 3 al giorno; con Pro è illimitato. Guida: salvare una chat Claude in PDF.

Mi serve Pro per esportare una chat Claude una volta?

No. Le esportazioni in Markdown, testo, JSON, XML, CSV e PNG sono gratuite e illimitate, senza account. PDF ed Export All sono gratuiti fino a 3 al giorno con accesso Google. Pro a 3,99 $ al mese o 26,99 $ all’anno elimina il limite.

Esportare chat Claude funziona con qualsiasi piano claude.ai?

Sì. I piani claude.ai Free, Pro, Team o Enterprise funzionano tutti, purché tu possa aprire la conversazione in Chrome. L’estensione non richiede il piano a pagamento di Anthropic.

Questa estensione per esportare Claude funziona con Claude Code?

Solo con Claude Code on the web. Le sessioni su claude.ai/code si aprono su claude.ai e si esportano come qualsiasi chat. Claude Code nel terminale usa /export o i file JSONL sul disco, e Download Claude conversations non li legge. Consulta la guida all’esportazione da Claude Code.

Posso esportare una chat Claude da Claude Desktop?

Non con questa estensione Chrome. Apri la stessa conversazione su claude.ai se è sincronizzata, oppure copia e incolla o usa l’Export data ufficiale. Desktop non mostra mai il pulsante arancione.

Quante esportazioni gratuite offre l’estensione?

Illimitate per Markdown, testo, JSON, XML, CSV e PNG, senza account. Dov’è il pulsante arancione per esportare la chat Claude?

A destra della casella dei messaggi, sull’URL di una conversazione di claude.ai, dopo aver installato Download Claude conversations e ricaricato la pagina. Non compare sulla home con la casella vuota né in Desktop.

Dopo l’accesso per PDF, esportazione in blocco o Pro, il nostro server vede solo lo stato della quota o dell’abbonamento e la tua email Google, mai il contenuto delle chat.
