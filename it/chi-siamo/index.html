Chi siamo

Download Claude conversations è un’estensione Chrome indipendente (nome del sito: Chat Downloader). Motori di ricerca e utenti la chiamano anche Claude Chat Downloader e Claude Conversation Downloader. Non è sviluppata, affiliata né approvata da Anthropic, PBC — Claude è un marchio di Anthropic. L’abbiamo creata per colmare una lacuna di claude.ai: non esiste un modo integrato per scaricare una singola conversazione come file.

L’estensione aggiunge a claude.ai un pulsante di esportazione e una Dashboard per le esportazioni in blocco, e scrive file PDF, Markdown, testo semplice, JSON, XML, CSV o PNG in locale, nel tuo browser. Le esportazioni della singola chat in Markdown, testo, JSON, XML, CSV e PNG sono illimitate e non richiedono alcun account. PDF e ZIP in blocco chiedono l’accesso con Google e sono gratuiti fino a 3 al giorno; Pro (3,99 $ al mese o 26,99 $ all’anno) elimina questo limite. Funziona con chat normali, Projects, sessioni Cowork e Claude Code on the web (claude.ai/code). Tutti i dettagli in come funziona. Non esporta le sessioni di Claude Code nel terminale.

Scheda del Chrome Web Store (da tenere allineata)

Usa questo testo nel Chrome Web Store, così l’anteprima dello Store corrisponde a ciò che le persone cercano:

  • Nome (≤ 75 caratteri): Claude Chat Downloader
  • Descrizione breve (≤ 132 caratteri): Free Chrome extension to save claude.ai chats as PDF, Markdown, text, JSON, XML, CSV or PNG — one chat or bulk Export All.

Mantieni l’ID esistente ljcgfcnobiealkonbknnfckhkdbodhak. Un cambio di nome nello Store può richiedere un ciclo di revisione; i titoli del sito corrispondono già alla query di ricerca.
