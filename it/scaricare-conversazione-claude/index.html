Come scarico una conversazione Claude in Chrome?

Su claude.ai si usa il pulsante arancione che Download Claude conversations aggiunge accanto alla casella dei messaggi. Apri la conversazione, scegli PDF, Markdown, JSON, testo, XML, CSV o PNG, poi fai clic su «Export». Chrome salva un file locale. Quel file è una conversazione, non uno ZIP dell’account.

Download Claude conversations è uno script di contenuto di Chrome. Legge la conversazione già caricata nella tua sessione di claude.ai, con il tuo accesso. Non chiama un’API separata di Anthropic con credenziali proprie e non carica la conversazione sui nostri server per generare alcun formato, PDF compreso.

  1. Installa Download Claude conversations dal Chrome Web Store (funzionano anche i browser Chromium che caricano le estensioni di Chrome).
  2. Ricarica claude.ai se la pagina era già aperta durante l’installazione. Chrome non si inserisce in una scheda vecchia.
  3. Apri l’URL della conversazione che ti serve: il pulsante arancione compare solo in una conversazione vera, non nella pagina iniziale con la casella vuota.

Scaricare la conversazione o usare Export data?

Scaricare una conversazione Claude con il pulsante arancione dà un file con il suo nome per la conversazione aperta su claude.ai, subito, in locale, PDF compreso. La stampa è un PDF visivo della pagina web. Il copia e incolla è testo senza struttura. Scegli la riga che corrisponde al tuo obiettivo.

Export data ufficiale è un backup di tutto l’account Anthropic, non il download di una singola conversazione. Anthropic ti invia per email un link che scade. Lo ZIP mescola le chat che avevi dimenticato con quelle che volevi tenere. Poi devi estrarre tu il JSON se ti serve una conversazione tra migliaia. Non è il percorso del pulsante arancione.

Con la stampa: apri la conversazione su claude.ai, nascondi la barra laterale se l’interfaccia lo consente, premi Ctrl+P (Windows/Linux) o Cmd+P (Mac), imposta la destinazione su «Salva come PDF» e salva. I blocchi di codice spesso si spezzano tra una pagina e l’altra. Gli elementi dell’interfaccia intorno alla casella di scrittura possono comparire su ogni foglio. La stampa è un’istantanea dello schermo, non Markdown. L’esportazione PDF dell’estensione salta questa finestra: chat Claude in PDF.

Il copia e incolla è un terzo metodo senza estensione. Selezioni il testo su claude.ai e lo incolli in Docs o in un’app per appunti. L’indentazione del codice di solito si perde. Le tabelle diventano righe continue. Una conversazione a più turni diventa un muro di testo senza struttura. Va bene per una risposta breve. In quale formato scaricare una conversazione Claude?

Per scegliere il formato: apri il pulsante arancione, scegli PDF, Markdown, JSON, testo, XML, CSV o PNG, poi «Export». Markdown è il file per gli appunti. JSON è l’albero dei messaggi per gli script. Il testo semplice non ha markup. XML serve per lo scambio di dati. CSV è una riga per messaggio. PDF è un documento impaginato. PNG è un’immagine.

Markdown mantiene titoli, blocchi di codice delimitati con il tag del linguaggio e tabelle. È la scelta abituale per Obsidian, GitHub o un wiki. JSON conserva l’albero che il parser ha già costruito, compresi artifact e ragionamento quando quelle opzioni sono attive. Non ha la stessa struttura dello ZIP dell’account di Anthropic. Note sui formati: tutti i formati.

Il testo semplice è la scelta giusta quando la destinazione elimina comunque il markup: un campo di un sistema di ticket, il corpo di un’email, un indice di ricerca che vuole stringhe grezze. XML è la scelta di nicchia per lo scambio di dati. CSV si apre in Excel, Google Sheets o Numbers. PNG serve per una slide o per lo screenshot della conversazione in una segnalazione di bug, non per una revisione di design di 40 turni in cui vorrai cercare con grep.

Posso scaricare una conversazione Claude da Desktop?

No. Claude Desktop non ti permette di scaricare una conversazione Claude con questa estensione. Download Claude conversations si inserisce solo su claude.ai in Chrome. Un terminale locale di Claude Code è un altro ambiente; Claude Code sul web, su claude.ai/code, invece si esporta. Apri la stessa conversazione su claude.ai, se esiste lì, poi usa il pulsante arancione.

Claude Desktop è una finestra separata. Lo script di contenuto di Chrome non si inserisce mai in quell’app. Se la stessa chat esiste su claude.ai, aprila lì e scaricala. Se esiste solo in Desktop, usa il copia e incolla o aspetta lo ZIP dell’account da Settings → Privacy → Export data.

Claude Code in locale vive nel terminale. In una sessione attiva, digita /export. La CLI di Anthropic apre un menu per copiare la trascrizione o salvarla in un file di testo semplice. Passa un nome di file per saltare il menu. Quella trascrizione è testo da leggere per una persona, non il Markdown, il JSON o il PDF di questa estensione. Percorsi: esportare da Claude Code.

Il JSONL sul disco è il log interno. Lo schema può cambiare da una versione di Claude Code all’altra. La documentazione di Anthropic stessa consiglia di preferire /export o le interfacce per script rispetto all’analisi del JSONL. Non integriamo quella CLI. Non leggiamo ~/.claude. Percorso su Windows: %USERPROFILE%\.claude\projects.

Claude Code sul web è l’eccezione. Le sessioni su claude.ai/code si aprono in Chrome, quindi Download Claude conversations le esporta come qualsiasi conversazione. Se tieni una conversazione parallela su claude.ai per lo stesso lavoro, scarica quella conversazione del browser con il pulsante arancione. Il log del terminale e la chat web non sono automaticamente lo stesso documento. Trattali come due registri distinti, a meno che tu non abbia incollato l’uno nell’altro.

Come scarico una conversazione Claude da claude.ai?

Installa Download Claude conversations, apri la conversazione su claude.ai, fai clic sul pulsante arancione a destra della casella dei messaggi, scegli PDF, Markdown, JSON, testo, XML, CSV o PNG, poi fai clic su «Export». Chrome salva un file locale. Quel file è una conversazione. Non serve alcun account, tranne per il PDF, che chiede l’accesso con Google.

«Scaricare conversazione Claude» porta alla scheda del Chrome Web Store?

Il titolo sul Chrome Web Store è Download Claude conversations, al plurale, perché «Export All» crea molti file. Ricerche come «scaricare conversazione Claude», «scaricare chat Claude» o, in inglese, «download claude conversation» portano tutte alla stessa scheda. Un’esportazione con il pulsante arancione resta una conversazione, un file.

Posso scaricare una conversazione Claude senza estensione?

Sì. Stampa la pagina di claude.ai (Ctrl/Cmd+P → Salva come PDF) per un’istantanea visiva, oppure usa Settings → Privacy → Export data per uno ZIP JSON dell’account, che arriva più tardi. Il copia e incolla va bene per una risposta breve. Nessuno di questi metodi crea un file Markdown strutturato per singola conversazione come fa l’estensione di Chrome.

Un file corrisponde a una conversazione scaricata?

Sì. Il pulsante arancione crea un file per la conversazione aperta su claude.ai. «Export All» crea un ZIP con un file per ogni riga selezionata. Lo ZIP di Export data di Anthropic ha la forma opposta: un archivio per tutto l’account, inviato più tardi per email, non un file con il nome della conversazione che stavi leggendo.

Posso scaricare una conversazione Claude in PDF?

Sì. Scegli PDF nel pannello del pulsante arancione e fai clic su «Export». La versione 1.16.2 crea il PDF nel browser senza finestra di stampa; imposti formato pagina, margini, modalità chiara o scura, carattere, numeri di pagina e indice. Il PDF richiede l’accesso con Google ed è gratuito fino a 3 al giorno; Pro è illimitato. Guida: chat Claude in PDF.

Serve l’accesso con Google per scaricare una conversazione Claude?

Solo per il PDF e per «Export All» in blocco. Markdown, testo semplice, JSON, XML, CSV e PNG non richiedono alcun account. Per PDF e blocco, Google verifica quale account hai scelto, così possiamo applicare il limite di 3 al giorno e ripristinare Pro dopo una reinstallazione. Il contenuto delle conversazioni non viene inviato con l’accesso. Conserviamo l’email verificata solo per la quota e lo stato Pro.

Si può scaricare la conversazione da Claude Desktop?

No. Download Claude conversations si inserisce solo su claude.ai in Chrome sul computer. Claude Desktop non mostra mai il pulsante arancione. Apri la stessa conversazione su claude.ai se è sincronizzata, oppure usa il copia e incolla o Export data ufficiale. Non esiste un’app per iOS o Android.

Quanti file gratuiti posso scaricare?

Illimitati per Markdown, testo semplice, JSON, XML, CSV e PNG, senza account. PDF e ZIP in blocco condividono 3 al giorno con il piano gratuito, con l’accesso con Google; ogni conversazione in uno ZIP in blocco conta come una e il giorno si azzera a mezzanotte UTC. Pro costa 3,99 $ al mese o 26,99 $ all’anno ed elimina il limite. Il pagamento è gestito da Paddle.

Scarica anche le conversazioni di Claude Code?

Solo sul web. Le sessioni di Claude Code su claude.ai/code si esportano come qualsiasi conversazione di claude.ai. Le sessioni locali del terminale no: usa /export o copia il JSONL da ~/.claude/projects (Windows: %USERPROFILE%\.claude\projects). Questa estensione di Chrome funziona solo su claude.ai. Guida: esportare da Claude Code.

In quali formati posso scaricare una conversazione Claude?

Sette: PDF, Markdown, JSON, testo semplice, XML, CSV e PNG, nell’estensione 1.16.2. Il PDF viene creato nel browser senza finestra di stampa. CSV è una riga per messaggio. PNG è un’immagine della conversazione. Panoramica dei formati: formati.
