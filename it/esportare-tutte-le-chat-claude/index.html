Esportare tutte le chat Claude: l’intera cronologia in blocco

Per esportare tutte le chat Claude da claude.ai, apri “View and Download All Conversations” (visualizza e scarica tutte le conversazioni), filtra e poi clicca “Export All” (Esporta tutto). Download Claude conversations crea in locale un unico ZIP con un file per ogni chat. Il piano gratuito copre 3 chat al giorno con l’accesso con Google; per l’intera cronologia serve Pro (3,99 $ al mese o 26,99 $ all’anno). Non si tratta di Claude Desktop, di Claude Code nel terminale né dello ZIP che Anthropic invia via email.

Come esporto l’intera cronologia delle chat Claude?

Clicca l’icona di Download Claude conversations, scegli “View and Download All Conversations” e poi clicca “Export All”. Quella pagina, la Dashboard, elenca la cronologia di claude.ai, così puoi scaricare in un unico ZIP tutte le chat Claude che ti servono. Il pulsante arancione nella singola conversazione è l’altro punto di accesso; l’esportazione in blocco passa da questa tabella. In inglese la stessa ricerca è “claude export all chats”.

  1. Installa l’estensione dal Chrome Web Store e fissala. Questa guida riguarda la versione 1.16.2, settembre 2026.
  2. Accedi a claude.ai in Chrome. “Export All” usa la stessa sessione del sito.
  3. Apri il popup e clicca “View and Download All Conversations”.
  4. Cerca o filtra, poi seleziona le chat che ti servono davvero. Nel piano gratuito non selezionarne più di quante te ne restano delle 3 di oggi.
  5. Scegli un formato in “Chat format” (tutti e sette, PDF compreso) e clicca “Export All”. Accedi con Google quando richiesto. Chrome salva un unico ZIP.

L’esportazione in blocco chiede l’accesso con Google fin dalla prima volta. L’estensione invia solo quell’email, per verificare il conteggio di oggi e lo stato di Pro. Intera cronologia significa un unico ZIP con un file per chat. “Export All” raccoglie le conversazioni di claude.ai selezionate in uno ZIP, un file per ogni chat. Settings → Privacy → Export data di Anthropic (le etichette possono essere tradotte se claude.ai è impostato in italiano) è lo ZIP in JSON dell’account, che arriva più tardi, se preferisci un unico backup dell’intero account invece di un file per chat.

Come filtro le chat Claude prima di Export All?

La ricerca trova le conversazioni per nome. I filtri sono “All conversations”, “New”, “Updated” e “Previously exported” (tutte, nuove, aggiornate, già esportate). Usali prima di esportare un gruppo di chat Claude, così non spendi le 3 di oggi per file che hai già. “New” indica le chat non ancora esportate con questa estensione. “Previously exported” segna quelle che hai già salvato.

Le schede Chat e Cowork separano le chat normali dalle sessioni Cowork. La ricerca per progetto limita la tabella a un solo Project di claude.ai. Un’esportazione in blocco tipica è “questo progetto” o “solo le nuove”, non “tutto dalla creazione dell’account”. Seleziona le righe, poi esegui “Export All” una volta sola. Ripetere il pulsante arancione su decine di URL è la strada lenta che questa tabella sostituisce.

Il filtro “Previously exported” è interno a Download Claude conversations. Non corrisponde al concetto di backup di Anthropic. Se in passato hai usato l’Export data ufficiale, quelle chat possono comparire qui come “New” finché questa estensione non ha creato i file. È normale. Che cosa include ogni file dell’esportazione in blocco?

L’esportazione in blocco usa le caselle della Dashboard “Chats”, “Thinking”, “Metadata”, “Tools” e “Sources” (chat, ragionamento, metadati, strumenti, fonti), più la disposizione degli artifact (“Original”, “Inline”, “Nested”, “Flat”). Esportare tutte le chat Claude in blocco non significa ottenere uno ZIP di qualità inferiore. Ogni file può conservare blocchi di codice, tabelle e, se vuoi, il ragionamento.

“Thinking” è l’extended thinking di Claude, quando la pagina lo mostrava. “Metadata” può includere titoli, orari e modello. “Tools” aggiunge i passaggi tool e MCP; “Sources” aggiunge le fonti della ricerca web. La disposizione degli artifact decide se restano dentro ogni file o finiscono in una cartella propria nello ZIP. Il PNG resta un’immagine della conversazione. Scegli PDF in “Chat format” e lo ZIP conterrà un PDF per ogni chat: chat Claude in PDF.

L’esportazione in blocco è l’esportazione singola applicata su larga scala: stesso parser, stesse opzioni, un unico ZIP. Nel piano gratuito condivide 3 chat al giorno con il PDF, e il resto dell’estensione resta illimitato. Pro a 3,99 $ al mese o 26,99 $ all’anno serve per esportare tutta la cronologia in una sola volta.

Se un file sembra corto, apri quella conversazione, aspetta ed esporta di nuovo quella riga. Il filtro “Previously exported” si aggiorna dopo un download riuscito.

Quante chat salva gratis Export All?

Tre al giorno. Nel piano gratuito ogni conversazione in uno ZIP di “Export All” consuma una delle 3 esportazioni giornaliere, condivise con il PDF. L’accesso con Google è obbligatorio fin dalla prima esportazione in blocco, e il conteggio si azzera a mezzanotte UTC. Pro a 3,99 $ al mese o 26,99 $ all’anno elimina il limite ed esporta l’intera cronologia.

Se la selezione supera quanto ti resta oggi, l’intero lotto viene bloccato. “Export All” non salva le prime chat per poi fermarsi. Scegli meno chat, aspetta la mezzanotte UTC o passa a Pro. Reinstallare non azzera il conteggio, perché è legato al tuo account Google; Pro si ripristina su un nuovo computer con lo stesso account. Funzionano i piani Free, Pro, Team ed Enterprise di claude.ai, purché la sessione possa elencare le conversazioni; il piano Anthropic non è il nostro limite.

Pianifica la selezione. Tre chat “New” in Markdown sono un’esportazione in blocco valida nel piano gratuito. Trenta chat richiedono Pro, oppure dieci giorni da tre. Il formato non cambia il conteggio: ogni chat nello ZIP conta una volta. Le esportazioni della singola chat in Markdown, JSON, testo, XML, CSV e PNG dal pulsante arancione non contano mai e non richiedono account. Pro è fatturato da Paddle; non vediamo mai i dati della carta. Il primo pagamento ha una garanzia di rimborso di 14 giorni: rimborsi.

Export All o ZIP di backup delle chat Claude?

Fare il backup delle chat Claude di solito significa usare Settings → Privacy → Export data di Anthropic: un unico ZIP in JSON dell’account, che arriva più tardi. “Export All” significa uno ZIP delle chat che scegli, subito, nel formato che scegli. Usa lo ZIP di Anthropic per il backup dell’account. Usa questa pagina per ottenere documenti.

Lo ZIP ufficiale non contiene un Markdown per chat e non ha i filtri “New” o “Previously exported”. “Export All” non è un archivio legale o di conformità di ogni conversazione dimenticata che non vedi nella tabella. Se una conversazione non compare nella Dashboard, questa estensione non può inventarla. Tutti i metodi a confronto, PDF compreso: come esportare una chat Claude.

Anche chi cerca “claude cronologia chat” (o, in inglese, “claude chat history export”) si trova davanti allo stesso bivio. Se l’obiettivo è il backup delle chat Claude, parti dall’Export data di Anthropic. Se l’obiettivo è una cartella di appunti, resta su “Export All”. Nessuna delle due strade è Claude Desktop. Nessuna delle due è /export di Claude Code.

Export All funziona in Desktop o in Claude Code?

Non in Claude Desktop né nel terminale di Claude Code. Per esportare tutte le chat Claude con questa estensione serve claude.ai in Chrome. Claude Desktop non mostra mai “View and Download All Conversations”. Claude Code nel terminale usa /export o i file JSONL su disco. Le sessioni Cowork e Claude Code on the web (claude.ai/code) funzionano su claude.ai, quindi l’estensione le copre.

Se le conversazioni di Desktop sono sincronizzate con lo stesso account, possono comparire nella Dashboard una volta presenti su claude.ai. Se non sono mai state sincronizzate, l’esportazione in blocco non le vede. Soluzioni per Desktop: esportare chat Claude Desktop. Sessioni nel terminale: esportare da Claude Code. Non eseguire “Export All” aspettandoti i JSONL di un repository.

Anche Chrome su mobile non è supportato. La Dashboard è un’interfaccia dell’estensione per computer. Nel 2026 questo team non offre uno strumento di esportazione in blocco per iOS. Apri claude.ai su un computer. Le policy aziendali che bloccano le estensioni bloccano anche “Export All”.

Quale formato usare con Export All?

Scegli un solo “Chat format” per tutta l’esecuzione di “Export All”. Markdown per archivi di appunti, JSON per pipeline di dati, testo semplice per archivi senza markup, XML per lo scambio di dati, CSV per fogli di calcolo, PNG per immagini, PDF per la lettura. L’esportazione di tutte le chat Claude usa gli stessi sette formati del pulsante arancione. Panoramica: formati.

Chi scrive di solito esporta in blocco in Markdown — guida al Markdown. Gli sviluppatori di solito in JSON — guida al JSON. XML: XML. PNG: PNG. Il JSON di “Export All” resta un insieme di file per chat ricavati dalla pagina, non la struttura dello ZIP dell’account di Anthropic. Non mescolare i due schemi nello stesso script.

La scelta del formato non cambia il conteggio. Nel piano gratuito ogni chat nello ZIP consuma una delle 3 di oggi, qualunque sia il formato. Eseguire di nuovo “Export All” in JSON conta di nuovo ogni chat. Usa il filtro “Previously exported” per evitare doppioni. Se ragioni in termini di “estrarre” gli stessi file: estrattore di conversazioni Claude. L’esportazione singola, dal punto di vista del prodotto: esportare chat Claude.

Non citiamo altri strumenti di esportazione. L’Export data ufficiale di Anthropic è nominato solo come termine di paragone per lo ZIP di backup. FAQ: esportare tutte le chat Claude

Queste domande riguardano come esportare tutte le chat Claude, “Export All” e il backup delle chat Claude: il limite giornaliero, la ricerca per progetto, Desktop, Claude Code, il PDF e lo ZIP di Anthropic. Le risposte si riferiscono all’estensione 1.16.2 su claude.ai. Il JSON-LD FAQPage nell’intestazione della pagina corrisponde a questo elenco.

Come scarico le chat Claude in blocco?

Apri “View and Download All Conversations”, seleziona o filtra le righe, scegli un formato e clicca “Export All”. Chrome salva un unico ZIP con un file per ogni chat. Il piano gratuito copre 3 chat al giorno con l’accesso con Google; Pro copre l’intera cronologia delle tue chat Claude.

L’esportazione in blocco costa più di quella singola?

Conta in modo diverso. Le esportazioni della singola chat in Markdown, JSON, testo, XML, CSV e PNG sono illimitate e non richiedono account. Ogni chat in uno ZIP in blocco consuma una delle 3 esportazioni giornaliere, condivise con il PDF. Pro a 3,99 $ al mese o 26,99 $ all’anno elimina quel limite.

Posso scaricare la cronologia delle conversazioni Claude di un solo progetto?

Sì. Usa la ricerca per progetto nella Dashboard, seleziona le chat di quel progetto e poi clicca “Export All”. Nel piano gratuito esportane 3 al giorno, oppure passa a Pro per avere l’intero progetto in un unico ZIP.

L’esportazione in blocco equivale all’esportazione ufficiale di Anthropic?

No. L’Export data ufficiale è un unico ZIP in JSON dell’intero account, inviato via email (backup delle chat Claude). “Export All” è uno ZIP delle chat che selezioni, subito, nel formato che scegli.

Download Claude conversations ricorda le chat già esportate?

Sì. Il filtro “Previously exported” mostra ciò che questa estensione ha già scaricato e “New” ciò che non ha ancora scaricato, così un successivo “Export All” può saltare le chat che hai già.

È così che si esporta tutta la cronologia delle chat Claude?

Sì — “Export All” nella Dashboard è il modo per esportare tutta la cronologia delle chat Claude come file in un unico ZIP. Il piano gratuito copre 3 chat al giorno; per l’intera cronologia serve Pro. L’Export data di Anthropic è invece un unico ZIP dell’account che arriva più tardi.

Export All funziona in Claude Desktop?

No. Questa estensione Chrome non funziona in Claude Desktop. Prima sincronizza le chat con claude.ai, oppure copia e incolla o usa lo ZIP ufficiale.

Posso fare il backup delle chat Claude con Export All?

“Export All” è uno ZIP di file leggibili, non lo ZIP di backup di Anthropic. Per il backup delle chat Claude a livello di account usa Settings → Privacy → Export data. Usali entrambi se vuoi sia i documenti sia un archivio.

Export All crea anche file PDF?

Sì. Scegli PDF in “Chat format” e “Export All” inserisce nello ZIP un PDF per ogni chat. Nel piano gratuito ogni chat conta una volta sulle 3 al giorno, la stessa quota usata dai singoli PDF. Pro è illimitato.

Esportare tutte le chat Claude funziona anche per Claude Code?

Solo sul web. Claude Code on the web (claude.ai/code) funziona su claude.ai, quindi l’estensione esporta quelle sessioni. Claude Code nel terminale usa /export o i file JSONL su disco; “Export All” non li vede mai.

Che cosa succede se il limite giornaliero blocca Export All?

La selezione supera quanto ti resta delle 3 di oggi, quindi l’intero lotto viene bloccato, non tagliato. Seleziona meno chat, aspetta l’azzeramento a mezzanotte UTC oppure passa a Pro (3,99 $ al mese o 26,99 $ all’anno). Reinstallare non azzera il conteggio.

Serve un piano Anthropic a pagamento per Export All?

No. Funziona qualsiasi piano di claude.ai che carichi la cronologia in Chrome. Il nostro limite gratuito/Pro è separato. Gli amministratori di un Team possono comunque bloccare l’estensione nel browser.
