Come salvare una chat Claude come file da conservare

Come salvare una chat Claude? Claude.ai conserva già ogni chat fatta con l’accesso nella cronologia (History), ma non ha un pulsante Salva che crei un file. Per salvare una conversazione Claude in PDF, Markdown, JSON, testo, XML, CSV o PNG, usa Download Claude conversations in Chrome, stampa la pagina o richiedi Settings → Privacy → Export data (le voci possono essere tradotte se claude.ai è impostato in italiano). Chiudere la scheda non elimina la conversazione.

Claude salva già le conversazioni nella cronologia?

Sì. Claude.ai conserva già nella cronologia dell’account Anthropic ogni conversazione fatta con l’accesso. Chiudere la scheda non cancella la conversazione. Però non esiste ancora un comando Salva che scriva un file sul disco. Salvare una conversazione Claude in Markdown o JSON è un lavoro diverso dalla cronologia.

La cronologia è l’elenco delle chat a sinistra su claude.ai. Ogni riga è una conversazione che Anthropic ha conservato per quell’account. Riapri una riga più tardi e ritrovi gli stessi turni. È spazio di archiviazione dell’account, non una cartella di download sul tuo portatile.

Chi cerca «come salvare chat Claude», o in inglese «how to save claude conversation», spesso vuole sapere: «sparirà quando esco?». Per una normale sessione con accesso la risposta è no. Claude.ai non richiede un clic su Salva per tenere la conversazione nell’account. Quello che manca è un esportatore di file, non un interruttore per non perdere la chat.

La cronologia non è un file Markdown, non è un albero JSON in cui cercare con grep e non è un PNG da mettere in una slide. La cronologia vive dietro il login di Anthropic. Se non riesci ad accedere, non puoi aprire quelle chat. Un file locale si apre anche quando la password non c’è più.

Due «salvataggi» diversi. Cronologia = Anthropic conserva la chat nell’account. File = sei tu a scrivere un PDF, Markdown, JSON, testo, XML, CSV o PNG sul disco. Claude.ai ha il primo. Per il secondo claude.ai non ha nessun pulsante.

Anche Projects e Recents su claude.ai fanno parte della cronologia. Inserire una chat in un progetto non crea un file. Rinominare la conversazione non crea un file. Aggiungerla ai preferiti o fissarla, se l’interfaccia lo prevede, non scrive comunque Markdown. Download Claude conversations esporta le chat dentro un progetto come tutte le altre, e nella pagina di un progetto «Project files» → «Download ZIP» (file del progetto → scarica ZIP) salva i file del progetto.

Gli spazi di lavoro Team ed Enterprise seguono la stessa distinzione. Se riesci ad aprire la conversazione su claude.ai, Anthropic l’ha già conservata per lo spazio di lavoro. Le regole di conservazione aziendali possono comunque eliminare o nascondere le chat secondo tempi che non controlli. Un file che hai esportato diventa allora la copia che tieni tu.

La modalità in incognito e un secondo profilo di Chrome non condividono la cronologia. La conversazione è legata all’account Anthropic usato in quella sessione. Se accedi con un altro account Anthropic, vedi un’altra cronologia. Per «salvare» tra account diversi serve un file, non un’unione delle cronologie.

Come salvare una conversazione Claude come file?

Per salvare una conversazione Claude come file, scegli un metodo che scriva sul disco: Download Claude conversations in Chrome, Stampa → Salva come PDF, oppure Settings → Privacy → Export data. La cronologia di claude.ai è archiviazione dell’account, non un file PDF, Markdown, JSON, testo, XML, CSV o PNG.

L’estensione di Chrome è la via per singola chat. Apri l’URL della conversazione, fai clic sul pulsante arancione accanto alla casella dei messaggi, scegli un formato, fai clic su «Export» (Esporta). L’API di download di Chrome scrive il file in locale. Markdown, testo, JSON, XML, CSV e PNG non richiedono un account; solo il PDF chiede l’accesso con Google. Il contenuto delle chat resta sul computer.

La stampa è la via visiva. Ctrl+P o Cmd+P, destinazione «Salva come PDF». Il risultato somiglia alla pagina di claude.ai, compresi gli elementi dell’interfaccia che gli stili di stampa non hanno nascosto. I blocchi di codice spesso si spezzano tra un foglio e l’altro. Usa la stampa quando chi rivede vuole un’istantanea, non un file di appunti. Per un PDF creato dai messaggi invece che dallo schermo, scegli PDF nell’estensione.

Export data ufficiale è la via dell’account. Settings → Privacy → Export data su claude.ai. Anthropic ti invia per email un link che scade. Lo ZIP è JSON per tutto l’account, non un file con il nome della chat sullo schermo. L’attesa è il prezzo di un backup completo.

Un file è la mossa giusta prima di lasciare un’azienda, prima di formattare un portatile, per un archivio di ricerca o prima di incollare una revisione del codice in git. La cronologia basta quando devi solo riaprire la stessa conversazione domani con lo stesso account Anthropic.

Il copia e incolla è un quinto metodo, e un file debole. Selezioni il testo su claude.ai e lo incolli in Docs. I blocchi di codice si perdono. Le tabelle diventano righe continue. I confini tra i messaggi spariscono. Va bene per un paragrafo. Non va bene come unica copia salvata di una revisione di design di 40 turni. Il pulsante «Copy» (Copia) dell’estensione mette invece negli appunti un Markdown pulito.

Come salvare una chat Claude con l’estensione di Chrome?

Con Download Claude conversations: installa l’estensione di Chrome, apri la conversazione su claude.ai, fai clic sul pulsante arancione accanto alla casella dei messaggi, scegli PDF, Markdown, JSON, testo, XML, CSV o PNG, poi «Export». Non serve alcun account, tranne per il PDF.

  1. Installa Download Claude conversations dal Chrome Web Store (funzionano anche i browser Chromium che caricano le estensioni di Chrome).
  2. Ricarica claude.ai se la pagina era già aperta durante l’installazione. Chrome non inserisce sempre uno script di contenuto nelle schede vecchie.
  3. Apri dalla cronologia l’URL di una conversazione vera: il pulsante arancione compare in una conversazione, non nella pagina iniziale con la casella vuota.
  4. Fai clic sul pulsante rotondo arancione a destra della casella dei messaggi. Si apre un pannello con Messages («All» / «Human» / «Assistant», cioè tutti / tuoi / di Claude), Format, «Thinking» (ragionamento), «Select» (Seleziona), «Copy» ed «Export».
  5. Scegli PDF, Markdown, testo semplice, JSON, XML, CSV o PNG. Fai clic su «Export». Chrome scarica subito il file.

L’estensione è uno script di contenuto di Chrome che funziona solo su claude.ai. Il parser legge la conversazione già caricata nella sessione con accesso. Download Claude conversations non chiama un’API separata di Anthropic con credenziali proprie e non carica la conversazione sui nostri server per generare il file.

Per Markdown, testo semplice, JSON, XML, CSV o PNG non serve alcun account. Queste esportazioni di una singola chat sono illimitate e gratuite: nessun accesso, nessun contatore. L’accesso con Google compare solo quando scegli PDF o avvii un «Export All» (Esporta tutto) in blocco. L’accesso con Google non è un login per leggere le chat. Il contenuto delle conversazioni resta sul tuo computer.

La casella «Thinking» include o esclude il ragionamento esteso. «Select» ti permette di spuntare singoli messaggi, così il file contiene solo quei turni. «Copy» mette Markdown, testo, JSON, XML o CSV negli appunti invece di scaricare un file. Aspetta che l’assistente abbia finito di scrivere prima di esportare. Un file salvato durante la generazione taglia l’ultima risposta. Un secondo tentativo in Markdown o JSON non costa nulla. Un secondo PDF usa un altro dei 3 slot giornalieri del piano gratuito: un motivo in più per verificare prima che la conversazione sia completa.

L’ultimo formato usato viene ricordato. Se volevi Markdown e hai ricevuto JSON, il menu era ancora su JSON dall’esportazione precedente. Controlla il menu ogni volta che cambi lavoro. Gli screenshot passo passo dello stesso pulsante arancione sono in come scaricare una chat Claude.

Come salvare una conversazione Claude senza estensione?

Senza estensione hai due strade: stampare la pagina di claude.ai o richiedere lo ZIP di Export data ad Anthropic. La stampa è un PDF visivo della pagina web. Export data è un archivio JSON di tutto l’account, che arriva più tardi. Nessuno dei due crea un file Markdown per singola chat.

Con la stampa: apri la conversazione su claude.ai, nascondi la barra laterale se l’interfaccia lo consente, premi Ctrl+P (Windows/Linux) o Cmd+P (Mac), imposta la destinazione su «Salva come PDF» e salva. Gli elementi dell’interfaccia intorno alla casella di scrittura possono ripetersi su ogni foglio. Le note complete sulla stampa sono in scaricare una chat Claude in PDF.

Con il metodo ufficiale: Settings → Privacy → Export data su claude.ai. Anthropic ti invia per email un link che scade. Estrai tu lo ZIP se ti serve una conversazione tra migliaia. Quell’archivio è il backup completo a fini legali, non un file di appunti per la riunione di domani.

Il copia e incolla resta disponibile senza installare nulla. Evidenzi i turni su claude.ai e li incolli in un’app per appunti. L’indentazione del codice di solito si perde. Una conversazione a più turni diventa un muro di testo senza struttura. Usa il copia e incolla per un singolo frammento, non come unico modo per salvare le conversazioni Claude.

La cronologia conserva la conversazione dopo la chiusura?

Sì. La cronologia conserva la conversazione Claude anche dopo che chiudi la scheda, ricarichi claude.ai o spegni il portatile, purché la chat sia stata creata con l’accesso. Chiudere una scheda non è eliminare. L’eliminazione dalla cronologia è l’azione che toglie la conversazione dall’interfaccia dell’account.

Se esci da claude.ai, la pagina si svuota. Se rientri con lo stesso account Anthropic, la cronologia ti restituisce quelle chat. Uscire nasconde l’elenco; di per sé non cancella l’archivio dell’account. Un altro account Anthropic mostra un’altra cronologia.

L’eliminazione dalla cronologia è il caso reale in cui le chat spariscono. Se rimuovi una conversazione nell’interfaccia di claude.ai, quella conversazione sparisce dalla barra laterale. Un file Markdown che hai già esportato con il pulsante arancione resta sul disco. Esporta prima, se la chat sta per essere ripulita.

Eliminare non è chiudere. Chiudere una scheda di claude.ai lascia intatta la cronologia. Eliminare la conversazione dalla cronologia la toglie dall’interfaccia dell’account. Export data ufficiale non ti aiuterà dopo un’eliminazione se Anthropic non include più quella conversazione. Crea il file prima di fare pulizia.

La modalità in incognito finisce quando chiudi la finestra. Se hai usato claude.ai in una finestra privata senza un accesso duraturo, non dare per scontato che la cronologia abbia tenuto il lavoro. Accedi da un normale profilo di Chrome, oppure esporta un file prima che la sessione in incognito finisca.

Gli amministratori degli spazi di lavoro Team ed Enterprise possono conservare o limitare le chat. Una policy che non hai impostato tu può nascondere una conversazione più tardi. Considera la cronologia aziendale uno spazio in prestito. Considera un file Markdown o JSON esportato la copia che resta dalla tua parte.

Passare dal telefono al portatile non richiede un clic speciale per salvare la conversazione quando entrambi i dispositivi usano lo stesso account Anthropic. Apri la cronologia sul portatile. Se la chat manca, sei su un altro account, in un altro spazio di lavoro, oppure la conversazione è stata eliminata: non è «non salvata».

Claude Desktop può mostrare le chat dello stesso account quando l’app ha effettuato l’accesso con lo stesso utente Anthropic. La sincronizzazione è compito di Anthropic. L’estensione di Chrome non si inserisce mai in Desktop. Se la conversazione esiste su claude.ai, apri claude.ai in Chrome per creare un file.

Come salvare una conversazione Claude in Markdown o JSON?

Apri il pulsante arancione su claude.ai, scegli il formato, poi «Export». Markdown è il file per gli appunti. JSON è l’albero dei messaggi per gli script. Il testo semplice non ha markup. CSV è una riga per messaggio. PDF è un documento impaginato. PNG è un’immagine.

Markdown mantiene titoli, blocchi di codice delimitati con il tag del linguaggio e tabelle. Markdown è la scelta abituale per Obsidian, GitHub o un wiki. Note sull’impaginazione di questo formato: esportazione in Markdown. JSON conserva l’albero che il parser ha già costruito, compresi artifact e ragionamento quando quelle opzioni sono attive.

Il JSON di Download Claude conversations non ha la stessa struttura dello ZIP dell’account di Anthropic. Il JSON dell’estensione è una conversazione così come la pagina l’ha mostrata. Il JSON di Export data è un’esportazione completa dell’account che Anthropic invia più tardi per email. Non mescolare i due schemi nello stesso script senza controllare le chiavi.

Il testo semplice è la scelta giusta quando la destinazione elimina il markup: un campo di un sistema di ticket, il corpo di un’email, un indice di ricerca che vuole stringhe grezze. XML è la scelta di nicchia per lo scambio di dati. CSV si apre in Excel, Google Sheets o Numbers. PNG serve per una slide o come immagine della conversazione in una segnalazione di bug, non per una revisione di 40 turni in cui vorrai cercare con grep.

Ragionamento, metadati, filtro per mittente e disposizione degli artifact cambiano cosa finisce nel Markdown e nel JSON. Spunta «Thinking» nel pannello quando ti serve il ragionamento esteso nell’archivio. Lascialo disattivato quando il file è per un lettore che deve vedere solo la risposta finale. Come salvare in blocco la cronologia delle chat Claude?

Per salvare la cronologia delle chat Claude in tanti file, non ripetere il pulsante arancione scheda per scheda. Apri «View and Download All Conversations» (vedi e scarica tutte le conversazioni) dal popup dell’estensione, filtra la tabella e fai clic su «Export All». «Export All» chiede l’accesso con Google. Con il piano gratuito ogni chat nello ZIP usa uno dei 3 slot giornalieri condivisi con il PDF. Pro elimina il limite.

La Dashboard elenca le conversazioni dell’account claude.ai con cui hai effettuato l’accesso: la stessa cronologia che hai già, trasformata in una tabella da filtrare. Cerca per nome. Filtra per All conversations, New, Updated o Previously exported (tutte, nuove, aggiornate, già esportate). Passa dalla scheda Chat alla scheda Cowork e cerca per progetto se su claude.ai raggruppi le chat così.

L’esportazione in blocco crea un unico ZIP con un file per chat, nel formato che scegli nel selettore «Chat format»: uno qualsiasi dei sette, PDF compreso. Usa lo stesso parser dell’esportazione di una singola chat. Le caselle decidono cosa entra nel file, «Chats», «Thinking», «Metadata», «Tools», «Sources» (chat, ragionamento, metadati, strumenti, fonti), più una disposizione degli artifact. «Export All» non è una versione ridotta. «Export All» è lo stesso parser applicato a molte conversazioni in un solo passaggio. Dettagli: «Export All» in blocco.

Export data di Anthropic resta il backup dell’account. Un ZIP, un’email, JSON per tutto, comprese le chat che avevi dimenticato. «Export All» fa l’opposto: scegli tu quali righe della cronologia, scegli tu il formato, lo ZIP arriva subito. Usali entrambi se vuoi un archivio completo a fini legali e una cartella di appunti leggibili.

La quota è condivisa e giornaliera. Con il piano gratuito, le esportazioni PDF e le chat in blocco condividono 3 slot al giorno, che si azzerano a mezzanotte UTC. Se selezioni 40 conversazioni, l’intero lotto viene bloccato, non tagliato. Scegline meno, oppure passa a Pro a 3,99 $ al mese o 26,99 $ all’anno tramite Paddle.

La Dashboard ricorda cosa hai già esportato, così alla visita successiva puoi filtrare solo New o Updated. In questo modo l’abitudine di salvare ogni settimana le chat Claude resta incrementale, senza duplicare il Markdown del mese scorso. Il conteggio dei 3 al giorno segue l’account Google, non l’installazione, e si azzera a mezzanotte UTC.

Seleziona solo una parte quando la cronologia è piena di bozze di una riga. «Export All» non significa che devi prendere ogni riga. Un filtro preciso più Markdown dà una cartella di ricerca più pulita di 200 conversazioni vuote che dicono solo «ciao».

Esportare una chat Claude, come verbo del prodotto, passa dallo stesso pulsante arancione e dalla stessa tabella di «Export All». La pagina collegata esportare una chat Claude descrive quei comandi se sei arrivato cercando «esportare» invece di «salvare».

Posso salvare una conversazione Claude da Desktop o Code?

Da Desktop no. Da Code, solo sul web. Download Claude conversations non può salvare una conversazione Claude da Claude Desktop né da un terminale locale di Claude Code. Le sessioni su claude.ai/code si aprono in Chrome sul computer, quindi si salvano come qualsiasi chat. Claude Desktop è un’app separata. Claude Code in locale è l’agente da terminale con /export e file JSONL sul disco.

Se la chat di Desktop esiste anche su claude.ai, apri quell’URL in Chrome e usa il pulsante arancione. Se la conversazione esiste solo in Desktop, usa il copia e incolla o aspetta Settings → Privacy → Export data. L’estensione non si inserisce mai nella finestra di Desktop.

In una sessione attiva di Claude Code, digita /export. La CLI di Anthropic apre un menu per copiare la trascrizione o salvarla in un file di testo semplice. Passa un nome di file per saltare il menu. Quella trascrizione è testo da leggere per una persona, non il Markdown, il JSON o il PDF di questa estensione. Tutti i percorsi: esportare da Claude Code.

Il JSONL sul disco è il log interno in ~/.claude/projects (Windows: %USERPROFILE%\.claude\projects). Lo schema può cambiare da una versione di Claude Code all’altra. La documentazione di Anthropic stessa consiglia di preferire /export all’analisi del JSONL. Non integriamo quella CLI. Non leggiamo ~/.claude.

Domande frequenti: come salvare una chat Claude

Come salvo una conversazione Claude come file?

Installa Download Claude conversations, apri la conversazione su claude.ai, fai clic sul pulsante arancione a destra della casella dei messaggi, scegli PDF, Markdown, JSON, testo, XML, CSV o PNG, poi fai clic su «Export». Il file viene scaricato in locale, senza account tranne che per il PDF. La cronologia ha già conservato la chat nell’account Anthropic; il pulsante arancione ne crea una copia sul disco.

Come salvo una chat Claude su claude.ai?

Non ti serve un pulsante Salva per tenere la conversazione nell’account. La cronologia di claude.ai elenca già le chat fatte con l’accesso. Per salvare una chat Claude come file, usa l’estensione di Chrome, Stampa → Salva come PDF, oppure Settings → Privacy → Export data per uno ZIP JSON dell’account, che arriva più tardi.

Come salvo una conversazione Claude senza estensione?

Stampa la pagina di claude.ai (Ctrl/Cmd+P → Salva come PDF) per una copia visiva, oppure usa Settings → Privacy → Export data per uno ZIP JSON di tutto l’account inviato per email. Il copia e incolla va bene per una risposta breve. Nessuno di questi metodi crea un file Markdown strutturato per singola chat come fa l’estensione di Chrome.

Claude salva già le conversazioni nella cronologia?

Sì. Le chat fatte con l’accesso su claude.ai restano nella cronologia dell’account Anthropic. Chiudere la scheda, ricaricare o aprire un altro dispositivo con lo stesso account non cancella la conversazione. La cronologia non è un PDF, un Markdown, un JSON né alcun altro file sul tuo disco.

Una conversazione Claude sparisce se chiudo la scheda?

No. Chiudere una scheda di claude.ai non elimina la conversazione dalla cronologia. Eliminare la chat dalla cronologia invece la toglie dall’interfaccia dell’account. Un file che hai già esportato con Download Claude conversations resta sul disco anche dopo quell’eliminazione.

Posso salvare una conversazione Claude in PDF?

Sì. Download Claude conversations 1.16.2 esporta direttamente in PDF: scegli PDF nel pannello del pulsante arancione e fai clic su «Export». Il file viene creato nel browser, senza finestra di stampa. Il PDF richiede l’accesso con Google ed è gratuito fino a 3 al giorno; Pro è illimitato. Guida: chat Claude in PDF.

Quanti file gratuiti posso salvare?

Illimitati per Markdown, testo semplice, JSON, XML, CSV e PNG, senza account. PDF e ZIP in blocco condividono 3 al giorno con il piano gratuito, con l’accesso con Google; ogni chat in uno ZIP in blocco conta come una e il giorno si azzera a mezzanotte UTC. Pro costa 3,99 $ al mese o 26,99 $ all’anno ed elimina il limite. Il pagamento è gestito da Paddle.

Si possono salvare le chat Claude dal telefono?

Con l’estensione di Chrome no. Funziona in Chrome sul computer (o in un altro browser Chromium che installa elementi dal Chrome Web Store). Non esiste un’app per iOS o Android. I browser mobili possono comunque aprire la cronologia e stampare una chat Claude, ma non possono mostrare il pulsante arancione.

Posso salvare in blocco le chat Claude della cronologia?

Sì. Apri «View and Download All Conversations» dal popup dell’estensione, filtra la tabella e fai clic su «Export All». L’esportazione in blocco richiede l’accesso con Google e rientra nei 3 al giorno del piano gratuito. Non è lo ZIP di Export data di Anthropic: quello ufficiale è un unico archivio di tutto l’account, inviato più tardi per email. Vedi download in blocco.

Salva anche le conversazioni di Claude Code?

Solo sul web. Le sessioni di Claude Code su claude.ai/code si salvano come qualsiasi chat di claude.ai. Le sessioni locali del terminale no: usa /export o copia il JSONL da ~/.claude/projects (Windows: %USERPROFILE%\.claude\projects). Questa estensione di Chrome funziona solo su claude.ai. Guida: esportare da Claude Code.

Serve l’accesso con Google per salvare una chat Claude?

No, non per Markdown, testo semplice, JSON, XML, CSV o PNG. L’accesso con Google è necessario solo per PDF, «Export All» in blocco e Pro, così possiamo applicare il limite di 3 al giorno e ripristinare Pro dopo una reinstallazione. Il contenuto delle conversazioni non viene inviato con l’accesso. Conserviamo l’email verificata solo per la quota e lo stato Pro.

Dov’è Export data ufficiale per salvare le chat Claude?

Su claude.ai: Settings → Privacy → Export data. Anthropic ti invia per email un link che scade. Lo ZIP è un archivio JSON a livello di account, non un file Markdown con il nome della chat che stavi leggendo. Usa Export data come backup; usa il pulsante arancione per avere subito un file leggibile.
