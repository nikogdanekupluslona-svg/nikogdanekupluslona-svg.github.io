Download Claude chats in bulk

To download Claude chats (plural), you need more than the open tab. This extension's browse page lists your conversations, lets you search by name, filter by project or previously exported, then Export All. Each completed file counts toward the 3 free exports unless you're on Pro.

Open the browse page

Download Claude conversations lives in two places: the orange button on a single conversation, and a separate browse page for everything else. Click the extension icon, then View and Download All Conversations. That opens a table of your claude.ai history — not a single chat, all of it — built specifically for the moment you decide to download Claude chats in bulk instead of one at a time.

Browse page listing Claude conversations with search and Export All

Search and filter before you export

Search finds conversations by name. Filters narrow the table further: All, New (not yet exported), Exported, and by Project, if you organize chats that way on claude.ai. This matters because a claude download conversation job across a large account is rarely "export everything" — it's usually "export the ones from this project" or "export what I haven't already saved." Select what you want, then run Export All once instead of repeating the single-chat flow dozens of times.

Choose what each export includes

Yes — bulk uses the same toggles as a single-chat export, just applied across your selection: Chats, Thinking (Claude's extended reasoning, when present), Metadata (titles, timestamps, model), and artifact layout — Original, Inline, Nested, or Flat. Nothing is stripped down for bulk; you get the same five formats — Markdown, JSON, plain text, XML, PNG — and the same fidelity, just for many conversations in one Export All pass. This is one of the things that separates Claude Conversation Downloader from a simple copy-paste workflow: bulk isn't a lesser version of the single-chat export, it's the same export applied at scale.

Free vs Pro for bulk

Every account gets 3 free exports total, and bulk exports count against that same number — one file from Export All is one export, same as clicking the orange button once. If you're regularly trying to download Claude chats in bulk beyond a handful of files, Pro removes the cap for $3.99/mo or $26.99/yr and covers both single and bulk exports. To be direct about it a second time: the free tier is 3 exports total, not 3 per bulk run — plan accordingly before you select 40 conversations at once.

Bulk export vs the official account ZIP

Anthropic's Settings → Privacy → Export data gives you one delayed archive, emailed as a single JSON ZIP for your whole account — useful as a backup, not for picking specific conversations. Bulk export here is the opposite: you choose which chats, in which format, and the files land immediately, no email, no wait. Use the official export for a full-account backup; use this Claude Conversation Downloader when you want control over exactly what gets exported and how.

FAQ

How do I download Claude chats in bulk?

Open the extension's browse page, select or filter conversations, and click Export All. Each file downloads in your chosen format.

Does bulk export cost more than a single export?

No — same price structure. 3 free exports total across single and bulk; Pro removes the limit for both.

Can I download Claude conversation history from a specific project only?

Yes, filter by Project on the browse page before running Export All.

Is bulk the same as Anthropic's official export?

No. The official export is one account-wide ZIP by email. Bulk here is files you select, in the format you pick, downloaded immediately.

Does Download Claude conversations remember what I've already exported?

Yes — the browse page's "Exported" filter tracks what's already been downloaded, so you can filter to only new conversations on a repeat visit.
