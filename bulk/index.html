How do I download entire Claude chat history?

Click the Download Claude conversations icon, choose View and Download All Conversations, then click Export All.   1. Install the Chrome listing and pin it. This guide covers version 1.16.2, September 2026.

Does bulk Export All run in Desktop or Code?

Not in Claude Desktop or the Claude Code terminal. Download entire Claude chat with this extension requires claude.ai in Chrome. Claude Desktop never shows View and Download All Conversations. Terminal Claude Code uses /export or JSONL on disk. Cowork sessions and Claude Code on the web (claude.ai/code) run on claude.ai, so the extension covers them.

If Desktop threads synced to the same account, they can appear on the Dashboard once they exist on claude.ai. If they never synced, bulk cannot see them. Desktop workarounds: export Claude Desktop chat. Terminal sessions: Claude Code export. Do not run Export All expecting JSONL from a repo.

Mobile Chrome is also unsupported. The Dashboard is a desktop extension UI. There is no iOS bulk downloader from this team in 2026. Open claude.ai on a computer. Team policies that block extensions block bulk Export All as well.

Does bulk export cost more than a single export?

It counts differently. Single-chat exports in Markdown, JSON, text, XML, CSV, and PNG are unlimited and need no account. Each chat in a bulk ZIP uses one of 3 daily exports, shared with PDF. Pro at $3.99 a month or $26.99 a year removes that cap.
