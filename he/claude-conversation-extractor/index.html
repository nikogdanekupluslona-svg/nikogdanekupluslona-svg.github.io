חילוץ צ'אט של Claude עובד ב-Claude Code?

לא. ‏Claude Code משתמש ב-/export או ב-JSONL בדיסק. כלי החילוץ הזה הוא content script של Chrome ל-claude.ai, לא חיבור לטרמינל.
