אפשר להוריד צ'אט של Claude כ-PDF באופן מובנה?

לא מתוך claude.ai עצמו — אין בו כפתור הורדה כ-PDF. עם Download Claude conversations — כן: בחרו PDF בחלונית הייצוא ולחצו "Export". גרסה 1.16.2 בונה את קובץ ה-‎.pdf בתוך הכרטיסייה, בלי חלון הדפסה. שום דבר לא מועלה.

  1. התקינו את Download Claude conversations מ-Chrome Web Store, ואז רעננו את claude.ai.
  2. פתחו את השיחה. צ'אטים רגילים, פרויקטים, סשנים של Cowork ו-Claude Code בגרסת הווב (claude.ai/code) — כולם עובדים.
  3. לחצו על כפתור ההורדה הכתום והעגול מימין לתיבת ההודעה.
  4. תחת "Format" (פורמט) בחרו PDF. השאירו את "Messages" (הודעות) על "All" (הכול), או בחרו "Human" (המשתמש) או "Assistant" (העוזר). לחצו "Select" (בחירה) כדי לסמן רק את ההודעות שאתם רוצים.
  5. לחצו "Export". בפעם הראשונה התחברו עם Google, הגדירו את אפשרויות ה-PDF ושמרו.

התוסף זוכר את הפורמט האחרון שבו השתמשתם. אם רציתם PDF וקיבלתם Markdown, הרשימה הנפתחת עדיין הייתה על Markdown. בדקו אותה לפני שאתם לוחצים "Export" — בתוכנית החינמית, גם PDF שלא התכוונתם ליצור מנצל אחד מ-3 הייצואים של היום.

הדפסה מול הייצוא הרשמי מול תוסף Chrome הזה?

הדפסה, Export data הרשמי ותוסף Chrome הזה הם שלוש משימות שחולקות את המילה "ייצוא". הדפסה ← Save as PDF היא שיחה אחת, חזותית, עכשיו. ה-ZIP הרשמי הוא כל החשבון, ב-JSON, שנשלח במייל מאוחר יותר. התוסף כותב שבעה פורמטים מקומיים, כולל PDF: שישה לא דורשים חשבון, ואילו PDF וייצוא מרוכז מבקשים התחברות עם Google.

אם התכוונתם ל-Claude Code בטרמינל, הדפסה לא תעזור: סשן מקומי אינו דף אינטרנט. השתמשו ב-/export. ‏Claude Code בגרסת הווב (claude.ai/code) הוא מקרה אחר: הוא נפתח ב-claude.ai, ולכן התוסף מייצא אותו כ-PDF כמו כל צ'אט. אם התכוונתם לאפליקציית Claude Desktop, התוסף לא פועל שם — ראו ייצוא צ'אט מ-Claude Desktop.

איך מייצאים צ'אט של Claude עם ה-ZIP לעומת הכפתור הכתום — מוסבר במדריך הייצוא. איך מורידים צ'אט של Claude, עם שלבים לווידג'ט — במדריך ההורדה. הדף הזה נשאר ממוקד ב-PDF ובהדפסה, כדי ששלושת הדפים יישארו נפרדים.

המגבלה היומית לא חלה על הדפסה. הדפסה מהדפדפן אינה התוסף. המכסה של התוכנית החינמית — 3 ייצואי PDF או ZIP מרוכז ביום, במשותף, שמתאפסת בחצות UTC — חלה רק על קובצי PDF של התוסף ועל Export All. Markdown, טקסט, JSON, XML, CSV ו-PNG הם ללא הגבלה. Pro ב-$3.99 לחודש או $26.99 לשנה מסיר את המגבלה. Paddle מעבדת את התשלום.

תוסף Chrome עצמאי, שאינו קשור ל-Anthropic, PBC. פעלו לפי תנאי השימוש של Anthropic. איננו יכולים להבטיח גיליון סגנונות להדפסה ש-Anthropic שולטת בו ולא אנחנו. אם שינוי בממשק של Claude שובר את ההדפסה, זה ה-CSS שלהם; ייצאו PDF מהתוסף במקום.
