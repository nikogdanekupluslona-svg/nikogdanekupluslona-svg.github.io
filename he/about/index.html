אודות

Download Claude conversations הוא תוסף Chrome עצמאי (שם האתר: Chat Downloader). מנועי חיפוש ומשתמשים קוראים לו גם Claude Chat Downloader ו-Claude Conversation Downloader. התוסף לא פותח על ידי Anthropic, PBC, אינו קשור אליה ואינו מאושר על ידה — Claude הוא סימן מסחרי של Anthropic. בנינו אותו כדי למלא חוסר ב-claude.ai עצמו: אין שם דרך מובנית להוריד שיחה בודדת כקובץ.

התוסף מוסיף ל-claude.ai כפתור ייצוא ולוח בקרה (Dashboard) לייצוא מרוכז, וכותב קובצי PDF, Markdown, טקסט פשוט, JSON, XML, CSV או PNG באופן מקומי בדפדפן. ייצוא של צ'אט בודד ל-Markdown, טקסט, JSON, XML, CSV ו-PNG הוא ללא הגבלה ולא דורש חשבון. PDF ו-ZIP מרוכז דורשים התחברות עם Google וחינמיים עד 3 ביום; Pro ‏($3.99 לחודש או $26.99 לשנה) מסיר את המגבלה. התוסף עובד עם צ'אטים רגילים, פרויקטים, סשנים של Cowork ו-Claude Code בגרסת הווב (claude.ai/code). פרטים נוספים באיך זה עובד. התוסף אינו מייצא סשנים של Claude Code מהטרמינל.
