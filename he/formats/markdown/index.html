איך מייצאים צ'אט של Claude ל-Markdown?

פתחו את השיחה ב-claude.ai ב-Chrome, לחצו על הכפתור הכתום ליד תיבת ההודעה, בחרו Markdown ולחצו Export. Download Claude conversations כותב קובץ ‎.md באופן מקומי. כך מייצאים צ'אט של Claude ל-Markdown בגרסה 1.16.2.

  1. התקינו את Download Claude conversations מ-Chrome Web Store.
  2. רעננו את claude.ai ופתחו כתובת של שיחה אמיתית, לא את דף הבית הריק עם תיבת הכתיבה.
  3. לחצו על כפתור ההורדה הכתום מימין לתיבת ההודעה.
  4. בחרו Markdown. התוסף זוכר את הפורמט האחרון שבו השתמשתם. לחצו "Select" (בחירה) כדי לסמן רק את ההודעות שאתם רוצים.
  5. לחצו Export. ‏Chrome מוריד את קובץ ה-‎.md דרך ממשק ההורדות של הדפדפן. או לחצו "Copy" (העתקה) כדי להעתיק את ה-Markdown ללוח.

לא צריך להתחבר כדי לייצא צ'אט של Claude ל-Markdown. ייצוא Markdown של צ'אט בודד הוא ללא הגבלה, אנונימי ולא שולח דבר לשרתים שלנו. התחברות עם Google נדרשת רק ל-PDF ול-Export All המרוכז. המנגנון: איך זה עובד.

אם הכפתור הכתום חסר, אתם לא בכתובת של שיחה, הלשונית צריכה רענון אחרי ההתקנה, או שהתוסף עדיין מוסתר בתפריט הפאזל של Chrome. הצמידו את Download Claude conversations ורעננו את claude.ai. הסקריפט אף פעם לא נטען ב-Claude Desktop או ב-Claude Code בטרמינל.

למה לייצא צ'אט של Claude ל-Markdown בשביל רשימות?

ייצאו ל-Markdown כשתקראו את הקובץ ב-Obsidian, בוויקי של GitHub או בכל עורך שמציג כותרות ובלוקי קוד. קובץ ה-‎.md הוא עדיין טקסט פשוט שאפשר לחפש בו ולהשוות גרסאות שלו. JSON עדיף למנתחים; PNG הוא תמונה שאי אפשר לחפש בה.

העתקה והדבקה מ-claude.ai בדרך כלל מאבדת את ההזחה ומשטחת טבלאות. הדפסה (Ctrl/Cmd+P) משאירה את סרגל הצד ולעיתים קרובות מפצלת בלוק קוד ארוך בין עמודים. כשמייצאים צ'אט של Claude ל-Markdown, תגיות השפה נשארות על בלוקי הקוד והטבלאות נשארות טבלאות. זו הסיבה שכותבים בוחרים בפורמט הזה ראשון.

אנחנו מתייחסים ל-Markdown כקובץ ברירת המחדל לקריאה בידי אדם: כותרות, בלוקי קוד עם תגיות שפה, וטבלאות מהשרשור ב-claude.ai. כשאתם צריכים עמודים במקום זה, בחרו PDF באותה חלונית. הוא נבנה בדפדפן, עם גודל עמוד, שוליים ותוכן עניינים.

מה נשמר בייצוא ל-Markdown?

כשמייצאים צ'אט של Claude ל-Markdown, Download Claude conversations שומר כותרות, בלוקי קוד עם תגיות שפה והזחה, טבלאות וקישורים. בלוקי חשיבה, מקורות של חיפוש באינטרנט ושלבי כלים / MCP הם אופציונליים, כל אחד בנפרד: "Thinking" (חשיבה) היא תיבת סימון בחלונית הייצוא, ושני האחרים מופעלים בהגדרות. מטא-דאטה (כותרת, חותמות זמן, מודל) יכולה להצטרף. מסנן השולח יכול להגביל את קובץ ה-‎.md לכל ההודעות, רק למשתמש או רק לעוזר.

פריסת הארטיפקטים היא מתג של ממש בגרסה 1.16.2: "Original",‏ "Inline",‏ "Nested" או "Flat" (מקורי, מוטמע, מקונן, שטוח). ייצוא Markdown יכול לשקף את מבנה הארטיפקטים שעל המסך, לשטח אותו למסמך ליניארי אחד, או להוציא את הארטיפקטים לתיקייה משלהם בתוך ZIP. בהגדרות אפשר להטמיע תמונות בקובץ ה-‎.md. הרשימה המלאה: תכונות תוסף Chrome. Markdown לא שומר את צבעי בועות ההודעה; השתמשו ב-PNG לצילום חזותי או ב-PDF לעמודים.

לוח הבקרה מציג את ההיסטוריה של claude.ai עם חיפוש לפי שם, המסננים All conversations, ‏New, ‏Updated ו-Previously exported (כל השיחות, חדשות, עודכנו, יוצאו בעבר), הלשוניות Chat ו-Cowork וחיפוש פרויקטים. ‏New פירושו שעדיין לא יוצא עם Download Claude conversations. ‏Previously exported עוקב אחרי צ'אטים שכבר שמרתם, כך ש-Export All נוסף יכול לדלג עליהם.

המגבלה היומית היא לכל חשבון. שלושה צ'אטים ביום בתוכנית החינמית, במשותף עם PDF. אם תבחרו 40 שיחות כשנשארו לכם 3, כל האצווה נחסמת, ולא נקטעת באמצע. בחרו פחות או השתמשו ב-Pro. ייצוא ‎.md בודד מהכפתור הכתום נשאר ללא הגבלה.

ייצוא Markdown מרוכז משתמש בתיבות הסימון של לוח הבקרה Chats, ‏Thinking, ‏Metadata, ‏Tools ו-Sources (צ'אטים, חשיבה, מטא-דאטה, כלים, מקורות), ובפורמט הארטיפקטים. ‏Export All אינו ה-ZIP של Anthropic שמגיע באיחור. זה ZIP אחד של קובצי ‎.md, אחד לכל צ'אט. אם רציתם ארכיון אחד של כל החשבון, זה Settings → Privacy → Export data (התוויות עשויות להופיע בעברית אם claude.ai מוגדר לעברית), והוא JSON, לא Markdown.
