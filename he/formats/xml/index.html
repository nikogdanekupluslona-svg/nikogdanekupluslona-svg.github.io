איך מייצאים צ'אט של Claude ל-XML?

פתחו את השיחה ב-claude.ai ב-Chrome, לחצו על הכפתור הכתום ליד תיבת ההודעה, בחרו XML ולחצו Export. Download Claude conversations כותב את הקובץ באופן מקומי. כך מייצאים צ'אט של Claude ל-XML בגרסה 1.13.0. בספטמבר 2026 אין ב-claude.ai פקד מובנה לשמירה כ-XML.

  1. התקינו את Download Claude conversations מ-Chrome Web Store (דירוג 5.0).
  2. רעננו את claude.ai ופתחו כתובת של שיחה אמיתית, לא את דף הבית הריק עם תיבת הכתיבה.
  3. לחצו על כפתור ההורדה הכתום מימין לתיבת ההודעה.
  4. בחרו XML. הפורמט האחרון שבו השתמשתם נשמר.
  5. לחצו Export. Chrome מוריד את ה-XML דרך ממשק ההורדות של הדפדפן.

כניסה עם Google נדרשת לפני הפעם הראשונה שמייצאים ל-XML. Download Claude conversations שומר את האימייל המאומת כדי לספור את 3 הייצואים החינמיים ולשחזר את Pro אחרי התקנה מחדש. טקסט הצ'אט אינו חלק מהכניסה הזו. המנגנון: איך זה עובד.

אם הכפתור הכתום חסר, אתם לא בכתובת של שיחה, הלשונית צריכה רענון, או שהתוסף מוסתר בתפריט הפאזל של Chrome. הצמידו את Download Claude conversations ורעננו את claude.ai. ייצוא XML אף פעם לא מופיע ב-Claude Desktop או ב-Claude Code.

קובץ אחד מול רבים. הכפתור הכתום מייצא את השרשור הפתוח כ-XML. לקובצי XML רבים, פתחו את "View and Download All Conversations" (הצגה והורדה של כל השיחות) והריצו "Export All" (ייצוא הכול) כש-XML נבחר — ראו ייצוא מרוכז עם Export All.

מתי כדאי לייצא צ'אט של Claude ל-XML?

ייצאו צ'אט של Claude ל-XML כשהמערכת המקבלת, צינור העיבוד או כלי ותיק דורשים XML להעברה מובנית. רוב המפתחים צריכים לבחור JSON במקום. Markdown מיועד לרשימות לבני אדם. PNG הוא תמונה. XML נמצא ברשימה כי יש כלים שעדיין קולטים XML ולא יקבלו JSON.

אל תייצאו ל-XML כאילו זה JSON "רשמי יותר". Download Claude conversations מבצע אותו ניתוח בשני המקרים. ההבדל הוא בצורת הקובץ, לא בשדות נוספים שמופיעים בדרך קסם. אם שום דבר שאתם משתמשים בו לא דורש XML, דלגו על הפורמט הזה והשתמשו ב-JSON.

אנחנו מספקים XML כי יש צינורות עיבוד שעדיין דורשים אותו, לא כי אנחנו חושבים שהוא עדיף על JSON בכל ייצוא מ-claude.ai. הניתוח זהה: הודעות, שולח, חשיבה וארטיפקטים אופציונליים. אנחנו עדיין לא מפיקים PDF. גרסה 1.13.0 שומרת את XML כאחד מחמישה פורמטים, לא כתוספת בתשלום.

מה נשמר בייצוא ל-XML?

כשמייצאים צ'אט של Claude ל-XML, Download Claude conversations כותב את מבנה השיחה — הודעות, שולח ומטא-דאטה זמינה — כסימון XML. בלוקי חשיבה וארטיפקטים פועלים לפי אותם מתגים כמו ב-Markdown וב-JSON. XML אינו גרסה מצומצמת של הפורמטים האלה.

פריסת הארטיפקטים בגרסה 1.13.0 היא "Original",‏ "Inline",‏ "Nested" או "Flat" (מקורי, מוטמע, מקונן, שטוח). מסנן השולח יכול להגביל את ה-XML לכל ההודעות, רק למשתמש או רק לעוזר. מטא-דאטה (כותרת, חותמות זמן, מודל) יכולה להצטרף. רשימת המתגים המלאה: תכונות תוסף Chrome.

JSON הוא הבחירה הנפוצה אצל מפתחים. ייצאו צ'אט של Claude ל-XML רק כשמערכת בהמשך השרשרת דורשת XML. Download Claude conversations לא הופך את XML ל"שלם יותר" מ-JSON. שניהם יכולים לכלול חשיבה וארטיפקטים. אף אחד מהם אינו ה-ZIP של החשבון מ-Anthropic. מרכז הפורמטים: פורמטים לייצוא צ'אט של Claude.

אפשר לייצא צ'אטים ל-XML בכמות גדולה?

כן. פתחו את View and Download All Conversations, הגדירו את הפורמט ל-XML, סננו את הטבלה ולחצו Export All. כל קובץ שהושלם הוא אחד מ-3 הייצואים החינמיים. Pro ב-$3.99 לחודש או $26.99 לשנה מסיר את המגבלה לייצוא XML מרוכז.

טבלת העיון מציגה את ההיסטוריה של claude.ai עם חיפוש לפי שם והמסננים All,‏ New,‏ Exported ו-Project (הכול, חדשים, יוצאו, פרויקט). New פירושו שעדיין לא יוצא עם Download Claude conversations. Exported עוקב אחרי צ'אטים שכבר שמרתם. Project תואם לאופן שבו אתם מקבצים צ'אטים ב-claude.ai. Export All הוא קובצי XML רבים, לא ZIP מעורב אחד.

המכסה היא לכל החשבון. שלושה ייצואים בחינם בסך הכול — לא שלושה קובצי XML לכל הרצה מרוכזת. בחירה של 40 שיחות מנצלת 40 ייצואים אם כל הקבצים מושלמים. תכננו את הבחירה, או השתמשו ב-Pro.

אי אפשר לערבב XML ו-JSON בלחיצה אחת על Export All. בחרו XML להרצה הזו. הריצו Export All שוב עם JSON אם אתם צריכים את שתי הצורות של אותו שרשור ב-claude.ai; גם ההרצה השנייה מנצלת מכסה.

לא. XML כלול ב-3 הייצואים החינמיים שכל חשבון שנכנס עם Google מקבל, בדיוק כמו Markdown,‏ JSON, טקסט ו-PNG. אחרי שלושת הקבצים האלה, Pro עולה $3.99 לחודש או $26.99 לשנה דרך Paddle. Download Claude conversations לא מתייחס ל-XML כפורמט בתשלום בלבד.

3 הייצואים החינמיים לא מתאפסים כשמתקינים מחדש את התוסף. זו הסיבה שנדרשת כניסה עם Google בפעם הראשונה שמייצאים צ'אט של Claude ל-XML. Pro משוחזר במחשב חדש מאותו חשבון Google. ‏Paddle היא הגורם המוכר הרשמי; הצוות שלנו אף פעם לא רואה מספרי כרטיסים.

לא צריך תוכנית בתשלום של claude.ai מ-Anthropic. צריך חשבון שיכול לטעון את השיחה ב-Chrome. גרסה 1.13.0, ספטמבר 2026, עדיין לא כותבת PDF,‏ Word או Notion. אם הרשימה תשתנה, הדף הזה ישתנה באותו יום.
