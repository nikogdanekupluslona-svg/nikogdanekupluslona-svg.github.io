איך מייצאים שיחה של Claude כ-JSON?

פתחו את השיחה ב-claude.ai ב-Chrome, לחצו על הכפתור הכתום ליד תיבת ההודעה, בחרו JSON ולחצו Export. Download Claude conversations כותב את הקובץ באופן מקומי. כך מייצאים שיחה של Claude כ-JSON בגרסה 1.13.0. בספטמבר 2026 אין ב-claude.ai פקד לשמירת צ'אט בודד כ-JSON.

  1. התקינו את Download Claude conversations מ-Chrome Web Store (דירוג 5.0).
  2. רעננו את claude.ai ופתחו כתובת של שיחה אמיתית, לא את דף הבית הריק עם תיבת הכתיבה.
  3. לחצו על כפתור ההורדה הכתום מימין לתיבת ההודעה.
  4. בחרו JSON. הפורמט האחרון שבו השתמשתם נשמר.
  5. לחצו Export. Chrome מוריד את ה-JSON דרך ממשק ההורדות של הדפדפן.

כניסה עם Google נדרשת לפני הפעם הראשונה שמייצאים שיחה כ-JSON. Download Claude conversations שומר את האימייל המאומת כדי לספור את 3 הייצואים החינמיים ולשחזר את Pro אחרי התקנה מחדש. תוכן הצ'אטים אינו חלק מהכניסה הזו. המנגנון: איך זה עובד.

אם הכפתור הכתום חסר, אתם לא בכתובת של שיחה, הלשונית צריכה רענון, או שהתוסף מוסתר בתפריט הפאזל של Chrome. הצמידו את Download Claude conversations ורעננו את claude.ai. הסקריפט אף פעם לא נטען ב-Claude Desktop או ב-Claude Code.

שרשור אחד מול קבצים רבים. הכפתור הכתום מייצא את הצ'אט הפתוח כ-JSON. לקובצי JSON רבים, פתחו את "View and Download All Conversations" (הצגה והורדה של כל השיחות) והריצו "Export All" (ייצוא הכול) כש-JSON נבחר — ראו ייצוא מרוכז עם Export All.

מתי כדאי לייצא שיחה של Claude כ-JSON?

ייצאו שיחה של Claude כ-JSON כשסקריפט, כלי אינדוקס או כלי השוואה יקראו את הקובץ. ה-JSON בנוי לעץ ההודעות, לא לקריאה ב-Obsidian. אם אתם רוצים כותרות ובלוקי קוד לבני אדם, בחרו Markdown.

העתקה והדבקה מ-claude.ai מאבדת את מבנה השולחים. הדפסה שומרת את רכיבי ממשק הדף. כשמייצאים שיחה כ-JSON, Download Claude conversations שומר את התורות, השולחים והחשיבה האופציונלית כנתונים, לא כפסקה משוטחת. זו הסיבה שמפתחים בוחרים JSON על פני טקסט פשוט.

אנחנו כותבים JSON מהעץ של claude.ai שכבר נמצא בדף — שולח, בלוקי תוכן, חותמות זמן, מטא-דאטה של המודל — בלי להעלות את השרשור. ה-JSON הזה אינו ה-ZIP של החשבון מ-Anthropic, והוא אינו PDF. גרסה 1.13.0 עדיין מספקת חמישה פורמטים בלבד.

מה יש בייצוא JSON של שיחת Claude?

ייצוא JSON של שיחת Claude משקף את עץ ההודעות ב-claude.ai: שולח, בלוקי תוכן, חותמות זמן ומטא-דאטה של המודל. בלוקי חשיבה וארטיפקטים נכללים כשהמתגים האלה פועלים. מסנן השולח יכול להגביל את הקובץ לכל ההודעות, רק למשתמש או רק לעוזר. שום דבר לא משוטח קודם ל-Markdown.

פריסת הארטיפקטים בגרסה 1.13.0 היא "Original",‏ "Inline",‏ "Nested" או "Flat" (מקורי, מוטמע, מקונן, שטוח). הפריסות האלה משנות את אופן קינון תוכן הארטיפקטים ב-JSON — אותן ארבע אפשרויות כמו ב-Markdown וב-XML. רשימת המתגים המלאה: תכונות תוסף Chrome. JSON עדיין לא הופך ל-PDF.

JSON של שיחה מול Export data של Anthropic?

שניהם JSON, אבל לא באותו מבנה ולא באותו היקף. Settings → Privacy → Export data של Anthropic (התוויות עשויות להופיע בעברית אם claude.ai מוגדר לעברית) שולח במייל, אחרי המתנה, ZIP אחד של כל החשבון. כשמייצאים שיחה של Claude כ-JSON, מקבלים שרשור אחד מיד ב-Chrome. השתמשו ב-ZIP לגיבוי.

אפשר לייצא שיחות כ-JSON בכמות גדולה?

כן. פתחו את View and Download All Conversations, הגדירו את הפורמט ל-JSON, סננו את הטבלה ולחצו Export All. כל קובץ שהושלם הוא אחד מ-3 הייצואים החינמיים. Pro ב-$3.99 לחודש או $26.99 לשנה מסיר את המגבלה לייצוא JSON מרוכז.

טבלת העיון מציגה את ההיסטוריה של claude.ai עם חיפוש לפי שם והמסננים All,‏ New,‏ Exported ו-Project (הכול, חדשים, יוצאו, פרויקט). New פירושו שעדיין לא יוצא עם Download Claude conversations. Exported עוקב אחרי צ'אטים שכבר שמרתם. Project תואם לאופן שבו אתם מקבצים צ'אטים ב-claude.ai. Export All הוא קובצי JSON רבים, לא ZIP מעורב אחד.

המכסה היא לכל החשבון. שלושה ייצואים בחינם בסך הכול — לא שלושה קובצי JSON לכל הרצה מרוכזת. בחירה של 40 שיחות מנצלת 40 ייצואים אם כל הקבצים מושלמים. תכננו את הבחירה, או השתמשו ב-Pro.

אפשר להשוות שני ייצואי JSON של אותו שרשור ב-claude.ai מזמנים שונים, כמו שמשווים כל קובץ JSON. כל ייצוא עומד בפני עצמו. Export All נוסף של אותם צ'אטים עדיין מנצל מכסה, אלא אם הקבצים לא הושלמו.

האם ייצוא JSON דורש Pro?

לא. JSON כלול ב-3 הייצואים החינמיים שכל חשבון שנכנס עם Google מקבל, בדיוק כמו Markdown, טקסט, XML ו-PNG. אחרי שלושת הקבצים האלה, Pro עולה $3.99 לחודש או $26.99 לשנה דרך Paddle. Download Claude conversations לא גובה תוספת על ייצוא שיחה של Claude כ-JSON.

3 הייצואים החינמיים לא מתאפסים כשמתקינים מחדש את התוסף. זו הסיבה שנדרשת כניסה עם Google בלחיצה הראשונה על Export. Pro משוחזר במחשב חדש מאותו חשבון Google. ‏Paddle היא הגורם המוכר הרשמי; הצוות שלנו אף פעם לא רואה מספרי כרטיסים.

התוסף פועל רק ב-claude.ai ב-Chrome. Claude Desktop ו-Claude Code לא מקבלים כפתור JSON. ‏/export של Claude Code או JSONL בדיסק הם מסלול אחר. גרסה 1.13.0, ספטמבר 2026, עדיין לא כותבת PDF,‏ Word או Notion.
