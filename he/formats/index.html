  1. התקינו את Download Claude conversations מ-Chrome Web Store (דירוג 5.0).
  2. רעננו את claude.ai ופתחו כתובת של שיחה אמיתית, לא את דף הבית הריק עם תיבת הכתיבה.

  4. בחרו Markdown,‏ JSON, טקסט פשוט, XML או PNG. הפורמט האחרון נשמר.

כניסה עם Google נדרשת לפני הייצוא הראשון. Download Claude conversations שומר את האימייל המאומת כדי לספור את 3 הייצואים החינמיים ולשחזר את Pro אחרי התקנה מחדש. טקסט הצ'אט אינו חלק מהכניסה הזו. המנגנון: איך זה עובד.
