שאלות נפוצות

אפשר להוריד שיחה של Claude מ-claude.ai?

לא עם כפתור מובנה. התקינו את Download Claude conversations מ-Chrome Web Store, פתחו את הצ'אט וייצאו קובץ.

אפשר להוריד צ'אטים של Claude בחינם?

כן. ייצוא ל-Markdown, טקסט פשוט, JSON, XML, CSV ו-PNG הוא ללא הגבלה ולא דורש חשבון. ייצוא PDF וייצוא ZIP מרוכז דורשים התחברות עם Google וחינמיים עד 3 ביום. Pro, ב-$3.99 לחודש או $26.99 לשנה, מסיר את המגבלה.

באילו דפדפנים זה עובד?

Chrome במחשב ודפדפנים מבוססי Chromium שמתקינים תוספים מ-Chrome Web Store. אין אפליקציה לנייד, והתוסף לא פועל בתוך Claude Desktop.

איך מבטלים את Pro, ואפשר לקבל החזר?

זה אותו דבר כמו Export data של Claude?

לא. ב-Settings → Privacy → Export data (התוויות עשויות להופיע בעברית אם claude.ai מוגדר לעברית) Anthropic שולחת במייל קובץ ZIP של כל החשבון (JSON). התוסף הזה מוריד את הצ'אט הנוכחי — או בחירה מרוכזת — כקבצים קריאים, מיד.

אתם שומרים את הצ'אטים שלי מ-Claude?

לא. כל פורמט, כולל PDF, נבנה בדפדפן שלכם, וטקסט השיחה אף פעם לא מגיע לשרתים שלנו. אם מתחברים עם Google בשביל PDF, ייצוא מרוכז או Pro, אנחנו שומרים את כתובת המייל הזו רק כדי לספור את המכסה היומית ולשייך את המנוי שלכם.

מה ההבדל בין "ייצוא צ'אט של Claude" לבין "claude export chat"?

אותה משימה, שתי דרכים לכתוב אותה — בעברית או באנגלית, כפי שרוב המשתמשים מחפשים. בכל מקרה משתמשים בכפתור הכתום ב-claude.ai.

אפשר לייצא ל-PDF?

כן, אם אפשר לפתוח את השיחה בדפדפן ב-claude.ai. אנחנו לא Anthropic.
