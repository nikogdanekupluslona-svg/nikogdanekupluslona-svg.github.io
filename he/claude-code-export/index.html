מהו ייצוא מ-Claude Code בטרמינל?

ייצוא מ-Claude Code הוא הפקודה /export בתוך סשן אינטראקטיבי של ה-CLI. לפי התיעוד של Anthropic, נפתח תפריט שמאפשר להעתיק את השיחה הנוכחית או לשמור אותה כקובץ טקסט פשוט, כשההודעות ופלטי הכלים מוצגים כטקסט קריא. אם מוסיפים שם קובץ, התפריט מדולג והקובץ נכתב ישירות.

זה לא Markdown מ-claude.ai, לא JSON מתוסף Chrome הזה, וגם לא PDF. זה תמליל מעובד שנועד לקריאה בידי אדם. Anthropic מציינת שיומן ה-JSONL בדיסק הוא פורמט אחר, פנימי, שנועד למוצר עצמו — לא API ציבורי בשבילכם.

/export

כדי לדלג על השאלה ולכתוב קובץ בשם מסוים בתיקיית העבודה הנוכחית:

/export my-session

תיעוד הסשנים של Anthropic הוא המקור המחייב לדגלים ולשמות קבצים; הם משתנים בין גרסאות של Claude Code. בלוגים של הקהילה הם מקור משני. אם הנוסח בחלון של /export לא תואם את מה שאתם רואים, ה-CLI שלכם הוא גרסה אחרת — היעזרו בעזרה שבתוך המוצר, לא בצילום מסך מ-2025.

לסקריפטים Anthropic מפנה לממשקים אחרים: claude -p עם --output-format json או stream-json, חידוש סשן לפי מזהה, hooks שמקבלים transcript_path, או ה-Agent SDK. אלה ממשקי פיתוח של Claude Code. הם לא תוסף Chrome של האתר הזה.

קריא מול מובנה. /export הוא התמליל לבני אדם. ה-JSONL בתיקיית projects הוא היומן. ה-JSON של תוסף Chrome הוא צורה שלישית, שנבנית רק מדף של claude.ai. אל תכתבו מנתח אחד לשלושתם.

איך מורידים שיחה של Claude Code מהדיסק?

כדי להוריד שיחה של Claude Code מהדיסק, העתיקו את קובץ ה-JSONL של הסשן מתיקיית projects, או הריצו /export לקבלת תמליל קריא. נתיב ברירת המחדל ב-macOS וב-Linux נמצא תחת ~/.claude/projects/. ב-Windows הוא %USERPROFILE%\.claude\projects. שמות הקבצים הם מזהי הסשנים.

שם תיקיית הפרויקט הוא תיקיית העבודה, כשכל תו שאינו אות או ספרה מוחלף במקף. Anthropic מקצרת שמות ארוכים מאוד ומוסיפה hash, כדי שהתיקייה תעמוד במגבלות מערכת הקבצים. אם אינכם מוצאים את התיקייה, הפעלתם את Claude Code מתיקיית עבודה אחרת ממה שחשבתם.

כל שורה ב-JSONL היא אובייקט JSON של הודעה, שימוש בכלי או מטא-דאטה. Anthropic מציינת שפורמט הרשומות הזה פנימי ומשתנה בין גרסאות. סקריפטים שמפענחים את הקבצים האלה עלולים להישבר עם גרסה חדשה של Claude Code. כשאתם צריכים משהו יציב, העדיפו את /export או את ממשקי הסקריפטים המתועדים.

מיקום האחסון יכול לזוז. CLAUDE_CONFIG_DIR מעביר את עץ ההגדרות אל מחוץ ל-~/.claude. CLAUDE_CODE_PROJECT_DIR_NAME קובע את שם תיקיית הפרויקט כשמשתמשים בו יחד עם תיקיית ההגדרות הזו (Claude Code v2.1.234 ואילך, לפי Anthropic). cleanupPeriodDays ב-settings.json משנה את תקופת השמירה המוגדרת כברירת מחדל. אף אחת מההגדרות האלה אינה תכונה של Download Claude conversations.

לכן, כדי לגבות קובצי שיחה של Claude Code: העתיקו את התיקייה, או ייצאו תמלילים עם /export באופן קבוע. האתר הזה לא יוסיף כפתור "ייבוא JSONL". אנחנו לא קוראים את תיקיית הבית שלכם.

איפה Claude Code שומר את היסטוריית השיחות?

חידוש סשן הוא פעולה אחרת מייצוא. claude --continue ו-claude --resume טוענים סשן מחדש כדי שתוכלו להמשיך לעבוד. /export כותב עותק שאפשר להשאיר ב-git או לשלוח במייל. האחד משחזר הקשר; השני נותן לכם רשומה לקחת איתכם. דף הסשנים של Anthropic מכסה את מצב ההרשאות בחידוש, דחיסה וסיכום, ואת התנהגות בורר הסשנים — שום דבר מזה אינו קשור לתוסף הזה.

לפי Anthropic, לאפליקציה השולחנית, ל-Claude Code באינטרנט ולתוסף של VS Code יש לכל אחד היסטוריית סשנים משלו. הנתיבים במדריך הזה הם של ה-CLI. אל תניחו שתמליל של Cowork ב-Desktop נמצא באותו עץ JSONL שבו אתם משתמשים מהטרמינל.

אל תתייחסו ל-JSONL כסכמה ציבורית. Anthropic מציינת שפורמט השורות משתנה. אם בכל זאת אתם מפענחים אותו, קבעו גרסה של Claude Code וצפו לשבירות. /export היא הדרך היציבה לקבל שיחה קריאה של Claude Code.

משתני סביבה כמו CLAUDE_CODE_SKIP_PROMPT_HISTORY יכולים למנוע כתיבת תמלילים. אם תיקיית projects ריקה, בדקו אם כיביתם את השמירה, הפניתם את CLAUDE_CONFIG_DIR למקום אחר, או מעולם לא הרצתם סשן אינטראקטיבי בתיקייה הזו.

שאלות נפוצות: ייצוא שיחה של Claude Code

איך מייצאים שיחה של Claude Code?

בטרמינל של Claude Code הקלידו /export (אפשר עם שם קובץ) כדי לשמור תמליל קריא, או העתיקו את קובץ ה-JSONL מ-~/.claude/projects ב-macOS/Linux או מ-%USERPROFILE%\.claude\projects ב-Windows. תיעוד הסשנים של Anthropic מתאר את חלון הדו-שיח העדכני.

האם תוסף Chrome הזה מוריד צ'אטים של Claude Code?

לא. Download Claude conversations עובד רק ב-claude.ai בתוך Chrome. הוא לא יכול לקרוא סשנים מהטרמינל, תמלילי JSONL או את הפקודה /export. ייצוא של Claude Code נשאר ב-CLI.

איפה Claude Code שומר את היסטוריית השיחות?

תמלילי הסשנים הם קובצי JSONL תחת ~/.claude/projects/<encoded-working-directory>/, ושמם הוא מזהה הסשן. המבנה המדויק עשוי להשתנות. השתמשו ב-/export כשאתם רוצים קובץ קריא במקום לפענח JSONL. המשתנה CLAUDE_CONFIG_DIR יכול להעביר את התיקייה למקום אחר.

איך מורידים שיחה של Claude Code כ-Markdown?

הפקודה /export של Claude Code מפיקה תמליל בטקסט פשוט, לא את ה-Markdown של התוסף הזה. אם אתם צריכים דווקא Markdown, ייצאו עותק של העבודה מ-claude.ai בעזרת Download Claude conversations, או המירו בעצמכם את הטקסט של /export. אנחנו לא ממירים JSONL ל-Markdown.

ואיך מורידים במקום זאת שיחה מ-Claude.ai?

התקינו את תוסף Chrome החינמי, פתחו את הצ'אט ב-claude.ai והשתמשו בכפתור הכתום — או ב-Export All להיסטוריה כולה. ראו איך מורידים צ'אט של Claude. 3 ייצואים בחינם; Pro עולה $3.99 לחודש או $26.99 לשנה.

האם /export זהה ל-Export data הרשמי?

אפשר לפענח את ה-JSONL של Claude Code עם jq?

אפשר, עם ההסתייגות ש-Anthropic מפרסמת: מבנה השורות פנימי ועשוי להשתנות. כשאתם צריכים ממשק יציב, העדיפו את /export או את claude -p --output-format json. אם בכל זאת אתם מפענחים JSONL, קבעו גרסת CLI מסוימת.

האם ייצוא מ-Claude Code עובד ב-Windows?

כן. /export היא פקודת CLI. התמלילים בדיסק נמצאים תחת %USERPROFILE%\.claude\projects, אלא אם הגדרתם CLAUDE_CONFIG_DIR. תוסף Chrome הזה עדיין לא רץ בתוך הטרמינל הזה.

האם Claude Code זהה ל-Claude Desktop?

לא. Claude Code הוא סוכן התכנות בטרמינל. Claude Desktop היא אפליקציית הצ'אט. claude.ai הוא האתר. רק האתר מקבל את התוסף הזה. הערות על ייצוא מ-Desktop: Claude Desktop.

האם התוסף יעטוף אי פעם את /export?

לא בגרסה 1.13.0. תחום המוצר הוא claude.ai: חמישה פורמטים, קבצים מקומיים, כניסה עם Google לספירת המכסה. אם התחום ישתנה, הדף הזה יציין זאת. עד אז השתמשו ב-CLI של Anthropic לייצוא מ-Claude Code.

האם /export כולל פלטים של כלים?

לפי Anthropic, /export מציג הודעות ופלטי כלים כטקסט קריא. זה התמליל שלהם, לא מנתח שלנו. כדי לדעת מה בדיוק נכלל היום, הריצו /export בגרסה שלכם וקראו את הקובץ — התיעוד עלול לפגר אחרי גרסה חדשה.

אפשר לייצא סשנים של Claude Code בכמות גדולה?

לא עם Export All של התוסף הזה. הייצוא המרוכז בדף העיון שלנו מיועד ל-claude.ai בלבד. לסשנים רבים של ה-CLI העתיקו את תיקיית projects או הריצו /export בכל סשן. אין ייצוא מרוכז בכפתור כתום עבור JSONL.
