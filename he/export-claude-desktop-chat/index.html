למה אי אפשר לייצא כאן צ'אט מ-Claude Desktop?

תוספי Chrome רצים על דפים שתואמים להרשאות המארח שלהם. התוסף הזה תואם לדפי שיחה של claude.ai. Claude Desktop אינו לשונית של claude.ai. אי אפשר ללחוץ "Add to Chrome" (הוספה ל-Chrome) בתוך אפליקציית Desktop. גרסה 1.13.0 (ספטמבר 2026) עדיין לא כוללת פלאגין ל-Desktop, עוזר בשורת התפריטים או קורא קבצים לתיקיית ההתקנה של Desktop.

מגבלה קשיחה. אי אפשר לייצא צ'אט מ-Claude Desktop עם תוסף Chrome הזה מתוך Desktop. אם אתם צריכים Markdown,‏ JSON, טקסט, XML או PNG מהווידג'ט שלנו, צאו מ-Desktop, פתחו את https://claude.ai ב-Chrome ופתחו שם את השיחה.

אנשים מחפשים איך לייצא צ'אט מ-Claude Desktop (ובאנגלית: export Claude Desktop chat) כי למוצרים יש מותג משותף. תוצאות החיפוש מערבבות את Desktop,‏ claude.ai ו-Claude Code. הקבצים אינם ניתנים להחלפה. צילום מסך של Desktop אינו ייצוא Markdown. יומן JSONL של Code אינו שרשור של claude.ai. הדף הזה קיים כדי שאי-ההתאמה הזו תהיה ברורה.

  2. מצאו את השיחה בהיסטוריה באתר. אם היא חסרה, עברו להעתקה והדבקה או ל-Export data — איננו יכולים למשוך צ'אט ש-Chrome מעולם לא טען.
  3. לחצו על הכפתור הכתום. בחרו Markdown,‏ JSON, טקסט פשוט, XML או PNG. לחצו "Export" (ייצוא).
  4. לשרשורים מסונכרנים רבים, פתחו את "View and Download All Conversations" (הצגה והורדה של כל השיחות) והריצו "Export All" (ייצוא הכול).
