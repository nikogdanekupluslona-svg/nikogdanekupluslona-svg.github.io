הגרסה בדף הזה היא 1.13.0, מספטמבר 2026. הפורמטים נשארים Markdown, ‏JSON, טקסט פשוט, XML ו-PNG. אם הרשימה תשתנה, המדריך הזה ישתנה באותו יום. עד אז, אל תצפו ל-Word, ל-Notion או ל-PDF מובנה מ-Download Claude conversations ב-claude.ai.

Claude exporter: אותו תוסף Chrome?

כן. "claude exporter" הוא הניסוח באנגלית שרבים מקלידים לאותה משימה: לשמור שיחה מ-claude.ai כקובץ. ‏Download Claude conversations הוא תוסף Chrome הזה — כפתור כתום, חמישה פורמטים, 3 ייצואים חינמיים. בדפים המשפטיים עשוי עדיין להופיע השם Claude Exporter עבור התוסף הזה.

גם חיפושים כמו "ייצוא שיחות Claude" או, באנגלית, "claude export chat" ו-"export Claude conversations" מתכוונים לכפתור הכתום בכתובת של שיחה ב-claude.ai, או ל-Export All מתוך View and Download All Conversations. הם לא מתכוונים ל-/export של Claude Code, ולא ל-ZIP של Anthropic שנשלח במייל — אלא אם בוחרים במסלול הרשמי הזה.

איך לייצא שיחה מ-Claude בלי תוסף? העתק-הדבק, הדפסה, או Settings → Privacy → Export data. העתק-הדבק מאבד טבלאות. הדפסה שומרת את רכיבי הממשק של claude.ai. ה-ZIP הוא JSON של החשבון שמגיע באיחור. ‏Download Claude conversations הוא המסלול המיידי ל-Markdown / JSON / טקסט / XML / PNG, ב-claude.ai בלבד.

אל תצפו ש-Download Claude conversations יופיע ב-Claude Desktop או בטרמינל של Claude Code. בממשקים האלה אף פעם אין את הכפתור הכתום. אם חיפשתם ייצוא שיחה מ-Claude וציפיתם לדגל של CLI, השתמשו ב-/export או ב-JSONL בדיסק. אם ציפיתם לכפתור באפליקציית Mac, פתחו את השיחה המסונכרנת ב-claude.ai ב-Chrome.

שאלות נפוצות: ייצוא שיחה מ-Claude

השאלות האלה מכסות ייצוא שיחה מ-Claude: פורמטים, מכסה, Claude Desktop, ‏Claude Code, ה-ZIP של Anthropic והכפתור הכתום ב-claude.ai. כל תשובה היא עובדה מ-Download Claude conversations 1.13.0. ה-JSON-LD מסוג FAQPage בראש הדף תואם לרשימה הזו.

מה המשמעות של ייצוא שיחה מ-Claude באתר הזה?

שמירת שיחה מ-claude.ai כקובץ עם Download Claude conversations: כפתור כתום, בחירת פורמט, «Export». אותה משימה שמחפשים באנגלית כ-"claude export conversation". לא ה-ZIP של Anthropic שנשלח במייל ולא /export של Claude Code.

ייצוא שיחה מ-Claude זה אותו דבר כמו Export data?

לא. Settings → Privacy → Export data הוא ZIP עם JSON של כל החשבון במייל. ייצוא שיחה עם התוסף הזה כותב את השיחה הפתוחה או בחירה של Export All כ-Markdown, ‏JSON, טקסט, XML או PNG, מיד ב-Chrome.

ייצוא שיחה מ-Claude יכול לכתוב PDF?

לא עם Download Claude conversations. הפורמטים הם Markdown, ‏JSON, טקסט פשוט, XML ו-PNG. לתמונת מצב בסגנון PDF, הדפיסו את דף claude.ai ב-Chrome. ‏PNG הוא תמונה, לא PDF.

צריך Pro כדי לייצא שיחה מ-Claude פעם אחת?

לא. 3 הייצואים הראשונים בכל חשבון שמחובר עם Google הם בחינם, בכל פורמט. ‏Pro ב-$3.99 לחודש או $26.99 לשנה מסיר את המגבלה לעוד קבצים בודדים או מרוכזים.

ייצוא שיחה מ-Claude עובד בכל תוכנית של claude.ai?

כן. תוכניות Free, ‏Pro, ‏Team או Enterprise של claude.ai עובדות אם אפשר לפתוח את השיחה ב-Chrome. ‏Download Claude conversations לא דורש את התוכנית בתשלום של Anthropic.

ייצוא שיחה מ-Claude מתאים ל-Claude Code?

לא. Download Claude conversations רץ ב-claude.ai ב-Chrome. ‏Claude Code משתמש ב-/export או ב-JSONL ב-~/.claude/projects. התוסף הזה לא קורא סשנים של Claude Code.

אפשר לייצא סשן של Claude מ-Claude Desktop?

לא עם תוסף Chrome הזה. פתחו את אותה שיחה ב-claude.ai אם היא מסונכרנת, או העתיקו-הדביקו / השתמשו ב-Export data הרשמי. ‏Claude Desktop אף פעם לא מציג את הכפתור הכתום.

כמה קובצי שיחה חינמיים מקבלים?

שלושה לכל חשבון שמחובר עם Google, משותפים לכפתור הכתום ול-Export All. התקנה מחדש לא מאפסת את המונה. ‏Pro משוחזר דרך ההתחברות עם Google.

איפה הכפתור הכתום לייצוא שיחה מ-Claude?

מימין לתיבת ההודעה, בכתובת של שיחה ב-claude.ai, אחרי שמתקינים את Download Claude conversations וטוענים מחדש. הוא לא מופיע בדף הבית הריק של תיבת הכתיבה ולא ב-Claude Desktop.

ייצוא שיחה מ-Claude מעלה את הצ'אטים שלי?

לא. הקבצים נבנים בדפדפן ונמסרים ל-API ההורדות של Chrome. ה-worker שלנו רואה מצב מנוי ומייל מאומת של Google, לא את תוכן השיחות.

באילו פורמטים ייצוא שיחה מ-Claude יכול לכתוב?

Markdown, ‏JSON, טקסט פשוט, XML ו-PNG — אותם חמישה לשיחה אחת ול-Export All. אין ייצוא ל-PDF, ‏Word, ‏Notion או Google Docs בגרסה 1.13.0.
