איזו תכונה של התוסף מייצאת צ'אט אחד?

התכונה המרכזית לשרשור אחד היא הכפתור הכתום ש-Download Claude conversations מוסיף ליד תיבת ההודעה ב-claude.ai. פתחו כתובת של שיחה, בחרו Markdown,‏ JSON, טקסט, XML או PNG ולחצו "Export" (ייצוא). הקובץ יורד מיד.

  1. התקינו את Download Claude conversations מ-Chrome Web Store (דירוג 5.0).
  2. רעננו את claude.ai ופתחו כתובת של שיחה אמיתית, לא את דף הבית הריק עם תיבת הכתיבה.
  3. לחצו על כפתור ההורדה הכתום מימין לתיבת ההודעה.
  4. בחרו פורמט. התוסף זוכר את הפורמט האחרון שבו השתמשתם.
  5. לחצו Export. Chrome שומר את הקובץ דרך ממשק ההורדות של הדפדפן.

הכפתור הכתום מופיע רק בשיחה טעונה. בדף הבית הריק אין מה לנתח. אם הכפתור חסר, הצמידו את התוסף בתפריט הפאזל של Chrome ורעננו את claude.ai. התכונות האלה אף פעם לא נטענות ב-Claude Desktop או ב-Claude Code.

קובץ מקומי. Markdown,‏ JSON, טקסט, XML ו-PNG נבנים בתוך הלשונית. בדיקות המכסה נשלחות לשרת שלנו. טקסט הצ'אט לא. המנגנון: איך זה עובד.

אילו תכונות של התוסף מכסות את Export All?

התכונות לייצוא מרוכז נמצאות ב-"View and Download All Conversations" (הצגה והורדה של כל השיחות): טבלה של היסטוריית claude.ai עם חיפוש, המסננים All / New / Exported / Project (הכול / חדשים / יוצאו / פרויקט), ו-"Export All" (ייצוא הכול). כל קובץ שהושלם הוא אחד מ-3 הייצואים החינמיים. Pro ב-$3.99 לחודש או $26.99 לשנה מסיר את המגבלה.

New פירושו שעדיין לא יוצא עם Download Claude conversations. Exported עוקב אחרי צ'אטים שכבר שמרתם, כך ש-Export All נוסף יכול לדלג עליהם. Project תואם לאופן שבו אתם מקבצים צ'אטים ב-claude.ai. החיפוש הוא לפי שם השיחה. התהליך המלא: ייצוא מרוכז עם Export All.

המכסה היא לכל החשבון. שלושה ייצואים בחינם בסך הכול — לא שלושה לכל הרצה מרוכזת. בחירה של 40 שיחות מנצלת 40 ייצואים אם כל הקבצים מושלמים. תכננו את הבחירה לפני שאתם לוחצים Export All, או השתמשו ב-Pro.

Export All משתמש באותם מתגי חשיבה, מטא-דאטה, שולח וארטיפקטים כמו שיחה בודדת. הוא מפיק קבצים רבים, אחד לכל צ'אט, ולא את ה-ZIP של החשבון ש-Anthropic שולחת באיחור. בוחרים פורמט אחד לכל הרצה. התוסף לא מערבב Markdown ו-JSON בלחיצה אחת.

האם התוסף שומר ארטיפקטים?

כן. תכונות התוסף כוללות פריסת ארטיפקטים: "Original",‏ "Inline",‏ "Nested" או "Flat" (מקורי, מוטמע, מקונן, שטוח). בלוקי חשיבה הם מתג אופציונלי למעקב אחר תהליך המחקר. Metadata יכול להוסיף כותרת, חותמות זמן ומודל. מסנן השולח מגביל את הקובץ ל-"all / human only / assistant only" (הכול / רק המשתמש / רק העוזר).

ארטיפקטים הם חלק מהשרשור ב-claude.ai, לא הורדה נפרדת. הפריסה משנה את מיקומם ב-Markdown,‏ JSON,‏ XML ובטקסט. ב-PNG הם מצוירים, לא נשמרים כסימון. אם החשיבה כבויה, הייצוא משמיט את החשיבה המורחבת גם אם claude.ai הציג אותה על המסך.

אם השרשור ארוך, גללו עד ש-claude.ai יטען את ההודעות המוקדמות. התוסף יכול לייצא רק את מה שהדף הציג. DOM טעון למחצה מפיק קובץ קטוע, שנראה כמו באג של ארטיפקט חסר, ובדרך כלל הוא פשוט שיחה שלא גללו בה.

איך התוסף מטפל בכניסה לחשבון?

כניסה עם Google נדרשת מהייצוא הראשון. התוסף משתמש בכניסה הזו כדי לספור את 3 הייצואים החינמיים לכל חשבון ולשחזר את Pro אחרי התקנה מחדש. תוכן השיחות אף פעם אינו חלק מהתהליך הזה. Download Claude conversations שומר אימייל שאומת על ידי Google לצורך המכסה ומצב המנוי.

3 הייצואים החינמיים לא מתאפסים כשמתקינים מחדש את התוסף. זו בדיוק מטרת הכניסה. Pro עולה $3.99 לחודש או $26.99 לשנה דרך Paddle. ‏Paddle היא הגורם המוכר הרשמי; הצוות שלנו אף פעם לא רואה מספרי כרטיסים. Pro משוחזר במחשב חדש מאותו חשבון Google.

לא צריך תוכנית בתשלום של claude.ai מ-Anthropic. התוכניות Free,‏ Pro,‏ Team ו-Enterprise של claude.ai עובדות אם Chrome יכול לפתוח את הצ'אט. אם מנהל סביבת העבודה חוסם תוספים, Download Claude conversations לא ייטען — זו מדיניות של הדפדפן, לא תכונה חסרה בדף הזה.

אילו תכונות אינן בגרסה 1.13.0?

התכונות שאינן בגרסה 1.13.0: PDF מובנה, ייצוא ל-Notion, ייצוא ל-Word, שליחה ל-Google Docs, חיבור ל-Claude Desktop ו-/export של Claude Code. Download Claude conversations הוא סקריפט תוכן של Chrome עבור claude.ai, לא אפליקציה נוספת בשם אחר.

Claude Desktop היא אפליקציה ל-Mac/Windows. Claude Code הוא הסוכן בטרמינל. אף אחד מהם לא מקבל את הכפתור הכתום. אם השרשור קיים גם ב-claude.ai, פתחו אותו ב-Chrome והשתמשו שם בתכונות התוסף. ההבדל מ-Desktop: ייצוא צ'אט מ-Claude Desktop. ההבדל מ-Code: ייצוא מ-Claude Code.

claude.ai בדפדפן בטלפון נמצא מחוץ לתחום. אין לצוות הזה אפליקציה ל-iOS או ל-Android ב-2026. הגרסה מתוארכת לספטמבר 2026. אם נוסיף פורמט, הדף הזה יתעדכן באותו יום. עד אז אל תצפו ל-PDF ברשימה הנפתחת.
