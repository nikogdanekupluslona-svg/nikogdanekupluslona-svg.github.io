איך מייצאים צ'אט של Claude מ-claude.ai?

פותחים את השיחה ב-claude.ai ב-Chrome, לוחצים על הכפתור הכתום ליד תיבת ההודעה, בוחרים Markdown, JSON, טקסט פשוט, XML או PNG ולוחצים «Export». ‏Download Claude conversations כותב את הקובץ מקומית. נכון לספטמבר 2026, אין ב-claude.ai עצמו פקד מובנה לייצוא של צ'אט בודד.

  1. התקינו את Download Claude conversations מ-Chrome Web Store (דירוג 5.0 בחנות).
  2. טענו מחדש את claude.ai ופתחו כתובת של שיחה אמיתית, לא את דף הבית הריק של תיבת הכתיבה.
  3. לחצו על כפתור ההורדה הכתום מימין לתיבת ההודעה.
  4. בחרו פורמט. תוסף הייצוא זוכר את הפורמט האחרון שבו השתמשתם.
  5. לחצו על «Export». ‏Chrome שומר את הקובץ מיד דרך ה-API להורדות של הדפדפן.

לפני הייצוא הראשון של צ'אט Claude נדרשת התחברות עם Google. ‏Download Claude conversations שומר את המייל המאומת כדי לספור את 3 הייצואים החינמיים ולשחזר Pro אחרי התקנה מחדש. טקסט הצ'אט לא חלק מההתחברות הזו. המנגנון: איך זה עובד.

אם הכפתור הכתום לא מופיע, אתם לא בכתובת של שיחה, הלשונית צריכה טעינה מחדש אחרי ההתקנה, או שסמל התוסף עדיין מוסתר בתפריט הפאזל של Chrome. הצמידו את Download Claude conversations ורעננו את claude.ai. תוסף הייצוא נטען רק ב-claude.ai, אף פעם לא באתרים אחרים.

שיחה אחת מול כל החשבון. הכפתור הכתום מייצא את הצ'אט הפתוח. להרבה קבצים, פתחו את «View and Download All Conversations» (הצגה והורדה של כל השיחות) והפעילו «Export All» (ייצוא הכול) — ראו ייצוא מרוכז עם Export All. ‏Settings → Privacy → Export data של Anthropic (התוויות עשויות להופיע בעברית אם claude.ai מוגדר לעברית) הוא ZIP של החשבון שמגיע באיחור, לא התהליך הזה.

מה תוסף ייצוא ל-Claude עושה בפועל?

תוסף ייצוא ל-Claude קורא את השיחה שכבר מוצגת בלשונית claude.ai המחוברת שלכם וכותב קובץ מובנה לדיסק. ‏Download Claude conversations הוא ה-content script הזה של Chrome: שולח, עץ הודעות, בלוקי קוד, טבלאות, חשיבה לבחירה ופריסת ארטיפקטים — לא צילום מסך של הממשק שמסביב לצ'אט.

העתק-הדבק מ-claude.ai מאבד הזחה ומקריס טבלאות. הדפסה (Ctrl/Cmd+P) משאירה את הסרגל הצדדי ולעתים קרובות חותכת בלוק קוד ארוך בין עמודים. תוסף הייצוא שומר על תגיות השפה בבלוקי הקוד ומשאיר טבלאות כטבלאות ב-Markdown, ב-JSON וב-XML. ‏PNG היא האפשרות לתמונת מצב חזותית; זה עדיין לא PDF.

פריסת ארטיפקטים היא אפשרות אמיתית בגרסה 1.13.0: ‏«Original», ‏«Inline», ‏«Nested» או «Flat» (מקורית, משולבת, מקוננת או שטוחה). בלוקי חשיבה הם לבחירה («include thinking»). מטא-דאטה (כותרת, חותמות זמן, מודל) יכולה להיכלל («include metadata»). סינון שולח יכול להגביל את הקובץ לכל ההודעות, רק למשתמש או רק לעוזר («all / human only / assistant only»). הרשימה המלאה: יכולות.

בנינו את הכפתור הכתום כדי שיכתוב קובץ אמיתי מהצ'אט שכבר נמצא ב-claude.ai — Markdown, ‏JSON, טקסט, XML או PNG — בלי להעלות את השיחה לשרתים שלנו. גרסה 1.13.0 עדיין לא מפיקה PDF.

Claude Code משתמש ב-/export או בתמלילי JSONL בדיסק. זה לא Markdown מתוסף Chrome הזה. אל תתקינו את Download Claude conversations בציפייה לחיבור לטרמינל. מדריך: ייצוא Claude Code. חיפוש של ייצוא צ'אט Claude עבור סשן CLI הוא מסלול של מוצר אחר.

claude.ai בדפדפן של טלפון גם הוא מחוץ לתחום. תוסף הייצוא צריך Chrome למחשב. אין מהצוות הזה אפליקציה ל-iOS או ל-Android ב-2026. פתחו את השיחה במחשב, ואז ייצאו את הצ'אט מהכפתור הכתום או מ-Export All.

לא. 3 הייצואים הראשונים בכל חשבון שמחובר עם Google הם בחינם, בכל פורמט. ‏Pro ב-$3.99 לחודש או $26.99 לשנה מסיר את המגבלה לעוד קבצים בודדים או מרוכזים.

כן. תוכניות Free, ‏Pro, ‏Team או Enterprise של claude.ai עובדות אם אפשר לפתוח את השיחה ב-Chrome. תוסף הייצוא לא דורש את התוכנית בתשלום של Anthropic.

לא. Download Claude conversations רץ ב-claude.ai ב-Chrome. ‏Claude Code משתמש ב-/export או ב-JSONL בדיסק. ראו את המדריך לייצוא Claude Code.

אפשר לייצא צ'אט של Claude מ-Claude Desktop?

לא עם תוסף Chrome הזה. פתחו את אותה שיחה ב-claude.ai אם היא מסונכרנת, או העתיקו-הדביקו / השתמשו ב-Export data הרשמי. ‏Desktop אף פעם לא מציג את הכפתור הכתום.

כמה ייצואים חינמיים נותן תוסף הייצוא ל-Claude?

שלושה לכל חשבון, משותפים לכפתור הכתום ול-Export All. התקנה מחדש לא מאפסת את המונה. ‏Pro משוחזר דרך ההתחברות עם Google.

איפה הכפתור הכתום לייצוא צ'אט של Claude?

מימין לתיבת ההודעה, בכתובת של שיחה ב-claude.ai, אחרי שמתקינים את Download Claude conversations וטוענים מחדש. הוא לא מופיע בדף הבית הריק של תיבת הכתיבה ולא ב-Desktop.

ייצוא צ'אט של Claude מעלה את השיחות שלי?

לא. הקבצים נבנים בדפדפן ונמסרים ל-API ההורדות של Chrome. ה-worker שלנו רואה מצב מנוי ומייל מאומת של Google, לא את תוכן הצ'אטים. פרטים בדף איך זה עובד.

באילו פורמטים תוסף הייצוא ל-Claude יכול לכתוב?

Markdown, ‏JSON, טקסט פשוט, XML ו-PNG — אותם חמישה לצ'אט בודד ול-Export All. אין ייצוא ל-PDF, ‏Word, ‏Notion או Google Docs בגרסה 1.13.0.
