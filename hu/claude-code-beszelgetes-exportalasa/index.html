Kezdőlap / Claude Code beszélgetés exportálása

Frissítve: 2026. szeptember · Bővítmény 1.16.2

Claude Code beszélgetés exportálása: melyik út a jó?

A Claude Code beszélgetés exportálása terminálos feladat: írd be a munkamenetben a /export parancsot, vagy másold ki a JSONL-fájlt a ~/.claude/projects mappából (angolul sokan „claude code export” néven keresik). Egy Claude Code-beszélgetést a terminálból nem az oldal narancssárga gombjával töltesz le. A Download Claude conversations a Chrome-ban megnyitott claude.ai chateket menti — a claude.ai/code címen futó webes Claude Code munkameneteket is. A helyi terminálos munkamenetek és a Desktop alkalmazás külön történet.

Download Claude conversations — ingyenes Chrome-bővítmény a claude.ai-hoz 1.16.2-es verzió (2026. szeptember) — korlátlan Markdown-, szöveg-, JSON-, XML-, CSV- és PNG-exportálás fiók nélkül; a PDF és a tömeges ZIP napi 3 alkalomig ingyenes

Mi a Claude Code beszélgetés exportálása a terminálban?

A Claude Code beszélgetés exportálása a /export parancs egy interaktív parancssori munkamenetben. Az Anthropic dokumentációja egy menüt ír le, amellyel az aktuális beszélgetést vágólapra másolhatod vagy egyszerű szöveges fájlba mentheted, az üzeneteket és az eszközkimeneteket olvasható szövegként megjelenítve. Ha fájlnevet adsz meg, a menü kimarad, és a parancs közvetlenül azt a fájlt írja.

Ez nem a claude.ai Markdownja, nem ennek a Chrome-bővítménynek a JSON-ja, és nem PDF. Emberi olvasásra szánt, megjelenített átirat. Az Anthropic szerint a lemezen lévő JSONL-napló egy másik, belső formátum, amely a termék működését szolgálja, nem nyilvános API-ként készült.

/export

A kérdés kihagyásához és egy elnevezett fájl írásához az aktuális munkakönyvtárba:

/export my-session

A kapcsolókról és fájlnevekről az Anthropic munkamenet-dokumentációja a hiteles forrás; ezek Claude Code-verziónként változnak. A közösségi blogokat másodlagos forrásként kezeld. Ha a /export párbeszédablakának szövege nem egyezik azzal, amit látsz, a parancssori eszközöd más buildből van — a terméken belüli súgót használd, ne egy 2025-ös képernyőképet.

Szkriptekhez az Anthropic más felületeket ajánl: a claude -p parancsot --output-format json vagy stream-json kapcsolóval, a munkamenet-azonosító szerinti folytatást, a transcript_path értéket kapó hookokat vagy az Agent SDK-t. Ezek a Claude Code fejlesztői felületei, nem ennek a weboldalnak a Chrome-bővítménye.

Olvasható kontra strukturált. A /export az emberi átirat. A projects mappa alatti JSONL a napló. A Chrome-bővítmény JSON-ja egy harmadik szerkezet, amely kizárólag egy claude.ai oldalból készül. Ne írj egyetlen feldolgozót mindháromhoz.

Hogyan tölthetek le egy Claude Code-beszélgetést a lemezről?

Egy Claude Code-beszélgetést úgy tölthetsz le a lemezről, hogy kimásolod a munkamenet JSONL-fájlját a projects könyvtárból, vagy olvasható átirathoz futtatod a /export parancsot. Az alapértelmezett útvonal macOS-en és Linuxon a ~/.claude/projects/ alatt van, Windowson a %USERPROFILE%\.claude\projects mappában. A fájlnevek a munkamenet-azonosítók.

A projektmappa neve a munkakönyvtár, amelyben a nem alfanumerikus karakterek kötőjelre cserélődnek. Az Anthropic a nagyon hosszú átalakított neveket levágja, és egy hash-t fűz hozzájuk, hogy a könyvtár a fájlrendszer korlátain belül maradjon. Ha nem találod a mappát, a Claude Code-ot más munkakönyvtárból indítottad, mint gondolod.

Minden JSONL-sor egy JSON-objektum egy üzenethez, eszközhasználathoz vagy metaadathoz. Az Anthropic kijelenti, hogy ez a bejegyzésformátum belső, és verziónként változik. Az ezeket a fájlokat feldolgozó szkriptek egy Claude Code-kiadással elromolhatnak. Ha stabil eredmény kell, inkább a /export parancsot vagy a dokumentált szkriptfelületeket használd.

A tárolás helye változhat. A CLAUDE_CONFIG_DIR a konfigurációs fát a ~/.claude helyett máshová teszi. A CLAUDE_CODE_PROJECT_DIR_NAME ezzel a konfigurációs könyvtárral együtt használva a projektkönyvtárat nevezi el (az Anthropic szerint a Claude Code v2.1.234-es vagy újabb verziójától). A settings.json cleanupPeriodDays beállítása az alapértelmezett megőrzési időt módosítja. Ezek egyike sem a Download Claude conversations funkciója.

A Claude Code-beszélgetések fájljainak letöltése biztonsági mentéshez tehát így megy: másold ki a mappát, vagy ütemezetten exportáld az átiratokat a /export paranccsal. Ez az oldal nem fog „JSONL importálása” gombot kapni. A saját mappádat nem olvassuk.

Működik a Claude Code exportálása ezzel a bővítménnyel?

Terminálos munkamenetekre nem. A Download Claude conversations nem olvassa a helyi Claude Code munkameneteket. A Chrome-bővítmény a claude.ai oldalra épül be. Nem látja a terminált, nem tudja futtatni a /export parancsot, és nem tud JSONL-t megnyitni. Kivétel a claude.ai/code címen futó webes Claude Code: az egy claude.ai oldal, így bármely chathez hasonlóan exportálható. Ha azt kerested, hogyan tölthetsz le egy Claude Code-beszélgetést a parancssorból, maradj az oldal parancssori lépéseinél.

Sokan azért jutnak ide, mert a Google egy csoportba sorolja a „Claude” és az „export” szavakat. A Web Store-bővítmény ettől még csak a claude.ai-on működik. A telepítése nem tesz narancssárga gombot az iTermbe, a Ghosttyba, a VS Code termináljába vagy a Claude Code asztali burkolójába.

Ha ugyanahhoz a programozási feladathoz a claude.ai oldalon is vezetsz egy párhuzamos beszélgetést, azt a böngészős chatet elmentheted a bővítménnyel. A két rekord nem olvad össze. A csak a parancssorban lefutott eszközhívások nem jelennek meg a webes exportban, hacsak be nem illesztetted őket oda.

Minden héten ugyanaz a támogatási levél érkezik: valaki telepítette a Chrome-bővítményt, és azt várta, hogy megjelenjen a /export. Mi csak a claude.ai-t dolgozzuk fel. A Claude Code-ban már eleve ott van a /export és a JSONL. A parancssor becsomagolása egy másik termék lenne, és ilyet nem adtunk ki.
A Download Claude conversations csapata — a Claude Chat Downloader Chrome-bővítmény fejlesztői

A bővítmény claude.ai-eszköz, nem Claude Code-bővítmény. A korlátai csak a claude.ai-ról történő exportálásra vonatkoznak: a Markdown, szöveg, JSON, XML, CSV és PNG korlátlan, fiók nélkül; a PDF és a tömeges ZIP Google-bejelentkezéssel napi 3 alkalomig ingyenes; a Pro havi 3,99 USD vagy évi 26,99 USD áron megszünteti a korlátot. Mindez nem méri a /export használatát.

Exportálhatom a webes Claude Code munkameneteket?

Igen. A webes Claude Code a claude.ai/code címen fut, így a Download Claude conversations ezeket a munkameneteket bármely claude.ai chathez hasonlóan exportálja. Nyisd meg a munkamenetet Chrome-ban, kattints a narancssárga gombra, válassz formátumot, és kattints az „Export” (exportálás) gombra. Ez az egyetlen Claude Code-felület, amelyet a bővítmény lefed.

A formátumok ugyanazok a hét, mint minden chatnél: PDF, Markdown, egyszerű szöveg, JSON, XML, CSV és PNG. A Markdown, szöveg, JSON, XML, CSV és PNG korlátlan, és nem kell hozzá fiók. A PDF Google-bejelentkezést kér, és az ingyenes csomagban a tömeges ZIP-pel osztozik a napi 3 alkalmon, hacsak nem vagy Pro. A kódblokkok megőrzik a nyelvi címkéiket. A kiterjesztett gondolkodás a panel „Thinking” (gondolkodás) jelölőnégyzete; az eszköz- / MCP-lépések és a webes keresési források a beállításokban kapcsolhatók be.

A webes exportálás azt rögzíti, amit a claude.ai/code a böngészőben mutat. Nem egy helyi parancssori futtatás JSONL-naplója, és nem éri el azokat a munkameneteket, amelyek csak a terminálodban futottak. Az Anthropic szerint a webes Claude Code saját munkamenet-előzményeket vezet, a parancssor ~/.claude/projects fájától külön. Terminálos munkamenethez továbbra is a /export az út.

Hol tárolja a Claude Code a beszélgetési előzményeket?

A Claude Code a beszélgetési előzményeket JSONL-átiratokként tárolja a konfigurációs könyvtár projects mappájában. Alapértelmezés macOS-en és Linuxon: ~/.claude/projects/<encoded-cwd>/<session-id>.jsonl. Windowson a %USERPROFILE%\.claude\projects mappa. Az Anthropic módosíthatja ezt a szerkezetet; ha egy útvonal hiányzik a lemezről, nézd meg az aktuális munkamenet-dokumentációt.

A folytatás más művelet, mint az exportálás. A claude --continue és a claude --resume újratölt egy munkamenetet, hogy dolgozhass tovább. A /export olyan másolatot ír, amelyet gitben hagyhatsz vagy e-mailben elküldhetsz. Az egyik visszaállítja a kontextust, a másik egy rekordot ad a kezedbe. Az Anthropic munkamenet-oldala leírja az engedélymódot folytatáskor, a tömörítést/összefoglalót és a választó működését — ezek egyike sem ez a bővítmény.

Az Anthropic szerint az asztali alkalmazás, a webes Claude Code és a VS Code-bővítmény mind saját munkamenet-előzményeket vezet. Ennek az útmutatónak az útvonalai a parancssorra vonatkoznak. A webes munkamenetek a claude.ai/code címen maradnak, ahol a bővítmény exportálni tudja őket. Ne feltételezd, hogy egy Desktop-alkalmazásbeli Cowork-átirat ugyanabban a JSONL-fában van, amelyet a terminálból használsz.

Ne kezeld a JSONL-t nyilvános sémaként. Az Anthropic szerint a sorformátum változik. Ha mégis feldolgozod, rögzíts egy Claude Code-verziót, és számíts hibákra. A /export a stabil módja annak, hogy emberileg olvasható Claude Code-beszélgetést kapj.

Az olyan környezeti kapcsolók, mint a CLAUDE_CODE_SKIP_PROMPT_HISTORY, letilthatják az átiratok írását. Ha a projects mappa üres, ellenőrizd, hogy nem kapcsoltad-e ki a mentést, nem irányítottad-e máshová a CLAUDE_CONFIG_DIR értékét, vagy futtattál-e egyáltalán interaktív munkamenetet abban a könyvtárban.

Hogyan tölthetek le inkább egy Claude chatet a claude.ai-ról?

Így tölthetsz le egy Claude chatet a claude.ai-ról: telepítsd a Download Claude conversations bővítményt, nyisd meg a beszélgetést Chrome-ban, kattints a narancssárga gombra, és válaszd a PDF, Markdown, egyszerű szöveg, JSON, XML, CSV vagy PNG formátumot. Ez a böngészős termék, és a claude.ai/code munkameneteket is lefedi. Nem a terminálos Claude Code exportálása. Lépésről lépésre: hogyan tölthetek le egy Claude chatet.

A teljes claude.ai-előzményt külön fájlokként az irányítópult (Dashboard) „Export All” (összes exportálása) funkciójával mentheted, nem a /export paranccsal. Az ingyenes csomagban a ZIP minden chatje beleszámít a napi 3 alkalomba (a PDF-fel közösen, éjfélkor UTC szerint nullázódik); a Pro megszünteti a korlátot. Útmutató: tömeges „Export All”. Formátumok: formátumok.

Az egy chatre szóló Markdown-, szöveg-, JSON-, XML-, CSV- vagy PNG-exportáláshoz nem kell fiók — ezek korlátlanok. Google-bejelentkezés csak a PDF-nél, a tömeges ZIP-nél és a Prónál jelenik meg, hogy számolhassuk a napi kvótát és visszaállíthassuk a Prót. A fájlok helyben készülnek, a PDF is. A Prót a Paddle számlázza havi 3,99 USD vagy évi 26,99 USD áron. Ezek egyike sem vonatkozik a terminálban futtatott /export parancsra.

Ha a munkád a Claude Code-ban kezdődött, és egy összefoglalót beillesztettél a claude.ai-ba, a webes beszélgetést jegyzetekhez töltsd le, a valódi parancssori naplóhoz pedig tartsd meg a /export kimenetét. Két fájl jobb, mint egy összezavart.

Claude Code exportálása vagy a hivatalos Anthropic Export data?

A Claude Code exportálása (/export vagy JSONL) egyetlen terminálos munkamenetre vonatkozik. A hivatalos Export data a claude.ai Settings → Privacy → Export data útvonala (a feliratok magyarul is megjelenhetnek, ha a claude.ai magyar nyelvre van állítva): az Anthropic-fiók késleltetett JSON-ZIP-je. A kettő nem ugyanaz az archívum. A ZIP nem helyettesíti a /export parancsot.

Hogy egy adott Claude Code munkamenet megjelenik-e a fiók-ZIP-ben, az attól függ, hogyan tárolja az Anthropic az adott terméket, nem ettől a bővítménytől. A ZIP-et webes fiókmentésként kezeld, hacsak az Anthropic aktuális adatvédelmi dokumentációja mást nem mond. Mi nem teszünk parancssori munkameneteket ebbe a ZIP-be.

Hogy hogyan exportálhatsz Claude chatet a weboldalról, beleértve a ZIP és a bővítmény összevetését, itt olvashatod: hogyan exportáljam a Claude chatet. A bővítmény PDF-exportálása terminálos felületre sem vonatkozik. A Claude chat letöltése PDF-ben útmutatót csak akkor nézd meg, ha a beszélgetés a claude.ai oldalon van, a claude.ai/code címet is beleértve.

Claude Code, Desktop vagy claude.ai exportálás?

A Claude Code, a Claude Desktop és a claude.ai három különböző felület. A Claude Code exportálása a /export parancsot és a JSONL-t használja. A Desktop egy alkalmazás, amelyben nincs meg ennek a bővítménynek a narancssárga gombja. A Chrome-ban megnyitott claude.ai az egyetlen hely, ahol a Download Claude conversations fut — a claude.ai/code címen futó webes Claude Code-dal együtt. Ha összekevered a neveket, az exportálás csendben meghiúsul.

Claude Desktop: ha a chat ugyanabba az Anthropic-fiókba szinkronizálódott, nyisd meg a claude.ai oldalon, és ott exportáld. Ha csak a Desktop ablakában létezik, másold ki, vagy várd meg a hivatalos Export data archívumot. Útmutató: Claude Desktop chat exportálása.

A VS Code Claude Code panelje közelebb áll a parancssorhoz, mint a claude.ai-hoz. Ne várd, hogy a tartalomszkriptünk abba a webview-ba beépüljön. Használd a /export parancsot abból a munkamenetből, amely valóban tartalmazza az üzeneteket.

Független Chrome-bővítmény, nem áll kapcsolatban az Anthropic, PBC céggel. A Claude az Anthropic védjegye. Tartsd be a felhasználási feltételeiket. Jogi tanácsot nem adhatunk a védett kódot tartalmazó eszközkimenetek másolásáról; ez közted, a munkáltatód és az Anthropic között dől el.

GYIK: Claude Code beszélgetés exportálása

Hogyan exportálhatok egy Claude Code-beszélgetést?

A Claude Code terminálban írd be a /export parancsot (opcionálisan fájlnévvel) egy megjelenített átirat mentéséhez, vagy másold ki a JSONL-fájlt a ~/.claude/projects mappából macOS-en/Linuxon, illetve a %USERPROFILE%\.claude\projects mappából Windowson. Az aktuális párbeszédablakot az Anthropic munkamenet-dokumentációja írja le.

Letölti ez a Chrome-bővítmény a Claude Code chateket?

A terminálból nem. A Download Claude conversations csak a claude.ai oldalon működik Chrome-ban. Nem tudja olvasni a helyi terminálos munkameneteket, a JSONL-átiratokat vagy a /export parancsot. A claude.ai/code címen futó webes Claude Code munkamenetek viszont bármely chathez hasonlóan exportálhatók.

Exportálhatom a webes Claude Code-ot (claude.ai/code)?

Igen. Nyisd meg a munkamenetet a claude.ai/code címen Chrome-ban, és használd a narancssárga gombot. PDF, Markdown, egyszerű szöveg, JSON, XML, CSV és PNG — mind működik. A hat nem PDF formátum korlátlan, fiók nélkül; a PDF-hez Google-bejelentkezés kell, és a napi 3 ingyenes alkalomba számít bele.

Hol tárolja a Claude Code a beszélgetési előzményeket?

A munkamenet-átiratok JSONL-fájlok a ~/.claude/projects/<encoded-working-directory>/ alatt, munkamenet-azonosító szerint elnevezve. A pontos szerkezet változhat. Ha JSONL-feldolgozás helyett olvasható fájl kell, használd a /export parancsot. A CLAUDE_CONFIG_DIR áthelyezheti a fát.

Hogyan tölthetek le egy Claude Code-beszélgetést Markdownként?

A Claude Code /export parancsa egyszerű szöveges átiratot ad, nem ennek a bővítménynek a Markdownját. Ha kifejezetten Markdown kell, exportálj egy claude.ai/code munkamenetet vagy a munka claude.ai-os másolatát a Download Claude conversations bővítménnyel, vagy alakítsd át magad a /export szövegét. JSONL-t nem alakítunk Markdownná.

Hogyan tölthetek le inkább egy claude.ai-beszélgetést?

Telepítsd az ingyenes Chrome-bővítményt, nyisd meg a chatet a claude.ai oldalon, és használd a narancssárga gombot — vagy az előzményekhez az „Export All” funkciót. Lásd: hogyan tölthetek le egy Claude chatet. A Markdown, szöveg, JSON, XML, CSV és PNG korlátlan, fiók nélkül; a PDF és a tömeges ZIP Google-bejelentkezéssel napi 3 alkalomig ingyenes; a Pro havi 3,99 USD vagy évi 26,99 USD.

Ugyanaz a /export, mint a hivatalos Export data?

Nem. A /export az aktuális Claude Code munkamenet. A Settings → Privacy → Export data az Anthropic-fiók JSON-ZIP-jét küldi el e-mailben. Más termékfelület, más fájlok, más várakozási idő.

Feldolgozhatom a Claude Code JSONL-t jq-val?

Igen, azzal a fenntartással, amelyet az Anthropic közzétesz: a sorséma belső, és változhat. Ha szerződésszerű stabilitás kell, inkább a /export vagy a claude -p --output-format json megoldást használd. Ha mégis JSONL-t dolgozol fel, rögzítsd a parancssori eszköz verzióját.

Működik a Claude Code exportálása Windowson?

Igen. A /export parancssori parancs. A lemezen lévő átiratok a %USERPROFILE%\.claude\projects mappában vannak, hacsak nem állítod be a CLAUDE_CONFIG_DIR értékét. Ez a Chrome-bővítmény ettől még nem fut abban a terminálban.

Ugyanaz a Claude Code, mint a Claude Desktop?

Nem. A Claude Code a terminálos programozási ügynök. A Claude Desktop a chatalkalmazás. A claude.ai a weboldal. Ezt a bővítményt csak a weboldal kapja meg, a claude.ai/code címmel együtt. A Desktop exportálásáról: Claude Desktop.

Becsomagolja valaha ez a bővítmény a /export parancsot?

Az 1.16.2-es verzióban nem. A termék hatóköre a claude.ai, a webes Claude Code-dal együtt: hét formátum, helyi fájlok, Google-bejelentkezés csak a PDF-hez, a tömeges exportáláshoz és a Próhoz. Ha ez a hatókör változik, ez az oldal jelezni fogja. Addig a terminálos Claude Code exportálásához az Anthropic parancssori eszközét használd.

Tartalmazza a /export az eszközkimeneteket?

Az Anthropic úgy írja le a /export parancsot, hogy az üzeneteket és az eszközkimeneteket olvasható szövegként jeleníti meg. Ez az ő átiratuk, nem a mi feldolgozónk. A pontos aktuális tartalomhoz futtasd a /export parancsot a saját buildeden, és olvasd el a fájlt — a dokumentáció késhet egy kiadáshoz képest.

Exportálhatok tömegesen Claude Code munkameneteket?

Helyi parancssori munkameneteket nem. Az irányítópult „Export All” funkciója csak a claude.ai-ra vonatkozik. Sok parancssori munkamenethez másold ki a projects mappát, vagy futtasd munkamenetenként a /export parancsot. JSONL-hez nincs narancssárga gombos tömeges exportálás.
