Frequently Asked Questions

Can I download a Claude conversation from claude.ai?

Not with a built-in button. Install Download Claude conversations from the Chrome Web Store, open the chat, and export a file.

Is this the same as Claude’s Export data?

No. Anthropic’s Settings → Privacy → Export data emails a ZIP of your account (JSON). This extension downloads the current chat — or a bulk selection — as readable files right away.

Do you store my Claude chats?

Export runs in the browser. We do not receive conversation content. We store a Google-verified email only to count free exports and attach a Pro subscription.

What’s the difference between download Claude chat and claude download chat?

Same task, two ways of typing it. Use the orange button on claude.ai either way.

Does it export PDF?

No. Current formats are Markdown, JSON, plain text, XML, and PNG. Print the page (Ctrl/Cmd+P → Save as PDF) if you need a quick visual PDF, or export Markdown and convert it.

Does it work with Claude Pro / Team?

Yes, if you can open the conversation in the browser on claude.ai. We are not Anthropic.

How do I save a Claude conversation?

Install the free Chrome extension, open the chat on claude.ai, click the orange button, and pick a format. That is how to save a Claude conversation as a real file. Print-to-PDF and Anthropic’s account ZIP are the other two options — comparison on how to download a Claude chat.

Does this download Claude Code conversations?

No. This extension only works on claude.ai in Chrome. Claude Code sessions use /export or JSONL files on disk — see Claude Code export.

Is Download Claude conversations affiliated with Anthropic?

No. Claude is a trademark of Anthropic, PBC. This is an independent Chrome extension, not an official Anthropic product.
