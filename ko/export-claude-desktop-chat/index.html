왜 여기서는 Claude Desktop 채팅을 내보낼 수 없나요?

Download Claude conversations는 claude.ai용 Chrome 콘텐츠 스크립트입니다. Claude Desktop은 독립 실행형 Mac/Windows 앱입니다. 그 창에는 확장 프로그램 도구 모음이 없으므로 주황색 버튼이 나타나지 않습니다. Desktop을 열어 둔 채 Chrome 확장 프로그램을 설치해도 Desktop에는 아무 변화가 없습니다.

Chrome 확장 프로그램은 호스트 권한과 일치하는 페이지에서 실행됩니다. 이 확장 프로그램은 claude.ai 대화 페이지와 일치합니다. Claude Desktop은 claude.ai 탭이 아닙니다. Desktop 앱 안에서 "Chrome에 추가"할 수는 없습니다. 버전 1.13.0(2026년 9월)에도 Desktop 플러그인, 메뉴 막대 도우미, Desktop 설치 폴더를 읽는 기능은 없습니다.

명확한 한계. Desktop 안에서 이 Chrome 확장 프로그램으로 Claude Desktop 채팅을 내보낼 수는 없습니다. 저희 위젯으로 Markdown, JSON, 텍스트, XML, PNG가 필요하다면 Desktop을 벗어나 Chrome에서 https://claude.ai를 열고 그곳에서 대화를 여십시오.

두 제품이 같은 브랜드를 쓰기 때문에 "Claude Desktop 채팅 내보내기"를 검색하는 분이 많습니다. 검색 결과에는 Desktop, claude.ai, Claude Code가 섞여 나옵니다. 하지만 파일은 서로 호환되지 않습니다. Desktop 스크린샷은 Markdown 내보내기가 아닙니다. Code의 JSONL 로그는 claude.ai 스레드가 아닙니다. 이 차이를 분명히 하려고 이 페이지를 만들었습니다.

claude.ai를 통해 Claude Desktop 채팅을 내보내려면?

많은 Desktop 세션은 웹과 같은 Claude 계정을 씁니다. 스레드가 claude.ai 기록에 있다면 Chrome에서 열고 Download Claude conversations를 쓰십시오. 이 확장 프로그램이 Claude Desktop 채팅 내보내기를 도울 수 있는 방법은 이것뿐입니다. 채팅이 먼저 claude.ai에 로드되어야 합니다.

  1. Desktop에서 헤매지 말고 Chrome에서 https://claude.ai를 열어 같은 계정으로 로그인합니다.
  2. 웹 기록에서 대화를 찾습니다. 없다면 복사해 붙여 넣기나 Export data로 넘어가십시오. Chrome이 한 번도 불러오지 않은 채팅은 가져올 수 없습니다.
  3. 주황색 버튼을 누릅니다. Markdown, JSON, 일반 텍스트, XML, PNG 중 하나를 고르고 "Export"(내보내기)를 누릅니다.
  4. 동기화된 스레드가 많다면 "View and Download All Conversations"(모든 대화 보기 및 다운로드)를 열고 "Export All"(모두 내보내기)을 실행합니다.
  5. 웹에서 보이는 화면을 PDF 같은 페이지로 남기려면 Chrome에서 인쇄하십시오. 저희는 PDF를 지원하지 않습니다. 가이드: 인쇄 / PDF.

웹에서 처음 내보낼 때의 Google 로그인은 무료 내보내기 3회를 집계하고 Pro(월 $3.99 또는 연 $26.99)를 복원하는 데 쓰입니다. 이 사용량은 claude.ai 파일에만 적용됩니다. Desktop에서 복사해 붙여 넣는 것은 확장 프로그램을 거치지 않으므로 사용량을 쓰지 않습니다. Pro 결제는 Paddle이 처리하며, 저희는 카드 번호를 보지 않습니다.

동기화는 Anthropic의 동작이지 저희 것이 아닙니다. Desktop에는 있는데 claude.ai에는 없는 채팅을 이 Chrome 확장 프로그램이 만들어 낼 수는 없습니다. 기다리거나 claude.ai를 새로 고치거나, 복사해 붙여 넣기 / 공식 ZIP을 쓰십시오. 저희는 Desktop의 로컬 데이터베이스를 읽지 않습니다. 탭이 열린 뒤 웹 내보내기가 작동하는 방식: 작동 방식.

claude.ai에 도착한 뒤의 형식. 노트에는 Markdown, 도구에는 JSON, 간단한 보관에는 텍스트, 데이터 교환에는 XML, 그림에는 PNG. 다른 가이드와 같은 5가지입니다. 허브: 형식. 이 확장 프로그램으로는 어떤 형식도 Desktop 앱 안에 나타나지 않습니다.

복사해 붙여 넣기로 Claude Desktop 채팅을 내보낼 수 있나요?

네. Claude Desktop에서 텍스트를 선택해 문서에 붙여 넣으면 됩니다. 스레드가 claude.ai에 보이지 않을 때 쓸 수 있는 정직한 대안입니다. 코드 블록의 정확성, 아티팩트 레이아웃, 사고 과정 옵션, 일괄 Export All은 잃게 됩니다. 짧은 답변에는 괜찮지만 긴 코딩 스레드에는 고생스럽습니다.

Desktop에서 복사해 붙여 넣는 불편함이 claude.ai용 Chrome 확장 프로그램이 존재하는 이유입니다. 웹 위젯은 언어 태그, 표, "Original"(원본)/"Inline"(인라인)/"Nested"(중첩)/"Flat"(평면) 아티팩트 레이아웃을 유지합니다. Desktop에는 저희의 내보내기 옵션이 전혀 없습니다. 같은 대화를 claude.ai로 옮길 수 있다면 복사해 붙여 넣기를 그만두고 그곳에서 Download Claude conversations를 쓰십시오.

Claude Desktop 스크린샷도 대안입니다. 하지만 그림일 뿐 Markdown이 아닙니다. 다시 쓸 수 있는 파일이라는 의미의 Claude Desktop 채팅 내보내기로는 볼 수 없습니다. 저희 확장 프로그램의 PNG도 그림이지만, 채팅을 claude.ai에서 연 뒤에만 만들어집니다. Desktop 창에서 그 PNG를 기대하지 마십시오.

Export data에 Claude Desktop 채팅이 포함되나요?

Anthropic의 Settings → Privacy → Export data(claude.ai를 한국어로 설정했다면 메뉴 이름이 번역되어 보일 수 있습니다)는 어느 창에서 입력했는지가 아니라 Claude 계정에 연결된 JSON ZIP을 이메일로 보냅니다. Desktop 대화가 그 계정에 저장되어 있다면 포함될 수 있습니다. ZIP은 백업으로 보시고, 이 확장 프로그램의 Markdown과 같다고 생각하지 마십시오.

ZIP은 느리고, 링크는 만료되며, Markdown, 텍스트, XML, PNG를 고르는 형식 선택기도 없습니다. 그래도 Claude Desktop 채팅 기록을 한 덩어리로 내보내야 할 때 계정 데이터를 가져가는 공식 방법입니다. 인쇄 및 Chrome 위젯과의 비교: Claude 채팅 내보내기 방법.

이 ZIP을 목록 페이지의 일괄 Export All과 혼동하지 마십시오. Export All은 claude.ai에서 고른 대화를 원하는 형식의 개별 파일로 즉시 만들며, 파일마다 무료 내보내기 3회 중 1회(또는 Pro)를 씁니다. 공식 Export data는 저희 사용량을 쓰지 않습니다. 동기화되지 않은 Desktop 전용 채팅은 둘 다에서 빠져 있을 수 있습니다.

Claude Desktop과 Claude Code는 같은 것인가요?

아니요. Claude Desktop은 채팅 앱입니다. Claude Code는 /export와 JSONL 기록을 쓰는 터미널 코딩 에이전트입니다. IDE 터미널 때문에 "Claude Desktop 채팅 내보내기"를 검색했다면 다른 제품을 찾은 것입니다. 이 Chrome 확장 프로그램은 두 환경 어디에서도 실행되지 않습니다.

"데스크톱"이 VS Code나 데스크톱의 터미널을 뜻했다면 Claude Code 내보내기를 따르십시오. Anthropic의 Desktop 채팅 앱을 뜻했다면 이 페이지를 계속 보십시오. 둘을 섞으면 시간만 낭비합니다. 디스크의 JSONL은 주황색 버튼이 아니고, Desktop에서의 복사해 붙여 넣기는 /export가 아닙니다.

Desktop과 Code가 둘 다 "브라우저가 아니라는" 이유만으로 Download Claude conversations에 Code 연동이 생기지는 않습니다. 제품 범위는 의도적으로 좁습니다: Chrome의 claude.ai, 5가지 형식, 무료 내보내기 3회, Pro 월 $3.99 또는 연 $26.99. 기능 범위: 기능. 웹 버튼을 "추출기" 관점에서 설명한 페이지: Claude 대화 추출기.

Claude Desktop 채팅 내보내기를 위해 하지 않는 일

저희는 Claude Desktop 플러그인, 메뉴 막대 앱, "Desktop에서 내보내기" 옵션을 제공하지 않습니다. Mac이나 Windows의 Claude Desktop 설치 파일을 읽지 않습니다. Claude Code의 /export를 대신하지 않습니다. 이것이 1.13.0 기준 Claude Desktop 채팅 내보내기에 대한 제품의 경계입니다.

다른 Chrome 내보내기 도구의 이름도 언급하지 않습니다. Anthropic의 공식 제품 — claude.ai, Claude Desktop, Claude Code, Settings → Privacy → Export data — 은 비교를 위해 이름을 밝혔습니다. Download Claude conversations는 Anthropic, PBC와 제휴하지 않은 독립 제품입니다. 이 페이지에 인용한 Chrome Web Store 평점 5.0은 웹 확장 프로그램의 평점이며, 존재하지 않는 Desktop 제품의 평점이 아닙니다.

Desktop만 쓴다면 Anthropic이 앱에 채팅별 파일 내보내기를 추가할 때까지 복사해 붙여 넣기와 공식 ZIP을 쓰십시오. claude.ai도 쓴다면 확장 프로그램을 설치하고 브라우저에서 내보내십시오. 저희가 정직하게 제안할 수 있는 것은 이것이 전부입니다. 모바일 Claude 앱도 마찬가지로 이 확장 프로그램의 범위 밖입니다.

웹 경로의 사용량 안내. 동기화된 채팅을 claude.ai에서 열면 3회까지 무료로 내보낼 수 있고, 그 이후 Pro는 월 $3.99 또는 연 $26.99입니다. Desktop에서의 복사해 붙여 넣기는 이 횟수를 늘리지 않습니다. Google 로그인은 실제로 Chrome 위젯을 쓸 때만 필요합니다.

이 확장 프로그램으로 Claude Desktop 채팅을 내보낼 수 있나요?

아니요. Download Claude conversations는 Chrome 안의 claude.ai에서 작동합니다. 주황색 버튼은 Claude Desktop 창에 나타나지 않습니다. 버전 1.13.0에는 Desktop 플러그인이 없습니다.

Claude Desktop 대화는 어떻게 내보내나요?

같은 채팅이 동기화된다면 Chrome의 claude.ai에서 열고 확장 프로그램이나 인쇄를 쓰십시오. 그렇지 않다면 Desktop에서 복사해 붙여 넣거나, Settings → Privacy → Export data로 계정 전체의 JSON ZIP을 받으십시오.

Claude Desktop과 Claude Code는 같은 것인가요?

아니요. Desktop은 채팅 앱입니다. Claude Code는 /export와 JSONL 기록을 쓰는 터미널 에이전트입니다. 이 Chrome 확장 프로그램은 둘 중 어디에서도 실행되지 않습니다.

공식 Export data에 Desktop 채팅도 포함되나요?
