Claude는 대화 기록에 대화를 이미 저장하나요?

네. Claude.ai는 로그인한 대화를 Anthropic 계정의 대화 기록에 이미 저장합니다. 탭을 닫아도 대화는 지워지지 않습니다. 그래도 디스크에 파일을 써 주는 저장 버튼은 여전히 없습니다. Claude 대화를 Markdown이나 JSON으로 저장하는 것은 대화 기록과는 별개의 작업입니다.

대화 기록은 claude.ai 왼쪽에 있는 채팅 목록입니다. 각 행은 Anthropic이 해당 로그인에 대해 저장한 대화입니다. 나중에 행을 열면 같은 대화가 그대로 돌아옵니다. 이것은 계정 저장소이지, 노트북의 다운로드 폴더가 아닙니다.

‘클로드 대화 저장’을 검색하는 분은 대개 “나가면 이 대화가 사라질까?”를 묻고 있습니다. 로그인한 일반 세션이라면 답은 ‘아니요’입니다. Claude.ai는 계정에 대화를 남기기 위해 저장 버튼을 누를 필요가 없습니다. 빠진 것은 파일 내보내기 기능이지, 대화를 유지하는 스위치가 아닙니다.

대화 기록은 Markdown 파일도, grep으로 검색할 수 있는 JSON 트리도, 슬라이드에 넣을 PNG도 아닙니다. 대화 기록은 Anthropic 로그인 뒤에 있습니다. 로그인할 수 없으면 그 채팅도 열 수 없습니다. 로컬 파일은 비밀번호를 잃어도 열립니다.

두 가지 ‘저장’. 대화 기록 = Anthropic이 계정에 채팅을 보관하는 것. 파일 = 사용자가 PDF, Markdown, JSON, 텍스트, XML, CSV, PNG를 디스크에 쓰는 것. Claude.ai에는 첫 번째가 있습니다. 두 번째를 위한 버튼은 Claude.ai에 없습니다.

claude.ai의 프로젝트와 최근 항목도 여전히 대화 기록입니다. 채팅을 프로젝트에 넣어도 파일이 생기지 않습니다. 대화 이름을 바꿔도 파일이 생기지 않습니다. 화면에 즐겨찾기나 고정 기능이 있더라도 Markdown이 만들어지지는 않습니다. Download Claude conversations는 프로젝트 안의 채팅도 다른 채팅처럼 내보내며, 프로젝트 페이지에서 “Project files” → “Download ZIP”(프로젝트 파일 → ZIP 다운로드)을 누르면 프로젝트의 파일을 저장할 수 있습니다.

Team과 Enterprise 워크스페이스도 같은 구분을 따릅니다. claude.ai에서 대화를 열 수 있다면 Anthropic이 이미 워크스페이스에 그 대화를 저장해 둔 것입니다. 다만 회사 보존 정책에 따라 사용자가 통제할 수 없는 일정으로 채팅이 삭제되거나 숨겨질 수 있습니다. 그때 남는 것은 직접 내보낸 파일입니다.

시크릿 모드와 다른 Chrome 프로필은 대화 기록을 공유하지 않습니다. 대화는 해당 세션에서 쓴 Anthropic 계정에 묶여 있습니다. 다른 Anthropic 계정으로 로그인하면 다른 대화 기록이 보입니다. 계정 간 ‘저장’은 대화 기록 병합이 아니라 파일입니다.

Claude 대화를 파일로 저장하려면?

Claude 대화를 파일로 저장하려면 디스크에 쓰는 방법을 고르세요. Chrome의 Download Claude conversations, 인쇄 → PDF로 저장, 또는 Settings → Privacy → Export data입니다. claude.ai의 대화 기록은 계정 저장소이지 PDF, Markdown, JSON, 텍스트, XML, CSV, PNG 파일이 아닙니다.

Chrome 확장 프로그램은 채팅별로 저장하는 방법입니다. 대화 URL을 열고, 메시지 입력창 옆의 주황색 버튼을 누르고, 형식을 고른 뒤 Export를 누르세요. Chrome의 다운로드 API가 파일을 로컬에 씁니다. Markdown, 텍스트, JSON, XML, CSV, PNG에는 계정이 필요 없고, Google 로그인을 요청하는 것은 PDF뿐입니다. 채팅 본문은 컴퓨터에 머뭅니다.

인쇄는 시각적인 방법입니다. Ctrl+P 또는 Cmd+P를 누르고 대상을 “PDF로 저장”으로 고르세요. 결과물은 claude.ai 페이지처럼 보이며, 인쇄 스타일이 숨기지 못한 화면 요소도 함께 찍힙니다. 코드 블록은 페이지 사이에서 잘리는 경우가 많습니다. 노트 파일이 아니라 검토자에게 보여 줄 스냅샷이 필요할 때 인쇄를 쓰세요. 화면이 아니라 메시지로 만든 PDF가 필요하면 확장 프로그램에서 PDF를 고르세요.

공식 Export data는 계정 단위 방법입니다. claude.ai의 Settings → Privacy → Export data입니다. Anthropic이 만료되는 링크를 이메일로 보내 줍니다. ZIP은 계정 전체의 JSON이며, 화면에 띄운 채팅 하나의 이름이 붙은 파일이 아닙니다. 기다리는 시간이 전체 백업의 대가입니다.

목적에 맞는 행을 고르세요. Claude 채팅 저장 방법을 찾는 사람 대부분은 두 번째 행, 즉 Obsidian, VS Code, 위키에서 열 수 있는 파일을 원합니다. 첫 번째 행은 대화 기록이 이미 해결했습니다. 인쇄와 Export data도 실제로 쓸 만하지만, 해결하는 문제가 다릅니다.

퇴사 전, 노트북 초기화 전, 연구 자료 보관 전, 코드 리뷰를 git에 붙여넣기 전에는 파일로 남기는 것이 맞습니다. 같은 Anthropic 계정으로 내일 같은 대화를 다시 열기만 하면 된다면 대화 기록으로 충분합니다.

복사해 붙여넣기는 다섯 번째 방법이지만 파일로서는 약합니다. claude.ai에서 텍스트를 선택해 문서에 붙여넣으면 코드 블록이 무너지고, 표는 한 줄로 이어지며, 메시지 경계가 사라집니다. 문단 하나에는 괜찮지만, 40턴짜리 설계 리뷰의 유일한 저장본으로는 부족합니다. 확장 프로그램의 “Copy”(복사) 버튼을 쓰면 대신 깔끔한 Markdown이 클립보드에 담깁니다.

Chrome 확장 프로그램으로 Claude 채팅을 저장하려면?

Download Claude conversations로 Claude 채팅을 저장하는 방법은 이렇습니다. Chrome 확장 프로그램을 설치하고, claude.ai에서 대화를 연 다음, 메시지 입력창 옆의 주황색 버튼을 누르고 PDF, Markdown, JSON, 텍스트, XML, CSV, PNG 중 하나를 고른 뒤 Export를 누르세요. PDF를 제외하면 계정이 필요 없습니다.

  1. Chrome Web Store에서 Download Claude conversations를 설치합니다(Chrome 확장 프로그램을 불러올 수 있는 Chromium 브라우저에서도 작동합니다).
  2. 설치하는 동안 claude.ai 페이지가 열려 있었다면 새로고침합니다. Chrome은 오래된 탭에 콘텐츠 스크립트를 항상 넣어 주지는 않습니다.
  3. 대화 기록에서 실제 대화 URL을 엽니다. 주황색 버튼은 빈 입력 화면이 아니라 대화 스레드에서 나타납니다.
  4. 메시지 입력창 오른쪽의 둥근 주황색 다운로드 버튼을 누릅니다. “Messages”(메시지: All / Human / Assistant), 형식, “Thinking”(사고 과정), “Select”(선택), “Copy”, “Export”(내보내기)가 있는 패널이 열립니다.
  5. PDF, Markdown, 일반 텍스트, JSON, XML, CSV, PNG 중에서 고르고 Export를 누릅니다. Chrome이 바로 파일을 다운로드합니다.

이 확장 프로그램은 claude.ai에서만 동작하는 Chrome 콘텐츠 스크립트입니다. 파서는 로그인된 세션에 이미 불러온 대화를 읽습니다. Download Claude conversations는 자체 자격 증명으로 별도의 Anthropic API를 호출하지 않으며, 파일을 만들기 위해 대화를 저희 서버에 올리지도 않습니다.

Markdown, 일반 텍스트, JSON, XML, CSV, PNG에는 계정이 필요 없습니다. 이 형식으로 채팅 하나를 내보내는 것은 무제한 무료이며, 로그인도 횟수 제한도 없습니다. Google 로그인은 PDF를 고르거나 일괄 “Export All”(모두 내보내기)을 실행할 때만 나타납니다. Google 로그인은 채팅을 읽기 위한 로그인이 아닙니다. 대화 본문은 사용자 컴퓨터에 머뭅니다.

PDF와 일괄 ZIP은 하루 3회의 무료 한도를 함께 쓰며, 이 한도는 UTC 자정에 초기화됩니다. 일괄 ZIP 안의 채팅은 하나하나가 1회로 계산됩니다. Pro는 월 $3.99 또는 연 $26.99이며 이 제한을 없애 줍니다. Pro 결제는 Paddle이 처리하며, 저희는 카드 번호를 보지 못합니다. PDF 단계: Claude 채팅을 PDF로 다운로드하기.

로컬 파일. PDF를 포함한 모든 형식이 브라우저 안에서 만들어져 Chrome의 다운로드 API로 전달됩니다. 채팅 텍스트는 절대 업로드되지 않습니다. Google 이메일과 함께 사용 한도 확인을 보내는 것은 PDF와 일괄 내보내기뿐입니다. 버전 1.16.2, 2026년 9월 기준입니다.

같은 패널에서 발신자별로 필터링할 수 있습니다. “All”, “Human”, “Assistant”(전체, 사용자, 어시스턴트) 중 하나를 고르면 됩니다. “Thinking” 체크박스로 확장 사고(extended thinking)를 넣거나 뺍니다. “Select”로 메시지를 하나씩 체크하면 파일에 그 턴만 담깁니다. “Copy”는 파일을 다운로드하는 대신 Markdown, 텍스트, JSON, XML, CSV를 클립보드에 담습니다. 도구 / MCP 단계와 웹 검색 출처는 설정(Settings)에서 켜는 선택 항목입니다. 메타데이터와 아티팩트 배치(“Original”, “Inline”, “Nested”, “Flat”)는 대시보드(Dashboard)에서 정합니다.

대화가 아주 길다면 claude.ai가 이전 메시지를 불러올 때까지 스크롤하세요. 확장 프로그램은 페이지에 렌더링된 내용만 내보낼 수 있습니다. 절반만 불러온 대화는 절반짜리 파일이 됩니다. 버그처럼 보이지만 대개는 스크롤하지 않은 DOM 때문입니다.

Export 전에 어시스턴트의 응답이 끝날 때까지 기다리세요. 응답 도중에 저장하면 마지막 답변이 잘린 파일이 됩니다. Markdown이나 JSON은 다시 시도해도 비용이 들지 않습니다. 반면 PDF를 다시 만들면 무료 플랜의 하루 3회 중 1회를 더 쓰므로, 먼저 대화가 완료되었는지 확인하세요.

마지막으로 사용한 형식이 기억됩니다. Markdown을 원했는데 JSON을 받았다면, 드롭다운이 이전 내보내기의 JSON으로 남아 있었던 것입니다. 작업이 바뀔 때마다 드롭다운을 확인하세요. 같은 주황색 버튼의 단계별 스크린샷은 Claude 채팅 다운로드 방법에 있습니다.

매주 같은 혼동을 듣습니다. 대화 기록이 곧 사라질 임시 초안이라고 생각해서 저장 버튼을 찾는 것이죠. Claude.ai는 이미 대화를 저장해 두었습니다. 저희 주황색 버튼은 이미 연 페이지에서 로컬 파일(PDF, Markdown, JSON, 텍스트, XML, CSV, PNG)을 만들 뿐입니다.

확장 프로그램 없이 Claude 대화를 저장하려면?

확장 프로그램 없이 Claude 대화를 저장하려면 claude.ai 페이지를 인쇄하거나 Anthropic의 Export data ZIP을 요청하세요. 인쇄는 웹페이지의 시각적 PDF이고, Export data는 나중에 도착하는 계정 전체 JSON 아카이브입니다. 둘 다 채팅별 Markdown 파일은 만들지 않습니다.

인쇄 방법: claude.ai에서 대화를 열고, 가능하면 사이드바를 숨긴 다음, Ctrl+P(Windows/Linux) 또는 Cmd+P(Mac)를 누르세요. 대상을 “PDF로 저장”으로 설정하고 저장합니다. 입력창 같은 화면 요소가 매 페이지에 반복될 수 있습니다. 인쇄에 관한 자세한 내용은 Claude 채팅을 PDF로 저장하기에 있습니다.

공식 방법: claude.ai의 Settings → Privacy → Export data. Anthropic이 만료되는 링크를 이메일로 보내 줍니다. 수천 개 중 대화 하나가 필요하면 직접 ZIP을 풀어야 합니다. 이 아카이브는 공식 보관용 백업이지, 내일 회의에 쓸 노트 파일이 아닙니다.

복사해 붙여넣기는 아무것도 설치하지 않고 쓸 수 있습니다. claude.ai에서 대화를 선택해 메모 앱에 붙여넣으면 됩니다. 코드의 들여쓰기는 대개 무너지고, 여러 번 주고받은 대화는 구조 없는 텍스트 덩어리가 됩니다. 코드 조각 하나에만 쓰고, 유일한 대화 저장 방법으로 삼지는 마세요.

휴대폰의 모바일 Safari와 Chrome으로도 인쇄는 할 수 있습니다. 하지만 이 브라우저들에는 이 Chrome Web Store 항목을 설치할 수 없습니다. 다시 쓸 수 있는 Markdown 파일이 필요하면 확장 프로그램을 추가한 뒤 데스크톱 Chrome에서 같은 대화 기록 항목을 여세요.

탭을 닫은 뒤에도 대화 기록에 Claude 대화가 남나요?

네. 로그인한 상태에서 만든 채팅이라면 탭을 닫거나, claude.ai를 새로고침하거나, 노트북을 꺼도 대화 기록에 Claude 대화가 남습니다. 탭을 닫는 것은 삭제가 아닙니다. 계정 화면에서 대화를 없애는 동작은 대화 기록에서의 삭제입니다.

claude.ai에서 로그아웃하면 페이지가 비어 보입니다. 같은 Anthropic 계정으로 다시 로그인하면 대화 기록에 그 채팅이 돌아옵니다. 로그아웃은 목록을 숨길 뿐, 그 자체로 계정 저장소를 지우지 않습니다. 다른 Anthropic 계정으로 로그인하면 다른 대화 기록이 보입니다.

실제로 대화가 사라지는 경우는 대화 기록에서 삭제했을 때입니다. claude.ai 화면에서 대화를 삭제하면 사이드바에서 사라집니다. 주황색 버튼으로 이미 내보낸 Markdown 파일은 디스크에 남습니다. 채팅을 정리할 예정이라면 먼저 내보내세요.

삭제는 닫기가 아닙니다. claude.ai 탭을 닫아도 대화 기록은 그대로입니다. 대화 기록에서 대화를 삭제하면 계정 화면에서 채팅이 사라집니다. Anthropic이 더 이상 그 대화를 포함하지 않는다면 삭제 후에는 공식 Export data도 도움이 되지 않습니다. 정리하기 전에 파일을 만드세요.

시크릿 모드는 창을 닫으면 끝납니다. 로그인을 유지하지 않고 시크릿 창에서 claude.ai를 썼다면 대화 기록이 작업을 보관했다고 가정하지 마세요. 일반 Chrome 프로필에서 로그인하거나, 시크릿 세션이 끝나기 전에 파일로 내보내세요.

Team과 Enterprise에서는 워크스페이스 관리자가 채팅을 보존하거나 제한할 수 있습니다. 사용자가 정하지 않은 정책 때문에 나중에 대화가 숨겨질 수 있습니다. 회사 대화 기록은 빌린 저장소로 여기고, 내보낸 Markdown이나 JSON 파일을 정책 바깥에 있는 내 사본으로 여기세요.

두 기기가 같은 Anthropic 계정을 쓴다면 휴대폰에서 노트북으로 옮길 때 별도의 저장 동작은 필요 없습니다. 노트북에서 대화 기록을 여세요. 채팅이 없다면 다른 계정이나 다른 워크스페이스에 로그인했거나, 대화가 삭제된 것입니다. ‘저장하지 않아서’가 아닙니다.

Claude Desktop 앱이 같은 Anthropic 사용자로 로그인되어 있다면 같은 계정의 채팅이 표시될 수 있습니다. 동기화는 Anthropic이 담당합니다. Chrome 확장 프로그램은 Desktop에 들어가지 않습니다. 대화가 claude.ai에 있다면 Chrome에서 claude.ai를 열어 파일을 만드세요.

Claude 대화를 Markdown이나 JSON으로 저장하려면?

Claude 대화를 Markdown이나 JSON으로 저장하려면 claude.ai에서 주황색 버튼을 열고 형식을 고른 뒤 Export를 누르세요. Markdown은 노트용 파일, JSON은 스크립트용 메시지 트리입니다. 일반 텍스트에는 마크업이 없습니다. CSV는 메시지 하나가 한 행입니다. PDF는 페이지로 나뉜 문서이고, PNG는 이미지입니다.

Markdown은 제목, 언어 태그가 붙은 코드 블록, 표를 유지합니다. Obsidian, GitHub, 위키에 넣을 때 주로 고르는 형식입니다. 이 형식의 레이아웃 설명: Markdown 내보내기. JSON은 파서가 만든 트리를 그대로 보존하며, 해당 옵션을 켜면 아티팩트와 사고 과정도 포함합니다.

Download Claude conversations의 JSON은 Anthropic 계정 ZIP과 구조가 다릅니다. 확장 프로그램의 JSON은 페이지에 렌더링된 대화 하나입니다. Export data의 JSON은 Anthropic이 나중에 이메일로 보내는 계정 덤프입니다. 키를 확인하지 않고 두 스키마를 한 스크립트에서 섞어 쓰지 마세요.

일반 텍스트는 마크업이 제거되는 곳에 넣을 때 알맞습니다. 티켓 입력란, 이메일 본문, 순수 문자열이 필요한 검색 색인 같은 경우입니다. XML은 특수한 데이터 교환용입니다. CSV는 Excel, Google Sheets, Numbers에서 열립니다. PNG는 슬라이드나 버그 리포트에 넣을 대화 그림용이며, 나중에 grep으로 검색할 40턴짜리 리뷰에는 맞지 않습니다.

PDF는 버전 1.16.2에 기본으로 들어 있습니다. PDF를 고르면 대화상자에서 파일 이름, 페이지 크기, 여백, 라이트 또는 다크 모드, 글꼴과 글자 크기, 페이지 번호, 목차, 타임스탬프, 프롬프트마다 페이지 나누기를 정할 수 있습니다. PDF는 Google 로그인이 필요하며 무료 플랜에서는 하루 3회로 제한됩니다. Pro는 무제한입니다. 자세한 내용: Claude 채팅 PDF 저장.

사고 과정, 메타데이터, 발신자 필터, 아티팩트 배치 옵션에 따라 Markdown과 JSON에 담기는 내용이 달라집니다. 확장 사고 과정을 아카이브에 남겨야 한다면 패널에서 “Thinking”을 체크하세요. 최종 답변만 봐야 하는 독자를 위한 파일이라면 체크하지 마세요. 메타데이터를 켜면 제목, 타임스탬프, 모델이 노트 파일 머리말에 추가됩니다.

“Messages”에서 “Human”(사용자)을 고르면 내 프롬프트를, “Assistant”(어시스턴트)를 고르면 Claude의 답변을 씁니다. “All”(전체)은 전체 대화입니다. “Select”를 쓰면 체크한 메시지만 파일에 담깁니다. 대시보드의 아티팩트 배치(“Original”, “Inline”, “Nested”, “Flat”)는 아티팩트를 파일 안에 둘지, ZIP 안의 별도 폴더에 둘지를 바꿉니다. 배치를 한 번 정해 계속 쓰면 저장한 채팅 폴더가 일관되게 유지됩니다.

Claude 대화 기록을 한꺼번에 저장하려면?

Claude 대화 기록을 여러 파일로 저장하려면 탭마다 주황색 버튼을 반복해서 누르지 마세요. 확장 프로그램 팝업에서 “View and Download All Conversations”(모든 대화 보기 및 다운로드)를 열고, 표를 필터링한 다음 “Export All”을 누르세요. Export All은 Google 로그인을 요청합니다. 무료 플랜에서는 ZIP 안의 채팅 하나하나가 PDF와 함께 쓰는 하루 3회 중 1회를 씁니다. Pro는 이 제한을 없애 줍니다.

대시보드에는 로그인한 claude.ai 계정의 대화가 표시됩니다. 이미 가진 대화 기록을 필터링할 수 있는 표로 바꾼 것입니다. 이름으로 검색하고, “All conversations”, “New”, “Updated”, “Previously exported”(전체 대화 / 새 항목 / 업데이트됨 / 이전에 내보냄)로 필터링할 수 있습니다. Chat 탭과 Cowork 탭을 오갈 수 있고, claude.ai에서 프로젝트로 채팅을 묶어 두었다면 프로젝트로 검색할 수도 있습니다.

일괄 내보내기는 “Chat format”(채팅 형식) 선택기에서 고른 형식으로, 채팅마다 파일 하나씩 담은 ZIP 하나를 만듭니다. PDF를 포함한 7가지 형식을 모두 고를 수 있습니다. 파서는 단일 채팅 내보내기와 같습니다. 무엇을 넣을지는 “Chats”, “Thinking”, “Metadata”, “Tools”, “Sources”(채팅, 사고 과정, 메타데이터, 도구, 출처) 체크박스와 아티팩트 배치로 정합니다. Export All은 기능이 줄어든 별도 처리 방식이 아닙니다. 같은 파서를 여러 대화 ID에 한 번에 적용할 뿐입니다. 자세한 내용: 일괄 Export All.

Anthropic의 Export data는 여전히 계정 백업 수단입니다. ZIP 하나, 이메일 한 통, 잊고 있던 채팅까지 모두 JSON으로 담깁니다. 일괄 Export All은 반대 방향의 작업입니다. 대화 기록에서 어떤 행을 받을지, 어떤 형식으로 받을지 직접 고르고, ZIP은 즉시 저장됩니다. 공식 보관용 아카이브와 읽기 쉬운 노트 폴더가 모두 필요하다면 둘 다 쓰세요.

사용 한도는 공유되며 하루 단위입니다. 무료 플랜에서는 PDF 내보내기와 일괄 내보내기 채팅을 합쳐 하루 3회이며, UTC 자정에 초기화됩니다. 대화 40개를 선택하면 중간에 끊기는 것이 아니라 일괄 작업 전체가 막힙니다. 개수를 줄이거나 Paddle을 통해 월 $3.99 또는 연 $26.99의 Pro로 업그레이드하세요.

대시보드는 이미 내보낸 항목을 기억하므로, 다음에 방문했을 때 New나 Updated만 골라 볼 수 있습니다. 그래서 매주 Claude 채팅을 저장하는 습관도 지난달 Markdown을 중복하지 않고 새 항목만 추가하는 방식으로 이어갈 수 있습니다. 하루 3회 횟수는 설치가 아니라 Google 계정을 따르며, UTC 자정에 초기화됩니다.

대화 기록이 한 줄짜리 초안으로 가득하다면 일부만 선택하세요. Export All이라고 해서 모든 행을 받아야 하는 것은 아닙니다. 필터를 잘 걸고 Markdown으로 받으면, 빈 “안녕하세요” 대화 200개보다 훨씬 깔끔한 연구 폴더가 됩니다.

‘Claude 채팅 내보내기’라는 표현도 같은 주황색 버튼과 같은 Export All 표를 가리킵니다. ‘저장’이 아니라 ‘내보내기’로 검색해서 오셨다면 관련 페이지 Claude 채팅 내보내기에서 같은 기능을 정리해 두었습니다.

Desktop이나 Claude Code의 대화도 저장할 수 있나요?

Desktop은 안 되고, Claude Code는 웹에서만 됩니다. Download Claude conversations로는 Claude Desktop이나 로컬 Claude Code 터미널의 대화를 저장할 수 없습니다. claude.ai/code의 세션은 데스크톱 Chrome에서 열리므로 다른 채팅처럼 저장됩니다. Claude Desktop은 별도의 앱이고, 로컬 Claude Code는 /export 명령과 디스크의 JSONL을 쓰는 터미널 에이전트입니다.

Desktop의 채팅이 claude.ai에도 있다면 Chrome에서 그 URL을 열고 주황색 버튼을 쓰세요. 대화가 Desktop에만 있다면 복사해 붙여넣거나 Settings → Privacy → Export data를 기다리세요. 확장 프로그램은 Desktop 창에 들어가지 않습니다.

진행 중인 Claude Code 세션 안에서 /export를 입력하세요. Anthropic의 CLI가 대화 기록을 복사하거나 일반 텍스트 파일로 저장하는 메뉴를 엽니다. 파일 이름을 함께 입력하면 메뉴를 건너뜁니다. 이 기록은 사람이 읽기 위한 텍스트이며, 이 확장 프로그램의 Markdown, JSON, PDF와는 다릅니다. 전체 경로: Claude Code 내보내기.

디스크의 JSONL은 ~/.claude/projects(Windows: %USERPROFILE%\.claude\projects) 아래에 있는 내부 로그입니다. 스키마는 Claude Code 버전마다 바뀔 수 있습니다. Anthropic 공식 문서도 JSONL을 직접 파싱하기보다 /export를 쓰라고 안내합니다. 저희는 그 CLI를 감싸지 않으며, ~/.claude를 읽지도 않습니다.

Chrome의 claude.ai에서 대화를 열 수 있다면 Team과 Enterprise 워크스페이스에서도 확장 프로그램이 작동합니다. 파서는 개인 요금제 전용 API가 아니라 렌더링된 페이지를 읽습니다. 회사 정책이 확장 프로그램을 막고 있다면 그것은 IT 부서의 결정이며, 저희 설정의 요금제 옵션으로 바꿀 수 있는 문제가 아닙니다.

Anthropic, PBC와 관련이 없는 독립 Chrome 확장 프로그램입니다. Claude는 Anthropic의 상표입니다. Anthropic의 서비스 약관을 따르세요. 특정 내보내기가 직장에서 허용되는지에 대한 법률 자문은 드릴 수 없습니다. 이 확장 프로그램은 웹사이트와 같은 방식으로 기존 세션을 사용하며, 계정 작업을 자동화하지 않습니다.

Pro 결제는 Paddle이 처리합니다. PDF, 일괄 내보내기, Pro에만 쓰는 Google 로그인으로 저희가 대화에 접근하게 되지는 않습니다. 사용 한도와 Pro 상태를 확인하는 Cloudflare 워커는 메시지 텍스트가 아니라 Google 이메일만 받습니다. 그 밖의 단일 채팅 내보내기는 아무것도 보내지 않습니다. 결제는 서버에서, 채팅은 디스크에서. 이 제품이 만드는 모든 대화 저장 파일에 대한 개인정보 보호의 핵심은 이 경계입니다.

FAQ: Claude 대화 저장 방법

Claude 대화를 파일로 저장하려면 어떻게 하나요?

Download Claude conversations를 설치하고, claude.ai에서 대화를 연 다음, 메시지 입력창 오른쪽의 주황색 버튼을 누르세요. PDF, Markdown, JSON, 텍스트, XML, CSV, PNG 중 하나를 고르고 Export(내보내기)를 누르면 파일이 로컬로 다운로드됩니다. PDF를 제외하면 계정이 필요 없습니다. 채팅은 이미 대화 기록(History)을 통해 Anthropic 계정에 저장되어 있고, 주황색 버튼은 디스크에 사본을 하나 더 씁니다.

claude.ai에서 Claude 채팅은 어떻게 저장하나요?

계정에 대화를 남겨 두는 데는 저장 버튼이 필요 없습니다. 로그인한 상태의 채팅은 이미 Claude.ai 대화 기록에 표시됩니다. Claude 채팅을 파일로 저장하려면 Chrome 확장 프로그램, 인쇄 → PDF로 저장, 또는 나중에 도착하는 계정 JSON ZIP인 Settings → Privacy → Export data를 쓰세요.

확장 프로그램 없이 Claude 대화를 저장하려면?

화면 그대로의 사본이 필요하면 claude.ai 페이지를 인쇄(Ctrl/Cmd+P → PDF로 저장)하고, 계정 전체를 담은 JSON ZIP을 이메일로 받으려면 Settings → Privacy → Export data를 사용하세요. 짧은 답변이라면 복사해 붙여넣기도 됩니다. 다만 이 방법들은 Chrome 확장 프로그램처럼 채팅별로 구조화된 Markdown 파일을 만들어 주지 않습니다.

Claude는 대화 기록에 대화를 이미 저장하나요?

네. claude.ai에서 로그인한 상태의 채팅은 Anthropic 계정의 대화 기록에 남습니다. 탭을 닫거나, 새로고침하거나, 같은 계정으로 다른 기기를 열어도 대화는 지워지지 않습니다. 다만 대화 기록은 디스크에 있는 PDF, Markdown, JSON이나 그 밖의 어떤 파일도 아닙니다.

탭을 닫으면 Claude 대화가 사라지나요?

아니요. claude.ai 탭을 닫아도 대화 기록에서 대화가 삭제되지 않습니다. 대화 기록에서 채팅을 삭제하면 계정 화면에서 사라집니다. Download Claude conversations로 이미 내보낸 파일은 삭제 후에도 디스크에 남습니다.

Claude 대화를 PDF로 저장할 수 있나요?

네. Download Claude conversations 1.16.2는 PDF를 바로 내보냅니다. 주황색 버튼 패널에서 PDF를 고르고 Export를 누르세요. 파일은 인쇄 대화상자 없이 브라우저 안에서 만들어집니다. PDF는 Google 로그인이 필요하고 하루 3회까지 무료이며, Pro에서는 무제한입니다. 가이드: Claude 채팅 PDF 저장.

Claude 대화는 무료로 몇 개까지 저장할 수 있나요?

Markdown, 일반 텍스트, JSON, XML, CSV, PNG는 계정 없이 무제한입니다. PDF와 일괄 ZIP은 Google 로그인 후 무료 플랜에서 합쳐 하루 3회이며, 일괄 ZIP에서는 채팅 하나가 1회로 계산되고 하루는 UTC 자정에 초기화됩니다. Pro는 월 $3.99 또는 연 $26.99이며 이 제한을 없애 줍니다. 결제는 Paddle이 처리합니다.

모바일에서도 Claude 대화를 저장할 수 있나요?

Chrome 확장 프로그램은 모바일에서 작동하지 않습니다. 데스크톱 Chrome(또는 Chrome Web Store 항목을 설치할 수 있는 다른 Chromium 브라우저)에서 실행됩니다. iOS나 Android 앱은 없습니다. 모바일 브라우저에서도 대화 기록을 열고 Claude 채팅을 인쇄할 수는 있지만, 주황색 버튼은 표시되지 않습니다.

대화 기록의 Claude 채팅을 한꺼번에 저장할 수 있나요?

네. 확장 프로그램 팝업에서 View and Download All Conversations를 열고, 표를 필터링한 다음 Export All을 누르세요. 일괄 내보내기는 Google 로그인이 필요하며 무료 플랜의 하루 3회에 포함됩니다. 이 일괄 방식은 Anthropic의 Export data ZIP과 다릅니다. 공식 Export data는 계정 전체를 담은 아카이브 하나를 나중에 이메일로 보내 줍니다. 일괄 다운로드를 참고하세요.

Claude Code의 대화도 저장되나요?

웹에서만 됩니다. claude.ai/code의 Claude Code 세션은 일반 claude.ai 채팅처럼 저장됩니다. 로컬 터미널 세션은 안 됩니다. /export를 쓰거나 ~/.claude/projects(Windows: %USERPROFILE%\.claude\projects)에서 JSONL을 복사하세요. 이 Chrome 확장 프로그램은 claude.ai에서만 실행됩니다. 가이드: Claude Code 내보내기.

Claude 채팅을 저장하려면 Google 로그인이 필요한가요?

아니요, Markdown, 일반 텍스트, JSON, XML, CSV, PNG에는 필요 없습니다. Google 로그인은 PDF, 일괄 Export All, Pro에만 필요하며, 이를 통해 하루 3회 한도를 적용하고 재설치 후에도 Pro를 복원할 수 있습니다. 이 로그인과 함께 대화 내용이 전송되지는 않습니다. 인증된 이메일은 사용 한도와 Pro 상태 확인용으로만 저장합니다.

Claude 채팅을 저장하는 공식 Export data는 어디에 있나요?

claude.ai의 Settings → Privacy → Export data입니다. Anthropic이 만료되는 링크를 이메일로 보내 줍니다. ZIP은 계정 단위의 JSON 아카이브이며, 읽고 있던 채팅의 이름이 붙은 Markdown 파일이 아닙니다. Export data는 백업용으로 쓰고, 읽기 쉬운 파일 하나가 지금 필요하면 주황색 버튼을 쓰세요.
