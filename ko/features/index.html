채팅 하나를 내보내는 Chrome 확장 프로그램 기능은?

스레드 하나를 위한 핵심 Chrome 확장 프로그램 기능은 Download Claude conversations가 claude.ai의 메시지 입력창 옆에 추가하는 주황색 버튼입니다. 대화 URL을 열고 Markdown, JSON, 텍스트, XML, PNG 중 하나를 고른 뒤 "Export"(내보내기)를 누르십시오. 파일이 바로 다운로드됩니다.

  1. Chrome Web Store에서 Download Claude conversations를 설치합니다(평점 5.0).
  2. claude.ai를 새로 고치고, 빈 입력 화면이 아닌 실제 대화 URL을 엽니다.
  3. 메시지 입력창 오른쪽의 주황색 다운로드 버튼을 누릅니다.
  4. 형식을 고릅니다. 마지막으로 쓴 형식이 기억됩니다.
  5. "Export"를 누릅니다. Chrome이 브라우저 다운로드 API로 파일을 저장합니다.

주황색 버튼은 로드된 대화에서만 나타납니다. 빈 입력 화면에는 분석할 내용이 없습니다. 버튼이 없다면 Chrome의 퍼즐 메뉴에서 확장 프로그램을 고정하고 claude.ai를 새로 고치십시오. 이 Chrome 확장 프로그램 기능은 Claude Desktop이나 Claude Code에는 삽입되지 않습니다.

로컬 파일. Markdown, JSON, 텍스트, XML, PNG는 탭 안에서 만들어집니다. 사용량 확인은 저희 서버(worker)로 가지만 채팅 텍스트는 가지 않습니다. 구조: 작동 방식.

Export All을 담당하는 Chrome 확장 프로그램 기능은?

일괄 내보내기 기능은 "View and Download All Conversations"(모든 대화 보기 및 다운로드)에 있습니다: 검색 가능한 claude.ai 기록 표, All / New / Exported / Project 필터, 그리고 "Export All"(모두 내보내기). 완성된 파일 하나가 무료 내보내기 3회 중 1회입니다. Pro(월 $3.99 또는 연 $26.99)는 이 제한을 없앱니다.

New(새 항목)는 Download Claude conversations로 아직 내보내지 않은 채팅입니다. Exported(내보냄)는 이미 저장한 채팅을 추적해 두 번째 Export All에서 건너뛸 수 있게 합니다. Project(프로젝트)는 claude.ai에서 채팅을 묶는 방식과 같습니다. 검색은 대화 이름으로 합니다. 전체 흐름: 일괄 Export All.

사용량은 계정 단위입니다. 무료 내보내기는 총 3회이며, 일괄 실행마다 3회가 아닙니다. 대화 40개를 선택하면 모든 파일이 완성될 경우 40회를 씁니다. Export All을 누르기 전에 선택을 계획하거나 Pro를 쓰십시오.

Export All은 대화 하나를 내보낼 때와 같은 사고 과정, 메타데이터, 발신자, 아티팩트 옵션을 씁니다. Anthropic의 시간이 걸리는 계정 ZIP이 아니라 채팅별 파일 여러 개입니다. 한 번 실행할 때 형식은 하나만 고릅니다. 한 번의 클릭으로 Markdown과 JSON을 섞을 수는 없습니다.

Chrome 확장 프로그램 기능은 어떤 형식을 만드나요?

Chrome 확장 프로그램 기능은 Markdown, JSON, 일반 텍스트, XML, PNG의 5가지 형식을 만듭니다. 주황색 버튼과 Export All의 목록은 같습니다. 버전 1.13.0에는 PDF가 없습니다. 완성된 파일 하나가 내보내기 1회로 계산됩니다. 형식별 페이지: Claude 채팅 내보내기 형식.

Chrome 확장 프로그램 기능은 아티팩트를 유지하나요?

네. Chrome 확장 프로그램 기능에는 아티팩트 레이아웃이 있습니다: "Original"(원본), "Inline"(인라인), "Nested"(중첩), "Flat"(평면). 사고 과정 블록은 연구 과정을 남기고 싶을 때 켜는 선택 옵션입니다. 메타데이터로 제목, 타임스탬프, 모델을 추가할 수 있습니다. 발신자 필터는 파일을 "all / human only / assistant only"(전체 / 사용자만 / 어시스턴트만)로 제한합니다.

아티팩트는 별도 다운로드가 아니라 claude.ai 스레드의 일부입니다. 레이아웃에 따라 Markdown, JSON, XML, 텍스트에서의 위치가 달라집니다. PNG에서는 마크업으로 저장되지 않고 그림으로 그려집니다. 사고 과정을 끄면 claude.ai 화면에 보였더라도 확장 사고가 파일에서 빠집니다.

스레드가 길다면 claude.ai가 이전 메시지를 불러올 때까지 스크롤하십시오. 확장 프로그램은 페이지에 렌더링된 내용만 내보낼 수 있습니다. 절반만 로드된 DOM은 잘린 파일을 만들며, 아티팩트가 빠진 버그처럼 보이지만 대개는 스크롤하지 않은 대화 때문입니다.

Chrome 확장 프로그램 기능은 로그인을 어떻게 처리하나요?

첫 내보내기부터 Google 로그인이 필요합니다. 이 로그인으로 계정당 무료 내보내기 3회를 집계하고, 다시 설치한 뒤 Pro를 복원합니다. 대화 내용은 이 과정에 전혀 포함되지 않습니다. Download Claude conversations는 사용량과 구독 상태를 위해 Google이 인증한 이메일을 저장합니다.

Chrome 확장 프로그램을 다시 설치해도 무료 내보내기 3회는 초기화되지 않습니다. 이것이 로그인의 목적입니다. Pro는 Paddle을 통해 월 $3.99 또는 연 $26.99입니다. Paddle이 판매 대행자(merchant of record)이며, 저희 팀은 카드 번호를 보지 않습니다. 새 컴퓨터에서도 같은 Google 계정으로 Pro가 복원됩니다.

Anthropic의 유료 claude.ai 요금제는 필요 없습니다. Chrome에서 채팅을 열 수 있다면 claude.ai Free, Pro, Team, Enterprise 모두 작동합니다. 워크스페이스 관리자가 확장 프로그램을 차단하면 Download Claude conversations가 삽입되지 않습니다. 이는 브라우저 정책 때문이지 기능이 없어서가 아닙니다.

1.13.0에 없는 Chrome 확장 프로그램 기능은?

1.13.0에 없는 Chrome 확장 프로그램 기능: 기본 PDF, Notion 내보내기, Word 내보내기, Google Docs 전송, Claude Desktop 연동, Claude Code /export. Download Claude conversations는 claude.ai용 Chrome 콘텐츠 스크립트이며, 다른 이름을 단 별도의 앱이 아닙니다.

Claude Desktop은 Mac/Windows 앱이고, Claude Code는 터미널 에이전트입니다. 둘 다 주황색 버튼이 나타나지 않습니다. 같은 스레드가 claude.ai에도 있다면 Chrome에서 열어 그곳에서 확장 프로그램 기능을 쓰십시오. Desktop과의 비교: Claude Desktop 채팅 내보내기. Code와의 비교: Claude Code 내보내기.

휴대폰 브라우저의 모바일 claude.ai는 범위 밖입니다. 2026년 현재 저희 팀의 iOS나 Android 앱은 없습니다. 이 버전은 2026년 9월 기준입니다. 형식을 추가하면 이 페이지도 당일에 갱신됩니다. 그전까지 드롭다운에서 PDF를 기대하지 마십시오.

FAQ: Chrome 확장 프로그램 기능

이 FAQ는 Download Claude conversations 1.13.0의 Chrome 확장 프로그램 기능을 다룹니다: 주황색 버튼, Export All, 형식, 아티팩트, 사용량, Desktop, Pro. 각 답변은 제품 사실입니다. 페이지 head의 FAQPage JSON-LD도 이 목록과 일치합니다.

채팅 하나를 내보내는 Chrome 확장 프로그램 기능은 무엇인가요?

claude.ai 대화 URL에서 메시지 입력창 옆에 있는 주황색 버튼입니다. Markdown, JSON, 텍스트, XML, PNG 중 하나를 고르고 "Export"(내보내기)를 누르십시오. 스레드 하나를 내보내는 가장 빠른 방법입니다.

Chrome 확장 프로그램 기능에 일괄 Export All이 포함되나요?

네. "View and Download All Conversations"(모든 대화 보기 및 다운로드)가 claude.ai 기록을 All, New, Exported, Project 필터와 함께 보여 줍니다. "Export All"(모두 내보내기)은 선택한 채팅마다 파일을 하나씩 만듭니다. Pro가 아니라면 파일마다 무료 내보내기 3회 중 1회로 계산됩니다.

Chrome 확장 프로그램 기능은 어떤 형식을 지원하나요?

Markdown, JSON, 일반 텍스트, XML, PNG입니다. PDF는 없습니다. PNG는 이미지입니다. PDF 같은 페이지가 필요하면 Chrome에서 claude.ai 탭을 인쇄하십시오.

Chrome 확장 프로그램 기능으로 아티팩트와 사고 과정도 내보내나요?

네. 아티팩트 레이아웃은 "Original"(원본), "Inline"(인라인), "Nested"(중첩), "Flat"(평면) 중에서 고릅니다. 사고 과정은 켜고 끌 수 있습니다. 메타데이터와 발신자 필터는 선택 사항입니다. Export All에도 같은 옵션이 적용됩니다.

Chrome 확장 프로그램 기능을 무료로 써 볼 수 있나요?

네. Google로 로그인한 모든 계정은 형식에 상관없이 무료 내보내기 3회를 받습니다. 채팅 하나든 일괄이든 더 많은 파일이 필요하면 Paddle을 통해 Pro(월 $3.99 또는 연 $26.99)를 이용하십시오.

Chrome 확장 프로그램 기능이 Desktop이나 Code에서도 되나요?

아니요. 콘텐츠 스크립트는 Chrome의 claude.ai에만 삽입됩니다. Claude Desktop과 Claude Code에는 주황색 버튼이 나타나지 않습니다. 같은 스레드가 claude.ai에 있다면 그곳에서 여십시오.

Chrome 확장 프로그램 기능이 제 채팅을 업로드하나요?

아니요. 파일은 브라우저에서 만들어집니다. Google 로그인은 사용량 확인과 Pro 복원을 위해 인증된 이메일을 저장합니다. 채팅 본문은 저희 서버(worker)로 보내지 않습니다. 경계는 작동 방식 페이지를 참고하십시오.
