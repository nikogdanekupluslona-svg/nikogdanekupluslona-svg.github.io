채팅 하나를 내보내는 Chrome 확장 프로그램 기능은?

스레드 하나를 위한 핵심 Chrome 확장 프로그램 기능은 Download Claude conversations가 claude.ai의 메시지 입력창 옆에 추가하는 주황색 버튼입니다. 대화 URL을 열고 형식을 고른 뒤 "Export"(내보내기) 또는 "Copy"를 누르십시오. 파일이 바로 다운로드됩니다. 로그인이 필요한 형식은 PDF뿐이며, 나머지 6가지 형식은 계정이 필요 없습니다.

  1. Chrome Web Store에서 Download Claude conversations를 설치합니다.
  2. claude.ai를 새로 고치고 실제 대화 URL을 엽니다. 일반 채팅, 프로젝트 채팅, Cowork 세션, 웹용 Claude Code 모두 가능합니다.
  3. 메시지 입력창 오른쪽의 주황색 다운로드 버튼을 누릅니다.
  4. "Messages"(메시지)에서 "All", "Human", "Assistant"(전체, 사용자, 어시스턴트) 중 하나를 고르고, 형식과 "Thinking"(사고 과정) 체크박스를 정합니다. 또는 "Select"를 눌러 메시지를 하나씩 체크합니다. 확장 프로그램은 마지막으로 쓴 형식을 기억합니다.
  5. "Export"를 누르면 파일이 다운로드되고, "Copy"를 누르면 결과가 클립보드에 담깁니다. Copy는 Markdown, 텍스트, JSON, XML, CSV에서 쓸 수 있습니다.

주황색 버튼은 로드된 대화에서만 나타납니다. 빈 입력 화면에는 분석할 내용이 없습니다. 버튼이 없다면 Chrome의 퍼즐 메뉴에서 확장 프로그램을 고정하고 claude.ai를 새로 고치십시오. 이 Chrome 확장 프로그램 기능은 Claude Desktop이나 Claude Code 터미널에는 삽입되지 않습니다. PDF를 고르면 파일 이름, 페이지 크기, 여백, 라이트 또는 다크 모드, 글꼴과 글꼴 크기, 페이지 번호, 목차, 타임스탬프, 프롬프트마다 페이지 나누기를 설정하는 대화상자가 열립니다: Claude 채팅 PDF 저장.

로컬 파일. PDF, Markdown, JSON, 텍스트, XML, CSV, PNG는 탭 안에서 만들어집니다. PDF가 아닌 형식으로 채팅 하나를 내보낼 때는 저희 서버로 아무것도 보내지 않습니다. PDF와 일괄 내보내기는 하루 사용량 집계를 위해 Google 이메일만 보냅니다. 채팅 텍스트는 밖으로 나가지 않습니다. 구조: 작동 방식.

Export All을 담당하는 Chrome 확장 프로그램 기능은?

일괄 내보내기 기능은 대시보드(Dashboard), 즉 "View and Download All Conversations"(모든 대화 보기 및 다운로드)에 있습니다: 검색, "All conversations / New / Updated / Previously exported"(전체 대화 / 새 항목 / 업데이트됨 / 이전에 내보냄) 필터, Chat과 Cowork 탭, 프로젝트 검색, 그리고 "Export All"(모두 내보내기). Export All은 ZIP 파일 하나로 저장합니다. 무료 요금제는 Google 로그인으로 하루 3개 채팅까지이며, Pro(월 $3.99 또는 연 $26.99)는 이 제한을 없앱니다.

New(새 항목)는 Download Claude conversations로 아직 내보내지 않은 채팅입니다. Previously exported(이전에 내보냄)는 이미 저장한 채팅을 추적해 두 번째 Export All에서 건너뛸 수 있게 합니다. Cowork 탭에는 일반 채팅 옆에 Cowork 세션이 표시됩니다. 프로젝트 검색으로 claude.ai 프로젝트 하나에 속한 채팅을 찾을 수 있습니다. 검색은 대화 이름으로 합니다. 전체 흐름: 일괄 Export All.

하루 한도는 계정 단위입니다. 무료 요금제에서는 PDF와 합쳐 하루 3개 채팅이며, 일괄 실행마다 3개가 아닙니다. 3개가 남은 상태에서 대화 40개를 선택하면 일부만 내보내지는 것이 아니라 전체가 막힙니다. Export All을 누르기 전에 선택을 계획하거나 Pro를 쓰십시오.

Export All은 대시보드의 "Chat format"(채팅 형식) 선택기(PDF를 포함한 7가지 형식 전체), "Chats", "Thinking", "Metadata", "Tools", "Sources"(채팅, 사고 과정, 메타데이터, 도구, 출처) 체크박스, 아티팩트 형식을 따릅니다. Anthropic의 시간이 걸리는 계정 ZIP이 아니라, 채팅마다 파일이 하나씩 담긴 ZIP 하나입니다. 한 번 실행할 때 형식은 하나만 고릅니다. 한 번의 클릭으로 Markdown과 JSON을 섞을 수는 없습니다. 대시보드에는 백업과 복원 기능도 있습니다.

Chrome 확장 프로그램 기능은 어떤 형식을 만드나요?

Chrome 확장 프로그램 기능은 PDF, Markdown, 일반 텍스트, JSON, XML, CSV, PNG의 7가지 형식을 만듭니다. Markdown, 텍스트, JSON, XML, CSV, PNG는 계정 없이 무제한입니다. PDF는 브라우저에서 만들어지고 Google 로그인이 필요하며, 무료 요금제에서는 하루 3회 한도에 포함됩니다. 주황색 버튼과 대시보드의 Chat format 선택기에 있는 목록은 같습니다. 형식별 페이지: Claude 채팅 내보내기 형식.

Chrome 확장 프로그램 기능은 아티팩트를 유지하나요?

네. Chrome 확장 프로그램 기능에는 아티팩트 레이아웃이 있습니다: "Original"(원본), "Inline"(인라인), "Nested"(중첩), "Flat"(평면). 사고 과정 블록, 도구 / MCP 단계, 웹 검색 출처는 각각 선택해서 켭니다. Thinking은 내보내기 패널의 체크박스이고, 도구와 출처는 설정에서 켜며, 대시보드에는 세 가지 모두의 체크박스가 있습니다. 메타데이터로 제목, 타임스탬프, 모델을 추가할 수 있습니다. 발신자 필터는 파일을 "all / human only / assistant only"(전체 / 사용자만 / 어시스턴트만)로 제한하고, Select로 메시지를 하나씩 체크할 수 있습니다.

아티팩트는 claude.ai 스레드의 일부입니다. 레이아웃에 따라 아티팩트가 Markdown, JSON, XML, 텍스트 파일 안에 들어갈지, ZIP 안의 별도 폴더로 갈지가 정해집니다. 아티팩트 ZIP은 무료이고 무제한이며, 프로젝트 파일 ZIP도 마찬가지입니다: 프로젝트 페이지에서 "Project files"(프로젝트 파일) → "Download ZIP"(ZIP 다운로드)을 누르십시오. PNG에서는 아티팩트가 마크업으로 저장되지 않고 그림으로 그려집니다. 사고 과정을 끄면 claude.ai 화면에 보였더라도 확장 사고가 파일에서 빠집니다.

스레드가 길다면 claude.ai가 이전 메시지를 불러올 때까지 스크롤하십시오. 확장 프로그램은 페이지에 렌더링된 내용만 내보낼 수 있습니다. 절반만 로드된 DOM은 잘린 파일을 만들며, 아티팩트가 빠진 버그처럼 보이지만 대개는 스크롤하지 않은 대화 때문입니다.

설정은 확장 프로그램의 옵션 페이지입니다. 파일 이름 템플릿, "Copy instead of download"(다운로드 대신 복사), Markdown에 이미지 포함, 도구 / MCP 단계, 웹 검색 출처, 날짜 및 시간 형식, 백업과 복원, 구독이 여기에 있습니다. 확장 프로그램 UI는 영어로만 제공됩니다.

Chrome 확장 프로그램 기능은 로그인을 어떻게 처리하나요?

대부분의 Chrome 확장 프로그램 기능은 로그인이 필요 없습니다. Markdown, 일반 텍스트, JSON, XML, CSV, PNG로 채팅 하나를 내보내는 것은 익명으로 무제한이며, Copy, Select, 아티팩트 ZIP, 프로젝트 파일 ZIP도 마찬가지입니다. Google 로그인은 PDF, 일괄 Export All, Pro에서만 요청합니다. 대화 내용은 이 과정에 전혀 포함되지 않습니다.

무료 요금제에서 PDF와 일괄 ZIP은 합쳐서 하루 3회이며, 저희 서버가 Google 이메일 기준으로 집계합니다. 하루는 UTC 자정에 초기화되며, 확장 프로그램을 다시 설치해도 초기화되지 않습니다. Pro는 Paddle을 통해 월 $3.99 또는 연 $26.99입니다. Paddle이 판매 대행자(merchant of record)이며, 저희 팀은 카드 번호를 보지 않습니다. 새 컴퓨터에서도 같은 Google 계정으로 로그인하면 Pro가 복원됩니다.

Anthropic의 유료 claude.ai 요금제는 필요 없습니다. Chrome에서 채팅을 열 수 있다면 claude.ai Free, Pro, Team, Enterprise 모두 작동합니다. 워크스페이스 관리자가 확장 프로그램을 차단하면 Download Claude conversations가 삽입되지 않습니다. 이는 브라우저 정책 때문이지 기능이 없어서가 아닙니다.

1.16.2에 없는 Chrome 확장 프로그램 기능은?

1.16.2에 없는 Chrome 확장 프로그램 기능: Notion 내보내기, Word 내보내기, Google Docs 전송, Claude Desktop 연동, 로컬 Claude Code 터미널 세션(/export, ~/.claude/projects). Download Claude conversations는 claude.ai용 Chrome 콘텐츠 스크립트이며, 다른 이름을 단 별도의 앱이 아닙니다. PDF는 더 이상 이 목록에 없으며, 이제 기본으로 들어 있습니다.

Claude Desktop은 Mac/Windows 앱이고, 터미널의 Claude Code는 로컬 에이전트입니다. 둘 다 주황색 버튼이 나타나지 않습니다. 웹용 Claude Code(claude.ai/code)와 Cowork 세션은 claude.ai에서 열리므로 일반 채팅처럼 내보낼 수 있습니다. Desktop 스레드가 claude.ai에도 있다면 Chrome에서 열어 그곳에서 확장 프로그램 기능을 쓰십시오. Desktop과의 비교: Claude Desktop 채팅 내보내기. Code와의 비교: Claude Code 내보내기.

휴대폰 브라우저의 모바일 claude.ai는 범위 밖입니다. 2026년 현재 저희 팀의 iOS나 Android 앱은 없습니다. PDF와 PNG에는 Copy를 쓸 수 없습니다. 이 버전은 2026년 9월 기준입니다. 형식을 추가하면 이 페이지도 당일에 갱신됩니다.

FAQ: Chrome 확장 프로그램 기능

이 FAQ는 Download Claude conversations 1.16.2의 Chrome 확장 프로그램 기능을 다룹니다: 주황색 버튼, Export All, 형식, 아티팩트, 무료 요금제, Desktop, Pro. 각 답변은 제품 사실입니다. 페이지 head의 FAQPage JSON-LD도 이 목록과 일치합니다.

채팅 하나를 내보내는 Chrome 확장 프로그램 기능은 무엇인가요?

claude.ai 대화 URL에서 메시지 입력창 옆에 있는 주황색 버튼입니다. PDF, Markdown, JSON, 텍스트, XML, CSV, PNG 중 하나를 고르고 "Export"(내보내기) 또는 "Copy"(복사)를 누르십시오. 스레드 하나를 내보내는 가장 빠른 방법이며, 로그인이 필요한 형식은 PDF뿐입니다.

Chrome 확장 프로그램 기능에 일괄 Export All이 포함되나요?

네. 대시보드("View and Download All Conversations")가 claude.ai 기록을 All conversations, New, Updated, Previously exported 필터, Chat과 Cowork 탭, 프로젝트 검색과 함께 보여 줍니다. "Export All"(모두 내보내기)은 ZIP 파일 하나로 저장합니다. 무료 요금제는 Google 로그인으로 하루 3개 채팅까지, Pro는 무제한입니다.

Chrome 확장 프로그램 기능은 어떤 형식을 지원하나요?

PDF, Markdown, 일반 텍스트, JSON, XML, CSV, PNG의 7가지입니다. PDF는 전용 대화상자와 함께 브라우저에서 만들어집니다. CSV는 메시지 하나당 한 행입니다. PNG는 대화 이미지 한 장입니다.

Chrome 확장 프로그램 기능으로 아티팩트와 사고 과정도 내보내나요?

네. 아티팩트 레이아웃은 "Original"(원본), "Inline"(인라인), "Nested"(중첩), "Flat"(평면) 중에서 고르며, 아티팩트를 ZIP 안의 별도 폴더로 뺄 수도 있습니다. 사고 과정, 도구 / MCP 단계, 웹 검색 출처는 각각 선택해서 켭니다. 메타데이터, 발신자 필터, Select는 선택 사항입니다.

Chrome 확장 프로그램 기능을 무료로 써 볼 수 있나요?

네. Markdown, 텍스트, JSON, XML, CSV, PNG 내보내기는 무제한이며 계정이 필요 없습니다. PDF와 일괄 ZIP은 Google 로그인으로 하루 3회입니다. Paddle을 통한 Pro(월 $3.99 또는 연 $26.99)는 이 제한을 없앱니다.

Chrome 확장 프로그램 기능이 Desktop이나 Code에서도 되나요?

Claude Desktop과 Claude Code 터미널에서는 되지 않습니다. 콘텐츠 스크립트는 Chrome의 claude.ai에만 삽입됩니다. 웹용 Claude Code(claude.ai/code)와 Cowork 세션은 claude.ai에서 실행되므로 내보낼 수 있습니다. Desktop 스레드가 claude.ai에도 있다면 그곳에서 여십시오.

Chrome 확장 프로그램 기능이 제 채팅을 업로드하나요?

아니요. PDF를 포함한 모든 파일은 브라우저에서 만들어집니다. 그 밖의 형식으로 채팅 하나를 내보낼 때는 아무것도 보내지 않습니다. PDF, 일괄 내보내기, Pro에서는 하루 사용량 집계와 구독 확인을 위해 Google 이메일만 전송됩니다. 경계는 작동 방식 페이지를 참고하십시오.
