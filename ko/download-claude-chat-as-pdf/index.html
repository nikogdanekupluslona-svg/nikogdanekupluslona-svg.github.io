  1. Chrome이나 다른 데스크톱 브라우저의 claude.ai에서 대화를 엽니다. 응답 생성이 끝날 때까지 기다립니다.

  3. Windows나 Linux에서는 Ctrl+P, Mac에서는 Cmd+P를 누릅니다.
  4. 대상을 PDF로 저장(Chrome) 또는 Print to PDF로 설정합니다. 종이로 인쇄하려면 프린터를 고릅니다.

인쇄한 Claude 채팅 PDF에는 메시지 구조가 아니라 레이아웃의 스냅샷이 남습니다. 보통 화면에 보이는 텍스트와 인쇄 CSS가 지우지 않은 요소가 남습니다. 온전한 코드 블록, 넓은 표, 접힌 아티팩트, 입력창 같은 UI가 없는 깔끔한 페이지는 잃는 경우가 많습니다.

Claude 채팅에는 PNG, PDF, Markdown 중 무엇이 좋을까요?

PNG, PDF, Markdown은 서로 다른 세 가지입니다. Claude 채팅 PDF 저장은 인쇄하거나 Markdown 파일을 변환하는 것입니다. 이 확장 프로그램의 PNG는 스레드의 그림입니다. Markdown은 구조가 있는 텍스트입니다. 이름을 혼동하면 엉뚱한 파일을 보내게 됩니다.

마지막으로 쓴 형식이 기억됩니다. 슬라이드용 PNG를 원했는데 Markdown이 나왔다면 드롭다운이 Markdown에 그대로 있었던 것입니다. 무료 내보내기를 쓰기 전에 확인하십시오.

인쇄 vs 공식 내보내기 vs 이 Chrome 확장 프로그램?

인쇄, 공식 Export data, 이 Chrome 확장 프로그램은 "내보내기"라는 말을 공유하는 세 가지 다른 작업입니다. 인쇄 → PDF로 저장은 대화 하나를, 보이는 그대로, 지금 저장합니다. 공식 ZIP은 계정 전체를 JSON으로 나중에 이메일로 보냅니다. 확장 프로그램은 5가지 형식을 로컬에 저장하며, 사용량 확인을 위해 Google 로그인을 씁니다.

터미널의 Claude Code를 말한 것이라면 인쇄는 도움이 되지 않습니다. 그 제품은 웹 페이지가 아니기 때문입니다. /export를 쓰십시오. Claude Desktop 앱을 말한 것이라면 그것도 이 확장 프로그램의 대상이 아닙니다 — Claude Desktop 채팅 내보내기를 참고하십시오.

ZIP과 주황색 버튼으로 Claude 채팅을 내보내는 방법은 내보내기 가이드에서 다룹니다. 위젯을 쓰는 단계별 Claude 채팅 다운로드 방법은 다운로드 가이드에 있습니다. 이 페이지는 PDF와 인쇄만 다루어 세 페이지의 역할이 겹치지 않게 합니다.

인쇄에는 사용량 제한이 없습니다. 브라우저 인쇄는 3회 내보내기 제한과 무관합니다. 제한은 확장 프로그램이 Markdown, JSON, 텍스트, XML, PNG를 만들 때 적용됩니다. Pro(월 $3.99 또는 연 $26.99)는 이 제한을 없앱니다. 결제는 Paddle이 처리합니다.

FAQ: Claude 채팅 PDF 저장

Claude 채팅을 PDF로 다운로드할 수 있나요?

claude.ai 자체 기능으로도, 이 Chrome 확장 프로그램으로도 안 됩니다. 화면 그대로의 PDF가 필요하면 대화를 인쇄(Ctrl/Cmd+P → PDF로 저장)하고, 더 깔끔한 문서가 필요하면 Markdown으로 내보낸 뒤 그 파일을 변환하십시오.

Claude 대화는 어떻게 인쇄하나요?

claude.ai에서 채팅을 열고, 가능하면 사이드바를 숨긴 뒤 Windows에서는 Ctrl+P, Mac에서는 Cmd+P를 누르고 PDF로 저장 또는 프린터를 선택해 인쇄합니다. 긴 스레드는 코드 블록이 페이지 사이에서 잘리는 경우가 많습니다. 먼저 스크롤해서 이전 대화를 모두 불러오십시오.

휴대폰에서 Claude 채팅을 인쇄할 수 있나요?

모바일 브라우저에서도 인쇄하거나 PDF로 공유할 수 있지만 레이아웃은 데스크톱보다 나쁩니다. 다시 쓸 파일이 필요하면 같은 채팅을 데스크톱 Chrome에서 열고 Markdown으로 내보내십시오. 확장 프로그램은 모바일에서 작동하지 않습니다.

Download Claude conversations는 PDF로 내보내나요?

아니요. 현재 형식은 Markdown, JSON, 일반 텍스트, XML, PNG입니다. PNG는 스레드의 이미지이지 PDF가 아닙니다. PDF 인쇄는 여전히 브라우저의 기능입니다. 버전 1.13.0에는 .pdf 출력 기능이 없습니다.

인쇄한 PDF는 Anthropic의 Export data와 같은가요?

아니요. 인쇄는 지금 보이는 페이지를 담습니다. Anthropic의 Settings → Privacy → Export data는 계정 전체를 JSON ZIP으로 이메일 발송합니다. 둘 다 주황색 버튼으로 받는 채팅별 Markdown 파일은 아닙니다.

코드가 읽기 좋게 Claude 채팅을 PDF로 저장하려면?

코드가 중요하다면 인쇄부터 시작하지 마십시오. Markdown으로 내보내 편집기에서 연 다음 그 문서를 인쇄하십시오. 채팅 화면이 아니라 파일 기준으로 페이지가 나뉩니다. Pro가 아니라면 무료 내보내기 3회 중 1회를 씁니다.

PNG로 PDF를 대신할 수 있나요?

아니요. PNG는 비트맵입니다. 인쇄로 만든 PDF는 claude.ai를 페이지 단위로 담은 스냅샷입니다. 둘 다 채팅 화면의 그림처럼 보이지만 실제 PDF는 인쇄로 만든 것뿐입니다. 어느 쪽도 검색과 비교(diff)에서 Markdown을 대신하지 못합니다.

인쇄도 무료 내보내기 3회에 포함되나요?

아니요. 인쇄는 브라우저 기능입니다. 사용량 제한은 확장 프로그램이 만드는 파일에만 적용됩니다. claude.ai를 인쇄할 때 Google 로그인은 필요 없습니다. 이 확장 프로그램으로 Markdown, JSON, 텍스트, XML, PNG를 내보낼 때만 필요합니다.

Claude 채팅을 PDF로 일괄 다운로드할 수 있나요?

PDF로 직접은 안 됩니다. "Export All"(모두 내보내기)로 Markdown이나 PNG 파일을 여러 개 만들 수 있으니, PDF가 필요하면 나중에 Markdown을 변환하십시오. 일괄 내보내기도 파일마다 무료 내보내기 3회에 포함됩니다. 일괄 Export All을 참고하십시오.

Claude Code 세션을 PDF로 인쇄할 수 있나요?

claude.ai 인쇄로는 안 됩니다. Claude Code는 터미널입니다. /export를 쓴 다음, 종이가 필요하면 편집기에서 텍스트 파일을 인쇄하십시오. 가이드: Claude Code 내보내기.

Team이나 Enterprise 요금제에서는 PDF 내보내기가 다른가요?

이 요금제에서도 별도의 PDF 버튼은 없습니다. Chrome에서 채팅을 열 수 있다면 인쇄할 수 있고, 확장 프로그램의 5가지 형식도 쓸 수 있습니다. 요금제에 따라 드롭다운에 .pdf가 추가되지는 않습니다.

형식 목록에 PDF를 추가할 계획이 있나요?

1.13.0에는 없습니다. 추가한다면 당일에 이 페이지에 안내합니다. 그전까지는 인쇄하거나 Markdown을 변환하십시오. 없는 "PDF로 다운로드" 기능을 지어내기보다 부족한 점을 솔직히 밝히겠습니다.
