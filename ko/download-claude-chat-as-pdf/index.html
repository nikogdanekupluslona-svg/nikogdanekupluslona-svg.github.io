Claude 채팅을 기본 기능으로 PDF 저장할 수 있나요?

claude.ai 자체로는 안 됩니다. "PDF로 다운로드" 버튼이 없기 때문입니다. Download Claude conversations를 쓰면 됩니다. 내보내기 패널에서 PDF를 고르고 "Export"를 클릭하십시오. 버전 1.16.2는 인쇄 대화 상자 없이 탭 안에서 .pdf를 만듭니다. 아무것도 업로드되지 않습니다.

  1. Chrome Web Store에서 Download Claude conversations를 설치한 뒤 claude.ai를 새로고침합니다.
  2. 대화를 엽니다. 일반 채팅, 프로젝트, Cowork 세션, 웹용 Claude Code(claude.ai/code) 세션 모두 됩니다.
  3. 메시지 입력창 오른쪽에 있는 둥근 주황색 다운로드 버튼을 클릭합니다.
  4. "Format"(형식)에서 PDF를 선택합니다. "Messages"(메시지)는 "All"(전체)로 두거나 "Human"(사용자) 또는 "Assistant"(어시스턴트)를 고릅니다. 원하는 메시지만 담으려면 "Select"(선택)로 하나씩 체크하십시오.
  5. "Export"를 클릭합니다. 처음 한 번은 Google로 로그인하고, PDF 옵션을 설정한 뒤 저장합니다.

무료 플랜의 PDF 한도. PDF는 처음 쓸 때부터 Google 로그인이 필요합니다. 무료 계정은 PDF와 일괄 ZIP 내보내기를 합쳐 하루 3회까지 쓸 수 있으며, 하루는 UTC 자정에 초기화됩니다. Pro(월 $3.99 또는 연 $26.99)는 이 한도를 없앱니다. Markdown, 텍스트, JSON, XML, CSV, PNG는 계정 없이 계속 무제한입니다.

데스크톱에서 Claude 대화는 어떻게 인쇄하나요?

  1. Chrome이나 다른 데스크톱 브라우저의 claude.ai에서 대화를 엽니다. 응답 생성이 끝날 때까지 기다립니다.
  2. 사이드바를 접어 대화가 페이지를 더 넓게 쓰도록 합니다. 종이에 넣고 싶지 않은 아티팩트나 프로젝트 패널도 숨깁니다.
  3. Windows나 Linux에서는 Ctrl+P, Mac에서는 Cmd+P를 누릅니다.
  4. 대상을 PDF로 저장(Chrome) 또는 Print to PDF로 설정합니다. 종이로 인쇄하려면 프린터를 고릅니다.
  5. 페이지가 흐릿하게 보이면 설정 더보기에서 배경 그래픽을 켜 보십시오. 사이드바가 여전히 공간을 차지하면 여백을 줄이십시오. 저장하거나 인쇄합니다.

Claude 채팅을 더 보기 좋은 레이아웃으로 인쇄할 수 있을까요? 인쇄 대화 상자로는 안 됩니다. 인쇄 대화 상자가 조판 도구가 되지는 않습니다. 대신 확장 프로그램에서 PDF를 고르십시오. 그곳에서는 용지 크기, 여백, 글꼴, 페이지 번호, 목차를 CSS 운에 맡기지 않고 직접 설정합니다.

인쇄한 Claude 채팅 PDF에는 무엇이 남나요?

인쇄한 Claude 채팅 PDF에는 메시지 구조가 아니라 레이아웃의 스냅샷이 남습니다. 보통 화면에 보이는 텍스트와 인쇄 CSS가 지우지 않은 요소가 남습니다. 온전한 코드 블록, 넓은 표, 접힌 아티팩트, 입력창 같은 UI가 없는 깔끔한 페이지는 잃는 경우가 많습니다.

  • 코드 블록은 줄바꿈되거나 페이지 사이에서 잘립니다. 들여쓰기는 인쇄 스타일시트가 pre 줄바꿈을 잘 제어할 때만 유지되는데, 그렇지 않은 경우가 많습니다.
  • 표가 용지 폭을 넘칩니다. 넓은 비교표는 읽을 수 없게 됩니다.
  • 입력창, 모델 선택기, 사이드바 같은 앱 UI를 먼저 숨기지 않으면 모든 페이지에 나타날 수 있습니다.
  • 아티팩트와 사고 과정은 화면에서 펼쳐져 있을 때만 인쇄됩니다. 접힌 UI는 PDF에 없습니다.
  • PDF를 Obsidian에서 Markdown처럼 다루거나 git에서 비교(diff)할 수 없습니다.

Claude 채팅에는 PNG, PDF, Markdown 중 무엇이 좋을까요?

PNG, PDF, Markdown은 서로 다른 세 가지입니다. 이 확장 프로그램의 PDF는 페이지로 나뉜 문서입니다. PNG는 스레드를 담은 한 장의 그림입니다. Markdown은 구조가 있는 텍스트입니다. 인쇄로 만든 PDF는 웹 페이지의 스냅샷입니다. 이름을 혼동하면 엉뚱한 파일을 보내게 됩니다.

일반 텍스트, XML, CSV도 있습니다. 모두 PDF는 아닙니다. 일반 텍스트는 줄만 빽빽하게 인쇄되고, XML은 태그째 인쇄됩니다. CSV는 메시지당 한 행이라 종이가 아니라 스프레드시트용입니다. 최종 결과물이 PDF라면 PDF를 고르십시오.

마지막으로 쓴 형식이 기억됩니다. PDF를 원했는데 Markdown이 나왔다면 드롭다운이 Markdown에 그대로 있었던 것입니다. "Export"를 클릭하기 전에 확인하십시오. 무료 플랜에서는 실수로 만든 PDF도 오늘의 3회 중 1회를 씁니다.

인쇄 vs 공식 내보내기 vs 이 Chrome 확장 프로그램?

인쇄, 공식 Export data, 이 Chrome 확장 프로그램은 "내보내기"라는 말을 공유하는 세 가지 다른 작업입니다. 인쇄 → PDF로 저장은 대화 하나를, 보이는 그대로, 지금 저장합니다. 공식 ZIP은 계정 전체를 JSON으로 나중에 이메일로 보냅니다. 확장 프로그램은 PDF를 포함한 7가지 형식을 로컬에 저장합니다. 그중 6가지는 계정이 필요 없고, PDF와 일괄 내보내기만 Google 로그인을 요청합니다.

터미널의 Claude Code를 말한 것이라면 인쇄는 도움이 되지 않습니다. 로컬 세션은 웹 페이지가 아니기 때문입니다. /export를 쓰십시오. 웹용 Claude Code(claude.ai/code)는 다릅니다. claude.ai에서 열리므로 확장 프로그램이 일반 채팅처럼 PDF로 내보냅니다. Claude Desktop 앱을 말한 것이라면 확장 프로그램은 그 앱 안에서 작동하지 않습니다 — Claude Desktop 채팅 내보내기를 참고하십시오.

ZIP과 주황색 버튼으로 Claude 채팅을 내보내는 방법은 내보내기 가이드에서 다룹니다. 위젯을 쓰는 단계별 Claude 채팅 다운로드 방법은 다운로드 가이드에 있습니다. 이 페이지는 PDF와 인쇄만 다루어 세 페이지의 역할이 겹치지 않게 합니다.

하루 한도는 인쇄에 적용되지 않습니다. 브라우저 인쇄는 확장 프로그램이 아닙니다. 무료 플랜의 한도(PDF와 일괄 ZIP 내보내기를 합쳐 하루 3회, UTC 자정에 초기화)는 확장 프로그램의 PDF와 "Export All"에만 적용됩니다. Markdown, 텍스트, JSON, XML, CSV, PNG는 무제한입니다. Pro(월 $3.99 또는 연 $26.99)는 이 한도를 없앱니다. 결제는 Paddle이 처리합니다.

Anthropic, PBC와 제휴하지 않은 독립 Chrome 확장 프로그램입니다. Anthropic의 서비스 약관을 따르십시오. Anthropic이 관리하는 인쇄 스타일시트에 대해서는 약속드릴 수 없습니다. Claude UI 변경으로 인쇄가 깨졌다면 그것은 Anthropic의 CSS 문제이니, 대신 확장 프로그램에서 PDF로 내보내십시오.

FAQ: Claude 채팅 PDF 저장

Claude 채팅을 PDF로 다운로드할 수 있나요?

네, Download Claude conversations로 가능합니다. claude.ai에서 채팅을 열고 주황색 버튼을 눌러 PDF를 고른 뒤 "Export"를 클릭하십시오. 파일은 인쇄 대화 상자 없이 브라우저에서 만들어집니다. claude.ai 자체에는 PDF 버튼이 없으며, 설치 없이 쓸 수 있는 대안은 인쇄(Ctrl/Cmd+P → PDF로 저장)입니다.

Claude 채팅을 PDF로 저장하려면 계정이 필요한가요?

네, 첫 PDF부터 Google 로그인이 필요합니다. 로그인으로 무료 플랜의 하루 3회 PDF·일괄 내보내기 횟수를 세고, Pro를 구매하면 그 계정에 연결합니다. Markdown, 텍스트, JSON, XML, CSV, PNG는 계정이 필요 없습니다.

Claude 대화는 어떻게 인쇄하나요?

claude.ai에서 채팅을 열고, 가능하면 사이드바를 숨긴 뒤 Windows에서는 Ctrl+P, Mac에서는 Cmd+P를 누르고 PDF로 저장 또는 프린터를 선택해 인쇄합니다. 긴 스레드는 코드 블록이 페이지 사이에서 잘리는 경우가 많습니다. 먼저 스크롤해서 이전 대화를 모두 불러오십시오.

휴대폰에서 Claude 채팅을 인쇄할 수 있나요?

모바일 브라우저에서도 인쇄하거나 PDF로 공유할 수 있지만 레이아웃은 데스크톱보다 나쁩니다. 확장 프로그램은 모바일에서 작동하지 않습니다. 깔끔한 PDF가 필요하면 같은 채팅을 데스크톱 Chrome에서 열고 PDF로 내보내십시오.

Download Claude conversations는 PDF로 내보내나요?

네. 버전 1.16.2는 Markdown, Plain Text(일반 텍스트), JSON, XML, CSV, PNG와 함께 PDF도 내보냅니다. PDF 대화 상자에서 파일 이름, 용지 크기, 여백, 라이트 또는 다크 모드, 글꼴과 크기, 페이지 번호, 목차, 타임스탬프, 모든 프롬프트 앞의 페이지 나눔을 설정합니다.

인쇄한 PDF는 Anthropic의 Export data와 같은가요?

아니요. 인쇄는 지금 보이는 페이지를 담습니다. Anthropic의 Settings → Privacy → Export data는 계정 전체를 JSON ZIP으로 이메일 발송합니다. 어느 쪽도 확장 프로그램이 주황색 버튼으로 만드는 채팅별 PDF는 아닙니다.

코드가 읽기 좋게 Claude 채팅을 PDF로 저장하려면?

확장 프로그램에서 PDF를 고르십시오. 코드 블록은 언어 표시와 서식을 유지하고, 용지 크기와 여백은 직접 정합니다. 인쇄는 코드에 약한 방법입니다. 블록이 줄바꿈되거나 페이지 사이에서 잘립니다. 조판을 직접 하고 싶다면 Markdown으로 내보내 편집기에서 인쇄하십시오.

PNG로 PDF를 대신할 수 있나요?

아니요. PNG는 대화를 담은 한 장의 이미지입니다. 확장 프로그램의 PDF는 페이지 번호와 목차를 넣을 수 있는, 페이지로 나뉜 문서입니다. 인쇄로 만든 PDF는 claude.ai를 페이지 단위로 담은 스냅샷입니다. 어느 것도 편집과 비교(diff)에서 Markdown을 대신하지 못합니다.

인쇄도 하루 PDF 한도에 포함되나요?

아니요. 인쇄는 확장 프로그램이 아니라 브라우저 기능입니다. 무료 플랜의 하루 3회 한도는 확장 프로그램의 PDF와 일괄 ZIP에만 적용됩니다. claude.ai를 인쇄할 때는 로그인이 필요 없고, Markdown, 텍스트, JSON, XML, CSV, PNG 내보내기는 무제한입니다.

Claude 채팅을 PDF로 일괄 다운로드할 수 있나요?

네. 대시보드에서 "Chat format"(채팅 형식)을 PDF로 고르고 채팅을 체크한 뒤 "Export All"(모두 내보내기)을 클릭하십시오. 채팅마다 PDF가 하나씩 담긴 ZIP 하나가 만들어집니다. 먼저 Google로 로그인하십시오. 무료 플랜은 하루 3개 채팅까지이며, ZIP 안의 채팅 하나가 1회로 계산됩니다. Pro는 무제한입니다. 일괄 Export All을 참고하십시오.

Claude Code 세션을 PDF로 저장할 수 있나요?

웹에서는 됩니다. 웹용 Claude Code(claude.ai/code)는 claude.ai에서 열리므로 확장 프로그램이 일반 채팅처럼 PDF로 내보냅니다. 로컬 터미널 세션은 웹 페이지가 아닙니다. 터미널에서는 /export를 쓴 다음 편집기에서 텍스트 파일을 인쇄하십시오. 가이드: Claude Code 내보내기.

Team이나 Enterprise 요금제에서는 PDF 내보내기가 다른가요?

아니요. PDF는 Claude 요금제가 아니라 확장 프로그램에서 만들어집니다. Chrome의 claude.ai에서 열리는 채팅이라면 PDF를 비롯한 7가지 형식 중 어느 것으로든 내보낼 수 있습니다. 무료 하루 3회 한도와 Pro는 모든 Claude 요금제에서 똑같이 적용됩니다.

Claude 채팅 PDF는 서버에서 만들어지나요?

아니요. PDF도 다른 모든 형식처럼 브라우저에서 생성됩니다. 대화 내용은 업로드되거나 저장되거나 분석되지 않습니다. 로그인한 뒤에는 하루 한도나 Pro를 확인하기 위해 Google 이메일만 전송됩니다.
