확장 프로그램으로 Claude 채팅을 내보내는 방법은?

Claude 채팅을 읽기 쉬운 파일로 내보내는 방법은 claude.ai의 주황색 버튼입니다. Download Claude conversations를 설치하고, 대화를 연 다음, Markdown, JSON, 텍스트, XML, PNG 중 하나를 고르고 “Export”(내보내기)를 누르세요. 파일은 브라우저 안에서 만들어져 로컬에 저장됩니다. Google 로그인으로 무료 내보내기 3회를 계산합니다.

이 확장 프로그램은 이미 불러온 페이지에서 동작하는 콘텐츠 스크립트입니다. 두 번째 Anthropic 세션을 열지 않으며, 파일을 만들기 위해 대화를 업로드하지도 않습니다. 그래서 버튼은 대화가 DOM에 존재한 뒤, 대화 URL에서만 나타납니다.

  1. Chrome Web Store에서 확장 프로그램을 설치합니다.
  2. claude.ai에서 대화를 엽니다. 설치하는 동안 탭이 열려 있었다면 새로고침합니다.
  3. 메시지 입력창 옆의 주황색 다운로드 버튼을 누릅니다.
  4. Markdown, JSON, 일반 텍스트, XML, PNG 중에서 고릅니다.
  5. 필요하면 사고 과정, 메타데이터, 발신자, 아티팩트 배치를 설정한 뒤 Export를 누릅니다.

대화가 여러 개라면 팝업에서 “View and Download All Conversations”(모든 대화 보기 및 다운로드)를 여세요. 검색하고, 프로젝트나 내보낸 여부로 필터링한 뒤 Export All을 누르세요. 그 묶음의 모든 파일이 같은 무료 3회에서 차감됩니다. 안내: 일괄 Export All.

공식 ZIP으로 Claude 대화를 내보내는 방법은?

계정 단위로 Claude 대화를 내보내는 방법은 Settings → Privacy → Export data입니다. Anthropic이 만료되는 링크를 이메일로 보내 줍니다. ZIP은 계정 전체의 JSON이며, 대화 하나를 보기 좋게 만든 파일이 아닙니다. 백업용으로 쓰세요.

워크스페이스를 떠날 때, 모든 것을 보관할 때, “내 데이터를 모두 달라”는 요청에 응할 때는 공식 ZIP이 맞는 도구입니다. 설계 리뷰 하나를 열어 두고 1분 안에 파일이 필요할 때는 맞지 않습니다.

그 방식에는 대화 ID 하나만 고르는 필터가 없습니다. 기다리고, 아카이브를 다운로드하고, 압축을 풀고, 대화를 찾아야 합니다. JSON 구조도 계정 단위입니다. 이 확장 프로그램이 열어 둔 페이지에서 만드는 채팅별 JSON과는 다릅니다.

둘 다 필요하다면 백업용으로 Export data를 한 번 실행하고, 작업용 파일이 필요할 때마다 Download Claude conversations를 쓰세요. 두 작업은 서로를 대신하지 않습니다. ZIP이 Markdown이 되지는 않고, 주황색 버튼이 2024년에 잊어버린 채팅까지 모두 이메일로 보내 주지도 않습니다.

공식 Export data는 PDF 인쇄와도 다릅니다. 인쇄는 웹페이지를 찍고, ZIP은 구조화된 계정 데이터입니다. 인쇄와 파일 비교: Claude 채팅을 PDF로 저장하기.

Claude 채팅을 Markdown이나 JSON으로 내보내려면?

Claude 채팅을 Markdown이나 JSON으로 내보내려면 Export 전에 드롭다운에서 그 형식을 고르세요. Markdown은 노트와 git용, JSON은 스크립트용 메시지 트리입니다. 일반 텍스트는 마크업을 없앱니다. PNG는 이미지이며 PDF가 아닙니다.

Markdown은 제목, 언어 태그가 붙은 코드 블록, 표를 유지합니다. 아티팩트 배치는 “Original”, “Inline”, “Nested”, “Flat” 중에서 고를 수 있습니다. 사고 과정 블록은 선택 사항입니다. 대부분의 사람이 ‘읽기 쉬운 내보내기’라고 할 때 떠올리는 것이 바로 이 파일입니다. 안내: 형식.

확장 프로그램의 JSON은 대화별(또는 일괄 선택별)입니다. Anthropic 계정 ZIP의 이름만 바꾼 것이 아닙니다. 파서를 만든다면 대화 하나에는 이 JSON을 쓰고, Anthropic이 저장한 모든 대화가 정말로 필요할 때만 공식 ZIP을 쓰세요.

돈을 내지 않고 Claude 채팅을 내보낼 수 있나요?

네. 어떤 계정이든 처음 파일 3개까지는 다섯 가지 형식 중 무엇으로든 돈을 내지 않고 Claude 채팅을 내보낼 수 있습니다. 그 이후 Pro는 월 $3.99 또는 연 $26.99입니다. Google 로그인 덕분에 재설치해도 무료 횟수가 초기화되지 않습니다.

일괄 Export All에 별도의 무료 한도가 있지는 않습니다. Export All로 만든 파일 하나도 주황색 버튼과 똑같이 1회입니다. 무료 계정에서 대화 20개를 선택하면 세 번째 파일 이후 멈춥니다. 선택을 미리 계획하세요.

인쇄와 Anthropic Export data는 저희 한도를 쓰지 않습니다. 하지만 채팅 하나의 Markdown도 주지 않습니다. 확장 프로그램 없는 ‘무료’ 방법에도 시간과 정리라는 비용이 따릅니다.

Google 로그인은 선택 사항이 아닙니다. 처음 Export를 누르면 Google에 이메일 확인을 요청합니다. 이 창을 닫으면 내보내기가 고장 난 것처럼 보입니다. 로그인을 마친 뒤 Export를 다시 누르세요. 무료 파일 3개에는 신용카드가 필요 없습니다.

컴퓨터를 옮기거나 재설치해도 Pro는 그 Google 이메일을 따라 복원됩니다. Anthropic 비밀번호와는 관계가 없습니다. 결제할 때 쓴 것과 같은 Google 계정으로 로그인하세요.

저희는 공식 ZIP과 저희 내보내기를 일부러 서로 다른 작업으로 둡니다. 이메일로 받는 계정 JSON은 Anthropic의 백업입니다. 채팅별 Markdown과 JSON은 열어 둔 대화로 저희가 브라우저 안에서 만드는 것입니다. 두 가지를 버튼 하나에 섞으면 둘 다 나빠집니다.

Claude 채팅 내보내기와 복사해 붙여넣기의 차이는?

복사해 붙여넣기는 아주 약한 의미에서만 Claude 채팅 내보내기입니다. 텍스트를 선택해 옮긴 것뿐이니까요. 코드는 들여쓰기를 잃고, 표는 무너지며, 긴 대화에는 메시지 경계가 없습니다. Claude 채팅을 구조화된 파일로 내보내는 방법은 여전히 확장 프로그램, 인쇄, 공식 ZIP입니다.

중간 방법으로 전체를 선택해 Google Docs나 Word에 붙여넣은 뒤 서식을 손으로 고칠 수 있습니다. 고객에게 한 번 보낼 결과물이라면 괜찮지만, 매주 쌓는 아카이브로는 맞지 않습니다. 새 대화가 생길 때마다 다시 정리해야 합니다. 확장 프로그램은 그런 정리를 붙여넣기에서 시작하지 않게 하려고 만든 것입니다.

복사해 붙여넣기는 접혀 있는 사고 과정과 펼치지 않은 아티팩트도 놓칩니다. 인쇄도 마찬가지로, 접힌 화면 요소는 PDF에 없습니다. 확장 프로그램의 옵션은 불러온 페이지 데이터에 있는 사고 과정과 아티팩트를 포함할 수 있으며, 이는 ‘화면에 보이는 픽셀’과는 다른 층위입니다.

Slack에 문단 하나만 필요하다면 복사해 붙여넣기가 솔직하고 빠릅니다. 코드 블록까지 포함한 리뷰 전체가 필요하다면 무료 3회 중 하나를 Markdown에 쓰세요.

Claude Code와 claude.ai 채팅은 내보내는 방법이 다른가요?

claude.ai에서 Claude 채팅을 내보내는 방법은 이 Chrome 확장 프로그램입니다. Claude Code 대화를 내보내는 방법은 터미널의 /export 명령이나 ~/.claude/projects 아래의 JSONL입니다. Claude Desktop은 세 번째 창이며 주황색 버튼이 생기지 않습니다.

Claude Code의 /export는 렌더링된 일반 텍스트 기록을 클립보드나 파일로 씁니다. Anthropic은 디스크의 JSONL이 바뀔 수 있는 내부 형식이라고 설명합니다. 보관할 기록이라면 /export나 공식 스크립트 인터페이스를 쓰세요. 단계: Claude Code 내보내기.

Claude Desktop: 동기화되었다면 같은 채팅을 claude.ai에서 열고 그곳에서 내보내세요. 아니면 Desktop에서 복사해 붙여넣거나, 계정 단위 JSON인 Settings → Privacy → Export data를 이용하세요. 가이드: Claude Desktop 채팅 내보내기.

이 사이트에서 ‘Claude Code 내보내기’를 찾으면 기능이 아니라 구분을 위한 안내 페이지로 연결됩니다. Web Store 등록 항목은 claude.ai 전용입니다. 이 제한은 빠진 체크박스가 아니라 제품의 범위입니다.

Claude 채팅을 내보내면 무엇이 남고 무엇이 빠지나요?

이 확장 프로그램으로 Claude 채팅을 내보내면 페이지가 불러온 메시지 트리가 남습니다. 발신자, 텍스트, 코드 블록, 표, 그리고 옵션을 켰다면 사고 과정, 메타데이터, 아티팩트입니다. 아직 렌더링되지 않은 내용과 입력창 같은 CSS 화면 요소는 빠집니다.

인쇄는 픽셀을 남기지만 깔끔한 코드 레이아웃은 대개 잃습니다. 공식 ZIP은 Anthropic이 계정 아카이브에 넣은 내용을 남기지만, 사람이 읽기 좋은 채팅별 문서는 없습니다. 복사해 붙여넣기는 선택한 글자만 남기고 구조는 버립니다.

발신자 필터: “all / human only / assistant only”(전체 / 사용자만 / 어시스턴트만). 답변 없이 프롬프트만, 또는 그 반대가 필요할 때 유용합니다. 메타데이터 옵션은 파일에 출처 정보가 필요할 때 제목, 타임스탬프, 모델을 추가합니다.

파일은 디스크에 남습니다. 저희 워커는 구독 상태를 봅니다. Google은 사용자가 승인한 OAuth 동의를 봅니다. claude.ai는 원래 대화를 갖고 있었습니다. 관련된 곳은 이것이 전부입니다. 저희는 Anthropic이 아닙니다. Claude는 Anthropic, PBC의 상표입니다.

내보낸 파일이 짧아 보인다면 대화를 더 불러온 뒤 다시 내보내세요. 무료 플랜에서는 그 두 번째 시도도 3회 중 1회입니다. 누르기 전에 응답이 끝났는지, 이전 메시지가 화면에 있는지 확인하세요.
