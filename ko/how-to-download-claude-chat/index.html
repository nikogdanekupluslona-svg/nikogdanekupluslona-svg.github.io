Chrome에서 Claude 채팅을 다운로드하는 방법은?

Claude 채팅 다운로드 방법에 대한 가장 직접적인 답은 Download Claude conversations가 claude.ai 메시지 입력창 옆에 추가하는 주황색 버튼입니다. 대화를 열고 Markdown, JSON, 텍스트, XML, PNG 중 하나를 고른 다음 “Export”(내보내기)를 누르세요. 파일은 브라우저 안에서 만들어져 디스크에 저장됩니다.

이 확장 프로그램은 Chrome 콘텐츠 스크립트입니다. 로그인된 claude.ai 세션에 이미 불러온 대화를 읽습니다. 자체 자격 증명으로 별도의 Anthropic API를 호출하지 않으며, 파일을 만들기 위해 대화를 저희 서버에 올리지도 않습니다.

  1. Chrome Web Store에서 Download Claude conversations를 설치합니다(Chrome 확장 프로그램을 불러올 수 있는 Chromium 브라우저에서도 작동합니다).
  2. 설치하는 동안 claude.ai 페이지가 열려 있었다면 새로고침합니다.
  3. 원하는 대화 URL을 엽니다. 주황색 버튼은 빈 입력 화면이 아니라 실제 대화 스레드에서만 나타납니다.
  4. 메시지 입력창 오른쪽의 주황색 다운로드 버튼을 누릅니다.
  5. Markdown, JSON, 일반 텍스트, XML, PNG 중에서 고르고 Export를 누릅니다. Chrome이 바로 파일을 다운로드합니다.

첫 내보내기 전에는 Google 로그인이 필요합니다. 이 로그인은 계정당 무료 내보내기 3회를 계산하고 나중에 Pro를 복원하기 위한 것이며, 채팅을 읽기 위한 로그인이 아닙니다. 사용 한도와 구독 상태 확인을 위해 Google로 인증된 이메일만 저장합니다. 대화 본문은 사용자 컴퓨터에 머뭅니다.

Markdown이든 PNG든 완성된 파일 하나가 내보내기 1회로 계산됩니다. 무료 계정은 총 3회를 쓸 수 있습니다. Pro는 월 $3.99 또는 연 $26.99이며, 단일 채팅과 일괄 “Export All”(모두 내보내기) 모두에서 이 제한을 없애 줍니다.

로컬 파일. Markdown, JSON, 텍스트, XML, PNG는 브라우저 안에서 만들어져 Chrome의 다운로드 API로 전달됩니다. 사용 한도 확인은 저희 워커로 가지만, 채팅 텍스트는 가지 않습니다.

같은 위젯에서 선택 옵션도 쓸 수 있습니다. 확장 사고(extended thinking) 포함 여부, 메타데이터(제목, 타임스탬프, 모델) 포함 여부, 발신자 필터(“all / human only / assistant only”, 즉 전체 / 사용자만 / 어시스턴트만), 그리고 아티팩트 배치(“Original”, “Inline”, “Nested”, “Flat”)입니다. 이 옵션은 일괄 목록 페이지에서와 똑같이 이 채팅 하나에도 적용됩니다.

대화가 아주 길다면 claude.ai가 이전 메시지를 불러올 때까지 위로 스크롤하세요. 확장 프로그램은 페이지에 렌더링된 내용만 내보낼 수 있습니다. 절반만 불러온 대화는 절반짜리 파일이 되는데, 버그처럼 보이지만 대개는 스크롤하지 않은 DOM 때문입니다.

저희는 사용자가 이미 연 claude.ai 페이지의 메시지 트리를 분석합니다. 코드 블록은 언어 태그와 들여쓰기를 유지하고, 표는 표 그대로 남습니다. 없는 PDF 형식을 만들어 내지는 않습니다. 인쇄용 페이지가 필요하면 가짜 “PDF로 내보내기” 버튼이 아니라 브라우저의 인쇄 대화상자를 쓰세요.

확장 프로그램 없이 Claude 채팅을 다운로드할 수 있나요?

네. 페이지를 인쇄하거나 Anthropic의 계정 내보내기를 요청하면 확장 프로그램 없이도 Claude 채팅을 다운로드할 수 있습니다. 인쇄는 웹페이지를 시각적인 PDF로 만든 것이고, Export data는 나중에 도착하는 계정 전체 JSON ZIP입니다. 둘 다 채팅별 Markdown 파일은 만들지 않습니다.

인쇄 방법: claude.ai에서 대화를 열고, 가능하면 사이드바를 숨긴 다음, Ctrl+P(Windows/Linux) 또는 Cmd+P(Mac)를 누르세요. 대상을 “PDF로 저장”으로 설정하고 저장합니다. 코드 블록이 페이지 사이에서 잘리는 경우가 많고, 입력창 같은 화면 요소가 매 페이지에 찍힐 수 있습니다. 인쇄에 관한 자세한 내용은 Claude 채팅을 PDF로 저장하기에 있습니다.

공식 방법: claude.ai의 Settings → Privacy → Export data(claude.ai를 한국어로 설정했다면 메뉴 이름이 한국어로 표시될 수 있습니다). Anthropic이 만료되는 링크를 이메일로 보내 줍니다. ZIP은 계정 단위의 JSON 아카이브이며, 읽고 있던 채팅의 이름이 붙은 파일이 아닙니다. 백업용으로 쓰고, 수천 개 중 대화 하나가 필요하면 직접 압축을 풀어 찾아야 합니다.

복사해 붙여넣기는 확장 프로그램 없이 쓸 수 있는 세 번째 방법입니다. 텍스트를 선택해 문서나 메모 앱에 붙여넣으면 됩니다. 코드의 들여쓰기는 대개 무너지고, 표는 한 줄로 이어지며, 여러 번 주고받은 대화는 구조 없는 텍스트 덩어리가 됩니다. 짧은 답변 하나에는 괜찮지만, 나중에 검색할 코드 리뷰에는 맞지 않습니다.

Claude 채팅 기록을 한꺼번에 다운로드하려면?

Claude 채팅 기록을 여러 파일로 다운로드하려면 탭마다 주황색 버튼을 반복해서 누르지 마세요. 확장 프로그램 팝업에서 “View and Download All Conversations”(모든 대화 보기 및 다운로드)를 열고, 표를 필터링한 다음 “Export All”을 누르세요. Pro가 아니라면 완성된 파일 하나하나가 같은 무료 3회에서 차감됩니다.

목록 페이지에는 로그인한 claude.ai 계정의 대화가 표시됩니다. 이름으로 검색하고, All(전체), New(아직 내보내지 않음), Exported(내보냄)로 필터링할 수 있으며, claude.ai에서 프로젝트로 채팅을 묶어 두었다면 Project로도 필터링할 수 있습니다. 오래된 초안까지 전부 폴더에 넣고 싶지 않다면 일부만 선택하세요.

일괄 내보내기는 단일 채팅 내보내기와 같은 다섯 가지 형식과 같은 옵션(사고 과정, 메타데이터, 발신자 필터, 아티팩트 배치)을 씁니다. Export All은 기능이 줄어든 별도 처리 방식이 아닙니다. 같은 파서를 여러 대화 ID에 한 번에 적용할 뿐입니다. 자세한 내용과 스크린샷: 일괄 Export All.

Anthropic의 Export data는 여전히 계정 백업 수단입니다. ZIP 하나, 이메일 한 통, 잊고 있던 채팅까지 모두 JSON으로 담깁니다. 일괄 Export All은 반대 방향의 작업입니다. 어떤 대화를 받을지, Markdown으로 받을지 JSON으로 받을지 직접 고르고, 파일은 즉시 저장됩니다. 공식 보관용 아카이브와 읽기 쉬운 노트 폴더가 모두 필요하다면 둘 다 쓰세요.

사용 한도는 공유됩니다. 무료 내보내기 3회는 단일 채팅과 일괄 파일을 합쳐서 계산합니다. 무료 계정에서 대화 40개를 선택하면 세 번째 파일 이후 멈춥니다. 선택을 미리 계획하거나 월 $3.99 또는 연 $26.99의 Pro로 업그레이드하세요.

목록 표는 이미 내보낸 항목도 기억하므로, 다음에 방문했을 때 New만 골라 볼 수 있습니다. 그래서 매주 Claude 채팅 기록을 다운로드하는 습관도 지난달 Markdown을 중복하지 않고 새 항목만 추가하는 방식으로 이어갈 수 있습니다.

Claude 채팅을 Markdown이나 JSON으로 다운로드하려면?

Claude 채팅을 Markdown이나 JSON으로 다운로드하려면 주황색 버튼을 열고 형식을 고른 뒤 Export를 누르세요. Markdown은 노트용 파일, JSON은 스크립트용 메시지 트리입니다. 일반 텍스트에는 마크업이 없습니다. PNG는 이미지이며 PDF가 아닙니다.

Markdown은 제목, 언어 태그가 붙은 코드 블록, 표를 유지합니다. Obsidian, GitHub, 위키에 넣을 때 주로 고르는 형식입니다. JSON은 파서가 만든 트리를 그대로 보존하며, 해당 옵션을 켜면 아티팩트와 사고 과정도 포함합니다. Anthropic 계정 ZIP과는 구조가 다릅니다. 형식별 설명: 모든 형식.

일반 텍스트는 어차피 마크업이 제거되는 곳에 넣을 때 알맞습니다. 티켓 입력란, 이메일 본문, 순수 문자열이 필요한 검색 색인 같은 경우입니다. XML은 특수한 데이터 교환용입니다. PNG는 슬라이드나 버그 리포트에 넣을 대화 스크린샷용이며, 나중에 grep으로 검색할 40턴짜리 설계 리뷰에는 맞지 않습니다.

버전 1.13.0에는 자체 PDF 형식이 없습니다. 고객에게 PDF를 보내야 한다면 Markdown으로 내보낸 뒤 Word, Google Docs, VS Code, Obsidian에서 그 파일을 인쇄하세요. 또는 claude.ai 화면을 직접 인쇄하세요. 이 확장 프로그램에 없는 .pdf 옵션을 기다리지 마세요. 변환 단계: 인쇄와 PDF.

마지막으로 사용한 형식이 기억됩니다. Markdown을 원했는데 JSON을 받았다면, 드롭다운이 이전 내보내기의 JSON으로 남아 있었던 것입니다. 작업이 바뀔 때마다 드롭다운을 확인하세요.

Claude 대화 저장, 인쇄나 ZIP과 무엇이 다른가요?

claude.ai에서 저장, 다운로드, 내보내기는 같은 작업입니다. 대화를 페이지 밖으로 꺼내는 것이죠. Claude 대화를 실제로 쓸 수 있는 파일로 저장하는 방법은 확장 프로그램입니다. 인쇄는 스냅샷이고, Anthropic Export data는 계정 ZIP입니다.

팀 안에서도 표현이 섞입니다. 연구자는 저장한다고, 개발자는 내보낸다고, 관리자는 다운로드한다고 말합니다. Chrome의 claude.ai라면 이 사이트에서 세 동사는 모두 같은 주황색 버튼으로 이어집니다. 관련 가이드인 Claude 채팅 내보내는 방법에서 공식 ZIP과 JSON 구조를 더 자세히 다룹니다.

인쇄가 필요한 경우도 있습니다. 제품 화면처럼 보여야 하는 일회성 첨부 파일이 그렇습니다. 공식 Export data도 쓸모가 있습니다. 퇴사, 법적 보존, 이중 백업 같은 경우입니다. 하지만 둘 다 다음 주에 편집할 Markdown 파일을 대신하지는 못합니다.

Claude Desktop은 다른 창입니다. Chrome 확장 프로그램은 Desktop 앱 안에 들어가지 않습니다. 같은 채팅이 claude.ai에도 있다면 그곳에서 열고 다운로드하세요. Desktop에만 있다면 복사해 붙여넣거나 계정 ZIP을 기다리세요. 단계별 안내: Claude Desktop 채팅 내보내기.

Pro 결제는 Paddle이 처리합니다. 저희는 카드 번호를 보지 못합니다. Google 로그인으로 저희가 대화에 접근하게 되지도 않습니다. Pro 상태를 확인하는 Cloudflare 워커는 메시지 텍스트가 아니라 라이선스 상태만 받습니다. 개인정보 보호의 핵심은 이 경계입니다. 결제는 서버에서, 채팅은 디스크에서.

Claude 채팅 다운로드 버튼이 보이지 않는 이유는?

대화 URL이 아닌 곳에 있거나, 설치 후 탭을 새로고침하지 않았거나, 확장 프로그램이 꺼져 있으면 Claude 채팅 다운로드 버튼이 보이지 않습니다. 아이콘을 고정하고 새로고침한 다음, Desktop 앱이나 휴대폰, Claude Code가 아니라 데스크톱 Chrome의 claude.ai에 있는지 확인하세요.

Team과 Enterprise 워크스페이스도 브라우저에서 대화를 열 수 있다면 작동합니다. 확장 프로그램은 요금제가 아니라 페이지를 읽습니다. 조직에서 Chrome 확장 프로그램을 막아 두었다면 IT 부서가 이 확장 프로그램을 허용해야 하며, 저희가 웹사이트에서 그 정책을 우회할 수는 없습니다.

로그인 요청: 정상입니다. 처음 Export를 누르면 Google 로그인을 요청합니다. 이 창을 닫으면 다운로드가 실패한 것처럼 보입니다. 로그인을 마친 뒤 Export를 다시 누르세요. 무료 내보내기 3회에는 신용카드가 필요 없습니다.

Claude Code의 채팅도 다운로드되나요?

아니요. Download Claude conversations는 Claude Code 대화를 다운로드하지 않습니다. Claude Code는 터미널 에이전트입니다. claude.ai에서 Claude 채팅을 다운로드하는 방법은 이 Chrome 확장 프로그램이고, 터미널 세션을 내보내는 방법은 /export 명령이나 ~/.claude/projects 아래의 JSONL 파일입니다. 제품이 다르고 파일도 다릅니다.

진행 중인 Claude Code 세션 안에서 /export를 입력하세요. Anthropic의 CLI가 대화 기록을 복사하거나 일반 텍스트 파일로 저장하는 메뉴를 엽니다. 파일 이름을 함께 입력하면 메뉴를 건너뜁니다. 이 기록은 사람이 읽기 위한 텍스트이며, 이 확장 프로그램의 Markdown/JSON/PNG와는 다릅니다. 전체 경로: Claude Code 내보내기.

디스크의 JSONL은 내부 로그입니다. 스키마는 Claude Code 버전마다 바뀔 수 있습니다. Anthropic 공식 문서도 JSONL을 직접 파싱하기보다 /export나 스크립트 인터페이스를 쓰라고 안내합니다. 저희는 그 CLI를 감싸지 않으며, ~/.claude를 읽지도 않습니다.

같은 작업을 claude.ai에서도 별도 대화로 진행하고 있다면, 그 브라우저 채팅은 주황색 버튼으로 다운로드하세요. 터미널 로그와 웹 채팅은 자동으로 같은 문서가 되지 않습니다. 한쪽을 다른 쪽에 붙여넣지 않았다면 두 개의 별도 기록으로 다루세요.

FAQ: Claude 채팅 다운로드 방법

Chrome에서 Claude 채팅을 어떻게 다운로드하나요?

Download Claude conversations를 설치하고, claude.ai에서 대화를 연 다음, 메시지 입력창 옆의 주황색 버튼을 누르세요. Markdown, JSON, 텍스트, XML, PNG 중 하나를 고르고 Export(내보내기)를 누르면 파일이 로컬로 다운로드됩니다. 무료 내보내기 3회를 계산하기 위해 첫 내보내기 전에 Google 로그인이 필요합니다.

확장 프로그램 없이 Claude 채팅을 다운로드할 수 있나요?

네. 화면 그대로의 사본이 필요하면 페이지를 인쇄(Ctrl/Cmd+P → PDF로 저장)하고, 계정 전체 JSON ZIP이 필요하면 Settings → Privacy → Export data를 사용하세요(ZIP은 나중에 도착합니다). 짧은 답변이라면 복사해 붙여넣기도 됩니다. 다만 이 방법들은 Chrome 확장 프로그램처럼 채팅별로 구조화된 Markdown 파일을 만들어 주지 않습니다.

Claude 채팅 기록은 어떻게 다운로드하나요?

대화 하나라면 주황색 버튼을 쓰세요. 여러 파일이 필요하면 View and Download All Conversations를 열고 Export All을 누르세요. 이 일괄 방식은 Anthropic의 Export data ZIP과 다릅니다. 공식 Export data는 계정 전체를 담은 아카이브 하나를 나중에 이메일로 보내 줍니다. 일괄 다운로드를 참고하세요.

Claude 채팅을 다운로드하려면 돈을 내야 하나요?

아니요. 모든 계정에 다섯 가지 형식 어디에나 쓸 수 있는 무료 내보내기 3회가 제공됩니다. 그 이후 Pro는 월 $3.99 또는 연 $26.99이며, 결제는 Paddle이 처리합니다. 무료 플랜은 무제한이 아니며, 일괄 내보내기 파일도 같은 3회에서 차감됩니다.

Download Claude conversations는 모바일에서 작동하나요?

아니요. 데스크톱 Chrome(또는 Chrome Web Store 항목을 설치할 수 있는 다른 Chromium 브라우저)용 Chrome 확장 프로그램입니다. iOS나 Android 앱은 없습니다. 모바일 브라우저에서도 Claude 채팅을 인쇄할 수는 있지만 이 확장 프로그램은 실행할 수 없습니다.

이 확장 프로그램 때문에 Anthropic 계정이 정지될 수 있나요?

법률 자문은 드릴 수 없습니다. 이 확장 프로그램은 사용자 본인의 세션에서 이미 불러온 claude.ai 페이지를 읽습니다. 별도 자격 증명으로 Anthropic을 호출하거나 계정에서 클릭을 자동화하지 않습니다. 저희는 Anthropic이 아닙니다. Anthropic의 서비스 약관과 소속 회사의 규정을 따르세요.

Claude 대화를 파일로 저장하려면 어떻게 하나요?

열어 둔 채팅을 깔끔한 파일로 받으려면 Chrome 확장 프로그램을 쓰세요. PDF 같은 스냅샷이 필요하면 인쇄를, 계정 전체 ZIP이 필요하면 Anthropic의 Export data를 쓰세요. claude.ai에서 대화를 화면 밖으로 꺼내고 싶을 때 저장, 다운로드, 내보내기는 모두 같은 작업을 가리킵니다.

Claude Code 세션에도 작동하나요?

아니요. Claude Code는 터미널에서 동작합니다. /export를 쓰거나 ~/.claude/projects(Windows: %USERPROFILE%\.claude\projects)에서 JSONL을 복사하세요. 이 Chrome 확장 프로그램은 claude.ai에서만 실행됩니다. 가이드: Claude Code 내보내기.

Claude 채팅을 다운로드하려면 Google 로그인이 필요한가요?

네, 첫 내보내기부터 필요합니다. Google이 선택한 계정을 확인해 주기 때문에 3회 내보내기 한도를 적용하고, 재설치 후에도 Pro를 복원할 수 있습니다. 이 로그인과 함께 대화 내용이 전송되지는 않습니다. 인증된 이메일은 사용 한도와 Pro 상태 확인용으로만 저장합니다.

Claude 채팅은 어떤 형식으로 다운로드할 수 있나요?

Markdown, JSON, 일반 텍스트, XML, PNG입니다. 확장 프로그램 1.13.0에는 PDF 내보내기가 없습니다. PDF가 필요하면 claude.ai를 인쇄하거나 Markdown 파일을 다른 앱에서 변환하세요. PNG는 대화의 이미지이며 PDF가 아닙니다. 형식 안내: 형식.
