Claude 대화 추출기란 무엇인가요?

Claude 대화 추출기는 렌더링된 claude.ai 대화를 분석해 진짜 파일을 만듭니다. Download Claude conversations가 그 Chrome 도구입니다. 스크린샷 유틸리티도, Anthropic의 계정 ZIP도 아닙니다. 사람들은 claude.ai의 같은 주황색 버튼을 두고 추출, 내보내기, 다운로드라고 각각 부릅니다.

개발자와 연구자가 ‘Claude 대화 추출기’를 검색하는 이유는 ‘추출’이 구조를 떠올리게 하기 때문입니다. 발신자, 콘텐츠 블록, 코드 블록, 표, 아티팩트 말이죠. Download Claude conversations는 이미 연 탭에서 그 분석을 수행합니다. 리뷰어들이 Claude Conversation Downloader나 Claude Exporter라고 부르기도 하지만, 모두 이 Chrome 등록 항목, 즉 Chrome Web Store의 Download Claude conversations 1.16.2를 가리킵니다.

이 추출기는 Claude Desktop 플러그인도, Claude Code CLI도 아닙니다. 터미널 기록을 찾으셨다면 /export를 쓰세요. 가이드: Claude Code 내보내기. Mac/Windows 앱을 찾으셨다면 Claude Desktop 채팅 내보내기를 보세요. 웹용 Claude Code(claude.ai/code)와 Cowork 세션은 claude.ai에서 열리므로 추출할 수 있습니다. 이 페이지는 Chrome의 claude.ai만 다룹니다.

같은 버튼, 다른 동사. ‘Claude 채팅 추출’, ‘Claude 채팅 내보내기’, ‘Claude 채팅 다운로드’는 모두 Download Claude conversations로 이어집니다. 제품 관점의 내보내기 설명은 Claude 채팅 내보내기에 있습니다. 이 가이드는 추출기가 무엇을 읽고 무엇을 버리는지에 집중합니다.

claude.ai에서 Claude 채팅을 어떻게 추출하나요?

Download Claude conversations를 설치하고, claude.ai에서 대화 URL을 연 다음, 메시지 입력창 옆의 주황색 버튼을 누르고 형식을 골라 Export를 누르세요. Claude 대화 추출기는 Chrome의 다운로드 API로 파일을 로컬에 씁니다. Markdown, 텍스트, JSON, XML, CSV, PNG에는 계정이 필요 없으며, Google 로그인은 PDF와 일괄 내보내기에서만 나타납니다.

  1. Chrome 등록 항목(Download Claude conversations, 2026년 9월 기준 버전 1.16.2)을 추가합니다.
  2. claude.ai를 새로고침하고 대화를 엽니다. 추출기에는 빈 시작 화면이 아니라 대화 URL이 필요합니다.
  3. 메시지 입력창 오른쪽의 둥근 주황색 버튼을 누릅니다.
  4. Messages(메시지)를 All, Human, Assistant(전체, 사용자, 어시스턴트) 중 하나로 정하고, 필요하면 “Thinking”(사고 과정)을 체크하거나 “Select”(선택)로 메시지를 하나씩 고릅니다. PDF, Markdown, JSON, 일반 텍스트, XML, CSV, PNG 중에서 형식을 고릅니다.
  5. Export를 누르거나, “Copy”(복사)를 눌러 Markdown, 텍스트, JSON, XML, CSV를 클립보드에 넣습니다. Claude 대화 추출기는 채팅 본문을 저희 서버에 올리지 않습니다.

주황색 버튼이 보이지 않는다면 확장 프로그램을 고정하고, 탭을 새로고침한 다음, URL이 실제 채팅인지 확인하세요. Claude 대화 추출기는 claude.ai에만 들어갑니다. Claude Desktop, Claude Code 터미널, 다른 웹사이트에는 나타나지 않습니다. 파일이 불완전하다면 대개 긴 대화가 아직 렌더링을 마치지 않은 것입니다. 스크롤하거나 기다린 뒤 다시 추출하세요.

추출기는 마지막으로 쓴 형식을 기억합니다. Markdown을 원했는데 JSON을 받았다면 Export 전에 드롭다운을 여세요. PDF를 고르면 Google 로그인을 요청합니다. 하루에 PDF나 일괄 내보내기를 3회 쓰고 나면 무료 요금제에서 월 $3.99 또는 연 $26.99의 Pro 안내가 나타납니다. 정상 동작이며 분석 실패가 아닙니다. 횟수는 자정(UTC)에 초기화됩니다.

인쇄와 ZIP 대안을 포함한 단계 목록이 필요하다면 Claude 채팅 다운로드 방법을 보세요. 인쇄 → PDF로 저장까지 포함한 방법 비교가 필요하다면 Claude 채팅 내보내는 방법을 보세요. 이 추출기 페이지는 열어 둔 대화를 구조화된 파일로 원한다고 가정합니다.

Claude 대화 추출기는 무엇을 가져오나요?

Claude 대화 추출기는 claude.ai가 이미 그린 메시지 트리를 읽습니다. 사용자와 어시스턴트의 차례, 언어 태그가 붙은 코드 블록, 표, 링크, 선택적인 사고 과정입니다. 아티팩트 배치는 “Original”, “Inline”, “Nested”, “Flat” 중 하나입니다. 같은 페이지에서 복사해 붙여넣으면 그 구조가 사라지지만, 추출기는 Markdown, JSON, XML에 구조를 그대로 남깁니다.

사고 과정은 체크박스로 넣고 뺍니다. 추출한 파일에 Claude의 표시된 추론 과정이 필요하면 켜고, 최종 답변만 원하면 끄세요. 메타데이터에는 제목, 타임스탬프, 모델을 담을 수 있습니다. Messages 필터(All, Human, Assistant), “Thinking”, “Select”는 내보내기 패널에서 Format(형식) 옆에 있고, 도구 / MCP 단계와 웹 검색 출처는 Settings(설정)에서 켜는 선택 사항입니다. 기능 목록: 기능.

추출기는 claude.ai 탭에서 페이지가 이미 렌더링한 대화를 읽습니다. 코드 블록, 표, 아티팩트 배치(Original, Inline, Nested, Flat)를 그곳에서 분석한 뒤 파일을 로컬에서 만듭니다. PDF도 마찬가지입니다.

추출기는 Chrome이 한 번도 불러오지 않은 채팅은 가져올 수 없습니다. 시크릿 모드, 로그아웃된 탭, Claude Desktop에만 있는 대화에서는 파일이 만들어지지 않습니다. 로그인한 상태에서 claude.ai 대화를 연 다음 Claude 대화 추출기를 실행하세요. 오프라인 내보내기는 그 페이지를 불러온 뒤에만 가능하며, 그때도 파일을 만들기 위해 서버를 거치지 않습니다.

Claude 채팅 추출기는 어떤 형식을 만드나요?

일곱 가지입니다. PDF, Markdown, JSON, 일반 텍스트, XML, CSV, PNG이며, Claude 채팅 하나를 추출하든 Export All을 실행하든 같은 일곱 가지입니다. Download Claude conversations 1.16.2에는 Word, Notion, Google Docs가 없습니다. 한도는 형식에 따라 정해집니다. 여섯 가지 형식은 계정 없이 무제한이고, PDF는 무료 요금제에서 한 번 만들 때마다 하루 3회 중 1회를 씁니다.

Claude 대화 추출기의 JSON은 Anthropic의 계정 단위 Export data ZIP과 구조가 다릅니다. 추출기 파일은 페이지에서 만든 채팅별(또는 일괄 선택별) 파일이고, ZIP은 나중에 도착하는 계정 아카이브입니다. 한쪽을 기대하는 스크립트에 다른 쪽을 넣지 마세요. 안내: 모든 형식.

Claude 대화를 일괄 추출할 수 있나요?

네. 확장 프로그램 팝업에서 View and Download All Conversations를 열고 필터링한 다음 Export All을 누르세요. Claude 대화 추출기가 선택한 채팅마다 파일이 하나씩, 고른 형식으로 담긴 ZIP 하나를 만듭니다. 일괄 내보내기에는 Google 로그인이 필요합니다. 계정이 월 $3.99 또는 연 $26.99의 Pro가 아니라면 무료 요금제에서 ZIP에 담긴 채팅마다 PDF와 함께 쓰는 하루 3회 중 1회를 씁니다.

Dashboard(대시보드)의 필터는 “All conversations”(모든 대화), “New”(새 항목), “Updated”(업데이트됨), “Previously exported”(이전에 내보냄)이며, Chat과 Cowork 탭, 프로젝트 검색도 있습니다. New는 Claude 대화 추출기가 아직 저장하지 않은 채팅입니다. Previously exported는 이미 추출한 기록을 표시하므로 이후 일괄 실행에서 건너뛸 수 있습니다. 프로젝트 검색은 claude.ai 프로젝트 구분과 같습니다. Export All을 누르기 전에 검색으로 이름을 찾아 대화를 고를 수 있습니다.

일괄 추출은 기능이 줄어든 분석이 아닙니다. Dashboard의 체크박스 “Chats”, “Thinking”, “Metadata”, “Tools”, “Sources”(채팅, 사고 과정, 메타데이터, 도구, 출처)와 아티팩트 배치가 각 파일에 담길 내용을 정하고, “Chat format”(채팅 형식) 선택기에서는 PDF를 포함한 일곱 가지 형식을 모두 고를 수 있습니다. 한도 주의 사항을 포함한 안내: 일괄 Export All. 계정 전체를 담은 ZIP 하나를 이메일로 받고 싶다면 그것은 이 추출기가 아니라 Settings → Privacy → Export data(claude.ai를 한국어로 설정했다면 메뉴 이름이 한국어로 표시될 수 있습니다)입니다.

일괄 내보내기는 채팅 단위로 계산됩니다. 무료 요금제에서 Export All은 PDF와 하루 3회를 함께 쓰며, ZIP에 담긴 채팅 하나하나가 1회씩 씁니다. 3회가 남은 상태에서 채팅 25개를 선택하면 일부만 내보내지는 것이 아니라 작업 전체가 막힙니다. New 필터로 선택을 줄이거나, 자정(UTC) 초기화를 기다리거나, 대량으로 추출하기 전에 Pro(월 $3.99 또는 연 $26.99)로 업그레이드하세요.

Claude 대화 추출기 vs 복사해 붙여넣기

복사해 붙여넣기는 짧은 Claude 답변 하나에는 괜찮지만 코드와 표에서는 실패합니다. Anthropic Export data는 계정 백업 ZIP입니다. Claude 대화 추출기는 그 중간입니다. 이 대화 또는 일괄 선택을, 구조화된 파일로, 즉시, Chrome의 claude.ai에서 만듭니다.

인쇄는 추출기가 아닙니다. 노트 파일에 넣고 싶지 않은 화면 요소까지 포함해 웹페이지를 그대로 찍습니다. Claude 대화 추출기는 그런 요소를 걷어내고 메시지 구조를 유지합니다. PDF가 필요하면 같은 패널에서 PDF를 고르세요. 확장 프로그램이 인쇄 대화상자 없이 브라우저 안에서 만듭니다. 텍스트를 클립보드에 넣고 싶다면 패널의 “Copy” 버튼이 페이지 텍스트 대신 Markdown, 텍스트, JSON, XML, CSV를 복사합니다.

Claude 대화 추출기는 안전한가요?

이 Claude 대화 추출기는 사이트와 같은 방식으로 기존 claude.ai 세션을 사용합니다. 계정 작업을 자동화하거나 채팅 본문을 저희 API로 보내지 않습니다. Google 로그인은 PDF, 일괄 내보내기, Pro에만 필요하며, 하루 한도를 계산하고 Pro를 복원하는 데 쓰입니다. 결제는 Paddle이 처리합니다. 저희는 Anthropic이 아니며, Anthropic의 약관은 그대로 적용됩니다.

PDF, 일괄 내보내기, Pro를 위해 로그인한 뒤에는 Cloudflare 워커가 Google 이메일, 오늘의 PDF·일괄 내보내기 횟수, Pro 여부를 확인합니다. FAQ: Claude 대화 추출기

이 FAQ는 Claude 대화 추출기와 Claude 채팅 추출에 관한 질문에 답합니다. 일괄 Export All, Desktop, Claude Code, PDF, Google 로그인, PDF와 일괄 내보내기의 하루 한도를 다룹니다. 답변은 claude.ai용 확장 프로그램 1.16.2 기준입니다. 문서 head의 FAQPage 스키마도 이 목록과 일치합니다.

Claude 대화 추출기란 무엇인가요?

열어 둔 claude.ai 대화를 읽어 PDF, Markdown, JSON, 일반 텍스트, XML, CSV, PNG로 만드는 도구입니다. Download Claude conversations가 추가하는 주황색 버튼이 Chrome 안에서 로컬로 이 분석을 수행합니다.

Claude 채팅 추출과 Claude 채팅 내보내기는 다른가요?

아니요. 같은 작업을 다른 동사로 부를 뿐입니다. 추출, 내보내기, 다운로드 모두 claude.ai의 같은 주황색 버튼과 같은 일곱 가지 형식으로 이어집니다. 이 페이지는 파서가 무엇을 보존하는지에 초점을 둡니다.

아무것도 설치하지 않고 Claude 채팅을 추출할 수 있나요?

코드 블록과 표가 사라지는 복사해 붙여넣기, 또는 계정 ZIP인 Anthropic Export data로만 가능합니다. 구조화된 Claude 대화 추출기는 페이지를 읽어야 하며, 그것이 Chrome 확장 프로그램입니다.

추출기는 대화 일괄 추출을 지원하나요?

네. 확장 프로그램 팝업에서 View and Download All Conversations(모든 대화 보기 및 다운로드)를 열고 Export All(모두 내보내기)을 누르면 ZIP이 만들어집니다. 일괄 내보내기에는 Google 로그인이 필요하며, 무료 요금제에서는 채팅마다 PDF와 함께 쓰는 하루 3회 중 1회가 차감됩니다. 월 $3.99 또는 연 $26.99의 Pro는 한도를 없애 줍니다. 필터: All conversations, New, Updated, Previously exported.

Claude 채팅 추출기는 안전한가요?

이 추출기는 로그인된 claude.ai 세션을 읽고 파일을 로컬에서 만듭니다. 대화 텍스트는 저희 서버로 전송되지 않습니다. 저희는 Anthropic이 아니며, 사용자는 계속 Anthropic의 서비스 약관을 따릅니다.

채팅을 추출하려면 Claude Pro가 필요한가요?

아니요. Chrome에서 대화를 열 수 있는 claude.ai 요금제라면 무엇이든 됩니다. 저희 쪽에서는 Markdown, 텍스트, JSON, XML, CSV, PNG 추출이 계정 없이 무료로 무제한이고, PDF와 일괄 내보내기는 하루 3회까지 무료입니다. Anthropic 유료 요금제는 저희 한도와 관계가 없습니다.

Claude 대화 추출기는 Desktop 앱에서 실행되나요?

아니요. Claude Desktop에는 주황색 버튼이 생기지 않습니다. 동기화된다면 같은 채팅을 claude.ai에서 여세요. 아니면 복사해 붙여넣거나 공식 ZIP을 쓰세요. 추출기는 claude.ai용 Chrome 전용입니다.

Claude 대화 추출기로 PDF를 만들 수 있나요?

네. 내보내기 패널에서 PDF를 고르고 Export를 누르세요. PDF는 인쇄 대화상자 없이 브라우저 안에서 만들어집니다. Google 로그인이 필요하고 하루 3회까지 무료이며, Pro에서는 무제한입니다.

Claude Code에서도 채팅 추출이 되나요?

웹에서만 됩니다. claude.ai/code의 Claude Code 세션은 claude.ai에서 열리므로 일반 채팅처럼 추출할 수 있습니다. 터미널의 Claude Code는 /export 명령이나 디스크의 JSONL을 씁니다. 이 Claude 대화 추출기는 claude.ai용 Chrome 콘텐츠 스크립트이며, 터미널 연동이 아닙니다.

추출기로 무료 추출은 몇 번까지 가능한가요?

Markdown, 텍스트, JSON, XML, CSV, PNG는 계정 없이 무제한입니다. PDF와 일괄 Export All은 무료 요금제에서 Google로 로그인한 계정당 하루 3회를 함께 쓰며, 자정(UTC)에 초기화됩니다. Pro는 한도를 없애 주며, Paddle 결제에 쓴 같은 Google 계정으로 복원됩니다.

Claude 대화 추출기는 무엇을 건너뛰나요?

페이지의 화면 요소, 입력창, 대화에 렌더링되지 않은 모든 것입니다. Chrome에서 한 번도 불러오지 않은 채팅도 건너뜁니다. Claude Desktop에만 있는 대화와 Claude Code의 JSONL은 대상이 아닙니다.
