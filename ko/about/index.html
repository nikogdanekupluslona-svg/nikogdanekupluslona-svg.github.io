소개

Download Claude conversations는 독립 Chrome 확장 프로그램입니다(사이트 이름: Chat Downloader). 검색 엔진과 사용자들은 Claude Chat Downloader, Claude Conversation Downloader라고도 부릅니다. Anthropic, PBC가 만들거나 제휴하거나 보증한 제품이 아닙니다. Claude(클로드)는 Anthropic의 상표이며, 저희는 claude.ai 자체의 빈틈을 메우려고 이 확장 프로그램을 만들었습니다. claude.ai에는 대화 하나를 파일로 다운로드하는 기본 기능이 없습니다.

이 확장 프로그램은 claude.ai에 내보내기 버튼을, 일괄 내보내기를 위한 목록 페이지를 추가하며, 브라우저 안에서 Markdown, JSON, 일반 텍스트, XML, PNG 파일을 로컬로 만듭니다. 모든 계정은 무료 내보내기 3회를 받으며, Pro는 제한을 없앱니다. 자세한 내용은 작동 방식을 참고하십시오. Claude Code 터미널 세션은 내보내지 않습니다.

검색하는 방식과 Store 스니펫이 일치하도록 Chrome Web Store에는 다음 문구를 사용합니다:

  • 이름(75자 이하): Claude Chat Downloader
  • 간단한 설명(132자 이하): Free Chrome extension to save claude.ai chats as Markdown, JSON, text, XML, or PNG — one conversation or bulk Export All.
