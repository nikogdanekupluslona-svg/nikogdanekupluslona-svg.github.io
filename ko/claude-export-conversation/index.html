주황색 버튼이 보이지 않는다면 탭이 claude.ai 대화 URL이 아니거나, 설치 후 아직 새로고침하지 않았거나, Download Claude conversations가 Chrome 퍼즐 메뉴 안에 숨어 있는 것입니다. 확장 프로그램을 고정한 뒤 새로고침하세요. 주황색 버튼은 다른 웹사이트에는 절대 나타나지 않습니다.

Download Claude conversations의 형식 선택은 마지막 선택을 기억합니다. “Select”(선택)로 메시지를 하나씩 고를 수 있고, “Copy”(복사)를 누르면 파일 대신 Markdown, 텍스트, JSON, XML, CSV가 클립보드에 들어갑니다. 파일이 불완전하다면 대개 긴 claude.ai 대화가 아직 메시지 트리를 다 렌더링하지 않은 것입니다. 기다린 뒤 Export를 다시 누르세요.

대화 하나 vs 계정 전체. 주황색 버튼은 열어 둔 대화를 내보냅니다. 여러 파일이 필요하면 확장 프로그램 팝업에서 “View and Download All Conversations”(모든 대화 보기 및 다운로드)를 열고 Export All을 실행하세요. Anthropic의 Settings → Privacy → Export data(claude.ai를 한국어로 설정했다면 메뉴 이름이 한국어로 표시될 수 있습니다)는 나중에 도착하는 계정 JSON ZIP이며, 이 Chrome 방식과 다릅니다.

Claude 대화를 내보내면 파일에 무엇이 남나요?

Download Claude conversations로 내보낸 Claude 대화에는 claude.ai에 이미 렌더링된 메시지 트리가 그대로 남습니다. 발신자, 코드 블록, 표, 선택적인 사고 과정, 메타데이터, 아티팩트 배치입니다. 사이드바를 찍은 스크린샷이 아닙니다. 이미지가 필요하면 PNG를, 페이지로 나뉜 문서가 필요하면 PDF를 고르세요. 버전 1.16.2에서는 PDF도 브라우저 안에서 만들어집니다.

claude.ai에서 복사해 붙여넣으면 들여쓰기가 사라지고 표가 무너집니다. 인쇄(Ctrl/Cmd+P)하면 claude.ai 화면 요소까지 찍히고 긴 코드 블록이 페이지 사이에서 잘리는 경우가 많습니다. Download Claude conversations는 코드 블록의 언어 태그를 유지하고, Markdown, JSON, XML에서 표를 표 그대로 남깁니다. PNG는 대화의 그림이며, 페이지로 나뉜 PDF가 아닙니다.

버전 1.16.2에서 확장 사고는 내보내기 패널의 체크박스로 넣고, 웹 검색 출처와 도구 / MCP 단계는 Settings(설정)에서 켜는 선택 사항입니다. 메타데이터에는 제목, 타임스탬프, 모델을 담을 수 있습니다. Messages 필터로 대화 파일을 전체 메시지, 사용자 메시지만, 어시스턴트 메시지만으로 제한할 수 있고, “Select”로 메시지를 하나씩 고를 수 있습니다. Export All용 아티팩트 배치(“Original”, “Inline”, “Nested”, “Flat”)는 Dashboard(대시보드)에서 정합니다.

저희는 claude.ai의 주황색 버튼을 중심으로 Claude 대화 내보내기를 만들었습니다. 화면에 있는 대화에서 PDF, Markdown, JSON, 텍스트, XML, CSV, PNG를 만들며, 대화를 업로드하지 않습니다. 버전 1.16.2는 PDF도 브라우저 안에서 만듭니다.

Export All로 Claude 대화 기록을 내보낼 수 있나요?

네. 확장 프로그램 팝업에서 View and Download All Conversations를 열고 필터링한 다음 Export All을 누르면 Claude 대화 기록이 대화별 파일을 담은 ZIP으로 내보내집니다. 일괄 내보내기에는 Google 로그인이 필요합니다. 무료 요금제에서는 ZIP에 담긴 대화 하나마다 PDF와 함께 쓰는 하루 3회 중 1회가 차감됩니다. 월 $3.99 또는 연 $26.99의 Pro는 일괄 내보내기 한도를 없애 줍니다.

Dashboard에는 claude.ai 대화 기록이 표시되며, 이름 검색, 필터(“All conversations”(모든 대화), “New”(새 항목), “Updated”(업데이트됨), “Previously exported”(이전에 내보냄)), Chat과 Cowork 탭, 프로젝트 검색을 쓸 수 있습니다. New는 아직 Download Claude conversations로 저장하지 않은 대화입니다. Previously exported는 이미 디스크에 쓴 대화를 추적하므로 두 번째 Export All에서 건너뛸 수 있습니다. 프로젝트 검색은 claude.ai에서 대화를 묶은 방식과 같습니다.

일괄 내보내기에는 PDF를 포함한 일곱 가지 형식을 모두 고를 수 있는 “Chat format”(채팅 형식) 선택기, “Chats”, “Thinking”, “Metadata”, “Tools”, “Sources”(채팅, 사고 과정, 메타데이터, 도구, 출처) 체크박스, 아티팩트 배치(Original, Inline, Nested, Flat)가 있습니다. Export All은 계정 전체를 기능만 줄여 묶은 ZIP이 아닙니다. 선택한 형식으로 대화마다 파일이 하나씩 담긴 ZIP 하나입니다. Anthropic Export data는 여전히 나중에 도착하는 계정 JSON ZIP입니다.

일괄 내보내기는 대화 단위로 계산됩니다. 무료 요금제에서 Export All과 PDF는 하루 3회를 함께 쓰며, ZIP에 담긴 대화 하나하나가 1회씩 씁니다. 3회가 남은 상태에서 대화 40개를 선택하면 일부만 내보내지는 것이 아니라 작업 전체가 막힙니다. 선택을 줄이거나, 자정(UTC) 초기화를 기다리거나, 월 $3.99 또는 연 $26.99의 Pro를 쓰세요. 공유 한도에 대한 자세한 내용: 일괄 Export All.

Export All이 하루 한도를 함께 쓰는 것은 PDF뿐입니다. 주황색 버튼으로 만드는 Markdown, 텍스트, JSON, XML, CSV, PNG는 이 한도에 전혀 영향을 주지 않으므로, 이 형식으로 Claude 대화를 내보내는 것은 언제나 무료입니다. 한도는 자정(UTC)에 초기화됩니다. Paddle로 구매한 Pro는 같은 Google 계정이라면 새 컴퓨터에서도 복원됩니다.

Desktop이나 Claude Code의 세션도 내보낼 수 있나요?

Desktop 앱이나 Claude Code 터미널에서는 안 됩니다. claude.ai에서 세션이란 열어 둔 대화 URL이며, 그곳에서 Claude 세션을 내보낸다는 것은 Chrome의 주황색 버튼을 뜻합니다. Cowork 세션과 웹용 Claude Code(claude.ai/code)도 claude.ai에서 열리므로 같은 방법으로 내보낼 수 있습니다. Claude Desktop에는 주황색 버튼이 나타나지 않습니다. 터미널의 Claude Code는 /export 명령이나 ~/.claude/projects의 JSONL을 씁니다.

그 대화가 claude.ai 계정에도 있다면 Chrome에서 열고 Download Claude conversations로 내보내세요. 채팅이 Claude Desktop에만 있다면 앱에서 복사해 붙여넣거나 웹에서 Settings → Privacy → Export data를 요청하세요. 비교: Claude Desktop 채팅 내보내기.

터미널의 Claude Code는 다른 제품 경로입니다. 그곳에서 /export를 실행하거나 ~/.claude/projects에서 JSONL 기록을 복사하세요. Download Claude conversations는 그 파일을 읽지 않으며 CLI에 들어가지도 않습니다. 터미널 에이전트의 세션을 내보내려고 검색했다면 디스크 경로가 답입니다. 가이드: Claude Code 내보내기.

휴대폰 브라우저의 모바일 claude.ai도 대상이 아닙니다. Download Claude conversations에는 데스크톱 Chrome(또는 Chrome Web Store 항목을 설치할 수 있는 다른 Chromium 브라우저)이 필요합니다. 2026년 현재 저희 팀의 iOS나 Android 앱은 없습니다. 컴퓨터에서 대화를 연 다음 주황색 버튼이나 Export All을 쓰세요.

Team과 Enterprise claude.ai 워크스페이스도 Chrome에서 대화 URL을 씁니다. 워크스페이스 관리자가 확장 프로그램을 막으면 Download Claude conversations가 페이지에 들어가지 못합니다. 이는 형식이 없어서가 아니라 브라우저 정책 때문입니다. 주황색 버튼은 열람이 허용된 대화 URL에서 새로고침한 뒤에만 나타납니다.

이 사이트에서 말하는 ‘Claude 대화 내보내기’란?

Download Claude conversations로 claude.ai 대화를 파일로 저장하는 것입니다. 주황색 버튼, 형식 선택, Export. 영어로 “export Claude conversation”이라고 부르는 것과 같은 작업입니다. Anthropic이 이메일로 보내는 ZIP도, Claude Code의 /export도 아닙니다.

Claude 대화 내보내기는 Export data와 같은 것인가요?

아니요. Settings → Privacy → Export data는 계정 전체를 담은 JSON ZIP을 이메일로 보내 줍니다. 이 확장 프로그램으로 Claude 대화를 내보내면 열어 둔 대화는 PDF, Markdown, JSON, 텍스트, XML, CSV, PNG로, Export All로 선택한 대화는 ZIP으로 Chrome에서 즉시 저장됩니다.

Claude 대화를 PDF로 내보낼 수 있나요?

Claude 대화 내보내기는 Claude Code용인가요?

Claude Desktop에서 Claude 세션을 내보낼 수 있나요?

Claude 대화 내보내기 파일은 무료로 몇 개인가요?

Markdown, 텍스트, JSON, XML, CSV, PNG는 계정 없이 무제한입니다. PDF와 일괄 Export All(모두 내보내기)은 무료 요금제에서 Google 로그인 후 하루 3회를 함께 쓰며, 일괄 ZIP에 담긴 대화 하나가 1회로 계산됩니다. 횟수는 자정(UTC)에 초기화됩니다. Pro는 한도를 없애 주며 Google 로그인으로 복원됩니다.

Claude 대화 내보내기용 주황색 버튼은 어디에 있나요?

Claude 대화를 내보내면 채팅이 업로드되나요?

아니요. PDF를 포함한 모든 형식은 브라우저 안에서 만들어져 Chrome의 다운로드 API로 전달됩니다. Markdown, 텍스트, JSON, XML, CSV, PNG 내보내기는 저희에게 아무것도 보내지 않습니다. PDF, 일괄 내보내기, Pro를 위해 로그인한 뒤에는 저희 워커가 사용 한도나 구독 상태와 Google 이메일을 확인하지만, 대화 본문은 보지 않습니다.

Claude 대화 내보내기는 어떤 형식을 만드나요?
