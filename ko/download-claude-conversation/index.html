Chrome에서 Claude 대화를 어떻게 다운로드하나요?

Markdown이든 PNG든 완성된 파일 하나가 내보내기 1회로 계산됩니다. 무료 계정은 총 3회를 쓸 수 있습니다. Pro는 월 $3.99 또는 연 $26.99이며, 단일 대화와 일괄 “Export All”(모두 내보내기) 모두에서 이 제한을 없애 줍니다. Pro 결제는 Paddle이 처리합니다.

로컬 파일. Markdown, JSON, 텍스트, XML, PNG는 브라우저 안에서 만들어져 Chrome의 다운로드 API로 전달됩니다. 사용 한도 확인은 저희 워커로 가지만, 채팅 텍스트는 가지 않습니다. 이 페이지 기준 버전은 1.13.0(2026년 9월)입니다.

Claude 대화 다운로드와 공식 Export data의 차이는?

주황색 버튼으로 하는 Claude 대화 다운로드는 열어 둔 claude.ai 대화를 이름 붙은 파일 하나로 즉시, 로컬에서 만듭니다. Anthropic의 Settings → Privacy → Export data(claude.ai를 한국어로 설정했다면 메뉴 이름이 한국어로 표시될 수 있습니다)는 나중에 이메일로 오는 계정 단위 JSON ZIP입니다. 인쇄는 웹페이지의 시각적 PDF이고, 복사해 붙여넣기는 구조 없는 텍스트입니다. 목적에 맞는 행을 고르세요.

공식 Export data는 대화별 다운로드가 아니라 Anthropic 계정 전체의 백업입니다. Anthropic이 만료되는 링크를 이메일로 보내 줍니다. ZIP에는 잊고 있던 채팅과 남기고 싶던 채팅이 섞여 있습니다. 수천 개 중 대화 하나가 필요하면 JSON을 직접 풀어야 합니다. 주황색 버튼 방식과는 다릅니다.

인쇄 방법: claude.ai에서 대화를 열고, 가능하면 사이드바를 숨긴 다음, Ctrl+P(Windows/Linux) 또는 Cmd+P(Mac)를 누르세요. 대상을 “PDF로 저장”으로 설정하고 저장합니다. 코드 블록이 페이지 사이에서 잘리는 경우가 많고, 입력창 같은 화면 요소가 매 페이지에 찍힐 수 있습니다. 인쇄는 화면의 스냅샷이지 Markdown이 아닙니다.

복사해 붙여넣기는 확장 프로그램 없이 쓸 수 있는 세 번째 방법입니다. claude.ai에서 텍스트를 선택해 문서나 메모 앱에 붙여넣으면 됩니다. 코드의 들여쓰기는 대개 무너지고, 표는 한 줄로 이어지며, 여러 번 주고받은 대화는 구조 없는 텍스트 덩어리가 됩니다. 짧은 답변 하나에는 괜찮지만, 나중에 검색할 코드 리뷰에는 맞지 않습니다.

Claude 대화를 어떤 형식으로 다운로드할까요?

Claude 대화를 어떤 형식으로 받을지는 주황색 버튼을 열고 Markdown, JSON, 텍스트, XML, PNG 중에서 고른 뒤 Export를 누르면 됩니다. Markdown은 노트용 파일, JSON은 스크립트용 메시지 트리입니다. 일반 텍스트에는 마크업이 없고, XML은 데이터 교환용입니다. PNG는 이미지이며 PDF가 아닙니다.

Markdown은 제목, 언어 태그가 붙은 코드 블록, 표를 유지합니다. Obsidian, GitHub, 위키에 넣을 때 주로 고르는 형식입니다. JSON은 파서가 만든 트리를 그대로 보존하며, 해당 옵션을 켜면 아티팩트와 사고 과정도 포함합니다. Anthropic 계정 ZIP과는 구조가 다릅니다. 형식별 설명: 모든 형식.

일반 텍스트는 어차피 마크업이 제거되는 곳에 넣을 때 알맞습니다. 티켓 입력란, 이메일 본문, 순수 문자열이 필요한 검색 색인 같은 경우입니다. XML은 특수한 데이터 교환용입니다. PNG는 슬라이드나 버그 리포트에 넣을 대화 스크린샷용이며, 나중에 grep으로 검색할 40턴짜리 설계 리뷰에는 맞지 않습니다.

버전 1.13.0에는 자체 PDF 형식이 없습니다. 고객에게 PDF를 보내야 한다면 Markdown으로 내보낸 뒤 Word, Google Docs, VS Code, Obsidian에서 그 파일을 인쇄하세요. 또는 claude.ai 화면을 직접 인쇄하세요. Download Claude conversations에 없는 .pdf 옵션을 기다리지 마세요.

마지막으로 사용한 형식이 기억됩니다. Markdown을 원했는데 JSON을 받았다면, 드롭다운이 이전 내보내기의 JSON으로 남아 있었던 것입니다. 작업이 바뀔 때마다 드롭다운을 확인하세요. 형식을 섞어 쓴다고 한도가 늘지는 않습니다. 완성된 파일 하나하나가 무료 3회 중 1회로 계산됩니다.

PNG는 PDF가 아닙니다. Download Claude conversations가 만드는 PNG는 대화의 이미지입니다. Chrome 인쇄 대화상자에서 만든 PDF는 claude.ai를 페이지로 나눈 스냅샷입니다. 둘 다 검색 가능한 Markdown 아카이브가 아닙니다. ‘다운로드’라는 단어가 아니라 다음에 쓸 앱에 맞는 형식을 고르세요.

목록 페이지에는 로그인한 claude.ai 계정의 대화가 표시됩니다. 이름으로 검색하고, All(전체), New(아직 내보내지 않음), Exported(내보냄)로 필터링할 수 있으며, claude.ai에서 프로젝트로 채팅을 묶어 두었다면 Project로도 필터링할 수 있습니다. 오래된 초안까지 전부 폴더에 넣고 싶지 않다면 일부만 선택하세요.

일괄 내보내기는 단일 대화 내보내기와 같은 다섯 가지 형식과 같은 옵션(사고 과정, 메타데이터, 발신자 필터, 아티팩트 배치)을 씁니다. Export All은 기능이 줄어든 별도 처리 방식이 아닙니다. 같은 파서를 여러 대화 ID에 한 번에 적용할 뿐입니다. 자세한 내용: 일괄 Export All.

Anthropic의 Export data는 여전히 계정 백업 수단입니다. ZIP 하나, 이메일 한 통, 잊고 있던 채팅까지 모두 JSON으로 담깁니다. 일괄 Export All은 반대 방향의 작업입니다. 어떤 대화를 받을지, Markdown으로 받을지 JSON으로 받을지 직접 고르고, 파일은 즉시 저장됩니다. 공식 보관용 아카이브와 읽기 쉬운 노트 폴더가 모두 필요하다면 둘 다 쓰세요.

사용 한도는 공유됩니다. 무료 내보내기 3회는 단일 대화와 일괄 파일을 합쳐서 계산합니다. 무료 계정에서 대화 40개를 선택하면 세 번째 파일 이후 멈춥니다. 선택을 미리 계획하거나 Paddle을 통해 월 $3.99 또는 연 $26.99의 Pro로 업그레이드하세요.

목록 표는 이미 내보낸 항목도 기억하므로, 다음에 방문했을 때 New만 골라 볼 수 있습니다. 그래서 매주 Claude 대화를 다운로드하는 습관도 지난달 Markdown을 중복하지 않고 새 항목만 추가하는 방식으로 이어갈 수 있습니다. 전체 기록이라도 이 확장 프로그램에서는 ZIP 하나가 아니라 여러 파일입니다.

첫 번째 주황색 버튼 파일과 마찬가지로, 첫 번째 일괄 파일 전에도 Google 로그인이 필요합니다. Download Claude conversations는 3회 한도를 적용하고 Pro를 복원하기 위해 인증된 이메일을 저장합니다. Export All이 디스크에 파일을 쓰는 동안 채팅 본문은 브라우저에 머뭅니다.

Claude 대화 다운로드 버튼이 사라진 이유는?

대화 URL이 아닌 곳에 있거나, 설치 후 탭을 새로고침하지 않았거나, 확장 프로그램이 꺼져 있으면 Claude 대화 다운로드 버튼이 보이지 않습니다. 아이콘을 고정하고 새로고침한 다음, Desktop 앱이나 휴대폰, Claude Code가 아니라 데스크톱 Chrome의 claude.ai에 있는지 확인하세요.

설치 후 Chrome이 이미 열려 있던 탭에 콘텐츠 스크립트를 항상 넣어 주지는 않습니다. claude.ai 탭을 닫거나 강력 새로고침하세요. 여러 프로필을 쓴다면 Anthropic에 로그인된 프로필에 Download Claude conversations를 설치해야 합니다.

Team과 Enterprise 워크스페이스도 브라우저에서 대화를 열 수 있다면 작동합니다. 확장 프로그램은 요금제가 아니라 페이지를 읽습니다. 조직에서 Chrome 확장 프로그램을 막아 두었다면 IT 부서가 이 확장 프로그램을 허용해야 하며, 저희가 chat-downloader.com에서 그 정책을 우회할 수는 없습니다.

로그인 요청: 정상입니다. 처음 Export를 누르면 Google 로그인을 요청합니다. 이 창을 닫으면 다운로드가 실패한 것처럼 보입니다. 로그인을 마친 뒤 Export를 다시 누르세요. 무료 내보내기 3회에는 신용카드가 필요 없습니다. Paddle은 Pro를 구매할 때만 나타납니다.

파일이 불완전함: 대화 응답이 아직 끝나지 않았거나, 이전 메시지가 화면 밖에서 아직 렌더링되지 않은 상태였습니다. 어시스턴트의 응답이 끝날 때까지 기다리세요. 긴 대화라면 처음 쪽으로 스크롤해 claude.ai가 해당 부분을 불러오게 한 다음 다시 내보내세요. 무료 플랜에서는 한도가 한 번 더 차감되므로 먼저 대화가 모두 불러와졌는지 확인하세요.

파일 형식이 다름: 마지막으로 쓴 형식이 그대로 선택되어 있었습니다. 계정이 다름: Pro가 연결된 주소와 다른 Google 주소로 로그인했습니다. Pro 복원은 Anthropic 로그인이나 Chrome 프로필 이름이 아니라 그 Google 이메일에 연결됩니다.

모바일 브라우저에서는 이 확장 프로그램이 실행되지 않습니다. iOS나 Android 앱도 없습니다. 휴대폰의 Safari로 claude.ai를 인쇄할 수는 있지만 주황색 버튼은 표시되지 않습니다. 다시 쓸 수 있는 파일이 필요하면 같은 대화를 데스크톱 Chrome에서 열고 그곳에서 다운로드하세요.

Desktop 앱에서 Claude 대화를 다운로드할 수 있나요?

아니요. Claude Desktop에서는 이 확장 프로그램으로 Claude 대화를 다운로드할 수 없습니다. Download Claude conversations는 Chrome의 claude.ai에만 들어갑니다. Claude Code는 터미널에서 쓰는 다른 제품입니다. 같은 대화가 claude.ai에 있다면 그곳에서 열고 주황색 버튼을 쓰세요.

Claude Desktop은 별도의 창입니다. Chrome 콘텐츠 스크립트는 그 앱 안에 들어가지 않습니다. 같은 채팅이 claude.ai에도 있다면 그곳에서 열고 다운로드하세요. Desktop에만 있다면 복사해 붙여넣거나 Settings → Privacy → Export data의 계정 ZIP을 기다리세요.

Claude Code는 터미널에서 동작합니다. 진행 중인 세션 안에서 /export를 입력하세요. Anthropic의 CLI가 대화 기록을 복사하거나 일반 텍스트 파일로 저장하는 메뉴를 엽니다. 파일 이름을 함께 입력하면 메뉴를 건너뜁니다. 이 기록은 사람이 읽기 위한 텍스트이며, 이 확장 프로그램의 Markdown, JSON, PNG와는 다릅니다. 경로: Claude Code 내보내기.

디스크의 JSONL은 내부 로그입니다. 스키마는 Claude Code 버전마다 바뀔 수 있습니다. Anthropic 공식 문서도 JSONL을 직접 파싱하기보다 /export나 스크립트 인터페이스를 쓰라고 안내합니다. 저희는 그 CLI를 감싸지 않으며, ~/.claude를 읽지도 않습니다. Windows 경로: %USERPROFILE%\.claude\projects.

FAQ: Claude 대화 다운로드

이 FAQ는 claude.ai에서 Claude 대화를 다운로드하는 방법, 복수형 스토어 이름, 대화당 파일 하나, 형식, 사용 한도, Google 로그인, Desktop, Claude Code를 다룹니다. Download Claude conversations는 Markdown, JSON, 텍스트, XML, PNG를 로컬에서 만듭니다. 파일 3개까지 무료이고, Pro는 Paddle을 통해 월 $3.99 또는 연 $26.99입니다.

claude.ai에서 Claude 대화를 어떻게 다운로드하나요?

Download Claude conversations를 설치하고, claude.ai에서 대화를 연 다음, 메시지 입력창 옆의 주황색 버튼을 누르세요. Markdown, JSON, 텍스트, XML, PNG 중 하나를 고르고 Export(내보내기)를 누르면 Chrome이 로컬 파일 하나를 저장합니다. 그 파일 하나가 대화 하나입니다. 무료 내보내기 3회를 계산하기 위해 첫 내보내기 전에 Google 로그인이 필요합니다.

‘Claude 대화 다운로드’가 스토어에 등록된 이름인가요?

스토어에 등록된 이름은 복수형인 Download Claude conversations입니다. Export All로 여러 파일을 만들 수 있기 때문입니다. ‘Claude 대화 다운로드’, ‘클로드 대화 다운로드’, 영어의 “download claude conversation” 같은 검색어는 모두 같은 등록 페이지를 가리킵니다. 주황색 버튼으로 한 번 내보내면 여전히 대화 하나, 파일 하나입니다.

확장 프로그램 없이 Claude 대화를 다운로드할 수 있나요?

네. 화면 그대로의 스냅샷이 필요하면 claude.ai 페이지를 인쇄(Ctrl/Cmd+P → PDF로 저장)하고, 계정 전체 JSON ZIP이 필요하면 Settings → Privacy → Export data를 사용하세요(ZIP은 나중에 도착합니다). 짧은 답변이라면 복사해 붙여넣기도 됩니다. 다만 이 방법들은 Chrome 확장 프로그램처럼 대화별로 구조화된 Markdown 파일을 만들어 주지 않습니다.

Claude 대화 다운로드 한 번이 파일 하나인가요?

네. 주황색 버튼은 열어 둔 claude.ai 대화 하나당 파일 하나를 만듭니다. Export All은 선택한 행마다 파일을 하나씩 만듭니다. Anthropic의 Export data ZIP은 정반대입니다. 계정 전체를 담은 아카이브 하나를 나중에 이메일로 보내 주며, 읽고 있던 대화의 이름이 붙은 파일이 아닙니다.

Claude 대화를 PDF로 다운로드할 수 있나요?

아니요. 버전 1.13.0은 Markdown, JSON, 일반 텍스트, XML, PNG만 만듭니다. PDF 내보내기는 없습니다. claude.ai 탭을 인쇄하거나, Markdown 파일을 다른 앱에서 변환하세요. PNG는 대화의 이미지이며 PDF가 아닙니다.

Claude 대화를 다운로드하려면 Google 로그인이 필요한가요?

네, 처음 Export를 누를 때부터 필요합니다. Google이 선택한 계정을 확인해 주기 때문에 3회 내보내기 한도를 적용하고, 재설치 후에도 Pro를 복원할 수 있습니다. 이 로그인과 함께 대화 내용이 전송되지는 않습니다. 인증된 이메일은 사용 한도와 Pro 상태 확인용으로만 저장합니다.

Claude Desktop에서도 대화를 다운로드할 수 있나요?

아니요. Download Claude conversations는 데스크톱 Chrome의 claude.ai에만 들어갑니다. Claude Desktop에는 주황색 버튼이 나타나지 않습니다. 동기화된다면 같은 대화를 claude.ai에서 여세요. 아니면 복사해 붙여넣거나 공식 Export data를 쓰세요. iOS나 Android 앱은 없습니다.

Claude 대화를 무료로 몇 개까지 다운로드할 수 있나요?

Google로 로그인한 모든 계정에 다섯 가지 형식 어디에나 쓸 수 있는 무료 내보내기 3회가 제공됩니다. 그 이후 Pro는 월 $3.99 또는 연 $26.99입니다. 결제는 Paddle이 처리합니다. 일괄 Export All 파일도 같은 3회에서 차감됩니다. 재설치해도 횟수는 초기화되지 않습니다.

Claude Code의 대화도 다운로드되나요?

아니요. Claude Code는 터미널에서 동작합니다. /export를 쓰거나 ~/.claude/projects(Windows: %USERPROFILE%\.claude\projects)에서 JSONL을 복사하세요. 이 Chrome 확장 프로그램은 claude.ai에서만 실행됩니다. 가이드: Claude Code 내보내기.

Claude 대화는 어떤 형식으로 다운로드되나요?

Markdown, JSON, 일반 텍스트, XML, PNG입니다. 확장 프로그램 1.13.0에는 PDF 내보내기가 없습니다. PDF가 필요하면 claude.ai를 인쇄하거나 Markdown 파일을 다른 앱에서 변환하세요. PNG는 대화의 이미지이며 PDF가 아닙니다. 형식 안내: 형식.
