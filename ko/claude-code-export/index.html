터미널의 Claude Code 내보내기란 무엇인가요?

Claude Code 내보내기는 대화형 CLI 세션 안에서 쓰는 /export 명령입니다. Anthropic 문서에 따르면 현재 대화를 복사하거나 일반 텍스트 파일로 저장하는 메뉴가 나타나며, 메시지와 도구 출력이 읽기 쉬운 텍스트로 렌더링됩니다. 파일 이름을 함께 입력하면 메뉴를 건너뛰고 바로 그 파일에 저장합니다.

이것은 claude.ai의 Markdown도, 이 Chrome 확장 프로그램의 JSON도, PDF도 아닙니다. 사람이 읽도록 렌더링한 대화 기록입니다. Anthropic은 디스크의 JSONL 로그가 이와 다른 내부 형식이며, 공개 API가 아니라 제품 내부용이라고 설명합니다.

/export

프롬프트를 건너뛰고 현재 작업 디렉터리에 이름을 지정한 파일로 저장하려면:

/export my-session

플래그와 파일 이름은 Anthropic의 세션 문서가 기준이며, Claude Code 버전마다 달라집니다. 커뮤니티 블로그는 참고용으로만 보십시오. /export 대화 상자의 문구가 화면과 다르다면 사용 중인 CLI 빌드가 다른 것입니다. 2025년 스크린샷이 아니라 제품 내 도움말을 확인하십시오.

스크립트용으로 Anthropic은 다른 인터페이스를 안내합니다: --output-format json 또는 stream-json을 붙인 claude -p, 세션 ID로 재개, transcript_path를 받는 훅, Agent SDK. 이들은 Claude Code의 개발자용 기능이며, 이 웹사이트의 Chrome 확장 프로그램과는 관계가 없습니다.

읽기용 vs 구조화 데이터. /export는 사람이 읽는 기록입니다. projects 폴더의 JSONL은 로그입니다. Chrome 확장 프로그램의 JSON은 claude.ai 페이지로만 만드는 세 번째 형태입니다. 세 가지를 하나의 파서로 처리하려 하지 마십시오.

디스크에서 Claude Code 대화를 가져오려면?

디스크에서 Claude Code 대화를 가져오려면 projects 디렉터리에서 해당 세션의 JSONL 파일을 복사하거나, 읽기 쉬운 기록이 필요하면 /export를 실행하십시오. macOS와 Linux의 기본 경로는 ~/.claude/projects/ 아래입니다. Windows에서는 %USERPROFILE%\.claude\projects입니다. 파일 이름은 세션 ID입니다.

프로젝트 폴더 이름은 작업 디렉터리 경로에서 영숫자가 아닌 문자를 하이픈으로 바꾼 것입니다. 변환한 이름이 너무 길면 Anthropic이 잘라 내고 해시를 붙여 파일 시스템 한도 안에 맞춥니다. 폴더를 찾을 수 없다면 생각과 다른 작업 디렉터리(cwd)에서 Claude Code를 실행한 것입니다.

JSONL의 각 줄은 메시지, 도구 사용, 메타데이터 중 하나를 담은 JSON 객체입니다. Anthropic은 이 항목 형식이 내부용이며 버전마다 바뀐다고 밝힙니다. 이 파일을 파싱하는 스크립트는 Claude Code 업데이트 후 깨질 수 있습니다. 안정성이 필요하면 /export나 문서화된 스크립트 인터페이스를 쓰십시오.

저장 위치는 바뀔 수 있습니다. CLAUDE_CONFIG_DIR은 설정 트리를 ~/.claude 밖으로 옮깁니다. CLAUDE_CODE_PROJECT_DIR_NAME은 그 설정 디렉터리와 함께 쓸 때 프로젝트 디렉터리 이름을 지정합니다(Anthropic에 따르면 Claude Code v2.1.234 이상). settings.json의 cleanupPeriodDays는 기본 보존 기간을 바꿉니다. 이 설정들은 모두 Download Claude conversations의 기능이 아닙니다.

따라서 백업용으로 Claude Code 대화 파일을 받는 방법은 폴더를 복사하거나, 정기적으로 /export로 기록을 내보내는 것입니다. 이 사이트에 "JSONL 가져오기" 버튼이 추가될 일은 없습니다. 저희는 사용자의 홈 디렉터리를 읽지 않습니다.

Claude Code 내보내기가 이 확장 프로그램으로 되나요?

아니요. Claude Code 내보내기는 Download Claude conversations로 할 수 없습니다. 이 Chrome 확장 프로그램은 claude.ai 페이지에 삽입되어 작동합니다. 터미널을 볼 수 없고, /export를 실행할 수 없으며, JSONL을 열 수 없습니다. Claude Code 대화를 다운로드하는 방법을 찾고 있었다면 이 페이지의 CLI 단계를 따르십시오.

검색 결과에서 "Claude"와 "내보내기"가 함께 묶이기 때문에 이 페이지에 오시는 분이 많습니다. 하지만 Web Store 등록 정보대로 이 확장 프로그램은 claude.ai 전용입니다. 설치해도 iTerm, Ghostty, VS Code 터미널, Claude Code의 데스크톱 래퍼에 주황색 버튼이 생기지 않습니다.

같은 코딩 작업을 claude.ai에서도 별도 스레드로 진행하고 있다면, 그 브라우저 채팅은 확장 프로그램으로 저장할 수 있습니다. 두 기록은 합쳐지지 않습니다. CLI에서만 일어난 도구 호출은 직접 붙여 넣지 않는 한 웹 내보내기에 나타나지 않습니다.

매주 같은 문의 메일을 받습니다. Chrome 확장 프로그램을 설치했더니 /export가 나타날 줄 알았다는 내용입니다. 저희는 claude.ai만 파싱합니다. Claude Code에는 이미 /export와 JSONL이 있습니다. CLI를 감싸는 기능은 전혀 다른 제품이 될 것이며, 저희는 그런 제품을 출시하지 않았습니다.

Claude Code는 대화 기록을 어디에 저장하나요?

Claude Code는 대화 기록을 설정 디렉터리의 projects 폴더 아래에 JSONL 기록으로 저장합니다. macOS와 Linux의 기본값: ~/.claude/projects/<encoded-cwd>/<session-id>.jsonl. Windows는 %USERPROFILE%\.claude\projects를 씁니다. Anthropic이 이 구조를 바꿀 수 있으니, 디스크에서 경로가 보이지 않으면 최신 세션 문서를 확인하십시오.

재개(resume)와 내보내기는 다른 동작입니다. claude --continue와 claude --resume은 세션을 다시 불러와 작업을 이어 가게 합니다. /export는 git에 남기거나 이메일로 보낼 수 있는 사본을 만듭니다. 하나는 맥락을 복원하고, 다른 하나는 기록을 가져갑니다. 재개 시 권한 모드, compact/요약, 선택기 동작은 Anthropic의 세션 페이지에서 다루며, 모두 이 확장 프로그램과는 무관합니다.

Anthropic에 따르면 데스크톱 앱, 웹의 Claude Code, VS Code 확장 프로그램은 각각 별도의 세션 기록을 관리합니다. 이 가이드의 경로는 CLI 기준입니다. Desktop Cowork 기록이 터미널에서 쓰는 JSONL 트리에 함께 있다고 가정하지 마십시오.

JSONL을 공개 스키마로 취급하지 마십시오. Anthropic은 줄 형식이 바뀐다고 밝힙니다. 그래도 파싱한다면 Claude Code 버전을 고정하고 깨질 수 있음을 감안하십시오. 사람이 읽을 수 있는 Claude Code 대화를 얻는 안정적인 방법은 /export입니다.

CLAUDE_CODE_SKIP_PROMPT_HISTORY 같은 환경 플래그는 기록 저장을 막을 수 있습니다. projects 폴더가 비어 있다면 저장을 비활성화했는지, CLAUDE_CONFIG_DIR을 다른 곳으로 지정했는지, 그 디렉터리에서 대화형 세션을 한 번도 실행하지 않았는지 확인하십시오.

대신 claude.ai에서 Claude 채팅을 다운로드하려면?

claude.ai에서 Claude 채팅을 다운로드하는 방법: Download Claude conversations를 설치하고, Chrome에서 스레드를 연 뒤 주황색 버튼을 눌러 Markdown, JSON, 텍스트, XML, PNG 중 하나를 고릅니다. 이것이 브라우저용 제품이며 Claude Code 내보내기가 아닙니다. 단계별 안내: Claude 채팅 다운로드 방법.

claude.ai 기록 전체를 개별 파일로 받으려면 /export가 아니라 목록 페이지의 "Export All"(모두 내보내기)을 씁니다. Pro가 아니라면 파일 하나하나가 무료 내보내기 3회에 포함됩니다. 가이드: 일괄 Export All. 형식: 형식.

claude.ai에서 처음 내보낼 때는 사용량을 집계하고 Pro를 복원하기 위해 Google 로그인이 필요합니다. 파일은 로컬에서 만들어집니다. Pro 결제는 Paddle이 처리하며 월 $3.99 또는 연 $26.99입니다. 이 중 어느 것도 터미널의 /export에는 적용되지 않습니다.

Claude Code에서 시작한 작업의 요약을 claude.ai에 붙여 넣었다면, 메모용으로는 웹 스레드를 다운로드하고 실제 CLI 로그는 /export로 보관하십시오. 뒤섞인 파일 하나보다 명확한 파일 두 개가 낫습니다.

Claude Code 내보내기 vs Anthropic 공식 Export data?

Claude Code 내보내기(/export 또는 JSONL)는 터미널 세션 하나를 대상으로 합니다. 공식 Export data는 claude.ai의 Settings → Privacy → Export data(claude.ai를 한국어로 설정했다면 메뉴 이름이 번역되어 보일 수 있습니다)로, 시간이 걸려 도착하는 Anthropic 계정 전체의 JSON ZIP입니다. 둘은 같은 아카이브가 아닙니다. ZIP이 /export를 대신하지 않습니다.

특정 Claude Code 세션이 계정 ZIP에 들어가는지는 Anthropic이 해당 제품의 데이터를 어떻게 저장하느냐에 달려 있으며, 이 확장 프로그램과는 무관합니다. Anthropic의 최신 개인정보 문서에 다른 설명이 없는 한 ZIP은 웹 계정 백업으로 보십시오. 저희는 그 ZIP에 CLI 세션을 추가하지 않습니다.

웹사이트에서 Claude 채팅을 내보내는 방법(ZIP과 확장 프로그램의 차이 포함)은 여기에 정리되어 있습니다: Claude 채팅 내보내기 방법. 웹 페이지를 PDF로 인쇄하는 방법은 터미널 UI에는 적용되지 않습니다. 대화가 브라우저에 있을 때만 인쇄 / PDF를 참고하십시오.

Claude Code vs Desktop vs claude.ai 내보내기?

Claude Code, Claude Desktop, claude.ai는 서로 다른 세 가지 환경입니다. Claude Code 내보내기는 /export와 JSONL을 씁니다. Desktop은 이 확장 프로그램의 주황색 버튼이 없는 앱입니다. Download Claude conversations가 실행되는 곳은 Chrome의 claude.ai뿐입니다. 이름을 혼동하면 내보내기가 소리 없이 실패합니다.

Claude Desktop: 채팅이 같은 Anthropic 계정에 동기화되었다면 claude.ai에서 열어 내보내십시오. Desktop 창에만 있다면 복사해 붙여 넣거나 공식 Export data를 기다리십시오. 가이드: Claude Desktop 채팅 내보내기.

VS Code의 Claude Code 패널은 claude.ai보다 CLI에 가깝습니다. 저희 콘텐츠 스크립트가 그 웹뷰에 삽입될 것이라고 기대하지 마십시오. 실제 메시지가 있는 세션에서 /export를 사용하십시오.

Anthropic, PBC와 제휴하지 않은 독립 Chrome 확장 프로그램입니다. Claude는 Anthropic의 상표입니다. Anthropic의 서비스 약관을 따르십시오. 독점 코드가 포함된 도구 출력을 복사하는 것에 대해서는 법률 자문을 드릴 수 없습니다. 이는 사용자, 고용주, Anthropic 사이의 문제입니다.

FAQ: Claude Code 대화 내보내기

Claude Code 대화는 어떻게 내보내나요?

Claude Code 터미널에서 /export(파일 이름은 선택)를 입력하면 읽기 쉬운 대화 기록이 저장됩니다. 또는 macOS/Linux에서는 ~/.claude/projects, Windows에서는 %USERPROFILE%\.claude\projects에서 JSONL 파일을 복사합니다. 현재 대화 상자는 Anthropic의 세션 문서에 설명되어 있습니다.

이 Chrome 확장 프로그램으로 Claude Code 채팅을 다운로드할 수 있나요?

아니요. Download Claude conversations는 Chrome의 claude.ai에서만 작동합니다. 터미널 세션, JSONL 기록, /export 명령은 읽을 수 없습니다. Claude Code 내보내기는 CLI에서 합니다.

Claude Code는 대화 기록을 어디에 저장하나요?

세션 기록은 ~/.claude/projects/<encoded-working-directory>/ 아래에 세션 ID를 이름으로 한 JSONL 파일로 저장됩니다. 정확한 구조는 바뀔 수 있습니다. JSONL을 파싱하는 대신 읽기 쉬운 파일이 필요하면 /export를 쓰십시오. CLAUDE_CONFIG_DIR로 이 폴더 트리를 옮길 수 있습니다.

Claude Code 대화를 Markdown으로 다운로드하려면 어떻게 하나요?

Claude Code의 /export는 일반 텍스트 기록이며, 이 확장 프로그램의 Markdown과는 다릅니다. 꼭 Markdown이 필요하다면 같은 작업의 claude.ai 사본을 Download Claude conversations로 내보내거나 /export 텍스트를 직접 변환하십시오. 저희는 JSONL을 Markdown으로 변환하지 않습니다.

대신 claude.ai 대화를 다운로드하려면 어떻게 하나요?

무료 Chrome 확장 프로그램을 설치하고 claude.ai에서 채팅을 연 뒤 주황색 버튼을 누르십시오. 기록 전체는 "Export All"(모두 내보내기)을 씁니다. Claude 채팅 다운로드 방법을 참고하십시오. 무료 내보내기 3회, Pro는 월 $3.99 또는 연 $26.99입니다.

/export는 공식 Export data와 같은 것인가요?

아니요. /export는 현재 Claude Code 세션만 대상으로 합니다. Settings → Privacy → Export data는 Anthropic 계정 전체를 JSON ZIP으로 이메일 발송합니다. 제품 영역도, 파일도, 대기 시간도 다릅니다.

Claude Code JSONL을 jq로 파싱할 수 있나요?

가능합니다. 다만 Anthropic이 밝힌 대로 줄 단위 스키마는 내부용이며 바뀔 수 있습니다. 안정적인 형식이 필요하면 /export나 claude -p --output-format json을 쓰십시오. 그래도 JSONL을 파싱한다면 CLI 버전을 고정하십시오.

Claude Code 내보내기는 Windows에서도 되나요?

네. /export는 CLI 명령입니다. CLAUDE_CONFIG_DIR을 설정하지 않았다면 디스크의 기록은 %USERPROFILE%\.claude\projects 아래에 있습니다. 이 Chrome 확장 프로그램은 여전히 그 터미널 안에서는 실행되지 않습니다.

Claude Code와 Claude Desktop은 같은 것인가요?

아니요. Claude Code는 터미널 코딩 에이전트, Claude Desktop은 채팅 앱, claude.ai는 웹사이트입니다. 이 확장 프로그램은 웹사이트에서만 작동합니다. Desktop 내보내기 안내: Claude Desktop.

이 확장 프로그램이 앞으로 /export를 지원하나요?

버전 1.13.0에서는 지원하지 않습니다. 제품 범위는 claude.ai입니다: 5가지 형식, 로컬 파일, 사용량 확인을 위한 Google 로그인. 범위가 바뀌면 이 페이지에 안내합니다. 그전까지 Claude Code 내보내기는 Anthropic의 CLI를 쓰십시오.

/export에 도구 출력도 포함되나요?

Anthropic은 /export를 메시지와 도구 출력을 읽기 쉬운 텍스트로 렌더링한 것이라고 설명합니다. 이는 Anthropic의 기록 형식이지 저희 파서가 아닙니다. 정확한 현재 내용은 사용 중인 빌드에서 /export를 실행해 파일을 직접 확인하십시오. 문서는 릴리스보다 늦게 갱신될 수 있습니다.

Claude Code 세션을 일괄 내보내기할 수 있나요?

이 확장 프로그램의 "Export All"로는 안 됩니다. 목록 페이지의 일괄 내보내기는 claude.ai 전용입니다. CLI 세션이 많다면 projects 폴더를 복사하거나 세션마다 /export를 실행하십시오. JSONL을 주황색 버튼으로 일괄 내보내는 기능은 없습니다.
