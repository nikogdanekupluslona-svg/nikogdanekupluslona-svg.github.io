Export All 전에 Claude 채팅을 필터링하려면?

검색은 이름으로 대화를 찾습니다. 필터는 "All"(전체), "New"(새 항목), "Exported"(내보냄), "Project"(프로젝트)입니다. Claude 채팅을 통째로 다운로드하기 전에 필터를 쓰면 이미 가진 파일에 사용량을 낭비하지 않습니다. New는 이 확장 프로그램으로 아직 내보내지 않은 채팅이고, Exported는 이미 저장한 채팅입니다.

Project는 claude.ai에서 스레드를 묶는 방식과 같습니다. 일반적인 일괄 작업은 "계정을 만든 뒤의 모든 것"이 아니라 "이 프로젝트"나 "New만"입니다. 행을 선택한 뒤 Export All을 한 번 실행하십시오. 수십 개의 URL에서 주황색 버튼을 반복해 누르는 느린 방법을 대신하려고 이 목록 표를 만들었습니다.

일괄 Export All 파일에는 무엇이 들어가나요?

일괄 내보내기는 채팅 하나를 저장할 때와 같은 옵션을 씁니다: 채팅, 사고 과정, 메타데이터, 아티팩트 레이아웃("Original"(원본), "Inline"(인라인), "Nested"(중첩), "Flat"(평면)). Claude 채팅을 통째로 내보낸다고 품질이 떨어지는 ZIP이 되지는 않습니다. 각 파일에 코드 블록, 표, 선택적 추론을 유지할 수 있습니다. 발신자 필터로 "all / human only / assistant only"(전체 / 사용자만 / 어시스턴트만)를 고를 수 있습니다.

사고 과정(Thinking)은 페이지에 표시된 경우 Claude의 확장 추론입니다. 메타데이터에는 제목, 타임스탬프, 모델이 들어갈 수 있습니다. 아티팩트 레이아웃은 Markdown, JSON, XML에서 아티팩트를 어떻게 배치할지 정합니다. PNG는 여전히 스레드의 그림입니다. 어떤 옵션으로도 PDF는 추가되지 않습니다. 인쇄는 별도의 브라우저 동작입니다: 인쇄 / PDF.

Export All은 모든 파일을 채팅 하나를 저장할 때와 같은 무료 내보내기 3회에서 차감합니다. 월 $3.99 또는 연 $26.99의 Pro는 두 방법에 똑같이 적용되는 라이선스입니다. 일괄 내보내기는 다른 제품이 아니라 단일 내보내기를 대량으로 적용한 것입니다.

일괄 Export All은 무료 내보내기를 몇 회 쓰나요?

완성된 파일 하나가 내보내기 1회이며, 주황색 버튼과 같습니다. 모든 계정은 단일·일괄을 합쳐 무료 내보내기 총 3회를 받습니다. 일괄 전용 한도는 따로 없습니다. Pro(월 $3.99 또는 연 $26.99)는 두 방법의 제한을 모두 없앱니다. Pro 결제는 Paddle이 처리하며, 저희는 카드 정보를 보지 않습니다.

Chrome을 다시 설치해도 3회 횟수는 초기화되지 않습니다. 그래서 처음 Claude 채팅 파일을 다운로드할 때 Google 로그인이 필요합니다. 새 컴퓨터에서도 같은 Google 계정으로 Pro가 복원됩니다. 세션에서 대화 목록을 볼 수 있다면 claude.ai Free, Pro, Team, Enterprise 모두 작동합니다. Anthropic의 요금제는 저희 사용량과 무관합니다.

선택을 미리 계획하십시오. New 채팅 3개를 Markdown으로 내보내는 것은 무료로 가능한 일괄 Export All입니다. 30개는 Pro가 필요합니다. 형식을 섞어도 사용량이 배로 늘지는 않지만, 완성된 PNG나 JSON은 각각 1회로 계산됩니다. 업그레이드 후 마음이 바뀌면 환불 페이지 안내대로 Paddle을 통해 환불받을 수 있습니다.

일괄 Export All vs Claude 채팅 백업 ZIP?

Claude 채팅 백업이라고 하면 보통 Anthropic의 Settings → Privacy → Export data를 말합니다. 계정 전체를 담아 시간이 걸려 도착하는 JSON ZIP 하나입니다. 일괄 Export All은 직접 고른 채팅을 Markdown, JSON, 텍스트, XML, PNG 파일로 즉시 만듭니다. 계정 백업에는 ZIP을, 문서가 필요하면 이 페이지의 방법을 쓰십시오.

일괄 Export All은 Desktop이나 Code에서 되나요?

아니요. 이 확장 프로그램으로 Claude 채팅 전체를 다운로드하려면 Chrome의 claude.ai가 필요합니다. Claude Desktop에는 "View and Download All Conversations"가 나타나지 않습니다. Claude Code는 /export나 디스크의 JSONL을 씁니다. 확장 프로그램을 설치해도 이 제품들에 일괄 Export All이 추가되지 않습니다.

Desktop 스레드가 같은 계정에 동기화되었다면 claude.ai에 나타나는 순간 목록 표에도 보입니다. 동기화된 적이 없다면 일괄 내보내기로 볼 수 없습니다. Desktop 우회 방법: Claude Desktop 채팅 내보내기. 터미널 세션: Claude Code 내보내기. 저장소의 JSONL을 기대하고 Export All을 실행하지 마십시오.

모바일 Chrome도 지원하지 않습니다. 목록 페이지는 데스크톱 확장 프로그램 UI입니다. 2026년 현재 저희 팀의 iOS용 일괄 다운로더는 없습니다. 컴퓨터에서 claude.ai를 여십시오. 확장 프로그램을 차단하는 팀 정책이 있다면 일괄 Export All도 막힙니다.

일괄 Export All에는 어떤 형식이 좋을까요?

Export All 한 번에는 형식 하나를 고릅니다. 노트 보관함에는 Markdown, 파이프라인에는 JSON, 마크업 없는 보관에는 일반 텍스트, 데이터 교환에는 XML, 이미지에는 PNG. Claude 채팅 전체 다운로드도 주황색 버튼과 같은 5가지 형식을 씁니다. 허브: 형식. 1.13.0에는 PDF가 없습니다.

글을 쓰는 분들은 보통 Markdown으로 일괄 내보냅니다 — Markdown 가이드. 개발자는 보통 JSON을 씁니다 — JSON 가이드. XML: XML. PNG: PNG. Export All의 JSON도 페이지에서 만든 채팅별 파일이며, Anthropic 계정 ZIP의 구조가 아닙니다. 두 스키마를 한 스크립트에서 섞지 마십시오.

형식을 바꿔도 가격은 같습니다. PNG로 일괄 내보내도 이미지마다 1회를 씁니다. 두 번째로 Markdown 대신 JSON으로 실행하면 채팅마다 1회가 추가로 차감됩니다. Exported 필터로 중복을 피하십시오. 같은 파일을 "추출" 관점에서 설명한 페이지: Claude 대화 추출기. 제품 관점의 단일 내보내기: Claude 채팅 내보내기.

다른 내보내기 도구의 이름은 언급하지 않습니다. Anthropic의 공식 Export data는 백업 ZIP과의 비교를 위해 이름을 밝혔습니다. Download Claude conversations(Claude Chat Downloader / Claude Conversation Downloader라고도 부름)가 Chrome에서의 일괄 내보내기 방법입니다. Anthropic, PBC와 제휴하지 않은 독립 확장 프로그램입니다. Chrome Web Store 평점 5.0.

Export All이 멈추면 claude.ai에 대한 Chrome 다운로드 권한을 확인하고, 3회 제한을 통과했는지 또는 Pro인지 확인한 뒤 New만 다시 시도하십시오. 표가 비어 있다면 로그아웃되었거나 콘텐츠 스크립트가 읽을 수 있는 claude.ai 세션이 아닌 것입니다. claude.ai를 새로 고친 뒤 "View and Download All Conversations"를 다시 여십시오.

일괄 내보내기는 한 개씩 내보낼 때보다 더 많이 차감되나요?

아니요. 같은 기준입니다: 주황색 버튼과 Export All을 합쳐 무료 내보내기는 총 3회입니다. Pro는 두 방법 모두 월 $3.99 또는 연 $26.99입니다. 일괄 내보내기 파일 하나는 채팅 하나를 저장할 때와 똑같이 1회로 계산됩니다.

프로젝트 하나의 Claude 대화 기록만 다운로드할 수 있나요?

네. 목록 페이지에서 "Project"(프로젝트)로 필터링한 뒤 Export All을 누르십시오. 계정의 모든 스레드를 가져오지 않고 Claude 채팅 묶음을 통째로 받는 일반적인 방법입니다.

일괄 내보내기는 Anthropic의 공식 내보내기와 같은가요?

아니요. 공식 Export data는 계정 전체를 하나의 JSON ZIP으로 이메일로 보내는 것(Claude 채팅 백업)입니다. 일괄 Export All은 선택한 채팅을 원하는 형식의 파일로 즉시 만듭니다.

Download Claude conversations는 이미 내보낸 채팅을 기억하나요?

네. "Exported"(내보냄) 필터가 이 확장 프로그램으로 이미 다운로드한 채팅을 추적하므로, 다음에는 "New"(새 항목)만 골라 Export All을 실행할 수 있습니다.

이것이 Claude 채팅 전체를 다운로드하는 방법인가요?

네 — 목록 페이지의 Export All이 Claude 대화 기록 전체를 개별 파일로 다운로드하는 방법입니다. Anthropic의 Export data는 대신 시간이 걸리는 계정 ZIP 하나를 줍니다.

일괄 Export All은 Claude Desktop에서도 되나요?

아니요. 이 Chrome 확장 프로그램은 Claude Desktop에서 실행되지 않습니다. 먼저 채팅을 claude.ai에 동기화하거나, 복사해 붙여 넣기 / 공식 ZIP을 쓰십시오.

Export All로 Claude 채팅을 백업할 수 있나요?

Export All은 읽을 수 있는 파일 폴더이지 Anthropic의 백업 ZIP이 아닙니다. 계정 단위로 Claude 채팅을 백업하려면 Settings → Privacy → Export data를 쓰십시오. 문서와 아카이브가 모두 필요하면 둘 다 쓰십시오.

일괄 Export All로 PDF 파일을 만들 수 있나요?

아니요. 형식은 Markdown, JSON, 일반 텍스트, XML, PNG입니다. PDF 같은 페이지가 필요하면 Chrome에서 인쇄하십시오. PNG로 일괄 내보내면 채팅마다 이미지 한 장이 만들어집니다.

Claude 채팅 전체 다운로드가 Claude Code에도 되나요?

아니요. Claude Code는 /export나 디스크의 JSONL을 씁니다. 일괄 Export All은 Chrome의 claude.ai 대화만 보여 줍니다.

Export All이 파일 세 개 뒤에 멈추면요?

무료 내보내기 3회를 다 쓴 것입니다. Pro(월 $3.99 또는 연 $26.99)로 업그레이드하거나 더 필요할 때까지 기다리십시오. 다시 설치해도 Google 계정에 연결된 횟수는 초기화되지 않습니다.

일괄 Export All을 쓰려면 Anthropic 유료 요금제가 필요한가요?

아니요. Chrome에서 기록을 불러올 수 있는 claude.ai 요금제라면 무엇이든 됩니다. 저희 무료/Pro 사용량은 별개입니다. 다만 Team 관리자가 브라우저에서 확장 프로그램을 차단할 수는 있습니다.
