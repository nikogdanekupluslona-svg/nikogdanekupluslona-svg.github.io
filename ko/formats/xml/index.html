Claude 채팅을 XML로 내보내려면?

Chrome의 claude.ai에서 대화를 열고, 메시지 입력창 옆의 주황색 버튼을 누른 뒤 XML을 고르고 "Export"를 누르십시오. Download Claude conversations가 파일을 로컬에 만듭니다. 버전 1.13.0에서 Claude 채팅을 XML로 내보내는 방법은 이것입니다. 2026년 9월 현재 claude.ai에는 "XML로 저장"하는 자체 기능이 없습니다.

  1. Chrome Web Store에서 Download Claude conversations를 설치합니다(평점 5.0).
  2. claude.ai를 새로 고치고, 빈 입력 화면이 아닌 실제 대화 URL을 엽니다.
  3. 메시지 입력창 오른쪽의 주황색 다운로드 버튼을 누릅니다.
  4. XML을 고릅니다. 마지막으로 쓴 형식이 기억됩니다.
  5. "Export"를 누릅니다. Chrome이 브라우저 다운로드 API로 XML을 다운로드합니다.

처음 Claude 채팅을 XML로 내보내기 전에 Google 로그인이 필요합니다. Download Claude conversations는 무료 내보내기 3회를 집계하고 다시 설치한 뒤 Pro를 복원하기 위해 인증된 이메일을 저장합니다. 채팅 텍스트는 로그인과 관계가 없습니다. 구조: 작동 방식.

주황색 버튼이 없다면 대화 URL이 아니거나, 탭을 새로 고쳐야 하거나, 확장 프로그램이 Chrome 퍼즐 메뉴에 숨어 있는 것입니다. Download Claude conversations를 고정한 뒤 claude.ai를 새로 고치십시오. XML 내보내기는 Claude Desktop이나 Claude Code에는 나타나지 않습니다.

파일 하나 vs 여러 개. 주황색 버튼은 열려 있는 스레드를 XML로 내보냅니다. XML 파일이 많이 필요하면 "View and Download All Conversations"(모든 대화 보기 및 다운로드)를 열고 XML을 선택한 채 "Export All"을 실행하십시오 — 일괄 Export All 참고.

언제 Claude 채팅을 XML로 내보내야 하나요?

받는 쪽 시스템, 파이프라인, 레거시 도구가 구조화된 데이터 교환에 XML을 요구할 때 Claude 채팅을 XML로 내보내십시오. 대부분의 개발자는 JSON을 고르는 편이 낫습니다. Markdown은 사람이 읽는 노트용이고, PNG는 그림입니다. 일부 도구가 여전히 XML만 받고 JSON을 받지 않기 때문에 드롭다운에 XML이 있습니다.

XML을 "더 공식적인" JSON으로 여기고 내보내지 마십시오. Download Claude conversations는 어느 쪽이든 같은 방식으로 분석합니다. 차이는 파일 모양이지 추가 필드가 저절로 생기는 것이 아닙니다. 사용하는 도구 중 XML을 요구하는 것이 없다면 이 형식은 건너뛰고 JSON을 쓰십시오.

저희가 XML을 제공하는 이유는 일부 파이프라인이 여전히 XML을 요구하기 때문이지, 모든 claude.ai 내보내기에서 JSON보다 낫다고 생각해서가 아닙니다. 분석 방식은 같습니다: 메시지, 발신자, 선택적 사고 과정과 아티팩트. PDF는 여전히 만들지 않습니다. 버전 1.13.0에서 XML은 유료 추가 기능이 아니라 5가지 형식 중 하나입니다.

XML로 내보내면 무엇이 유지되나요?

Claude 채팅을 XML로 내보내면 Download Claude conversations가 대화 구조 — 메시지, 발신자, 사용 가능한 메타데이터 — 를 XML 마크업으로 씁니다. 사고 과정 블록과 아티팩트는 Markdown, JSON과 같은 옵션을 따릅니다. XML은 그 형식들의 축소판이 아닙니다.

버전 1.13.0의 아티팩트 레이아웃은 "Original"(원본), "Inline"(인라인), "Nested"(중첩), "Flat"(평면)입니다. 발신자 필터로 XML을 "all / human only / assistant only"(전체 / 사용자만 / 어시스턴트만)로 제한할 수 있습니다. 메타데이터(제목, 타임스탬프, 모델)도 함께 넣을 수 있습니다. 전체 옵션 목록: Chrome 확장 프로그램 기능.

Claude 채팅을 내보낼 때 XML vs JSON?

개발자에게는 JSON이 흔한 선택입니다. 연결된 시스템이 XML을 요구할 때만 Claude 채팅을 XML로 내보내십시오. Download Claude conversations에서 XML이 JSON보다 "더 완전"하지는 않습니다. 둘 다 사고 과정과 아티팩트를 담을 수 있습니다. 둘 다 Anthropic의 계정 ZIP이 아닙니다. 형식 허브: Claude 채팅 내보내기 형식.

Anthropic의 Settings → Privacy → Export data(claude.ai를 한국어로 설정했다면 메뉴 이름이 번역되어 보일 수 있습니다)는 XML이 아니라 JSON(ZIP)입니다. 인쇄 → PDF로 저장은 웹 페이지 스냅샷입니다. 둘 다 주황색 버튼의 XML 내보내기를 대신하지 못합니다. 이 XML이 공개되지 않은 Anthropic 스키마와 일치하리라고 기대하지 마십시오.

확장 프로그램은 Chrome의 claude.ai에서만 실행됩니다. Claude Desktop과 Claude Code에는 XML 버튼이 없습니다. 같은 스레드가 claude.ai에도 있다면 그곳에서 열어 XML로 내보내십시오. Claude Code의 /export는 다른 제품의 방법입니다.

Claude 채팅을 XML로 일괄 내보낼 수 있나요?

네. "View and Download All Conversations"를 열고 형식을 XML로 설정한 뒤 표를 필터링하고 "Export All"을 누르십시오. 완성된 파일 하나가 무료 내보내기 3회 중 1회입니다. Pro(월 $3.99 또는 연 $26.99)는 일괄 XML의 제한을 없앱니다.

목록 표는 claude.ai 기록을 이름 검색과 "All"(전체), "New"(새 항목), "Exported"(내보냄), "Project"(프로젝트) 필터로 보여 줍니다. New는 Download Claude conversations로 아직 내보내지 않은 채팅입니다. Exported는 이미 저장한 채팅을 추적합니다. Project는 claude.ai에서 채팅을 묶는 방식과 같습니다. Export All은 여러 형식이 섞인 ZIP 하나가 아니라 XML 파일 여러 개입니다.

사용량은 계정 단위입니다. 무료 내보내기는 총 3회이며, 일괄 실행마다 XML 파일 3개가 아닙니다. 대화 40개를 선택하면 모든 파일이 완성될 경우 40회를 씁니다. 선택을 계획하거나 Pro를 쓰십시오.

한 번의 Export All 클릭으로 XML과 JSON을 섞을 수는 없습니다. 그 실행에서는 XML을 고르십시오. 같은 claude.ai 스레드를 두 가지 모양으로 받아야 한다면 JSON으로 Export All을 다시 실행하십시오. 두 번째 실행도 사용량을 씁니다.

XML로 내보내려면 Pro가 필요한가요?

아니요. XML도 Markdown, JSON, 텍스트, PNG와 마찬가지로 Google로 로그인한 모든 계정이 받는 무료 내보내기 3회에 포함됩니다. 파일 3개 이후 Pro는 Paddle을 통해 월 $3.99 또는 연 $26.99입니다. Download Claude conversations는 XML을 유료 전용 형식으로 취급하지 않습니다.

Chrome 확장 프로그램을 다시 설치해도 무료 내보내기 3회는 초기화되지 않습니다. 그래서 처음 XML로 내보낼 때 Google 로그인이 필요합니다. 새 컴퓨터에서도 같은 Google 계정으로 Pro가 복원됩니다. Paddle이 판매 대행자(merchant of record)이며, 저희 팀은 카드 번호를 보지 않습니다.

Anthropic의 유료 claude.ai 요금제는 필요 없습니다. Chrome에서 대화를 불러올 수 있는 로그인만 있으면 됩니다. 버전 1.13.0(2026년 9월)도 PDF, Word, Notion은 만들지 않습니다. 이 목록이 바뀌면 이 페이지도 당일에 바뀝니다.

FAQ: Claude 채팅 XML로 내보내기

이 FAQ는 Download Claude conversations 1.13.0에서 Claude 채팅을 XML로 내보내는 방법을 다룹니다: JSON과의 비교, 일괄 Export All, 사용량, Desktop, PDF, Pro. 각 답변은 제품 사실입니다. 페이지 head의 FAQPage JSON-LD도 이 목록과 일치합니다.

Claude 채팅 내보내기에는 XML이 JSON보다 나은가요?

일반적으로는 아닙니다. 개발자에게는 JSON이 더 흔한 선택입니다. 연결된 시스템이 구조화된 데이터 교환에 XML을 요구할 때 Claude 채팅을 XML로 내보내십시오. claude.ai에서 분석하는 방식은 같고, 파일 모양만 다릅니다.

Claude 채팅을 XML로 일괄 내보낼 수 있나요?

네. 목록 페이지의 같은 "Export All"(모두 내보내기) 흐름이 XML을 지원합니다. Pro(월 $3.99 또는 연 $26.99)가 아니라면 완성된 파일마다 무료 내보내기 3회 중 1회로 계산됩니다.

XML은 유료 전용 형식인가요?

아니요. XML을 포함한 5가지 형식 모두 Google로 로그인한 모든 계정이 받는 무료 내보내기 3회에 포함됩니다. 파일 3개 이후 Pro는 월 $3.99 또는 연 $26.99입니다.

Claude 채팅 XML 내보내기는 Anthropic의 ZIP과 같은가요?

아니요. Anthropic의 Export data는 시간이 걸려 도착하는 계정 JSON ZIP입니다. Download Claude conversations는 Chrome에서 채팅별(또는 선택별) XML 파일을 즉시 만듭니다. 같은 스키마가 아닙니다.

Claude 채팅을 XML로 내보내면 PDF가 만들어지나요?

아니요. XML은 마크업입니다. 제품의 형식은 Markdown, JSON, 일반 텍스트, XML, PNG입니다. 인쇄용 페이지가 필요하면 Chrome의 인쇄 대화 상자를 쓰십시오. PNG는 이미지이며 역시 PDF가 아닙니다.

Desktop에서 Claude 채팅을 XML로 내보낼 수 있나요?

아니요. Chrome 확장 프로그램은 claude.ai에만 삽입됩니다. Claude Desktop에는 XML 드롭다운이 나타나지 않습니다. 같은 스레드가 claude.ai에 있다면 Chrome에서 여십시오.

한 번 XML로 내보내는 데도 Pro가 필요한가요?

아니요. 처음 3회는 XML을 포함해 어떤 형식이든 무료입니다. Pro(월 $3.99 또는 연 $26.99)는 채팅 하나든 일괄이든 XML 파일 수의 제한을 없앱니다.
