Claude 대화를 JSON으로 내보내려면?

Chrome의 claude.ai에서 대화를 열고, 메시지 입력창 옆의 주황색 버튼을 누른 뒤 JSON을 고르고 "Export"를 누르십시오. Download Claude conversations가 파일을 로컬에 만듭니다. 버전 1.13.0에서 Claude 대화를 JSON으로 내보내는 방법은 이것입니다. 2026년 9월 현재 claude.ai에는 채팅별로 "JSON으로 저장"하는 자체 기능이 없습니다.

  1. Chrome Web Store에서 Download Claude conversations를 설치합니다(평점 5.0).
  2. claude.ai를 새로 고치고, 빈 입력 화면이 아닌 실제 대화 URL을 엽니다.
  3. 메시지 입력창 오른쪽의 주황색 다운로드 버튼을 누릅니다.
  4. JSON을 고릅니다. 마지막으로 쓴 형식이 기억됩니다.
  5. "Export"를 누릅니다. Chrome이 브라우저 다운로드 API로 JSON을 다운로드합니다.

처음 Claude 대화를 JSON으로 내보내기 전에 Google 로그인이 필요합니다. Download Claude conversations는 무료 내보내기 3회를 집계하고 다시 설치한 뒤 Pro를 복원하기 위해 인증된 이메일을 저장합니다. 채팅 본문은 로그인과 관계가 없습니다. 구조: 작동 방식.

주황색 버튼이 없다면 대화 URL이 아니거나, 탭을 새로 고쳐야 하거나, 확장 프로그램이 Chrome 퍼즐 메뉴에 숨어 있는 것입니다. Download Claude conversations를 고정한 뒤 claude.ai를 새로 고치십시오. 콘텐츠 스크립트는 Claude Desktop이나 Claude Code에는 삽입되지 않습니다.

스레드 하나 vs 파일 여러 개. 주황색 버튼은 열려 있는 채팅을 JSON으로 내보냅니다. JSON 파일이 많이 필요하면 "View and Download All Conversations"(모든 대화 보기 및 다운로드)를 열고 JSON을 선택한 채 "Export All"을 실행하십시오 — 일괄 Export All 참고.

언제 Claude 대화를 JSON으로 내보내야 하나요?

스크립트, 인덱서, 비교(diff) 도구가 파일을 읽는다면 Claude 대화를 JSON으로 내보내십시오. 이 JSON은 Obsidian에서 읽기 위한 것이 아니라 메시지 트리를 담기 위한 것입니다. 사람이 읽을 제목과 코드 블록이 필요하다면 Markdown을 고르십시오.

claude.ai에서 복사해 붙여 넣으면 발신자 구조가 사라집니다. 인쇄는 웹 페이지의 UI까지 담습니다. Claude 대화를 JSON으로 내보내면 Download Claude conversations가 대화 턴, 발신자, 선택적 사고 과정을 뭉개진 문단이 아니라 데이터로 유지합니다. 개발자들이 일반 텍스트보다 JSON을 고르는 이유입니다.

저희는 페이지에 이미 있는 claude.ai 트리 — 발신자, 콘텐츠 블록, 타임스탬프, 모델 메타데이터 — 로 스레드를 업로드하지 않고 JSON을 만듭니다. 이 JSON은 Anthropic의 계정 ZIP이 아니며, PDF도 아닙니다. 버전 1.13.0도 여전히 5가지 형식만 제공합니다.

Claude 대화 JSON 내보내기에는 무엇이 들어 있나요?

Claude 대화 JSON 내보내기는 claude.ai의 메시지 트리를 따릅니다: 발신자, 콘텐츠 블록, 타임스탬프, 모델 메타데이터. 해당 옵션을 켜면 사고 과정 블록과 아티팩트도 포함됩니다. 발신자 필터로 파일을 "all / human only / assistant only"(전체 / 사용자만 / 어시스턴트만)로 제한할 수 있습니다. 먼저 Markdown으로 평평하게 바꾸는 과정은 없습니다.

버전 1.13.0의 아티팩트 레이아웃은 "Original"(원본), "Inline"(인라인), "Nested"(중첩), "Flat"(평면)입니다. 이 레이아웃에 따라 JSON 안에서 아티팩트 내용이 중첩되는 방식이 달라지며, Markdown과 XML에서 쓰는 것과 같은 네 가지 옵션입니다. 전체 옵션 목록: Chrome 확장 프로그램 기능. JSON이 PDF가 되지는 않습니다.

Claude 대화 JSON vs Anthropic Export data?

둘 다 JSON이지만 구조도 범위도 다릅니다. Anthropic의 Settings → Privacy → Export data(claude.ai를 한국어로 설정했다면 메뉴 이름이 번역되어 보일 수 있습니다)는 한참 기다린 뒤 계정 전체의 ZIP 하나를 이메일로 보냅니다. Claude 대화를 JSON으로 내보내면 스레드 하나를 Chrome에서 즉시 받습니다. 백업에는 ZIP을 쓰십시오.

Anthropic의 ZIP 요청에서는 Markdown을 고를 수 없습니다. 또한 이 확장 프로그램의 JSON을 그 ZIP 스키마 대신 그대로 쓸 수도 없습니다. 형식 허브: Claude 채팅 내보내기 형식. 인쇄는 시각적 우회 방법이지 JSON 내보내기가 아닙니다.

Download Claude conversations는 Anthropic, PBC와 제휴하지 않았습니다. 콘텐츠 스크립트는 사용자가 이미 claude.ai에서 연 세션을 씁니다. 별도의 인증 정보로 Anthropic에 로그인하지 않습니다. 계정에 대해서는 Anthropic의 규칙을 따르십시오.

Claude 대화를 JSON으로 일괄 내보낼 수 있나요?

네. "View and Download All Conversations"를 열고 형식을 JSON으로 설정한 뒤 표를 필터링하고 "Export All"을 누르십시오. 완성된 파일 하나가 무료 내보내기 3회 중 1회입니다. Pro(월 $3.99 또는 연 $26.99)는 일괄 JSON의 제한을 없앱니다.

목록 표는 claude.ai 기록을 이름 검색과 "All"(전체), "New"(새 항목), "Exported"(내보냄), "Project"(프로젝트) 필터로 보여 줍니다. New는 Download Claude conversations로 아직 내보내지 않은 채팅입니다. Exported는 이미 저장한 채팅을 추적합니다. Project는 claude.ai에서 채팅을 묶는 방식과 같습니다. Export All은 여러 형식이 섞인 ZIP 하나가 아니라 JSON 파일 여러 개입니다.

사용량은 계정 단위입니다. 무료 내보내기는 총 3회이며, 일괄 실행마다 JSON 파일 3개가 아닙니다. 대화 40개를 선택하면 모든 파일이 완성될 경우 40회를 씁니다. 선택을 계획하거나 Pro를 쓰십시오.

같은 claude.ai 스레드를 서로 다른 시점에 내보낸 두 JSON은 여느 JSON 파일처럼 비교할 수 있습니다. 각 내보내기는 독립된 파일입니다. 같은 채팅을 다시 Export All 하면, 파일이 완성되지 않은 경우를 제외하고 사용량을 또 씁니다.

Claude 대화 JSON 내보내기에 Pro가 필요한가요?

아니요. JSON도 Markdown, 텍스트, XML, PNG와 마찬가지로 Google로 로그인한 모든 계정이 받는 무료 내보내기 3회에 포함됩니다. 파일 3개 이후 Pro는 Paddle을 통해 월 $3.99 또는 연 $26.99입니다. Download Claude conversations는 Claude 대화를 JSON으로 내보내는 데 추가 요금을 받지 않습니다.

Chrome 확장 프로그램을 다시 설치해도 무료 내보내기 3회는 초기화되지 않습니다. 그래서 처음 "Export"를 누를 때 Google 로그인이 필요합니다. 새 컴퓨터에서도 같은 Google 계정으로 Pro가 복원됩니다. Paddle이 판매 대행자(merchant of record)이며, 저희 팀은 카드 번호를 보지 않습니다.

확장 프로그램은 Chrome의 claude.ai에서만 실행됩니다. Claude Desktop과 Claude Code에는 JSON 버튼이 없습니다. Claude Code의 /export나 디스크의 JSONL은 다른 방법입니다. 버전 1.13.0(2026년 9월)도 PDF, Word, Notion은 만들지 않습니다.

FAQ: Claude 대화 JSON으로 내보내기

이 FAQ는 Download Claude conversations 1.13.0에서 Claude 대화를 JSON으로 내보내는 방법을 다룹니다: 일괄 Export All, 스키마, 사용량, 비교(diff), Anthropic의 ZIP, Desktop. 각 답변은 제품 사실입니다. 페이지 head의 FAQPage JSON-LD도 이 목록과 일치합니다.

Claude 대화를 JSON으로 일괄 내보낼 수 있나요?

네. 목록 페이지의 "Export All"(모두 내보내기)은 단일 내보내기와 똑같이 JSON을 지원합니다. Pro(월 $3.99 또는 연 $26.99)가 아니라면 완성된 파일마다 무료 내보내기 3회 중 1회로 계산됩니다.

JSON 구조는 문서화되어 있나요?

claude.ai 자체의 메시지 트리를 따릅니다: 발신자, 콘텐츠 블록, 타임스탬프, 모델 메타데이터이며, 해당 옵션을 켜면 아티팩트와 사고 과정 블록도 포함됩니다. Anthropic 계정 ZIP의 스키마는 아닙니다.

Claude 대화를 JSON으로 내보내려면 Pro가 필요한가요?

아니요. JSON도 다른 모든 형식과 마찬가지로 Google로 로그인한 모든 계정이 받는 무료 내보내기 3회에 포함됩니다. 파일 3개 이후 Pro는 월 $3.99 또는 연 $26.99입니다.

같은 채팅의 JSON 내보내기 두 개를 비교(diff)할 수 있나요?

네. Claude 대화를 JSON으로 내보낼 때마다 같은 방식으로 만든 독립된 파일을 받습니다. 같은 스레드를 서로 다른 시점에 내보낸 두 파일은 다른 JSON 파일처럼 비교할 수 있습니다.

이 JSON은 Anthropic의 Export data와 같은가요?

아니요. Anthropic의 Export data는 시간이 걸려 도착하는 계정 전체 ZIP입니다. Download Claude conversations는 Chrome에서 채팅별(또는 선택별) JSON 파일을 즉시 만듭니다. 둘 다 JSON일 수 있지만 서로 대체할 수 없습니다.

Claude 대화를 JSON으로 내보내면 PDF가 만들어지나요?

아니요. JSON은 구조화된 데이터입니다. 제품의 형식은 Markdown, JSON, 일반 텍스트, XML, PNG입니다. 인쇄용 페이지가 필요하면 이 드롭다운이 아니라 Chrome의 인쇄 대화 상자를 쓰십시오.

JSON 내보내기는 Claude Desktop에서도 되나요?

아니요. Chrome 확장 프로그램은 claude.ai에만 삽입됩니다. Claude Desktop에는 JSON 옵션이 나타나지 않습니다. 같은 스레드가 claude.ai에 있다면 Chrome에서 여십시오.
