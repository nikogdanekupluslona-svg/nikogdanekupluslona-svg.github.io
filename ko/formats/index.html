스프레드시트용입니다. CSV는 메시지 하나를 한 행으로 쓰며 Excel, Google Sheets, Numbers에서 열립니다. 무제한이고 계정이 필요 없으며, 다운로드 대신 클립보드에 복사할 수도 있습니다.

Claude 채팅 내보내기 형식에 하루 한도가 있나요?

PDF와 일괄 내보내기에만 있습니다. Markdown, 텍스트, JSON, XML, CSV, PNG로 채팅 하나를 내보내는 것은 무제한이며 무료입니다. 무료 요금제에서 PDF와 일괄 ZIP은 합쳐서 하루 3회이며, UTC 자정에 초기화됩니다. Pro(월 $3.99 또는 연 $26.99)는 이 한도를 없앱니다.

Export All에서 Claude 채팅 내보내기 형식을 섞을 수 있나요?

아니요. Export All 한 번에는 형식 하나를 쓰며, ZIP 하나가 만들어집니다. 같은 claude.ai 채팅을 두 가지 파일로 받고 싶다면 다른 형식으로 다시 실행하십시오. 무료 요금제에서는 ZIP마다 모든 채팅이 PDF·일괄 공통의 하루 3회에서 차감됩니다.

Claude 채팅 내보내기 형식은 Export data와 같은가요?

아니요. Anthropic의 Export data는 시간이 걸려 도착하는 계정 JSON ZIP입니다. Claude 채팅 내보내기 형식은 Download Claude conversations가 Chrome에서 즉시 만드는 채팅별(또는 선택별) 파일입니다.

Claude 채팅 내보내기 형식을 Desktop이나 Code에서 쓸 수 있나요?

웹에서는 됩니다. 일반 채팅, 프로젝트, Cowork 세션, 웹용 Claude Code(claude.ai/code)는 Chrome에서 모든 형식을 쓸 수 있습니다. Claude Desktop 앱과 로컬 Claude Code 터미널 세션에는 형식 드롭다운이 나타나지 않습니다. 같은 스레드가 claude.ai에 있다면 Chrome에서 여십시오.

Claude 채팅 내보내기 형식을 써 보려면 Pro가 필요한가요?

아니요. 무료 요금제에서 6가지 형식은 계정 없이 무제한입니다. PDF는 Google 로그인으로 하루 3회까지 무료이며, 이 횟수는 일괄 ZIP과 함께 씁니다. PDF나 일괄 내보내기를 무제한으로 써야 할 때 Pro(월 $3.99 또는 연 $26.99)를 쓰십시오.
