Claude 채팅 내보내기 형식은 어떻게 고르나요?

Chrome의 claude.ai에서 대화 URL을 열고, 메시지 입력창 옆의 주황색 버튼을 누른 뒤 Claude 채팅 내보내기 형식 중 하나를 고르고 "Export"(내보내기)를 누르십시오. Download Claude conversations가 탭 안에서 파일을 만듭니다. 2026년 9월 현재 claude.ai에는 "이 채팅 내보내기" 같은 자체 기능이 없습니다.

  1. Chrome Web Store에서 Download Claude conversations를 설치합니다(평점 5.0).
  2. claude.ai를 새로 고치고, 빈 입력 화면이 아닌 실제 대화 URL을 엽니다.
  3. 메시지 입력창 오른쪽의 주황색 다운로드 버튼을 누릅니다.
  4. Markdown, JSON, 일반 텍스트, XML, PNG 중 하나를 고릅니다. 마지막 형식이 유지됩니다.
  5. "Export"를 누릅니다. Chrome이 파일을 즉시 저장합니다.

첫 내보내기 전에 Google 로그인이 필요합니다. Download Claude conversations는 무료 내보내기 3회를 집계하고 다시 설치한 뒤 Pro를 복원하기 위해 인증된 이메일을 저장합니다. 채팅 텍스트는 로그인과 관계가 없습니다. 구조: 작동 방식.

같은 위젯의 옵션은 모든 형식에 적용됩니다: 사고 과정 켜기/끄기, 메타데이터(제목, 타임스탬프, 모델), 발신자 필터("all / human only / assistant only", 전체 / 사용자만 / 어시스턴트만), 아티팩트 레이아웃("Original"(원본), "Inline"(인라인), "Nested"(중첩), "Flat"(평면)). PNG는 여전히 그림을 렌더링하고, 나머지 네 형식은 텍스트나 구조화된 마크업을 만듭니다.

Claude 채팅 내보내기 형식은 Export All에서도 되나요?

네. "View and Download All Conversations"(모든 대화 보기 및 다운로드)를 열고 표를 필터링한 뒤, 같은 Claude 채팅 내보내기 형식 드롭다운에서 고르고 "Export All"(모두 내보내기)을 누르십시오. 완성된 파일 하나가 무료 내보내기 3회 중 1회입니다. Pro(월 $3.99 또는 연 $26.99)는 일괄과 단일 채팅 모두의 제한을 없앱니다.

목록 표는 claude.ai 기록을 이름 검색과 All, New, Exported, Project 필터로 보여 줍니다. New는 Download Claude conversations로 아직 내보내지 않은 채팅입니다. Exported는 이미 저장한 채팅을 추적합니다. Project는 claude.ai에서 채팅을 묶는 방식과 같습니다. Export All은 시간이 걸리는 계정 ZIP이 아닙니다.

사용량은 계정 단위입니다. 무료 내보내기는 총 3회이며, 형식마다 3회도, 일괄 실행마다 3회도 아닙니다. 대화 40개를 선택하면 모든 파일이 완성될 경우 40회를 씁니다. 선택을 계획하거나 Pro를 쓰십시오.

일괄 내보내기는 대화 하나를 내보낼 때와 같은 사고 과정, 메타데이터, 발신자, 아티팩트 옵션을 씁니다. 한 번의 클릭으로 Markdown과 JSON이 섞인 묶음을 받을 수는 없습니다. 실행할 때마다 Claude 채팅 내보내기 형식 하나를 고릅니다. 같은 스레드를 두 가지 모양으로 받아야 한다면 다른 형식으로 Export All을 다시 실행하십시오. 두 번째 실행도 사용량을 씁니다.
