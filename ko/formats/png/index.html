Claude 채팅을 PNG로 다운로드하려면?

Chrome의 claude.ai에서 대화를 열고, 메시지 입력창 옆의 주황색 버튼을 누른 뒤 PNG를 고르고 "Export"를 누르십시오. Download Claude conversations가 탭 안에서 이미지를 렌더링합니다. 버전 1.16.2에서 Claude 채팅을 PNG로 다운로드하는 방법은 이것이며, 계정 없이 무제한 무료입니다.

  1. Chrome Web Store에서 Download Claude conversations를 설치합니다.
  2. claude.ai를 새로 고치고, 빈 입력 화면이 아닌 실제 대화 URL을 엽니다.
  3. 메시지 입력창 오른쪽의 둥근 주황색 다운로드 버튼을 누릅니다.
  4. PNG를 고릅니다. 마지막으로 쓴 형식이 기억됩니다.
  5. "Export"를 누릅니다. Chrome이 PNG를 즉시 다운로드합니다.

Claude 채팅을 PNG로 다운로드하는 데는 Google 로그인이 필요 없습니다. 채팅 하나를 PNG로 내보내는 것은 무제한이고 익명입니다. 횟수 집계도 없고, 채팅에 관한 어떤 정보도 브라우저 밖으로 나가지 않습니다. 로그인은 PDF를 고르거나, "Export All"(모두 내보내기)을 실행하거나, Pro를 구매할 때만 나타납니다. 구조: 작동 방식.

주황색 버튼이 없다면 대화 URL이 아니거나, 설치 후 탭을 새로 고쳐야 하거나, 확장 프로그램이 Chrome 퍼즐 메뉴에 숨어 있는 것입니다. Download Claude conversations를 고정한 뒤 claude.ai를 새로 고치십시오. 프로젝트, Cowork 세션, 웹용 Claude Code(claude.ai/code)도 일반 채팅처럼 내보낼 수 있습니다. PNG 내보내기는 Claude Desktop 앱이나 로컬 Claude Code 터미널 세션에는 나타나지 않습니다.

이미지 하나 vs 여러 장. 주황색 버튼은 열려 있는 스레드의 PNG 한 장을 만듭니다. 이미지가 많이 필요하면 "View and Download All Conversations"(모든 대화 보기 및 다운로드)를 열고 PNG를 선택한 채 "Export All"을 실행하십시오. 일괄 내보내기는 ZIP 하나로 저장되며 하루 일괄 한도를 씁니다 — 일괄 Export All 참고.

언제 Claude 채팅을 PNG로 다운로드해야 하나요?

슬라이드, 메신저, 티켓처럼 .md 파일보다 이미지를 넣기 쉬운 곳에 쓸 그림이 필요할 때 Claude 채팅을 PNG로 다운로드하십시오. 나중에 검색하거나 코드를 복사해야 한다면 PNG를 고르지 마십시오. 그럴 때는 Markdown을, 페이지 형태가 필요하면 PDF를 쓰십시오.

직접 찍은 claude.ai 스크린샷에는 사이드바와 입력창이 함께 담기는 경우가 많습니다. Download Claude conversations는 운영체제 스크린샷이 아니라 이미 분석한 대화 내용으로 PNG를 만듭니다. 그래도 이미지입니다. 메시지 트리도, 텍스트로 복사할 수 있는 코드 블록 언어 태그도 없습니다.

claude.ai 스레드의 시각적 스냅샷을 파일 하나로 저장할 수 있도록 PNG를 추가했습니다. 긴 이미지 한 장이 아니라 페이지가 필요하다면 PDF를 고르십시오. 확장 프로그램이 페이지 번호와 목차를 넣어 직접 만듭니다. PNG는 계속 계정 없이 무제한입니다.

PNG 다운로드는 PDF와 같은가요?

아니요. PNG는 이미지 형식이고 PDF는 페이지로 나뉜 문서 형식입니다. Download Claude conversations는 둘 다 내보냅니다. 그림 한 장이 필요하면 PNG, 페이지가 필요하면 PDF입니다. PNG는 계정 없이 무제한이고, PDF는 Google 로그인이 필요하며 하루 3회까지 무료입니다. 안내: Claude 채팅 PDF로 다운로드.

Claude 채팅 PNG에는 무엇이 들어가나요?

Claude 채팅 PNG는 Download Claude conversations가 렌더링한 대화 내용의 이미지 한 장입니다. Markdown이나 JSON과 달리 PNG에는 파싱할 수 있는 메시지 트리가 없습니다. 코드와 표는 픽셀입니다. 사고 과정과 아티팩트는 텍스트로 저장되지 않고 그림으로 그려집니다.

"Messages"(메시지) 필터로 그릴 내용을 "All", "Human", "Assistant"(전체, 사용자, 어시스턴트) 중에서 정하고, "Thinking"(사고 과정) 체크박스로 확장 사고를 넣거나 빼며, "Select"(선택)로 메시지를 하나씩 체크할 수 있습니다. 메타데이터와 아티팩트 레이아웃("Original"(원본), "Inline"(인라인), "Nested"(중첩), "Flat"(평면))은 Export All용 대시보드 옵션입니다. 메타데이터는 JSON에서처럼 PNG 위에서 선택 가능한 텍스트가 되지 않습니다. "Copy"(복사)는 PNG에 쓸 수 없으며, PNG는 항상 파일로 저장됩니다.

스레드가 아주 길다면 PNG로 다운로드하기 전에 claude.ai가 이전 메시지를 불러올 때까지 스크롤하십시오. 확장 프로그램은 페이지에 로드된 내용만 렌더링할 수 있습니다. 절반만 로드된 스레드는 잘린 이미지를 만듭니다. 전체 옵션 목록: Chrome 확장 프로그램 기능.

글이 중요하다면 텍스트 사본도 보관하십시오. PNG는 스냅샷입니다. 나중에 함수 이름을 grep으로 찾으려 해도 찾을 수 없습니다. Markdown이나 JSON을 두 번째 파일로 내보내십시오. PNG와 마찬가지로 무제한이며 무료입니다.

Claude 채팅을 PNG로 일괄 다운로드할 수 있나요?

네. "View and Download All Conversations"를 열고 "Chat format"(채팅 형식)을 PNG로 설정한 뒤 목록을 필터링하고 "Export All"을 누르십시오. 선택한 대화마다 PNG가 한 장씩 담긴 ZIP 하나를 받습니다. 일괄 내보내기에는 Google 로그인이 필요하며, 무료 요금제에서는 ZIP 안의 채팅 하나하나가 PDF·일괄 공통의 하루 3회 중 1회를 씁니다. Pro(월 $3.99 또는 연 $26.99)는 이 한도를 없앱니다.

대시보드는 claude.ai 기록을 이름 검색, 프로젝트 검색, Chat과 Cowork 탭, 그리고 "All conversations"(전체 대화), "New"(새 항목), "Updated"(업데이트됨), "Previously exported"(이전에 내보냄) 필터로 보여 줍니다. New는 Download Claude conversations로 아직 내보내지 않은 채팅입니다. Export All은 ZIP 안에 선택한 대화마다 PNG 한 장을 만들며, 여러 장을 모은 콜라주나 PDF 묶음을 만들지 않습니다.

일괄 한도는 UTC 자정에 초기화됩니다. 무료 요금제에서 오늘 남은 횟수보다 많이 선택하면 일부만 저장되는 것이 아니라 전체가 차단됩니다. 채팅 수를 줄이거나 Pro를 쓰십시오. 주황색 버튼으로 채팅 하나를 PNG로 받는 것은 계속 무제한입니다. Anthropic의 Settings → Privacy → Export data(claude.ai를 한국어로 설정했다면 메뉴 이름이 번역되어 보일 수 있습니다)는 여전히 시간이 걸리는 JSON ZIP이지 이미지 폴더가 아닙니다.

PNG 다운로드에 추가 비용이 드나요?

아니요. PNG는 Markdown, JSON, 텍스트, XML, CSV와 마찬가지로 무료이고 무제한입니다. Google 계정도, 횟수 집계도 없습니다. Paddle을 통한 Pro(월 $3.99 또는 연 $26.99)는 PNG가 아니라 PDF와 일괄 ZIP을 무제한으로 쓰기 위한 것입니다. Download Claude conversations는 PNG 다운로드에 추가 요금을 받지 않습니다.

로그인은 PDF나 Export All을 쓸 때만 필요합니다. 무료 요금제에서 이 둘은 합쳐서 하루 3회입니다. 새 컴퓨터에서도 같은 Google 계정으로 로그인하면 Pro가 복원됩니다. Paddle이 판매 대행자(merchant of record)이며, 저희 팀은 카드 번호를 보지 않습니다.

확장 프로그램은 Chrome의 claude.ai에서 실행됩니다: 일반 채팅, 프로젝트, Cowork 세션, 웹용 Claude Code(claude.ai/code). Claude Desktop 앱과 로컬 Claude Code 터미널 세션에는 PNG 버튼이 없습니다. 2026년 현재 저희 팀의 iOS나 Android 앱은 없습니다. 버전 1.16.2는 PDF를 만들지만 Word나 Notion 파일은 만들지 않습니다.

FAQ: Claude 채팅 PNG 이미지로 다운로드

이 FAQ는 Download Claude conversations 1.16.2에서 Claude 채팅을 PNG로 다운로드하는 방법을 다룹니다: PDF, 일괄 Export All, 한도, 이미지에 담기는 내용. 각 답변은 제품 사실입니다. 페이지 head의 FAQPage JSON-LD도 이 목록과 일치합니다.

Download Claude conversations는 PDF로 내보내나요?

네. 페이지 번호와 목차를 넣을 수 있는 페이지 문서가 필요하면 내보내기 패널에서 PDF를 고르십시오. PNG는 스레드 이미지 한 장입니다. PDF는 Google 로그인이 필요하며 하루 3회까지 무료이고, PNG는 계정 없이 무제한입니다.

기록 전체를 PNG로 다운로드할 수 있나요?

네. 대시보드의 "Export All"(모두 내보내기)은 PNG를 지원하며, 선택한 대화마다 이미지가 한 장씩 담긴 ZIP 하나를 만듭니다. 일괄 내보내기에는 Google 로그인이 필요하며, 무료 요금제에서는 ZIP 안의 채팅 하나하나가 PDF·일괄 공통의 하루 3회 중 1회를 씁니다. Pro는 무제한입니다.

PNG는 무료인가요, Pro 전용인가요?

무료이며 무제한입니다. 채팅 하나를 PNG로 내보내는 데는 계정이 필요 없고 횟수 집계도 없습니다. Pro(월 $3.99 또는 연 $26.99)는 PDF와 일괄 ZIP을 무제한으로 쓰기 위한 것입니다.

Claude 채팅 PNG에서 코드를 복사할 수 있나요?

깔끔하게는 안 됩니다. PNG로 다운로드하면 픽셀이 저장됩니다. 언어 태그가 붙은 코드 블록이 필요하면 Markdown이나 JSON으로 내보내십시오. 그림과 검색 가능한 텍스트가 모두 필요하면 두 파일을 함께 보관하십시오.

PNG 다운로드는 Chrome 화면을 캡처한 것인가요?

아니요. Download Claude conversations는 claude.ai에서 분석한 대화로 PNG를 렌더링합니다. 그래도 Markdown 파일이 아닌 이미지입니다. 창 전체를 운영체제로 캡처한 스크린샷은 사용자가 직접 만드는 다른 파일입니다.

PNG는 Claude Desktop에서도 되나요?

아니요. Chrome 확장 프로그램은 Claude Desktop 앱이 아니라 Chrome의 claude.ai에서 실행됩니다. Claude Desktop에는 PNG 옵션이 나타나지 않습니다. 같은 스레드가 claude.ai에 있다면 Chrome에서 여십시오.

PNG 내보내기도 Markdown과 같은 사용량을 쓰나요?

네, 둘 다 사용량 한도가 없다는 점에서 같습니다. 채팅 하나를 PNG나 Markdown으로 내보내는 것은 모두 무제한이며 익명입니다. 유일한 한도는 무료 요금제의 PDF 또는 일괄 ZIP 하루 3회이며, Pro는 이 한도를 없앱니다.
