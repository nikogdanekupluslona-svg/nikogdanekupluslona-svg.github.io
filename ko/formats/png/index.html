Claude 채팅을 PNG로 다운로드하려면?

Chrome의 claude.ai에서 대화를 열고, 메시지 입력창 옆의 주황색 버튼을 누른 뒤 PNG를 고르고 "Export"를 누르십시오. Download Claude conversations가 탭 안에서 이미지를 렌더링합니다. 버전 1.13.0에서 Claude 채팅을 PNG로 다운로드하는 방법은 이것입니다.

  1. Chrome Web Store에서 Download Claude conversations를 설치합니다(평점 5.0).
  2. claude.ai를 새로 고치고, 빈 입력 화면이 아닌 실제 대화 URL을 엽니다.
  3. 메시지 입력창 오른쪽의 주황색 다운로드 버튼을 누릅니다.
  4. PNG를 고릅니다. 마지막으로 쓴 형식이 기억됩니다.
  5. "Export"를 누릅니다. Chrome이 PNG를 즉시 다운로드합니다.

처음 Claude 채팅을 PNG로 다운로드하기 전에 Google 로그인이 필요합니다. Download Claude conversations는 무료 내보내기 3회를 집계하고 다시 설치한 뒤 Pro를 복원하기 위해 인증된 이메일을 저장합니다. 로그인할 때 채팅 이미지는 업로드되지 않습니다. 구조: 작동 방식.

주황색 버튼이 없다면 대화 URL이 아니거나, 설치 후 탭을 새로 고쳐야 하거나, 확장 프로그램이 Chrome 퍼즐 메뉴에 숨어 있는 것입니다. Download Claude conversations를 고정한 뒤 claude.ai를 새로 고치십시오. PNG 내보내기는 Claude Desktop이나 Claude Code에는 나타나지 않습니다.

이미지 하나 vs 여러 장. 주황색 버튼은 열려 있는 스레드의 PNG 한 장을 만듭니다. 이미지가 많이 필요하면 "View and Download All Conversations"(모든 대화 보기 및 다운로드)를 열고 PNG를 선택한 채 "Export All"을 실행하십시오 — 일괄 Export All 참고.

언제 Claude 채팅을 PNG로 다운로드해야 하나요?

슬라이드, 메신저, 티켓처럼 .md 파일보다 이미지를 넣기 쉬운 곳에 쓸 그림이 필요할 때 Claude 채팅을 PNG로 다운로드하십시오. 나중에 검색하거나 코드를 복사해야 한다면 PNG를 고르지 마십시오. 그럴 때는 Markdown을 쓰십시오.

직접 찍은 claude.ai 스크린샷에는 사이드바와 입력창이 함께 담기는 경우가 많습니다. Download Claude conversations는 운영체제 스크린샷이 아니라 이미 분석한 대화 내용으로 PNG를 만듭니다. 그래도 이미지입니다. 메시지 트리도, 텍스트로 복사할 수 있는 코드 블록 언어 태그도 없습니다.

claude.ai 스레드의 시각적 스냅샷을 저장할 수 있도록 PNG를 추가했습니다. PDF는 추가하지 않았습니다. Claude 채팅을 PNG로 다운로드하면 이미지 파일을 받습니다. 인쇄용 페이지가 필요하면 Chrome의 인쇄 대화 상자를 쓰십시오. 이는 브라우저 기능이지 여섯 번째 형식이 아닙니다.

PNG 다운로드는 PDF와 같은가요?

아니요. PNG는 이미지 형식이고 PDF는 페이지로 나뉜 문서 형식입니다. Download Claude conversations는 PDF가 아니라 PNG를 내보냅니다. 정말 PDF 같은 페이지가 필요하다면 Chrome에서 claude.ai 탭을 인쇄하십시오(Ctrl/Cmd+P → PDF로 저장). 안내: Claude 대화 인쇄하기.

인쇄는 claude.ai 사이드바 UI까지 담고 코드를 페이지 사이에서 자르는 경우가 많습니다. PNG 다운로드는 스레드 내용의 스냅샷에 더 가깝습니다. 둘 다 구조화된 아카이브는 아닙니다. 나중에 글이 필요할 수 있다면 Markdown이나 JSON 내보내기도 보관하십시오.

Claude 채팅 PNG에는 무엇이 들어가나요?

Claude 채팅 PNG는 Download Claude conversations가 렌더링한 대화 내용의 이미지 한 장입니다. Markdown이나 JSON과 달리 PNG에는 파싱할 수 있는 메시지 트리가 없습니다. 코드와 표는 픽셀입니다. 사고 과정과 아티팩트는 텍스트로 저장되지 않고 그림으로 그려집니다.

아티팩트 레이아웃("Original"(원본), "Inline"(인라인), "Nested"(중첩), "Flat"(평면))은 다른 형식과 마찬가지로 이미지에서 아티팩트가 보이는 방식을 바꿉니다. 발신자 필터로 그릴 내용을 "all / human only / assistant only"(전체 / 사용자만 / 어시스턴트만)로 제한할 수 있습니다. 메타데이터는 JSON에서처럼 선택 가능한 텍스트가 되지 않습니다.

스레드가 아주 길다면 PNG로 다운로드하기 전에 claude.ai가 이전 메시지를 불러올 때까지 스크롤하십시오. 확장 프로그램은 페이지에 로드된 내용만 렌더링할 수 있습니다. 절반만 로드된 스레드는 잘린 이미지를 만듭니다. 전체 옵션 목록: Chrome 확장 프로그램 기능.

글이 중요하다면 텍스트 사본도 보관하십시오. PNG는 스냅샷입니다. 나중에 함수 이름을 grep으로 찾으려 해도 찾을 수 없습니다. Markdown이나 JSON을 두 번째 파일로 내보내십시오. 두 번째 파일도 무료 내보내기 3회에 포함됩니다.

Claude 채팅을 PNG로 일괄 다운로드할 수 있나요?

네. "View and Download All Conversations"를 열고 형식을 PNG로 설정한 뒤 표를 필터링하고 "Export All"을 누르십시오. 완성된 이미지 한 장은 주황색 버튼으로 PNG를 받을 때와 같은 무료 내보내기 3회에서 1회를 씁니다. Pro(월 $3.99 또는 연 $26.99)는 일괄 PNG의 제한을 없앱니다.

목록 표는 claude.ai 기록을 이름 검색과 "All"(전체), "New"(새 항목), "Exported"(내보냄), "Project"(프로젝트) 필터로 보여 줍니다. New는 Download Claude conversations로 아직 내보내지 않은 채팅입니다. Export All은 선택한 대화마다 PNG 한 장을 만들며, 여러 장을 모은 콜라주나 PDF 묶음을 만들지 않습니다.

사용량은 계정 단위입니다. 대화 40개를 선택하면 모든 PNG가 완성될 경우 40회를 씁니다. Export All을 누르기 전에 선택을 계획하십시오. Anthropic의 Settings → Privacy → Export data(claude.ai를 한국어로 설정했다면 메뉴 이름이 번역되어 보일 수 있습니다)는 여전히 시간이 걸리는 JSON ZIP이지 이미지 폴더가 아닙니다.

PNG 다운로드에 추가 비용이 드나요?

아니요. PNG도 Markdown, JSON, 텍스트, XML과 마찬가지로 Google로 로그인한 모든 계정이 받는 무료 내보내기 3회에 포함됩니다. 파일 3개 이후 Pro는 Paddle을 통해 월 $3.99 또는 연 $26.99입니다. Download Claude conversations는 PNG 다운로드에 추가 요금을 받지 않습니다.

Chrome 확장 프로그램을 다시 설치해도 무료 내보내기 3회는 초기화되지 않습니다. 그래서 처음 "Export"를 누를 때 Google 로그인이 필요합니다. 새 컴퓨터에서도 같은 Google 계정으로 Pro가 복원됩니다. Paddle이 판매 대행자(merchant of record)이며, 저희 팀은 카드 번호를 보지 않습니다.

확장 프로그램은 Chrome의 claude.ai에서만 실행됩니다. Claude Desktop과 Claude Code에는 PNG 버튼이 없습니다. 2026년 현재 저희 팀의 iOS나 Android 앱은 없습니다. 버전 1.13.0도 PDF, Word, Notion은 만들지 않습니다.

FAQ: Claude 채팅 PNG 이미지로 다운로드

이 FAQ는 Download Claude conversations 1.13.0에서 Claude 채팅을 PNG로 다운로드하는 방법을 다룹니다: PDF, 일괄 Export All, 사용량, 이미지에 담기는 내용. 각 답변은 제품 사실입니다. 페이지 head의 FAQPage JSON-LD도 이 목록과 일치합니다.

Download Claude conversations는 PDF로 내보내나요?

아니요. 현재 형식은 Markdown, JSON, 일반 텍스트, XML, PNG입니다. PNG가 시각적 사본에 가장 가깝지만 PDF가 아니라 이미지입니다. PDF 같은 파일이 필요하면 Chrome에서 claude.ai 페이지를 인쇄하십시오.

기록 전체를 PNG로 다운로드할 수 있나요?

네. 일괄 페이지의 "Export All"(모두 내보내기)은 단일 내보내기와 똑같이 PNG를 지원하며, 선택한 대화마다 이미지 한 장을 만듭니다. Pro가 아니라면 이미지마다 무료 내보내기 3회 중 1회로 계산됩니다.

PNG는 무료인가요, Pro 전용인가요?

무료입니다. PNG를 포함한 모든 형식이 Google로 로그인한 계정의 무료 내보내기 3회에 포함됩니다. 파일 3개 이후 Pro는 월 $3.99 또는 연 $26.99입니다.

Claude 채팅 PNG에서 코드를 복사할 수 있나요?

깔끔하게는 안 됩니다. PNG로 다운로드하면 픽셀이 저장됩니다. 언어 태그가 붙은 코드 블록이 필요하면 Markdown이나 JSON으로 내보내십시오. 그림과 검색 가능한 텍스트가 모두 필요하면 두 파일을 함께 보관하십시오.

PNG 다운로드는 Chrome 화면을 캡처한 것인가요?

아니요. Download Claude conversations는 claude.ai에서 분석한 대화로 PNG를 렌더링합니다. 그래도 Markdown 파일이 아닌 이미지입니다. 창 전체를 운영체제로 캡처한 스크린샷은 사용자가 직접 만드는 다른 파일입니다.

PNG는 Claude Desktop에서도 되나요?

아니요. Chrome 확장 프로그램은 claude.ai에만 삽입됩니다. Claude Desktop에는 PNG 옵션이 나타나지 않습니다. 같은 스레드가 claude.ai에 있다면 Chrome에서 여십시오.

PNG 내보내기도 Markdown과 같은 사용량을 쓰나요?

네. 완성된 PNG 하나는 .md나 JSON 파일 하나와 같이 1회입니다. 무료 내보내기 3회는 형식마다 3회가 아닙니다. Pro는 PNG를 포함한 모든 형식의 제한을 없앱니다.
