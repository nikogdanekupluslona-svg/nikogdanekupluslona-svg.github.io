Claude 채팅을 PDF 파일 하나로 받으려면?

"Export"를 한 번 클릭하면 첫 프롬프트부터 마지막 답변까지 Claude 채팅 전체가 담긴 PDF 파일 하나가 나옵니다. Claude 채팅을 PDF 형태로 클립보드에 복사할 수는 없지만("Copy"(복사)는 Markdown, 텍스트, JSON, XML, CSV만 지원), 내보낸 파일 자체가 이미 PDF 하나입니다.

채팅의 일부만 PDF 하나에 담으려면 "Select"(선택)를 쓰십시오. 내보내기 패널에서 "Select"를 클릭하고 원하는 메시지를 체크한 뒤 PDF를 고르고 "Export"를 클릭합니다. PDF에는 그 메시지만 순서대로 담깁니다. "Messages" 필터는 한쪽 발화에 대해 같은 일을 합니다. "Assistant"는 Claude의 답변만, "Human"은 사용자의 프롬프트만 남깁니다.

Markdown에서 Claude 채팅을 PDF로 변환하려면?

먼저 텍스트를 고치고 싶다면 Markdown을 거쳐 Claude 채팅을 PDF로 변환하십시오. 채팅을 Markdown으로 내보내고(무제한, 계정 불필요), .md 파일을 VS Code, Obsidian, Typora 같은 편집기에서 열어 다듬은 뒤, 그 편집기의 인쇄 또는 PDF로 내보내기 기능을 씁니다.

  1. claude.ai에서 주황색 버튼을 누르고 Markdown을 고른 뒤 "Export"를 클릭합니다. 로그인도, 횟수 제한도 없습니다.
  2. 편집기에서 파일을 엽니다. 메시지를 덜어 내고, 제목을 고치고, 메모를 덧붙입니다.
  3. 편집기의 PDF로 내보내기 또는 인쇄 → PDF로 저장을 원하는 템플릿과 글꼴로 실행합니다.

Markdown은 일반 텍스트로도 읽기 쉬워서 중간 단계로 알맞습니다. Markdown을 만든 John Gruber는 “Markdown은 가능한 한 읽기 쉽고 쓰기 쉽게 만들어졌다.”라고 썼습니다. 마크업과 씨름하지 않고 Claude 채팅을 Markdown에서 고친 뒤 한 번에 조판하면 됩니다.

대신 도구를 하나가 아니라 두 개 써야 합니다. 고칠 것이 없다면 확장 프로그램의 PDF가 더 빠르고, 페이지 번호와 목차도 이미 들어 있습니다. Markdown은 하루 PDF 한도에도 전혀 영향을 주지 않아 무료 플랜에서 유용합니다. 형식에 대해 더 알아보기: Markdown 내보내기.

Anthropic의 계정 내보내기는 변환의 출발점으로 알맞지 않습니다. 계정 전체의 JSON ZIP이라, 먼저 대화 하나를 꺼내고 JSON을 읽을 수 있는 텍스트로 바꿔야 합니다. 열려 있는 채팅에서 Markdown을 내보내면 이 과정을 모두 건너뜁니다.

FAQ: Claude 채팅 PDF 내보내기

Claude 채팅을 PDF로 내보내려면 어떻게 하나요?

Download Claude conversations를 설치하고, claude.ai에서 채팅을 연 뒤 메시지 입력창 옆의 주황색 버튼을 누르고 PDF를 골라 "Export"를 클릭하십시오. 처음 한 번은 Google로 로그인하고, 용지 크기와 다른 옵션을 설정한 뒤 저장합니다. PDF는 브라우저에서 만들어집니다.

Claude 채팅을 무료로 PDF 저장하려면?

확장 프로그램의 PDF 내보내기는 Google 로그인 후 하루 3개 PDF까지 무료입니다. Chrome의 인쇄 대화 상자(Ctrl+P 또는 Cmd+P → PDF로 저장)는 제한 없이 무료지만 웹 페이지 스냅샷이 나옵니다. Markdown으로 내보내 편집기에서 변환하는 방법도 무료이고 무제한입니다.

Claude 채팅을 PDF로 다운로드하려면?

여기서는 다운로드와 내보내기가 같은 작업입니다. 내보내기 패널에서 PDF를 고르면 Chrome이 다른 다운로드처럼 파일을 저장합니다. 인쇄와 내보낸 파일을 나란히 비교한 내용은 Claude 채팅 PDF 저장을 참고하십시오.

Claude 채팅을 PDF 하나로 복사할 수 있나요?

클립보드로는 안 됩니다. "Copy"는 Markdown, 텍스트, JSON, XML, CSV를 지원하며 PDF는 지원하지 않습니다. 대신 "Export"를 클릭하십시오. 한 번 내보내면 채팅 전체가 담긴 PDF 파일 하나가 나옵니다. 일부 메시지만 넣으려면 내보내기 전에 "Select"를 쓰십시오.

Claude의 답변만 PDF로 내보낼 수 있나요?

네. 내보내기 패널에서 "Messages"를 "Assistant"로 정하고 PDF를 고른 뒤 "Export"를 클릭하십시오. 그러면 PDF에는 프롬프트 없이 Claude의 답변만 담깁니다. "Human"은 그 반대입니다.

Claude 채팅 PDF에 코드 블록과 표가 유지되나요?

네, 내보내기를 쓰면 유지됩니다. 코드 블록은 언어 표시와 서식을 유지하고, 표와 목록도 깨지지 않습니다. 약한 쪽은 인쇄입니다. 코드 블록이 줄바꿈되거나 페이지 사이에서 잘리고, 넓은 표는 잘려 나갑니다.

Claude 채팅을 다크 모드 PDF로 내보낼 수 있나요?

네. PDF 대화 상자에 라이트 모드와 다크 모드가 있습니다. 다크는 화면으로 읽기에, 라이트는 종이에 인쇄하기에 알맞습니다.

휴대폰에서 Claude 채팅을 PDF로 변환할 수 있나요?

확장 프로그램으로는 안 됩니다. 확장 프로그램은 데스크톱 Chrome과 Chromium 브라우저에서만 작동합니다. 모바일 브라우저로도 페이지를 인쇄하거나 PDF로 공유할 수 있지만 레이아웃이 비좁습니다. 깔끔한 PDF가 필요하면 같은 채팅을 데스크톱 Chrome에서 여십시오.

Claude Code 세션을 PDF로 내보낼 수 있나요?

웹용 Claude Code(claude.ai/code)는 claude.ai에서 열리므로 확장 프로그램이 일반 채팅처럼 PDF로 내보냅니다. 터미널 세션은 웹 페이지가 아닙니다. 터미널에서 /export를 쓰고 편집기에서 텍스트 파일을 인쇄하십시오.

PDF로 내보낼 때 Claude 채팅이 업로드되나요?

아니요. PDF도 다른 모든 형식처럼 브라우저에서 생성됩니다. 로그인한 뒤에는 하루 한도나 Pro를 확인하기 위해 Google 계정 이메일만 전송됩니다.

Claude 채팅 PDF 대신 Markdown 파일이 나온 이유는?

내보내기 패널은 마지막에 쓴 형식을 기억합니다. "Export"를 클릭하기 전에 "Format"을 PDF로 정하십시오. 무료 플랜에서는 PDF 하나하나가 하루 3회에 포함되므로 먼저 확인하십시오.
