Claude 채팅 다운로더: Claude 대화 내보내기

Claude 대화를 Markdown, JSON, 텍스트, XML, PNG로 저장

Claude(클로드) 대화 내보내기 기능은 Claude.ai에 따로 없습니다. 채팅 하나를 다운로드하는 기본 버튼이 없기 때문입니다. Download Claude conversations는 Claude Chat Downloader 또는 Claude Conversation Downloader라고도 불리는 무료 Chrome 확장 프로그램으로, 열어 둔 채팅이나 전체 대화 기록을 Markdown, JSON, 일반 텍스트, XML, PNG로 저장합니다. 파일은 브라우저 안에서 만들어집니다. Claude 채팅 다운로드 방법을 확인하세요. 터미널을 쓰고 계신가요? 그 경우는 이 확장 프로그램이 아니라 Claude Code 내보내기입니다.

Claude 채팅 다운로드를 위한 6가지 핵심 기능

01

Markdown, JSON, XML, 텍스트 & PNG 내보내기

Claude 채팅을 웹페이지 스크린샷이 아닌 진짜 파일로 다운로드하세요. 메모용 Markdown, 개발자용 JSON, 가장 단순한 보관용 일반 텍스트, 데이터 교환용 XML, 시각적 스냅샷용 PNG를 제공합니다.

02

Claude 채팅 일괄 다운로드

View and Download All Conversations(모든 대화 보기 및 다운로드)를 열면 대화 기록 목록이 표시됩니다. 이름으로 검색하고 프로젝트로 필터링한 뒤 Export All(모두 내보내기)을 누르세요. 탭을 하나씩 여는 대신 한 번에 끝납니다.

03

코드, 표, 아티팩트 유지

내보내기 엔진이 메시지 트리를 분석하므로 코드 블록은 들여쓰기를 유지하고, 표는 표 그대로 남으며, 아티팩트는 Original, Inline, Nested, Flat 중에서 배치를 고를 수 있습니다.

04

사고 과정 블록과 메타데이터(선택)

검토 기록이 필요하면 Claude의 확장 사고(extended thinking)를 포함하고, 필요 없으면 제외하세요. 제목, 타임스탬프, 모델 메타데이터도 같은 파일에 함께 담을 수 있습니다.

05

내보내기 전에 검색과 필터

새 채팅, 이미 내보낸 채팅, 특정 Claude 프로젝트로 목록을 좁힌 다음 선택한 항목만 내보내세요.

06

브라우저 안에서 로컬로 생성

대화 내용은 사용자 기기에서 파일로 조립되어 디스크에 다운로드됩니다. Google 로그인은 무료 내보내기 횟수 확인에만 쓰이며, 채팅 텍스트를 저희 서버로 올리는 데 쓰이지 않습니다.

자주 묻는 질문

claude.ai에서 Claude 대화를 다운로드할 수 있나요?

기본 버튼으로는 할 수 없습니다. Chrome Web Store에서 Download Claude conversations를 설치하고, 채팅을 연 다음 파일로 내보내세요.

Claude의 데이터 내보내기(Export data)와 같은 기능인가요?

아닙니다. Anthropic의 Settings → Privacy → Export data(claude.ai를 한국어로 설정했다면 메뉴 이름이 한국어로 표시될 수 있습니다)는 계정 전체를 담은 ZIP 파일(JSON)을 이메일로 보내 줍니다. 이 확장 프로그램은 지금 열어 둔 채팅이나 일괄 선택한 채팅을 읽기 쉬운 파일로 바로 다운로드합니다.

제 Claude 채팅을 저장하나요?

내보내기는 브라우저 안에서 실행됩니다. 저희는 대화 내용을 받지 않습니다. 무료 내보내기 횟수를 세고 Pro 구독을 연결하기 위해 Google로 인증된 이메일 주소만 저장합니다.

‘Claude 대화 내보내기’와 ‘클로드 대화 저장’은 다른 건가요?

같은 작업을 다르게 부르는 말일 뿐입니다. 영어로 “download Claude chat”이라고 검색하는 분도 많습니다. 어느 쪽이든 claude.ai의 주황색 버튼을 사용하면 됩니다.

PDF로 내보낼 수 있나요?

아니요. 현재 지원 형식은 Markdown, JSON, 일반 텍스트, XML, PNG입니다. 간단한 PDF가 필요하면 페이지를 인쇄(Ctrl/Cmd+P → PDF로 저장)하거나, Markdown으로 내보낸 뒤 변환하세요. 자세한 방법: Claude 채팅을 PDF로 저장하기.

Claude Pro / Team에서도 작동하나요?

네, claude.ai 브라우저 화면에서 대화를 열 수 있다면 작동합니다. 저희는 Anthropic이 아닙니다.

Claude 대화는 어떻게 저장하나요?

무료 Chrome 확장 프로그램을 설치하고, claude.ai에서 채팅을 연 다음, 주황색 버튼을 누르고 형식을 고르세요. 이것이 Claude 대화를 실제 파일로 저장하는 방법입니다. 그 밖의 방법으로는 PDF 인쇄와 Anthropic의 계정 ZIP이 있으며, Claude 채팅 다운로드 방법에서 비교해 두었습니다.

Claude Code 대화도 다운로드되나요?

아니요. 이 확장 프로그램은 Chrome의 claude.ai에서만 작동합니다. Claude Code 세션은 /export 명령이나 디스크에 저장된 JSONL 파일을 사용합니다. Claude Code 내보내기를 참고하세요.

Download Claude conversations는 Anthropic과 관련이 있나요?

아니요. Claude는 Anthropic, PBC의 상표입니다. 이 제품은 Anthropic 공식 제품이 아닌 독립 Chrome 확장 프로그램입니다.
