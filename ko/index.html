Claude 채팅 다운로드를 위한 6가지 핵심 기능

01

PDF, Markdown, JSON, CSV 등으로 내보내기

Claude 채팅을 웹페이지 스크린샷이 아닌 진짜 파일로 다운로드하세요. 읽고 공유하기 좋은 PDF, 메모용 Markdown, 개발자용 JSON, 스프레드시트용 CSV, 가장 단순한 보관용 일반 텍스트, 데이터 교환용 XML, 시각적 스냅샷용 PNG를 제공합니다. Copy(복사)를 누르면 결과를 클립보드에 바로 담을 수도 있습니다.

02

Claude 채팅 일괄 다운로드

View and Download All Conversations를 열면 대화 기록 목록이 표시됩니다. 이름으로 검색하고 프로젝트나 Cowork로 필터링한 뒤 Export All(모두 내보내기)을 누르세요. 탭을 하나씩 여는 대신 ZIP 파일 하나로 받습니다. 무료 요금제에서는 하루 3개 채팅까지, Pro에서는 무제한입니다.

03

코드, 표, 아티팩트 유지

내보내기 엔진이 메시지 트리를 분석하므로 코드 블록은 들여쓰기를 유지하고, 표는 표 그대로 남으며, 아티팩트는 Original, Inline, Nested, Flat 중에서 배치를 고를 수 있습니다.

04

파일에 담을 내용 선택

대화 전체, 내 프롬프트만, Claude의 답변만, 또는 Select(선택)로 체크한 메시지만 내보낼 수 있습니다. 검토 기록이 필요하면 확장 사고(extended thinking)를 포함하고, 필요 없으면 제외하세요. 제목, 타임스탬프, 모델 메타데이터도 같은 파일에 함께 담을 수 있습니다.

05

내보내기 전에 검색과 필터

새 채팅, 이미 내보낸 채팅, 특정 Claude 프로젝트로 목록을 좁힌 다음 선택한 항목만 내보내세요.

06

브라우저 안에서 로컬로 생성

PDF를 포함한 모든 파일은 사용자 기기에서 만들어져 디스크에 다운로드됩니다. 대부분의 내보내기에는 계정이 필요 없습니다. Google 로그인은 PDF와 일괄 내보내기 횟수를 세고 Pro 구독을 연결하는 데만 쓰이며, 채팅 텍스트를 저희 서버로 올리지 않습니다.

Claude 채팅은 어떤 형식으로 다운로드해야 할까요?

PDF

읽기, 인쇄, 전달

원하는 페이지 크기, 라이트 또는 다크 테마, 글꼴, 목차를 적용한 페이지 단위 파일입니다.

 Markdown

Obsidian이나 Notion 메모

제목, 코드 블록, 표를 메모 보관함이나 문서 저장소에 깔끔하게 붙여 넣을 수 있습니다.

 JSON

스크립트, 데이터셋, RAG

역할과 메타데이터가 담긴 구조화된 메시지로, 코드에서 바로 읽을 수 있습니다.

 일반 텍스트

간단한 보관용

어디서나 열리고 검색이 빠르며, 도구가 바뀌어도 깨지지 않습니다.

 CSV

스프레드시트와 검토

메시지 하나가 한 행이 되어 Excel, Google Sheets, Numbers에서 열 수 있습니다.

 XML

다른 시스템으로 가져오기

XML을 요구하는 파이프라인과 도구를 위해 태그가 붙은 메시지입니다.

 PNG

시각적 스냅샷 공유

슬라이드, 티켓, 메시지에 넣을 수 있는 대화 이미지 한 장입니다.

자주 묻는 질문

claude.ai에서 Claude 대화를 다운로드할 수 있나요?

기본 버튼으로는 할 수 없습니다. Chrome Web Store에서 Download Claude conversations를 설치하고, 채팅을 연 다음 파일로 내보내세요.

Claude 채팅 다운로드는 무료인가요?

네. Markdown, 일반 텍스트, JSON, XML, CSV, PNG 내보내기는 무제한이며 계정이 필요 없습니다. PDF와 일괄 ZIP 내보내기는 Google 로그인이 필요하며 하루 3회까지 무료입니다. 월 $3.99 또는 연 $26.99인 Pro를 이용하면 이 제한이 없어집니다.

어떤 브라우저에서 작동하나요?

데스크톱 Chrome과, Chrome Web Store에서 확장 프로그램을 설치할 수 있는 Chromium 기반 브라우저에서 작동합니다. 모바일 앱은 없으며, Claude Desktop 앱 안에서는 작동하지 않습니다.

Pro는 어떻게 해지하고, 환불받을 수 있나요?

확장 프로그램 옵션 페이지의 “Cancel subscription”(구독 취소) 또는 Paddle에서 언제든 해지할 수 있습니다. 첫 결제에는 14일 환불 보장이 적용되며, 이유는 묻지 않습니다.

Claude의 데이터 내보내기(Export data)와 같은 기능인가요?

아닙니다. Anthropic의 Settings → Privacy → Export data(claude.ai를 한국어로 설정했다면 메뉴 이름이 한국어로 표시될 수 있습니다)는 계정 전체를 담은 ZIP 파일(JSON)을 이메일로 보내 줍니다. 이 확장 프로그램은 지금 열어 둔 채팅이나 일괄 선택한 채팅을 읽기 쉬운 파일로 바로 다운로드합니다.

제 Claude 채팅을 저장하나요?

아니요. PDF를 포함한 모든 형식은 브라우저 안에서 만들어지며, 대화 내용은 저희 서버에 전달되지 않습니다. PDF, 일괄 내보내기, Pro를 위해 Google로 로그인하면 하루 사용량을 세고 구독을 연결하는 용도로만 그 이메일 주소를 저장합니다.

‘Claude 대화 내보내기’와 ‘클로드 대화 저장’은 다른 건가요?

같은 작업을 다르게 부르는 말일 뿐입니다. 영어로 “download Claude chat”이라고 검색하는 분도 많습니다. 어느 쪽이든 claude.ai의 주황색 버튼을 사용하면 됩니다.

PDF로 내보낼 수 있나요?

네. 내보내기 패널에서 PDF를 고르고 페이지 크기, 여백, 라이트 또는 다크 모드, 글꼴, 페이지 번호, 목차를 설정하세요. PDF는 Google 로그인이 필요하며, 무료 요금제에서는 PDF 또는 일괄 내보내기를 하루 3회까지, Pro에서는 무제한으로 쓸 수 있습니다. 자세한 방법: Claude 채팅을 PDF로 저장하기.

Claude Pro / Team에서도 작동하나요?

네, claude.ai 브라우저 화면에서 대화를 열 수 있다면 작동합니다. 저희는 Anthropic이 아닙니다.

Claude 대화는 어떻게 저장하나요?

무료 Chrome 확장 프로그램을 설치하고, claude.ai에서 채팅을 연 다음, 주황색 버튼을 누르고 형식을 골라 Export를 클릭하세요. Markdown, 텍스트, JSON, XML, CSV, PNG는 계정이 필요 없습니다. 이것이 Claude 대화를 실제 파일로 저장하는 방법입니다. 그 밖의 방법으로는 페이지 인쇄와 Anthropic의 계정 ZIP이 있으며, Claude 채팅 다운로드 방법에서 비교해 두었습니다.

Claude Code 대화도 다운로드되나요?

claude.ai에 있는 대화만 가능합니다. 웹용 Claude Code(claude.ai/code)와 Cowork 세션은 일반 채팅처럼 내보낼 수 있습니다. 로컬 터미널 세션은 확장 프로그램이 읽지 않으며, /export 명령이나 디스크에 저장된 JSONL 파일을 사용합니다. Claude Code 내보내기를 참고하세요.

Download Claude conversations는 Anthropic과 관련이 있나요?

아니요. Claude는 Anthropic, PBC의 상표입니다. 이 제품은 Anthropic 공식 제품이 아닌 독립 Chrome 확장 프로그램입니다.
