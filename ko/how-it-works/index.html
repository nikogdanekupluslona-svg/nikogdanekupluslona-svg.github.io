claude.ai에서 Download Claude conversations는 어떻게 작동하나요?

claude.ai에서의 작동 방식: 확장 프로그램이 사용자가 이미 연 페이지에, 이미 로그인한 세션으로 콘텐츠 스크립트를 삽입합니다. 별도의 Anthropic API가 아니라 렌더링된 대화를 읽습니다. 주황색 버튼은 실제 대화 URL에서만 나타납니다.

  1. Chrome Web Store에서 Download Claude conversations를 설치합니다(평점 5.0).
  2. 설치하는 동안 탭이 열려 있었다면 claude.ai를 새로 고칩니다.
  3. 대화 URL을 엽니다. 주황색 버튼은 메시지 입력창 오른쪽에 있습니다.
  4. Markdown, JSON, 일반 텍스트, XML, PNG 중 하나를 고르고 "Export"(내보내기)를 누릅니다.
  5. Chrome이 파일을 다운로드합니다. 브라우저 쪽 과정은 이것이 전부입니다.

빈 입력 화면에는 메시지 트리가 없으므로 버튼이 나타나지 않습니다. 아이콘이 숨어 있다면 Chrome 퍼즐 메뉴에서 확장 프로그램을 고정한 뒤 claude.ai를 새로 고치십시오. Download Claude conversations는 claude.ai에서만 작동합니다. Claude Desktop과 Claude Code에는 이 스크립트가 들어가지 않습니다. 기능 목록: Chrome 확장 프로그램 기능.

같은 세션, 같은 페이지. 콘텐츠 스크립트는 로그인한 claude.ai 탭에 이미 보이는 내용을 봅니다. 두 번째 비밀번호로 Anthropic에 로그인하지 않습니다. 계정에 대해서는 Anthropic의 규칙을 따르십시오.

파일은 로컬에서 만들어지나요?

네. Markdown, JSON, 일반 텍스트, XML, PNG는 브라우저 안에서 만들어져 Chrome의 다운로드 API로 넘겨집니다. 대화 텍스트는 기기를 떠나 저희 인프라로 가지 않습니다. 주황색 버튼으로 한 번 내보낼 때도, 일괄 페이지의 Export All도 마찬가지입니다.

claude.ai가 스레드를 불러온 뒤에는 파일 생성이 저희 서버를 기다리지 않습니다. 사용량과 라이선스 확인은 별도의 요청입니다. Chrome이 claude.ai의 다운로드를 막는다면 허용하십시오. 이는 브라우저 설정이지 분석 실패가 아닙니다. 긴 스레드를 절반만 스크롤했다면 DOM이 불완전하므로 파일도 절반만 만들어집니다.

저희는 분명한 원칙에 따라 Download Claude conversations를 설계했습니다: 채팅 본문은 탭 안에 남고, 저희 서버는 "무료 내보내기가 몇 회 남았는가"와 "이 Google 계정이 Pro인가"에만 답합니다. Markdown, JSON, 텍스트, XML, PNG를 만들기 위해 스레드를 업로드하지 않으며, PDF도 여전히 만들지 않습니다.

사용량 확인에 왜 Google 로그인을 쓰나요?

Google 로그인은 계정당 무료 내보내기 3회를 집계하고 다시 설치한 뒤 Pro를 복원하기 위해 있습니다. 첫 "Export" 클릭부터 필요합니다. 저희는 인증된 이메일을 저장하며, 채팅 텍스트는 저장하지 않습니다.

확장 프로그램을 제거했다가 다시 추가해도 무료 내보내기 3회는 초기화되지 않습니다. 그래서 로그인은 선택 사항이 아닙니다. 로그인이 없다면 다시 설치할 때마다 파일 3개가 슬그머니 새로 생길 것입니다. Pro(월 $3.99 또는 연 $26.99)는 새 컴퓨터에서도 같은 Google 계정으로 복원됩니다.

Google 로그인은 claude.ai 로그인이 아닙니다. 웹사이트에서는 여전히 Anthropic 세션을 씁니다. Download Claude conversations는 사용량을 식별하는 데만 Google을 씁니다. 같은 확장 프로그램을 Claude Chat Downloader라는 이름으로 찾는 분들도 있으며, 로그인 규칙은 똑같습니다.

사용량은 계정 단위입니다. 무료 내보내기는 형식에 상관없이, 일괄 Export All을 포함해 총 3회입니다. 대화 40개를 선택하면 모든 파일이 완성될 경우 40회를 씁니다. 로그인 덕분에 다시 설치해도 이 횟수가 유지됩니다.

Paddle과 Pro 결제는 어떻게 이루어지나요?

Paddle.com Market Limited가 결제 처리자이자 판매 대행자(merchant of record)입니다. 결제 과정: Paddle이 카드 정보와 세금을 처리합니다. 저희는 결제 정보를 보지 않습니다. Pro는 월 $3.99 또는 연 $26.99입니다. 환불도 Paddle을 통해 처리됩니다.

Pro는 주황색 버튼과 Export All의 3회 제한을 없앱니다. PDF, Notion, Word가 추가되지는 않습니다. 형식은 Markdown, JSON, 텍스트, XML, PNG 그대로입니다. Anthropic의 유료 claude.ai 요금제는 필요 없습니다. Chrome에서 스레드를 불러올 수 있는 claude.ai 로그인이면 충분합니다.

이 서버 덕분에 다시 설치해도 무료 내보내기 3회가 초기화되지 않고, Pro도 복원됩니다. 채팅 백업은 아닙니다. claude.ai 기록은 여전히 Anthropic 쪽에 있습니다. 저희는 두 번째 사본을 보관하지 않습니다. 저장하는 이메일에 대해서는 이 사이트의 개인정보처리방침에 설명되어 있습니다.
