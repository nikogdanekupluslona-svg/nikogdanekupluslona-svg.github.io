Čo je export konverzácie Claude Code v termináli?

Export konverzácie Claude Code je príkaz /export v interaktívnej relácii príkazového riadku. Dokumentácia Anthropic opisuje ponuku, ktorá aktuálnu konverzáciu skopíruje alebo uloží ako súbor s čistým textom, pričom správy a výstupy nástrojov sú vykreslené ako čitateľný text. Ak zadáte názov súboru, ponuka sa preskočí a zapíše sa priamo tento súbor.

Nie je to Markdown z claude.ai, nie je to JSON z tohto rozšírenia pre Chrome a nie je to PDF. Je to vykreslený prepis na čítanie. Anthropic uvádza, že denník JSONL na disku je iný, interný formát určený pre produkt, nie vaše verejné API.

/export

Ak chcete preskočiť výzvu a zapísať pomenovaný súbor do aktuálneho pracovného priečinka:

/export my-session

Pre prepínače a názvy súborov je smerodajná dokumentácia relácií od Anthropic; medzi verziami Claude Code sa menia. Komunitné blogy berte ako druhotný zdroj. Ak sa text dialógu /export nezhoduje s tým, čo vidíte, máte inú verziu CLI – použite pomocníka v produkte, nie snímku obrazovky z roku 2025.

Pre skripty Anthropic odkazuje na iné rozhrania: claude -p s --output-format json alebo stream-json, obnovenie podľa ID relácie, hooky, ktoré dostanú transcript_path, alebo Agent SDK. To sú vývojárske rozhrania Claude Code. Nie sú to funkcie rozšírenia pre Chrome z tohto webu.

Čitateľné verzus štruktúrované. /export je prepis pre človeka. JSONL v priečinku projektov je denník. JSON z rozšírenia pre Chrome je tretia štruktúra, vytvorená iba zo stránky claude.ai. Nepíšte jeden parser pre všetky tri.

Ako stiahnuť konverzáciu Claude Code z disku?

Konverzáciu Claude Code z disku stiahnete tak, že skopírujete súbor JSONL relácie z priečinka projektov, alebo spustíte /export pre čitateľný prepis. Predvolená cesta na macOS a Linuxe je v ~/.claude/projects/. Na Windows je to %USERPROFILE%\.claude\projects. Názvy súborov sú ID relácií.

Názov priečinka projektu je pracovný priečinok, v ktorom sú znaky okrem písmen a číslic nahradené pomlčkami. Veľmi dlhé prevedené názvy Anthropic skráti a pridá hash, aby priečinok neprekročil limity súborového systému. Ak priečinok nenájdete, spustili ste Claude Code z iného pracovného priečinka, než si myslíte.

Každý riadok JSONL je objekt JSON pre správu, použitie nástroja alebo metadáta. Anthropic uvádza, že formát týchto záznamov je interný a medzi verziami sa mení. Skripty, ktoré tieto súbory spracúvajú, sa môžu s novou verziou Claude Code pokaziť. Keď potrebujete niečo stabilné, uprednostnite /export alebo zdokumentované skriptové rozhrania.

Úložisko sa dá presunúť. CLAUDE_CONFIG_DIR presunie konfiguračný strom mimo ~/.claude. CLAUDE_CODE_PROJECT_DIR_NAME pomenuje priečinok projektu, ak sa použije spolu s týmto konfiguračným priečinkom (Claude Code v2.1.234 alebo novší, podľa Anthropic). cleanupPeriodDays v settings.json mení predvolenú dobu uchovávania. Žiadne z týchto nastavení nie je funkciou Download Claude conversations.

Záloha konverzácií Claude Code teda znamená: skopírovať priečinok alebo pravidelne exportovať prepisy cez /export. Tento web nepridá tlačidlo „importovať JSONL“. Váš domovský priečinok nečítame.

Funguje export z Claude Code s týmto rozšírením?

Pre relácie v termináli nie. Download Claude conversations nečíta lokálne relácie Claude Code. Rozšírenie pre Chrome sa načítava do claude.ai. Nevidí terminál, nevie spustiť /export a nevie otvoriť JSONL. Výnimkou je Claude Code on the web na claude.ai/code: je to stránka claude.ai, takže sa exportuje ako každý chat. Ak ste hľadali, ako stiahnuť konverzáciu Claude Code z príkazového riadku, držte sa krokov pre CLI na tejto stránke.

Ľudia sem prichádzajú, pretože Google spája slová „Claude“ a „export“. Záznam v Chrome Web Store je však stále iba pre claude.ai. Inštalácia rozšírenia nepridá oranžové tlačidlo do iTerm, Ghostty, terminálu vo VS Code ani do desktopového obalu Claude Code.

Ak si k tej istej programátorskej úlohe vediete aj paralelnú konverzáciu na claude.ai, tento chat v prehliadači sa dá rozšírením uložiť. Tieto dva záznamy sa nespájajú. Volania nástrojov, ktoré prebehli iba v CLI, sa vo webovom exporte neobjavia, pokiaľ ste ich tam nevložili.

Každý týždeň dostávame rovnakú otázku na podporu: niekto nainštaloval rozšírenie pre Chrome a čakal, že sa objaví /export. Spracúvame iba claude.ai. Claude Code už /export aj JSONL má. Obal pre CLI by bol iný produkt a ten sme nevydali.

Dajú sa exportovať relácie Claude Code on the web?

Áno. Claude Code on the web beží na claude.ai/code, takže Download Claude conversations exportuje tieto relácie ako každý chat na claude.ai. Otvorte reláciu v Chrome, kliknite na oranžové tlačidlo, vyberte formát a kliknite na „Export“ (Exportovať). Toto je jediné prostredie Claude Code, ktoré rozšírenie pokrýva.

Formáty sú tých istých sedem ako pri každom chate: PDF, Markdown, čistý text, JSON, XML, CSV a PNG. Markdown, text, JSON, XML, CSV a PNG sú neobmedzené a bez účtu. PDF vyžaduje prihlásenie cez Google a na bezplatnom pláne zdieľa 3 denne s hromadným ZIP-om, pokiaľ nemáte Pro. Bloky kódu si zachovajú označenie jazyka. Rozšírené uvažovanie je políčko „Thinking“ (uvažovanie) v paneli; kroky nástrojov / MCP a zdroje z webového vyhľadávania sa zapínajú v nastaveniach.

Webový export je to, čo claude.ai/code zobrazuje v prehliadači. Nie je to denník JSONL z lokálneho behu CLI a nedosiahne na relácie, ktoré bežali iba vo vašom termináli. Podľa Anthropic má Claude Code on the web vlastnú históriu relácií, oddelenú od stromu ~/.claude/projects v CLI. Pre reláciu v termináli je cestou stále /export.

Kde Claude Code ukladá históriu konverzácií?

Claude Code ukladá históriu konverzácií ako prepisy JSONL v priečinku projektov v konfiguračnom priečinku. Predvolene na macOS a Linuxe: ~/.claude/projects/<encoded-cwd>/<session-id>.jsonl. Windows používa %USERPROFILE%\.claude\projects. Anthropic môže toto usporiadanie zmeniť; ak cesta na disku chýba, pozrite si aktuálnu dokumentáciu relácií.

Obnovenie je iné sloveso než export. claude --continue a claude --resume reláciu znova načítajú, aby ste mohli pokračovať v práci. /export zapíše kópiu, ktorú môžete nechať v gite alebo poslať e-mailom. Jedno obnovuje kontext. Druhé vám dá záznam so sebou. Stránka Anthropic o reláciách opisuje režim oprávnení pri obnovení, zhrnutie (compact/summary) a správanie výberu – nič z toho nesúvisí s týmto rozšírením.

Aplikácia Desktop, Claude Code on the web a rozšírenie pre VS Code majú podľa Anthropic každé vlastnú históriu relácií. Cesty v tomto návode platia pre CLI. Webové relácie zostávajú na claude.ai/code, kde ich rozšírenie vie exportovať. Nepredpokladajte, že prepis Cowork z aplikácie Desktop leží v tom istom strome JSONL, ktorý používate z terminálu.

Neberte JSONL ako verejnú schému. Anthropic uvádza, že formát riadkov sa mení. Ak ho aj tak spracúvate, zafixujte verziu Claude Code a počítajte s tým, že sa niečo pokazí. /export je stabilný spôsob, ako získať čitateľnú konverzáciu Claude Code.

Premenné prostredia ako CLAUDE_CODE_SKIP_PROMPT_HISTORY môžu zápis prepisov potlačiť. Ak je priečinok projektov prázdny, overte, či ste nevypli ukladanie, nenasmerovali CLAUDE_CONFIG_DIR inam alebo či ste v danom priečinku vôbec spustili interaktívnu reláciu.

Ako namiesto toho stiahnuť chat Claude na claude.ai?

Chat Claude na claude.ai stiahnete takto: nainštalujte Download Claude conversations, otvorte konverzáciu v Chrome, kliknite na oranžové tlačidlo a vyberte PDF, Markdown, čistý text, JSON, XML, CSV alebo PNG. To je produkt pre prehliadač a pokrýva aj relácie na claude.ai/code. Nie je to export z Claude Code v termináli. Postup krok za krokom: ako stiahnuť chat Claude.

Celú históriu claude.ai ako samostatné súbory získate cez „Export All“ (Exportovať všetko) na Dashboarde, nie cez /export. Na bezplatnom pláne sa každý chat v ZIP-e počíta do 3 denne (spoločne s PDF, vynulovanie o polnoci UTC); Pro limit ruší. Návod: hromadný Export All. Formáty: formáty.

Na export jedného chatu do Markdown, textu, JSON, XML, CSV alebo PNG nepotrebujete účet – tieto exporty sú neobmedzené. Prihlásenie cez Google sa objaví iba pri PDF, hromadnom ZIP-e a Pro, aby sme vedeli počítať denný limit a obnoviť Pro. Súbory vznikajú lokálne, vrátane PDF. Paddle účtuje Pro za 3,99 USD mesačne alebo 26,99 USD ročne. Nič z toho sa netýka /export v termináli.

Ak práca začala v Claude Code a zhrnutie ste vložili do claude.ai, webovú konverzáciu si stiahnite na poznámky a /export si nechajte pre skutočný denník CLI. Dva súbory sú lepšie než jeden zmätený.

Export z Claude Code, alebo oficiálny Export data od Anthropic?

Export z Claude Code (/export alebo JSONL) je jedna relácia v termináli. Oficiálny Export data je Settings → Privacy → Export data na claude.ai (ak máte claude.ai v slovenčine, názvy môžu byť preložené): oneskorený ZIP s JSON účtu Anthropic. Nie je to ten istý archív. ZIP nenahradí /export.

Či sa konkrétna relácia Claude Code objaví v ZIP-e účtu, závisí od toho, ako Anthropic tento produkt ukladá, nie od tohto rozšírenia. ZIP berte ako zálohu webového účtu, pokiaľ aktuálna dokumentácia Anthropic o súkromí neuvádza inak. Relácie z CLI do tohto ZIP-u nepridávame.

Ako exportovať chat Claude z webu, vrátane porovnania tohto ZIP-u s rozšírením, popisuje návod ako exportovať chat Claude. Export do PDF z rozšírenia sa na rozhranie terminálu tiež nevzťahuje. Návod chat Claude do PDF použite iba vtedy, keď je konverzácia na claude.ai, vrátane claude.ai/code.

Export z Claude Code, Desktop a claude.ai?

Claude Code, Claude Desktop a claude.ai sú tri rôzne prostredia. Export z Claude Code používa /export a JSONL. Desktop je aplikácia bez oranžového tlačidla tohto rozšírenia. claude.ai v Chrome je jediné miesto, kde Download Claude conversations beží – vrátane Claude Code on the web na claude.ai/code. Keď sa tieto názvy zamieňajú, exporty potichu zlyhávajú.

Claude Desktop: ak sa chat synchronizoval do toho istého účtu Anthropic, otvorte ho na claude.ai a exportujte tam. Ak existuje iba v okne aplikácie Desktop, skopírujte ho alebo počkajte na oficiálny Export data. Návod: export chatu z Claude Desktop.

Panel Claude Code vo VS Code má bližšie k CLI než ku claude.ai. Nečakajte, že sa náš obsahový skript načíta do tohto webview. Použite /export z relácie, ktorá správy naozaj obsahuje.

Nezávislé rozšírenie pre Chrome, nijako neprepojené so spoločnosťou Anthropic, PBC. Claude je ochranná známka spoločnosti Anthropic. Dodržiavajte ich podmienky služby. Nemôžeme poskytovať právne rady o kopírovaní výstupov nástrojov, ktoré obsahujú proprietárny kód; to je vec medzi vami, vaším zamestnávateľom a Anthropic.

Časté otázky: export konverzácie Claude Code

Ako exportovať konverzáciu Claude Code?

V termináli Claude Code zadajte /export (voliteľne s názvom súboru) a uložíte vykreslený prepis, alebo skopírujte súbor JSONL z ~/.claude/projects na macOS/Linuxe či z %USERPROFILE%\.claude\projects na Windows. Aktuálny dialóg opisuje dokumentácia relácií od Anthropic.

Sťahuje toto rozšírenie pre Chrome chaty z Claude Code?

Z terminálu nie. Download Claude conversations funguje iba na claude.ai v Chrome. Nevie čítať lokálne relácie v termináli, prepisy JSONL ani príkaz /export. Relácie Claude Code on the web na claude.ai/code sa exportujú ako každý chat.

Dá sa exportovať Claude Code on the web (claude.ai/code)?

Áno. Otvorte reláciu na claude.ai/code v Chrome a použite oranžové tlačidlo. Fungujú PDF, Markdown, čistý text, JSON, XML, CSV aj PNG. Šesť formátov okrem PDF je neobmedzených a bez účtu; PDF vyžaduje prihlásenie cez Google a počíta sa do 3 bezplatných denne.

Kde Claude Code ukladá históriu konverzácií?

Prepisy relácií sú súbory JSONL v ~/.claude/projects/<encoded-working-directory>/, pomenované podľa ID relácie. Presné usporiadanie sa môže zmeniť. Keď chcete čitateľný súbor namiesto spracúvania JSONL, použite /export. CLAUDE_CONFIG_DIR môže strom presunúť.

Ako stiahnuť konverzáciu Claude Code ako Markdown?

/export v Claude Code je prepis v čistom texte, nie Markdown z tohto rozšírenia. Ak potrebujete práve Markdown, exportujte reláciu z claude.ai/code alebo kópiu práce na claude.ai cez Download Claude conversations, prípadne si text z /export preveďte sami. JSONL do Markdown neprevádzame.

Ako namiesto toho stiahnuť konverzáciu z claude.ai?

Nainštalujte bezplatné rozšírenie pre Chrome, otvorte chat na claude.ai a použite oranžové tlačidlo – alebo „Export All“ pre celú históriu. Pozrite ako stiahnuť chat Claude. Markdown, text, JSON, XML, CSV a PNG sú neobmedzené a bez účtu; PDF a hromadný ZIP sú zadarmo 3 denne s prihlásením cez Google; Pro stojí 3,99 USD mesačne alebo 26,99 USD ročne.

Je /export to isté ako oficiálny Export data?

Nie. /export je aktuálna relácia Claude Code. Settings → Privacy → Export data pošle e-mailom ZIP s JSON účtu Anthropic. Iné prostredia produktu, iné súbory, iné čakanie.

Môžem spracovať JSONL z Claude Code nástrojom jq?

Môžete, s výhradou, ktorú Anthropic zverejňuje: schéma riadkov je interná a môže sa zmeniť. Keď potrebujete pevný kontrakt, uprednostnite /export alebo claude -p --output-format json. Ak JSONL aj tak spracúvate, zafixujte verziu CLI.

Funguje export z Claude Code na Windows?

Áno. /export je príkaz CLI. Prepisy na disku sú v %USERPROFILE%\.claude\projects, pokiaľ nenastavíte CLAUDE_CONFIG_DIR. Toto rozšírenie pre Chrome v tomto termináli ani tak nebeží.

Je Claude Code to isté ako Claude Desktop?

Nie. Claude Code je programátorský agent v termináli. Claude Desktop je aplikácia na chat. claude.ai je webová stránka. Toto rozšírenie funguje iba na webe, vrátane claude.ai/code. Poznámky k exportu z aplikácie Desktop: Claude Desktop.

Bude toto rozšírenie niekedy obaľovať /export?

Vo verzii 1.16.2 nie. Rozsah produktu je claude.ai vrátane Claude Code on the web: sedem formátov, lokálne súbory, prihlásenie cez Google iba pre PDF, hromadný export a Pro. Ak sa rozsah zmení, táto stránka to uvedie. Dovtedy na export z Claude Code v termináli používajte CLI od Anthropic.

Obsahuje /export výstupy nástrojov?

Anthropic opisuje /export ako správy a výstupy nástrojov vykreslené ako čitateľný text. Je to ich prepis, nie náš parser. Presný aktuálny obsah zistíte, keď spustíte /export vo svojej verzii a prečítate súbor – dokumentácia môže za vydaním zaostávať.

Dajú sa relácie Claude Code exportovať hromadne?

Lokálne relácie CLI nie. „Export All“ na Dashboarde je iba pre claude.ai. Pre veľa relácií CLI skopírujte priečinok projektov alebo spustite /export pre každú reláciu. Hromadný export oranžovým tlačidlom pre JSONL neexistuje.
