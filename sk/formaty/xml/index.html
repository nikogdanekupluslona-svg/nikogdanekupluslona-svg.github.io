Ako exportovať chat Claude do XML?

Otvorte konverzáciu na claude.ai v Chrome, kliknite na oranžové tlačidlo vedľa poľa na správu, vyberte XML a kliknite na „Export“. Download Claude conversations zapíše súbor lokálne. Takto exportujete chat Claude do XML vo verzii 1.16.2. Samotné claude.ai v septembri 2026 nemá vlastné tlačidlo na uloženie ako XML.

  1. Nainštalujte Download Claude conversations z Chrome Web Store.
  2. Obnovte claude.ai a otvorte skutočnú adresu konverzácie, nie prázdnu úvodnú stránku s poľom na písanie.
  3. Kliknite na oranžové tlačidlo sťahovania vpravo od poľa na správu.
  4. Vyberte XML. Rozšírenie si pamätá posledný použitý formát. Cez „Select“ (Vybrať) označte len tie správy, ktoré chcete.
  5. Kliknite na „Export“. Chrome stiahne XML cez rozhranie sťahovania prehliadača. Alebo kliknite na „Copy“ (Kopírovať) a XML sa vloží do schránky.

Na export chatu Claude do XML sa nemusíte prihlasovať. Export jedného chatu do XML je neobmedzený, anonymný a na naše servery nič neposiela. Prihlásenie cez Google sa vyžaduje iba pri PDF a hromadnom „Export All“ (Exportovať všetko). Podrobnosti: ako to funguje.

Ak oranžové tlačidlo chýba, nie ste na adrese konverzácie, karta potrebuje obnoviť alebo je rozšírenie skryté v ponuke rozšírení Chrome (ikona puzzle). Pripnite Download Claude conversations a obnovte claude.ai. Export do XML sa nikdy neobjaví v Claude Desktop ani v termináli Claude Code.

Jeden súbor verzus veľa. Oranžové tlačidlo exportuje otvorenú konverzáciu do XML. Pre veľa súborov XML otvorte „View and Download All Conversations“ (Zobraziť a stiahnuť všetky konverzácie) a spustite „Export All“ so zvoleným XML: jeden ZIP, na bezplatnom pláne 3 chaty denne – pozrite hromadný Export All.

Kedy exportovať chat Claude do XML?

Exportujte chat Claude do XML, keď prijímajúci systém, dátový tok alebo starší nástroj vyžaduje na výmenu štruktúrovaných dát XML. Väčšina vývojárov by mala zvoliť radšej JSON. Markdown je na poznámky pre ľudí. CSV je pre tabuľkové procesory. PNG je obrázok. XML je v rozbaľovacom zozname preto, že niektoré nástroje stále prijímajú XML a JSON neakceptujú.

Neexportujte chat Claude do XML ako „oficiálnejší“ JSON. Download Claude conversations spracúva konverzáciu v oboch prípadoch rovnako. Rozdiel je v tvare súboru, nie v tom, že by sa zázračne objavili ďalšie polia. Ak nič, čo používate, XML nevyžaduje, tento formát preskočte a použite JSON.

XML ponúkame, pretože ho niektoré dátové toky stále vyžadujú, nie preto, že by sme ho pri každom exporte z claude.ai považovali za lepší ako JSON. Spracovanie je rovnaké: správy, odosielateľ, voliteľné uvažovanie a artefakty. Verzia 1.16.2 ponecháva XML ako jeden zo siedmich formátov, zadarmo a bez účtu, nie ako platený doplnok.

Čo export chatu Claude do XML zachová?

Pri exporte chatu Claude do XML zapíše Download Claude conversations štruktúru konverzácie – správy, odosielateľa a dostupné metadáta – ako značkovanie XML. Bloky uvažovania, zdroje z webového vyhľadávania, kroky nástrojov / MCP a artefakty sa riadia rovnakými možnosťami ako pri Markdown a JSON: „Thinking“ (uvažovanie) je zaškrtávacie políčko v paneli exportu, nástroje a zdroje sa zapínajú v nastaveniach. XML nie je okresaná verzia týchto formátov.

Rozloženie artefaktov je vo verzii 1.16.2 „Original“, „Inline“, „Nested“ alebo „Flat“ (pôvodné, vložené, vnorené, ploché). Filter odosielateľa obmedzí XML na všetky správy, len vaše alebo len odpovede asistenta. Pridať sa dajú aj metadáta (názov, časové údaje, model). XML, alebo JSON pri exporte chatu Claude?

JSON je bežná voľba vývojárov. Exportujte chat Claude do XML, len keď XML vyžaduje nadväzujúci systém. Download Claude conversations nerobí XML „úplnejším“ ako JSON. Oba môžu obsahovať uvažovanie aj artefakty. Ani jeden nie je ZIP účtu od Anthropic. Prehľad formátov: formáty exportu chatu Claude.

Príkaz /export v termináli Claude Code je úplne iná cesta.

Dá sa exportovať chat Claude do XML hromadne?

Áno. Otvorte „View and Download All Conversations“, v „Chat format“ (formát chatu) nastavte XML, vyfiltrujte tabuľku a kliknite na „Export All“. Chrome uloží jeden ZIP s jedným súborom XML na chat. Na bezplatnom pláne to sú 3 chaty denne s prihlásením cez Google, spoločne s PDF. Pro za 3,99 USD mesačne alebo 26,99 USD ročne tento limit pre hromadné XML ruší.

Dashboard zobrazuje históriu claude.ai s vyhľadávaním podľa názvu, filtrami „All conversations“, „New“, „Updated“ a „Previously exported“ (všetky, nové, aktualizované, už exportované), kartami „Chat“ a „Cowork“ a vyhľadávaním v projektoch. „New“ znamená, že chat ešte nebol exportovaný cez Download Claude conversations. „Previously exported“ sleduje už uložené chaty. „Export All“ je jeden ZIP so samostatnými súbormi XML pre každý chat, nie archív so zmiešanými formátmi.

Denný limit platí pre celý účet. Na bezplatnom pláne tri chaty denne, spoločne s PDF. Ak vyberiete 40 konverzácií a zostávajú vám 3, celá dávka sa zablokuje, neskráti sa. Vyberte menej alebo prejdite na Pro. Jednotlivé exporty do XML cez oranžové tlačidlo zostávajú neobmedzené.

XML a JSON nemôžete skombinovať v jednom kliknutí na „Export All“. Pre daný beh zvoľte XML. Ak potrebujete oba tvary tej istej konverzácie z claude.ai, spustite „Export All“ znova s JSON; druhý beh započíta každý chat znova.

Potrebuje export chatu Claude do XML Pro?

Nie. Export jedného chatu do XML je zadarmo a neobmedzený, bez účtu a bez počítadla – rovnako ako Markdown, JSON, text, CSV a PNG. Bezplatný limit majú iba PDF a hromadný „Export All“: 3 denne s prihlásením cez Google. Pro stojí 3,99 USD mesačne alebo 26,99 USD ročne cez Paddle. Download Claude conversations nepovažuje XML za platený formát.

Limit sa prejaví pri hromadnom XML. Každý chat v ZIP-e z „Export All“ spotrebuje jeden z 3 denne a počítadlo sa vynuluje o polnoci UTC. Pro limit ruší a na novom počítači sa obnoví z toho istého účtu Google. Predajcom je Paddle; tento tím čísla kariet nikdy nevidí.

Platený plán claude.ai od Anthropic nepotrebujete. Stačí prihlásenie, s ktorým sa konverzácia v Chrome načíta. Verzia 1.16.2 zo septembra 2026 stále nezapisuje do Wordu ani Notion. Ak sa tento zoznam zmení, táto stránka sa zmení v ten istý deň.

Je XML lepšie ako JSON na export chatov Claude?

Vo všeobecnosti nie. Pre vývojárov je JSON bežnejšia voľba. Exportujte chat Claude do XML, keď nadväzujúci systém vyžaduje XML na výmenu štruktúrovaných dát. Spracovanie z claude.ai je rovnaké; líši sa tvar súboru.

Dá sa exportovať chat Claude do XML hromadne?

Áno. Ten istý postup „Export All“ na Dashboarde podporuje XML a uloží jeden ZIP so súborom XML pre každý chat. Na bezplatnom pláne pokryje 3 chaty denne s prihlásením cez Google; Pro za 3,99 USD mesačne alebo 26,99 USD ročne je neobmedzený.

Je XML len platený formát?

Nie. Export jednotlivých chatov do XML je neobmedzený a bez účtu, rovnako ako Markdown, text, JSON, CSV a PNG. Bezplatný limit 3 denne majú iba PDF a hromadný „Export All“. Pro stojí 3,99 USD mesačne alebo 26,99 USD ročne.

Zodpovedá export chatu Claude do XML ZIP-u od Anthropic?

Nie. Export data od Anthropic je oneskorený ZIP s JSON celého účtu. Download Claude conversations zapíše súbor XML pre jeden chat (alebo výber správ) okamžite v Chrome. Nejde o rovnakú schému.

Vytvorí export chatu Claude do XML aj PDF?

Nie. XML je značkovanie. Na stránky zvoľte v tom istom paneli PDF; sedem formátov je PDF, Markdown, JSON, čistý text, XML, CSV a PNG. PDF vyžaduje prihlásenie cez Google a na bezplatnom pláne sa započítava do 3 denne.

Dá sa exportovať chat Claude do XML v Desktop?

Nie. Rozšírenie pre Chrome sa načítava iba na claude.ai. Claude Desktop rozbaľovací zoznam s XML nikdy nezobrazí. Otvorte tú istú konverzáciu na claude.ai v Chrome, ak tam existuje.

Nie. Nepotrebujete vôbec žiadny účet. Export jednotlivých chatov do XML je na bezplatnom pláne neobmedzený. Pro za 3,99 USD mesačne alebo 26,99 USD ročne ruší iba limit 3 denne pri hromadnom „Export All“ a PDF.
