Ako exportovať konverzáciu Claude do JSON?

Otvorte konverzáciu na claude.ai v Chrome, kliknite na oranžové tlačidlo vedľa poľa na správu, vyberte JSON a kliknite na „Export“. Download Claude conversations zapíše súbor lokálne. Takto exportujete konverzáciu Claude do JSON vo verzii 1.16.2. Samotné claude.ai v septembri 2026 nemá tlačidlo na uloženie jedného chatu ako JSON.

  1. Nainštalujte Download Claude conversations z Chrome Web Store.
  2. Obnovte claude.ai a otvorte skutočnú adresu konverzácie, nie prázdnu úvodnú stránku s poľom na písanie.
  3. Kliknite na oranžové tlačidlo sťahovania vpravo od poľa na správu.
  4. Vyberte JSON. Rozšírenie si pamätá posledný použitý formát. Cez „Select“ (Vybrať) označte len tie správy, ktoré chcete.
  5. Kliknite na „Export“. Chrome stiahne JSON cez rozhranie sťahovania prehliadača. Alebo kliknite na „Copy“ (Kopírovať) a JSON sa vloží do schránky.

Na export konverzácie Claude do JSON sa nemusíte prihlasovať. Export jedného chatu do JSON je neobmedzený, anonymný a na naše servery nič neposiela. Prihlásenie cez Google sa vyžaduje iba pri PDF a hromadnom „Export All“ (Exportovať všetko). Podrobnosti: ako to funguje.

Ak oranžové tlačidlo chýba, nie ste na adrese konverzácie, karta potrebuje obnoviť alebo je rozšírenie skryté v ponuke rozšírení Chrome (ikona puzzle). Pripnite Download Claude conversations a obnovte claude.ai. Obsahový skript sa nikdy nenačíta v Claude Desktop ani v termináli Claude Code.

Jedna konverzácia verzus veľa súborov. Oranžové tlačidlo exportuje otvorený chat do JSON. Pre veľa súborov JSON otvorte „View and Download All Conversations“ (Zobraziť a stiahnuť všetky konverzácie) a spustite „Export All“ so zvoleným JSON: jeden ZIP, na bezplatnom pláne 3 chaty denne – pozrite hromadný Export All.

Kedy exportovať konverzáciu Claude do JSON?

Exportujte konverzáciu Claude do JSON, keď bude súbor čítať skript, indexer alebo nástroj na porovnávanie. JSON je postavený na strome správ, nie na čítanie v Obsidiane. Ak chcete nadpisy a bloky kódu pre ľudí, zvoľte radšej Markdown. Pre tabuľkový procesor zvoľte CSV: jeden riadok na správu.

Kopírovanie z claude.ai stráca štruktúru odosielateľov. Tlač ponechá prvky webovej stránky. Pri exporte konverzácie Claude do JSON zachová Download Claude conversations jednotlivé ťahy, odosielateľov aj voliteľné uvažovanie ako dáta, nie ako zlúčený odsek. Preto vývojári uprednostňujú JSON pred čistým textom.

JSON zapisujeme zo stromu claude.ai, ktorý už je na stránke – odosielateľ, bloky obsahu, časové údaje, metadáta modelu – bez nahrávania konverzácie. Tento JSON nie je ZIP účtu od Anthropic. Vo verzii 1.16.2 je jedným zo siedmich formátov, vedľa PDF a CSV, a je zadarmo bez účtu.

Čo obsahuje export konverzácie Claude do JSON?

Export konverzácie Claude do JSON kopíruje strom správ na claude.ai: odosielateľa, bloky obsahu, časové údaje a metadáta modelu. Bloky uvažovania, zdroje z webového vyhľadávania, kroky nástrojov / MCP a artefakty sú zahrnuté, keď tieto možnosti zapnete: „Thinking“ (uvažovanie) je zaškrtávacie políčko v paneli exportu, nástroje a zdroje sa zapínajú v nastaveniach. Filter odosielateľa obmedzí súbor na všetky správy, len vaše alebo len odpovede asistenta. Nič sa predtým neprevádza do Markdown.

Rozloženie artefaktov je vo verzii 1.16.2 „Original“, „Inline“, „Nested“ alebo „Flat“ (pôvodné, vložené, vnorené, ploché). Tieto rozloženia menia, ako je obsah artefaktov vnorený v JSON – sú to tie isté štyri možnosti ako pri Markdown a XML. Úplný zoznam: funkcie rozšírenia pre Chrome. JSON konverzácie Claude, alebo Export data od Anthropic?

Oba sú JSON, no nemajú rovnaký tvar ani rozsah. Settings → Privacy → Export data od Anthropic (ak máte claude.ai v slovenčine, názvy môžu byť preložené) po čase pošle e-mailom jeden ZIP celého účtu. Pri exporte konverzácie Claude do JSON dostanete jednu konverzáciu okamžite v Chrome. ZIP použite na zálohu.

Dá sa exportovať konverzácia Claude do JSON hromadne?

Áno. Otvorte „View and Download All Conversations“, v „Chat format“ (formát chatu) nastavte JSON, vyfiltrujte tabuľku a kliknite na „Export All“. Chrome uloží jeden ZIP s jedným súborom JSON na chat. Na bezplatnom pláne to sú 3 chaty denne s prihlásením cez Google, spoločne s PDF. Pro za 3,99 USD mesačne alebo 26,99 USD ročne tento limit pre hromadný JSON ruší.

Dashboard zobrazuje históriu claude.ai s vyhľadávaním podľa názvu, filtrami „All conversations“, „New“, „Updated“ a „Previously exported“ (všetky, nové, aktualizované, už exportované), kartami „Chat“ a „Cowork“ a vyhľadávaním v projektoch. „New“ znamená, že chat ešte nebol exportovaný cez Download Claude conversations. „Previously exported“ sleduje už uložené chaty. „Export All“ je jeden ZIP so samostatnými súbormi JSON pre každý chat, nie archív so zmiešanými formátmi.

Denný limit platí pre celý účet. Na bezplatnom pláne tri chaty denne, spoločne s PDF. Ak vyberiete 40 konverzácií a zostávajú vám 3, celá dávka sa zablokuje, neskráti sa. Vyberte menej alebo prejdite na Pro. Jednotlivé exporty do JSON cez oranžové tlačidlo zostávajú neobmedzené.

Dva exporty do JSON tej istej konverzácie z claude.ai, urobené v rôznom čase, porovnáte rovnako ako akékoľvek súbory JSON. Každý export je samostatný. Druhý „Export All“ tých istých chatov započíta každý chat znova.

Potrebuje export konverzácie Claude do JSON Pro?

Nie. Export jedného chatu do JSON je zadarmo a neobmedzený, bez účtu a bez počítadla – rovnako ako Markdown, text, XML, CSV a PNG. Bezplatný limit majú iba PDF a hromadný „Export All“: 3 denne s prihlásením cez Google. Pro stojí 3,99 USD mesačne alebo 26,99 USD ročne cez Paddle. Download Claude conversations si za export konverzácie Claude do JSON nič navyše neúčtuje.

Limit sa prejaví pri hromadnom JSON. Každý chat v ZIP-e z „Export All“ spotrebuje jeden z 3 denne a počítadlo sa vynuluje o polnoci UTC. Pro limit ruší a na novom počítači sa obnoví z toho istého účtu Google. Predajcom je Paddle; tento tím čísla kariet nikdy nevidí.

Rozšírenie beží iba na claude.ai v Chrome. Claude Desktop ani terminál Claude Code tlačidlo pre JSON nedostanú; Claude Code on the web (claude.ai/code) beží na claude.ai, takže sa exportuje ako každý chat. Príkaz /export v termináli Claude Code alebo súbory JSONL na disku sú iná cesta. Verzia 1.16.2 zo septembra 2026 stále nezapisuje do Wordu ani Notion.

Dá sa exportovať konverzácia Claude do JSON hromadne?

Áno. „Export All“ na Dashboarde podporuje JSON a uloží jeden ZIP so súborom JSON pre každý chat. Na bezplatnom pláne pokryje 3 chaty denne s prihlásením cez Google; Pro za 3,99 USD mesačne alebo 26,99 USD ročne je neobmedzený.

Kopíruje vlastný strom správ claude.ai: odosielateľa, bloky obsahu, časové údaje a metadáta modelu, plus artefakty, bloky uvažovania, zdroje z webového vyhľadávania a kroky nástrojov / MCP, ak tieto možnosti zapnete. Nie je to schéma ZIP-u účtu od Anthropic.
