Ako exportovať chat Claude do Markdown?

Otvorte konverzáciu na claude.ai v Chrome, kliknite na oranžové tlačidlo vedľa poľa na správu, vyberte Markdown a kliknite na „Export“. Download Claude conversations zapíše súbor .md lokálne. Takto exportujete chat Claude do Markdown vo verzii 1.16.2.

  1. Nainštalujte Download Claude conversations z Chrome Web Store.
  2. Obnovte claude.ai a otvorte skutočnú adresu konverzácie, nie prázdnu úvodnú stránku s poľom na písanie.
  3. Kliknite na oranžové tlačidlo sťahovania vpravo od poľa na správu.
  4. Vyberte Markdown. Rozšírenie si pamätá posledný použitý formát. Cez „Select“ (Vybrať) označte len tie správy, ktoré chcete.
  5. Kliknite na „Export“. Chrome stiahne súbor .md cez rozhranie sťahovania prehliadača. Alebo kliknite na „Copy“ (Kopírovať) a Markdown sa vloží do schránky.

Na export chatu Claude do Markdown sa nemusíte prihlasovať. Export jedného chatu do Markdown je neobmedzený, anonymný a na naše servery nič neposiela. Prihlásenie cez Google sa vyžaduje iba pri PDF a hromadnom „Export All“ (Exportovať všetko). Podrobnosti: ako to funguje.

Ak oranžové tlačidlo chýba, nie ste na adrese konverzácie, karta potrebuje po inštalácii obnoviť alebo je rozšírenie stále skryté v ponuke rozšírení Chrome (ikona puzzle). Pripnite Download Claude conversations a obnovte claude.ai. Obsahový skript sa nikdy nenačíta v Claude Desktop ani v termináli Claude Code.

Jeden chat verzus veľa chatov. Oranžové tlačidlo exportuje otvorenú konverzáciu do Markdown. Pre veľa súborov .md otvorte „View and Download All Conversations“ (Zobraziť a stiahnuť všetky konverzácie) a spustite „Export All“ so zvoleným Markdown: jeden ZIP, na bezplatnom pláne 3 chaty denne – pozrite hromadný Export All.

Prečo exportovať chat Claude do Markdown na poznámky?

Exportujte chat Claude do Markdown, keď budete súbor čítať v Obsidiane, na wiki v GitHube alebo v akomkoľvek editore, ktorý zobrazí nadpisy a bloky kódu. Súbor .md je stále obyčajný text, v ktorom môžete vyhľadávať a porovnávať verzie. JSON je lepší pre parsery; PNG je obrázok, v ktorom text nenájdete.

Kopírovanie z claude.ai zvyčajne stratí odsadenie a rozbije tabuľky. Tlač (Ctrl/Cmd+P) ponechá bočný panel a dlhý blok kódu často rozdelí na viac strán. Pri exporte chatu Claude do Markdown zostane pri blokoch kódu označenie jazyka a tabuľky zostanú tabuľkami. Preto autori textov siahajú najprv po tomto formáte.

Markdown považujeme za predvolený súbor na čítanie pre ľudí: nadpisy, bloky kódu s označením jazyka a tabuľky z konverzácie na claude.ai. Keď potrebujete stránky, vyberte v tom istom paneli PDF. Vytvára sa v prehliadači s veľkosťou strany, okrajmi a obsahom.

Čo export chatu Claude do Markdown zachová?

Pri exporte chatu Claude do Markdown zachová Download Claude conversations nadpisy, bloky kódu s označením jazyka a odsadením, tabuľky a odkazy. Bloky uvažovania, zdroje z webového vyhľadávania a kroky nástrojov / MCP sú voliteľné: „Thinking“ (uvažovanie) je zaškrtávacie políčko v paneli exportu, ďalšie dve možnosti sa zapínajú v nastaveniach. Pridať sa dajú aj metadáta (názov, časové údaje, model). Filter odosielateľa obmedzí súbor .md na všetky správy, len vaše alebo len odpovede asistenta.

Rozloženie artefaktov je vo verzii 1.16.2 skutočný prepínač: „Original“, „Inline“, „Nested“ alebo „Flat“ (pôvodné, vložené, vnorené, ploché). Export do Markdown môže kopírovať štruktúru artefaktov z obrazovky, zlúčiť ich do jedného lineárneho dokumentu alebo ich vytiahnuť do samostatného priečinka v ZIP-e. V nastaveniach môžete obrázky vložiť priamo do súboru .md. Úplný zoznam: funkcie rozšírenia pre Chrome. Markdown nezachová farby bublín správ; na vizuálnu snímku použite PNG, na stránky PDF.

Dá sa exportovať chat Claude do Markdown hromadne?

Áno. Otvorte „View and Download All Conversations“, v „Chat format“ (formát chatu) nastavte Markdown, vyfiltrujte tabuľku a kliknite na „Export All“. Chrome uloží jeden ZIP s jedným súborom .md na chat. Na bezplatnom pláne to sú 3 chaty denne s prihlásením cez Google, spoločne s PDF. Pro za 3,99 USD mesačne alebo 26,99 USD ročne tento limit pre hromadný Markdown ruší.

Dashboard zobrazuje históriu claude.ai s vyhľadávaním podľa názvu, filtrami „All conversations“, „New“, „Updated“ a „Previously exported“ (všetky, nové, aktualizované, už exportované), kartami „Chat“ a „Cowork“ a vyhľadávaním v projektoch. „New“ znamená, že chat ešte nebol exportovaný cez Download Claude conversations. „Previously exported“ sleduje už uložené chaty, takže ďalší „Export All“ ich môže vynechať.

Denný limit platí pre celý účet. Na bezplatnom pláne tri chaty denne, spoločne s PDF. Ak vyberiete 40 konverzácií a zostávajú vám 3, celá dávka sa zablokuje, neskráti sa. Vyberte menej alebo prejdite na Pro. Jednotlivé exporty .md cez oranžové tlačidlo zostávajú neobmedzené.

Hromadný Markdown využíva zaškrtávacie políčka na Dashboarde „Chats“, „Thinking“, „Metadata“, „Tools“ a „Sources“ (chaty, uvažovanie, metadáta, nástroje, zdroje) a rozloženie artefaktov. „Export All“ nie je oneskorený ZIP od Anthropic. Je to jeden ZIP so samostatnými súbormi .md pre každý chat. Ak ste chceli jeden archív celého účtu, to je Settings → Privacy → Export data (ak máte claude.ai v slovenčine, názvy môžu byť preložené) a ten je v JSON, nie v Markdown.

Markdown, alebo JSON pri exporte chatu Claude?

Exportujte chat Claude do Markdown, keď bude súbor čítať človek. Do JSON exportujte, keď bude strom správ spracúvať skript. Download Claude conversations ponúka oba v jednom rozbaľovacom zozname, spolu s PDF, čistým textom, XML, CSV a PNG. Prehľad formátov: formáty exportu chatu Claude.

Export data od Anthropic je tiež JSON, ale ide o ZIP celého účtu poslaný e-mailom, nie o súbor .md pre jeden chat. V tejto žiadosti si Markdown vybrať nemôžete. Tlač z prehliadača je snímka webovej stránky. Ani jedno nenahradí export chatu Claude do Markdown cez oranžové tlačidlo.

Rozšírenie beží iba na claude.ai v Chrome. Claude Desktop ani terminál Claude Code tlačidlo pre Markdown nedostanú. Claude Code on the web (claude.ai/code) beží na claude.ai, takže sa exportuje ako každý chat. Ak konverzácia existuje aj na claude.ai, otvorte ju tam a exportujte chat Claude do Markdown. Príkaz /export v termináli Claude Code je úplne iná cesta.

Stojí export chatu Claude do Markdown niečo navyše?

Nie. Export jedného chatu do Markdown je zadarmo a neobmedzený, bez účtu a bez počítadla – rovnako ako JSON, text, XML, CSV a PNG. Bezplatný limit majú iba PDF a hromadný „Export All“: 3 denne s prihlásením cez Google. Pro stojí 3,99 USD mesačne alebo 26,99 USD ročne cez Paddle. Download Claude conversations si za Markdown nič navyše neúčtuje.

Limit sa prejaví pri hromadnom Markdown. Každý chat v ZIP-e z „Export All“ spotrebuje jeden z 3 denne a počítadlo sa vynuluje o polnoci UTC. Pro limit ruší a na novom počítači sa obnoví z toho istého účtu Google. Predajcom je Paddle; tento tím čísla kariet nikdy nevidí.

Platený plán claude.ai od Anthropic nepotrebujete. Stačí prihlásenie, s ktorým sa konverzácia v Chrome načíta. Plány Team a Enterprise fungujú s oranžovým tlačidlom rovnako ako Free. Verzia 1.16.2 zo septembra 2026 stále nezapisuje do Wordu ani Notion.

Stratí export chatu Claude do Markdown kód?

Nie. Bloky kódu si zachovajú označenie jazyka aj odsadenie, na rozdiel od obyčajného kopírovania z claude.ai. Tabuľky zostanú tabuľkami Markdown. To je hlavný dôvod exportovať chat Claude do Markdown namiesto ručného označovania textu.

Dá sa exportovať chat Claude do Markdown hromadne?

Je Markdown to isté ako Export data od Anthropic?

Nie. Oficiálny export od Anthropic je ZIP s JSON celého účtu, ktorý príde e-mailom po čase. Export chatu Claude do Markdown je súbor .md pre jeden chat (alebo výber správ) z Download Claude conversations.
