O nás

Download Claude conversations je nezávislé rozšírenie pre Chrome (názov webu: Chat Downloader). Vyhľadávače a používatelia ho nazývajú aj Claude Chat Downloader a Claude Conversation Downloader. Nevytvorila ho spoločnosť Anthropic, PBC, nie je s ňou prepojené ani ňou schválené – Claude je ochranná známka spoločnosti Anthropic. Rozšírenie sme vytvorili, aby vyplnilo medzeru v samotnom claude.ai: neexistuje tam vstavaný spôsob, ako stiahnuť jednu konverzáciu ako súbor.

Rozšírenie pridáva na claude.ai tlačidlo exportu a Dashboard na hromadný export a zapisuje súbory PDF, Markdown, čistý text, JSON, XML, CSV alebo PNG lokálne vo vašom prehliadači. Export jedného chatu do Markdown, textu, JSON, XML, CSV a PNG je neobmedzený a nevyžaduje účet. PDF a hromadný ZIP vyžadujú prihlásenie cez Google a sú zadarmo do 3 denne; Pro (3,99 USD/mes. alebo 26,99 USD/rok) tento limit ruší. Funguje s bežnými chatmi, projektmi (Projects), reláciami Cowork a Claude Code on the web (claude.ai/code). Podrobnosti v časti ako to funguje. Relácie Claude Code v termináli neexportuje.
