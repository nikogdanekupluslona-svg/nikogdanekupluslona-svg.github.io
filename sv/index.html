6 kärnfunktioner för att ladda ner Claude-chattar

01

Exportera PDF, Markdown, JSON, CSV med mera

Ladda ner en Claude-chatt som en riktig fil – inte en skärmdump av webbsidan. PDF för att läsa och dela, Markdown för anteckningar, JSON för utvecklare, CSV för kalkylark, ren text för det enklaste arkivet, XML för utbyte mellan system och PNG för en visuell ögonblicksbild. Eller tryck på Copy (kopiera) för att lägga resultatet i urklipp.

02

Ladda ner många Claude-chattar på en gång

Öppna View and Download All Conversations för att lista din historik, söka på namn, filtrera på projekt eller Cowork och klicka på Export All (exportera alla). En enda ZIP-fil i stället för en flik i taget – 3 chattar om dagen med gratisplanen, obegränsat med Pro.

03

Behåll kod, tabeller och artefakter

Exportmotorn läser meddelandeträdet så att kodblock behåller sina indrag, tabeller förblir tabeller och artefakter kan exporteras som ”Original”, ”Inline”, ”Nested” eller ”Flat” (original, inbäddade, nästlade eller platta).

04

Välj vad som hamnar i filen

Exportera hela tråden, bara dina prompter, bara Claudes svar eller bara de meddelanden du bockar för med Select (markera). Ta med Claudes utökade resonemang (extended thinking) när du behöver ett spår att granska i efterhand, eller hoppa över det. Titlar, tidsstämplar och modellmetadata kan följa med i samma fil.

05

Sök och filtrera innan du exporterar

Begränsa listan till nya chattar, redan exporterade chattar eller ett Claude-projekt, och exportera sedan bara det du har markerat.

06

Skapas lokalt i din webbläsare

Varje fil, även PDF, sätts ihop på din enhet och sparas på disken. De flesta exporter kräver inget konto. Google-inloggningen används bara för att räkna PDF- och massexporter och koppla ett Pro-abonnemang – chattexten laddas aldrig upp till våra servrar.

 PNG

En bild av konversationen för en presentation, ett ärende eller ett meddelande.

Vanliga frågor

Kan jag ladda ner en Claude-konversation från claude.ai?

Inte med en inbyggd knapp. Installera Download Claude conversations från Chrome Web Store, öppna chatten och exportera en fil.

Är det gratis att ladda ner Claude-chattar?

Ja. Exporter i Markdown, ren text, JSON, XML, CSV och PNG är obegränsade och kräver inget konto. PDF-exporter och massexporter som ZIP kräver Google-inloggning och är gratis upp till 3 om dagen. Pro, för 3,99 $ i månaden eller 26,99 $ om året, tar bort den gränsen.

Vilka webbläsare fungerar det i?

Chrome på datorn och Chromium-baserade webbläsare som installerar tillägg från Chrome Web Store. Det finns ingen mobilapp, och tillägget fungerar inte i Claude Desktop.

Hur avslutar jag Pro, och kan jag få pengarna tillbaka?

Du kan avsluta när du vill på tilläggets inställningssida (Options) med ”Cancel subscription” (avsluta abonnemang) eller via Paddle. Den första betalningen omfattas av 14 dagars pengarna-tillbaka-garanti – inga frågor ställs.

Är det samma sak som Claudes Export data?

Nej. Anthropics Settings → Privacy → Export data (namnen kan vara översatta om claude.ai är inställt på svenska) skickar en ZIP-fil med hela kontot (JSON) via e-post. Tillägget laddar ner den aktuella chatten – eller ett urval av många chattar – som läsbara filer direkt.

Sparar ni mina Claude-chattar?

Nej. Varje format, även PDF, skapas i din webbläsare, och konversationstexten når aldrig våra servrar. Om du loggar in med Google för PDF, massexport eller Pro sparar vi bara e-postadressen för att räkna den dagliga kvoten och koppla ditt abonnemang.

Är det skillnad på att söka ”ladda ner Claude-chatt” och ”claude export chat”?

Nej, det är samma uppgift skriven på svenska och på engelska. Använd den orange knappen på claude.ai i båda fallen.

Kan den exportera PDF?

Ja. Välj PDF i exportpanelen och ställ in sidstorlek, marginaler, ljust eller mörkt läge, typsnitt, sidnummer och innehållsförteckning. PDF kräver Google-inloggning; gratisplanen ger 3 PDF- eller massexporter om dagen, och med Pro är det obegränsat. Hela genomgången: ladda ner en Claude-chatt som PDF.

Fungerar det med Claude Pro / Team?

Ja, om du kan öppna konversationen i webbläsaren på claude.ai. Vi är inte Anthropic.

Hur sparar jag en Claude-konversation?

Installera det gratis Chrome-tillägget, öppna chatten på claude.ai, klicka på den orange knappen, välj ett format och klicka på Export. Inget konto behövs för Markdown, text, JSON, XML, CSV eller PNG. Så sparar du en Claude-konversation som en riktig fil. Att skriva ut sidan och Anthropics ZIP-export av kontot är de två andra alternativen – jämförelse i guiden så laddar du ner en Claude-chatt.

Laddar det ner Claude Code-konversationer?

Bara de som finns på claude.ai. Claude Code på webben (claude.ai/code) och Cowork-sessioner exporteras som vilken chatt som helst. Lokala terminalsessioner läser tillägget inte; de använder /export eller JSONL-filer på disken – se export från Claude Code.

Är Download Claude conversations associerat med Anthropic?

Nej. Claude är ett varumärke som tillhör Anthropic, PBC. Det här är ett fristående Chrome-tillägg, inte en officiell Anthropic-produkt.
