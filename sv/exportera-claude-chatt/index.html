Hur exporterar jag en Claude-chatt från claude.ai?

Öppna konversationen på claude.ai i Chrome, klicka på den orange knappen bredvid meddelanderutan, välj Markdown, JSON, ren text, XML eller PNG och klicka på ”Export”. Download Claude conversations skriver filen lokalt. I september 2026 finns det ingen inbyggd knapp på claude.ai för att exportera en enskild chatt.

  1. Installera Download Claude conversations från Chrome Web Store (betyg 5,0).
  2. Ladda om claude.ai och öppna en riktig konversationsadress, inte den tomma startsidan med skrivfältet.
  3. Klicka på den orange nedladdningsknappen till höger om meddelanderutan.
  4. Välj format. Exporttillägget kommer ihåg det format du använde senast.
  5. Klicka på ”Export”. Chrome sparar filen direkt via webbläsarens nedladdnings-API.

Google-inloggning krävs före den första exporten. Download Claude conversations sparar den verifierade e-postadressen för att räkna de 3 gratis exporterna och återställa Pro efter en ominstallation. Chattexten ingår inte i inloggningen. Så fungerar det tekniskt: så fungerar det.

Om den orange knappen saknas är du inte på en konversationsadress, fliken behöver laddas om efter installationen, eller så ligger tilläggsikonen fortfarande gömd i Chromes pusselmeny. Fäst Download Claude conversations och uppdatera claude.ai. Exporttillägget körs bara på claude.ai, aldrig på andra webbplatser.

En tråd eller hela kontot. Den orange knappen exporterar den öppna chatten. För många filer öppnar du ”View and Download All Conversations” (visa och ladda ner alla konversationer) och kör ”Export All” (exportera alla) – se exportera alla med Export All. Anthropics Settings → Privacy → Export data (namnen kan vara översatta om claude.ai är inställt på svenska) är en ZIP för kontot som kommer senare, inte det här flödet.

Vad gör ett exporttillägg för Claude egentligen?

Ett exporttillägg för Claude läser konversationen som redan är renderad i din inloggade claude.ai-flik och skriver en strukturerad fil till disken. Download Claude conversations är ett sådant innehållsskript i Chrome: avsändare, meddelandeträd, kodblock, tabeller, valfritt resonemang och layout för artefakter – inte en skärmdump av gränssnittet runt chatten.

Kopiera och klistra in från claude.ai tappar indrag och klämmer ihop tabeller. Utskrift (Ctrl/Cmd+P) tar med sidopanelen och delar ofta ett långt kodblock över flera sidor. Exporttillägget behåller språktaggar på kodblock och låter tabeller förbli tabeller i Markdown, JSON och XML. PNG är alternativet för en visuell ögonblicksbild; det är fortfarande inte en PDF.

Layout för artefakter är en riktig inställning i version 1.13.0: ”Original”, ”Inline”, ”Nested” eller ”Flat” (original, inbäddade, nästlade eller platta). Tankeblock är valfria. Metadata (titel, tidsstämplar, modell) kan följa med. Avsändarfiltret kan begränsa filen till alla meddelanden, bara människa eller bara assistent (”all / human only / assistant only”). Hela listan: funktioner.

Vi byggde den orange knappen för att skriva en riktig fil från chatten som redan finns på claude.ai – Markdown, JSON, text, XML eller PNG – utan att ladda upp tråden till våra servrar. Version 1.13.0 skapar fortfarande ingen PDF.

Söker du på ”extrahera” i stället för ”exportera” hamnar du vid samma knapp; den vinkeln finns i guiden Claude conversation extractor.

Vilket format ska jag exportera Claude-chatten till?

Exportera Claude-chatten till Markdown för anteckningar, JSON för skript, ren text för ett enkelt arkiv, XML för datautbyte eller PNG för en bild av tråden. Download Claude conversations erbjuder de fem i en och samma listruta. Det finns inget PDF-format i exporttillägget.

Format som exporttillägget skapar från claude.ai
Format Passar för Du får
Markdown Obsidian, GitHub, wikis Rubriker, kodblock, tabeller – guide om Markdown
JSON Jämförelser, dataflöden, verktyg Meddelandeträd, inte Anthropics ZIP för kontot – guide om JSON
Ren text Arkiv som kan klistras in var som helst Konversationens ordning, ingen märkning – översikt över format
XML System som kräver XML Strukturerat datautbyte – guide om XML
PNG Visuell ögonblicksbild Bild av tråden, inte PDF – guide om PNG

Skribenter exporterar oftast Claude-chatten som Markdown. Utvecklare väljer oftast JSON. Behöver du just en PDF-liknande sida skriver du ut från Chrome i stället för att vänta på ett format som vi inte har – genomgång: skriv ut en Claude-konversation. En PNG från exporttillägget är en bildfil, inte ett sidindelat dokument.

Formatvalet påverkar inte kvoten på 3 exporter. Markdown, JSON, text, XML och PNG räknas var och en som en export när filen är klar. Pro för 3,99 $/mån eller 26,99 $/år tar bort taket för alla format. Download Claude conversations lägger inte till export till Notion, Word eller Google Docs i 1.13.0.

Kan jag exportera många Claude-chattar med Export All?

Ja. Öppna ”View and Download All Conversations”, filtrera tabellen och klicka på ”Export All”. Varje färdig fil räknas som en export mot samma 3 gratis exporter som den orange knappen. Pro tar bort taket för massexport på samma sätt som för en enskild tråd.

Översiktstabellen listar claude.ai-historiken med sökning på namn och filtren All, New, Exported och Project. New betyder ännu inte exporterad med Download Claude conversations. Exported håller reda på chattar du redan har sparat så att en andra körning av Export All kan hoppa över dem. Project motsvarar hur du grupperar chattar på claude.ai.

Massexporten använder samma inställningar som en enskild konversation: Chats, Thinking, Metadata, layout för artefakter (Original, Inline, Nested, Flat) och samma fem format. Export All är ingen avskalad ZIP. Det är många filer, en per chatt. Om du ville ha ett enda arkiv över hela kontot som kommer senare är det Anthropics Export data, som jämförs i nästa avsnitt och på sidan om massexport.

Kvoten gäller hela kontot. Tre gratis exporter totalt – inte tre per körning. Markerar du 40 konversationer på översiktssidan går det åt 40 exporter om varje fil blir klar. Planera urvalet innan du klickar på ”Export All”, eller använd Pro för 3,99 $/mån eller 26,99 $/år.

Fungerar exporten i Desktop eller Code?

Nej. Exporttillägget körs bara på claude.ai i Chrome (eller en annan Chromium-webbläsare som kan installera tillägget). Claude Desktop är en separat app för Mac/Windows. Claude Code är agenten i terminalen. Den orange knappen syns aldrig i de fönstren.

Om tråden även finns i ditt claude.ai-konto öppnar du den i Chrome och exporterar Claude-chatten där med Download Claude conversations. Finns chatten bara i Desktop kopierar du från appen eller begär Settings → Privacy → Export data på webben. Jämförelse steg för steg: exportera en Claude Desktop-chatt.

Claude Code använder /export eller JSONL-transkript på disken. Det är inte Markdown från det här Chrome-tillägget. Installera inte Download Claude conversations i tron att det kopplar in sig i terminalen. Guide: export från Claude Code. Att exportera en CLI-session är en helt annan väg.

claude.ai i en mobilwebbläsare ligger också utanför. Exporttillägget kräver Chrome på datorn. Det finns ingen app för iOS eller Android från oss 2026. Öppna konversationen på en dator och exportera sedan med den orange knappen eller Export All.

Exportera Claude-chatt eller Anthropics Export data?

Anthropics Export data skickar en JSON-ZIP med hela kontot via e-post efter en väntetid. Att exportera en Claude-chatt med Download Claude conversations sparar den öppna tråden direkt som Markdown, JSON, text, XML eller PNG. Använd ZIP-filen som säkerhetskopia och exporttillägget för en läsbar fil nu.

Den officiella ZIP-filen är ingen snyggare variant av att exportera en chatt. Den är JSON på kontonivå. Du kan inte välja en konversation eller Markdown i den begäran. Exporttillägget kan inte ersätta ZIP-filen om du behöver varje bortglömd tråd i ett arkiv. Jämförelse av metoder med utskriftssteg: så exporterar du en Claude-chatt.

Download Claude conversations är inte associerat med Anthropic, PBC. Att använda exporttillägget ändrar inte Anthropics användarvillkor. Innehållsskriptet använder sessionen du redan har öppnat på claude.ai; det loggar inte in hos Anthropic med egna uppgifter. Följ Anthropics regler för ditt konto.

Vad kostar exporttillägget?

Varje konto med Google-inloggning får 3 gratis exporter. Därefter kostar Pro 3,99 $ per månad eller 26,99 $ per år via Paddle. Priset gäller både den orange knappen och Export All. Download Claude conversations tar inte betalt per format. Alla claude.ai-abonnemang fungerar om Chrome kan öppna chatten.

De 3 gratis exporterna nollställs inte när du installerar om tillägget. Det är därför Google-inloggning krävs vid det första klicket på ”Export”. Pro återställs på en ny dator från samma Google-konto. Paddle är återförsäljare (merchant of record); vi ser aldrig några kortnummer. Återbetalningar går via Paddle enligt sidan om återbetalning.

Du behöver inte Anthropics betalda claude.ai-abonnemang för att använda exporttillägget. Du behöver en claude.ai-inloggning som kan ladda konversationen, plus Chrome. Team och Enterprise fungerar precis som Free med den orange knappen. Om en administratör blockerar tillägg körs Download Claude conversations inte – det är en policy i webbläsaren, inte en begränsning i formaten.

Samma uppgift, olika sökord. Exportera en Claude-chatt, ladda ner en Claude-chatt och extrahera en Claude-konversation betyder alla att spara tråden som fil – och många skriver det på engelska, som ”claude export chat”. Guiden med utskrift och ZIP som alternativ är så laddar du ner en Claude-chatt. Den här sidan handlar om exporttillägget som produkt.

Felsökning när exporten misslyckas: vänta tills den långa tråden har laddats i claude.ai, kontrollera listrutan för format (det senast använda formatet ligger kvar) och kontrollera spärren på 3 exporter. Om Chrome blockerade nedladdningen tillåter du nedladdningar från claude.ai. Ofullständiga filer betyder oftast att sidan inte hade renderat hela meddelandeträdet ännu.

Sidan gäller version 1.13.0, september 2026. Formaten är fortfarande Markdown, JSON, ren text, XML och PNG. Ändras listan uppdateras guiden samma dag. Fram till dess ska du inte räkna med Word, Notion eller inbyggd PDF från exporttillägget.

Vanliga frågor: exportera Claude-chatt

De här frågorna handlar om att exportera Claude-chattar och om exporttillägget: format, kvot, Desktop, Claude Code, Anthropics ZIP och var den orange knappen sitter. Varje svar är ett faktum från version 1.13.0. FAQPage-datan (JSON-LD) i sidhuvudet motsvarar listan.

Vad betyder ”exportera Claude-chatt” på den här webbplatsen?

Att spara en claude.ai-konversation som fil med Download Claude conversations: orange knapp, formatval, ”Export”. Samma uppgift som engelska ”claude export chat”. Inte Anthropics ZIP via e-post och inte /export i Claude Code.

Är ett exporttillägg för Claude samma sak som Export data?

Nej. Settings → Privacy → Export data är en JSON-ZIP med hela kontot via e-post. Exporttillägget skriver den öppna chatten eller ett urval från Export All som Markdown, JSON, text, XML eller PNG direkt i Chrome.

Kan jag exportera en Claude-chatt som PDF?

Inte med det här exporttillägget. Formaten är Markdown, JSON, ren text, XML och PNG. För en PDF-liknande ögonblicksbild skriver du ut claude.ai-sidan i Chrome. PNG är en bild, inte en PDF.

Behöver jag Pro för att exportera en Claude-chatt en gång?

Nej. De första 3 exporterna på ett konto med Google-inloggning är gratis, i valfritt format. Pro för 3,99 $/mån eller 26,99 $/år tar bort gränsen för fler enskilda filer eller massexport.

Fungerar exporten med alla claude.ai-abonnemang?

Ja. Free, Pro, Team och Enterprise på claude.ai fungerar om du kan öppna konversationen i Chrome. Exporttillägget kräver inte Anthropics betalda abonnemang.

Är exporttillägget till för Claude Code?

Nej. Download Claude conversations körs på claude.ai i Chrome. Claude Code använder /export eller JSONL på disken. Se guiden om export från Claude Code.

Kan jag exportera en Claude-chatt från Claude Desktop?

Inte med det här Chrome-tillägget. Öppna samma tråd på claude.ai om den synkas, eller kopiera och klistra in / använd den officiella Export data. Desktop visar aldrig den orange knappen.

Hur många gratis exporter ger exporttillägget?

Tre per konto, delade mellan den orange knappen och Export All. En ominstallation nollställer inte räknaren. Pro återställs via Google-inloggning.

Var finns den orange knappen för att exportera Claude-chatten?

Till höger om meddelanderutan på en konversationsadress på claude.ai, när du har installerat Download Claude conversations och laddat om. Den syns inte på den tomma startsidan med skrivfältet eller i Desktop.

Laddar exporten upp mina konversationer?

Nej. Filerna skapas i webbläsaren och lämnas över till Chromes nedladdnings-API. Vår worker ser abonnemangsstatus och en e-postadress verifierad av Google, inte chattarnas innehåll. Detaljer under så fungerar det.

Vilka format kan exporttillägget skapa?

Markdown, JSON, ren text, XML och PNG – samma fem för en chatt och för Export All. Ingen export till PDF, Word, Notion eller Google Docs i version 1.13.0.
