Hur exporterar jag en Claude-chatt från claude.ai?

Öppna konversationen på claude.ai i Chrome, klicka på den orange knappen bredvid meddelanderutan, välj PDF, Markdown, JSON, ren text, XML, CSV eller PNG och klicka på ”Export”. Download Claude conversations skriver filen lokalt. I september 2026 finns det ingen inbyggd knapp på claude.ai för att exportera en enskild chatt.

  1. Installera Download Claude conversations från Chrome Web Store.
  2. Ladda om claude.ai och öppna en riktig konversationsadress, inte den tomma startsidan med skrivfältet.
  3. Klicka på den runda orange nedladdningsknappen till höger om meddelanderutan.
  4. I panelen ställer du in ”Messages” (meddelanden) på ”All”, ”Human” eller ”Assistant” (alla, människa eller assistent) och väljer sedan ett format. Kryssa i ”Thinking” (tänkande) för att ta med utökat tänkande, eller använd ”Select” (markera) för att bocka för enskilda meddelanden. Exporttillägget kommer ihåg det format du använde senast.
  5. Klicka på ”Export”. Chrome sparar filen direkt via webbläsarens nedladdnings-API. ”Copy” (kopiera) lägger i stället Markdown, text, JSON, XML eller CSV i urklipp.

Du behöver inget konto för att exportera en Claude-chatt som Markdown, text, JSON, XML, CSV eller PNG. De exporterna av enskilda chattar är obegränsade, och tillägget skickar ingenting till våra servrar för dem. Google-inloggning dyker upp först när du väljer PDF eller kör massexport med ”Export All”: gratisplanen ger 3 sådana per dag, sammanlagt, och räkningen nollställs vid midnatt UTC. Chattexten ingår aldrig i inloggningen. Så fungerar det tekniskt: så fungerar det.

Om den orange knappen saknas är du inte på en konversationsadress, fliken behöver laddas om efter installationen, eller så ligger tilläggsikonen fortfarande gömd i Chromes pusselmeny. Fäst Download Claude conversations och uppdatera claude.ai. Exporttillägget körs bara på claude.ai, aldrig på andra webbplatser.

En tråd eller hela kontot. Den orange knappen exporterar den öppna chatten. För många filer öppnar du ”View and Download All Conversations” (visa och ladda ner alla konversationer) från tilläggets popup och kör ”Export All” (exportera alla) – se exportera alla med Export All. Anthropics Settings → Privacy → Export data (namnen kan vara översatta om claude.ai är inställt på svenska) är en ZIP för kontot som kommer senare, inte det här flödet.

Vad gör ett exporttillägg för Claude egentligen?

Ett exporttillägg för Claude läser konversationen som redan är renderad i din inloggade claude.ai-flik och skriver en strukturerad fil till disken. Download Claude conversations är ett sådant innehållsskript i Chrome: avsändare, meddelandeträd, kodblock, tabeller, valfritt resonemang och layout för artefakter – inte en skärmdump av gränssnittet runt chatten. Det fungerar med vanliga chattar, projekt, Cowork-sessioner och Claude Code på webben.

Kopiera och klistra in från claude.ai tappar indrag och klämmer ihop tabeller. Utskrift (Ctrl/Cmd+P) tar med sidopanelen och delar ofta ett långt kodblock över flera sidor. Exporttillägget behåller språktaggar på kodblock och låter tabeller förbli tabeller i Markdown, JSON och XML. PNG är alternativet för en visuell ögonblicksbild. PDF är det sidindelade alternativet, som skapas i webbläsaren utan utskriftsdialog.

Layout för artefakter är en riktig inställning i version 1.16.2: ”Original”, ”Inline”, ”Nested” eller ”Flat” (original, inbäddade, nästlade eller platta), som du väljer på översiktssidan (Dashboard). Utökat tänkande är en kryssruta i exportpanelen; källor från webbsökning och verktygs-/MCP-steg slår du på i inställningarna (Settings). Metadata (titel, tidsstämplar, modell) kan följa med. Filtret ”Messages” begränsar filen till alla meddelanden, bara människa eller bara assistent, och ”Select” bockar för enskilda meddelanden. Hela listan: funktioner.

Vi byggde den orange knappen för att skriva en riktig fil från chatten som redan finns på claude.ai – PDF, Markdown, JSON, text, XML, CSV eller PNG – utan att ladda upp tråden till våra servrar. Version 1.16.2 skapar även PDF-filen i webbläsaren.

Söker du på ”extrahera” i stället för ”exportera” hamnar du vid samma knapp; den vinkeln finns i guiden Claude conversation extractor.

Vilket format ska jag exportera Claude-chatten till?

Exportera Claude-chatten till PDF för att dela eller skriva ut, Markdown för anteckningar, JSON för skript, ren text för ett enkelt arkiv, XML för datautbyte, CSV för ett kalkylark eller PNG för en bild av tråden. Download Claude conversations erbjuder alla sju i en och samma listruta.

Format som exporttillägget skapar från claude.ai
Format Passar för Du får
PDF Delning, utskrift, kunder Sidindelad fil som skapas i webbläsaren – guide om PDF
Markdown Obsidian, GitHub, wikis Rubriker, kodblock, tabeller – guide om Markdown
JSON Jämförelser, dataflöden, verktyg Meddelandeträd, inte Anthropics ZIP för kontot – guide om JSON
Ren text Arkiv som kan klistras in var som helst Konversationens ordning, ingen märkning – översikt över format
XML System som kräver XML Strukturerat datautbyte – guide om XML
CSV Excel, Google Sheets, Numbers En rad per meddelande – översikt över format
PNG Visuell ögonblicksbild En bild av tråden – guide om PNG

Skribenter exporterar oftast Claude-chatten som Markdown. Utvecklare väljer oftast JSON. Behöver du ett sidindelat dokument väljer du PDF: i dialogrutan ställer du in sidstorlek, marginaler, ljust eller mörkt läge, typsnitt, sidnummer och en innehållsförteckning – genomgång: spara en Claude-chatt som PDF. En PNG från exporttillägget är en enda bildfil, inte ett sidindelat dokument.

Formatet avgör om det finns en gräns. Markdown, text, JSON, XML, CSV och PNG är obegränsade och kräver inget konto. PDF kräver Google-inloggning och räknas mot 3 per dag på gratisplanen, delat med massexport via ”Export All”. Pro för 3,99 $ i månaden eller 26,99 $ om året tar bort taket. Download Claude conversations lägger inte till export till Notion, Word eller Google Docs i 1.16.2.

Kan jag exportera många Claude-chattar med Export All?

Ja. Öppna ”View and Download All Conversations” från tilläggets popup, filtrera tabellen och klicka på ”Export All” för att få en ZIP. Massexport kräver Google-inloggning. På gratisplanen delar den 3 per dag med PDF, och varje konversation i ZIP-filen räknas som en. Pro tar bort taket för hela historiken.

Översiktssidan (Dashboard) listar claude.ai-historiken med sökning på namn, filtren ”All conversations”, ”New”, ”Updated” och ”Previously exported” (alla konversationer, nya, uppdaterade, tidigare exporterade), flikarna ”Chat” och ”Cowork” samt sökning på projekt. New betyder ännu inte exporterad med Download Claude conversations. Previously exported håller reda på chattar du redan har sparat så att en andra körning av Export All kan hoppa över dem. Projektsökningen motsvarar hur du grupperar chattar på claude.ai.

Massexporten har formatväljaren ”Chat format” (chattformat) med alla sju format, även PDF, kryssrutorna ”Chats”, ”Thinking”, ”Metadata”, ”Tools” och ”Sources” (chattar, tänkande, metadata, verktyg, källor) och layout för artefakter (Original, Inline, Nested, Flat). Export All är inget avskalat arkiv. Det är en ZIP med en fil per chatt i det valda formatet. Om du ville ha ett enda arkiv över hela kontot som kommer senare är det Anthropics Export data, som jämförs i nästa avsnitt och på sidan om massexport.

Massexport räknas per chatt. På gratisplanen delar Export All och PDF på 3 per dag, och varje konversation i ZIP-filen räknas som en. Markerar du 40 konversationer när du har 3 kvar blockeras hela körningen – den kortas inte av. Välj färre, vänta på nollställningen vid midnatt UTC eller använd Pro för 3,99 $ i månaden eller 26,99 $ om året.

Fungerar exporten i Desktop eller Code?

Inte i Desktop-appen eller i Claude Code i terminalen. Exporttillägget körs bara på claude.ai i Chrome (eller en annan Chromium-webbläsare som kan installera tillägget). Claude Desktop är en separat app för Mac/Windows, och den orange knappen syns aldrig där eller i en terminal. Claude Code på webben (claude.ai/code) är undantaget: de sessionerna öppnas på claude.ai och exporteras som vilken chatt som helst.

Om tråden även finns i ditt claude.ai-konto öppnar du den i Chrome och exporterar Claude-chatten där med Download Claude conversations. Finns chatten bara i Desktop kopierar du från appen eller begär Settings → Privacy → Export data på webben. Jämförelse steg för steg: exportera en Claude Desktop-chatt.

Claude Code i terminalen använder /export eller JSONL-transkript på disken. Det här Chrome-tillägget läser inte de lokala sessionerna. Installera inte Download Claude conversations i tron att det kopplar in sig i terminalen. Guide: export från Claude Code. Att exportera en CLI-session är en helt annan väg.

claude.ai i en mobilwebbläsare ligger också utanför. Exporttillägget kräver Chrome på datorn. Det finns ingen app för iOS eller Android från oss 2026. Öppna konversationen på en dator och exportera sedan med den orange knappen eller Export All.

Exportera Claude-chatt eller Anthropics Export data?

Anthropics Export data skickar en JSON-ZIP med hela kontot via e-post efter en väntetid. Att exportera en Claude-chatt med Download Claude conversations sparar den öppna tråden direkt som PDF, Markdown, JSON, text, XML, CSV eller PNG. Använd ZIP-filen som säkerhetskopia och exporttillägget för en läsbar fil nu.

Den officiella ZIP-filen är ingen snyggare variant av att exportera en chatt. Den är JSON på kontonivå. Du kan inte välja en konversation eller Markdown i den begäran. Exporttillägget kan inte ersätta ZIP-filen om du behöver varje bortglömd tråd i ett arkiv. Jämförelse av metoder med utskriftssteg: så exporterar du en Claude-chatt.

Download Claude conversations är inte associerat med Anthropic, PBC. Att använda exporttillägget ändrar inte Anthropics användarvillkor. Innehållsskriptet använder sessionen du redan har öppnat på claude.ai; det loggar inte in hos Anthropic med egna uppgifter. Följ Anthropics regler för ditt konto.

Vad kostar exporttillägget?

Exporter som Markdown, text, JSON, XML, CSV och PNG är gratis och obegränsade, utan konto. PDF och massexport med Export All är gratis upp till 3 per dag med Google-inloggning. Pro kostar 3,99 $ i månaden eller 26,99 $ om året via Paddle och gör PDF och massexport obegränsade. Download Claude conversations tar inte betalt per format. Alla claude.ai-abonnemang fungerar om Chrome kan öppna chatten.

Den dagliga räkningen för PDF och massexport nollställs vid midnatt UTC. Pro återställs på en ny dator när du loggar in med samma Google-konto. Du kan säga upp när som helst från tilläggets inställningssida (Options) eller via Paddle. Paddle är återförsäljare (merchant of record); vi ser aldrig några kortnummer. Den första betalningen har 14 dagars pengarna-tillbaka-garanti, som hanteras via Paddle enligt sidan om återbetalning.

Du behöver inte Anthropics betalda claude.ai-abonnemang för att använda exporttillägget. Du behöver en claude.ai-inloggning som kan ladda konversationen, plus Chrome. Team och Enterprise fungerar precis som Free med den orange knappen. Om en administratör blockerar tillägg körs Download Claude conversations inte – det är en policy i webbläsaren, inte en begränsning i formaten.

Samma uppgift, olika sökord. Exportera en Claude-chatt, ladda ner en Claude-chatt och extrahera en Claude-konversation betyder alla att spara tråden som fil – och många skriver det på engelska, som ”claude export chat”. Guiden med utskrift och ZIP som alternativ är så laddar du ner en Claude-chatt. Den här sidan handlar om exporttillägget som produkt.

Felsökning när exporten misslyckas: vänta tills den långa tråden har laddats i claude.ai, kontrollera listrutan för format (det senast använda formatet ligger kvar) och, för PDF eller massexport, kontrollera hur många av dagens 3 du har kvar. Om Chrome blockerade nedladdningen tillåter du nedladdningar från claude.ai. Ofullständiga filer betyder oftast att sidan inte hade renderat hela meddelandeträdet ännu.

Sidan gäller version 1.16.2, september 2026. Formaten är PDF, Markdown, ren text, JSON, XML, CSV och PNG. Ändras listan uppdateras guiden samma dag. Fram till dess ska du inte räkna med export till Word, Notion eller Google Docs från exporttillägget.

Vanliga frågor: exportera Claude-chatt

De här frågorna handlar om att exportera Claude-chattar och om exporttillägget: format, gränser, Desktop, Claude Code, Anthropics ZIP och var den orange knappen sitter. Varje svar är ett faktum från version 1.16.2. FAQPage-datan (JSON-LD) i sidhuvudet motsvarar listan.

Vad betyder ”exportera Claude-chatt” på den här webbplatsen?

Att spara en claude.ai-konversation som fil med Download Claude conversations: orange knapp, formatval, ”Export”. Samma uppgift som engelska ”claude export chat”. Inte Anthropics ZIP via e-post och inte /export i Claude Code.

Är ett exporttillägg för Claude samma sak som Export data?

Nej. Settings → Privacy → Export data är en JSON-ZIP med hela kontot via e-post. Exporttillägget skriver den öppna chatten som PDF, Markdown, JSON, text, XML, CSV eller PNG, eller ett urval från Export All som en ZIP, direkt i Chrome.

Kan jag exportera en Claude-chatt som PDF?

Ja. Välj PDF i formatlistan och klicka på ”Export”. Exporttillägget skapar PDF-filen i webbläsaren, utan utskriftsdialog. PDF kräver Google-inloggning och är gratis upp till 3 per dag; Pro gör det obegränsat. Guide: spara en Claude-chatt som PDF.

Behöver jag Pro för att exportera en Claude-chatt en gång?

Nej. Exporter som Markdown, text, JSON, XML, CSV och PNG är gratis och obegränsade, utan konto. PDF och massexport med Export All är gratis upp till 3 per dag med Google-inloggning. Pro för 3,99 $ i månaden eller 26,99 $ om året tar bort det taket.

Fungerar exporten med alla claude.ai-abonnemang?

Ja. Free, Pro, Team och Enterprise på claude.ai fungerar om du kan öppna konversationen i Chrome. Exporttillägget kräver inte Anthropics betalda abonnemang.

Är exporttillägget till för Claude Code?

Bara för Claude Code på webben. Sessioner på claude.ai/code öppnas på claude.ai och exporteras som vilken chatt som helst. Claude Code i terminalen använder /export eller JSONL på disken, och Download Claude conversations läser inte dem. Se guiden om export från Claude Code.

Kan jag exportera en Claude-chatt från Claude Desktop?

Inte med det här Chrome-tillägget. Öppna samma tråd på claude.ai om den synkas, eller kopiera och klistra in / använd den officiella Export data. Desktop visar aldrig den orange knappen.

Hur många gratis exporter ger exporttillägget?

Obegränsat för Markdown, text, JSON, XML, CSV och PNG, utan konto. PDF och massexport med Export All delar på 3 per dag på gratisplanen, med Google-inloggning; varje chatt i en ZIP räknas som en. Räkningen nollställs vid midnatt UTC. Pro tar bort taket och återställs via Google-inloggning.

Var finns den orange knappen för att exportera Claude-chatten?

Till höger om meddelanderutan på en konversationsadress på claude.ai, när du har installerat Download Claude conversations och laddat om. Den syns inte på den tomma startsidan med skrivfältet eller i Desktop.

Laddar exporten upp mina konversationer?

Nej. Alla format, även PDF, skapas i webbläsaren och lämnas över till Chromes nedladdnings-API. Exporter som Markdown, text, JSON, XML, CSV och PNG skickar ingenting till oss. När du har loggat in för PDF, massexport eller Pro ser vår worker kvot- eller abonnemangsstatus och e-postadressen till ditt Google-konto, aldrig chattarnas innehåll. Detaljer under så fungerar det.

Vilka format kan exporttillägget skapa?

Sju: PDF, Markdown, ren text, JSON, XML, CSV och PNG – samma sju för en chatt och för Export All. Ingen export till Word, Notion eller Google Docs i version 1.16.2.
