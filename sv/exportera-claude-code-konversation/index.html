Vad är export av en Claude Code-konversation i terminalen?

Export i Claude Code är kommandot /export i en interaktiv CLI-session. Anthropics dokumentation beskriver en meny där du kan kopiera den aktuella konversationen eller spara en fil i ren text, med meddelanden och verktygsutdata återgivna som läsbar text. Anger du ett filnamn hoppar du över menyn och filen skrivs direkt.

Det här är inte Markdown från claude.ai, inte JSON från Chrome-tillägget och inte en PDF. Det är en läsbar transkription för en människa. Enligt Anthropic är JSONL-loggen på disken ett annat, internt format som är avsett för produkten, inte som ditt publika API.

/export

För att hoppa över frågan och skriva en namngiven fil i den aktuella arbetskatalogen:

/export my-session

Anthropics dokumentation om sessioner är den auktoritativa källan för flaggor och filnamn; de ändras mellan versioner av Claude Code. Se bloggar från communityn som sekundära källor. Om texten i dialogen för /export inte stämmer med det du ser har du en annan version av CLI:t – använd hjälpen i produkten, inte en skärmdump från 2025.

För skript hänvisar Anthropic till andra gränssnitt: claude -p med --output-format json eller stream-json, återupptagning via sessions-id, hooks som tar emot en transcript_path, eller Agent SDK. Det är utvecklarytor i Claude Code. De är inte den här webbplatsens Chrome-tillägg.

Läsbart eller strukturerat. /export är transkriptionen för människor. JSONL i projects-mappen är loggen. Chrome-tilläggets JSON är en tredje form, byggd enbart från en claude.ai-sida. Skriv inte en parser för alla tre.

Hur hämtar jag en Claude Code-konversation från disken?

Kopiera sessionens JSONL-fil från projects-katalogen, eller kör /export för en läsbar transkription. Standardsökvägen på macOS och Linux ligger under ~/.claude/projects/. På Windows är det %USERPROFILE%\.claude\projects. Filnamnen är sessions-id:n.

Projektmappens namn är arbetskatalogen där alla tecken som inte är bokstäver eller siffror ersatts med bindestreck. Anthropic kortar mycket långa konverterade namn och lägger till en hash så att katalogen håller sig inom filsystemets gränser. Hittar du inte mappen startade du Claude Code från en annan arbetskatalog än du tror.

Varje JSONL-rad är ett JSON-objekt för ett meddelande, ett verktygsanrop eller metadata. Anthropic anger att formatet är internt och ändras mellan versioner. Skript som tolkar filerna kan gå sönder vid en ny version av Claude Code. Använd hellre /export eller de dokumenterade skriptgränssnitten när du behöver något stabilt.

Lagringsplatsen kan flyttas. CLAUDE_CONFIG_DIR flyttar konfigurationsträdet från ~/.claude. CLAUDE_CODE_PROJECT_DIR_NAME namnger projektkatalogen när den används tillsammans med den konfigurationskatalogen (Claude Code v2.1.234 eller senare, enligt Anthropic). cleanupPeriodDays i settings.json ändrar hur länge filerna sparas som standard. Inga av de inställningarna är funktioner i Download Claude conversations.

För backup av Claude Code-konversationer gäller alltså: kopiera mappen, eller exportera transkriptioner med /export regelbundet. Den här webbplatsen kommer inte att lägga till någon knapp för att importera JSONL. Vi läser inte din hemkatalog.

Fungerar export av Claude Code-konversationer med tillägget?

Nej. Claude Code-export fungerar inte med Download Claude conversations. Chrome-tillägget körs i claude.ai. Det kan inte se terminalen, inte köra /export och inte öppna JSONL. Letar du efter hur du laddar ner en Claude Code-konversation, håll dig till stegen för CLI:t på den här sidan.

Många hamnar här eftersom sökmotorer grupperar ”Claude” och ”export”. Tillägget i Chrome Web Store gäller ändå bara claude.ai. Att installera det lägger ingen orange knapp i iTerm, Ghostty, terminalen i VS Code eller Claude Codes skrivbordsomslag.

Har du också en parallell tråd på claude.ai för samma kodjobb kan den webbchatten sparas med tillägget. De två posterna slås inte ihop. Verktygsanrop som bara skedde i CLI:t syns inte i webbexporten om du inte klistrat in dem där.

Vi får samma supportmejl varje vecka: någon har installerat Chrome-tillägget och väntat sig att /export ska dyka upp. Vi läser bara claude.ai. Claude Code har redan /export och JSONL. Att bygga in CLI:t vore en annan produkt, och den har vi inte släppt.

Var sparar Claude Code konversationshistoriken?

Claude Code sparar konversationshistoriken som JSONL-transkriptioner i konfigurationskatalogens projects-mapp. Standard på macOS och Linux: ~/.claude/projects/<encoded-cwd>/<session-id>.jsonl. Windows använder %USERPROFILE%\.claude\projects. Anthropic kan ändra strukturen; kontrollera den aktuella dokumentationen om sessioner om en sökväg saknas på disken.

Att återuppta är något annat än att exportera. claude --continue och claude --resume läser in en session igen så att du kan fortsätta arbeta. /export skriver en kopia som du kan lägga i git eller mejla. Det ena återställer sammanhanget. Det andra ger dig en post att ta med. Anthropics sida om sessioner tar upp behörighetsläge vid återupptagning, komprimering/sammanfattning och väljarens beteende – inget av det gäller tillägget.

Skrivbordsappen, Claude Code på webben och VS Code-tillägget har var och en sin egen sessionshistorik, enligt Anthropic. Sökvägarna i den här guiden gäller CLI:t. Anta inte att en transkription från Cowork i Desktop ligger i samma JSONL-träd som du använder från terminalen.

Behandla inte JSONL som ett publikt schema. Anthropic säger att radformatet ändras. Tolkar du det ändå, lås en version av Claude Code och räkna med att det går sönder. /export är det stabila sättet att få en läsbar Claude Code-konversation.

Miljövariabler som CLAUDE_CODE_SKIP_PROMPT_HISTORY kan stänga av skrivningen av transkriptioner. Är projects-mappen tom, kontrollera om du har stängt av lagringen, pekat CLAUDE_CONFIG_DIR någon annanstans eller aldrig kört en interaktiv session i den katalogen.

Hur laddar jag ner en Claude-chatt på claude.ai i stället?

Installera Download Claude conversations, öppna tråden i Chrome, klicka på den orangea knappen och välj Markdown, JSON, text, XML eller PNG. Det är webbläsarprodukten. Det är inte export från Claude Code. Steg för steg: ladda ner en Claude-chatt.

Hela claude.ai-historiken som separata filer får du med Export All på översiktssidan, inte med /export. Varje fil räknas mot 3 gratis exporter om du inte har Pro. Guide: massexport med Export All. Format: format.

Google-inloggning krävs vid den första exporten från claude.ai så att vi kan räkna kvoten och återställa Pro. Filerna skapas lokalt. Paddle fakturerar Pro för 3,99 $/mån eller 26,99 $/år. Inget av det gäller /export i terminalen.

Började arbetet i Claude Code och du klistrade in en sammanfattning i claude.ai, ladda ner webbtråden för anteckningar och behåll /export för den faktiska CLI-loggen. Två filer är bättre än en rörig fil.

Export av Claude Code-konversation eller Anthropics Export data?

Export från Claude Code (/export eller JSONL) gäller en terminalsession. Den officiella Export data är Settings → Privacy → Export data på claude.ai (etiketterna kan vara översatta om claude.ai är inställt på svenska): ett fördröjt ZIP-arkiv med JSON för Anthropic-kontot. Det är inte samma arkiv. ZIP-arkivet ersätter inte /export.

Om en viss Claude Code-session finns med i kontots ZIP-arkiv beror på hur Anthropic lagrar den produkten, inte på tillägget. Se ZIP-arkivet som en backup av webbkontot om inte Anthropics aktuella integritetsdokumentation säger något annat. Vi lägger inte till CLI-sessioner i det arkivet.

Hur du exporterar en Claude-chatt från webbplatsen, inklusive ZIP-arkivet jämfört med tillägget, beskrivs här: så exporterar du en Claude-chatt. Att skriva ut en webbsida som PDF fungerar inte för ett terminalgränssnitt. Se utskrift / PDF bara när konversationen finns i webbläsaren.

Export från Claude Code, Desktop eller claude.ai?

Claude Code, Claude Desktop och claude.ai är tre olika ytor. Claude Code exporterar med /export och JSONL. Desktop är en app utan tilläggets orangea knapp. claude.ai i Chrome är det enda stället där Download Claude conversations körs. Blandar man ihop namnen misslyckas exporten utan att det märks.

Claude Desktop: om chatten synkats till samma Anthropic-konto, öppna den på claude.ai och exportera där. Finns den bara i Desktop-fönstret, kopiera och klistra in eller vänta på den officiella Export data. Guide: exportera en Claude Desktop-chatt.

Claude Code-panelen i VS Code ligger närmare CLI:t än claude.ai. Räkna inte med att vårt innehållsskript körs i den webbvyn. Använd /export i den session som faktiskt innehåller meddelandena.

Fristående Chrome-tillägg, inte knutet till Anthropic, PBC. Claude är ett varumärke som tillhör Anthropic. Följ deras användarvillkor. Vi kan inte ge juridisk rådgivning om att kopiera verktygsutdata som innehåller skyddad kod; det är en fråga mellan dig, din arbetsgivare och Anthropic.

Vanliga frågor: exportera Claude Code-konversation

Hur exporterar jag en Claude Code-konversation?

Skriv /export i Claude Codes terminal (eventuellt med ett filnamn) för att spara en läsbar transkription, eller kopiera JSONL-filen från ~/.claude/projects på macOS/Linux eller %USERPROFILE%\.claude\projects på Windows. Anthropics dokumentation om sessioner beskriver den aktuella dialogen.

Laddar det här Chrome-tillägget ner Claude Code-chattar?

Nej. Download Claude conversations fungerar bara på claude.ai i Chrome. Det kan inte läsa terminalsessioner, JSONL-transkriptioner eller kommandot /export. Export från Claude Code sker i CLI:t.

Var sparar Claude Code konversationshistoriken?

Sessionstranskriptioner är JSONL-filer under ~/.claude/projects/<encoded-working-directory>/, namngivna efter sessions-id. Den exakta strukturen kan ändras. Använd /export när du vill ha en läsbar fil i stället för att tolka JSONL. CLAUDE_CONFIG_DIR kan flytta hela trädet.

Hur laddar jag ner en Claude Code-konversation som Markdown?

Claude Codes /export är en transkription i ren text, inte tilläggets Markdown. Behöver du just Markdown, exportera en kopia av arbetet från claude.ai med Download Claude conversations, eller konvertera texten från /export själv. Vi konverterar inte JSONL till Markdown.

Hur laddar jag ner en claude.ai-konversation i stället?

Installera det gratis Chrome-tillägget, öppna chatten på claude.ai och använd den orangea knappen – eller Export All för historiken. Se ladda ner en Claude-chatt. 3 gratis exporter; Pro kostar 3,99 $/mån eller 26,99 $/år.

Är /export samma sak som den officiella Export data?

Nej. /export gäller den aktuella Claude Code-sessionen. Settings → Privacy → Export data mejlar ett ZIP-arkiv med JSON för Anthropic-kontot. Olika produkter, olika filer, olika väntetider.

Kan jag tolka Claude Codes JSONL med jq?

Ja, med den reservation som Anthropic anger: radformatet är internt och kan ändras. Använd hellre /export eller claude -p --output-format json när du behöver ett stabilt format. Lås din CLI-version om du ändå tolkar JSONL.

Fungerar export från Claude Code på Windows?

Ja. /export är ett CLI-kommando. Transkriptioner på disken ligger under %USERPROFILE%\.claude\projects om du inte har satt CLAUDE_CONFIG_DIR. Chrome-tillägget körs ändå inte i den terminalen.

Är Claude Code samma sak som Claude Desktop?

Nej. Claude Code är kodagenten i terminalen. Claude Desktop är chattappen. claude.ai är webbplatsen. Bara webbplatsen får det här tillägget. Om export från Desktop: Claude Desktop.

Kommer tillägget någon gång att stödja /export?

Inte i version 1.13.0. Produkten gäller claude.ai: fem format, lokala filer, Google-inloggning för kvoten. Ändras det kommer den här sidan att säga det. Tills dess använder du Anthropics CLI för att exportera från Claude Code.

Innehåller /export verktygsutdata?

Anthropic beskriver /export som meddelanden och verktygsutdata återgivna som läsbar text. Det är deras transkription, inte vår tolkning. För det exakta innehållet just nu, kör /export i din version och läs filen – dokumentationen kan ligga en version efter.

Kan jag massexportera Claude Code-sessioner?

Inte med tilläggets Export All. Massexporten på vår översiktssida gäller bara claude.ai. För många CLI-sessioner kopierar du projects-mappen eller kör /export per session. Det finns ingen massexport av JSONL via den orangea knappen.
