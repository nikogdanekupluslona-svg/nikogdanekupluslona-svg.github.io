Vad är en Claude conversation extractor?

En Claude conversation extractor tolkar den renderade claude.ai-tråden och skriver en riktig fil. Download Claude conversations är ett sådant verktyg för Chrome: inget skärmdumpsverktyg och inte Anthropics ZIP för kontot. Folk skriver extrahera, exportera eller ladda ner – och menar samma orange knapp på claude.ai.

Utvecklare och forskare söker ofta på ”Claude conversation extractor” eftersom ordet extrahera antyder struktur: avsändare, innehållsblock, kodblock, tabeller, artefakter. Download Claude conversations gör den tolkningen i fliken du redan har öppnat. Andra kallar det Claude Conversation Downloader, Claude Exporter eller på engelska ”claude chat exporter”; namnen betyder fortfarande det här tillägget, som har betyget 5,0 i Chrome Web Store.

Extractorn är inget tillägg för Claude Desktop och inget CLI för Claude Code. Gällde sökningen historik i terminalen använder du /export – guide: export från Claude Code. Gällde den appen för Mac/Windows, se exportera en Claude Desktop-chatt. Den här sidan gäller bara claude.ai i Chrome.

Samma knapp, olika verb. Extrahera en Claude-chatt, exportera en Claude-chatt och ladda ner en Claude-chatt leder alla till Download Claude conversations. Genomgången med fokus på exporten som produkt är exportera Claude-chatt. Den här guiden handlar om vad extractorn läser och vad den tar bort.

Hur extraherar jag en Claude-chatt på claude.ai?

Installera Download Claude conversations, öppna konversationens adress på claude.ai, klicka på den orange knappen bredvid meddelanderutan, välj format och klicka på ”Export”. Extractorn skriver filen lokalt via Chromes nedladdnings-API. Google-inloggningen görs en gång, före den första extraheringen, för att räkna de 3 gratis exporterna.

  1. Lägg till tillägget från Chrome Web Store (Download Claude conversations, version 1.13.0 i september 2026).
  2. Ladda om claude.ai och öppna tråden – extractorn behöver en konversationsadress, inte den tomma startsidan med skrivfältet.
  3. Klicka på den orange knappen till höger om meddelanderutan.
  4. Välj Markdown, JSON, ren text, XML eller PNG.
  5. Klicka på ”Export”. Extractorn laddar inte upp chattens innehåll till våra servrar.

Om den orange knappen saknas fäster du tillägget, uppdaterar fliken och kontrollerar att adressen är en riktig chatt. Extractorn körs bara på claude.ai. Den dyker inte upp i Claude Desktop, i Claude Code eller på andra webbplatser. Ofullständiga filer betyder oftast att den långa tråden inte hade renderats klart; scrolla eller vänta och extrahera igen.

Extractorn kommer ihåg det format du använde senast. Om du ville ha Markdown men fick JSON öppnar du listrutan före ”Export”. När du når spärren på 3 exporter visas ett erbjudande om Pro för 3,99 $/mån eller 26,99 $/år – det ska vara så, det är ingen misslyckad tolkning. Google-inloggningen vid första extraheringen krävs så att en ominstallation inte kan nollställa gratisräknaren.

Vill du ha steglistan med utskrift och ZIP som alternativ? Läs så laddar du ner en Claude-chatt. Vill du jämföra metoder, inklusive Skriv ut → Spara som PDF? Läs så exporterar du en Claude-chatt. Den här sidan utgår från att du vill ha en strukturerad fil av den öppna tråden.

Vad hämtar extractorn ur konversationen?

Extractorn läser meddelandeträdet som claude.ai redan har ritat upp: turer från människa och assistent, kodblock med språktaggar, tabeller, länkar och valfritt resonemang. Layouten för artefakter är ”Original”, ”Inline”, ”Nested” eller ”Flat” (original, inbäddade, nästlade eller platta). Kopiera och klistra in från samma sida tappar den strukturen; extractorn behåller den i Markdown, JSON och XML.

Tankeblock är en inställning. Slå på dem när du behöver Claudes synliga resonemang i den extraherade filen; låt dem vara avstängda när du bara vill ha det slutliga svaret. Metadata kan innehålla titlar, tidsstämplar och modell. Avsändarfiltret kan behålla alla meddelanden, bara människa eller bara assistent (”all / human only / assistant only”). Kontrollerna finns i samma widget som formatet. Lista över funktioner: funktioner.

Extractorn läser konversationen som sidan redan har renderat i din claude.ai-flik. Kodblock, tabeller och layouter för artefakter (Original, Inline, Nested, Flat) tolkas där, och sedan skapas filen lokalt. Vi har ingen PDF.

PNG är undantaget: det är en bild av tråden, inte en tolkning som du kan söka i. Använd PNG när du behöver en visuell kopia från extractorn till ett ärende eller en presentation. Använd Markdown eller JSON när du behöver sökbar text. Varken PNG eller Markdown är en PDF; utskrift är fortfarande den PDF-liknande lösningen, se utskrift / PDF.

Extractorn kan inte hämta en chatt som Chrome aldrig har laddat. Privat läge, en utloggad flik eller en konversation som bara finns i Claude Desktop ger ingen fil. Öppna tråden på claude.ai medan du är inloggad och kör sedan extractorn. Export utan nätverk fungerar bara när sidan redan har laddats; det finns fortfarande ingen serverrunda för att skapa filens innehåll.

Vilka format kan extractorn skriva?

Markdown, JSON, ren text, XML och PNG – samma fem oavsett om du extraherar en Claude-chatt eller kör Export All. Download Claude conversations lägger inte till Word, Notion eller inbyggd PDF i 1.13.0. Formatvalet påverkar inte kvoten på 3 exporter; varje färdig fil räknas som en extrahering.

Markdown Läsbar .md med kodblock och tabeller Anteckningsvalv – Markdown

JSON från extractorn har inte samma struktur som Anthropics ZIP från Export data på kontonivå. Extractorns fil gäller en chatt (eller ett urval vid massexport) från sidan. ZIP-filen är ett arkiv för kontot som kommer senare. Mata inte in det ena i ett skript som väntar sig det andra. Översikt: alla format.

Kan jag extrahera många Claude-konversationer på en gång?

Ja. Öppna ”View and Download All Conversations” (visa och ladda ner alla konversationer), filtrera och klicka på ”Export All” (exportera alla). Extractorn skriver en fil per markerad chatt. Varje fil förbrukar en av de 3 gratis exporterna om kontot inte har Pro för 3,99 $/mån eller 26,99 $/år.

Filter på översiktssidan: All, New, Exported och Project. New betyder att extractorn inte har sparat chatten ännu. Exported markerar historik som du redan har extraherat så att en senare massexport kan hoppa över den. Project motsvarar projektgrupperingen på claude.ai. Sökningen hittar konversationer på namn innan du bestämmer dig för Export All.

Massexporten är ingen sämre tolkning. Thinking, Metadata, layout för artefakter och avsändaralternativ är desamma som i widgeten för en chatt. Genomgång med varningar om kvoten: exportera alla med Export All. Ville du ha en ZIP med hela kontot via e-post är det Settings → Privacy → Export data (namnen kan vara översatta om claude.ai är inställt på svenska), inte den här extractorn.

Tre gratis extraheringar totalt. Export All har ingen egen kvot. Markerar du 25 chattar går det åt 25 exporter om varje fil blir klar. Använd filtren New/Project, eller uppgradera till Pro (3,99 $/mån eller 26,99 $/år) före en stor körning med extractorn.

Extractor eller kopiera och klistra in?

Kopiera och klistra in duger för ett kort Claude-svar men fallerar på kod och tabeller. Anthropics Export data är ZIP-filen med säkerhetskopian av kontot. Extractorn ligger mittemellan: den här tråden eller ett urval av många, strukturerad fil, direkt, på claude.ai i Chrome.

Utskrift är ingen extractor. Den fångar webbsidan, inklusive gränssnitt som du inte vill ha i en anteckningsfil. Extractorn tar bort gränssnittet och behåller meddelandestrukturen. Behöver du ändå en PDF efter att ha extraherat Markdown konverterar du .md-filen själv; widgeten skapar ingen PDF.

Är det säkert att använda en extractor för Claude?

Den här extractorn använder din befintliga claude.ai-session på samma sätt som webbplatsen gör. Den automatiserar inte kontot och skickar inte chattarnas innehåll till vårt API. Google-inloggningen räknar de 3 gratis exporterna och återställer Pro. Paddle hanterar betalningen. Vi är inte Anthropic; deras villkor gäller fortfarande.

En Cloudflare Worker ser abonnemangsstatus: antal gratis exporter och om kontot har Pro eller inte. Den tar inte emot den extraherade Markdown-, JSON-, text-, XML- eller PNG-filen. Filerna lämnar aldrig webbläsaren, förutom till Chromes nedladdningsmapp. Hela gränsdragningen: så fungerar det. Den som undrar om en extractor för Claude-chattar är säker bör titta på den uppdelningen – betalningen i workern, chatten i fliken.

Vi kan inte lova ”noll nätverkstrafik”. claude.ai, Google och workern finns alla. Vi kan säga att chattarnas innehåll inte laddas upp till oss. Följ Anthropics användarvillkor. Download Claude conversations är ett fristående Chrome-tillägg, inte en officiell Anthropic-produkt. E-postadressen till supporten finns i sidfoten.

Mobilwebbläsare och Claude Desktop stöds inte. En extractor som är ett innehållsskript i Chrome kan inte köras där. Räkna inte med någon version för Safari eller Firefox i september 2026. Använd Chrome på datorn på claude.ai. Företagspolicyer som blockerar tillägg blockerar också den här extractorn.

Vad är en Claude conversation extractor?

Ett verktyg som läser en claude.ai-konversation som du har öppen och skriver Markdown, JSON, ren text, XML eller PNG. Download Claude conversations lägger till den orange knappen som gör den tolkningen lokalt i Chrome.

Är det skillnad på att extrahera och att exportera en Claude-chatt?

Nej – samma uppgift, olika verb. Extrahera, exportera och ladda ner leder alla till samma orange knapp och samma fem format på claude.ai. Den här sidan fokuserar på vad tolkaren behåller.

Kan jag extrahera en Claude-chatt utan att installera något?

Bara genom att kopiera och klistra in, vilket tappar kodblock och tabeller, eller via Anthropics Export data, som är en ZIP för hela kontot. En strukturerad extractor för Claude-konversationer måste läsa sidan; det gör Chrome-tillägget.

Kan extractorn extrahera många konversationer på en gång?

Ja. ”View and Download All Conversations”, sedan ”Export All”. Varje fil räknas mot de 3 gratis exporterna. Pro för 3,99 $/mån eller 26,99 $/år tar bort taket. Filter: All, New, Exported, Project.

Är det säkert att använda en extractor för Claude-chattar?

Den här läser den inloggade claude.ai-sessionen och skapar filerna lokalt. Konversationens text skickas inte till våra servrar. Vi är inte Anthropic; deras användarvillkor gäller fortfarande för dig.

Behöver jag Claude Pro för att extrahera en chatt?

Nej. Alla claude.ai-abonnemang som kan öppna tråden i Chrome fungerar. De första 3 filerna från extractorn är gratis hos oss. Anthropics betalda abonnemang har inget med vår kvot på 3 exporter att göra.

Fungerar extractorn i Claude Desktop?

Nej. Claude Desktop får aldrig den orange knappen. Öppna samma chatt på claude.ai om den synkas, eller kopiera och klistra in / använd den officiella ZIP-filen. Extractorn fungerar bara i Chrome på claude.ai.

Kan en extractor för Claude-konversationer skapa PDF?

Nej. Formaten är Markdown, JSON, ren text, XML och PNG. Skriv ut claude.ai-sidan om du behöver en PDF-liknande ögonblicksbild. PNG är en bild, inte en PDF.

Går det att extrahera en Claude-chatt i Claude Code?

Nej. Claude Code använder /export eller JSONL på disken. Den här extractorn är ett innehållsskript i Chrome för claude.ai, ingen koppling till terminalen.

Hur många gratis extraheringar tillåter extractorn?

Tre per konto med Google-inloggning, delade med Export All. En ominstallation nollställer inte räknaren. Pro återställs från samma Google-konto via betalning hos Paddle.

Vad hoppar extractorn över?

Sidans gränssnitt, skrivfältet och allt som inte är renderat i konversationen. Den hoppar också över chattar som aldrig har laddats i Chrome. Trådar som bara finns i Claude Desktop och JSONL från Claude Code ligger utanför.
