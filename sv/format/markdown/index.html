Hur exporterar jag en Claude-chatt till Markdown?

Öppna konversationen på claude.ai i Chrome, klicka på den orangea knappen bredvid meddelanderutan, välj Markdown och klicka på ”Export”. Download Claude conversations skriver en .md-fil lokalt. Så exporterar du en Claude-chatt till Markdown i version 1.13.0.

  1. Installera Download Claude conversations från Chrome Web Store (betyg 5,0).
  2. Ladda om claude.ai och öppna en riktig konversations-URL, inte den tomma startsidan med inmatningsrutan.
  3. Klicka på den orangea nedladdningsknappen till höger om meddelanderutan.
  4. Välj Markdown. Tillägget kommer ihåg det format du använde senast.
  5. Klicka på ”Export”. Chrome laddar ner .md-filen via webbläsarens nedladdnings-API.

Google-inloggning krävs innan du exporterar första gången. Download Claude conversations sparar den verifierade e-postadressen för att räkna de 3 gratis exporterna och för att återställa Pro efter en ominstallation. Chattexten laddas inte upp vid inloggningen. Tekniken: så fungerar det.

Saknas den orangea knappen är du inte på en konversations-URL, fliken behöver laddas om efter installationen eller så är tillägget fortfarande dolt under pusselikonen i Chrome. Fäst Download Claude conversations och uppdatera claude.ai. Innehållsskriptet körs aldrig i Claude Desktop eller Claude Code.

En chatt eller många. Den orangea knappen exporterar den öppna tråden som Markdown. För många .md-filer öppnar du ”View and Download All Conversations” (visa och ladda ner alla konversationer) och kör ”Export All” (exportera alla) med Markdown valt – se massexport med Export All.

Varför exportera Claude-chattar till Markdown för anteckningar?

Välj Markdown när du ska läsa filen i Obsidian, en GitHub-wiki eller någon editor som visar rubriker och kodblock. En .md-fil är ändå ren text som du kan söka i och jämföra. JSON passar bättre för parsers; PNG är en bild som du inte kan söka i.

Kopierar du från claude.ai försvinner oftast indragen och tabellerna blir platta. Utskrift (Ctrl/Cmd+P) tar med sidofältet och delar ofta ett långt kodblock över flera sidor. I en Markdown-export sitter språktaggarna kvar på kodblocken och tabellerna förblir tabeller. Därför väljer skribenter det här formatet först.

Vi ser Markdown som standardfilen för människor att läsa: rubriker, kodblock med språktaggar och tabeller från claude.ai-tråden. Vi hittar fortfarande inte på något PDF-format – behöver du en utskriftsbar sida, använd Chromes utskriftsdialog efter Markdown-exporten eller i stället för den.

Vad behålls när du exporterar en Claude-chatt till Markdown?

Download Claude conversations behåller rubriker, kodblock med språktaggar och indrag, tabeller och länkar. Tankeblock är valfria. Metadata (titel, tidsstämplar, modell) kan följa med. Avsändarfiltret kan begränsa .md-filen till alla meddelanden, bara människan eller bara assistenten.

Artefaktlayouten är en riktig inställning i version 1.13.0: ”Original”, ”Inline”, ”Nested” eller ”Flat” (ursprunglig, inbäddad, kapslad, platt). En Markdown-export kan spegla artefaktstrukturen på skärmen eller platta ut den till ett linjärt dokument. Alla inställningar: Chrome-tilläggets funktioner. Markdown behåller inte färgerna på meddelandebubblorna; använd PNG om du behöver en visuell ögonblicksbild.

Är tråden mycket lång, scrolla tills claude.ai har läst in tidigare meddelanden innan du exporterar. Tillägget kan bara skriva det som sidan har renderat. En halvt inläst tråd ger en halv .md-fil – det ser ut som en bugg men beror oftast på att sidan inte scrollats igenom.

Kan jag exportera Claude-chattar till Markdown i en massexport?

Ja. Öppna ”View and Download All Conversations”, välj formatet Markdown, filtrera tabellen och klicka på ”Export All”. Varje färdig .md-fil drar en export från samma 3 gratis exporter som en körning med den orangea knappen. Pro för 3,99 $/mån eller 26,99 $/år tar bort taket för massexport till Markdown.

Översiktstabellen listar din claude.ai-historik med namnsökning och filtren All, New, Exported och Project. New betyder att chatten ännu inte exporterats med Download Claude conversations. Exported håller koll på chattar du redan sparat, så att en andra körning av Export All kan hoppa över dem. Project motsvarar hur du grupperar chattar på claude.ai.

Kvoten gäller hela kontot. Tre gratis exporter totalt – inte tre Markdown-filer per dag. Väljer du 40 konversationer går 40 exporter åt om alla .md-filer blir klara. Planera urvalet innan du klickar på Export All.

Massexport till Markdown använder samma inställningar för tänkande, metadata, avsändare och artefakter som en enskild konversation. Export All är inte Anthropics fördröjda ZIP-arkiv. Det är många .md-filer, en per chatt. Vill du ha ett arkiv med hela kontot är det Settings → Privacy → Export data (etiketterna kan vara översatta om claude.ai är inställt på svenska), och det ger JSON, inte Markdown.

Markdown eller JSON när jag exporterar en Claude-chatt?

Välj Markdown när en människa ska läsa filen. Välj JSON när ett skript ska läsa meddelandeträdet. Download Claude conversations har båda i samma lista, plus ren text, XML och PNG. PDF finns fortfarande inte. Formatöversikt: exportformat för Claude-chattar.

Markdown jämfört med de andra exportfilerna från claude.ai
Format Välj det när
Markdown Anteckningar, Obsidian, GitHub, wikis
JSON Jämförelser, pipelines, verktyg – guide till JSON
Ren text Ingen markering alls, arkiv att klistra in var som helst
XML Ett system som kräver XML
PNG En bild av tråden, inte sökbar text

Anthropics Export data är också JSON, men det är ett ZIP-arkiv för kontot via e-post, inte en .md-fil per chatt. Du kan inte välja Markdown i den begäran. Skriv ut → Spara som PDF är en ögonblicksbild av webbsidan. Ingen av dem ersätter Markdown-exporten från den orangea knappen.

Tillägget körs bara på claude.ai i Chrome. Claude Desktop och Claude Code får ingen Markdown-knapp. Finns tråden också på claude.ai, öppna den där och exportera den till Markdown. Claude Codes /export är en annan väg i en annan produkt.

Kostar det extra att exportera Claude-chattar till Markdown?

Nej. Markdown ingår i de 3 gratis exporterna som varje konto med Google-inloggning får, precis som JSON, text, XML och PNG. Efter de tre filerna kostar Pro 3,99 $ i månaden eller 26,99 $ om året via Paddle. Download Claude conversations tar inget tillägg för Markdown.

De 3 gratis exporterna nollställs inte om du installerar om tillägget. Därför krävs Google-inloggning första gången du exporterar. Pro återställs på en ny dator med samma Google-konto. Paddle är återförsäljare (merchant of record); vi ser aldrig några kortnummer.

Du behöver inte Anthropics betalda claude.ai-abonnemang. Du behöver en inloggning som kan läsa in konversationen i Chrome. Team och Enterprise fungerar precis som Free med den orangea knappen. Version 1.13.0, september 2026, skriver fortfarande inte Word, Notion eller PDF.

Vanliga frågor: exportera Claude-chatt till Markdown

Frågorna gäller Markdown-export i Download Claude conversations 1.13.0: kodblock, massexport med Export All, Anthropics ZIP, kvot och Desktop. Varje svar är ett produktfaktum. FAQPage-datan (JSON-LD) i sidhuvudet motsvarar listan här.

Försvinner kod när jag exporterar en Claude-chatt till Markdown?

Nej. Kodblock behåller språktagg och indrag, till skillnad från vanlig kopiering från claude.ai. Tabeller förblir Markdown-tabeller. Det är huvudskälet att exportera till Markdown i stället för att markera text för hand.

Kan jag exportera Claude-chattar till Markdown i en massexport?

Ja. Export All på översiktssidan stöder Markdown precis som export av en enskild chatt. Varje färdig .md-fil räknas som en av de 3 gratis exporterna om du inte har Pro.

Är Markdown samma sak som Anthropics Export data?

Nej. Anthropics officiella export är ett ZIP-arkiv med JSON för hela kontot, som mejlas efter en väntetid. En Markdown-export är en .md-fil per chatt (eller per urval) från Download Claude conversations.

Kostar Markdown extra jämfört med andra format?

Nej. Markdown ingår i de 3 gratis exporterna på varje konto som loggat in med Google, precis som JSON, text, XML och PNG. Därefter kostar Pro 3,99 $/mån eller 26,99 $/år för obegränsat antal filer.

Kan jag exportera till Markdown i Claude Desktop?

Nej. Download Claude conversations körs bara på claude.ai i Chrome. Claude Desktop visar aldrig formatlistan med Markdown. Öppna samma tråd på claude.ai om den finns där.

Skapar en Markdown-export en PDF?

Nej. Markdown är en .md-textfil. Produkten skapar inte PDF. För en utskriftsbar sida, använd Chromes utskriftsdialog. PNG är en bild och inte heller en PDF.

Behöver jag Pro för att exportera till Markdown en gång?

Nej. De första 3 exporterna är gratis, i valfritt format, även Markdown. Pro för 3,99 $/mån eller 26,99 $/år tar bort gränsen för fler enskilda .md-filer eller massexporter.
