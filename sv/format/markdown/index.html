Hur exporterar jag en Claude-chatt till Markdown?

Öppna konversationen på claude.ai i Chrome, klicka på den orangea knappen bredvid meddelanderutan, välj Markdown och klicka på ”Export”. Download Claude conversations skriver en .md-fil lokalt. Så exporterar du en Claude-chatt till Markdown i version 1.16.2.

  1. Installera Download Claude conversations från Chrome Web Store.
  2. Ladda om claude.ai och öppna en riktig konversations-URL, inte den tomma startsidan med inmatningsrutan.
  3. Klicka på den orangea nedladdningsknappen till höger om meddelanderutan.
  4. Välj Markdown. Tillägget kommer ihåg det format du använde senast. Använd ”Select” (markera) för att bocka för bara de meddelanden du vill ha med.
  5. Klicka på ”Export”. Chrome laddar ner .md-filen via webbläsarens nedladdnings-API. Eller klicka på ”Copy” (kopiera) för att lägga Markdown-texten i urklipp.

Du behöver inte logga in för att exportera en Claude-chatt till Markdown. Markdown-export av enskilda chattar är obegränsad, anonym och skickar ingenting till våra servrar. Google-inloggning krävs bara för PDF och massexport med Export All. Tekniken: så fungerar det.

Saknas den orangea knappen är du inte på en konversations-URL, fliken behöver laddas om efter installationen eller så är tillägget fortfarande dolt under pusselikonen i Chrome. Fäst Download Claude conversations och uppdatera claude.ai. Innehållsskriptet körs aldrig i Claude Desktop eller i Claude Code i terminalen.

En chatt eller många. Den orangea knappen exporterar den öppna tråden som Markdown. För många .md-filer öppnar du ”View and Download All Conversations” (visa och ladda ner alla konversationer) och kör ”Export All” (exportera alla) med Markdown valt: ett ZIP-arkiv, 3 chattar per dag på gratisplanen – se massexport med Export All.

Varför exportera Claude-chattar till Markdown för anteckningar?

Välj Markdown när du ska läsa filen i Obsidian, en GitHub-wiki eller någon editor som visar rubriker och kodblock. En .md-fil är ändå ren text som du kan söka i och jämföra. JSON passar bättre för parsers; PNG är en bild som du inte kan söka i.

Kopierar du från claude.ai försvinner oftast indragen och tabellerna blir platta. Utskrift (Ctrl/Cmd+P) tar med sidofältet och delar ofta ett långt kodblock över flera sidor. I en Markdown-export sitter språktaggarna kvar på kodblocken och tabellerna förblir tabeller. Därför väljer skribenter det här formatet först.

Vi ser Markdown som standardfilen för människor att läsa: rubriker, kodblock med språktaggar och tabeller från claude.ai-tråden. Behöver du sidor i stället, välj PDF i samma panel. Den sätts upp i webbläsaren, med sidstorlek, marginaler och innehållsförteckning.

Vad behålls när du exporterar en Claude-chatt till Markdown?

Download Claude conversations behåller rubriker, kodblock med språktaggar och indrag, tabeller och länkar. Tankeblock, källor från webbsökning och verktygs- och MCP-steg väljer du till var för sig: ”Thinking” (tänkande) är en kryssruta i exportpanelen, och de andra två slås på i inställningarna. Metadata (titel, tidsstämplar, modell) kan följa med. Avsändarfiltret kan begränsa .md-filen till alla meddelanden, bara människan eller bara assistenten.

Artefaktlayouten är en riktig inställning i version 1.16.2: ”Original”, ”Inline”, ”Nested” eller ”Flat” (ursprunglig, inbäddad, kapslad, platt). En Markdown-export kan spegla artefaktstrukturen på skärmen, platta ut den till ett linjärt dokument eller lägga artefakterna i en egen mapp i ett ZIP-arkiv. I inställningarna kan du bädda in bilder i .md-filen. Alla inställningar: Chrome-tilläggets funktioner. Markdown behåller inte färgerna på meddelandebubblorna; använd PNG för en visuell ögonblicksbild eller PDF för sidor.

Är tråden mycket lång, scrolla tills claude.ai har läst in tidigare meddelanden innan du exporterar. Tillägget kan bara skriva det som sidan har renderat. En halvt inläst tråd ger en halv .md-fil – det ser ut som en bugg men beror oftast på att sidan inte scrollats igenom.

Kan jag exportera Claude-chattar till Markdown i en massexport?

Ja. Öppna ”View and Download All Conversations”, sätt ”Chat format” (chattformat) till Markdown, filtrera tabellen och klicka på ”Export All”. Chrome sparar ett ZIP-arkiv med en .md-fil per chatt. På gratisplanen gäller det 3 chattar per dag med Google-inloggning, delat med PDF. Pro för 3,99 $ i månaden eller 26,99 $ om året tar bort taket för massexport till Markdown.

Översiktssidan (Dashboard) listar din claude.ai-historik med namnsökning, filtren ”All conversations”, ”New”, ”Updated” och ”Previously exported” (alla konversationer, nya, uppdaterade, tidigare exporterade), flikarna ”Chat” och ”Cowork” samt projektsökning. New betyder att chatten ännu inte exporterats med Download Claude conversations. Previously exported håller koll på chattar du redan sparat, så att en andra körning av Export All kan hoppa över dem.

Dagsgränsen gäller per konto. Tre chattar per dag på gratisplanen, delat med PDF. Markerar du 40 konversationer när du har 3 kvar blockeras hela omgången – den kortas inte av. Välj färre eller använd Pro. Enskilda .md-exporter via den orangea knappen förblir obegränsade.

Massexport till Markdown använder kryssrutorna på översiktssidan – ”Chats”, ”Thinking”, ”Metadata”, ”Tools” och ”Sources” (chattar, tänkande, metadata, verktyg, källor) – plus artefaktformatet. Export All är inte Anthropics fördröjda ZIP-arkiv. Det är ett ZIP-arkiv med .md-filer, en per chatt. Vill du ha ett arkiv med hela kontot är det Settings → Privacy → Export data (etiketterna kan vara översatta om claude.ai är inställt på svenska), och det ger JSON, inte Markdown.

Markdown eller JSON när jag exporterar en Claude-chatt?

Välj Markdown när en människa ska läsa filen. Välj JSON när ett skript ska läsa meddelandeträdet. Download Claude conversations har båda i samma lista, plus PDF, ren text, XML, CSV och PNG. Formatöversikt: exportformat för Claude-chattar.

CSV Kalkylblad, en rad per meddelande

PNG En bild av tråden, inte sökbar text

Anthropics Export data är också JSON, men det är ett ZIP-arkiv för kontot via e-post, inte en .md-fil per chatt. Du kan inte välja Markdown i den begäran. Utskrift från webbläsaren är en ögonblicksbild av webbsidan. Ingen av dem ersätter Markdown-exporten från den orangea knappen.

Tillägget körs bara på claude.ai i Chrome. Claude Desktop och Claude Code i terminalen får ingen Markdown-knapp. Claude Code på webben (claude.ai/code) körs på claude.ai och exporteras därför som vilken chatt som helst. Finns tråden också på claude.ai, öppna den där och exportera den till Markdown. /export i Claude Code i terminalen är en annan väg i en annan produkt.

Kostar det extra att exportera Claude-chattar till Markdown?

Nej. Markdown-export av en chatt är gratis och obegränsad, utan konto och utan räknare – precis som JSON, text, XML, CSV och PNG. Bara PDF och massexport med Export All har en gratisgräns: 3 per dag med Google-inloggning. Pro kostar 3,99 $ i månaden eller 26,99 $ om året via Paddle. Download Claude conversations tar inget tillägg för Markdown.

Det är vid massexport till Markdown som gränsen märks. Varje chatt i ett ZIP-arkiv från Export All använder en av de 3 per dag, och räkningen nollställs vid midnatt UTC. Pro tar bort gränsen och återställs på en ny dator med samma Google-konto. Paddle är återförsäljare (merchant of record); vi ser aldrig några kortnummer.

Du behöver inte Anthropics betalda claude.ai-abonnemang. Du behöver en inloggning som kan läsa in konversationen i Chrome. Team och Enterprise fungerar precis som Free med den orangea knappen. Version 1.16.2, september 2026, skriver fortfarande inte Word eller Notion.

Vanliga frågor: exportera Claude-chatt till Markdown

Frågorna gäller Markdown-export i Download Claude conversations 1.16.2: kodblock, massexport med Export All, Anthropics ZIP, kostnad, PDF och Desktop. Varje svar är ett produktfaktum. FAQPage-datan (JSON-LD) i sidhuvudet motsvarar listan här.

Försvinner kod när jag exporterar en Claude-chatt till Markdown?

Nej. Kodblock behåller språktagg och indrag, till skillnad från vanlig kopiering från claude.ai. Tabeller förblir Markdown-tabeller. Det är huvudskälet att exportera till Markdown i stället för att markera text för hand.

Kan jag exportera Claude-chattar till Markdown i en massexport?

Ja. Export All på översiktssidan stöder Markdown och sparar ett ZIP-arkiv med .md-filer. På gratisplanen gäller det 3 chattar per dag med Google-inloggning; med Pro är det obegränsat.

Är Markdown samma sak som Anthropics Export data?

Nej. Anthropics officiella export är ett ZIP-arkiv med JSON för hela kontot, som mejlas efter en väntetid. En Markdown-export är en .md-fil per chatt (eller per urval) från Download Claude conversations.

Kostar Markdown extra jämfört med andra format?

Nej. Markdown-export av enskilda chattar är obegränsad och kräver inget konto, precis som JSON, text, XML, CSV och PNG. Bara PDF och ZIP-massexport har en gratisgräns på 3 per dag. Pro kostar 3,99 $ i månaden eller 26,99 $ om året.

Kan jag exportera till Markdown i Claude Desktop?

Nej. Download Claude conversations körs bara på claude.ai i Chrome. Claude Desktop visar aldrig formatlistan med Markdown. Öppna samma tråd på claude.ai om den finns där.

Skapar en Markdown-export en PDF?

Nej. Markdown är en .md-textfil. För sidor väljer du i stället PDF i samma panel: den skapas i webbläsaren med sidstorlek, marginaler och innehållsförteckning. PDF kräver Google-inloggning och räknas mot 3 per dag på gratisplanen.

Behöver jag Pro för att exportera till Markdown en gång?

Nej. Du behöver inget konto alls. Markdown-export av enskilda chattar är obegränsad på gratisplanen. Pro för 3,99 $ i månaden eller 26,99 $ om året lyfter bara gränsen på 3 per dag för massexport med Export All och för PDF.
