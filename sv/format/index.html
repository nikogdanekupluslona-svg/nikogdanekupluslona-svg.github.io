Vilka exportformat för Claude-chattar finns här?

Exportformaten på den här webbplatsen är de fem filtyper som Download Claude conversations skriver från en claude.ai-tråd: Markdown, JSON, ren text, XML och PNG. Version 1.13.0 kan inte skapa PDF. Varje färdig fil räknas som en av de 3 gratis exporterna.

Tillägget körs bara på claude.ai. Claude Desktop och Claude Code visar aldrig den orangea knappen. Finns samma tråd på ditt claude.ai-konto, öppna den URL:en i Chrome och välj format där. Listan kommer ihåg det format du valde senast.

Många söker också på Claude Chat Downloader och Claude Conversation Downloader efter samma tillägg. De namnen syftar på den här produkten, inte på ett annat exportverktyg. Juridiska sidor kan fortfarande säga Claude Exporter. Filerna du får är ändå Markdown, JSON, text, XML eller PNG.

En lista, två ingångar. Den orangea knappen och Export All har samma exportformat. En massexport ger många filer, en per chatt – inte ett blandat ZIP-arkiv. Mer: massexport med Export All.

Vilket exportformat för Claude-chattar ska jag välja?

Välj Markdown för anteckningar, JSON för skript, ren text för ett arkiv som kan klistras in var som helst, XML när ett system kräver XML och PNG för en bild av tråden. Download Claude conversations utser inget format till bäst. Formaten skiljer sig i form, inte i kvot.

Skribenter hamnar oftast på Markdown. Utvecklare hamnar oftast på JSON. PNG är det enda bildformatet; i efterhand kan du varken söka i den eller kopiera kod rent. Behöver du en utskriftsbar sida, använd Chromes utskriftsdialog. Det ger en ögonblicksbild från webbläsaren, inte ett sjätte produktformat.

Vi levererar fem exportformat – Markdown, JSON, text, XML och PNG – och vi skapar fortfarande inte PDF. Listan är densamma i den orangea knappen och i Export All, så en massexport hittar aldrig på en annan filtyp.

Hur väljer jag exportformat för Claude-chattar?

Öppna en konversations-URL på claude.ai i Chrome, klicka på den orangea knappen bredvid meddelanderutan, välj ett av formaten och klicka på ”Export” (exportera). Download Claude conversations sätter ihop filen i fliken. claude.ai har ingen inbyggd knapp för att exportera en enskild chatt i september 2026.

  1. Installera Download Claude conversations från Chrome Web Store (betyg 5,0).
  2. Ladda om claude.ai och öppna en riktig konversations-URL, inte den tomma startsidan med inmatningsrutan.
  3. Klicka på den orangea nedladdningsknappen till höger om meddelanderutan.
  4. Välj Markdown, JSON, ren text, XML eller PNG. Det senaste formatet sparas.
  5. Klicka på ”Export”. Chrome sparar filen direkt.

Google-inloggning krävs före den första exporten. Download Claude conversations sparar den verifierade e-postadressen för att räkna de 3 gratis exporterna och för att återställa Pro efter en ominstallation. Chattexten ingår inte i inloggningen. Tekniken: så fungerar det.

Inställningarna i samma ruta gäller alla format: tänkande på eller av, metadata (titel, tidsstämplar, modell), avsändarfilter (”all”, ”human only”, ”assistant only” – alla, bara människa, bara assistent) och artefaktlayout (”Original”, ”Inline”, ”Nested”, ”Flat”). PNG blir fortfarande en bild; de andra fyra skriver text eller strukturerad markering.

Fungerar exportformaten för Claude-chattar i Export All?

Ja. Öppna ”View and Download All Conversations” (visa och ladda ner alla konversationer), filtrera tabellen, välj i samma formatlista och klicka på ”Export All” (exportera alla). Varje färdig fil är en av de 3 gratis exporterna. Pro för 3,99 $/mån eller 26,99 $/år tar bort taket för både massexport och enskilda chattar.

Översiktstabellen listar din claude.ai-historik med namnsökning och filtren All, New, Exported och Project. New betyder att chatten ännu inte exporterats med Download Claude conversations. Exported håller koll på chattar du redan sparat. Project motsvarar hur du grupperar chattar på claude.ai. Export All är inte ett fördröjt ZIP-arkiv för kontot.

Kvoten gäller hela kontot. Tre gratis exporter totalt – inte tre per format och inte tre per massexport. Väljer du 40 konversationer går 40 exporter åt om alla filer blir klara. Planera urvalet, eller använd Pro.

Massexporten använder samma inställningar för tänkande, metadata, avsändare och artefakter som en enskild konversation. Du får inget blandat paket med Markdown och JSON i ett klick. Du väljer ett format för körningen. Kör Export All igen med ett annat format om du behöver samma tråd i två former; den andra körningen drar också av kvoten.

Exportformat för Claude-chattar eller Anthropics ZIP?

Anthropics Settings → Privacy → Export data (etiketterna kan vara översatta om claude.ai är inställt på svenska) mejlar ett ZIP-arkiv med JSON för hela kontot efter en väntetid. Download Claude conversations sparar den öppna tråden direkt som Markdown, JSON, text, XML eller PNG. Använd ZIP-arkivet för backup; använd tillägget när du behöver filen nu.

Det officiella ZIP-arkivet är inte en snyggare variant av tilläggets format. Du kan inte välja Markdown i den begäran. Download Claude conversations kan inte ersätta ZIP-arkivet om du vill ha varenda bortglömd tråd i ett och samma arkiv. Utskrift är en visuell nödlösning, inte ett format vi levererar.

Download Claude conversations är inte knutet till Anthropic, PBC. Att använda tillägget ändrar inte Anthropics användarvillkor. Innehållsskriptet använder den session du redan har öppnat på claude.ai. Följ Anthropics regler för ditt konto.

Vad kostar exportformaten för Claude-chattar?

Varje konto som loggat in med Google får 3 gratis exporter. Därefter kostar Pro 3,99 $ i månaden eller 26,99 $ om året via Paddle. Priset gäller alla format. Download Claude conversations tar inte extra betalt för JSON eller PNG.

De 3 gratis exporterna nollställs inte om du installerar om tillägget. Därför krävs Google-inloggning vid första klicket på Export. Pro återställs på en ny dator med samma Google-konto. Paddle är återförsäljare (merchant of record); vi ser aldrig några kortnummer.

Versionen på den här sidan är 1.13.0, daterad september 2026. Exportformaten är fortfarande Markdown, JSON, ren text, XML och PNG. Det finns fortfarande ingen export till Notion eller Word och ingen inbyggd PDF. Ändras listan, uppdateras den här översikten samma dag.

Vanliga frågor: exportformat för Claude-chattar

Frågorna gäller exportformaten i Download Claude conversations 1.13.0: listan med fem filtyper, kvot, Export All, Anthropics ZIP, Desktop och Pro. Varje svar är ett produktfaktum. FAQPage-datan (JSON-LD) i sidhuvudet motsvarar listan här.

Vilka exportformat för Claude-chattar kan jag ladda ner?

Markdown, JSON, ren text, XML och PNG. Download Claude conversations skapar inte PDF. PNG är en bild av claude.ai-tråden, inte ett dokument med sidor.

Är PDF ett av exportformaten?

Nej. Formatlistan innehåller aldrig PDF. Vill du ha en PDF-liknande sida kan du skriva ut claude.ai-fliken i Chrome. Den filen är en ögonblicksbild från webbläsaren, inte en export från tillägget.

Delar alla format på de 3 gratis exporterna?

Ja. Markdown, JSON, text, XML och PNG räknas var för sig som en export när filen är klar. Pro för 3,99 $/mån eller 26,99 $/år tar bort taket för alla format.

Kan jag blanda format i Export All?

Nej. En körning av Export All använder ett format. Kör den igen med ett annat format om du behöver två filer av samma claude.ai-chatt. Varje färdig fil räknas fortfarande mot kvoten.

Är exportformaten samma sak som Export data?

Nej. Anthropics Export data är ett fördröjt ZIP-arkiv med JSON för hela kontot. Tilläggets exportformat är filer per chatt (eller per urval) som Download Claude conversations skriver direkt i Chrome.

Fungerar exportformaten i Claude Desktop eller Claude Code?

Nej. Chrome-tillägget körs bara på claude.ai. Claude Desktop och Claude Code visar aldrig formatlistan. Öppna samma tråd på claude.ai i Chrome om den finns där.

Behöver jag Pro för att prova exportformaten?

Nej. De första 3 exporterna på varje konto som loggat in med Google är gratis, i valfritt format. Pro kostar 3,99 $/mån eller 26,99 $/år när du behöver fler enskilda filer eller massexporter.
