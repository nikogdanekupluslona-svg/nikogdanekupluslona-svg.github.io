Hur exporterar jag en Claude-chatt till XML?

Öppna konversationen på claude.ai i Chrome, klicka på den orangea knappen bredvid meddelanderutan, välj XML och klicka på ”Export”. Download Claude conversations skriver filen lokalt. Så exporterar du en Claude-chatt till XML i version 1.16.2. claude.ai har ingen inbyggd funktion för att spara som XML i september 2026.

  1. Installera Download Claude conversations från Chrome Web Store.
  2. Ladda om claude.ai och öppna en riktig konversations-URL, inte den tomma startsidan med inmatningsrutan.
  3. Klicka på den orangea nedladdningsknappen till höger om meddelanderutan.
  4. Välj XML. Det senast använda formatet sparas. Använd ”Select” (markera) för att bocka för bara de meddelanden du vill ha med.
  5. Klicka på ”Export”. Chrome laddar ner XML-filen via webbläsarens nedladdnings-API. Eller klicka på ”Copy” (kopiera) för att lägga XML-texten i urklipp.

Du behöver inte logga in för att exportera en Claude-chatt till XML. XML-export av enskilda chattar är obegränsad, anonym och skickar ingenting till våra servrar. Google-inloggning krävs bara för PDF och massexport med Export All. Tekniken: så fungerar det.

Saknas den orangea knappen är du inte på en konversations-URL, fliken behöver laddas om eller så är tillägget dolt under pusselikonen i Chrome. Fäst Download Claude conversations och uppdatera claude.ai. XML-export finns aldrig i Claude Desktop eller i Claude Code i terminalen.

En fil eller många. Den orangea knappen exporterar den öppna tråden som XML. För många XML-filer öppnar du ”View and Download All Conversations” (visa och ladda ner alla konversationer) och kör ”Export All” (exportera alla) med XML valt: ett ZIP-arkiv, 3 chattar per dag på gratisplanen – se massexport med Export All.

När ska jag exportera en Claude-chatt till XML?

Välj XML när systemet, pipelinen eller det äldre verktyget som tar emot filen kräver XML för strukturerat datautbyte. De flesta utvecklare bör välja JSON i stället. Markdown är för anteckningar som människor läser. CSV är för kalkylblad. PNG är en bild. XML finns i listan för att vissa verktyg fortfarande läser in XML och inte accepterar JSON.

Exportera inte till XML i tron att det är en ”mer officiell” JSON. Download Claude conversations läser av sidan på samma sätt i båda fallen. Skillnaden ligger i filens form, inte i att det dyker upp extra fält. Om inget av dina verktyg kräver XML, hoppa över formatet och använd JSON.

Vi levererar XML för att vissa pipelines fortfarande kräver det, inte för att vi tycker att det slår JSON för varje export från claude.ai. Avläsningen är densamma: meddelanden, avsändare, valfritt tänkande och artefakter. I version 1.16.2 är XML ett av sju format, gratis utan konto, inte ett betalt tillägg.

Många söker också på Claude Chat Downloader och Claude Conversation Downloader efter samma tillägg. XML-exporten är samma orangea knapp. Juridiska sidor kan fortfarande säga Claude Exporter. De namnen syftar på den här produkten.

Vad behålls när du exporterar en Claude-chatt till XML?

Download Claude conversations skriver konversationens struktur – meddelanden, avsändare och tillgänglig metadata – som XML-markering. Tankeblock, källor från webbsökning, verktygs- och MCP-steg och artefakter följer samma alternativ som i Markdown och JSON: ”Thinking” (tänkande) är en kryssruta i exportpanelen, och verktyg och källor slås på i inställningarna. XML är ingen avskalad släkting till de formaten.

Artefaktlayouten i version 1.16.2 är ”Original”, ”Inline”, ”Nested” eller ”Flat” (ursprunglig, inbäddad, kapslad, platt). Avsändarfiltret kan begränsa XML-filen till alla meddelanden, bara människan eller bara assistenten. Metadata (titel, tidsstämplar, modell) kan följa med. Alla inställningar: Chrome-tilläggets funktioner.

XML eller JSON när jag exporterar en Claude-chatt?

JSON är utvecklarnas vanliga val. Välj XML bara när ett system längre fram i kedjan kräver det. Download Claude conversations gör inte XML ”mer komplett” än JSON. Båda kan innehålla tänkande och artefakter. Ingen av dem är Anthropics ZIP-arkiv för kontot. Formatöversikt: exportformat för Claude-chattar.

Anthropics Settings → Privacy → Export data (etiketterna kan vara översatta om claude.ai är inställt på svenska) ger JSON (i ett ZIP-arkiv), inte XML. PDF från samma panel är sidor för människor, inte markering. Ingen av dem ersätter XML-exporten från den orangea knappen. Räkna inte med att XML-filen matchar något opublicerat schema från Anthropic.

Tillägget körs bara på claude.ai i Chrome. Claude Desktop och Claude Code i terminalen får ingen XML-knapp. Claude Code på webben (claude.ai/code) körs på claude.ai och exporteras därför som vilken chatt som helst. Finns tråden också på claude.ai, öppna den där och exportera den till XML. /export i Claude Code i terminalen är en annan väg i en annan produkt.

Kan jag exportera Claude-chattar till XML i en massexport?

Ja. Öppna ”View and Download All Conversations”, sätt ”Chat format” (chattformat) till XML, filtrera tabellen och klicka på ”Export All”. Chrome sparar ett ZIP-arkiv med en XML-fil per chatt. På gratisplanen gäller det 3 chattar per dag med Google-inloggning, delat med PDF. Pro för 3,99 $ i månaden eller 26,99 $ om året tar bort taket för massexport till XML.

Översiktssidan (Dashboard) listar din claude.ai-historik med namnsökning, filtren ”All conversations”, ”New”, ”Updated” och ”Previously exported” (alla konversationer, nya, uppdaterade, tidigare exporterade), flikarna ”Chat” och ”Cowork” samt projektsökning. New betyder att chatten ännu inte exporterats med Download Claude conversations. Previously exported håller koll på chattar du redan sparat. Export All ger ett ZIP-arkiv med XML-filer, en per chatt – inte ett arkiv med blandade format.

Dagsgränsen gäller per konto. Tre chattar per dag på gratisplanen, delat med PDF. Markerar du 40 konversationer när du har 3 kvar blockeras hela omgången – den kortas inte av. Välj färre eller använd Pro. Enskilda XML-exporter via den orangea knappen förblir obegränsade.

Du kan inte blanda XML och JSON i ett klick på Export All. Välj XML för den körningen. Kör Export All igen med JSON om du behöver samma claude.ai-tråd i båda formerna; den andra körningen räknar varje chatt igen.

Kräver XML-export av Claude-chattar Pro?

Nej. XML-export av en chatt är gratis och obegränsad, utan konto och utan räknare – precis som Markdown, JSON, text, CSV och PNG. Bara PDF och massexport med Export All har en gratisgräns: 3 per dag med Google-inloggning. Pro kostar 3,99 $ i månaden eller 26,99 $ om året via Paddle. Download Claude conversations behandlar inte XML som ett betalformat.

Det är vid massexport till XML som gränsen märks. Varje chatt i ett ZIP-arkiv från Export All använder en av de 3 per dag, och räkningen nollställs vid midnatt UTC. Pro tar bort gränsen och återställs på en ny dator med samma Google-konto. Paddle är återförsäljare (merchant of record); vi ser aldrig några kortnummer.

Du behöver inte Anthropics betalda claude.ai-abonnemang. Du behöver en inloggning som kan läsa in konversationen i Chrome. Version 1.16.2, september 2026, skriver fortfarande inte Word eller Notion. Ändras listan, uppdateras den här sidan samma dag.

Vanliga frågor: exportera Claude-chatt till XML

Frågorna gäller XML-export i Download Claude conversations 1.16.2: jämförelse med JSON, massexport med Export All, kostnad, Desktop, PDF och Pro. Varje svar är ett produktfaktum. FAQPage-datan (JSON-LD) i sidhuvudet motsvarar listan här.

Är XML bättre än JSON för export av Claude-chattar?

Inte generellt. JSON är det vanligare valet för utvecklare. Exportera till XML när systemet som tar emot filen kräver XML för strukturerat datautbyte. Avläsningen från claude.ai är densamma; det är filens form som skiljer sig.

Kan jag massexportera Claude-chattar till XML?

Ja. Samma Export All-flöde på översiktssidan stöder XML och sparar ett ZIP-arkiv med en XML-fil per chatt. På gratisplanen gäller det 3 chattar per dag med Google-inloggning; Pro för 3,99 $ i månaden eller 26,99 $ om året är obegränsat.

Är XML ett format bara för betalande?

Nej. XML-export av enskilda chattar är obegränsad och kräver inget konto, precis som Markdown, text, JSON, CSV och PNG. Bara PDF och massexport med Export All har en gratisgräns på 3 per dag. Pro kostar 3,99 $ i månaden eller 26,99 $ om året.

Motsvarar XML-exporten Anthropics ZIP-arkiv?

Nej. Anthropics Export data är ett fördröjt ZIP-arkiv med JSON för kontot. Download Claude conversations skriver en XML-fil per chatt (eller per urval) direkt i Chrome. Schemat är inte detsamma.

Skapar en XML-export en PDF?

Nej. XML är markering. För sidor väljer du PDF i samma panel; de sju formaten är PDF, Markdown, JSON, ren text, XML, CSV och PNG. PDF kräver Google-inloggning och räknas mot 3 per dag på gratisplanen.

Kan jag exportera till XML i Claude Desktop?

Nej. Chrome-tillägget körs bara på claude.ai. Claude Desktop visar aldrig formatlistan med XML. Öppna samma tråd på claude.ai i Chrome om den finns där.

Behöver jag Pro för att exportera till XML en gång?

Nej. Du behöver inget konto alls. XML-export av enskilda chattar är obegränsad på gratisplanen. Pro för 3,99 $ i månaden eller 26,99 $ om året lyfter bara gränsen på 3 per dag för massexport med Export All och för PDF.
