Exportera en Claude-konversation som läsbar fil

Att exportera en Claude-konversation betyder att spara en claude.ai-tråd som fil. Installera Download Claude conversations, öppna konversationens adress, klicka på den orange knappen, välj Markdown, JSON, text, XML eller PNG och klicka på ”Export” (exportera). Filerna skapas lokalt i Chrome, inte i Claude Desktop eller Claude Code. Tre exporter är gratis; Pro kostar 3,99 $/mån eller 26,99 $/år.

Hur fungerar export av en Claude-konversation i Chrome?

Öppna en konversationsadress på claude.ai i Chrome, klicka på den orange knappen till höger om meddelanderutan, välj Markdown, JSON, text, XML eller PNG och klicka på ”Export”. Download Claude conversations skriver filen med konversationen lokalt. Ladda om claude.ai efter installationen. claude.ai har ingen exportknapp per tråd.

  1. Installera Download Claude conversations från Chrome Web Store (betyg 5,0, version 1.13.0).
  2. Ladda om claude.ai-fliken så att innehållsskriptet kan läggas in på en konversationsadress.
  3. Öppna en riktig konversation, inte den tomma startsidan med skrivfältet på claude.ai.
  4. Klicka på den orange nedladdningsknappen till höger om meddelanderutan.
  5. Välj Markdown, JSON, ren text, XML eller PNG och klicka sedan på ”Export”.

Google-inloggning krävs före det första klicket på ”Export”. Download Claude conversations sparar den verifierade e-postadressen så att de 3 gratis exporterna och Pro kan återställas efter en ominstallation. Konversationens text ingår inte i Google-inloggningen. Så fungerar det tekniskt: så fungerar det.

Om den orange knappen saknas är fliken inte på en konversationsadress på claude.ai, sidan behöver fortfarande laddas om efter installationen, eller så ligger Download Claude conversations gömt i Chromes pusselmeny. Fäst tillägget och uppdatera. Den orange knappen visas aldrig på andra webbplatser.

Formatvalet i Download Claude conversations kommer ihåg det senaste valet. Markdown, JSON, ren text, XML och PNG räknas var och en som en export när Chrome har laddat ner filen. Ofullständiga filer betyder oftast att den långa claude.ai-tråden inte hade renderat klart meddelandeträdet. Vänta och klicka på ”Export” igen.

En konversation eller hela kontot. Den orange knappen exporterar den öppna tråden. För många filer öppnar du ”View and Download All Conversations” (visa och ladda ner alla konversationer) och kör ”Export All” (exportera alla). Anthropics Settings → Privacy → Export data (namnen kan vara översatta om claude.ai är inställt på svenska) är en JSON-ZIP för kontot som kommer senare, inte det här flödet i Chrome.

Vad behåller den exporterade filen?

En konversation som exporteras med Download Claude conversations behåller meddelandeträdet som redan är renderat på claude.ai: avsändare, kodblock, tabeller, valfritt resonemang, metadata och layout för artefakter. Det är ingen skärmdump av sidopanelen. PNG är bildalternativet. Version 1.13.0 skapar fortfarande ingen PDF.

Kopiera och klistra in från claude.ai tappar indrag och klämmer ihop tabeller. Utskrift (Ctrl/Cmd+P) tar med claude.ai:s gränssnitt och delar ofta ett långt kodblock över flera sidor. Download Claude conversations behåller språktaggar på kodblock och låter tabeller förbli tabeller i Markdown, JSON och XML. PNG är en bild av tråden, inte en sidindelad PDF.

Tankeblock är en inställning i version 1.13.0. Metadata kan innehålla titel, tidsstämplar och modell. Avsändarfiltret kan begränsa filen till alla meddelanden, bara människa eller bara assistent (”all / human only / assistant only”). Layouten för artefakter är ”Original”, ”Inline”, ”Nested” eller ”Flat” (original, inbäddade, nästlade eller platta). Inställningarna gäller både den öppna tråden och Export All.

Vi byggde exporten av Claude-konversationer kring den orange knappen på claude.ai: den skriver Markdown, JSON, text, XML eller PNG från konversationen som redan visas på skärmen, utan att ladda upp tråden. Version 1.13.0 skapar fortfarande ingen PDF.

Hur exporterar jag en konversation från Claude som Markdown?

Att exportera en konversation från Claude som Markdown är skribentens väg: orange knapp, Markdown i listrutan, ”Export”. Download Claude conversations skriver även JSON, ren text, XML och PNG från samma claude.ai-tråd. Det finns inget PDF-format i version 1.13.0. Formatvalet påverkar inte kvoten på 3 exporter.

Format som Download Claude conversations skapar från en claude.ai-konversation
Format Passar för Du får
Markdown Obsidian, GitHub, wikis Rubriker, kodblock, tabeller
JSON Jämförelser, dataflöden, verktyg Meddelandeträd – se guiden om konversationen som JSON-fil

Skribenter väljer oftast Markdown när de exporterar Claude-konversationer som anteckningar. Utvecklare väljer oftast JSON när de behöver en maskinläsbar konversationsfil. Ren text är arkivet utan märkning. XML är för datautbyte som kräver taggar. PNG är filen som liknar en skärmdump. Download Claude conversations lägger inte till export till Word, Notion eller Google Docs i 1.13.0.

Behöver du just en PDF-liknande sida skriver du ut claude.ai-konversationen från Chrome i stället för att vänta på ett format som vi inte har. En PNG från Download Claude conversations är en bildfil. Markdown från en exporterad konversation kan konverteras senare i Word, Google Docs eller en Markdown-app om du behöver ett sidindelat dokument.

Varje färdig nedladdning i Markdown, JSON, text, XML eller PNG räknas som en av de 3 gratis exporterna på ett konto med Google-inloggning. Pro för 3,99 $/mån eller 26,99 $/år tar bort taket för alla format. Att exportera samma claude.ai-konversation igen i ett annat format kostar ytterligare en export om du inte har Pro.

Kan jag exportera Claude-konversationer med Export All?

Ja. Öppna ”View and Download All Conversations”, filtrera och klicka på ”Export All” för att exportera Claude-konversationer som en fil per tråd. Varje färdig fil använder samma 3 gratis exporter som den orange knappen. Pro för 3,99 $/mån eller 26,99 $/år tar bort taket för massexport precis som för en tråd.

Översiktstabellen listar claude.ai-historiken med sökning på namn och filtren All, New, Exported och Project. New betyder ännu inte sparad med Download Claude conversations. Exported håller reda på konversationer du redan har skrivit till disken så att en andra körning av Export All kan hoppa över dem. Project motsvarar hur du grupperar trådar på claude.ai.

Massexporten använder samma inställningar som export av en enskild konversation: Chats, Thinking, Metadata, layout för artefakter (Original, Inline, Nested, Flat) och samma fem format. Export All är ingen avskalad ZIP av hela kontot. Det är många filer, en per konversation. Anthropics Export data är fortfarande JSON-ZIP-filen för kontot som kommer senare.

Kvoten gäller hela kontot. Tre gratis exporter totalt – inte tre per körning. Markerar du 40 konversationer på översiktssidan går det åt 40 exporter om varje fil blir klar. Planera urvalet innan du klickar på ”Export All”, eller använd Pro för 3,99 $/mån eller 26,99 $/år. Detaljer om den gemensamma kvoten: exportera alla med Export All.

Export All och den orange knappen delar på en kvot kopplad till Google-inloggningen. Du kan inte få tre gratis filer från den orange knappen och ytterligare tre från Export All. En ominstallation av Download Claude conversations nollställer inte räknaren. Pro återställs på en ny dator från samma Google-konto via Paddle.

Kan jag exportera en Claude-session i Desktop eller Code?

På claude.ai är en session den öppna konversationsadressen. Att exportera en Claude-session där betyder den orange knappen i Chrome, inte en koppling till Desktop eller terminalen. Download Claude conversations körs bara på claude.ai. Claude Desktop visar aldrig den orange knappen. Claude Code använder /export eller JSONL i ~/.claude/projects.

Om tråden även finns i ditt claude.ai-konto öppnar du konversationen i Chrome och exporterar den med Download Claude conversations. Finns chatten bara i Claude Desktop kopierar du från appen eller begär Settings → Privacy → Export data på webben. Jämförelse: exportera en Claude Desktop-chatt.

Claude Code är en annan produkt och en annan väg. Kör /export i terminalen, eller kopiera JSONL-transkript från ~/.claude/projects. Download Claude conversations läser inte de filerna och kopplar inte in sig i CLI:n. Letar du efter hur du exporterar en session från agenten i terminalen är det den vägen på disken – guide: export från Claude Code.

claude.ai i en mobilwebbläsare ligger också utanför. Download Claude conversations kräver Chrome på datorn (eller en annan Chromium-webbläsare som kan installera tillägg från Chrome Web Store). Det finns ingen app för iOS eller Android från oss 2026. Öppna konversationen på en dator och använd sedan den orange knappen eller Export All.

Team- och Enterprise-arbetsytor på claude.ai använder fortfarande konversationsadresser i Chrome. Om en administratör blockerar tillägg körs Download Claude conversations inte – det är en policy i webbläsaren, inte ett saknat format. Den orange knappen visas bara efter en omladdning på en konversationsadress som du har behörighet att öppna.

Exportera Claude-konversation eller Anthropics Export data?

Anthropics Export data skickar en JSON-ZIP med hela kontot via e-post efter en väntetid. Att exportera en Claude-konversation med Download Claude conversations sparar den öppna tråden direkt som Markdown, JSON, text, XML eller PNG. Använd ZIP-filen som säkerhetskopia. Använd Chrome-tillägget för en läsbar fil från claude.ai nu.

Den officiella ZIP-filen är ingen snyggare variant av att exportera en konversation. Den är JSON på kontonivå. Du kan inte välja en claude.ai-konversation eller Markdown i den begäran. Download Claude conversations kan inte ersätta ZIP-filen om du behöver varje bortglömd tråd i ett arkiv. Jämförelse av metoder: så exporterar du en Claude-chatt.

Vad kostar det att exportera Claude-konversationer?

Varje konto med Google-inloggning får 3 gratis exporter. Därefter kostar Pro 3,99 $ per månad eller 26,99 $ per år via Paddle. Priset gäller både den orange knappen och Export All. Download Claude conversations tar inte betalt per format. Alla claude.ai-abonnemang fungerar om Chrome kan öppna konversationen.

De 3 gratis exporterna nollställs inte när du installerar om tillägget. Det är därför Google-inloggning krävs vid det första klicket på ”Export”. Pro återställs på en ny dator från samma Google-konto. Paddle är återförsäljare (merchant of record); vi ser aldrig några kortnummer. Återbetalningar går via Paddle enligt sidan om återbetalning.

Du behöver inte Anthropics betalda claude.ai-abonnemang för att exportera konversationer. Du behöver en claude.ai-inloggning som kan ladda konversationen, plus Chrome. Team och Enterprise fungerar precis som Free med den orange knappen. Om Chrome blockerade nedladdningen tillåter du nedladdningar från claude.ai innan du klickar på ”Export” igen.

Samma uppgift, olika sökord. ”Exportera Claude-konversation”, ”exportera Claude-konversationer” och engelska ”claude export conversation” betyder alla att spara tråden som fil. Den här sidan använder orden konversation och session. Produktsidan med ordet chatt är en systersida, inte ett andra tillägg.

Felsökning när exporten misslyckas: vänta tills den långa tråden har laddats i claude.ai, kontrollera listrutan för format (det senast använda formatet ligger kvar) och kontrollera spärren på 3 exporter. Ofullständiga PNG- eller Markdown-filer betyder oftast att meddelandeträdet fortfarande strömmades. Scrolla i konversationen och klicka på ”Export” när assistentens sista tur syns på skärmen.

Sidan gäller version 1.13.0, september 2026. Formaten är fortfarande Markdown, JSON, ren text, XML och PNG. Ändras listan uppdateras guiden samma dag. Fram till dess ska du inte räkna med Word, Notion eller inbyggd PDF från Download Claude conversations på claude.ai.

Vanliga frågor: exportera Claude-konversation

De här frågorna handlar om att exportera Claude-konversationer: format, kvot, Claude Desktop, Claude Code, Anthropics ZIP och den orange knappen på claude.ai. Varje svar är ett faktum från Download Claude conversations 1.13.0. FAQPage-datan (JSON-LD) i sidhuvudet motsvarar listan.

Vad betyder ”exportera Claude-konversation” på den här webbplatsen?

Att spara en claude.ai-konversation som fil med Download Claude conversations: orange knapp, formatval, ”Export”. Samma uppgift som engelska ”claude export conversation”. Inte Anthropics ZIP via e-post och inte /export i Claude Code.

Är export av en Claude-konversation samma sak som Export data?

Nej. Settings → Privacy → Export data är en JSON-ZIP med hela kontot via e-post. Med det här tillägget skrivs den öppna tråden eller ett urval från Export All som Markdown, JSON, text, XML eller PNG direkt i Chrome.

Kan en exporterad Claude-konversation bli en PDF?

Inte med Download Claude conversations. Formaten är Markdown, JSON, ren text, XML och PNG. För en PDF-liknande ögonblicksbild skriver du ut claude.ai-sidan i Chrome. PNG är en bild, inte en PDF.

Behöver jag Pro för att exportera en Claude-konversation en gång?

Nej. De första 3 exporterna på ett konto med Google-inloggning är gratis, i valfritt format. Pro för 3,99 $/mån eller 26,99 $/år tar bort gränsen för fler enskilda filer eller massexport.

Fungerar exporten av Claude-konversationer med alla claude.ai-abonnemang?

Ja. Free, Pro, Team och Enterprise på claude.ai fungerar om du kan öppna konversationen i Chrome. Download Claude conversations kräver inte Anthropics betalda abonnemang.

Gäller exporten av Claude-konversationer Claude Code?

Nej. Download Claude conversations körs på claude.ai i Chrome. Claude Code använder /export eller JSONL i ~/.claude/projects. Tillägget läser inte Claude Code-sessioner.

Kan jag exportera en Claude-session från Claude Desktop?

Inte med det här Chrome-tillägget. Öppna samma konversation på claude.ai om den synkas, eller kopiera och klistra in / använd den officiella Export data. Claude Desktop visar aldrig den orange knappen.

Hur många Claude-konversationer kan jag exportera gratis?

Tre per konto med Google-inloggning, delade mellan den orange knappen och Export All. En ominstallation nollställer inte räknaren. Pro återställs via Google-inloggning.

Var finns den orange knappen för att exportera en Claude-konversation?

Till höger om meddelanderutan på en konversationsadress på claude.ai, när du har installerat Download Claude conversations och laddat om. Den syns inte på den tomma startsidan med skrivfältet eller i Claude Desktop.

Laddar exporten upp mina chattar?

Nej. Filerna skapas i webbläsaren och lämnas över till Chromes nedladdnings-API. Vår worker ser abonnemangsstatus och en e-postadress verifierad av Google, inte konversationernas innehåll.

Vilka format kan en exporterad Claude-konversation ha?

Markdown, JSON, ren text, XML och PNG – samma fem för en konversation och för Export All. Ingen export till PDF, Word, Notion eller Google Docs i version 1.13.0.
