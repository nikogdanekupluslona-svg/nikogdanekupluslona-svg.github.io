Hur fungerar export av en Claude-konversation i Chrome?

Öppna en konversationsadress på claude.ai i Chrome, klicka på den orange knappen till höger om meddelanderutan, välj PDF, Markdown, JSON, text, XML, CSV eller PNG och klicka på ”Export”. Download Claude conversations skriver filen med konversationen lokalt. Ladda om claude.ai efter installationen. claude.ai har ingen exportknapp per tråd.

  1. Installera Download Claude conversations från Chrome Web Store (version 1.16.2).
  2. Ladda om claude.ai-fliken så att innehållsskriptet kan läggas in på en konversationsadress.
  3. Öppna en riktig konversation, inte den tomma startsidan med skrivfältet på claude.ai.
  4. Klicka på den runda orange nedladdningsknappen till höger om meddelanderutan.
  5. Ställ in ”Messages” (meddelanden) på ”All”, ”Human” eller ”Assistant” (alla, människa eller assistent), kryssa i ”Thinking” (tänkande) om du vill ha med det, välj PDF, Markdown, JSON, ren text, XML, CSV eller PNG och klicka sedan på ”Export”.

Du behöver inget konto för att exportera en Claude-konversation som Markdown, text, JSON, XML, CSV eller PNG. De exporterna av enskilda konversationer är obegränsade och skickar ingenting till våra servrar. Google-inloggning krävs bara för PDF och massexport med ”Export All”, som delar på 3 per dag på gratisplanen. Konversationens text ingår aldrig i Google-inloggningen. Så fungerar det tekniskt: så fungerar det.

Om den orange knappen saknas är fliken inte på en konversationsadress på claude.ai, sidan behöver fortfarande laddas om efter installationen, eller så ligger Download Claude conversations gömt i Chromes pusselmeny. Fäst tillägget och uppdatera. Den orange knappen visas aldrig på andra webbplatser.

Formatvalet i Download Claude conversations kommer ihåg det senaste valet. ”Select” (markera) bockar för enskilda meddelanden, och ”Copy” (kopiera) lägger Markdown, text, JSON, XML eller CSV i urklipp i stället för i en fil. Ofullständiga filer betyder oftast att den långa claude.ai-tråden inte hade renderat klart meddelandeträdet. Vänta och klicka på ”Export” igen.

En konversation eller hela kontot. Den orange knappen exporterar den öppna tråden. För många filer öppnar du ”View and Download All Conversations” (visa och ladda ner alla konversationer) från tilläggets popup och kör ”Export All” (exportera alla). Anthropics Settings → Privacy → Export data (namnen kan vara översatta om claude.ai är inställt på svenska) är en JSON-ZIP för kontot som kommer senare, inte det här flödet i Chrome.

Vad behåller den exporterade filen?

En konversation som exporteras med Download Claude conversations behåller meddelandeträdet som redan är renderat på claude.ai: avsändare, kodblock, tabeller, valfritt resonemang, metadata och layout för artefakter. Det är ingen skärmdump av sidopanelen. PNG är bildalternativet; PDF är det sidindelade, som skapas i webbläsaren i version 1.16.2.

Kopiera och klistra in från claude.ai tappar indrag och klämmer ihop tabeller. Utskrift (Ctrl/Cmd+P) tar med claude.ai:s gränssnitt och delar ofta ett långt kodblock över flera sidor. Download Claude conversations behåller språktaggar på kodblock och låter tabeller förbli tabeller i Markdown, JSON och XML. PNG är en bild av tråden, inte en sidindelad PDF.

I version 1.16.2 är utökat tänkande en kryssruta i exportpanelen, och källor från webbsökning och verktygs-/MCP-steg slår du på i inställningarna (Settings). Metadata kan innehålla titel, tidsstämplar och modell. Filtret ”Messages” begränsar filen till alla meddelanden, bara människa eller bara assistent, och ”Select” bockar för enskilda meddelanden. Layouten för artefakter (”Original”, ”Inline”, ”Nested” eller ”Flat” – original, inbäddade, nästlade eller platta) väljer du på översiktssidan (Dashboard) för Export All.

Vi byggde exporten av Claude-konversationer kring den orange knappen på claude.ai: den skriver PDF, Markdown, JSON, text, XML, CSV eller PNG från konversationen som redan visas på skärmen, utan att ladda upp tråden. Version 1.16.2 skapar även PDF-filen i webbläsaren.

Hur exporterar jag en konversation från Claude som Markdown?

Att exportera en konversation från Claude som Markdown är skribentens väg: orange knapp, Markdown i listrutan, ”Export”. Download Claude conversations skriver även PDF, JSON, ren text, XML, CSV och PNG från samma claude.ai-tråd. Markdown är obegränsat och kräver inget konto.

Skribenter väljer oftast Markdown när de exporterar Claude-konversationer som anteckningar. Utvecklare väljer oftast JSON när de behöver en maskinläsbar konversationsfil. Behöver du ett sidindelat dokument väljer du PDF i samma listruta. Den skapas i webbläsaren, med sidstorlek, marginaler, ljust eller mörkt läge, sidnummer och en innehållsförteckning – genomgång: spara en Claude-chatt som PDF. En PNG från Download Claude conversations är en enda bildfil. Markdown från en exporterad konversation kan fortfarande konverteras senare i Word, Google Docs eller en Markdown-app.

Nedladdningar i Markdown, JSON, text, XML, CSV och PNG är obegränsade och kräver inget konto, så att exportera samma claude.ai-konversation igen i ett annat format kostar ingenting. Varje PDF använder en av 3 per dag på gratisplanen, med Google-inloggning. Pro för 3,99 $ i månaden eller 26,99 $ om året tar bort det taket.

Kan jag exportera Claude-konversationer med Export All?

Ja. Öppna ”View and Download All Conversations” från tilläggets popup, filtrera och klicka på ”Export All” för att exportera Claude-konversationer som en ZIP med en fil per tråd. Massexport kräver Google-inloggning. På gratisplanen använder varje konversation i ZIP-filen en av 3 per dag, delat med PDF. Pro för 3,99 $ i månaden eller 26,99 $ om året tar bort taket för massexport.

Översiktssidan (Dashboard) listar claude.ai-historiken med sökning på namn, filtren ”All conversations”, ”New”, ”Updated” och ”Previously exported” (alla konversationer, nya, uppdaterade, tidigare exporterade), flikarna ”Chat” och ”Cowork” samt sökning på projekt. New betyder ännu inte sparad med Download Claude conversations. Previously exported håller reda på konversationer du redan har skrivit till disken så att en andra körning av Export All kan hoppa över dem. Projektsökningen motsvarar hur du grupperar trådar på claude.ai.

Massexporten har formatväljaren ”Chat format” (chattformat) med alla sju format, även PDF, kryssrutorna ”Chats”, ”Thinking”, ”Metadata”, ”Tools” och ”Sources” (chattar, tänkande, metadata, verktyg, källor) och layout för artefakter (Original, Inline, Nested, Flat). Export All är ingen avskalad ZIP av hela kontot. Det är en ZIP med en fil per konversation i det valda formatet. Anthropics Export data är fortfarande JSON-ZIP-filen för kontot som kommer senare.

Massexport räknas per konversation. På gratisplanen delar Export All och PDF på 3 per dag, och varje konversation i ZIP-filen räknas som en. Markerar du 40 konversationer när du har 3 kvar blockeras hela körningen – den kortas inte av. Välj färre, vänta på nollställningen vid midnatt UTC eller använd Pro för 3,99 $ i månaden eller 26,99 $ om året. Detaljer om den gemensamma gränsen: exportera alla med Export All.

Export All delar sin dagliga kvot bara med PDF. Markdown, text, JSON, XML, CSV och PNG från den orange knappen påverkar den aldrig, så en exporterad Claude-konversation i de formaten är alltid gratis. Kvoten nollställs vid midnatt UTC. Pro återställs på en ny dator från samma Google-konto via Paddle.

Kan jag exportera en Claude-session i Desktop eller Code?

Inte i Desktop-appen eller i Claude Code i terminalen. På claude.ai är en session den öppna konversationsadressen, och att exportera en Claude-session där betyder den orange knappen i Chrome. Cowork-sessioner och Claude Code på webben (claude.ai/code) öppnas också på claude.ai, så de exporteras på samma sätt. Claude Desktop visar aldrig den orange knappen. Claude Code i terminalen använder /export eller JSONL i ~/.claude/projects.

Om tråden även finns i ditt claude.ai-konto öppnar du konversationen i Chrome och exporterar den med Download Claude conversations. Finns chatten bara i Claude Desktop kopierar du från appen eller begär Settings → Privacy → Export data på webben. Jämförelse: exportera en Claude Desktop-chatt.

Claude Code i terminalen är en annan produkt och en annan väg. Kör /export där, eller kopiera JSONL-transkript från ~/.claude/projects. Download Claude conversations läser inte de filerna och kopplar inte in sig i CLI:n. Letar du efter hur du exporterar en session från agenten i terminalen är det den vägen på disken – guide: export från Claude Code.

claude.ai i en mobilwebbläsare ligger också utanför. Download Claude conversations kräver Chrome på datorn (eller en annan Chromium-webbläsare som kan installera tillägg från Chrome Web Store). Det finns ingen app för iOS eller Android från oss 2026. Öppna konversationen på en dator och använd sedan den orange knappen eller Export All.

Team- och Enterprise-arbetsytor på claude.ai använder fortfarande konversationsadresser i Chrome. Om en administratör blockerar tillägg körs Download Claude conversations inte – det är en policy i webbläsaren, inte ett saknat format. Den orange knappen visas bara efter en omladdning på en konversationsadress som du har behörighet att öppna.

Exportera Claude-konversation eller Anthropics Export data?

Anthropics Export data skickar en JSON-ZIP med hela kontot via e-post efter en väntetid. Att exportera en Claude-konversation med Download Claude conversations sparar den öppna tråden direkt som PDF, Markdown, JSON, text, XML, CSV eller PNG. Använd ZIP-filen som säkerhetskopia. Använd Chrome-tillägget för en läsbar fil från claude.ai nu.

Exporter som Markdown, text, JSON, XML, CSV och PNG är gratis och obegränsade, utan konto. PDF och massexport med Export All är gratis upp till 3 per dag med Google-inloggning. Den dagliga räkningen för PDF och massexport nollställs vid midnatt UTC. Pro återställs på en ny dator när du loggar in med samma Google-konto. Du kan säga upp när som helst från tilläggets inställningssida (Options) eller via Paddle. Paddle är återförsäljare (merchant of record); vi ser aldrig några kortnummer. Den första betalningen har 14 dagars pengarna-tillbaka-garanti, som hanteras via Paddle enligt sidan om återbetalning.

Du behöver inte Anthropics betalda claude.ai-abonnemang för att exportera konversationer. Du behöver en claude.ai-inloggning som kan ladda konversationen, plus Chrome. Felsökning när exporten misslyckas: vänta tills den långa tråden har laddats i claude.ai, kontrollera listrutan för format (det senast använda formatet ligger kvar) och, för PDF, kontrollera hur många av dagens 3 du har kvar. Ofullständiga PNG- eller Markdown-filer betyder oftast att meddelandeträdet fortfarande strömmades. Scrolla i konversationen och klicka på ”Export” när assistentens sista tur syns på skärmen.

Vanliga frågor: exportera Claude-konversation

De här frågorna handlar om att exportera Claude-konversationer: format, gränser, Claude Desktop, Claude Code, Anthropics ZIP och den orange knappen på claude.ai. Varje svar är ett faktum från Download Claude conversations 1.16.2. FAQPage-datan (JSON-LD) i sidhuvudet motsvarar listan.

Vad betyder ”exportera Claude-konversation” på den här webbplatsen?

Att spara en claude.ai-konversation som fil med Download Claude conversations: orange knapp, formatval, ”Export”. Samma uppgift som engelska ”claude export conversation”. Inte Anthropics ZIP via e-post och inte /export i Claude Code.

Är export av en Claude-konversation samma sak som Export data?

Nej. Settings → Privacy → Export data är en JSON-ZIP med hela kontot via e-post. Med det här tillägget skrivs den öppna tråden som PDF, Markdown, JSON, text, XML, CSV eller PNG, eller ett urval från Export All som en ZIP, direkt i Chrome.

Kan en exporterad Claude-konversation bli en PDF?

Ja. Välj PDF i formatlistan och klicka på ”Export”. Download Claude conversations skapar PDF-filen i webbläsaren, utan utskriftsdialog. PDF kräver Google-inloggning och är gratis upp till 3 per dag; Pro gör det obegränsat. Guide: spara en Claude-chatt som PDF.

Behöver jag Pro för att exportera en Claude-konversation en gång?

Nej. Exporter som Markdown, text, JSON, XML, CSV och PNG är gratis och obegränsade, utan konto. PDF och massexport med Export All är gratis upp till 3 per dag med Google-inloggning. Pro för 3,99 $ i månaden eller 26,99 $ om året tar bort det taket.

Fungerar exporten av Claude-konversationer med alla claude.ai-abonnemang?

Ja. Free, Pro, Team och Enterprise på claude.ai fungerar om du kan öppna konversationen i Chrome. Download Claude conversations kräver inte Anthropics betalda abonnemang.

Gäller exporten av Claude-konversationer Claude Code?

Bara för Claude Code på webben. Sessioner på claude.ai/code öppnas på claude.ai och exporteras som vilken konversation som helst. Claude Code i terminalen använder /export eller JSONL i ~/.claude/projects, och tillägget läser inte de lokala sessionerna.

Kan jag exportera en Claude-session från Claude Desktop?

Inte med det här Chrome-tillägget. Öppna samma konversation på claude.ai om den synkas, eller kopiera och klistra in / använd den officiella Export data. Claude Desktop visar aldrig den orange knappen.

Hur många Claude-konversationer kan jag exportera gratis?

Var finns den orange knappen för att exportera en Claude-konversation?

Till höger om meddelanderutan på en konversationsadress på claude.ai, när du har installerat Download Claude conversations och laddat om. Den syns inte på den tomma startsidan med skrivfältet eller i Claude Desktop.

Laddar exporten upp mina chattar?

Nej. Alla format, även PDF, skapas i webbläsaren och lämnas över till Chromes nedladdnings-API. Exporter som Markdown, text, JSON, XML, CSV och PNG skickar ingenting till oss. När du har loggat in för PDF, massexport eller Pro ser vår worker kvot- eller abonnemangsstatus och e-postadressen till ditt Google-konto, aldrig konversationernas innehåll.

Vilka format kan en exporterad Claude-konversation ha?

Sju: PDF, Markdown, ren text, JSON, XML, CSV och PNG – samma sju för en konversation och för Export All. Ingen export till Word, Notion eller Google Docs i version 1.16.2.
