Om oss

Download Claude conversations är ett fristående Chrome-tillägg (webbplatsens namn: Chat Downloader). Sökmotorer och användare kallar det också Claude Chat Downloader och Claude Conversation Downloader. Det är inte gjort av, knutet till eller godkänt av Anthropic, PBC – Claude är ett varumärke som tillhör Anthropic. Vi byggde tillägget för att fylla en lucka i claude.ai: det finns inget inbyggt sätt att ladda ner en enskild konversation som fil.

Tillägget lägger till en exportknapp i claude.ai och en översiktssida (Dashboard) för massexport, och skriver PDF, Markdown, ren text, JSON, XML, CSV eller PNG lokalt i din webbläsare. Exporter av enskilda chattar i Markdown, text, JSON, XML, CSV och PNG är obegränsade och kräver inget konto. PDF och massexport som ZIP kräver Google-inloggning och är gratis upp till 3 om dagen; Pro (3,99 $/mån eller 26,99 $/år) tar bort den gränsen. Tillägget fungerar med vanliga chattar, projekt, Cowork-sessioner och Claude Code på webben (claude.ai/code). Mer om hur det fungerar. Terminalsessioner i Claude Code exporteras inte.
