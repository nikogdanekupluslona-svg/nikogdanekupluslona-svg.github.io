O nas

Download Claude conversations to niezależne rozszerzenie Chrome (nazwa witryny: Chat Downloader). Wyszukiwarki i użytkownicy nazywają je też Claude Chat Downloader i Claude Conversation Downloader. Nie jest tworzone, wspierane ani powiązane z Anthropic, PBC — Claude to znak towarowy Anthropic. Zbudowaliśmy je, żeby wypełnić lukę w samym claude.ai: nie ma tam wbudowanego sposobu, by pobrać pojedynczą rozmowę jako plik.

Rozszerzenie dodaje do claude.ai przycisk eksportu i Dashboard do eksportu zbiorczego, a pliki PDF, Markdown, zwykły tekst, JSON, XML, CSV lub PNG zapisuje lokalnie w Twojej przeglądarce. Eksporty pojedynczych czatów do Markdown, tekstu, JSON, XML, CSV i PNG są bez limitu i nie wymagają konta. PDF i zbiorczy ZIP wymagają logowania Google i są darmowe do 3 dziennie; Pro (3,99 USD/mies. lub 26,99 USD/rok) znosi ten limit. Działa ze zwykłymi czatami, projektami (Projects), sesjami Cowork i Claude Code on the web (claude.ai/code). Szczegóły: jak to działa. Nie eksportuje sesji Claude Code z terminala.

Wpis w Chrome Web Store (do synchronizacji)

Użyj tego tekstu w Chrome Web Store, żeby opis w sklepie pasował do tego, czego szukają ludzie:

  • Nazwa (≤75 znaków): Claude Chat Downloader
  • Krótki opis (≤132 znaki): Free Chrome extension to save claude.ai chats as PDF, Markdown, text, JSON, XML, CSV or PNG — one chat or bulk Export All.
