Jak zrobić eksport rozmowy Claude do JSON?

Otwórz rozmowę na claude.ai w Chrome, kliknij pomarańczowy przycisk obok pola wiadomości, wybierz JSON i kliknij „Export”. Download Claude conversations zapisze plik lokalnie. Tak działa eksport do JSON w wersji 1.16.2. We wrześniu 2026 samo claude.ai nie ma opcji zapisu pojedynczego czatu jako JSON.

  1. Zainstaluj Download Claude conversations z Chrome Web Store.
  2. Odśwież claude.ai i otwórz adres konkretnej rozmowy, a nie pustą stronę startową.
  3. Kliknij pomarańczowy przycisk pobierania po prawej stronie pola wiadomości.
  4. Wybierz JSON. Rozszerzenie pamięta ostatnio użyty format. Użyj „Select” (Zaznacz), żeby wybrać tylko potrzebne wiadomości.
  5. Kliknij „Export”. Chrome pobierze plik JSON przez API pobierania przeglądarki. Możesz też kliknąć „Copy” (Kopiuj), żeby wrzucić JSON do schowka.

Do eksportu do JSON nie musisz się logować. Eksporty pojedynczych czatów do JSON są bez limitu, anonimowe i nic nie wysyłają na nasze serwery. Logowanie Google pojawia się tylko przy PDF i zbiorczym „Export All” (Eksportuj wszystko). Mechanizm: jak to działa.

Jeśli nie widzisz pomarańczowego przycisku, to nie jesteś na adresie rozmowy, karta wymaga odświeżenia albo rozszerzenie jest schowane w menu puzzla w Chrome. Przypnij Download Claude conversations i odśwież claude.ai. Skrypt rozszerzenia nigdy nie działa w Claude Desktop ani w terminalu Claude Code.

Jeden wątek czy wiele plików. Pomarańczowy przycisk eksportuje otwarty czat jako JSON. Po wiele plików JSON otwórz „View and Download All Conversations” (Wyświetl i pobierz wszystkie rozmowy) i uruchom „Export All” z wybranym JSON: jeden ZIP, 3 czaty dziennie w darmowym planie — zobacz zbiorczy Export All.

Kiedy warto eksportować rozmowę do JSON?

Eksportuj rozmowę do JSON, gdy plik ma czytać skrypt, indekser albo narzędzie do porównywania (diff). JSON odwzorowuje drzewo wiadomości i nie jest przeznaczony do czytania w Obsidian. Jeśli chcesz nagłówków i bloków kodu dla ludzi, wybierz Markdown. Do arkusza wybierz CSV: jeden wiersz na wiadomość.

Kopiuj-wklej z claude.ai gubi strukturę nadawców. Drukowanie zostawia elementy interfejsu strony. W eksporcie do JSON Download Claude conversations zachowuje tury, nadawców i opcjonalne myślenie jako dane, a nie jako spłaszczony akapit. Dlatego programiści wybierają JSON zamiast zwykłego tekstu.

Zapisujemy JSON z drzewa claude.ai, które już jest na stronie — nadawca, bloki treści, znaczniki czasu, metadane modelu — bez wysyłania wątku. Ten JSON to nie ZIP konta od Anthropic. W wersji 1.16.2 to jeden z siedmiu formatów, obok PDF i CSV, i jest darmowy, bez konta.

Co zawiera plik JSON z rozmowy Claude?

Eksport rozmowy do JSON odwzorowuje drzewo wiadomości z claude.ai: nadawcę, bloki treści, znaczniki czasu i metadane modelu. Bloki myślenia, źródła wyszukiwania w sieci, kroki narzędzi / MCP i artefakty trafiają do pliku, gdy te opcje są włączone: „Thinking” (Myślenie) to pole wyboru w panelu eksportu, a narzędzia i źródła włączasz w ustawieniach. Filtr nadawcy ogranicza plik do wszystkich wiadomości, tylko Twoich albo tylko odpowiedzi asystenta. Nic nie jest najpierw spłaszczane do Markdown.

Układ artefaktów w wersji 1.16.2 to „Original”, „Inline”, „Nested” lub „Flat” (oryginalny, w treści, zagnieżdżony, płaski). Te układy zmieniają sposób zagnieżdżenia treści artefaktów w JSON — to te same cztery opcje co dla Markdown i XML. Pełna lista: funkcje rozszerzenia Chrome. Jeśli zamiast danych potrzebujesz stron, eksportuj do PDF.

JSON z rozmowy czy Export data od Anthropic?

Oba to JSON, ale o innej strukturze i zakresie. Settings → Privacy → Export data od Anthropic (nazwy mogą być po polsku, jeśli claude.ai masz ustawione na polski) po pewnym czasie wysyła mailem jeden ZIP całego konta. Eksport rozmowy do JSON daje jeden wątek od razu w Chrome. ZIP służy do kopii zapasowej.

W zgłoszeniu ZIP od Anthropic nie wybierzesz Markdown. Nie możesz też traktować JSON z tego rozszerzenia jako zamiennika schematu tamtego ZIP. Przegląd formatów: formaty eksportu czatu Claude. PDF służy do czytania, a nie jest eksportem JSON.

Download Claude conversations nie jest powiązane z Anthropic, PBC. Skrypt rozszerzenia korzysta z sesji, którą już masz otwartą na claude.ai. Nie loguje się do Anthropic osobnymi danymi. Przestrzegaj zasad Anthropic dotyczących Twojego konta.

Czy mogę eksportować rozmowy do JSON zbiorczo?

Tak. Otwórz „View and Download All Conversations”, ustaw „Chat format” (format czatu) na JSON, przefiltruj tabelę i kliknij „Export All”. Chrome zapisze jeden ZIP z jednym plikiem JSON na czat. W darmowym planie to 3 czaty dziennie z logowaniem Google, wspólnie z PDF. Pro za 3,99 USD miesięcznie lub 26,99 USD rocznie znosi ten limit dla zbiorczego JSON.

Dashboard pokazuje historię z claude.ai z wyszukiwaniem po nazwie, filtrami „All conversations”, „New”, „Updated” i „Previously exported” (wszystkie rozmowy, nowe, zaktualizowane, wcześniej wyeksportowane), zakładkami Chat i Cowork oraz wyszukiwaniem projektów. „New” oznacza czaty jeszcze nie wyeksportowane przez Download Claude conversations. „Previously exported” śledzi czaty, które już zapisałeś. „Export All” to jeden ZIP z osobnymi plikami JSON dla każdego czatu, a nie archiwum z mieszanymi formatami.

Dzienny limit dotyczy konta. Trzy czaty dziennie w darmowym planie, wspólnie z PDF. Jeśli zaznaczysz 40 rozmów, a zostały Ci 3, cała paczka zostanie zablokowana, a nie przycięta. Zaznacz mniej albo przejdź na Pro. Pojedyncze eksporty JSON z pomarańczowego przycisku pozostają bez limitu.

Dwa eksporty JSON tego samego wątku z claude.ai, zrobione w różnym czasie, porównasz tak jak każde inne pliki JSON. Każdy eksport jest samodzielnym plikiem. Ponowny „Export All” tych samych czatów liczy każdy czat jeszcze raz.

Czy eksport do JSON wymaga Pro?

Nie. Eksport jednego czatu do JSON jest darmowy i bez limitu, bez konta i bez licznika — tak samo jak Markdown, tekst, XML, CSV i PNG. Darmowy limit mają tylko PDF i zbiorczy „Export All”: 3 dziennie z logowaniem Google. Pro kosztuje 3,99 USD miesięcznie lub 26,99 USD rocznie przez Paddle. Download Claude conversations nie pobiera dopłaty za eksport do JSON.

Limit widać dopiero przy zbiorczym JSON. Każdy czat w ZIP z „Export All” zużywa jeden z 3 dziennych eksportów, a licznik resetuje się o północy UTC. Pro znosi limit i przywrócisz go na nowym komputerze tym samym kontem Google. Sprzedawcą jest Paddle; nasz zespół nigdy nie widzi numerów kart.

Rozszerzenie działa tylko na claude.ai w Chrome. Claude Desktop i terminal Claude Code nie dostają przycisku JSON; Claude Code on the web (claude.ai/code) działa na claude.ai, więc eksportuje się jak każdy czat. Polecenie /export w terminalu Claude Code albo pliki JSONL na dysku to inna ścieżka. Wersja 1.16.2 z września 2026 nadal nie zapisuje do Worda ani Notion.

FAQ: eksport rozmowy Claude do JSON

Te pytania dotyczą eksportu do JSON w Download Claude conversations 1.16.2: zbiorczego „Export All”, struktury pliku, kosztów, porównywania, ZIP od Anthropic, PDF i aplikacji Desktop. Każda odpowiedź opisuje fakt o produkcie. Dane FAQPage JSON-LD w nagłówku strony odpowiadają tej liście.

Czy mogę eksportować rozmowy Claude do JSON zbiorczo?

Tak. „Export All” w Dashboardzie obsługuje JSON i zapisuje jeden ZIP z plikiem JSON dla każdego czatu. W darmowym planie obejmuje 3 czaty dziennie z logowaniem Google; Pro za 3,99 USD miesięcznie lub 26,99 USD rocznie jest bez limitu.

Czy struktura JSON jest opisana?

Odwzorowuje drzewo wiadomości samego claude.ai: nadawcę, bloki treści, znaczniki czasu i metadane modelu, a także artefakty, bloki myślenia, źródła wyszukiwania w sieci i kroki narzędzi / MCP, jeśli włączysz te opcje. To nie jest schemat ZIP konta od Anthropic.

Czy potrzebuję Pro, żeby eksportować rozmowę Claude do JSON?

Nie. Eksporty pojedynczych czatów do JSON są bez limitu i bez konta, tak jak każdy format poza PDF. Pro za 3,99 USD miesięcznie lub 26,99 USD rocznie znosi tylko limit 3 dziennie dla PDF i zbiorczego „Export All”.

Czy mogę porównać dwa eksporty JSON jednego czatu?

Tak. Każdy eksport rozmowy do JSON daje samodzielny plik zbudowany w ten sam sposób. Porównanie dwóch eksportów tego samego wątku z różnych momentów działa jak diff każdego innego pliku JSON.

Czy ten JSON to to samo co Export data od Anthropic?

Nie. Export data od Anthropic to opóźniony ZIP całego konta. Download Claude conversations od razu zapisuje w Chrome plik JSON z jednego czatu (lub z zaznaczonych wiadomości). Oba mogą być w JSON, ale nie są wymienne.

Czy eksport rozmowy do JSON tworzy PDF?

Nie. JSON to dane strukturalne. Jeśli potrzebujesz stron, wybierz PDF w tym samym panelu; siedem formatów to PDF, Markdown, JSON, zwykły tekst, XML, CSV i PNG. PDF wymaga logowania Google i w darmowym planie liczy się do limitu 3 dziennie.

Czy eksport do JSON działa w Claude Desktop?

Nie. Rozszerzenie Chrome działa tylko na claude.ai. Claude Desktop nigdy nie pokaże opcji JSON. Otwórz ten sam wątek na claude.ai w Chrome, jeśli tam istnieje.
