Czym jest eksport rozmowy Claude Code w terminalu?

Eksport rozmowy Claude Code to polecenie /export w interaktywnej sesji CLI. Dokumentacja Anthropic opisuje menu, w którym kopiujesz bieżącą rozmowę albo zapisujesz plik tekstowy, z wiadomościami i wynikami narzędzi w czytelnej formie. Podaj nazwę pliku, żeby pominąć menu i od razu zapisać plik.

To nie jest Markdown z claude.ai, nie JSON z tego rozszerzenia Chrome i nie PDF. To sformatowany transkrypt do czytania przez człowieka. Anthropic zaznacza, że log JSONL na dysku to inny, wewnętrzny format przeznaczony dla produktu, a nie Twoje publiczne API.

/export

Żeby pominąć pytanie i zapisać plik o podanej nazwie w bieżącym katalogu roboczym:

/export my-session

Dokumentacja sesji od Anthropic to źródło prawdy o flagach i nazwach plików; zmieniają się one między wersjami Claude Code. Blogi społeczności traktuj jako źródło drugorzędne. Jeśli okno /export wygląda inaczej niż u Ciebie, masz inną wersję CLI — korzystaj z pomocy w samym narzędziu, a nie ze zrzutu ekranu z 2025 roku.

Do skryptów Anthropic wskazuje inne interfejsy: claude -p z --output-format json lub stream-json, wznawianie po identyfikatorze sesji, hooki, które dostają transcript_path, albo Agent SDK. To narzędzia deweloperskie Claude Code. Nie są częścią rozszerzenia Chrome z tej strony.

Czytelne a uporządkowane. /export to transkrypt dla człowieka. JSONL w folderze projektów to log. JSON z rozszerzenia Chrome to trzecia struktura, tworzona wyłącznie ze strony claude.ai. Nie pisz jednego parsera dla wszystkich trzech.

Jak pobrać rozmowę z Claude Code z dysku?

Rozmowę z Claude Code pobierzesz z dysku, kopiując plik JSONL sesji z katalogu projektów, albo uruchamiając /export, żeby dostać czytelny transkrypt. Domyślna ścieżka na macOS i Linuksie to ~/.claude/projects/. Na Windows to %USERPROFILE%\.claude\projects. Nazwy plików to identyfikatory sesji.

Nazwa folderu projektu to katalog roboczy, w którym znaki inne niż litery i cyfry zamieniono na myślniki. Anthropic skraca bardzo długie nazwy i dodaje hash, żeby katalog mieścił się w limitach systemu plików. Jeśli nie możesz znaleźć folderu, uruchomiłeś Claude Code z innego katalogu, niż myślisz.

Każda linia JSONL to obiekt JSON z wiadomością, użyciem narzędzia lub metadanymi. Anthropic podaje, że ten format wpisów jest wewnętrzny i zmienia się między wersjami. Skrypty, które parsują te pliki, mogą przestać działać po nowym wydaniu Claude Code. Gdy potrzebujesz czegoś stabilnego, wybieraj /export albo udokumentowane interfejsy skryptowe.

Miejsce przechowywania może się zmienić. CLAUDE_CONFIG_DIR przenosi drzewo konfiguracji poza ~/.claude. CLAUDE_CODE_PROJECT_DIR_NAME nadaje nazwę katalogowi projektu, gdy używasz go razem z tym katalogiem konfiguracji (Claude Code v2.1.234 lub nowszy, według Anthropic). cleanupPeriodDays w settings.json zmienia domyślny czas przechowywania. Żadne z tych ustawień nie jest funkcją Download Claude conversations.

Pobranie plików rozmów z Claude Code jako kopii zapasowej wygląda więc tak: skopiuj folder albo regularnie eksportuj transkrypty przez /export. Ta strona nie doda przycisku „importuj JSONL”. Nie czytamy Twojego katalogu domowego.

Czy eksport z Claude Code działa z tym rozszerzeniem?

Nie dla sesji w terminalu. Download Claude conversations nie czyta lokalnych sesji Claude Code. Rozszerzenie Chrome działa na claude.ai. Nie widzi terminala, nie uruchomi /export i nie otworzy JSONL. Wyjątkiem jest Claude Code on the web na claude.ai/code: to strona claude.ai, więc eksportuje się jak każdy czat. Jeśli szukałeś, jak pobrać rozmowę z Claude Code z CLI, trzymaj się kroków CLI z tej strony.

Ludzie trafiają tutaj, bo Google łączy „Claude” i „eksport”. Wpis w Chrome Web Store dotyczy jednak tylko claude.ai. Instalacja rozszerzenia nie doda pomarańczowego przycisku w iTerm, Ghostty, terminalu VS Code ani w desktopowej nakładce Claude Code.

Jeśli do tego samego zadania programistycznego prowadzisz też równoległy wątek na claude.ai, ten czat w przeglądarce zapiszesz rozszerzeniem. Te dwa zapisy nie są łączone. Wywołania narzędzi, które odbyły się tylko w CLI, nie pojawią się w eksporcie z przeglądarki, chyba że je tam wkleiłeś.

Co tydzień dostajemy ten sam mail do pomocy: ktoś zainstalował rozszerzenie Chrome i spodziewał się, że pojawi się /export. My analizujemy tylko claude.ai. Claude Code ma już /export i JSONL. Obudowanie CLI byłoby innym produktem i go nie wydaliśmy.

Czy mogę wyeksportować sesje Claude Code on the web?

Tak. Claude Code on the web działa na claude.ai/code, więc Download Claude conversations eksportuje te sesje jak każdy czat z claude.ai. Otwórz sesję w Chrome, kliknij pomarańczowy przycisk, wybierz format i kliknij „Export” (Eksportuj). To jedyna odmiana Claude Code, którą obsługuje rozszerzenie.

Formaty są te same siedem co dla każdego czatu: PDF, Markdown, zwykły tekst, JSON, XML, CSV i PNG. Markdown, tekst, JSON, XML, CSV i PNG są bez limitu i nie wymagają konta. PDF wymaga logowania Google i dzieli z zbiorczym ZIP-em 3 dzienne eksporty darmowego planu, chyba że masz Pro. Bloki kodu zachowują oznaczenia języka. Rozszerzone myślenie to pole „Thinking” (Myślenie) w panelu; kroki narzędzi / MCP i źródła wyszukiwania w sieci włączasz w ustawieniach.

Eksport z przeglądarki to to, co claude.ai/code pokazuje na stronie. To nie jest log JSONL z lokalnego uruchomienia CLI i nie obejmuje sesji, które działały tylko w Twoim terminalu. Według Anthropic Claude Code on the web ma własną historię sesji, oddzielną od drzewa ~/.claude/projects z CLI. Dla sesji w terminalu ścieżką nadal jest /export.

Gdzie Claude Code przechowuje historię rozmów?

Claude Code przechowuje historię rozmów jako transkrypty JSONL w folderze projektów w katalogu konfiguracji. Domyślnie na macOS i Linuksie: ~/.claude/projects/<encoded-cwd>/<session-id>.jsonl. Windows używa %USERPROFILE%\.claude\projects. Anthropic może zmienić ten układ; jeśli ścieżki brakuje na dysku, sprawdź aktualną dokumentację sesji.

Wznowienie to coś innego niż eksport. claude --continue i claude --resume wczytują sesję, żebyś mógł pracować dalej. /export zapisuje kopię, którą zostawisz w gicie albo wyślesz mailem. Jedno przywraca kontekst. Drugie daje Ci zapis na wynos. Strona Anthropic o sesjach opisuje tryb uprawnień przy wznawianiu, kompaktowanie/podsumowanie i działanie wyboru sesji — nic z tego nie dotyczy tego rozszerzenia.

Według Anthropic aplikacja desktopowa, Claude Code on the web i rozszerzenie VS Code mają każde własną historię sesji. Ścieżki w tym poradniku dotyczą CLI. Sesje webowe zostają na claude.ai/code, gdzie rozszerzenie może je wyeksportować. Nie zakładaj, że transkrypt Cowork z Desktop leży w tym samym drzewie JSONL, którego używasz z terminala.

Nie traktuj JSONL jako publicznego schematu. Anthropic zaznacza, że format linii się zmienia. Jeśli mimo to go parsujesz, przypnij wersję Claude Code i licz się z awariami. /export to stabilny sposób na czytelną rozmowę z Claude Code.

Zmienne środowiskowe, takie jak CLAUDE_CODE_SKIP_PROMPT_HISTORY, mogą wyłączyć zapisywanie transkryptów. Jeśli folder projektów jest pusty, sprawdź, czy nie wyłączyłeś zapisywania, nie przekierowałeś CLAUDE_CONFIG_DIR gdzie indziej albo czy w ogóle uruchomiłeś interaktywną sesję w tym katalogu.

Jak zamiast tego pobrać czat Claude z claude.ai?

Czat Claude z claude.ai pobierzesz tak: zainstaluj Download Claude conversations, otwórz wątek w Chrome, kliknij pomarańczowy przycisk, wybierz PDF, Markdown, zwykły tekst, JSON, XML, CSV lub PNG. To produkt przeglądarkowy i obejmuje też sesje z claude.ai/code. To nie jest eksport z Claude Code w terminalu. Krok po kroku: jak pobrać czat Claude.

Całą historię claude.ai jako osobne pliki eksportujesz przez „Export All” (Eksportuj wszystko) w Dashboardzie, a nie przez /export. Na darmowym planie każdy czat w ZIP-ie wlicza się do 3 dziennie (wspólnie z PDF, reset o północy UTC); Pro znosi limit. Poradnik: zbiorczy Export All. Formaty: formaty.

Do eksportu pojedynczego czatu w Markdown, tekście, JSON, XML, CSV lub PNG nie potrzebujesz konta — te eksporty są bez limitu. Logowanie Google pojawia się tylko przy PDF, zbiorczym ZIP-ie i Pro, żebyśmy mogli liczyć dzienny limit i przywracać Pro. Pliki powstają lokalnie, również PDF. Paddle rozlicza Pro za 3,99 USD/mies. lub 26,99 USD/rok. Nic z tego nie dotyczy /export w terminalu.

Jeśli praca zaczęła się w Claude Code, a podsumowanie wkleiłeś do claude.ai, pobierz wątek z przeglądarki jako notatki, a /export zachowaj dla prawdziwego logu z CLI. Dwa pliki są lepsze niż jeden pomieszany.

Eksport z Claude Code czy oficjalny Export data od Anthropic?

Eksport z Claude Code (/export lub JSONL) dotyczy jednej sesji w terminalu. Oficjalny Export data to Settings → Privacy → Export data na claude.ai (nazwy mogą być po polsku, jeśli claude.ai masz ustawione na polski): opóźniony ZIP z JSON konta Anthropic. To nie jest to samo archiwum. ZIP nie zastąpi /export.

To, czy dana sesja Claude Code trafi do ZIP-a konta, zależy od tego, jak Anthropic przechowuje ten produkt, a nie od tego rozszerzenia. Traktuj ZIP jako kopię zapasową konta webowego, chyba że aktualna dokumentacja prywatności Anthropic mówi inaczej. Nie dodajemy sesji z CLI do tego ZIP-a.

Eksport z Claude Code, Desktop czy claude.ai?

Claude Code, Claude Desktop i claude.ai to trzy różne miejsca. Eksport z Claude Code używa /export i JSONL. Desktop to aplikacja bez pomarańczowego przycisku tego rozszerzenia. claude.ai w Chrome to jedyne miejsce, w którym działa Download Claude conversations — łącznie z Claude Code on the web na claude.ai/code. Mieszanie tych nazw sprawia, że eksporty po cichu się nie udają.

Claude Desktop: jeśli czat zsynchronizował się z tym samym kontem Anthropic, otwórz go na claude.ai i tam wyeksportuj. Jeśli istnieje tylko w oknie Desktop, skopiuj go ręcznie albo poczekaj na oficjalny Export data. Poradnik: eksport czatu Claude Desktop.

Panel Claude Code w VS Code jest bliżej CLI niż claude.ai. Nie spodziewaj się, że nasz skrypt uruchomi się w tym widoku. Użyj /export w sesji, która faktycznie zawiera wiadomości.

Niezależne rozszerzenie Chrome, niepowiązane z Anthropic, PBC. Claude jest znakiem towarowym Anthropic. Przestrzegaj ich Warunków korzystania z usług. Nie udzielamy porad prawnych dotyczących kopiowania wyników narzędzi zawierających zastrzeżony kod; to sprawa między Tobą, Twoim pracodawcą i Anthropic.

FAQ: eksport rozmowy Claude Code

Jak wyeksportować rozmowę z Claude Code?

W terminalu Claude Code wpisz /export (opcjonalnie z nazwą pliku), żeby zapisać sformatowany transkrypt, albo skopiuj plik JSONL z ~/.claude/projects na macOS/Linuksie lub z %USERPROFILE%\.claude\projects na Windows. Aktualne okno opisuje dokumentacja sesji od Anthropic.

Czy to rozszerzenie Chrome pobiera czaty z Claude Code?

Nie z terminala. Download Claude conversations działa tylko na claude.ai w Chrome. Nie czyta lokalnych sesji terminala, transkryptów JSONL ani polecenia /export. Sesje Claude Code on the web na claude.ai/code eksportują się jak każdy czat.

Czy mogę wyeksportować Claude Code on the web (claude.ai/code)?

Tak. Otwórz sesję na claude.ai/code w Chrome i użyj pomarańczowego przycisku. Działają PDF, Markdown, zwykły tekst, JSON, XML, CSV i PNG. Sześć formatów poza PDF jest bez limitu i bez konta; PDF wymaga logowania Google i wlicza się do 3 darmowych eksportów dziennie.

Gdzie Claude Code przechowuje historię rozmów?

Transkrypty sesji to pliki JSONL w ~/.claude/projects/<encoded-working-directory>/, nazwane identyfikatorem sesji. Dokładny układ może się zmienić. Użyj /export, gdy chcesz czytelnego pliku zamiast parsowania JSONL. CLAUDE_CONFIG_DIR może przenieść to drzewo.

Jak pobrać rozmowę z Claude Code jako Markdown?

/export w Claude Code to transkrypt tekstowy, a nie Markdown z tego rozszerzenia. Jeśli potrzebujesz właśnie Markdown, wyeksportuj sesję z claude.ai/code albo kopię pracy na claude.ai przez Download Claude conversations, lub samodzielnie przekonwertuj tekst z /export. Nie konwertujemy JSONL do Markdown.

Jak zamiast tego pobrać rozmowę z claude.ai?

Zainstaluj darmowe rozszerzenie Chrome, otwórz czat na claude.ai i użyj pomarańczowego przycisku — albo „Export All” dla całej historii. Zobacz jak pobrać czat Claude. Markdown, tekst, JSON, XML, CSV i PNG są bez limitu i bez konta; PDF i zbiorczy ZIP to 3 dziennie za darmo z logowaniem Google; Pro kosztuje 3,99 USD/mies. lub 26,99 USD/rok.

Czy /export to to samo co oficjalny Export data?

Nie. /export dotyczy bieżącej sesji Claude Code. Settings → Privacy → Export data wysyła mailem ZIP z JSON konta Anthropic. Różne produkty, różne pliki, różny czas oczekiwania.

Czy mogę parsować JSONL z Claude Code za pomocą jq?

Możesz, z zastrzeżeniem, które publikuje Anthropic: schemat linii jest wewnętrzny i może się zmienić. Gdy potrzebujesz stabilnego kontraktu, wybieraj /export albo claude -p --output-format json. Jeśli mimo to parsujesz JSONL, przypnij wersję CLI.

Czy eksport z Claude Code działa na Windows?

Tak. /export to polecenie CLI. Transkrypty na dysku są w %USERPROFILE%\.claude\projects, chyba że ustawisz CLAUDE_CONFIG_DIR. To rozszerzenie Chrome nadal nie działa w tym terminalu.

Czy Claude Code to to samo co Claude Desktop?

Nie. Claude Code to agent programistyczny w terminalu. Claude Desktop to aplikacja do czatu. claude.ai to strona internetowa. Tylko strona, łącznie z claude.ai/code, działa z tym rozszerzeniem. Uwagi o eksporcie z Desktop: Claude Desktop.

Czy to rozszerzenie kiedyś obsłuży /export?

Nie w wersji 1.16.2. Zakres produktu to claude.ai, łącznie z Claude Code on the web: siedem formatów, lokalne pliki, logowanie Google tylko dla PDF, eksportu zbiorczego i Pro. Jeśli ten zakres się zmieni, ta strona to powie. Do tego czasu do eksportu z Claude Code w terminalu używaj CLI od Anthropic.

Czy /export zawiera wyniki narzędzi?

Anthropic opisuje /export jako wiadomości i wyniki narzędzi w czytelnej formie tekstowej. To ich transkrypt, a nie nasz parser. Żeby poznać dokładną aktualną zawartość, uruchom /export w swojej wersji i przeczytaj plik — dokumentacja może nie nadążać za wydaniami.

Czy mogę zbiorczo wyeksportować sesje Claude Code?

Nie lokalne sesje CLI. „Export All” w Dashboardzie działa tylko dla claude.ai. Przy wielu sesjach CLI skopiuj folder projektów albo uruchom /export w każdej sesji. Dla JSONL nie ma zbiorczego eksportu pomarańczowym przyciskiem.
