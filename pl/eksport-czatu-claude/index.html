Jak zrobić eksport czatu Claude z claude.ai?

Otwórz rozmowę na claude.ai w Chrome, kliknij pomarańczowy przycisk obok pola wiadomości, wybierz PDF, Markdown, JSON, zwykły tekst, XML, CSV lub PNG i kliknij „Export”. Download Claude conversations zapisze plik lokalnie. We wrześniu 2026 samo claude.ai nie ma wbudowanej opcji eksportu pojedynczego czatu.

  1. Zainstaluj Download Claude conversations z Chrome Web Store.
  2. Odśwież claude.ai i otwórz adres konkretnej rozmowy, a nie pustą stronę startową.
  3. Kliknij okrągły pomarańczowy przycisk pobierania po prawej stronie pola wiadomości.
  4. W panelu ustaw Messages na „All / Human / Assistant” (Wszystkie / Człowiek / Asystent), a potem wybierz format. Zaznacz „Thinking” (Myślenie), żeby dołączyć rozszerzone myślenie, albo użyj „Select” (Zaznacz), żeby wybrać pojedyncze wiadomości. Rozszerzenie pamięta ostatnio użyty format.
  5. Kliknij „Export”. Chrome od razu zapisze plik przez API pobierania przeglądarki. „Copy” (Kopiuj) zamiast tego wrzuca Markdown, tekst, JSON, XML lub CSV do schowka.

Do eksportu czatu Claude jako Markdown, tekst, JSON, XML, CSV lub PNG nie potrzebujesz konta. Te eksporty pojedynczych czatów są bez limitu, a rozszerzenie nie wysyła przy nich niczego na nasze serwery. Logowanie Google pojawia się dopiero, gdy wybierzesz PDF albo uruchomisz zbiorczy „Export All” (Eksportuj wszystko): darmowy plan pozwala na 3 takie eksporty dziennie łącznie, z resetem o północy UTC. Treść czatu nigdy nie jest częścią tego logowania. Szczegóły: jak to działa.

Jeśli nie widzisz pomarańczowego przycisku, to nie jesteś na adresie rozmowy, karta wymaga odświeżenia po instalacji albo ikona rozszerzenia wciąż siedzi schowana w menu puzzla w Chrome. Przypnij Download Claude conversations i odśwież claude.ai. Rozszerzenie działa tylko na claude.ai, nigdy na innych stronach.

Jeden wątek czy całe konto. Pomarańczowy przycisk eksportuje otwarty czat. Po wiele plików otwórz okienko rozszerzenia → „View and Download All Conversations” (Wyświetl i pobierz wszystkie rozmowy) i uruchom „Export All” — zobacz zbiorczy Export All. Settings → Privacy → Export data (nazwy mogą być po polsku, jeśli claude.ai masz ustawione na polski) od Anthropic to opóźniony ZIP całego konta, a nie ta ścieżka.

Co właściwie robi rozszerzenie do eksportu Claude?

Rozszerzenie do eksportu Claude odczytuje rozmowę, która jest już wyświetlona w Twojej zalogowanej karcie claude.ai, i zapisuje na dysku uporządkowany plik. Działa ze zwykłymi czatami, projektami (Projects), sesjami Cowork i Claude Code on the web.

Kopiuj-wklej z claude.ai gubi wcięcia i spłaszcza tabele. Drukowanie (Ctrl/Cmd+P) zostawia pasek boczny i często dzieli długi blok kodu między strony. Układ artefaktów to w wersji 1.16.2 prawdziwy przełącznik: „Original”, „Inline”, „Nested” lub „Flat” (oryginalny, w treści, zagnieżdżony, płaski), ustawiany w Dashboardzie. Czy eksport czatu Claude działa w Desktop lub Code?

Nie w aplikacji Desktop ani w terminalu Claude Code. To rozszerzenie działa tylko na claude.ai w Chrome (lub innej przeglądarce opartej na Chromium, która instaluje z Chrome Web Store). Claude Desktop to osobna aplikacja na Maca i Windows — pomarańczowy przycisk nigdy się tam nie pojawia, podobnie jak w terminalu. Wyjątkiem jest Claude Code on the web (claude.ai/code): te sesje otwierają się na claude.ai i eksportują się jak każdy czat.

Jeśli wątek jest też na Twoim koncie claude.ai, otwórz go w Chrome i zrób eksport czatu Claude tam, przez Download Claude conversations. Jeśli czat istnieje tylko w Desktop, skopiuj go z aplikacji albo zamów Settings → Privacy → Export data w wersji webowej. Porównanie krok po kroku: eksport czatu Claude Desktop.

Claude Code w terminalu używa /export lub transkryptów JSONL na dysku. To rozszerzenie Chrome nie czyta tych lokalnych sesji. Nie instaluj Download Claude conversations w nadziei na integrację z terminalem. Poradnik: eksport rozmowy Claude Code. Eksport sesji z CLI to zupełnie inna ścieżka.

Mobilne claude.ai w przeglądarce telefonu też odpada. Rozszerzenie wymaga Chrome na komputerze. W 2026 roku ten zespół nie ma aplikacji na iOS ani Androida. Otwórz rozmowę na komputerze i wyeksportuj czat pomarańczowym przyciskiem albo przez „Export All”.

Co na tej stronie oznacza eksport czatu Claude?

Zapisanie rozmowy z claude.ai jako pliku przez Download Claude conversations: pomarańczowy przycisk, wybór formatu, „Export”. To samo, co po angielsku wpisujesz jako „claude export chat”. To nie jest ZIP wysyłany mailem przez Anthropic ani /export z Claude Code.

Czy rozszerzenie do eksportu Claude to to samo co Export data?

Nie. Settings → Privacy → Export data to ZIP z JSON całego konta, wysyłany mailem. Rozszerzenie od razu w Chrome zapisuje otwarty czat jako PDF, Markdown, JSON, tekst, XML, CSV lub PNG albo wybór z „Export All” jako ZIP.

Czy mogę wyeksportować czat Claude do PDF?

Czy potrzebuję Pro, żeby raz wyeksportować czat Claude?

Czy to rozszerzenie do eksportu Claude działa z Claude Code?
