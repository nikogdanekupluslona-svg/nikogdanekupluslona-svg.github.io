Mikä on Claude Code -vienti terminaalissa?

Claude Code -vienti (englanniksi usein ”Claude Code export”) on komento /export interaktiivisessa CLI-istunnossa. Anthropicin dokumentaation mukaan se avaa valikon, josta voit kopioida nykyisen keskustelun tai tallentaa sen tekstitiedostoon. Viestit ja työkalujen tulosteet muotoillaan luettavaksi tekstiksi. Jos annat komennolle tiedostonimen, valikko ohitetaan ja tiedosto kirjoitetaan suoraan.

Tulos ei ole claude.ai:n Markdownia, ei tämän Chrome-laajennuksen JSONia eikä PDF:ää. Se on ihmisen luettavaksi muotoiltu transkripti. Anthropicin mukaan levylle tallentuva JSONL-loki on eri formaatti: sisäinen, tuotteen omaan käyttöön tarkoitettu, ei julkinen rajapinta.

/export

Voit ohittaa kysymyksen ja kirjoittaa nimetyn tiedoston nykyiseen työhakemistoon:

/export my-session

Anthropicin istuntodokumentaatio on luotettava lähde lipuille ja tiedostonimille, sillä ne muuttuvat Claude Coden versioiden välillä. Pidä yhteisöblogeja toissijaisina. Jos /export-dialogin teksti ei vastaa näkemääsi, käytössäsi on eri versio – katso ohjelman oma ohje, älä vuoden 2025 kuvakaappausta.

Skripteihin Anthropic suosittelee muita rajapintoja: claude -p yhdessä --output-format json- tai stream-json-asetuksen kanssa, istunnon jatkaminen tunnisteella, hookit, jotka saavat transcript_path-arvon, tai Agent SDK. Ne ovat Claude Coden kehittäjätyökaluja, eivät tämän sivuston Chrome-laajennus.

Luettava vai rakenteinen. /export on ihmiselle tarkoitettu transkripti. Projects-kansion JSONL on loki. Chrome-laajennuksen JSON on kolmas muoto, joka rakennetaan vain claude.ai-sivulta. Älä kirjoita yhtä jäsennintä kaikille kolmelle.

Miten Claude Code -keskustelun saa levyltä?

Claude Code -keskustelun saa levyltä kahdella tavalla: kopioi istunnon JSONL-tiedosto projects-hakemistosta tai aja /export, jos haluat luettavan transkriptin. Oletuspolku macOS:ssä ja Linuxissa on ~/.claude/projects/. Windowsissa se on %USERPROFILE%\.claude\projects. Tiedostonimet ovat istuntotunnisteita.

Projektikansion nimi on työhakemiston polku, jossa muut kuin kirjaimet ja numerot on korvattu yhdysmerkeillä. Anthropic lyhentää hyvin pitkiä nimiä ja lisää loppuun tiivisteen, jotta hakemisto pysyy tiedostojärjestelmän rajoissa. Jos et löydä kansiota, käynnistit Claude Coden todennäköisesti eri hakemistosta kuin luulet.

Jokainen JSONL-rivi on JSON-objekti, joka kuvaa viestin, työkalukutsun tai metatiedon. Anthropicin mukaan tämä rivimuoto on sisäinen ja muuttuu versioiden välillä. Näitä tiedostoja jäsentävät skriptit voivat hajota Claude Coden päivityksessä. Kun tarvitset jotain vakaata, käytä /export-komentoa tai dokumentoituja skriptirajapintoja.

Tallennuspaikka voi muuttua. CLAUDE_CONFIG_DIR siirtää asetuspuun pois kansiosta ~/.claude. CLAUDE_CODE_PROJECT_DIR_NAME nimeää projektihakemiston, kun sitä käytetään tuon asetushakemiston kanssa (Anthropicin mukaan Claude Code v2.1.234 tai uudempi). settings.json-tiedoston cleanupPeriodDays muuttaa oletussäilytysaikaa. Mikään näistä ei ole Download Claude conversations -laajennuksen ominaisuus.

Varmuuskopio Claude Code -keskusteluista syntyy siis näin: kopioi kansio tai vie transkriptit säännöllisesti /export-komennolla. Tälle sivustolle ei tule ”tuo JSONL” -painiketta. Emme lue kotihakemistoasi.

Toimiiko Claude Code -vienti tämän laajennuksen kanssa?

Ei terminaali-istunnoissa. Download Claude conversations ei lue paikallisia Claude Code -istuntoja. Chrome-laajennus toimii vain claude.ai-sivulla. Se ei näe terminaalia, ei voi ajaa /export-komentoa eikä avata JSONL-tiedostoja. Poikkeus on Claude Code on the web osoitteessa claude.ai/code: se on claude.ai-sivu, joten sen voi viedä kuten minkä tahansa chatin. Jos etsit tapaa ladata Claude Code -keskustelu CLI:stä, pysy tämän sivun CLI-ohjeissa.

Moni päätyy tänne, koska Google niputtaa sanat ”Claude” ja ”export” yhteen. Chrome Web Store -listaus koskee silti vain claude.ai:ta. Laajennuksen asentaminen ei tuo oranssia painiketta iTermiin, Ghosttyyn, VS Coden terminaaliin tai Claude Coden työpöytäsovellukseen.

Jos pidät samasta koodaustyöstä rinnakkaista keskustelua myös claude.ai:ssa, sen selainchatin voi tallentaa laajennuksella. Tallenteita ei yhdistetä. Vain CLI:ssä tehdyt työkalukutsut eivät näy verkkoviennissä, ellet ole liittänyt niitä sinne itse.

Saamme joka viikko saman tukiviestin: joku asensi Chrome-laajennuksen ja odotti /export-komennon ilmestyvän. Jäsennämme vain claude.ai:ta. Claude Codessa on jo valmiina /export ja JSONL. CLI:n kääriminen olisi eri tuote, emmekä ole julkaisseet sellaista.

Voiko Claude Code on the web -istunnot viedä?

Kyllä. Claude Code on the web toimii osoitteessa claude.ai/code, joten Download Claude conversations vie nämä istunnot kuten minkä tahansa claude.ai-chatin. Avaa istunto Chromessa, napsauta oranssia painiketta, valitse formaatti ja napsauta ”Export” (vie). Tämä on ainoa Claude Coden käyttöliittymä, jonka laajennus kattaa.

Formaatit ovat samat seitsemän kuin kaikissa chateissa: PDF, Markdown, pelkkä teksti, JSON, XML, CSV ja PNG. Markdown, teksti, JSON, XML, CSV ja PNG ovat rajattomia eivätkä vaadi tiliä. PDF pyytää Google-kirjautumista ja jakaa ilmaisversion 3 kertaa päivässä ZIP-joukkoviennin kanssa, ellei sinulla ole Pro-tilausta. Koodilohkot säilyttävät kielitunnisteensa. Laajennettu ajattelu on paneelissa valintaruutu ”Thinking” (ajattelu); työkalu- ja MCP-vaiheet sekä verkkohaun lähteet otetaan halutessasi käyttöön asetuksissa (Settings).

Verkkovienti sisältää sen, mitä claude.ai/code näyttää selaimessa. Se ei ole paikallisen CLI-ajon JSONL-loki, eikä se tavoita istuntoja, jotka ajettiin vain terminaalissa. Anthropicin mukaan Claude Code on the webillä on oma istuntohistoriansa, erillään CLI:n ~/.claude/projects-puusta. Terminaali-istunnolle /export on yhä oikea tapa.

Mihin Claude Code tallentaa keskusteluhistorian?

Claude Code tallentaa keskusteluhistorian JSONL-transkripteina asetushakemiston projects-kansioon. Oletus macOS:ssä ja Linuxissa: ~/.claude/projects/<encoded-cwd>/<session-id>.jsonl. Windowsissa polku on %USERPROFILE%\.claude\projects. Anthropic voi muuttaa rakennetta; jos polkua ei löydy levyltä, tarkista ajantasainen istuntodokumentaatio.

Jatkaminen on eri asia kuin vienti. claude --continue ja claude --resume lataavat istunnon uudelleen, jotta voit jatkaa työtä. /export kirjoittaa kopion, jonka voit jättää gitiin tai lähettää sähköpostilla. Toinen palauttaa kontekstin, toinen antaa sinulle tallenteen mukaan. Anthropicin istuntosivu kertoo lupatilasta jatkettaessa, tiivistyksestä ja istuntovalitsimesta – mikään niistä ei liity tähän laajennukseen.

Anthropicin mukaan työpöytäsovelluksella, Claude Code on the webillä ja VS Code -laajennuksella on kullakin oma istuntohistoriansa. Tämän oppaan polut koskevat CLI:tä. Verkkoistunnot pysyvät osoitteessa claude.ai/code, josta laajennus voi viedä ne. Älä oleta, että Desktopin Cowork-transkripti on samassa JSONL-puussa, jota käytät terminaalista.

Älä käsittele JSONL:ää julkisena skeemana. Anthropicin mukaan rivimuoto muuttuu. Jos jäsennät sitä silti, lukitse Claude Coden versio ja varaudu rikkoutumisiin. /export on vakaa tapa saada Claude Code -keskustelu luettavaan muotoon.

Ympäristömuuttujat, kuten CLAUDE_CODE_SKIP_PROMPT_HISTORY, voivat estää transkriptien kirjoittamisen. Jos projects-kansio on tyhjä, tarkista, oletko poistanut tallennuksen käytöstä, ohjannut CLAUDE_CONFIG_DIR-muuttujan muualle tai jättänyt ajamatta interaktiivista istuntoa siinä hakemistossa.

Miten ladata Claude-chat claude.ai:sta?

Claude-chatin lataus claude.ai:sta: asenna Download Claude conversations, avaa keskustelu Chromessa, napsauta viestikentän vieressä olevaa oranssia painiketta ja valitse PDF, Markdown, pelkkä teksti, JSON, XML, CSV tai PNG. Se on selaintuote, ja se kattaa myös claude.ai/code-istunnot. Se ei ole terminaalin Claude Code -vienti. Vaiheittaiset ohjeet: näin lataat Claude-chatin.

Koko claude.ai-historia erillisinä tiedostoina onnistuu hallintapaneelin (Dashboard) ”Export All” (vie kaikki) -toiminnolla, ei /export-komennolla. Ilmaisversiossa jokainen ZIPin chat lasketaan 3 päivittäisen viennin rajaan (yhteinen PDF:n kanssa, nollautuu keskiyöllä UTC-aikaa); Pro poistaa rajan. Opas: Export All -joukkovienti. Formaatit: formaatit.

Yksittäisen chatin Markdown-, teksti-, JSON-, XML-, CSV- tai PNG-vienti ei vaadi tiliä – nämä viennit ovat rajattomia. Google-kirjautuminen tulee vastaan vain PDF:ssä, ZIP-joukkoviennissä ja Pro-tilauksessa, jotta voimme laskea päivän kiintiön ja palauttaa Pron. Tiedostot rakennetaan paikallisesti, myös PDF. Paddle laskuttaa Pron hintaan 3,99 $/kk tai 26,99 $/vuosi. Mikään tästä ei koske terminaalin /export-komentoa.

Jos työ alkoi Claude Codessa ja liitit tiivistelmän claude.ai:hin, lataa verkkokeskustelu muistiinpanoiksi ja pidä /export varsinaisena CLI-lokina. Kaksi tiedostoa on parempi kuin yksi sekava.

Claude Code -vienti vai Anthropicin virallinen Export data?

Claude Code -vienti (/export tai JSONL) koskee yhtä terminaali-istuntoa. Virallinen Export data on claude.ai:ssa kohdassa Settings → Privacy → Export data (valikot voivat näkyä suomeksi, jos claude.ai on asetettu suomen kielelle): viiveellä toimitettava JSON-ZIP koko Anthropic-tilistä. Ne eivät ole sama arkisto. ZIP ei korvaa /export-komentoa.

Näkyykö tietty Claude Code -istunto tilin ZIP-tiedostossa, riippuu siitä, miten Anthropic tallentaa kyseisen tuotteen – ei tästä laajennuksesta. Pidä ZIPiä verkkotilin varmuuskopiona, ellei Anthropicin ajantasainen tietosuojadokumentaatio kerro muuta. Emme lisää CLI-istuntoja siihen ZIPiin.

Claude-chatin vienti verkkosivustolta, mukaan lukien ZIPin ja laajennuksen erot, on kuvattu täällä: näin viet Claude-chatin. Laajennuksen PDF-vienti ei myöskään sovellu terminaalikäyttöliittymään. Katso Claude-keskustelu PDF:nä vain, kun keskustelu on claude.ai:ssa, claude.ai/code mukaan lukien.

Claude Code, Desktop vai claude.ai: mikä vienti?

Claude Code, Claude Desktop ja claude.ai ovat kolme eri käyttöliittymää. Claude Code -vienti käyttää /export-komentoa ja JSONL:ää. Desktop on sovellus, jossa ei ole tämän laajennuksen oranssia painiketta. claude.ai Chromessa on ainoa paikka, jossa Download Claude conversations toimii – Claude Code on the web osoitteessa claude.ai/code mukaan lukien. Kun nimet menevät sekaisin, vienti epäonnistuu huomaamatta.

Claude Desktop: jos chat on synkronoitunut samaan Anthropic-tiliin, avaa se claude.ai:ssa ja vie sieltä. Jos se on olemassa vain Desktop-ikkunassa, kopioi ja liitä tai odota virallista Export dataa. Opas: vie Claude Desktop -chat.

VS Coden Claude Code -paneeli on lähempänä CLI:tä kuin claude.ai:ta. Älä odota, että sisältöskriptimme toimii siinä webviewissä. Aja /export siinä istunnossa, jossa viestit oikeasti ovat.

Itsenäinen Chrome-laajennus, ei yhteydessä Anthropic, PBC:hen. Claude on Anthropicin tavaramerkki. Noudata Anthropicin käyttöehtoja. Emme voi antaa oikeudellista neuvontaa siitä, saako työkalujen tulosteita, joissa on suojattua koodia, kopioida; se on sinun, työnantajasi ja Anthropicin välinen asia.

UKK: Claude Code -keskustelun vienti

Miten vien Claude Code -keskustelun?

Kirjoita Claude Code -terminaalissa /export (halutessasi tiedostonimen kanssa) tallentaaksesi luettavan transkriptin, tai kopioi JSONL-tiedosto kansiosta ~/.claude/projects macOS:ssä/Linuxissa tai %USERPROFILE%\.claude\projects Windowsissa. Anthropicin istuntodokumentaatio kuvaa nykyisen dialogin.

Lataako tämä Chrome-laajennus Claude Code -chatteja?

Ei terminaalista. Download Claude conversations toimii vain claude.ai:ssa Chromessa. Se ei pysty lukemaan paikallisia terminaali-istuntoja, JSONL-transkriptejä eikä /export-komentoa. Claude Code on the web -istunnot osoitteessa claude.ai/code voi viedä kuten minkä tahansa chatin.

Voiko Claude Code on the web -istunnon (claude.ai/code) viedä?

Kyllä. Avaa istunto osoitteessa claude.ai/code Chromessa ja käytä oranssia painiketta. PDF, Markdown, pelkkä teksti, JSON, XML, CSV ja PNG toimivat kaikki. Muut kuusi formaattia ovat rajattomia ilman tiliä; PDF vaatii Google-kirjautumisen ja lasketaan 3 ilmaiseen kertaan päivässä.

Mihin Claude Code tallentaa keskusteluhistorian?

Istuntojen transkriptit ovat JSONL-tiedostoja polussa ~/.claude/projects/<encoded-working-directory>/, ja ne on nimetty istuntotunnisteen mukaan. Tarkka rakenne voi muuttua. Käytä /export-komentoa, kun haluat luettavan tiedoston JSONL:n jäsentämisen sijaan. CLAUDE_CONFIG_DIR voi siirtää koko puun.

Miten Claude Code -keskustelun saa Markdownina?

Claude Coden /export tuottaa pelkän tekstin transkriptin, ei tämän laajennuksen Markdownia. Jos tarvitset nimenomaan Markdownia, vie claude.ai/code-istunto tai työn claude.ai-kopio Download Claude conversations -laajennuksella tai muunna /export-teksti itse. Emme muunna JSONL:ää Markdowniksi.

Miten lataan sen sijaan claude.ai-keskustelun?

Asenna ilmainen Chrome-laajennus, avaa chat claude.ai:ssa ja käytä oranssia painiketta – tai historiaan ”Export All” -toimintoa. Katso näin lataat Claude-chatin. Markdown, teksti, JSON, XML, CSV ja PNG ovat rajattomia ilman tiliä; PDF ja joukkovienti ZIP-tiedostona ovat ilmaisia 3 kertaa päivässä Google-kirjautumisella; Pro maksaa 3,99 $/kk tai 26,99 $/vuosi.

Onko /export sama kuin virallinen Export data?

Ei. /export koskee nykyistä Claude Code -istuntoa. Settings → Privacy → Export data lähettää sähköpostiin JSON-ZIPin koko Anthropic-tilistä. Eri tuotteet, eri tiedostot, eri odotusajat.

Voiko Claude Coden JSONL:ää jäsentää jq:lla?

Voi, mutta Anthropicin varauksella: rivien skeema on sisäinen ja voi muuttua. Käytä mieluummin /export-komentoa tai claude -p --output-format json -komentoa, kun tarvitset vakaan sopimuksen. Jos jäsennät JSONL:ää silti, lukitse CLI:n versio.

Toimiiko Claude Code -vienti Windowsissa?

Kyllä. /export on CLI-komento. Levyllä transkriptit ovat polussa %USERPROFILE%\.claude\projects, ellet ole asettanut CLAUDE_CONFIG_DIR-muuttujaa. Tämä Chrome-laajennus ei silti toimi siinä terminaalissa.

Onko Claude Code sama kuin Claude Desktop?

Ei. Claude Code on terminaalissa toimiva koodausagentti. Claude Desktop on chat-sovellus. claude.ai on verkkosivusto. Vain verkkosivustolla, claude.ai/code mukaan lukien, toimii tämä laajennus. Desktopin vientiohjeet: Claude Desktop.

Tukeeko laajennus joskus /export-komentoa?

Ei versiossa 1.16.2. Tuotteen rajaus on claude.ai, Claude Code on the web mukaan lukien: seitsemän formaattia, paikalliset tiedostot, Google-kirjautuminen vain PDF:ää, joukkovientiä ja Pro-tilausta varten. Jos rajaus muuttuu, kerromme siitä tällä sivulla. Siihen asti käytä terminaalin Claude Code -vientiin Anthropicin CLI:tä.

Sisältääkö /export työkalujen tulosteet?

Anthropicin mukaan /export sisältää viestit ja työkalujen tulosteet luettavaksi tekstiksi muotoiltuina. Se on heidän transkriptinsa, ei meidän jäsentimemme. Tarkan nykyisen sisällön näet ajamalla /export-komennon omassa versiossasi ja lukemalla tiedoston – dokumentaatio voi olla julkaisua jäljessä.

Voiko Claude Code -istunnot viedä kerralla?

Ei paikallisia CLI-istuntoja. Hallintapaneelin ”Export All” koskee vain claude.ai:ta. Jos CLI-istuntoja on paljon, kopioi projects-kansio tai aja /export jokaisessa istunnossa. JSONL:lle ei ole oranssin painikkeen joukkovientiä.
