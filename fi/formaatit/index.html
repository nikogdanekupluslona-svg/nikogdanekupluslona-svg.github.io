Mitkä ovat Claude-chatin vientiformaatit?

Claude-chatin vientiformaatit tällä sivustolla ovat ne viisi tiedostotyyppiä, jotka Download Claude conversations kirjoittaa claude.ai-keskustelusta: Markdown, JSON, pelkkä teksti, XML ja PNG. Versiossa 1.13.0 ei ole PDF-kirjoitinta. Jokainen valmis tiedosto lasketaan yhdeksi 3 ilmaisesta viennistä.

Chrome-laajennus toimii vain claude.ai:ssa. Claude Desktop ja Claude Code eivät koskaan näytä oranssia painiketta. Jos sama keskustelu on claude.ai-tililläsi, avaa sen URL Chromessa ja valitse formaatti siellä. Valikko muistaa viimeksi käyttämäsi formaatin.

Samaa laajennusta haetaan myös nimillä Claude Chat Downloader ja Claude Conversation Downloader, ja englanniksi usein hakusanalla ”claude chat export”. Nimet viittaavat tähän tuotteeseen, eivät toiseen vientityökaluun. Juridisilla sivuilla voi yhä lukea Claude Exporter. Saamasi tiedostot ovat silti Markdownia, JSONia, tekstiä, XML:ää tai PNG:tä.

Yksi lista, kaksi reittiä. Oranssilla painikkeella ja Export Allilla on samat vientiformaatit. Joukkovienti tuottaa monta chatkohtaista tiedostoa, ei yhtä sekalaista ZIPiä. Lisätietoja: Export All -joukkovienti.

Minkä vientiformaatin valitsen?

Valitse Markdown muistiinpanoihin, JSON skripteihin, pelkkä teksti minne tahansa liitettävään arkistoon, XML silloin kun järjestelmä vaatii XML:ää ja PNG, kun haluat kuvan keskustelusta. Download Claude conversations ei nimeä yhtä parhaaksi. Claude-chatin vientiformaatit eroavat rakenteeltaan, eivät kiintiöltään.

Tarjoamme viisi Claude-chatin vientiformaattia – Markdown, JSON, teksti, XML ja PNG – emmekä edelleenkään tuota PDF:ää. Valikko on sama oranssissa painikkeessa ja Export Allissa, joten joukkovienti ei koskaan keksi eri tiedostotyyppiä.

Miten valitsen vientiformaatin?

Avaa keskustelun URL claude.ai:ssa Chromessa, napsauta viestikentän vieressä olevaa oranssia painiketta, valitse jokin vientiformaateista ja napsauta ”Export” (vie). Download Claude conversations kokoaa tiedoston välilehdessä. claude.ai:ssa ei syyskuussa 2026 ole omaa ”vie tämä chat” -toimintoa.

  1. Asenna Download Claude conversations Chrome Web Storesta (arvosana 5,0).
  2. Lataa claude.ai uudelleen ja avaa oikea keskustelun URL, älä tyhjää aloitussivua.
  3. Napsauta viestikentän oikealla puolella olevaa oranssia latauspainiketta.
  4. Valitse Markdown, JSON, pelkkä teksti, XML tai PNG. Viimeisin formaatti jää muistiin.
  5. Napsauta ”Export”. Chrome tallentaa tiedoston heti.

Google-kirjautuminen vaaditaan ennen ensimmäistä vientiä. Download Claude conversations tallentaa vahvistetun sähköpostiosoitteen laskeakseen 3 ilmaista vientiä ja palauttaakseen Pron uudelleenasennuksen jälkeen. Keskustelujen teksti ei kuulu kirjautumiseen. Toimintaperiaate: näin se toimii.

Saman työkalun valinnat koskevat kaikkia formaatteja: ajattelu päälle tai pois (”include thinking”), metatiedot (otsikko, aikaleimat, malli; ”include metadata”), lähettäjäsuodatin (”all / human only / assistant only” eli kaikki, vain käyttäjä, vain avustaja) ja artefaktien asettelu (”Original”, ”Inline”, ”Nested”, ”Flat”). PNG piirtää silti kuvan; muut neljä kirjoittavat tekstiä tai rakenteista merkintää.

Toimivatko vientiformaatit Export Allissa?

Kyllä. Avaa ”View and Download All Conversations” (näytä ja lataa kaikki keskustelut), suodata taulukko, valitse sama vientiformaattivalikko ja napsauta Export All. Jokainen valmis tiedosto on yksi 3 ilmaisesta viennistä. Pro hintaan 3,99 $/kk tai 26,99 $/vuosi poistaa rajan sekä joukko- että yksittäisviennistä.

Selaustaulukko listaa claude.ai-historian, ja siinä on nimihaku sekä suodattimet All, New, Exported ja Project (kaikki, uudet, viedyt, projekti). ”New” tarkoittaa keskusteluja, joita ei ole vielä viety Download Claude conversations -laajennuksella. ”Exported” seuraa jo tallennettuja chatteja. ”Project” vastaa sitä, miten ryhmittelet chatit claude.ai:ssa. Export All ei ole viiveellä tuleva tilin ZIP.

Kiintiö koskee koko tiliä. Kolme ilmaista vientiä yhteensä – ei kolme formaattia kohden eikä kolme joukkovientiä kohden. 40 keskustelun valinta kuluttaa 40 vientiä, jos jokainen tiedosto valmistuu. Suunnittele valinta tai käytä Prota.

Joukkovienti käyttää samoja ajattelu-, metatieto-, lähettäjä- ja artefaktivalintoja kuin yksittäinen keskustelu. Et saa yhdellä napsautuksella sekapakettia Markdownia ja JSONia. Valitset yhden vientiformaatin ajoa kohden. Aja Export All uudelleen eri formaatilla, jos tarvitset samasta keskustelusta kaksi muotoa; toinenkin ajo kuluttaa kiintiötä.

Vientiformaatit vai Anthropicin ZIP?

Anthropicin Settings → Privacy → Export data (valikot voivat näkyä suomeksi, jos claude.ai on asetettu suomen kielelle) lähettää odotuksen jälkeen sähköpostiin JSON-ZIPin koko tilistä. Download Claude conversations tallentaa avoimen keskustelun heti Markdownina, JSONina, tekstinä, XML:nä tai PNG:nä. Käytä ZIPiä varmuuskopioon ja tätä laajennusta, kun tarvitset tiedoston nyt.

Mitä vientiformaatit maksavat?

Jokainen Googlella kirjautunut tili saa 3 ilmaista vientiä. Sen jälkeen Pro maksaa 3,99 $ kuukaudessa tai 26,99 $ vuodessa Paddlen kautta. Hinta kattaa kaikki Claude-chatin vientiformaatit. Download Claude conversations ei veloita JSONista tai PNG:stä erikseen.

3 ilmaista vientiä eivät nollaudu, kun asennat laajennuksen uudelleen. Siksi Google-kirjautuminen vaaditaan ensimmäisellä ”Export”-napsautuksella. Pro palautuu uudella tietokoneella samalla Google-tilillä. Paddle on myyjä (merchant of record); emme koskaan näe korttinumeroita.

UKK: Claude-chatin vientiformaatit

Nämä kysymykset koskevat Download Claude conversations 1.13.0 -laajennuksen vientiformaatteja: viiden tiedostotyypin lista, kiintiö, Export All, Anthropicin ZIP, Desktop ja Pro. Jokainen vastaus on tuotefakta. Sivun FAQPage JSON-LD vastaa tätä listaa.

Missä formaateissa Claude-chatin voi ladata?

Markdown, JSON, pelkkä teksti, XML ja PNG. Download Claude conversations ei kirjoita PDF:ää. PNG on kuva claude.ai-keskustelusta, ei sivuiksi jaettu dokumentti.

Onko PDF yksi vientiformaateista?

Ei. Tuotteen valikossa ei ole koskaan PDF:ää. PDF-tyyppisen sivun saat tulostamalla claude.ai-välilehden Chromessa. Se tiedosto on selaimen tilannekuva, ei tämän laajennuksen vienti.

Jakavatko vientiformaatit samat 3 ilmaista vientiä?

Kyllä. Markdown, JSON, teksti, XML ja PNG lasketaan kukin yhdeksi vienniksi, kun tiedosto valmistuu. Pro hintaan 3,99 $/kk tai 26,99 $/vuosi poistaa rajan kaikista formaateista.

Voiko Export Allissa sekoittaa vientiformaatteja?

Ei. Yksi Export All -ajo käyttää yhtä formaattia. Aja se uudelleen eri formaatilla, jos tarvitset samasta claude.ai-chatista kaksi tiedostoa. Jokainen valmis tiedosto lasketaan silti kiintiöön.

Ovatko vientiformaatit sama asia kuin Export data?

Eivät. Anthropicin Export data on viiveellä tuleva tilin JSON-ZIP. Vientiformaatit ovat chatkohtaisia (tai valintakohtaisia) tiedostoja, jotka Download Claude conversations kirjoittaa heti Chromessa.

Toimivatko vientiformaatit Desktopissa tai Codessa?

Eivät. Chrome-laajennus toimii vain claude.ai:ssa. Claude Desktop ja Claude Code eivät koskaan näytä formaattivalikkoa. Avaa sama keskustelu claude.ai:ssa Chromessa, jos se on siellä.

Tarvitsenko Pron kokeillakseni vientiformaatteja?

Et. Minkä tahansa Googlella kirjautuneen tilin 3 ensimmäistä vientiä ovat ilmaisia missä tahansa formaatissa. Pro maksaa 3,99 $/kk tai 26,99 $/vuosi, kun tarvitset lisää yksittäisiä tai joukkovientitiedostoja.
