Mitkä ovat Claude-chatin vientiformaatit?

Claude-chatin vientiformaatit tällä sivustolla ovat ne seitsemän tiedostotyyppiä, jotka Download Claude conversations kirjoittaa claude.ai-keskustelusta: PDF, Markdown, pelkkä teksti, JSON, XML, CSV ja PNG. Versio 1.16.2 rakentaa jokaisen niistä selaimessasi. Kuusi niistä on rajattomia ilman tiliä. PDF pyytää Google-kirjautumista ja on ilmainen enintään 3 kertaa päivässä.

Laajennus toimii kaikkialla, missä keskustelu aukeaa claude.ai:ssa Chromessa: tavallisissa chateissa, projekteissa (Projects), Cowork-istunnoissa ja Claude Code on the web -istunnoissa (claude.ai/code). Claude Desktop -sovellus ja paikalliset Claude Code -pääteistunnot eivät koskaan näytä oranssia painiketta. Jos sama keskustelu on claude.ai-tililläsi, avaa sen URL Chromessa ja valitse formaatti siellä. Valikko muistaa viimeksi käyttämäsi formaatin.

Samaa laajennusta haetaan myös nimillä Claude Chat Downloader ja Claude Conversation Downloader, ja englanniksi usein hakusanalla ”claude chat export”. Nimet viittaavat tähän tuotteeseen, eivät toiseen vientityökaluun. Juridisilla sivuilla voi yhä lukea Claude Exporter. Saamasi tiedostot ovat samat seitsemän formaattia.

Yksi lista, kaksi reittiä. Oranssi painike vie avoimen chatin. Hallintapaneelin (Dashboard) Export All vie monta chattia yhteen ZIPiin, yksi tiedosto chattia kohden, siinä seitsemästä formaatista, jonka valitset kohdassa ”Chat format” (keskustelun muoto) – myös PDF:nä. Lisätietoja: Export All -joukkovienti.

Minkä vientiformaatin valitsen?

Valitse PDF lukemiseen ja jakamiseen, Markdown muistiinpanoihin, JSON skripteihin, CSV taulukkolaskentaan, pelkkä teksti minne tahansa liitettävään arkistoon, XML silloin kun järjestelmä vaatii XML:ää ja PNG, kun haluat kuvan keskustelusta. Download Claude conversations ei nimeä yhtä parhaaksi. Claude-chatin vientiformaatit eroavat rakenteeltaan; ilmaisversiossa vain PDF:llä on päiväraja.

Miten valitsen vientiformaatin?

Avaa keskustelun URL claude.ai:ssa Chromessa, napsauta viestikentän vieressä olevaa oranssia painiketta, valitse jokin vientiformaateista ja napsauta ”Export” (vie). Download Claude conversations kokoaa tiedoston välilehdessä. claude.ai:ssa ei syyskuussa 2026 ole omaa ”vie tämä chat” -toimintoa.

  1. Asenna Download Claude conversations Chrome Web Storesta.
  2. Lataa claude.ai uudelleen ja avaa oikea keskustelun URL, älä tyhjää aloitussivua.
  3. Napsauta viestikentän oikealla puolella olevaa pyöreää oranssia latauspainiketta.
  4. Valitse PDF, Markdown, pelkkä teksti, JSON, XML, CSV tai PNG. Viimeisin formaatti jää muistiin.
  5. Napsauta ”Export”. Chrome tallentaa tiedoston heti. PDF:lle määritä asetukset PDF-ikkunassa; ensimmäinen PDF pyytää Google-kirjautumista.

Markdown, teksti, JSON, XML, CSV ja PNG eivät vaadi kirjautumista: nämä viennit ovat rajattomia ja anonyymejä, eivätkä ne lähetä mitään. Google-kirjautuminen tulee vastaan vain PDF:n, Export Allin tai Pron kohdalla. Silloinkin laajennus lähettää vain Google-sähköpostiosoitteen tarkistaakseen päivärajan ja palauttaakseen Pron uudelleenasennuksen jälkeen. Keskustelun tekstiä ei koskaan lähetetä. Toimintaperiaate: näin se toimii.

Vientipaneelissa valitaan myös ”Messages” (viestit: ”All”, ”Human”, ”Assistant” eli kaikki, ihminen, avustaja), ”Thinking” (ajattelu) -valintaruutu ja ”Select” (valitse), jolla rastitat yksittäisiä viestejä. ”Copy” vie Markdownin, tekstin, JSONin, XML:n tai CSV:n leikepöydälle tiedoston sijaan; se on rajaton, mutta ei käytettävissä PDF:lle eikä PNG:lle. Työkalu- ja MCP-vaiheet sekä verkkohaun lähteet otetaan käyttöön asetuksissa (Settings). Metatiedot ja artefaktien asettelu (”Original”, ”Inline”, ”Nested”, ”Flat”) ovat hallintapaneelin valintoja; asettelu ratkaisee, ovatko artefaktit tiedoston sisällä vai omassa kansiossaan ZIPissä.

Toimivatko vientiformaatit Export Allissa?

Kyllä. Avaa laajennuksen ponnahdusikkuna → ”View and Download All Conversations” (näytä ja lataa kaikki keskustelut), suodata lista, rastita chatit, valitse mikä tahansa seitsemästä formaatista kohdassa ”Chat format” ja napsauta ”Export All”. Saat yhden ZIPin, jossa on yksi tiedosto chattia kohden. Joukkovienti vaatii Google-kirjautumisen; ilmaisversiossa jokainen ZIPin chat kuluttaa yhden 3 päivittäisestä PDF- tai joukkoviennistä. Pro hintaan 3,99 $/kk tai 26,99 $/vuosi poistaa rajan.

Hallintapaneeli listaa claude.ai-historian, ja siinä on nimihaku, projektihaku, välilehdet Chat ja Cowork sekä suodattimet ”All conversations”, ”New”, ”Updated” ja ”Previously exported” (kaikki keskustelut, uudet, päivitetyt, aiemmin viedyt). ”New” tarkoittaa keskusteluja, joita ei ole vielä viety Download Claude conversations -laajennuksella. ”Previously exported” seuraa jo tallennettuja chatteja. Export All ei ole viiveellä tuleva tilin ZIP.

Joukkoviennin raja on päivittäinen. Ilmaisversiossa PDF ja joukkovienti jakavat 3 vientiä päivässä, ja päivä vaihtuu keskiyöllä UTC-aikaa. Jokainen ZIPin chat lasketaan yhdeksi. Jos valitset enemmän kuin päivässä on jäljellä, koko erä estetään eikä sitä lyhennetä. Valitse vähemmän chatteja tai käytä Prota.

Joukkoviennillä on omat sisällytysvalintaruutunsa – ”Chats”, ”Thinking”, ”Metadata”, ”Tools”, ”Sources” (chatit, ajattelu, metatiedot, työkalut, lähteet) – sekä artefaktien asettelu. Et saa yhdellä napsautuksella sekapakettia Markdownia ja JSONia. Valitset ajoa kohden yhden vientiformaatin ”Chat format” -valitsimesta. Aja Export All uudelleen eri formaatilla, jos tarvitset samasta keskustelusta kaksi muotoa; ilmaisversiossa toinenkin ajo lasketaan rajaan.

Vientiformaatit vai Anthropicin ZIP?

Anthropicin Settings → Privacy → Export data (valikot voivat näkyä suomeksi, jos claude.ai on asetettu suomen kielelle) lähettää odotuksen jälkeen sähköpostiin JSON-ZIPin koko tilistä. Download Claude conversations tallentaa avoimen keskustelun heti PDF:nä, Markdownina, tekstinä, JSONina, XML:nä, CSV:nä tai PNG:nä. Käytä ZIPiä varmuuskopioon ja tätä laajennusta, kun tarvitset tiedoston nyt.

Mitä vientiformaatit maksavat?

Kuusi Claude-chatin vientiformaattia on maksuttomia eivätkä ne vaadi tiliä: Markdown, pelkkä teksti, JSON, XML, CSV ja PNG ovat rajattomia. PDF ja joukkovienti ZIP-tiedostona ovat ilmaisia enintään 3 kertaa päivässä yhteensä, Google-kirjautumisella. Pro maksaa 3,99 $ kuukaudessa tai 26,99 $ vuodessa Paddlen kautta ja tekee PDF:stä ja joukkoviennistä rajattomia. Download Claude conversations ei veloita mistään yksittäisestä formaatista erikseen.

Päivittäinen laskuri nollautuu keskiyöllä UTC-aikaa ja seuraa Google-tiliäsi, minkä vuoksi PDF ja joukkovienti pyytävät kirjautumista. Pro palautuu uudella tietokoneella, kun kirjaudut samalla Google-tilillä. Paddle on myyjä (merchant of record); emme koskaan näe korttinumeroita. Voit perua tilauksen milloin tahansa laajennuksen asetussivulta (Options); ensimmäisellä maksulla on 14 päivän rahat takaisin -takuu.

UKK: Claude-chatin vientiformaatit

Nämä kysymykset koskevat Download Claude conversations 1.16.2 -laajennuksen vientiformaatteja: seitsemän formaatin lista, PDF, CSV, rajat, Export All, Anthropicin ZIP, Desktop ja Code sekä Pro. Jokainen vastaus on tuotefakta. Sivun FAQPage JSON-LD vastaa tätä listaa.

Missä formaateissa Claude-chatin voi ladata?

Seitsemässä: PDF, Markdown, pelkkä teksti, JSON, XML, CSV ja PNG. Markdown, teksti, JSON, XML, CSV ja PNG ovat rajattomia eivätkä vaadi tiliä. PDF vaatii Google-kirjautumisen ja on ilmainen enintään 3 kertaa päivässä.

Onko PDF yksi vientiformaateista?

On. Valitse vientipaneelista PDF. PDF-ikkunassa määrität tiedostonimen, sivukoon, marginaalit, vaalean tai tumman tilan, fontin ja fonttikoon, sivunumerot, sisällysluettelon, aikaleimat ja sivunvaihdon ennen jokaista kehotetta. Tiedosto rakennetaan selaimessa ilman tulostusikkunaa.

Mihin CSV-vientiä käytetään?

Taulukkolaskentaan. CSV kirjoittaa yhden rivin viestiä kohden ja aukeaa Excelissä, Google Sheetsissä ja Numbersissa. Se on rajaton, ei vaadi tiliä, ja sen voi kopioida leikepöydälle lataamisen sijaan.

Onko vientiformaateilla päiväraja?

Vain PDF:llä ja joukkoviennillä. Yksittäisen chatin Markdown-, teksti-, JSON-, XML-, CSV- ja PNG-viennit ovat rajattomia ja ilmaisia. Ilmaisversiossa PDF ja joukkovienti ZIP-tiedostona jakavat 3 vientiä päivässä, ja laskuri nollautuu keskiyöllä UTC-aikaa. Pro hintaan 3,99 $/kk tai 26,99 $/vuosi poistaa rajan.

Voiko Export Allissa sekoittaa vientiformaatteja?

Ei. Yksi Export All -ajo käyttää yhtä formaattia ja tuottaa yhden ZIPin. Aja se uudelleen eri formaatilla, jos tarvitset samasta claude.ai-chatista kaksi tiedostoa. Ilmaisversiossa jokainen ZIPin chat lasketaan 3 päivittäiseen PDF- tai joukkovientiin.

Ovatko vientiformaatit sama asia kuin Export data?

Eivät. Anthropicin Export data on viiveellä tuleva tilin JSON-ZIP. Vientiformaatit ovat chatkohtaisia (tai valintakohtaisia) tiedostoja, jotka Download Claude conversations kirjoittaa heti Chromessa.

Toimivatko vientiformaatit Desktopissa tai Codessa?

Verkossa toimivat. Chatit, projektit, Cowork-istunnot ja Claude Code on the web (claude.ai/code) saavat Chromessa kaikki formaatit. Claude Desktop -sovellus ja paikalliset Claude Code -pääteistunnot eivät koskaan näytä formaattivalikkoa. Avaa sama keskustelu claude.ai:ssa Chromessa, jos se on siellä.

Tarvitsenko Pron kokeillakseni vientiformaatteja?

Et. Kuusi formaattia on ilmaisversiossa rajattomia ilman tiliä. PDF on ilmainen enintään 3 kertaa päivässä Google-kirjautumisella, ja raja on yhteinen ZIP-joukkoviennin kanssa. Pro maksaa 3,99 $/kk tai 26,99 $/vuosi, kun tarvitset rajattoman PDF:n tai joukkoviennin.
