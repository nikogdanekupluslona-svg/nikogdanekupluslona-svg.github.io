6 keskeistä ominaisuutta Claude-chattien lataamiseen

01

Vienti PDF-, Markdown-, JSON-, CSV- ja muihin muotoihin

Lataa Claude-chat oikeana tiedostona – ei kuvakaappauksena verkkosivusta. PDF lukemiseen ja jakamiseen, Markdown muistiinpanoihin, JSON kehittäjille, CSV taulukkolaskentaan, pelkkä teksti yksinkertaisimpaan arkistoon, XML tiedonsiirtoon ja PNG visuaaliseksi tilannekuvaksi. Voit myös painaa Copy (kopioi), jolloin tulos siirtyy leikepöydälle.

02

Lataa Claude-chatit kerralla

Avaa View and Download All Conversations (näytä ja lataa kaikki keskustelut), niin näet historiasi, voit hakea nimellä, suodattaa projektin tai Coworkin mukaan ja napsauttaa Export All (vie kaikki). Yksi ZIP-tiedosto sen sijaan, että kävisit välilehdet läpi yksi kerrallaan – ilmaisversiossa 3 chattia päivässä, Prossa rajattomasti.

03

Koodi, taulukot ja artefaktit säilyvät

Vientimoottori jäsentää viestipuun, joten koodilohkojen sisennykset säilyvät, taulukot pysyvät taulukkoina ja artefaktien asettelu voi olla ”Original”, ”Inline”, ”Nested” tai ”Flat” (alkuperäinen, upotettu, sisäkkäinen tai litteä).

04

Valitse, mitä tiedostoon tulee

Vie koko keskustelu, vain omat kehotteesi, vain Clauden vastaukset tai pelkät viestit, jotka rastitat Select-toiminnolla (valitse). Sisällytä laajennettu ajattelu, kun tarvitset jäljitettävyyttä, tai jätä se pois. Otsikot, aikaleimat ja mallin metatiedot voivat kulkea mukana samassa tiedostossa.

05

Hae ja suodata ennen vientiä

Rajaa kirjasto uusiin keskusteluihin, jo vietyihin keskusteluihin tai yhteen Claude-projektiin ja vie vain valitsemasi.

06

Tiedostot luodaan paikallisesti selaimessa

Jokainen tiedosto, myös PDF, kootaan laitteellasi ja ladataan levylle. Useimmat viennit eivät vaadi tiliä. Google-kirjautumista käytetään vain PDF- ja joukkovientien laskemiseen ja Pro-tilauksen liittämiseen – sillä ei koskaan lähetetä chatin tekstiä palvelimillemme.

Usein kysytyt kysymykset

Voiko Claude-keskustelun ladata claude.ai:sta?

Ei sisäänrakennetulla painikkeella. Asenna Download Claude conversations Chrome Web Storesta, avaa keskustelu ja vie se tiedostoksi.

Onko Claude-chattien lataaminen ilmaista?

On. Markdown-, pelkkä teksti-, JSON-, XML-, CSV- ja PNG-viennit ovat rajattomia eivätkä vaadi tiliä. PDF- ja ZIP-joukkoviennit pyytävät Google-kirjautumista, ja ne ovat ilmaisia enintään 3 kertaa päivässä. Pro hintaan 3,99 $/kk tai 26,99 $/vuosi poistaa tämän rajan.

Missä selaimissa se toimii?

Tietokoneen Chromessa ja Chromium-pohjaisissa selaimissa, jotka asentavat laajennuksia Chrome Web Storesta. Mobiilisovellusta ei ole, eikä laajennus toimi Claude Desktop -sovelluksessa.

Miten peruutan Pron ja saanko rahat takaisin?

Voit perua tilauksen milloin tahansa laajennuksen asetussivulta (Options) kohdasta ”Cancel subscription” (peru tilaus) tai Paddlen kautta. Ensimmäisellä maksullasi on 14 päivän rahat takaisin -takuu ilman kysymyksiä.

Onko tämä sama asia kuin Clauden Export data?

Ei. Anthropicin Settings → Privacy → Export data (valikoiden nimet voivat näkyä suomeksi, jos claude.ai on asetettu suomen kielelle) lähettää sähköpostiin koko tilin ZIP-paketin (JSON). Tämä laajennus lataa avoimen keskustelun – tai joukkovalinnan – luettavina tiedostoina heti.

Tallennatteko Claude-keskusteluni?

Emme. Jokainen muoto, myös PDF, rakennetaan selaimessasi, eikä keskustelujen teksti koskaan päädy palvelimillemme. Jos kirjaudut Googlella PDF:ää, joukkovientiä tai Pro-tilausta varten, tallennamme sähköpostiosoitteen vain päiväkiintiön laskemiseen ja tilauksesi liittämiseen.

Onko ”lataa Claude-keskustelu” eri asia kuin ”claude chat export”?

Sama tehtävä, eri sanamuoto – suomeksi tai englanniksi. Kummassakin tapauksessa käytät claude.ai:n oranssia painiketta.

Voiko sillä viedä PDF-tiedoston?

Voi. Valitse vientipaneelista PDF ja aseta sivukoko, marginaalit, vaalea tai tumma tila, fontti, sivunumerot ja sisällysluettelo. PDF vaatii Google-kirjautumisen; ilmaisversioon sisältyy 3 PDF- tai joukkovientiä päivässä, ja Prossa niitä on rajattomasti. Koko ohje: lataa Claude-chat PDF-muodossa.

Toimiiko se Claude Pro- ja Team-tileillä?

Kyllä, jos voit avata keskustelun selaimessa claude.ai:ssa. Emme ole Anthropic.

Miten tallennan Claude-keskustelun?

Asenna ilmainen Chrome-laajennus, avaa keskustelu claude.ai:ssa, napsauta oranssia painiketta, valitse muoto ja napsauta Export. Markdown, teksti, JSON, XML, CSV ja PNG eivät vaadi tiliä. Näin Claude-keskustelu tallentuu oikeaksi tiedostoksi. Muut kaksi vaihtoehtoa ovat sivun tulostaminen ja Anthropicin tilin ZIP-paketti – vertailu löytyy oppaasta näin lataat Claude-keskustelun.

Lataako tämä Claude Code -keskusteluja?

Vain ne, jotka ovat claude.ai:ssa. Claude Code on the web (claude.ai/code) ja Cowork-istunnot viedään kuten mikä tahansa chat. Paikallisia terminaali-istuntoja laajennus ei lue; niissä käytetään komentoa /export tai levyllä olevia JSONL-tiedostoja – katso Claude Code -vienti.

Liittyykö Download Claude conversations Anthropiciin?

Ei. Claude on Anthropic, PBC:n tavaramerkki. Tämä on itsenäinen Chrome-laajennus, ei Anthropicin virallinen tuote.
