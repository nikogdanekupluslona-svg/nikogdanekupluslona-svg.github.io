Comment exporter une conversation Claude avec l’extension ?

Pour obtenir un fichier lisible, utilisez le bouton orange sur claude.ai. Installez Download Claude conversations, ouvrez la conversation, choisissez Markdown, JSON, texte, XML ou PNG, puis cliquez sur « Export » (exporter). Le fichier est généré dans votre navigateur et enregistré en local. La connexion Google sert à compter les 3 exports gratuits.

L’extension est un script de contenu qui agit sur la page déjà chargée. Elle n’ouvre pas de seconde session Anthropic et n’envoie pas la conversation en ligne pour générer le fichier. C’est pourquoi le bouton n’apparaît que sur l’URL d’une conversation, une fois celle-ci présente dans la page.

  1. Installez l’extension depuis le Chrome Web Store.
  2. Ouvrez la conversation sur claude.ai. Rechargez l’onglet s’il était ouvert pendant l’installation.
  3. Cliquez sur le bouton orange de téléchargement, à côté de la zone de message.
  4. Choisissez Markdown, JSON, texte brut, XML ou PNG.
  5. Réglez si besoin la réflexion (« include thinking »), les métadonnées (« include metadata »), l’auteur (« all / human only / assistant only ») et la mise en page des artefacts (« Original », « Inline », « Nested », « Flat »). Cliquez sur « Export ».

Pour plusieurs conversations, ouvrez « View and Download All Conversations » (afficher et télécharger toutes les conversations) depuis la fenêtre de l’extension. Cherchez, filtrez par projet ou par conversations déjà exportées, puis cliquez sur « Export All » (tout exporter). Chaque fichier du lot compte dans les mêmes 3 exports gratuits. Présentation : exporter tout l’historique avec Export All.

Les conversations Team et Enterprise s’exportent de la même façon si vous pouvez les ouvrir dans Chrome. L’analyseur ne vérifie pas le nom de l’offre Anthropic. Si votre organisation bloque les extensions, c’est une règle du service informatique, pas une option Pro manquante de notre côté.

Quota et utilisation Anthropic. Exporter avec cette extension ne consomme pas vos crédits de messages Claude : elle lit la page. La limite de 3 exports est notre quota, facturé séparément via Paddle si vous achetez Pro à 3,99 $/mois ou 26,99 $/an.

Comment exporter ses conversations Claude avec le ZIP officiel ?

À l’échelle du compte, l’export passe par Settings → Privacy → Export data (les libellés peuvent être traduits si claude.ai est en français). Anthropic envoie par e-mail un lien qui expire. Le ZIP contient le JSON de tout le compte, pas un fichier soigné pour une conversation. Utilisez-le comme sauvegarde.

Le ZIP officiel est le bon outil quand vous quittez un espace de travail, archivez tout ou répondez à une demande du type « donnez-moi toutes mes données ». C’est le mauvais outil quand une revue de conception est ouverte et qu’il vous faut un fichier dans la minute.

Ce parcours ne permet pas de filtrer une seule conversation. Vous attendez, téléchargez l’archive, la décompressez, puis retrouvez la conversation. La structure JSON est celle du compte. Ce n’est pas le JSON par conversation que cette extension écrit à partir de la page ouverte.

Si vous avez besoin des deux, lancez Export data une fois pour la sauvegarde et utilisez Download Claude conversations chaque fois qu’il vous faut un fichier de travail. Ces deux besoins ne se remplacent pas. Le ZIP ne deviendra pas du Markdown. Le bouton orange ne vous enverra pas par e-mail toutes les conversations oubliées de 2024.

Export data n’est pas non plus une impression en PDF. L’impression capture la page web. Le ZIP contient des données structurées du compte. Comparaison entre impression et fichiers : enregistrer une conversation Claude en PDF.

Comment exporter une conversation Claude en Markdown ou JSON ?

Choisissez ce format dans la liste déroulante avant de cliquer sur « Export ». Markdown sert aux notes et à git. JSON est l’arborescence des messages pour vos scripts. Le texte brut supprime le balisage. Le PNG est une image, pas un PDF.

Markdown conserve les titres, les blocs de code avec leur langage et les tableaux. La mise en page des artefacts peut être « Original », « Inline », « Nested » ou « Flat ». Les blocs de réflexion sont facultatifs. C’est ce fichier que la plupart des gens appellent un export lisible. Page dédiée : formats.

Le JSON de l’extension correspond à une conversation (ou à une sélection groupée). Ce n’est pas le ZIP de compte d’Anthropic renommé. Si vous écrivez un analyseur, utilisez ce JSON pour une conversation et le ZIP officiel uniquement si vous avez vraiment besoin de toutes les conversations stockées par Anthropic.

Le PNG n’est pas un PDF. Si un client exige un PDF, imprimez claude.ai ou convertissez le Markdown dans une autre application. Nous ne produisons pas de .pdf. Prétendre le contraire reviendrait à inventer une fonctionnalité.

La liste déroulante mémorise le dernier format. Exporter du JSON par erreur après une session de scripts est le signalement de « mauvais fichier » le plus courant. Regardez la liste avant d’utiliser un export de l’offre gratuite.

Peut-on exporter une conversation Claude sans payer ?

Oui. Les 3 premiers fichiers de tout compte sont gratuits, dans n’importe lequel des cinq formats. Ensuite, Pro coûte 3,99 $ par mois ou 26,99 $ par an. La connexion Google empêche qu’une réinstallation remette le compteur gratuit à zéro.

« Export All » n’a pas de quota gratuit séparé. Un fichier issu d’« Export All » est un export, comme avec le bouton orange. Sélectionner vingt conversations sur un compte gratuit s’arrête après le troisième fichier. Préparez votre sélection.

L’impression et Export data d’Anthropic n’utilisent pas notre quota. Elles ne vous donnent pas non plus le Markdown d’une conversation. Se passer d’extension a quand même un coût en temps et en nettoyage.

La connexion Google n’est pas facultative. Le premier clic sur « Export » demande à Google de vérifier une adresse e-mail. Si vous annulez, cela ressemble à un export raté. Terminez la connexion, puis cliquez de nouveau sur « Export ». Aucune carte bancaire n’est demandée pour les 3 fichiers gratuits.

La restauration de Pro suit cette adresse Google si vous changez d’ordinateur ou réinstallez l’extension. Elle ne suit pas le mot de passe Anthropic. Connectez-vous avec le compte Google utilisé lors du paiement.

Nous gardons volontairement le ZIP officiel et notre export comme deux besoins distincts. Le JSON du compte par e-mail est la sauvegarde d’Anthropic. Le Markdown et le JSON par conversation sont ce que nous générons dans le navigateur à partir de la conversation ouverte. Réunir les deux dans un seul bouton dégraderait l’un et l’autre.

Exporter une conversation Claude ou faire un copier-coller ?

Le copier-coller n’exporte une conversation Claude qu’au sens le plus faible : vous avez sélectionné du texte et l’avez déplacé. Le code perd son indentation. Les tableaux s’écrasent. Une longue conversation n’a plus de séparation entre les messages. Pour un fichier structuré, il reste l’extension, l’impression ou le ZIP officiel.

Une solution intermédiaire consiste à tout sélectionner, coller dans Google Docs ou Word, puis corriger la mise en forme à la main. Cela convient pour un livrable client ponctuel, pas pour une archive hebdomadaire. Chaque nouvel échange implique un nouveau nettoyage. L’extension existe pour que ce nettoyage ne parte pas d’un collage.

Le copier-coller manque aussi la réflexion repliée et les artefacts qui n’ont pas été dépliés. L’impression a la même lacune : l’interface repliée est absente du PDF. Les options de l’extension peuvent inclure la réflexion et les artefacts quand ils figurent dans les données chargées de la page, ce qui est une autre couche que « les pixels visibles ».

Si vous n’avez besoin que d’un paragraphe pour Slack, le copier-coller est honnête et plus rapide. Si vous avez besoin de toute la revue avec les blocs de code, utilisez un des 3 exports gratuits en Markdown.

Comment exporter depuis Claude Code plutôt que claude.ai ?

Pour une conversation sur claude.ai, c’est cette extension Chrome. Pour une conversation Claude Code, c’est /export dans le terminal, ou les fichiers JSONL dans ~/.claude/projects. Claude Desktop est une troisième fenêtre et n’affiche pas le bouton orange.

La commande /export de Claude Code écrit une transcription en texte brut (presse-papiers ou fichier). Anthropic précise que le JSONL sur le disque est un format interne susceptible de changer. Préférez /export ou leurs interfaces de script pour tout ce que vous voulez conserver. Étapes : exporter une conversation Claude Code.

Claude Desktop : ouvrez la même conversation sur claude.ai si elle est synchronisée, puis exportez-la là. Sinon, faites un copier-coller depuis Desktop, ou comptez sur Settings → Privacy → Export data pour un JSON au niveau du compte. Guide : exporter une conversation Claude Desktop.

Sur ce site, chercher « export Claude Code » mène à une page de clarification, pas à une fonctionnalité de la fiche du Chrome Web Store. La fiche concerne uniquement claude.ai. Cette limite fait partie du produit ; ce n’est pas une case à cocher manquante.

Que garde et que perd l’export d’une conversation Claude ?

L’export d’une conversation Claude avec cette extension conserve l’arborescence des messages chargée par la page : auteurs, texte, blocs de code, tableaux et, si les options sont activées, la réflexion, les métadonnées et les artefacts. Il laisse de côté ce qui n’est pas encore affiché et les éléments d’interface comme la zone de saisie.

L’impression conserve les pixels. Elle perd le plus souvent une mise en page propre du code. Le ZIP officiel conserve ce qu’Anthropic a mis dans l’archive du compte. Il ne fournit pas de document lisible par conversation. Le copier-coller conserve les caractères sélectionnés et perd la structure.

Filtre par auteur : tous les messages, humain seul ou assistant seul. Utile quand vous voulez les questions sans les réponses, ou l’inverse. L’option métadonnées ajoute titres, horodatages et modèle quand vous avez besoin d’une référence dans le fichier.

Les fichiers restent sur le disque. Notre serveur voit l’état de l’abonnement. Google voit le consentement OAuth que vous avez accordé. claude.ai avait déjà la conversation. Voilà la liste complète des intervenants. Nous ne sommes pas Anthropic. Claude est une marque d’Anthropic, PBC.

Si l’export semble trop court, chargez davantage la conversation et exportez de nouveau. Sur l’offre gratuite, ce deuxième essai consomme un des 3 exports. Vérifiez que la réponse est terminée et que les anciens échanges sont à l’écran avant de cliquer.

FAQ : comment exporter une conversation Claude

Comment exporter une seule conversation Claude ?

Utilisez Download Claude conversations sur la conversation claude.ai ouverte. L’export officiel Export data couvre tout le compte et prend plus de temps qu’il n’en faut pour une seule conversation. L’impression donne un PDF visuel, pas du Markdown.

Comment exporter une conversation Claude en PDF ?

Ni claude.ai ni cette extension ne produisent de PDF natif. Imprimez (Ctrl/Cmd+P → Enregistrer au format PDF) pour un instantané. Ou exportez en Markdown et convertissez le fichier dans Word, Google Docs ou une application Markdown. Guide : enregistrer une conversation Claude en PDF.

L’export officiel inclut-il les artefacts et la réflexion ?

Le ZIP contient ce qu’Anthropic a stocké dans le JSON du compte. Il n’est pas mis en forme en Markdown par conversation avec une mise en page d’artefacts choisie. L’export de l’extension est conçu pour garder ces éléments lisibles quand les options sont activées et que la page les a chargés.

Une extension Chrome met-elle mon compte Anthropic en danger ?

L’extension utilise votre session claude.ai existante, comme le fait le site. Elle n’automatise aucune action sur le compte et n’appelle pas Anthropic avec ses propres identifiants. Nous ne sommes pas Anthropic. Vous restez soumis à leurs conditions d’utilisation.

Existe-t-il un moyen gratuit d’exporter une conversation Claude ?

Oui. 3 exports gratuits sur tout compte, en Markdown, JSON, texte, XML ou PNG. Ensuite, Pro coûte 3,99 $/mois ou 26,99 $/an. L’impression et l’export officiel Export data n’utilisent pas ce quota.

Puis-je exporter une conversation Claude depuis un espace Team ?

Oui, si vous pouvez ouvrir la conversation sur claude.ai dans Chrome. L’extension travaille à partir de la page, pas d’une offre réservée aux particuliers. Les listes d’extensions autorisées par votre entreprise s’appliquent toujours.

L’export consomme-t-il les limites du compte Anthropic ?

Non. Download Claude conversations lit la page déjà chargée. Elle n’envoie aucune requête de génération supplémentaire à Claude et ne compte pas dans les limites de messages ou d’utilisation d’Anthropic.

Le premier export groupé est-il gratuit ?

Les 3 premiers fichiers d’un compte sont gratuits, qu’ils viennent d’une conversation, de trois conversations ou d’une petite sélection groupée. « Export All » n’a pas de quota gratuit séparé.

Comment exporter une conversation Claude Code ?

Dans le terminal, lancez /export ou copiez les fichiers JSONL depuis ~/.claude/projects. Cette extension Chrome n’exporte pas les conversations Claude Code. Étapes complètes : exporter une conversation Claude Code.

La connexion Google est-elle obligatoire pour exporter une conversation Claude ?

Oui, dès le premier export. Elle applique le quota gratuit et restaure Pro. Le contenu des conversations n’est pas envoyé lors de la connexion. Nous conservons l’adresse e-mail vérifiée pour le quota et le statut d’abonnement.

Dans quels formats puis-je exporter une conversation Claude ?

Markdown, JSON, texte brut, XML et PNG. Pas de PDF. Le PNG est une image. Consultez la page formats pour savoir lequel choisir.

Claude Conversation Downloader est-il la même extension ?

Oui. Download Claude conversations, Claude Chat Downloader et Claude Conversation Downloader désignent la même extension Chrome : bouton orange sur claude.ai, cinq formats, 3 exports gratuits, Pro à 3,99 $/mois ou 26,99 $/an.
