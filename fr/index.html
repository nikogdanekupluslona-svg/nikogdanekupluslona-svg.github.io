Comment télécharger une conversation Claude en 3 étapes

  1. 1

    Ajoutez l’extension

    Installez Download Claude conversations depuis le Chrome Web Store et épinglez-la. Comptez une dizaine de secondes.

  2. 2

    Ouvrez une conversation sur claude.ai

    Un bouton de téléchargement orange apparaît à droite de la zone de message. Pour de nombreuses conversations, ouvrez View and Download All Conversations (afficher et télécharger toutes les conversations).

  3. 3

    Choisissez un format et exportez

    Choisissez PDF, Markdown, JSON, texte, CSV, XML ou PNG, puis cliquez sur Export (exporter). Aucun compte requis : la connexion Google n’est demandée que pour le PDF et les exports groupés.

6 fonctionnalités clés pour télécharger vos conversations Claude

01

Export en PDF, Markdown, JSON, CSV et plus

Téléchargez une conversation Claude sous forme de vrai fichier, pas de capture d’écran de la page web. PDF pour lire et partager, Markdown pour vos notes, JSON pour les développeurs, CSV pour les tableurs, texte brut pour l’archive la plus simple, XML pour l’échange de données, PNG pour un aperçu visuel. Ou cliquez sur Copy (copier) pour placer le résultat dans le presse-papiers.

02

Télécharger plusieurs conversations Claude d’un coup

Ouvrez View and Download All Conversations pour lister votre historique, chercher par nom, filtrer par projet ou par Cowork, puis cliquez sur Export All (tout exporter). Un seul ZIP au lieu d’un onglet après l’autre : 3 conversations par jour avec l’offre gratuite, sans limite avec Pro.

03

Code, tableaux et artefacts préservés

Le moteur d’export analyse l’arborescence des messages : les blocs de code gardent leur indentation, les tableaux restent des tableaux, et les artefacts peuvent être rendus en « Original », « Inline », « Nested » ou « Flat » (original, intégré, imbriqué ou à plat).

04

Choisissez ce que contient le fichier

Exportez toute la conversation, uniquement vos messages, uniquement les réponses de Claude, ou seulement les messages que vous cochez avec Select (sélectionner). Incluez la réflexion étendue quand vous avez besoin d’une trace complète, ou laissez-la de côté. Titres, horodatages et métadonnées du modèle peuvent figurer dans le même fichier.

05

Rechercher et filtrer avant d’exporter

Limitez la liste aux nouvelles conversations, aux conversations déjà exportées ou à un projet Claude, puis exportez uniquement votre sélection.

06

Généré localement dans votre navigateur

Chaque fichier, PDF compris, est assemblé sur votre appareil puis enregistré sur le disque. La plupart des exports ne demandent aucun compte. La connexion Google sert uniquement à compter les exports PDF et groupés et à rattacher un abonnement Pro : elle n’envoie jamais le texte de vos conversations vers nos serveurs.

Questions fréquentes

Puis-je télécharger une conversation Claude depuis claude.ai ?

Pas avec un bouton intégré. Installez Download Claude conversations depuis le Chrome Web Store, ouvrez la conversation et exportez un fichier.

Le téléchargement des conversations Claude est-il gratuit ?

Oui. Les exports Markdown, texte brut, JSON, XML, CSV et PNG sont illimités et ne demandent aucun compte. Les exports PDF et ZIP groupés demandent une connexion Google et sont gratuits jusqu’à 3 par jour. Pro, à 3,99 $ par mois ou 26,99 $ par an, supprime cette limite.

Avec quels navigateurs l’extension fonctionne-t-elle ?

Chrome sur ordinateur et les navigateurs basés sur Chromium qui installent des extensions depuis le Chrome Web Store. Il n’existe pas d’application mobile, et l’extension ne fonctionne pas dans Claude Desktop.

Comment résilier Pro, et puis-je être remboursé ?

Résiliez à tout moment depuis la page Options de l’extension (« Cancel subscription », résilier l’abonnement) ou via Paddle. Votre premier paiement est couvert par une garantie satisfait ou remboursé de 14 jours, sans justification à fournir.

Est-ce la même chose que l’option Export data de Claude ?

Non. Settings → Privacy → Export data d’Anthropic (les libellés peuvent être traduits si claude.ai est en français) vous envoie par e-mail un ZIP de tout votre compte (JSON). Cette extension télécharge immédiatement la conversation ouverte, ou une sélection de conversations, sous forme de fichiers lisibles.

Conservez-vous mes conversations Claude ?

Non. Chaque format, PDF compris, est généré dans votre navigateur, et le texte des conversations n’atteint jamais nos serveurs. Si vous vous connectez avec Google pour le PDF, l’export groupé ou Pro, nous conservons uniquement cette adresse e-mail pour compter le quota quotidien et rattacher votre abonnement.

Quelle différence entre « exporter une conversation Claude » et « télécharger une conversation Claude » ?

C’est la même tâche, formulée de deux façons. Dans les deux cas, utilisez le bouton orange sur claude.ai.

L’extension exporte-t-elle en PDF ?

Oui. Choisissez PDF dans le panneau d’export et réglez le format de page, les marges, le mode clair ou sombre, la police, la numérotation des pages et une table des matières. Le PDF demande une connexion Google ; l’offre gratuite inclut 3 exports PDF ou groupés par jour, et Pro est illimité. Guide complet : enregistrer une conversation Claude en PDF.

Fonctionne-t-elle avec Claude Pro / Team ?

Oui, si vous pouvez ouvrir la conversation dans le navigateur sur claude.ai. Nous ne sommes pas Anthropic.

Comment sauvegarder une conversation Claude ?

Installez l’extension Chrome gratuite, ouvrez la conversation sur claude.ai, cliquez sur le bouton orange, choisissez un format, puis cliquez sur Export. Aucun compte n’est nécessaire pour Markdown, texte, JSON, XML, CSV ou PNG. C’est ainsi que l’on sauvegarde une conversation Claude sous forme de vrai fichier. L’impression de la page et le ZIP de compte d’Anthropic sont les deux autres options ; comparaison dans le guide télécharger une conversation Claude.

L’extension télécharge-t-elle les conversations Claude Code ?

Seulement celles de claude.ai. Les sessions Claude Code sur le web (claude.ai/code) et les sessions Cowork s’exportent comme n’importe quelle conversation. L’extension ne lit pas les sessions locales du terminal : celles-ci passent par /export ou par des fichiers JSONL sur le disque (voir exporter une conversation Claude Code).

Download Claude conversations est-elle liée à Anthropic ?

Non. Claude est une marque d’Anthropic, PBC. Il s’agit d’une extension Chrome indépendante, pas d’un produit officiel d’Anthropic.
