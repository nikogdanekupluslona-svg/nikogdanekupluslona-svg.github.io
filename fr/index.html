Pour exporter une conversation Claude, claude.ai ne propose aucun bouton intégré. 6 fonctionnalités clés pour télécharger vos conversations Claude

01

Export en Markdown, JSON, XML, texte et PNG

Téléchargez une conversation Claude sous forme de vrai fichier, pas de capture d’écran de la page web. Markdown pour vos notes, JSON pour les développeurs, texte brut pour l’archive la plus simple, XML pour l’échange de données, PNG pour un aperçu visuel.

02

Télécharger plusieurs conversations Claude d’un coup

Ouvrez View and Download All Conversations (afficher et télécharger toutes les conversations) pour lister votre historique, chercher par nom, filtrer par projet, puis cliquez sur Export All (tout exporter). Une seule passe au lieu d’un onglet après l’autre.

03

Code, tableaux et artefacts préservés

Le moteur d’export analyse l’arborescence des messages : les blocs de code gardent leur indentation, les tableaux restent des tableaux, et les artefacts peuvent être rendus en « Original », « Inline », « Nested » ou « Flat » (original, intégré, imbriqué ou à plat).

04

Blocs de réflexion et métadonnées en option

Incluez la réflexion étendue de Claude quand vous avez besoin d’une trace complète, ou laissez-la de côté. Titres, horodatages et métadonnées du modèle peuvent figurer dans le même fichier.

05

Rechercher et filtrer avant d’exporter

Limitez la liste aux nouvelles conversations, aux conversations déjà exportées ou à un projet Claude, puis exportez uniquement votre sélection.

06

Généré localement dans votre navigateur

Le contenu de la conversation est assemblé sur votre appareil puis enregistré sur le disque. La connexion Google sert au quota d’exports gratuits, pas à envoyer le texte de vos conversations vers nos serveurs.

Questions fréquentes

Puis-je télécharger une conversation Claude depuis claude.ai ?

Pas avec un bouton intégré. Installez Download Claude conversations depuis le Chrome Web Store, ouvrez la conversation et exportez un fichier.

Est-ce la même chose que l’option Export data de Claude ?

Non. Settings → Privacy → Export data d’Anthropic (les libellés peuvent être traduits si claude.ai est en français) vous envoie par e-mail un ZIP de tout votre compte (JSON). Cette extension télécharge immédiatement la conversation ouverte, ou une sélection de conversations, sous forme de fichiers lisibles.

Conservez-vous mes conversations Claude ?

L’export s’exécute dans le navigateur. Nous ne recevons pas le contenu des conversations. Nous conservons uniquement une adresse e-mail vérifiée par Google pour compter les exports gratuits et rattacher un abonnement Pro.

Quelle différence entre « exporter une conversation Claude » et « télécharger une conversation Claude » ?

C’est la même tâche, formulée de deux façons. Dans les deux cas, utilisez le bouton orange sur claude.ai.

L’extension exporte-t-elle en PDF ?

Non. Les formats actuels sont Markdown, JSON, texte brut, XML et PNG. Imprimez la page (Ctrl/Cmd+P → Enregistrer au format PDF) si vous avez besoin d’un PDF visuel rapide, ou exportez en Markdown puis convertissez le fichier. Guide complet : enregistrer une conversation Claude en PDF.

Fonctionne-t-elle avec Claude Pro / Team ?

Oui, si vous pouvez ouvrir la conversation dans le navigateur sur claude.ai. Nous ne sommes pas Anthropic.

Comment sauvegarder une conversation Claude ?

Installez l’extension Chrome gratuite, ouvrez la conversation sur claude.ai, cliquez sur le bouton orange et choisissez un format. C’est ainsi que l’on sauvegarde une conversation Claude sous forme de vrai fichier. L’impression en PDF et le ZIP de compte d’Anthropic sont les deux autres options ; comparaison dans le guide télécharger une conversation Claude.

L’extension télécharge-t-elle les conversations Claude Code ?

Non. Cette extension fonctionne uniquement sur claude.ai dans Chrome. Les sessions Claude Code passent par /export ou par des fichiers JSONL sur le disque ; voir exporter une conversation Claude Code.

Download Claude conversations est-elle liée à Anthropic ?

Non. Claude est une marque d’Anthropic, PBC. Il s’agit d’une extension Chrome indépendante, pas d’un produit officiel d’Anthropic.
