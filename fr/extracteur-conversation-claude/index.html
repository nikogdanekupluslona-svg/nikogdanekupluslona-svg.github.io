Qu’est-ce qu’un extracteur de conversations Claude ?

Un extracteur de conversations Claude analyse la conversation affichée sur claude.ai et écrit un vrai fichier. Download Claude conversations est cet outil Chrome : ni un utilitaire de capture d’écran, ni le ZIP de compte d’Anthropic. On tape « extraire », « exporter » ou « télécharger » pour arriver au même bouton orange sur claude.ai.

Développeurs et chercheurs parlent souvent d’extracteur, parce qu’« extraire » suggère une structure : auteur, blocs de contenu, blocs de code, tableaux, artefacts. Download Claude conversations effectue cette analyse dans l’onglet déjà ouvert. Certains disent Claude Conversation Downloader ou Claude Exporter (en anglais, « claude exporter » est une recherche fréquente) ; ces noms désignent toujours cette fiche Chrome, notée 5,0 sur le Chrome Web Store.

L’extracteur n’est ni un module pour Claude Desktop, ni un outil en ligne de commande pour Claude Code. Si vous cherchiez l’historique du terminal, utilisez /export ; guide : exporter une conversation Claude Code. Si vous cherchiez l’application Mac/Windows, voir exporter une conversation Claude Desktop. Cette page concerne uniquement claude.ai dans Chrome.

Même bouton, verbes différents. Extraire, exporter et télécharger une conversation Claude mènent tous à Download Claude conversations. La présentation orientée produit se trouve dans exporter une conversation Claude. Ce guide porte sur ce que l’extracteur lit et sur ce qu’il laisse de côté.

Comment extraire une conversation Claude sur claude.ai ?

Installez Download Claude conversations, ouvrez l’URL de la conversation sur claude.ai, cliquez sur le bouton orange à côté de la zone de message, choisissez un format, puis cliquez sur « Export ». L’extracteur écrit le fichier en local via l’API de téléchargement de Chrome. La connexion Google a lieu une fois, avant la première extraction, pour compter les 3 exports gratuits.

  1. Ajoutez la fiche Chrome (Download Claude conversations, version 1.13.0 en septembre 2026).
  2. Rechargez claude.ai et ouvrez la conversation : l’extracteur a besoin de l’URL d’une conversation, pas de la page d’accueil vide.
  3. Cliquez sur le bouton orange à droite de la zone de message.
  4. Choisissez Markdown, JSON, texte brut, XML ou PNG.
  5. Cliquez sur « Export ». L’extracteur n’envoie pas le contenu de la conversation sur nos serveurs.

Si le bouton orange est absent, épinglez l’extension, actualisez l’onglet et vérifiez que l’URL est bien celle d’une conversation. L’extracteur s’injecte uniquement sur claude.ai. Il n’apparaîtra ni dans Claude Desktop, ni dans Claude Code, ni sur d’autres sites. Un fichier incomplet signifie généralement que la longue conversation n’avait pas fini de s’afficher : faites défiler ou patientez, puis relancez l’extraction.

L’extracteur mémorise le dernier format utilisé. Si vous vouliez du Markdown et avez reçu du JSON, ouvrez la liste avant de cliquer sur « Export ». Atteindre la limite de 3 exports affiche une proposition Pro à 3,99 $/mois ou 26,99 $/an : c’est normal, pas une analyse ratée. La connexion Google au premier export est obligatoire pour qu’une réinstallation ne puisse pas remettre le compteur gratuit à zéro.

Qu’extrait exactement l’extracteur ?

L’extracteur de conversations Claude lit l’arborescence des messages déjà affichée par claude.ai : échanges humains et réponses de l’assistant, blocs de code avec leur langage, tableaux, liens et réflexion en option. La mise en page des artefacts est « Original », « Inline », « Nested » ou « Flat » (original, intégré, imbriqué ou à plat). Le copier-coller depuis la même page perd cette structure ; l’extracteur la conserve en Markdown, JSON et XML.

Les blocs de réflexion sont une option (« include thinking »). Activez-la quand vous voulez le raisonnement visible de Claude dans le fichier extrait ; laissez-la désactivée si vous ne voulez que la réponse finale. Les métadonnées (« include metadata ») peuvent inclure titres, horodatages et modèle. Le filtre par auteur garde tous les messages, les messages humains seuls ou ceux de l’assistant seul (« all / human only / assistant only »). Ces réglages se trouvent dans le même panneau que le format. Liste des fonctionnalités : fonctionnalités.

L’extracteur lit la conversation que la page a déjà affichée dans votre onglet claude.ai. Les blocs de code, les tableaux et les mises en page d’artefacts (Original, Inline, Nested, Flat) y sont analysés, puis le fichier est généré localement. Nous ne proposons pas de PDF.

L’équipe Download Claude conversations

Le PNG fait exception : c’est une image de la conversation, pas une analyse dans laquelle chercher. Utilisez le PNG quand vous avez besoin d’un résultat visuel pour un ticket ou une diapositive. Utilisez Markdown ou JSON quand vous avez besoin de texte consultable. Ni le PNG ni le Markdown ne sont des PDF ; l’impression reste la solution de type PDF, décrite dans impression / PDF.

L’extracteur ne peut pas extraire une conversation que Chrome n’a jamais chargée. Une fenêtre privée, un onglet déconnecté ou une conversation qui n’existe que dans Claude Desktop ne donneront pas de fichier. Ouvrez la conversation sur claude.ai en étant connecté, puis lancez l’extracteur. L’export hors ligne ne fonctionne qu’une fois la page chargée ; il n’y a de toute façon aucun aller-retour avec un serveur pour générer le fichier.

Quels formats l’extracteur peut-il produire ?

Markdown, JSON, texte brut, XML et PNG : les mêmes cinq, que vous extrayiez une conversation Claude ou que vous lanciez « Export All » (tout exporter). Download Claude conversations n’ajoute ni Word, ni Notion, ni PDF natif dans la version 1.13.0. Le choix du format ne change pas le quota de 3 exports ; chaque fichier terminé compte pour une extraction.

Peut-on extraire plusieurs conversations Claude d’un coup ?

Oui. Ouvrez « View and Download All Conversations » (afficher et télécharger toutes les conversations), filtrez, puis cliquez sur « Export All ». L’extracteur écrit un fichier par conversation sélectionnée. Chaque fichier consomme un des 3 exports gratuits, sauf si le compte a Pro, à 3,99 $/mois ou 26,99 $/an.

Filtres de la page de navigation : All, New, Exported et Project. New signifie que l’extracteur n’a pas encore enregistré cette conversation. Exported marque l’historique déjà extrait, pour qu’un export groupé ultérieur puisse l’ignorer. Project reprend le regroupement par projet de claude.ai. La recherche trouve les conversations par nom avant de lancer « Export All ».

L’export groupé n’est pas une analyse allégée. Réflexion, métadonnées, mise en page des artefacts et filtre par auteur sont identiques au panneau d’une conversation isolée. Présentation avec les avertissements sur le quota : exporter tout l’historique avec Export All. Si vous vouliez un seul ZIP de tout le compte envoyé par e-mail, c’est Settings → Privacy → Export data (les libellés peuvent être traduits si claude.ai est en français), pas cet extracteur.

Trois extractions gratuites au total. « Export All » n’a pas de quota séparé. Sélectionner 25 conversations consomme 25 exports si chaque fichier aboutit. Utilisez les filtres New ou Project, ou passez à Pro (3,99 $/mois ou 26,99 $/an) avant une grosse extraction.

Extracteur ou copier-coller ?

Le copier-coller suffit pour une réponse courte de Claude et échoue sur le code et les tableaux. Export data d’Anthropic est la sauvegarde du compte sous forme de ZIP. L’extracteur de conversations Claude se situe entre les deux : cette conversation ou une sélection groupée, en fichier structuré, immédiatement, sur claude.ai dans Chrome.

L’impression n’est pas un extracteur. Elle capture la page web, y compris l’interface dont vous ne voulez pas dans un fichier de notes. L’extracteur de conversations Claude retire cette interface et conserve la structure des messages. Si vous avez tout de même besoin d’un PDF après avoir extrait du Markdown, convertissez vous-même le fichier .md ; le panneau ne produit pas de PDF.

Un extracteur de conversations Claude est-il sûr ?

Cet extracteur de conversations Claude utilise votre session claude.ai existante, comme le fait le site. Il n’automatise pas le compte et n’envoie pas le contenu des conversations à notre API. La connexion Google compte les 3 exports gratuits et restaure Pro. Paddle gère le paiement. Nous ne sommes pas Anthropic ; leurs conditions continuent de s’appliquer.

Un serveur Cloudflare Worker voit le statut d’abonnement : nombre d’exports gratuits utilisés et Pro ou non. Il ne reçoit pas le Markdown, le JSON, le texte, le XML ou le PNG extraits. Les fichiers ne quittent le navigateur que pour le dossier de téléchargement de Chrome. Toute la séparation est décrite dans comment ça marche. Si vous vous demandez si un extracteur de conversations Claude est sûr, regardez cette séparation : la facturation sur le serveur, la conversation dans l’onglet.

Nous ne pouvons pas promettre « zéro réseau » : claude.ai, Google et notre serveur existent. Nous pouvons affirmer que le contenu des conversations ne nous est pas envoyé. Respectez les conditions d’utilisation d’Anthropic. Download Claude conversations est une extension Chrome indépendante, pas un produit officiel d’Anthropic. L’adresse d’assistance figure en bas du site.

Les navigateurs mobiles et Claude Desktop ne sont pas pris en charge. Un extracteur qui est un script de contenu Chrome ne peut pas y fonctionner. N’attendez pas de version Safari ou Firefox en septembre 2026. Utilisez Chrome sur ordinateur, sur claude.ai. Les règles d’entreprise qui bloquent les extensions bloquent aussi cet extracteur.

Qu’est-ce qu’un extracteur de conversations Claude ?

Un outil qui lit une conversation claude.ai ouverte et écrit du Markdown, du JSON, du texte brut, du XML ou du PNG. Download Claude conversations ajoute le bouton orange qui effectue cette analyse localement dans Chrome.

Extraire une conversation Claude, est-ce différent de l’exporter ?

Non : même tâche, autre verbe. Extraire, exporter et télécharger mènent au même bouton orange et aux mêmes cinq formats sur claude.ai. Cette page insiste sur ce que l’analyseur conserve.

Puis-je extraire une conversation Claude sans rien installer ?

Seulement par copier-coller, qui perd les blocs de code et les tableaux, ou via Export data d’Anthropic, qui fournit un ZIP du compte. Un extracteur de conversations Claude structuré doit lire la page : c’est le rôle de l’extension Chrome.

L’extracteur permet-il d’extraire plusieurs conversations d’un coup ?

Oui. « View and Download All Conversations », puis « Export All ». Chaque fichier compte dans les 3 exports gratuits. Pro, à 3,99 $/mois ou 26,99 $/an, supprime la limite. Filtres : All, New, Exported, Project.

Un extracteur de conversations Claude est-il sûr ?

Celui-ci lit la session claude.ai connectée et génère les fichiers localement. Le texte des conversations n’est pas envoyé sur nos serveurs. Nous ne sommes pas Anthropic ; leurs conditions d’utilisation continuent de s’appliquer.

Faut-il Claude Pro pour extraire une conversation ?

Non. Toute offre claude.ai qui permet d’ouvrir la conversation dans Chrome fonctionne. Les 3 premiers fichiers de l’extracteur sont gratuits de notre côté. L’offre payante d’Anthropic n’a aucun rapport avec notre quota de 3 exports.

L’extracteur de conversations Claude fonctionne-t-il dans Desktop ?

Non. Claude Desktop n’affiche jamais le bouton orange. Ouvrez la même conversation sur claude.ai si elle est synchronisée, ou faites un copier-coller, ou utilisez le ZIP officiel. L’extracteur fonctionne uniquement dans Chrome, sur claude.ai.

Un extracteur de conversations Claude peut-il produire un PDF ?

Non. Les formats sont Markdown, JSON, texte brut, XML et PNG. Imprimez la page claude.ai si vous avez besoin d’un instantané de type PDF. Le PNG est une image, pas un PDF.

L’extraction fonctionne-t-elle dans Claude Code ?

Non. Claude Code utilise /export ou des fichiers JSONL sur le disque. Cet extracteur de conversations Claude est un script de contenu Chrome pour claude.ai, pas une intégration au terminal.

Combien d’extractions gratuites l’extracteur permet-il ?

Trois par compte connecté avec Google, partagées avec « Export All ». Une réinstallation ne remet pas le compteur à zéro. Pro se restaure avec le même compte Google, la facturation passant par Paddle.

Qu’est-ce que l’extracteur de conversations Claude ignore ?

L’interface de la page, la zone de saisie et tout ce qui n’est pas affiché dans la conversation. Il ignore aussi les conversations jamais chargées dans Chrome. Les conversations présentes uniquement dans Claude Desktop et le JSONL de Claude Code sont hors de sa portée.
