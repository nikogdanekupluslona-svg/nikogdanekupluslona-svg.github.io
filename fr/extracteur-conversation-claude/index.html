Un extracteur de conversations Claude lit la conversation ouverte sur claude.ai et écrit du PDF, du Markdown, du JSON, du texte, du XML, du CSV ou du PNG au lieu d’un bloc copié-collé. Download Claude conversations est cet extracteur pour Chrome : bouton orange, puis « Export » (exporter). Il ne fonctionne ni dans Claude Desktop ni dans le terminal Claude Code. Le PDF et le ZIP groupé sont gratuits jusqu’à 3 par jour ; Pro coûte 3,99 $ par mois ou 26,99 $ par an.

Qu’est-ce qu’un extracteur de conversations Claude ?

Un extracteur de conversations Claude analyse la conversation affichée sur claude.ai et écrit un vrai fichier. Download Claude conversations est cet outil Chrome : ni un utilitaire de capture d’écran, ni le ZIP de compte d’Anthropic. On tape « extraire », « exporter » ou « télécharger » pour arriver au même bouton orange sur claude.ai.

Développeurs et chercheurs parlent souvent d’extracteur, parce qu’« extraire » suggère une structure : auteur, blocs de contenu, blocs de code, tableaux, artefacts. Download Claude conversations effectue cette analyse dans l’onglet déjà ouvert. Certains disent Claude Conversation Downloader ou Claude Exporter (en anglais, « claude exporter » est une recherche fréquente) ; ces noms désignent toujours cette fiche Chrome, Download Claude conversations 1.16.2 sur le Chrome Web Store.

L’extracteur n’est ni un module pour Claude Desktop, ni un outil en ligne de commande pour Claude Code. Si vous cherchiez l’historique du terminal, utilisez /export ; guide : exporter une conversation Claude Code. Si vous cherchiez l’application Mac/Windows, voir exporter une conversation Claude Desktop. Claude Code sur le web (claude.ai/code) et les sessions Cowork, eux, s’extraient, car ils s’ouvrent sur claude.ai. Cette page concerne uniquement claude.ai dans Chrome.

Même bouton, verbes différents. Extraire, exporter et télécharger une conversation Claude mènent tous à Download Claude conversations. La présentation orientée produit se trouve dans exporter une conversation Claude. Ce guide porte sur ce que l’extracteur lit et sur ce qu’il laisse de côté.

Comment extraire une conversation Claude sur claude.ai ?

Installez Download Claude conversations, ouvrez l’URL de la conversation sur claude.ai, cliquez sur le bouton orange à côté de la zone de message, choisissez un format, puis cliquez sur « Export ». L’extracteur écrit le fichier en local via l’API de téléchargement de Chrome. Aucun compte n’est nécessaire pour le Markdown, le texte, le JSON, le XML, le CSV ou le PNG ; la connexion Google n’apparaît que pour le PDF et l’export groupé.

  1. Ajoutez la fiche Chrome (Download Claude conversations, version 1.16.2 en septembre 2026).
  2. Rechargez claude.ai et ouvrez la conversation : l’extracteur a besoin de l’URL d’une conversation, pas de la page d’accueil vide.
  3. Cliquez sur le bouton orange rond à droite de la zone de message.
  4. Réglez « Messages » sur « All », « Human » ou « Assistant » (tous, humain ou assistant), cochez « Thinking » (réflexion) si vous le souhaitez, ou utilisez « Select » (sélectionner) pour cocher des messages précis. Choisissez PDF, Markdown, JSON, texte brut, XML, CSV ou PNG.
  5. Cliquez sur « Export », ou sur « Copy » (copier) pour placer le Markdown, le texte, le JSON, le XML ou le CSV dans le presse-papiers. L’extracteur n’envoie pas le contenu de la conversation sur nos serveurs.

Si le bouton orange est absent, épinglez l’extension, actualisez l’onglet et vérifiez que l’URL est bien celle d’une conversation. L’extracteur s’injecte uniquement sur claude.ai. Il n’apparaîtra ni dans Claude Desktop, ni dans le terminal Claude Code, ni sur d’autres sites. Un fichier incomplet signifie généralement que la longue conversation n’avait pas fini de s’afficher : faites défiler ou patientez, puis relancez l’extraction.

L’extracteur mémorise le dernier format utilisé. Si vous vouliez du Markdown et avez reçu du JSON, ouvrez la liste avant de cliquer sur « Export ». Choisir le PDF demande une connexion Google. Après 3 exports PDF ou groupés dans la journée, l’offre gratuite affiche une proposition Pro à 3,99 $ par mois ou 26,99 $ par an : c’est normal, pas une analyse ratée. Le compteur revient à zéro à minuit UTC.

Qu’extrait exactement l’extracteur ?

L’extracteur de conversations Claude lit l’arborescence des messages déjà affichée par claude.ai : échanges humains et réponses de l’assistant, blocs de code avec leur langage, tableaux, liens et réflexion en option. La mise en page des artefacts est « Original », « Inline », « Nested » ou « Flat » (original, intégré, imbriqué ou à plat). Le copier-coller depuis la même page perd cette structure ; l’extracteur la conserve en Markdown, JSON et XML.

La réflexion est une case à cocher. Cochez-la quand vous voulez le raisonnement visible de Claude dans le fichier extrait ; laissez-la décochée si vous ne voulez que la réponse finale. Les métadonnées peuvent inclure titres, horodatages et modèle. Le filtre « Messages » (« All », « Human », « Assistant »), la case « Thinking » (réflexion) et « Select » (sélectionner) se trouvent dans le panneau d’export, à côté du format ; les étapes d’outils / MCP et les sources de recherche web s’activent dans les paramètres. L’extracteur lit la conversation que la page a déjà affichée dans votre onglet claude.ai. Les blocs de code, les tableaux et les mises en page d’artefacts (Original, Inline, Nested, Flat) y sont analysés, puis le fichier est généré localement, PDF compris.

L’équipe Download Claude conversations

Le PNG fait exception : c’est une image de la conversation, pas une analyse dans laquelle chercher. Utilisez le PNG quand vous avez besoin d’un résultat visuel pour un ticket ou une diapositive. Utilisez Markdown ou JSON quand vous avez besoin de texte consultable. Ni le PNG ni le Markdown ne sont des PDF ; si vous avez besoin de pages, choisissez PDF : voir conversation Claude en PDF.

L’extracteur ne peut pas extraire une conversation que Chrome n’a jamais chargée. Une fenêtre privée, un onglet déconnecté ou une conversation qui n’existe que dans Claude Desktop ne donneront pas de fichier. Ouvrez la conversation sur claude.ai en étant connecté, puis lancez l’extracteur. L’export hors ligne ne fonctionne qu’une fois la page chargée ; il n’y a de toute façon aucun aller-retour avec un serveur pour générer le fichier.

Quels formats l’extracteur peut-il produire ?

Sept : PDF, Markdown, JSON, texte brut, XML, CSV et PNG, les mêmes sept, que vous extrayiez une conversation Claude ou que vous lanciez « Export All » (tout exporter). Download Claude conversations n’ajoute ni Word, ni Notion, ni Google Docs dans la version 1.16.2. Le choix du format détermine la limite : six formats sont illimités et sans compte, tandis que chaque PDF utilise un des 3 exports par jour de l’offre gratuite.

Peut-on extraire plusieurs conversations Claude d’un coup ?

Oui. Ouvrez « View and Download All Conversations » (afficher et télécharger toutes les conversations) depuis la fenêtre de l’extension, filtrez, puis cliquez sur « Export All ». L’extracteur écrit un ZIP avec un fichier par conversation sélectionnée, dans le format choisi. L’export groupé demande une connexion Google. Avec l’offre gratuite, chaque conversation du ZIP utilise un des 3 exports par jour, partagés avec le PDF, sauf si le compte a Pro, à 3,99 $ par mois ou 26,99 $ par an.

Filtres du tableau de bord : « All conversations », « New », « Updated » et « Previously exported » (toutes, nouvelles, mises à jour, déjà exportées), plus les onglets « Chat » et « Cowork » et une recherche par projet. New signifie que l’extracteur n’a pas encore enregistré cette conversation. Previously exported marque l’historique déjà extrait, pour qu’un export groupé ultérieur puisse l’ignorer. La recherche par projet reprend le regroupement de claude.ai. La recherche par nom trouve les conversations avant de lancer « Export All ».

L’export groupé n’est pas une analyse allégée. Les cases du tableau de bord, « Chats », « Thinking », « Metadata », « Tools » et « Sources » (conversations, réflexion, métadonnées, outils, sources), ainsi que la mise en page des artefacts décident de ce qui entre dans chaque fichier, et le sélecteur « Chat format » (format des conversations) propose les sept formats, PDF compris. Présentation avec les avertissements sur les limites : exporter tout l’historique avec Export All. Si vous vouliez un seul ZIP de tout le compte envoyé par e-mail, c’est Settings → Privacy → Export data (les libellés peuvent être traduits si claude.ai est en français), pas cet extracteur.

L’export groupé compte par conversation. Avec l’offre gratuite, « Export All » partage 3 exports par jour avec le PDF, et chaque conversation du ZIP en utilise un. Sélectionnez 25 conversations alors qu’il vous en reste 3 : tout le lot est bloqué, pas tronqué. Utilisez le filtre New pour en choisir moins, attendez la remise à zéro de minuit UTC, ou passez à Pro (3,99 $ par mois ou 26,99 $ par an) avant une grosse extraction.

Extracteur ou copier-coller ?

Le copier-coller suffit pour une réponse courte de Claude et échoue sur le code et les tableaux. Export data d’Anthropic est la sauvegarde du compte sous forme de ZIP. L’extracteur de conversations Claude se situe entre les deux : cette conversation ou une sélection groupée, en fichier structuré, immédiatement, sur claude.ai dans Chrome.

L’impression n’est pas un extracteur. Elle capture la page web, y compris l’interface dont vous ne voulez pas dans un fichier de notes. L’extracteur de conversations Claude retire cette interface et conserve la structure des messages. Si vous avez besoin d’un PDF, choisissez PDF dans le même panneau : l’extension le génère dans le navigateur, sans boîte de dialogue d’impression. Si vous voulez du texte dans le presse-papiers, le bouton « Copy » du panneau copie du Markdown, du texte, du JSON, du XML ou du CSV au lieu du texte brut de la page.

Un extracteur de conversations Claude est-il sûr ?

Cet extracteur de conversations Claude utilise votre session claude.ai existante, comme le fait le site. Il n’automatise pas le compte et n’envoie pas le contenu des conversations à notre API. La connexion Google n’est demandée que pour le PDF, l’export groupé et Pro, afin de compter le quota quotidien et de restaurer Pro. Paddle gère le paiement. Nous ne sommes pas Anthropic ; leurs conditions continuent de s’appliquer.

Une fois que vous êtes connecté pour le PDF, l’export groupé ou Pro, un serveur Cloudflare Worker voit votre adresse e-mail Google, le nombre de PDF et d’exports groupés du jour, et si vous avez Pro ou non. Les exports d’une conversation en Markdown, JSON, texte, XML, CSV et PNG ne lui envoient rien, et il ne reçoit jamais de fichier extrait, PDF compris. Les fichiers ne quittent le navigateur que pour le dossier de téléchargement de Chrome. Toute la séparation est décrite dans comment ça marche. Si vous vous demandez si un extracteur de conversations Claude est sûr, regardez cette séparation : la facturation sur le serveur, la conversation dans l’onglet.

Nous ne pouvons pas promettre « zéro réseau » : claude.ai, Google et notre serveur existent. Nous pouvons affirmer que le contenu des conversations ne nous est pas envoyé. Respectez les conditions d’utilisation d’Anthropic. Download Claude conversations est une extension Chrome indépendante, pas un produit officiel d’Anthropic. L’adresse d’assistance figure en bas du site.

Les navigateurs mobiles et Claude Desktop ne sont pas pris en charge. Un extracteur qui est un script de contenu Chrome ne peut pas y fonctionner. N’attendez pas de version Safari ou Firefox en septembre 2026. Utilisez Chrome sur ordinateur, sur claude.ai. Les règles d’entreprise qui bloquent les extensions bloquent aussi cet extracteur.

L’extracteur de conversations Claude fonctionne-t-il dans Desktop ?

Seulement sur le web. Les sessions Claude Code sur claude.ai/code s’ouvrent sur claude.ai et s’extraient comme n’importe quelle conversation.
