Comment sauvegarder une conversation Claude dans un fichier à conserver

Pour sauvegarder une conversation Claude, sachez d’abord que claude.ai conserve déjà dans l’historique chaque conversation faite en étant connecté. Aucun bouton Enregistrer n’écrit de fichier. Pour obtenir du PDF, du Markdown, du JSON, du texte, du XML, du CSV ou du PNG, utilisez Download Claude conversations dans Chrome, imprimez la page ou demandez Settings → Privacy → Export data. Fermer l’onglet ne supprime pas la conversation.

Claude sauvegarde-t-il déjà la conversation dans l’historique ?

Oui. Claude.ai conserve déjà la conversation dans l’historique du compte Anthropic, dès lors que vous êtes connecté. Fermer l’onglet n’efface pas la conversation. Il n’existe pourtant aucune commande Enregistrer qui écrive un fichier sur le disque. Sauvegarder une conversation Claude en Markdown ou en JSON est une tâche distincte de l’historique.

L’historique, c’est la liste des conversations à gauche sur claude.ai. Chaque ligne est une conversation qu’Anthropic a conservée pour ce compte. Rouvrez une ligne plus tard et les mêmes échanges réapparaissent. C’est un stockage lié au compte, pas un dossier de téléchargement sur votre ordinateur.

Quand on cherche comment enregistrer une conversation Claude, on veut souvent savoir si elle va disparaître en partant. Pour une session normale, connectée, la réponse est non. Claude.ai n’exige aucun clic sur Enregistrer pour garder la conversation dans le compte. Ce qui manque, c’est un outil d’export de fichier, pas un interrupteur de conservation.

L’historique n’est pas un fichier Markdown, ni une arborescence JSON dans laquelle chercher, ni un PNG à glisser dans une diapositive. Il se trouve derrière la connexion Anthropic. Si vous ne pouvez plus vous connecter, vous ne pouvez plus ouvrir ces conversations. Un fichier local, lui, s’ouvre encore quand le mot de passe n’est plus là.

Deux sortes de « sauvegarde ». Historique = Anthropic garde la conversation dans le compte. Fichier = vous écrivez du PDF, du Markdown, du JSON, du texte, du XML, du CSV ou du PNG sur le disque. Claude.ai propose la première. Claude.ai n’a aucun bouton pour la seconde.

Les projets et les conversations récentes sur claude.ai font toujours partie de l’historique. Ranger une conversation dans un projet ne crée pas de fichier. La renommer non plus. La mettre en favori ou l’épingler, si l’interface le propose, n’écrit toujours pas de Markdown. Download Claude conversations exporte les conversations d’un projet comme les autres, et sur la page d’un projet, « Project files » → « Download ZIP » (fichiers du projet → télécharger le ZIP) enregistre les fichiers du projet.

Les espaces Team et Enterprise suivent la même logique. Si vous pouvez ouvrir la conversation sur claude.ai, Anthropic l’a déjà conservée pour l’espace de travail. Les règles de conservation de l’entreprise peuvent toutefois supprimer ou masquer des conversations selon un calendrier que vous ne maîtrisez pas. Un fichier exporté devient alors la copie que vous gardez.

La navigation privée et un second profil Chrome ne partagent pas l’historique. La conversation est liée au compte Anthropic utilisé dans cette session. Un autre compte Anthropic affiche un autre historique. Pour « sauvegarder » d’un compte à l’autre, il faut un fichier, pas une fusion d’historiques.

Comment sauvegarder une conversation Claude dans un fichier ?

Pour sauvegarder une conversation Claude dans un fichier, choisissez une méthode qui écrit sur le disque : Download Claude conversations dans Chrome, Imprimer → Enregistrer au format PDF, ou Settings → Privacy → Export data (les libellés peuvent être traduits si claude.ai est en français). L’historique de claude.ai est un stockage lié au compte, pas un fichier PDF, Markdown, JSON, texte, XML, CSV ou PNG.

L’extension Chrome est la voie conversation par conversation. Ouvrez l’URL de la conversation, cliquez sur le bouton orange à côté de la zone de message, choisissez un format, cliquez sur « Export » (exporter). L’API de téléchargement de Chrome écrit le fichier en local. Markdown, texte, JSON, XML, CSV et PNG ne demandent aucun compte ; seul le PDF demande une connexion Google. Le contenu des conversations reste sur la machine.

L’impression est la voie visuelle. Ctrl+P ou Cmd+P, destination « Enregistrer au format PDF ». Le résultat ressemble à la page claude.ai, y compris les éléments d’interface que les styles d’impression n’ont pas masqués. Les blocs de code se coupent souvent entre deux feuilles. Imprimez quand un relecteur veut un instantané, pas un fichier de notes. Pour un PDF construit à partir des messages plutôt que de l’écran, choisissez PDF dans l’extension.

Export data est la voie du compte. Settings → Privacy → Export data sur claude.ai. Anthropic envoie par e-mail un lien qui expire. Le ZIP contient le JSON de tout le compte, pas un fichier nommé pour la conversation affichée. L’attente est le prix d’une sauvegarde complète.

L’historique s’occupe déjà de la première. L’impression et Export data restent utiles, pour d’autres besoins.

Un fichier s’impose avant un départ d’entreprise, avant de réinitialiser un ordinateur, pour une archive de recherche ou avant de verser une revue de code dans git. L’historique suffit quand vous voulez seulement rouvrir la même conversation demain avec le même compte Anthropic.

Le copier-coller est une cinquième méthode, qui donne un fichier médiocre. Sélectionnez le texte sur claude.ai, collez-le dans Docs. Les blocs de code s’écrasent. Les tableaux deviennent des lignes continues. La séparation des messages disparaît. Suffisant pour un paragraphe, insuffisant comme unique sauvegarde d’une revue de conception de 40 échanges. Le bouton « Copy » (copier) de l’extension place plutôt un Markdown propre dans le presse-papiers.

Comment enregistrer une conversation Claude avec l’extension Chrome ?

Avec Download Claude conversations : installez l’extension Chrome, ouvrez la conversation sur claude.ai, cliquez sur le bouton orange à côté de la zone de message, choisissez PDF, Markdown, JSON, texte, XML, CSV ou PNG, puis « Export ». Aucun compte n’est nécessaire, sauf pour le PDF.

  1. Installez Download Claude conversations depuis le Chrome Web Store (les navigateurs Chromium qui acceptent les extensions Chrome fonctionnent aussi).
  2. Rechargez claude.ai si la page était déjà ouverte pendant l’installation. Chrome n’injecte pas toujours le script de contenu dans les anciens onglets.
  3. Ouvrez une vraie conversation depuis l’historique : le bouton orange apparaît sur une conversation, pas sur la page d’accueil vide.
  4. Cliquez sur le bouton orange de téléchargement, à droite de la zone de message. Un panneau s’ouvre avec Messages (« All / Human / Assistant », soit tous, humain, assistant), Format, « Thinking » (réflexion), « Select » (sélectionner), « Copy » et « Export ».
  5. Choisissez PDF, Markdown, texte brut, JSON, XML, CSV ou PNG. Cliquez sur « Export ». Chrome télécharge le fichier immédiatement.

L’extension est un script de contenu Chrome qui fonctionne uniquement sur claude.ai. L’analyseur lit la conversation déjà chargée dans la session connectée. Download Claude conversations n’appelle pas une API Anthropic distincte avec ses propres identifiants et n’envoie pas la conversation sur nos serveurs pour générer le fichier.

Aucun compte n’est nécessaire pour Markdown, texte brut, JSON, XML, CSV ou PNG. Ces exports d’une conversation sont illimités et gratuits : pas de connexion, pas de compteur. La connexion Google n’apparaît que si vous choisissez le PDF ou lancez un export groupé avec « Export All » (tout exporter). Ce n’est pas un accès à vos conversations. Leur contenu reste sur votre machine.

Le PDF et le ZIP groupé partagent un quota gratuit de 3 par jour, remis à zéro à minuit UTC. Chaque conversation d’un ZIP groupé compte pour une. Comment sauvegarder une conversation Claude sans extension ?

Sans extension, imprimez la page claude.ai ou demandez le ZIP Export data d’Anthropic. L’impression donne un PDF visuel de la page web. Export data fournit, avec un délai, une archive JSON de tout le compte. Aucune des deux ne produit un fichier Markdown par conversation.

Par l’impression : ouvrez la conversation sur claude.ai, masquez la barre latérale si l’interface le permet, appuyez sur Ctrl+P (Windows/Linux) ou Cmd+P (Mac), choisissez « Enregistrer au format PDF » comme destination, puis enregistrez. La zone de saisie peut se répéter sur chaque feuille. Tous les détails sur l’impression : enregistrer une conversation Claude en PDF.

Par la voie officielle : Settings → Privacy → Export data sur claude.ai. Anthropic envoie par e-mail un lien qui expire. Décompressez le ZIP vous-même si vous avez besoin d’une conversation parmi des milliers. Cette archive est une sauvegarde de type conservation légale, pas un fichier de notes pour la réunion de demain.

Le copier-coller reste possible sans rien installer. Sélectionnez les échanges sur claude.ai, collez-les dans une application de notes. L’indentation du code disparaît généralement. Une conversation à plusieurs tours devient un bloc sans structure. Utilisez le copier-coller pour un extrait, pas comme seule stratégie de sauvegarde.

L’historique garde-t-il la conversation après fermeture ?

Oui. L’historique garde la conversation après la fermeture de l’onglet, l’actualisation de claude.ai ou l’extinction de l’ordinateur, à condition que la conversation ait été créée en étant connecté. Fermer un onglet n’est pas supprimer. C’est la suppression depuis l’historique qui retire la conversation de l’interface du compte.

Déconnectez-vous de claude.ai et la page devient vide. Reconnectez-vous au même compte Anthropic et l’historique affiche de nouveau ces conversations. La déconnexion masque la liste ; elle n’efface pas, à elle seule, le stockage du compte. Un autre compte Anthropic affiche un autre historique.

La suppression depuis l’historique est le vrai cas de disparition. Supprimez une conversation dans l’interface de claude.ai et elle disparaît de la barre latérale. Un fichier Markdown déjà exporté avec le bouton orange reste sur le disque. Exportez d’abord si la conversation va être supprimée lors d’un tri.

Supprimer n’est pas fermer. Fermer un onglet claude.ai laisse l’historique intact. Supprimer la conversation de l’historique la retire de l’interface du compte. Export data ne vous aidera pas après une suppression si Anthropic n’inclut plus cette conversation. Écrivez le fichier avant de faire le tri.

La navigation privée se termine à la fermeture de la fenêtre. Si vous avez utilisé claude.ai dans une fenêtre privée sans connexion durable, ne comptez pas sur l’historique pour avoir gardé le travail. Connectez-vous dans un profil Chrome normal, ou exportez un fichier avant la fin de la session privée.

Les administrateurs d’espaces Team et Enterprise peuvent conserver ou restreindre les conversations. Une règle que vous n’avez pas fixée peut masquer une conversation plus tard. Considérez l’historique d’entreprise comme un stockage prêté, et un fichier Markdown ou JSON exporté comme la copie qui reste de votre côté.

Passer d’un téléphone à un ordinateur ne demande aucun clic spécial pour sauvegarder, tant que les deux appareils utilisent le même compte Anthropic. Ouvrez l’historique sur l’ordinateur. Si la conversation manque, vous êtes sur un autre compte, un autre espace de travail, ou la conversation a été supprimée : elle n’est pas « non enregistrée ».

Claude Desktop peut afficher les conversations du même compte lorsque l’application est connectée au même utilisateur Anthropic. La synchronisation relève d’Anthropic. L’extension Chrome ne s’injecte jamais dans Desktop. Si la conversation existe sur claude.ai, ouvrez claude.ai dans Chrome pour écrire un fichier.

Comment sauvegarder une conversation Claude en Markdown ou JSON ?

Cliquez sur le bouton orange sur claude.ai, choisissez le format, puis « Export ». Markdown est le fichier de notes. JSON est l’arborescence des messages pour vos scripts. Le texte brut n’a aucun balisage. Le CSV compte une ligne par message. Le PDF est un document paginé. Le PNG est une image.

Markdown conserve les titres, les blocs de code avec leur langage et les tableaux. C’est le choix habituel pour Obsidian, GitHub ou un wiki. Notes de mise en page pour ce format : export Markdown. JSON conserve l’arborescence construite par l’analyseur, y compris les artefacts et la réflexion quand ces options sont activées.

Le JSON produit par Download Claude conversations n’a pas la même structure que le ZIP de compte d’Anthropic. Le JSON de l’extension contient une conversation, telle que la page l’a affichée. Le JSON d’Export data est un export complet du compte envoyé plus tard par e-mail. Ne mélangez pas les deux schémas dans un même script sans vérifier les clés.

Le texte brut convient quand la destination supprime le balisage : un champ de ticket, le corps d’un e-mail, un index de recherche qui attend du texte simple. XML est le choix de niche pour l’échange de données. Le CSV s’ouvre dans Excel, Google Sheets ou Numbers. Le PNG sert pour une diapositive ou une illustration dans un rapport de bug, pas pour une revue de 40 échanges dans laquelle vous ferez des recherches.

Comment sauvegarder tout l’historique Claude d’un coup ?

Pour sauvegarder votre historique Claude en plusieurs fichiers, ne répétez pas le bouton orange onglet par onglet. Ouvrez « View and Download All Conversations » (afficher et télécharger toutes les conversations) depuis la fenêtre de l’extension, filtrez le tableau, puis cliquez sur « Export All ». « Export All » demande une connexion Google. Sur l’offre gratuite, chaque conversation du ZIP consomme l’un des 3 créneaux quotidiens partagés avec le PDF. Pro supprime la limite.

Le tableau de bord liste les conversations du compte claude.ai auquel vous êtes connecté : c’est votre historique, transformé en tableau filtrable. Cherchez par nom. Filtrez par « All conversations » (toutes), « New » (nouvelles), « Updated » (mises à jour) ou « Previously exported » (déjà exportées). Passez de l’onglet Chat à l’onglet Cowork, et cherchez par projet si vous organisez vos conversations ainsi sur claude.ai.

L’export groupé produit un seul ZIP, avec un fichier par conversation, dans le format choisi via le sélecteur « Chat format » (format des conversations) : n’importe lequel des sept, PDF compris. Il utilise le même analyseur qu’un export unique. Des cases à cocher définissent le contenu (« Chats », « Thinking », « Metadata », « Tools », « Sources », soit conversations, réflexion, métadonnées, outils, sources), ainsi que la mise en page des artefacts. « Export All » n’est pas une version allégée : c’est le même analyseur appliqué à de nombreuses conversations en une seule passe. Détails : exporter tout l’historique avec Export All.

Export data d’Anthropic reste la sauvegarde du compte : un ZIP, un e-mail, du JSON pour tout, y compris les conversations oubliées. « Export All » répond au besoin inverse : vous choisissez les lignes de l’historique, vous choisissez le format, et le ZIP arrive immédiatement. Utilisez les deux si vous voulez à la fois une archive complète et un dossier de notes lisibles.

Le quota est commun et quotidien. Sur l’offre gratuite, les exports PDF et les conversations exportées en groupe partagent 3 par jour, remis à zéro à minuit UTC. Sélectionnez 40 conversations et tout le lot est bloqué, sans être coupé en cours de route. Choisissez-en moins, ou passez à Pro pour 3,99 $ par mois ou 26,99 $ par an via Paddle.

Le tableau de bord mémorise ce que vous avez déjà exporté : lors d’une visite suivante, vous pouvez filtrer sur New ou Updated uniquement. C’est ainsi qu’une sauvegarde hebdomadaire reste incrémentale au lieu de dupliquer les fichiers Markdown du mois dernier. Le compteur de 3 par jour suit le compte Google, pas l’installation, et repart à zéro à minuit UTC.

Sélectionnez un sous-ensemble quand l’historique est rempli de brouillons d’une ligne. « Export All » ne vous oblige pas à tout prendre. Un filtre précis et du Markdown donnent un dossier de recherche plus propre que 200 conversations vides commençant par « bonjour ».

Exporter une conversation Claude, formulé côté produit, c’est le même bouton orange et le même tableau « Export All ». La page voisine exporter une conversation Claude présente ces commandes si vous êtes arrivé par une recherche sur « exporter » plutôt que « sauvegarder ».

Peut-on sauvegarder une conversation depuis Desktop ou Claude Code ?

Desktop, non. Claude Code, seulement sur le web. Download Claude conversations ne peut pas sauvegarder de conversation depuis Claude Desktop ni depuis un terminal Claude Code local. Les sessions sur claude.ai/code s’ouvrent dans Chrome sur ordinateur : elles se sauvegardent comme n’importe quelle conversation. Claude Desktop est une application distincte. Claude Code en local est l’agent du terminal, avec /export et des fichiers JSONL sur le disque.

Si la conversation Desktop existe aussi sur claude.ai, ouvrez cette URL dans Chrome et utilisez le bouton orange. Si elle n’existe que dans Desktop, faites un copier-coller ou attendez Settings → Privacy → Export data. L’extension ne s’injecte jamais dans la fenêtre Desktop.

Dans une session Claude Code active, tapez /export. L’outil en ligne de commande d’Anthropic ouvre un menu pour copier la transcription ou l’enregistrer dans un fichier texte. Indiquez un nom de fichier pour passer le menu. Cette transcription est un texte destiné à être lu, pas le Markdown, le JSON ou le PDF de cette extension. Chemins complets : exporter une conversation Claude Code.

Le JSONL sur le disque est le journal interne, dans ~/.claude/projects (Windows : %USERPROFILE%\.claude\projects). Son schéma peut changer d’une version de Claude Code à l’autre. La documentation d’Anthropic recommande d’utiliser /export plutôt que d’analyser le JSONL. Nous n’encapsulons pas cet outil et ne lisons pas ~/.claude.

FAQ : sauvegarder une conversation Claude

Comment sauvegarder une conversation Claude dans un fichier ?

Installez Download Claude conversations, ouvrez la conversation sur claude.ai, cliquez sur le bouton orange à côté de la zone de message, choisissez PDF, Markdown, JSON, texte, XML, CSV ou PNG, puis cliquez sur « Export ». Le fichier est téléchargé localement, sans compte sauf pour le PDF. L’historique conservait déjà la conversation dans le compte Anthropic ; le bouton orange en écrit une copie sur le disque.

Comment enregistrer une conversation Claude sur claude.ai ?

Vous n’avez pas besoin d’un bouton Enregistrer pour garder la conversation dans le compte : l’historique de claude.ai liste déjà les conversations faites en étant connecté. Pour l’enregistrer dans un fichier, utilisez l’extension Chrome, Imprimer → Enregistrer au format PDF, ou Settings → Privacy → Export data pour un ZIP JSON du compte reçu plus tard.

Comment sauvegarder une conversation Claude sans extension ?

Imprimez la page claude.ai (Ctrl/Cmd+P → Enregistrer au format PDF) pour une copie visuelle, ou utilisez Settings → Privacy → Export data pour recevoir par e-mail un ZIP JSON de tout le compte. Le copier-coller suffit pour une réponse courte. Aucune de ces méthodes ne produit un fichier Markdown structuré par conversation comme le fait l’extension Chrome.

Claude sauvegarde-t-il déjà la conversation dans l’historique ?

Oui. Les conversations faites en étant connecté sur claude.ai restent dans l’historique du compte Anthropic. Fermer l’onglet, actualiser la page ou ouvrir un autre appareil avec le même compte n’efface pas la conversation. L’historique n’est pas un fichier PDF, Markdown, JSON ni aucun autre fichier sur votre disque.

Une conversation Claude disparaît-elle si je ferme l’onglet ?

Non. Fermer un onglet claude.ai ne supprime pas la conversation de l’historique. Supprimer la conversation de l’historique, en revanche, la retire de l’interface du compte. Un fichier déjà exporté avec Download Claude conversations reste sur le disque même après cette suppression.

Puis-je sauvegarder une conversation Claude en PDF ?

Oui. Download Claude conversations 1.16.2 exporte directement en PDF : choisissez PDF dans le panneau du bouton orange et cliquez sur « Export ». Le fichier est construit dans le navigateur, sans boîte de dialogue d’impression. Le PDF demande une connexion Google et est gratuit jusqu’à 3 par jour ; Pro est illimité. Guide : conversation Claude en PDF.

Combien de fichiers gratuits pour sauvegarder mes conversations Claude ?

Un nombre illimité en Markdown, texte brut, JSON, XML, CSV et PNG, sans compte. Le PDF et le ZIP groupé partagent 3 par jour sur l’offre gratuite, avec une connexion Google ; chaque conversation d’un ZIP groupé compte pour une, et le compteur repart à zéro à minuit UTC. Pro coûte 3,99 $ par mois ou 26,99 $ par an et supprime la limite. Paddle traite le paiement.

Peut-on sauvegarder une conversation Claude sur mobile ?

Pas avec l’extension Chrome. Elle fonctionne dans Chrome sur ordinateur (ou un autre navigateur Chromium capable d’installer des extensions du Chrome Web Store). Il n’existe pas d’application iOS ou Android. Les navigateurs mobiles peuvent toujours ouvrir l’historique et imprimer une conversation Claude, mais ils ne peuvent pas afficher le bouton orange.

Puis-je sauvegarder tout mon historique Claude d’un coup ?

Oui. Ouvrez « View and Download All Conversations » depuis la fenêtre de l’extension, filtrez le tableau, puis cliquez sur « Export All ». L’export groupé demande une connexion Google et compte dans les 3 par jour de l’offre gratuite. Cet export groupé n’est pas le ZIP Export data d’Anthropic : l’export officiel est une archive unique de tout le compte, envoyée plus tard par e-mail. Voir l’export de l’historique.

L’extension sauvegarde-t-elle les conversations Claude Code ?

Seulement sur le web. Les sessions Claude Code sur claude.ai/code se sauvegardent comme n’importe quelle conversation claude.ai. Pas les sessions locales du terminal : utilisez /export ou copiez les fichiers JSONL depuis ~/.claude/projects (Windows : %USERPROFILE%\.claude\projects). Cette extension Chrome fonctionne uniquement sur claude.ai. Guide : exporter une conversation Claude Code.

La connexion Google est-elle obligatoire pour sauvegarder une conversation Claude ?

Non, pas pour Markdown, texte brut, JSON, XML, CSV ou PNG. La connexion Google n’est requise que pour le PDF, l’export groupé « Export All » et Pro, afin d’appliquer la limite de 3 par jour et de restaurer Pro après une réinstallation. Le contenu des conversations n’est pas transmis avec cette connexion. Nous conservons l’adresse e-mail vérifiée uniquement pour le quota et le statut Pro.

Où se trouve l’export officiel Export data pour sauvegarder mes conversations Claude ?

Sur claude.ai : Settings → Privacy → Export data. Anthropic envoie par e-mail un lien qui expire. Le ZIP est une archive JSON du compte entier, pas un fichier Markdown nommé pour la conversation que vous lisiez. Utilisez Export data comme sauvegarde ; utilisez le bouton orange pour obtenir tout de suite un fichier lisible.
