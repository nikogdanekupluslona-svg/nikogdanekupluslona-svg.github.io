Exporter une discussion Claude dans un fichier lisible

Exporter une discussion Claude, c’est enregistrer une conversation claude.ai dans un fichier. Installez Download Claude conversations, ouvrez l’URL de la conversation, cliquez sur le bouton orange, choisissez PDF, Markdown, JSON, texte, XML, CSV ou PNG, puis « Export » (exporter). Les fichiers sont générés localement dans Chrome, pas dans Claude Desktop ni dans le terminal Claude Code. Markdown, texte, JSON, XML, CSV et PNG sont gratuits et illimités, sans compte. Le PDF et le ZIP groupé sont gratuits jusqu’à 3 par jour ; Pro coûte 3,99 $ par mois ou 26,99 $ par an.

Comment exporter une discussion Claude dans Chrome ?

Ouvrez l’URL d’une conversation sur claude.ai dans Chrome, cliquez sur le bouton orange à droite de la zone de message, choisissez PDF, Markdown, JSON, texte, XML, CSV ou PNG, puis « Export ». Download Claude conversations écrit le fichier en local. Rechargez claude.ai après l’installation. claude.ai ne propose aucune commande d’export par conversation.

  1. Installez Download Claude conversations depuis le Chrome Web Store (version 1.16.2).
  2. Rechargez l’onglet claude.ai pour que le script de contenu puisse s’injecter sur l’URL d’une conversation.
  3. Ouvrez une vraie conversation, pas la page d’accueil vide de claude.ai.
  4. Cliquez sur le bouton orange rond de téléchargement, à droite de la zone de message.
  5. Réglez « Messages » sur « All », « Human » ou « Assistant » (tous, humain ou assistant), cochez « Thinking » (réflexion) si vous le souhaitez, choisissez PDF, Markdown, JSON, texte brut, XML, CSV ou PNG, puis cliquez sur « Export ».

Aucun compte n’est nécessaire pour exporter une discussion Claude en Markdown, texte, JSON, XML, CSV ou PNG. Ces exports d’une seule conversation sont illimités et n’envoient rien à nos serveurs. La connexion Google n’est demandée que pour le PDF et l’export groupé « Export All », qui partagent 3 exports par jour avec l’offre gratuite. Le texte des conversations ne fait jamais partie de cette connexion Google. Fonctionnement détaillé : comment ça marche.

Si le bouton orange est absent, l’onglet n’est pas sur l’URL d’une conversation claude.ai, la page doit encore être rechargée après l’installation, ou Download Claude conversations est cachée dans le menu en forme de pièce de puzzle de Chrome. Épinglez l’extension, puis actualisez. Le bouton orange n’apparaît jamais sur d’autres sites.

La liste des formats mémorise le dernier choix. « Select » (sélectionner) permet de cocher des messages précis, et « Copy » (copier) place le Markdown, le texte, le JSON, le XML ou le CSV dans le presse-papiers au lieu de créer un fichier. Un fichier incomplet signifie généralement que la longue conversation claude.ai n’avait pas fini d’afficher l’arborescence des messages. Attendez, puis cliquez de nouveau sur « Export ».

Une discussion ou tout le compte. Le bouton orange exporte la discussion ouverte. Pour de nombreux fichiers, ouvrez « View and Download All Conversations » (afficher et télécharger toutes les conversations) depuis la fenêtre de l’extension et lancez « Export All » (tout exporter). Settings → Privacy → Export data d’Anthropic (les libellés peuvent être traduits si claude.ai est en français) fournit un ZIP JSON différé du compte, ce n’est pas ce parcours Chrome.

Que conserve le fichier exporté ?

Une discussion Claude exportée avec Download Claude conversations conserve l’arborescence des messages déjà affichée sur claude.ai : auteurs, blocs de code, tableaux, réflexion en option, métadonnées et mise en page des artefacts. Ce n’est pas une capture de la barre latérale. Le PNG est l’option image ; le PDF est l’option paginée, générée dans le navigateur dans la version 1.16.2.

Le copier-coller depuis claude.ai supprime l’indentation et écrase les tableaux. L’impression (Ctrl/Cmd+P) garde l’interface de claude.ai et coupe souvent un long bloc de code entre deux pages. Download Claude conversations conserve le langage des blocs de code et garde les tableaux sous forme de tableaux en Markdown, JSON et XML. Le PNG est une image de la conversation, pas un PDF paginé.

Dans la version 1.16.2, la réflexion étendue est une case à cocher du panneau d’export, et les sources de recherche web ainsi que les étapes d’outils / MCP s’activent dans les paramètres. Les métadonnées peuvent inclure le titre, les horodatages et le modèle. Le filtre « Messages » limite le fichier à tous les messages, aux messages humains seuls ou à ceux de l’assistant seul, et « Select » permet de cocher des messages précis. La mise en page des artefacts (« Original », « Inline », « Nested », « Flat » : d’origine, intégrée, imbriquée ou à plat) se règle dans le tableau de bord pour « Export All ».

Nous avons construit l’export autour du bouton orange sur claude.ai : il écrit du PDF, du Markdown, du JSON, du texte, du XML, du CSV ou du PNG à partir de la conversation déjà à l’écran, sans l’envoyer en ligne. La version 1.16.2 génère aussi le PDF dans le navigateur.

C’est le parcours des rédacteurs : bouton orange, Markdown dans la liste, « Export ». Download Claude conversations produit aussi du PDF, du JSON, du texte brut, du XML, du CSV et du PNG à partir de la même conversation claude.ai. Le Markdown est illimité et ne demande aucun compte.

Si vous avez besoin d’une page paginée, choisissez PDF dans la même liste. Il est généré dans le navigateur, avec format de page, marges, mode clair ou sombre, numéros de page et table des matières. Le Markdown d’une discussion exportée peut toujours être converti ensuite dans Word, Google Docs ou une application Markdown.

Les téléchargements en Markdown, JSON, texte, XML, CSV et PNG sont illimités et ne demandent aucun compte : réexporter la même conversation claude.ai dans un second format ne coûte donc rien. Chaque PDF utilise un des 3 exports par jour de l’offre gratuite, avec une connexion Google. Pro, à 3,99 $ par mois ou 26,99 $ par an, supprime cette limite.

Peut-on exporter plusieurs discussions avec Export All ?

Oui. Ouvrez « View and Download All Conversations » depuis la fenêtre de l’extension, filtrez, puis cliquez sur « Export All » pour exporter vos discussions Claude dans un ZIP, avec un fichier par conversation. L’export groupé demande une connexion Google. Avec l’offre gratuite, chaque conversation du ZIP utilise un des 3 exports par jour, partagés avec le PDF. Pro, à 3,99 $ par mois ou 26,99 $ par an, supprime la limite de l’export groupé.

Le tableau de bord liste l’historique claude.ai, avec une recherche par nom, des filtres (« All conversations », « New », « Updated », « Previously exported » : toutes, nouvelles, mises à jour, déjà exportées), les onglets « Chat » et « Cowork » et une recherche par projet. New signifie « pas encore enregistrée avec Download Claude conversations ». Previously exported suit les conversations déjà écrites sur le disque, pour qu’un second « Export All » puisse les ignorer. La recherche par projet reprend la façon dont vous regroupez vos conversations sur claude.ai.

L’export groupé propose un sélecteur « Chat format » (format des conversations) avec les sept formats, PDF compris, les cases « Chats », « Thinking », « Metadata », « Tools » et « Sources » (conversations, réflexion, métadonnées, outils, sources) et la mise en page des artefacts (« Original », « Inline », « Nested », « Flat »). « Export All » n’est pas un ZIP allégé de tout le compte : c’est un seul ZIP, avec un fichier par conversation dans le format choisi. Export data d’Anthropic reste le ZIP JSON différé du compte.

L’export groupé compte par conversation. Avec l’offre gratuite, « Export All » et le PDF partagent 3 exports par jour, et chaque conversation du ZIP en utilise un. Sélectionnez 40 conversations alors qu’il vous en reste 3 : tout le lot est bloqué, pas tronqué. Choisissez-en moins, attendez la remise à zéro de minuit UTC, ou passez à Pro pour 3,99 $ par mois ou 26,99 $ par an. Détails sur la limite partagée : exporter tout l’historique avec Export All.

« Export All » ne partage son quota quotidien qu’avec le PDF. Le Markdown, le texte, le JSON, le XML, le CSV et le PNG du bouton orange n’y touchent jamais : exporter une discussion Claude dans ces formats reste toujours gratuit. Le quota revient à zéro à minuit UTC. Pro se restaure sur un nouvel ordinateur avec le même compte Google, via Paddle.

Exporter une session Claude : Desktop ou Claude Code ?

Pas dans l’application Desktop ni dans le terminal Claude Code. Sur claude.ai, une session correspond à l’URL de la conversation ouverte, et exporter une session Claude signifie alors utiliser le bouton orange dans Chrome. Les sessions Cowork et Claude Code sur le web (claude.ai/code) s’ouvrent aussi sur claude.ai : elles s’exportent de la même façon. Claude Desktop n’affiche jamais le bouton orange. Claude Code dans le terminal utilise /export ou des fichiers JSONL dans ~/.claude/projects.

Si la conversation existe aussi sur votre compte claude.ai, ouvrez-la dans Chrome et exportez-la avec Download Claude conversations. Si elle n’existe que dans Claude Desktop, faites un copier-coller depuis l’application ou demandez Settings → Privacy → Export data sur le web. Comparaison : exporter une conversation Claude Desktop.

Claude Code dans le terminal relève d’un autre parcours. Lancez-y /export, ou copiez les transcriptions JSONL depuis ~/.claude/projects. Download Claude conversations ne lit pas ces fichiers et ne s’injecte pas dans l’outil en ligne de commande. Exporter une session d’agent dans le terminal passe par le disque ; guide : exporter une conversation Claude Code.

claude.ai dans un navigateur de téléphone n’est pas pris en charge non plus. Download Claude conversations nécessite Chrome sur ordinateur (ou un autre navigateur Chromium capable de charger la fiche du Chrome Web Store). Notre équipe ne propose pas d’application iOS ou Android en 2026. Ouvrez la conversation sur un ordinateur, puis utilisez le bouton orange ou « Export All ».

Les espaces Team et Enterprise de claude.ai utilisent eux aussi des URL de conversation dans Chrome. Si un administrateur bloque les extensions, Download Claude conversations ne s’injectera pas : c’est une règle du navigateur, pas un format manquant. Le bouton orange n’apparaît qu’après un rechargement, sur l’URL d’une conversation que vous avez le droit d’ouvrir.

Exporter une discussion ou utiliser Export data d’Anthropic ?

Export data d’Anthropic envoie par e-mail, après un délai, un ZIP JSON de tout le compte. Exporter une discussion Claude avec Download Claude conversations enregistre immédiatement la conversation ouverte en PDF, Markdown, JSON, texte, XML, CSV ou PNG. Le ZIP sert de sauvegarde. L’extension Chrome sert à obtenir tout de suite un fichier lisible depuis claude.ai.

Discussion, conversation, chat : la même extension Chrome ?

Oui. « Exporter discussion Claude », « exporter conversation Claude » ou « comment exporter une conversation Claude » décrivent la même tâche : enregistrer une conversation claude.ai dans un fichier. Download Claude conversations est cette extension Chrome : bouton orange, sept formats, exports gratuits et illimités dans six d’entre eux. Certaines pages légales mentionnent encore Claude Exporter pour cette fiche.

Beaucoup tapent aussi directement la formulation anglaise, « claude export conversation » ou « claude export chat ». Ces recherches désignent toujours le bouton orange sur l’URL d’une conversation claude.ai, ou « Export All » depuis « View and Download All Conversations ». Elles ne désignent ni la commande /export de Claude Code, ni le ZIP envoyé par e-mail par Anthropic, sauf si vous choisissez cette voie officielle.

Pour exporter une conversation Claude sans extension : copier-coller, impression ou Settings → Privacy → Export data. Le copier-coller perd les tableaux. L’impression garde l’interface de claude.ai. Le ZIP est un JSON différé du compte. Download Claude conversations est la voie immédiate vers PDF, Markdown, JSON, texte, XML, CSV ou PNG, uniquement sur claude.ai.

N’attendez pas de Download Claude conversations qu’elle apparaisse dans Claude Desktop ou dans le terminal Claude Code. Ces interfaces n’affichent jamais le bouton orange. Si vous cherchiez une option en ligne de commande, utilisez /export ou le JSONL sur le disque. Si vous attendiez un bouton dans l’application Mac, ouvrez la conversation synchronisée sur claude.ai dans Chrome.

FAQ : exporter une discussion Claude

Ces questions portent sur l’export d’une discussion Claude : formats, limites, Claude Desktop, Claude Code, ZIP d’Anthropic et bouton orange sur claude.ai. Chaque réponse décrit Download Claude conversations 1.16.2. Les données structurées FAQPage dans l’en-tête de la page reprennent cette liste.

Que signifie « exporter une discussion Claude » sur ce site ?

Enregistrer une conversation claude.ai dans un fichier avec Download Claude conversations : bouton orange, choix du format, « Export ». C’est la même chose qu’« exporter une conversation Claude ». Ce n’est ni le ZIP envoyé par e-mail par Anthropic, ni la commande /export de Claude Code.

Exporter une discussion Claude, est-ce la même chose qu’Export data ?

Non. Settings → Privacy → Export data fournit par e-mail un ZIP JSON de tout le compte. Avec cette extension, l’export écrit immédiatement dans Chrome la discussion ouverte en PDF, Markdown, JSON, texte, XML, CSV ou PNG, ou une sélection « Export All » sous forme de ZIP.

Peut-on exporter une discussion Claude en PDF ?

Oui. Choisissez PDF dans la liste des formats et cliquez sur « Export ». Download Claude conversations génère le PDF dans le navigateur, sans boîte de dialogue d’impression. Le PDF demande une connexion Google et reste gratuit jusqu’à 3 par jour ; Pro le rend illimité. Guide : télécharger une conversation Claude en PDF.

Faut-il Pro pour exporter une discussion Claude une seule fois ?

Non. Les exports Markdown, texte, JSON, XML, CSV et PNG sont gratuits et illimités, sans compte. Le PDF et l’export groupé « Export All » sont gratuits jusqu’à 3 par jour avec une connexion Google. Pro, à 3,99 $ par mois ou 26,99 $ par an, supprime cette limite.

L’export fonctionne-t-il avec toutes les offres claude.ai ?

Oui. Les offres claude.ai Free, Pro, Team ou Enterprise fonctionnent si vous pouvez ouvrir la conversation dans Chrome. Download Claude conversations ne nécessite pas d’offre payante chez Anthropic.

Exporter une discussion Claude fonctionne-t-il pour Claude Code ?

Seulement pour Claude Code sur le web. Les sessions sur claude.ai/code s’ouvrent sur claude.ai et s’exportent comme n’importe quelle conversation. Claude Code dans le terminal utilise /export ou des fichiers JSONL dans ~/.claude/projects, et cette extension ne lit pas ces sessions locales.

Puis-je exporter une session Claude depuis Claude Desktop ?

Pas avec cette extension Chrome. Ouvrez la même conversation sur claude.ai si elle est synchronisée, ou faites un copier-coller, ou utilisez l’export officiel Export data. Claude Desktop n’affiche jamais le bouton orange.

Combien de discussions Claude puis-je exporter gratuitement ?

Un nombre illimité en Markdown, texte, JSON, XML, CSV et PNG, sans compte. Avec l’offre gratuite et une connexion Google, le PDF et « Export All » partagent 3 exports par jour ; chaque conversation d’un ZIP groupé compte pour un. Le compteur revient à zéro à minuit UTC. Pro supprime la limite et se restaure via la connexion Google.

Où se trouve le bouton orange pour exporter une discussion Claude ?

À droite de la zone de message, sur l’URL d’une conversation claude.ai, après avoir installé Download Claude conversations et rechargé la page. Il n’apparaît pas sur la page d’accueil vide ni dans Claude Desktop.

L’export envoie-t-il mes discussions en ligne ?

Non. Chaque format, PDF compris, est généré dans le navigateur puis transmis à l’API de téléchargement de Chrome. Les exports Markdown, texte, JSON, XML, CSV et PNG ne nous envoient rien. Une fois que vous êtes connecté pour le PDF, l’export groupé ou Pro, notre serveur voit le quota ou le statut d’abonnement et votre adresse e-mail Google, jamais le contenu des conversations.

Dans quels formats peut-on exporter une discussion Claude ?

Sept : PDF, Markdown, texte brut, JSON, XML, CSV et PNG, les mêmes sept pour une conversation et pour « Export All ». Pas d’export Word, Notion ou Google Docs dans la version 1.16.2.
