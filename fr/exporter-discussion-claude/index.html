Exporter une discussion Claude dans un fichier lisible

Exporter une discussion Claude, c’est enregistrer une conversation claude.ai dans un fichier. Installez Download Claude conversations, ouvrez l’URL de la conversation, cliquez sur le bouton orange, choisissez Markdown, JSON, texte, XML ou PNG, puis « Export » (exporter). Les fichiers sont générés localement dans Chrome, pas dans Claude Desktop ni dans Claude Code. Trois exports sont gratuits ; Pro coûte 3,99 $/mois ou 26,99 $/an.

Comment exporter une discussion Claude dans Chrome ?

Ouvrez l’URL d’une conversation sur claude.ai dans Chrome, cliquez sur le bouton orange à droite de la zone de message, choisissez Markdown, JSON, texte, XML ou PNG, puis « Export ». Download Claude conversations écrit le fichier en local. Rechargez claude.ai après l’installation. claude.ai ne propose aucune commande d’export par conversation.

  1. Installez Download Claude conversations depuis le Chrome Web Store (fiche notée 5,0, version 1.13.0).
  2. Rechargez l’onglet claude.ai pour que le script de contenu puisse s’injecter sur l’URL d’une conversation.
  3. Ouvrez une vraie conversation, pas la page d’accueil vide de claude.ai.
  4. Cliquez sur le bouton orange de téléchargement, à droite de la zone de message.
  5. Choisissez Markdown, JSON, texte brut, XML ou PNG, puis cliquez sur « Export ».

Une connexion Google est requise avant le premier export. Download Claude conversations conserve l’adresse e-mail vérifiée pour que les 3 exports gratuits et Pro soient restaurés après une réinstallation. Le texte des conversations ne fait pas partie de cette connexion Google. Fonctionnement détaillé : comment ça marche.

Si le bouton orange est absent, l’onglet n’est pas sur l’URL d’une conversation claude.ai, la page doit encore être rechargée après l’installation, ou Download Claude conversations est cachée dans le menu en forme de pièce de puzzle de Chrome. Épinglez l’extension, puis actualisez. Le bouton orange n’apparaît jamais sur d’autres sites.

La liste des formats mémorise le dernier choix. Markdown, JSON, texte brut, XML et PNG comptent chacun pour un export quand Chrome termine le téléchargement. Un fichier incomplet signifie généralement que la longue conversation claude.ai n’avait pas fini d’afficher l’arborescence des messages. Attendez, puis cliquez de nouveau sur « Export ».

Une discussion ou tout le compte. Le bouton orange exporte la discussion ouverte. Pour de nombreux fichiers, ouvrez « View and Download All Conversations » (afficher et télécharger toutes les conversations) et lancez « Export All » (tout exporter). Settings → Privacy → Export data d’Anthropic (les libellés peuvent être traduits si claude.ai est en français) fournit un ZIP JSON différé du compte, ce n’est pas ce parcours Chrome.

Que conserve le fichier exporté ?

Une discussion Claude exportée avec Download Claude conversations conserve l’arborescence des messages déjà affichée sur claude.ai : auteurs, blocs de code, tableaux, réflexion en option, métadonnées et mise en page des artefacts. Ce n’est pas une capture de la barre latérale. Le PNG est l’option image. La version 1.13.0 ne produit toujours pas de PDF.

Le copier-coller depuis claude.ai supprime l’indentation et écrase les tableaux. L’impression (Ctrl/Cmd+P) garde l’interface de claude.ai et coupe souvent un long bloc de code entre deux pages. Download Claude conversations conserve le langage des blocs de code et garde les tableaux sous forme de tableaux en Markdown, JSON et XML. Le PNG est une image de la conversation, pas un PDF paginé.

Les blocs de réflexion sont une option dans la version 1.13.0 (« include thinking »). Les métadonnées (« include metadata ») peuvent inclure le titre, les horodatages et le modèle. Le filtre par auteur peut limiter le fichier à tous les messages, aux messages humains seuls ou à ceux de l’assistant seul (« all / human only / assistant only »). La mise en page des artefacts est « Original », « Inline », « Nested » ou « Flat ». Ces options s’appliquent à la discussion ouverte comme à « Export All ».

Nous avons construit l’export autour du bouton orange sur claude.ai : il écrit du Markdown, du JSON, du texte, du XML ou du PNG à partir de la conversation déjà à l’écran, sans l’envoyer en ligne. La version 1.13.0 ne produit toujours pas de PDF.

Comment exporter une discussion Claude en Markdown ?

C’est le parcours des rédacteurs : bouton orange, Markdown dans la liste, « Export ». Download Claude conversations produit aussi du JSON, du texte brut, du XML et du PNG à partir de la même conversation claude.ai. La version 1.13.0 ne propose pas de format PDF. Le choix du format ne change pas le quota de 3 exports.

Les rédacteurs choisissent généralement Markdown pour exporter leurs notes de discussion. Les développeurs choisissent plutôt JSON quand ils ont besoin d’un fichier lisible par une machine. Le texte brut est l’archive sans balisage. XML sert à l’échange de données qui exige des balises. Le PNG est le fichier de type capture d’écran. Download Claude conversations n’ajoute pas d’export vers Word, Notion ou Google Docs dans la version 1.13.0.

Si vous avez besoin précisément d’une page de type PDF, imprimez la conversation claude.ai depuis Chrome au lieu d’attendre un format que nous ne proposons pas. Un PNG produit par Download Claude conversations est un fichier image. Le Markdown d’une discussion exportée peut ensuite être converti dans Word, Google Docs ou une application Markdown si vous avez besoin d’un document paginé.

Chaque téléchargement terminé, en Markdown, JSON, texte, XML ou PNG, compte pour un des 3 exports gratuits d’un compte connecté avec Google. Pro, à 3,99 $/mois ou 26,99 $/an, supprime cette limite pour tous les formats. Réexporter la même conversation claude.ai dans un second format consomme un export de plus, sauf avec Pro.

Peut-on exporter plusieurs discussions avec Export All ?

Oui. Ouvrez « View and Download All Conversations », filtrez, puis cliquez sur « Export All » pour exporter vos discussions Claude sous forme de fichiers séparés, un par conversation. Chaque fichier terminé utilise les mêmes 3 exports gratuits que le bouton orange. Pro, à 3,99 $/mois ou 26,99 $/an, supprime la limite de l’export groupé comme pour une seule conversation.

Le tableau liste l’historique claude.ai, avec une recherche par nom et des filtres All, New, Exported et Project. New signifie « pas encore enregistrée avec Download Claude conversations ». Exported suit les conversations déjà écrites sur le disque, pour qu’un second Export All puisse les ignorer. Project reprend la façon dont vous regroupez vos conversations sur claude.ai.

L’export groupé utilise les mêmes options qu’une discussion isolée : conversations, réflexion, métadonnées, mise en page des artefacts (« Original », « Inline », « Nested », « Flat ») et les mêmes cinq formats. « Export All » n’est pas un ZIP allégé de tout le compte : ce sont de nombreux fichiers, un par conversation. Export data d’Anthropic reste le ZIP JSON différé du compte.

Le quota couvre tout le compte. Trois exports gratuits au total, pas trois par export groupé. Sélectionner 40 conversations sur la page de navigation consommera 40 exports si chaque fichier aboutit. Préparez votre sélection avant de cliquer sur « Export All », ou passez à Pro pour 3,99 $/mois ou 26,99 $/an. Détails sur le quota partagé : exporter tout l’historique avec Export All.

« Export All » et le bouton orange partagent un seul quota lié au compte Google. Vous ne pouvez pas obtenir trois fichiers gratuits avec le bouton orange et trois autres avec « Export All ». Réinstaller Download Claude conversations ne remet pas le compteur à zéro. Pro se restaure sur un nouvel ordinateur avec le même compte Google, via Paddle.

Exporter une session Claude : Desktop ou Claude Code ?

Sur claude.ai, une session correspond à l’URL de la conversation ouverte. Exporter une session Claude signifie alors utiliser le bouton orange dans Chrome, pas une intégration à Desktop ou au terminal. Download Claude conversations fonctionne uniquement sur claude.ai. Claude Desktop n’affiche jamais le bouton orange. Claude Code utilise /export ou des fichiers JSONL dans ~/.claude/projects.

Si la conversation existe aussi sur votre compte claude.ai, ouvrez-la dans Chrome et exportez-la avec Download Claude conversations. Si elle n’existe que dans Claude Desktop, faites un copier-coller depuis l’application ou demandez Settings → Privacy → Export data sur le web. Comparaison : exporter une conversation Claude Desktop.

Claude Code relève d’un autre parcours. Lancez /export dans le terminal, ou copiez les transcriptions JSONL depuis ~/.claude/projects. Download Claude conversations ne lit pas ces fichiers et ne s’injecte pas dans l’outil en ligne de commande. Exporter une session d’agent dans le terminal passe par le disque ; guide : exporter une conversation Claude Code.

claude.ai dans un navigateur de téléphone n’est pas pris en charge non plus. Download Claude conversations nécessite Chrome sur ordinateur (ou un autre navigateur Chromium capable de charger la fiche du Chrome Web Store). Notre équipe ne propose pas d’application iOS ou Android en 2026. Ouvrez la conversation sur un ordinateur, puis utilisez le bouton orange ou « Export All ».

Les espaces Team et Enterprise de claude.ai utilisent eux aussi des URL de conversation dans Chrome. Si un administrateur bloque les extensions, Download Claude conversations ne s’injectera pas : c’est une règle du navigateur, pas un format manquant. Le bouton orange n’apparaît qu’après un rechargement, sur l’URL d’une conversation que vous avez le droit d’ouvrir.

Exporter une discussion ou utiliser Export data d’Anthropic ?

Export data d’Anthropic envoie par e-mail, après un délai, un ZIP JSON de tout le compte. Exporter une discussion Claude avec Download Claude conversations enregistre immédiatement la conversation ouverte en Markdown, JSON, texte, XML ou PNG. Le ZIP sert de sauvegarde. L’extension Chrome sert à obtenir tout de suite un fichier lisible depuis claude.ai.

Combien coûte l’export d’une discussion Claude ?

Chaque compte connecté avec Google dispose de 3 exports gratuits. Ensuite, Pro coûte 3,99 $ par mois ou 26,99 $ par an via Paddle. Ce prix couvre le bouton orange et « Export All ». Download Claude conversations ne facture pas par format. Toute offre claude.ai convient si Chrome peut ouvrir la conversation.

Les 3 exports gratuits ne se renouvellent pas quand vous réinstallez l’extension. C’est pourquoi la connexion Google est demandée au premier clic sur « Export ». Pro se restaure sur un nouvel ordinateur avec le même compte Google. Paddle est le revendeur officiel ; notre équipe ne voit jamais les numéros de carte. Les remboursements passent par Paddle, comme décrit sur la page des remboursements.

Vous n’avez pas besoin de l’offre payante de claude.ai pour exporter une discussion. Il vous faut une connexion claude.ai capable de charger la conversation, plus Chrome. Team et Enterprise fonctionnent comme Free avec le bouton orange. Si Chrome a bloqué le téléchargement, autorisez les téléchargements depuis claude.ai avant de cliquer de nouveau sur « Export ».

Discussion, conversation, chat : la même extension Chrome ?

Oui. « Exporter discussion Claude », « exporter conversation Claude » ou « comment exporter une conversation Claude » décrivent la même tâche : enregistrer une conversation claude.ai dans un fichier. Download Claude conversations est cette extension Chrome : bouton orange, cinq formats, 3 exports gratuits. Certaines pages légales mentionnent encore Claude Exporter pour cette fiche.

Beaucoup tapent aussi directement la formulation anglaise, « claude export conversation » ou « claude export chat ». Ces recherches désignent toujours le bouton orange sur l’URL d’une conversation claude.ai, ou « Export All » depuis « View and Download All Conversations ». Elles ne désignent ni la commande /export de Claude Code, ni le ZIP envoyé par e-mail par Anthropic, sauf si vous choisissez cette voie officielle.

Pour exporter une conversation Claude sans extension : copier-coller, impression ou Settings → Privacy → Export data. Le copier-coller perd les tableaux. L’impression garde l’interface de claude.ai. Le ZIP est un JSON différé du compte. Download Claude conversations est la voie immédiate vers Markdown, JSON, texte, XML ou PNG, uniquement sur claude.ai.

N’attendez pas de Download Claude conversations qu’elle apparaisse dans Claude Desktop ou dans le terminal Claude Code. Ces interfaces n’affichent jamais le bouton orange. Si vous cherchiez une option en ligne de commande, utilisez /export ou le JSONL sur le disque. Si vous attendiez un bouton dans l’application Mac, ouvrez la conversation synchronisée sur claude.ai dans Chrome.

FAQ : exporter une discussion Claude

Ces questions portent sur l’export d’une discussion Claude : formats, quota, Claude Desktop, Claude Code, ZIP d’Anthropic et bouton orange sur claude.ai. Chaque réponse décrit Download Claude conversations 1.13.0. Les données structurées FAQPage dans l’en-tête de la page reprennent cette liste.

Que signifie « exporter une discussion Claude » sur ce site ?

Enregistrer une conversation claude.ai dans un fichier avec Download Claude conversations : bouton orange, choix du format, « Export ». C’est la même chose qu’« exporter une conversation Claude ». Ce n’est ni le ZIP envoyé par e-mail par Anthropic, ni la commande /export de Claude Code.

Exporter une discussion Claude, est-ce la même chose qu’Export data ?

Non. Settings → Privacy → Export data fournit par e-mail un ZIP JSON de tout le compte. Avec cette extension, l’export écrit immédiatement dans Chrome la discussion ouverte, ou une sélection « Export All », en Markdown, JSON, texte, XML ou PNG.

Peut-on exporter une discussion Claude en PDF ?

Pas avec Download Claude conversations. Les formats sont Markdown, JSON, texte brut, XML et PNG. Pour un instantané de type PDF, imprimez la page claude.ai dans Chrome. Le PNG est une image, pas un PDF.

Faut-il Pro pour exporter une discussion Claude une seule fois ?

Non. Les 3 premiers exports de tout compte connecté avec Google sont gratuits, dans n’importe quel format. Pro, à 3,99 $/mois ou 26,99 $/an, supprime la limite pour davantage de fichiers, individuels ou groupés.

L’export fonctionne-t-il avec toutes les offres claude.ai ?

Oui. Les offres claude.ai Free, Pro, Team ou Enterprise fonctionnent si vous pouvez ouvrir la conversation dans Chrome. Download Claude conversations ne nécessite pas d’offre payante chez Anthropic.

Exporter une discussion Claude fonctionne-t-il pour Claude Code ?

Non. Download Claude conversations fonctionne sur claude.ai dans Chrome. Claude Code utilise /export ou des fichiers JSONL dans ~/.claude/projects. Cette extension ne lit pas les sessions Claude Code.

Puis-je exporter une session Claude depuis Claude Desktop ?

Pas avec cette extension Chrome. Ouvrez la même conversation sur claude.ai si elle est synchronisée, ou faites un copier-coller, ou utilisez l’export officiel Export data. Claude Desktop n’affiche jamais le bouton orange.

Combien de discussions Claude puis-je exporter gratuitement ?

Trois par compte connecté avec Google, partagées entre le bouton orange et « Export All ». Une réinstallation ne remet pas le compteur à zéro. Pro se restaure via la connexion Google.

Où se trouve le bouton orange pour exporter une discussion Claude ?

À droite de la zone de message, sur l’URL d’une conversation claude.ai, après avoir installé Download Claude conversations et rechargé la page. Il n’apparaît pas sur la page d’accueil vide ni dans Claude Desktop.

L’export envoie-t-il mes discussions en ligne ?

Non. Les fichiers sont générés dans le navigateur puis transmis à l’API de téléchargement de Chrome. Notre serveur voit le statut d’abonnement et une adresse e-mail vérifiée par Google, pas le contenu des conversations.

Dans quels formats peut-on exporter une discussion Claude ?

Markdown, JSON, texte brut, XML et PNG : les mêmes cinq pour une conversation et pour « Export All ». Pas d’export PDF, Word, Notion ou Google Docs dans la version 1.13.0.
