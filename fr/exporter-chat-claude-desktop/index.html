Pourquoi ne peut-on pas exporter un chat Claude Desktop ici ?

Download Claude conversations est un script de contenu Chrome pour claude.ai. Claude Desktop est une application autonome pour Mac/Windows. Sa fenêtre n’a pas de barre d’extensions : le bouton orange n’y apparaît donc jamais. Installer l’extension Chrome pendant que Desktop est ouvert ne change rien à Desktop.

Les extensions Chrome s’exécutent sur les pages correspondant à leurs autorisations d’hôte. Cette extension correspond aux pages de conversation claude.ai. Claude Desktop n’est pas un onglet claude.ai. Vous ne pouvez pas « ajouter à Chrome » dans l’application Desktop. La version 1.13.0 (septembre 2026) n’a toujours ni plugin Desktop, ni utilitaire dans la barre de menus, ni lecteur de fichiers pour le dossier d’installation de Desktop.

Limite stricte. Vous ne pouvez pas exporter un chat Claude Desktop avec cette extension Chrome depuis Desktop. Si vous voulez du Markdown, du JSON, du texte, du XML ou du PNG depuis notre widget, quittez Desktop, ouvrez https://claude.ai dans Chrome et ouvrez-y la conversation.

Beaucoup cherchent à exporter un chat Claude Desktop parce que les produits partagent la même marque. Les résultats de recherche mélangent Desktop, claude.ai et Claude Code. Les fichiers ne sont pas interchangeables. Une capture d’écran de Desktop n’est pas un export Markdown. Un journal JSONL de Code n’est pas une conversation claude.ai. Cette page existe pour rendre cette différence explicite.

Exporter un chat Claude Desktop, claude.ai ou Claude Code ?

Claude Desktop est l’application de conversation. claude.ai est le produit pour navigateur. Claude Code est l’agent en terminal. Seul claude.ai dans Chrome bénéficie de Download Claude conversations. Exporter un chat Claude Desktop est donc une question de solution de contournement, pas un travail pour le bouton orange dans l’application.

Comment exporter un chat Claude Desktop via claude.ai ?

Beaucoup de sessions Desktop utilisent le même compte Claude que le web. Si la conversation figure dans votre historique claude.ai, ouvrez-la dans Chrome et utilisez Download Claude conversations. C’est la seule façon dont cette extension vous aide à exporter un chat Claude Desktop : la conversation doit d’abord se charger sur claude.ai.

  1. Cessez de chercher dans Desktop. Ouvrez https://claude.ai dans Chrome et connectez-vous avec le même compte.
  2. Retrouvez la conversation dans l’historique web. Si elle n’y est pas, passez au copier-coller ou à Export data — nous ne pouvons pas récupérer une conversation que Chrome n’a jamais chargée.
  3. Cliquez sur le bouton orange. Choisissez Markdown, JSON, texte brut, XML ou PNG. Cliquez sur « Export » (Exporter).
  4. Pour de nombreuses conversations synchronisées, ouvrez « View and Download All Conversations » (afficher et télécharger toutes les conversations) et lancez « Export All » (Tout exporter).
  5. Si vous avez besoin d’une page proche d’un PDF de ce que vous voyez sur le web, imprimez depuis Chrome — nous ne proposons pas le PDF. Guide : impression / PDF.

La connexion Google lors du premier export web compte les 3 exportations gratuites et restaure Pro à 3,99 $/mois ou 26,99 $/an. Ce quota ne s’applique qu’aux fichiers claude.ai. Le copier-coller dans Desktop ne consomme pas notre quota, car il ne passe jamais par l’extension. Paddle facture Pro ; nous ne voyons jamais les numéros de carte.

La synchronisation dépend d’Anthropic, pas de nous. Si Desktop affiche une conversation que claude.ai n’affiche pas, cette extension Chrome ne peut pas l’inventer. Patientez, actualisez claude.ai, ou utilisez le copier-coller / le ZIP officiel. Nous ne lisons pas la base de données locale de Desktop. Les formats une fois sur claude.ai. Markdown pour les notes, JSON pour les outils, texte pour une archive minimale, XML pour l’échange de données, PNG pour une image. Les cinq mêmes que dans tous les autres guides. Page centrale : formats. Aucun de ces formats n’apparaît dans l’application Desktop grâce à cette extension.

Peut-on exporter un chat Claude Desktop par copier-coller ?

Oui. Sélectionnez le texte dans Claude Desktop et collez-le dans un document. C’est la solution de repli honnête quand la conversation n’apparaît pas sur claude.ai. Vous perdez la fidélité des blocs de code, les mises en page d’artifacts, les options de réflexion et l’exportation groupée Export All. Suffisant pour une réponse courte ; pénible pour une longue conversation de programmation.

Le copier-coller depuis Desktop est justement la raison d’être de l’extension Chrome sur claude.ai : le widget web conserve les balises de langage, les tableaux et les artifacts en « Original », « Inline », « Nested » ou « Flat » (d’origine, intégrée, imbriquée, à plat). Desktop ne dispose d’aucune de ces commandes d’export de notre part. Si vous pouvez retrouver la même conversation sur claude.ai, arrêtez le copier-coller et utilisez-y Download Claude conversations.

Les captures d’écran de Claude Desktop sont une autre solution de repli. Ce sont des images, pas du Markdown, et elles ne constituent pas un export réutilisable d’un chat Claude Desktop. Le PNG de notre extension est aussi une image, mais il n’est généré qu’une fois la conversation ouverte sur claude.ai. Ne l’attendez pas depuis la fenêtre Desktop.

Export data couvre-t-il les conversations Claude Desktop ?

Settings → Privacy → Export data d’Anthropic (les libellés peuvent être traduits si claude.ai est réglé en français) envoie par e-mail une archive ZIP JSON liée au compte Claude, et non à la fenêtre dans laquelle vous avez écrit. Si une conversation Desktop est enregistrée sur ce compte, elle peut apparaître. Considérez le ZIP comme une sauvegarde, pas comme le Markdown de cette extension.

Le ZIP est lent, le lien expire, et il n’existe aucun choix de format pour Markdown, texte, XML ou PNG. Cela reste la méthode officielle pour emporter votre compte lorsque vous devez exporter l’historique Claude Desktop en un seul bloc. Comparaison avec l’impression et le widget Chrome : comment exporter une conversation Claude.

Ne confondez pas ce ZIP avec Export All sur notre page de consultation. Export All crée des fichiers séparés que vous sélectionnez sur claude.ai, immédiatement, dans le format choisi, et chaque fichier consomme l’une des 3 exportations gratuites (ou Pro). Export data officiel n’utilise pas notre quota. Les conversations restées uniquement dans Desktop, jamais synchronisées, peuvent manquer dans les deux.

Claude Desktop est-il la même chose que Claude Code ?

Non. Claude Desktop est l’application de conversation. Claude Code est l’agent de programmation en terminal, avec /export et des transcriptions JSONL. Chercher à exporter un chat Claude Desktop pour un terminal d’IDE, c’est se tromper de produit. Cette extension Chrome ne fonctionne dans aucun des deux.

Si par « desktop » vous entendiez VS Code ou un terminal sur votre ordinateur, suivez exporter une conversation Claude Code. Si vous parliez de l’application de conversation Desktop d’Anthropic, restez sur cette page. Confondre les deux fait perdre du temps : le JSONL sur le disque n’est pas un bouton orange, et le copier-coller dans Desktop n’est pas /export.

Download Claude conversations n’ajoutera pas d’intégration Code sous prétexte que Desktop et Code ne sont « pas le navigateur ». Le produit est volontairement restreint : claude.ai dans Chrome, cinq formats, 3 exportations gratuites, Pro à 3,99 $/mois ou 26,99 $/an. Périmètre des fonctionnalités : fonctionnalités. Ce que nous ne ferons pas pour exporter un chat Claude Desktop

Nous ne proposons ni plugin Claude Desktop, ni application dans la barre de menus, ni option « exporter depuis Desktop ». Nous ne lisons pas les fichiers de votre installation Claude Desktop sur Mac ou Windows. Nous ne remplaçons pas le /export de Claude Code. Ces phrases définissent la limite du produit pour l’export d’un chat Claude Desktop dans la version 1.13.0.

Nous ne citons pas non plus d’autres extensions d’exportation pour Chrome. Les outils officiels d’Anthropic — claude.ai, Claude Desktop, Claude Code, Settings → Privacy → Export data — sont mentionnés ici à titre de comparaison. Download Claude conversations reste indépendant, non affilié à Anthropic, PBC. La note de 5.0 sur le Chrome Web Store citée sur cette page concerne l’extension web, pas un produit Desktop qui n’existe pas.

Si vous n’utilisez que Desktop, servez-vous du copier-coller et du ZIP officiel jusqu’à ce qu’Anthropic propose un export de fichier par conversation dans l’application. Si vous utilisez aussi claude.ai, installez l’extension et exportez depuis le navigateur. C’est toute notre offre, en toute honnêteté. Les applications mobiles Claude sont également hors du périmètre de cette extension.

Rappel du quota pour la voie web. Une fois une conversation synchronisée ouverte sur claude.ai, 3 exportations sont gratuites, puis Pro coûte 3,99 $/mois ou 26,99 $/an. Le copier-coller dans Desktop n’incrémente jamais ce compteur. La connexion Google n’est requise que lorsque vous utilisez réellement le widget Chrome.

Dépannage : extension installée mais aucun bouton dans Desktop — c’est normal. Bouton absent sur claude.ai — rechargez, épinglez l’icône, ouvrez une URL de conversation. Conversation présente dans Desktop mais pas sur le web — ce n’est pas un bug de l’extension. Mauvais produit (Code ou Desktop) — vérifiez si vous êtes dans un terminal. Besoin d’une copie visuelle proche d’un PDF une fois sur le web — imprimez, n’attendez pas un format PDF que nous ne proposons pas.

FAQ : exporter un chat Claude Desktop

Ces questions couvrent l’export d’un chat Claude Desktop : pourquoi le bouton orange est absent, comment passer par claude.ai si la conversation est synchronisée, le copier-coller, Export data officiel et Claude Code. Les réponses correspondent à la version 1.13.0. Le schéma FAQPage dans l’en-tête correspond à cette liste.

Puis-je exporter un chat Claude Desktop avec cette extension ?

Non. Download Claude conversations fonctionne sur claude.ai dans Chrome. Le bouton orange n’apparaît jamais dans la fenêtre de Claude Desktop. La version 1.13.0 n’a pas de plugin Desktop.

Comment exporter une conversation Claude Desktop ?

Ouvrez la même conversation sur claude.ai dans Chrome si elle est synchronisée, puis utilisez l’extension ou l’impression. Sinon, faites un copier-coller depuis Desktop, ou utilisez Settings → Privacy → Export data pour obtenir une archive ZIP JSON de tout le compte.

Claude Desktop est-il la même chose que Claude Code ?

Non. Desktop est l’application de conversation. Claude Code est l’agent en terminal, avec /export et des transcriptions JSONL. Cette extension Chrome ne fonctionne dans aucun des deux.

Export data officiel inclut-il les conversations Desktop ?

L’archive ZIP est liée à votre compte Claude. Si une conversation Desktop y est enregistrée, elle peut apparaître. Cela reste une archive de sauvegarde, pas un fichier Markdown par conversation issu de cette extension.

L’export d’un chat Claude Desktop fonctionne-t-il une fois sur claude.ai ?

Oui, pour les conversations qui se chargent sur claude.ai. Download Claude conversations peut alors générer du Markdown, du JSON, du texte, du XML ou du PNG. Les conversations jamais synchronisées restent limitées au copier-coller ou au ZIP.

Cette extension peut-elle lire le dossier d’installation de Claude Desktop ?

Non. Nous n’analysons pas les fichiers de Desktop sur Mac ou Windows. Le script de contenu ne voit qu’une page claude.ai déjà affichée par Chrome.

Ai-je besoin de Pro pour exporter un chat Claude Desktop sur le web ?

Pas pour les 3 premières exportations web. Ensuite, Pro coûte 3,99 $/mois ou 26,99 $/an. Le copier-coller dans Desktop n’utilise pas notre quota.

Puis-je exporter un chat Claude Desktop en PDF avec cet outil ?

Non. Nous ne proposons pas non plus le PDF sur claude.ai. Imprimez depuis Chrome une fois la conversation sur le web, ou contentez-vous d’un PNG, qui est une image. Nous n’offrons aucune impression depuis Desktop.

Ajouter l’extension à Chrome permet-il d’exporter un chat Claude Desktop ?

Non. Installer Download Claude conversations ne concerne que Chrome sur claude.ai. Desktop reste inchangé. Épinglez l’extension, puis travaillez dans l’onglet du navigateur.

Existe-t-il une solution mobile pour exporter un chat Claude Desktop ?

Pas avec cette extension. Elle nécessite Chrome sur ordinateur, sur claude.ai. Les navigateurs de téléphone et l’application Desktop ne sont pas pris en charge par le bouton orange.

Quels formats fonctionnent une fois une conversation Desktop sur claude.ai ?

Markdown, JSON, texte brut, XML et PNG — les cinq mêmes que dans tous les autres guides Download Claude conversations. Les mises en page d’artifacts et l’option de réflexion ne s’appliquent que dans ce widget web.
