Comment télécharger un chat Claude dans Chrome ?

Sur claude.ai, on télécharge une conversation grâce au bouton orange que Download Claude conversations ajoute à côté de la zone de message. Ouvrez la conversation, choisissez PDF, Markdown, JSON, texte, XML, CSV ou PNG, puis cliquez sur « Export ». Chrome enregistre un fichier local. Ce fichier contient une conversation, pas un ZIP de compte.

Download Claude conversations est un script de contenu Chrome. Il lit la conversation déjà chargée dans votre session claude.ai connectée. Il n’appelle pas une API Anthropic distincte avec ses propres identifiants et n’envoie pas la conversation sur nos serveurs pour générer quelque format que ce soit, PDF compris.

  1. Installez Download Claude conversations depuis le Chrome Web Store (les navigateurs Chromium qui acceptent les extensions Chrome fonctionnent aussi).
  2. Rechargez claude.ai si la page était déjà ouverte pendant l’installation. Chrome ne s’injecte pas dans un onglet resté ouvert.
  3. Ouvrez l’URL de la conversation voulue : le bouton orange n’apparaît que sur une vraie conversation, pas sur la page d’accueil vide.
  4. Cliquez sur le bouton orange de téléchargement, à droite de la zone de message. Un panneau s’ouvre avec Messages (« All / Human / Assistant », soit tous, humain, assistant), Format, « Thinking » (réflexion), « Select » (sélectionner), « Copy » (copier) et « Export ».
  5. Choisissez PDF, Markdown, texte brut, JSON, XML, CSV ou PNG. Cliquez sur « Export ». Chrome télécharge immédiatement un fichier.

Aucun compte n’est nécessaire pour Markdown, texte brut, JSON, XML, CSV ou PNG. Ces exports d’une conversation sont illimités et gratuits : pas de connexion, pas de compteur. La connexion Google n’apparaît que si vous choisissez le PDF ou lancez un export groupé avec « Export All » (tout exporter). Ce n’est pas un accès à vos conversations claude.ai. Leur contenu reste sur votre machine.

Le PDF et le ZIP groupé partagent un quota gratuit de 3 par jour, remis à zéro à minuit UTC. Chaque conversation d’un ZIP groupé compte pour une. Fichiers locaux. Tous les formats, PDF compris, sont générés dans le navigateur puis transmis à l’API de téléchargement de Chrome. Le texte des conversations n’est jamais envoyé. Seuls les exports PDF et groupés envoient une vérification de quota avec votre adresse Google. Version décrite sur cette page : 1.16.2, septembre 2026.

Le même panneau filtre par auteur : All, Human ou Assistant. La case « Thinking » inclut ou ignore la réflexion étendue. « Select » permet de cocher des messages précis pour que le fichier ne contienne que ces échanges. « Copy » place du Markdown, du texte, du JSON, du XML ou du CSV dans le presse-papiers au lieu de télécharger un fichier. Les étapes d’outils / MCP et les sources de recherche web s’activent dans les paramètres (Settings). Les métadonnées et la mise en page des artefacts (« Original », « Inline », « Nested » ou « Flat ») se règlent dans le tableau de bord (Dashboard).

Si la conversation est très longue, faites défiler jusqu’à ce que claude.ai ait chargé les messages plus anciens. Download Claude conversations ne peut exporter que ce que la page a affiché. Une conversation à moitié chargée donne un fichier à moitié rempli : cela ressemble à un bug, mais c’est presque toujours une page qui n’a pas été défilée.

Télécharger un chat Claude ou utiliser Export data ?

Télécharger un chat Claude avec le bouton orange donne un fichier nommé de la conversation claude.ai ouverte, immédiatement, en local, PDF compris. Settings → Privacy → Export data d’Anthropic (les libellés peuvent être traduits si claude.ai est en français) donne un ZIP JSON du compte, envoyé plus tard par e-mail. L’impression donne un PDF visuel de la page web. Le copier-coller donne du texte sans structure. Choisissez la ligne qui correspond à votre besoin.

Export data est une sauvegarde de tout le compte Anthropic, pas un téléchargement par conversation. Anthropic envoie par e-mail un lien qui expire. Le ZIP mélange les conversations oubliées et celles que vous vouliez garder. Il faut ensuite décompresser le JSON vous-même pour retrouver une conversation parmi des milliers. Ce n’est pas la voie du bouton orange.

Par l’impression : ouvrez la conversation sur claude.ai, masquez la barre latérale si l’interface le permet, appuyez sur Ctrl+P (Windows/Linux) ou Cmd+P (Mac), choisissez « Enregistrer au format PDF » comme destination, puis enregistrez. Les blocs de code se coupent souvent entre deux pages, et la zone de saisie peut apparaître sur chaque feuille. L’impression est un instantané de l’écran, pas du Markdown. L’export PDF de l’extension évite cette boîte de dialogue : conversation Claude en PDF.

Le copier-coller est une troisième méthode sans extension. Sélectionnez le texte sur claude.ai, collez-le dans Docs ou une application de notes. L’indentation du code disparaît généralement. Les tableaux deviennent des lignes continues. Une conversation à plusieurs tours devient un bloc sans structure. Suffisant pour une réponse courte, insuffisant pour une revue de code que vous voudrez retrouver plus tard.

Dans quel format télécharger un chat Claude ?

Cliquez sur le bouton orange, choisissez PDF, Markdown, JSON, texte, XML, CSV ou PNG, puis « Export ». Markdown est le fichier de notes. JSON est l’arborescence des messages pour vos scripts. Le texte brut n’a aucun balisage. XML sert à l’échange de données. Le CSV compte une ligne par message. Le PDF est un document paginé. Le PNG est une image.

Markdown conserve les titres, les blocs de code avec leur langage et les tableaux. C’est le choix habituel pour Obsidian, GitHub ou un wiki. JSON conserve l’arborescence construite par l’analyseur, y compris les artefacts et la réflexion quand ces options sont activées. Sa structure diffère de celle du ZIP de compte d’Anthropic. Notes sur les formats : tous les formats.

Le texte brut convient quand la destination supprime de toute façon le balisage : un champ de ticket, le corps d’un e-mail, un index de recherche qui attend du texte simple. XML est le choix de niche pour l’échange de données. Le CSV s’ouvre dans Excel, Google Sheets ou Numbers. Le PNG sert pour une diapositive ou une capture dans un rapport de bug, pas pour une revue de conception de 40 échanges dans laquelle vous ferez des recherches.

Peut-on télécharger plusieurs conversations Claude d’un coup ?

Oui. Vous pouvez télécharger votre historique Claude en plusieurs fichiers sans répéter le bouton orange onglet par onglet. Ouvrez « View and Download All Conversations » (afficher et télécharger toutes les conversations) depuis la fenêtre de l’extension, filtrez le tableau, puis cliquez sur « Export All ». « Export All » demande une connexion Google. Sur l’offre gratuite, chaque conversation du ZIP consomme l’un des 3 créneaux quotidiens partagés avec le PDF. Pro supprime la limite.

Le tableau de bord liste les conversations du compte claude.ai auquel vous êtes connecté. Cherchez par nom. Filtrez par « All conversations » (toutes), « New » (nouvelles), « Updated » (mises à jour) ou « Previously exported » (déjà exportées). Passez de l’onglet Chat à l’onglet Cowork, et cherchez par projet si vous organisez vos conversations ainsi sur claude.ai. Sélectionnez un sous-ensemble si vous ne voulez pas tous les vieux brouillons dans le dossier.

L’export groupé produit un seul ZIP, avec un fichier par conversation, dans le format choisi via le sélecteur « Chat format » (format des conversations) : n’importe lequel des sept, PDF compris. Il utilise le même analyseur qu’un export unique. Des cases à cocher définissent le contenu (« Chats », « Thinking », « Metadata », « Tools », « Sources », soit conversations, réflexion, métadonnées, outils, sources), ainsi que la mise en page des artefacts. « Export All » n’est pas une version allégée : c’est le même analyseur appliqué à de nombreuses conversations en une seule passe. Export data d’Anthropic reste la sauvegarde du compte : un ZIP, un e-mail, du JSON pour tout, y compris les conversations oubliées. « Export All » répond au besoin inverse : vous choisissez les conversations, vous choisissez le format, et le ZIP arrive immédiatement. Utilisez les deux si vous voulez à la fois une archive complète et un dossier de notes lisibles.

Le quota est commun et quotidien. Sur l’offre gratuite, les exports PDF et les conversations exportées en groupe partagent 3 par jour, remis à zéro à minuit UTC. Sélectionnez 40 conversations et tout le lot est bloqué, sans être coupé en cours de route. Choisissez-en moins, ou passez à Pro pour 3,99 $ par mois ou 26,99 $ par an via Paddle.

Le tableau de bord mémorise aussi ce que vous avez déjà exporté : lors d’une visite suivante, vous pouvez filtrer sur New ou Updated uniquement. C’est ainsi qu’un téléchargement hebdomadaire reste incrémental au lieu de dupliquer les fichiers Markdown du mois dernier. Sur l’offre gratuite, un historique entier sort au rythme de 3 conversations par jour. Pro exporte tout l’historique en une seule passe.

La connexion Google est requise avant le premier ZIP groupé. Un fichier unique du bouton orange en Markdown, texte, JSON, XML, CSV ou PNG ne la demande jamais. Download Claude conversations conserve l’adresse e-mail vérifiée pour appliquer la limite de 3 par jour et restaurer Pro. Pourquoi le bouton de téléchargement a-t-il disparu ?

Le bouton orange est absent quand vous n’êtes pas sur l’URL d’une conversation, que l’onglet n’a pas été rechargé après l’installation ou que l’extension est désactivée. Épinglez l’icône, rechargez, et vérifiez que vous êtes bien dans Chrome sur ordinateur, sur claude.ai : pas dans Desktop, sur un téléphone ou dans un terminal Claude Code.

Après l’installation, Chrome n’injecte pas toujours le script de contenu dans les onglets déjà ouverts. Fermez l’onglet claude.ai ou rechargez-le complètement. Si vous utilisez plusieurs profils, Download Claude conversations doit être installée dans le profil connecté à Anthropic.

Les espaces Team et Enterprise fonctionnent si vous pouvez ouvrir la conversation dans le navigateur. L’extension lit la page, pas le niveau d’abonnement. Si votre organisation bloque les extensions Chrome, le service informatique doit autoriser celle-ci ; nous ne pouvons pas contourner cette règle depuis chat-downloader.com.

Demande de connexion : elle n’est normale que pour le PDF et « Export All ». Markdown, texte, JSON, XML, CSV et PNG s’exportent sans compte. Le premier export PDF ou groupé demande une connexion Google. Si vous l’annulez, cela ressemble à un téléchargement raté. Terminez la connexion, puis cliquez de nouveau sur « Export ». Aucune carte bancaire n’est demandée sur l’offre gratuite. Paddle n’apparaît que si vous achetez Pro.

Fichier incomplet : la réponse n’avait pas fini de s’afficher, ou les anciens échanges n’étaient pas encore chargés hors de l’écran. Attendez que l’assistant ait terminé. Faites défiler vers le début d’une longue conversation pour que claude.ai charge ces messages, puis exportez de nouveau. Refaire un export Markdown ou JSON ne coûte rien. Refaire un PDF consomme un autre des 3 créneaux quotidiens de l’offre gratuite : vérifiez d’abord que tout est chargé.

Mauvais type de fichier : le dernier format utilisé était encore sélectionné. Mauvais compte : vous vous êtes connecté à Google avec une autre adresse que celle qui détient Pro. La restauration de Pro est liée à cette adresse Google, ni à la connexion Anthropic, ni au nom du profil Chrome.

Les navigateurs mobiles n’exécutent pas cette extension. Il n’existe pas d’application iOS ou Android. Safari sur téléphone peut imprimer claude.ai, mais ne peut pas afficher le bouton orange. Pour un fichier réutilisable, ouvrez la même conversation dans Chrome sur ordinateur et téléchargez-la là.

Pas de bouton sur la page d’accueil vide. La page d’accueil de claude.ai, avec la zone de saisie, n’est pas l’URL d’une conversation. Commencez ou ouvrez d’abord une conversation. La commande orange se trouve à droite de la zone de message de cette conversation, après un rechargement suivant l’installation.

Peut-on télécharger un chat Claude depuis Desktop ?

Non. Claude Desktop ne permet pas de télécharger un chat Claude avec cette extension. Download Claude conversations s’injecte uniquement sur claude.ai dans Chrome. Un terminal Claude Code local est une autre interface ; Claude Code sur le web, sur claude.ai/code, s’exporte bien. Ouvrez la même conversation sur claude.ai si elle y existe, puis utilisez le bouton orange.

Claude Desktop est une fenêtre à part. Le script de contenu Chrome ne s’injecte jamais dans cette application. Si la même conversation existe sur claude.ai, ouvrez-la là et téléchargez-la. Si elle n’existe que dans Desktop, faites un copier-coller ou attendez le ZIP du compte via Settings → Privacy → Export data.

Claude Code en local fonctionne dans le terminal. Dans une session active, tapez /export. L’outil en ligne de commande d’Anthropic ouvre un menu pour copier la transcription ou l’enregistrer dans un fichier texte. Indiquez un nom de fichier pour passer le menu. Cette transcription est un texte destiné à être lu, pas le Markdown, le JSON ou le PDF de cette extension. Chemins : exporter une conversation Claude Code.

Le JSONL sur le disque est le journal interne. Son schéma peut changer d’une version de Claude Code à l’autre. La documentation d’Anthropic recommande d’utiliser /export ou les interfaces de script plutôt que d’analyser le JSONL. Nous n’encapsulons pas cet outil et ne lisons pas ~/.claude. Chemin sous Windows : %USERPROFILE%\.claude\projects.

Claude Code sur le web fait exception. Les sessions sur claude.ai/code s’ouvrent dans Chrome : Download Claude conversations les exporte comme n’importe quelle conversation. Si vous menez en parallèle une conversation sur claude.ai pour le même travail, téléchargez cette conversation du navigateur avec le bouton orange. Le journal du terminal et la conversation web ne sont pas automatiquement le même document. Considérez-les comme deux archives distinctes, sauf si vous avez collé l’un dans l’autre.

Installez Download Claude conversations, ouvrez la conversation sur claude.ai, cliquez sur le bouton orange à côté de la zone de message, choisissez PDF, Markdown, JSON, texte, XML, CSV ou PNG, puis cliquez sur « Export ». Chrome enregistre un fichier local, qui correspond à une conversation. Aucun compte n’est nécessaire, sauf pour le PDF, qui demande une connexion Google.

« Télécharger un chat Claude », est-ce la fiche du Chrome Web Store ?

La fiche s’appelle Download Claude conversations, au pluriel, parce qu’« Export All » produit de nombreux fichiers. Les recherches « télécharger chat Claude », « télécharger conversation Claude » ou, en anglais, « download claude conversation » mènent toutes à cette même fiche. Un export avec le bouton orange reste une conversation, un fichier.

Puis-je télécharger une conversation Claude sans extension ?

Oui. Imprimez la page claude.ai (Ctrl/Cmd+P → Enregistrer au format PDF) pour un instantané visuel, ou utilisez Settings → Privacy → Export data pour recevoir plus tard un ZIP JSON du compte. Le copier-coller suffit pour une réponse courte. Aucune de ces méthodes ne produit un fichier Markdown structuré par conversation comme le fait l’extension Chrome.

Un fichier correspond-il à un chat Claude téléchargé ?

Oui. Le bouton orange produit un fichier pour la conversation claude.ai ouverte. « Export All » produit un ZIP avec un fichier par ligne sélectionnée. Le ZIP Export data d’Anthropic suit la logique inverse : une archive pour tout le compte, envoyée plus tard par e-mail, et non un fichier nommé pour la conversation que vous lisiez.

Puis-je télécharger un chat Claude en PDF ?

Oui. Choisissez PDF dans le panneau du bouton orange et cliquez sur « Export ». La version 1.16.2 construit le PDF dans le navigateur, sans boîte de dialogue d’impression ; vous réglez le format de page, les marges, le mode clair ou sombre, la police, la numérotation des pages et une table des matières. Le PDF demande une connexion Google et est gratuit jusqu’à 3 par jour ; Pro est illimité. Guide : conversation Claude en PDF.

La connexion Google est-elle obligatoire pour télécharger un chat Claude ?

Seulement pour le PDF et l’export groupé « Export All ». Markdown, texte brut, JSON, XML, CSV et PNG ne demandent aucun compte. Pour le PDF et l’export groupé, Google confirme le compte choisi pour que nous puissions appliquer la limite de 3 par jour et restaurer Pro après une réinstallation. Le contenu des conversations n’est pas transmis avec cette connexion. Nous conservons l’adresse e-mail vérifiée uniquement pour le quota et le statut Pro.

Le téléchargement fonctionne-t-il dans Claude Desktop ?

Non. Download Claude conversations s’injecte uniquement sur claude.ai dans Chrome sur ordinateur. Claude Desktop n’affiche jamais le bouton orange. Ouvrez la même conversation sur claude.ai si elle est synchronisée, ou faites un copier-coller, ou utilisez l’export officiel Export data. Il n’existe pas d’application iOS ou Android.

Combien de fichiers gratuits puis-je télécharger ?

Un nombre illimité en Markdown, texte brut, JSON, XML, CSV et PNG, sans compte. Le PDF et le ZIP groupé partagent 3 par jour sur l’offre gratuite, avec une connexion Google ; chaque conversation d’un ZIP groupé compte pour une, et le compteur repart à zéro à minuit UTC. Pro coûte 3,99 $ par mois ou 26,99 $ par an et supprime la limite. Paddle traite le paiement.

L’extension télécharge-t-elle les conversations Claude Code ?

Seulement sur le web. Les sessions Claude Code sur claude.ai/code s’exportent comme n’importe quelle conversation claude.ai. Pas les sessions locales du terminal : utilisez /export ou copiez les fichiers JSONL depuis ~/.claude/projects (Windows : %USERPROFILE%\.claude\projects). Cette extension Chrome fonctionne uniquement sur claude.ai. Guide : exporter une conversation Claude Code.

Dans quels formats puis-je télécharger un chat Claude ?

Sept : PDF, Markdown, JSON, texte brut, XML, CSV et PNG, dans la version 1.16.2 de l’extension. Le PDF est construit dans le navigateur, sans boîte de dialogue d’impression. Le CSV compte une ligne par message. Le PNG est une image de la conversation. Page dédiée : formats.
