Fonctionnalités de l’extension Chrome pour exporter depuis claude.ai

Les fonctionnalités de l’extension Chrome Download Claude conversations sont : le bouton orange sur une conversation claude.ai, l’exportation groupée « Export All » (tout exporter), sept formats dont PDF et CSV, « Select » et « Copy » (sélectionner et copier), les mises en page d’artifacts, la réflexion et les réglages. Les fichiers sont générés sur votre machine. Markdown, texte, JSON, XML, CSV et PNG sont illimités et sans compte ; le PDF et le ZIP groupé sont gratuits jusqu’à 3 par jour, illimités avec Pro (3,99 $ par mois ou 26,99 $ par an).

Quelles fonctionnalités de l’extension Chrome exportent une seule conversation ?

Pour une seule conversation, la fonctionnalité centrale est le bouton orange que Download Claude conversations ajoute à côté de la zone de message sur claude.ai. Ouvrez l’URL d’une conversation, choisissez un format, puis cliquez sur « Export » (exporter) ou « Copy » (copier). Le fichier se télécharge immédiatement. Seul le PDF demande une connexion ; les six autres formats ne demandent aucun compte.

  1. Installez Download Claude conversations depuis le Chrome Web Store.
  2. Rechargez claude.ai et ouvrez une vraie URL de conversation : une conversation, une conversation de projet, une session Cowork ou Claude Code sur le web.
  3. Cliquez sur le bouton de téléchargement orange à droite de la zone de message.
  4. Choisissez les messages (« All », « Human » ou « Assistant » : tous, humain ou assistant), un format et la case « Thinking » (réflexion), ou cliquez sur « Select » pour cocher des messages précis. L’extension retient le dernier format utilisé.
  5. Cliquez sur « Export » pour télécharger le fichier, ou sur « Copy » pour le placer dans le presse-papiers. « Copy » fonctionne pour Markdown, texte, JSON, XML et CSV.

Le bouton orange n’apparaît que sur une conversation chargée. La page d’accueil vide n’a rien à analyser. Si le bouton manque, épinglez l’extension dans le menu en forme de pièce de puzzle de Chrome et actualisez claude.ai. L’extension ne s’injecte jamais dans Claude Desktop ni dans Claude Code en terminal. Si vous choisissez PDF, une fenêtre s’ouvre pour régler le nom du fichier, le format de page, les marges, le mode clair ou sombre, la police et sa taille, la numérotation des pages, une table des matières, les horodatages et un saut de page avant chaque prompt : conversation Claude en PDF.

Fichier local. Les fichiers PDF, Markdown, JSON, texte, XML, CSV et PNG sont générés dans l’onglet. Les exportations d’une conversation dans les formats autres que PDF n’envoient rien à nos serveurs. Le PDF et l’exportation groupée n’envoient que votre adresse e-mail Google, pour le décompte quotidien. Le texte des conversations ne quitte jamais votre navigateur. Quelles fonctionnalités de l’extension Chrome couvrent Export All ?

Les fonctionnalités d’exportation groupée se trouvent sur le tableau de bord (Dashboard), « View and Download All Conversations » (afficher et télécharger toutes les conversations) : recherche, filtres « All conversations » / « New » / « Updated » / « Previously exported » (toutes, nouvelles, mises à jour, déjà exportées), onglets « Chat » et « Cowork », recherche par projet et « Export All ». Export All enregistre un seul ZIP. L’offre gratuite couvre 3 conversations par jour avec connexion Google ; Pro, à 3,99 $ par mois ou 26,99 $ par an, supprime cette limite.

New désigne les conversations pas encore exportées avec Download Claude conversations. Previously exported suit celles que vous avez déjà sauvegardées, pour qu’un second Export All puisse les ignorer. L’onglet Cowork liste les sessions Cowork à côté des conversations classiques. La recherche par projet trouve les conversations d’un projet claude.ai. La recherche porte sur le nom de la conversation. Procédure complète : exportation groupée Export All.

La limite quotidienne s’applique par compte. Trois conversations par jour avec l’offre gratuite, partagées avec le PDF — pas trois par exportation groupée. Si vous sélectionnez 40 conversations alors qu’il vous en reste 3, tout le lot est bloqué, et non tronqué. Préparez votre sélection avant de cliquer sur Export All, ou passez à Pro.

Export All utilise le sélecteur « Chat format » (format des conversations) du tableau de bord, avec les sept formats, PDF compris, les cases « Chats », « Thinking », « Metadata », « Tools » et « Sources » (conversations, réflexion, métadonnées, outils et sources), ainsi que le format des artifacts. Il produit un seul ZIP avec un fichier par conversation, pas l’archive ZIP différée du compte Anthropic. Vous choisissez un format par exécution : l’extension ne mélange pas Markdown et JSON en un seul clic. Le tableau de bord permet aussi la sauvegarde et la restauration.

Quels formats les fonctionnalités de l’extension Chrome génèrent-elles ?

L’extension génère sept formats : PDF, Markdown, texte brut, JSON, XML, CSV et PNG. Markdown, texte, JSON, XML, CSV et PNG sont illimités et sans compte. Le PDF est généré dans le navigateur, demande une connexion Google et compte dans la limite de 3 par jour de l’offre gratuite. La liste est identique sur le bouton orange et dans le sélecteur « Chat format » du tableau de bord. Pages dédiées : formats d’exportation des conversations Claude.

L’équipe Download Claude conversations

Les rédacteurs choisissent généralement Markdown, les développeurs JSON. CSV donne une ligne par message pour Excel, Google Sheets ou Numbers. PNG est une image : impossible d’y rechercher du texte. Le PDF est le fichier à lire, imprimer ou envoyer, avec le format de page, les marges et une table des matières réglés dans sa fenêtre.

Les fonctionnalités de l’extension Chrome conservent-elles les artifacts ?

Oui. L’extension propose plusieurs mises en page d’artifacts : « Original », « Inline », « Nested » ou « Flat » (d’origine, intégrée, imbriquée ou à plat). Les blocs de réflexion, les étapes d’outils / MCP et les sources de recherche web sont chacun optionnels : la réflexion est une case du panneau d’export, les outils et les sources s’activent dans les réglages, et le tableau de bord propose une case pour chacun des trois. Les métadonnées peuvent ajouter le titre, les horodatages et le modèle. Le filtre par expéditeur limite le fichier à tous les messages, aux messages humains ou aux réponses de l’assistant, et « Select » permet de cocher des messages précis.

Les artifacts font partie de la conversation claude.ai. La mise en page détermine s’ils restent dans le fichier Markdown, JSON, XML ou texte, ou s’ils vont dans leur propre dossier à l’intérieur d’un ZIP. Les ZIP d’artifacts sont illimités et gratuits, tout comme le ZIP des fichiers de projet : sur la page d’un projet, cliquez sur « Project files » → « Download ZIP » (fichiers du projet → télécharger le ZIP). En PNG, les artifacts sont dessinés, pas stockés sous forme de balisage. Si la réflexion est désactivée, l’export omet la réflexion étendue même si claude.ai l’affichait à l’écran.

Si la conversation est longue, faites défiler la page jusqu’à ce que claude.ai ait chargé les messages plus anciens. L’extension ne peut exporter que ce que la page a affiché. Un DOM à moitié chargé donne un fichier tronqué : cela ressemble à un bug d’artifact manquant, mais il s’agit le plus souvent d’une conversation que l’on n’a pas fait défiler.

Quelles fonctionnalités de l’extension Chrome se trouvent dans les réglages ?

Les réglages (Settings) correspondent à la page Options de l’extension. On y trouve le modèle de nom de fichier, « Copy instead of download » (copier au lieu de télécharger), l’intégration des images dans le Markdown, les étapes d’outils / MCP, les sources de recherche web, le format de date et d’heure, la sauvegarde et la restauration, ainsi que votre abonnement. L’interface de l’extension est uniquement en anglais.

Comment les fonctionnalités de l’extension Chrome gèrent-elles la connexion ?

La plupart des fonctionnalités de l’extension ne demandent aucune connexion. Les exportations d’une conversation en Markdown, texte brut, JSON, XML, CSV et PNG sont illimitées et anonymes, tout comme « Copy », « Select », les ZIP d’artifacts et le ZIP des fichiers de projet. La connexion Google n’est demandée que pour le PDF, l’exportation groupée Export All et Pro. Le contenu des conversations ne fait jamais partie de ce processus.

Le PDF et le ZIP groupé partagent la limite de 3 par jour de l’offre gratuite, comptée sur notre serveur à partir de votre adresse e-mail Google. Le compteur se remet à zéro à minuit UTC, et une réinstallation ne le réinitialise pas. Pro coûte 3,99 $ par mois ou 26,99 $ par an via Paddle. Paddle est le revendeur officiel (merchant of record) ; notre équipe ne voit jamais les numéros de carte. Pro se restaure sur un nouvel ordinateur quand vous vous connectez avec le même compte Google.

Vous n’avez pas besoin d’un abonnement payant claude.ai d’Anthropic. Les offres Free, Pro, Team et Enterprise de claude.ai fonctionnent si Chrome peut ouvrir la conversation. Si l’administrateur de votre espace de travail bloque les extensions, Download Claude conversations ne s’injectera pas : c’est une règle du navigateur, pas une fonctionnalité manquante.

Quelles fonctionnalités ne figurent pas dans la version 1.16.2 ?

Absents de la version 1.16.2 : l’export vers Notion, l’export Word, l’envoi vers Google Docs, l’intégration à Claude Desktop et les sessions locales de Claude Code en terminal (/export, ~/.claude/projects). Download Claude conversations est un script de contenu Chrome pour claude.ai, pas une seconde application sous un autre nom. Le PDF ne fait plus partie de cette liste : il est intégré.

Claude Desktop est une application Mac/Windows. Claude Code en terminal est un agent local. Aucun des deux n’affiche le bouton orange. Claude Code sur le web (claude.ai/code) et les sessions Cowork s’ouvrent sur claude.ai : ils s’exportent donc comme n’importe quelle conversation. Si une conversation Desktop existe aussi sur claude.ai, ouvrez-la dans Chrome et utilisez-y l’extension. Pour Desktop : exporter une conversation Claude Desktop. Pour Code : exporter une conversation Claude Code.

claude.ai dans le navigateur d’un téléphone n’est pas pris en charge. Notre équipe ne propose aucune application iOS ou Android en 2026. « Copy » n’est disponible ni pour le PDF ni pour le PNG. Version datée de septembre 2026. Si nous ajoutons un format, cette page sera mise à jour le jour même.

FAQ : fonctionnalités de l’extension Chrome

Ces questions couvrent les fonctionnalités de Download Claude conversations 1.16.2 : le bouton orange, Export All, les formats, les artifacts, l’offre gratuite, Desktop et Pro. Chaque réponse est un fait sur le produit. Le JSON-LD FAQPage dans l’en-tête de la page correspond à cette liste.

Quelles fonctionnalités de l’extension Chrome exportent une seule conversation ?

Le bouton orange à côté de la zone de message, sur une URL de conversation claude.ai. Choisissez PDF, Markdown, JSON, texte, XML, CSV ou PNG, puis cliquez sur « Export » (exporter) ou « Copy » (copier). C’est le chemin le plus rapide pour une seule conversation, et seul le PDF demande une connexion.

L’extension Chrome propose-t-elle l’exportation groupée Export All ?

Oui. Le tableau de bord (« View and Download All Conversations ») liste l’historique claude.ai avec les filtres All conversations, New, Updated et Previously exported, les onglets Chat et Cowork, et une recherche par projet. « Export All » (tout exporter) enregistre un seul ZIP. L’offre gratuite couvre 3 conversations par jour avec connexion Google ; Pro est illimité.

Quels formats l’extension Chrome prend-elle en charge ?

Sept : PDF, Markdown, texte brut, JSON, XML, CSV et PNG. Le PDF est généré dans le navigateur, avec sa propre fenêtre de réglages. CSV donne une ligne par message. PNG est une image de la conversation.

L’extension Chrome exporte-t-elle les artifacts et la réflexion ?

Oui. La mise en page des artifacts est Original, Inline, Nested ou Flat, et les artifacts peuvent aller dans leur propre dossier à l’intérieur d’un ZIP. La réflexion, les étapes d’outils / MCP et les sources de recherche web sont chacune optionnelles. Les métadonnées, le filtre par expéditeur et « Select » sont facultatifs.

Peut-on essayer l’extension Chrome gratuitement ?

Oui. Les exportations Markdown, texte, JSON, XML, CSV et PNG sont illimitées et ne demandent aucun compte. Le PDF et le ZIP groupé sont limités à 3 par jour avec connexion Google. Pro, à 3,99 $ par mois ou 26,99 $ par an via Paddle, supprime cette limite.

L’extension Chrome fonctionne-t-elle avec Claude Desktop ou Claude Code ?

Pas dans Claude Desktop ni dans Claude Code en terminal. Le script de contenu ne s’injecte que sur claude.ai dans Chrome. Claude Code sur le web (claude.ai/code) et les sessions Cowork s’y exécutent : ils s’exportent donc. Ouvrez une conversation Desktop sur claude.ai si elle y existe.

L’extension Chrome envoie-t-elle mes conversations sur un serveur ?

Non. Chaque fichier, PDF compris, est créé dans le navigateur. Les exportations d’une conversation dans les autres formats n’envoient rien. Pour le PDF, l’exportation groupée ou Pro, seule votre adresse e-mail Google est envoyée, pour le décompte quotidien et l’abonnement. Consultez la page comment ça marche pour connaître la limite exacte.
