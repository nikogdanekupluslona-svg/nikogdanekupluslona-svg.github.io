Fonctionnalités de l’extension Chrome pour exporter depuis claude.ai

Les fonctionnalités de l’extension Chrome Download Claude conversations sont : le bouton orange sur une conversation claude.ai, l’exportation groupée « Export All », cinq formats, les mises en page d’artifacts, la réflexion, le filtre par expéditeur et la connexion Google pour le quota. Les fichiers restent sur votre machine. Trois exportations sont gratuites ; Pro coûte 3,99 $/mois ou 26,99 $/an. La version 1.13.0 ne génère pas de PDF.

Quelles fonctionnalités de l’extension Chrome exportent une seule conversation ?

Pour une seule conversation, la fonctionnalité centrale est le bouton orange que Download Claude conversations ajoute à côté de la zone de message sur claude.ai. Ouvrez l’URL d’une conversation, choisissez Markdown, JSON, texte, XML ou PNG, puis cliquez sur « Export » (Exporter). Le fichier se télécharge immédiatement.

  1. Installez Download Claude conversations depuis le Chrome Web Store (fiche notée 5.0).
  2. Rechargez claude.ai et ouvrez une vraie URL de conversation, pas la page d’accueil vide avec la zone de saisie.
  3. Cliquez sur le bouton de téléchargement orange à droite de la zone de message.
  4. Choisissez un format. L’extension retient le dernier format utilisé.
  5. Cliquez sur « Export ». Chrome enregistre le fichier via l’API de téléchargement du navigateur.

Le bouton orange n’apparaît que sur une conversation chargée. La page d’accueil vide n’a rien à analyser. Si le bouton manque, épinglez l’extension dans le menu en forme de pièce de puzzle de Chrome et actualisez claude.ai. L’extension ne s’injecte jamais dans Claude Desktop ni dans Claude Code.

Fichier local. Les fichiers Markdown, JSON, texte, XML et PNG sont générés dans l’onglet. Les vérifications de quota passent par notre serveur. Le texte des conversations, non. Fonctionnement détaillé : comment ça marche.

Quelles fonctionnalités de l’extension Chrome couvrent Export All ?

Les fonctionnalités d’exportation groupée se trouvent sur la page « View and Download All Conversations » (afficher et télécharger toutes les conversations) : un tableau consultable de l’historique claude.ai, les filtres All / New / Exported / Project (toutes, nouvelles, exportées, projet) et « Export All » (Tout exporter). Chaque fichier terminé compte comme l’une des 3 exportations gratuites. Pro, à 3,99 $/mois ou 26,99 $/an, supprime cette limite.

New désigne les conversations pas encore exportées avec Download Claude conversations. Exported suit celles que vous avez déjà sauvegardées, pour qu’un second Export All puisse les ignorer. Project reprend la façon dont vous regroupez vos conversations sur claude.ai. La recherche porte sur le nom de la conversation. Procédure complète : exportation groupée Export All.

Le quota s’applique à tout le compte. Trois exportations gratuites au total — pas trois par exportation groupée. Sélectionner 40 conversations consomme 40 exportations si chaque fichier aboutit. Préparez votre sélection avant de cliquer sur Export All, ou passez à Pro.

Export All utilise les mêmes options de réflexion, de métadonnées, d’expéditeur et d’artifacts que l’exportation d’une seule conversation. Il produit de nombreux fichiers individuels, pas l’archive ZIP différée d’Anthropic. Vous choisissez un format par exécution : l’extension ne mélange pas Markdown et JSON en un seul clic.

Quels formats les fonctionnalités de l’extension Chrome génèrent-elles ?

L’extension génère cinq formats : Markdown, JSON, texte brut, XML et PNG. La liste est identique sur le bouton orange et dans Export All. La version 1.13.0 ne propose pas de PDF. Chaque fichier terminé compte comme une exportation. Pages dédiées : formats d’exportation des conversations Claude.

Nous gardons volontairement un périmètre étroit : cinq types de fichiers à partir de la conversation claude.ai déjà affichée, plus l’exportation groupée Export All et les options qui modifient le contenu de ces fichiers. Nous ne proposons toujours ni PDF, ni Notion, ni Word. Si cela change, cette page sera mise à jour le jour même.

L’équipe Download Claude conversations

Les rédacteurs choisissent généralement Markdown, les développeurs JSON. PNG est une image : impossible d’y rechercher du texte. Imprimez depuis Chrome si vous avez besoin d’une page proche d’un PDF. Cette impression est une fonction du navigateur, pas de l’extension.

Les fonctionnalités de l’extension Chrome conservent-elles les artifacts ?

Oui. L’extension propose plusieurs mises en page d’artifacts : « Original », « Inline », « Nested » ou « Flat » (d’origine, intégrée, imbriquée ou à plat). Les blocs de réflexion sont une option pour garder la trace d’une recherche. Les métadonnées peuvent ajouter le titre, les horodatages et le modèle. Le filtre par expéditeur limite le fichier à « all / human only / assistant only » (tous, humain uniquement, assistant uniquement).

Les artifacts font partie de la conversation claude.ai ; ils ne se téléchargent pas séparément. La mise en page change leur place dans les fichiers Markdown, JSON, XML et texte. En PNG, ils sont dessinés, pas stockés sous forme de balisage. Si la réflexion est désactivée, l’export omet la réflexion étendue même si claude.ai l’affichait à l’écran.

Si la conversation est longue, faites défiler la page jusqu’à ce que claude.ai ait chargé les messages plus anciens. L’extension ne peut exporter que ce que la page a affiché. Un DOM à moitié chargé donne un fichier tronqué : cela ressemble à un bug d’artifact manquant, mais il s’agit le plus souvent d’une conversation que l’on n’a pas fait défiler.

Comment les fonctionnalités de l’extension Chrome gèrent-elles la connexion ?

La connexion Google est requise dès la première exportation. L’extension s’en sert pour compter les 3 exportations gratuites par compte et pour restaurer Pro après une réinstallation. Le contenu des conversations ne fait jamais partie de ce processus. Download Claude conversations enregistre une adresse e-mail vérifiée par Google pour le quota et l’état de l’abonnement.

Les 3 exportations gratuites ne se réinitialisent pas quand vous réinstallez l’extension. C’est tout l’intérêt de la connexion. Pro coûte 3,99 $ par mois ou 26,99 $ par an via Paddle. Paddle est le revendeur officiel (merchant of record) ; notre équipe ne voit jamais les numéros de carte. Pro se restaure sur un nouvel ordinateur avec le même compte Google.

Vous n’avez pas besoin d’un abonnement payant claude.ai d’Anthropic. Les offres Free, Pro, Team et Enterprise de claude.ai fonctionnent si Chrome peut ouvrir la conversation. Si l’administrateur de votre espace de travail bloque les extensions, Download Claude conversations ne s’injectera pas : c’est une règle du navigateur, pas une fonctionnalité manquante.

Quelles fonctionnalités ne figurent pas dans la version 1.13.0 ?

Absents de la version 1.13.0 : le PDF natif, l’export vers Notion, l’export Word, l’envoi vers Google Docs, l’intégration à Claude Desktop et le /export de Claude Code. Download Claude conversations est un script de contenu Chrome pour claude.ai, pas une seconde application sous un autre nom.

Claude Desktop est une application Mac/Windows. Claude Code est l’agent en ligne de commande. Aucun des deux n’affiche le bouton orange. Si la conversation existe aussi sur claude.ai, ouvrez-la dans Chrome et utilisez-y l’extension. Pour Desktop : exporter une conversation Claude Desktop. Pour Code : exporter une conversation Claude Code.

claude.ai dans le navigateur d’un téléphone n’est pas pris en charge. Notre équipe ne propose aucune application iOS ou Android en 2026. Version datée de septembre 2026. FAQ : fonctionnalités de l’extension Chrome

Ces questions couvrent les fonctionnalités de Download Claude conversations 1.13.0 : le bouton orange, Export All, les formats, les artifacts, le quota, Desktop et Pro. Chaque réponse est un fait sur le produit. Le JSON-LD FAQPage dans l’en-tête de la page correspond à cette liste.

Quelles fonctionnalités de l’extension Chrome exportent une seule conversation ?

Le bouton orange à côté de la zone de message, sur une URL de conversation claude.ai. Choisissez Markdown, JSON, texte, XML ou PNG, puis cliquez sur « Export » (Exporter). C’est le chemin le plus rapide pour une seule conversation.

L’extension Chrome propose-t-elle l’exportation groupée Export All ?

Oui. « View and Download All Conversations » (afficher et télécharger toutes les conversations) liste l’historique claude.ai avec les filtres All, New, Exported et Project. « Export All » (Tout exporter) crée un fichier par conversation sélectionnée. Chaque fichier compte comme l’une des 3 exportations gratuites, sauf avec Pro.

Quels formats l’extension Chrome prend-elle en charge ?

Markdown, JSON, texte brut, XML et PNG. Il n’y a pas de PDF. PNG est une image. Imprimez l’onglet claude.ai dans Chrome si vous avez besoin d’une page proche d’un PDF.

L’extension Chrome exporte-t-elle les artifacts et la réflexion ?

Oui. La mise en page des artifacts est Original, Inline, Nested ou Flat. La réflexion (thinking) est une option à activer. Les métadonnées et le filtre par expéditeur sont facultatifs. Les mêmes options s’appliquent à Export All.

Peut-on essayer l’extension Chrome gratuitement ?

Oui. Chaque compte connecté avec Google dispose de 3 exportations gratuites, dans n’importe quel format. Pro coûte 3,99 $/mois ou 26,99 $/an via Paddle pour davantage de fichiers, individuels ou groupés.

L’extension Chrome fonctionne-t-elle avec Claude Desktop ou Claude Code ?

Non. Le script de contenu ne s’injecte que sur claude.ai dans Chrome. Claude Desktop et Claude Code n’affichent jamais le bouton orange. Ouvrez la même conversation sur claude.ai si elle y existe.

L’extension Chrome envoie-t-elle mes conversations sur un serveur ?

Non. Les fichiers sont créés dans le navigateur. La connexion Google enregistre une adresse e-mail vérifiée pour le quota et la restauration de Pro. Le contenu des conversations n’est pas envoyé à notre serveur. Consultez la page comment ça marche pour connaître la limite exacte.
