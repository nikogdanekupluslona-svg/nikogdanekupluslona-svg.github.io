Comment télécharger une conversation Claude avec Chrome ?

La réponse directe, c’est le bouton orange que Download Claude conversations ajoute à côté de la zone de message sur claude.ai. Ouvrez la conversation, choisissez PDF, Markdown, JSON, texte, XML, CSV ou PNG, puis cliquez sur « Export » (exporter). Le fichier est assemblé dans votre navigateur et enregistré sur le disque.

L’extension est un script de contenu Chrome. Elle lit la conversation déjà chargée dans votre session claude.ai connectée. Elle n’appelle pas une API Anthropic distincte avec ses propres identifiants et n’envoie pas la conversation sur nos serveurs pour générer le fichier.

  1. Installez Download Claude conversations depuis le Chrome Web Store (les navigateurs Chromium qui acceptent les extensions Chrome fonctionnent aussi).
  2. Rechargez claude.ai si la page était déjà ouverte pendant l’installation.
  3. Ouvrez l’URL de la conversation voulue : le bouton orange n’apparaît que sur une vraie conversation, pas sur la page d’accueil vide.
  4. Cliquez sur le bouton orange de téléchargement, à droite de la zone de message. Un panneau s’ouvre avec Messages (« All / Human / Assistant », soit tous, humain, assistant), Format, « Thinking » (réflexion), « Select » (sélectionner), « Copy » (copier) et « Export ».
  5. Choisissez PDF, Markdown, texte brut, JSON, XML, CSV ou PNG. Cliquez sur « Export ». Chrome télécharge le fichier immédiatement.

Aucun compte n’est nécessaire pour Markdown, texte brut, JSON, XML, CSV ou PNG. Ces exports d’une conversation sont illimités et gratuits : pas de connexion, pas de compteur. La connexion Google n’apparaît que si vous choisissez le PDF ou lancez un export groupé avec « Export All » (tout exporter). Ce n’est pas un accès à vos conversations. Leur contenu reste sur votre machine.

Le PDF et le ZIP groupé partagent un quota gratuit de 3 par jour, remis à zéro à minuit UTC. Chaque conversation d’un ZIP groupé compte pour une. Pro coûte 3,99 $ par mois ou 26,99 $ par an et supprime cette limite. Options et étapes du PDF : télécharger une conversation Claude en PDF.

Fichiers locaux. Tous les formats, PDF compris, sont générés dans le navigateur puis transmis à l’API de téléchargement de Chrome. Le texte des conversations n’est jamais envoyé. Seuls les exports PDF et groupés envoient une vérification de quota avec votre adresse Google.

Le même panneau filtre par auteur : All, Human ou Assistant. La case « Thinking » inclut ou ignore la réflexion étendue. « Select » permet de cocher des messages précis pour que le fichier ne contienne que ces échanges. « Copy » place du Markdown, du texte, du JSON, du XML ou du CSV dans le presse-papiers au lieu de télécharger un fichier. Les étapes d’outils / MCP et les sources de recherche web s’activent dans les paramètres (Settings). Les métadonnées et la mise en page des artefacts (« Original », « Inline », « Nested » ou « Flat ») se règlent dans le tableau de bord (Dashboard).

Si la conversation est très longue, faites défiler jusqu’à ce que claude.ai ait chargé les messages plus anciens. L’extension ne peut exporter que ce que la page a affiché. Une conversation à moitié chargée donne un fichier à moitié rempli : cela ressemble à un bug, mais c’est presque toujours une page qui n’a pas été défilée.

Nous analysons l’arborescence des messages sur la page claude.ai que vous avez déjà ouverte. Les blocs de code gardent leur langage et leur indentation ; les tableaux restent des tableaux. Le PDF est construit à partir de cette même arborescence, dans le navigateur, sans boîte de dialogue d’impression : un fichier imprimable n’est plus une capture de la page web.

Peut-on télécharger une conversation Claude sans extension ?

Oui. Sans extension, vous pouvez imprimer la page ou demander l’export du compte à Anthropic. L’impression donne un PDF visuel de la page web. Export data fournit, avec un délai, un ZIP JSON de tout le compte. Aucune des deux méthodes ne produit un fichier Markdown par conversation.

Par l’impression : ouvrez la conversation sur claude.ai, masquez la barre latérale si l’interface le permet, appuyez sur Ctrl+P (Windows/Linux) ou Cmd+P (Mac), choisissez « Enregistrer au format PDF » comme destination, puis enregistrez. Les blocs de code se coupent souvent entre deux pages, et la zone de saisie peut apparaître sur chaque feuille. L’export PDF de l’extension évite cette boîte de dialogue. Les deux méthodes sont comparées ici : enregistrer une conversation Claude en PDF.

Par la voie officielle : Settings → Privacy → Export data sur claude.ai (les libellés peuvent être traduits si claude.ai est en français). Anthropic envoie par e-mail un lien qui expire. Le ZIP est une archive JSON du compte entier, pas un fichier nommé pour la conversation que vous lisiez. Utilisez-le comme sauvegarde, puis décompressez-le vous-même si vous avez besoin d’une conversation parmi des milliers.

Le copier-coller est une troisième méthode sans extension. Sélectionnez le texte, collez-le dans Docs ou une application de notes. L’indentation du code disparaît généralement. Les tableaux deviennent des lignes continues. Une conversation à plusieurs tours devient un bloc sans structure. Suffisant pour une réponse courte, insuffisant pour une revue de code que vous voudrez retrouver plus tard. Le bouton « Copy » de l’extension place plutôt un Markdown propre dans le presse-papiers.

Comment télécharger tout l’historique Claude d’un coup ?

Pour télécharger votre historique Claude en plusieurs fichiers, ne répétez pas le bouton orange onglet par onglet. Ouvrez « View and Download All Conversations » (afficher et télécharger toutes les conversations) depuis la fenêtre de l’extension, filtrez le tableau, puis cliquez sur « Export All ». « Export All » demande une connexion Google. Sur l’offre gratuite, chaque conversation du ZIP consomme l’un des 3 créneaux quotidiens partagés avec le PDF. Pro supprime la limite.

Le tableau de bord liste les conversations du compte claude.ai auquel vous êtes connecté. Cherchez par nom. Filtrez par « All conversations » (toutes), « New » (nouvelles), « Updated » (mises à jour) ou « Previously exported » (déjà exportées). Passez de l’onglet Chat à l’onglet Cowork, et cherchez par projet si vous organisez vos conversations ainsi sur claude.ai. Sélectionnez un sous-ensemble si vous ne voulez pas tous les vieux brouillons dans le dossier.

L’export groupé produit un seul ZIP, avec un fichier par conversation, dans le format choisi via le sélecteur « Chat format » (format des conversations) : n’importe lequel des sept, PDF compris. Il utilise le même analyseur qu’un export unique. Des cases à cocher définissent le contenu (« Chats », « Thinking », « Metadata », « Tools », « Sources », soit conversations, réflexion, métadonnées, outils, sources), ainsi que la mise en page des artefacts. « Export All » n’est pas une version allégée : c’est le même analyseur appliqué à de nombreuses conversations en une seule passe. Détails et captures : exporter tout l’historique avec Export All.

Export data d’Anthropic reste la sauvegarde du compte : un ZIP, un e-mail, du JSON pour tout, y compris les conversations oubliées. « Export All » répond au besoin inverse : vous choisissez les conversations, vous choisissez le format, et le ZIP arrive immédiatement. Utilisez les deux si vous voulez à la fois une archive complète et un dossier de notes lisibles.

Le quota est commun et quotidien. Sur l’offre gratuite, les exports PDF et les conversations exportées en groupe partagent 3 par jour, remis à zéro à minuit UTC. Sélectionnez 40 conversations et tout le lot est bloqué, sans être coupé en cours de route. Choisissez-en moins, ou passez à Pro pour 3,99 $ par mois ou 26,99 $ par an.

Le tableau de bord mémorise aussi ce que vous avez déjà exporté : lors d’une visite suivante, vous pouvez filtrer sur New ou Updated uniquement. C’est ainsi qu’un téléchargement hebdomadaire de l’historique reste incrémental au lieu de dupliquer les fichiers Markdown du mois dernier.

Comment télécharger une conversation Claude en Markdown ou JSON ?

Cliquez sur le bouton orange, choisissez le format, puis « Export ». Markdown est le fichier de notes. JSON est l’arborescence des messages pour vos scripts. Le texte brut n’a aucun balisage. Le CSV compte une ligne par message. Le PDF est un document paginé. Le PNG est une image.

Markdown conserve les titres, les blocs de code avec leur langage et les tableaux. C’est le choix habituel pour Obsidian, GitHub ou un wiki. JSON conserve l’arborescence construite par l’analyseur, y compris les artefacts et la réflexion quand ces options sont activées. Sa structure diffère de celle du ZIP de compte d’Anthropic. Notes sur les formats : tous les formats.

Le texte brut convient quand la destination supprime de toute façon le balisage : un champ de ticket, le corps d’un e-mail, un index de recherche qui attend du texte simple. XML est le choix de niche pour l’échange de données. Le CSV s’ouvre dans Excel, Google Sheets ou Numbers. Le PNG sert pour une diapositive ou une capture dans un rapport de bug, pas pour une revue de conception de 40 échanges dans laquelle vous ferez des recherches.

Sauvegarder une conversation Claude : fichier, impression ou ZIP ?

Sauvegarder, télécharger et exporter désignent la même tâche sur claude.ai : sortir la conversation de la page. Pour sauvegarder une conversation Claude dans un fichier exploitable, PDF compris, utilisez l’extension. L’impression donne un instantané. Export data d’Anthropic donne un ZIP du compte.

Les équipes mélangent souvent ces mots. Une chercheuse dit sauvegarder, un développeur dit exporter, un responsable dit télécharger. Sur ce site, ces trois verbes mènent au même bouton orange quand vous êtes sur claude.ai dans Chrome. Le guide voisin comment exporter une conversation Claude détaille le ZIP officiel et les structures JSON.

L’impression garde son utilité : une pièce jointe ponctuelle qui doit ressembler exactement à l’écran de claude.ai. Export data aussi : un départ d’entreprise, une conservation légale ou une sauvegarde de sécurité. Aucune des deux ne remplace un fichier Markdown que vous modifierez la semaine prochaine.

Claude Desktop est une autre fenêtre. L’extension Chrome ne s’injecte pas dans l’application Desktop. Si la même conversation existe sur claude.ai, ouvrez-la là et téléchargez-la. Si elle n’existe que dans Desktop, faites un copier-coller ou attendez le ZIP du compte. Étapes : exporter une conversation Claude Desktop.

Paddle traite les paiements Pro. Nous ne voyons pas les numéros de carte. La connexion Google, utilisée uniquement pour le PDF, l’export groupé et Pro, ne nous donne pas accès aux conversations. Le serveur Cloudflare qui vérifie le quota et le statut Pro reçoit votre adresse Google, pas le texte des messages. Les autres exports d’une conversation n’envoient rien. Toute la confidentialité tient dans cette séparation : la facturation sur le serveur, les conversations sur votre disque.

Pourquoi le bouton de téléchargement n’apparaît-il pas ?

Le bouton orange est absent quand vous n’êtes pas sur l’URL d’une conversation, que l’onglet n’a pas été rechargé après l’installation ou que l’extension est désactivée. Épinglez l’icône, rechargez, et vérifiez que vous êtes bien dans Chrome sur ordinateur, sur claude.ai : pas dans Desktop, sur un téléphone ou dans un terminal Claude Code.

Après l’installation, Chrome n’injecte pas toujours le script de contenu dans les onglets déjà ouverts. Fermez l’onglet claude.ai ou rechargez-le complètement. Si vous utilisez plusieurs profils, l’extension doit être installée dans le profil connecté à Anthropic.

Les espaces Team et Enterprise fonctionnent si vous pouvez ouvrir la conversation dans le navigateur. L’extension lit la page, pas le niveau d’abonnement. Si votre organisation bloque les extensions Chrome, le service informatique doit autoriser celle-ci ; nous ne pouvons pas contourner cette règle depuis le site.

Demande de connexion : elle n’est normale que pour le PDF et « Export All ». Markdown, texte, JSON, XML, CSV et PNG s’exportent sans compte. Le premier export PDF ou groupé demande une connexion Google. Si vous l’annulez, cela ressemble à un téléchargement raté. Terminez la connexion, puis cliquez de nouveau sur « Export ». Aucune carte bancaire n’est demandée sur l’offre gratuite.

Fichier incomplet : la réponse n’avait pas fini de s’afficher, ou les anciens échanges n’étaient pas encore chargés hors de l’écran. Attendez que l’assistant ait terminé. Faites défiler vers le début d’une longue conversation pour que claude.ai charge ces messages, puis exportez de nouveau. Refaire un export Markdown ou JSON ne coûte rien. Refaire un PDF consomme un autre des 3 créneaux quotidiens de l’offre gratuite, d’où l’intérêt de vérifier d’abord que tout est chargé.

Mauvais type de fichier : le dernier format utilisé était encore sélectionné. Mauvais compte : vous vous êtes connecté à Google avec une autre adresse que celle qui détient Pro. La restauration de Pro est liée à cette adresse Google, ni à la connexion Anthropic, ni au nom du profil Chrome.

Les navigateurs mobiles n’exécutent pas cette extension. Il n’existe pas d’application iOS ou Android. Safari sur téléphone peut imprimer, mais ne peut pas afficher le bouton orange. Pour un fichier réutilisable, ouvrez la même conversation dans Chrome sur ordinateur.

L’extension télécharge-t-elle les conversations Claude Code ?

Seulement depuis Claude Code sur le web. Les sessions sur claude.ai/code s’ouvrent dans Chrome : Download Claude conversations les exporte comme n’importe quelle conversation. Une session Claude Code locale, dans le terminal, c’est autre chose. Pour l’exporter, utilisez /export ou le fichier JSONL dans ~/.claude/projects. Interfaces différentes, fichiers différents.

Dans une session Claude Code active, tapez /export. L’outil en ligne de commande d’Anthropic ouvre un menu pour copier la transcription ou l’enregistrer dans un fichier texte. Indiquez un nom de fichier pour passer le menu. Cette transcription est un texte destiné à être lu, pas le Markdown, le JSON ou le PDF de cette extension. Chemins complets : exporter une conversation Claude Code.

Le JSONL sur le disque est le journal interne. Son schéma peut changer d’une version de Claude Code à l’autre. La documentation d’Anthropic recommande d’utiliser /export ou les interfaces de script plutôt que d’analyser le JSONL. Nous n’encapsulons pas cet outil et ne lisons pas ~/.claude.

Si vous menez en parallèle une conversation sur claude.ai pour le même travail, téléchargez-la avec le bouton orange. Le journal du terminal et la conversation web ne sont pas automatiquement le même document. Considérez-les comme deux archives distinctes, sauf si vous avez collé l’un dans l’autre.

FAQ : télécharger une conversation Claude

Comment télécharger une conversation Claude dans Chrome ?

Installez Download Claude conversations, ouvrez la conversation sur claude.ai, cliquez sur le bouton orange à côté de la zone de message, choisissez PDF, Markdown, JSON, texte, XML, CSV ou PNG, puis cliquez sur « Export ». Le fichier est téléchargé localement. Aucun compte n’est nécessaire, sauf pour le PDF, qui demande une connexion Google.

Puis-je télécharger une conversation Claude sans extension ?

Oui. Imprimez la page (Ctrl/Cmd+P → Enregistrer au format PDF) pour une copie visuelle, ou utilisez Settings → Privacy → Export data pour recevoir plus tard un ZIP JSON de votre compte. Le copier-coller suffit pour une réponse courte. Aucune de ces méthodes ne produit un fichier Markdown structuré par conversation comme le fait l’extension Chrome.

Comment télécharger l’historique de mes conversations Claude ?

Pour une conversation, utilisez le bouton orange. Pour de nombreux fichiers, ouvrez « View and Download All Conversations » depuis la fenêtre de l’extension et cliquez sur « Export All ». L’export groupé demande une connexion Google et compte dans les 3 par jour de l’offre gratuite. Cet export groupé n’est pas le ZIP Export data d’Anthropic : l’export officiel est une archive unique de tout le compte, envoyée plus tard par e-mail. Voir l’export de l’historique.

Faut-il payer pour télécharger une conversation Claude ?

Non. Les exports Markdown, texte brut, JSON, XML, CSV et PNG sont illimités et gratuits, sans compte. Le PDF et le ZIP groupé sont gratuits jusqu’à 3 par jour avec une connexion Google ; chaque conversation d’un ZIP groupé compte pour une. Pro coûte 3,99 $ par mois ou 26,99 $ par an et supprime cette limite. Paddle traite le paiement.

Download Claude conversations fonctionne-t-elle sur mobile ?

Non. C’est une extension pour Chrome sur ordinateur (ou un autre navigateur Chromium capable d’installer des extensions du Chrome Web Store). Il n’existe pas d’application iOS ou Android. Les navigateurs mobiles peuvent toujours imprimer une conversation Claude, mais ils ne peuvent pas exécuter cette extension.

Mon compte Anthropic risque-t-il d’être suspendu ?

Nous ne pouvons pas donner de conseil juridique. L’extension lit la page claude.ai que vous avez déjà chargée dans votre propre session. Elle n’appelle pas Anthropic avec d’autres identifiants et n’automatise aucun clic sur votre compte. Nous ne sommes pas Anthropic. Respectez leurs conditions d’utilisation et les règles de votre employeur.

Comment enregistrer une conversation Claude dans un fichier ?

Utilisez l’extension Chrome pour obtenir un fichier propre de la conversation ouverte, PDF compris. Imprimez pour un instantané de la page web. Utilisez Export data d’Anthropic pour un ZIP de tout le compte. Sauvegarder, télécharger et exporter désignent la même tâche sur claude.ai : sortir la conversation de l’écran.

Cela fonctionne-t-il pour les sessions Claude Code ?

Seulement sur le web. Les sessions Claude Code sur claude.ai/code s’exportent comme n’importe quelle conversation claude.ai. Pas les sessions locales du terminal : utilisez /export ou copiez les fichiers JSONL depuis ~/.claude/projects (Windows : %USERPROFILE%\.claude\projects). Cette extension Chrome fonctionne uniquement sur claude.ai. Guide : exporter une conversation Claude Code.

La connexion Google est-elle obligatoire pour télécharger une conversation Claude ?

Non, pas pour Markdown, texte brut, JSON, XML, CSV ou PNG. La connexion Google n’est requise que pour le PDF, l’export groupé « Export All » et Pro, afin d’appliquer la limite de 3 par jour et de restaurer Pro après une réinstallation. Le contenu des conversations n’est pas transmis avec cette connexion. Nous conservons l’adresse e-mail vérifiée uniquement pour le quota et le statut Pro.

Dans quels formats puis-je télécharger une conversation Claude ?

Sept : PDF, Markdown, JSON, texte brut, XML, CSV et PNG, dans la version 1.16.2 de l’extension. Le PDF est construit dans le navigateur, sans boîte de dialogue d’impression. Le CSV compte une ligne par message. Le PNG est une image de la conversation. Page dédiée : formats.

Puis-je exporter depuis un espace Team ou Enterprise ?

Oui, si vous pouvez ouvrir la conversation sur claude.ai dans Chrome. L’extension travaille à partir de la page affichée, pas d’une API réservée aux comptes grand public. Si une règle d’entreprise bloque les extensions, c’est une décision du service informatique, pas un réglage lié à l’offre dans nos paramètres.
