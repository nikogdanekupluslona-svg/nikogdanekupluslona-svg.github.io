À propos

Download Claude conversations est une extension Chrome indépendante (nom du site : Chat Downloader). Les moteurs de recherche et les utilisateurs l’appellent aussi Claude Chat Downloader et Claude Conversation Downloader. Elle n’est ni développée, ni affiliée, ni approuvée par Anthropic, PBC — Claude est une marque d’Anthropic. Nous l’avons créée pour combler un manque de claude.ai : il n’existe aucun moyen intégré de télécharger une seule conversation sous forme de fichier.

L’extension ajoute un bouton d’exportation à claude.ai ainsi qu’une page de consultation pour les exportations groupées, et génère des fichiers Markdown, JSON, texte brut, XML ou PNG en local, dans votre navigateur. Chaque compte dispose de 3 exportations gratuites ; Pro supprime la limite. Tous les détails dans comment ça marche. Elle n’exporte pas les sessions de terminal Claude Code.

Fiche Chrome Web Store (à garder synchronisée)

Utilisez ce texte dans le Chrome Web Store pour que l’extrait affiché dans la boutique corresponde aux recherches des utilisateurs :

  • Nom (≤ 75 caractères) : Claude Chat Downloader
  • Description courte (≤ 132 caractères) : Free Chrome extension to save claude.ai chats as Markdown, JSON, text, XML, or PNG — one conversation or bulk Export All.

Conservez l’identifiant existant ljcgfcnobiealkonbknnfckhkdbodhak. Un changement de nom dans la boutique peut nécessiter un cycle de validation ; les titres du site correspondent déjà à la requête de recherche.
