Comment exporter une conversation Claude depuis claude.ai ?

Ouvrez la conversation sur claude.ai dans Chrome, cliquez sur le bouton orange à côté de la zone de message, choisissez PDF, Markdown, JSON, texte brut, XML, CSV ou PNG, puis cliquez sur « Export ». Download Claude conversations écrit ce fichier en local. En septembre 2026, claude.ai ne propose lui-même aucune commande native pour exporter une conversation.

  1. Installez Download Claude conversations depuis le Chrome Web Store.
  2. Rechargez claude.ai et ouvrez l’URL d’une vraie conversation, pas la page d’accueil vide.
  3. Cliquez sur le bouton orange rond de téléchargement, à droite de la zone de message.
  4. Dans le panneau, réglez « Messages » sur « All », « Human » ou « Assistant » (tous, humain ou assistant), puis choisissez un format. Cochez « Thinking » (réflexion) pour inclure la réflexion étendue, ou utilisez « Select » (sélectionner) pour cocher des messages précis. L’extension d’export Claude mémorise le dernier format utilisé.
  5. Cliquez sur « Export ». Chrome enregistre immédiatement le fichier via l’API de téléchargement du navigateur. « Copy » (copier) place plutôt le Markdown, le texte, le JSON, le XML ou le CSV dans le presse-papiers.

Aucun compte n’est nécessaire pour exporter une conversation Claude en Markdown, texte, JSON, XML, CSV ou PNG. Ces exports sont illimités, et l’extension n’envoie rien à nos serveurs pour eux. La connexion Google n’apparaît que si vous choisissez le PDF ou lancez l’export groupé « Export All » : l’offre gratuite en autorise 3 par jour au total, avec une remise à zéro à minuit UTC. Le texte des conversations ne fait jamais partie de cette connexion. Fonctionnement détaillé : comment ça marche.

Si le bouton orange est absent, vous n’êtes pas sur l’URL d’une conversation, l’onglet doit être rechargé après l’installation, ou l’icône de l’extension est encore cachée dans le menu en forme de pièce de puzzle de Chrome. Épinglez Download Claude conversations, puis actualisez claude.ai. L’extension d’export Claude s’injecte uniquement sur claude.ai, jamais sur d’autres sites.

Une conversation ou tout le compte. Le bouton orange exporte la conversation ouverte. Pour de nombreux fichiers, ouvrez « View and Download All Conversations » (afficher et télécharger toutes les conversations) depuis la fenêtre de l’extension et lancez « Export All » (tout exporter) : voir exporter tout l’historique avec Export All. Settings → Privacy → Export data d’Anthropic (les libellés peuvent être traduits si claude.ai est en français) fournit un ZIP différé du compte, ce n’est pas ce parcours.

Que fait concrètement une extension d’export Claude ?

Une extension d’export Claude lit la conversation déjà affichée dans votre onglet claude.ai connecté et écrit un fichier structuré sur le disque. Download Claude conversations est ce script de contenu Chrome : auteur, arborescence des messages, blocs de code, tableaux, réflexion en option et mise en page des artefacts. Pas une capture de l’interface autour de la conversation. Elle fonctionne avec les conversations classiques, les projets, les sessions Cowork et Claude Code sur le web.

Le copier-coller depuis claude.ai supprime l’indentation et écrase les tableaux. L’impression (Ctrl/Cmd+P) garde la barre latérale et coupe souvent un long bloc de code entre deux pages. L’extension d’export Claude conserve le langage des blocs de code et garde les tableaux sous forme de tableaux en Markdown, JSON et XML. Le PNG est l’option d’instantané visuel. Le PDF est l’option paginée, générée dans le navigateur sans boîte de dialogue d’impression.

La mise en page des artefacts est une vraie option dans la version 1.16.2 : « Original », « Inline », « Nested » ou « Flat » (original, intégré, imbriqué ou à plat), à régler dans le tableau de bord. La réflexion étendue est une case à cocher du panneau d’export ; les sources de recherche web et les étapes d’outils / MCP s’activent dans les paramètres. Les métadonnées (titre, horodatages, modèle) peuvent être ajoutées. Le filtre « Messages » limite le fichier à tous les messages, aux messages humains seuls ou à ceux de l’assistant seul, et « Select » permet de cocher des messages précis. Liste complète : fonctionnalités.

Nous avons conçu le bouton orange pour écrire un vrai fichier à partir de la conversation déjà ouverte sur claude.ai (PDF, Markdown, JSON, texte, XML, CSV ou PNG) sans envoyer la conversation sur nos serveurs. La version 1.16.2 génère aussi le PDF dans le navigateur.

Dans quel format exporter une conversation Claude ?

Exportez une conversation Claude en PDF pour la partager ou l’imprimer, en Markdown pour vos notes, en JSON pour vos scripts, en texte brut pour une archive dépouillée, en XML pour l’échange de données, en CSV pour un tableur ou en PNG pour une image de la conversation. Download Claude conversations propose ces sept formats dans une seule liste déroulante.

Les rédacteurs exportent généralement en Markdown, les développeurs choisissent plutôt JSON. Si vous avez besoin d’un document paginé, choisissez PDF : sa boîte de dialogue règle le format de page, les marges, le mode clair ou sombre, la police, les numéros de page et une table des matières. Marche à suivre : télécharger une conversation Claude en PDF. Un PNG produit par l’extension d’export Claude est une seule image, pas un document paginé.

C’est le format qui détermine si une limite s’applique. Markdown, texte, JSON, XML, CSV et PNG sont illimités, sans compte. Le PDF demande une connexion Google et compte dans les 3 exports par jour de l’offre gratuite, partagés avec l’export groupé « Export All ». Pro, à 3,99 $ par mois ou 26,99 $ par an, supprime cette limite. Download Claude conversations n’ajoute pas d’export vers Notion, Word ou Google Docs dans la version 1.16.2.

Peut-on tout exporter d’un coup avec Export All ?

Oui. Ouvrez « View and Download All Conversations » depuis la fenêtre de l’extension, filtrez le tableau, puis cliquez sur « Export All » pour obtenir un ZIP. L’export groupé demande une connexion Google. Avec l’offre gratuite, il partage 3 exports par jour avec le PDF, et chaque conversation du ZIP en utilise un. Pro supprime la limite pour tout l’historique.

Le tableau de bord liste l’historique claude.ai, avec une recherche par nom, des filtres (« All conversations », « New », « Updated », « Previously exported » : toutes, nouvelles, mises à jour, déjà exportées), les onglets « Chat » et « Cowork » et une recherche par projet. New signifie « pas encore exportée avec Download Claude conversations ». Previously exported suit les conversations déjà enregistrées, pour qu’un second « Export All » puisse les ignorer. La recherche par projet reprend la façon dont vous regroupez vos conversations sur claude.ai.

L’export groupé propose un sélecteur « Chat format » (format des conversations) avec les sept formats, PDF compris, les cases « Chats », « Thinking », « Metadata », « Tools » et « Sources » (conversations, réflexion, métadonnées, outils, sources) et la mise en page des artefacts (« Original », « Inline », « Nested », « Flat »). « Export All » n’est pas une archive allégée : c’est un seul ZIP, avec un fichier par conversation dans le format choisi. Si vous vouliez une seule archive différée de tout le compte, c’est Export data d’Anthropic, comparé dans la section suivante et sur la page d’export de l’historique.

L’export groupé compte par conversation. Avec l’offre gratuite, « Export All » et le PDF partagent 3 exports par jour, et chaque conversation du ZIP en utilise un. Sélectionnez 40 conversations alors qu’il vous en reste 3 : tout le lot est bloqué, pas tronqué. Choisissez-en moins, attendez la remise à zéro de minuit UTC, ou passez à Pro pour 3,99 $ par mois ou 26,99 $ par an.

L’export fonctionne-t-il dans Desktop ou Claude Code ?

Pas dans l’application Desktop ni dans le terminal Claude Code. Cette extension d’export Claude fonctionne uniquement sur claude.ai dans Chrome (ou un autre navigateur Chromium capable de charger la fiche). Claude Desktop est une application Mac/Windows distincte : le bouton orange n’y apparaît jamais, pas plus que dans un terminal. Claude Code sur le web (claude.ai/code) fait exception : ces sessions s’ouvrent sur claude.ai et s’exportent comme n’importe quelle conversation.

Si la conversation existe aussi sur votre compte claude.ai, ouvrez-la dans Chrome et exportez-la avec Download Claude conversations. Si elle n’existe que dans Desktop, faites un copier-coller depuis l’application ou demandez Settings → Privacy → Export data sur le web. Comparaison pas à pas : exporter une conversation Claude Desktop.

Claude Code dans le terminal utilise /export ou des transcriptions JSONL sur le disque. Cette extension Chrome ne lit pas ces sessions locales. N’installez pas Download Claude conversations en espérant une intégration au terminal. Guide : exporter une conversation Claude Code. Exporter une session en ligne de commande relève d’un autre produit.

claude.ai dans un navigateur de téléphone n’est pas pris en charge non plus. L’extension d’export Claude nécessite Chrome sur ordinateur. Notre équipe ne propose pas d’application iOS ou Android en 2026. Ouvrez la conversation sur un ordinateur, puis exportez-la avec le bouton orange ou « Export All ».

Exporter une conversation ou utiliser Export data d’Anthropic ?

Export data d’Anthropic envoie par e-mail, après un délai, un ZIP JSON de tout le compte. Exporter une conversation Claude avec Download Claude conversations enregistre immédiatement la conversation ouverte en PDF, Markdown, JSON, texte, XML, CSV ou PNG. Le ZIP sert de sauvegarde ; l’extension d’export Claude, à obtenir tout de suite un fichier lisible.

Vous ne pouvez ni choisir une conversation ni demander du Markdown dans cette demande. Le script de contenu utilise la session déjà ouverte sur claude.ai ; il ne se connecte pas à Anthropic avec d’autres identifiants. Respectez les règles d’Anthropic pour votre compte.

Combien coûte une extension d’export Claude ?

Les exports Markdown, texte, JSON, XML, CSV et PNG sont gratuits et illimités, sans compte. Le PDF et l’export groupé « Export All » sont gratuits jusqu’à 3 par jour avec une connexion Google. Pro coûte 3,99 $ par mois ou 26,99 $ par an via Paddle et rend le PDF et l’export groupé illimités. Download Claude conversations ne facture pas par format. Toute offre claude.ai convient si Chrome peut ouvrir la conversation.

Le compteur quotidien du PDF et de l’export groupé revient à zéro à minuit UTC. Pro se restaure sur un nouvel ordinateur quand vous vous connectez avec le même compte Google. Vous pouvez résilier à tout moment depuis la page Options de l’extension ou via Paddle. Paddle est le revendeur officiel ; notre équipe ne voit jamais les numéros de carte. Le premier paiement bénéficie d’une garantie satisfait ou remboursé de 14 jours, gérée par Paddle comme décrit sur la page des remboursements.

Vous n’avez pas besoin de l’offre payante de claude.ai pour utiliser l’extension d’export Claude. Il vous faut une connexion claude.ai capable de charger la conversation, plus Chrome. Team et Enterprise fonctionnent comme Free avec le bouton orange. Si un administrateur bloque les extensions, Download Claude conversations ne s’injectera pas : c’est une règle du navigateur, pas une limite de format.

FAQ : exporter une conversation Claude

Ces questions portent sur l’export d’une conversation Claude et sur l’extension d’export Claude : formats, limites, Desktop, Claude Code, ZIP d’Anthropic et emplacement du bouton orange. Chaque réponse décrit la version 1.16.2. Les données structurées FAQPage dans l’en-tête de la page reprennent cette liste.

Que signifie « exporter une conversation Claude » sur ce site ?

Enregistrer une conversation claude.ai dans un fichier avec Download Claude conversations : bouton orange, choix du format, « Export ». C’est ce que beaucoup cherchent aussi en anglais sous « claude export chat ». Ce n’est ni le ZIP envoyé par e-mail par Anthropic, ni la commande /export de Claude Code.

Une extension d’export Claude, est-ce la même chose qu’Export data ?

Non. Settings → Privacy → Export data fournit par e-mail un ZIP JSON de tout le compte. L’extension d’export Claude écrit immédiatement dans Chrome la conversation ouverte en PDF, Markdown, JSON, texte, XML, CSV ou PNG, ou une sélection « Export All » sous forme de ZIP.

Puis-je exporter une conversation Claude en PDF ?

Oui. Choisissez PDF dans la liste des formats et cliquez sur « Export ». L’extension d’export Claude génère le PDF dans le navigateur, sans boîte de dialogue d’impression. Le PDF demande une connexion Google et reste gratuit jusqu’à 3 par jour ; Pro le rend illimité. Guide : télécharger une conversation Claude en PDF.

Faut-il Pro pour exporter une conversation Claude une seule fois ?

Non. Les exports Markdown, texte, JSON, XML, CSV et PNG sont gratuits et illimités, sans compte. Le PDF et l’export groupé « Export All » sont gratuits jusqu’à 3 par jour avec une connexion Google. Pro, à 3,99 $ par mois ou 26,99 $ par an, supprime cette limite.

L’export fonctionne-t-il avec toutes les offres claude.ai ?

Oui. Les offres claude.ai Free, Pro, Team ou Enterprise fonctionnent si vous pouvez ouvrir la conversation dans Chrome. L’extension d’export Claude ne nécessite pas d’offre payante chez Anthropic.

Cette extension d’export Claude fonctionne-t-elle avec Claude Code ?

Seulement pour Claude Code sur le web. Les sessions sur claude.ai/code s’ouvrent sur claude.ai et s’exportent comme n’importe quelle conversation. Claude Code dans le terminal utilise /export ou des fichiers JSONL sur le disque, que Download Claude conversations ne lit pas. Voir le guide d’export Claude Code.

Puis-je exporter une conversation depuis Claude Desktop ?

Pas avec cette extension Chrome. Ouvrez la même conversation sur claude.ai si elle est synchronisée, ou faites un copier-coller, ou utilisez l’export officiel Export data. Desktop n’affiche jamais le bouton orange.

Combien d’exports gratuits offre l’extension d’export Claude ?

Un nombre illimité pour Markdown, texte, JSON, XML, CSV et PNG, sans compte. Avec l’offre gratuite et une connexion Google, le PDF et « Export All » partagent 3 exports par jour ; chaque conversation d’un ZIP groupé compte pour un. Le compteur revient à zéro à minuit UTC. Pro supprime la limite et se restaure via la connexion Google.

Où se trouve le bouton orange pour exporter une conversation Claude ?

À droite de la zone de message, sur l’URL d’une conversation claude.ai, après avoir installé Download Claude conversations et rechargé la page. Il n’apparaît pas sur la page d’accueil vide ni dans Desktop.

L’export envoie-t-il mes conversations en ligne ?

Non. Chaque format, PDF compris, est généré dans le navigateur puis transmis à l’API de téléchargement de Chrome. Les exports Markdown, texte, JSON, XML, CSV et PNG ne nous envoient rien. Une fois que vous êtes connecté pour le PDF, l’export groupé ou Pro, notre serveur voit le quota ou le statut d’abonnement et votre adresse e-mail Google, jamais le contenu des conversations. Détails dans comment ça marche.

Quels formats l’extension d’export Claude peut-elle produire ?

Sept : PDF, Markdown, texte brut, JSON, XML, CSV et PNG, les mêmes sept pour une conversation et pour « Export All ». Pas d’export Word, Notion ou Google Docs dans la version 1.16.2.
