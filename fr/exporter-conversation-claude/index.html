Comment exporter une conversation Claude depuis claude.ai ?

Ouvrez la conversation sur claude.ai dans Chrome, cliquez sur le bouton orange à côté de la zone de message, choisissez Markdown, JSON, texte brut, XML ou PNG, puis cliquez sur « Export ». Download Claude conversations écrit ce fichier en local. En septembre 2026, claude.ai ne propose lui-même aucune commande native pour exporter une conversation.

  1. Installez Download Claude conversations depuis le Chrome Web Store (fiche notée 5,0).
  2. Rechargez claude.ai et ouvrez l’URL d’une vraie conversation, pas la page d’accueil vide.
  3. Cliquez sur le bouton orange de téléchargement, à droite de la zone de message.
  4. Choisissez un format. L’extension d’export Claude mémorise le dernier format utilisé.
  5. Cliquez sur « Export ». Chrome enregistre immédiatement le fichier via l’API de téléchargement du navigateur.

Une connexion Google est requise avant le premier export. Download Claude conversations conserve l’adresse e-mail vérifiée pour compter les 3 exports gratuits et restaurer Pro après une réinstallation. Le texte des conversations ne fait pas partie de cette connexion. Fonctionnement détaillé : comment ça marche.

Si le bouton orange est absent, vous n’êtes pas sur l’URL d’une conversation, l’onglet doit être rechargé après l’installation, ou l’icône de l’extension est encore cachée dans le menu en forme de pièce de puzzle de Chrome. Épinglez Download Claude conversations, puis actualisez claude.ai. L’extension d’export Claude s’injecte uniquement sur claude.ai, jamais sur d’autres sites.

Une conversation ou tout le compte. Le bouton orange exporte la conversation ouverte. Pour de nombreux fichiers, ouvrez « View and Download All Conversations » (afficher et télécharger toutes les conversations) et lancez « Export All » (tout exporter) : voir exporter tout l’historique avec Export All. Settings → Privacy → Export data d’Anthropic (les libellés peuvent être traduits si claude.ai est en français) fournit un ZIP différé du compte, ce n’est pas ce parcours.

Que fait concrètement une extension d’export Claude ?

Une extension d’export Claude lit la conversation déjà affichée dans votre onglet claude.ai connecté et écrit un fichier structuré sur le disque. Download Claude conversations est ce script de contenu Chrome : auteur, arborescence des messages, blocs de code, tableaux, réflexion en option et mise en page des artefacts. Pas une capture de l’interface autour de la conversation.

Le copier-coller depuis claude.ai supprime l’indentation et écrase les tableaux. L’impression (Ctrl/Cmd+P) garde la barre latérale et coupe souvent un long bloc de code entre deux pages. L’extension d’export Claude conserve le langage des blocs de code et garde les tableaux sous forme de tableaux en Markdown, JSON et XML. Le PNG est l’option d’instantané visuel ; ce n’est toujours pas un PDF.

La mise en page des artefacts est une vraie option dans la version 1.13.0 : « Original », « Inline », « Nested » ou « Flat » (original, intégré, imbriqué ou à plat). Les blocs de réflexion sont facultatifs. Les métadonnées (titre, horodatages, modèle) peuvent être ajoutées. Le filtre par auteur peut limiter le fichier à tous les messages, aux messages humains seuls ou à ceux de l’assistant seul. Liste complète : fonctionnalités.

Nous avons conçu le bouton orange pour écrire un vrai fichier à partir de la conversation déjà ouverte sur claude.ai (Markdown, JSON, texte, XML ou PNG) sans envoyer la conversation sur nos serveurs. La version 1.13.0 ne produit toujours pas de PDF.

Dans quel format exporter une conversation Claude ?

Exportez une conversation Claude en Markdown pour vos notes, en JSON pour vos scripts, en texte brut pour une archive dépouillée, en XML pour l’échange de données ou en PNG pour une image de la conversation. Download Claude conversations propose ces cinq formats dans une seule liste déroulante. L’extension d’export Claude ne propose pas de format PDF.

Formats produits par l’extension d’export Claude depuis claude.ai
Format Idéal pour Ce que vous obtenez
Markdown Obsidian, GitHub, wikis Titres, blocs de code, tableaux : guide Markdown
JSON Comparaisons, chaînes de traitement, outils Arborescence des messages, pas le ZIP de compte d’Anthropic : guide JSON
Texte brut Archive à coller n’importe où Ordre de la conversation, sans balisage : tous les formats
XML Systèmes qui exigent du XML Échange structuré : guide XML
PNG Instantané visuel Image de la conversation, pas un PDF : guide PNG

Les rédacteurs exportent généralement en Markdown, les développeurs choisissent plutôt JSON. Si vous avez besoin précisément d’une page de type PDF, imprimez depuis Chrome au lieu d’attendre un format que nous ne proposons pas. Marche à suivre : imprimer une conversation Claude. Un PNG produit par l’extension d’export Claude est un fichier image, pas un document paginé.

Le choix du format ne change pas le quota de 3 exports. Markdown, JSON, texte, XML et PNG comptent chacun pour un export quand le fichier est terminé. Pro, à 3,99 $/mois ou 26,99 $/an, supprime cette limite pour tous les formats. Download Claude conversations n’ajoute pas d’export vers Notion, Word ou Google Docs dans la version 1.13.0.

Peut-on tout exporter d’un coup avec Export All ?

Oui. Ouvrez « View and Download All Conversations », filtrez le tableau, puis cliquez sur « Export All ». Chaque fichier terminé compte pour un export, dans les mêmes 3 exports gratuits que le bouton orange. Pro supprime la limite pour l’export groupé comme pour une conversation isolée.

Le tableau liste l’historique claude.ai, avec une recherche par nom et des filtres All, New, Exported et Project. New signifie « pas encore exportée avec Download Claude conversations ». Exported suit les conversations déjà enregistrées, pour qu’un second Export All puisse les ignorer. Project reprend la façon dont vous regroupez vos conversations sur claude.ai.

L’export groupé utilise les mêmes options qu’une conversation : conversations, réflexion, métadonnées, mise en page des artefacts (« Original », « Inline », « Nested », « Flat ») et les mêmes cinq formats. « Export All » n’est pas un ZIP allégé : ce sont de nombreux fichiers, un par conversation. Si vous vouliez une seule archive différée de tout le compte, c’est Export data d’Anthropic, comparé dans la section suivante et sur la page d’export de l’historique.

Le quota couvre tout le compte. Trois exports gratuits au total, pas trois par export groupé. Sélectionner 40 conversations sur la page de navigation consommera 40 exports si chaque fichier aboutit. Préparez votre sélection avant de cliquer sur « Export All », ou passez à Pro pour 3,99 $/mois ou 26,99 $/an.

L’export fonctionne-t-il dans Desktop ou Claude Code ?

Non. Cette extension d’export Claude fonctionne uniquement sur claude.ai dans Chrome (ou un autre navigateur Chromium capable de charger la fiche). Claude Desktop est une application Mac/Windows distincte. Claude Code est l’agent du terminal. Le bouton orange n’apparaît jamais dans ces fenêtres.

Si la conversation existe aussi sur votre compte claude.ai, ouvrez-la dans Chrome et exportez-la avec Download Claude conversations. Si elle n’existe que dans Desktop, faites un copier-coller depuis l’application ou demandez Settings → Privacy → Export data sur le web. Comparaison pas à pas : exporter une conversation Claude Desktop.

Claude Code utilise /export ou des transcriptions JSONL sur le disque. Ce n’est pas le Markdown de cette extension Chrome. N’installez pas Download Claude conversations en espérant une intégration au terminal. Guide : exporter une conversation Claude Code. Exporter une session en ligne de commande relève d’un autre produit.

claude.ai dans un navigateur de téléphone n’est pas pris en charge non plus. L’extension d’export Claude nécessite Chrome sur ordinateur. Notre équipe ne propose pas d’application iOS ou Android en 2026. Ouvrez la conversation sur un ordinateur, puis exportez-la avec le bouton orange ou « Export All ».

Exporter une conversation ou utiliser Export data d’Anthropic ?

Export data d’Anthropic envoie par e-mail, après un délai, un ZIP JSON de tout le compte. Exporter une conversation Claude avec Download Claude conversations enregistre immédiatement la conversation ouverte en Markdown, JSON, texte, XML ou PNG. Le ZIP sert de sauvegarde ; l’extension d’export Claude, à obtenir tout de suite un fichier lisible.

Combien coûte une extension d’export Claude ?

Chaque compte connecté avec Google dispose de 3 exports gratuits. Ensuite, Pro coûte 3,99 $ par mois ou 26,99 $ par an via Paddle. Ce prix couvre le bouton orange et « Export All ». Download Claude conversations ne facture pas par format. Toute offre claude.ai convient si Chrome peut ouvrir la conversation.

Les 3 exports gratuits ne se renouvellent pas quand vous réinstallez l’extension. C’est pourquoi la connexion Google est demandée au premier clic sur « Export ». Pro se restaure sur un nouvel ordinateur avec le même compte Google. Paddle est le revendeur officiel ; notre équipe ne voit jamais les numéros de carte. Les remboursements passent par Paddle, comme décrit sur la page des remboursements.

Vous n’avez pas besoin de l’offre payante de claude.ai pour utiliser l’extension d’export Claude. Il vous faut une connexion claude.ai capable de charger la conversation, plus Chrome. Team et Enterprise fonctionnent comme Free avec le bouton orange. Si un administrateur bloque les extensions, Download Claude conversations ne s’injectera pas : c’est une règle du navigateur, pas une limite de format.

Même besoin, recherches différentes. Exporter une conversation Claude, télécharger une conversation Claude et extraire une conversation Claude signifient tous « enregistrer cette conversation dans un fichier ». Le guide pratique, avec l’impression et le ZIP comme alternatives, est comment télécharger une conversation Claude. Cette page présente le produit, l’extension d’export Claude.

Si un export échoue : attendez que la longue conversation soit entièrement chargée dans claude.ai, vérifiez la liste des formats (le dernier format utilisé reste sélectionné) et contrôlez la limite de 3 exports. Si Chrome a bloqué le téléchargement, autorisez les téléchargements depuis claude.ai. Un fichier incomplet signifie généralement que la page n’avait pas encore affiché toute l’arborescence des messages.

La version décrite ici est la 1.13.0, datée de septembre 2026. Les formats restent Markdown, JSON, texte brut, XML et PNG. Si cette liste change, ce guide sera mis à jour le jour même. D’ici là, n’attendez pas de Word, de Notion ou de PDF natif de l’extension d’export Claude.

FAQ : exporter une conversation Claude

Ces questions portent sur l’export d’une conversation Claude et sur l’extension d’export Claude : formats, quota, Desktop, Claude Code, ZIP d’Anthropic et emplacement du bouton orange. Chaque réponse décrit la version 1.13.0. Les données structurées FAQPage dans l’en-tête de la page reprennent cette liste.

Que signifie « exporter une conversation Claude » sur ce site ?

Enregistrer une conversation claude.ai dans un fichier avec Download Claude conversations : bouton orange, choix du format, « Export ». C’est ce que beaucoup cherchent aussi en anglais sous « claude export chat ». Ce n’est ni le ZIP envoyé par e-mail par Anthropic, ni la commande /export de Claude Code.

Une extension d’export Claude, est-ce la même chose qu’Export data ?

Non. Settings → Privacy → Export data fournit par e-mail un ZIP JSON de tout le compte. L’extension d’export Claude écrit immédiatement dans Chrome la conversation ouverte, ou une sélection « Export All », en Markdown, JSON, texte, XML ou PNG.

Puis-je exporter une conversation Claude en PDF ?

Pas avec cette extension d’export Claude. Les formats sont Markdown, JSON, texte brut, XML et PNG. Pour un instantané de type PDF, imprimez la page claude.ai dans Chrome. Le PNG est une image, pas un PDF.

Faut-il Pro pour exporter une conversation Claude une seule fois ?

Non. Les 3 premiers exports de tout compte connecté avec Google sont gratuits, dans n’importe quel format. Pro, à 3,99 $/mois ou 26,99 $/an, supprime la limite pour davantage de fichiers, individuels ou groupés.

L’export fonctionne-t-il avec toutes les offres claude.ai ?

Oui. Les offres claude.ai Free, Pro, Team ou Enterprise fonctionnent si vous pouvez ouvrir la conversation dans Chrome. L’extension d’export Claude ne nécessite pas d’offre payante chez Anthropic.

Cette extension d’export Claude fonctionne-t-elle avec Claude Code ?

Non. Download Claude conversations fonctionne sur claude.ai dans Chrome. Claude Code utilise /export ou des fichiers JSONL sur le disque. Voir le guide d’export Claude Code.

Puis-je exporter une conversation depuis Claude Desktop ?

Pas avec cette extension Chrome. Ouvrez la même conversation sur claude.ai si elle est synchronisée, ou faites un copier-coller, ou utilisez l’export officiel Export data. Desktop n’affiche jamais le bouton orange.

Combien d’exports gratuits offre l’extension d’export Claude ?

Trois par compte, partagés entre le bouton orange et « Export All ». Une réinstallation ne remet pas le compteur à zéro. Pro se restaure via la connexion Google.

Où se trouve le bouton orange pour exporter une conversation Claude ?

À droite de la zone de message, sur l’URL d’une conversation claude.ai, après avoir installé Download Claude conversations et rechargé la page. Il n’apparaît pas sur la page d’accueil vide ni dans Desktop.

L’export envoie-t-il mes conversations en ligne ?

Non. Les fichiers sont générés dans le navigateur puis transmis à l’API de téléchargement de Chrome. Notre serveur voit le statut d’abonnement et une adresse e-mail vérifiée par Google, pas le contenu des conversations. Détails dans comment ça marche.

Quels formats l’extension d’export Claude peut-elle produire ?

Markdown, JSON, texte brut, XML et PNG : les mêmes cinq pour une conversation et pour « Export All ». Pas d’export PDF, Word, Notion ou Google Docs dans la version 1.13.0.
