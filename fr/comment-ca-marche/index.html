Comment fonctionne Download Claude conversations dans Chrome

Voici comment fonctionne Download Claude conversations : un script de contenu lit la conversation claude.ai déjà ouverte dans votre onglet, génère le fichier Markdown, JSON, texte, XML ou PNG dans le navigateur, puis le transmet à Chrome. La connexion Google compte les 3 exportations gratuites et restaure Pro. Le contenu des conversations n’est jamais envoyé à notre serveur. Pro coûte 3,99 $/mois ou 26,99 $/an via Paddle.

Comment fonctionne Download Claude conversations sur claude.ai ?

Sur claude.ai, l’extension injecte un script de contenu dans la page que vous avez déjà ouverte, en utilisant la session sur laquelle vous êtes déjà connecté. Elle lit la conversation affichée, et non une API Anthropic distincte. Le bouton orange n’apparaît que sur une vraie URL de conversation.

  1. Installez Download Claude conversations depuis le Chrome Web Store (fiche notée 5.0).
  2. Rechargez claude.ai si l’onglet était ouvert pendant l’installation.
  3. Ouvrez une URL de conversation. Le bouton orange se trouve à droite de la zone de message.
  4. Choisissez Markdown, JSON, texte brut, XML ou PNG. Cliquez sur « Export » (Exporter).
  5. Chrome télécharge le fichier. C’est tout le parcours côté client.

La page d’accueil vide avec la zone de saisie n’a pas d’arborescence de messages : le bouton n’y apparaît donc pas. Épinglez l’extension dans le menu en forme de pièce de puzzle de Chrome si l’icône est masquée, puis actualisez claude.ai. Le fonctionnement s’arrête à claude.ai : Claude Desktop et Claude Code ne reçoivent jamais ce script. Liste des fonctionnalités : fonctionnalités de l’extension Chrome.

Même session, même page. Le script de contenu voit ce que votre onglet claude.ai connecté affiche déjà. Il ne se connecte pas à Anthropic avec un second mot de passe. Respectez les règles d’Anthropic pour votre compte.

Les fichiers restent-ils en local quand Download Claude conversations fonctionne ?

Oui. Les fichiers Markdown, JSON, texte brut, XML et PNG sont assemblés dans votre navigateur et transmis à l’API de téléchargement de Chrome. Le texte des conversations ne quitte jamais votre appareil pour rejoindre notre infrastructure. C’est vrai pour une exportation via le bouton orange comme pour Export All sur la page d’exportation groupée.

Une fois la conversation chargée par claude.ai, la génération du fichier n’attend pas notre serveur. Les vérifications de quota et de licence sont une requête distincte. Si Chrome bloque les téléchargements depuis claude.ai, autorisez-les : c’est un réglage du navigateur, pas un échec d’analyse. Une longue conversation à moitié défilée donne toujours un fichier à moitié rempli, car le DOM était incomplet.

Nous avons conçu Download Claude conversations autour d’une limite stricte : le contenu des conversations reste dans l’onglet ; notre serveur répond seulement à « combien d’exportations gratuites restent-il » et « ce compte Google est-il sur Pro ». Nous n’envoyons toujours pas les conversations sur un serveur pour générer le Markdown, le JSON, le texte, le XML ou le PNG, et nous ne générons toujours pas de PDF.

L’équipe Download Claude conversations

Le PNG est dessiné en local sous forme d’image. JSON et XML sont sérialisés en local à partir de la même arborescence. Nous n’envoyons aucun de ces fichiers par e-mail. Settings → Privacy → Export data (les libellés peuvent être traduits si claude.ai est réglé en français) est une archive ZIP différée d’Anthropic, un tout autre circuit que ce traitement local.

Pourquoi la connexion Google fonctionne-t-elle ainsi pour le quota ?

La connexion Google permet de compter 3 exportations gratuites par compte et de restaurer Pro après une réinstallation. Elle est requise dès le premier clic sur « Export ». Nous enregistrons l’adresse e-mail vérifiée. Nous n’enregistrons pas le texte des conversations.

Les 3 exportations gratuites ne se réinitialisent pas si vous supprimez l’extension puis la réinstallez. C’est pourquoi la connexion n’est pas facultative : sans elle, une réinstallation créerait discrètement trois nouveaux fichiers gratuits. Pro, à 3,99 $/mois ou 26,99 $/an, se restaure sur un nouvel ordinateur avec le même compte Google.

La connexion Google n’est pas une connexion à claude.ai. Vous continuez à utiliser votre session Anthropic sur le site. Download Claude conversations a seulement besoin de Google pour rattacher le quota. Certains cherchent aussi Claude Chat Downloader pour trouver la même fiche ; la règle de connexion est identique.

Le quota s’applique à tout le compte. Trois exportations gratuites au total, tous formats confondus, exportation groupée Export All comprise. Sélectionner 40 conversations consomme 40 exportations si chaque fichier aboutit. La connexion permet à ce compteur de survivre à une réinstallation.

Comment fonctionne le paiement avec Paddle et Pro ?

Paddle.com Market Limited est le prestataire de paiement et le revendeur officiel (merchant of record). Pour la facturation, Paddle collecte les données de carte et la TVA. Nous ne voyons jamais les détails de paiement. Pro coûte 3,99 $ par mois ou 26,99 $ par an. Les remboursements passent par Paddle.

Pro supprime la limite de 3 exportations pour le bouton orange et pour Export All. Il n’ajoute ni PDF, ni Notion, ni Word : les formats restent Markdown, JSON, texte, XML et PNG. Vous n’avez pas besoin d’un abonnement payant claude.ai d’Anthropic. Tout identifiant claude.ai qui charge la conversation dans Chrome suffit.

Que voit notre serveur quand l’extension fonctionne ?

Un Cloudflare Worker vérifie l’état de l’abonnement : si le compte Google est sur Pro et combien d’exportations gratuites il a utilisées. Quand Download Claude conversations fonctionne, ce serveur ne reçoit pas le contenu des conversations. L’exportation et la vérification de licence sont deux circuits distincts. Seul celui de la licence passe par nos serveurs.

Ce serveur explique pourquoi une réinstallation ne réinitialise pas les 3 exportations gratuites, et pourquoi Pro se restaure. Ce n’est pas une sauvegarde de conversations. Anthropic conserve votre historique claude.ai de son côté ; nous n’en gardons pas de seconde copie. La politique de confidentialité de ce site décrit l’adresse e-mail que nous enregistrons.

Version 1.13.0, septembre 2026. Si le serveur est injoignable, il se peut que vous ne puissiez pas lancer une exportation tant que l’état n’a pas pu être vérifié. C’est un contrôle de licence, pas une obligation d’envoyer la conversation. Les fichiers sont toujours assemblés en local une fois la vérification réussie.

Cet outil d’export des conversations Claude est-il sûr ?

Nous ne promettrons pas « zéro réseau ». L’extension communique toujours avec Google, Paddle, claude.ai et notre serveur. Le contenu des conversations n’est pas envoyé à notre API ; l’état de la licence et de la connexion, si. Le script n’automatise aucune action supplémentaire sur votre compte Anthropic.

FAQ : comment fonctionne Download Claude conversations

Ces questions couvrent le fonctionnement de Download Claude conversations : fichiers locaux, connexion Google, Paddle, serveur, affiliation, quota et Pro. Chaque réponse est un fait sur la version 1.13.0. Le JSON-LD FAQPage dans l’en-tête de la page correspond à cette liste.

Download Claude conversations stocke-t-il mes conversations ?

Non. Les exportations sont générées en local et ne sont jamais envoyées. Nous enregistrons uniquement une adresse e-mail vérifiée par Google pour suivre l’utilisation des exportations gratuites et l’état de Pro. Le contenu des conversations reste dans l’onglet claude.ai et dans le fichier que Chrome télécharge.

La connexion Google est-elle obligatoire ou facultative ?

Obligatoire, dès votre première exportation. C’est ainsi que nous appliquons la limite de 3 exportations gratuites sans qu’une réinstallation remette le compteur à zéro. Ce n’est pas une connexion permettant de lire vos conversations.

Qui traite le paiement de Pro ?

Paddle. Nous ne voyons jamais les détails de votre carte. Pro coûte 3,99 $/mois ou 26,99 $/an. Paddle est le revendeur officiel (merchant of record). Les remboursements passent par Paddle.

Cette extension est-elle affiliée à Anthropic ?

Non. C’est une extension Chrome indépendante, non affiliée à Anthropic, PBC. Claude est une marque d’Anthropic. Download Claude conversations utilise votre session claude.ai existante ; elle ne remplace pas les produits d’Anthropic.

Le fonctionnement inclut-il un format PDF ?

Non. Les fichiers sont en Markdown, JSON, texte brut, XML ou PNG, tous générés en local. Pour une page proche d’un PDF, imprimez l’onglet claude.ai dans Chrome. PNG est une image, pas un PDF.

Que voit le serveur lors d’une exportation ?

L’état de l’abonnement : l’indicateur Pro et le nombre d’exportations gratuites déjà utilisées par le compte Google. Le serveur ne reçoit pas le contenu des conversations. Le processus d’exportation reste dans le navigateur.

Ai-je besoin de Pro pour utiliser Download Claude conversations ?

Non. Les 3 premières exportations sont gratuites pour tout compte connecté avec Google. Pro, à 3,99 $/mois ou 26,99 $/an, supprime la limite pour davantage de fichiers, individuels ou groupés. La génération locale des fichiers est identique en gratuit et en Pro.
