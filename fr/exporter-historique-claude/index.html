Exporter tout l’historique Claude en une seule fois

Pour exporter tout l’historique Claude depuis claude.ai, ouvrez « View and Download All Conversations » (afficher et télécharger toutes les conversations), filtrez, puis cliquez sur « Export All » (Tout exporter). Download Claude conversations génère des fichiers Markdown, JSON, texte, XML ou PNG en local. Chaque fichier utilise l’une des 3 exportations gratuites, sauf avec Pro (3,99 $/mois ou 26,99 $/an). Il ne s’agit ni de Claude Desktop, ni de Claude Code, ni de l’archive ZIP envoyée par e-mail par Anthropic.

Comment exporter tout l’historique Claude ?

Cliquez sur l’icône de Download Claude conversations, choisissez « View and Download All Conversations », puis cliquez sur Export All. Cette page de consultation liste l’historique claude.ai pour que vous puissiez exporter vos conversations Claude sous forme de fichiers séparés. Le bouton orange sur une conversation est l’autre point d’entrée ; l’exportation groupée, c’est ce tableau.

  1. Installez l’extension depuis le Chrome Web Store (notée 5.0) et épinglez-la. Ce guide porte sur la version 1.13.0, septembre 2026.
  2. Connectez-vous à claude.ai dans Chrome. Export All lit la même session que le site.
  3. Ouvrez la fenêtre de l’extension et cliquez sur « View and Download All Conversations ».
  4. Recherchez ou filtrez, puis sélectionnez les conversations dont vous avez vraiment besoin.
  5. Choisissez Markdown, JSON, texte brut, XML ou PNG et cliquez sur Export All.

Page de consultation listant les conversations Claude avec recherche et bouton Export All

La connexion Google est requise avant le premier fichier, y compris pour le premier Export All. Download Claude conversations enregistre l’adresse e-mail vérifiée pour appliquer la limite de 3 exportations gratuites et restaurer Pro. Le contenu des conversations reste dans le navigateur. Fonctionnement : comment ça marche. Si vous n’avez besoin que d’un onglet, suivez les étapes pour une seule conversation : comment télécharger une conversation Claude.

Tout l’historique, c’est de nombreux fichiers, pas un ZIP. Export All crée un fichier par conversation claude.ai sélectionnée. Settings → Privacy → Export data (les libellés peuvent être traduits si claude.ai est réglé en français) fournit l’archive ZIP différée du compte, si vous vouliez une seule sauvegarde plutôt qu’un dossier de fichiers Markdown ou JSON.

Comment filtrer les conversations Claude avant Export All ?

La recherche trouve les conversations par leur nom. Les filtres sont All, New, Exported et Project (toutes, nouvelles, exportées, projet). Utilisez-les avant d’exporter votre historique pour ne pas dépenser de quota sur des fichiers que vous avez déjà. New désigne les conversations pas encore exportées avec cette extension. Exported marque celles que vous avez déjà sauvegardées.

Project reprend la façon dont vous regroupez vos conversations sur claude.ai. Une exportation groupée typique porte sur « ce projet » ou « seulement les nouvelles », pas sur « tout depuis la création du compte ». Sélectionnez les lignes, puis lancez Export All une fois. Répéter le bouton orange sur des dizaines d’URL, c’est justement la méthode lente que ce tableau remplace.

Le filtre Exported est propre à Download Claude conversations. Il n’a rien à voir avec la notion de sauvegarde d’Anthropic. Si vous avez déjà utilisé Export data, ces conversations peuvent encore apparaître comme New ici tant que l’extension n’a pas créé de fichiers. C’est normal. Présentation du tableau : fonctionnalités.

Sélectionnez avant de vous lancer. Export All tentera de créer un fichier pour chaque ligne sélectionnée. Avec une limite gratuite de 3 exportations, une sélection de 40 lignes relève de Pro (3,99 $/mois ou 26,99 $/an), pas d’un essai gratuit. Filtrez d’abord sur New ou sur un projet.

Que contient chaque fichier d’Export All ?

L’exportation groupée utilise les mêmes options qu’une conversation individuelle : Chats, réflexion (« include thinking »), métadonnées (« include metadata ») et mise en page des artifacts (« Original », « Inline », « Nested », « Flat » — d’origine, intégrée, imbriquée, à plat). Exporter tout l’historique ne donne pas un ZIP de moindre qualité. Chaque fichier peut conserver les blocs de code, les tableaux et, en option, le raisonnement. Le filtre par expéditeur peut garder « all / human only / assistant only » (tous, humain uniquement, assistant uniquement).

La réflexion correspond au raisonnement étendu de Claude, quand la page l’affichait. Les métadonnées peuvent inclure les titres, les horodatages et le modèle. La mise en page des artifacts détermine leur place dans les fichiers Markdown, JSON ou XML. PNG reste une image de la conversation. Aucune de ces options n’ajoute le PDF. L’impression reste une action distincte du navigateur : impression / PDF.

Export All décompte chaque fichier sur les mêmes 3 exportations gratuites qu’une conversation enregistrée individuellement. Pro, à 3,99 $ par mois ou 26,99 $ par an, est la même licence pour les deux. L’exportation groupée, c’est l’exportation individuelle appliquée à grande échelle, pas un autre produit.

L’équipe Download Claude conversations

Un fichier groupé incomplet signifie généralement qu’une très longue conversation n’était pas entièrement affichée. Export All dépend toujours de ce que claude.ai a chargé pour chaque conversation qu’il ouvre. Si un fichier semble court, ouvrez cette conversation, patientez, puis exportez à nouveau cette ligne. L’état Exported du tableau se met à jour après un téléchargement réussi.

Combien d’exportations gratuites Export All utilise-t-il ?

Un fichier terminé équivaut à une exportation, comme avec le bouton orange. Chaque compte dispose de 3 exportations gratuites au total, individuelles et groupées confondues. Il n’existe pas de quota séparé pour l’exportation groupée. Pro, à 3,99 $/mois ou 26,99 $/an, supprime la limite pour les deux. Paddle facture Pro ; nous ne voyons jamais les détails de carte.

Réinstaller Chrome ne réinitialise pas le compteur de 3 exportations. C’est pourquoi la connexion Google est requise dès le premier fichier. Pro se restaure sur une nouvelle machine avec le même compte Google. Les offres claude.ai Free, Pro, Team et Enterprise fonctionnent toutes si la session peut lister les conversations ; l’abonnement Anthropic n’est pas notre compteur.

Préparez votre sélection. Trois conversations New en Markdown : c’est un Export All valable en gratuit. Trente conversations : c’est Pro. Changer de format ne multiplie pas le quota ; chaque PNG ou JSON terminé compte toujours pour un. Si vous passez à Pro puis changez d’avis, les remboursements passent par Paddle, comme indiqué sur la page des remboursements.

Export All ou archive ZIP de sauvegarde des conversations Claude ?

Sauvegarder ses conversations Claude signifie généralement utiliser Settings → Privacy → Export data d’Anthropic : une seule archive ZIP JSON du compte, envoyée en différé. Export All, ce sont les fichiers que vous choisissez, immédiatement, en Markdown, JSON, texte, XML ou PNG. Utilisez le ZIP pour sauvegarder le compte, et cette page pour obtenir des documents.

L’archive officielle ne contient pas un fichier Markdown par conversation et n’a pas de filtres New/Exported. Export All n’est pas une extraction légale ou de conformité de toutes les conversations oubliées qui n’apparaissent pas dans le tableau. Si une conversation n’est pas listée sur la page de consultation, l’extension ne peut pas l’inventer. Comparaison des méthodes, impression comprise : comment exporter une conversation Claude.

Certains cherchent « historique conversation claude » ou, en anglais, « claude export chat » pour le même choix. Si l’objectif est de sauvegarder vos conversations Claude, commencez par Export data d’Anthropic. Si l’objectif est un dossier de notes, restez sur Export All. Aucune de ces deux voies ne concerne Claude Desktop, ni le /export de Claude Code.

Export All fonctionne-t-il dans Claude Desktop ou Claude Code ?

Non. Exporter tout l’historique Claude avec cette extension nécessite claude.ai dans Chrome. Claude Desktop n’affiche jamais « View and Download All Conversations ». Claude Code utilise /export ou des fichiers JSONL sur le disque. Installer l’extension n’ajoute pas Export All à ces produits.

Si des conversations Desktop sont synchronisées avec le même compte, elles peuvent apparaître dans le tableau dès qu’elles existent sur claude.ai. Si elles n’ont jamais été synchronisées, l’exportation groupée ne peut pas les voir. Solutions pour Desktop : exporter une conversation Claude Desktop. Sessions de terminal : exporter une conversation Claude Code. Ne lancez pas Export All en espérant obtenir le JSONL d’un dépôt.

Chrome sur mobile n’est pas non plus pris en charge. La page de consultation est une interface d’extension pour ordinateur. Notre équipe ne propose aucun outil d’exportation groupée pour iOS en 2026. Ouvrez claude.ai sur un ordinateur. Les règles d’équipe qui bloquent les extensions bloquent aussi Export All.

Quel format choisir pour Export All ?

Choisissez un seul format pour toute l’exécution d’Export All : Markdown pour les coffres de notes, JSON pour les pipelines, texte brut pour une archive sans balisage, XML pour l’échange de données, PNG pour des images. L’exportation de tout l’historique utilise les cinq mêmes formats que le bouton orange. Page centrale : formats. Pas de PDF dans la version 1.13.0.

Les rédacteurs exportent généralement en Markdown — guide Markdown. Les développeurs exportent généralement en JSON — guide JSON. XML : XML. PNG : PNG. Le JSON d’Export All reste un ensemble de fichiers par conversation issus de la page, pas la structure de l’archive ZIP du compte Anthropic. Ne mélangez pas ces schémas dans un même script.

Le choix du format ne change pas le prix. En PNG, l’exportation groupée consomme toujours une exportation par image. Passer de Markdown à JSON lors d’une seconde exécution consomme une seconde exportation par conversation. Utilisez le filtre Exported pour éviter les doublons. Formulation orientée extraction pour les mêmes fichiers : extracteur de conversations Claude. Exportation individuelle côté produit : exporter une conversation Claude.

Nous ne citons pas d’autres outils d’exportation. Export data d’Anthropic est mentionné comme point de comparaison pour l’archive ZIP de sauvegarde. Download Claude conversations (aussi appelé Claude Chat Downloader / Claude Conversation Downloader) est la solution d’exportation groupée dans Chrome. Extension indépendante, non affiliée à Anthropic, PBC. Notée 5.0 sur le Chrome Web Store.

Si Export All se bloque, vérifiez les autorisations de téléchargement de Chrome pour claude.ai, confirmez que vous n’avez pas dépassé les 3 exportations ou que vous êtes sur Pro, puis réessayez avec New uniquement. Si le tableau est vide, vous êtes déconnecté ou la session claude.ai n’est pas lisible par le script de contenu. Rechargez claude.ai, puis rouvrez « View and Download All Conversations ».

FAQ : exporter tout l’historique Claude

Ces questions couvrent l’exportation de tout l’historique Claude, Export All et la sauvegarde des conversations : quota, filtres par projet, Desktop, Claude Code, PDF et archive ZIP d’Anthropic. Les réponses concernent l’extension 1.13.0 sur claude.ai. Le JSON-LD FAQPage dans l’en-tête correspond à cette liste.

Comment télécharger des conversations Claude de façon groupée ?

Ouvrez « View and Download All Conversations », sélectionnez ou filtrez les lignes, choisissez un format, puis cliquez sur « Export All ». Chaque fichier est en Markdown, JSON, texte, XML ou PNG. C’est ainsi que l’on exporte tout l’historique Claude sous forme de documents séparés.

L’exportation groupée coûte-t-elle plus cher qu’une exportation individuelle ?

Non. Même compteur : 3 exportations gratuites au total, bouton orange et Export All confondus. Pro coûte 3,99 $/mois ou 26,99 $/an pour les deux. Un fichier groupé coûte une exportation, comme une conversation enregistrée individuellement.

Puis-je télécharger l’historique des conversations d’un seul projet ?

Oui. Filtrez par Project sur la page de consultation, puis lancez Export All. C’est la méthode habituelle pour exporter un ensemble de conversations Claude sans prendre toutes celles du compte.

L’exportation groupée est-elle identique à l’export officiel d’Anthropic ?

Non. Export data officiel est une seule archive ZIP JSON de tout le compte, envoyée par e-mail (sauvegarde des conversations Claude). Export All produit les fichiers que vous sélectionnez, immédiatement, dans le format choisi.

Download Claude conversations se souvient-il des conversations exportées ?

Oui. Le filtre Exported suit ce que l’extension a déjà téléchargé, pour que vous puissiez lancer Export All sur les seules conversations New lors d’une visite ultérieure.

Est-ce ainsi que l’on télécharge une conversation Claude en entier ?

Oui — Export All, sur la page de consultation, permet d’exporter tout l’historique Claude sous forme de fichiers séparés. Export data d’Anthropic est au contraire une seule archive ZIP du compte, envoyée en différé.

Export All fonctionne-t-il dans Claude Desktop ?

Non. Cette extension Chrome ne fonctionne pas dans Claude Desktop. Synchronisez d’abord les conversations avec claude.ai, ou faites un copier-coller, ou utilisez l’archive ZIP officielle.

Puis-je sauvegarder mes conversations Claude avec Export All ?

Export All produit un dossier de fichiers lisibles, pas l’archive ZIP de sauvegarde d’Anthropic. Pour une sauvegarde au niveau du compte, utilisez Settings → Privacy → Export data. Utilisez les deux si vous voulez à la fois des documents et une archive.

Export All génère-t-il un fichier PDF ?

Non. Les formats sont Markdown, JSON, texte brut, XML et PNG. Imprimez depuis Chrome si vous avez besoin d’une page proche d’un PDF. En PNG, l’exportation groupée produit toujours des images, une par conversation.

L’exportation de tout l’historique fonctionne-t-elle pour Claude Code ?

Non. Claude Code utilise /export ou des fichiers JSONL sur le disque. Export All ne liste que les conversations claude.ai dans Chrome.

Que faire si Export All s’arrête après trois fichiers ?

Vous avez atteint les 3 exportations gratuites. Passez à Pro (3,99 $/mois ou 26,99 $/an) ou attendez d’en avoir besoin. Réinstaller l’extension ne réinitialise pas le compteur lié à votre compte Google.

Ai-je besoin d’un abonnement payant Anthropic pour Export All ?

Non. Toute offre claude.ai capable de charger l’historique dans Chrome fonctionne. Notre compteur gratuit/Pro est distinct. Les administrateurs Team peuvent toutefois bloquer l’extension dans le navigateur.
