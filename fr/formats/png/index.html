Comment télécharger une conversation Claude en PNG ?

Ouvrez la conversation sur claude.ai dans Chrome, cliquez sur le bouton orange à côté de la zone de message, choisissez PNG, puis cliquez sur « Export ». Download Claude conversations génère l’image dans l’onglet. C’est ainsi que l’on télécharge une conversation Claude en PNG avec la version 1.16.2 — gratuitement, sans limite et sans compte.

  1. Installez Download Claude conversations depuis le Chrome Web Store.
  2. Rechargez claude.ai et ouvrez une vraie URL de conversation, pas la page d’accueil vide avec la zone de saisie.
  3. Cliquez sur le bouton rond orange de téléchargement, à droite de la zone de message.
  4. Sélectionnez PNG. Le dernier format utilisé est mémorisé.
  5. Cliquez sur « Export ». Chrome télécharge le PNG immédiatement.

Aucune connexion Google n’est nécessaire pour télécharger une conversation Claude en PNG. Les exports PNG d’une conversation sont illimités et anonymes : aucun compteur, et rien de la conversation ne quitte le navigateur. La connexion n’apparaît que si vous choisissez PDF, lancez Export All ou achetez Pro. Fonctionnement détaillé : comment ça marche.

Si le bouton orange n’apparaît pas, vous n’êtes pas sur une URL de conversation, l’onglet doit être rechargé après l’installation, ou l’extension est masquée dans le menu en forme de pièce de puzzle de Chrome. Épinglez Download Claude conversations, puis actualisez claude.ai. Les projets, les sessions Cowork et Claude Code sur le web (claude.ai/code) s’exportent comme n’importe quelle conversation. L’export PNG n’apparaît jamais dans l’application Claude Desktop ni dans les sessions locales de Claude Code dans le terminal.

Une image ou plusieurs. Le bouton orange crée un PNG de la conversation ouverte. Pour obtenir de nombreuses images, ouvrez « View and Download All Conversations » (afficher et télécharger toutes les conversations) et lancez « Export All » (Tout exporter) avec PNG sélectionné. L’exportation groupée produit un ZIP et utilise le quota quotidien des exportations groupées — voir exportation groupée Export All.

Quand télécharger une conversation Claude en PNG ?

Choisissez PNG quand vous avez besoin d’une image pour une présentation, une messagerie ou un ticket — partout où une image se dépose plus facilement qu’un fichier .md. Ne choisissez pas PNG si vous devrez plus tard rechercher du texte ou copier du code : prenez Markdown, ou PDF si vous avez besoin de pages.

Une capture d’écran de claude.ai faite à la main inclut souvent la barre latérale et la zone de saisie. Download Claude conversations crée le PNG à partir du contenu de la conversation qu’il a déjà analysé, pas à partir d’une capture système prise au hasard. Cela reste une image : pas d’arborescence de messages, pas de balises de langage sur les blocs de code à copier en texte.

Nous avons ajouté PNG pour que vous puissiez enregistrer une capture visuelle d’une conversation claude.ai en un seul fichier. Si vous avez besoin de pages plutôt que d’une longue image, choisissez PDF : l’extension le génère directement, avec numéros de page et table des matières. PNG reste illimité, sans compte.

Télécharger une conversation Claude en PNG, est-ce la même chose qu’un PDF ?

Non. PNG est un format d’image, PDF un format de document paginé. Download Claude conversations exporte les deux : PNG pour une seule image, PDF pour des pages. PNG est illimité, sans compte ; le PDF demande une connexion Google et reste gratuit jusqu’à 3 par jour. Tutoriel : télécharger une conversation Claude en PDF.

La version 1.16.2, de septembre 2026, propose sept formats : PDF, Markdown, texte brut, JSON, XML, CSV et PNG. Un PNG de cette extension n’est pas un PDF renommé. Page centrale : formats d’export des conversations Claude.

L’impression garde la barre latérale de claude.ai et coupe souvent le code sur plusieurs pages. L’export PNG se rapproche davantage d’une capture du contenu de la conversation. Aucune des deux méthodes n’est une archive structurée. Gardez un export Markdown ou JSON si vous risquez d’avoir besoin du texte plus tard.

Que contient l’export PNG d’une conversation Claude ?

Un export PNG est une seule image du contenu de la conversation, générée par Download Claude conversations. Contrairement à Markdown ou JSON, le PNG ne contient pas d’arborescence de messages analysable. Le code et les tableaux sont des pixels. La réflexion et les artifacts sont dessinés, pas stockés en texte.

Le filtre « Messages » limite le dessin à tous les messages, aux messages humains uniquement ou à ceux de l’assistant uniquement ; la case « Thinking » (réflexion) ajoute ou retire la réflexion étendue, et « Select » (sélectionner) permet de cocher des messages précis. Les métadonnées et la mise en page des artifacts (« Original », « Inline », « Nested », « Flat » — d’origine, intégrée, imbriquée, à plat) sont des options du tableau de bord pour Export All. Les métadonnées ne deviennent pas du texte sélectionnable dans le PNG, contrairement au JSON. « Copy » (copier) ne fonctionne pas pour PNG : c’est toujours un fichier.

Si la conversation est très longue, faites défiler la page jusqu’à ce que claude.ai ait chargé les messages plus anciens avant l’export PNG. L’extension ne peut dessiner que ce que la page a chargé. Une conversation à moitié chargée donne une image tronquée. Liste complète des options : fonctionnalités de l’extension Chrome.

Gardez une copie texte si le contenu compte. PNG est une capture. Si vous devez plus tard chercher un nom de fonction, la recherche échouera. Exportez un second fichier en Markdown ou en JSON ; il est illimité et gratuit, comme le PNG.

Peut-on télécharger des conversations Claude en PNG de façon groupée ?

Oui. Ouvrez « View and Download All Conversations », réglez « Chat format » (format des conversations) sur PNG, filtrez la liste, puis cliquez sur Export All. Vous obtenez un seul ZIP avec un PNG par conversation sélectionnée. L’exportation groupée demande une connexion Google ; dans l’offre gratuite, chaque conversation du ZIP utilise l’une des 3 exportations PDF ou groupées du jour. Pro, à 3,99 $ par mois ou 26,99 $ par an, supprime cette limite.

Le tableau de bord liste l’historique claude.ai avec une recherche par nom, une recherche par projet, les onglets Chat et Cowork, et les filtres All conversations, New, Updated et Previously exported (toutes les conversations, nouvelles, mises à jour, déjà exportées). New désigne les conversations pas encore exportées avec Download Claude conversations. Export All produit un PNG par conversation sélectionnée dans le ZIP, pas une planche-contact ni un classeur PDF.

La limite de l’exportation groupée se remet à zéro à minuit UTC. Dans l’offre gratuite, une sélection plus grande que ce qu’il vous reste aujourd’hui est bloquée en entier, pas tronquée : choisissez moins de conversations ou passez à Pro. Le PNG d’une conversation via le bouton orange reste illimité. Settings → Privacy → Export data (les libellés peuvent être traduits si claude.ai est réglé en français) reste une archive ZIP JSON envoyée en différé, pas un dossier d’images.

Télécharger une conversation Claude en PNG coûte-t-il plus cher ?

Non. PNG est gratuit et illimité, comme Markdown, JSON, texte, XML et CSV. Pas de compte Google, pas de compteur. Pro — 3,99 $ par mois ou 26,99 $ par an via Paddle — sert au PDF et au ZIP groupé illimités, pas au PNG. Download Claude conversations ne facture aucun supplément pour l’export PNG.

La connexion n’intervient que si vous voulez le PDF ou Export All : ils partagent 3 exportations par jour dans l’offre gratuite. Pro se restaure sur un nouvel ordinateur quand vous vous connectez avec le même compte Google. Paddle est le revendeur officiel (merchant of record) ; notre équipe ne voit jamais les numéros de carte.

L’extension fonctionne sur claude.ai dans Chrome : conversations, projets, sessions Cowork et Claude Code sur le web (claude.ai/code). L’application Claude Desktop et les sessions locales de Claude Code dans le terminal n’ont pas de bouton PNG. Notre équipe ne propose aucune application iOS ou Android en 2026. La version 1.16.2 génère des PDF, mais ni Word ni Notion.

FAQ : télécharger une conversation Claude en PNG

Ces questions couvrent l’export PNG dans Download Claude conversations 1.16.2 : PDF, exportation groupée Export All, limites et contenu de l’image. Chaque réponse est un fait sur le produit. Le JSON-LD FAQPage dans l’en-tête de la page correspond à cette liste.

Download Claude conversations exporte-t-il en PDF ?

Oui. Choisissez PDF dans le panneau d’exportation pour obtenir un document paginé, avec numéros de page et table des matières en option. PNG est une seule image de la conversation. Le PDF demande une connexion Google et reste gratuit jusqu’à 3 par jour ; PNG est illimité, sans compte.

Puis-je télécharger tout mon historique Claude en PNG ?

Oui. Export All, dans le tableau de bord, prend en charge PNG et produit un ZIP avec une image par conversation sélectionnée. L’exportation groupée demande une connexion Google ; dans l’offre gratuite, chaque conversation du ZIP utilise l’une des 3 exportations PDF ou groupées du jour. Pro est illimité.

PNG est-il gratuit ou réservé à Pro ?

Gratuit et illimité. Les exports PNG d’une conversation ne demandent aucun compte et n’ont pas de compteur. Pro, à 3,99 $ par mois ou 26,99 $ par an, sert au PDF et au ZIP groupé illimités.

Puis-je copier du code depuis un PNG de conversation Claude ?

Pas proprement. Un export PNG stocke des pixels. Exportez en Markdown ou en JSON si vous avez besoin de blocs de code avec balise de langage. Gardez les deux fichiers si vous voulez à la fois une image et du texte consultable.

L’export PNG est-il une capture d’écran de Chrome ?

Non. Download Claude conversations génère un PNG à partir de la conversation analysée sur claude.ai. Cela reste une image, pas un fichier Markdown. Une capture d’écran de toute la fenêtre par le système est un autre fichier, que vous réalisez vous-même.

PNG fonctionne-t-il sur Claude Desktop ?

Non. L’extension Chrome fonctionne sur claude.ai dans Chrome, pas dans l’application Claude Desktop. Claude Desktop n’affiche jamais l’option PNG. Ouvrez la même conversation sur claude.ai dans Chrome si elle y existe.

Un export PNG utilise-t-il le même quota que Markdown ?

Oui — ni l’un ni l’autre n’en a. Les exports PNG et Markdown d’une conversation sont tous deux illimités et anonymes. La seule limite est de 3 exportations PDF ou ZIP groupé par jour dans l’offre gratuite ; Pro la supprime.
