Comment télécharger une conversation Claude en PNG ?

Ouvrez la conversation sur claude.ai dans Chrome, cliquez sur le bouton orange à côté de la zone de message, choisissez PNG, puis cliquez sur « Export ». Download Claude conversations génère l’image dans l’onglet. C’est ainsi que l’on télécharge une conversation Claude en PNG avec la version 1.13.0.

  1. Installez Download Claude conversations depuis le Chrome Web Store (fiche notée 5.0).
  2. Rechargez claude.ai et ouvrez une vraie URL de conversation, pas la page d’accueil vide avec la zone de saisie.
  3. Cliquez sur le bouton de téléchargement orange à droite de la zone de message.
  4. Sélectionnez PNG. Le dernier format utilisé est mémorisé.
  5. Cliquez sur « Export ». Chrome télécharge le PNG immédiatement.

La connexion Google est requise avant votre premier export PNG. Download Claude conversations enregistre l’adresse e-mail vérifiée pour compter les 3 exportations gratuites et restaurer Pro après une réinstallation. Les images des conversations ne sont pas envoyées lors de cette connexion. Fonctionnement détaillé : comment ça marche.

Si le bouton orange n’apparaît pas, vous n’êtes pas sur une URL de conversation, l’onglet doit être rechargé après l’installation, ou l’extension est masquée dans le menu en forme de pièce de puzzle de Chrome. Épinglez Download Claude conversations, puis actualisez claude.ai. L’export PNG n’apparaît jamais dans Claude Desktop ni dans Claude Code.

Une image ou plusieurs. Le bouton orange crée un PNG de la conversation ouverte. Pour obtenir de nombreuses images, ouvrez « View and Download All Conversations » (afficher et télécharger toutes les conversations) et lancez « Export All » (Tout exporter) avec PNG sélectionné — voir exportation groupée Export All.

Quand télécharger une conversation Claude en PNG ?

Choisissez PNG quand vous avez besoin d’une image pour une présentation, une messagerie ou un ticket — partout où une image se dépose plus facilement qu’un fichier .md. Ne choisissez pas PNG si vous devrez plus tard rechercher du texte ou copier du code : prenez Markdown.

Une capture d’écran de claude.ai faite à la main inclut souvent la barre latérale et la zone de saisie. Download Claude conversations crée le PNG à partir du contenu de la conversation qu’il a déjà analysé, pas à partir d’une capture système prise au hasard. Cela reste une image : pas d’arborescence de messages, pas de balises de langage sur les blocs de code à copier en texte.

Nous avons ajouté PNG pour que vous puissiez enregistrer une capture visuelle d’une conversation claude.ai. Nous n’avons pas ajouté le PDF. Un export PNG vous donne un fichier image ; si vous avez besoin d’une page imprimable, utilisez la boîte de dialogue d’impression de Chrome, une fonction du navigateur et non un sixième format du produit.

L’équipe Download Claude conversations

Certains cherchent aussi Claude Chat Downloader pour trouver la même fiche. L’export PNG passe par ce bouton orange. Les pages juridiques peuvent encore mentionner Claude Exporter. Ces noms désignent ce produit, pas un second outil d’exportation.

Télécharger une conversation Claude en PNG, est-ce la même chose qu’un PDF ?

Non. PNG est un format d’image, PDF un format de document paginé. Download Claude conversations exporte en PNG, pas en PDF. Si vous avez vraiment besoin d’une page proche d’un PDF, imprimez l’onglet claude.ai dans Chrome (Ctrl/Cmd+P → Enregistrer au format PDF). Tutoriel : imprimer une conversation Claude.

N’attendez pas d’option PDF dans la liste des formats. La version 1.13.0, de septembre 2026, ne propose toujours que Markdown, JSON, texte brut, XML et PNG. Un PNG de cette extension n’est pas un PDF renommé. Page centrale : formats d’export des conversations Claude.

L’impression garde la barre latérale de claude.ai et coupe souvent le code sur plusieurs pages. L’export PNG se rapproche davantage d’une capture du contenu de la conversation. Aucune des deux méthodes n’est une archive structurée. Gardez un export Markdown ou JSON si vous risquez d’avoir besoin du texte plus tard.

Que contient l’export PNG d’une conversation Claude ?

Un export PNG est une seule image du contenu de la conversation, générée par Download Claude conversations. Contrairement à Markdown ou JSON, le PNG ne contient pas d’arborescence de messages analysable. Le code et les tableaux sont des pixels. La réflexion et les artifacts sont dessinés, pas stockés en texte.

La mise en page des artifacts (« Original », « Inline », « Nested », « Flat » — d’origine, intégrée, imbriquée, à plat) modifie toujours leur apparence dans l’image, avec les mêmes quatre options que les autres formats. Le filtre par expéditeur peut limiter le dessin à tous les messages, aux messages humains uniquement ou à ceux de l’assistant uniquement. Les métadonnées ne deviennent pas du texte sélectionnable dans le PNG, contrairement au JSON.

Si la conversation est très longue, faites défiler la page jusqu’à ce que claude.ai ait chargé les messages plus anciens avant l’export PNG. L’extension ne peut dessiner que ce que la page a chargé. Une conversation à moitié chargée donne une image tronquée. Liste complète des options : fonctionnalités de l’extension Chrome.

Gardez une copie texte si le contenu compte. PNG est une capture. Si vous devez plus tard chercher un nom de fonction, la recherche échouera. Exportez un second fichier en Markdown ou en JSON ; ce second fichier compte aussi dans les 3 exportations gratuites.

Peut-on télécharger des conversations Claude en PNG de façon groupée ?

Oui. Ouvrez « View and Download All Conversations », réglez le format sur PNG, filtrez le tableau, puis cliquez sur Export All. Chaque image terminée compte comme une exportation, sur le même quota de 3 exportations gratuites qu’un PNG via le bouton orange. Pro, à 3,99 $/mois ou 26,99 $/an, supprime cette limite pour le PNG groupé.

Le tableau liste l’historique claude.ai avec une recherche par nom et les filtres All, New, Exported et Project (toutes, nouvelles, exportées, projet). New désigne les conversations pas encore exportées avec Download Claude conversations. Export All produit un PNG par conversation sélectionnée, pas une planche-contact ni un classeur PDF.

Le quota s’applique à tout le compte. Sélectionner 40 conversations consomme 40 exportations si chaque PNG aboutit. Préparez votre sélection avant de cliquer sur Export All. Settings → Privacy → Export data (les libellés peuvent être traduits si claude.ai est réglé en français) reste une archive ZIP JSON envoyée en différé, pas un dossier d’images.

Télécharger une conversation Claude en PNG coûte-t-il plus cher ?

Non. PNG est inclus dans les 3 exportations gratuites de chaque compte connecté avec Google, comme Markdown, JSON, texte et XML. Après ces trois fichiers, Pro coûte 3,99 $ par mois ou 26,99 $ par an via Paddle. Download Claude conversations ne facture aucun supplément pour l’export PNG.

Les 3 exportations gratuites ne se réinitialisent pas quand vous réinstallez l’extension. C’est pourquoi la connexion Google est requise au premier clic sur « Export ». Pro se restaure sur un nouvel ordinateur avec le même compte Google. Paddle est le revendeur officiel (merchant of record) ; notre équipe ne voit jamais les numéros de carte.

L’extension ne fonctionne que sur claude.ai dans Chrome. Claude Desktop et Claude Code n’ont pas de bouton PNG. Notre équipe ne propose aucune application iOS ou Android en 2026. La version 1.13.0 ne génère toujours ni PDF, ni Word, ni Notion.

FAQ : télécharger une conversation Claude en PNG

Ces questions couvrent l’export PNG dans Download Claude conversations 1.13.0 : PDF, exportation groupée Export All, quota et contenu de l’image. Chaque réponse est un fait sur le produit. Le JSON-LD FAQPage dans l’en-tête de la page correspond à cette liste.

Download Claude conversations exporte-t-il en PDF ?

Non. Les formats actuels sont Markdown, JSON, texte brut, XML et PNG. PNG est ce qui se rapproche le plus d’une copie visuelle, mais c’est une image, pas un PDF. Imprimez la page claude.ai dans Chrome si vous avez besoin d’un fichier proche d’un PDF.

Puis-je télécharger tout mon historique Claude en PNG ?

Oui. Export All, sur la page d’exportation groupée, prend en charge PNG comme l’exportation d’une seule conversation et produit une image par conversation sélectionnée. Chaque image compte comme l’une des 3 exportations gratuites, sauf avec Pro.

PNG est-il gratuit ou réservé à Pro ?

Gratuit. Tous les formats, PNG compris, font partie des 3 exportations gratuites de tout compte connecté avec Google. Pro coûte 3,99 $/mois ou 26,99 $/an après ces trois fichiers.

Puis-je copier du code depuis un PNG de conversation Claude ?

Pas proprement. Un export PNG stocke des pixels. Exportez en Markdown ou en JSON si vous avez besoin de blocs de code avec balise de langage. Gardez les deux fichiers si vous voulez à la fois une image et du texte consultable.

L’export PNG est-il une capture d’écran de Chrome ?

Non. Download Claude conversations génère un PNG à partir de la conversation analysée sur claude.ai. Cela reste une image, pas un fichier Markdown. Une capture d’écran de toute la fenêtre par le système est un autre fichier, que vous réalisez vous-même.

PNG fonctionne-t-il sur Claude Desktop ?

Non. L’extension Chrome ne s’injecte que sur claude.ai. Claude Desktop n’affiche jamais l’option PNG. Ouvrez la même conversation sur claude.ai dans Chrome si elle y existe.

Un export PNG utilise-t-il le même quota que Markdown ?

Oui. Un PNG terminé compte pour une exportation, comme un fichier .md ou JSON. Les 3 exportations gratuites ne sont pas trois par format. Pro supprime la limite pour tous les formats, PNG compris.
