Comment exporter une conversation Claude en XML ?

Ouvrez la conversation sur claude.ai dans Chrome, cliquez sur le bouton orange à côté de la zone de message, choisissez XML, puis cliquez sur « Export ». Download Claude conversations génère le fichier en local. C’est ainsi que l’on exporte une conversation Claude en XML avec la version 1.13.0. En septembre 2026, claude.ai ne propose aucune commande native pour enregistrer en XML.

  1. Installez Download Claude conversations depuis le Chrome Web Store (fiche notée 5.0).
  2. Rechargez claude.ai et ouvrez une vraie URL de conversation, pas la page d’accueil vide avec la zone de saisie.
  3. Cliquez sur le bouton de téléchargement orange à droite de la zone de message.
  4. Sélectionnez XML. Le dernier format utilisé est mémorisé.
  5. Cliquez sur « Export ». Chrome télécharge le XML via l’API de téléchargement du navigateur.

La connexion Google est requise avant votre premier export XML. Download Claude conversations enregistre l’adresse e-mail vérifiée pour compter les 3 exportations gratuites et restaurer Pro après une réinstallation. Le texte des conversations ne fait pas partie de cette connexion. Fonctionnement détaillé : comment ça marche.

Si le bouton orange n’apparaît pas, vous n’êtes pas sur une URL de conversation, l’onglet doit être rechargé, ou l’extension est masquée dans le menu en forme de pièce de puzzle de Chrome. Épinglez Download Claude conversations, puis actualisez claude.ai. L’export XML n’apparaît jamais dans Claude Desktop ni dans Claude Code.

Un fichier ou plusieurs. Le bouton orange exporte la conversation ouverte en XML. Pour obtenir de nombreux fichiers XML, ouvrez « View and Download All Conversations » (afficher et télécharger toutes les conversations) et lancez « Export All » (Tout exporter) avec XML sélectionné — voir exportation groupée Export All.

Quand exporter une conversation Claude en XML ?

Choisissez XML quand le système destinataire, le pipeline ou l’outil ancien exige du XML pour l’échange de données structurées. La plupart des développeurs devraient plutôt choisir JSON. Markdown sert aux notes lisibles, PNG à obtenir une image. XML figure dans la liste parce que certains outils n’acceptent encore que le XML, et pas le JSON.

N’exportez pas en XML en pensant obtenir un JSON « plus officiel ». Download Claude conversations applique la même analyse dans les deux cas. La différence tient à la forme du fichier ; aucun champ supplémentaire n’apparaît comme par magie. Si aucun de vos outils n’exige du XML, passez ce format et utilisez JSON.

Nous proposons XML parce que certains pipelines l’exigent encore, pas parce que nous pensons qu’il surpasse JSON pour chaque export claude.ai. L’analyse est la même : messages, expéditeur, réflexion et artifacts en option. Nous ne générons toujours pas de PDF. La version 1.13.0 garde XML comme l’un des cinq formats, pas comme une option payante.

L’équipe Download Claude conversations

Certains cherchent aussi Claude Chat Downloader ou Claude Conversation Downloader pour trouver la même fiche. L’export XML passe par ce bouton orange. Les pages juridiques peuvent encore mentionner Claude Exporter. Ces noms désignent ce produit.

Que conserve l’export d’une conversation Claude en XML ?

Lors d’un export XML, Download Claude conversations écrit la structure de la conversation — messages, expéditeur et métadonnées disponibles — sous forme de balisage XML. Les blocs de réflexion et les artifacts suivent les mêmes options que Markdown et JSON. XML n’est pas une version appauvrie de ces formats.

Dans la version 1.13.0, la mise en page des artifacts est « Original », « Inline », « Nested » ou « Flat » (d’origine, intégrée, imbriquée ou à plat). Le filtre par expéditeur peut limiter le XML à tous les messages, aux messages humains uniquement ou à ceux de l’assistant uniquement. Les métadonnées (titre, horodatages, modèle) peuvent être ajoutées. Liste complète des options : fonctionnalités de l’extension Chrome.

Si la conversation est longue, faites défiler la page jusqu’à ce que claude.ai ait chargé les messages plus anciens avant d’exporter en XML. L’extension ne peut sérialiser que ce que la page a affiché. Un DOM à moitié chargé donne un XML tronqué.

XML ou JSON pour exporter une conversation Claude ?

JSON est le choix courant des développeurs. N’exportez en XML que si un système en aval l’exige. Download Claude conversations ne rend pas le XML « plus complet » que le JSON. Les deux peuvent inclure la réflexion et les artifacts. Aucun des deux n’est l’archive ZIP du compte Anthropic. Page centrale : formats d’export des conversations Claude.

XML comparé aux autres fichiers d’export claude.ai
Format À choisir pour
XML Un outil ou un schéma qui exige du XML
JSON Scripts, comparaisons, la plupart des pipelines modernes
Markdown Notes lisibles par un humain
Texte brut Aucun balisage
PNG Une image de la conversation

Settings → Privacy → Export data (les libellés peuvent être traduits si claude.ai est réglé en français) produit du JSON (dans un ZIP), pas du XML. Imprimer → Enregistrer au format PDF produit une capture de la page web. Aucune de ces options ne remplace l’export XML via le bouton orange. Ne vous attendez pas à ce que ce XML corresponde à un schéma Anthropic non publié.

L’extension ne fonctionne que sur claude.ai dans Chrome. Claude Desktop et Claude Code n’ont pas de bouton XML. Si la conversation existe aussi sur claude.ai, ouvrez-la là-bas et exportez-la en XML. Le /export de Claude Code est une autre voie, propre à ce produit.

Peut-on exporter des conversations Claude en XML de façon groupée ?

Oui. Ouvrez « View and Download All Conversations », réglez le format sur XML, filtrez le tableau, puis cliquez sur Export All. Chaque fichier terminé compte comme l’une des 3 exportations gratuites. Pro, à 3,99 $/mois ou 26,99 $/an, supprime cette limite pour le XML groupé.

Le tableau liste l’historique claude.ai avec une recherche par nom et les filtres All, New, Exported et Project (toutes, nouvelles, exportées, projet). New désigne les conversations pas encore exportées avec Download Claude conversations. Exported suit celles que vous avez déjà sauvegardées. Project reprend la façon dont vous regroupez vos conversations sur claude.ai. Export All produit de nombreux fichiers XML, pas une archive ZIP mélangée.

Le quota s’applique à tout le compte. Trois exportations gratuites au total — pas trois fichiers XML par exportation groupée. Sélectionner 40 conversations consomme 40 exportations si chaque fichier aboutit. Préparez votre sélection, ou passez à Pro.

Vous ne pouvez pas mélanger XML et JSON en un seul clic sur Export All. Choisissez XML pour cette exécution. Relancez Export All en JSON si vous avez besoin des deux versions d’une même conversation claude.ai ; la seconde exécution consomme aussi du quota.

Exporter une conversation Claude en XML nécessite-t-il Pro ?

Non. XML est inclus dans les 3 exportations gratuites de chaque compte connecté avec Google, comme Markdown, JSON, texte et PNG. Après ces trois fichiers, Pro coûte 3,99 $ par mois ou 26,99 $ par an via Paddle. Download Claude conversations ne réserve pas XML aux abonnés payants.

Les 3 exportations gratuites ne se réinitialisent pas quand vous réinstallez l’extension. C’est pourquoi la connexion Google est requise lors de votre premier export. Pro se restaure sur un nouvel ordinateur avec le même compte Google. Paddle est le revendeur officiel (merchant of record) ; notre équipe ne voit jamais les numéros de carte.

Vous n’avez pas besoin d’un abonnement payant claude.ai d’Anthropic, seulement d’un identifiant qui peut charger la conversation dans Chrome. La version 1.13.0, de septembre 2026, ne génère toujours ni PDF, ni Word, ni Notion. Si cette liste change, cette page sera mise à jour le jour même.

FAQ : exporter une conversation Claude en XML

Ces questions couvrent l’export XML dans Download Claude conversations 1.13.0 : comparaison avec JSON, exportation groupée Export All, quota, Desktop, PDF et Pro. Chaque réponse est un fait sur le produit. Le JSON-LD FAQPage dans l’en-tête de la page correspond à cette liste.

XML est-il meilleur que JSON pour exporter une conversation Claude ?

Pas en général. JSON est le choix le plus courant chez les développeurs. Exportez en XML quand le système en aval exige du XML pour l’échange de données structurées. L’analyse de claude.ai est la même ; seule la forme du fichier change.

Puis-je exporter des conversations Claude en XML de façon groupée ?

Oui. Le même processus Export All, sur la page de consultation, prend en charge XML. Chaque fichier terminé compte comme l’une des 3 exportations gratuites, sauf avec Pro à 3,99 $/mois ou 26,99 $/an.

XML est-il un format réservé aux abonnés payants ?

Non. Les cinq formats, XML compris, sont couverts par les 3 exportations gratuites de chaque compte connecté avec Google. Pro coûte 3,99 $/mois ou 26,99 $/an après ces trois fichiers.

L’export XML correspond-il à l’archive ZIP d’Anthropic ?

Non. Export data d’Anthropic est une archive ZIP JSON du compte, envoyée en différé. Download Claude conversations génère immédiatement dans Chrome un fichier XML par conversation (ou par sélection). Ce n’est pas le même schéma.

L’export XML crée-t-il un PDF ?

Non. XML est un balisage. Les formats du produit sont Markdown, JSON, texte brut, XML et PNG. Pour une page imprimable, utilisez la boîte de dialogue d’impression de Chrome. PNG est une image, pas un PDF non plus.

Puis-je exporter une conversation Claude en XML depuis Claude Desktop ?

Non. L’extension Chrome ne s’injecte que sur claude.ai. Claude Desktop n’affiche jamais la liste des formats. Ouvrez la même conversation sur claude.ai dans Chrome si elle y existe.

Ai-je besoin de Pro pour exporter une seule fois en XML ?

Non. Les 3 premières exportations sont gratuites, dans n’importe quel format, XML compris. Pro, à 3,99 $/mois ou 26,99 $/an, supprime la limite pour davantage de fichiers XML, individuels ou groupés.
