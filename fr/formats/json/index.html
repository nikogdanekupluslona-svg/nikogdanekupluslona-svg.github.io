Comment exporter une conversation Claude en JSON ?

Ouvrez la conversation sur claude.ai dans Chrome, cliquez sur le bouton orange à côté de la zone de message, choisissez JSON, puis cliquez sur « Export ». Download Claude conversations génère le fichier en local. C’est ainsi que l’on exporte une conversation Claude en JSON avec la version 1.13.0. En septembre 2026, claude.ai ne propose aucune commande pour enregistrer une conversation en JSON.

  1. Installez Download Claude conversations depuis le Chrome Web Store (fiche notée 5.0).
  2. Rechargez claude.ai et ouvrez une vraie URL de conversation, pas la page d’accueil vide avec la zone de saisie.
  3. Cliquez sur le bouton de téléchargement orange à droite de la zone de message.
  4. Sélectionnez JSON. Le dernier format utilisé est mémorisé.
  5. Cliquez sur « Export ». Chrome télécharge le JSON via l’API de téléchargement du navigateur.

La connexion Google est requise avant votre premier export JSON. Download Claude conversations enregistre l’adresse e-mail vérifiée pour compter les 3 exportations gratuites et restaurer Pro après une réinstallation. Le contenu des conversations ne fait pas partie de cette connexion. Fonctionnement détaillé : comment ça marche.

Si le bouton orange n’apparaît pas, vous n’êtes pas sur une URL de conversation, l’onglet doit être rechargé, ou l’extension est masquée dans le menu en forme de pièce de puzzle de Chrome. Épinglez Download Claude conversations, puis actualisez claude.ai. Le script de contenu ne s’injecte jamais dans Claude Desktop ni dans Claude Code.

Une conversation ou plusieurs fichiers. Le bouton orange exporte la conversation ouverte en JSON. Pour obtenir de nombreux fichiers JSON, ouvrez « View and Download All Conversations » (afficher et télécharger toutes les conversations) et lancez « Export All » (Tout exporter) avec JSON sélectionné — voir exportation groupée Export All.

Quand exporter une conversation Claude en JSON ?

Choisissez JSON quand un script, un outil d’indexation ou un outil de comparaison lira le fichier. Ce JSON est conçu pour l’arborescence des messages, pas pour la lecture dans Obsidian. Si vous voulez des titres et des blocs de code lisibles par un humain, choisissez plutôt Markdown.

Un copier-coller depuis claude.ai perd la structure des expéditeurs. L’impression garde l’habillage de la page web. Avec l’export JSON, Download Claude conversations conserve les tours de parole, les expéditeurs et, en option, la réflexion sous forme de données, et non comme un paragraphe aplati. C’est pourquoi les développeurs préfèrent JSON au texte brut.

Nous générons le JSON à partir de l’arborescence claude.ai déjà présente sur la page — expéditeur, blocs de contenu, horodatages, métadonnées du modèle — sans envoyer la conversation sur un serveur. Ce JSON n’est pas l’archive ZIP du compte Anthropic, ni un PDF. La version 1.13.0 ne propose toujours que cinq formats.

L’équipe Download Claude conversations

Certains cherchent aussi Claude Chat Downloader ou Claude Conversation Downloader pour trouver la même fiche. L’export JSON passe par ce bouton orange, pas par un second produit. Les pages juridiques peuvent encore mentionner Claude Exporter.

Que contient l’export JSON d’une conversation Claude ?

Un export JSON reproduit l’arborescence des messages de claude.ai : expéditeur, blocs de contenu, horodatages et métadonnées du modèle. Les blocs de réflexion et les artifacts sont inclus quand ces options sont activées. Le filtre par expéditeur peut limiter le fichier à tous les messages, aux messages humains uniquement ou à ceux de l’assistant uniquement. Rien n’est d’abord converti en Markdown.

Dans la version 1.13.0, la mise en page des artifacts est « Original », « Inline », « Nested » ou « Flat » (d’origine, intégrée, imbriquée ou à plat). Elle change la façon dont le contenu des artifacts est imbriqué dans le JSON — les mêmes quatre options que pour Markdown et XML. Liste complète des options : fonctionnalités de l’extension Chrome. Le JSON ne devient toujours pas un PDF.

Si la conversation est longue, faites défiler la page jusqu’à ce que claude.ai ait chargé les messages plus anciens avant d’exporter en JSON. L’extension ne peut sérialiser que ce que la page a affiché. Un DOM à moitié chargé donne un fichier JSON tronqué.

JSON d’une conversation Claude ou Export data d’Anthropic ?

Les deux sont en JSON, mais ni la structure ni la portée ne sont les mêmes. Settings → Privacy → Export data (les libellés peuvent être traduits si claude.ai est réglé en français) envoie par e-mail, après un délai, une seule archive ZIP de tout le compte. Avec l’export JSON de l’extension, vous obtenez une conversation immédiatement dans Chrome. Utilisez le ZIP pour la sauvegarde.

Deux façons différentes d’obtenir du JSON depuis claude.ai
Méthode Portée Arrivée du fichier
JSON de Download Claude conversations Cette conversation ou une sélection groupée Immédiatement, via un téléchargement Chrome
Settings → Privacy → Export data Tout le compte Lien par e-mail qui expire
Imprimer → Enregistrer au format PDF Page web visible Immédiatement, mais c’est un PDF, pas du JSON

Vous ne pouvez pas choisir Markdown dans la demande d’archive ZIP d’Anthropic. Et le JSON de cette extension ne remplace pas directement le schéma de ce ZIP. Page centrale : formats d’export des conversations Claude. L’impression est une solution de contournement visuelle, pas un export JSON.

Download Claude conversations n’est pas affilié à Anthropic, PBC. Le script de contenu utilise la session que vous avez déjà ouverte sur claude.ai. Il ne se connecte pas à Anthropic avec des identifiants distincts. Respectez les règles d’Anthropic pour votre compte.

Peut-on exporter des conversations Claude en JSON de façon groupée ?

Oui. Ouvrez « View and Download All Conversations », réglez le format sur JSON, filtrez le tableau, puis cliquez sur Export All. Chaque fichier terminé compte comme l’une des 3 exportations gratuites. Pro, à 3,99 $/mois ou 26,99 $/an, supprime cette limite pour le JSON groupé.

Le tableau liste l’historique claude.ai avec une recherche par nom et les filtres All, New, Exported et Project (toutes, nouvelles, exportées, projet). New désigne les conversations pas encore exportées avec Download Claude conversations. Exported suit celles que vous avez déjà sauvegardées. Project reprend la façon dont vous regroupez vos conversations sur claude.ai. Export All produit de nombreux fichiers JSON, pas une archive ZIP mélangée.

Le quota s’applique à tout le compte. Trois exportations gratuites au total — pas trois fichiers JSON par exportation groupée. Sélectionner 40 conversations consomme 40 exportations si chaque fichier aboutit. Préparez votre sélection, ou passez à Pro.

Vous pouvez comparer deux exports JSON d’une même conversation claude.ai réalisés à des moments différents, comme n’importe quel fichier JSON. Chaque export est autonome. Un second Export All des mêmes conversations consomme à nouveau du quota, sauf si ces fichiers n’aboutissent pas.

Exporter une conversation Claude en JSON nécessite-t-il Pro ?

Non. JSON est inclus dans les 3 exportations gratuites de chaque compte connecté avec Google, comme Markdown, texte, XML et PNG. Après ces trois fichiers, Pro coûte 3,99 $ par mois ou 26,99 $ par an via Paddle. Download Claude conversations ne facture aucun supplément pour l’export JSON.

Les 3 exportations gratuites ne se réinitialisent pas quand vous réinstallez l’extension. C’est pourquoi la connexion Google est requise au premier clic sur « Export ». Pro se restaure sur un nouvel ordinateur avec le même compte Google. Paddle est le revendeur officiel (merchant of record) ; notre équipe ne voit jamais les numéros de carte.

L’extension ne fonctionne que sur claude.ai dans Chrome. Claude Desktop et Claude Code n’ont pas de bouton JSON. Le /export de Claude Code ou les fichiers JSONL sur le disque sont une autre voie. La version 1.13.0, de septembre 2026, ne génère toujours ni PDF, ni Word, ni Notion.

FAQ : exporter une conversation Claude en JSON

Ces questions couvrent l’export JSON dans Download Claude conversations 1.13.0 : exportation groupée Export All, schéma, quota, comparaisons, archive ZIP d’Anthropic et Desktop. Chaque réponse est un fait sur le produit. Le JSON-LD FAQPage dans l’en-tête de la page correspond à cette liste.

Puis-je exporter des conversations Claude en JSON de façon groupée ?

Oui. Export All, sur la page de consultation, prend en charge JSON comme l’exportation d’une seule conversation. Chaque fichier terminé compte comme l’une des 3 exportations gratuites, sauf avec Pro à 3,99 $/mois ou 26,99 $/an.

La structure du JSON est-elle documentée ?

Elle reproduit l’arborescence des messages de claude.ai : expéditeur, blocs de contenu, horodatages et métadonnées du modèle, avec les artifacts et les blocs de réflexion si vous activez ces options. Ce n’est pas le schéma de l’archive ZIP du compte Anthropic.

Ai-je besoin de Pro pour exporter une conversation Claude en JSON ?

Non. JSON est inclus dans les 3 exportations gratuites de chaque compte connecté avec Google, comme tous les autres formats. Pro coûte 3,99 $/mois ou 26,99 $/an après ces trois fichiers.

Puis-je comparer deux exports JSON d’une même conversation ?

Oui. Chaque export JSON produit un fichier autonome, construit de la même manière. Comparer deux exports d’une même conversation réalisés à des moments différents se fait comme pour n’importe quel autre fichier JSON.

Ce JSON est-il identique à Export data d’Anthropic ?

Non. Export data d’Anthropic est une archive ZIP de tout le compte, envoyée en différé. Download Claude conversations génère immédiatement dans Chrome un fichier JSON par conversation (ou par sélection). Les deux peuvent être en JSON, mais ils ne sont pas interchangeables.

L’export JSON crée-t-il un PDF ?

Non. JSON est un format de données structurées. Les formats du produit sont Markdown, JSON, texte brut, XML et PNG. Pour une page imprimable, utilisez la boîte de dialogue d’impression de Chrome, pas cette liste déroulante.

L’export JSON fonctionne-t-il sur Claude Desktop ?

Non. L’extension Chrome ne s’injecte que sur claude.ai. Claude Desktop n’affiche jamais l’option JSON. Ouvrez la même conversation sur claude.ai dans Chrome si elle y existe.
