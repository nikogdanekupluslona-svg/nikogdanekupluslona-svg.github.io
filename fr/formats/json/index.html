Comment exporter une conversation Claude en JSON ?

Ouvrez la conversation sur claude.ai dans Chrome, cliquez sur le bouton orange à côté de la zone de message, choisissez JSON, puis cliquez sur « Export ». Download Claude conversations génère le fichier en local. C’est ainsi que l’on exporte une conversation Claude en JSON avec la version 1.16.2. En septembre 2026, claude.ai ne propose aucune commande pour enregistrer une conversation en JSON.

  1. Installez Download Claude conversations depuis le Chrome Web Store.
  2. Rechargez claude.ai et ouvrez une vraie URL de conversation, pas la page d’accueil vide avec la zone de saisie.
  3. Cliquez sur le bouton de téléchargement orange à droite de la zone de message.
  4. Sélectionnez JSON. Le dernier format utilisé est mémorisé. Utilisez « Select » (sélectionner) pour ne cocher que les messages voulus.
  5. Cliquez sur « Export ». Chrome télécharge le JSON via l’API de téléchargement du navigateur. Ou cliquez sur « Copy » (copier) pour placer le JSON dans le presse-papier.

Aucune connexion n’est nécessaire pour exporter une conversation Claude en JSON. Les exports JSON d’une conversation sont illimités, anonymes et n’envoient rien à nos serveurs. La connexion Google n’est demandée que pour le PDF et l’exportation groupée Export All. Fonctionnement détaillé : comment ça marche.

Si le bouton orange n’apparaît pas, vous n’êtes pas sur une URL de conversation, l’onglet doit être rechargé, ou l’extension est masquée dans le menu en forme de pièce de puzzle de Chrome. Épinglez Download Claude conversations, puis actualisez claude.ai. Le script de contenu ne s’injecte jamais dans Claude Desktop ni dans le terminal Claude Code.

Une conversation ou plusieurs fichiers. Le bouton orange exporte la conversation ouverte en JSON. Pour obtenir de nombreux fichiers JSON, ouvrez « View and Download All Conversations » (afficher et télécharger toutes les conversations) et lancez « Export All » (Tout exporter) avec JSON sélectionné : un seul ZIP, 3 conversations par jour dans l’offre gratuite — voir exportation groupée Export All.

Quand exporter une conversation Claude en JSON ?

Choisissez JSON quand un script, un outil d’indexation ou un outil de comparaison lira le fichier. Ce JSON est conçu pour l’arborescence des messages, pas pour la lecture dans Obsidian. Si vous voulez des titres et des blocs de code lisibles par un humain, choisissez plutôt Markdown. Pour un tableur, choisissez CSV : une ligne par message.

Un copier-coller depuis claude.ai perd la structure des expéditeurs. L’impression garde l’habillage de la page web. Avec l’export JSON, Download Claude conversations conserve les tours de parole, les expéditeurs et, en option, la réflexion sous forme de données, et non comme un paragraphe aplati. C’est pourquoi les développeurs préfèrent JSON au texte brut.

Nous générons le JSON à partir de l’arborescence claude.ai déjà présente sur la page — expéditeur, blocs de contenu, horodatages, métadonnées du modèle — sans envoyer la conversation sur un serveur. Ce JSON n’est pas l’archive ZIP du compte Anthropic. Dans la version 1.16.2, c’est l’un des sept formats, à côté du PDF et du CSV, et il est gratuit, sans compte.

L’équipe Download Claude conversations

Certains cherchent aussi Claude Chat Downloader ou Claude Conversation Downloader pour trouver la même fiche. L’export JSON passe par ce bouton orange, pas par un second produit. Les pages juridiques peuvent encore mentionner Claude Exporter.

Que contient l’export JSON d’une conversation Claude ?

Un export JSON reproduit l’arborescence des messages de claude.ai : expéditeur, blocs de contenu, horodatages et métadonnées du modèle. Les blocs de réflexion, les sources de recherche web, les étapes d’outils / MCP et les artifacts sont inclus quand ces options sont activées : la réflexion est une case « Thinking » (réflexion) du panneau d’exportation, les outils et les sources s’activent dans les réglages de l’extension. Le filtre par expéditeur peut limiter le fichier à tous les messages, aux messages humains uniquement ou à ceux de l’assistant uniquement. Rien n’est d’abord converti en Markdown.

Dans la version 1.16.2, la mise en page des artifacts est « Original », « Inline », « Nested » ou « Flat » (d’origine, intégrée, imbriquée ou à plat). Elle change la façon dont le contenu des artifacts est imbriqué dans le JSON — les mêmes quatre options que pour Markdown et XML. Liste complète des options : fonctionnalités de l’extension Chrome. Pour des pages plutôt que des données, exportez en PDF.

Si la conversation est longue, faites défiler la page jusqu’à ce que claude.ai ait chargé les messages plus anciens avant d’exporter en JSON. L’extension ne peut sérialiser que ce que la page a affiché. Un DOM à moitié chargé donne un fichier JSON tronqué.

JSON d’une conversation Claude ou Export data d’Anthropic ?

Les deux sont en JSON, mais ni la structure ni la portée ne sont les mêmes. Settings → Privacy → Export data (les libellés peuvent être traduits si claude.ai est réglé en français) envoie par e-mail, après un délai, une seule archive ZIP de tout le compte. Avec l’export JSON de l’extension, vous obtenez une conversation immédiatement dans Chrome. Utilisez le ZIP pour la sauvegarde.

Deux façons différentes d’obtenir du JSON depuis claude.ai
Méthode Portée Arrivée du fichier
JSON de Download Claude conversations Cette conversation ou une sélection groupée Immédiatement, via un téléchargement Chrome
Settings → Privacy → Export data Tout le compte Lien par e-mail qui expire
PDF de Download Claude conversations Cette conversation, sous forme de pages Immédiatement, mais c’est un PDF, pas du JSON

Vous ne pouvez pas choisir Markdown dans la demande d’archive ZIP d’Anthropic. Et le JSON de cette extension ne remplace pas directement le schéma de ce ZIP. Page centrale : formats d’export des conversations Claude. Le PDF sert à la lecture, ce n’est pas un export JSON.

Download Claude conversations n’est pas affilié à Anthropic, PBC. Le script de contenu utilise la session que vous avez déjà ouverte sur claude.ai. Il ne se connecte pas à Anthropic avec des identifiants distincts. Respectez les règles d’Anthropic pour votre compte.

Peut-on exporter des conversations Claude en JSON de façon groupée ?

Oui. Ouvrez « View and Download All Conversations », réglez « Chat format » (format des conversations) sur JSON, filtrez le tableau, puis cliquez sur Export All. Chrome enregistre un seul ZIP avec un fichier JSON par conversation. Dans l’offre gratuite, c’est 3 conversations par jour avec connexion Google, limite partagée avec le PDF. Pro, à 3,99 $ par mois ou 26,99 $ par an, supprime cette limite pour le JSON groupé.

Le tableau de bord liste l’historique claude.ai avec une recherche par nom, les filtres All conversations, New, Updated et Previously exported (toutes les conversations, nouvelles, mises à jour, déjà exportées), les onglets Chat et Cowork et une recherche par projet. New désigne les conversations pas encore exportées avec Download Claude conversations. Previously exported suit celles que vous avez déjà sauvegardées. Export All produit un seul ZIP de fichiers JSON, un par conversation, pas une archive aux formats mélangés.

La limite quotidienne s’applique par compte. Trois conversations par jour dans l’offre gratuite, limite partagée avec le PDF. Si vous sélectionnez 40 conversations alors qu’il vous en reste 3, tout le lot est bloqué, pas tronqué. Sélectionnez-en moins ou passez à Pro. Les exports JSON individuels via le bouton orange restent illimités.

Vous pouvez comparer deux exports JSON d’une même conversation claude.ai réalisés à des moments différents, comme n’importe quel fichier JSON. Chaque export est autonome. Un second Export All des mêmes conversations compte à nouveau chaque conversation.

Exporter une conversation Claude en JSON nécessite-t-il Pro ?

Non. L’export JSON d’une conversation est gratuit et illimité, sans compte ni compteur — comme Markdown, texte, XML, CSV et PNG. Seuls le PDF et l’exportation groupée Export All ont une limite gratuite : 3 par jour avec connexion Google. Pro coûte 3,99 $ par mois ou 26,99 $ par an via Paddle. Download Claude conversations ne facture aucun supplément pour l’export JSON.

C’est avec le JSON groupé que la limite apparaît. Chaque conversation d’un ZIP Export All utilise l’une des 3 du jour, et le compteur se remet à zéro à minuit UTC. Pro supprime cette limite et se restaure sur un nouvel ordinateur avec le même compte Google. Paddle est le revendeur officiel (merchant of record) ; notre équipe ne voit jamais les numéros de carte.

L’extension ne fonctionne que sur claude.ai dans Chrome. Claude Desktop et le terminal Claude Code n’ont pas de bouton JSON ; Claude Code sur le web (claude.ai/code) tourne sur claude.ai et s’exporte donc comme n’importe quelle conversation. Le /export de Claude Code dans le terminal ou les fichiers JSONL sur le disque sont une autre voie. La version 1.16.2, de septembre 2026, ne génère toujours ni Word ni Notion.

FAQ : exporter une conversation Claude en JSON

Ces questions couvrent l’export JSON dans Download Claude conversations 1.16.2 : exportation groupée Export All, schéma, coût, comparaisons, archive ZIP d’Anthropic, PDF et Desktop. Chaque réponse est un fait sur le produit. Le JSON-LD FAQPage dans l’en-tête de la page correspond à cette liste.

Puis-je exporter des conversations Claude en JSON de façon groupée ?

Oui. Export All, dans le tableau de bord, prend en charge JSON et enregistre un seul ZIP avec un fichier JSON par conversation. Dans l’offre gratuite, il couvre 3 conversations par jour avec connexion Google ; Pro, à 3,99 $ par mois ou 26,99 $ par an, est illimité.

La structure du JSON est-elle documentée ?

Elle reproduit l’arborescence des messages de claude.ai : expéditeur, blocs de contenu, horodatages et métadonnées du modèle, avec les artifacts, les blocs de réflexion, les sources de recherche web et les étapes d’outils / MCP si vous activez ces options. Ce n’est pas le schéma de l’archive ZIP du compte Anthropic.

Ai-je besoin de Pro pour exporter une conversation Claude en JSON ?

Non. Les exports JSON d’une conversation sont illimités et ne demandent aucun compte, comme tous les formats sauf le PDF. Pro, à 3,99 $ par mois ou 26,99 $ par an, lève seulement la limite de 3 par jour sur le PDF et l’exportation groupée Export All.

Puis-je comparer deux exports JSON d’une même conversation ?

Oui. Chaque export JSON produit un fichier autonome, construit de la même manière. Comparer deux exports d’une même conversation réalisés à des moments différents se fait comme pour n’importe quel autre fichier JSON.

Ce JSON est-il identique à Export data d’Anthropic ?

Non. Export data d’Anthropic est une archive ZIP de tout le compte, envoyée en différé. Download Claude conversations génère immédiatement dans Chrome un fichier JSON par conversation (ou par sélection). Les deux peuvent être en JSON, mais ils ne sont pas interchangeables.

L’export JSON crée-t-il un PDF ?

Non. JSON est un format de données structurées. Pour des pages, choisissez PDF dans le même panneau ; les sept formats sont PDF, Markdown, JSON, texte brut, XML, CSV et PNG. Le PDF demande une connexion Google et compte dans les 3 par jour de l’offre gratuite.

L’export JSON fonctionne-t-il sur Claude Desktop ?

Non. L’extension Chrome ne s’injecte que sur claude.ai. Claude Desktop n’affiche jamais l’option JSON. Ouvrez la même conversation sur claude.ai dans Chrome si elle y existe.
