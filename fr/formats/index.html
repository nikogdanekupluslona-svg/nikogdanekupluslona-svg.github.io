Quels sont les formats d’export des conversations Claude proposés ici ?

Sur ce site, les formats d’export des conversations Claude sont les cinq types de fichiers que Download Claude conversations génère à partir d’une conversation claude.ai : Markdown, JSON, texte brut, XML et PNG. La version 1.13.0 ne génère pas de PDF. Chaque fichier terminé compte comme l’une des 3 exportations gratuites.

L’extension Chrome ne s’injecte que sur claude.ai. Claude Desktop et Claude Code n’affichent jamais le bouton orange. Si la même conversation existe sur votre compte claude.ai, ouvrez cette URL dans Chrome et choisissez-y un format. La liste déroulante retient le dernier format utilisé.

Certains cherchent aussi Claude Chat Downloader ou Claude Conversation Downloader pour trouver la même fiche. Ces noms désignent ce produit, pas un second outil d’exportation. Les pages juridiques peuvent encore mentionner Claude Exporter. Les fichiers obtenus restent du Markdown, du JSON, du texte, du XML ou du PNG.

Une seule liste, deux points d’entrée. Le bouton orange et Export All partagent les mêmes formats d’export. Une exportation groupée produit de nombreux fichiers individuels, pas une archive ZIP mélangée. Détails : exportation groupée Export All.

Quel format d’export des conversations Claude choisir ?

Choisissez Markdown pour vos notes, JSON pour vos scripts, le texte brut pour une archive à coller partout, XML quand un système l’exige et PNG pour une image de la conversation. Download Claude conversations ne désigne aucun format comme le meilleur. Les formats diffèrent par leur structure, pas par le quota.

Format Idéal pour Nature du fichier

Les rédacteurs optent généralement pour Markdown, les développeurs pour JSON. PNG est le seul format image : vous ne pourrez ni y rechercher du texte ni en copier proprement du code plus tard. Si vous avez besoin d’une page imprimable, utilisez la boîte de dialogue d’impression de Chrome. Il s’agit d’une capture du navigateur, pas d’un sixième format du produit.

Nous proposons cinq formats d’export — Markdown, JSON, texte, XML et PNG — et nous ne générons toujours pas de PDF. La liste déroulante est la même sur le bouton orange et dans Export All, pour qu’une exportation groupée n’invente jamais un autre type de fichier.

Comment choisir un format d’export des conversations Claude ?

Ouvrez l’URL d’une conversation sur claude.ai dans Chrome, cliquez sur le bouton orange à côté de la zone de message, choisissez un format, puis cliquez sur « Export » (Exporter). Download Claude conversations assemble le fichier dans l’onglet. En septembre 2026, claude.ai ne propose aucune commande native pour exporter une conversation.

  1. Installez Download Claude conversations depuis le Chrome Web Store (fiche notée 5.0).
  2. Rechargez claude.ai et ouvrez une vraie URL de conversation, pas la page d’accueil vide avec la zone de saisie.
  3. Cliquez sur le bouton de téléchargement orange à droite de la zone de message.
  4. Choisissez Markdown, JSON, texte brut, XML ou PNG. Le dernier format est mémorisé.
  5. Cliquez sur « Export ». Chrome enregistre le fichier immédiatement.

La connexion Google est requise avant la première exportation. Download Claude conversations enregistre l’adresse e-mail vérifiée pour compter les 3 exportations gratuites et restaurer Pro après une réinstallation. Le texte des conversations ne fait pas partie de cette connexion. Fonctionnement détaillé : comment ça marche.

Les options du même widget s’appliquent à tous les formats : réflexion activée ou non (« include thinking »), métadonnées (« include metadata » : titre, horodatages, modèle), filtre par expéditeur (« all / human only / assistant only » : tous, humain uniquement, assistant uniquement) et mise en page des artifacts (« Original », « Inline », « Nested », « Flat »). PNG produit toujours une image ; les quatre autres formats écrivent du texte ou un balisage structuré.

Les formats d’export fonctionnent-ils dans Export All ?

Oui. Ouvrez « View and Download All Conversations » (afficher et télécharger toutes les conversations), filtrez le tableau, choisissez un format dans la même liste déroulante, puis cliquez sur Export All. Chaque fichier terminé compte comme l’une des 3 exportations gratuites. Pro, à 3,99 $/mois ou 26,99 $/an, supprime cette limite pour les exportations groupées comme individuelles.

Le tableau liste l’historique claude.ai avec une recherche par nom et les filtres All, New, Exported et Project (toutes, nouvelles, exportées, projet). New désigne les conversations pas encore exportées avec Download Claude conversations. Exported suit celles que vous avez déjà sauvegardées. Project reprend la façon dont vous regroupez vos conversations sur claude.ai. Export All n’est pas une archive ZIP du compte envoyée en différé.

Le quota s’applique à tout le compte. Trois exportations gratuites au total — pas trois par format ni trois par exportation groupée. Sélectionner 40 conversations consomme 40 exportations si chaque fichier aboutit. Préparez votre sélection, ou passez à Pro.

L’exportation groupée utilise les mêmes options de réflexion, de métadonnées, d’expéditeur et d’artifacts qu’une seule conversation. Vous n’obtenez pas un lot mélangé Markdown + JSON en un clic : vous choisissez un format pour chaque exécution. Relancez Export All avec un autre format si vous avez besoin de deux versions de la même conversation ; cette seconde exécution consomme aussi du quota.

Formats d’export des conversations Claude ou archive ZIP d’Anthropic ?

Dans claude.ai, Settings → Privacy → Export data (les libellés peuvent être traduits si claude.ai est réglé en français) envoie par e-mail, après un délai, une archive ZIP JSON de tout le compte. Download Claude conversations enregistre immédiatement la conversation ouverte en Markdown, JSON, texte, XML ou PNG. Utilisez le ZIP pour la sauvegarde, et cette extension quand vous en avez besoin tout de suite.

Récupérer une conversation Claude depuis claude.ai
Méthode Ce que vous obtenez Attente
Download Claude conversations MD / JSON / TXT / XML / PNG Non — Chrome télécharge le fichier
Settings → Privacy → Export data Archive ZIP JSON du compte, par e-mail Oui — le lien expire ; pas de Markdown par conversation
Imprimer → Enregistrer au format PDF PDF de la page web Non, mais le code et la barre latérale sont souvent abîmés

L’archive officielle n’est pas une version plus soignée de ces formats d’export. Vous ne pouvez pas y choisir Markdown. Et Download Claude conversations ne peut pas remplacer ce ZIP si vous voulez toutes vos conversations oubliées dans une seule archive. L’impression est une solution de contournement visuelle, pas un format que nous proposons.

Download Claude conversations n’est pas affilié à Anthropic, PBC. Utiliser l’extension ne modifie pas les conditions d’utilisation d’Anthropic. Le script de contenu utilise la session que vous avez déjà ouverte sur claude.ai. Respectez les règles d’Anthropic pour votre compte.

Combien coûtent les formats d’export des conversations Claude ?

Chaque compte connecté avec Google dispose de 3 exportations gratuites. Ensuite, Pro coûte 3,99 $ par mois ou 26,99 $ par an via Paddle. Ce prix couvre tous les formats d’export : Download Claude conversations ne facture rien de plus pour JSON ou PNG.

Les 3 exportations gratuites ne se réinitialisent pas quand vous réinstallez l’extension. C’est pourquoi la connexion Google est requise au premier clic sur « Export ». Pro se restaure sur un nouvel ordinateur avec le même compte Google. Paddle est le revendeur officiel (merchant of record) ; notre équipe ne voit jamais les numéros de carte.

La version décrite ici est la 1.13.0, datée de septembre 2026. Les formats d’export restent Markdown, JSON, texte brut, XML et PNG. Il n’existe toujours ni export Notion, ni Word, ni PDF natif. Si cette liste change, cette page sera mise à jour le jour même.

FAQ : formats d’export des conversations Claude

Ces questions couvrent les formats d’export de Download Claude conversations 1.13.0 : la liste des cinq fichiers, le quota, Export All, l’archive ZIP d’Anthropic, Desktop et Pro. Chaque réponse est un fait sur le produit. Le JSON-LD FAQPage dans l’en-tête de la page correspond à cette liste.

Dans quels formats puis-je télécharger une conversation Claude ?

Markdown, JSON, texte brut, XML et PNG. Download Claude conversations ne génère pas de PDF. PNG est une image de la conversation claude.ai, pas un document paginé.

Le PDF fait-il partie des formats d’export des conversations Claude ?

Non. La liste déroulante du produit ne propose jamais le PDF. Pour une page proche d’un PDF, imprimez l’onglet claude.ai dans Chrome. Ce fichier est une capture du navigateur, pas une exportation de cette extension.

Les formats d’export partagent-ils les 3 exportations gratuites ?

Oui. Markdown, JSON, texte, XML et PNG comptent chacun pour une exportation une fois le fichier terminé. Pro, à 3,99 $/mois ou 26,99 $/an, supprime la limite pour tous les formats.

Puis-je mélanger plusieurs formats dans Export All ?

Non. Une exécution d’Export All utilise un seul format. Relancez-la avec un autre format si vous avez besoin de deux fichiers pour la même conversation claude.ai. Chaque fichier terminé compte toujours dans le quota.

Ces formats d’export sont-ils identiques à Export data ?

Non. Export data d’Anthropic est une archive ZIP JSON de tout le compte, envoyée en différé. Les formats d’export des conversations Claude sont des fichiers par conversation (ou par sélection), générés immédiatement dans Chrome par Download Claude conversations.

Ces formats d’export fonctionnent-ils sur Claude Desktop ou Claude Code ?

Non. L’extension Chrome ne s’injecte que sur claude.ai. Claude Desktop et Claude Code n’affichent jamais la liste des formats. Ouvrez la même conversation sur claude.ai dans Chrome si elle y existe.

Ai-je besoin de Pro pour essayer ces formats d’export ?

Non. Les 3 premières exportations de tout compte connecté avec Google sont gratuites, dans n’importe quel format. Pro coûte 3,99 $/mois ou 26,99 $/an si vous avez besoin de davantage de fichiers, individuels ou groupés.
