Quels sont les formats d’export des conversations Claude proposés ici ?

Sur ce site, les formats d’export des conversations Claude sont les sept types de fichiers que Download Claude conversations génère à partir d’une conversation claude.ai : PDF, Markdown, texte brut, JSON, XML, CSV et PNG. La version 1.16.2 les construit tous dans votre navigateur. Six sont illimités, sans compte. Le PDF demande une connexion Google et reste gratuit jusqu’à 3 par jour.

L’extension fonctionne partout où une conversation s’ouvre sur claude.ai dans Chrome : conversations, projets, sessions Cowork et Claude Code sur le web (claude.ai/code). L’application Claude Desktop et les sessions locales de Claude Code dans le terminal n’affichent jamais le bouton orange. Si la même conversation existe sur votre compte claude.ai, ouvrez cette URL dans Chrome et choisissez-y un format. La liste déroulante retient le dernier format utilisé.

Certains cherchent aussi Claude Chat Downloader ou Claude Conversation Downloader pour trouver la même fiche. Ces noms désignent ce produit, pas un second outil d’exportation. Les pages juridiques peuvent encore mentionner Claude Exporter. Les fichiers obtenus restent les mêmes sept formats.

Une seule liste, deux points d’entrée. Le bouton orange exporte la conversation ouverte. Export All, dans le tableau de bord, exporte de nombreuses conversations dans un seul ZIP, un fichier par conversation, dans celui des sept formats que vous choisissez comme « Chat format » (format des conversations) — PDF compris. Détails : exportation groupée Export All.

Quel format d’export des conversations Claude choisir ?

Choisissez PDF pour lire et partager, Markdown pour vos notes, JSON pour vos scripts, CSV pour les tableurs, le texte brut pour une archive à coller partout, XML quand un système l’exige et PNG pour une image de la conversation. Download Claude conversations ne désigne aucun format comme le meilleur. Les formats diffèrent par leur structure ; seul le PDF a une limite quotidienne dans l’offre gratuite.

Les rédacteurs optent généralement pour Markdown, les développeurs pour JSON. PNG est le seul format image : vous ne pourrez ni y rechercher du texte ni en copier proprement du code plus tard. Si vous avez besoin d’une page imprimable, choisissez PDF : l’extension le génère directement, avec format de page, marges, mode clair ou sombre et table des matières. La boîte de dialogue d’impression de Chrome n’est qu’une solution de repli.

CSV écrit une ligne par message : une conversation devient une feuille que vous pouvez trier et filtrer. Le fichier s’ouvre dans Excel, Google Sheets et Numbers. Il n’existe pas de guide CSV séparé ; cette page le couvre. Comme Markdown, JSON, XML et le texte brut, CSV peut aussi aller dans le presse-papier avec « Copy » (copier) au lieu d’être téléchargé.

Nous proposons sept formats d’export des conversations Claude — PDF, Markdown, texte brut, JSON, XML, CSV et PNG — et chacun est généré dans votre navigateur. Six sont illimités, sans compte. PDF et ZIP groupé demandent une connexion Google et sont gratuits jusqu’à 3 par jour.

Comment choisir un format d’export des conversations Claude ?

Ouvrez l’URL d’une conversation sur claude.ai dans Chrome, cliquez sur le bouton orange à côté de la zone de message, choisissez un format, puis cliquez sur « Export » (exporter). Download Claude conversations assemble le fichier dans l’onglet. En septembre 2026, claude.ai ne propose aucune commande native pour exporter une conversation.

  1. Installez Download Claude conversations depuis le Chrome Web Store.
  2. Rechargez claude.ai et ouvrez une vraie URL de conversation, pas la page d’accueil vide avec la zone de saisie.
  3. Cliquez sur le bouton rond orange de téléchargement, à droite de la zone de message.
  4. Choisissez PDF, Markdown, texte brut, JSON, XML, CSV ou PNG. Le dernier format est mémorisé.
  5. Cliquez sur « Export ». Chrome enregistre le fichier immédiatement. Pour le PDF, réglez les options dans la boîte de dialogue PDF ; le premier PDF demande une connexion Google.

Aucune connexion pour Markdown, texte, JSON, XML, CSV ou PNG : ces exportations sont illimitées, anonymes et n’envoient rien. La connexion Google n’apparaît que pour le PDF, Export All ou Pro. L’extension n’envoie alors que l’adresse e-mail Google, pour vérifier la limite quotidienne et restaurer Pro après une réinstallation. Le texte des conversations n’est jamais envoyé. Fonctionnement détaillé : comment ça marche.

Le panneau d’exportation règle aussi « Messages » (« All », « Human », « Assistant » : tous, humain, assistant), une case « Thinking » (réflexion) et « Select » (sélectionner), qui permet de cocher des messages précis. « Copy » place Markdown, texte, JSON, XML ou CSV dans le presse-papier au lieu d’un fichier ; c’est illimité, mais indisponible pour PDF et PNG. Les étapes d’outils / MCP et les sources de recherche web s’activent dans les réglages de l’extension. Les métadonnées et la mise en page des artifacts (« Original », « Inline », « Nested », « Flat ») sont des options du tableau de bord ; la mise en page décide si les artifacts restent dans le fichier ou vont dans leur propre dossier du ZIP.

Les formats d’export fonctionnent-ils dans Export All ?

Oui. Ouvrez la fenêtre de l’extension → « View and Download All Conversations » (afficher et télécharger toutes les conversations), filtrez la liste, cochez les conversations, choisissez l’un des sept formats comme « Chat format », puis cliquez sur Export All. Vous obtenez un seul ZIP, avec un fichier par conversation. L’exportation groupée demande une connexion Google ; dans l’offre gratuite, chaque conversation du ZIP utilise l’une des 3 exportations PDF ou groupées du jour. Pro, à 3,99 $ par mois ou 26,99 $ par an, supprime cette limite.

Le tableau de bord liste l’historique claude.ai avec une recherche par nom, une recherche par projet, les onglets Chat et Cowork, et les filtres All conversations, New, Updated et Previously exported (toutes les conversations, nouvelles, mises à jour, déjà exportées). New désigne les conversations pas encore exportées avec Download Claude conversations. Previously exported suit celles que vous avez déjà sauvegardées. Export All n’est pas une archive ZIP du compte envoyée en différé.

La limite de l’exportation groupée est quotidienne. Dans l’offre gratuite, PDF et exportation groupée partagent 3 exportations par jour, remises à zéro à minuit UTC. Chaque conversation d’un ZIP compte pour une. Si vous en sélectionnez plus qu’il ne vous en reste aujourd’hui, tout le lot est bloqué, pas tronqué. Sélectionnez moins de conversations, ou passez à Pro.

L’exportation groupée a ses propres cases à cocher — « Chats », « Thinking », « Metadata », « Tools », « Sources » (conversations, réflexion, métadonnées, outils, sources) — plus la mise en page des artifacts. Vous n’obtenez pas un lot mélangé Markdown + JSON en un clic : pour chaque exécution, vous choisissez un seul format dans le sélecteur « Chat format ». Relancez Export All avec un autre format si vous avez besoin de deux versions de la même conversation ; dans l’offre gratuite, cette seconde exécution compte à nouveau.

Formats d’export des conversations Claude ou archive ZIP d’Anthropic ?

Dans claude.ai, Settings → Privacy → Export data (les libellés peuvent être traduits si claude.ai est réglé en français) envoie par e-mail, après un délai, une archive ZIP JSON de tout le compte. Download Claude conversations enregistre immédiatement la conversation ouverte en PDF, Markdown, texte, JSON, XML, CSV ou PNG. Utilisez le ZIP pour la sauvegarde, et cette extension quand vous en avez besoin tout de suite.

L’archive officielle n’est pas une version plus soignée de ces formats d’export. Vous ne pouvez y choisir ni Markdown ni PDF. Et Download Claude conversations ne peut pas remplacer ce ZIP si vous voulez toutes vos conversations oubliées dans une seule archive. L’impression est une solution de contournement visuelle ; le PDF de l’extension donne un fichier plus propre.

Download Claude conversations n’est pas affilié à Anthropic, PBC. Utiliser l’extension ne modifie pas les conditions d’utilisation d’Anthropic. Le script de contenu utilise la session que vous avez déjà ouverte sur claude.ai. Respectez les règles d’Anthropic pour votre compte.

Combien coûtent les formats d’export des conversations Claude ?

Six formats d’export des conversations Claude ne coûtent rien et ne demandent aucun compte : Markdown, texte brut, JSON, XML, CSV et PNG sont illimités. PDF et ZIP groupé sont gratuits jusqu’à 3 par jour au total, avec connexion Google. Pro coûte 3,99 $ par mois ou 26,99 $ par an via Paddle et rend le PDF et l’exportation groupée illimités. Download Claude conversations ne facture aucun format en supplément.

Le compteur quotidien se remet à zéro à minuit UTC et suit votre compte Google : c’est pourquoi PDF et exportation groupée demandent une connexion. Pro se restaure sur un nouvel ordinateur quand vous vous connectez avec le même compte Google. Paddle est le revendeur officiel (merchant of record) ; notre équipe ne voit jamais les numéros de carte. Résiliez à tout moment depuis la page d’options de l’extension ; le premier paiement bénéficie d’une garantie de remboursement de 14 jours.

FAQ : formats d’export des conversations Claude

Ces questions couvrent les formats d’export de Download Claude conversations 1.16.2 : la liste des sept formats, le PDF, le CSV, les limites, Export All, l’archive ZIP d’Anthropic, Desktop et Code, et Pro. Chaque réponse est un fait sur le produit. Le JSON-LD FAQPage dans l’en-tête de la page correspond à cette liste.

Dans quels formats puis-je télécharger une conversation Claude ?

Sept : PDF, Markdown, texte brut, JSON, XML, CSV et PNG. Markdown, texte, JSON, XML, CSV et PNG sont illimités et ne demandent aucun compte. Le PDF demande une connexion Google et reste gratuit jusqu’à 3 par jour.

Le PDF fait-il partie des formats d’export des conversations Claude ?

Oui. Choisissez PDF dans le panneau d’exportation. La boîte de dialogue PDF règle le nom du fichier, le format de page, les marges, le mode clair ou sombre, la police et sa taille, les numéros de page, une table des matières, les horodatages et un saut de page avant chaque prompt. Le fichier est généré dans le navigateur, sans boîte de dialogue d’impression.

À quoi sert l’export CSV ?

Aux tableurs. CSV écrit une ligne par message et s’ouvre dans Excel, Google Sheets et Numbers. C’est illimité, sans compte, et vous pouvez le copier dans le presse-papier au lieu de le télécharger.

Les formats d’export ont-ils une limite quotidienne ?

Seulement le PDF et l’exportation groupée. Les exportations individuelles en Markdown, texte, JSON, XML, CSV et PNG sont illimitées et gratuites. PDF et ZIP groupé partagent 3 exportations par jour dans l’offre gratuite, remises à zéro à minuit UTC. Pro, à 3,99 $ par mois ou 26,99 $ par an, supprime la limite.

Puis-je mélanger plusieurs formats dans Export All ?

Non. Une exécution d’Export All utilise un seul format et produit un seul ZIP. Relancez-la avec un autre format si vous avez besoin de deux fichiers pour la même conversation claude.ai. Dans l’offre gratuite, chaque conversation de chaque ZIP compte dans les 3 exportations PDF ou groupées du jour.

Ces formats d’export sont-ils identiques à Export data ?

Non. Export data d’Anthropic est une archive ZIP JSON de tout le compte, envoyée en différé. Les formats d’export des conversations Claude sont des fichiers par conversation (ou par sélection), générés immédiatement dans Chrome par Download Claude conversations.

Ces formats d’export fonctionnent-ils sur Claude Desktop ou Claude Code ?

Sur le web, oui. Les conversations, les projets, les sessions Cowork et Claude Code sur le web (claude.ai/code) disposent de tous les formats dans Chrome. L’application Claude Desktop et les sessions locales de Claude Code dans le terminal n’affichent jamais la liste des formats. Ouvrez la même conversation sur claude.ai dans Chrome si elle y existe.

Ai-je besoin de Pro pour essayer ces formats d’export ?

Non. Six formats sont illimités dans l’offre gratuite, sans compte. Le PDF est gratuit jusqu’à 3 par jour avec connexion Google, limite partagée avec le ZIP groupé. Pro coûte 3,99 $ par mois ou 26,99 $ par an si vous avez besoin de PDF ou d’exportations groupées illimités.
