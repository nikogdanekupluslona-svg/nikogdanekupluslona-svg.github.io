Comment exporter une conversation Claude en Markdown ?

Ouvrez la conversation sur claude.ai dans Chrome, cliquez sur le bouton orange à côté de la zone de message, choisissez Markdown, puis cliquez sur « Export ». Download Claude conversations génère un fichier .md en local. C’est ainsi que l’on exporte une conversation Claude en Markdown avec la version 1.13.0.

  1. Installez Download Claude conversations depuis le Chrome Web Store (fiche notée 5.0).
  2. Rechargez claude.ai et ouvrez une vraie URL de conversation, pas la page d’accueil vide avec la zone de saisie.
  3. Cliquez sur le bouton de téléchargement orange à droite de la zone de message.
  4. Sélectionnez Markdown. L’extension retient le dernier format utilisé.
  5. Cliquez sur « Export ». Chrome télécharge le fichier .md via l’API de téléchargement du navigateur.

La connexion Google est requise avant votre premier export en Markdown. Download Claude conversations enregistre l’adresse e-mail vérifiée pour compter les 3 exportations gratuites et restaurer Pro après une réinstallation. Le texte des conversations n’est pas envoyé lors de cette connexion. Fonctionnement détaillé : comment ça marche.

Si le bouton orange n’apparaît pas, vous n’êtes pas sur une URL de conversation, l’onglet doit être rechargé après l’installation, ou l’extension est encore masquée dans le menu en forme de pièce de puzzle de Chrome. Épinglez Download Claude conversations, puis actualisez claude.ai. Le script de contenu ne s’injecte jamais dans Claude Desktop ni dans Claude Code.

Une conversation ou plusieurs. Le bouton orange exporte la conversation ouverte en Markdown. Pour obtenir de nombreux fichiers .md, ouvrez « View and Download All Conversations » (afficher et télécharger toutes les conversations) et lancez « Export All » (Tout exporter) avec Markdown sélectionné — voir exportation groupée Export All.

Pourquoi exporter une conversation Claude en Markdown pour ses notes ?

Choisissez Markdown si vous lirez le fichier dans Obsidian, un wiki GitHub ou tout éditeur qui affiche les titres et les blocs de code. Le fichier .md reste du texte brut que vous pouvez rechercher et comparer. JSON convient mieux aux parseurs ; PNG est une image dans laquelle on ne peut pas chercher de texte.

Un copier-coller depuis claude.ai supprime généralement l’indentation et aplatit les tableaux. L’impression (Ctrl/Cmd+P) garde la barre latérale et coupe souvent un long bloc de code sur plusieurs pages. Avec l’export en Markdown, les balises de langage restent sur les blocs de code et les tableaux restent des tableaux. C’est pourquoi les rédacteurs choisissent ce format en premier.

Nous considérons Markdown comme le fichier lisible par défaut : titres, blocs de code avec balise de langage et tableaux issus de la conversation claude.ai. Nous n’inventons toujours pas de format PDF — si vous avez besoin d’une page imprimable, utilisez la boîte de dialogue d’impression de Chrome après l’export en Markdown ou à sa place.

L’équipe Download Claude conversations

Certains cherchent aussi Claude Chat Downloader pour trouver la même fiche. L’export en Markdown passe par le même bouton orange, pas par un second produit. Les pages juridiques peuvent encore mentionner Claude Exporter. Tous ces noms désignent Download Claude conversations.

Que conserve l’export d’une conversation Claude en Markdown ?

Lors d’un export en Markdown, Download Claude conversations conserve les titres, les blocs de code avec balise de langage et indentation, les tableaux et les liens. Les blocs de réflexion sont facultatifs. Les métadonnées (titre, horodatages, modèle) peuvent être ajoutées. Le filtre par expéditeur peut limiter le fichier .md à tous les messages, aux messages humains uniquement ou à ceux de l’assistant uniquement.

La mise en page des artifacts est une vraie option dans la version 1.13.0 : « Original », « Inline », « Nested » ou « Flat » (d’origine, intégrée, imbriquée ou à plat). Un export Markdown peut reproduire la structure des artifacts affichée à l’écran ou l’aplatir en un seul document linéaire. Liste complète des options : fonctionnalités de l’extension Chrome. Markdown ne conserve pas les couleurs des bulles de message ; utilisez PNG si vous avez besoin d’une capture visuelle.

Si la conversation est très longue, faites défiler la page jusqu’à ce que claude.ai ait chargé les messages plus anciens avant d’exporter. L’extension ne peut écrire que ce que la page a affiché. Une conversation à moitié chargée donne un fichier .md à moitié rempli : cela ressemble à un bug, mais il s’agit le plus souvent d’un DOM que l’on n’a pas fait défiler.

Peut-on exporter des conversations Claude en Markdown de façon groupée ?

Oui. Ouvrez « View and Download All Conversations », réglez le format sur Markdown, filtrez le tableau, puis cliquez sur Export All. Chaque fichier .md terminé compte comme une exportation, sur le même quota de 3 exportations gratuites qu’un export via le bouton orange. Pro, à 3,99 $/mois ou 26,99 $/an, supprime cette limite pour le Markdown groupé.

Le tableau liste l’historique claude.ai avec une recherche par nom et les filtres All, New, Exported et Project (toutes, nouvelles, exportées, projet). New désigne les conversations pas encore exportées avec Download Claude conversations. Exported suit celles que vous avez déjà sauvegardées, pour qu’un second Export All puisse les ignorer. Project reprend la façon dont vous regroupez vos conversations sur claude.ai.

Le quota s’applique à tout le compte. Trois exportations gratuites au total — pas trois fichiers Markdown par jour. Sélectionner 40 conversations consomme 40 exportations si chaque fichier .md aboutit. Préparez votre sélection avant de cliquer sur Export All.

L’export Markdown groupé utilise les mêmes options de réflexion, de métadonnées, d’expéditeur et d’artifacts qu’une seule conversation. Export All n’est pas l’archive ZIP différée d’Anthropic : il produit de nombreux fichiers .md, un par conversation. Si vous voulez une archive de tout le compte, c’est Settings → Privacy → Export data (les libellés peuvent être traduits si claude.ai est réglé en français), en JSON et non en Markdown.

Markdown ou JSON pour exporter une conversation Claude ?

Choisissez Markdown quand une personne lira le fichier, JSON quand un script analysera l’arborescence des messages. Download Claude conversations propose les deux dans la même liste déroulante, avec le texte brut, XML et PNG. Toujours pas de PDF. Page centrale : formats d’export des conversations Claude.

Markdown comparé aux autres fichiers d’export claude.ai
Format À choisir pour
Markdown Notes, Obsidian, GitHub, wikis
JSON Comparaisons, pipelines, outils — guide JSON
Texte brut Aucun balisage, archive à coller partout
XML Un système qui exige du XML
PNG Une image de la conversation, pas du texte consultable

Export data d’Anthropic est aussi du JSON, mais il s’agit d’une archive ZIP du compte envoyée par e-mail, pas d’un fichier .md par conversation. Vous ne pouvez pas y choisir Markdown. Imprimer → Enregistrer au format PDF produit une capture de la page web. Aucune de ces options ne remplace l’export en Markdown via le bouton orange.

L’extension ne fonctionne que sur claude.ai dans Chrome. Claude Desktop et Claude Code n’ont pas de bouton Markdown. Si la conversation existe aussi sur claude.ai, ouvrez-la là-bas et exportez-la en Markdown. Le /export de Claude Code est une autre voie, propre à ce produit.

Exporter une conversation Claude en Markdown coûte-t-il plus cher ?

Non. Markdown est inclus dans les 3 exportations gratuites de chaque compte connecté avec Google, comme JSON, texte, XML et PNG. Après ces trois fichiers, Pro coûte 3,99 $ par mois ou 26,99 $ par an via Paddle. Download Claude conversations ne facture aucun supplément pour Markdown.

Les 3 exportations gratuites ne se réinitialisent pas quand vous réinstallez l’extension. C’est pourquoi la connexion Google est requise lors de votre premier export. Pro se restaure sur un nouvel ordinateur avec le même compte Google. Paddle est le revendeur officiel (merchant of record) ; notre équipe ne voit jamais les numéros de carte.

Vous n’avez pas besoin d’un abonnement payant claude.ai d’Anthropic, seulement d’un identifiant qui peut charger la conversation dans Chrome. Les offres Team et Enterprise fonctionnent comme Free avec le bouton orange. La version 1.13.0, de septembre 2026, ne génère toujours ni Word, ni Notion, ni PDF.

FAQ : exporter une conversation Claude en Markdown

Ces questions couvrent l’export en Markdown dans Download Claude conversations 1.13.0 : blocs de code, exportation groupée Export All, archive ZIP d’Anthropic, quota et Desktop. Chaque réponse est un fait sur le produit. Le JSON-LD FAQPage dans l’en-tête de la page correspond à cette liste.

Exporter une conversation Claude en Markdown fait-il perdre du code ?

Non. Les blocs de code conservent leur balise de langage et leur indentation, contrairement à un simple copier-coller depuis claude.ai. Les tableaux restent des tableaux Markdown. C’est la principale raison d’exporter en Markdown plutôt que de sélectionner le texte à la main.

Puis-je exporter des conversations Claude en Markdown de façon groupée ?

Oui. Export All, sur la page de consultation, prend en charge Markdown comme l’exportation d’une seule conversation. Chaque fichier .md terminé compte comme l’une des 3 exportations gratuites, sauf avec Pro.

Le Markdown est-il identique à Export data d’Anthropic ?

Non. L’export officiel d’Anthropic est une archive ZIP JSON de tout votre compte, envoyée par e-mail après un délai. L’export en Markdown est un fichier .md par conversation (ou par sélection), créé par Download Claude conversations.

Le Markdown coûte-t-il plus cher que les autres formats ?

Non. Markdown est inclus dans les 3 exportations gratuites de tout compte connecté avec Google, comme JSON, texte, XML et PNG. Ensuite, Pro coûte 3,99 $/mois ou 26,99 $/an pour des fichiers illimités.

Puis-je exporter une conversation Claude en Markdown depuis Claude Desktop ?

Non. Download Claude conversations ne s’injecte que sur claude.ai dans Chrome. Claude Desktop n’affiche jamais la liste des formats. Ouvrez la même conversation sur claude.ai si elle y existe.

L’export en Markdown crée-t-il un PDF ?

Non. Markdown est un fichier texte .md. Le produit ne génère pas de PDF. Pour une page imprimable, utilisez la boîte de dialogue d’impression de Chrome. PNG est une image, pas un PDF non plus.

Ai-je besoin de Pro pour exporter une seule fois en Markdown ?

Non. Les 3 premières exportations sont gratuites, dans n’importe quel format, Markdown compris. Pro, à 3,99 $/mois ou 26,99 $/an, supprime la limite pour davantage de fichiers .md, individuels ou groupés.
