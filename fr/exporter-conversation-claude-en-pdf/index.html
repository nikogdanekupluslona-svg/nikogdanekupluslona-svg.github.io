Exporter une conversation Claude en PDF en un clic — avec les bons réglages

Pour exporter une conversation Claude en PDF : installez Download Claude conversations, ouvrez la conversation sur claude.ai, cliquez sur le bouton orange, choisissez PDF, puis cliquez sur « Export » (exporter). L’extension génère le PDF dans votre navigateur, avec votre format de page, vos marges, le mode sombre ou clair et une table des matières. C’est gratuit jusqu’à 3 PDF par jour.

claude.ai n’a pas de bouton PDF, et Ctrl+P vous donne la page web découpée en pages — barre latérale, blocs de code coupés et tout le reste. Ce guide montre comment obtenir un document propre : les cinq étapes, le rôle de chaque réglage PDF, comment réunir des messages choisis dans un seul PDF, et que faire quand le fichier n’a pas l’allure attendue. Comment exporter une conversation Claude en PDF ?

Pour exporter une conversation Claude en PDF, il vous faut Chrome sur ordinateur et l’extension gratuite Download Claude conversations. Cinq clics suffisent : ouvrir la conversation, cliquer sur le bouton orange, choisir PDF, cliquer sur « Export », puis valider la boîte de dialogue PDF. Le premier PDF vous demande de vous connecter avec Google.

  1. Installez Download Claude conversations depuis le Chrome Web Store, puis rechargez les onglets claude.ai déjà ouverts.
  2. Ouvrez la conversation sur claude.ai et attendez que la dernière réponse soit entièrement affichée.
  3. Cliquez sur le bouton rond orange de téléchargement, à droite de la zone de saisie. Le panneau d’exportation s’ouvre.
  4. Sous « Format », choisissez PDF. Laissez « Messages » sur « All » (tous), ou choisissez « Human » (humain) ou « Assistant » pour ne garder qu’un côté de la conversation.
  5. Cliquez sur « Export ». Connectez-vous avec Google la première fois, réglez les options du PDF, puis enregistrez le fichier.

Ces cinq étapes valent pour les conversations classiques, les projets, les sessions Cowork et Claude Code sur le web (claude.ai/code). Tout ce qui s’ouvre sur claude.ai dans Chrome peut être exporté en PDF. L’extension ne fonctionne ni dans l’application Claude Desktop ni sur téléphone ; ouvrez plutôt la même conversation dans Chrome sur ordinateur.

La réflexion étendue est une case « Thinking » (réflexion) dans le panneau d’exportation. Les étapes d’outils et MCP ainsi que les sources de recherche web s’activent dans les paramètres de l’extension. Le PDF ne contient que ce que vous avez coché : une conversation au long raisonnement peut donc rester courte sur papier.

Limite PDF de l’offre gratuite. L’export PDF demande une connexion Google et reste gratuit jusqu’à 3 par jour, au total avec les exports ZIP groupés ; le compteur repart à zéro à minuit UTC. Pro — 3,99 $ par mois ou 26,99 $ par an — rend le PDF illimité. Markdown, texte, JSON, XML, CSV et PNG restent illimités, sans compte.

Quels réglages PDF choisir pour exporter une conversation ?

La boîte de dialogue PDF décide de l’allure d’une conversation Claude une fois devenue document. Le format de page, les marges et la police déterminent la lisibilité. Les numéros de page, la table des matières et les horodatages rendent une longue conversation facile à parcourir. Un saut de page avant chaque prompt fait commencer chaque question sur une nouvelle page.

Nom du fichier
Réglez-le avant d’enregistrer si vous classez vos PDF par projet ou par date.
Format de page
A4 ou Letter pour l’impression ; prenez le papier qu’utilisent vos lecteurs.
Marges
Des marges étroites laissent de la place au code et aux tableaux larges ; des marges normales se lisent mieux sur papier.
Mode clair ou sombre
Clair pour imprimer, sombre pour lire le PDF sur un écran.
Police et taille de police
Une taille plus grande aide sur tablette ; une taille plus petite fait tenir les longues réponses sur moins de pages.
Numéros de page
Utiles dès que quelqu’un dira « voir page 12 ».
Table des matières
Ajoute une page de sommaire : une conversation de 40 messages devient facile à parcourir.

Indiquent quand chaque message a été envoyé — pratique pour les archives et les relectures.

Chaque question commence sur une nouvelle page : aucune réponse ne démarre en milieu de page.

Les blocs de code gardent leur langage et leur mise en forme dans le PDF, et les tableaux et les listes restent des tableaux et des listes. C’est la principale raison d’exporter une conversation Claude en PDF plutôt que de l’imprimer : l’impression coupe le code là où la feuille s’arrête.

Pourquoi un PDF ? Adobe, qui a créé le format, décrit le PDF comme « un moyen simple et fiable de présenter et d’échanger des documents, quels que soient le logiciel, le matériel ou le système d’exploitation utilisés ». Une conversation Claude exportée en PDF s’ouvre de la même façon sur l’ordinateur portable d’un collègue, le téléphone d’un client ou une imprimante.

Nous générons le PDF dans votre navigateur, donc les réglages font ce qu’ils annoncent : format de page, marges, mode sombre, numéros de page, table des matières et saut de page avant chaque prompt. L’impression ne peut vous donner que la page web. Si vous devez modifier le texte avant de le partager, exportez plutôt en Markdown.

Comment enregistrer en PDF sans installer d’extension ?

Pour enregistrer une conversation Claude en PDF sans rien installer, utilisez la boîte de dialogue d’impression de Chrome : ouvrez la conversation, appuyez sur Ctrl+P sous Windows ou Cmd+P sur Mac, choisissez la destination « Enregistrer au format PDF », puis enregistrez. Le fichier est une capture de la page web, pas un document exporté, et il n’offre aucun réglage propre à Claude.

  1. Ouvrez la conversation sur claude.ai et remontez jusqu’au tout premier message pour que tous les échanges soient chargés.
  2. Réduisez la barre latérale et fermez les panneaux d’artifacts que vous ne voulez pas sur papier.
  3. Appuyez sur Ctrl+P ou Cmd+P. Sous « Destination », choisissez « Enregistrer au format PDF ».
  4. Ouvrez « Plus de paramètres », choisissez la taille du papier et les marges, et cochez « Graphiques d’arrière-plan » si la page paraît délavée.
  5. Cliquez sur « Enregistrer ».

L’aide de Google Chrome termine la même procédure par une seule ligne : « Cliquez sur Enregistrer au format PDF. » C’est tout ce que l’impression sait faire. Elle n’ajoute ni numérotation par prompt, ni table des matières, ni mode sombre.

Ce qui se retrouve sur chaque page dépend de la feuille de style d’impression de claude.ai, pas de vous. MDN décrit les médias paginés CSS comme les règles qui précisent « la manière dont les pages sont générées et mises en page pour accueillir un contenu fragmenté dans une présentation paginée ». Quand ces règles coupent un bloc de code, le PDF garde la coupure.

Chargez d’abord toute la conversation. Les longues conversations Claude ne chargent les anciens messages que lorsque vous remontez. Une impression ou un export fait avant ressemble à un PDF dont le début manque. Remontez tout en haut, patientez une seconde, puis imprimez ou exportez.

L’impression suffit pour un besoin ponctuel. Pour une comparaison détaillée entre l’impression et un vrai fichier PDF, téléphones compris, voir conversation Claude en PDF.

Comment obtenir une conversation Claude en un seul PDF ?

Un clic sur « Export » donne un seul fichier PDF qui contient toute la conversation Claude, du premier prompt à la dernière réponse. Vous ne pouvez pas copier une conversation Claude en PDF dans le presse-papiers — « Copy » (copier) fonctionne pour Markdown, texte, JSON, XML et CSV — mais le fichier exporté est déjà un PDF unique.

Pour ne mettre qu’une partie de la conversation dans un seul PDF, utilisez « Select » (sélectionner). Cliquez sur « Select » dans le panneau d’exportation, cochez les messages voulus, choisissez PDF et cliquez sur « Export ». Le PDF ne contient que ces messages, dans l’ordre. Le filtre « Messages » fait la même chose pour un seul côté : « Assistant » ne garde que les réponses de Claude, « Human » ne garde que vos prompts.

Plusieurs conversations ne fusionnent jamais en un seul PDF. L’export groupé écrit un PDF par conversation dans un ZIP. S’il vous faut un seul document, exportez les conversations et assemblez les PDF dans n’importe quel éditeur de PDF, ou exportez en Markdown et collez les conversations dans un seul fichier avant de le convertir.

Comment convertir en PDF en passant par Markdown ?

Passez par Markdown pour convertir une conversation Claude en PDF quand vous voulez d’abord modifier le texte. Exportez la conversation en Markdown — illimité, sans compte —, ouvrez le fichier .md dans un éditeur comme VS Code, Obsidian ou Typora, retouchez-le, puis utilisez la commande d’impression ou d’export en PDF de cet éditeur.

  1. Sur claude.ai, cliquez sur le bouton orange, choisissez Markdown et cliquez sur « Export ». Ni connexion, ni compteur.
  2. Ouvrez le fichier dans votre éditeur. Supprimez des messages, corrigez les titres, ajoutez vos propres notes.
  3. Utilisez l’export PDF de l’éditeur ou Imprimer → Enregistrer au format PDF, avec votre propre modèle et vos polices.

Markdown fonctionne bien comme étape intermédiaire parce qu’il reste lisible en texte brut. John Gruber, créateur de Markdown, a écrit que « Markdown est conçu pour être aussi facile à lire et à écrire que possible. » Vous pouvez retoucher une conversation Claude en Markdown sans vous battre avec le balisage, puis la mettre en page une seule fois.

La contrepartie : deux outils au lieu d’un. Si vous n’avez rien à modifier, le PDF de l’extension est plus rapide et comporte déjà numéros de page et table des matières. Markdown ne touche jamais à la limite quotidienne de PDF, ce qui aide avec l’offre gratuite. Plus d’informations sur le format : export Markdown.

L’export de compte d’Anthropic est un mauvais point de départ pour une conversion. C’est un ZIP de JSON pour tout le compte : il faudrait d’abord en extraire une conversation, puis transformer le JSON en texte lisible. Exporter en Markdown depuis la conversation ouverte évite tout cela.

Peut-on exporter plusieurs conversations Claude en PDF ?

Oui. Le tableau de bord de l’extension exporte plusieurs conversations Claude en PDF en une seule fois : réglez « Chat format » (format de conversation) sur PDF, cochez les conversations et cliquez sur « Export All » (tout exporter). Vous obtenez un ZIP avec un PDF par conversation. Avec l’offre gratuite, chaque conversation du ZIP compte dans les 3 exports quotidiens.

  1. Cliquez sur l’icône de l’extension dans Chrome et choisissez « View and Download All Conversations » (afficher et télécharger toutes les conversations).
  2. Filtrez ou recherchez dans la liste, puis cochez les conversations voulues.
  3. Réglez « Chat format » sur PDF. Choisissez d’inclure ou non « Thinking », « Metadata » (métadonnées), « Tools » (outils) et « Sources ».
  4. Cliquez sur « Export All » et enregistrez le ZIP.

Si vous cochez plus de conversations que votre quota gratuit du jour, tout le lot est bloqué au lieu d’être tronqué ; choisissez moins de conversations ou passez à Pro. Pro supprime la limite pour le PDF comme pour l’export groupé. La procédure complète, avec filtres et options d’artifacts, se trouve dans le guide d’export groupé.

Gardez vos PDF du jour pour l’essentiel. Pour une grosse archive, exportez d’abord en groupe au format Markdown ou JSON — tous deux illimités — et n’exportez en PDF que les conversations que vous allez vraiment envoyer ou imprimer.

Pourquoi mon PDF de conversation Claude est-il raté ?

La plupart des PDF ratés de conversations Claude ont l’une de ces quatre causes : la conversation n’était pas entièrement chargée, le menu « Format » était resté sur le dernier format utilisé, la limite gratuite du jour était atteinte, ou vous avez imprimé au lieu d’exporter. Chaque cause a sa solution rapide, dans le tableau ci-dessous.

Problèmes d’export PDF d’une conversation Claude et solutions
Symptôme Cause Solution
Les premiers messages manquent Les anciens échanges n’étaient pas chargés Remontez en haut de la conversation, patientez, exportez à nouveau
Vous avez obtenu un fichier .md, pas un PDF Le panneau retient le dernier format Réglez « Format » sur PDF avant de cliquer sur « Export »
L’export vous propose de passer à Pro Les 3 exports PDF ou groupés gratuits du jour sont épuisés Attendez minuit UTC, exportez en Markdown ou passez à Pro
Blocs de code coupés, barre latérale visible Le PDF vient de l’impression, pas de l’export Utilisez plutôt le bouton orange → PDF
Le raisonnement manque « Thinking » était décoché Cochez « Thinking » dans le panneau d’exportation
Sources web ou étapes d’outils absentes Elles sont désactivées par défaut Activez-les dans les paramètres de l’extension

Un PDF raté compte quand même avec l’offre gratuite : vérifiez donc le menu « Format » avant de cliquer sur « Export ». Si le bouton orange n’apparaît pas, rechargez claude.ai après l’installation ; le bouton s’affiche à côté de la zone de saisie sur chaque page de conversation.

Exporter une conversation Claude en PDF : quelle méthode ?

Trois méthodes transforment une conversation Claude en fichier, et une seule produit un vrai PDF d’une conversation. L’extension exporte un PDF paginé en quelques secondes. L’impression donne une capture de la page web. Export data d’Anthropic envoie par e-mail un ZIP de tout le compte, et ce n’est pas un PDF.

La voie officielle se trouve dans claude.ai, sous Settings → Privacy → Export data (les libellés peuvent être traduits si claude.ai est réglé en français). Le centre d’aide de Claude explique : « Une fois l’export traité, vous recevrez un lien de téléchargement par e-mail. » La même page précise que « le lien de téléchargement expirera 24 heures après son envoi ».

Extension → PDF PDF paginé d’une conversation, avec réglages Quelques secondes Connexion Google ; 3 par jour gratuits
Imprimer → Enregistrer au format PDF Capture de la page web Quelques secondes Aucun
Extension → Markdown → éditeur Votre propre PDF mis en page Quelques minutes Aucun
Settings → Privacy → Export data ZIP de JSON pour tout le compte E-mail plus tard ; lien valable 24 heures Votre compte Claude

Pour une conversation que vous allez envoyer, archiver ou imprimer, exportez-la en PDF avec l’extension. Imprimez quand vous ne pouvez rien installer, passez par Markdown quand vous devez d’abord modifier le texte, et utilisez le ZIP officiel pour une sauvegarde complète. Pour tous les autres formats et méthodes, voir comment exporter une conversation Claude.

Claude Code dans un terminal, c’est différent : une session locale n’est pas une page web, utilisez donc /export — voir exporter une conversation Claude Code. Download Claude conversations est une extension Chrome indépendante, non affiliée à Anthropic, PBC. Chaque PDF est généré en local ; le texte des conversations n’est jamais envoyé, stocké ni analysé.

FAQ : exporter une conversation Claude en PDF

Comment exporter une conversation Claude en PDF ?

Installez Download Claude conversations, ouvrez la conversation sur claude.ai, cliquez sur le bouton orange à côté de la zone de saisie, choisissez PDF et cliquez sur « Export ». Connectez-vous avec Google la première fois, réglez le format de page et les autres options, puis enregistrez. Le PDF est généré dans votre navigateur.

Comment enregistrer une conversation Claude en PDF gratuitement ?

L’export PDF de l’extension est gratuit jusqu’à 3 PDF par jour avec une connexion Google. La boîte de dialogue d’impression de Chrome (Ctrl+P ou Cmd+P → Enregistrer au format PDF) est gratuite et sans limite, mais donne une capture de la page web. Exporter en Markdown puis convertir dans un éditeur est aussi gratuit et illimité.

Comment télécharger une conversation Claude en PDF ?

Ici, télécharger et exporter reviennent au même : choisissez PDF dans le panneau d’exportation et Chrome enregistre le fichier comme n’importe quel téléchargement. Pour comparer côte à côte l’impression et le fichier exporté, voir conversation Claude en PDF.

Puis-je copier une conversation Claude en un seul PDF ?

Pas dans le presse-papiers — « Copy » prend en charge Markdown, texte, JSON, XML et CSV, pas le PDF. Cliquez plutôt sur « Export » : un export donne un seul fichier PDF avec toute la conversation. Pour n’inclure que certains messages, utilisez « Select » avant d’exporter.

Puis-je exporter uniquement les réponses de Claude en PDF ?

Oui. Réglez « Messages » sur « Assistant » dans le panneau d’exportation, choisissez PDF et cliquez sur « Export ». Le PDF contient alors les réponses de Claude sans vos prompts. « Human » fait l’inverse.

Le PDF d’une conversation Claude garde-t-il le code et les tableaux ?

Oui, quand vous exportez. Les blocs de code gardent leur langage et leur mise en forme, et les tableaux et les listes restent intacts. L’impression est le point faible : les blocs de code reviennent à la ligne ou se coupent entre deux pages, et les tableaux larges sont tronqués.

Puis-je exporter une conversation Claude en PDF en mode sombre ?

Oui. La boîte de dialogue PDF propose un mode clair et un mode sombre. Le sombre convient à la lecture sur écran ; le clair est préférable pour imprimer sur papier.

Puis-je convertir une conversation Claude en PDF sur mon téléphone ?

Pas avec l’extension, qui ne fonctionne que dans Chrome et les navigateurs Chromium sur ordinateur. Un navigateur mobile peut imprimer ou partager la page en PDF, mais la mise en page est à l’étroit. Pour un PDF propre, ouvrez la même conversation dans Chrome sur ordinateur.

Puis-je exporter une session Claude Code en PDF ?

Claude Code sur le web (claude.ai/code) s’ouvre sur claude.ai, donc l’extension l’exporte en PDF comme n’importe quelle conversation. Une session dans le terminal n’est pas une page web : utilisez /export et imprimez le fichier texte depuis un éditeur.

Ma conversation Claude est-elle envoyée quand je l’exporte en PDF ?

Non. Le PDF est généré dans votre navigateur, comme tous les autres formats. Après la connexion, seule votre adresse e-mail Google est envoyée, pour vérifier la limite quotidienne ou Pro.

Pourquoi ai-je obtenu un fichier Markdown au lieu d’un PDF de ma conversation Claude ?

Le panneau d’exportation retient le dernier format utilisé. Réglez « Format » sur PDF avant de cliquer sur « Export ». Avec l’offre gratuite, vérifiez-le d’abord, car chaque PDF compte dans les 3 par jour.
