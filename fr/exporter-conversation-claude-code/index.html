Exporter une conversation Claude Code ou claude.ai : choisir la bonne méthode

Exporter une conversation Claude Code se fait dans le terminal. Tapez /export dans la session, ou copiez le JSONL depuis ~/.claude/projects. Le bouton orange de ce site ne sert pas à télécharger une conversation Claude Code. Download Claude conversations enregistre uniquement les conversations que vous ouvrez sur claude.ai dans Chrome. Desktop et Code sont des produits distincts.

Qu’est-ce que l’export d’une conversation Claude Code dans le terminal ?

L’export Claude Code, c’est la commande /export dans une session CLI interactive. La documentation d’Anthropic décrit un menu permettant de copier la conversation en cours ou de l’enregistrer dans un fichier texte brut, avec les messages et les sorties des outils rendus sous forme de texte lisible. Indiquez un nom de fichier pour passer le menu et écrire directement ce fichier.

Ce n’est pas du Markdown issu de claude.ai, ni du JSON issu de cette extension Chrome, ni un PDF. C’est une transcription destinée à être lue par une personne. Anthropic précise que le journal JSONL sur le disque est un format différent, interne au produit, et non une API publique à votre disposition.

/export

Pour passer l’invite et écrire un fichier nommé dans le répertoire de travail courant :

/export my-session

La documentation d’Anthropic sur les sessions fait foi pour les options et les noms de fichiers ; ils changent d’une version de Claude Code à l’autre. Considérez les blogs de la communauté comme des sources secondaires. Si la boîte de dialogue de /export ne correspond pas à ce que vous voyez, votre CLI est une autre version — utilisez l’aide intégrée, pas une capture d’écran de 2025.

Pour les scripts, Anthropic oriente vers d’autres interfaces : claude -p avec --output-format json ou stream-json, la reprise par identifiant de session, les hooks qui reçoivent un transcript_path, ou l’Agent SDK. Ce sont des interfaces de développement de Claude Code, pas l’extension Chrome de ce site.

Lisible ou structuré. /export est la transcription pour les humains. Le JSONL du dossier projects est le journal. Le JSON de l’extension Chrome est une troisième structure, construite uniquement à partir d’une page claude.ai. N’écrivez pas un seul parseur pour les trois.

Comment récupérer une conversation Claude Code sur le disque ?

Pour récupérer une conversation Claude Code sur le disque, copiez le fichier JSONL de la session depuis le répertoire des projets, ou lancez /export pour obtenir une transcription lisible. Le chemin par défaut sous macOS et Linux se trouve dans ~/.claude/projects/. Sous Windows, c’est %USERPROFILE%\.claude\projects. Les noms de fichiers sont les identifiants de session.

Le nom du dossier de projet correspond au répertoire de travail, dont les caractères non alphanumériques sont remplacés par des tirets. Anthropic tronque les noms convertis très longs et ajoute un hachage pour que le répertoire respecte les limites du système de fichiers. Si vous ne trouvez pas le dossier, c’est que vous avez lancé Claude Code depuis un autre répertoire que celui auquel vous pensez.

Chaque ligne JSONL est un objet JSON correspondant à un message, à une utilisation d’outil ou à des métadonnées. Anthropic indique que ce format d’entrée est interne et change entre les versions. Les scripts qui analysent ces fichiers peuvent cesser de fonctionner après une mise à jour de Claude Code. Préférez /export ou les interfaces de script documentées si vous avez besoin de stabilité.

L’emplacement peut changer. CLAUDE_CONFIG_DIR déplace l’arborescence de configuration hors de ~/.claude. CLAUDE_CODE_PROJECT_DIR_NAME nomme le répertoire du projet lorsqu’il est utilisé avec ce répertoire de configuration (Claude Code v2.1.234 ou ultérieur, selon Anthropic). cleanupPeriodDays dans settings.json modifie la durée de conservation par défaut. Aucun de ces réglages n’est une fonctionnalité de Download Claude conversations.

Pour sauvegarder les fichiers de conversation Claude Code, il faut donc copier le dossier, ou exporter régulièrement les transcriptions avec /export. Ce site n’ajoutera pas de bouton « importer du JSONL ». Nous ne lisons pas votre répertoire personnel.

L’export d’une conversation Claude Code fonctionne-t-il avec cette extension ?

Non. L’export Claude Code ne fonctionne pas avec Download Claude conversations. L’extension Chrome s’injecte dans claude.ai. Elle ne voit pas le terminal, ne peut pas lancer /export et ne peut pas ouvrir le JSONL. Si vous cherchiez comment télécharger une conversation Claude Code, suivez les étapes CLI de cette page.

Beaucoup arrivent ici parce que Google regroupe « Claude » et « exporter ». La fiche du Web Store ne concerne que claude.ai. Installer l’extension ne fera pas apparaître de bouton orange dans iTerm, Ghostty, le terminal de VS Code ou l’enveloppe de bureau de Claude Code.

Si vous menez en parallèle une conversation sur claude.ai pour le même travail de développement, cette conversation du navigateur peut être enregistrée avec l’extension. Les deux historiques ne sont pas fusionnés. Les appels d’outils qui ont eu lieu uniquement dans la CLI n’apparaîtront pas dans l’export web, sauf si vous les y avez collés.

Nous recevons chaque semaine le même message au support : quelqu’un a installé l’extension Chrome et s’attendait à voir apparaître /export. Nous n’analysons que claude.ai. Claude Code propose déjà /export et le JSONL. Envelopper la CLI serait un autre produit, et nous ne l’avons pas développé.

Où Claude Code stocke-t-il l’historique des conversations ?

Claude Code stocke l’historique des conversations sous forme de transcriptions JSONL dans le dossier projects du répertoire de configuration. Par défaut sous macOS et Linux : ~/.claude/projects/<encoded-cwd>/<session-id>.jsonl. Windows utilise %USERPROFILE%\.claude\projects. Anthropic peut modifier cette organisation ; consultez la documentation actuelle sur les sessions si un chemin est absent du disque.

Reprendre n’est pas exporter. claude --continue et claude --resume rechargent une session pour que vous puissiez continuer à travailler. /export écrit une copie que vous pouvez conserver dans git ou envoyer par e-mail. L’un restaure le contexte, l’autre vous donne une trace à emporter. La page d’Anthropic sur les sessions traite du mode d’autorisation à la reprise, du compactage/résumé et du sélecteur — rien de tout cela ne concerne cette extension.

Selon Anthropic, l’application de bureau, Claude Code sur le web et l’extension VS Code gèrent chacun leur propre historique de sessions. Les chemins de ce guide concernent la CLI. Ne supposez pas qu’une transcription Cowork de Desktop se trouve dans la même arborescence JSONL que celle du terminal.

Ne traitez pas le JSONL comme un schéma public. Anthropic indique que le format des lignes change. Si vous l’analysez quand même, figez une version de Claude Code et attendez-vous à des ruptures. /export est la méthode stable pour obtenir une conversation Claude Code lisible.

Des variables d’environnement comme CLAUDE_CODE_SKIP_PROMPT_HISTORY peuvent empêcher l’écriture des transcriptions. Si le dossier projects est vide, vérifiez si vous avez désactivé la persistance, redirigé CLAUDE_CONFIG_DIR ailleurs, ou jamais lancé de session interactive dans ce répertoire.

Comment télécharger plutôt une conversation sur claude.ai ?

Pour télécharger une conversation sur claude.ai : installez Download Claude conversations, ouvrez la conversation dans Chrome, cliquez sur le bouton orange et choisissez Markdown, JSON, texte, XML ou PNG. C’est le produit pour navigateur, pas l’export Claude Code. Étapes détaillées : comment télécharger une conversation Claude.

Pour tout l’historique claude.ai en fichiers séparés, utilisez « Export All » (Tout exporter) sur la page de consultation, pas /export. Chaque fichier compte dans les 3 exportations gratuites, sauf avec Pro. Guide : exportation groupée Export All. Formats : formats.

La connexion Google est requise lors du premier export claude.ai pour que nous puissions compter le quota et restaurer Pro. Les fichiers sont générés en local. Paddle facture Pro à 3,99 $/mois ou 26,99 $/an. Rien de tout cela ne s’applique à /export dans le terminal.

Si votre travail a commencé dans Claude Code et que vous avez collé un résumé dans claude.ai, téléchargez la conversation web pour vos notes et gardez /export pour le véritable journal CLI. Deux fichiers valent mieux qu’un seul fichier confus.

Exporter une conversation Claude Code ou utiliser Export data d’Anthropic ?

L’export Claude Code (/export ou JSONL) concerne une session de terminal. Export data officiel, c’est Settings → Privacy → Export data sur claude.ai (les libellés peuvent être traduits si claude.ai est réglé en français) : une archive ZIP JSON du compte Anthropic, envoyée en différé. Ce ne sont pas les mêmes archives. Le ZIP ne remplace pas /export.

La présence d’une session Claude Code donnée dans le ZIP du compte dépend de la façon dont Anthropic stocke ce produit, pas de cette extension. Considérez le ZIP comme une sauvegarde du compte web, sauf si la documentation actuelle d’Anthropic sur la confidentialité indique autre chose. Nous n’ajoutons pas de sessions CLI à ce ZIP.

Pour exporter une conversation depuis le site web, y compris la comparaison entre ce ZIP et l’extension, consultez : comment exporter une conversation Claude. L’impression en PDF d’une page web ne s’applique pas à une interface de terminal. Consultez impression / PDF uniquement si la conversation se trouve dans le navigateur.

Exporter depuis Claude Code, Claude Desktop ou claude.ai ?

Claude Code, Claude Desktop et claude.ai sont trois interfaces différentes. L’export Claude Code utilise /export et le JSONL. Desktop est une application sans le bouton orange de cette extension. claude.ai dans Chrome est le seul endroit où Download Claude conversations fonctionne. Confondre ces noms, c’est la meilleure façon de voir un export échouer sans message d’erreur.

Claude Desktop : si la conversation est synchronisée avec le même compte Anthropic, ouvrez-la sur claude.ai et exportez-la là-bas. Si elle n’existe que dans la fenêtre Desktop, faites un copier-coller ou attendez l’Export data officiel. Guide : exporter une conversation Claude Desktop.

Le panneau Claude Code de VS Code est plus proche de la CLI que de claude.ai. Ne vous attendez pas à ce que notre script de contenu s’injecte dans cette webview. Utilisez /export depuis la session qui contient réellement les messages.

FAQ : exporter une conversation Claude Code

Comment exporter une conversation Claude Code ?

Dans le terminal Claude Code, tapez /export (éventuellement suivi d’un nom de fichier) pour enregistrer une transcription lisible, ou copiez le fichier JSONL depuis ~/.claude/projects sous macOS/Linux ou %USERPROFILE%\.claude\projects sous Windows. La documentation d’Anthropic sur les sessions décrit la boîte de dialogue actuelle.

Cette extension Chrome télécharge-t-elle les conversations Claude Code ?

Non. Download Claude conversations ne fonctionne que sur claude.ai dans Chrome. Elle ne peut lire ni les sessions de terminal, ni les transcriptions JSONL, ni la commande /export. L’export Claude Code reste dans la CLI.

Où Claude Code stocke-t-il l’historique des conversations ?

Les transcriptions de session sont des fichiers JSONL sous ~/.claude/projects/<encoded-working-directory>/, nommés d’après l’identifiant de session. L’organisation exacte peut changer. Utilisez /export si vous voulez un fichier lisible plutôt que d’analyser le JSONL. CLAUDE_CONFIG_DIR permet de déplacer l’arborescence.

Comment télécharger une conversation Claude Code en Markdown ?

Le /export de Claude Code produit une transcription en texte brut, pas le Markdown de cette extension. Si vous avez spécifiquement besoin de Markdown, exportez une copie du travail sur claude.ai avec Download Claude conversations, ou convertissez vous-même le texte de /export. Nous ne convertissons pas le JSONL en Markdown.

Comment télécharger plutôt une conversation claude.ai ?

Installez l’extension Chrome gratuite, ouvrez la conversation sur claude.ai et utilisez le bouton orange — ou Export All pour l’historique. Voir comment télécharger une conversation Claude. 3 exportations gratuites ; Pro coûte 3,99 $/mois ou 26,99 $/an.

/export est-il identique à Export data officiel ?

Non. /export concerne la session Claude Code en cours. Settings → Privacy → Export data envoie par e-mail une archive ZIP JSON du compte Anthropic. Produits différents, fichiers différents, délais différents.

Puis-je analyser le JSONL de Claude Code avec jq ?

Oui, avec la réserve publiée par Anthropic : le schéma des lignes est interne et peut changer. Préférez /export ou claude -p --output-format json si vous avez besoin d’un format stable. Figez la version de votre CLI si vous analysez quand même le JSONL.

L’export Claude Code fonctionne-t-il sous Windows ?

Oui. /export est une commande de la CLI. Les transcriptions sur disque se trouvent sous %USERPROFILE%\.claude\projects, sauf si vous définissez CLAUDE_CONFIG_DIR. Cette extension Chrome ne fonctionne toujours pas dans ce terminal.

Claude Code est-il la même chose que Claude Desktop ?

Non. Claude Code est l’agent de programmation en terminal. Claude Desktop est l’application de conversation. claude.ai est le site web. Seul le site web reçoit cette extension. Notes sur l’export depuis Desktop : Claude Desktop.

Cette extension intégrera-t-elle un jour /export ?

Pas dans la version 1.13.0. Le périmètre du produit est claude.ai : cinq formats, fichiers locaux, connexion Google pour le quota. Si ce périmètre change, cette page l’indiquera. D’ici là, utilisez la CLI d’Anthropic pour exporter depuis Claude Code.

/export inclut-il les sorties des outils ?

Anthropic décrit /export comme les messages et les sorties des outils rendus sous forme de texte lisible. C’est leur transcription, pas notre analyseur. Pour connaître le contenu exact actuel, lancez /export sur votre version et lisez le fichier — la documentation peut avoir une version de retard.

Puis-je exporter des sessions Claude Code de façon groupée ?

Pas avec l’Export All de cette extension. L’exportation groupée de notre page de consultation concerne uniquement claude.ai. Pour de nombreuses sessions CLI, copiez le dossier projects ou lancez /export pour chaque session. Il n’existe pas d’exportation groupée du JSONL par bouton orange.
