Despre noi

Download Claude conversations este o extensie Chrome independentă (numele site-ului: Chat Downloader). Motoarele de căutare și utilizatorii o numesc și Claude Chat Downloader sau Claude Conversation Downloader. Nu este creată, afiliată sau susținută de Anthropic, PBC — Claude este o marcă comercială a Anthropic. Am construit-o ca să acoperim o lipsă din claude.ai: nu există o metodă integrată de a descărca o singură conversație ca fișier.

Extensia adaugă un buton de export pe claude.ai și un Dashboard (panou de control) pentru exporturile în bloc și scrie local, în browser, fișiere PDF, Markdown, text simplu, JSON, XML, CSV sau PNG. Exporturile unui singur chat în Markdown, text, JSON, XML, CSV și PNG sunt nelimitate și nu cer cont. PDF-ul și ZIP-ul în bloc cer autentificare Google și sunt gratuite până la 3 pe zi; Pro (3,99 USD/lună sau 26,99 USD/an) elimină limita. Funcționează cu chaturi obișnuite, proiecte (Projects), sesiuni Cowork și Claude Code on the web (claude.ai/code). Detalii despre cum funcționează. Nu exportă sesiunile Claude Code din terminal.

Fișa din Chrome Web Store (de păstrat sincronizată)

Folosiți acest text în Chrome Web Store, ca fragmentul afișat în magazin să corespundă felului în care caută oamenii:

  • Nume (≤75 de caractere): Claude Chat Downloader
  • Descriere scurtă (≤132 de caractere): Free Chrome extension to save claude.ai chats as PDF, Markdown, text, JSON, XML, CSV or PNG — one chat or bulk Export All.
