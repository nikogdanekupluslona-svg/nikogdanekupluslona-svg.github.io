Cum fac export chat Claude de pe claude.ai?

Deschideți conversația pe claude.ai în Chrome, faceți clic pe butonul portocaliu de lângă caseta de mesaj, alegeți PDF, Markdown, JSON, text simplu, XML, CSV sau PNG, apoi apăsați „Export”. Download Claude conversations scrie fișierul local. În septembrie 2026, claude.ai nu are o comandă proprie pentru exportul unei singure conversații.

  1. Instalați Download Claude conversations din Chrome Web Store.
  2. Reîncărcați claude.ai și deschideți adresa unei conversații reale, nu pagina de start goală.
  3. Faceți clic pe butonul rotund portocaliu de descărcare, aflat în dreapta casetei de mesaj.
  4. În panou, setați „Messages” (Mesaje) pe „All”, „Human” sau „Assistant” (Toate, Om sau Asistent), apoi alegeți un format. Bifați „Thinking” (Gândire) pentru a include gândirea extinsă sau folosiți „Select” (Selectare) pentru a bifa mesaje individuale. Extensia reține ultimul format folosit.
  5. Apăsați „Export”. Chrome salvează fișierul imediat, prin API-ul de descărcări al browserului. „Copy” (Copiere) pune în schimb Markdown, text, JSON, XML sau CSV în clipboard.

Nu aveți nevoie de cont pentru a exporta chatul Claude în Markdown, text, JSON, XML, CSV sau PNG. Aceste exporturi ale unui singur chat sunt nelimitate, iar extensia nu trimite nimic către serverele noastre. Autentificarea Google apare doar când alegeți PDF sau porniți exportul în bloc „Export All” (Exportă tot): planul gratuit permite 3 astfel de operațiuni pe zi, în total, cu resetare la miezul nopții UTC. Textul conversației nu face niciodată parte din această autentificare. Detalii tehnice: cum funcționează.

Dacă butonul portocaliu lipsește, nu vă aflați pe adresa unei conversații, fila trebuie reîncărcată după instalare sau pictograma extensiei este încă ascunsă în meniul cu piesa de puzzle din Chrome. Fixați Download Claude conversations, apoi reîmprospătați claude.ai. Extensia se activează doar pe claude.ai, niciodată pe alte site-uri.

O conversație sau tot contul. Butonul portocaliu exportă chatul deschis. Pentru multe fișiere, deschideți fereastra extensiei → „View and Download All Conversations” (Vizualizați și descărcați toate conversațiile) și porniți „Export All” — vedeți exportul în bloc. Settings → Privacy → Export data de la Anthropic (etichetele pot apărea traduse dacă claude.ai este setat în limba română) este o arhivă ZIP a contului, livrată cu întârziere, nu acest flux.

Ce face, concret, o extensie de export pentru Claude?

O extensie de export pentru Claude citește conversația deja afișată în fila claude.ai în care sunteți autentificat și scrie un fișier structurat pe disc. Download Claude conversations este acest script de conținut pentru Chrome: expeditor, arborele mesajelor, blocuri de cod, tabele, gândirea (opțional) și aranjarea artefactelor — nu o captură de ecran a interfeței din jurul chatului. Funcționează cu chaturi obișnuite, Projects, sesiuni Cowork și Claude Code on the web.

Copierea din claude.ai pierde indentarea și strică tabelele. Tipărirea (Ctrl/Cmd+P) păstrează bara laterală și adesea rupe un bloc lung de cod pe mai multe pagini. Extensia păstrează eticheta de limbaj a blocurilor de cod și lasă tabelele ca tabele în Markdown, JSON și XML. PNG este varianta de captură vizuală. PDF este varianta paginată, generată în browser, fără dialogul de tipărire.

Aranjarea artefactelor este o opțiune reală în versiunea 1.16.2: „Original”, „Inline”, „Nested” sau „Flat” (original, în text, imbricat sau plat), setată în Dashboard. Gândirea extinsă este o casetă de bifat în panoul de export; sursele căutării web și pașii de instrumente / MCP se activează opțional din Settings (Setări). Metadatele (titlu, marcaje de timp, model) pot fi incluse. Filtrul „Messages” limitează fișierul la toate mesajele, doar cele umane sau doar cele ale asistentului, iar „Select” bifează mesaje individuale. Lista completă: funcționalități.

Am creat butonul portocaliu ca să scrie un fișier real din chatul deja deschis pe claude.ai — PDF, Markdown, JSON, text, XML, CSV sau PNG — fără să încarce conversația pe serverele noastre. Versiunea 1.16.2 generează și PDF-ul direct în browser.

În ce format să export chatul Claude?

Exportați chatul Claude în PDF pentru partajare sau tipărire, în Markdown pentru notițe, în JSON pentru scripturi, în text simplu pentru o arhivă brută, în XML pentru schimb de date, în CSV pentru un tabel sau în PNG pentru o imagine a conversației. Download Claude conversations oferă toate cele șapte formate într-o singură listă.

Cei care scriu exportă de obicei chatul Claude în Markdown. Dezvoltatorii aleg de regulă JSON. Dacă aveți nevoie de un document paginat, alegeți PDF: dialogul său setează dimensiunea paginii, marginile, modul luminos sau întunecat, fontul, numerotarea paginilor și un cuprins — pașii detaliați: descărcați chatul Claude ca PDF. Un PNG generat de extensie este un singur fișier imagine, nu un document paginat.

Formatul decide dacă se aplică o limită. Markdown, text, JSON, XML, CSV și PNG sunt nelimitate, fără cont. Download Claude conversations nu oferă export în Notion, Word sau Google Docs în versiunea 1.16.2.

Pot exporta chaturile Claude în bloc cu „Export All”?

Da. Deschideți fereastra extensiei → „View and Download All Conversations”, filtrați tabelul, apoi apăsați „Export All” pentru o arhivă ZIP. Exportul în bloc cere autentificare Google. Pe planul gratuit împarte limita de 3 pe zi cu PDF-ul, iar fiecare conversație din ZIP consumă una. Pro elimină limita pentru întregul istoric.

Dashboard-ul afișează istoricul claude.ai cu căutare după nume, filtre („All conversations”, „New”, „Updated”, „Previously exported” — toate conversațiile, noi, actualizate, exportate anterior), filele „Chat” și „Cowork” și căutare după proiect. „New” înseamnă conversații încă neexportate cu Download Claude conversations. „Previously exported” urmărește chaturile deja salvate, astfel încât un nou „Export All” să le poată sări. Căutarea după proiect urmează modul în care vă grupați chaturile pe claude.ai.

Exportul în bloc are un selector „Chat format” (formatul chatului) cu toate cele șapte formate, inclusiv PDF, casete de bifat „Chats”, „Thinking”, „Metadata”, „Tools” și „Sources” (chaturi, gândire, metadate, instrumente, surse) și aranjarea artefactelor („Original”, „Inline”, „Nested”, „Flat”). „Export All” nu este o arhivă sărăcită. Este o singură arhivă ZIP, cu câte un fișier pentru fiecare chat, în formatul ales. Dacă doreați o singură arhivă a întregului cont, livrată cu întârziere, aceea este „Export data” de la Anthropic, comparată în secțiunea următoare și pe pagina despre exportul în bloc.

Exportul în bloc se numără pe chat. Pe planul gratuit, „Export All” și PDF-ul împart limita de 3 pe zi, iar fiecare conversație din ZIP consumă una. Dacă selectați 40 de conversații și mai aveți 3, întregul lot este blocat, nu trunchiat. Alegeți mai puține, așteptați resetarea de la miezul nopții UTC sau treceți la Pro, cu 3,99 USD pe lună sau 26,99 USD pe an.

Funcționează exportul în Claude Desktop sau Claude Code?

Nu în aplicația Desktop și nici în terminalul Claude Code. Această extensie de export pentru Claude rulează doar pe claude.ai, în Chrome (sau într-un alt browser Chromium care poate instala extensia din magazin). Claude Desktop este o aplicație separată pentru Mac/Windows, iar butonul portocaliu nu apare niciodată acolo sau într-un terminal. Claude Code on the web (claude.ai/code) este excepția: acele sesiuni se deschid pe claude.ai și se exportă ca orice chat.

Dacă firul există și în contul dumneavoastră claude.ai, deschideți-l în Chrome și exportați chatul Claude de acolo cu Download Claude conversations. Dacă chatul există doar în Desktop, copiați textul din aplicație sau solicitați Settings → Privacy → Export data pe web. Comparația pas cu pas: exportul unui chat din Claude Desktop.

Claude Code în terminal folosește /export sau transcrieri JSONL pe disc. Această extensie Chrome nu citește acele sesiuni locale. Nu instalați Download Claude conversations așteptând o integrare cu terminalul. Ghid: export din Claude Code. Căutarea „export chat Claude” pentru o sesiune din linia de comandă duce la un cu totul alt drum.

Nici claude.ai deschis în browserul unui telefon nu este acoperit. Extensia are nevoie de Chrome pe desktop. Această echipă nu are o aplicație pentru iOS sau Android în 2026. Deschideți conversația pe un calculator, apoi exportați chatul Claude cu butonul portocaliu sau cu „Export All”.

Export chat Claude sau „Export data” de la Anthropic?

„Export data” de la Anthropic trimite prin e-mail, după o așteptare, o arhivă ZIP JSON a întregului cont. Exportul cu Download Claude conversations salvează imediat conversația deschisă ca PDF, Markdown, JSON, text, XML, CSV sau PNG. Folosiți arhiva ZIP pentru backup; folosiți extensia de export pentru un fișier lizibil chiar acum.

Cât costă o extensie de export pentru Claude?

Exporturile în Markdown, text, JSON, XML, CSV și PNG sunt gratuite și nelimitate, fără cont. PDF-ul și exportul în bloc „Export All” sunt gratuite până la 3 pe zi, cu autentificare Google. Pro costă 3,99 USD pe lună sau 26,99 USD pe an, prin Paddle, și face PDF-ul și exportul în bloc nelimitate. Download Claude conversations nu taxează pe format. Orice plan claude.ai funcționează dacă Chrome poate deschide chatul.

Numărătoarea zilnică pentru PDF și exportul în bloc se resetează la miezul nopții UTC. Pro se restaurează pe un calculator nou când vă autentificați cu același cont Google. Puteți anula oricând din pagina de opțiuni a extensiei sau prin Paddle. Paddle este comerciantul înregistrat; această echipă nu vede niciodată numerele cardurilor. Prima plată are garanție de returnare a banilor în 14 zile, gestionată prin Paddle, așa cum este descris pe pagina de rambursări.

Nu aveți nevoie de planul plătit claude.ai de la Anthropic pentru a folosi extensia. Aveți nevoie de un cont claude.ai care poate deschide conversația, plus Chrome. Team și Enterprise funcționează la fel ca Free cu butonul portocaliu. Dacă un administrator de spațiu de lucru blochează extensiile, Download Claude conversations nu se va activa — este o politică a browserului, nu o limită de format.

Ce înseamnă „export chat Claude” pe acest site?

Salvarea unei conversații claude.ai ca fișier cu Download Claude conversations: butonul portocaliu, alegerea formatului, „Export”. Este același lucru pe care îl caută cei care tastează în engleză „claude export chat”. Nu este arhiva ZIP trimisă prin e-mail de Anthropic și nici /export din Claude Code.

O extensie de export pentru Claude este același lucru cu „Export data”?

Nu. Settings → Privacy → Export data este o arhivă ZIP JSON a întregului cont, trimisă prin e-mail. Extensia scrie imediat, în Chrome, chatul deschis ca PDF, Markdown, JSON, text, XML, CSV sau PNG, ori o selecție „Export All” ca arhivă ZIP.

Pot exporta chatul Claude ca PDF?

Da. Alegeți PDF din lista de formate și apăsați „Export”. Extensia generează PDF-ul în browser, fără dialogul de tipărire. PDF-ul cere autentificare Google și este gratuit până la 3 pe zi; Pro îl face nelimitat. Ghid: descărcați chatul Claude ca PDF.

Am nevoie de Pro pentru a exporta o singură dată un chat Claude?

Nu. Exporturile în Markdown, text, JSON, XML, CSV și PNG sunt gratuite și nelimitate, fără cont. PDF-ul și exportul în bloc „Export All” sunt gratuite până la 3 pe zi, cu autentificare Google. Pro, la 3,99 USD pe lună sau 26,99 USD pe an, elimină această limită.

Funcționează exportul chatului Claude cu orice plan claude.ai?

Da. Planurile claude.ai Free, Pro, Team sau Enterprise funcționează, dacă puteți deschide conversația în Chrome. Extensia nu cere un plan plătit de la Anthropic.

Este această extensie de export și pentru Claude Code?

Doar pentru Claude Code on the web. Sesiunile de la claude.ai/code se deschid pe claude.ai și se exportă ca orice chat. Claude Code în terminal folosește /export sau fișiere JSONL pe disc, iar Download Claude conversations nu le citește. Consultați ghidul de export din Claude Code.

Pot exporta chatul Claude din Claude Desktop?

Nu cu această extensie Chrome. Deschideți același fir pe claude.ai, dacă se sincronizează, sau copiați textul / folosiți exportul oficial „Export data”. Desktop nu afișează niciodată butonul portocaliu.

Câte exporturi gratuite oferă extensia de export pentru Claude?
