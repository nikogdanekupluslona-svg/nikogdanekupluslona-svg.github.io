Întrebări frecvente

Pot descărca o conversație Claude de pe claude.ai?

Nu cu un buton integrat. Instalați Download Claude conversations din Chrome Web Store, deschideți chatul și exportați un fișier.

Descărcarea chaturilor Claude este gratuită?

Da. Exporturile în Markdown, text simplu, JSON, XML, CSV și PNG sunt nelimitate și nu cer cont. Exporturile PDF și arhivele ZIP în bloc cer autentificare Google și sunt gratuite până la 3 pe zi. Pro, la 3,99 USD pe lună sau 26,99 USD pe an, elimină această limită.

În ce browsere funcționează?

În Chrome pentru desktop și în browserele bazate pe Chromium care instalează extensii din Chrome Web Store. Nu există aplicație mobilă, iar extensia nu rulează în Claude Desktop.

Cum anulez Pro și pot primi banii înapoi?

Anulați oricând din pagina Options a extensiei („Cancel subscription”, anulează abonamentul) sau prin Paddle. Prima plată beneficiază de o garanție de rambursare în 14 zile, fără întrebări.

Este același lucru cu Export data din Claude?

Nu. Opțiunea Settings → Privacy → Export data de la Anthropic (etichetele pot fi traduse dacă claude.ai este setat în română) vă trimite pe e-mail o arhivă ZIP a contului (JSON). Această extensie descarcă imediat chatul curent — sau o selecție în bloc — ca fișiere ușor de citit.

Stocați chaturile mele Claude?

Nu. Fiecare format, inclusiv PDF, este creat în browserul dumneavoastră, iar textul conversațiilor nu ajunge niciodată pe serverele noastre. Dacă vă autentificați cu Google pentru PDF, export în bloc sau Pro, păstrăm doar acea adresă de e-mail, pentru a număra cota zilnică și a lega abonamentul.

Care este diferența dintre „descărcare chat Claude” și „claude chat download”?

Aceeași sarcină, scrisă o dată în română și o dată în engleză. În ambele cazuri folosiți butonul portocaliu de pe claude.ai.

Exportă și în PDF?

Da. Alegeți PDF în panoul de export și setați formatul paginii, marginile, modul deschis sau întunecat, fontul, numerotarea paginilor și un cuprins. PDF-ul cere autentificare Google; planul gratuit include 3 exporturi PDF sau în bloc pe zi, iar Pro este nelimitat. Ghid complet: descărcați un chat Claude în PDF.

Funcționează cu Claude Pro / Team?

Da, dacă puteți deschide conversația în browser, pe claude.ai. Nu suntem Anthropic.

Cum salvez o conversație Claude?

Instalați extensia Chrome gratuită, deschideți chatul pe claude.ai, apăsați butonul portocaliu, alegeți un format și apăsați „Export”. Pentru Markdown, text, JSON, XML, CSV sau PNG nu aveți nevoie de cont. Așa salvați o conversație Claude ca fișier real. Tipărirea paginii și arhiva ZIP a contului de la Anthropic sunt celelalte două variante — comparația se află în ghidul cum descărcați un chat Claude.

Descarcă și conversațiile Claude Code?

Doar pe cele de pe claude.ai. Claude Code pe web (claude.ai/code) și sesiunile Cowork se exportă ca orice chat. Sesiunile locale din terminal nu sunt citite de extensie; pentru ele se folosesc /export sau fișierele JSONL de pe disc — vedeți exportul Claude Code.

Download Claude conversations este afiliată cu Anthropic?

Nu. Claude este o marcă comercială a Anthropic, PBC. Aceasta este o extensie Chrome independentă, nu un produs oficial Anthropic.
