Ce este exportul unei conversații Claude Code în terminal?

Exportul unei conversații Claude Code este comanda /export dintr-o sesiune interactivă în linia de comandă. Documentația Anthropic descrie un meniu pentru a copia conversația curentă sau a o salva ca fișier text simplu, cu mesajele și rezultatele instrumentelor redate ca text lizibil. Dacă adăugați un nume de fișier, meniul este sărit și se scrie direct acel fișier.

Nu este Markdown de pe claude.ai, nu este JSON din această extensie Chrome și nu este PDF. Este o transcriere redată, destinată lecturii de către o persoană. Anthropic precizează că jurnalul JSONL de pe disc este un format diferit, intern, destinat produsului, nu unui API public pentru dumneavoastră.

/export

Pentru a sări peste întrebare și a scrie un fișier cu nume în directorul de lucru curent:

/export my-session

Documentația Anthropic despre sesiuni este sursa de referință pentru opțiuni și nume de fișiere; acestea se schimbă între versiunile Claude Code. Tratați blogurile comunității ca surse secundare. Dacă textul dialogului /export nu corespunde cu ce vedeți, aveți o altă versiune a liniei de comandă — folosiți ajutorul din produs, nu o captură de ecran din 2025.

Pentru scripturi, Anthropic recomandă alte interfețe: claude -p cu --output-format json sau stream-json, reluarea după ID-ul sesiunii, hook-uri care primesc un transcript_path sau Agent SDK. Acestea sunt interfețe pentru dezvoltatori ale Claude Code. Nu sunt extensia Chrome a acestui site.

Lizibil sau structurat. /export este transcrierea pentru oameni. JSONL din dosarul de proiecte este jurnalul. JSON-ul extensiei Chrome este o a treia structură, generată doar dintr-o pagină claude.ai. Nu scrieți un singur parser pentru toate trei.

Cum descărcați de pe disc o conversație Claude Code?

Pentru a descărca de pe disc o conversație Claude Code, copiați fișierul JSONL al sesiunii din directorul de proiecte sau rulați /export pentru o transcriere lizibilă. Calea implicită pe macOS și Linux se află în ~/.claude/projects/. Pe Windows este %USERPROFILE%\.claude\projects. Numele fișierelor sunt ID-urile sesiunilor.

Numele dosarului de proiect este directorul de lucru, cu caracterele non-alfanumerice înlocuite cu cratime. Anthropic scurtează numele convertite foarte lungi și adaugă un hash, ca directorul să rămână în limitele sistemului de fișiere. Dacă nu găsiți dosarul, ați pornit Claude Code dintr-un alt director de lucru decât credeți.

Fiecare linie JSONL este un obiect JSON pentru un mesaj, o utilizare de instrument sau metadate. Anthropic afirmă că acest format al înregistrărilor este intern și se schimbă între versiuni. Scripturile care analizează aceste fișiere se pot strica la o nouă versiune Claude Code. Preferați /export sau interfețele documentate pentru scripturi când aveți nevoie de ceva stabil.

Locația de stocare se poate muta. CLAUDE_CONFIG_DIR mută arborele de configurare în afara ~/.claude. CLAUDE_CODE_PROJECT_DIR_NAME denumește directorul de proiect când este folosit împreună cu acel director de configurare (Claude Code v2.1.234 sau mai nou, conform Anthropic). cleanupPeriodDays din settings.json schimbă perioada implicită de păstrare. Niciuna dintre aceste setări nu este o funcție a Download Claude conversations.

Prin urmare, pentru backup, fișierele conversațiilor Claude Code se descarcă astfel: copiați dosarul sau exportați periodic transcrierile cu /export. Acest site nu va adăuga un buton de „import JSONL”. Nu citim directorul dumneavoastră personal.

Funcționează exportul din Claude Code cu această extensie?

Nu, nu pentru sesiunile din terminal. Download Claude conversations nu citește sesiunile locale Claude Code. Extensia Chrome se activează pe claude.ai. Nu poate vedea terminalul, nu poate rula /export și nu poate deschide JSONL. Claude Code on the web de la claude.ai/code este excepția: este o pagină claude.ai, deci se exportă ca orice chat. Dacă ați căutat cum să descărcați o conversație Claude Code din linia de comandă, rămâneți la pașii pentru linia de comandă de pe această pagină.

Oamenii ajung aici pentru că Google grupează „Claude” și „export”. Extensia din Web Store rămâne totuși doar pentru claude.ai. Instalarea ei nu va pune un buton portocaliu în iTerm, Ghostty, terminalul din VS Code sau în aplicația desktop a Claude Code.

Dacă țineți și un fir paralel pe claude.ai pentru aceeași sarcină de programare, acel chat din browser poate fi salvat cu extensia. Cele două înregistrări nu se unesc. Apelurile de instrumente care au avut loc doar în linia de comandă nu vor apărea în exportul web decât dacă le-ați lipit acolo.

Primim săptămânal același mesaj la asistență: cineva a instalat extensia Chrome și se aștepta să apară /export. Noi analizăm doar claude.ai. Claude Code are deja /export și JSONL. Un înveliș pentru linia de comandă ar fi un alt produs, iar noi nu l-am lansat.

Pot exporta sesiunile Claude Code on the web?

Da. Claude Code on the web rulează la claude.ai/code, deci Download Claude conversations exportă aceste sesiuni ca pe orice chat claude.ai. Deschideți sesiunea în Chrome, faceți clic pe butonul portocaliu, alegeți un format și apăsați „Export” (Exportă). Aceasta este singura interfață Claude Code acoperită de extensie.

Formatele sunt aceleași șapte ca pentru orice chat: PDF, Markdown, text simplu, JSON, XML, CSV și PNG. Markdown, text, JSON, XML, CSV și PNG sunt nelimitate și nu cer cont. PDF-ul cere autentificare Google și împarte cu arhiva ZIP în bloc limita de 3 pe zi a planului gratuit, dacă nu aveți Pro. Blocurile de cod își păstrează eticheta de limbaj. Gândirea extinsă este o casetă de bifat „Thinking” (Gândire) în panou; pașii de instrumente / MCP și sursele căutării web se activează opțional din Settings (Setări).

Exportul web este ceea ce afișează claude.ai/code în browser. Nu este jurnalul JSONL al unei rulări locale în linia de comandă și nu ajunge la sesiunile care au rulat doar în terminalul dumneavoastră. Conform Anthropic, Claude Code on the web își păstrează propriul istoric de sesiuni, separat de arborele ~/.claude/projects al liniei de comandă. Pentru o sesiune din terminal, drumul rămâne /export.

Unde stochează Claude Code istoricul conversațiilor?

Claude Code stochează istoricul conversațiilor ca transcrieri JSONL în dosarul de proiecte din directorul de configurare. Implicit pe macOS și Linux: ~/.claude/projects/<encoded-cwd>/<session-id>.jsonl. Windows folosește %USERPROFILE%\.claude\projects. Anthropic poate schimba această structură; consultați documentația actuală despre sesiuni dacă o cale lipsește de pe disc.

Reluarea este altceva decât exportul. claude --continue și claude --resume reîncarcă o sesiune ca să puteți continua lucrul. /export scrie o copie pe care o puteți păstra în git sau trimite prin e-mail. Una restaurează contextul. Cealaltă vă dă o înregistrare de luat cu dumneavoastră. Pagina Anthropic despre sesiuni acoperă modul de permisiuni la reluare, compactarea/rezumatul și comportamentul selectorului — nimic din toate acestea nu ține de această extensie.

Aplicația desktop, Claude Code on the web și extensia pentru VS Code își păstrează fiecare propriul istoric de sesiuni, conform Anthropic. Căile din acest ghid sunt cele ale liniei de comandă. Sesiunile web rămân pe claude.ai/code, unde extensia le poate exporta. Nu presupuneți că o transcriere Cowork din Desktop se află în același arbore JSONL pe care îl folosiți din terminal.

Nu tratați JSONL ca pe o schemă publică. Anthropic spune că formatul liniilor se schimbă. Dacă îl analizați totuși, fixați o versiune Claude Code și așteptați-vă la defecțiuni. /export este metoda stabilă de a obține o conversație Claude Code lizibilă.

Variabilele de mediu precum CLAUDE_CODE_SKIP_PROMPT_HISTORY pot opri scrierea transcrierilor. Dacă dosarul de proiecte este gol, verificați dacă ați dezactivat persistența, ați îndreptat CLAUDE_CONFIG_DIR în altă parte sau nu ați rulat niciodată o sesiune interactivă în acel director.

Exportul din Claude Code sau „Export data” oficial de la Anthropic?

Exportul din Claude Code (/export sau JSONL) înseamnă o singură sesiune din terminal. „Export data” oficial este Settings → Privacy → Export data pe claude.ai (etichetele pot apărea traduse dacă claude.ai este setat în limba română): o arhivă ZIP JSON a contului Anthropic, livrată cu întârziere. Nu sunt aceeași arhivă. Arhiva ZIP nu înlocuiește /export.

Dacă o anumită sesiune Claude Code apare în arhiva contului depinde de modul în care Anthropic stochează acel produs, nu de această extensie. Tratați arhiva ZIP ca pe un backup al contului web, cu excepția cazului în care documentația actuală Anthropic despre confidențialitate spune altceva. Noi nu adăugăm sesiuni din linia de comandă în acea arhivă.

Export din Claude Code, Desktop sau claude.ai?

Claude Code, Claude Desktop și claude.ai sunt trei interfețe diferite. Exportul conversațiilor Claude Code folosește /export și JSONL. Desktop este o aplicație fără butonul portocaliu al acestei extensii. claude.ai în Chrome este singurul loc în care rulează Download Claude conversations — inclusiv Claude Code on the web de la claude.ai/code. Amestecarea acestor nume este motivul pentru care exporturile eșuează fără niciun mesaj.

Claude Desktop: dacă chatul s-a sincronizat în același cont Anthropic, deschideți-l pe claude.ai și exportați de acolo. Dacă există doar în fereastra Desktop, copiați textul sau așteptați „Export data” oficial. Ghid: exportul unui chat din Claude Desktop.

Panoul Claude Code din VS Code este mai apropiat de linia de comandă decât de claude.ai. Nu vă așteptați ca scriptul nostru de conținut să se activeze în acel webview. Folosiți /export din sesiunea care conține efectiv mesajele.

Extensie Chrome independentă, neafiliată cu Anthropic, PBC. Claude este o marcă înregistrată a Anthropic. Respectați Termenii lor de utilizare. Nu putem oferi consultanță juridică despre copierea rezultatelor instrumentelor care includ cod proprietar; aceasta este o chestiune între dumneavoastră, angajatorul dumneavoastră și Anthropic.

Întrebări frecvente: export conversație Claude Code

Cum export o conversație Claude Code?

În terminalul Claude Code, tastați /export (opțional cu un nume de fișier) pentru a salva o transcriere redată sau copiați fișierul JSONL din ~/.claude/projects pe macOS/Linux ori din %USERPROFILE%\.claude\projects pe Windows. Documentația Anthropic despre sesiuni descrie dialogul actual.

Această extensie Chrome descarcă chaturile din Claude Code?

Nu din terminal. Download Claude conversations funcționează doar pe claude.ai, în Chrome. Nu poate citi sesiunile locale din terminal, transcrierile JSONL sau comanda /export. Sesiunile Claude Code on the web de la claude.ai/code se exportă, ca orice chat.

Pot exporta Claude Code on the web (claude.ai/code)?

Da. Deschideți sesiunea de la claude.ai/code în Chrome și folosiți butonul portocaliu. PDF, Markdown, text simplu, JSON, XML, CSV și PNG funcționează toate. Cele șase formate în afară de PDF sunt nelimitate, fără cont; PDF-ul cere autentificare Google și intră în limita de 3 gratuite pe zi.

Unde stochează Claude Code istoricul conversațiilor?

Transcrierile sesiunilor sunt fișiere JSONL în ~/.claude/projects/<encoded-working-directory>/, denumite după ID-ul sesiunii. Structura exactă se poate schimba. Folosiți /export când doriți un fișier lizibil în loc să analizați JSONL. CLAUDE_CONFIG_DIR poate muta arborele.

Cum descarc o conversație Claude Code ca Markdown?

/export din Claude Code produce o transcriere în text simplu, nu Markdown-ul acestei extensii. Dacă aveți nevoie anume de Markdown, exportați o sesiune claude.ai/code sau o copie a lucrului de pe claude.ai cu Download Claude conversations ori convertiți singur textul din /export. Noi nu convertim JSONL în Markdown.

Cum descarc în schimb o conversație de pe Claude.ai?

Instalați extensia Chrome gratuită, deschideți chatul pe claude.ai și folosiți butonul portocaliu — sau „Export All” pentru istoric. Vedeți cum descărcați un chat Claude. Markdown, text, JSON, XML, CSV și PNG sunt nelimitate, fără cont; PDF-ul și arhiva ZIP în bloc sunt gratuite 3 pe zi, cu autentificare Google; Pro costă 3,99 USD/lună sau 26,99 USD/an.

Este /export același lucru cu „Export data” oficial?

Nu. /export înseamnă sesiunea Claude Code curentă. Settings → Privacy → Export data trimite prin e-mail o arhivă ZIP JSON a contului Anthropic. Interfețe de produs diferite, fișiere diferite, timpi de așteptare diferiți.

Pot analiza fișierele JSONL din Claude Code cu jq?

Puteți, cu avertismentul publicat de Anthropic: schema liniilor este internă și se poate schimba. Preferați /export sau claude -p --output-format json când aveți nevoie de un format garantat. Fixați versiunea liniei de comandă dacă analizați totuși JSONL.

Funcționează exportul din Claude Code pe Windows?

Da. /export este o comandă a liniei de comandă. Transcrierile de pe disc se află în %USERPROFILE%\.claude\projects, dacă nu setați CLAUDE_CONFIG_DIR. Această extensie Chrome tot nu rulează în acel terminal.

Este Claude Code același lucru cu Claude Desktop?

Nu. Claude Code este agentul de programare din terminal. Claude Desktop este aplicația de chat. claude.ai este site-ul web. Doar site-ul, inclusiv claude.ai/code, beneficiază de această extensie. Note despre exportul din Desktop: Claude Desktop.

Va prelua vreodată această extensie funcția /export?

Nu în versiunea 1.16.2. Aria produsului este claude.ai, inclusiv Claude Code on the web: șapte formate, fișiere locale, autentificare Google doar pentru PDF, export în bloc și Pro. Dacă aria se schimbă, această pagină o va spune. Până atunci, folosiți linia de comandă Anthropic pentru exportul din Claude Code în terminal.

Include /export rezultatele instrumentelor?

Anthropic descrie /export ca mesaje și rezultate ale instrumentelor redate ca text lizibil. Aceasta este transcrierea lor, nu parserul nostru. Pentru conținutul exact actual, rulați /export pe versiunea dumneavoastră și citiți fișierul — documentația poate rămâne în urmă cu o versiune.

Pot exporta în bloc sesiunile Claude Code?

Nu sesiunile locale din linia de comandă. „Export All” din Dashboard este doar pentru claude.ai. Pentru multe sesiuni din linia de comandă, copiați dosarul de proiecte sau rulați /export pentru fiecare sesiune. Nu există export în bloc cu butonul portocaliu pentru JSONL.
