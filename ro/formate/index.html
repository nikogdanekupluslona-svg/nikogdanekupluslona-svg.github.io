Care sunt formatele de export pentru chat Claude?

Formatele de export pentru chat Claude de pe acest site sunt cele șapte fișiere pe care Download Claude conversations le scrie dintr-un fir claude.ai: PDF, Markdown, text simplu, JSON, XML, CSV și PNG. Versiunea 1.16.2 le generează pe toate în browser. Șase sunt nelimitate, fără cont. PDF-ul cere autentificare Google și este gratuit până la 3 pe zi.

Extensia funcționează oriunde se deschide un fir pe claude.ai în Chrome: chaturi, Projects, sesiuni Cowork și Claude Code on the web (claude.ai/code). Aplicația Claude Desktop și sesiunile locale Claude Code din terminal nu afișează niciodată butonul portocaliu. Dacă același fir există în contul claude.ai, deschideți acea adresă în Chrome și alegeți acolo un format. Lista reține ultimul format folosit.

Aceeași pagină din Chrome Web Store este căutată și ca Claude Chat Downloader sau Claude Conversation Downloader. Aceste nume desemnează acest produs, nu un al doilea instrument de export. Paginile juridice pot folosi încă denumirea Claude Exporter. Fișierele pe care le primiți sunt aceleași șapte formate.

O listă, două puncte de intrare. Butonul portocaliu exportă chatul deschis. „Export All” din Dashboard exportă multe chaturi într-o singură arhivă ZIP, câte un fișier per chat, în oricare dintre cele șapte formate pe care îl alegeți ca „Chat format” (Formatul chatului) — inclusiv PDF. Detalii: exportul în bloc „Export All”.

Ce format de export să aleg pentru un chat Claude?

Alegeți PDF pentru citire și partajare, Markdown pentru notițe, JSON pentru scripturi, CSV pentru tabele de calcul, text simplu pentru o arhivă de lipit oriunde, XML când un sistem cere XML și PNG pentru o imagine a firului. Download Claude conversations nu declară niciunul drept cel mai bun. Formatele diferă ca formă; pe planul gratuit, doar PDF-ul are o limită zilnică.

Cum aleg formatul la export?

Deschideți adresa unei conversații pe claude.ai în Chrome, faceți clic pe butonul portocaliu de lângă caseta de mesaj, alegeți unul dintre formatele de export, apoi apăsați „Export” (Exportă). Download Claude conversations asamblează fișierul în filă. În septembrie 2026, claude.ai nu are o comandă proprie pentru exportul acestui chat.

  1. Instalați Download Claude conversations din Chrome Web Store.
  2. Reîncărcați claude.ai și deschideți adresa unei conversații reale, nu pagina de start goală.
  3. Faceți clic pe butonul rotund portocaliu de descărcare, aflat în dreapta casetei de mesaj.
  4. Alegeți PDF, Markdown, text simplu, JSON, XML, CSV sau PNG. Ultimul format rămâne selectat.
  5. Apăsați „Export”. Chrome salvează fișierul imediat. Pentru PDF, setați opțiunile în dialogul PDF; primul PDF cere autentificare Google.

Fără autentificare pentru Markdown, text, JSON, XML, CSV sau PNG: aceste exporturi sunt nelimitate, anonime și nu trimit nimic. Autentificarea Google apare doar pentru PDF, „Export All” sau Pro. Extensia trimite atunci doar adresa de e-mail Google, pentru a verifica limita zilnică și a restaura Pro după o reinstalare. Textul chatului nu este niciodată încărcat. Mecanismul: cum funcționează.

Panoul de export setează și „Messages” (Mesaje: „All”, „Human”, „Assistant” — toate, om, asistent), o casetă „Thinking” (Gândire) și „Select” (Selectare), care bifează mesaje individuale. „Copy” pune Markdown, text, JSON, XML sau CSV în clipboard în loc de fișier; este nelimitat și nu este disponibil pentru PDF sau PNG. Pașii de instrumente / MCP și sursele căutării web se activează din Settings (Setări). Metadatele și aranjarea artefactelor („Original”, „Inline”, „Nested”, „Flat” — original, în text, imbricat, plat) sunt opțiuni din Dashboard; aranjarea decide dacă artefactele stau în fișier sau într-un folder propriu din ZIP.

Formatele funcționează și în „Export All”?

Da. Deschideți fereastra extensiei → „View and Download All Conversations” (Vizualizați și descărcați toate conversațiile), filtrați lista, bifați chaturile, alegeți oricare dintre cele șapte formate ca „Chat format”, apoi apăsați „Export All”. Primiți o arhivă ZIP cu câte un fișier pentru fiecare chat. Exportul în bloc cere autentificare Google; pe planul gratuit, fiecare chat din ZIP consumă unul din cele 3 exporturi PDF sau în bloc pe zi. Pro, la 3,99 USD pe lună sau 26,99 USD pe an, elimină această limită.

Dashboard-ul listează istoricul claude.ai cu căutare după nume, căutare după proiect, taburile Chat și Cowork și filtrele „All conversations”, „New”, „Updated” și „Previously exported” (toate, noi, actualizate, exportate anterior). „New” înseamnă încă neexportat cu Download Claude conversations. „Previously exported” ține evidența chaturilor deja salvate. „Export All” nu este o arhivă ZIP a contului, livrată cu întârziere.

Limita pentru exportul în bloc este zilnică. Pe planul gratuit, PDF-ul și exportul în bloc împart 3 exporturi pe zi, resetate la miezul nopții UTC. Fiecare chat dintr-o arhivă ZIP contează ca unul. Dacă selectați mai multe decât v-au rămas azi, întregul lot este blocat, nu tăiat. Alegeți mai puține chaturi sau folosiți Pro.

Exportul în bloc are propriile casete de includere — „Chats”, „Thinking”, „Metadata”, „Tools”, „Sources” (chaturi, gândire, metadate, instrumente, surse) — plus aranjarea artefactelor. Nu primiți un pachet mixt de Markdown plus JSON la un singur clic. Pentru fiecare rulare alegeți un singur format în selectorul „Chat format”. Rulați din nou „Export All” cu alt format dacă aveți nevoie de două forme ale aceluiași fir; pe planul gratuit, a doua rulare se numără din nou.

Formatele extensiei sau arhiva ZIP de la Anthropic?

Settings → Privacy → Export data de la Anthropic (etichetele pot apărea traduse dacă claude.ai este setat în limba română) trimite prin e-mail, după o așteptare, o arhivă ZIP JSON a întregului cont. Formatele de export pentru chat Claude din Download Claude conversations salvează imediat firul deschis ca PDF, Markdown, text, JSON, XML, CSV sau PNG. Folosiți arhiva ZIP pentru backup; folosiți această extensie acum.

Cât costă formatele de export?

Șase formate de export pentru chaturile Claude nu costă nimic și nu cer cont: Markdown, text simplu, JSON, XML, CSV și PNG sunt nelimitate. PDF-ul și ZIP-ul în bloc sunt gratuite până la 3 pe zi, în total, cu autentificare Google. Pro costă 3,99 USD pe lună sau 26,99 USD pe an, prin Paddle, și face PDF-ul și exportul în bloc nelimitate. Download Claude conversations nu percepe nimic în plus pentru vreun format anume.

Numărătoarea zilnică se resetează la miezul nopții UTC și urmează contul Google, motiv pentru care PDF-ul și exportul în bloc cer autentificare. Pro se restaurează pe un calculator nou când vă autentificați cu același cont Google. Paddle este comerciantul înregistrat; echipa noastră nu vede niciodată numerele cardurilor. Puteți anula oricând din pagina de opțiuni; prima plată are o garanție de returnare a banilor de 14 zile.

Întrebări frecvente: formate de export pentru chat Claude

Aceste întrebări acoperă formatele de export pentru chat Claude din Download Claude conversations 1.16.2: lista celor șapte formate, PDF, CSV, limitele, „Export All”, arhiva ZIP a Anthropic, Desktop și Code, precum și Pro. Fiecare răspuns este un fapt despre produs. JSON-LD-ul FAQPage din antetul paginii corespunde acestei liste.

În ce formate pot descărca un chat Claude?

Șapte: PDF, Markdown, text simplu, JSON, XML, CSV și PNG. Markdown, text, JSON, XML, CSV și PNG sunt nelimitate și nu cer cont. PDF-ul cere autentificare Google și este gratuit până la 3 pe zi.

PDF este unul dintre formatele de export pentru chat Claude?

Da. Alegeți PDF în panoul de export. Dialogul PDF setează numele fișierului, dimensiunea paginii, marginile, modul luminos sau întunecat, fontul și dimensiunea lui, numerele de pagină, un cuprins, marcajele de timp și un salt de pagină înaintea fiecărui prompt. Este generat în browser, fără dialogul de tipărire.

La ce folosește exportul CSV?

Pentru tabele de calcul. CSV scrie câte un rând pentru fiecare mesaj și se deschide în Excel, Google Sheets și Numbers. Este nelimitat, nu cere cont și poate fi copiat în clipboard în loc să fie descărcat.

Formatele de export au o limită zilnică?

Doar PDF-ul și exportul în bloc. Exporturile unui singur chat în Markdown, text, JSON, XML, CSV și PNG sunt nelimitate și gratuite. PDF-ul și ZIP-ul în bloc împart 3 pe zi pe planul gratuit, cu resetare la miezul nopții UTC. Pro, la 3,99 USD pe lună sau 26,99 USD pe an, elimină limita.

Pot amesteca formatele în „Export All”?

Nu. O rulare „Export All” folosește un singur format și scrie o singură arhivă ZIP. Rulați-o din nou cu alt format dacă aveți nevoie de două fișiere pentru același chat claude.ai. Pe planul gratuit, fiecare chat din fiecare ZIP se numără din cele 3 exporturi PDF sau în bloc pe zi.

Formatele de export sunt același lucru cu „Export data”?

Nu. „Export data” de la Anthropic este o arhivă ZIP JSON a contului, livrată cu întârziere. Formatele de export pentru chat Claude sunt fișiere per chat (sau per selecție), scrise imediat în Chrome de Download Claude conversations.

Formatele de export funcționează în Desktop sau în Claude Code?

Pe web, da. Chaturile, Projects, sesiunile Cowork și Claude Code on the web (claude.ai/code) primesc toate formatele în Chrome. Aplicația Claude Desktop și sesiunile locale Claude Code din terminal nu afișează niciodată lista de formate. Deschideți același fir pe claude.ai în Chrome, dacă există acolo.

Am nevoie de Pro ca să încerc formatele de export?

Nu. Șase formate sunt nelimitate pe planul gratuit, fără cont. PDF-ul este gratuit până la 3 pe zi, cu autentificare Google, în comun cu ZIP-ul în bloc. Pro costă 3,99 USD pe lună sau 26,99 USD pe an, când aveți nevoie de PDF sau export în bloc nelimitate.
