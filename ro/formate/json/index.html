Cum fac exportul unei conversații Claude în JSON?

Deschideți conversația pe claude.ai în Chrome, faceți clic pe butonul portocaliu de lângă caseta de mesaj, alegeți JSON, apoi apăsați „Export”. Download Claude conversations scrie fișierul local. Așa funcționează exportul unei conversații Claude în JSON în versiunea 1.16.2. În septembrie 2026, claude.ai nu are o comandă proprie de salvare în JSON pentru un singur chat.

  1. Instalați Download Claude conversations din Chrome Web Store.
  2. Reîncărcați claude.ai și deschideți adresa unei conversații reale, nu pagina de start goală.
  3. Faceți clic pe butonul portocaliu de descărcare, aflat în dreapta casetei de mesaj.
  4. Alegeți JSON. Ultimul format folosit este reținut. Cu „Select” (Selectare) bifați doar mesajele dorite.
  5. Apăsați „Export”. Chrome descarcă fișierul JSON prin API-ul de descărcări al browserului. Sau apăsați „Copy” (Copiere) ca să puneți JSON-ul în clipboard.

Pentru exportul în JSON nu este nevoie de autentificare. Exporturile JSON ale unui singur chat sunt nelimitate, anonime și nu trimit nimic către serverele noastre. Autentificarea Google este cerută doar pentru PDF și pentru exportul în bloc „Export All” (Exportă tot). Mecanismul: cum funcționează.

Dacă butonul portocaliu lipsește, nu vă aflați pe adresa unei conversații, fila trebuie reîncărcată sau extensia este ascunsă în meniul cu piesa de puzzle din Chrome. Fixați Download Claude conversations, apoi reîmprospătați claude.ai. Scriptul extensiei nu se injectează niciodată în Claude Desktop sau în terminalul Claude Code.

Un fir sau mai multe fișiere. Butonul portocaliu exportă chatul deschis în JSON. Pentru mai multe fișiere JSON, deschideți „View and Download All Conversations” (Vizualizați și descărcați toate conversațiile) și rulați „Export All” cu JSON selectat: o singură arhivă ZIP, 3 chaturi pe zi pe planul gratuit — vedeți exportul în bloc „Export All”.

Când merită exportul în JSON?

Exportați conversația Claude în JSON când fișierul va fi citit de un script, de un indexator sau de un instrument de comparare. JSON-ul este construit pentru arborele mesajelor, nu pentru lectură în Obsidian. Dacă doriți titluri și cod delimitat pentru oameni, alegeți Markdown. Pentru o foaie de calcul, alegeți CSV: câte un rând pe mesaj.

Copierea din claude.ai pierde structura expeditorilor. Tipărirea păstrează elementele paginii web. La exportul în JSON, Download Claude conversations păstrează replicile, expeditorii și, opțional, gândirea ca date, nu ca un paragraf aplatizat. De aceea dezvoltatorii preferă JSON în locul textului simplu.

Scriem JSON-ul din arborele claude.ai deja încărcat în pagină — expeditor, blocuri de conținut, marcaje de timp, metadatele modelului — fără să încărcăm firul nicăieri. Acest JSON nu este arhiva ZIP a contului de la Anthropic. În versiunea 1.16.2 este unul dintre cele șapte formate, alături de PDF și CSV, și este gratuit, fără cont.

Ce conține exportul JSON al unei conversații Claude?

Exportul JSON al unei conversații Claude reproduce arborele de mesaje de pe claude.ai: expeditor, blocuri de conținut, marcaje de timp și metadatele modelului. Blocurile de gândire, sursele căutării web, pașii tool / MCP și artefactele sunt incluse când aceste opțiuni sunt active: „Thinking” (Gândire) este o casetă de bifat în panoul de export, iar uneltele și sursele se activează în Settings (Setări). Filtrul după expeditor poate limita fișierul la toate mesajele, doar la cele ale omului sau doar la cele ale asistentului. Nimic nu este convertit mai întâi în Markdown.

Aranjarea artefactelor în versiunea 1.16.2 este „Original”, „Inline”, „Nested” sau „Flat” (original, în text, imbricat, plat). Aceste variante schimbă felul în care conținutul artefactelor este imbricat în JSON, aceleași patru opțiuni ca pentru Markdown și XML. Lista completă: funcțiile extensiei Chrome. Pentru pagini în loc de date, exportați PDF.

JSON-ul conversației sau exportul de date Anthropic?

Ambele sunt JSON, dar nu au aceeași formă și nici aceeași acoperire. Settings → Privacy → Export data (etichetele pot fi traduse dacă claude.ai este setat în română) de la Anthropic trimite pe e-mail, după o așteptare, o singură arhivă ZIP a întregului cont. La exportul unei conversații Claude în JSON primiți imediat un singur fir, în Chrome. Folosiți arhiva ZIP pentru copii de siguranță.

Download Claude conversations nu este afiliată cu Anthropic, PBC. Scriptul extensiei folosește sesiunea pe care ați deschis-o deja pe claude.ai. Nu se autentifică la Anthropic cu date de acces separate. Respectați regulile Anthropic pentru contul dumneavoastră.

Pot exporta conversații Claude în JSON în bloc?

Da. Deschideți „View and Download All Conversations”, setați „Chat format” (Formatul chatului) la JSON, filtrați tabelul, apoi apăsați „Export All”. Chrome salvează o singură arhivă ZIP, cu câte un fișier JSON pentru fiecare chat. Pe planul gratuit asta înseamnă 3 chaturi pe zi, cu autentificare Google, limită comună cu PDF-ul. Pro, la 3,99 USD pe lună sau 26,99 USD pe an, elimină limita pentru JSON în bloc.

Dashboard-ul listează istoricul claude.ai, cu căutare după nume, filtrele „All conversations”, „New”, „Updated” și „Previously exported” (toate, noi, actualizate, exportate anterior), taburile Chat și Cowork și căutare după proiect. „New” înseamnă că firul nu a fost încă exportat cu Download Claude conversations. „Previously exported” urmărește chaturile deja salvate. „Export All” produce o arhivă ZIP cu fișiere JSON, câte unul pe chat, nu o arhivă cu formate amestecate.

Limita zilnică este per cont. Trei chaturi pe zi pe planul gratuit, în comun cu PDF-ul. Dacă selectați 40 de conversații și mai aveți 3, întregul lot este blocat, nu trunchiat. Selectați mai puține sau folosiți Pro. Exporturile JSON individuale din butonul portocaliu rămân nelimitate.

Puteți compara două exporturi JSON ale aceluiași fir claude.ai, făcute în momente diferite, la fel ca orice fișiere JSON. Fiecare export este de sine stătător. Un al doilea „Export All” al acelorași chaturi consumă din nou câte o unitate pentru fiecare chat.

Exportul JSON are nevoie de Pro?

Nu. Exportul JSON al unui singur chat este gratuit și nelimitat, fără cont și fără contor — la fel ca Markdown, text, XML, CSV și PNG. Doar PDF-ul și exportul în bloc „Export All” au o limită gratuită: 3 pe zi, cu autentificare Google. Pro costă 3,99 USD pe lună sau 26,99 USD pe an, prin Paddle. Download Claude conversations nu percepe nimic în plus pentru exportul unei conversații Claude în JSON.

Limita se vede la JSON în bloc. Fiecare chat dintr-o arhivă ZIP „Export All” consumă unul din cele 3 pe zi, iar numărătoarea se resetează la miezul nopții UTC. Pro elimină limita și se restaurează pe un calculator nou din același cont Google. Paddle este comerciantul înregistrat; echipa noastră nu vede niciodată numerele cardurilor.

Extensia rulează doar pe claude.ai în Chrome. Claude Desktop și terminalul Claude Code nu primesc un buton JSON; Claude Code on the web (claude.ai/code) rulează pe claude.ai, deci se exportă ca orice chat. Comanda /export din terminalul Claude Code sau fișierele JSONL de pe disc sunt o cale diferită. Versiunea 1.16.2, din septembrie 2026, tot nu scrie fișiere Word sau Notion.

Întrebări frecvente: export conversație Claude în JSON

Aceste întrebări acoperă exportul unei conversații Claude în JSON cu Download Claude conversations 1.16.2: „Export All” în bloc, structura datelor, cost, comparații, arhiva ZIP a Anthropic, PDF și Desktop. Fiecare răspuns este un fapt despre produs. Datele structurate FAQPage din antetul paginii corespund acestei liste.

Pot exporta conversații Claude în JSON în bloc?

Da. „Export All” din Dashboard acceptă JSON și salvează o arhivă ZIP cu câte un fișier JSON pe chat. Pe planul gratuit acoperă 3 chaturi pe zi, cu autentificare Google; Pro, la 3,99 USD pe lună sau 26,99 USD pe an, este nelimitat.

Structura JSON este documentată?

Reproduce arborele de mesaje al claude.ai: expeditor, blocuri de conținut, marcaje de timp și metadatele modelului, cu artefacte, blocuri de gândire, surse ale căutării web și pași tool / MCP incluși când activați aceste opțiuni. Nu este schema arhivei ZIP a contului de la Anthropic.

Am nevoie de Pro pentru exportul unei conversații Claude în JSON?

Nu. Exporturile JSON ale unui singur chat sunt nelimitate și nu cer cont, la fel ca toate formatele în afară de PDF. Pro, la 3,99 USD pe lună sau 26,99 USD pe an, ridică doar limita de 3 pe zi pentru PDF și pentru „Export All” în bloc.

Pot compara două exporturi JSON ale aceluiași chat?

Da. De fiecare dată când exportați conversația Claude în JSON, primiți un fișier de sine stătător, construit la fel. Compararea a două exporturi ale aceluiași fir, făcute în momente diferite, funcționează ca pentru orice alt fișier JSON.

Acest JSON este același lucru cu exportul de date Anthropic?

Nu. Exportul de date Anthropic este o arhivă ZIP a întregului cont, livrată cu întârziere. Download Claude conversations scrie imediat, în Chrome, un fișier JSON per chat (sau per selecție). Ambele pot fi JSON, dar nu sunt interschimbabile.

Exportul conversației Claude în JSON creează un PDF?

Nu. JSON înseamnă date structurate. Pentru pagini, alegeți PDF în același panou; cele șapte formate sunt PDF, Markdown, JSON, text simplu, XML, CSV și PNG. PDF-ul cere autentificare Google și intră în limita de 3 pe zi pe planul gratuit.

Exportul JSON funcționează în Claude Desktop?

Nu. Extensia Chrome se injectează doar pe claude.ai. Claude Desktop nu afișează niciodată opțiunea JSON. Deschideți același fir pe claude.ai în Chrome, dacă există acolo.
