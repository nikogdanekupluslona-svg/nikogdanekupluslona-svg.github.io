Cum fac exportul unui chat Claude în Markdown?

Deschideți conversația pe claude.ai în Chrome, faceți clic pe butonul portocaliu de lângă caseta de mesaj, alegeți Markdown, apoi apăsați „Export”. Download Claude conversations scrie local un fișier .md. Așa funcționează exportul unui chat Claude în Markdown în versiunea 1.16.2.

  1. Instalați Download Claude conversations din Chrome Web Store.
  2. Reîncărcați claude.ai și deschideți adresa unei conversații reale, nu pagina de start goală.
  3. Faceți clic pe butonul portocaliu de descărcare, aflat în dreapta casetei de mesaj.
  4. Alegeți Markdown. Extensia reține ultimul format folosit. Cu „Select” (Selectare) bifați doar mesajele dorite.
  5. Apăsați „Export”. Chrome descarcă fișierul .md prin API-ul de descărcări al browserului. Sau apăsați „Copy” (Copiere) ca să puneți textul Markdown în clipboard.

Pentru exportul în Markdown nu este nevoie de autentificare. Exporturile Markdown ale unui singur chat sunt nelimitate, anonime și nu trimit nimic către serverele noastre. Autentificarea Google este cerută doar pentru PDF și pentru exportul în bloc „Export All” (Exportă tot). Mecanismul: cum funcționează.

Dacă butonul portocaliu lipsește, nu vă aflați pe adresa unei conversații, fila trebuie reîncărcată după instalare sau extensia este încă ascunsă în meniul cu piesa de puzzle din Chrome. Fixați Download Claude conversations, apoi reîmprospătați claude.ai. Scriptul extensiei nu se injectează niciodată în Claude Desktop sau în terminalul Claude Code.

Un chat sau mai multe. Butonul portocaliu exportă firul deschis în Markdown. Pentru mai multe fișiere .md, deschideți „View and Download All Conversations” (Vizualizați și descărcați toate conversațiile) și rulați „Export All” cu Markdown selectat: o singură arhivă ZIP, 3 chaturi pe zi pe planul gratuit — vedeți exportul în bloc „Export All”.

De ce Markdown pentru notițe?

Alegeți Markdown când veți citi fișierul în Obsidian, într-un wiki GitHub sau în orice editor care afișează titlurile și blocurile de cod. Fișierul .md rămâne text simplu, în care puteți căuta și compara versiuni. JSON este mai potrivit pentru programe de analiză; PNG este o imagine în care nu puteți căuta text.

Copierea din claude.ai pierde de obicei indentarea și aplatizează tabelele. Tipărirea (Ctrl/Cmd+P) păstrează bara laterală și adesea rupe un bloc lung de cod pe mai multe pagini. La exportul în Markdown, etichetele de limbaj rămân pe blocurile de cod, iar tabelele rămân tabele. De aceea cei care scriu aleg mai întâi acest format.

Considerăm Markdown fișierul implicit pentru oameni: titluri, cod delimitat cu etichete de limbaj și tabele din firul claude.ai. Când aveți nevoie de pagini, alegeți PDF în același panou. Este așezat în pagină direct în browser, cu dimensiunea paginii, margini și cuprins.

Ce păstrează exportul în Markdown?

La exportul unui chat Claude în Markdown, Download Claude conversations păstrează titlurile, codul delimitat cu eticheta de limbaj și indentarea, tabelele și linkurile. Blocurile de gândire, sursele căutării web și pașii tool / MCP sunt fiecare opționali: „Thinking” (Gândire) este o casetă de bifat în panoul de export, iar celelalte două se activează în Settings (Setări). Metadatele (titlu, marcaje de timp, model) pot fi incluse. Filtrul după expeditor poate limita fișierul .md la toate mesajele, doar la cele ale omului sau doar la cele ale asistentului.

Aranjarea artefactelor este o opțiune reală în versiunea 1.16.2: „Original”, „Inline”, „Nested” sau „Flat” (original, în text, imbricat, plat). Un export Markdown poate reproduce structura artefactelor de pe ecran, o poate aplatiza într-un singur document liniar sau poate muta artefactele în propriul folder dintr-o arhivă ZIP. Settings poate încorpora imaginile în fișierul .md. Lista completă: funcțiile extensiei Chrome. Markdown nu păstrează culorile bulelor de mesaj; folosiți PNG pentru o captură vizuală sau PDF pentru pagini.

Dacă firul este foarte lung, derulați până când claude.ai încarcă mesajele mai vechi, înainte de export. Extensia poate scrie doar ce a afișat pagina. Un fir încărcat pe jumătate produce un fișier .md pe jumătate, ceea ce pare o eroare, dar de obicei înseamnă doar că pagina nu a fost derulată.

Pot exporta chaturi Claude în Markdown în bloc?

Da. Deschideți „View and Download All Conversations”, setați „Chat format” (Formatul chatului) la Markdown, filtrați tabelul, apoi apăsați „Export All”. Chrome salvează o singură arhivă ZIP, cu câte un fișier .md pentru fiecare chat. Pe planul gratuit asta înseamnă 3 chaturi pe zi, cu autentificare Google, limită comună cu PDF-ul. Pro, la 3,99 USD pe lună sau 26,99 USD pe an, elimină limita pentru Markdown în bloc.

Dashboard-ul listează istoricul claude.ai, cu căutare după nume, filtrele „All conversations”, „New”, „Updated” și „Previously exported” (toate, noi, actualizate, exportate anterior), taburile Chat și Cowork și căutare după proiect. „New” înseamnă că firul nu a fost încă exportat cu Download Claude conversations. „Previously exported” urmărește chaturile deja salvate, ca un al doilea „Export All” să le poată sări.

Limita zilnică este per cont. Trei chaturi pe zi pe planul gratuit, în comun cu PDF-ul. Dacă selectați 40 de conversații și mai aveți 3, întregul lot este blocat, nu trunchiat. Selectați mai puține sau folosiți Pro. Exporturile .md individuale din butonul portocaliu rămân nelimitate.

Exportul Markdown în bloc folosește casetele din Dashboard „Chats”, „Thinking”, „Metadata”, „Tools” și „Sources” (chaturi, gândire, metadate, unelte, surse), plus formatul artefactelor. „Export All” nu este arhiva ZIP întârziată a Anthropic. Este o singură arhivă ZIP cu fișiere .md, câte unul pe chat. Dacă doriți o arhivă a întregului cont, aceasta se află la Settings → Privacy → Export data (etichetele pot fi traduse dacă claude.ai este setat în română) și conține JSON, nu Markdown.

Markdown sau JSON la exportul unui chat Claude?

Alegeți Markdown când fișierul va fi citit de un om. Alegeți JSON când un script va analiza arborele mesajelor. Download Claude conversations le oferă pe amândouă în același meniu derulant, plus PDF, text simplu, XML, CSV și PNG. Pagina formatelor: formatele de export pentru chaturile Claude.

CSV Foi de calcul, câte un rând pe mesaj

Exportul de date al Anthropic este tot JSON, dar este o arhivă ZIP a contului trimisă pe e-mail, nu un fișier .md per chat. În acea cerere nu puteți alege Markdown. Tipărirea din browser este o captură a paginii web. Niciuna nu înlocuiește exportul în Markdown din butonul portocaliu.

Extensia rulează doar pe claude.ai în Chrome. Claude Desktop și terminalul Claude Code nu primesc un buton Markdown. Claude Code on the web (claude.ai/code) rulează pe claude.ai, deci se exportă ca orice chat. Dacă un fir există și pe claude.ai, deschideți-l acolo și exportați-l în Markdown. Comanda /export din terminalul Claude Code este o cale diferită, a altui produs.

Exportul în Markdown costă în plus?

Nu. Exportul unui chat în Markdown este gratuit și nelimitat, fără cont și fără contor — la fel ca JSON, text, XML, CSV și PNG. Doar PDF-ul și exportul în bloc „Export All” au o limită gratuită: 3 pe zi, cu autentificare Google. Pro costă 3,99 USD pe lună sau 26,99 USD pe an, prin Paddle. Download Claude conversations nu percepe niciun supliment pentru Markdown.

Limita se vede la Markdown în bloc. Fiecare chat dintr-o arhivă ZIP „Export All” consumă unul din cele 3 pe zi, iar numărătoarea se resetează la miezul nopții UTC. Pro elimină limita și se restaurează pe un calculator nou din același cont Google. Paddle este comerciantul înregistrat; echipa noastră nu vede niciodată numerele cardurilor.

Nu aveți nevoie de un plan claude.ai plătit de la Anthropic. Aveți nevoie doar de o autentificare care poate încărca conversația în Chrome. Team și Enterprise funcționează la fel ca Free cu butonul portocaliu. Versiunea 1.16.2, din septembrie 2026, tot nu scrie fișiere Word sau Notion.

Întrebări frecvente: export chat Claude în Markdown

Aceste întrebări acoperă exportul unui chat Claude în Markdown cu Download Claude conversations 1.16.2: blocuri de cod, „Export All” în bloc, arhiva ZIP a Anthropic, cost, PDF și Desktop. Fiecare răspuns este un fapt despre produs. Datele structurate FAQPage din antetul paginii corespund acestei liste.

Exportul unui chat Claude în Markdown pierde codul?

Nu. Blocurile de cod își păstrează eticheta de limbaj și indentarea, spre deosebire de o simplă copiere din claude.ai. Tabelele rămân tabele Markdown. Acesta este principalul motiv pentru a exporta chatul Claude în Markdown în loc să selectați textul manual.

Pot exporta chaturi Claude în Markdown în bloc?

Da. „Export All” din Dashboard acceptă Markdown și salvează o arhivă ZIP cu fișiere .md. Pe planul gratuit acoperă 3 chaturi pe zi, cu autentificare Google; Pro este nelimitat.

Markdown este același lucru cu exportul de date Anthropic?

Nu. Exportul oficial al Anthropic este o arhivă ZIP cu JSON pentru întregul cont, trimisă pe e-mail după o așteptare. Exportul chatului Claude în Markdown este un fișier .md per chat (sau per selecție), creat de Download Claude conversations.

Markdown costă mai mult decât alte formate?

Nu. Exporturile Markdown ale unui singur chat sunt nelimitate și nu cer cont, la fel ca JSON, text, XML, CSV și PNG. Doar PDF-ul și ZIP-ul în bloc au o limită gratuită de 3 pe zi. Pro costă 3,99 USD pe lună sau 26,99 USD pe an.

Pot exporta un chat Claude în Markdown din Desktop?

Nu. Download Claude conversations se injectează doar pe claude.ai în Chrome. Claude Desktop nu afișează niciodată meniul derulant cu Markdown. Deschideți același fir pe claude.ai, dacă există acolo.

Exportul în Markdown creează un PDF?

Nu. Markdown este un fișier text .md. Pentru pagini, alegeți PDF în același panou: este construit în browser, cu dimensiunea paginii, margini și cuprins. PDF-ul cere autentificare Google și intră în limita de 3 pe zi pe planul gratuit.

Am nevoie de Pro pentru un singur export în Markdown?

Nu. Nu aveți nevoie de niciun cont. Exporturile Markdown ale unui singur chat sunt nelimitate pe planul gratuit. Pro, la 3,99 USD pe lună sau 26,99 USD pe an, ridică doar limita de 3 pe zi pentru „Export All” în bloc și pentru PDF.
