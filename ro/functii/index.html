Ce funcții ale extensiei exportă un singur chat?

Funcția de bază pentru un singur fir este butonul portocaliu pe care Download Claude conversations îl adaugă lângă caseta de mesaj pe claude.ai. Deschideți adresa unei conversații, alegeți un format, apoi apăsați „Export” sau „Copy”. Fișierul se descarcă imediat. Doar PDF-ul cere autentificare; celelalte șase formate nu cer cont.

  1. Instalați Download Claude conversations din Chrome Web Store.
  2. Reîncărcați claude.ai și deschideți adresa unei conversații reale — un chat, un chat dintr-un Project, o sesiune Cowork sau Claude Code on the web.
  3. Faceți clic pe butonul portocaliu de descărcare, aflat în dreapta casetei de mesaj.
  4. Alegeți „Messages” (Mesaje: „All”, „Human” sau „Assistant” — toate, om sau asistent), un format și caseta „Thinking” (Gândire), sau apăsați „Select” pentru a bifa mesaje individuale. Extensia reține ultimul format folosit.
  5. Apăsați „Export” pentru a descărca fișierul sau „Copy” pentru a-l pune în clipboard. „Copy” funcționează pentru Markdown, text, JSON, XML și CSV.

Butonul portocaliu apare doar pe o conversație încărcată. Pagina de start goală nu are nimic de analizat. Dacă butonul lipsește, fixați extensia din meniul cu piesa de puzzle din Chrome și reîmprospătați claude.ai. Funcțiile extensiei Chrome nu se injectează niciodată în Claude Desktop sau în terminalul Claude Code. Alegerea PDF deschide un dialog pentru numele fișierului, dimensiunea paginii, margini, mod luminos sau întunecat, font și dimensiunea fontului, numere de pagină, cuprins, marcaje de timp și un salt de pagină înaintea fiecărui prompt: chat Claude în PDF.

Fișier local. PDF, Markdown, JSON, text, XML, CSV și PNG sunt generate în filă. Exporturile unui singur chat în formatele non-PDF nu trimit nimic către serverele noastre. PDF-ul și exportul în bloc trimit doar adresa de e-mail Google, pentru numărătoarea zilnică. Textul chatului nu pleacă niciodată. Mecanismul: cum funcționează.

Ce funcții acoperă exportul în bloc „Export All”?

Funcțiile pentru exportul în bloc se află în Dashboard, „View and Download All Conversations” (Vizualizați și descărcați toate conversațiile): căutare, filtrele „All conversations” / „New” / „Updated” / „Previously exported” (toate, noi, actualizate, exportate anterior), taburile Chat și Cowork, căutarea după proiect și „Export All”. „Export All” salvează o singură arhivă ZIP. Planul gratuit acoperă 3 chaturi pe zi, cu autentificare Google; Pro, la 3,99 USD pe lună sau 26,99 USD pe an, elimină limita.

„New” înseamnă încă neexportat cu Download Claude conversations. „Previously exported” ține evidența chaturilor deja salvate, ca un al doilea „Export All” să le poată sări. Tabul Cowork listează sesiunile Cowork lângă chaturile obișnuite. Căutarea după proiect găsește chaturile dintr-un singur Project de pe claude.ai. Căutarea se face după numele conversației. Fluxul complet: exportul în bloc „Export All”.

Limita zilnică este per cont. Trei chaturi pe zi pe planul gratuit, comune cu PDF-ul — nu trei pentru fiecare rulare în bloc. Dacă selectați 40 de conversații și v-au rămas 3, întregul lot este blocat, nu tăiat. Planificați selecția înainte să apăsați „Export All” sau folosiți Pro.

„Export All” folosește selectorul „Chat format” (Formatul chatului) din Dashboard (toate cele șapte formate, inclusiv PDF), casetele „Chats”, „Thinking”, „Metadata”, „Tools” și „Sources” (chaturi, gândire, metadate, instrumente, surse) și formatul artefactelor. Rezultatul este o arhivă ZIP cu câte un fișier per chat, nu arhiva contului de la Anthropic, livrată cu întârziere. Alegeți un singur format per rulare. Extensia nu amestecă Markdown și JSON la un singur clic. Dashboard-ul are și backup și restaurare.

În ce formate scrie extensia Chrome?

Extensia Chrome scrie șapte formate: PDF, Markdown, text simplu, JSON, XML, CSV și PNG. Markdown, text, JSON, XML, CSV și PNG sunt nelimitate, fără cont. PDF-ul este generat în browser, cere autentificare Google și intră în limita de 3 pe zi a planului gratuit. Lista este aceeași la butonul portocaliu și în selectorul „Chat format” din Dashboard. Extensia păstrează artefactele?

Da. Printre funcțiile extensiei Chrome se numără aranjarea artefactelor: „Original”, „Inline”, „Nested” sau „Flat” (original, în text, imbricat sau plat). Blocurile de gândire, pașii de instrumente / MCP și sursele căutării web sunt fiecare opționale: „Thinking” este o casetă în panoul de export, instrumentele și sursele se activează din Settings, iar Dashboard-ul are casete pentru toate trei. „Metadata” poate adăuga titlul, marcajele de timp și modelul. Filtrul de expeditor limitează fișierul la toate mesajele, doar cele umane sau doar cele ale asistentului, iar „Select” bifează mesaje individuale.

Artefactele fac parte din firul claude.ai. Aranjarea decide dacă stau în fișierul Markdown, JSON, XML sau text ori merg într-un folder propriu dintr-o arhivă ZIP. Arhivele ZIP cu artefacte sunt nelimitate și gratuite, la fel ca arhiva ZIP cu fișierele proiectului: pe pagina unui Project, faceți clic pe „Project files” → „Download ZIP” (Fișierele proiectului → Descărcare ZIP). În PNG, artefactele sunt desenate, nu stocate ca marcaje. Dacă gândirea este dezactivată, exportul omite gândirea extinsă chiar dacă claude.ai a afișat-o pe ecran.

Dacă firul este lung, derulați până când claude.ai încarcă mesajele mai vechi. Extensia poate exporta doar ce a afișat pagina. Un DOM încărcat pe jumătate produce un fișier trunchiat, care pare o eroare de artefact lipsă și este de obicei o conversație nederulată.

Ce funcții găsiți în Settings?

Settings (Setări) este pagina de opțiuni a extensiei. Conține șablonul numelui de fișier, „Copy instead of download” (Copiere în loc de descărcare), imaginile încorporate în Markdown, pașii de instrumente / MCP, sursele căutării web, formatul datei și orei, backup și restaurare, precum și abonamentul. Interfața extensiei este doar în engleză.

Cum gestionează extensia autentificarea?

Majoritatea funcțiilor extensiei nu cer autentificare. Exporturile unui singur chat în Markdown, text simplu, JSON, XML, CSV și PNG sunt nelimitate și anonime, la fel ca „Copy”, „Select”, arhivele ZIP cu artefacte și arhiva ZIP cu fișierele proiectului. Autentificarea Google este cerută doar pentru PDF, exportul în bloc „Export All” și Pro. Conținutul conversațiilor nu face niciodată parte din acest flux.

PDF-ul și ZIP-ul în bloc împart 3 pe zi pe planul gratuit, numărate pe serverul nostru după adresa de e-mail Google. Ziua se resetează la miezul nopții UTC, iar o reinstalare nu o resetează. Pro costă 3,99 USD pe lună sau 26,99 USD pe an, prin Paddle. Paddle este comerciantul înregistrat; echipa noastră nu vede niciodată numerele cardurilor. Pro se restaurează pe un calculator nou când vă autentificați cu același cont Google.

Nu aveți nevoie de planul plătit claude.ai de la Anthropic. Planurile claude.ai Free, Pro, Team și Enterprise funcționează dacă Chrome poate deschide chatul. Dacă un administrator de spațiu de lucru blochează extensiile, Download Claude conversations nu se va injecta — este o politică a browserului, nu o funcție lipsă de pe această pagină.

Ce funcții nu există în versiunea 1.16.2?

Funcțiile extensiei Chrome care nu există în 1.16.2: export în Notion, export în Word, trimitere în Google Docs, integrare cu Claude Desktop și sesiunile locale Claude Code din terminal (/export, ~/.claude/projects). Download Claude conversations este un script de conținut Chrome pentru claude.ai, nu o a doua aplicație sub alt nume. PDF-ul nu mai este pe această listă; este inclus.

Claude Desktop este o aplicație pentru Mac/Windows. Claude Code în terminal este un agent local. Niciunul nu primește butonul portocaliu. Claude Code on the web (claude.ai/code) și sesiunile Cowork se deschid pe claude.ai, deci se exportă ca orice chat. Dacă un fir din Desktop există și pe claude.ai, deschideți-l în Chrome și folosiți acolo funcțiile extensiei. Diferența față de Desktop: export chat Claude Desktop. Diferența față de Code: export din Claude Code.

claude.ai pe mobil, într-un browser de telefon, este în afara scopului. Echipa noastră nu are în 2026 o aplicație pentru iOS sau Android. „Copy” nu este disponibil pentru PDF sau PNG. Versiune datată septembrie 2026. Dacă adăugăm un format, această pagină se actualizează în aceeași zi.

Ce funcții ale extensiei Chrome exportă un singur chat?

Butonul portocaliu de lângă caseta de mesaj, pe adresa unei conversații claude.ai. Alegeți PDF, Markdown, JSON, text, XML, CSV sau PNG, apoi apăsați „Export” sau „Copy”. Aceasta este calea cea mai rapidă pentru un singur fir și doar PDF-ul cere autentificare.

Funcțiile extensiei includ exportul în bloc „Export All”?

Da. Dashboard-ul („View and Download All Conversations”) listează istoricul claude.ai cu filtrele „All conversations”, „New”, „Updated” și „Previously exported”, taburile Chat și Cowork și căutarea după proiect. „Export All” salvează o singură arhivă ZIP. Ce formate acceptă extensia Chrome?

Șapte: PDF, Markdown, text simplu, JSON, XML, CSV și PNG. PDF-ul este generat în browser, cu propriul dialog. CSV înseamnă câte un rând pentru fiecare mesaj. PNG este o singură imagine a conversației.

Extensia exportă artefactele și gândirea?

Da. Aranjarea artefactelor este „Original”, „Inline”, „Nested” sau „Flat”, iar artefactele pot merge într-un folder propriu din arhiva ZIP. Gândirea, pașii de instrumente / MCP și sursele căutării web sunt fiecare opționale. Metadatele, filtrul de expeditor și „Select” sunt opționale.

Funcțiile extensiei pot fi încercate gratuit?

Da. Exporturile în Markdown, text, JSON, XML, CSV și PNG sunt nelimitate și nu cer cont. PDF-ul și ZIP-ul în bloc sunt 3 pe zi, cu autentificare Google. Pro, la 3,99 USD pe lună sau 26,99 USD pe an, prin Paddle, elimină această limită.

Funcțiile extensiei merg în Desktop sau în Claude Code?

Nu în Claude Desktop și nici în terminalul Claude Code. Scriptul de conținut se injectează doar pe claude.ai, în Chrome. Claude Code on the web (claude.ai/code) și sesiunile Cowork rulează acolo, deci se exportă. Deschideți un fir din Desktop pe claude.ai, dacă există acolo.

Extensia îmi încarcă chaturile undeva?

Nu. Fiecare fișier, inclusiv PDF-ul, este generat în browser. Exporturile unui singur chat în celelalte formate nu trimit nimic. Pentru PDF, export în bloc sau Pro se trimite doar adresa de e-mail Google, pentru numărătoarea zilnică și abonament. Limitele exacte sunt descrise în pagina despre cum funcționează.
