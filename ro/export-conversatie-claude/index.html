Cum funcționează exportul unei conversații Claude în Chrome?

Deschideți adresa unei conversații pe claude.ai în Chrome, faceți clic pe butonul portocaliu din dreapta casetei de mesaj, alegeți PDF, Markdown, JSON, text, XML, CSV sau PNG, apoi „Export”. Download Claude conversations scrie local fișierul conversației. Reîncărcați claude.ai după instalare. claude.ai nu are o comandă de export pentru o singură conversație.

  1. Instalați Download Claude conversations din Chrome Web Store (versiunea 1.16.2).
  2. Reîncărcați fila claude.ai, ca scriptul de conținut să se poată activa pe adresa unei conversații.
  3. Deschideți o conversație reală, nu pagina de start goală de pe claude.ai.
  4. Faceți clic pe butonul rotund portocaliu de descărcare, aflat în dreapta casetei de mesaj.
  5. Setați „Messages” (Mesaje) pe „All”, „Human” sau „Assistant” (Toate, Om sau Asistent), bifați „Thinking” (Gândire) dacă doriți, alegeți PDF, Markdown, JSON, text simplu, XML, CSV sau PNG, apoi apăsați „Export”.

Nu aveți nevoie de cont pentru a exporta o conversație Claude în Markdown, text, JSON, XML, CSV sau PNG. Aceste exporturi ale unei singure conversații sunt nelimitate și nu trimit nimic către serverele noastre. Autentificarea Google este cerută doar pentru PDF și pentru exportul în bloc „Export All” (Exportă tot), care împart 3 pe zi pe planul gratuit. Textul conversației nu face niciodată parte din această autentificare Google. Detalii tehnice: cum funcționează.

Dacă butonul portocaliu lipsește, fila nu se află pe adresa unei conversații claude.ai, pagina trebuie încă reîncărcată după instalare sau Download Claude conversations este ascunsă în meniul cu piesa de puzzle din Chrome. Fixați extensia, apoi reîmprospătați pagina. Butonul portocaliu nu apare niciodată pe alte site-uri.

Lista de formate din Download Claude conversations reține ultima alegere. „Select” (Selectare) bifează mesaje individuale, iar „Copy” (Copiere) pune Markdown, text, JSON, XML sau CSV în clipboard în loc de fișier. Fișierele incomplete înseamnă de obicei că firul lung de pe claude.ai nu terminase de afișat arborele de mesaje. Așteptați, apoi apăsați din nou „Export”.

O conversație sau tot contul. Butonul portocaliu exportă conversația deschisă. Pentru multe fișiere, deschideți fereastra extensiei → „View and Download All Conversations” (Vizualizați și descărcați toate conversațiile) și porniți „Export All”. Settings → Privacy → Export data de la Anthropic (etichetele pot apărea traduse dacă claude.ai este setat în limba română) este o arhivă ZIP JSON a contului, livrată cu întârziere, nu acest flux din Chrome.

Ce păstrează fișierul la exportul conversației Claude?

Exportul unei conversații Claude cu Download Claude conversations păstrează arborele de mesaje deja afișat pe claude.ai: expeditori, blocuri de cod, tabele, gândirea (opțional), metadate și aranjarea artefactelor. Nu este o captură de ecran a barei laterale. PNG este varianta imagine; PDF este varianta paginată, generată în browser în versiunea 1.16.2.

Copierea din claude.ai pierde indentarea și strică tabelele. Tipărirea (Ctrl/Cmd+P) păstrează interfața claude.ai și adesea rupe un bloc lung de cod pe mai multe pagini. Download Claude conversations păstrează eticheta de limbaj a blocurilor de cod și lasă tabelele ca tabele în Markdown, JSON și XML. PNG este o imagine a conversației, nu un PDF paginat.

În versiunea 1.16.2, gândirea extinsă este o casetă de bifat în panoul de export, iar sursele căutării web și pașii de instrumente / MCP se activează opțional din Settings (Setări). Metadatele pot include titlul, marcajele de timp și modelul. Filtrul „Messages” limitează fișierul exportat la toate mesajele, doar cele umane sau doar cele ale asistentului, iar „Select” bifează mesaje individuale. Aranjarea artefactelor („Original”, „Inline”, „Nested”, „Flat” — original, în text, imbricat, plat) se setează în Dashboard pentru „Export All”.
