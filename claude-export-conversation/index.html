How does Claude export conversation work in Chrome?

Open a conversation URL on claude.ai in Chrome, click the orange button right of the message box, pick PDF, Markdown, JSON, text, XML, CSV, or PNG, then Export. Download Claude conversations writes the Claude export conversation file locally. Reload claude.ai after install. claude.ai has no per-thread export control.

  1. Install Download Claude conversations from the Chrome Web Store (version 1.16.2).
  2. Reload the claude.ai tab so the content script can inject on a conversation URL.
  3. Open a real conversation, not the empty home composer on claude.ai.
  4. Click the round orange download button to the right of the message box.
  5. Set Messages to All, Human, or Assistant, tick Thinking if you want it, choose PDF, Markdown, JSON, plain text, XML, CSV, or PNG, then click Export.

No account is needed for a Claude export conversation in Markdown, text, JSON, XML, CSV, or PNG. Those single-conversation exports are unlimited and send nothing to our servers. Google sign-in is asked only for PDF and bulk Export All, which share 3 a day on the free plan. Conversation text is never part of that Google sign-in. Mechanics: how it works.

If the orange button is missing, the tab is not on a claude.ai conversation URL, the page still needs a reload after install, or Download Claude conversations is hidden in the Chrome puzzle menu. Pin the extension, then refresh. The orange button never appears on other websites.

The format picker remembers the last choice in Download Claude conversations. Select ticks individual messages, and Copy puts Markdown, text, JSON, XML, or CSV on the clipboard instead of a file. Incomplete files usually mean the long claude.ai thread had not finished rendering the message tree yet. Wait, then click Export again.

One conversation vs the whole account. The orange button runs Claude export conversation for the open thread. For many files, open the extension popup → View and Download All Conversations and run Export All. Anthropic Settings → Privacy → Export data is a delayed account JSON ZIP, not this Chrome flow.

What does Claude export conversation keep in the file?

A Claude export conversation from Download Claude conversations keeps the message tree already rendered on claude.ai: senders, code fences, tables, optional thinking, metadata, and artifact layout. It is not a screenshot of the sidebar. PNG is the image option; PDF is the paginated one, built in the browser in version 1.16.2.

Copy-paste from claude.ai drops indentation and collapses tables. Print (Ctrl/Cmd+P) keeps the claude.ai chrome and often splits a long code fence across pages. Download Claude conversations keeps language tags on fences and leaves tables as tables in Markdown, JSON, and XML. PNG is a picture of the thread, not a paginated PDF.

In version 1.16.2, extended thinking is a checkbox in the export panel, and web search sources and tool / MCP steps are opt-in in Settings. Metadata can include title, timestamps, and model. The Messages filter limits the Claude export conversation file to all messages, human only, or assistant only, and Select ticks individual messages. Artifact layout (Original, Inline, Nested, Flat) is set on the Dashboard for Export All.

We built Claude export conversation around the orange button on claude.ai: it writes PDF, Markdown, JSON, text, XML, CSV, or PNG from the conversation already on screen, without uploading the thread. Version 1.16.2 builds the PDF in the browser too.

Can I export Claude conversations with Export All?

Yes. Open the extension popup → View and Download All Conversations, filter, then click Export All to export Claude conversations as a ZIP of per-thread files. Bulk asks for Google sign-in. On the free plan each conversation in the ZIP uses one of 3 a day, shared with PDF. Pro at $3.99 a month or $26.99 a year removes the bulk cap.

The Dashboard lists claude.ai history with search by name, filters (All conversations, New, Updated, Previously exported), Chat and Cowork tabs, and project search. New means not yet saved with Download Claude conversations. Previously exported tracks conversations you already wrote to disk so a second Export All can skip them. Project search matches how you group threads on claude.ai.

Bulk has a Chat format picker with all seven formats, PDF included, checkboxes for Chats, Thinking, Metadata, Tools, and Sources, and artifact layout (Original, Inline, Nested, Flat). Export All is not a stripped ZIP of the whole account. It is one ZIP with one file per conversation in the chosen format. Anthropic Export data remains the delayed account JSON ZIP.

Bulk counts per conversation. On the free plan, Export All and PDF share 3 a day, and every conversation in the ZIP uses one. Select 40 conversations with 3 left and the whole batch is blocked, not cut short. Pick fewer, wait for the midnight UTC reset, or use Pro at $3.99 a month or $26.99 a year. Does export Claude session work on Desktop or Code?

Not in the Desktop app or the Claude Code terminal. On claude.ai, a session is the open conversation URL, and export Claude session there means the orange button in Chrome. Cowork sessions and Claude Code on the web (claude.ai/code) open on claude.ai too, so they export the same way. Claude Desktop never shows the orange button. Claude Code in the terminal uses /export or JSONL in ~/.claude/projects.

If the thread also exists on your claude.ai account, open that conversation in Chrome and run Claude export conversation with Download Claude conversations. If the chat lives only in Claude Desktop, copy-paste from the app or request Settings → Privacy → Export data on the web. Contrast: export Claude Desktop chat.

Claude Code in the terminal is a different product path. Run /export there, or copy JSONL transcripts from ~/.claude/projects. Download Claude conversations does not read those files and does not inject into the CLI. Searching export Claude session for a terminal agent is that disk path — guide: Claude Code export.

Mobile claude.ai in a phone browser is also out of scope. Download Claude conversations needs desktop Chrome (or another Chromium browser that can load the Chrome Web Store listing). There is no iOS or Android app from this team in 2026. Open the conversation on a computer, then use the orange button or Export All.

Team and Enterprise claude.ai workspaces still use conversation URLs in Chrome. If a workspace admin blocks extensions, Download Claude conversations will not inject — that is a browser policy, not a missing format. The orange button only appears after a reload on a conversation URL you are allowed to open.

FAQ: Claude export conversation

These FAQ items cover Claude export conversation: formats, limits, Claude Desktop, Claude Code, Anthropic’s ZIP, and the orange button on claude.ai. Each answer is a fact from Download Claude conversations 1.16.2. The FAQPage JSON-LD in the page head matches this list.

What does Claude export conversation mean on this site?

Saving a claude.ai conversation as a file with Download Claude conversations: orange button, format picker, Export. Same job as “export Claude conversation.” Not Anthropic’s emailed ZIP and not Claude Code /export.

Is Claude export conversation the same as Export data?

No. Settings → Privacy → Export data is a full-account JSON ZIP by email. Claude export conversation with this extension writes the open thread as PDF, Markdown, JSON, text, XML, CSV, or PNG, or an Export All selection as a ZIP, immediately in Chrome.

Can Claude export conversation write a PDF?

Yes. Pick PDF in the format list and click Export. Download Claude conversations builds the PDF in the browser, with no print dialog. PDF asks for Google sign-in and is free up to 3 a day; Pro makes it unlimited. Guide: download Claude chat as PDF.

Do I need Pro to export Claude conversation once?

No. Markdown, text, JSON, XML, CSV, and PNG exports are free and unlimited, with no account. PDF and bulk Export All are free up to 3 a day with Google sign-in. Pro at $3.99 a month or $26.99 a year removes that cap.

Does export Claude conversation work on any claude.ai plan?

Yes. Free, Pro, Team, or Enterprise claude.ai plans work if you can open the conversation in Chrome. Download Claude conversations does not require Anthropic’s paid plan.

Is Claude export conversation for Claude Code?

Only for Claude Code on the web. Sessions at claude.ai/code open on claude.ai and export like any conversation. Claude Code in the terminal uses /export or JSONL in ~/.claude/projects, and this extension does not read those local sessions.

Can I export Claude session from Claude Desktop?

Not with this Chrome extension. Open the same conversation on claude.ai if it syncs, or copy-paste / use official Export data. Claude Desktop never shows the orange button.

How many free Claude export conversation files do I get?

Unlimited in Markdown, text, JSON, XML, CSV, and PNG, with no account. PDF and bulk Export All share 3 a day on the free plan, with Google sign-in; each conversation in a bulk ZIP counts as one. The count resets at midnight UTC. Pro removes the cap and restores via Google sign-in.

Where is the orange button for Claude export conversation?

To the right of the message box on a claude.ai conversation URL after you install Download Claude conversations and reload. It does not appear on the empty home composer or in Claude Desktop.

Does Claude export conversation upload my chats?

No. Every format, PDF included, is built in the browser and handed to Chrome’s download API. Markdown, text, JSON, XML, CSV, and PNG exports send nothing to us. After you sign in for PDF, bulk, or Pro, our worker sees quota or subscription status and your Google email, never conversation bodies.

What formats can Claude export conversation write?

Seven: PDF, Markdown, plain text, JSON, XML, CSV, and PNG — the same seven for one conversation and for Export All. No Word, Notion, or Google Docs export in version 1.16.2.
