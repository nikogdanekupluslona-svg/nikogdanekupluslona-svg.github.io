How does Claude export conversation work in Chrome?

Open a conversation URL on claude.ai in Chrome, click the orange button right of the message box, pick Markdown, JSON, text, XML, or PNG, then Export. Download Claude conversations writes the Claude export conversation file locally. Reload claude.ai after install. claude.ai has no per-thread export control.

  1. Install Download Claude conversations from the Chrome Web Store (listing rated 5.0, version 1.13.0).
  2. Reload the claude.ai tab so the content script can inject on a conversation URL.
  3. Open a real conversation, not the empty home composer on claude.ai.
  4. Click the orange download button to the right of the message box.
  5. Choose Markdown, JSON, plain text, XML, or PNG, then click Export.

Google sign-in is required before the first Claude export conversation click. Download Claude conversations stores the verified email so the 3 free exports and Pro can restore after a reinstall. Conversation text is not part of that Google sign-in. Mechanics: how it works.

If the orange button is missing, the tab is not on a claude.ai conversation URL, the page still needs a reload after install, or Download Claude conversations is hidden in the Chrome puzzle menu. Pin the extension, then refresh. The orange button never appears on other websites.

The format picker remembers the last choice in Download Claude conversations. Markdown, JSON, plain text, XML, and PNG each count as one export when Chrome finishes the download. Incomplete files usually mean the long claude.ai thread had not finished rendering the message tree yet. Wait, then click Export again.

One conversation vs the whole account. The orange button runs Claude export conversation for the open thread. For many files, open View and Download All Conversations and run Export All. Anthropic Settings → Privacy → Export data is a delayed account JSON ZIP, not this Chrome flow.

What does Claude export conversation keep in the file?

A Claude export conversation from Download Claude conversations keeps the message tree already rendered on claude.ai: senders, code fences, tables, optional thinking, metadata, and artifact layout. It is not a screenshot of the sidebar. PNG is the image option. Version 1.13.0 still does not emit PDF.

Copy-paste from claude.ai drops indentation and collapses tables. Print (Ctrl/Cmd+P) keeps the claude.ai chrome and often splits a long code fence across pages. Download Claude conversations keeps language tags on fences and leaves tables as tables in Markdown, JSON, and XML. PNG is a picture of the thread, not a paginated PDF.

Thinking blocks are a toggle in version 1.13.0. Metadata can include title, timestamps, and model. Sender filter can limit the Claude export conversation file to all messages, human only, or assistant only. Artifact layout is Original, Inline, Nested, or Flat. Those toggles apply to the open thread and to Export All.

We built Claude export conversation around the orange button on claude.ai: it writes Markdown, JSON, text, XML, or PNG from the conversation already on screen, without uploading the thread. Version 1.13.0 still does not emit PDF.

Can I export Claude conversations with Export All?

Yes. Open View and Download All Conversations, filter, then click Export All to export Claude conversations as per-thread files. Each completed file uses the same 3 free exports as the orange button. Pro at $3.99/mo or $26.99/yr removes the bulk cap the same as one thread.

The browse table lists claude.ai history with search by name and filters All, New, Exported, and Project. New means not yet saved with Download Claude conversations. Exported tracks conversations you already wrote to disk so a second Export All can skip them. Project matches how you group threads on claude.ai.

Bulk uses the same toggles as one Claude export conversation: Chats, Thinking, Metadata, artifact layout (Original, Inline, Nested, Flat), and the same five formats. Export All is not a stripped ZIP of the whole account. It is many per-conversation files. Anthropic Export data remains the delayed account JSON ZIP.

Quota is account-wide. Three free exports total — not three per bulk run. Selecting 40 conversations on the browse page will consume 40 exports if every file completes. Plan the selection before you click Export All, or use Pro at $3.99/mo or $26.99/yr. Shared quota details: bulk Export All.

Export All and the orange button share one Google-signed quota. You cannot get three free Claude export conversation files from the orange button and another three from Export All. Reinstalling Download Claude conversations does not reset the count. Pro restores on a new computer from the same Google account via Paddle.

Does export Claude session work on Desktop or Code?

On claude.ai, a session is the open conversation URL. Export Claude session there means the orange button in Chrome, not a Desktop or terminal hook. Download Claude conversations runs only on claude.ai. Claude Desktop never shows the orange button. Claude Code uses /export or JSONL in ~/.claude/projects.

If the thread also exists on your claude.ai account, open that conversation in Chrome and run Claude export conversation with Download Claude conversations. If the chat lives only in Claude Desktop, copy-paste from the app or request Settings → Privacy → Export data on the web. Contrast: export Claude Desktop chat.

Claude Code is a different product path. Run /export in the terminal, or copy JSONL transcripts from ~/.claude/projects. Download Claude conversations does not read those files and does not inject into the CLI. Searching export Claude session for a terminal agent is that disk path — guide: Claude Code export.

Mobile claude.ai in a phone browser is also out of scope. Download Claude conversations needs desktop Chrome (or another Chromium browser that can load the Chrome Web Store listing). There is no iOS or Android app from this team in 2026. Open the conversation on a computer, then use the orange button or Export All.

Team and Enterprise claude.ai workspaces still use conversation URLs in Chrome. If a workspace admin blocks extensions, Download Claude conversations will not inject — that is a browser policy, not a missing format. The orange button only appears after a reload on a conversation URL you are allowed to open.

FAQ: Claude export conversation

These FAQ items cover Claude export conversation: formats, quota, Claude Desktop, Claude Code, Anthropic’s ZIP, and the orange button on claude.ai. Each answer is a fact from Download Claude conversations 1.13.0. The FAQPage JSON-LD in the page head matches this list.

What does Claude export conversation mean on this site?

Saving a claude.ai conversation as a file with Download Claude conversations: orange button, format picker, Export. Same job as “export Claude conversation.” Not Anthropic’s emailed ZIP and not Claude Code /export.

Is Claude export conversation the same as Export data?

No. Settings → Privacy → Export data is a full-account JSON ZIP by email. Claude export conversation with this extension writes the open thread or an Export All selection as Markdown, JSON, text, XML, or PNG immediately in Chrome.

Can Claude export conversation write a PDF?

Not with Download Claude conversations. Formats are Markdown, JSON, plain text, XML, and PNG. For a PDF-like snapshot, print the claude.ai page in Chrome. PNG is an image, not a PDF.

Do I need Pro to export Claude conversation once?

No. The first 3 exports on any Google-signed account are free, any format. Pro at $3.99/mo or $26.99/yr removes the limit for more single or bulk files.

Does export Claude conversation work on any claude.ai plan?

Yes. Free, Pro, Team, or Enterprise claude.ai plans work if you can open the conversation in Chrome. Download Claude conversations does not require Anthropic’s paid plan.

Is Claude export conversation for Claude Code?

No. Download Claude conversations runs on claude.ai in Chrome. Claude Code uses /export or JSONL in ~/.claude/projects. This extension does not read Claude Code sessions.

Can I export Claude session from Claude Desktop?

Not with this Chrome extension. Open the same conversation on claude.ai if it syncs, or copy-paste / use official Export data. Claude Desktop never shows the orange button.

How many free Claude export conversation files do I get?

Three per Google-signed account, shared by the orange button and Export All. Reinstalling does not reset the count. Pro restores via Google sign-in.

Where is the orange button for Claude export conversation?

To the right of the message box on a claude.ai conversation URL after you install Download Claude conversations and reload. It does not appear on the empty home composer or in Claude Desktop.

Does Claude export conversation upload my chats?

No. Files are built in the browser and handed to Chrome’s download API. Our worker sees subscription status and a Google-verified email, not conversation bodies.

What formats can Claude export conversation write?

Markdown, JSON, plain text, XML, and PNG — the same five for one conversation and for Export All. No PDF, Word, Notion, or Google Docs export in version 1.13.0.
