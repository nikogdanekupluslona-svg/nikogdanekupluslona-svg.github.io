How to export a Claude Code conversation

Claude Code export and a claude.ai chat download are different products. Claude Code is the terminal / CLI coding agent. This site’s Chrome extension — also called Claude Chat Downloader or Claude Conversation Downloader — only saves chats you open in the browser on claude.ai. If you searched “how to download claude code conversation,” use the terminal steps below, not the orange button.

How to export the current Claude Code session

Inside an active Claude Code session, type:

/export

Claude Code offers to copy the transcript or save it to a file. To skip the prompt and write a named file:

/export my-session.md

That file is a readable transcript of the current conversation. It is not the same as this extension’s Markdown/JSON/PNG export from claude.ai. Official session details live in Anthropic’s Claude Code docs (session storage and /export change between versions).

Where Claude Code stores history on disk

Every session is also written as JSONL (one JSON object per line) under your config directory. On macOS and Linux the usual path is:

~/.claude/projects/<encoded-working-directory>/

On Windows:

%USERPROFILE%\.claude\projects\

The project folder name is derived from the working directory you launched Claude Code in (slashes typically become hyphens). Filenames are session ids. Treat JSONL as an internal log: the schema can change, so /export is the stable way to get a human-readable Claude Code conversation. Parsing JSONL with jq or a script is fine if you accept that a Claude Code update may break your parser.

How to download a Claude.ai chat instead

FAQ

How do I export a Claude Code conversation?

In the Claude Code terminal, type /export (optionally with a filename like /export notes.md) to save the current session as a transcript, or copy the JSONL file from ~/.claude/projects on macOS/Linux or %USERPROFILE%\.claude\projects on Windows.

Does this Chrome extension download Claude Code chats?

No. Download Claude conversations (the Claude Chat Downloader) only works on claude.ai in Chrome. It cannot read terminal sessions, JSONL transcripts, or the /export command.

Where does Claude Code store conversation history?

Session transcripts are JSONL files under ~/.claude/projects/<encoded-working-directory>/, named by session id. The exact subfolder layout can change between Claude Code versions — use /export when you want a readable file instead of parsing JSONL.

How do I download a Claude.ai conversation instead?

Install the free Chrome extension, open the chat on claude.ai, and use the orange button — or Export All for entire chat history. See how to download a Claude chat.
