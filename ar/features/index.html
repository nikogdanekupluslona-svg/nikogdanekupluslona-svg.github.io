ما ميزات الإضافة التي تصدّر محادثة واحدة؟

الميزة الأساسية لمحادثة واحدة هي الزر البرتقالي الذي تضيفه Download Claude conversations بجوار مربع الرسائل في claude.ai. افتح رابط محادثة، واختر صيغة، ثم انقر «Export» (تصدير) أو «Copy». يُنزَّل الملف فورًا. وحده PDF يطلب تسجيل الدخول؛ أما الصيغ الست الأخرى فلا تحتاج أي حساب.

  1. ثبّت Download Claude conversations من Chrome Web Store.
  2. أعد تحميل claude.ai وافتح رابط محادثة حقيقية — محادثة عادية، أو محادثة داخل مشروع (Project)، أو جلسة Cowork، أو Claude Code على الويب.
  3. انقر زر التنزيل البرتقالي على يمين مربع الرسائل.
  4. اختر الرسائل «All» أو «Human» أو «Assistant» (الكل / المستخدم / المساعد)، ثم الصيغة، وخانة الاختيار «Thinking» (التفكير)، أو انقر «Select» لتحديد رسائل بعينها. تتذكر الإضافة آخر صيغة استخدمتها.
  5. انقر «Export» لتنزيل الملف، أو «Copy» لوضعه في الحافظة. يعمل «Copy» مع Markdown والنص العادي وJSON وXML وCSV.

يظهر الزر البرتقالي فقط في محادثة محمّلة؛ فالصفحة الرئيسية الفارغة لمربع الكتابة لا تحتوي شيئًا لتحليله. إذا غاب الزر، فثبّت الإضافة من قائمة الإضافات (أيقونة قطعة الأحجية) في Chrome وحدّث claude.ai. ولا تُحقن هذه الميزات أبدًا في Claude Desktop ولا في Claude Code داخل الطرفية. واختيار PDF يفتح نافذة لضبط اسم الملف وحجم الصفحة والهوامش والوضع الفاتح أو الداكن والخط وحجمه وأرقام الصفحات وجدول المحتويات والطوابع الزمنية وفاصل صفحة قبل كل رسالة ترسلها: محادثة Claude بصيغة PDF.

ملف محلي. تُنشأ ملفات PDF وMarkdown وJSON والنص العادي وXML وCSV وPNG داخل علامة التبويب. تصدير المحادثة الواحدة بالصيغ الأخرى غير PDF لا يرسل شيئًا إلى خوادمنا. أما PDF والتصدير الجماعي فلا يرسلان سوى بريدك في Google لاحتساب العدد اليومي. ونص المحادثة لا يغادر متصفحك أبدًا. الآلية: كيف تعمل الإضافة.

ما ميزات الإضافة التي تغطي Export All؟

ميزات التصدير الجماعي موجودة في لوحة التحكم (Dashboard)، أي صفحة «View and Download All Conversations» (عرض كل المحادثات وتنزيلها): بحث، ومرشّحات «All conversations / New / Updated / Previously exported» (كل المحادثات / الجديدة / المحدَّثة / المصدَّرة سابقًا)، وتبويبا «Chat» و«Cowork»، والبحث في المشاريع، وزر «Export All». يحفظ «Export All» ملف ZIP واحدًا. تغطي الخطة المجانية 3 محادثات يوميًا مع تسجيل الدخول عبر Google، واشتراك Pro بسعر $3.99 شهريًا أو $26.99 سنويًا يلغي هذا الحد.

«New» تعني ما لم يُصدَّر بعد بـDownload Claude conversations. و«Previously exported» تتتبع المحادثات التي حفظتها من قبل كي يتخطاها تشغيل ثانٍ لـ«Export All». ويعرض تبويب «Cowork» جلسات Cowork بجانب المحادثات العادية. والبحث في المشاريع يجد المحادثات داخل مشروع واحد على claude.ai. والبحث يتم باسم المحادثة. المسار الكامل: التصدير الجماعي Export All.

الحد اليومي لكل حساب. ثلاث محادثات يوميًا في الخطة المجانية، مشتركة مع PDF — لا ثلاث لكل تشغيل جماعي. إذا حددت 40 محادثة ولم يتبقَّ لك سوى 3، فستُحظر الدفعة كلها، ولن تُصدَّر جزئيًا. خطّط لما تحدده قبل النقر على «Export All»، أو استخدم Pro.

يستخدم «Export All» منتقي «Chat format» (صيغة المحادثة) في لوحة التحكم (الصيغ السبع كلها، بما فيها PDF)، وخانات الاختيار «Chats» و«Thinking» و«Metadata» و«Tools» و«Sources» (المحادثات والتفكير والبيانات الوصفية والأدوات والمصادر)، وصيغة المخرجات. والنتيجة ملف ZIP واحد فيه ملف لكل محادثة، لا ملف ZIP الخاص بحساب Anthropic الذي يصل بعد تأخير. تختار صيغة واحدة لكل تشغيل، ولا تخلط الإضافة بين Markdown وJSON في نقرة واحدة. وفي لوحة التحكم أيضًا نسخ احتياطي واستعادة.

ما الصيغ التي تكتبها الإضافة؟

تكتب الإضافة سبع صيغ: PDF وMarkdown والنص العادي وJSON وXML وCSV وPNG. صيغ Markdown والنص العادي وJSON وXML وCSV وPNG غير محدودة ولا تحتاج حسابًا. أما PDF فيُنشأ داخل المتصفح، ويتطلب تسجيل الدخول عبر Google، ويُحتسب ضمن 3 مرات يوميًا في الخطة المجانية. القائمة نفسها في الزر البرتقالي وفي منتقي «Chat format» في لوحة التحكم. صفحات الصيغ: صيغ تصدير محادثات Claude.

هل تحتفظ الإضافة بالمخرجات؟

نعم. تشمل ميزات الإضافة تخطيط المخرجات (artifacts): «Original» (الأصلي) أو «Inline» (مضمّن) أو «Nested» (متداخل) أو «Flat» (مسطّح). وكتل التفكير وخطوات الأدوات / MCP ومصادر البحث على الويب كلها اختيارية: «Thinking» خانة اختيار في لوحة التصدير، والأدوات والمصادر تُفعَّل من الإعدادات، وفي لوحة التحكم خانات اختيار للثلاثة. والبيانات الوصفية قد تضيف العنوان والطوابع الزمنية والنموذج. ومرشّح المرسل يقصر الملف على «All / Human / Assistant» (الكل / المستخدم فقط / المساعد فقط)، و«Select» يحدد رسائل بعينها.

المخرجات جزء من محادثة claude.ai. ويحدد التخطيط ما إذا كانت ستبقى داخل ملف Markdown أو JSON أو XML أو النص العادي، أو ستذهب إلى مجلد خاص بها داخل ملف ZIP. ملفات ZIP للمخرجات غير محدودة ومجانية، وكذلك ملف ZIP لملفات المشروع: في صفحة المشروع، انقر «Project files» → «Download ZIP» (ملفات المشروع، ثم تنزيل ZIP). أما في PNG فتُرسم المخرجات ولا تُحفظ كترميز. وإذا كان التفكير معطّلًا، فالتصدير يُسقط التفكير الموسّع حتى لو عرضه claude.ai على الشاشة.

إذا كانت المحادثة طويلة، فمرّر حتى يحمّل claude.ai الرسائل الأقدم. لا تستطيع الإضافة تصدير إلا ما عرضته الصفحة. والصفحة المحمّلة جزئيًا تنتج ملفًا مبتورًا يبدو كخطأ في المخرجات المفقودة، وهو في الغالب محادثة لم تُمرَّر.

كيف تتعامل الإضافة مع تسجيل الدخول؟

معظم ميزات إضافة Chrome لا تحتاج تسجيل الدخول. تصدير المحادثة الواحدة بصيغ Markdown والنص العادي وJSON وXML وCSV وPNG غير محدود ومن دون هوية، وكذلك «Copy» و«Select» وملفات ZIP للمخرجات وملف ZIP لملفات المشروع. لا يُطلب تسجيل الدخول عبر Google إلا لـPDF والتصدير الجماعي «Export All» واشتراك Pro. ولا يدخل محتوى المحادثات في هذه العملية أبدًا.

يتشارك PDF والتصدير الجماعي بملف ZIP حد 3 مرات يوميًا في الخطة المجانية، ويُحتسب هذا العدد على خادمنا مقابل بريدك في Google. يبدأ اليوم الجديد عند منتصف الليل بتوقيت UTC، ولا تعيد إعادة التثبيت ضبط العدد. يكلف Pro ‏$3.99 شهريًا أو $26.99 سنويًا عبر Paddle. وPaddle هي البائع الرسمي؛ فريقنا لا يرى أرقام البطاقات أبدًا. ويُستعاد Pro على كمبيوتر جديد عند تسجيل الدخول بحساب Google نفسه.

لا تحتاج خطة claude.ai مدفوعة من Anthropic. خطط claude.ai كلها — Free وPro وTeam وEnterprise — تعمل إذا استطاع Chrome فتح المحادثة. وإذا حظر مسؤول مساحة العمل الإضافات، فلن تُحقن Download Claude conversations — وهذه سياسة المتصفح، لا ميزة ناقصة في هذه الصفحة.

Claude Desktop تطبيق لـMac وWindows. وClaude Code في الطرفية وكيل محلي. ولا يحصل أي منهما على الزر البرتقالي. أما Claude Code على الويب (claude.ai/code) وجلسات Cowork فتُفتح على claude.ai، لذا تُصدَّر مثل أي محادثة. وإذا كانت محادثة من Desktop موجودة أيضًا على claude.ai، فافتحها في Chrome واستخدم ميزات الإضافة هناك. المقارنة مع Desktop: تصدير محادثة Claude Desktop. والمقارنة مع Code: تصدير Claude Code.
