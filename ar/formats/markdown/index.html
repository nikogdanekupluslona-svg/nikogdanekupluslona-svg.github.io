كيف أصدّر محادثة Claude إلى Markdown؟

افتح المحادثة على claude.ai في Chrome، وانقر الزر البرتقالي بجوار مربع الرسائل، واختر Markdown، ثم انقر «Export». تكتب Download Claude conversations ملف .md محليًا. هكذا تصدّر محادثة Claude إلى Markdown في الإصدار 1.13.0.

  1. ثبّت Download Claude conversations من Chrome Web Store (تقييم الإضافة 5.0).
  2. أعد تحميل claude.ai وافتح رابط محادثة حقيقية، لا الصفحة الرئيسية الفارغة لمربع الكتابة.
  3. انقر زر التنزيل البرتقالي على يمين مربع الرسائل.
  4. اختر Markdown. تتذكر الإضافة آخر صيغة استخدمتها.
  5. انقر «Export». ينزّل Chrome ملف .md عبر واجهة التنزيل في المتصفح.

تسجيل الدخول بحساب Google مطلوب قبل أول تصدير إلى Markdown. تحفظ Download Claude conversations البريد الإلكتروني الموثّق لاحتساب عمليات التصدير المجانية الثلاث ولاستعادة Pro بعد إعادة التثبيت. ولا يُرفع نص المحادثة من أجل تسجيل الدخول. الآلية: كيف تعمل الإضافة.

إذا غاب الزر البرتقالي، فأنت لست في رابط محادثة، أو تحتاج علامة التبويب إلى إعادة تحميل بعد التثبيت، أو أن الإضافة ما زالت مخفية في قائمة الإضافات (أيقونة قطعة الأحجية) في Chrome. ثبّت Download Claude conversations في الشريط، ثم حدّث claude.ai. ولا يُحقن سكربت المحتوى أبدًا في Claude Desktop أو Claude Code.

محادثة واحدة أم محادثات كثيرة؟ يصدّر الزر البرتقالي المحادثة المفتوحة بصيغة Markdown. ولملفات .md كثيرة، افتح «View and Download All Conversations» (عرض كل المحادثات وتنزيلها) وشغّل «Export All» (تصدير الكل) مع اختيار Markdown — راجع التصدير الجماعي Export All.

لماذا أصدّر محادثة Claude إلى Markdown للملاحظات؟

صدّر محادثة Claude إلى Markdown عندما ستقرأ الملف في Obsidian أو في ويكي على GitHub أو في أي محرر يعرض العناوين وكتل الشيفرة. يبقى ملف .md نصًا عاديًا يمكنك البحث فيه ومقارنة نسخه. ‏JSON أفضل لأدوات التحليل، وPNG صورة لا يمكنك البحث فيها.

النسخ واللصق من claude.ai يُسقط المسافات البادئة عادةً ويسطّح الجداول. والطباعة (Ctrl/Cmd+P) تُبقي الشريط الجانبي وكثيرًا ما تقسم كتلة شيفرة طويلة بين الصفحات. أما عند التصدير إلى Markdown فتبقى وسوم اللغة على كتل الشيفرة وتبقى الجداول جداول. لهذا يختار الكتّاب هذه الصيغة أولًا.

نعامل Markdown بوصفه الملف الافتراضي المقروء للبشر: عناوين، وكتل شيفرة مع وسوم اللغة، وجداول من محادثة claude.ai. وما زلنا لا نخترع صيغة PDF — إذا احتجت صفحة قابلة للطباعة، فاستخدم مربع حوار الطباعة في Chrome بعد تصدير المحادثة إلى Markdown أو بدلًا منه.

ماذا يحفظ التصدير إلى Markdown؟

عند تصدير محادثة Claude إلى Markdown، تحتفظ Download Claude conversations بالعناوين، وكتل الشيفرة مع وسوم اللغة والمسافات البادئة، والجداول، والروابط. كتل التفكير اختيارية. ويمكن إضافة البيانات الوصفية (العنوان والطوابع الزمنية والنموذج). ومرشّح المرسل يقصر ملف .md على «all / human only / assistant only» (الكل / المستخدم فقط / المساعد فقط).

تخطيط المخرجات (artifacts) خيار فعلي في الإصدار 1.13.0: «Original» (الأصلي) أو «Inline» (مضمّن) أو «Nested» (متداخل) أو «Flat» (مسطّح). يمكن لتصدير Markdown أن يعكس بنية المخرجات كما تظهر على الشاشة، أو أن يسطّحها في مستند خطي واحد. القائمة الكاملة للخيارات: ميزات إضافة Chrome. لا يحتفظ Markdown بألوان فقاعات الرسائل؛ استخدم PNG إذا احتجت لقطة مرئية.

هل يمكنني التصدير إلى Markdown دفعة واحدة؟

نعم. افتح «View and Download All Conversations»، واضبط الصيغة على Markdown، وصفِّ الجدول، ثم انقر «Export All». كل ملف .md مكتمل يُحتسب عملية تصدير واحدة من عمليات التصدير المجانية الثلاث نفسها التي يستهلكها الزر البرتقالي. واشتراك Pro بسعر $3.99 شهريًا أو $26.99 سنويًا يلغي هذا الحد للتصدير الجماعي إلى Markdown.

يعرض جدول التصفح سجل claude.ai مع البحث بالاسم والمرشّحات «All» و«New» و«Exported» و«Project» (الكل / الجديدة / المصدّرة / المشروع). «New» تعني ما لم يُصدَّر بعد بـDownload Claude conversations. و«Exported» تتتبع المحادثات التي حفظتها من قبل كي يتخطاها تشغيل ثانٍ لـ«Export All». و«Project» تطابق طريقة تجميعك للمحادثات على claude.ai.

الحصة على مستوى الحساب. ثلاث عمليات تصدير مجانية إجمالًا — لا ثلاثة ملفات Markdown يوميًا. تحديد 40 محادثة يستهلك 40 عملية تصدير إذا اكتمل كل ملف .md. خطّط لما تحدده قبل النقر على «Export All».

يستخدم التصدير الجماعي إلى Markdown خيارات التفكير والبيانات الوصفية والمرسل والمخرجات نفسها التي تستخدمها المحادثة الواحدة. و«Export All» ليس ملف ZIP من Anthropic يصل بعد تأخير، بل ملفات .md كثيرة لكل محادثة. إذا أردت أرشيفًا واحدًا للحساب كله، فذلك هو Settings → Privacy → Export data (قد تظهر التسميات مترجمة إذا كانت لغة claude.ai مضبوطة على العربية)، وهو بصيغة JSON لا Markdown.

Markdown أم JSON عند تصدير محادثة Claude؟

صدّر محادثة Claude إلى Markdown عندما سيقرأ الملف إنسان، وبصيغة JSON عندما سيحلل سكربت شجرة الرسائل. توفر Download Claude conversations الصيغتين في قائمة منسدلة واحدة، إلى جانب النص العادي وXML وPNG. ولا يوجد PDF حتى الآن. الصفحة الرئيسية للصيغ: صيغ تصدير محادثات Claude.

‏Export data من Anthropic بصيغة JSON أيضًا، لكنه ملف ZIP للحساب يصل بالبريد، لا ملف .md لكل محادثة، ولا يمكنك اختيار Markdown داخل ذلك الطلب. والطباعة ← Save as PDF لقطة لصفحة الويب. ولا يغني أي منهما عن تصدير المحادثة إلى Markdown من الزر البرتقالي.

تعمل الإضافة فقط على claude.ai في Chrome. لا يحصل Claude Desktop ولا Claude Code على زر Markdown. إذا كانت المحادثة موجودة أيضًا على claude.ai، فافتحها هناك وصدّرها إلى Markdown. أما /export في Claude Code فمسار منتج مختلف.

هل يكلف التصدير إلى Markdown أكثر؟

لا. ‏Markdown مشمول في عمليات التصدير المجانية الثلاث التي يحصل عليها كل حساب مسجّل بـGoogle، مثل JSON والنص العادي وXML وPNG. بعد هذه الملفات الثلاثة يكلف Pro ‏$3.99 شهريًا أو $26.99 سنويًا عبر Paddle. ولا تفرض Download Claude conversations رسومًا إضافية على Markdown.

لا تُعاد عمليات التصدير المجانية الثلاث عند إعادة تثبيت الإضافة، ولهذا يُطلب تسجيل الدخول بحساب Google عند أول تصدير إلى Markdown. ويُستعاد Pro على كمبيوتر جديد من حساب Google نفسه. وPaddle هي البائع الرسمي؛ فريقنا لا يرى أرقام البطاقات أبدًا.

لا تحتاج خطة claude.ai مدفوعة من Anthropic، بل حسابًا يستطيع تحميل المحادثة في Chrome. وتعمل خطط Team وEnterprise مع الزر البرتقالي كما تعمل الخطة المجانية. والإصدار 1.13.0 (سبتمبر 2026) ما زال لا يكتب Word ولا Notion ولا PDF.

الأسئلة الشائعة: تصدير محادثة Claude إلى Markdown

تغطي هذه الأسئلة تصدير محادثة Claude إلى Markdown في Download Claude conversations 1.13.0: كتل الشيفرة، والتصدير الجماعي «Export All»، وملف ZIP من Anthropic، والحصة، وDesktop. كل إجابة حقيقة عن المنتج، وبيانات FAQPage بصيغة JSON-LD في رأس الصفحة تطابق هذه القائمة.

هل يُفقد تصدير محادثة Claude إلى Markdown الشيفرة؟

لا. تحتفظ كتل الشيفرة بوسم اللغة والمسافات البادئة، على عكس النسخ واللصق العادي من claude.ai. وتبقى الجداول جداول Markdown. هذا هو السبب الرئيسي لتصدير محادثة Claude إلى Markdown بدل تحديد النص يدويًا.

هل يمكنني تصدير محادثات Claude إلى Markdown دفعة واحدة؟

نعم. يدعم «Export All» في صفحة التصفح صيغة Markdown تمامًا كتصدير المحادثة الواحدة. وكل ملف .md مكتمل يُحتسب واحدة من عمليات التصدير المجانية الثلاث ما لم تكن مشتركًا في Pro.

هل Markdown هو نفسه Export data من Anthropic؟

لا. التصدير الرسمي من Anthropic ملف ZIP بصيغة JSON لحسابك كله يصل بالبريد بعد انتظار. أما تصدير محادثة Claude إلى Markdown فملف .md لكل محادثة (أو لكل تحديد) من Download Claude conversations.

هل يكلف Markdown أكثر من الصيغ الأخرى؟

لا. ‏Markdown مشمول في عمليات التصدير المجانية الثلاث على أي حساب مسجّل بـGoogle، مثل JSON والنص العادي وXML وPNG. بعدها يكلف Pro ‏$3.99 شهريًا أو $26.99 سنويًا لملفات غير محدودة.

هل يمكنني تصدير محادثة Claude إلى Markdown في Desktop؟

لا. تُحقن Download Claude conversations فقط في claude.ai داخل Chrome. لا يعرض Claude Desktop قائمة Markdown أبدًا. افتح المحادثة نفسها على claude.ai إذا كانت موجودة هناك.

هل ينتج تصدير محادثة Claude إلى Markdown ملف PDF؟

لا. ‏Markdown ملف نصي .md. والمنتج لا يوفر PDF. للحصول على صفحة قابلة للطباعة استخدم مربع حوار الطباعة في Chrome. و‏PNG صورة، وليست PDF أيضًا.

هل أحتاج Pro لتصدير محادثة Claude إلى Markdown مرة واحدة؟

لا. أول 3 عمليات تصدير مجانية، بأي صيغة بما فيها Markdown. واشتراك Pro بسعر $3.99 شهريًا أو $26.99 سنويًا يلغي الحد لمزيد من ملفات .md الفردية أو الجماعية.
