كيف أصدّر محادثة Claude إلى Markdown؟

افتح المحادثة على claude.ai في Chrome، وانقر الزر البرتقالي بجوار مربع الرسائل، واختر Markdown، ثم انقر «Export». تكتب Download Claude conversations ملف .md محليًا. هكذا تصدّر محادثة Claude إلى Markdown في الإصدار 1.16.2.

  1. ثبّت Download Claude conversations من Chrome Web Store.
  2. أعد تحميل claude.ai وافتح رابط محادثة حقيقية، لا الصفحة الرئيسية الفارغة لمربع الكتابة.
  3. انقر زر التنزيل البرتقالي على يمين مربع الرسائل.
  4. اختر Markdown. تتذكر الإضافة آخر صيغة استخدمتها. واستخدم «Select» (تحديد) لتحديد الرسائل التي تريدها فقط.
  5. انقر «Export». ينزّل Chrome ملف .md عبر واجهة التنزيل في المتصفح. أو انقر «Copy» (نسخ) لوضع محتوى Markdown في الحافظة.

لا حاجة إلى تسجيل الدخول لتصدير محادثة Claude إلى Markdown. التصدير الفردي إلى Markdown غير محدود ومن دون هوية، ولا يرسل شيئًا إلى خوادمنا. ولا يُطلب تسجيل الدخول عبر Google إلا لـPDF والتصدير الجماعي «Export All». الآلية: كيف تعمل الإضافة.

إذا غاب الزر البرتقالي، فأنت لست في رابط محادثة، أو تحتاج علامة التبويب إلى إعادة تحميل بعد التثبيت، أو أن الإضافة ما زالت مخفية في قائمة الإضافات (أيقونة قطعة الأحجية) في Chrome. ثبّت Download Claude conversations في الشريط، ثم حدّث claude.ai. ولا يُحقن سكربت المحتوى أبدًا في Claude Desktop أو في Claude Code داخل الطرفية.

محادثة واحدة أم محادثات كثيرة؟ يصدّر الزر البرتقالي المحادثة المفتوحة بصيغة Markdown. ولملفات .md كثيرة، افتح «View and Download All Conversations» (عرض كل المحادثات وتنزيلها) وشغّل «Export All» (تصدير الكل) مع اختيار Markdown: ملف ZIP واحد، و3 محادثات يوميًا في الخطة المجانية — راجع التصدير الجماعي Export All.

لماذا أصدّر محادثة Claude إلى Markdown للملاحظات؟

صدّر محادثة Claude إلى Markdown عندما ستقرأ الملف في Obsidian أو في ويكي على GitHub أو في أي محرر يعرض العناوين وكتل الشيفرة. يبقى ملف .md نصًا عاديًا يمكنك البحث فيه ومقارنة نسخه. ‏JSON أفضل لأدوات التحليل، وPNG صورة لا يمكنك البحث فيها.

النسخ واللصق من claude.ai يُسقط المسافات البادئة عادةً ويسطّح الجداول. والطباعة (Ctrl/Cmd+P) تُبقي الشريط الجانبي وكثيرًا ما تقسم كتلة شيفرة طويلة بين الصفحات. أما عند التصدير إلى Markdown فتبقى وسوم اللغة على كتل الشيفرة وتبقى الجداول جداول. لهذا يختار الكتّاب هذه الصيغة أولًا.

نعامل Markdown بوصفه الملف الافتراضي المقروء للبشر: عناوين، وكتل شيفرة مع وسوم اللغة، وجداول من محادثة claude.ai. وعندما تحتاج صفحات بدلًا من ذلك، اختر PDF من اللوحة نفسها؛ فهو يُنسَّق داخل المتصفح، مع حجم الصفحة والهوامش وجدول المحتويات.

ماذا يحفظ التصدير إلى Markdown؟

عند تصدير محادثة Claude إلى Markdown، تحتفظ Download Claude conversations بالعناوين، وكتل الشيفرة مع وسوم اللغة والمسافات البادئة، والجداول، والروابط. وكتل التفكير ومصادر البحث على الويب وخطوات الأدوات / MCP كلها اختيارية: «Thinking» (التفكير) خانة اختيار في لوحة التصدير، والأخريان تُفعَّلان من الإعدادات. ويمكن إضافة البيانات الوصفية (العنوان والطوابع الزمنية والنموذج). ومرشّح المرسل يقصر ملف .md على «All / Human / Assistant» (الكل / المستخدم فقط / المساعد فقط).

تخطيط المخرجات (artifacts) خيار فعلي في الإصدار 1.16.2: «Original» (الأصلي) أو «Inline» (مضمّن) أو «Nested» (متداخل) أو «Flat» (مسطّح). يمكن لتصدير Markdown أن يعكس بنية المخرجات كما تظهر على الشاشة، أو أن يسطّحها في مستند خطي واحد، أو أن ينقلها إلى مجلد خاص بها داخل ملف ZIP. ويمكن من الإعدادات تضمين الصور في ملف .md. القائمة الكاملة: ميزات إضافة Chrome. لا يحتفظ Markdown بألوان فقاعات الرسائل؛ استخدم PNG للقطة مرئية أو PDF للصفحات.

هل يمكنني التصدير إلى Markdown دفعة واحدة؟

نعم. افتح «View and Download All Conversations»، واضبط «Chat format» (صيغة المحادثة) على Markdown، وصفِّ الجدول، ثم انقر «Export All». يحفظ Chrome ملف ZIP واحدًا فيه ملف .md لكل محادثة. وفي الخطة المجانية يعني ذلك 3 محادثات يوميًا مع تسجيل الدخول عبر Google، بالاشتراك مع PDF. واشتراك Pro بسعر $3.99 شهريًا أو $26.99 سنويًا يلغي هذا الحد للتصدير الجماعي إلى Markdown.

تعرض لوحة التحكم (Dashboard) سجل claude.ai مع البحث بالاسم، والبحث في المشاريع، وتبويبي «Chat» و«Cowork»، والمرشّحات «All conversations» و«New» و«Updated» و«Previously exported» (كل المحادثات / الجديدة / المحدَّثة / المصدَّرة سابقًا). «New» تعني ما لم يُصدَّر بعد بـDownload Claude conversations. و«Previously exported» تتتبع المحادثات التي حفظتها من قبل كي يتخطاها تشغيل ثانٍ لـ«Export All».

الحد اليومي لكل حساب. ثلاث محادثات يوميًا في الخطة المجانية، بالاشتراك مع PDF. إذا حددت 40 محادثة ولم يتبقَّ لك سوى 3، فتُحظر الدفعة كلها ولا تُقتطع. حدّد عددًا أقل أو استخدم Pro. أما التصدير الفردي إلى .md من الزر البرتقالي فيبقى غير محدود.

يستخدم التصدير الجماعي إلى Markdown خانات الاختيار في لوحة التحكم «Chats» و«Thinking» و«Metadata» و«Tools» و«Sources» (المحادثات والتفكير والبيانات الوصفية والأدوات والمصادر)، إضافة إلى تخطيط المخرجات. و«Export All» ليس ملف ZIP من Anthropic يصل بعد تأخير، بل ملف ZIP واحد من ملفات .md لكل محادثة. إذا أردت أرشيفًا واحدًا للحساب كله، فذلك هو Settings → Privacy → Export data (قد تظهر التسميات مترجمة إذا كانت لغة claude.ai مضبوطة على العربية)، وهو بصيغة JSON لا Markdown.

Markdown أم JSON عند تصدير محادثة Claude؟

صدّر محادثة Claude إلى Markdown عندما سيقرأ الملف إنسان، وبصيغة JSON عندما سيحلل سكربت شجرة الرسائل. توفر Download Claude conversations الصيغتين في قائمة منسدلة واحدة، إلى جانب PDF والنص العادي وXML وCSV وPNG. الصفحة الرئيسية للصيغ: صيغ تصدير محادثات Claude.

‏Export data من Anthropic بصيغة JSON أيضًا، لكنه ملف ZIP للحساب يصل بالبريد، لا ملف .md لكل محادثة، ولا يمكنك اختيار Markdown داخل ذلك الطلب. والطباعة من المتصفح لقطة لصفحة الويب. ولا يغني أي منهما عن تصدير المحادثة إلى Markdown من الزر البرتقالي.

تعمل الإضافة فقط على claude.ai في Chrome. لا يحصل Claude Desktop ولا Claude Code في الطرفية على زر Markdown. أما Claude Code على الويب (claude.ai/code) فيعمل على claude.ai، لذا يُصدَّر مثل أي محادثة. إذا كانت المحادثة موجودة أيضًا على claude.ai، فافتحها هناك وصدّرها إلى Markdown. و/export في Claude Code داخل الطرفية مسار منتج مختلف.

هل يكلف التصدير إلى Markdown أكثر؟

لا. تصدير محادثة واحدة إلى Markdown مجاني وغير محدود، بلا حساب ولا عدّاد — مثل JSON والنص العادي وXML وCSV وPNG. والحد المجاني يقتصر على PDF و«Export All» الجماعي: 3 مرات يوميًا مع تسجيل الدخول عبر Google. ويكلف Pro ‏$3.99 شهريًا أو $26.99 سنويًا عبر Paddle. ولا تفرض Download Claude conversations رسومًا إضافية على Markdown.

يظهر الحد في التصدير الجماعي إلى Markdown: كل محادثة في ملف ZIP من «Export All» تستهلك واحدة من المرات الثلاث اليومية، ويُعاد ضبط العدد عند منتصف الليل بتوقيت UTC. ويلغي Pro هذا الحد، ويُستعاد على كمبيوتر جديد من حساب Google نفسه. وPaddle هي البائع الرسمي؛ فريقنا لا يرى أرقام البطاقات أبدًا.

لا تحتاج خطة claude.ai مدفوعة من Anthropic، بل حسابًا يستطيع تحميل المحادثة في Chrome. وتعمل خطط Team وEnterprise مع الزر البرتقالي كما تعمل الخطة المجانية. والإصدار 1.16.2 (سبتمبر 2026) ما زال لا يكتب Word ولا Notion.

هل يُفقد تصدير محادثة Claude إلى Markdown الشيفرة؟

لا. تحتفظ كتل الشيفرة بوسم اللغة والمسافات البادئة، على عكس النسخ واللصق العادي من claude.ai. وتبقى الجداول جداول Markdown. هذا هو السبب الرئيسي لتصدير محادثة Claude إلى Markdown بدل تحديد النص يدويًا.

هل يمكنني تصدير محادثات Claude إلى Markdown دفعة واحدة؟

نعم. يدعم «Export All» في لوحة التحكم صيغة Markdown ويحفظ ملف ZIP واحدًا من ملفات .md. وفي الخطة المجانية يشمل ذلك 3 محادثات يوميًا مع تسجيل الدخول عبر Google؛ أما Pro فبلا حدود.

هل Markdown هو نفسه Export data من Anthropic؟

لا. التصدير الرسمي من Anthropic ملف ZIP بصيغة JSON لحسابك كله يصل بالبريد بعد انتظار. أما تصدير محادثة Claude إلى Markdown فملف .md لكل محادثة (أو لكل تحديد) من Download Claude conversations.

هل يكلف Markdown أكثر من الصيغ الأخرى؟

لا. التصدير الفردي إلى Markdown غير محدود ولا يحتاج إلى حساب، مثل JSON والنص العادي وXML وCSV وPNG. والحد المجاني، 3 مرات يوميًا، يقتصر على PDF والتصدير الجماعي بملف ZIP. ويكلف Pro ‏$3.99 شهريًا أو $26.99 سنويًا.

هل يمكنني تصدير محادثة Claude إلى Markdown في Desktop؟

لا. تُحقن Download Claude conversations فقط في claude.ai داخل Chrome. لا يعرض Claude Desktop قائمة Markdown أبدًا. افتح المحادثة نفسها على claude.ai إذا كانت موجودة هناك.

هل ينتج تصدير محادثة Claude إلى Markdown ملف PDF؟

لا. ‏Markdown ملف نصي .md. للصفحات، اختر PDF في اللوحة نفسها بدلًا منه: يُبنى داخل المتصفح مع حجم الصفحة والهوامش وجدول المحتويات. ويتطلب PDF تسجيل الدخول عبر Google، ويُحتسب من المرات الثلاث اليومية في الخطة المجانية.
