كيف أصدّر محادثة Claude إلى XML؟

افتح المحادثة على claude.ai في Chrome، وانقر الزر البرتقالي بجوار مربع الرسائل، واختر XML، ثم انقر «Export». تكتب Download Claude conversations الملف محليًا. هكذا تصدّر محادثة Claude إلى XML في الإصدار 1.16.2. لا يوجد في claude.ai زر مدمج للحفظ بصيغة XML حتى سبتمبر 2026.

  1. ثبّت Download Claude conversations من Chrome Web Store.
  2. أعد تحميل claude.ai وافتح رابط محادثة حقيقية، لا الصفحة الرئيسية الفارغة لمربع الكتابة.
  3. انقر زر التنزيل البرتقالي على يمين مربع الرسائل.
  4. اختر XML. تُحفظ آخر صيغة استخدمتها. واستخدم «Select» (تحديد) لتحديد الرسائل التي تريدها فقط.
  5. انقر «Export». ينزّل Chrome ملف XML عبر واجهة التنزيل في المتصفح. أو انقر «Copy» (نسخ) لوضع XML في الحافظة.

لا حاجة إلى تسجيل الدخول لتصدير محادثة Claude إلى XML. التصدير الفردي إلى XML غير محدود ومن دون هوية، ولا يرسل شيئًا إلى خوادمنا. ولا يُطلب تسجيل الدخول عبر Google إلا لـPDF والتصدير الجماعي «Export All». الآلية: كيف تعمل الإضافة.

إذا غاب الزر البرتقالي، فأنت لست في رابط محادثة، أو تحتاج علامة التبويب إلى إعادة تحميل، أو أن الإضافة مخفية في قائمة الإضافات (أيقونة قطعة الأحجية) في Chrome. ثبّت Download Claude conversations في الشريط، ثم حدّث claude.ai. ولا يظهر التصدير إلى XML أبدًا في Claude Desktop أو في Claude Code داخل الطرفية.

ملف واحد أم ملفات كثيرة؟ يصدّر الزر البرتقالي المحادثة المفتوحة بصيغة XML. ولملفات XML كثيرة، افتح «View and Download All Conversations» (عرض كل المحادثات وتنزيلها) وشغّل «Export All» (تصدير الكل) مع اختيار XML: ملف ZIP واحد، و3 محادثات يوميًا في الخطة المجانية — راجع التصدير الجماعي Export All.

متى أصدّر محادثة Claude إلى XML؟

صدّر محادثة Claude إلى XML عندما يتطلب النظام المستقبِل أو خط المعالجة أو الأداة القديمة XML لتبادل البيانات المنظّمة. معظم المطورين ينبغي أن يختاروا JSON بدلًا منه. ‏Markdown للملاحظات البشرية، وCSV لجداول البيانات، وPNG صورة. وXML موجود في القائمة لأن بعض الأدوات ما زالت تستقبل XML ولا تقبل JSON.

لا تصدّر محادثة Claude إلى XML على أنه نسخة «أكثر رسمية» من JSON. تطبّق Download Claude conversations التحليل نفسه في الحالتين، والاختلاف في شكل الملف، لا في حقول إضافية تظهر بطريقة سحرية. إذا لم تكن أي أداة تستخدمها تتطلب XML، فتجاوز هذه الصيغة واستخدم JSON.

نوفر XML لأن بعض خطوط المعالجة ما زالت تتطلبه، لا لأننا نراه أفضل من JSON في كل تصدير من claude.ai. التحليل واحد: الرسائل، والمرسل، والتفكير والمخرجات الاختيارية. ويُبقي الإصدار 1.16.2 صيغة XML واحدة من سبع صيغ، مجانية بلا حساب، لا إضافة مدفوعة.

ماذا يحفظ التصدير إلى XML؟

عند تصدير محادثة Claude إلى XML، تكتب Download Claude conversations بنية المحادثة — الرسائل، والمرسل، والبيانات الوصفية المتاحة — كترميز XML. وتتبع كتل التفكير ومصادر البحث على الويب وخطوات الأدوات / MCP والمخرجات الخيارات نفسها المستخدمة في Markdown وJSON: «Thinking» (التفكير) خانة اختيار في لوحة التصدير، والأدوات والمصادر تُفعَّل من الإعدادات. فـXML ليس نسخة مجرّدة من تلك الصيغ.

تخطيط المخرجات في الإصدار 1.16.2 هو «Original» (الأصلي) أو «Inline» (مضمّن) أو «Nested» (متداخل) أو «Flat» (مسطّح). ويقصر مرشّح المرسل ملف XML على «All / Human / Assistant» (الكل / المستخدم فقط / المساعد فقط). ويمكن إضافة البيانات الوصفية (العنوان والطوابع الزمنية والنموذج). القائمة الكاملة للخيارات: ميزات إضافة Chrome.

XML أم JSON عند تصدير محادثة Claude؟

‏JSON هو الاختيار الشائع للمطورين. صدّر محادثة Claude إلى XML فقط عندما يتطلبه نظام لاحق. لا تجعل Download Claude conversations صيغة XML «أكمل» من JSON؛ فكلاهما يمكن أن يتضمن التفكير والمخرجات، ولا أي منهما هو ملف ZIP الخاص بحساب Anthropic. الصفحة الرئيسية للصيغ: صيغ تصدير محادثات Claude.

خيار Settings → Privacy → Export data لدى Anthropic (قد تظهر التسميات مترجمة إذا كانت لغة claude.ai مضبوطة على العربية) ينتج JSON (ملف ZIP)، لا XML. وملف PDF من اللوحة نفسها صفحات للبشر، لا ترميز. ولا يغني أي منهما عن تصدير المحادثة إلى XML من الزر البرتقالي. ولا تتوقع أن يطابق ملف XML هذا بنية غير منشورة لدى Anthropic.

تعمل الإضافة فقط على claude.ai في Chrome. لا يحصل Claude Desktop ولا Claude Code في الطرفية على زر XML. أما Claude Code على الويب (claude.ai/code) فيعمل على claude.ai، لذا يُصدَّر مثل أي محادثة. إذا كانت المحادثة موجودة أيضًا على claude.ai، فافتحها هناك وصدّرها إلى XML. و/export في Claude Code داخل الطرفية مسار منتج مختلف.

هل يمكنني التصدير إلى XML دفعة واحدة؟

نعم. افتح «View and Download All Conversations»، واضبط «Chat format» (صيغة المحادثة) على XML، وصفِّ الجدول، ثم انقر «Export All». يحفظ Chrome ملف ZIP واحدًا فيه ملف XML لكل محادثة. وفي الخطة المجانية يعني ذلك 3 محادثات يوميًا مع تسجيل الدخول عبر Google، بالاشتراك مع PDF. واشتراك Pro بسعر $3.99 شهريًا أو $26.99 سنويًا يلغي هذا الحد للتصدير الجماعي إلى XML.

تعرض لوحة التحكم (Dashboard) سجل claude.ai مع البحث بالاسم، والبحث في المشاريع، وتبويبي «Chat» و«Cowork»، والمرشّحات «All conversations» و«New» و«Updated» و«Previously exported» (كل المحادثات / الجديدة / المحدَّثة / المصدَّرة سابقًا). «New» تعني ما لم يُصدَّر بعد بـDownload Claude conversations. و«Previously exported» تتتبع المحادثات التي حفظتها من قبل. و«Export All» ملف ZIP واحد من ملفات XML لكل محادثة، لا أرشيف مختلط الصيغ.

الحد اليومي لكل حساب. ثلاث محادثات يوميًا في الخطة المجانية، بالاشتراك مع PDF. إذا حددت 40 محادثة ولم يتبقَّ لك سوى 3، فتُحظر الدفعة كلها ولا تُقتطع. حدّد عددًا أقل أو استخدم Pro. أما التصدير الفردي إلى XML من الزر البرتقالي فيبقى غير محدود.

لا يمكنك خلط XML وJSON في نقرة «Export All» واحدة. اختر XML لذلك التشغيل، وشغّل «Export All» مرة أخرى بصيغة JSON إذا احتجت الشكلين للمحادثة نفسها من claude.ai؛ والتشغيل الثاني يحتسب كل محادثة من جديد.

هل يحتاج التصدير إلى XML إلى Pro؟

لا. تصدير محادثة واحدة إلى XML مجاني وغير محدود، بلا حساب ولا عدّاد — مثل Markdown وJSON والنص العادي وCSV وPNG. والحد المجاني يقتصر على PDF و«Export All» الجماعي: 3 مرات يوميًا مع تسجيل الدخول عبر Google. ويكلف Pro ‏$3.99 شهريًا أو $26.99 سنويًا عبر Paddle. ولا تعامل Download Claude conversations صيغة XML كصيغة مدفوعة فقط.

يظهر الحد في التصدير الجماعي إلى XML: كل محادثة في ملف ZIP من «Export All» تستهلك واحدة من المرات الثلاث اليومية، ويُعاد ضبط العدد عند منتصف الليل بتوقيت UTC. ويلغي Pro هذا الحد، ويُستعاد على كمبيوتر جديد من حساب Google نفسه. وPaddle هي البائع الرسمي؛ فريقنا لا يرى أرقام البطاقات أبدًا.

لا تحتاج خطة claude.ai مدفوعة من Anthropic، بل حسابًا يستطيع تحميل المحادثة في Chrome. والإصدار 1.16.2 (سبتمبر 2026) ما زال لا يكتب Word ولا Notion. إذا تغيّرت هذه القائمة، فستتغير هذه الصفحة في اليوم نفسه.

هل XML أفضل من JSON لتصدير محادثات Claude؟

ليس عمومًا. ‏JSON هي الخيار الأكثر شيوعًا بين المطورين. صدّر محادثة Claude إلى XML عندما يتطلب النظام المستقبِل XML لتبادل البيانات المنظّمة. التحليل من claude.ai واحد؛ والاختلاف في شكل الملف.

هل يمكنني تصدير محادثات Claude إلى XML دفعة واحدة؟

نعم. يدعم مسار «Export All» نفسه في لوحة التحكم صيغة XML ويحفظ ملف ZIP واحدًا فيه ملف XML لكل محادثة. وفي الخطة المجانية يشمل ذلك 3 محادثات يوميًا مع تسجيل الدخول عبر Google؛ أما Pro بسعر $3.99 شهريًا أو $26.99 سنويًا فبلا حدود.

هل XML صيغة مدفوعة فقط؟

لا. التصدير الفردي إلى XML غير محدود ولا يحتاج إلى حساب، مثل Markdown والنص العادي وJSON وCSV وPNG. والحد المجاني، 3 مرات يوميًا، يقتصر على PDF و«Export All» الجماعي. ويكلف Pro ‏$3.99 شهريًا أو $26.99 سنويًا.

هل يطابق التصدير إلى XML ملف ZIP من Anthropic؟

لا. ‏Export data من Anthropic ملف ZIP بصيغة JSON للحساب يصل بعد تأخير. أما Download Claude conversations فتكتب ملف XML لكل محادثة (أو لكل تحديد) فورًا في Chrome. ليست البنية نفسها.

هل ينتج تصدير محادثة Claude إلى XML ملف PDF؟

لا. ‏XML لغة ترميز. للصفحات، اختر PDF في اللوحة نفسها؛ والصيغ السبع هي PDF وMarkdown وJSON والنص العادي وXML وCSV وPNG. ويتطلب PDF تسجيل الدخول عبر Google، ويُحتسب من المرات الثلاث اليومية في الخطة المجانية.

هل يمكنني تصدير محادثة Claude إلى XML في Desktop؟

لا. تُحقن إضافة Chrome فقط في claude.ai. لا يعرض Claude Desktop قائمة XML أبدًا. افتح المحادثة نفسها على claude.ai في Chrome إذا كانت موجودة هناك.
