كيف أصدّر محادثة Claude إلى XML؟

افتح المحادثة على claude.ai في Chrome، وانقر الزر البرتقالي بجوار مربع الرسائل، واختر XML، ثم انقر «Export». تكتب Download Claude conversations الملف محليًا. هكذا تصدّر محادثة Claude إلى XML في الإصدار 1.13.0. لا يوجد في claude.ai زر مدمج للحفظ بصيغة XML حتى سبتمبر 2026.

  1. ثبّت Download Claude conversations من Chrome Web Store (تقييم الإضافة 5.0).
  2. أعد تحميل claude.ai وافتح رابط محادثة حقيقية، لا الصفحة الرئيسية الفارغة لمربع الكتابة.
  3. انقر زر التنزيل البرتقالي على يمين مربع الرسائل.
  4. اختر XML. تُحفظ آخر صيغة استخدمتها.
  5. انقر «Export». ينزّل Chrome ملف XML عبر واجهة التنزيل في المتصفح.

متى أصدّر محادثة Claude إلى XML؟

صدّر محادثة Claude إلى XML عندما يتطلب النظام المستقبِل أو خط المعالجة أو الأداة القديمة XML لتبادل البيانات المنظّمة. معظم المطورين ينبغي أن يختاروا JSON بدلًا منه. ‏Markdown للملاحظات البشرية، وPNG صورة. وXML موجود في القائمة لأن بعض الأدوات ما زالت تستقبل XML ولا تقبل JSON.

لا تصدّر محادثة Claude إلى XML على أنه نسخة «أكثر رسمية» من JSON. تطبّق Download Claude conversations التحليل نفسه في الحالتين، والاختلاف في شكل الملف، لا في حقول إضافية تظهر بطريقة سحرية. إذا لم تكن أي أداة تستخدمها تتطلب XML، فتجاوز هذه الصيغة واستخدم JSON.

نوفر XML لأن بعض خطوط المعالجة ما زالت تتطلبه، لا لأننا نراه أفضل من JSON في كل تصدير من claude.ai. التحليل واحد: الرسائل، والمرسل، والتفكير والمخرجات الاختيارية. وما زلنا لا نُخرج PDF. ويُبقي الإصدار 1.13.0 صيغة XML واحدة من خمس صيغ، لا إضافة مدفوعة.

ماذا يحفظ التصدير إلى XML؟

عند تصدير محادثة Claude إلى XML، تكتب Download Claude conversations بنية المحادثة — الرسائل، والمرسل، والبيانات الوصفية المتاحة — كترميز XML. وتتبع كتل التفكير والمخرجات الخيارات نفسها المستخدمة في Markdown وJSON. فـXML ليس نسخة مجرّدة من تلك الصيغ.

تخطيط المخرجات في الإصدار 1.13.0 هو «Original» (الأصلي) أو «Inline» (مضمّن) أو «Nested» (متداخل) أو «Flat» (مسطّح). ويقصر مرشّح المرسل ملف XML على «all / human only / assistant only» (الكل / المستخدم فقط / المساعد فقط). ويمكن إضافة البيانات الوصفية (العنوان والطوابع الزمنية والنموذج). القائمة الكاملة للخيارات: ميزات إضافة Chrome.

هل يمكنني التصدير إلى XML دفعة واحدة؟

نعم. افتح «View and Download All Conversations»، واضبط الصيغة على XML، وصفِّ الجدول، ثم انقر «Export All». كل ملف مكتمل يُحتسب واحدة من عمليات التصدير المجانية الثلاث. واشتراك Pro بسعر $3.99 شهريًا أو $26.99 سنويًا يلغي هذا الحد للتصدير الجماعي إلى XML.

يعرض جدول التصفح سجل claude.ai مع البحث بالاسم والمرشّحات «All» و«New» و«Exported» و«Project» (الكل / الجديدة / المصدّرة / المشروع). «New» تعني ما لم يُصدَّر بعد بـDownload Claude conversations. و«Exported» تتتبع المحادثات التي حفظتها من قبل. و«Project» تطابق طريقة تجميعك للمحادثات على claude.ai. و«Export All» يعني ملفات XML كثيرة، لا ملف ZIP واحدًا مختلطًا.

الحصة على مستوى الحساب. ثلاث عمليات تصدير مجانية إجمالًا — لا ثلاثة ملفات XML لكل تشغيل جماعي. تحديد 40 محادثة يستهلك 40 عملية تصدير إذا اكتمل كل ملف. خطّط لما تحدده، أو استخدم Pro.
