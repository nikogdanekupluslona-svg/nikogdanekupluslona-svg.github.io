كيف أصدّر محادثة Claude بصيغة JSON؟

افتح المحادثة على claude.ai في Chrome، وانقر الزر البرتقالي بجوار مربع الرسائل، واختر JSON، ثم انقر «Export». تكتب Download Claude conversations الملف محليًا. هكذا تصدّر محادثة Claude بصيغة JSON في الإصدار 1.16.2. لا يوجد في claude.ai زر لحفظ محادثة واحدة بصيغة JSON حتى سبتمبر 2026.

  1. ثبّت Download Claude conversations من Chrome Web Store.
  2. أعد تحميل claude.ai وافتح رابط محادثة حقيقية، لا الصفحة الرئيسية الفارغة لمربع الكتابة.
  3. انقر زر التنزيل البرتقالي على يمين مربع الرسائل.
  4. اختر JSON. تُحفظ آخر صيغة استخدمتها. واستخدم «Select» (تحديد) لتحديد الرسائل التي تريدها فقط.
  5. انقر «Export». ينزّل Chrome ملف JSON عبر واجهة التنزيل في المتصفح. أو انقر «Copy» (نسخ) لوضع JSON في الحافظة.

لا حاجة إلى تسجيل الدخول لتصدير محادثة Claude بصيغة JSON. التصدير الفردي بصيغة JSON غير محدود ومن دون هوية، ولا يرسل شيئًا إلى خوادمنا. ولا يُطلب تسجيل الدخول عبر Google إلا لـPDF والتصدير الجماعي «Export All». الآلية: كيف تعمل الإضافة.

إذا غاب الزر البرتقالي، فأنت لست في رابط محادثة، أو تحتاج علامة التبويب إلى إعادة تحميل، أو أن الإضافة مخفية في قائمة الإضافات (أيقونة قطعة الأحجية) في Chrome. ثبّت Download Claude conversations في الشريط، ثم حدّث claude.ai. ولا يُحقن سكربت المحتوى أبدًا في Claude Desktop أو في Claude Code داخل الطرفية.

محادثة واحدة أم ملفات كثيرة؟ يصدّر الزر البرتقالي المحادثة المفتوحة بصيغة JSON. ولملفات JSON كثيرة، افتح «View and Download All Conversations» (عرض كل المحادثات وتنزيلها) وشغّل «Export All» (تصدير الكل) مع اختيار JSON: ملف ZIP واحد، و3 محادثات يوميًا في الخطة المجانية — راجع التصدير الجماعي Export All.

متى أصدّر محادثة Claude بصيغة JSON؟

صدّر محادثة Claude بصيغة JSON عندما سيقرأ الملف سكربت أو أداة فهرسة أو أداة مقارنة. ملف JSON مبني لشجرة الرسائل، لا للقراءة في Obsidian. إذا أردت عناوين وكتل شيفرة للقراءة البشرية، فاختر Markdown بدلًا منه. ولجدول بيانات، اختر CSV: صف لكل رسالة.

النسخ واللصق من claude.ai يُفقد بنية المرسلين. والطباعة تُبقي عناصر صفحة الويب. أما عند التصدير بصيغة JSON فتحتفظ Download Claude conversations بالأدوار والمرسلين والتفكير الاختياري كبيانات، لا كفقرة مسطّحة. لهذا يفضّل المطورون JSON على النص العادي.

نكتب JSON من شجرة claude.ai الموجودة أصلًا في الصفحة — المرسل، وكتل المحتوى، والطوابع الزمنية، والبيانات الوصفية للنموذج — دون رفع المحادثة. ملف JSON هذا ليس ملف ZIP الخاص بحساب Anthropic. وهو في الإصدار 1.16.2 إحدى سبع صيغ، إلى جانب PDF وCSV، ومجاني بلا حساب.

ماذا يوجد في ملف JSON لمحادثة Claude؟

ملف JSON لمحادثة Claude يعكس شجرة الرسائل في claude.ai: المرسل، وكتل المحتوى، والطوابع الزمنية، والبيانات الوصفية للنموذج. وتُضمَّن كتل التفكير ومصادر البحث على الويب وخطوات الأدوات / MCP والمخرجات عند تفعيل خياراتها: «Thinking» (التفكير) خانة اختيار في لوحة التصدير، والأدوات والمصادر تُفعَّل من الإعدادات. ويقصر مرشّح المرسل الملف على «All / Human / Assistant» (الكل / المستخدم فقط / المساعد فقط). ولا يُسطَّح أي شيء إلى Markdown أولًا.

تخطيط المخرجات في الإصدار 1.16.2 هو «Original» (الأصلي) أو «Inline» (مضمّن) أو «Nested» (متداخل) أو «Flat» (مسطّح). تغيّر هذه التخطيطات طريقة تداخل محتوى المخرجات في JSON، وهي الخيارات الأربعة نفسها المستخدمة في Markdown وXML. القائمة الكاملة: ميزات إضافة Chrome. ولصفحات بدل البيانات، صدّر بصيغة PDF.

ملف JSON للمحادثة أم Export data من Anthropic؟

كلاهما JSON، لكنهما مختلفان في الشكل والنطاق. خيار Settings → Privacy → Export data لدى Anthropic (قد تظهر التسميات مترجمة إذا كانت لغة claude.ai مضبوطة على العربية) يرسل بالبريد ملف ZIP واحدًا للحساب كله بعد انتظار. أما عند تصدير محادثة Claude بصيغة JSON فتحصل على محادثة واحدة فورًا في Chrome. استخدم ملف ZIP للنسخ الاحتياطي.

هل يمكنني التصدير بصيغة JSON دفعة واحدة؟

نعم. افتح «View and Download All Conversations»، واضبط «Chat format» (صيغة المحادثة) على JSON، وصفِّ الجدول، ثم انقر «Export All». يحفظ Chrome ملف ZIP واحدًا فيه ملف JSON لكل محادثة. وفي الخطة المجانية يعني ذلك 3 محادثات يوميًا مع تسجيل الدخول عبر Google، بالاشتراك مع PDF. واشتراك Pro بسعر $3.99 شهريًا أو $26.99 سنويًا يلغي هذا الحد للتصدير الجماعي بصيغة JSON.

تعرض لوحة التحكم (Dashboard) سجل claude.ai مع البحث بالاسم، والبحث في المشاريع، وتبويبي «Chat» و«Cowork»، والمرشّحات «All conversations» و«New» و«Updated» و«Previously exported» (كل المحادثات / الجديدة / المحدَّثة / المصدَّرة سابقًا). «New» تعني ما لم يُصدَّر بعد بـDownload Claude conversations. و«Previously exported» تتتبع المحادثات التي حفظتها من قبل. و«Export All» ملف ZIP واحد من ملفات JSON لكل محادثة، لا أرشيف مختلط الصيغ.

الحد اليومي لكل حساب. ثلاث محادثات يوميًا في الخطة المجانية، بالاشتراك مع PDF. إذا حددت 40 محادثة ولم يتبقَّ لك سوى 3، فتُحظر الدفعة كلها ولا تُقتطع. حدّد عددًا أقل أو استخدم Pro. أما التصدير الفردي بصيغة JSON من الزر البرتقالي فيبقى غير محدود.

يمكنك مقارنة ملفي JSON للمحادثة نفسها من claude.ai صُدّرا في وقتين مختلفين كما تقارن أي ملفي JSON. كل تصدير مستقل بذاته. وتشغيل «Export All» مرة ثانية على المحادثات نفسها يحتسب كل محادثة من جديد.

هل يحتاج التصدير بصيغة JSON إلى Pro؟

لا. تصدير محادثة واحدة بصيغة JSON مجاني وغير محدود، بلا حساب ولا عدّاد — مثل Markdown والنص العادي وXML وCSV وPNG. والحد المجاني يقتصر على PDF و«Export All» الجماعي: 3 مرات يوميًا مع تسجيل الدخول عبر Google. ويكلف Pro ‏$3.99 شهريًا أو $26.99 سنويًا عبر Paddle. ولا تفرض Download Claude conversations رسومًا إضافية على تصدير محادثة Claude بصيغة JSON.

يظهر الحد في التصدير الجماعي بصيغة JSON: كل محادثة في ملف ZIP من «Export All» تستهلك واحدة من المرات الثلاث اليومية، ويُعاد ضبط العدد عند منتصف الليل بتوقيت UTC. ويلغي Pro هذا الحد، ويُستعاد على كمبيوتر جديد من حساب Google نفسه. وPaddle هي البائع الرسمي؛ فريقنا لا يرى أرقام البطاقات أبدًا.

تعمل الإضافة فقط على claude.ai في Chrome. لا يحصل Claude Desktop ولا Claude Code في الطرفية على زر JSON؛ أما Claude Code على الويب (claude.ai/code) فيعمل على claude.ai، لذا يُصدَّر مثل أي محادثة. و/export في Claude Code داخل الطرفية أو ملفات JSONL على القرص مسار مختلف. والإصدار 1.16.2 (سبتمبر 2026) ما زال لا يكتب Word ولا Notion.

الأسئلة الشائعة: تصدير محادثة Claude بصيغة JSON

هل يمكنني تصدير محادثات Claude بصيغة JSON دفعة واحدة؟

نعم. يدعم «Export All» في لوحة التحكم صيغة JSON ويحفظ ملف ZIP واحدًا فيه ملف JSON لكل محادثة. وفي الخطة المجانية يشمل ذلك 3 محادثات يوميًا مع تسجيل الدخول عبر Google؛ أما Pro بسعر $3.99 شهريًا أو $26.99 سنويًا فبلا حدود.

هل بنية JSON موثّقة؟

تعكس شجرة الرسائل في claude.ai نفسه: المرسل، وكتل المحتوى، والطوابع الزمنية، والبيانات الوصفية للنموذج، مع المخرجات وكتل التفكير ومصادر البحث على الويب وخطوات الأدوات / MCP عند تفعيل خياراتها. وهي ليست بنية ملف ZIP الخاص بحساب Anthropic.

هل أحتاج Pro لتصدير محادثة Claude بصيغة JSON؟

لا. التصدير الفردي بصيغة JSON غير محدود ولا يحتاج إلى حساب، مثل كل الصيغ ما عدا PDF. واشتراك Pro بسعر $3.99 شهريًا أو $26.99 سنويًا يرفع فقط حد 3 مرات يوميًا عن PDF و«Export All» الجماعي.

هل يمكنني مقارنة ملفي JSON لمحادثة واحدة؟

نعم. في كل مرة تصدّر فيها محادثة Claude بصيغة JSON تحصل على ملف مستقل مبني بالطريقة نفسها. ومقارنة تصديرين للمحادثة نفسها في وقتين مختلفين تتم كمقارنة أي ملفي JSON آخرين.

هل ملف JSON هذا هو نفسه Export data من Anthropic؟

لا. ‏Export data من Anthropic ملف ZIP للحساب كله يصل بعد تأخير. أما Download Claude conversations فتكتب ملف JSON لكل محادثة (أو لكل تحديد) فورًا في Chrome. قد يكون كلاهما JSON، لكنهما غير قابلين للتبادل.

هل ينتج تصدير محادثة Claude بصيغة JSON ملف PDF؟

لا. ‏JSON بيانات منظّمة. للصفحات، اختر PDF في اللوحة نفسها؛ والصيغ السبع هي PDF وMarkdown وJSON والنص العادي وXML وCSV وPNG. ويتطلب PDF تسجيل الدخول عبر Google، ويُحتسب من المرات الثلاث اليومية في الخطة المجانية.

هل يعمل التصدير بصيغة JSON في Claude Desktop؟

لا. تُحقن إضافة Chrome فقط في claude.ai. لا يعرض Claude Desktop خيار JSON أبدًا. افتح المحادثة نفسها على claude.ai في Chrome إذا كانت موجودة هناك.
