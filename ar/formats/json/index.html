كيف أصدّر محادثة Claude بصيغة JSON؟

افتح المحادثة على claude.ai في Chrome، وانقر الزر البرتقالي بجوار مربع الرسائل، واختر JSON، ثم انقر «Export». تكتب Download Claude conversations الملف محليًا. هكذا تصدّر محادثة Claude بصيغة JSON في الإصدار 1.13.0. لا يوجد في claude.ai زر لحفظ محادثة واحدة بصيغة JSON حتى سبتمبر 2026.

  1. ثبّت Download Claude conversations من Chrome Web Store (تقييم الإضافة 5.0).
  2. أعد تحميل claude.ai وافتح رابط محادثة حقيقية، لا الصفحة الرئيسية الفارغة لمربع الكتابة.
  3. انقر زر التنزيل البرتقالي على يمين مربع الرسائل.
  4. اختر JSON. تُحفظ آخر صيغة استخدمتها.
  5. انقر «Export». ينزّل Chrome ملف JSON عبر واجهة التنزيل في المتصفح.

تسجيل الدخول بحساب Google مطلوب قبل أول تصدير بصيغة JSON. تحفظ Download Claude conversations البريد الإلكتروني الموثّق لاحتساب عمليات التصدير المجانية الثلاث ولاستعادة Pro بعد إعادة التثبيت. ونصوص المحادثات ليست جزءًا من تسجيل الدخول. الآلية: كيف تعمل الإضافة.

إذا غاب الزر البرتقالي، فأنت لست في رابط محادثة، أو تحتاج علامة التبويب إلى إعادة تحميل، أو أن الإضافة مخفية في قائمة الإضافات (أيقونة قطعة الأحجية) في Chrome. ثبّت Download Claude conversations في الشريط، ثم حدّث claude.ai. ولا يُحقن سكربت المحتوى أبدًا في Claude Desktop أو Claude Code.

محادثة واحدة أم ملفات كثيرة؟ يصدّر الزر البرتقالي المحادثة المفتوحة بصيغة JSON. ولملفات JSON كثيرة، افتح «View and Download All Conversations» (عرض كل المحادثات وتنزيلها) وشغّل «Export All» (تصدير الكل) مع اختيار JSON — راجع التصدير الجماعي Export All.

متى أصدّر محادثة Claude بصيغة JSON؟

صدّر محادثة Claude بصيغة JSON عندما سيقرأ الملف سكربت أو أداة فهرسة أو أداة مقارنة. ملف JSON مبني لشجرة الرسائل، لا للقراءة في Obsidian. إذا أردت عناوين وكتل شيفرة للقراءة البشرية، فاختر Markdown بدلًا منه.

النسخ واللصق من claude.ai يُفقد بنية المرسلين. والطباعة تُبقي عناصر صفحة الويب. أما عند التصدير بصيغة JSON فتحتفظ Download Claude conversations بالأدوار والمرسلين والتفكير الاختياري كبيانات، لا كفقرة مسطّحة. لهذا يفضّل المطورون JSON على النص العادي.

نكتب JSON من شجرة claude.ai الموجودة أصلًا في الصفحة — المرسل، وكتل المحتوى، والطوابع الزمنية، والبيانات الوصفية للنموذج — دون رفع المحادثة. ملف JSON هذا ليس ملف ZIP الخاص بحساب Anthropic، وليس PDF. والإصدار 1.13.0 ما زال يوفر خمس صيغ فقط.

ماذا يوجد في ملف JSON لمحادثة Claude؟

ملف JSON لمحادثة Claude يعكس شجرة الرسائل في claude.ai: المرسل، وكتل المحتوى، والطوابع الزمنية، والبيانات الوصفية للنموذج. وتُضمَّن كتل التفكير والمخرجات عند تفعيل خياراتها. ويقصر مرشّح المرسل الملف على «all / human only / assistant only» (الكل / المستخدم فقط / المساعد فقط). ولا يُسطَّح أي شيء إلى Markdown أولًا.

تخطيط المخرجات في الإصدار 1.13.0 هو «Original» (الأصلي) أو «Inline» (مضمّن) أو «Nested» (متداخل) أو «Flat» (مسطّح). تغيّر هذه التخطيطات طريقة تداخل محتوى المخرجات في JSON، وهي الخيارات الأربعة نفسها المستخدمة في Markdown وXML. القائمة الكاملة للخيارات: ميزات إضافة Chrome. ولا يتحول JSON إلى PDF.

ملف JSON للمحادثة أم Export data من Anthropic؟

كلاهما JSON، لكنهما مختلفان في الشكل والنطاق. خيار Settings → Privacy → Export data لدى Anthropic (قد تظهر التسميات مترجمة إذا كانت لغة claude.ai مضبوطة على العربية) يرسل بالبريد ملف ZIP واحدًا للحساب كله بعد انتظار. أما عند تصدير محادثة Claude بصيغة JSON فتحصل على محادثة واحدة فورًا في Chrome. استخدم ملف ZIP للنسخ الاحتياطي.

هل يمكنني التصدير بصيغة JSON دفعة واحدة؟

نعم. افتح «View and Download All Conversations»، واضبط الصيغة على JSON، وصفِّ الجدول، ثم انقر «Export All». كل ملف مكتمل يُحتسب واحدة من عمليات التصدير المجانية الثلاث. واشتراك Pro بسعر $3.99 شهريًا أو $26.99 سنويًا يلغي هذا الحد للتصدير الجماعي بصيغة JSON.

يعرض جدول التصفح سجل claude.ai مع البحث بالاسم والمرشّحات «All» و«New» و«Exported» و«Project» (الكل / الجديدة / المصدّرة / المشروع). «New» تعني ما لم يُصدَّر بعد بـDownload Claude conversations. و«Exported» تتتبع المحادثات التي حفظتها من قبل. و«Project» تطابق طريقة تجميعك للمحادثات على claude.ai. و«Export All» يعني ملفات JSON كثيرة، لا ملف ZIP واحدًا مختلطًا.

الحصة على مستوى الحساب. ثلاث عمليات تصدير مجانية إجمالًا — لا ثلاثة ملفات JSON لكل تشغيل جماعي. تحديد 40 محادثة يستهلك 40 عملية تصدير إذا اكتمل كل ملف. خطّط لما تحدده، أو استخدم Pro.

يمكنك مقارنة ملفي JSON للمحادثة نفسها من claude.ai صُدّرا في وقتين مختلفين كما تقارن أي ملفي JSON. كل تصدير مستقل بذاته. وتشغيل «Export All» مرة ثانية على المحادثات نفسها يستهلك الحصة أيضًا ما لم تفشل تلك الملفات في الاكتمال.

هل يحتاج التصدير بصيغة JSON إلى Pro؟

لا. ‏JSON مشمولة في عمليات التصدير المجانية الثلاث التي يحصل عليها كل حساب مسجّل بـGoogle، مثل Markdown والنص العادي وXML وPNG. بعد هذه الملفات الثلاثة يكلف Pro ‏$3.99 شهريًا أو $26.99 سنويًا عبر Paddle. ولا تفرض Download Claude conversations رسومًا إضافية على تصدير محادثة Claude بصيغة JSON.

لا تُعاد عمليات التصدير المجانية الثلاث عند إعادة تثبيت الإضافة، ولهذا يُطلب تسجيل الدخول بحساب Google عند أول نقرة على «Export». ويُستعاد Pro على كمبيوتر جديد من حساب Google نفسه. وPaddle هي البائع الرسمي؛ فريقنا لا يرى أرقام البطاقات أبدًا.

تعمل الإضافة فقط على claude.ai في Chrome. لا يحصل Claude Desktop ولا Claude Code على زر JSON. أما /export في Claude Code أو ملفات JSONL على القرص فمسار مختلف. والإصدار 1.13.0 (سبتمبر 2026) ما زال لا يكتب PDF ولا Word ولا Notion.

هل أحتاج Pro لتصدير محادثة Claude بصيغة JSON؟

لا. ‏JSON مشمولة في عمليات التصدير المجانية الثلاث التي يحصل عليها كل حساب مسجّل بـGoogle، مثل كل الصيغ الأخرى. بعد هذه الملفات الثلاثة يكلف Pro ‏$3.99 شهريًا أو $26.99 سنويًا.

هل يمكنني مقارنة ملفي JSON لمحادثة واحدة؟

هل ملف JSON هذا هو نفسه Export data من Anthropic؟

لا. ‏Export data من Anthropic ملف ZIP للحساب كله يصل بعد تأخير. أما Download Claude conversations فتكتب ملف JSON لكل محادثة (أو لكل تحديد) فورًا في Chrome. قد يكون كلاهما JSON، لكنهما غير قابلين للتبادل.

هل ينتج تصدير محادثة Claude بصيغة JSON ملف PDF؟

لا. ‏JSON بيانات منظّمة. وصيغ المنتج هي Markdown وJSON والنص العادي وXML وPNG. للحصول على صفحة قابلة للطباعة، استخدم مربع حوار الطباعة في Chrome، لا هذه القائمة المنسدلة.

لا. تُحقن إضافة Chrome فقط في claude.ai. لا يعرض Claude Desktop خيار JSON أبدًا. افتح المحادثة نفسها على claude.ai في Chrome إذا كانت موجودة هناك.
