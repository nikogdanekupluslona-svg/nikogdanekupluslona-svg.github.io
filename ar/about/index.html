من نحن

Download Claude conversations إضافة Chrome مستقلة (اسم الموقع: Chat Downloader). تسمّيها محركات البحث والمستخدمون أيضًا Claude Chat Downloader وClaude Conversation Downloader. لم تطوّرها شركة Anthropic, PBC، ولا ترتبط بها، ولا تحظى بتأييدها — فـClaude علامة تجارية مملوكة لـAnthropic. أنشأنا هذه الإضافة لسدّ ثغرة في claude.ai نفسه: لا توجد طريقة مدمجة لتنزيل محادثة واحدة كملف.

تضيف الإضافة زر تصدير إلى claude.ai ولوحة تحكم (Dashboard) للتصدير الجماعي، وتكتب ملفات PDF أو Markdown أو نص عادي أو JSON أو XML أو CSV أو PNG محليًا داخل متصفحك. تصدير المحادثة الواحدة بصيغ Markdown والنص العادي وJSON وXML وCSV وPNG غير محدود ولا يتطلب حسابًا. أما PDF والتصدير الجماعي بملف ZIP فيتطلبان تسجيل الدخول عبر Google، وهما مجانيان حتى 3 مرات يوميًا؛ ويلغي اشتراك Pro ‏($3.99 شهريًا أو $26.99 سنويًا) هذا الحد. تعمل الإضافة مع المحادثات العادية والمشاريع (Projects) وجلسات Cowork وجلسات Claude Code على الويب (claude.ai/code). التفاصيل في صفحة كيف تعمل الإضافة. لا تصدّر الإضافة جلسات الطرفية في Claude Code.

بيانات الإضافة في Chrome Web Store (يجب إبقاؤها متطابقة)

استخدم هذا النص في Chrome Web Store حتى يطابق مقتطف المتجر طريقة بحث المستخدمين:

  • الاسم (75 حرفًا كحد أقصى): Claude Chat Downloader
  • الوصف المختصر (132 حرفًا كحد أقصى): Free Chrome extension to save claude.ai chats as PDF, Markdown, text, JSON, XML, CSV or PNG — one chat or bulk Export All.
