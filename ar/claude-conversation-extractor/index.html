هل يمكنني استخراج محادثة Claude دون تثبيت أي شيء؟

فقط بالنسخ واللصق، وهو يُفقدك الكتل المسوّرة والجداول، أو عبر Export data من Anthropic، وهو ملف ZIP للحساب. أما أداة استخراج منظمة لمحادثات Claude فتحتاج إلى قراءة الصفحة؛ وهذا ما تفعله إضافة Chrome.

هل تدعم أداة الاستخراج استخراج المحادثات دفعةً واحدة؟

نعم. افتح View and Download All Conversations من النافذة المنبثقة للإضافة، ثم Export All للحصول على ملف ZIP. يطلب التصدير الجماعي تسجيل الدخول عبر Google؛ وفي الخطة المجانية تُحتسب كل محادثة من 3 عمليات يوميًا، يتقاسمها مع PDF. ويرفع Pro بسعر $3.99 شهريًا أو $26.99 سنويًا هذا الحد. عوامل التصفية: All conversations وNew وUpdated وPreviously exported.

هل استخدام أداة استخراج محادثات Claude آمن؟

تقرأ هذه الأداة جلسة claude.ai المسجّلة الدخول وتنشئ الملفات محليًا. لا يُرسَل نص المحادثة إلى خوادمنا. نحن لسنا Anthropic، وتبقى خاضعًا لشروط الخدمة لديهم.

هل أحتاج إلى Claude Pro لاستخراج محادثة؟

لا. تعمل أي خطة في claude.ai تتيح فتح المحادثة في Chrome. ومن جهتنا، عمليات الاستخراج بصيغ Markdown والنص وJSON وXML وCSV وPNG مجانية وغير محدودة وبلا حساب؛ أما PDF والتصدير الجماعي فمجانيان حتى 3 مرات يوميًا. وخطة Anthropic المدفوعة لا علاقة لها بحدودنا.

هل تعمل أداة استخراج محادثات Claude في Desktop؟

لا. لا يحصل Claude Desktop على الزر البرتقالي أبدًا. افتح المحادثة نفسها على claude.ai إذا كانت متزامنة، أو انسخها والصقها، أو استخدم ملف ZIP الرسمي. تعمل أداة الاستخراج في Chrome فقط وعلى claude.ai.

هل يمكن لأداة استخراج محادثات Claude كتابة PDF؟

نعم. اختر PDF في لوحة التصدير وانقر على «Export». يُنشأ ملف PDF داخل المتصفح، بلا نافذة طباعة. يطلب تسجيل الدخول عبر Google، وهو مجاني حتى 3 مرات يوميًا؛ ويجعله Pro غير محدود.

هل يعمل استخراج محادثة Claude في Claude Code؟

على الويب فقط. تُفتح جلسات Claude Code على claude.ai/code داخل claude.ai وتُستخرج مثل أي محادثة. أما Claude Code داخل الطرفية فيستخدم الأمر /export أو ملفات JSONL على القرص؛ وأداة استخراج محادثات Claude هذه سكربت محتوى في Chrome لـ claude.ai، لا ربطًا بالطرفية.

كم عملية استخراج مجانية تتيحها الأداة؟

غير محدودة بصيغ Markdown والنص وJSON وXML وCSV وPNG، بلا حساب. أما PDF والتصدير الجماعي عبر Export All فيتقاسمان 3 عمليات يوميًا لكل حساب مسجّل عبر Google في الخطة المجانية، ويُعاد ضبطها عند منتصف الليل بتوقيت UTC. ويرفع Pro الحد ويُستعاد من حساب Google نفسه عبر فوترة Paddle.

ما الذي تتجاهله أداة استخراج محادثات Claude؟

إطار واجهة الصفحة، ومربع كتابة الرسائل، وأي شيء لم يُعرض في المحادثة. كما تتجاهل المحادثات التي لم تُحمَّل قط في Chrome. والمحادثات الموجودة في Claude Desktop فقط وملفات JSONL المحلية الخاصة بـ Claude Code خارج نطاقها.
