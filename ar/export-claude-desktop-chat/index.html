هل Claude Desktop هو نفسه Claude Code؟

لا. إذا كنت تقصد بكلمة «سطح المكتب» VS Code أو طرفية على جهازك، فاتبع تصدير Claude Code. وإذا كنت تقصد تطبيق المحادثة Claude Desktop من Anthropic، فابقَ في هذه الصفحة. الخلط بين الاثنين يضيع الوقت: ملفات JSONL على القرص ليست زرًا برتقاليًا، والنسخ واللصق من Desktop ليس /export.

لن تضيف Download Claude conversations ارتباطًا بـCode لمجرد أن Desktop وCode كلاهما «ليس المتصفح». المنتج ضيق النطاق عمدًا: claude.ai في Chrome، وسبع صيغ، وتصدير غير محدود بلا حساب باستثناء PDF والتصدير الجماعي بملف ZIP (3 مرات يوميًا مجانًا)، واشتراك Pro بسعر $3.99 شهريًا أو $26.99 سنويًا. نطاق الميزات: الميزات. وصياغة «الاستخراج» لزر الويب: أداة استخراج محادثات Claude.

لا نوفر إضافة لتطبيق Claude Desktop، ولا تطبيقًا في شريط القوائم، ولا خيار «تصدير من Desktop». لا نقرأ ملفات من تثبيت Claude Desktop على Mac أو Windows. ولا نحل محل /export في Claude Code. هذه الجمل هي حدود المنتج فيما يخص تصدير محادثة Claude Desktop في الإصدار 1.16.2.

ولا نذكر أيضًا أسماء أدوات تصدير أخرى لـChrome. نذكر هنا واجهات Anthropic الرسمية — claude.ai وClaude Desktop وClaude Code وSettings → Privacy → Export data — على سبيل المقارنة. وتبقى Download Claude conversations إضافة مستقلة، غير تابعة لشركة Anthropic, PBC. وكل ما تقوله هذه الصفحة عن الإضافة يخص إضافة الويب، لا منتجًا لتطبيق Desktop غير موجود.

إذا كنت تعمل في Desktop فقط، فاستخدم النسخ واللصق وملف ZIP الرسمي إلى أن توفر Anthropic تصديرًا لكل محادثة كملف داخل التطبيق. وإذا كنت تستخدم claude.ai أيضًا، فثبّت الإضافة وصدّر من المتصفح. هذا هو العرض الصادق بالكامل. وتطبيقات Claude للهاتف خارج نطاق هذه الإضافة كذلك.
