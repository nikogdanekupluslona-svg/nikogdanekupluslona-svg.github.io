ماذا يعني «تصدير محادثة Claude» على هذا الموقع؟

هل إضافة تصدير Claude هي نفسها Export data؟

لا. ‏Settings → Privacy → Export data ملف ZIP بصيغة JSON للحساب كله يصل بالبريد. أما إضافة التصدير فتكتب المحادثة المفتوحة بصيغة PDF أو Markdown أو JSON أو النص أو XML أو CSV أو PNG، أو ما حددته عبر Export All كملف ZIP، فورًا في Chrome.

هل يمكنني تصدير محادثة Claude بصيغة PDF؟

نعم. اختر PDF من قائمة الصيغ وانقر على «Export». تُنشئ إضافة التصدير ملف PDF داخل المتصفح، بلا نافذة طباعة. يطلب PDF تسجيل الدخول عبر Google، وهو مجاني حتى 3 مرات يوميًا؛ ويجعله Pro غير محدود. الدليل: تنزيل محادثة Claude بصيغة PDF.

هل أحتاج إلى Pro لتصدير محادثة Claude مرة واحدة؟

لا. عمليات التصدير بصيغ Markdown والنص وJSON وXML وCSV وPNG مجانية وغير محدودة، بلا حساب. أما PDF والتصدير الجماعي عبر Export All فمجانيان حتى 3 مرات يوميًا مع تسجيل الدخول عبر Google. ويرفع Pro بسعر $3.99 شهريًا أو $26.99 سنويًا هذا الحد.

هل يعمل تصدير محادثة Claude مع أي خطة في claude.ai؟

نعم. تعمل خطط Free وPro وTeam وEnterprise في claude.ai ما دمت تستطيع فتح المحادثة في Chrome. لا تتطلب إضافة التصدير خطة Anthropic المدفوعة.

هل إضافة تصدير Claude هذه مخصصة لـ Claude Code؟

فقط لـ Claude Code على الويب. تُفتح الجلسات على claude.ai/code داخل claude.ai وتُصدَّر مثل أي محادثة. أما Claude Code داخل الطرفية فيستخدم /export أو ملفات JSONL على القرص، ولا تقرأ Download Claude conversations تلك الملفات. راجع دليل تصدير Claude Code.

هل يمكنني تصدير محادثة Claude من Claude Desktop؟

ليس بإضافة Chrome هذه. افتح المحادثة نفسها على claude.ai إذا كانت متزامنة، أو انسخها والصقها، أو استخدم Export data الرسمي. لا يُظهر Desktop الزر البرتقالي أبدًا.

كم عملية تصدير مجانية تمنحها إضافة تصدير Claude؟

غير محدودة لصيغ Markdown والنص وJSON وXML وCSV وPNG، بلا حساب. أما PDF والتصدير الجماعي عبر Export All فيتقاسمان 3 عمليات يوميًا في الخطة المجانية، مع تسجيل الدخول عبر Google؛ وكل محادثة داخل ملف ZIP جماعي تُحتسب واحدة. يُعاد ضبط العدد عند منتصف الليل بتوقيت UTC. ويرفع Pro الحد ويُستعاد عبر تسجيل الدخول بحساب Google.

أين الزر البرتقالي لتصدير محادثة Claude؟

هل يرفع تصدير محادثة Claude محادثاتي إلى الخادم؟

لا. كل الصيغ، بما فيها PDF، تُنشأ داخل المتصفح وتُسلَّم إلى واجهة التنزيل في Chrome. عمليات التصدير بصيغ Markdown والنص وJSON وXML وCSV وPNG لا ترسل إلينا أي شيء. وبعد تسجيل الدخول لـ PDF أو التصدير الجماعي أو Pro، يرى خادمنا المصغّر حالة الحصة أو الاشتراك وبريدك في Google، ولا يرى نصوص المحادثات أبدًا. التفاصيل في صفحة طريقة العمل.
