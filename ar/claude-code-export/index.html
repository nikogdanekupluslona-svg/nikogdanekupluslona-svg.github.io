ما هو تصدير Claude Code في الطرفية؟

تصدير Claude Code هو الأمر /export داخل جلسة تفاعلية في واجهة سطر الأوامر. يصف توثيق Anthropic قائمة تتيح نسخ المحادثة الحالية أو حفظها في ملف نصي عادي، مع عرض الرسائل ومخرجات الأدوات كنص مقروء. وإذا مرّرت اسم ملف، تتخطى القائمة ويُكتب ذلك الملف مباشرة.

هذا ليس Markdown من claude.ai، ولا JSON من إضافة Chrome هذه، ولا ملف PDF. إنه نص منسّق للجلسة ليقرأه إنسان. وتقول Anthropic إن سجل JSONL المحفوظ على القرص صيغة داخلية مختلفة مخصصة للمنتج نفسه، وليست واجهة برمجية عامة لك.

/export

لتخطي السؤال وكتابة ملف باسم محدد في مجلد العمل الحالي:

/export my-session

توثيق الجلسات لدى Anthropic هو المرجع الموثوق للخيارات وأسماء الملفات، فهي تتغير بين إصدارات Claude Code. اعتبر المدونات المجتمعية مصدرًا ثانويًا. وإذا لم يطابق نص مربع حوار /export ما تراه، فواجهة سطر الأوامر لديك إصدار مختلف — استخدم المساعدة داخل المنتج، لا لقطة شاشة من 2025.

للسكربتات، تشير Anthropic إلى واجهات أخرى: claude -p مع --output-format json أو stream-json، أو الاستئناف بمعرّف الجلسة، أو الخطافات (hooks) التي تستقبل transcript_path، أو Agent SDK. هذه واجهات للمطورين في Claude Code، وليست إضافة Chrome التي يقدمها هذا الموقع.

مقروء أم منظَّم؟ /export هو النص المخصص للبشر. وملفات JSONL في مجلد projects هي السجل. أما JSON الذي تنتجه إضافة Chrome فهو شكل ثالث، يُبنى فقط من صفحة على claude.ai. لا تكتب أداة تحليل واحدة للأشكال الثلاثة.

كيف أنزّل محادثة Claude Code من القرص؟

لتنزيل محادثة Claude Code من القرص: انسخ ملف JSONL الخاص بالجلسة من مجلد projects، أو شغّل /export للحصول على نص مقروء. المسار الافتراضي على macOS وLinux داخل ~/.claude/projects/، وعلى Windows هو %USERPROFILE%\.claude\projects. أسماء الملفات هي معرّفات الجلسات.

اسم مجلد المشروع هو مسار مجلد العمل بعد استبدال كل الأحرف غير الأبجدية الرقمية بشَرطات. وتختصر Anthropic الأسماء الطويلة جدًا وتضيف إليها قيمة تجزئة (hash) كي يبقى اسم المجلد ضمن حدود نظام الملفات. إذا لم تجد المجلد، فأنت شغّلت Claude Code من مجلد عمل غير الذي تظنه.

كل سطر في JSONL كائن JSON يمثل رسالة أو استخدام أداة أو بيانات وصفية. وتوضح Anthropic أن صيغة هذه الإدخالات داخلية وتتغير بين الإصدارات، لذا قد تتعطل السكربتات التي تحلل هذه الملفات مع أي إصدار جديد من Claude Code. فضّل /export أو واجهات السكربتات الموثقة إذا احتجت شيئًا مستقرًا.

مكان التخزين قابل للتغيير. CLAUDE_CONFIG_DIR ينقل مجلد الإعدادات بعيدًا عن ~/.claude. وCLAUDE_CODE_PROJECT_DIR_NAME يحدد اسم مجلد المشروع عند استخدامه مع ذلك المجلد (في Claude Code v2.1.234 أو أحدث، بحسب Anthropic). ويغيّر cleanupPeriodDays في settings.json مدة الاحتفاظ الافتراضية. لا شيء من هذه الإعدادات من ميزات Download Claude conversations.

إذن، لتنزيل ملفات محادثات Claude Code كنسخة احتياطية: انسخ المجلد، أو صدّر النصوص بالأمر /export بشكل دوري. لن يضيف هذا الموقع زرًا لـ«استيراد JSONL»، ونحن لا نقرأ مجلدك الشخصي.

هل يعمل تصدير Claude Code مع هذه الإضافة؟

لا. تصدير محادثة Claude Code لا يعمل مع Download Claude conversations. فإضافة Chrome تُحقن داخل claude.ai، ولا ترى الطرفية، ولا تستطيع تشغيل /export، ولا فتح ملفات JSONL. إذا كنت تبحث عن طريقة لتنزيل محادثة Claude Code، فالتزم بخطوات سطر الأوامر في هذه الصفحة.

يصل الناس إلى هنا لأن Google يجمع بين «Claude» و«export» في نتائج واحدة. لكن صفحة الإضافة في المتجر تخص claude.ai فقط. وتثبيت الإضافة لن يضع زرًا برتقاليًا في iTerm أو Ghostty أو طرفية VS Code أو غلاف Claude Code لسطح المكتب.

وإذا كنت تحتفظ أيضًا بمحادثة موازية على claude.ai للمهمة البرمجية نفسها، فيمكن حفظ تلك المحادثة بالإضافة. لكن السجلين لا يُدمجان. واستدعاءات الأدوات التي جرت في سطر الأوامر فقط لن تظهر في تصدير الويب ما لم تكن قد لصقتها هناك.

أين يخزّن Claude Code سجل المحادثات؟

يخزّن Claude Code سجل المحادثات كنصوص JSONL داخل مجلد projects في مجلد الإعدادات. المسار الافتراضي على macOS وLinux: ~/.claude/projects/<encoded-cwd>/<session-id>.jsonl، وعلى Windows: %USERPROFILE%\.claude\projects. قد تغيّر Anthropic هذا الهيكل؛ راجع توثيق الجلسات الحالي إذا لم تجد مسارًا ما على القرص.

الاستئناف فعل مختلف عن التصدير. claude --continue وclaude --resume يعيدان تحميل الجلسة لتواصل العمل. أما /export فيكتب نسخة يمكنك تركها في git أو إرسالها بالبريد. الأول يستعيد السياق، والثاني يمنحك سجلًا تحمله معك. تغطي صفحة الجلسات لدى Anthropic وضع الأذونات عند الاستئناف، والضغط/التلخيص، وسلوك أداة الاختيار — ولا شيء من ذلك يخص هذه الإضافة.

بحسب Anthropic، يحتفظ كل من تطبيق سطح المكتب وClaude Code على الويب وإضافة VS Code بسجل جلسات خاص به. المسارات في هذا الدليل تخص واجهة سطر الأوامر. لا تفترض أن نص جلسة Cowork في تطبيق سطح المكتب موجود في شجرة JSONL نفسها التي تستخدمها من الطرفية.

لا تعامل JSONL كبنية عامة. تقول Anthropic إن صيغة الأسطر تتغير. وإذا حللتها على أي حال، فثبّت إصدار Claude Code وتوقّع الأعطال. /export هو الطريقة المستقرة للحصول على محادثة Claude Code مقروءة.

متغيرات بيئة مثل CLAUDE_CODE_SKIP_PROMPT_HISTORY قد تمنع كتابة النصوص. إذا كان مجلد projects فارغًا، فتحقق مما إذا كنت قد عطّلت الحفظ، أو وجّهت CLAUDE_CONFIG_DIR إلى مكان آخر، أو لم تشغّل أي جلسة تفاعلية في ذلك المجلد أصلًا.

كيف أنزّل محادثة Claude من claude.ai بدلًا من ذلك؟

لتنزيل محادثة Claude من claude.ai: ثبّت Download Claude conversations، وافتح المحادثة في Chrome، وانقر الزر البرتقالي بجوار مربع الرسائل، ثم اختر Markdown أو JSON أو نص عادي أو XML أو PNG. هذا هو منتج المتصفح، وهو ليس تصدير Claude Code. الخطوات بالتفصيل: كيف تنزّل محادثة Claude.

لتنزيل سجل claude.ai كاملًا كملفات منفصلة تستخدم «Export All» (تصدير الكل) في صفحة التصفح، لا /export. كل ملف يُحتسب من عمليات التصدير المجانية الثلاث ما لم تكن مشتركًا في Pro. الدليل: التصدير الجماعي Export All. الصيغ: الصيغ.

إذا بدأ عملك في Claude Code ثم لصقت ملخصًا في claude.ai، فنزّل محادثة الويب كملاحظات، واحتفظ بـ/export للسجل الحقيقي من سطر الأوامر. ملفان واضحان أفضل من ملف واحد مشوّش.

تصدير Claude Code أم خيار Export data الرسمي من Anthropic؟

تصدير Claude Code (/export أو JSONL) يخص جلسة طرفية واحدة. أما Export data الرسمي فهو Settings → Privacy → Export data على claude.ai (قد تظهر التسميات مترجمة إذا كانت لغة claude.ai مضبوطة على العربية): ملف ZIP بصيغة JSON لحساب Anthropic يصل بعد تأخير. ليسا الأرشيف نفسه، وملف ZIP لن يغني عن /export.

ظهور جلسة معينة من Claude Code في ملف ZIP الخاص بالحساب يعتمد على طريقة تخزين Anthropic لذلك المنتج، لا على هذه الإضافة. اعتبر ملف ZIP نسخة احتياطية لحساب الويب ما لم يذكر توثيق الخصوصية الحالي لدى Anthropic غير ذلك. نحن لا نضيف جلسات سطر الأوامر إلى ذلك الملف.

كيفية تصدير محادثة Claude من الموقع، بما في ذلك المقارنة بين ملف ZIP والإضافة، موثّقة هنا: كيف تصدّر محادثة Claude. الطباعة إلى PDF تخص صفحات الويب ولا تنطبق على واجهة الطرفية. راجع الطباعة / PDF فقط عندما تكون المحادثة في المتصفح.

التصدير من Claude Code أم Desktop أم claude.ai؟

Claude Code وClaude Desktop وclaude.ai ثلاث واجهات مختلفة. تصدير Claude Code يتم بـ/export وJSONL. وDesktop تطبيق لا يحتوي على الزر البرتقالي الخاص بهذه الإضافة. أما claude.ai في Chrome فهو المكان الوحيد الذي تعمل فيه Download Claude conversations. الخلط بين هذه الأسماء هو ما يجعل عمليات التصدير تفشل دون أن تلاحظ.

Claude Desktop: إذا كانت المحادثة متزامنة مع حساب Anthropic نفسه، فافتحها على claude.ai وصدّرها من هناك. وإذا كانت موجودة في نافذة Desktop فقط، فانسخها والصقها أو انتظر Export data الرسمي. الدليل: تصدير محادثة Claude Desktop.

لوحة Claude Code في VS Code أقرب إلى واجهة سطر الأوامر منها إلى claude.ai. لا تتوقع أن يُحقن سكربت المحتوى الخاص بنا في ذلك العرض. استخدم /export من الجلسة التي تحتوي فعلًا على الرسائل.

إضافة Chrome مستقلة، غير تابعة لشركة Anthropic, PBC. ‏Claude علامة تجارية لـAnthropic. التزم بشروط الخدمة الخاصة بها. لا يمكننا تقديم استشارة قانونية بشأن نسخ مخرجات أدوات تتضمن شيفرة مملوكة؛ فهذا شأن بينك وبين جهة عملك وAnthropic.

الأسئلة الشائعة: تصدير Claude Code

كيف أصدّر محادثة Claude Code؟

في طرفية Claude Code اكتب /export (مع اسم ملف اختياريًا) لحفظ نص منسّق للجلسة، أو انسخ ملف JSONL من ~/.claude/projects على macOS وLinux، أو من %USERPROFILE%\.claude\projects على Windows. توثيق الجلسات لدى Anthropic يشرح مربع الحوار الحالي.

هل تنزّل إضافة Chrome هذه محادثات Claude Code؟

لا. تعمل Download Claude conversations على claude.ai في Chrome فقط. لا تستطيع قراءة جلسات الطرفية ولا نصوص JSONL ولا تنفيذ الأمر /export. تصدير Claude Code يبقى داخل واجهة سطر الأوامر.

أين يخزّن Claude Code سجل المحادثات؟

نصوص الجلسات ملفات JSONL داخل ~/.claude/projects/<encoded-working-directory>/، وتحمل أسماؤها معرّف الجلسة. قد يتغير هذا الهيكل. استخدم /export إذا أردت ملفًا مقروءًا بدل تحليل JSONL. ويمكن للمتغير CLAUDE_CONFIG_DIR نقل المجلد بالكامل.

كيف أنزّل محادثة Claude Code بصيغة Markdown؟

الأمر /export في Claude Code ينتج نصًا عاديًا، لا ملف Markdown كالذي تنتجه هذه الإضافة. إذا احتجت Markdown تحديدًا فصدّر نسخة العمل الموجودة على claude.ai باستخدام Download Claude conversations، أو حوّل نص /export بنفسك. نحن لا نحوّل JSONL إلى Markdown.

كيف أنزّل محادثة من Claude.ai بدلًا من ذلك؟

ثبّت إضافة Chrome المجانية، وافتح المحادثة على claude.ai، واستخدم الزر البرتقالي — أو «Export All» (تصدير الكل) للسجل الكامل. راجع كيف تنزّل محادثة Claude. تحصل على 3 عمليات تصدير مجانية، واشتراك Pro بسعر $3.99 شهريًا أو $26.99 سنويًا.

هل /export هو نفسه خيار Export data الرسمي؟

لا. /export يخص جلسة Claude Code الحالية. أما Settings → Privacy → Export data فيرسل إليك بالبريد ملف ZIP بصيغة JSON لحساب Anthropic كله. منتجان مختلفان، وملفات مختلفة، وأوقات انتظار مختلفة.

هل يمكنني تحليل ملفات JSONL الخاصة بـClaude Code باستخدام jq؟

نعم، مع التحفظ الذي تنشره Anthropic: بنية الأسطر داخلية وقابلة للتغيير. فضّل /export أو claude -p --output-format json إذا احتجت صيغة ثابتة. وإذا حلّلت JSONL على أي حال، فثبّت إصدار واجهة سطر الأوامر.

هل يعمل تصدير Claude Code على Windows؟

نعم. /export أمر في واجهة سطر الأوامر. تُحفظ النصوص على القرص داخل %USERPROFILE%\.claude\projects ما لم تضبط CLAUDE_CONFIG_DIR. ومع ذلك لا تعمل إضافة Chrome هذه داخل تلك الطرفية.

هل Claude Code هو نفسه Claude Desktop؟

لا. Claude Code وكيل برمجة يعمل في الطرفية. Claude Desktop تطبيق للمحادثة. claude.ai هو الموقع. والموقع وحده يعمل مع هذه الإضافة. ملاحظات تصدير تطبيق سطح المكتب: Claude Desktop.

هل ستدعم هذه الإضافة الأمر /export يومًا ما؟

ليس في الإصدار 1.13.0. نطاق المنتج هو claude.ai: خمس صيغ، وملفات محلية، وتسجيل دخول Google لاحتساب الحصة. إذا تغيّر هذا النطاق فستذكر هذه الصفحة ذلك. وحتى ذلك الحين استخدم واجهة سطر الأوامر من Anthropic لتصدير Claude Code.

هل يتضمن /export مخرجات الأدوات؟

تصف Anthropic الأمر /export بأنه يعرض الرسائل ومخرجات الأدوات كنص مقروء. هذا نصّها هي، لا نتاج أداة تحليل لدينا. لمعرفة المحتوى الحالي بدقة، شغّل /export على إصدارك واقرأ الملف — فالتوثيق قد يتأخر عن الإصدارات.

هل يمكنني تصدير جلسات Claude Code دفعة واحدة؟

ليس عبر «Export All» في هذه الإضافة. التصدير الجماعي في صفحة التصفح لدينا خاص بـclaude.ai فقط. لعدد كبير من جلسات سطر الأوامر، انسخ مجلد projects أو شغّل /export لكل جلسة. لا يوجد تصدير جماعي بالزر البرتقالي لملفات JSONL.
