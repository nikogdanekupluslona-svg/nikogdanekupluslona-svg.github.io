أي صيغة أختار للتصدير الجماعي؟

اختر صيغة واحدة لكل تشغيل لـ«Export All». ‏Markdown لخزائن الملاحظات، وJSON لخطوط المعالجة، والنص العادي لأرشيف خالٍ من التنسيق، وXML لتبادل البيانات، وPNG للصور. تنزيل محادثات Claude كلها يستخدم الصيغ الخمس نفسها التي يستخدمها الزر البرتقالي. الصفحة الرئيسية للصيغ: الصيغ. لا يوجد PDF في الإصدار 1.13.0.

الكتّاب يصدّرون عادةً بصيغة Markdown — دليل Markdown. والمطورون يصدّرون عادةً بصيغة JSON — دليل JSON. ‏XML: XML. ‏PNG: PNG. وملفات JSON من «Export All» تبقى ملفات لكل محادثة مأخوذة من الصفحة، لا بنية ملف ZIP الخاص بحساب Anthropic. لا تخلط هاتين البنيتين في سكربت واحد.

اختيار الصيغة لا يغيّر السعر. التصدير الجماعي بصيغة PNG يستهلك عملية تصدير لكل صورة. والتحويل من Markdown إلى JSON في تشغيل ثانٍ يستهلك عملية تصدير ثانية لكل محادثة. استخدم مرشّح «Exported» لتجنب التكرار. صياغة «الاستخراج» للملفات نفسها: أداة استخراج محادثات Claude. والتصدير الفردي كمنتج: تصدير محادثة Claude.

لا نذكر أسماء أدوات تصدير أخرى. نذكر Export data الرسمي من Anthropic للمقارنة بوصفه ملف ZIP الاحتياطي. وDownload Claude conversations (المعروفة أيضًا باسم Claude Chat Downloader أو Claude Conversation Downloader) هي مسار التصدير الجماعي في Chrome. إضافة مستقلة، غير تابعة لشركة Anthropic, PBC. تقييمها 5.0 في Chrome Web Store.
