ما خطوات تصدير محادثة Claude إلى PDF؟

  1. ثبّت Download Claude conversations من Chrome Web Store، ثم أعد تحميل أي علامة تبويب مفتوحة لـclaude.ai.
  2. افتح المحادثة على claude.ai وانتظر حتى يكتمل ظهور الرد الأخير.
  3. انقر زر التنزيل البرتقالي الدائري بجوار مربع الرسائل. تُفتح لوحة التصدير.
  4. في «Format» (الصيغة)، اختر PDF. أبقِ «Messages» (الرسائل) على «All» (الكل)، أو اختر «Human» (المستخدم) أو «Assistant» (المساعد) للإبقاء على طرف واحد من المحادثة.

حد PDF في الخطة المجانية. يطلب تصدير PDF تسجيل الدخول عبر Google، وهو مجاني حتى 3 مرات يوميًا، مشتركة مع التصدير الجماعي بملف ZIP؛ ويُعاد ضبط العدّاد عند منتصف الليل بتوقيت UTC. واشتراك Pro — بسعر $3.99 شهريًا أو $26.99 سنويًا — يجعل PDF بلا حدود. وتبقى صيغ Markdown والنص العادي وJSON وXML وCSV وPNG غير محدودة وبلا حساب.

كيف تحفظ محادثة Claude بصيغة PDF دون إضافة؟

لحفظ محادثة Claude بصيغة PDF دون تثبيت أي شيء، استخدم نافذة الطباعة في Chrome: افتح المحادثة، واضغط Ctrl+P على Windows أو Cmd+P على Mac، واضبط الوجهة على «Save as PDF» (حفظ بتنسيق PDF)، ثم احفظ. الملف لقطة من صفحة الويب، لا مستند مُصدَّر، وليس فيه أي إعدادات خاصة بـClaude.

  1. افتح المحادثة على claude.ai ومرّر إلى أول رسالة تمامًا كي تُحمَّل كل الأدوار.
  2. اطوِ الشريط الجانبي وأغلق لوحات المخرجات (artifacts) التي لا تريدها على الورق.
  3. اضغط Ctrl+P أو Cmd+P. وتحت «Destination» (الوجهة) اختر «Save as PDF».
  4. افتح «More settings» (المزيد من الإعدادات)، واختر حجم الورق والهوامش، وفعّل «Background graphics» (رسومات الخلفية) إذا بدت الصفحة باهتة.
  5. انقر «Save» (حفظ).

تختم صفحة Chrome Help من Google الإجراء نفسه بسطر واحد: «انقر Save as PDF.» وهذا كل ما تستطيعه الطباعة. فهي لا تضيف أرقام صفحات لكل رسالة، ولا جدول محتويات، ولا وضعًا داكنًا.

ما يظهر في كل صفحة تحدده أنماط الطباعة في claude.ai، لا أنت. تصف MDN وسائط CSS المقسّمة إلى صفحات (paged media) بأنها القواعد التي تحدد «كيفية إنشاء الصفحات وتخطيطها لاحتواء المحتوى المجزّأ في عرض مقسّم إلى صفحات». وحين تقسم هذه القواعد كتلة شيفرة، يحتفظ ملف PDF بهذا الانقسام.

حمّل المحادثة كاملة أولًا. محادثات Claude الطويلة لا تحمّل الرسائل الأقدم إلا حين تمرّر إلى الأعلى. والطباعة أو التصدير قبل ذلك يعطيك ملف PDF تنقصه البداية. مرّر إلى الأعلى، وانتظر ثانية، ثم اطبع أو صدّر.

الطباعة مناسبة لنسخة سريعة لمرة واحدة. ولمقارنة مفصّلة بين الطباعة وملف PDF حقيقي، بما في ذلك الهواتف، راجع حفظ محادثة Claude بصيغة PDF.

كيف تحصل على محادثة Claude في ملف PDF واحد؟

نقرة «Export» واحدة تعطيك ملف PDF واحدًا يضم محادثة Claude كلها، من أول رسالة إلى آخر إجابة. لا يمكنك نسخ محادثة Claude كملف PDF إلى الحافظة — فزر «Copy» (نسخ) يعمل مع Markdown والنص العادي وJSON وXML وCSV — لكن الملف المُصدَّر هو أصلًا ملف PDF واحد.

لوضع جزء فقط من المحادثة في ملف PDF واحد، استخدم «Select» (تحديد). انقر «Select» في لوحة التصدير، وحدد الرسائل التي تريدها، واختر PDF، ثم انقر «Export». يحتوي ملف PDF على تلك الرسائل فقط، بترتيبها. ويفعل مرشّح «Messages» الشيء نفسه لطرف واحد: «Assistant» يُبقي إجابات Claude فقط، و«Human» يُبقي رسائلك فقط.

لا تُدمج محادثات متعددة في ملف PDF واحد أبدًا. فالتصدير الجماعي يكتب ملف PDF لكل محادثة داخل ملف ZIP. وإذا احتجت إلى مستند واحد مجمّع، فصدّر المحادثات وادمج ملفات PDF في أي محرر PDF، أو صدّر بصيغة Markdown والصق المحادثات في ملف واحد قبل تحويله.

كيف تحوّل محادثة Claude إلى PDF عبر Markdown؟

حوّل محادثة Claude إلى PDF عبر Markdown حين تريد تحرير النص أولًا. صدّر المحادثة بصيغة Markdown — بلا حدود وبلا حساب — وافتح ملف .md في محرر مثل VS Code أو Obsidian أو Typora، وعدّله، ثم استخدم أمر الطباعة أو التصدير إلى PDF في ذلك المحرر.

  1. على claude.ai، انقر الزر البرتقالي، واختر Markdown، ثم انقر «Export». لا تسجيل دخول ولا عدّاد.
  2. افتح الملف في محررك. احذف ما لا تحتاجه من رسائل، وأصلح العناوين، وأضف ملاحظاتك الخاصة.
  3. استخدم أمر Export as PDF في المحرر أو Print ← Save as PDF، بقالبك وخطوطك الخاصة.

يصلح Markdown كخطوة وسيطة لأنه يبقى مقروءًا كنص عادي. كتب John Gruber، مبتكر Markdown: «صُمّم Markdown ليكون سهل القراءة وسهل الكتابة إلى أقصى حد ممكن.» يمكنك تحرير محادثة Claude بصيغة Markdown دون صراع مع الوسوم، ثم تنضيدها مرة واحدة.

الثمن هو أداتان بدل أداة واحدة. وإذا لم تكن بحاجة إلى تعديلات، فملف PDF من الإضافة نفسها أسرع، وفيه أصلًا أرقام الصفحات وجدول المحتويات. كما أن Markdown لا يمس أبدًا الحد اليومي لملفات PDF، وهذا مفيد في الخطة المجانية. المزيد عن الصيغة: التصدير بصيغة Markdown.

تصدير الحساب الرسمي من Anthropic نقطة بداية سيئة للتحويل. فهو ملف ZIP بصيغة JSON للحساب كله، لذا عليك أولًا استخراج محادثة واحدة وتحويل JSON إلى نص مقروء. أما تصدير Markdown من المحادثة المفتوحة فيختصر كل ذلك.

هل يمكن تصدير محادثات Claude كثيرة إلى PDF دفعة واحدة؟

نعم. تصدّر لوحة التحكم (Dashboard) في الإضافة محادثات Claude كثيرة إلى PDF في عملية واحدة: اضبط «Chat format» (صيغة المحادثة) على PDF، وحدد المحادثات، ثم انقر «Export All» (تصدير الكل). تحصل على ملف ZIP واحد فيه ملف PDF لكل محادثة. وفي الخطة المجانية تُحتسب كل محادثة داخل ملف ZIP ضمن عمليات التصدير اليومية الثلاث.

  1. انقر أيقونة الإضافة في Chrome واختر «View and Download All Conversations» (عرض كل المحادثات وتنزيلها).
  2. رشّح القائمة أو ابحث فيها، ثم حدد المحادثات التي تحتاجها.
  3. اضبط «Chat format» على PDF. واختر ما إذا كنت ستضمّن التفكير والبيانات الوصفية والأدوات والمصادر.
  4. انقر «Export All» واحفظ ملف ZIP.

إذا حددت محادثات أكثر مما تبقى من الحصة المجانية اليوم، فستُحظر الدفعة كلها ولن تُصدَّر جزئيًا؛ حدد محادثات أقل أو رقِّ اشتراكك. ويلغي Pro الحد لكل من PDF والتصدير الجماعي. وسير عمل التصدير الجماعي الكامل، مع المرشّحات وخيارات المخرجات (artifacts)، موجود في دليل التصدير الجماعي.

احتفظ بملفات PDF اليومية لما يهم. لأرشيف كبير، صدّر أولًا بصيغة Markdown أو JSON دفعة واحدة — فكلتاهما بلا حدود — ثم صدّر إلى PDF فقط المحادثات التي سترسلها أو تطبعها فعلًا.
