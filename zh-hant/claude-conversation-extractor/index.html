什麼是 Claude 對話擷取工具？

Claude 對話擷取工具會解析 claude.ai 上已顯示的對話，寫出真正的檔案。Download Claude conversations 就是這樣的 Chrome 工具：它不是截圖工具，也不是 Anthropic 的帳號 ZIP。不管搜尋「擷取」、「匯出」還是「下載」，找到的都是 claude.ai 上同一個橘色按鈕。

開發者和研究人員常搜尋 Claude 對話擷取工具，因為「擷取」意味著結構：發話者、內容區塊、程式碼區塊、表格、artifact。Download Claude conversations 就在你已開啟的分頁中完成這個解析。評論者可能會說 Claude Conversation Downloader 或 Claude Exporter；這些名稱指的仍是這個 Chrome 商店頁面，也就是 Chrome Web Store 上的 Download Claude conversations 1.16.2。

這個擷取工具不是 Claude Desktop 外掛，也不是 Claude Code CLI。如果你要的是終端機紀錄，請用 /export，指南：Claude Code 匯出。如果你要的是 Mac／Windows 應用程式，請看匯出 Claude Desktop 聊天。Claude Code on the web（claude.ai/code）和 Cowork 工作階段可以擷取，因為它們在 claude.ai 上開啟。本頁只談 Chrome 中的 claude.ai。

同一個按鈕，不同的動詞。擷取 Claude 聊天、匯出 Claude 聊天、下載 Claude 聊天，最後都會用到 Download Claude conversations。以產品角度介紹匯出的文章是匯出 Claude 聊天。本指南專注在擷取工具會讀取什麼、捨棄什麼。

如何在 claude.ai 上擷取 Claude 聊天？

安裝 Download Claude conversations，在 claude.ai 開啟對話網址，點訊息輸入框旁的橘色按鈕，選格式，再按「Export」。Claude 對話擷取工具會透過 Chrome 的下載 API 在本機寫出檔案。Markdown、文字、JSON、XML、CSV 或 PNG 不需要帳號；只有 PDF 和批次匯出才會出現 Google 登入。

  1. 加入 Chrome 商店頁面上的擴充功能（Download Claude conversations，截至 2026 年 9 月為 1.16.2 版）。
  2. 重新載入 claude.ai 並開啟對話：擷取工具需要對話網址，而不是空白的輸入首頁。
  3. 點訊息輸入框右側的圓形橘色按鈕。
  4. 把 Messages（訊息）設為「All」、「Human」或「Assistant」（全部／使用者／助理），需要的話勾選「Thinking」（思考過程），或用「Select」（選取）勾選個別訊息。選擇 PDF、Markdown、JSON、純文字、XML、CSV 或 PNG。
  5. 按「Export」，或按「Copy」（複製）把 Markdown、文字、JSON、XML 或 CSV 放進剪貼簿。Claude 對話擷取工具不會把聊天內容上傳到我們的伺服器。

如果看不到橘色按鈕，請釘選擴充功能、重新整理分頁，並確認網址是真正的聊天。Claude 對話擷取工具只會在 claude.ai 上注入，不會出現在 Claude Desktop、Claude Code 終端機或其他網站上。檔案不完整，通常是因為長對話還沒顯示完畢；請捲動或稍候，再擷取一次。

擷取工具會記住你上次用的格式。如果你想要 Markdown 卻拿到 JSON，請在按「Export」前先打開下拉選單。選 PDF 會要求 Google 登入。一天內用完 3 次 PDF 或批次匯出後，免費方案會顯示 Pro 的提示（每月 US$3.99 或每年 US$26.99）；這是正常的，不是解析失敗。次數於 UTC 午夜重置。

需要包含列印和 ZIP 替代方案的步驟清單？請看如何下載 Claude 聊天。需要包含「列印 → 另存為 PDF」的方法比較？請看如何匯出 Claude 聊天。本頁假設你要的是目前開啟對話的結構化檔案。

Claude 對話擷取工具會擷取哪些內容？

Claude 對話擷取工具會讀取 claude.ai 已經畫出的訊息樹：使用者和助理的每一輪、帶語言標籤的程式碼區塊、表格、連結，以及選用的思考過程。artifact 版面可選「Original」、「Inline」、「Nested」或「Flat」（原始／內嵌／巢狀／平面）。從同一頁複製貼上會失去這些結構；擷取工具則會在 Markdown、JSON 和 XML 中保留它們。

思考過程是一個核取方塊。需要在擷取出的檔案中看到 Claude 可見的推理時就打開；只想要最終答案就關掉。中繼資料可包含標題、時間戳記和模型。Messages 篩選器（All、Human、Assistant）、「Thinking」和「Select」都在匯出面板中，位於 Format（格式）旁邊；工具／MCP 步驟和網路搜尋來源則是設定中的選用開關。功能清單：功能。

擷取工具讀取的是你的 claude.ai 分頁中已經顯示的對話。程式碼區塊、表格和 artifact 版面（Original、Inline、Nested、Flat）都在那裡解析，接著檔案在本機產生，PDF 也一樣。

PNG 是例外：它是整段對話的圖片，不是能用 grep 搜尋的解析結果。需要貼到工單或簡報的視覺化擷取結果時，用 PNG。需要可搜尋的文字時，用 Markdown 或 JSON。PNG 和 Markdown 都不是 PDF；需要分頁時請選 PDF，請看 Claude 聊天存成 PDF。

擷取工具無法取出 Chrome 從未載入過的聊天。無痕模式、已登出的分頁，或只存在 Claude Desktop 中的對話，都不會產生檔案。請在登入狀態下於 claude.ai 開啟對話，再執行 Claude 對話擷取工具。頁面載入後才能離線匯出；產生檔案內容時仍然不需要和伺服器往返。

Claude 聊天擷取工具能寫出哪些格式？

七種：PDF、Markdown、JSON、純文字、XML、CSV 和 PNG。無論擷取一段 Claude 聊天還是執行「Export All」（一次匯出全部），都是這七種。Download Claude conversations 1.16.2 版不提供 Word、Notion 或 Google 文件。格式決定次數限制：六種格式免帳號、不限次數，而在免費方案中，每個 PDF 會用掉每天 3 次中的 1 次。

可以批次擷取 Claude 對話嗎？

可以。打開擴充功能的彈出視窗 →「View and Download All Conversations」（檢視並下載所有對話），篩選後按「Export All」。Claude 對話擷取工具會寫出一個 ZIP，每段選取的聊天一個檔案，採用你選的格式。批次匯出需要 Google 登入。除非帳號是 Pro（每月 US$3.99 或每年 US$26.99），否則在免費方案中，ZIP 裡的每段聊天都會用掉每天 3 次中的 1 次，與 PDF 共用。

控制台（Dashboard）上的篩選器有：All conversations、New、Updated 和 Previously exported（全部／新的／已更新／曾匯出），另有 Chat 和 Cowork 分頁以及專案搜尋。New 表示 Claude 對話擷取工具還沒儲存過那段聊天。Previously exported 會標出你已擷取過的紀錄，之後的批次執行可以略過。專案搜尋對應 claude.ai 的專案分組。按「Export All」前，可以先用搜尋依名稱找到對話。

批次匯出的解析並沒有比較陽春。控制台的核取方塊「Chats」、「Thinking」、「Metadata」、「Tools」、「Sources」（聊天、思考過程、中繼資料、工具、來源），加上 artifact 版面，決定每個檔案要放哪些內容；「Chat format」（聊天格式）選單提供全部七種格式，PDF 也包括在內。含額度提醒的操作說明：批次 Export All。如果你要的是整個帳號、用電子郵件寄來的單一 ZIP，那是 Settings → Privacy → Export data（若 claude.ai 設為中文，選單名稱可能顯示為中文），不是這個擷取工具。

批次匯出按聊天計算。免費方案中，「Export All」與 PDF 共用每天 3 次，ZIP 裡的每段聊天都算一次。剩 3 次卻選了 25 段聊天，整批都會被擋下，而不是只匯出一部分。在大量執行 Claude 對話擷取工具之前，請用 New 篩選器少選幾段、等 UTC 午夜重置，或升級到 Pro（每月 US$3.99 或每年 US$26.99）。

Claude 對話擷取工具和複製貼上有什麼不同？

複製貼上適合一則簡短的 Claude 回答，遇到程式碼和表格就不行。Anthropic 的 Export data 是帳號備份 ZIP。Claude 對話擷取工具介於兩者之間：這段對話或批次選取的對話，立即產生結構化檔案，在 Chrome 中的 claude.ai 上完成。

使用 Claude 對話擷取工具安全嗎？

這個 Claude 對話擷取工具使用你現有的 claude.ai 工作階段，方式和網站本身相同。它不會自動操作帳號，也不會把聊天內容傳送到我們的 API。只有 PDF、批次匯出和 Pro 會要求 Google 登入，用來計算每日額度和恢復 Pro。付款由 Paddle 處理。我們不是 Anthropic，他們的服務條款仍然適用。

為了 PDF、批次匯出或 Pro 登入後，Cloudflare Worker 會看到你的 Google 電子郵件、今天的 PDF 和批次匯出次數，以及是否為 Pro。單一聊天的 Markdown、JSON、文字、XML、CSV 和 PNG 匯出不會傳送任何資料給它，它也絕不會收到擷取出的檔案，PDF 也不例外。檔案只會進入 Chrome 的下載資料夾，不會離開瀏覽器。完整的界線說明：運作方式。想問「Claude 聊天擷取工具安全嗎」的人，可以看看這個分工：計費在伺服器上，聊天留在分頁裡。

我們無法保證「完全不連網」。claude.ai、Google 和這個伺服器都存在。我們能說的是：聊天內容不會上傳給我們。請遵守 Anthropic 的服務條款。Download Claude conversations 是獨立開發的 Chrome 擴充功能，不是 Anthropic 的官方產品。客服電子郵件列在網站頁尾。

行動瀏覽器和 Claude Desktop 都不支援。作為 Chrome 內容腳本的 Claude 對話擷取工具無法在那裡執行。2026 年 9 月本頁不提供 Safari 或 Firefox 版本。請在桌面版 Chrome 中使用 claude.ai。封鎖擴充功能的團隊政策也會封鎖這個擷取工具。

常見問題：Claude 對話擷取工具

以下問答回答關於 Claude 對話擷取工具和擷取 Claude 聊天的問題：批次「Export All」、Desktop、Claude Code、PDF、Google 登入，以及 PDF 和批次匯出的每日限制。答案依據 claude.ai 上的擴充功能 1.16.2 版。文件開頭的 FAQPage 結構化資料與這份清單一致。

什麼是 Claude 對話擷取工具？

一種工具，讀取你開啟中的 claude.ai 對話，寫出 PDF、Markdown、JSON、純文字、XML、CSV 或 PNG。Download Claude conversations 加上的橘色按鈕，就在 Chrome 本機完成這個解析。

擷取 Claude 聊天和匯出 Claude 聊天不一樣嗎？

一樣，只是動詞不同。「擷取」、「匯出」、「下載」用的都是 claude.ai 上同一個橘色按鈕和同樣的七種格式。本頁著重在解析器會保留什麼。

不安裝任何東西，能擷取 Claude 聊天嗎？

只能複製貼上（會失去程式碼區塊和表格），或使用 Anthropic 的 Export data（那是帳號 ZIP）。結構化的 Claude 對話擷取工具必須讀取頁面，也就是這個 Chrome 擴充功能。

擷取工具支援批次擷取對話嗎？

支援。從擴充功能的彈出視窗打開「View and Download All Conversations」，再按「Export All」取得 ZIP。批次匯出需要 Google 登入；免費方案中每段聊天都計入每天 3 次，與 PDF 共用。Pro 每月 US$3.99 或每年 US$26.99，可取消上限。篩選器：All conversations、New、Updated、Previously exported。

Claude 聊天擷取工具安全嗎？

這個工具讀取已登入的 claude.ai 工作階段，在本機產生檔案。對話內容不會傳送到我們的伺服器。我們不是 Anthropic，你仍受他們的服務條款約束。

擷取聊天需要 Claude Pro 嗎？

不需要。任何能在 Chrome 中開啟對話的 claude.ai 方案都可以。在我們這邊，Markdown、文字、JSON、XML、CSV 和 PNG 擷取免費、不限次數，也不需要帳號；PDF 和批次匯出每天最多免費 3 次。Anthropic 的付費方案與我們的限制無關。

Claude 對話擷取工具能在 Desktop 中執行嗎？

不能。Claude Desktop 永遠不會出現橘色按鈕。如果對話有同步，請在 claude.ai 上開啟同一段聊天；否則請複製貼上或使用官方 ZIP。這個擷取工具只支援 Chrome 中的 claude.ai。

Claude 對話擷取工具可以寫出 PDF 嗎？

可以。在匯出面板中選 PDF，按「Export」。PDF 在瀏覽器中產生，不經過列印對話框。它需要 Google 登入，每天最多免費 3 次；Pro 則不限次數。

擷取 Claude 聊天能用在 Claude Code 嗎？

只能用在網頁版。claude.ai/code 上的 Claude Code 工作階段在 claude.ai 中開啟，可以像一般聊天一樣擷取。終端機中的 Claude Code 使用 /export 或磁碟上的 JSONL；這個 Claude 對話擷取工具是 claude.ai 的 Chrome 內容腳本，不是終端機掛鉤。

擷取工具提供多少次免費擷取？

Markdown、文字、JSON、XML、CSV 和 PNG 不限次數，也不需要帳號。免費方案中，每個已用 Google 登入的帳號，PDF 和批次「Export All」合計每天 3 次，於 UTC 午夜重置。Pro 取消上限，並可透過 Paddle 計費用同一個 Google 帳號恢復。

Claude 對話擷取工具會略過什麼？

頁面介面、輸入框，以及任何沒有顯示在對話中的內容。它也會略過從未在 Chrome 中載入的聊天。只存在 Claude Desktop 中的對話和本機的 Claude Code JSONL 都不在範圍內。
