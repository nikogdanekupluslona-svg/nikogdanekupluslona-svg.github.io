如何儲存 Claude 對話，存成自己保留的檔案

Claude 會自動把對話存在對話紀錄裡嗎？

會。Claude.ai 已經把登入狀態下的對話保存在 Anthropic 帳號的對話紀錄中，關閉分頁並不會清掉對話。不過，仍然沒有任何儲存按鈕可以把它寫成磁碟上的檔案。把 Claude 對話儲存成 Markdown 或 JSON，是和對話紀錄不同的另一件事。

對話紀錄就是 claude.ai 左側的聊天清單。每一列都是 Anthropic 為該登入帳號保存的一段對話。之後再打開那一列，同樣的內容就會回來。這是帳號儲存空間，而不是你筆電上的下載資料夾。

搜尋「claude 儲存對話」的人，常常其實是想問「離開之後對話會不會消失？」對一般登入狀態的工作階段來說，答案是不會。claude.ai 不需要按「儲存」才能把對話留在帳號中。缺少的是檔案匯出工具，而不是保存開關。

對話紀錄不是 Markdown 檔，不是可以用 grep 搜尋的 JSON 樹，也不是可以放進簡報的 PNG。對話紀錄在 Anthropic 登入之後才看得到。如果無法登入，就打不開那些聊天。本機檔案則在密碼不見之後依然打得開。

兩種不同的「儲存」。對話紀錄＝Anthropic 把聊天保存在帳號中。檔案＝你把 PDF、Markdown、JSON、文字、XML、CSV 或 PNG 寫到磁碟。claude.ai 有前者，但沒有能做到後者的按鈕。

claude.ai 上的 Projects 和 Recents 也仍然是對話紀錄。把聊天歸到某個 Project 不會產生檔案，重新命名對話不會產生檔案，加星號或釘選（如果介面有提供）也不會寫出 Markdown。Download Claude conversations 可以像其他聊天一樣匯出 Project 中的聊天；在 Project 頁面上，「Project files」→「Download ZIP」（專案檔案 → 下載 ZIP）則會儲存專案的檔案。

Team 和 Enterprise 工作區也是同樣的區分。如果你能在 claude.ai 上開啟對話，代表 Anthropic 已經為該工作區保存了那段對話。但公司的保留規則仍可能依你無法控制的排程刪除或隱藏聊天。這時，你匯出的檔案就是你自己保留的副本。

無痕視窗和另一個 Chrome 設定檔不會共用對話紀錄。對話綁定在該工作階段使用的 Anthropic 帳號上。登入另一個 Anthropic 帳號，就會看到另一份對話紀錄。跨帳號的「儲存」要靠檔案，而不是合併對話紀錄。

如何把 Claude 對話儲存成檔案？

要把 Claude 對話儲存成檔案，請選一種會寫到磁碟的方法：Chrome 中的 Download Claude conversations、列印 → 另存為 PDF，或 Settings → Privacy → Export data。claude.ai 上的對話紀錄是帳號儲存空間，不是 PDF、Markdown、JSON、文字、XML、CSV 或 PNG 檔。

Chrome 擴充功能是單一聊天的路線。開啟對話網址，點訊息輸入框旁的橘色按鈕，選擇格式，按「Export」（匯出）。Chrome 的下載 API 會把檔案寫到本機。Markdown、文字、JSON、XML、CSV 和 PNG 不需要帳號，只有 PDF 需要用 Google 登入。聊天內容一直留在你的電腦上。

列印是視覺路線。按 Ctrl+P 或 Cmd+P，目的地選「另存為 PDF」。結果看起來就像 claude.ai 頁面，包括列印樣式沒有隱藏的介面元素。程式碼區塊常常被切到不同頁。當審閱者要的是快照而不是筆記檔時，才用列印。如果想要從訊息內容而非畫面產生的 PDF，請在擴充功能中選 PDF。

官方 Export data 是帳號路線：claude.ai 上的 Settings → Privacy → Export data。Anthropic 會寄出一個會過期的連結。ZIP 是整個帳號的 JSON，而不是畫面上那段聊天的具名檔案。等待時間就是完整備份的代價。

選擇符合你需求的那一列。大多數搜尋「claude 儲存對話」的人要的是第二列：一個能在 Obsidian、VS Code 或 wiki 中打開的檔案。第一列對話紀錄已經幫你做到了。列印和 Export data 也都有效，只是解決的是不同的需求。

在離職交接、筆電重灌、研究封存，或把程式碼審查貼進 git 之前，存成檔案是正確的做法。如果你只需要明天用同一個 Anthropic 帳號重新打開同一段對話，對話紀錄就夠了。

複製貼上是第五種方法，但做出來的檔案很弱。在 claude.ai 上選取文字，貼到 Google 文件。程式碼區塊會跑掉，表格會變成一整串文字，訊息分界會消失。一段文字還可以；但如果是 40 輪的設計審查，只靠它來儲存 Claude 對話就不夠了。擴充功能的「Copy」（複製）按鈕則會把乾淨的 Markdown 放進剪貼簿。

如何用 Chrome 擴充功能儲存 Claude 聊天？

用 Download Claude conversations 儲存 Claude 聊天：安裝 Chrome 擴充功能，在 claude.ai 開啟對話，點訊息輸入框旁的橘色按鈕，選 PDF、Markdown、JSON、文字、XML、CSV 或 PNG，再按 Export。除了 PDF 之外都不需要帳號。

  1. 從 Chrome Web Store 安裝 Download Claude conversations（可載入 Chrome 擴充功能的 Chromium 系瀏覽器也可以）。
  2. 如果安裝時 claude.ai 已經開著，請重新載入頁面。Chrome 不一定會把內容腳本注入到舊的分頁。
  3. 從對話紀錄開啟一個真正的對話網址。橘色按鈕只會出現在對話中，不會出現在空白的輸入首頁。
  4. 點訊息輸入框右側的圓形橘色下載按鈕。面板會打開，裡面有 Messages（訊息：All / Human / Assistant，全部／使用者／助理）、Format（格式）、Thinking（思考過程）、Select（選取）、Copy 和 Export。
  5. 選擇 PDF、Markdown、Plain Text（純文字）、JSON、XML、CSV 或 PNG，按 Export，Chrome 會立刻下載檔案。

這個擴充功能是只在 claude.ai 上運作的 Chrome 內容腳本（content script）。解析器讀取的是登入工作階段中已經載入的對話。Download Claude conversations 不會用自己的憑證另外呼叫 Anthropic API，也不會為了產生檔案而把對話上傳到我們的伺服器。

Markdown、純文字、JSON、XML、CSV 或 PNG 都不需要帳號。這些單一聊天匯出不限次數而且免費：不用登入，也沒有計數。只有在選 PDF 或執行批次「Export All」（一次匯出全部）時，才會出現 Google 登入。Google 登入不是用來讀取聊天的登入，對話內容一直留在你的電腦上。

PDF 和批次 ZIP 共用每天 3 次的免費額度，於 UTC 午夜重置。批次 ZIP 裡的每一個聊天都算一次。Pro 每月 US$3.99 或每年 US$26.99，可取消這個上限。Pro 的付款由 Paddle 處理，我們看不到卡號。PDF 步驟：把 Claude 聊天下載成 PDF。

本機檔案。每種格式（包括 PDF）都在瀏覽器中產生，再交給 Chrome 的下載 API。聊天文字絕不會被上傳。只有 PDF 和批次匯出會用你的 Google 電子郵件做一次額度檢查。版本 1.16.2，2026 年 9 月。

同一個面板可以依發話者篩選：All、Human 或 Assistant。Thinking 核取方塊決定要不要包含延伸思考。Select 讓你勾選個別訊息，檔案裡就只放那幾輪對話。Copy 會把 Markdown、文字、JSON、XML 或 CSV 放到剪貼簿，而不是下載檔案。工具／MCP 步驟和網路搜尋來源是在設定中另外開啟的選項。中繼資料和 artifact 版面（"Original"、"Inline"、"Nested" 或 "Flat"）則在控制台（Dashboard）中設定。

如果對話很長，請一路捲動，讓 claude.ai 載入較早的訊息。擴充功能只能匯出頁面已經顯示出來的內容。載入一半的對話就會產生一半的檔案，看起來像錯誤，其實通常只是還沒捲動到的 DOM。

請等助理串流完成後再按 Export。在串流途中儲存 Claude 對話，檔案會少掉最後一則回答。重新匯出 Markdown 或 JSON 不需任何成本；在免費方案中，重新匯出 PDF 會再用掉每天 3 次中的一次，所以最好先確認對話已經完整。

擴充功能會記住上次使用的格式。如果你想要 Markdown 卻拿到 JSON，那是因為下拉選單還停在上次匯出的 JSON。每次換用途時，都請確認一下下拉選單。同一顆橘色按鈕的逐步截圖，請看如何下載 Claude 聊天。

我們每週都聽到同樣的誤會：大家以為對話紀錄是會消失的草稿，所以到處找儲存按鈕。其實 claude.ai 早就保存了對話。我們的橘色按鈕只是從你已經開啟的頁面，寫出一個本機檔案：PDF、Markdown、JSON、文字、XML、CSV 或 PNG。

不裝擴充功能，如何在 Claude 中儲存對話？

不裝擴充功能，在 Claude 中儲存對話的方法有兩種：列印 claude.ai 頁面，或申請 Anthropic 的 Export data ZIP。列印得到的是網頁的視覺 PDF；Export data 則是稍後寄來、涵蓋整個帳號的 JSON 封存檔。兩者都不會產生單一聊天的 Markdown 檔。

列印的方法：在 claude.ai 開啟對話，介面允許的話先隱藏側邊欄，按 Ctrl+P（Windows/Linux）或 Cmd+P（Mac），把目的地設為「另存為 PDF」，然後儲存。輸入框等介面元素可能在每一頁重複出現。完整的列印說明請看把 Claude 聊天下載成 PDF。

官方的方法：claude.ai 上的 Settings → Privacy → Export data。Anthropic 會寄出一個會過期的連結。如果要從上千段對話中取出一段，就得自己解開 ZIP。那份封存檔是正式的備份，而不是明天站立會議要用的筆記檔。

複製貼上也不用安裝任何東西。在 claude.ai 上反白幾輪對話，貼到筆記 App。程式碼的縮排通常會消失，多輪對話會變成沒有結構的一大段。複製貼上適合單一片段，不適合當作儲存 Claude 對話的唯一方法。

當你現在就需要從對話紀錄中的某一項取得結構化的 Markdown 時，以上任何一列都無法取代 Download Claude conversations。但在 IT 封鎖 Chrome 擴充功能、你需要官方 ZIP，或交付物就是畫面的完整列印時，這些不用擴充功能的方法仍然重要。

手機上的 Safari 和 Chrome 可以列印，但無法安裝這個 Chrome Web Store 項目。想要可重複使用的 Markdown 檔，請先安裝擴充功能，再在桌面版 Chrome 中打開對話紀錄裡的同一項。

關閉分頁後，對話紀錄還會保存 Claude 對話嗎？

會。只要聊天是在登入狀態下建立的，關閉分頁、重新整理 claude.ai 或闔上筆電之後，對話紀錄仍然會保存 Claude 對話。關閉分頁不等於刪除；從對話紀錄中刪除，才會把對話從帳號介面中移除。

登出 claude.ai，頁面就會變成空白。重新登入同一個 Anthropic 帳號，對話紀錄就會把那些聊天帶回來。登出只是隱藏清單，本身並不會清除帳號儲存空間。登入另一個 Anthropic 帳號，就會看到另一份對話紀錄。

從對話紀錄中刪除，才是大家真正會遇到的消失情況。在 claude.ai 介面中移除一段對話，它就會從側邊欄消失。你之前用橘色按鈕匯出的 Markdown 檔仍然留在磁碟上。如果聊天快要被清理，請先匯出。

刪除不等於關閉。關閉 claude.ai 分頁不會影響對話紀錄。從對話紀錄中刪除對話，則會把聊天從帳號介面中移除。如果 Anthropic 不再包含那段對話，刪除後官方 Export data 也幫不上忙。整理之前，先寫出檔案。

無痕視窗一關閉就結束了。如果你在沒有持續登入的無痕視窗中使用 claude.ai，不要以為對話紀錄會保留你的工作。請在一般的 Chrome 設定檔中登入，或在無痕工作階段結束前匯出檔案。

Team 和 Enterprise 的工作區管理員可以保留或限制聊天。一項不是你設定的政策，之後可能會隱藏某段對話。請把公司的對話紀錄當成借來的儲存空間，而把匯出的 Markdown 或 JSON 檔當成政策之外、屬於你這一邊的副本。

只要兩台裝置使用同一個 Anthropic 帳號，從手機換到筆電時，不需要特別按一下來儲存 Claude 對話。在筆電上打開對話紀錄就好。如果找不到聊天，代表你用的是別的帳號、別的工作區，或對話已被刪除，而不是「沒有儲存」。

當 Claude Desktop 登入同一個 Anthropic 使用者時，可能會顯示同一個帳號的聊天。同步是 Anthropic 的工作。Chrome 擴充功能永遠不會注入到 Desktop。如果對話在 claude.ai 上，請在 Chrome 中打開 claude.ai 來寫出檔案。

如何把 Claude 對話儲存成 Markdown 或 JSON？

要把 Claude 對話儲存成 Markdown 或 JSON：在 claude.ai 上打開橘色按鈕，選擇格式，再按 Export。Markdown 是筆記檔，JSON 是給腳本用的訊息樹，純文字沒有任何標記，CSV 是每則訊息一列，PDF 是分頁的文件，PNG 是一張圖片。

Markdown 保留標題、附語言標籤的程式碼區塊和表格，是 Obsidian、GitHub 或 wiki 的常見選擇。這個格式的版面說明：Markdown 匯出。JSON 保留解析器已經建好的樹狀結構，開啟對應選項時也包括 artifact 和思考過程。

Download Claude conversations 產生的 JSON，結構和 Anthropic 的帳號 ZIP 不同。擴充功能的 JSON 是頁面渲染出來的一段對話；Export data 的 JSON 則是 Anthropic 稍後寄來的整個帳號資料。在同一個腳本中混用這兩種結構之前，請先確認欄位。

當目的地會去掉標記時，純文字是正確選擇，例如工單欄位、電子郵件內文，或只要原始字串的搜尋索引。XML 是較小眾的資料交換格式。CSV 可以用 Excel、Google 試算表或 Numbers 開啟。PNG 適合放進簡報或錯誤回報的對話圖，不適合之後要用 grep 搜尋的 40 輪審查。

思考過程、中繼資料、發話者篩選和 artifact 版面，都會改變寫進 Markdown 和 JSON 的內容。需要在封存中保留延伸推理時，就在面板中勾選 Thinking；如果檔案是給只該看到最終回答的讀者，就不要勾。想讓筆記檔有個標頭時，中繼資料會加上標題、時間戳記和模型。

Messages 選「Human」會寫出你的提問，「Assistant」會寫出 Claude 的回覆，「All」則是整段對話。Select 會把檔案縮小到你勾選的訊息。控制台上的 artifact 版面（"Original"、"Inline"、"Nested" 或 "Flat"）決定 artifact 放在檔案裡，還是放在 ZIP 中自己的資料夾。選定一種版面後固定使用，儲存下來的聊天資料夾就會保持一致。

如何批次儲存 Claude 聊天紀錄？

要把 Claude 聊天紀錄儲存成許多檔案，不必每個分頁都按一次橘色按鈕。從擴充功能的彈出視窗開啟「View and Download All Conversations」（檢視並下載所有對話），篩選清單，再按 Export All。Export All 需要用 Google 登入。免費方案中，ZIP 裡的每個聊天都會用掉每天 3 次額度中的一次，這個額度與 PDF 共用。Pro 沒有上限。

控制台會列出你目前登入的 claude.ai 帳號中的對話，也就是你原本的對話紀錄，變成一張可以篩選的表格。可以依名稱搜尋，依 All conversations、New、Updated 或 Previously exported（全部、新的、已更新、已匯出過）篩選，在 Chat 和 Cowork 分頁之間切換；如果你在 claude.ai 上用 Project 分類聊天，也可以依 Project 搜尋。

批次匯出會產生一個 ZIP，每個聊天一個檔案，格式由「Chat format」選單決定，七種格式都可以，包括 PDF。它使用和單一聊天匯出相同的解析器。核取方塊決定要放進哪些內容：Chats、Thinking、Metadata、Tools、Sources（聊天、思考過程、中繼資料、工具、來源），另外還有 artifact 版面。Export All 不是比較陽春的流程，而是同一個解析器一次套用到許多對話 ID。細節：批次 Export All。

Anthropic 的 Export data 仍然是帳號備份：一個 ZIP、一封電子郵件、全部都是 JSON，連你忘記的聊天也在裡面。批次 Export All 則是相反的用途：由你挑選對話紀錄中的哪幾列、挑選格式，ZIP 立刻下載。如果你既想要一份正式的封存，又想要一個好讀的筆記資料夾，兩者都用。

額度共用，每日計算。在免費方案中，PDF 匯出和批次中的聊天共用每天 3 次，於 UTC 午夜重置。如果選了 40 段對話，整批都會被擋下，而不是只匯出一部分。請少選一些，或透過 Paddle 升級到 Pro（每月 US$3.99 或每年 US$26.99）。

控制台會記得你已經匯出過哪些對話，所以下次可以只篩選 New 或 Updated。這樣每週儲存 Claude 聊天的習慣就能只補上新的部分，而不會重複上個月的 Markdown。每天 3 次的計數跟著 Google 帳號而不是安裝，並於 UTC 午夜重置。

如果對話紀錄裡滿是一行的草稿，就只選一部分。Export All 不代表每一列都得匯出。精準的篩選加上 Markdown，會比 200 個空的「hello」對話更像一個乾淨的研究資料夾。

「匯出 Claude 聊天」這個說法，指的也是同一顆橘色按鈕和同一張 Export All 表格；香港用戶也常說「導出」。如果你是用「匯出」而不是「儲存」搜尋過來的，相關頁面匯出 Claude 聊天會說明這些控制項。

可以在 Desktop 或 Code 中儲存 Claude 對話嗎？

Desktop 不行；Code 只有網頁版可以。Download Claude conversations 無法從 Claude Desktop 或本機的 Claude Code 終端機儲存 Claude 對話。claude.ai/code 上的工作階段是在桌面版 Chrome 中開啟的，所以可以像一般聊天一樣儲存。Claude Desktop 是另一個 App。本機 Claude Code 是終端機代理程式，使用 /export 和磁碟上的 JSONL。

常見問題：如何儲存 Claude 對話

如何把 Claude 對話儲存成檔案？

安裝 Download Claude conversations，在 claude.ai 開啟對話，點訊息輸入框右側的橘色按鈕，選 PDF、Markdown、JSON、文字、XML、CSV 或 PNG，再按 Export。檔案會下載到本機，除了 PDF 之外都不需要帳號。對話紀錄已經把聊天保存在 Anthropic 帳號中；橘色按鈕則是寫出一份磁碟上的副本。

如何在 claude.ai 上儲存 Claude 聊天？

要把對話留在帳號中，不需要儲存按鈕。claude.ai 的對話紀錄已經列出登入狀態下的聊天。要把 Claude 聊天存成檔案，可以使用 Chrome 擴充功能、列印 → 另存為 PDF，或用 Settings → Privacy → Export data 取得稍後寄來的帳號 JSON ZIP。

不裝擴充功能，如何在 Claude 中儲存對話？

列印 claude.ai 頁面（Ctrl/Cmd+P → 另存為 PDF）可得到視覺副本，或用 Settings → Privacy → Export data 取得寄到信箱、涵蓋整個帳號的 JSON ZIP。簡短回答可以複製貼上。但這些方法都無法像 Chrome 擴充功能那樣，為每段聊天產生結構化的 Markdown 檔。

Claude 會自動把對話存在對話紀錄裡嗎？

會。claude.ai 上登入狀態下的聊天會保存在 Anthropic 帳號的對話紀錄中。關閉分頁、重新整理，或在另一台裝置用同一個帳號登入，都不會清掉對話。但對話紀錄不是你磁碟上的 PDF、Markdown、JSON 或任何其他檔案。

關閉分頁，Claude 對話會消失嗎？

不會。關閉 claude.ai 分頁不會把對話從對話紀錄中刪除。從對話紀錄中刪除聊天，才會把它從帳號介面中移除。你之前用 Download Claude conversations 匯出的檔案，即使在刪除之後也仍然留在磁碟上。

可以把 Claude 對話儲存成 PDF 嗎？

可以。Download Claude conversations 1.16.2 可以直接匯出 PDF：在橘色按鈕的面板中選 PDF，再按 Export。檔案在瀏覽器中產生，不經過列印對話框。PDF 需要 Google 登入，每天最多免費 3 次；Pro 無限制。教學：Claude 聊天存成 PDF。

儲存 Claude 對話可以免費幾個檔案？

Markdown、純文字、JSON、XML、CSV 和 PNG 不限次數，也不需要帳號。PDF 和批次 ZIP 在免費方案中共用每天 3 次，需要 Google 登入；批次 ZIP 中每個聊天算一次，每天於 UTC 午夜重置。Pro 每月 US$3.99 或每年 US$26.99，可取消上限。付款由 Paddle 處理。

可以在手機上儲存 Claude 對話嗎？

Chrome 擴充功能不行。它在桌面版 Chrome（或其他可安裝 Chrome Web Store 項目的 Chromium 瀏覽器）中執行，沒有 iOS 或 Android App。行動瀏覽器仍然可以打開對話紀錄並列印 Claude 聊天，但無法顯示橘色按鈕。

可以從對話紀錄批次儲存 Claude 聊天嗎？

可以。從擴充功能的彈出視窗開啟 View and Download All Conversations，篩選清單，再按 Export All。批次匯出需要 Google 登入，在免費方案中計入每天 3 次的額度。這個批次流程不是 Anthropic 的 Export data ZIP；官方 Export data 是整個帳號的一個封存檔，稍後才寄到信箱。請看批次下載。

可以從 Claude Code 儲存 Claude 對話嗎？

只有網頁版可以。claude.ai/code 上的 Claude Code 工作階段可以像一般 claude.ai 聊天一樣儲存。本機終端機工作階段不行：請使用 /export，或從 ~/.claude/projects（Windows：%USERPROFILE%\.claude\projects）複製 JSONL。這個 Chrome 擴充功能只在 claude.ai 上執行。教學：Claude Code 匯出。

用來儲存 Claude 聊天的官方 Export data 在哪裡？

在 claude.ai 上：Settings → Privacy → Export data。Anthropic 會寄出一個會過期的連結。ZIP 是帳號層級的 JSON 封存檔，而不是你正在讀的那段聊天的具名 Markdown 檔。把 Export data 當作備份；現在就要一個好讀的檔案時，用橘色按鈕。
