如何從 claude.ai 匯出 Claude 聊天？

在 Chrome 中開啟 claude.ai 上的對話，點訊息輸入框旁的橘色按鈕，選 PDF、Markdown、JSON、純文字、XML、CSV 或 PNG，再按「Export」。Download Claude conversations 會把檔案存在本機。截至 2026 年 9 月，claude.ai 本身沒有「匯出這段聊天」的原生功能。

  1. 從 Chrome Web Store 安裝 Download Claude conversations。
  2. 重新載入 claude.ai，開啟一個真正的對話網址，而不是空白的輸入首頁。
  3. 點訊息輸入框右側的圓形橘色下載按鈕。
  4. 在面板中把 Messages（訊息）設為「All」、「Human」或「Assistant」（全部／使用者／助理），再選格式。勾選「Thinking」（思考過程）可包含延伸思考，或用「Select」（選取）勾選個別訊息。擴充功能會記住你上次用的格式。
  5. 按「Export」。Chrome 會透過瀏覽器的下載 API 立即儲存檔案。「Copy」（複製）則會把 Markdown、文字、JSON、XML 或 CSV 放進剪貼簿。

把 Claude 聊天匯出成 Markdown、文字、JSON、XML、CSV 或 PNG 都不需要帳號。這些單一聊天匯出不限次數，擴充功能也不會為此傳送任何資料到我們的伺服器。只有選 PDF 或執行批次「Export All」（一次匯出全部）時，才會出現 Google 登入：免費方案每天合計 3 次，於 UTC 午夜重置。登入時絕不會用到聊天內容。運作原理請看：運作方式。

如果看不到橘色按鈕，原因通常是：你不在對話網址上、安裝後分頁還沒重新載入，或擴充功能圖示還藏在 Chrome 的拼圖選單裡。把 Download Claude conversations 釘選起來，再重新整理 claude.ai。這個擴充功能只會在 claude.ai 上注入，絕不會在其他網站上執行。

單一對話，還是整個帳號？橘色按鈕匯出的是目前開啟的聊天。要一次取得很多檔案，請打開擴充功能的彈出視窗 →「View and Download All Conversations」（檢視並下載所有對話），執行「Export All」，詳見批次 Export All。Anthropic 的 Settings → Privacy → Export data（若 claude.ai 設為中文，選單名稱可能顯示為中文）是稍後才寄來的帳號 ZIP，不是這個流程。

Claude 匯出擴充功能到底做什麼？

Claude 匯出擴充功能會讀取你已登入的 claude.ai 分頁中已經顯示的對話，然後在磁碟上寫出一個有結構的檔案。Download Claude conversations 就是這樣的 Chrome 內容腳本：發話者、訊息樹、程式碼區塊、表格、選用的思考過程和 artifact 版面，而不是連同周圍介面一起截圖。它適用於一般聊天、Projects、Cowork 工作階段，以及 Claude Code on the web。

從 claude.ai 複製貼上會失去縮排，表格也會擠成一團。列印（Ctrl/Cmd+P）會連側邊欄一起印出，長的程式碼區塊也常被切到不同頁。這個擴充功能會保留程式碼區塊的語言標籤，在 Markdown、JSON 和 XML 中表格仍是表格。PNG 是視覺快照；PDF 則是分頁文件，直接在瀏覽器中產生，不經過列印對話框。

在 1.16.2 版中，artifact 版面是真正可切換的選項：「Original」、「Inline」、「Nested」或「Flat」（原始／內嵌／巢狀／平面），在控制台（Dashboard）中設定。延伸思考是匯出面板中的核取方塊；網路搜尋來源和工具／MCP 步驟則要在設定中開啟。中繼資料（標題、時間戳記、模型）也可以一併放入。Messages 篩選器可限定檔案只含全部訊息、只含使用者或只含助理，「Select」則可勾選個別訊息。完整清單：功能。

我們做這個橘色按鈕，是為了從 claude.ai 上已經顯示的聊天寫出真正的檔案：PDF、Markdown、JSON、文字、XML、CSV 或 PNG，而且不把對話上傳到我們的伺服器。1.16.2 版連 PDF 也在瀏覽器中產生。

也有人搜尋 Claude Chat Downloader 或 Claude Conversation Downloader，找到的是同一個 Chrome 商店頁面。法律頁面上可能仍寫著 Claude Exporter。這些名稱指的都是 Download Claude conversations，不是另一個產品。搜尋「擷取」而不是「匯出」，最後也會用到同一個按鈕；那個角度請看 Claude 對話擷取工具指南。

匯出 Claude 聊天該選哪種格式？

要分享或列印，把 Claude 聊天匯出成 PDF；寫筆記用 Markdown；給程式處理用 JSON；純粹封存用純文字；資料交換用 XML；試算表用 CSV；要一張對話圖片就用 PNG。Download Claude conversations 在同一個下拉選單中提供這七種格式。

格式決定是否有次數限制。Markdown、文字、JSON、XML、CSV 和 PNG 免帳號、不限次數。PDF 需要 Google 登入，在免費方案中計入每天 3 次的額度，與批次「Export All」共用。Pro 每月 US$3.99 或每年 US$26.99，可取消這個上限。Download Claude conversations 1.16.2 版不提供 Notion、Word 或 Google 文件格式。

可以用「Export All」批次匯出 Claude 聊天嗎？

可以。打開擴充功能的彈出視窗 →「View and Download All Conversations」，篩選表格，再按「Export All」取得一個 ZIP。批次匯出需要 Google 登入。免費方案中它與 PDF 共用每天 3 次的額度，ZIP 裡的每段對話都算一次。Pro 可取消整個紀錄的上限。

控制台會列出 claude.ai 的對話紀錄，可依名稱搜尋，有篩選器（All conversations、New、Updated、Previously exported，即全部／新的／已更新／曾匯出）、Chat 和 Cowork 分頁，以及專案搜尋。New 表示還沒用 Download Claude conversations 匯出過。Previously exported 會記錄你已儲存的聊天，第二次執行「Export All」時可以略過它們。專案搜尋則對應你在 claude.ai 上分組聊天的方式。

批次匯出有「Chat format」（聊天格式）選單，七種格式都有，PDF 也包括在內；還有「Chats」、「Thinking」、「Metadata」、「Tools」、「Sources」（聊天、思考過程、中繼資料、工具、來源）核取方塊，以及 artifact 版面（Original、Inline、Nested、Flat）。「Export All」不是縮水的封存檔，而是一個 ZIP，每段聊天一個檔案，採用你選的格式。如果你要的是整個帳號、稍後寄來的單一封存檔，那是 Anthropic 的 Export data，下一節和批次匯出頁面有比較。

批次匯出按聊天計算。免費方案中，「Export All」和 PDF 共用每天 3 次，ZIP 裡的每段對話都算一次。剩 3 次卻選了 40 段對話，整批都會被擋下，而不是只匯出一部分。請少選幾段、等 UTC 午夜重置，或改用 Pro（每月 US$3.99 或每年 US$26.99）。

在 Desktop 或 Code 上能匯出 Claude 聊天嗎？

在 Desktop 應用程式或 Claude Code 終端機中都不行。這個擴充功能只在 Chrome（或其他能從商店安裝擴充功能的 Chromium 瀏覽器）中的 claude.ai 上執行。Claude Desktop 是另一個 Mac／Windows 應用程式，那裡和終端機裡都不會出現橘色按鈕。Claude Code on the web（claude.ai/code）是例外：這些工作階段在 claude.ai 上開啟，可以像一般聊天一樣匯出。

如果這段對話也存在你的 claude.ai 帳號中，就在 Chrome 開啟它，用 Download Claude conversations 在那裡匯出 Claude 聊天。如果聊天只存在 Desktop 中，請從應用程式複製貼上，或在網頁版申請 Settings → Privacy → Export data。逐步比較請看：匯出 Claude Desktop 聊天。

終端機中的 Claude Code 使用 /export 或存在磁碟上的 JSONL 對話紀錄。這個 Chrome 擴充功能不會讀取這些本機工作階段。不要以為安裝 Download Claude conversations 就能掛進終端機。指南：Claude Code 匯出。如果你要匯出的是 CLI 工作階段，那是另一條路。

在手機瀏覽器中使用的 claude.ai 也不在支援範圍內。這個擴充功能需要桌面版 Chrome。2026 年我們團隊沒有 iOS 或 Android 應用程式。請在電腦上開啟對話，再用橘色按鈕或「Export All」匯出 Claude 聊天。

匯出 Claude 聊天和 Anthropic 的 Export data 有什麼不同？

Anthropic 的 Export data 會在一段時間後，用電子郵件寄來整個帳號的 JSON ZIP。用 Download Claude conversations 匯出 Claude 聊天，則會立即把目前開啟的對話存成 PDF、Markdown、JSON、文字、XML、CSV 或 PNG。備份用 ZIP；現在就要一個好讀的檔案，就用擴充功能。

Claude 匯出擴充功能要多少錢？

Markdown、文字、JSON、XML、CSV 和 PNG 匯出免費、不限次數，也不需要帳號。PDF 和批次「Export All」用 Google 登入後每天最多免費 3 次。Pro 透過 Paddle 付款，每月 US$3.99 或每年 US$26.99，PDF 和批次匯出都不限次數。Download Claude conversations 不按格式收費。只要 Chrome 能開啟聊天，任何 claude.ai 方案都可以用。

PDF 和批次匯出的每日次數於 UTC 午夜重置。在新電腦上用同一個 Google 帳號登入，就能恢復 Pro。你可以隨時從擴充功能的選項頁面或透過 Paddle 取消。Paddle 是交易的銷售方（merchant of record），我們團隊不會看到卡號。首次付款享有 14 天退款保證，依退款頁面的說明透過 Paddle 處理。

使用這個擴充功能不需要 Anthropic 的 claude.ai 付費方案。你只需要一個能載入對話的 claude.ai 帳號，加上 Chrome。Team 和 Enterprise 使用橘色按鈕的方式與 Free 相同。如果工作區管理員封鎖了擴充功能，Download Claude conversations 就無法注入；那是瀏覽器政策，不是格式限制。

同一件事，不同的搜尋詞。匯出 Claude 聊天、下載 Claude 聊天、擷取 Claude 對話，意思都是把這段對話存成檔案。包含列印和 ZIP 替代方案的教學是如何下載 Claude 聊天。本頁介紹的是 Claude 匯出擴充功能這條產品路線。

匯出 Claude 聊天失敗時的排解方式：等長對話在 claude.ai 中完全載入，確認格式下拉選單（會沿用上次的格式），如果是 PDF 或批次匯出，再看看今天的 3 次還剩多少。如果 Chrome 擋下了下載，請允許 claude.ai 下載檔案。檔案不完整，通常是因為頁面還沒顯示完整的訊息樹。

本頁對應的版本是 1.16.2，日期為 2026 年 9 月。格式有 PDF、Markdown、純文字、JSON、XML、CSV 和 PNG。如果這份清單有變，本指南會在同一天更新。在那之前，這個擴充功能不提供 Word、Notion 或 Google 文件匯出。

常見問題：如何匯出 Claude 聊天

以下問答涵蓋匯出 Claude 聊天和 Claude 匯出擴充功能：格式、次數限制、Desktop、Claude Code、Anthropic 的 ZIP，以及橘色按鈕的位置。每個答案都是 1.16.2 版的事實。頁首的 FAQPage JSON-LD 與這份清單一致。

在本站，「匯出 Claude 聊天」是什麼意思？

用 Download Claude conversations 把 claude.ai 對話存成檔案：橘色按鈕、選格式、按「Export」。中文常搜尋「claude 匯出對話」，香港使用者也會打「claude 導出 對話」，英文則是「claude export chat」，指的都是同一件事。它不是 Anthropic 用電子郵件寄來的 ZIP，也不是 Claude Code 的 /export。

Claude 匯出擴充功能和 Export data 一樣嗎？

不一樣。Settings → Privacy → Export data 是透過電子郵件寄來的整個帳號 JSON ZIP。Claude 匯出擴充功能則會在 Chrome 中立即把目前開啟的聊天寫成 PDF、Markdown、JSON、文字、XML、CSV 或 PNG，或把「Export All」選取的對話打包成 ZIP。

可以把 Claude 聊天匯出成 PDF 嗎？

可以。在格式清單中選 PDF，按「Export」。擴充功能直接在瀏覽器中產生 PDF，不經過列印對話框。PDF 需要 Google 登入，每天最多免費 3 次；Pro 則不限次數。指南：把 Claude 聊天下載成 PDF。

只匯出一次 Claude 聊天也需要 Pro 嗎？

不需要。Markdown、文字、JSON、XML、CSV 和 PNG 匯出免費、不限次數，也不需要帳號。PDF 和批次「Export All」用 Google 登入後每天最多免費 3 次。Pro 每月 US$3.99 或每年 US$26.99，可取消這個上限。

任何 claude.ai 方案都能匯出 Claude 聊天嗎？

可以。只要能在 Chrome 中開啟對話，claude.ai 的 Free、Pro、Team 或 Enterprise 方案都可以。這個擴充功能不需要 Anthropic 的付費方案。

這個 Claude 匯出擴充功能能用在 Claude Code 嗎？

只能用在 Claude Code on the web。claude.ai/code 上的工作階段在 claude.ai 中開啟，可以像一般聊天一樣匯出。終端機中的 Claude Code 使用 /export 或磁碟上的 JSONL，Download Claude conversations 不會讀取它們。請看 Claude Code 匯出指南。

可以從 Claude Desktop 匯出 Claude 聊天嗎？

這個 Chrome 擴充功能做不到。如果對話有同步，請在 claude.ai 上開啟同一段對話；否則請複製貼上，或使用官方的 Export data。Desktop 裡永遠不會出現橘色按鈕。

Claude 匯出擴充功能提供多少次免費匯出？

Markdown、文字、JSON、XML、CSV 和 PNG 不限次數，也不需要帳號。免費方案中，PDF 和批次「Export All」用 Google 登入後合計每天 3 次；批次 ZIP 裡的每段聊天各算一次。次數於 UTC 午夜重置。Pro 取消上限，並可透過 Google 登入恢復。

匯出 Claude 聊天的橘色按鈕在哪裡？

安裝 Download Claude conversations 並重新載入後，它會出現在 claude.ai 對話網址中訊息輸入框的右側。空白的首頁輸入畫面和 Desktop 中都不會出現。

匯出 Claude 聊天會上傳我的對話嗎？

不會。每種格式（包括 PDF）都在瀏覽器中產生，再交給 Chrome 的下載 API。Markdown、文字、JSON、XML、CSV 和 PNG 匯出不會傳送任何資料給我們。為了 PDF、批次匯出或 Pro 登入後，我們的伺服器只會看到額度或訂閱狀態和你的 Google 電子郵件，絕不會看到聊天內容。詳情請看運作方式。

Claude 匯出擴充功能能寫出哪些格式？

七種：PDF、Markdown、純文字、JSON、XML、CSV 和 PNG。單一聊天和「Export All」都是這七種。1.16.2 版不提供 Word、Notion 或 Google 文件匯出。
