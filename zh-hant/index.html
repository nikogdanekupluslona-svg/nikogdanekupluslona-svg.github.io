下載 Claude 聊天的 6 大核心功能

01

匯出 PDF、Markdown、JSON、CSV 等格式

把 Claude 聊天下載成真正的檔案，而不是網頁截圖。PDF 適合閱讀和分享，Markdown 適合做筆記，JSON 給開發者，CSV 給試算表，純文字是最簡單的封存方式，XML 方便資料交換，PNG 則是一張視覺快照。也可以按「Copy」（複製）把結果放到剪貼簿。

02

批次下載 Claude 聊天

開啟 View and Download All Conversations 列出你的對話紀錄，依名稱搜尋，依專案或 Cowork 篩選，再按「Export All」（一次匯出全部）。得到一個 ZIP 檔，不必一個分頁一個分頁處理。免費方案每天 3 個聊天，Pro 無限制。

03

保留程式碼、表格和 artifact

匯出引擎會解析訊息樹，所以程式碼區塊保留縮排，表格仍是表格，artifact 可以選擇 "Original"、"Inline"、"Nested" 或 "Flat" 版面。

04

自己決定檔案要放什麼

可以匯出整段對話、只匯出你的提問、只匯出 Claude 的回答，或用「Select」（選取）只勾選特定訊息。需要稽核紀錄時可以附上延伸思考（extended thinking），不需要就略過。標題、時間戳記和模型中繼資料也能一起放進同一個檔案。

05

匯出前先搜尋與篩選

把清單縮小到新的聊天、已匯出過的聊天，或某個 Claude 專案，然後只匯出你選取的項目。

06

在你的瀏覽器中本機產生

每個檔案（包括 PDF）都在你的裝置上組成並下載到磁碟。大多數匯出不需要帳號。Google 登入只用來計算 PDF 與批次匯出的次數，以及綁定 Pro 訂閱，絕不會把聊天文字上傳到我們的伺服器。

常見問題

可以從 claude.ai 下載 Claude 對話嗎？

沒有內建按鈕可以做到。請從 Chrome Web Store 安裝 Download Claude conversations，開啟聊天，再匯出成檔案。

下載 Claude 聊天要付費嗎？

不用。Markdown、純文字、JSON、XML、CSV 和 PNG 匯出不限次數，也不需要帳號。PDF 和批次 ZIP 匯出需要用 Google 登入，每天最多免費 3 次。Pro 每月 US$3.99 或每年 US$26.99，可取消這個上限。

支援哪些瀏覽器？

桌面版 Chrome，以及可從 Chrome Web Store 安裝擴充功能的 Chromium 系瀏覽器。沒有行動版 App，也無法在 Claude Desktop 內執行。

怎麼取消 Pro？可以退款嗎？

隨時可以在擴充功能的選項頁面（「Cancel subscription」，取消訂閱）或透過 Paddle 取消。首次付款享有 14 天退款保證，不問理由。

這和 Claude 的 Export data 一樣嗎？

不一樣。Anthropic 的 Settings → Privacy → Export data（若 claude.ai 設為中文，選單名稱可能顯示為中文）會把整個帳號打包成 ZIP（JSON）寄到你的電子郵件。這個擴充功能則是立即把目前的聊天，或批次選取的聊天，下載成好讀的檔案。

你們會儲存我的 Claude 聊天嗎？

不會。每種格式（包括 PDF）都在你的瀏覽器中產生，對話文字絕不會傳到我們的伺服器。如果你為了 PDF、批次匯出或 Pro 而用 Google 登入，我們只會儲存那個電子郵件地址，用來計算每日額度和綁定你的訂閱。

「Claude 下載對話」和「Claude 匯出對話」有什麼不同？

是同一件事，只是說法不同；香港用戶也常說「導出」，也有人直接用英文輸入 download Claude chat。不論哪種說法，都是使用 claude.ai 上的橘色按鈕。

可以匯出 PDF 嗎？

可以。在匯出面板中選 PDF，再設定紙張大小、邊界、淺色或深色模式、字型、頁碼和目錄。PDF 需要用 Google 登入；免費方案每天可做 3 次 PDF 或批次匯出，Pro 無限制。完整教學：把 Claude 聊天下載成 PDF。

Claude Pro / Team 可以用嗎？

可以，只要你能在瀏覽器中於 claude.ai 開啟那段對話即可。我們不是 Anthropic。

如何儲存 Claude 對話？

安裝免費的 Chrome 擴充功能，在 claude.ai 開啟聊天，點橘色按鈕，選擇格式，再按「Export」。Markdown、文字、JSON、XML、CSV 或 PNG 都不需要帳號。這就是把 Claude 對話儲存成真正檔案的方法。另外兩種做法是列印網頁和 Anthropic 的帳號 ZIP，比較請看如何下載 Claude 聊天。

可以下載 Claude Code 的對話嗎？

只限 claude.ai 上的對話。網頁版 Claude Code（claude.ai/code）和 Cowork 工作階段可以像一般聊天一樣匯出。擴充功能不會讀取本機終端機的工作階段；那些要用 /export 或磁碟上的 JSONL 檔，請看 Claude Code 匯出。

Download Claude conversations 和 Anthropic 有關係嗎？

沒有。Claude 是 Anthropic, PBC 的商標。這是一款獨立的 Chrome 擴充功能，不是 Anthropic 的官方產品。
