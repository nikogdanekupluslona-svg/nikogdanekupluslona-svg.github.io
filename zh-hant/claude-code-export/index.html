Claude Code 匯出對話與 claude.ai：選對方法

終端機中的 Claude Code 匯出對話是什麼？

Claude Code 匯出指的是互動式 CLI 工作階段中的 /export 指令。Anthropic 的文件說明，它會顯示一個選單，讓你複製目前的對話或儲存成純文字檔，訊息和工具輸出都會轉成好讀的文字。在指令後加上檔名，就會略過選單，直接寫出那個檔案。

這不是來自 claude.ai 的 Markdown，不是這個 Chrome 擴充功能產生的 JSON，也不是 PDF，而是一份給人閱讀的對話紀錄。Anthropic 表示，磁碟上的 JSONL 紀錄檔是另一種供產品內部使用的格式，不是給你用的公開 API。

/export

要略過提示，直接在目前的工作目錄寫出指定名稱的檔案：

/export my-session

參數和檔名請以 Anthropic 的工作階段文件為準；它們會隨 Claude Code 版本而變。社群部落格只能當作參考。如果 /export 對話框的文字和你看到的不一樣，代表你的 CLI 是另一個版本；請使用產品內的說明，而不是 2025 年的截圖。

如果是腳本用途，Anthropic 指向其他介面：搭配 --output-format json 或 stream-json 的 claude -p、依工作階段 ID 繼續、接收 transcript_path 的 hooks，或 Agent SDK。這些都是 Claude Code 的開發者介面，不是本網站的 Chrome 擴充功能。

好讀的紀錄和結構化資料不同。/export 是給人看的對話紀錄；projects 資料夾下的 JSONL 是紀錄檔；Chrome 擴充功能的 JSON 則是第三種結構，只能從 claude.ai 頁面產生。不要為這三種寫同一個解析器。

如何從磁碟下載 Claude Code 對話？

如何從磁碟下載 Claude Code 對話：從 projects 目錄複製該工作階段的 JSONL 檔，或執行 /export 取得好讀的對話紀錄。macOS 和 Linux 的預設路徑在 ~/.claude/projects/ 下；Windows 則是 %USERPROFILE%\.claude\projects。檔名就是工作階段 ID。

專案資料夾的名稱，是把工作目錄中非英數字元換成連字號後的結果。轉換後名稱太長時，Anthropic 會截短並加上雜湊值，讓目錄符合檔案系統的限制。如果找不到資料夾，代表你啟動 Claude Code 時的工作目錄和你以為的不同。

JSONL 的每一行都是一個 JSON 物件，代表一則訊息、一次工具使用或中繼資料。Anthropic 表示，這種項目格式是內部格式，會隨版本變動。解析這些檔案的腳本，可能在某次 Claude Code 更新後失效。需要穩定的結果時，請優先使用 /export 或有文件說明的腳本介面。

儲存位置可以更改。CLAUDE_CONFIG_DIR 可以把設定目錄從 ~/.claude 移到別處。依 Anthropic 的說明，CLAUDE_CODE_PROJECT_DIR_NAME 搭配該設定目錄使用時，可以指定專案目錄的名稱（需要 Claude Code v2.1.234 以上）。settings.json 中的 cleanupPeriodDays 可以改變預設的保留期限。這些設定都不是 Download Claude conversations 的功能。

所以，要備份 Claude Code 對話檔案，方法就是：複製資料夾，或定期用 /export 匯出對話紀錄。本站不會加上「匯入 JSONL」按鈕，我們也不會讀取你的家目錄。

Claude Code 匯出能用這個擴充功能嗎？

終端機工作階段不行。Download Claude conversations 不會讀取本機的 Claude Code 工作階段。這個 Chrome 擴充功能只注入 claude.ai，看不到終端機，不能執行 /export，也不能開啟 JSONL。claude.ai/code 上的 Claude Code on the web 是例外：它是 claude.ai 的頁面，所以可以像一般聊天一樣匯出。如果你搜尋的是如何從 CLI 下載 Claude Code 對話，請照本頁的 CLI 步驟做。

會有人來到這裡，是因為 Google 把「Claude」和「匯出」歸在一起。這個 Chrome 商店頁面上的擴充功能仍然只支援 claude.ai。安裝後，iTerm、Ghostty、VS Code 的終端機或 Claude Code 的桌面外殼中都不會出現橘色按鈕。

如果你為同一個程式開發工作，在 claude.ai 上另外開了一段對話，那段瀏覽器聊天可以用擴充功能儲存。兩份紀錄不會合併。只在 CLI 中發生的工具呼叫，除非你貼到網頁上，否則不會出現在網頁匯出中。

每週我們都會收到同樣的客服信：有人安裝了 Chrome 擴充功能，以為會出現 /export。我們只解析 claude.ai。Claude Code 本來就提供 /export 和 JSONL。包裝 CLI 會是另一個產品，而我們並沒有推出。

這個擴充功能是 claude.ai 的工具，不是 Claude Code 外掛。它的限制只在你從 claude.ai 匯出時適用：Markdown、文字、JSON、XML、CSV 和 PNG 免帳號、不限次數；PDF 和批次 ZIP 用 Google 登入後每天免費 3 次；Pro（每月 US$3.99 或每年 US$26.99）可取消上限。這些都不會限制 /export。

可以匯出 Claude Code on the web 工作階段嗎？

可以。Claude Code on the web 在 claude.ai/code 上執行，所以 Download Claude conversations 可以像匯出任何 claude.ai 聊天一樣匯出這些工作階段。在 Chrome 中開啟工作階段，點橘色按鈕，選格式，再按「Export」（匯出）。這是這個擴充功能唯一支援的 Claude Code 介面。

格式和所有聊天一樣是七種：PDF、Markdown、Plain Text（純文字）、JSON、XML、CSV 和 PNG。Markdown、文字、JSON、XML、CSV 和 PNG 不限次數，也不需要帳號。PDF 需要 Google 登入，除非你是 Pro，否則與批次 ZIP 共用免費方案每天 3 次的額度。程式碼區塊會保留語言標籤。延伸思考是面板中的「Thinking」（思考過程）核取方塊；工具／MCP 步驟和網路搜尋來源則是設定中的選用開關。

網頁匯出的內容，就是 claude.ai/code 在瀏覽器中顯示的內容。它不是本機 CLI 執行的 JSONL 紀錄，也無法取得只在終端機中執行過的工作階段。依 Anthropic 的說明，Claude Code on the web 有自己的工作階段紀錄，與 CLI 的 ~/.claude/projects 目錄分開。終端機工作階段仍然要用 /export。

Claude Code 的對話紀錄存在哪裡？

Claude Code 的對話紀錄以 JSONL 格式存在設定目錄的 projects 資料夾下。macOS 和 Linux 的預設路徑是 ~/.claude/projects/<encoded-cwd>/<session-id>.jsonl；Windows 使用 %USERPROFILE%\.claude\projects。Anthropic 可能改變這個結構；如果磁碟上找不到路徑，請查看最新的工作階段文件。

「繼續」和「匯出」是不同的動作。claude --continue 和 claude --resume 會重新載入工作階段，讓你繼續工作；/export 則寫出一份可以放進 git 或寄出的副本。一個恢復上下文，另一個讓你帶走紀錄。Anthropic 的工作階段頁面說明了繼續時的權限模式、compact／摘要和選擇器的行為，這些都與本擴充功能無關。

依 Anthropic 的說明，桌面應用程式、Claude Code on the web 和 VS Code 擴充功能各自維護自己的工作階段紀錄。本指南的路徑是 CLI 的路徑。網頁工作階段留在 claude.ai/code 上，擴充功能可以在那裡匯出。不要以為 Desktop 的 Cowork 對話紀錄會和你在終端機中使用的 JSONL 放在同一個目錄。

不要把 JSONL 當成公開的結構定義。Anthropic 表示每行的格式會變。如果你還是要解析，請固定 Claude Code 的版本，並預期會出問題。/export 才是取得好讀 Claude Code 對話的穩定方法。

CLAUDE_CODE_SKIP_PROMPT_HISTORY 之類的環境變數可能會停止寫入對話紀錄。如果 projects 資料夾是空的，請檢查你是否關閉了保存功能、把 CLAUDE_CONFIG_DIR 指到別處，或從未在那個目錄中執行過互動式工作階段。

改在 claude.ai 上下載 Claude 聊天該怎麼做？

在 claude.ai 上下載 Claude 聊天：安裝 Download Claude conversations，在 Chrome 中開啟對話，點橘色按鈕，選 PDF、Markdown、純文字、JSON、XML、CSV 或 PNG。這是瀏覽器產品，也涵蓋 claude.ai/code 工作階段，但不是終端機的 Claude Code 匯出。逐步說明：如何下載 Claude 聊天。

要把整個 claude.ai 紀錄存成個別檔案，請用控制台（Dashboard）上的「Export All」（一次匯出全部），而不是 /export。在免費方案中，ZIP 裡的每段聊天都計入每天 3 次（與 PDF 共用，於 UTC 午夜重置）；Pro 可取消上限。指南：批次 Export All。格式：格式。

單一聊天的 Markdown、文字、JSON、XML、CSV 或 PNG 不需要帳號，而且不限次數。只有 PDF、批次 ZIP 和 Pro 會出現 Google 登入，讓我們計算每日額度並恢復 Pro。檔案在本機產生，PDF 也一樣。Pro 由 Paddle 計費，每月 US$3.99 或每年 US$26.99。這些都不適用於終端機中的 /export。

如果你的工作從 Claude Code 開始，後來把摘要貼到 claude.ai，就把網頁對話下載下來當筆記，並保留 /export 作為真正的 CLI 紀錄。兩個清楚的檔案，勝過一個混亂的檔案。

Claude Code 匯出和 Anthropic 官方的 Export data 有什麼不同？

Claude Code 匯出（/export 或 JSONL）針對的是一個終端機工作階段。官方的 Export data 是 claude.ai 上的 Settings → Privacy → Export data（若 claude.ai 設為中文，選單名稱可能顯示為中文）：稍後寄來的 Anthropic 帳號 JSON ZIP。兩者不是同一份封存檔，ZIP 也無法取代 /export。

某個 Claude Code 工作階段會不會出現在帳號 ZIP 中，取決於 Anthropic 如何儲存那個產品的資料，與這個擴充功能無關。除非 Anthropic 最新的隱私權文件另有說明，否則請把 ZIP 當作網頁帳號的備份。我們不會把 CLI 工作階段加進那個 ZIP。

如何從網站匯出 Claude 聊天，包括那個 ZIP 和擴充功能的比較，都寫在這裡：如何匯出 Claude 聊天。擴充功能的 PDF 匯出同樣不適用於終端機介面。只有當對話在 claude.ai（包括 claude.ai/code）上時，才請參考把 Claude 聊天下載成 PDF。

Claude Code、Desktop 和 claude.ai 的匯出有何不同？

Claude Code、Claude Desktop 和 claude.ai 是三個不同的介面。Claude Code 匯出使用 /export 和 JSONL。Desktop 是應用程式，沒有這個擴充功能的橘色按鈕。Chrome 中的 claude.ai 是 Download Claude conversations 唯一能執行的地方，claude.ai/code 上的 Claude Code on the web 也包括在內。把這些名稱混在一起，匯出就會在不知不覺中失敗。

Claude Desktop：如果聊天已同步到同一個 Anthropic 帳號，請在 claude.ai 上開啟並在那裡匯出。如果它只存在 Desktop 視窗中，請複製貼上，或等待官方的 Export data。指南：匯出 Claude Desktop 聊天。

VS Code 的 Claude Code 面板比較接近 CLI，而不是 claude.ai。不要期待我們的內容腳本會注入那個 webview。請在真正保存訊息的工作階段中使用 /export。

這是獨立開發的 Chrome 擴充功能，與 Anthropic, PBC 沒有關係。Claude 是 Anthropic 的商標。請遵守他們的服務條款。對於複製含有專有程式碼的工具輸出，我們無法提供法律建議；那是你、你的雇主和 Anthropic 之間的事。

常見問題：Claude Code 匯出

如何匯出 Claude Code 對話？

在 Claude Code 終端機中輸入 /export（可加上檔名）儲存轉換後的對話紀錄，或複製 JSONL 檔：macOS／Linux 在 ~/.claude/projects，Windows 在 %USERPROFILE%\.claude\projects。目前的對話框請看 Anthropic 的工作階段文件。

這個 Chrome 擴充功能能下載 Claude Code 聊天嗎？

終端機中的不行。Download Claude conversations 只在 Chrome 中的 claude.ai 上運作，無法讀取本機終端機工作階段、JSONL 對話紀錄或 /export 指令。claude.ai/code 上的 Claude Code on the web 工作階段則可以像一般聊天一樣匯出。

可以匯出 Claude Code on the web（claude.ai/code）嗎？

可以。在 Chrome 中開啟 claude.ai/code 上的工作階段，使用橘色按鈕。PDF、Markdown、純文字、JSON、XML、CSV 和 PNG 都可以。PDF 以外的六種格式免帳號、不限次數；PDF 需要 Google 登入，計入每天 3 次的免費額度。

Claude Code 的對話紀錄存在哪裡？

工作階段的對話紀錄是 ~/.claude/projects/<encoded-working-directory>/ 下的 JSONL 檔，以工作階段 ID 命名。確切的結構可能會變。想要好讀的檔案而不是解析 JSONL 時，請用 /export。CLAUDE_CONFIG_DIR 可以移動這個目錄。

如何把 Claude Code 對話下載成 Markdown？

Claude Code 的 /export 產生的是純文字對話紀錄，不是這個擴充功能的 Markdown。如果一定要 Markdown，請用 Download Claude conversations 匯出 claude.ai/code 工作階段或 claude.ai 上的工作副本，或自行轉換 /export 的文字。我們不提供 JSONL 轉 Markdown。

改為下載 Claude.ai 對話該怎麼做？

安裝免費的 Chrome 擴充功能，在 claude.ai 開啟聊天，使用橘色按鈕；要匯出整個紀錄則用「Export All」。請看如何下載 Claude 聊天。Markdown、文字、JSON、XML、CSV 和 PNG 免帳號、不限次數；PDF 和批次 ZIP 用 Google 登入後每天免費 3 次；Pro 每月 US$3.99 或每年 US$26.99。

/export 和官方的 Export data 一樣嗎？

不一樣。/export 針對目前的 Claude Code 工作階段。Settings → Privacy → Export data 則會用電子郵件寄來 Anthropic 帳號的 JSON ZIP。不同的產品介面、不同的檔案、不同的等待時間。

可以用 jq 解析 Claude Code 的 JSONL 嗎？

可以，但要注意 Anthropic 公布的但書：每行的結構是內部格式，可能會變。需要穩定的格式時，請優先使用 /export 或 claude -p --output-format json。如果還是要解析 JSONL，請固定 CLI 的版本。

Claude Code 匯出在 Windows 上能用嗎？

能。/export 是 CLI 指令。除非你設定了 CLAUDE_CONFIG_DIR，否則磁碟上的對話紀錄位於 %USERPROFILE%\.claude\projects。這個 Chrome 擴充功能仍然無法在那個終端機中執行。

Claude Code 和 Claude Desktop 一樣嗎？

不一樣。Claude Code 是終端機中的程式開發代理，Claude Desktop 是聊天應用程式，claude.ai 是網站。只有網站（包括 claude.ai/code）能使用這個擴充功能。Desktop 匯出說明：Claude Desktop。

這個擴充功能將來會包裝 /export 嗎？

1.16.2 版不會。產品範圍是 claude.ai，包括 Claude Code on the web：七種格式、本機檔案、只有 PDF、批次匯出和 Pro 需要 Google 登入。如果範圍有變，本頁會說明。在那之前，終端機的 Claude Code 匯出請使用 Anthropic 的 CLI。

/export 包含工具輸出嗎？

Anthropic 說明 /export 會把訊息和工具輸出轉成好讀的文字。那是他們的對話紀錄，不是我們的解析器。要知道目前確切的內容，請在你的版本上執行 /export 並閱讀檔案，因為文件可能比版本更新慢一步。

可以批次匯出 Claude Code 工作階段嗎？

本機 CLI 工作階段不行。控制台上的「Export All」只適用於 claude.ai。要處理很多 CLI 工作階段，請複製 projects 資料夾，或逐一執行 /export。JSONL 沒有橘色按鈕式的批次匯出。
