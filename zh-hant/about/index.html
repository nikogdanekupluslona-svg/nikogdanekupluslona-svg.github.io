關於 Chat Downloader

關於 Chat Downloader：Download Claude conversations 是一款獨立的 Chrome 擴充功能（網站名稱：Chat Downloader）。搜尋引擎和使用者也稱它為 Claude Chat Downloader 或 Claude Conversation Downloader。它不是由 Anthropic, PBC 開發，與 Anthropic 沒有關聯，也未獲其背書。Claude 是 Anthropic 的商標。我們開發這個擴充功能，是為了補上 claude.ai 本身的缺口：claude.ai 沒有內建方法，可以把單一對話下載成檔案。

這個擴充功能會在 claude.ai 加上一個匯出按鈕，並提供批次匯出用的 Dashboard（控制台），在你的瀏覽器中於本機寫出 PDF、Markdown、純文字、JSON、XML、CSV 或 PNG 檔案。單一聊天匯出成 Markdown、文字、JSON、XML、CSV 和 PNG 不限次數，也不需要帳號。PDF 和批次 ZIP 需要 Google 登入，每天免費 3 次；Pro（每月 US$3.99 或每年 US$26.99）沒有這個上限。支援一般聊天、Projects、Cowork 工作階段，以及 Claude Code 網頁版（claude.ai/code）。詳情請見運作方式。它不會匯出 Claude Code 的終端機工作階段。

  • 簡短說明（132 字元以內）： Free Chrome extension to save claude.ai chats as PDF, Markdown, text, JSON, XML, CSV or PNG — one chat or bulk Export All.
