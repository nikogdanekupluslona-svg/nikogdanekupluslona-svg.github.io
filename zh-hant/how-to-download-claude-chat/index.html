如何用 Chrome 下載 Claude 聊天？

如何下載 Claude 聊天？最直接的答案，就是 Download Claude conversations 在 claude.ai 訊息輸入框旁加上的橘色按鈕。開啟對話，選 PDF、Markdown、JSON、文字、XML、CSV 或 PNG，再按「Export」（匯出）。檔案在你的瀏覽器中組成，並儲存到磁碟。

這個擴充功能是一個 Chrome 內容腳本（content script）。它讀取你已登入的 claude.ai 工作階段中已經載入的對話，不會用自己的憑證另外呼叫 Anthropic API，也不會為了產生檔案而把對話上傳到我們的伺服器。

  1. 從 Chrome Web Store 安裝 Download Claude conversations（可載入 Chrome 擴充功能的 Chromium 系瀏覽器也可以）。
  2. 如果安裝時 claude.ai 已經開著，請重新載入頁面。
  3. 開啟你要的對話網址。橘色按鈕只會出現在真正的對話中，不會出現在空白的輸入首頁。
  4. 點訊息輸入框右側的圓形橘色下載按鈕。面板會打開，裡面有 Messages（訊息：All / Human / Assistant，全部／使用者／助理）、Format（格式）、Thinking（思考過程）、Select（選取）、Copy（複製）和 Export。
  5. 選擇 PDF、Markdown、Plain Text（純文字）、JSON、XML、CSV 或 PNG，按 Export，Chrome 會立刻下載檔案。

Markdown、純文字、JSON、XML、CSV 或 PNG 都不需要帳號。這些單一聊天匯出不限次數而且免費：不用登入，也沒有計數。只有在選 PDF 或執行批次「Export All」（一次匯出全部）時，才會出現 Google 登入。這不是用來讀取你聊天內容的登入，對話內容一直留在你的電腦上。

PDF 和批次 ZIP 共用每天 3 次的免費額度，於 UTC 午夜重置。批次 ZIP 裡的每一個聊天都算一次。Pro 每月 US$3.99 或每年 US$26.99，可取消這個上限。PDF 的選項和步驟請看：把 Claude 聊天下載成 PDF。

本機檔案。每種格式（包括 PDF）都在瀏覽器中產生，再交給 Chrome 的下載 API。聊天文字絕不會被上傳。只有 PDF 和批次匯出會用你的 Google 電子郵件做一次額度檢查。

同一個面板可以依發話者篩選：All、Human 或 Assistant。Thinking 核取方塊決定要不要包含延伸思考。Select 讓你勾選個別訊息，檔案裡就只放那幾輪對話。Copy 會把 Markdown、文字、JSON、XML 或 CSV 放到剪貼簿，而不是下載檔案。工具／MCP 步驟和網路搜尋來源是在設定中另外開啟的選項。中繼資料和 artifact 版面（"Original"、"Inline"、"Nested" 或 "Flat"）則在控制台（Dashboard）中設定。

如果對話很長，請一路捲動，讓 claude.ai 載入較早的訊息。擴充功能只能匯出頁面已經顯示出來的內容。載入一半的對話就會產生一半的檔案，看起來像錯誤，其實通常只是還沒捲動到的 DOM。

我們解析你已經開啟的 claude.ai 頁面上的訊息樹。程式碼區塊保留語言標籤和縮排，表格仍是表格。PDF 也是在瀏覽器中從同一棵樹產生，不經過列印對話框，所以可列印的檔案不再等於網頁截圖。

不裝擴充功能能下載 Claude 聊天嗎？

可以。不裝擴充功能，也能透過列印網頁或申請 Anthropic 的帳號匯出來下載 Claude 聊天。列印得到的是網頁的視覺 PDF；Export data 則是稍後寄來、涵蓋整個帳號的 JSON ZIP。兩者都不會產生單一聊天的 Markdown 檔。

列印的方法：在 claude.ai 開啟對話，介面允許的話先隱藏側邊欄，按 Ctrl+P（Windows/Linux）或 Cmd+P（Mac），把目的地設為「另存為 PDF」，然後儲存。程式碼區塊常常被切到不同頁，輸入框等介面元素也可能出現在每一頁。擴充功能本身的 PDF 匯出則會跳過這個對話框。兩種做法的比較請看把 Claude 聊天下載成 PDF。

官方的方法：claude.ai 上的 Settings → Privacy → Export data（若 claude.ai 設為中文，選單名稱可能顯示為中文）。Anthropic 會寄出一個會過期的連結。ZIP 是帳號層級的 JSON 封存檔，而不是你剛才在讀的那段聊天的具名檔案。把它當作備份，如果要從上千段對話中取出一段，就得自己解開。

複製貼上是第三種不用擴充功能的方法：選取文字，貼到 Google 文件或筆記 App。程式碼的縮排通常會消失，表格會變成一整串文字，多輪對話會變成沒有結構的一大段。只要一則簡短回答還可以；如果是之後要搜尋的程式碼審查，就不太適合。擴充功能的 Copy 按鈕則會把乾淨的 Markdown 放進剪貼簿。

如何批次下載 Claude 聊天紀錄？

要把 Claude 聊天紀錄下載成許多檔案，不必每個分頁都按一次橘色按鈕。從擴充功能的彈出視窗開啟「View and Download All Conversations」（檢視並下載所有對話），篩選清單，再按 Export All。Export All 需要用 Google 登入。免費方案中，ZIP 裡的每個聊天都會用掉每天 3 次額度中的一次，這個額度與 PDF 共用。Pro 沒有上限。

控制台會列出你目前登入的 claude.ai 帳號中的對話。可以依名稱搜尋，依 All conversations、New、Updated 或 Previously exported（全部、新的、已更新、已匯出過）篩選，在 Chat 和 Cowork 分頁之間切換；如果你在 claude.ai 上用 Project 分類聊天，也可以依 Project 搜尋。不想把每一份舊草稿都放進資料夾時，就只選一部分。

批次匯出會產生一個 ZIP，每個聊天一個檔案，格式由「Chat format」選單決定，七種格式都可以，包括 PDF。它使用和單一聊天匯出相同的解析器。核取方塊決定要放進哪些內容：Chats、Thinking、Metadata、Tools、Sources（聊天、思考過程、中繼資料、工具、來源），另外還有 artifact 版面。Export All 不是比較陽春的流程，而是同一個解析器一次套用到許多對話 ID。細節和截圖：批次 Export All。

Anthropic 的 Export data 仍然是帳號備份：一個 ZIP、一封電子郵件、全部都是 JSON，連你忘記的聊天也在裡面。批次 Export All 則是相反的用途：由你挑選對話、挑選格式，ZIP 立刻下載。如果你既想要一份正式的封存，又想要一個好讀的筆記資料夾，兩者都用。

額度共用，每日計算。在免費方案中，PDF 匯出和批次中的聊天共用每天 3 次，於 UTC 午夜重置。如果選了 40 段對話，整批都會被擋下，而不是只匯出一部分。請少選一些，或升級到 Pro（每月 US$3.99 或每年 US$26.99）。

控制台也會記得你已經匯出過哪些對話，所以下次可以只篩選 New 或 Updated。這樣每週下載 Claude 聊天紀錄的習慣就能只補上新的部分，而不會重複上個月的 Markdown。

如何把 Claude 聊天下載成 Markdown 或 JSON？

要把 Claude 聊天下載成 Markdown 或 JSON：打開橘色按鈕，選擇格式，再按 Export。Markdown 是筆記檔，JSON 是給腳本用的訊息樹，純文字沒有任何標記，CSV 是每則訊息一列，PDF 是分頁的文件，PNG 是一張圖片。

Markdown 保留標題、附語言標籤的程式碼區塊和表格，是 Obsidian、GitHub 或 wiki 的常見選擇。JSON 保留解析器已經建好的樹狀結構，開啟對應選項時也包括 artifact 和思考過程。它的結構和 Anthropic 的帳號 ZIP 不同。格式說明：所有格式。

當目的地本來就會去掉標記時，純文字是正確選擇，例如貼到工單欄位、電子郵件內文，或只要原始字串的搜尋索引。XML 是較小眾的資料交換格式。CSV 可以用 Excel、Google 試算表或 Numbers 開啟。PNG 適合放進簡報或錯誤回報的對話截圖，不適合之後要用 grep 搜尋的 40 輪設計審查。

擴充功能會記住上次使用的格式。如果你想要 Markdown 卻拿到 JSON，那是因為下拉選單還停在上次匯出的 JSON。每次換用途時，都請確認一下下拉選單。

儲存 Claude 對話，和列印或 ZIP 有什麼不同？

在 claude.ai 上，儲存、下載和匯出是同一件事：把對話從網頁上帶走。要把 Claude 對話儲存成可用的檔案（包括 PDF），用擴充功能。列印只是快照，Anthropic 的 Export data 則是帳號 ZIP。

團隊裡常常混著說：研究人員說「儲存」，開發者說「匯出」，主管說「下載」。在本網站上，只要是在 Chrome 中使用 claude.ai，這三個動詞指的都是同一顆橘色按鈕。相關教學如何匯出 Claude 聊天會更深入說明官方 ZIP 和 JSON 的結構。

列印仍然有用：當你需要一份和 claude.ai 畫面一模一樣的一次性附件。官方的 Export data 也仍然有用：離職、法律保全，或多一層保險的備份。但兩者都無法取代你下週還要編輯的 Markdown 檔。

Claude Desktop 是另一個視窗。Chrome 擴充功能不會注入到 Desktop App 中。如果同一段聊天也在 claude.ai 上，就在那裡開啟並下載。如果只存在於 Desktop，就複製貼上，或等帳號 ZIP。步驟：匯出 Claude Desktop 聊天。

Pro 的付款由 Paddle 處理，我們看不到卡號。Google 登入只用於 PDF、批次匯出和 Pro，並不會讓我們取得對話內容。負責檢查額度和 Pro 狀態的 Cloudflare worker 收到的是你的 Google 電子郵件，而不是訊息文字。其他單一聊天匯出則什麼都不傳送。這條界線就是隱私的全部：帳務在伺服器，聊天在你的磁碟。

為什麼看不到 Claude 聊天的下載按鈕？

看不到 Claude 聊天的下載按鈕，通常是因為你不在對話網址上、安裝後沒有重新載入分頁，或擴充功能被停用了。請釘選圖示、重新載入，並確認你是在桌面版 Chrome 上使用 claude.ai，而不是 Desktop App、手機或 Claude Code 終端機。

安裝後，Chrome 不一定會把內容腳本注入到已經開啟的分頁。請關閉 claude.ai 分頁，或強制重新載入。如果你使用多個設定檔，擴充功能必須安裝在已登入 Anthropic 的那個設定檔中。

只要能在瀏覽器中開啟對話，Team 和 Enterprise 工作區都可以使用。擴充功能讀取的是頁面，而不是方案等級。如果公司封鎖 Chrome 擴充功能，就需要 IT 允許這一個；我們無法從網站繞過這項政策。

登入提示：只有 PDF 和 Export All 才會出現。Markdown、文字、JSON、XML、CSV 和 PNG 匯出都不需要帳號。第一次 PDF 或批次匯出時會要求 Google 登入。取消登入提示看起來就像下載失敗。請完成登入，再按一次 Export。免費方案不需要信用卡。

檔案不完整：對話還沒串流完成，或較早的訊息仍在畫面外、尚未渲染。等助理回答完畢，把長對話往開頭捲動，讓 claude.ai 載入那些節點，再匯出一次。重新匯出 Markdown 或 JSON 不需任何成本；在免費方案中，重新匯出 PDF 會再用掉每天 3 次中的一次，所以最好先確認對話已經完全載入。

檔案類型不對：還選著上次用的格式。帳號不對：你用來登入 Google 的地址，不是擁有 Pro 的那一個。Pro 的恢復綁定在那個 Google 電子郵件上，而不是 Anthropic 帳號，也不是 Chrome 設定檔的名稱。

行動瀏覽器無法執行這個擴充功能，也沒有 iOS 或 Android App。手機上的 Safari 可以列印，但無法顯示橘色按鈕。想要可重複使用的檔案，請在桌面版 Chrome 中開啟同一段聊天。

可以從 Claude Code 下載 Claude 聊天嗎？

只有網頁版 Claude Code 可以。claude.ai/code 上的工作階段是在 Chrome 中開啟的，所以 Download Claude conversations 可以像一般聊天一樣匯出。本機的 Claude Code 終端機工作階段則不同：匯出終端機工作階段要用 /export，或 ~/.claude/projects 底下的 JSONL 檔。介面不同，檔案也不同。

在進行中的 Claude Code 工作階段裡輸入 /export。Anthropic 的 CLI 會開啟選單，讓你複製對話紀錄或儲存成純文字檔；直接指定檔名就能跳過選單。那份紀錄是給人閱讀的純文字，不是這個擴充功能的 Markdown、JSON 或 PDF。完整路徑請看：Claude Code 匯出。

磁碟上的 JSONL 是內部紀錄，結構可能隨 Claude Code 版本而改變。Anthropic 自己的文件也建議優先使用 /export 或腳本介面，而不是解析 JSONL。我們沒有包裝那個 CLI，也不會讀取 ~/.claude。

如果你在 claude.ai 上為同一件工作另開了一段對話，就用橘色按鈕下載那段瀏覽器聊天。終端機紀錄和網頁聊天不會自動成為同一份文件。除非你把其中一個貼進另一個，否則請把它們當成兩份紀錄。

常見問題：如何下載 Claude 聊天

如何在 Chrome 中下載 Claude 聊天？

安裝 Download Claude conversations，在 claude.ai 開啟對話，點訊息輸入框右側的橘色按鈕，選 PDF、Markdown、JSON、文字、XML、CSV 或 PNG，再按 Export。檔案會下載到本機。除了 PDF 需要 Google 登入，其他都不需要帳號。

不裝擴充功能能下載 Claude 聊天嗎？

可以。列印網頁（Ctrl/Cmd+P → 另存為 PDF）可得到視覺副本，或用 Settings → Privacy → Export data 取得稍後寄來的帳號 JSON ZIP。簡短回答可以複製貼上。但這些方法都無法像 Chrome 擴充功能那樣，為每段聊天產生結構化的 Markdown 檔。

如何下載 Claude 聊天紀錄？

單一對話用橘色按鈕。要很多檔案時，從擴充功能的彈出視窗開啟 View and Download All Conversations，再按 Export All。批次匯出需要 Google 登入，在免費方案中計入每天 3 次的額度。這個批次流程不是 Anthropic 的 Export data ZIP；官方 Export data 是整個帳號的一個封存檔，稍後才寄到信箱。請看批次下載。

下載 Claude 聊天需要付費嗎？

不用。Markdown、純文字、JSON、XML、CSV 和 PNG 匯出不限次數、免費，也不需要帳號。PDF 和批次 ZIP 用 Google 登入後每天最多免費 3 次；批次 ZIP 中每個聊天算一次。Pro 每月 US$3.99 或每年 US$26.99，可取消這個上限。付款由 Paddle 處理。

Download Claude conversations 可以在手機上用嗎？

不行。它是給桌面版 Chrome（或其他可安裝 Chrome Web Store 項目的 Chromium 瀏覽器）用的擴充功能，沒有 iOS 或 Android App。行動瀏覽器仍然可以列印 Claude 聊天，但無法執行這個擴充功能。

這樣會讓我的 Anthropic 帳號被停權嗎？

我們無法提供法律建議。擴充功能讀取的是你在自己的工作階段中已經載入的 claude.ai 頁面，不會用另外的憑證呼叫 Anthropic，也不會在你的帳號上自動點擊。我們不是 Anthropic。請遵守他們的服務條款和你公司的規定。

如何把 Claude 對話儲存成檔案？

要把開啟中的聊天存成乾淨的檔案（包括 PDF），用 Chrome 擴充功能。要網頁快照，就列印。要整個帳號的 ZIP，就用 Anthropic 的 Export data。當你想把對話從畫面上帶走時，儲存、下載和匯出在 claude.ai 上指的都是同一件事。

Claude Code 的工作階段也可以嗎？

只有網頁版可以。claude.ai/code 上的 Claude Code 工作階段可以像一般 claude.ai 聊天一樣匯出。本機終端機工作階段不行：請使用 /export，或從 ~/.claude/projects（Windows：%USERPROFILE%\.claude\projects）複製 JSONL。這個 Chrome 擴充功能只在 claude.ai 上執行。教學：Claude Code 匯出。

下載 Claude 聊天一定要用 Google 登入嗎？

不用，Markdown、純文字、JSON、XML、CSV 或 PNG 都不需要。只有 PDF、批次 Export All 和 Pro 需要 Google 登入，這樣我們才能套用每天 3 次的上限，並在重新安裝後恢復 Pro。登入時不會傳送對話內容。我們只儲存經過驗證的電子郵件，用於額度和 Pro 狀態。

Claude 聊天可以下載成哪些格式？

在擴充功能 1.16.2 中共有七種：PDF、Markdown、JSON、純文字、XML、CSV 和 PNG。PDF 在瀏覽器中產生，不經過列印對話框。CSV 是每則訊息一列。PNG 是對話的圖片。格式總覽：格式。

可以從 Team 或 Enterprise 工作區匯出嗎？

可以，只要你能在 Chrome 中於 claude.ai 開啟對話。擴充功能是根據渲染出來的頁面運作，而不是只限個人版的 API。如果公司政策封鎖擴充功能，那是 IT 的決定，不是我們設定裡的方案開關。

Claude Chat Downloader 和這個產品是同一個嗎？
