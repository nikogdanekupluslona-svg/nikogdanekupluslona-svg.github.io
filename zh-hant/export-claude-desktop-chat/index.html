為什麼這裡無法匯出 Claude Desktop 聊天？

Download Claude conversations 是在 claude.ai 上執行的 Chrome 內容腳本（content script），而 Claude Desktop 是獨立的 Mac／Windows 應用程式。那個視窗裡沒有擴充功能工具列，所以橘色按鈕永遠不會出現。在 Desktop 開著的時候從 Chrome Web Store 安裝，也不會對 Desktop 產生任何作用。

Chrome 擴充功能只會在符合主機權限的網頁上執行，而本擴充功能對應的是 claude.ai 的對話頁面。Claude Desktop 不是 claude.ai 分頁，你也無法在 Desktop App 裡按「Add to Chrome」（加到 Chrome）。1.16.2 版（2026 年 9 月）仍然沒有 Desktop 外掛、選單列小工具，也不會讀取 Desktop 安裝資料夾裡的檔案。

硬性限制。你無法在 Desktop 裡用這個 Chrome 擴充功能匯出 Claude Desktop 聊天。如果需要用我們的小工具取得 PDF、Markdown、JSON、文字、XML、CSV 或 PNG，請離開 Desktop，在 Chrome 開啟 https://claude.ai，並在那裡開啟對話。

大家會搜尋「Claude Desktop 匯出對話」（香港使用者也常打「導出」），是因為這幾個產品共用同一個品牌，搜尋結果把 Desktop、claude.ai 和 Claude Code 混在一起。但它們的檔案不能互換：Desktop 截圖不是 Markdown 匯出，Code 的 JSONL 記錄也不是 claude.ai 的對話。這一頁就是要把這個落差講清楚。

Claude Desktop、claude.ai 與 Claude Code 的匯出有何不同？

Claude Desktop 是聊天 App，claude.ai 是瀏覽器版產品，Claude Code 是終端機代理。只有 Chrome 裡的 claude.ai 能用 Download Claude conversations。因此，匯出 Claude Desktop 聊天是一個要找替代方案的問題，而不是在 App 裡按橘色按鈕就能解決的事。

如何透過 claude.ai 匯出 Claude Desktop 聊天？

許多 Desktop 工作階段和網頁版使用同一個 Claude 帳號。如果那段對話出現在你的 claude.ai 紀錄中，就在 Chrome 開啟它，並使用 Download Claude conversations。這是本擴充功能協助你匯出 Claude Desktop 聊天的唯一方式：聊天必須先在 claude.ai 上載入。

  1. 別在 Desktop 裡摸索了。在 Chrome 開啟 https://claude.ai，用同一個帳號登入。
  2. 在網頁版紀錄中找到那段對話。如果找不到，就跳到複製貼上或 Export data；Chrome 從未載入過的聊天，我們無法取得。
  3. 點橘色按鈕，選擇 PDF、Markdown、Plain Text、JSON、XML、CSV 或 PNG，再按「Export」（匯出）。
  4. 有很多已同步的對話時，開啟「View and Download All Conversations」（查看並下載所有對話），執行「Export All」。Dashboard（控制台）有 Chat 和 Cowork 兩個分頁。在免費方案中，ZIP 裡的每個聊天都會計入每天 3 次。
  5. 如果需要 PDF，就在同一個面板選 PDF：檔案在瀏覽器中產生，不經過列印對話框。教學：把 Claude 聊天存成 PDF。

網頁版的 Markdown、文字、JSON、XML、CSV 和 PNG 匯出不限次數、免帳號。只有 PDF 和批次 ZIP（兩者共用每天 3 次免費額度，UTC 午夜重置），以及恢復 Pro（每月 US$3.99 或每年 US$26.99）時，才需要 Google 登入。這個額度只適用於 claude.ai 的檔案；Desktop 的複製貼上完全不經過擴充功能，所以不會用到我們的額度。Pro 由 Paddle 收費，我們永遠看不到卡號。

同步是 Anthropic 的行為，不是我們的。如果 Desktop 顯示的聊天在 claude.ai 上找不到，這個 Chrome 擴充功能也無法憑空變出來。請稍等、重新整理 claude.ai，或改用複製貼上／官方 ZIP。我們不會讀取 Desktop 的本機資料庫。分頁開好之後，網頁版匯出工具如何運作，請見運作方式。

到了 claude.ai 之後可用的格式。PDF 用來分享或列印，Markdown 用於筆記，JSON 給工具使用，文字適合最簡單的封存，XML 用於資料交換，CSV 用於試算表，PNG 則是一張圖片。和其他教學一樣是這七種格式，總覽請見格式。這些格式都不會透過本擴充功能出現在 Desktop App 裡。

可以用複製貼上匯出 Claude Desktop 聊天嗎？

可以。在 Claude Desktop 選取文字，貼到文件中。當對話沒有出現在 claude.ai 上時，這是最實在的備案。但你會失去程式碼區塊的完整格式、Artifact 版面、思考過程的開關，以及批次「Export All」。短短一則回答還可以；很長的程式開發對話就很痛苦。

正因為從 Desktop 複製貼上很麻煩，claude.ai 上才有這個 Chrome 擴充功能：網頁版小工具會保留語言標示、表格，以及「Original」「Inline」「Nested」「Flat」（原始／內嵌／巢狀／平面）等 Artifact 版面。Desktop 裡沒有我們提供的任何匯出控制項。如果能把同一段對話移到 claude.ai 上，就別再複製貼上，直接在那裡使用 Download Claude conversations。

Claude Desktop 的截圖是另一個備案，但那是圖片，不是 Markdown，不算是能重複使用的檔案形式的「匯出 Claude Desktop 聊天」。我們擴充功能產生的 PNG 雖然也是圖片，但只有在聊天於 claude.ai 開啟後才能產生。別期待能從 Desktop 視窗得到那張 PNG。

Export data 包含 Claude Desktop 聊天嗎？

Anthropic 的 Settings → Privacy → Export data（若 claude.ai 介面設為中文，選單名稱可能已翻譯）會把 JSON ZIP 寄到你的電子郵件。這個 ZIP 綁定的是 Claude 帳號，而不是你在哪個視窗輸入。如果 Desktop 的對話儲存在該帳號中，就可能出現在裡面。請把這個 ZIP 當作備份，而不是本擴充功能產生的 Markdown。

ZIP 來得慢、連結會過期，也沒有 PDF、Markdown、文字、XML、CSV 或 PNG 的格式選項。不過，當你需要把 Claude Desktop 聊天紀錄整包帶走時，它仍然是官方做法。與列印和 Chrome 小工具的比較，請見如何匯出 Claude 聊天。

別把這個 ZIP 和我們 Dashboard 上的批次「Export All」搞混。「Export All」會立即以你選的格式，為你在 claude.ai 選取的每個聊天各寫出一個檔案，打包成一個 ZIP。在免費方案中，ZIP 裡的每個聊天都會用掉每天 3 次中的一次（與 PDF 共用）；Pro 沒有上限。官方 Export data 不會用到我們的額度。從未同步過、只存在 Desktop 的聊天，可能兩邊都找不到。

Claude Desktop 和 Claude Code 是同一個東西嗎？

不是。Claude Desktop 是聊天 App；Claude Code 是終端機裡的程式開發代理，有 /export 和 JSONL 對話紀錄。如果你要處理的是 IDE 終端機，搜尋「匯出 Claude Desktop 聊天」就找錯產品了。這個 Chrome 擴充功能在兩者中都無法執行。唯一的例外是 claude.ai/code 上的 Claude Code 網頁版：它是 claude.ai 頁面，所以能像一般聊天一樣匯出。

如果你說的「桌面」是指 VS Code 或桌面上的終端機，請看 Claude Code 匯出。如果指的是 Anthropic 的 Desktop 聊天 App，就繼續看本頁。把兩者混在一起只會浪費時間：磁碟上的 JSONL 不是橘色按鈕，Desktop 的複製貼上也不是 /export。

Download Claude conversations 不會因為 Desktop 和 Code 都「不是瀏覽器」，就加上 Code 的掛鉤。這個產品刻意保持專注：Chrome 裡的 claude.ai、七種格式、除了 PDF 和批次 ZIP（每天免費 3 次）以外都不限次數且免帳號，Pro 為每月 US$3.99 或每年 US$26.99。功能範圍請見功能。偏好「擷取」說法的網頁按鈕介紹，請見 Claude 對話擷取工具。

匯出 Claude Desktop 聊天：我們不會做的事

我們不提供 Claude Desktop 外掛、選單列 App，也沒有「從 Desktop 匯出」的開關。我們不會讀取你 Mac 或 Windows 上 Claude Desktop 安裝的檔案，也不取代 Claude Code 的 /export。這些就是 1.16.2 版在匯出 Claude Desktop 聊天上的產品界線。

我們也不會提及其他 Chrome 匯出工具的名稱。本頁提到 Anthropic 的官方產品（claude.ai、Claude Desktop、Claude Code、Settings → Privacy → Export data）只是作為對照。Download Claude conversations 仍是獨立開發的產品，與 Anthropic, PBC 無關。本頁對擴充功能的所有描述都是指網頁版擴充功能，而不是一個不存在的 Desktop 產品。

如果你只用 Desktop，在 Anthropic 於 App 中推出單一聊天的檔案匯出之前，請使用複製貼上和官方 ZIP。如果你也使用 claude.ai，就安裝擴充功能並從瀏覽器匯出。我們能老實提供的就是這些。Claude 的手機 App 同樣不在本擴充功能的範圍內。

網頁版做法的額度提醒。在 claude.ai 開啟已同步的聊天後，Markdown、文字、JSON、XML、CSV 和 PNG 匯出不限次數、免帳號。PDF 和批次 ZIP 需要 Google 登入，每天免費 3 次；Pro（每月 US$3.99 或每年 US$26.99）沒有上限。Desktop 的複製貼上永遠不會增加這個計數。

疑難排解：已安裝擴充功能但 Desktop 裡沒有按鈕，這是正常的。claude.ai 上沒有按鈕，請重新整理、釘選圖示，並開啟一個對話網址。聊天在 Desktop 裡有、網頁版沒有，這不是擴充功能的錯誤。搞錯產品（Code 還是 Desktop），請確認你是否在終端機裡。到了網頁版後需要 PDF，請在匯出面板選 PDF（需 Google 登入，每天免費 3 次）。

常見問題：匯出 Claude Desktop 聊天

以下常見問題涵蓋匯出 Claude Desktop 聊天的各個面向：為什麼沒有橘色按鈕、對話有同步時如何使用 claude.ai、複製貼上、官方 Export data，以及 Claude Code。答案以 1.16.2 版為準，頁首的 FAQPage 結構化資料與此清單一致。

可以用這個擴充功能匯出 Claude Desktop 聊天嗎？

不行。Download Claude conversations 在 Chrome 裡的 claude.ai 上執行，橘色按鈕永遠不會出現在 Claude Desktop 視窗中。1.16.2 版沒有 Desktop 外掛。

如何匯出 Claude Desktop 對話？

如果對話有同步，就在 Chrome 的 claude.ai 開啟同一段聊天，再用擴充功能匯出（包括 PDF）。否則請從 Desktop 複製貼上，或用 Settings → Privacy → Export data 取得整個帳號的 JSON ZIP。

Claude Desktop 和 Claude Code 是同一個東西嗎？

不是。Desktop 是聊天 App；Claude Code 是終端機代理，有 /export 和 JSONL 對話紀錄。這個 Chrome 擴充功能在兩者中都無法執行；只有 claude.ai/code 上的 Claude Code 網頁版能像一般聊天一樣匯出。

官方 Export data 包含 Desktop 聊天嗎？

帳號 ZIP 綁定你的 Claude 帳號。如果 Desktop 的對話儲存在帳號中，就可能出現在裡面。但它仍是備份 ZIP，不是本擴充功能產生的單一聊天 Markdown。

開啟 claude.ai 之後就能匯出 Claude Desktop 聊天嗎？

可以，前提是對話能在 claude.ai 上載入。之後 Download Claude conversations 就能寫出 PDF、Markdown、Plain Text、JSON、XML、CSV 或 PNG。從未同步的聊天只能靠複製貼上或 ZIP。

這個擴充功能能讀取我的 Claude Desktop 安裝資料夾嗎？

不能。我們不會掃描 Mac 或 Windows 上的 Desktop 檔案。內容腳本只看得到 Chrome 已經顯示出來的 claude.ai 頁面。

在網頁版匯出 Claude Desktop 聊天需要 Pro 嗎？

不需要。Markdown、文字、JSON、XML、CSV 和 PNG 匯出不限次數、免費且免帳號。PDF 和批次 ZIP 用 Google 登入後每天免費 3 次；Pro（每月 US$3.99 或每年 US$26.99）沒有上限。在 Desktop 裡複製貼上不會用到我們的額度。

可以用這個工具把 Claude Desktop 聊天匯出成 PDF 嗎？

可以，只要聊天已在 Chrome 的 claude.ai 開啟。在匯出面板選 PDF，檔案就會在瀏覽器中產生。這需要 Google 登入，並計入每天 3 次免費額度。我們沒有為 Desktop 本身提供任何 PDF 流程。

按「Add to Chrome」就能匯出 Claude Desktop 聊天嗎？

不能。安裝 Download Claude conversations 只會影響 Chrome 裡的 claude.ai，Desktop 不會有任何變化。請釘選擴充功能，然後在瀏覽器分頁中操作。

有辦法用手機匯出 Claude Desktop 聊天嗎？

用這個擴充功能不行。它需要電腦版 Chrome 上的 claude.ai。手機瀏覽器和 Desktop App 都不支援橘色按鈕。

Desktop 聊天到了 claude.ai 之後可以用哪些格式？

PDF、Markdown、Plain Text、JSON、XML、CSV 和 PNG，和其他 Download Claude conversations 教學一樣是這七種。Artifact 版面和思考過程開關只在網頁版小工具中有效。
