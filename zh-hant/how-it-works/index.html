擴充功能在 claude.ai 上的運作方式是什麼？

Download Claude conversations 在 claude.ai 上是這樣運作的：它會在你已經開啟的頁面注入一個內容腳本，使用你已經登入的工作階段。它讀取的是頁面上已顯示的對話，而不是另外呼叫 Anthropic 的 API。橘色按鈕只會出現在真正的對話網址上：一般聊天、Project 裡的聊天、Cowork 工作階段，或 Claude Code 網頁版。

  1. 從 Chrome Web Store 安裝 Download Claude conversations。
  2. 如果安裝時 claude.ai 分頁已經開著，請重新整理。
  3. 開啟一個對話網址。橘色按鈕位於訊息輸入框的右側。
  4. 選擇 PDF、Markdown、JSON、純文字、XML、CSV 或 PNG。按「Export」（匯出），或按「Copy」（複製）放到剪貼簿。
  5. Chrome 會下載檔案。除了 PDF 以外的每種格式，整個流程都在用戶端完成：不需要登入，也不會呼叫我們的伺服器。

空白的輸入首頁沒有訊息結構，所以按鈕不會出現。如果圖示被隱藏，請在 Chrome 的拼圖選單中釘選擴充功能，再重新整理 claude.ai。這套運作方式只限於 claude.ai：Claude Desktop 和 Claude Code 終端機永遠不會載入這個腳本。功能清單：Chrome 擴充功能特色。

同一個工作階段、同一個頁面。內容腳本看到的，就是你已登入的 claude.ai 分頁上已經顯示的內容。它不會用第二組密碼登入 Anthropic。請遵守 Anthropic 對你帳號的規範。

匯出的檔案是在本機產生的嗎？

是的。Download Claude conversations 運作時，每種格式（包括 PDF）都在你的瀏覽器中組成，再交給 Chrome 的下載 API。對話文字永遠不會離開你的裝置、傳到我們的基礎設施。無論是用橘色按鈕匯出單一對話，還是在批次匯出頁面上使用「Export All」（全部匯出），都是如此。

claude.ai 載入對話後，產生檔案不需要等待我們的伺服器。PDF 和批次匯出會先另外檢查額度；其他格式的單一聊天匯出則會略過這一步。如果 Chrome 封鎖了來自 claude.ai 的下載，請允許下載；那是瀏覽器設定，不是解析失敗。很長的對話如果只捲動到一半，產出的檔案也只會有一半，因為 DOM 還不完整。

我們在設計 Download Claude conversations 的運作方式時守住一條底線：聊天內容只留在分頁裡。我們的 Worker 只回答「今天還剩幾次 PDF 或批次匯出」和「這個 Google 帳號是不是 Pro」。PDF 也是在瀏覽器中排版，不經過列印對話框，也不上傳。

Download Claude conversations 團隊

PNG 在本機繪製成圖片。PDF 在本機排版。JSON、XML 和 CSV 則從同一個結構在本機序列化。我們不會以電子郵件寄送任何這些檔案。Anthropic 的 Settings → Privacy → Export data（若 claude.ai 設為中文，選單名稱可能會顯示為中文）是 Anthropic 另外提供、延遲寄出的 ZIP，不是這條本機路徑。

為什麼額度要用 Google 登入來計算？

Google 登入只用於 PDF、批次「Export All」和 Pro。Markdown、Plain Text、JSON、XML、CSV 和 PNG 的單一聊天匯出永遠不會要求登入，也不會傳送任何資料。你第一次選擇 PDF 或執行「Export All」時，擴充功能會請你登入。我們會儲存經過驗證的電子郵件地址，不會儲存聊天文字。

這個電子郵件地址是伺服器端每日計數的依據：免費方案每天合計 3 次 PDF 或批次匯出，在 UTC 午夜重設。批次 ZIP 裡的每個聊天各算一次。如果批次選取的數量超過今天剩下的額度，整批會被擋下，而不是只匯出一部分。因為計數存在我們的 Worker 上，移除再重新安裝擴充功能並不會重設它。Pro（每月 US$3.99 或每年 US$26.99）在新電腦上用同一個 Google 帳號登入即可恢復。

Google 登入不是登入 claude.ai。你在網站上仍然使用自己的 Anthropic 工作階段。Download Claude conversations 只需要 Google 帳號來記錄每日計數和 Pro。也有人搜尋 Claude Chat Downloader 找到同一個商店頁面；登入規則完全相同。

每日限制以帳號計算。免費方案每天合計 3 次 PDF 或批次匯出。只剩 3 次時選了 40 個對話，整批會被擋下，而不是匯出前三個。登入是讓這個計數在重新安裝後依然有效的方式。

Paddle 與 Pro 的付款如何運作？

Paddle.com Market Limited 是付款處理商，也是正式的交易商家。Download Claude conversations 的計費是這樣運作的：由 Paddle 收取卡片資料和稅金。我們永遠看不到付款資料。Pro 是每月 US$3.99 或每年 US$26.99。隨時可以在設定頁（「Cancel subscription」，取消訂閱）或透過 Paddle 取消。首次付款享有 14 天退款保證。

Pro 取消 PDF 和批次「Export All」每天 3 次的上限。其他功能在免費方案中就已經不限次數。Pro 不會加入 Notion 或 Word；格式仍然是同樣七種：PDF、Markdown、JSON、文字、XML、CSV 和 PNG。你不需要 Anthropic 的付費 claude.ai 方案。任何能在 Chrome 中載入對話的 claude.ai 帳號都可以。

匯出時，Worker 會看到什麼？

一個 Cloudflare Worker 負責檢查訂閱和額度狀態：這個用 Google 登入的帳號是否為 Pro，以及今天已經用了幾次 PDF 或批次匯出。它只會收到帳號的電子郵件地址，而且只在你為 PDF、批次匯出或 Pro 登入之後。Download Claude conversations 運作時，這個 Worker 不會收到對話內容。其他格式的單一聊天匯出完全不會連到它。

正因為有 Worker，重新安裝無法重設每日計數，Pro 也才能恢復。它不是聊天備份。Anthropic 仍然在他們那邊保存你的 claude.ai 對話紀錄。我們不保留第二份副本。本網站的隱私權政策說明了我們儲存的電子郵件地址。

1.16.2 版，2026 年 9 月。如果連不上 Worker，你可能暫時無法開始 PDF 或批次匯出，直到狀態可以確認為止。那是授權檢查，不是要求上傳對話。檢查通過後，檔案仍然在本機組成。其他格式的單一聊天匯出不需要等待它。

使用這個 Claude 聊天匯出工具安全嗎？

我們不會保證每條路徑都「零網路連線」。Markdown、文字、JSON、XML、CSV 和 PNG 的單一聊天匯出不會連到我們。PDF、批次匯出和 Pro 會連到 Google 和我們的 Worker，Pro 還會連到 Paddle。聊天內容不會傳到我們的 API；傳送的是帳號電子郵件地址和額度狀態。腳本不會在你的 Anthropic 帳號上自動執行其他動作。

Download Claude conversations 會儲存我的聊天嗎？

不會。每次匯出（包括 PDF）都在本機產生，永遠不會上傳。如果你為 PDF、批次匯出或 Pro 用 Google 登入，我們只會儲存那個電子郵件地址，用來計算每日額度和綁定 Pro。聊天內容只留在 claude.ai 分頁和 Chrome 下載的檔案裡。

Google 登入是必要的，還是選用的？

只有 PDF、批次「Export All」和 Pro 需要。Markdown、文字、JSON、XML、CSV 和 PNG 的單一聊天匯出不需要帳號。PDF 和批次匯出從第一次使用就會要求登入，這樣重新安裝就無法重設每天 3 次的計數。它不是用來讀取你聊天內容的登入。

Pro 的付款由誰處理？

Paddle。我們永遠看不到你的卡片資料。Pro 是每月 US$3.99 或每年 US$26.99。Paddle 是正式的交易商家。退款透過 Paddle 處理。

這和 Anthropic 有關嗎？

沒有。這是獨立的 Chrome 擴充功能，與 Anthropic, PBC 沒有關聯。Claude 是 Anthropic 的商標。Download Claude conversations 的運作方式是使用你現有的 claude.ai 工作階段；它不會取代 Anthropic 的產品。

運作方式中包含 PDF 格式嗎？

包含。PDF 和其他六種格式一樣在瀏覽器中產生：Markdown、JSON、純文字、XML、CSV 和 PNG。過程中不會用到列印對話框。PDF 需要 Google 登入，在免費方案中計入每天 3 次。

匯出時，Worker 會看到什麼？

只有在你為 PDF、批次匯出或 Pro 登入之後：帳號的電子郵件地址、Pro 標記，以及今天已使用的 PDF 或批次匯出次數。Worker 不會收到對話內容。匯出流程始終留在瀏覽器中。

使用 Download Claude conversations 需要 Pro 嗎？

不需要。Markdown、文字、JSON、XML、CSV 和 PNG 的單一聊天匯出免費、不限次數，也不需要帳號。PDF 和批次 ZIP 用 Google 登入後每天免費 3 次。Pro（每月 US$3.99 或每年 US$26.99）取消這個上限。免費版和 Pro 的本機檔案產生流程完全相同。
