如何在 Chrome 中下載 Claude 對話？

在 claude.ai 上下載 Claude 對話的方法，就是 Download Claude conversations 在訊息輸入框旁加上的橘色按鈕。開啟對話，選 PDF、Markdown、JSON、文字、XML、CSV 或 PNG，再按 Export。Chrome 會儲存一個本機檔案。這個檔案是一段對話，而不是帳號 ZIP。

Download Claude conversations 是一個 Chrome 內容腳本（content script）。它讀取你已登入的 claude.ai 工作階段中已經載入的對話，不會用自己的憑證另外呼叫 Anthropic API，也不會為了產生任何格式（包括 PDF）而把對話上傳到我們的伺服器。

  1. 從 Chrome Web Store 安裝 Download Claude conversations（可載入 Chrome 擴充功能的 Chromium 系瀏覽器也可以）。
  2. 如果安裝時 claude.ai 已經開著，請重新載入頁面。Chrome 不會注入到舊的分頁。
  3. 開啟你要的對話網址。橘色按鈕只會出現在真正的對話中，不會出現在空白的輸入首頁。
  4. 點訊息輸入框右側的圓形橘色下載按鈕。面板會打開，裡面有 Messages（訊息：All / Human / Assistant，全部／使用者／助理）、Format（格式）、Thinking（思考過程）、Select（選取）、Copy（複製）和 Export。
  5. 選擇 PDF、Markdown、Plain Text（純文字）、JSON、XML、CSV 或 PNG，按 Export，Chrome 會立刻下載一個檔案。

Markdown、純文字、JSON、XML、CSV 或 PNG 都不需要帳號。這些單一對話匯出不限次數而且免費：不用登入，也沒有計數。只有在選 PDF 或執行批次「Export All」（一次匯出全部）時，才會出現 Google 登入。這不是用來讀取 claude.ai 聊天的登入，對話內容一直留在你的電腦上。

PDF 和批次 ZIP 共用每天 3 次的免費額度，於 UTC 午夜重置。批次 ZIP 裡的每一段對話都算一次。Pro 每月 US$3.99 或每年 US$26.99，可取消這個上限。Pro 的付款由 Paddle 處理。PDF 步驟：把 Claude 聊天下載成 PDF。

本機檔案。每種格式（包括 PDF）都在瀏覽器中產生，再交給 Chrome 的下載 API。聊天文字絕不會被上傳。只有 PDF 和批次匯出會用你的 Google 電子郵件做一次額度檢查。本頁說明的是 2026 年 9 月的 1.16.2 版。

同一個面板可以依發話者篩選：All、Human 或 Assistant。Thinking 核取方塊決定要不要包含延伸思考。Select 讓你勾選個別訊息，檔案裡就只放那幾輪對話。Copy 會把 Markdown、文字、JSON、XML 或 CSV 放到剪貼簿，而不是下載檔案。工具／MCP 步驟和網路搜尋來源是在設定中另外開啟的選項。中繼資料和 artifact 版面（"Original"、"Inline"、"Nested" 或 "Flat"）則在控制台（Dashboard）中設定。

如果對話很長，請一路捲動，讓 claude.ai 載入較早的訊息。Download Claude conversations 只能匯出頁面已經顯示出來的內容。載入一半的對話就會產生一半的檔案，看起來像錯誤，其實通常只是還沒捲動到的 DOM。

這裡說的「下載 Claude 對話」是什麼意思？

在本網站上，「下載 Claude 對話」指的是 Chrome Web Store 上的產品 Download Claude conversations，為開啟中的 claude.ai 對話產生一個檔案。產品名稱是英文複數形，但搜尋框裡的需求通常是單一一段對話。按一次 Export，仍然只會得到一個對話檔案。

同一個需求，大家會用不同的說法搜尋：「claude 下載對話」、「claude 對話 下載」、「下載 Claude 對話」，也有人直接輸入英文 download claude conversation。這些都指向同一個 Store 產品，都不是指 Claude Desktop，也不是指 Claude Code 終端機，而是桌面版 Chrome 中的 claude.ai。只打「claude 下載」通常是想下載 App，所以請明確加上「對話」。

下載 Claude 對話和官方 Export data 有什麼不同？

用橘色按鈕下載 Claude 對話，會立即在本機得到開啟中的 claude.ai 對話的一個具名檔案，包括 PDF。Anthropic 的 Settings → Privacy → Export data（若 claude.ai 設為中文，選單名稱可能顯示為中文）則是稍後寄到信箱的帳號層級 JSON ZIP。列印是網頁的視覺 PDF，複製貼上是沒有結構的文字。選擇符合你需求的那一列。

官方 Export data 是整個 Anthropic 帳號的備份，而不是單一對話的下載。Anthropic 會寄出一個會過期的連結。ZIP 裡混著你忘記的聊天和你想保留的聊天；如果要從上千段中取出一段，就得自己解開 JSON。這不是橘色按鈕的路線。

列印的方法：在 claude.ai 開啟對話，介面允許的話先隱藏側邊欄，按 Ctrl+P（Windows/Linux）或 Cmd+P（Mac），把目的地設為「另存為 PDF」，然後儲存。程式碼區塊常常被切到不同頁，輸入框等介面元素也可能出現在每一頁。列印是畫面的快照，不是 Markdown。擴充功能本身的 PDF 匯出則會跳過這個對話框：Claude 聊天存成 PDF。

複製貼上是第三種不用擴充功能的方法：在 claude.ai 上選取文字，貼到 Google 文件或筆記 App。程式碼的縮排通常會消失，表格會變成一整串文字，多輪對話會變成沒有結構的一大段。只要一則簡短回答還可以；如果是之後要搜尋的程式碼審查，就不太適合。

ZIP 不是一段對話。Anthropic 的 Export data 封存檔是帳號層級的。Download Claude conversations 從未自稱是那個 ZIP。如果你要的是畫面上那段對話的一個檔案，請用橘色按鈕，而不是 Settings → Privacy。

Claude 對話該下載成哪種格式？

決定 Claude 對話要下載成哪種格式：打開橘色按鈕，選 PDF、Markdown、JSON、文字、XML、CSV 或 PNG，再按 Export。Markdown 是筆記檔，JSON 是給腳本用的訊息樹，純文字沒有任何標記，XML 用於資料交換，CSV 是每則訊息一列，PDF 是分頁的文件，PNG 是一張圖片。

Markdown 保留標題、附語言標籤的程式碼區塊和表格，是 Obsidian、GitHub 或 wiki 的常見選擇。JSON 保留解析器已經建好的樹狀結構，開啟對應選項時也包括 artifact 和思考過程。它的結構和 Anthropic 的帳號 ZIP 不同。格式說明：所有格式。

當目的地本來就會去掉標記時，純文字是正確選擇，例如貼到工單欄位、電子郵件內文，或只要原始字串的搜尋索引。XML 是較小眾的資料交換格式。CSV 可以用 Excel、Google 試算表或 Numbers 開啟。PNG 適合放進簡報或錯誤回報的對話截圖，不適合之後要用 grep 搜尋的 40 輪設計審查。

1.16.2 版內建 PDF。選 PDF 後會出現對話框，可設定檔名、紙張大小、邊界、淺色或深色模式、字型和字級、頁碼、目錄、時間戳記，以及每個提問前換頁。PDF 需要用 Google 登入，免費方案每天最多 3 次，Pro 無限制。細節：Claude 聊天存成 PDF。

擴充功能會記住上次使用的格式。如果你想要 Markdown 卻拿到 JSON，那是因為下拉選單還停在上次匯出的 JSON。每次換用途時，都請確認一下下拉選單。Markdown、文字、JSON、XML、CSV 和 PNG 完全沒有額度限制；在免費方案中，只有 PDF 會計入每天 3 次。

PNG 不是 PDF。Download Claude conversations 產生的 PNG 是整段對話的一張圖片。擴充功能的 PDF 是分頁的文件，需要的話可以加上頁碼和目錄。Chrome 列印對話框產生的 PDF 則是 claude.ai 畫面的快照。這些都不是 Markdown 封存。請依照下一個要用的 App 選格式，而不是看「下載」這兩個字。

可以批次下載 Claude 對話嗎？

可以。要把 Claude 對話紀錄下載成許多檔案，不必每個分頁都按一次橘色按鈕。從擴充功能的彈出視窗開啟「View and Download All Conversations」（檢視並下載所有對話），篩選清單，再按 Export All。Export All 需要用 Google 登入。免費方案中，ZIP 裡的每段對話都會用掉每天 3 次額度中的一次，這個額度與 PDF 共用。Pro 沒有上限。

控制台會列出你目前登入的 claude.ai 帳號中的對話。可以依名稱搜尋，依 All conversations、New、Updated 或 Previously exported（全部、新的、已更新、已匯出過）篩選，在 Chat 和 Cowork 分頁之間切換；如果你在 claude.ai 上用 Project 分類聊天，也可以依 Project 搜尋。不想把每一份舊草稿都放進資料夾時，就只選一部分。

批次匯出會產生一個 ZIP，每個聊天一個檔案，格式由「Chat format」選單決定，七種格式都可以，包括 PDF。它使用和單一對話匯出相同的解析器。核取方塊決定要放進哪些內容：Chats、Thinking、Metadata、Tools、Sources（聊天、思考過程、中繼資料、工具、來源），另外還有 artifact 版面。Export All 不是比較陽春的流程，而是同一個解析器一次套用到許多對話 ID。細節：批次 Export All。

Anthropic 的 Export data 仍然是帳號備份：一個 ZIP、一封電子郵件、全部都是 JSON，連你忘記的聊天也在裡面。批次 Export All 則是相反的用途：由你挑選對話、挑選格式，ZIP 立刻下載。如果你既想要一份正式的封存，又想要一個好讀的筆記資料夾，兩者都用。

額度共用，每日計算。在免費方案中，PDF 匯出和批次中的對話共用每天 3 次，於 UTC 午夜重置。如果選了 40 段對話，整批都會被擋下，而不是只匯出一部分。請少選一些，或透過 Paddle 升級到 Pro（每月 US$3.99 或每年 US$26.99）。

控制台也會記得你已經匯出過哪些對話，所以下次可以只篩選 New 或 Updated。這樣每週下載 Claude 對話的習慣就能只補上新的部分，而不會重複上個月的 Markdown。在免費方案中，整個紀錄每天可以匯出 3 段對話；Pro 則能一次匯出全部紀錄。

第一次批次 ZIP 之前需要用 Google 登入。用橘色按鈕產生單一 Markdown、文字、JSON、XML、CSV 或 PNG 檔時，永遠不會要求登入。Download Claude conversations 會儲存經過驗證的電子郵件，用來套用每天 3 次的上限和恢復 Pro。Export All 寫入磁碟時，聊天內容一直留在瀏覽器中。

為什麼 Claude 對話的下載按鈕不見了？

看不到 Claude 對話的下載按鈕，通常是因為你不在對話網址上、安裝後沒有重新載入分頁，或擴充功能被停用了。請釘選圖示、重新載入，並確認你是在桌面版 Chrome 上使用 claude.ai，而不是 Desktop App、手機或 Claude Code 終端機。

安裝後，Chrome 不一定會把內容腳本注入到已經開啟的分頁。請關閉 claude.ai 分頁，或強制重新載入。如果你使用多個設定檔，Download Claude conversations 必須安裝在已登入 Anthropic 的那個設定檔中。

只要能在瀏覽器中開啟對話，Team 和 Enterprise 工作區都可以使用。擴充功能讀取的是頁面，而不是方案等級。如果公司封鎖 Chrome 擴充功能，就需要 IT 允許這一個；我們無法從 chat-downloader.com 繞過這項政策。

登入提示：只有 PDF 和 Export All 才會出現。Markdown、文字、JSON、XML、CSV 和 PNG 匯出都不需要帳號。第一次 PDF 或批次匯出時會要求 Google 登入。取消登入提示看起來就像下載失敗。請完成登入，再按一次 Export。免費方案不需要信用卡，只有購買 Pro 時才會出現 Paddle。

檔案不完整：對話還沒串流完成，或較早的訊息仍在畫面外、尚未渲染。等助理回答完畢，把長對話往開頭捲動，讓 claude.ai 載入那些節點，再匯出一次。重新匯出 Markdown 或 JSON 不需任何成本；在免費方案中，重新匯出 PDF 會再用掉每天 3 次中的一次，所以請先確認對話已經完全載入。

檔案類型不對：還選著上次用的格式。帳號不對：你用來登入 Google 的地址，不是擁有 Pro 的那一個。Pro 的恢復綁定在那個 Google 電子郵件上，而不是 Anthropic 帳號，也不是 Chrome 設定檔的名稱。

行動瀏覽器無法執行這個擴充功能，也沒有 iOS 或 Android App。手機上的 Safari 可以列印 claude.ai，但無法顯示橘色按鈕。想要可重複使用的檔案，請在桌面版 Chrome 中開啟同一段對話，在那裡下載 Claude 對話。

空白首頁沒有按鈕。claude.ai 的輸入首頁不是對話網址。請先開始或開啟一段對話。安裝後重新載入，橘色按鈕就會出現在該對話訊息輸入框的右側。

Desktop 可以下載 Claude 對話嗎？

不行。在 Claude Desktop 中無法用這個產品下載 Claude 對話。Download Claude conversations 只會注入到 Chrome 中的 claude.ai。本機的 Claude Code 終端機是另一個介面；網頁版 Claude Code（claude.ai/code）則可以匯出。如果同一段對話也在 claude.ai 上，就在那裡開啟，再用橘色按鈕。

Claude Desktop 是另一個視窗，Chrome 內容腳本永遠不會注入到那個 App。如果同一段聊天也在 claude.ai 上，就在那裡開啟並下載。如果只存在於 Desktop，就複製貼上，或等 Settings → Privacy → Export data 的帳號 ZIP。

本機 Claude Code 在終端機中執行。在進行中的工作階段裡輸入 /export，Anthropic 的 CLI 會開啟選單，讓你複製對話紀錄或儲存成純文字檔；直接指定檔名就能跳過選單。那份紀錄是給人閱讀的純文字，不是這個擴充功能的 Markdown、JSON 或 PDF。路徑請看：Claude Code 匯出。

磁碟上的 JSONL 是內部紀錄，結構可能隨 Claude Code 版本而改變。Anthropic 自己的文件也建議優先使用 /export 或腳本介面，而不是解析 JSONL。我們沒有包裝那個 CLI，也不會讀取 ~/.claude。Windows 路徑：%USERPROFILE%\.claude\projects。

網頁版 Claude Code 是例外。claude.ai/code 上的工作階段是在 Chrome 中開啟的，所以 Download Claude conversations 可以像一般對話一樣匯出。如果你在 claude.ai 上為同一件工作另開了一段對話，就用橘色按鈕下載那段瀏覽器對話。終端機紀錄和網頁聊天不會自動成為同一份文件。除非你把其中一個貼進另一個，否則請把它們當成兩份紀錄。

下載超過 3 個檔案後還免費嗎？

是的。下載 Claude 對話超過 3 個檔案後仍然免費：Markdown、純文字、JSON、XML、CSV 和 PNG 不限次數，也不需要帳號。3 次的限制只適用於 PDF 和批次 ZIP，而且是每天計算，於 UTC 午夜重置。Pro 每月 US$3.99 或每年 US$26.99，可取消這個限制。Paddle 是正式的銷售方（merchant of record）。

只有 PDF 和批次匯出才會出現 Google 登入。經過驗證的電子郵件讓每日上限綁定在帳號而不是安裝上，也讓 Pro 能跟著你到新電腦。我們儲存電子郵件是為了額度和 Pro 狀態，登入時不會傳送對話內容。伺服器端只回答「今天還剩幾次」和「這個帳號是不是 Pro」。

Pro 取消 PDF 和 Export All 的每日上限，但不會新增 Word、Notion 或 Google 文件格式。每個方案都是同樣七種格式。你不需要 Anthropic 的付費 claude.ai 方案；任何能在 Chrome 中載入對話的 claude.ai 帳號都可以，包括 IT 允許擴充功能的 Team 和 Enterprise。

如何從 claude.ai 下載 Claude 對話？

「下載 Claude 對話」就是 Store 上的那個產品嗎？

Store 上的名稱是 Download Claude conversations（複數），因為 Export All 會產生許多檔案。「claude 下載對話」、「claude 對話 下載」，或英文的 download claude conversation 等搜尋字詞，都指向同一個產品。用橘色按鈕匯出一次，仍然是一段對話、一個檔案。

不裝擴充功能能下載 Claude 對話嗎？

可以。列印 claude.ai 頁面（Ctrl/Cmd+P → 另存為 PDF）可得到視覺快照，或用 Settings → Privacy → Export data 取得稍後寄來的帳號 JSON ZIP。簡短回答可以複製貼上。但這些方法都無法像 Chrome 擴充功能那樣，為每段對話產生結構化的 Markdown 檔。

一個檔案就等於一段 Claude 對話嗎？

是的。橘色按鈕會為開啟中的 claude.ai 對話產生一個檔案。Export All 則產生一個 ZIP，每個選取的項目一個檔案。Anthropic 的 Export data ZIP 剛好相反：整個帳號一個封存檔，稍後寄到信箱，而不是你正在讀的那段對話的具名檔案。

可以把 Claude 對話下載成 PDF 嗎？

只有 PDF 和批次 Export All 需要。Markdown、純文字、JSON、XML、CSV 和 PNG 都不需要帳號。PDF 和批次匯出時，Google 會確認你選的是哪個帳號，這樣我們才能套用每天 3 次的上限，並在重新安裝後恢復 Pro。登入時不會傳送對話內容。我們只儲存經過驗證的電子郵件，用於額度和 Pro 狀態。
