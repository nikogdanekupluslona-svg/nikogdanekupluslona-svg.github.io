Claude 對話匯出在 Chrome 中怎麼運作？

在 Chrome 中開啟 claude.ai 的對話網址，點訊息輸入框右側的橘色按鈕，選 PDF、Markdown、JSON、文字、XML、CSV 或 PNG，再按「Export」。Download Claude conversations 會在本機寫出對話檔案。安裝後請重新載入 claude.ai。claude.ai 本身沒有單一對話的匯出功能。

  1. 從 Chrome Web Store 安裝 Download Claude conversations（版本 1.16.2）。
  2. 重新載入 claude.ai 分頁，讓內容腳本能在對話網址上注入。
  3. 開啟一段真正的對話，而不是 claude.ai 上空白的輸入首頁。
  4. 點訊息輸入框右側的圓形橘色下載按鈕。
  5. 把 Messages（訊息）設為「All」、「Human」或「Assistant」（全部／使用者／助理），需要的話勾選「Thinking」（思考過程），選 PDF、Markdown、JSON、純文字、XML、CSV 或 PNG，再按「Export」。

把 Claude 對話匯出成 Markdown、文字、JSON、XML、CSV 或 PNG 都不需要帳號。這些單一對話匯出不限次數，也不會傳送任何資料到我們的伺服器。只有 PDF 和批次「Export All」（一次匯出全部）會要求 Google 登入，兩者在免費方案中共用每天 3 次。對話內容絕不會用在這次 Google 登入中。運作原理請看：運作方式。

如果看不到橘色按鈕，原因通常是：分頁不在 claude.ai 的對話網址上、安裝後頁面還沒重新載入，或 Download Claude conversations 還藏在 Chrome 的拼圖選單裡。把擴充功能釘選起來，再重新整理。橘色按鈕絕不會出現在其他網站上。

Download Claude conversations 的格式選單會記住上次的選擇。「Select」（選取）可勾選個別訊息，「Copy」（複製）則把 Markdown、文字、JSON、XML 或 CSV 放進剪貼簿，而不是產生檔案。檔案不完整，通常是因為 claude.ai 上的長對話還沒顯示完整個訊息樹。請稍候，再按一次「Export」。

單一對話，還是整個帳號？橘色按鈕只匯出目前開啟的對話。要一次取得很多檔案，請打開擴充功能的彈出視窗 →「View and Download All Conversations」（檢視並下載所有對話），執行「Export All」。Anthropic 的 Settings → Privacy → Export data（若 claude.ai 設為中文，選單名稱可能顯示為中文）是稍後才寄來的帳號 JSON ZIP，不是這個 Chrome 流程。

Claude 對話匯出會在檔案裡保留什麼？

用 Download Claude conversations 匯出的 Claude 對話，會保留 claude.ai 上已經顯示的訊息樹：發話者、程式碼區塊、表格、選用的思考過程、中繼資料和 artifact 版面。它不是連同側邊欄一起的截圖。PNG 是圖片選項；PDF 是分頁文件，在 1.16.2 版中直接於瀏覽器產生。

從 claude.ai 複製貼上會失去縮排，表格也會擠成一團。列印（Ctrl/Cmd+P）會連 claude.ai 的介面一起印出，長的程式碼區塊也常被切到不同頁。Download Claude conversations 會保留程式碼區塊的語言標籤，在 Markdown、JSON 和 XML 中表格仍是表格。PNG 是整段對話的圖片，不是分頁的 PDF。

在 1.16.2 版中，延伸思考是匯出面板中的核取方塊，網路搜尋來源和工具／MCP 步驟則要在設定中開啟。中繼資料可包含標題、時間戳記和模型。Messages 篩選器可限定對話檔案只含全部訊息、只含使用者或只含助理，「Select」則可勾選個別訊息。artifact 版面（「Original」、「Inline」、「Nested」、「Flat」，即原始／內嵌／巢狀／平面）是在控制台（Dashboard）中為「Export All」設定的。

我們圍繞 claude.ai 上的橘色按鈕打造了 Claude 對話匯出：它從畫面上已有的對話寫出 PDF、Markdown、JSON、文字、XML、CSV 或 PNG，而且不上傳對話。1.16.2 版連 PDF 也在瀏覽器中產生。

Download Claude conversations 團隊

也有人搜尋 Claude Chat Downloader 或 Claude Conversation Downloader，找到的是同一個 Chrome 商店頁面。法律頁面上可能仍寫著 Claude Exporter。這些名稱指的都是 Download Claude conversations，不是另一個產品。搜尋「聊天」而不是「對話」，只是用詞不同，不是另一個橘色按鈕。

如何把 Claude 對話匯出成 Markdown？

把 Claude 對話匯出成 Markdown 是寫作者的做法：點橘色按鈕，在下拉選單中選 Markdown，按「Export」。Download Claude conversations 也能從同一段 claude.ai 對話寫出 PDF、JSON、純文字、XML、CSV 和 PNG。Markdown 不限次數，也不需要帳號。

寫作者匯出 Claude 對話筆記時通常選 Markdown。開發者需要機器可讀的對話檔案時通常選 JSON。純文字是沒有標記的封存；XML 用於需要標籤的資料交換；CSV 每則訊息一列，適合試算表；PNG 是類似截圖的檔案；PDF 是分頁文件。Download Claude conversations 1.16.2 版不提供 Word、Notion 或 Google 文件格式。

需要分頁的文件，就在同一個下拉選單中選 PDF。它在瀏覽器中產生，可設定頁面大小、邊界、淺色或深色模式、頁碼和目錄。操作步驟：把 Claude 聊天下載成 PDF。Download Claude conversations 匯出的 PNG 是一個圖片檔。匯出的 Markdown 之後仍可在 Word、Google 文件或 Markdown 應用程式中轉換。

Markdown、JSON、文字、XML、CSV 和 PNG 下載不限次數，也不需要帳號，所以把同一段 claude.ai 對話再匯出成另一種格式完全不用成本。在免費方案中，每個 PDF 會用掉每天 3 次中的 1 次，需要 Google 登入。Pro 每月 US$3.99 或每年 US$26.99，可取消這個上限。

可以用「Export All」匯出多段 Claude 對話嗎？

可以。打開擴充功能的彈出視窗 →「View and Download All Conversations」，篩選後按「Export All」，就能把 Claude 對話匯出成一個 ZIP，每段對話一個檔案。批次匯出需要 Google 登入。免費方案中，ZIP 裡的每段對話都會用掉每天 3 次中的 1 次，與 PDF 共用。Pro 每月 US$3.99 或每年 US$26.99，可取消批次匯出的上限。

控制台會列出 claude.ai 的對話紀錄，可依名稱搜尋，有篩選器（All conversations、New、Updated、Previously exported，即全部／新的／已更新／曾匯出）、Chat 和 Cowork 分頁，以及專案搜尋。New 表示還沒用 Download Claude conversations 儲存過。Previously exported 會記錄你已寫到磁碟的對話，第二次執行「Export All」時可以略過它們。專案搜尋則對應你在 claude.ai 上分組對話的方式。

批次匯出有「Chat format」（聊天格式）選單，七種格式都有，PDF 也包括在內；還有「Chats」、「Thinking」、「Metadata」、「Tools」、「Sources」（聊天、思考過程、中繼資料、工具、來源）核取方塊，以及 artifact 版面（Original、Inline、Nested、Flat）。「Export All」不是整個帳號的縮水 ZIP，而是一個 ZIP，每段對話一個檔案，採用你選的格式。Anthropic 的 Export data 仍是稍後寄來的帳號 JSON ZIP。

批次匯出按對話計算。免費方案中，「Export All」和 PDF 共用每天 3 次，ZIP 裡的每段對話都算一次。剩 3 次卻選了 40 段對話，整批都會被擋下，而不是只匯出一部分。請少選幾段、等 UTC 午夜重置，或改用 Pro（每月 US$3.99 或每年 US$26.99）。共用額度的詳情：批次 Export All。

「Export All」只與 PDF 共用每日額度。從橘色按鈕匯出的 Markdown、文字、JSON、XML、CSV 和 PNG 完全不會用到它，所以用這些格式匯出 Claude 對話永遠免費。額度於 UTC 午夜重置。在新電腦上，透過 Paddle 用同一個 Google 帳號就能恢復 Pro。

在 Desktop 或 Code 上能匯出 Claude 工作階段嗎？

在 Desktop 應用程式或 Claude Code 終端機中都不行。在 claude.ai 上，工作階段就是開啟中的對話網址，在那裡匯出 Claude 工作階段，指的就是 Chrome 中的橘色按鈕。Cowork 工作階段和 Claude Code on the web（claude.ai/code）也在 claude.ai 上開啟，所以匯出方式相同。Claude Desktop 裡永遠不會出現橘色按鈕。終端機中的 Claude Code 使用 /export 或 ~/.claude/projects 中的 JSONL。

如果這段對話也存在你的 claude.ai 帳號中，就在 Chrome 開啟它，用 Download Claude conversations 匯出。如果聊天只存在 Claude Desktop 中，請從應用程式複製貼上，或在網頁版申請 Settings → Privacy → Export data。比較請看：匯出 Claude Desktop 聊天。

終端機中的 Claude Code 是另一條產品路線。請在那裡執行 /export，或從 ~/.claude/projects 複製 JSONL 對話紀錄。Download Claude conversations 不會讀取這些檔案，也不會注入 CLI。如果你要匯出的是終端機代理程式的工作階段，走的就是磁碟那條路，指南：Claude Code 匯出。

在手機瀏覽器中使用的 claude.ai 也不在支援範圍內。Download Claude conversations 需要桌面版 Chrome（或其他能從 Chrome Web Store 安裝擴充功能的 Chromium 瀏覽器）。2026 年我們團隊沒有 iOS 或 Android 應用程式。請在電腦上開啟對話，再用橘色按鈕或「Export All」。

claude.ai 的 Team 和 Enterprise 工作區，在 Chrome 中同樣使用對話網址。如果工作區管理員封鎖了擴充功能，Download Claude conversations 就無法注入；那是瀏覽器政策，不是缺少某種格式。橘色按鈕只會在你有權開啟的對話網址重新載入後出現。

Claude 對話匯出和 Anthropic 的 Export data 有什麼不同？

Anthropic 的 Export data 會在一段時間後，用電子郵件寄來整個帳號的 JSON ZIP。用 Download Claude conversations 做 Claude 對話匯出，則會立即把目前開啟的對話存成 PDF、Markdown、JSON、文字、XML、CSV 或 PNG。備份用 ZIP；現在就要從 claude.ai 取得好讀的檔案，就用 Chrome 擴充功能。

Download Claude conversations 與 Anthropic, PBC 沒有關係。使用 Claude 對話匯出不會改變 Anthropic 的服務條款。內容腳本使用你在 claude.ai 上已經開啟的工作階段，不會用另外的憑證登入 Anthropic。請遵守 Anthropic 對你帳號的規定。以「聊天」為用詞的同一條產品路線：匯出 Claude 聊天。

匯出 Claude 對話要多少錢？

Markdown、文字、JSON、XML、CSV 和 PNG 匯出免費、不限次數，也不需要帳號。PDF 和批次「Export All」用 Google 登入後每天最多免費 3 次。Pro 透過 Paddle 付款，每月 US$3.99 或每年 US$26.99，PDF 和批次匯出都不限次數。Download Claude conversations 不按格式收費。只要 Chrome 能開啟對話，任何 claude.ai 方案都可以用。

PDF 和批次匯出的每日次數於 UTC 午夜重置。在新電腦上用同一個 Google 帳號登入，就能恢復 Pro。你可以隨時從擴充功能的選項頁面或透過 Paddle 取消。Paddle 是交易的銷售方（merchant of record），我們團隊不會看到卡號。首次付款享有 14 天退款保證，依退款頁面的說明透過 Paddle 處理。

匯出 Claude 對話不需要 Anthropic 的 claude.ai 付費方案。你只需要一個能載入對話的 claude.ai 帳號，加上 Chrome。Team 和 Enterprise 使用橘色按鈕的方式與 Free 相同。如果 Chrome 擋下了下載，請先允許 claude.ai 下載檔案，再按一次「Export」。

同一件事，不同的搜尋詞。Claude 對話匯出、匯出 Claude 對話、匯出多段 Claude 對話，意思都是把對話存成檔案。本頁用的是「對話」和「工作階段」的說法。以「聊天」為用詞的產品頁是姊妹頁，不是另一個擴充功能。

Claude 對話匯出失敗時的排解方式：等長對話在 claude.ai 中完全載入，確認格式下拉選單（會沿用上次的格式），如果是 PDF，再看看今天的 3 次還剩多少。PNG 或 Markdown 檔案不完整，通常是因為訊息樹還在串流輸出。請捲動對話，等最後一則助理回覆出現在畫面上後再按「Export」。

本頁對應的版本是 1.16.2，日期為 2026 年 9 月。格式有 PDF、Markdown、純文字、JSON、XML、CSV 和 PNG。如果這份清單有變，本指南會在同一天更新。在那之前，claude.ai 上的 Download Claude conversations 不提供 Word、Notion 或 Google 文件匯出。

「導出」、「匯出」和英文說法：是同一個擴充功能嗎？

是的。台灣常說「claude 匯出對話」，香港使用者也常打「claude 導出 對話」，英文則是「claude export conversation」。三種說法都是同一件事：把 claude.ai 對話存成檔案。Download Claude conversations 就是這個 Chrome 擴充功能：橘色按鈕、七種格式，其中六種免費無限次匯出。法律頁面上可能仍以 Claude Exporter 稱呼它。

搜尋引擎也會顯示「claude 對話紀錄匯出」或「claude 對話 匯出」這類說法。它們指的仍是 claude.ai 對話網址上的橘色按鈕，或「View and Download All Conversations」中的「Export All」。除非你自己選擇那條官方路線，否則它們不是指 Claude Code 的 /export，也不是指 Anthropic 用電子郵件寄來的 ZIP。

不用擴充功能匯出 Claude 對話的方法有：複製貼上、列印，或 Settings → Privacy → Export data。複製貼上會失去表格，列印會保留 claude.ai 的介面，ZIP 則是稍後寄來的帳號 JSON。Download Claude conversations 是只在 claude.ai 上、能立即產生 PDF／Markdown／JSON／文字／XML／CSV／PNG 的方法。

不要期待 Download Claude conversations 出現在 Claude Desktop 或 Claude Code 終端機中。那些環境永遠不會有橘色按鈕。如果你搜尋 Claude 對話匯出，想找的是 CLI 參數，請改用 /export 或磁碟上的 JSONL。如果你想找 Mac 應用程式裡的按鈕，請在 Chrome 中開啟 claude.ai 上已同步的對話。

常見問題：Claude 對話匯出

以下問答涵蓋 Claude 對話匯出：格式、次數限制、Claude Desktop、Claude Code、Anthropic 的 ZIP，以及 claude.ai 上的橘色按鈕。每個答案都是 Download Claude conversations 1.16.2 版的事實。頁首的 FAQPage JSON-LD 與這份清單一致。

在本站，「Claude 對話匯出」是什麼意思？

用 Download Claude conversations 把 claude.ai 對話存成檔案：橘色按鈕、選格式、按「Export」。和「匯出 Claude 對話」或英文的「claude export conversation」是同一件事。它不是 Anthropic 用電子郵件寄來的 ZIP，也不是 Claude Code 的 /export。

Claude 對話匯出和 Export data 一樣嗎？

不一樣。Settings → Privacy → Export data 是透過電子郵件寄來的整個帳號 JSON ZIP。用這個擴充功能做 Claude 對話匯出，則會在 Chrome 中立即把目前開啟的對話寫成 PDF、Markdown、JSON、文字、XML、CSV 或 PNG，或把「Export All」選取的對話打包成 ZIP。

Claude 對話匯出可以產生 PDF 嗎？

可以。在格式清單中選 PDF，按「Export」。Download Claude conversations 直接在瀏覽器中產生 PDF，不經過列印對話框。PDF 需要 Google 登入，每天最多免費 3 次；Pro 則不限次數。指南：把 Claude 聊天下載成 PDF。

只匯出一次 Claude 對話也需要 Pro 嗎？

不需要。Markdown、文字、JSON、XML、CSV 和 PNG 匯出免費、不限次數，也不需要帳號。PDF 和批次「Export All」用 Google 登入後每天最多免費 3 次。Pro 每月 US$3.99 或每年 US$26.99，可取消這個上限。

任何 claude.ai 方案都能匯出 Claude 對話嗎？

可以。只要能在 Chrome 中開啟對話，claude.ai 的 Free、Pro、Team 或 Enterprise 方案都可以。Download Claude conversations 不需要 Anthropic 的付費方案。

Claude 對話匯出能用在 Claude Code 嗎？

只能用在 Claude Code on the web。claude.ai/code 上的工作階段在 claude.ai 中開啟，可以像一般對話一樣匯出。終端機中的 Claude Code 使用 /export 或 ~/.claude/projects 中的 JSONL，這個擴充功能不會讀取這些本機工作階段。

可以從 Claude Desktop 匯出 Claude 工作階段嗎？

這個 Chrome 擴充功能做不到。如果對話有同步，請在 claude.ai 上開啟同一段對話；否則請複製貼上，或使用官方的 Export data。Claude Desktop 裡永遠不會出現橘色按鈕。

Claude 對話匯出可以免費產生多少個檔案？

Markdown、文字、JSON、XML、CSV 和 PNG 不限次數，也不需要帳號。免費方案中，PDF 和批次「Export All」用 Google 登入後合計每天 3 次；批次 ZIP 裡的每段對話各算一次。次數於 UTC 午夜重置。Pro 取消上限，並可透過 Google 登入恢復。

Claude 對話匯出的橘色按鈕在哪裡？

安裝 Download Claude conversations 並重新載入後，它會出現在 claude.ai 對話網址中訊息輸入框的右側。空白的首頁輸入畫面和 Claude Desktop 中都不會出現。

Claude 對話匯出會上傳我的聊天嗎？

不會。每種格式（包括 PDF）都在瀏覽器中產生，再交給 Chrome 的下載 API。Markdown、文字、JSON、XML、CSV 和 PNG 匯出不會傳送任何資料給我們。為了 PDF、批次匯出或 Pro 登入後，我們的伺服器只會看到額度或訂閱狀態和你的 Google 電子郵件，絕不會看到對話內容。

Claude 對話匯出能寫出哪些格式？

七種：PDF、Markdown、純文字、JSON、XML、CSV 和 PNG。單一對話和「Export All」都是這七種。1.16.2 版不提供 Word、Notion 或 Google 文件匯出。
