claude.ai 能直接把聊天下載成 PDF 嗎？

claude.ai 本身不行，它沒有「下載為 PDF」按鈕。裝了 Download Claude conversations 就可以：在匯出面板選 PDF，按「Export」。1.16.2 版會直接在分頁裡產生 .pdf，不經過列印對話框，也不會上傳任何內容。

  1. 從 Chrome Web Store 安裝 Download Claude conversations，再重新整理 claude.ai。
  2. 開啟對話。一般聊天、Projects、Cowork 工作階段和 Claude Code 網頁版（claude.ai/code）都能用。
  3. 點訊息輸入框右側的圓形橘色下載按鈕。
  4. 在 Format（格式）選 PDF。Messages 保持 All，或改選 Human 或 Assistant（全部／使用者／助理）。用「Select」（選取）只勾選你要的訊息。
  5. 按「Export」。第一次會要求用 Google 登入，接著設定 PDF 選項並儲存。

PDF 對話框能設定列印永遠做不到的項目：

  • 檔名、頁面大小與邊界。
  • 淺色或深色模式。
  • 字型與字級。
  • 頁碼與目錄。
  • 時間戳記。
  • 每則提示前分頁。

程式碼區塊會保留語言標示與格式，表格和清單也完整保留。延伸思考是匯出面板裡的「Thinking」核取方塊；工具／MCP 步驟與網頁搜尋來源則在設定中開啟。PDF 只會包含你選擇的內容。

免費方案的 PDF 限制。PDF 從第一次使用起就需要 Google 登入。免費帳號每天共 3 次 PDF 或批次 ZIP 匯出（兩者合計），每天在 UTC 午夜重置。Pro 每月 US$3.99 或每年 US$26.99，不限次數。Markdown、文字、JSON、XML、CSV 和 PNG 則一律不限次數、免帳號。

Anthropic 的 Settings → Privacy → Export data（若 claude.ai 介面設為中文，選單名稱可能已翻譯）也不是 PDF。它是稍後才寄出的整個帳號 JSON ZIP，解壓縮後也不會得到排版好的對話。如果你要的是目前這段對話的 PDF，就不必等那封電子郵件。

如何在電腦上列印 Claude 對話？

在電腦上列印 Claude 對話的方法：在 claude.ai 開啟對話，盡量收起側邊欄，按 Ctrl+P 或 Cmd+P，選「另存為 PDF」，再列印。請先等對話完整載入；很長又沒捲動過的聊天，只會印出目前已載入的 DOM。無法安裝擴充功能、或只是臨時要一份時，就用列印。

  1. 在 Chrome 或其他電腦瀏覽器中開啟 claude.ai 上的對話，等回覆輸出完畢。
  2. 收起側邊欄，讓對話內容占滿更多版面。不想印到紙上的 Artifact 或專案面板也先隱藏。
  3. Windows 或 Linux 按 Ctrl+P，Mac 按 Cmd+P。
  4. 目的地選「另存為 PDF」（Chrome）或「Print to PDF」；要印在紙上就選印表機。
  5. 如果頁面看起來很淡，在「更多設定」中試著勾選「背景圖形」。側邊欄仍占用版面時，把邊界調小。然後儲存或列印。

列印 Claude 對話的流程就只有這樣。列印不會加上頁碼、目錄，也不會在每則提示前分頁。你拿到的是網站在列印模式下套用的 CSS，通常就是「分成好幾頁的網頁」。

能不能印出更好看的 Claude 聊天？列印對話框辦不到，它不會變成排版工具。請改在擴充功能中選 PDF：頁面大小、邊界、字型、頁碼和目錄都是可調整的設定，不必碰運氣看 CSS。

先把對話載入完整。很長的聊天採虛擬化顯示，沒捲動到的舊訊息不會載入。只載入一半就列印或存 PNG，看起來就像被截斷的 PDF。請先捲動到最開頭、稍等一下再列印。擴充功能匯出時也有同樣的限制。

列印出來的 Claude 聊天 PDF 會保留什麼？

列印出來的 Claude 聊天 PDF 保留的是版面快照，而不是訊息結構的匯出。通常會留下可見的文字，以及列印 CSS 沒有丟掉的部分；完整的程式碼區塊、寬表格、收合的 Artifact，以及不含輸入框等介面元素的乾淨頁面，則常常保不住。

  • 程式碼區塊會換行或跨頁切開。只有列印樣式表把 pre 的換行控制好，縮排才會保留，而多半沒有。
  • 表格超出紙張寬度，寬的比較表會變得無法閱讀。
  • 除非先隱藏，否則輸入框、模型選單、側邊欄等介面元素可能每一頁都會出現。
  • Artifact 和思考過程只有在畫面上展開時才會印出，收合的內容不會出現在 PDF 裡。
  • 這份 PDF 無法當成 Markdown 放進 Obsidian，也不能用 git 比對差異。

如果只是臨時附一份「看起來像 Claude」的檔案，列印就夠了。要寄出、歸檔或印在紙上閱讀的 PDF，擴充功能產生的 PDF 更好。如果是要編輯、引用或比對差異的工作文件，請用擴充功能匯出 Markdown 或 JSON，詳見如何匯出 Claude 聊天。

背景圖形和紙張大小會改變快照的樣子，A4 或 Letter 也會影響程式碼在哪裡被切開。但這些設定都救不回比視窗還寬的表格。如果那張表格很重要，請從擴充功能匯出 PDF 或 Markdown。

可以用手機列印 Claude 聊天嗎？

有時可以。只要手機瀏覽器提供「分享 → PDF」或「列印」，就能從手機列印 Claude 聊天。不過 claude.ai 的手機版是窄欄配上大輸入框，印出來的 PDF 通常比電腦版差：介面元素更多、每行更短、分頁更多。

這個 Chrome 擴充功能無法在 iOS 或 Android 上執行，Download Claude conversations 也沒有 App 版本，Safari 更無法載入 Chrome Web Store 的項目。想要乾淨的 PDF，請在電腦版 Chrome 開啟同一段對話，再到擴充功能選 PDF。

如果那段聊天只能在手機上開、手邊又沒有電腦，就從手機列印並接受那樣的版面，或等拿到筆電再處理。從設定使用官方 Export data 仍須透過網頁登入帳號，而且拿到的仍不是 PDF。

即使團隊政策封鎖了電腦上的擴充功能，手機列印也不會因此變好，你只剩下列印和官方 ZIP 兩種方式。這兩種不需要我們的軟體也一直能用。

如何透過 Markdown 把 Claude 聊天存成 PDF？

透過 Markdown 把 Claude 聊天存成 PDF 的方法：用 Download Claude conversations 匯出 Markdown，在編輯器中開啟 .md 檔，再用該軟體的「列印」或「匯出為 PDF」。想先修改文字或套用自己的範本時，就走這條路。Markdown 匯出不限次數、免帳號，完全不會用到每天的 PDF 額度。

  1. 在 claude.ai 開啟聊天，點橘色按鈕，選 Markdown，按「Export」。不用登入，也不計次。
  2. 用 VS Code、Obsidian、Typora、Google 文件開啟檔案，或貼到 Word。
  3. 用該軟體的「列印」或「匯出為 PDF」。紙張大小和標題樣式在那裡設定，不是在 claude.ai。

代價是要用兩個工具而不是一個。擴充功能本身的 PDF 已經能設定頁面大小、邊界、字型和目錄；只有在 PDF 需要修改內容、使用公司指定字型，或需要對話框沒有提供的範本時，才從 Markdown 開始。PNG 也無法取代：它是點陣圖，放進簡報很合適，但拿來做 40 頁的設計審查就派不上用場。

所有檔案（包括 PDF）都在你的瀏覽器中於本機產生，對話內容絕不會被上傳、儲存或分析。格式清單請見格式。

PDF 和其他格式一樣，都是在你的瀏覽器中產生：沒有列印對話框，也沒有伺服器。這個對話框處理了列印從來做不到的事：頁面大小、邊界、深色模式、頁碼、目錄，以及每則提示前分頁。如果分享前需要修改文字，請改為匯出 Markdown。

一次需要很多份 PDF？開啟 Dashboard（控制台），把「Chat format」（聊天格式）設為 PDF，勾選聊天，再按「Export All」（全部匯出）。你會得到一個 ZIP，每個聊天一份 PDF。這需要 Google 登入；在免費方案中，ZIP 裡的每個聊天都會用掉同一組每天 3 次額度中的一次。如果選取的數量超過今天剩餘的額度，整批會被擋下，而不是只匯出一部分。Pro 沒有這個上限。教學請見批次匯出。

Claude 聊天該用 PNG、PDF 還是 Markdown？

PNG、PDF 和 Markdown 是三種不同的東西。這個擴充功能產生的 PDF 是分頁文件；PNG 是整段對話的一張圖片；Markdown 是有結構的文字；「列印成 PDF」則是網頁的快照。名稱一混用，就容易寄錯檔案。

格式 是什麼 適合用途 免費方案

列印 → 另存為 PDF 瀏覽器拍下的 claude.ai 快照 快速分享，「看起來像 Claude」 瀏覽器功能，沒有限制

另外還有純文字、XML 和 CSV，但都不是 PDF。純文字印出來是一大片文字行，XML 印出來是一堆標籤，CSV 則是每則訊息一列，適合試算表而不是紙張。如果要交出的是 PDF，就選 PDF。

擴充功能會記住上次使用的格式。如果你想要 PDF 卻拿到 Markdown，就是下拉選單還停在 Markdown。按「Export」前請先確認；在免費方案中，不小心產生的 PDF 也會用掉今天 3 次中的一次。

列印、官方匯出與這個 Chrome 擴充功能有何不同？

列印、官方 Export data 和這個 Chrome 擴充功能，是三件都叫「匯出」的不同工作。列印 → 另存為 PDF 是單一對話、視覺快照、立即取得。官方 ZIP 是整個帳號、JSON 格式、稍後寄到電子郵件。擴充功能則在本機寫出七種格式（包括 PDF）：其中六種免帳號，PDF 和批次匯出需要 Google 登入。

如果你指的是終端機裡的 Claude Code，列印幫不上忙，因為本機工作階段不是網頁，請用 /export。Claude Code 網頁版（claude.ai/code）則不同：它在 claude.ai 上開啟，所以擴充功能可以像一般聊天一樣把它匯出成 PDF。如果你指的是 Claude Desktop 應用程式，擴充功能無法在那裡執行，請見匯出 Claude Desktop 聊天。

用 ZIP 還是用橘色按鈕匯出 Claude 聊天，在匯出教學中有說明；用小工具下載 Claude 聊天的步驟則在下載教學裡。本頁只談 PDF 和列印，讓三個網址各有各的主題。

每日限制不適用於列印。瀏覽器列印不是擴充功能。免費方案的上限是每天共 3 次 PDF 或批次 ZIP 匯出（兩者合計，UTC 午夜重置），只計算擴充功能的 PDF 與「Export All」。Markdown、文字、JSON、XML、CSV 和 PNG 不限次數。Pro 每月 US$3.99 或每年 US$26.99，沒有上限，付款由 Paddle 處理。

這是獨立開發的 Chrome 擴充功能，與 Anthropic, PBC 無關。請遵守 Anthropic 的服務條款。我們無法保證 Anthropic 所掌控的列印樣式表；如果 Claude 介面改版導致列印出問題，那是對方的 CSS，請改用擴充功能匯出 PDF。

如何把 Claude 聊天存成 PDF，並讓程式碼清楚易讀？

在擴充功能中選 PDF。程式碼區塊會保留語言標示與格式，頁面大小和邊界也由你設定。列印對程式碼最不友善：區塊會換行或跨頁切開。如果想自己排版，就匯出 Markdown，再從編輯器列印。
