哪些 Chrome 擴充功能特色可以匯出單一聊天？

針對單一對話，最核心的 Chrome 擴充功能特色，就是 Download Claude conversations 在 claude.ai 訊息輸入框旁加上的橘色按鈕。開啟一個對話網址，選擇格式，再按「Export」（匯出）或「Copy」。檔案會立即下載。只有 PDF 需要登入，其他六種格式都不需要帳號。

  1. 從 Chrome Web Store 安裝 Download Claude conversations。
  2. 重新整理 claude.ai，開啟一個真正的對話網址：聊天、Project 裡的聊天、Cowork 工作階段，或 Claude Code 網頁版。
  3. 點訊息輸入框右側的橘色下載按鈕。
  4. 選擇 Messages（All、Human 或 Assistant，即全部、使用者或助理）、格式和「Thinking」核取方塊，或按「Select」逐一勾選訊息。擴充功能會記住你上次使用的格式。
  5. 按「Export」下載檔案，或按「Copy」複製到剪貼簿。「Copy」適用於 Markdown、文字、JSON、XML 和 CSV。

橘色按鈕只會出現在已載入的對話上；空白的輸入首頁沒有可解析的內容。如果找不到按鈕，請在 Chrome 的拼圖選單中釘選擴充功能，再重新整理 claude.ai。這些功能永遠不會注入 Claude Desktop 或 Claude Code 終端機。選擇 PDF 時會開啟一個對話框，可設定檔名、頁面大小、邊界、淺色或深色模式、字型與字級、頁碼、目錄、時間戳記，以及每則提示前分頁：Claude 聊天存成 PDF。

本機檔案。PDF、Markdown、JSON、文字、XML、CSV 和 PNG 都在分頁中產生。非 PDF 格式的單一聊天匯出不會傳送任何資料到我們的伺服器。PDF 和批次匯出只會傳送你的 Google 電子郵件地址，用於每日計數。聊天內容絕不外傳。運作機制請見運作方式。

哪些 Chrome 擴充功能特色涵蓋「Export All」？

批次相關的 Chrome 擴充功能特色都在 Dashboard（控制台），也就是「View and Download All Conversations」（查看並下載所有對話）：搜尋、All conversations／New／Updated／Previously exported（所有對話／新的／已更新／先前已匯出）篩選條件、Chat 與 Cowork 分頁、專案搜尋，以及「Export All」。「Export All」會存成一個 ZIP。免費方案用 Google 登入後每天可匯出 3 個聊天；Pro（每月 US$3.99 或每年 US$26.99）沒有這個上限。

New 表示尚未用 Download Claude conversations 匯出過。Previously exported 會記錄你已存過的聊天，讓第二次「Export All」可以略過它們。Cowork 分頁把 Cowork 工作階段列在一般聊天旁邊。專案搜尋可以找出單一 claude.ai Project 裡的聊天。搜尋依對話名稱進行。完整流程請見批次「Export All」。

每日限制以帳號計算。免費方案每天 3 個聊天，與 PDF 共用，而不是每次批次執行 3 個。如果只剩 3 次卻選了 40 個對話，整批會被擋下，而不是只匯出一部分。按「Export All」之前先規劃好選取範圍，或改用 Pro。

「Export All」使用 Dashboard 的「Chat format」（聊天格式）選單（七種格式皆可，包括 PDF）、「Chats」「Thinking」「Metadata」「Tools」「Sources」（聊天、思考過程、中繼資料、工具、來源）核取方塊，以及 Artifact 格式。產出的是一個 ZIP、每個聊天一個檔案，不是 Anthropic 稍後寄出的帳號 ZIP。每次執行只能選一種格式，無法一次點擊就同時產出 Markdown 和 JSON。Dashboard 也提供備份與還原。

Chrome 擴充功能特色能寫出哪些格式？

這些 Chrome 擴充功能特色可以寫出七種格式：PDF、Markdown、Plain Text、JSON、XML、CSV 和 PNG。Markdown、文字、JSON、XML、CSV 和 PNG 不限次數、免帳號。PDF 在瀏覽器中產生，需要 Google 登入，在免費方案中計入每天 3 次。橘色按鈕和 Dashboard 的「Chat format」選單提供的清單相同。各格式介紹請見 Claude 聊天匯出格式。

我們刻意讓擴充功能保持專注：從頁面上已有的 claude.ai 對話寫出七種檔案類型，再加上批次「Export All」，以及決定檔案內容的各種選項。PDF 現在也是其中之一，在瀏覽器中排版，不經過列印對話框。我們仍然不提供 Notion 或 Word 匯出。如果這點有所改變，本頁會在同一天更新。

寫作者通常選 Markdown，開發者通常選 JSON。CSV 每則訊息一列，可用 Excel、Google 試算表或 Numbers 開啟。PNG 是圖片，無法用 grep 搜尋。PDF 則是用來閱讀、列印或寄送的檔案，頁面大小、邊界和目錄都在它的對話框中設定。

Chrome 擴充功能特色會保留 Artifact 嗎？

會。Chrome 擴充功能特色包括 Artifact 版面：「Original」「Inline」「Nested」或「Flat」（原始、內嵌、巢狀或平面）。思考區塊、工具／MCP 步驟和網頁搜尋來源都要自行開啟：「Thinking」是匯出面板裡的核取方塊，工具和來源在設定中開啟，Dashboard 則三者都有核取方塊。Metadata 可以加入標題、時間戳記和模型。寄件者篩選可把檔案限制為全部、只有使用者或只有助理，「Select」則可逐一勾選訊息。

Artifact 是 claude.ai 對話的一部分。版面設定決定它們要放在 Markdown、JSON、XML 或文字檔裡，還是放進 ZIP 內各自的資料夾。Artifact ZIP 不限次數且免費，專案檔案 ZIP 也一樣：在 Project 頁面點「Project files」→「Download ZIP」（專案檔案 → 下載 ZIP）。在 PNG 中，Artifact 會被繪製成圖像，而不是以標記儲存。如果關閉思考過程，即使 claude.ai 畫面上有顯示延伸思考，匯出檔也不會包含。

如果對話很長，請捲動到 claude.ai 載入較早的訊息為止。擴充功能只能匯出頁面已顯示的內容。只載入一半的 DOM 會產生被截斷的檔案，看起來像是 Artifact 遺失的錯誤，但通常只是對話沒有捲動到底。

設定頁裡有哪些 Chrome 擴充功能特色？

設定就是擴充功能的選項頁面，包含檔名範本、「Copy instead of download」（以複製取代下載）、在 Markdown 中嵌入圖片、工具／MCP 步驟、網頁搜尋來源、日期與時間格式、備份與還原，以及你的訂閱。擴充功能介面只有英文版。

Chrome 擴充功能特色如何處理登入？

大多數 Chrome 擴充功能特色都不需要登入。單一聊天的 Markdown、Plain Text、JSON、XML、CSV 和 PNG 匯出不限次數且匿名，「Copy」、「Select」、Artifact ZIP 和專案檔案 ZIP 也一樣。只有 PDF、批次「Export All」和 Pro 才會要求 Google 登入。對話內容從不參與這個流程。

在免費方案中，PDF 和批次 ZIP 共用每天 3 次，由我們的伺服器依你的 Google 電子郵件計算。每天在 UTC 午夜重置，重新安裝也不會重置。Pro 透過 Paddle 付款，每月 US$3.99 或每年 US$26.99。Paddle 是登記銷售商（merchant of record），本團隊永遠看不到卡號。在新電腦上用同一個 Google 帳號登入，就能恢復 Pro。

你不需要 Anthropic 的 claude.ai 付費方案。只要 Chrome 能開啟聊天，claude.ai 的 Free、Pro、Team 和 Enterprise 方案都能使用。如果工作區管理員封鎖了擴充功能，Download Claude conversations 就無法注入；這是瀏覽器政策，而不是本頁少了什麼功能。

1.16.2 版沒有哪些 Chrome 擴充功能特色？

1.16.2 版沒有的 Chrome 擴充功能特色：Notion 匯出、Word 匯出、推送到 Google 文件、Claude Desktop 掛鉤，以及本機 Claude Code 終端機工作階段（/export、~/.claude/projects）。Download Claude conversations 是 claude.ai 的 Chrome 內容腳本，不是換個名字的另一個應用程式。PDF 已不在這份清單上，現在已內建。

Claude Desktop 是 Mac／Windows 應用程式，終端機裡的 Claude Code 是本機代理，兩者都沒有橘色按鈕。Claude Code 網頁版（claude.ai/code）和 Cowork 工作階段都在 claude.ai 上開啟，所以能像一般聊天一樣匯出。如果某段 Desktop 對話也存在於 claude.ai，就在 Chrome 開啟它並使用擴充功能。與 Desktop 的比較請見匯出 Claude Desktop 聊天；與 Code 的比較請見 Claude Code 匯出。

手機瀏覽器中的 claude.ai 不在支援範圍內，2026 年本團隊也沒有 iOS 或 Android App。PDF 和 PNG 無法使用「Copy」。本頁內容以 2026 年 9 月的版本為準；如果我們新增格式，本頁會在同一天更新。

常見問題：Chrome 擴充功能特色

以下常見問題涵蓋 Download Claude conversations 1.16.2 的 Chrome 擴充功能特色：橘色按鈕、「Export All」、格式、Artifact、免費方案、Desktop 和 Pro。每個答案都是產品事實，頁首的 FAQPage JSON-LD 與本頁清單一致。

哪些 Chrome 擴充功能特色可以匯出單一聊天？

claude.ai 對話網址上、訊息輸入框旁的橘色按鈕。選擇 PDF、Markdown、JSON、文字、XML、CSV 或 PNG，再按「Export」或「Copy」。這是匯出單一對話最快的方式，而且只有 PDF 需要登入。

Chrome 擴充功能特色包含批次「Export All」嗎？

包含。Dashboard（「View and Download All Conversations」）會列出 claude.ai 紀錄，提供 All conversations、New、Updated 和 Previously exported 篩選條件、Chat 與 Cowork 分頁，以及專案搜尋。「Export All」會存成一個 ZIP。免費方案用 Google 登入後每天可匯出 3 個聊天；Pro 不限次數。

Chrome 擴充功能特色支援哪些格式？

七種：PDF、Markdown、Plain Text、JSON、XML、CSV 和 PNG。PDF 在瀏覽器中產生，有專屬的對話框。CSV 每則訊息一列。PNG 是整段對話的一張圖片。

Chrome 擴充功能特色能匯出 Artifact 和思考過程嗎？

可以。Artifact 版面有 Original、Inline、Nested 或 Flat，Artifact 也可以放進 ZIP 內各自的資料夾。思考過程、工具／MCP 步驟和網頁搜尋來源都要自行開啟。Metadata、寄件者篩選和「Select」皆為選用。

Chrome 擴充功能特色可以免費試用嗎？

可以。Markdown、文字、JSON、XML、CSV 和 PNG 匯出不限次數、免帳號。PDF 和批次 ZIP 用 Google 登入後每天 3 次。透過 Paddle 付款的 Pro（每月 US$3.99 或每年 US$26.99）沒有這個上限。

Chrome 擴充功能特色能在 Desktop 或 Code 中使用嗎？

在 Claude Desktop 或 Claude Code 終端機中不行。內容腳本只會注入 Chrome 裡的 claude.ai。Claude Code 網頁版（claude.ai/code）和 Cowork 工作階段在那裡執行，所以可以匯出。如果 Desktop 對話也存在於 claude.ai，就在那裡開啟。

Chrome 擴充功能特色會上傳我的聊天嗎？

不會。所有檔案（包括 PDF）都在瀏覽器中產生。其他格式的單一聊天匯出不會傳送任何資料。使用 PDF、批次匯出或 Pro 時，只會傳送你的 Google 電子郵件地址，用於每日計數和訂閱。界線說明請見運作方式。
