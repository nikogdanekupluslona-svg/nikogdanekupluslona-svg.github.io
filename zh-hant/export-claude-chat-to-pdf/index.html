如何一步步把 Claude 聊天匯出 PDF？

要把 Claude 聊天匯出 PDF，你需要電腦版 Chrome 和免費的 Download Claude conversations 擴充功能。整個過程只要點五下：開啟聊天、點橘色按鈕、選 PDF、按「Export」，再確認 PDF 對話框。第一次匯出 PDF 時會要求用 Google 登入。

  1. 從 Chrome Web Store 安裝 Download Claude conversations，再重新整理已開啟的 claude.ai 分頁。
  2. 在 claude.ai 開啟對話，等最後一則回覆完整輸出。
  3. 點訊息輸入框右側的圓形橘色下載按鈕，開啟匯出面板。
  4. 在「Format」（格式）選 PDF。「Messages」（訊息）保持「All」（全部），或改選「Human」（使用者）或「Assistant」（助理），只保留對話的一方。
  5. 按「Export」。第一次會要求用 Google 登入，接著設定 PDF 選項並儲存檔案。

同樣的五個步驟適用於一般聊天、Projects、Cowork 工作階段和 Claude Code 網頁版（claude.ai/code）。只要能在 Chrome 的 claude.ai 上開啟，就能匯出成 PDF。擴充功能無法在 Claude Desktop 應用程式或手機上執行；請改在電腦版 Chrome 開啟同一段聊天。

延伸思考是匯出面板裡的「Thinking」（思考）核取方塊。工具與 MCP 步驟、網頁搜尋來源則在擴充功能的設定中開啟。PDF 只包含你勾選的內容，所以推理很長的聊天，印成紙本也能保持精簡。

免費方案的 PDF 限制。PDF 匯出需要 Google 登入，每天免費 3 次，與批次 ZIP 匯出共用；次數在 UTC 午夜重置。Pro 每月 US$3.99 或每年 US$26.99，PDF 不限次數。Markdown、文字、JSON、XML、CSV 和 PNG 一律不限次數、免帳號。

Claude 聊天匯出 PDF 時，哪些設定最重要？

PDF 對話框決定 Claude 聊天做成文件後的樣子。頁面大小、邊界和字型影響易讀性；頁碼、目錄和時間戳記讓長聊天更好查找；每則提示前分頁，讓每個問題都從新的一頁開始。

列印用 A4 或 Letter；配合讀者使用的紙張。

窄邊界放得下寬的程式碼和表格；一般邊界印在紙上比較好讀。

每個問題都從新的一頁開始，回答不會從頁面中間起頭。

程式碼區塊在 PDF 中保留語言標示與格式，表格和清單也維持原樣。這正是把 Claude 聊天匯出 PDF、而不是直接列印的主要原因：列印會在紙張用完的地方把程式碼切斷。

不裝擴充功能，如何把 Claude 聊天存成 PDF？

不安裝任何東西也能把 Claude 聊天存成 PDF，用 Chrome 的列印對話框就行：開啟聊天，Windows 按 Ctrl+P、Mac 按 Cmd+P，把目的地設為「另存為 PDF」，再儲存。這個檔案是網頁的快照，不是匯出的文件，也沒有任何針對 Claude 的設定。

  1. 在 claude.ai 開啟對話，捲動到最前面的第一則訊息，讓每一輪對話都載入。
  2. 收起側邊欄，關閉不想印到紙上的 Artifact 面板。
  3. 按 Ctrl+P 或 Cmd+P，在「目的地」選「另存為 PDF」。
  4. 開啟「更多設定」，選擇紙張大小和邊界；如果頁面看起來很淡，勾選「背景圖形」。
  5. 按「儲存」。

Google 的 Chrome 說明中心在同一套步驟的最後只寫了一行：「按一下 [另存為 PDF]。」列印能做的就這麼多：不會為每則提示加上頁碼，沒有目錄，也沒有深色模式。

每一頁會放進什麼，由 claude.ai 的列印樣式表決定，不是由你決定。MDN 將 CSS 分頁媒體描述為規範「如何產生頁面並進行版面配置，以便在分頁呈現中容納被分割的內容」的規則。當這些規則把程式碼區塊切開，PDF 也會照樣保留切口。

先把整段對話載入。很長的 Claude 聊天只有在往上捲動時才會載入較早的訊息。在那之前列印或匯出，得到的 PDF 就會少了開頭。請捲動到最上方、稍等一下，再列印或匯出。

臨時要一份時，列印就夠用。想看列印與真正 PDF 檔的詳細比較（包括手機），請見Claude 聊天存成 PDF。

如何把 Claude 聊天做成單一 PDF？

按一次「Export」就會得到一個 PDF 檔，從第一則提示到最後一則回答，整段 Claude 聊天都在裡面。你無法把 Claude 聊天以 PDF 形式複製到剪貼簿（「Copy」（複製）只支援 Markdown、文字、JSON、XML 和 CSV），但匯出的檔案本來就是單一 PDF。

只想把部分聊天放進一份 PDF，就用「Select」（選取）。在匯出面板點「Select」，勾選要的訊息，選 PDF，按「Export」。PDF 只會包含這些訊息，並依原本的順序排列。「Messages」篩選則只保留一方：「Assistant」只留 Claude 的回答，「Human」只留你的提示。

多個聊天不會合併成一份 PDF。批次匯出會在 ZIP 裡為每個聊天各寫一份 PDF。如果需要一份合併的文件，請先匯出各個聊天，再用任何 PDF 編輯器合併；或匯出 Markdown，把聊天貼進同一個檔案後再轉換。

如何從 Markdown 把 Claude 聊天轉成 PDF？

想先編輯文字時，就從 Markdown 把 Claude 聊天轉成 PDF。先把聊天匯出為 Markdown（不限次數、免帳號），用 VS Code、Obsidian 或 Typora 等編輯器開啟 .md 檔並修改，再用該編輯器的列印或匯出 PDF 功能。

  1. 在 claude.ai 點橘色按鈕，選 Markdown，按「Export」。不用登入，也不計次。
  2. 在編輯器中開啟檔案。刪減訊息、修正標題，加上你自己的筆記。
  3. 使用編輯器的「匯出為 PDF」或「列印 → 另存為 PDF」，套用你自己的範本和字型。

Markdown 很適合當中間步驟，因為它以純文字來看也很好讀。Markdown 的創造者 John Gruber 寫道：「Markdown 的目標是盡可能容易閱讀、容易書寫。」你可以在 Markdown 中編輯 Claude 聊天，不必跟標記語法搏鬥，最後再一次排版。

代價是要用兩個工具而不是一個。如果不需要修改，擴充功能本身的 PDF 更快，也已經有頁碼和目錄。Markdown 完全不會用到每天的 PDF 額度，對免費方案很有幫助。格式詳情：Markdown 匯出。

Anthropic 的帳號匯出不適合當轉換的起點。它是整個帳號的 JSON ZIP，你得先從中取出一段對話，再把 JSON 轉成可閱讀的文字。直接從開啟中的聊天匯出 Markdown，就能省下這些步驟。

能一次把多個 Claude 聊天匯出 PDF 嗎？

可以。擴充功能的 Dashboard（控制台）能一次產生多個聊天的 PDF：把「Chat format」（聊天格式）設為 PDF，勾選對話，再按「Export All」（全部匯出）。你會得到一個 ZIP，每個聊天一份 PDF。在免費方案中，ZIP 裡的每個聊天都會計入每天 3 次的額度。

  1. 點 Chrome 中的擴充功能圖示，選「View and Download All Conversations」（檢視並下載所有對話）。
  2. 篩選或搜尋清單，勾選需要的聊天。
  3. 把「Chat format」設為 PDF，並選擇是否包含「Thinking」、「Metadata」（中繼資料）、「Tools」（工具）和「Sources」（來源）。
  4. 按「Export All」並儲存 ZIP。

如果勾選的聊天超過今天剩下的免費額度，整批會被擋下，而不是只匯出一部分；請少選幾個，或升級。Pro 取消 PDF 和批次匯出的上限。包含篩選和 Artifact 選項的完整批次流程，請見批次匯出教學。

把每天的 PDF 額度留給重要的聊天。要建立大型封存時，先批次匯出 Markdown 或 JSON（兩者都不限次數），只把真正要寄出或列印的聊天匯出成 PDF。

Claude 聊天匯出的 PDF 為什麼不對勁？

Claude 聊天匯出的 PDF 出問題，大多來自四個原因：對話沒有完整載入、「Format」下拉選單還停在上次用的格式、已用完每天的免費額度，或是用了列印而不是匯出。每個原因都有簡單的解法，列在下表。

Claude 聊天轉 PDF：擴充功能、列印還是官方匯出？

有三種方法能把 Claude 聊天變成檔案，但只有一種能為單一聊天產生真正的 PDF。擴充功能幾秒內就能匯出分頁 PDF；列印得到的是網頁快照；Anthropic 的 Export data 會把整個帳號的 ZIP 寄到電子郵件，而且不是 PDF。

官方做法在 claude.ai 的 Settings → Privacy → Export data（若 claude.ai 介面設為中文，選單名稱可能已翻譯）。Claude 說明中心寫道：「匯出處理完成後，你會透過電子郵件收到下載連結。」同一頁還補充：「下載連結會在寄出 24 小時後失效」。

常見問題：如何把 Claude 聊天匯出 PDF

如何把 Claude 聊天匯出 PDF？

安裝 Download Claude conversations，在 claude.ai 開啟聊天，點訊息輸入框旁的橘色按鈕，選 PDF，按「Export」。第一次要用 Google 登入，設定頁面大小等選項後儲存。PDF 在你的瀏覽器中產生。

如何免費把 Claude 聊天存成 PDF？

擴充功能的 PDF 匯出用 Google 登入後每天免費 3 次。Chrome 的列印對話框（Ctrl+P 或 Cmd+P → 另存為 PDF）免費、不限次數，但得到的是網頁快照。匯出 Markdown 再用編輯器轉換，也是免費且不限次數。

如何把 Claude 聊天下載成 PDF？

在這裡，下載和匯出是同一件事：在匯出面板選 PDF，Chrome 就會像一般下載一樣儲存檔案。列印與匯出檔案的並列比較，請見Claude 聊天存成 PDF。

可以把 Claude 聊天複製成單一 PDF 嗎？

無法複製到剪貼簿：「Copy」只支援 Markdown、文字、JSON、XML 和 CSV，不支援 PDF。請改按「Export」，一次匯出就是一個包含整段聊天的 PDF 檔。只想放入部分訊息，匯出前先用「Select」。

可以只把 Claude 的回答匯出成 PDF 嗎？

可以。在匯出面板把「Messages」設為「Assistant」，選 PDF，按「Export」。PDF 只會包含 Claude 的回覆，不含你的提示。「Human」則正好相反。

Claude 聊天的 PDF 會保留程式碼區塊和表格嗎？

用匯出就會。程式碼區塊保留語言標示與格式，表格和清單也完整保留。列印才是弱點：程式碼區塊會換行或跨頁切開，寬表格會被裁掉。

Claude 聊天可以用深色模式匯出成 PDF 嗎？

可以。PDF 對話框有淺色和深色模式。深色適合在螢幕上閱讀，淺色較適合印在紙上。

可以在手機上把 Claude 聊天轉成 PDF 嗎？

用擴充功能不行，它只能在電腦版 Chrome 和 Chromium 瀏覽器中執行。手機瀏覽器可以把頁面列印或分享成 PDF，但版面擁擠。想要乾淨的 PDF，請在電腦版 Chrome 開啟同一段聊天。

可以把 Claude Code 工作階段匯出成 PDF 嗎？

Claude Code 網頁版（claude.ai/code）在 claude.ai 上開啟，所以擴充功能能像一般聊天一樣把它匯出成 PDF。終端機的工作階段不是網頁：請在那裡用 /export，再從編輯器列印文字檔。

匯出 PDF 時，我的 Claude 聊天會被上傳嗎？

不會。PDF 和其他格式一樣，都在你的瀏覽器中產生。登入後，只會傳送你的 Google 帳號電子郵件，用來確認每日額度或 Pro 狀態。

為什麼我拿到的是 Markdown 檔，而不是 Claude 聊天的 PDF？

匯出面板會記住你上次用的格式。按「Export」前請把「Format」設為 PDF。使用免費方案時更要先確認，因為每份 PDF 都會計入每天 3 次的額度。
