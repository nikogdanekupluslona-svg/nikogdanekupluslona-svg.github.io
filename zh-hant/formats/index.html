這裡的 Claude 聊天匯出格式有哪些？

本網站所說的 Claude 聊天匯出格式，是 Download Claude conversations 從 claude.ai 對話寫出的七種檔案：PDF、Markdown、Plain Text、JSON、XML、CSV 和 PNG。1.16.2 版會在你的瀏覽器中產生每一種格式。其中六種不限次數、免帳號；PDF 需要 Google 登入，每天免費 3 次。

只要對話能在 Chrome 的 claude.ai 上開啟，擴充功能就能使用：聊天、Projects、Cowork 工作階段和 Claude Code 網頁版（claude.ai/code）。Claude Desktop 應用程式和本機 Claude Code 終端機工作階段永遠不會顯示橘色按鈕。如果同一段對話存在於你的 claude.ai 帳號中，就在 Chrome 開啟那個網址，並在那裡選擇格式。下拉選單會記住你上次選擇的格式。

也有人會搜尋 Claude Chat Downloader 或 Claude Conversation Downloader 來找同一個擴充功能。這些名稱指的都是本產品，而不是另一個匯出工具。法律頁面上可能仍寫著 Claude Exporter。你拿到的檔案都是同樣的七種格式。

同一份清單，兩個入口。橘色按鈕匯出目前開啟的聊天。Dashboard（控制台）上的「Export All」則把多個聊天匯出成一個 ZIP，每個聊天一個檔案，格式是你在「Chat format」（聊天格式）中選的七種之一，包括 PDF。詳情請見批次「Export All」。

該選哪種 Claude 聊天匯出格式？

閱讀和分享選 PDF，筆記選 Markdown，腳本選 JSON，試算表選 CSV，貼到哪裡都能用的封存選純文字，系統要求 XML 時選 XML，要一張對話圖片就選 PNG。Download Claude conversations 不會說哪一種最好。這些 Claude 聊天匯出格式只是形式不同；在免費方案中，只有 PDF 有每日上限。

如何選擇 Claude 聊天匯出格式？

在 Chrome 開啟 claude.ai 的對話網址，點訊息輸入框旁的橘色按鈕，選擇一種 Claude 聊天匯出格式，再按「Export」（匯出）。Download Claude conversations 會在分頁中組出檔案。截至 2026 年 9 月，claude.ai 本身沒有「匯出這段聊天」的功能。

  1. 從 Chrome Web Store 安裝 Download Claude conversations。
  2. 重新整理 claude.ai，開啟一個真正的對話網址，而不是空白的輸入首頁。
  3. 點訊息輸入框右側的圓形橘色下載按鈕。
  4. 選擇 PDF、Markdown、Plain Text、JSON、XML、CSV 或 PNG。擴充功能會記住上次的格式。
  5. 按「Export」，Chrome 會立即存下檔案。選 PDF 時，請在 PDF 對話框中設定選項；第一次存 PDF 會要求用 Google 登入。

Markdown、文字、JSON、XML、CSV 和 PNG 不需要登入：這些匯出不限次數、匿名，也不會傳送任何資料。只有 PDF、「Export All」或 Pro 才會出現 Google 登入。之後擴充功能只會傳送 Google 電子郵件地址，用來確認每日限制，以及在重新安裝後恢復 Pro。聊天內容絕不會被上傳。運作機制請見運作方式。

匯出面板還能設定 Messages（All、Human、Assistant，即全部、使用者、助理）、「Thinking」核取方塊，以及可逐一勾選訊息的「Select」（選取）。「Copy」會把 Markdown、文字、JSON、XML 或 CSV 放到剪貼簿，而不是存成檔案；它不限次數，但不適用於 PDF 或 PNG。工具／MCP 步驟和網頁搜尋來源在設定中開啟。Metadata 和 Artifact 版面（「Original」「Inline」「Nested」「Flat」，即原始／內嵌／巢狀／平面）是 Dashboard 的選項；版面決定 Artifact 要放在檔案裡，還是放進 ZIP 中各自的資料夾。

Claude 聊天匯出格式能用於「Export All」嗎？

可以。開啟擴充功能的彈出視窗 →「View and Download All Conversations」（查看並下載所有對話），篩選清單、勾選聊天，在「Chat format」中選七種格式中的任一種，再按「Export All」。你會得到一個 ZIP，每個聊天一個檔案。批次匯出需要 Google 登入；在免費方案中，ZIP 裡的每個聊天都會用掉每天 3 次 PDF 或批次匯出中的一次。Pro（每月 US$3.99 或每年 US$26.99）沒有這個上限。

Dashboard 會列出 claude.ai 紀錄，提供依名稱搜尋、專案搜尋、Chat 與 Cowork 分頁，以及 All conversations、New、Updated 和 Previously exported（所有對話、新的、已更新、先前已匯出）篩選條件。New 表示尚未用 Download Claude conversations 匯出過；Previously exported 會記錄你已存過的聊天。「Export All」不是稍後才寄來的帳號 ZIP。

批次上限以天計算。在免費方案中，PDF 和批次匯出共用每天 3 次，於 UTC 午夜重置。ZIP 裡的每個聊天各算一次。如果選取的數量超過今天剩餘的額度，整批會被擋下，而不是只匯出一部分。請減少選取的聊天，或改用 Pro。

批次匯出有自己的包含項目核取方塊「Chats」「Thinking」「Metadata」「Tools」「Sources」（聊天、思考過程、中繼資料、工具、來源），以及 Artifact 版面。一次點擊不會同時得到 Markdown 加 JSON 的混合包；每次執行只能在「Chat format」選單中選一種 Claude 聊天匯出格式。如果同一段對話需要兩種格式，就換個格式再執行一次「Export All」；在免費方案中，第二次執行會再計算一次。

Claude 聊天匯出格式與 Anthropic ZIP 有何不同？

Anthropic 的 Settings → Privacy → Export data（若 claude.ai 介面設為中文，選單名稱可能已翻譯）會在等待一段時間後，把整個帳號的 JSON ZIP 寄到你的電子郵件。Download Claude conversations 的 Claude 聊天匯出格式則會立即把目前開啟的對話存成 PDF、Markdown、文字、JSON、XML、CSV 或 PNG。要備份就用 ZIP；現在就要檔案，就用這個擴充功能。

常見問題：Claude 聊天匯出格式

以下常見問題涵蓋 Download Claude conversations 1.16.2 的 Claude 聊天匯出格式：七種格式清單、PDF、CSV、限制、「Export All」、Anthropic 的 ZIP、Desktop 與 Code，以及 Pro。每個答案都是產品事實，頁首的 FAQPage JSON-LD 與此清單一致。

可以下載哪些 Claude 聊天匯出格式？

七種：PDF、Markdown、Plain Text、JSON、XML、CSV 和 PNG。Markdown、文字、JSON、XML、CSV 和 PNG 不限次數、免帳號。PDF 需要 Google 登入，每天免費 3 次。

PDF 是 Claude 聊天匯出格式之一嗎？

是的。在匯出面板選 PDF。PDF 對話框可設定檔名、頁面大小、邊界、淺色或深色模式、字型與字級、頁碼、目錄、時間戳記，以及每則提示前分頁。檔案在瀏覽器中產生，不經過列印對話框。

CSV 匯出是做什麼用的？

用於試算表。CSV 每則訊息寫成一列，可用 Excel、Google 試算表和 Numbers 開啟。它不限次數、免帳號，也可以複製到剪貼簿而不必下載。

Claude 聊天匯出格式有每日限制嗎？

只有 PDF 和批次匯出有。單一聊天的 Markdown、文字、JSON、XML、CSV 和 PNG 匯出不限次數且免費。在免費方案中，PDF 和批次 ZIP 共用每天 3 次，於 UTC 午夜重置。Pro（每月 US$3.99 或每年 US$26.99）沒有上限。

可以在「Export All」中混用 Claude 聊天匯出格式嗎？

不行。每次執行「Export All」只使用一種格式，並寫出一個 ZIP。如果同一個 claude.ai 聊天需要兩種檔案，就換個格式再執行一次。在免費方案中，每個 ZIP 裡的每個聊天都會計入每天 3 次的 PDF 或批次匯出。

Claude 聊天匯出格式和 Export data 一樣嗎？

不一樣。Anthropic 的 Export data 是稍後才寄來的帳號 JSON ZIP。Claude 聊天匯出格式則是 Download Claude conversations 在 Chrome 中立即寫出的單一聊天（或選取範圍）檔案。

Claude 聊天匯出格式能在 Desktop 或 Code 中使用嗎？

網頁版可以。聊天、Projects、Cowork 工作階段和 Claude Code 網頁版（claude.ai/code）在 Chrome 中都能使用所有格式。Claude Desktop 應用程式和本機 Claude Code 終端機工作階段永遠不會顯示格式下拉選單。如果同一段對話也存在於 claude.ai，就在 Chrome 中開啟它。

試用 Claude 聊天匯出格式需要 Pro 嗎？

不需要。免費方案中有六種格式不限次數、免帳號。PDF 用 Google 登入後每天免費 3 次，與批次 ZIP 共用。需要不限次數的 PDF 或批次匯出時，再選擇 Pro（每月 US$3.99 或每年 US$26.99）。
