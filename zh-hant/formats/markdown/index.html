如何把 Claude 聊天匯出成 Markdown？

在 Chrome 中開啟 claude.ai 上的對話，點訊息輸入框旁的橘色按鈕，選擇 Markdown，再按「Export」。Download Claude conversations 會在本機寫出一個 .md 檔。這就是在 1.16.2 版中把 Claude 聊天匯出成 Markdown 的方法（香港使用者常說「導出」，指的是同一件事）。

  1. 從 Chrome Web Store 安裝 Download Claude conversations。
  2. 重新整理 claude.ai，開啟一個真正的對話網址，而不是空白的輸入首頁。
  3. 點訊息輸入框右側的橘色下載按鈕。
  4. 選擇 Markdown。擴充功能會記住你上次使用的格式。用「Select」（選取）只勾選你需要的訊息。
  5. 按「Export」。Chrome 會透過瀏覽器的下載 API 存下 .md 檔。也可以按「Copy」（複製），把 Markdown 放到剪貼簿。

匯出 Markdown 不需要登入。單一聊天的 Markdown 匯出不限次數、匿名進行，不會傳送任何資料到我們的伺服器。只有 PDF 和批次「Export All」（全部匯出）才會要求 Google 登入。運作機制請見運作方式。

如果看不到橘色按鈕，可能是你不在對話網址上、安裝後分頁還沒重新整理，或擴充功能仍藏在 Chrome 的拼圖選單裡。釘選 Download Claude conversations，再重新整理 claude.ai。內容腳本永遠不會注入 Claude Desktop 或 Claude Code 終端機。

一個聊天或很多個。橘色按鈕會把目前開啟的對話匯出成 Markdown。要產出很多 .md 檔，請開啟「View and Download All Conversations」（查看並下載所有對話），選好 Markdown 後執行「Export All」：產出一個 ZIP，免費方案每天 3 個聊天，詳見批次「Export All」。

為什麼做筆記要用 Markdown？

如果你會在 Obsidian、GitHub wiki 或任何能顯示標題和程式碼區塊的編輯器裡閱讀檔案，就選 Markdown。.md 檔仍然是純文字，可以搜尋，也可以比對差異。JSON 比較適合解析程式；PNG 則是一張圖片，無法用 grep 搜尋。

從 claude.ai 複製貼上，通常會弄丟縮排，表格也會被攤平。列印（Ctrl/Cmd+P）會連側邊欄一起印出，長的程式碼區塊也常被切到好幾頁。匯出成 Markdown 時，程式碼區塊會保留語言標籤，表格仍是表格。這就是撰稿者優先選這個格式的原因。

我們把 Markdown 當作預設的人類可讀檔案：包含 claude.ai 對話裡的標題、帶語言標籤的程式碼區塊和表格。需要分頁文件時，請在同一個面板選 PDF。它在瀏覽器中排版，可設定頁面大小、邊界和目錄。

Markdown 檔會保留哪些內容？

匯出成 Markdown 時，Download Claude conversations 會保留標題、帶語言標籤與縮排的程式碼區塊、表格和連結。思考區塊、網頁搜尋來源，以及工具／MCP 步驟都需要自行開啟：「Thinking」（思考過程）是匯出面板中的核取方塊，另外兩項在設定頁開啟。中繼資料（標題、時間戳記、模型）也可以一併匯出。傳送者篩選可以讓 .md 檔只包含全部訊息、只有使用者，或只有助理的訊息。

在 1.16.2 版中，Artifact 版面是真正可切換的選項：「Original」「Inline」「Nested」或「Flat」（原始、內嵌、巢狀、扁平）。Markdown 匯出可以照畫面上的 Artifact 結構呈現、攤平成一份線性文件，或把 Artifact 放進 ZIP 裡各自的資料夾。設定頁可以把圖片嵌入 .md 檔。完整清單：Chrome 擴充功能特色。Markdown 不會保留訊息泡泡的顏色；要視覺快照請用 PNG，要分頁文件請用 PDF。

如果對話很長，匯出成 Markdown 前請先往上捲動，讓 claude.ai 載入較早的訊息。擴充功能只能寫出頁面已經顯示的內容。只載入一半的對話會產生只有一半的 .md 檔，看起來像錯誤，其實通常只是還沒捲動載入。

可以一次把多個聊天匯出成 Markdown 嗎？

可以。開啟「View and Download All Conversations」，把「Chat format」（聊天格式）設為 Markdown，篩選表格，再按「Export All」。Chrome 會存下一個 ZIP，每個聊天一個 .md 檔。免費方案用 Google 登入後每天可匯出 3 個聊天，與 PDF 共用。Pro（每月 US$3.99 或每年 US$26.99）取消批次 Markdown 的這個上限。

Dashboard（控制台）會列出 claude.ai 的對話紀錄，可依名稱搜尋，提供 All conversations、New、Updated 和 Previously exported（所有對話、新的、已更新、先前已匯出）篩選條件、Chat 與 Cowork 分頁，以及專案搜尋。New 表示尚未用 Download Claude conversations 匯出過。Previously exported 會記錄你已存過的聊天，讓第二次「Export All」可以略過它們。

每日限制以帳號計算。免費方案每天 3 個聊天，與 PDF 共用。如果只剩 3 次卻選了 40 個對話，整批會被擋下，而不是只匯出一部分。少選一些，或改用 Pro。從橘色按鈕匯出的單一 .md 檔仍然不限次數。

批次 Markdown 使用 Dashboard 的「Chats」「Thinking」「Metadata」「Tools」「Sources」（聊天、思考過程、中繼資料、工具、來源）核取方塊，以及 Artifact 格式。「Export All」不是 Anthropic 稍後寄出的 ZIP，而是一個 ZIP，裡面每個聊天各一個 .md 檔。如果你想要整個帳號的單一封存檔，那是 Settings → Privacy → Export data（若 claude.ai 設為中文，選單名稱可能會顯示為中文），格式是 JSON，不是 Markdown。

匯出 Claude 聊天時，該選 Markdown 還是 JSON？

檔案要給人閱讀時，選 Markdown。要讓腳本解析訊息結構時，匯出成 JSON。Download Claude conversations 在同一個選單裡提供這兩種，還有 PDF、純文字、XML、CSV 和 PNG。格式總覽：Claude 聊天匯出格式。

Anthropic 的 Export data 也是 JSON，但它是以電子郵件寄送的帳號 ZIP，不是單一聊天的 .md 檔。在那個申請裡無法選擇 Markdown。瀏覽器列印則是網頁快照。兩者都無法取代用橘色按鈕把 Claude 聊天匯出成 Markdown。

擴充功能只在 Chrome 的 claude.ai 上執行。Claude Desktop 和 Claude Code 終端機都沒有 Markdown 按鈕。Claude Code 網頁版（claude.ai/code）在 claude.ai 上執行，所以能像一般聊天一樣匯出。如果某個對話也在 claude.ai 上，請在那裡開啟再匯出成 Markdown。終端機版 Claude Code 的 /export 是另一條產品路徑。

匯出 Markdown 要額外付費嗎？

不用。單一聊天的 Markdown 匯出免費、不限次數，不需要帳號，也沒有計數，和 JSON、文字、XML、CSV、PNG 一樣。只有 PDF 和批次「Export All」有免費限制：用 Google 登入後每天 3 次。Pro 透過 Paddle 付款，每月 US$3.99 或每年 US$26.99。Download Claude conversations 不會為 Markdown 額外收費。

限制只會出現在批次 Markdown。「Export All」ZIP 裡的每個聊天都會用掉每天 3 次中的 1 次，計數在 UTC 午夜重設。Pro 取消這個限制，在新電腦上用同一個 Google 帳號登入即可恢復。Paddle 是正式的交易商家；我們團隊永遠看不到卡號。

你不需要 Anthropic 的付費 claude.ai 方案，只需要一個能在 Chrome 中載入對話的登入帳號。Team 和 Enterprise 使用橘色按鈕的方式和 Free 相同。2026 年 9 月的 1.16.2 版仍然不會寫出 Word 或 Notion 檔案。

常見問題：Claude 聊天匯出 Markdown

這些常見問題說明如何在 Download Claude conversations 1.16.2 中把 Claude 聊天匯出成 Markdown：程式碼區塊、批次「Export All」、Anthropic 的 ZIP、費用、PDF 和 Desktop。每個回答都是產品事實。頁首的 FAQPage JSON-LD 與這份清單一致。

把 Claude 聊天匯出成 Markdown 會弄丟程式碼嗎？

不會。程式碼區塊會保留語言標籤和縮排，不像從 claude.ai 直接複製貼上。表格仍是 Markdown 表格。這正是選擇匯出成 Markdown、而不是手動選取文字的主要原因。

可以一次把多個 Claude 聊天匯出成 Markdown 嗎？

可以。Dashboard 上的「Export All」支援 Markdown，會存成一個裝滿 .md 檔的 ZIP。免費方案用 Google 登入後每天可匯出 3 個聊天；Pro 不限次數。

Markdown 和 Anthropic 的 Export data 一樣嗎？

不一樣。Anthropic 的官方匯出是整個帳號的 JSON ZIP，要等一段時間才會寄到信箱。用 Download Claude conversations 匯出 Markdown，得到的是單一聊天（或所選訊息）的 .md 檔。

Markdown 比其他格式貴嗎？

不會。單一聊天的 Markdown 匯出不限次數、不需要帳號，和 JSON、文字、XML、CSV、PNG 一樣。只有 PDF 和批次 ZIP 有每天 3 次的免費限制。Pro 是每月 US$3.99 或每年 US$26.99。

可以在 Desktop 上把 Claude 聊天匯出成 Markdown 嗎？

不行。Download Claude conversations 只會注入 Chrome 中的 claude.ai。Claude Desktop 永遠不會出現 Markdown 選單。如果同一個對話也在 claude.ai 上，請在那裡開啟。

匯出成 Markdown 會產生 PDF 嗎？

不會。Markdown 是 .md 文字檔。需要分頁文件時，請改在同一個面板選 PDF：它在瀏覽器中產生，可設定頁面大小、邊界和目錄。PDF 需要 Google 登入，在免費方案中計入每天 3 次。

只匯出一次 Markdown 也需要 Pro 嗎？

不需要。你完全不需要帳號。免費方案中，單一聊天的 Markdown 匯出不限次數。Pro（每月 US$3.99 或每年 US$26.99）只是取消批次「Export All」和 PDF 每天 3 次的限制。
