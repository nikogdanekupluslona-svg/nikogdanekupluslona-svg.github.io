如何下載 Claude 聊天為 PNG？

在 Chrome 中開啟 claude.ai 上的對話，點訊息輸入框旁的橘色按鈕，選擇 PNG，再按「Export」。Download Claude conversations 會在分頁中繪製圖片。這就是在 1.16.2 版中把 Claude 聊天匯出（香港常說「導出」）成 PNG 的方法：免費、不限次數、不需要帳號。

  1. 從 Chrome Web Store 安裝 Download Claude conversations。
  2. 重新整理 claude.ai，開啟一個真正的對話網址，而不是空白的輸入首頁。
  3. 點訊息輸入框右側的圓形橘色下載按鈕。
  4. 選擇 PNG。擴充功能會記住你上次使用的格式。
  5. 按「Export」。Chrome 會立即下載 PNG。

存成 PNG 不需要 Google 登入。單一聊天的 PNG 匯出不限次數、匿名進行：沒有計數，聊天的任何內容都不會離開瀏覽器。只有在你選擇 PDF、執行「Export All」（全部匯出）或購買 Pro 時，才會出現登入。運作機制請見運作方式。

如果看不到橘色按鈕，可能是你不在對話網址上、安裝後分頁還沒重新整理，或擴充功能藏在 Chrome 的拼圖選單裡。釘選 Download Claude conversations，再重新整理 claude.ai。Projects、Cowork 工作階段和 Claude Code 網頁版（claude.ai/code）都能像一般聊天一樣匯出。PNG 匯出永遠不會出現在 Claude Desktop 應用程式或本機的 Claude Code 終端機工作階段中。

一張圖或很多張。橘色按鈕會為目前開啟的對話寫出一張 PNG。要產出很多張圖片，請開啟「View and Download All Conversations」（查看並下載所有對話），選好 PNG 後執行「Export All」。批次匯出會寫出一個 ZIP，並使用每日的批次額度，詳見批次「Export All」。

什麼時候該存成 PNG？

當你需要一張圖片放進簡報、聊天 App 或工單，也就是放圖片比放 .md 檔方便的地方，就把 Claude 聊天存成 PNG。如果之後需要搜尋或複製程式碼，就不要選 PNG。那種情況請用 Markdown，需要分頁則用 PDF。

自己手動截取的 claude.ai 畫面，常常會連側邊欄和輸入框一起截進去。Download Claude conversations 是根據已經解析好的對話內容產生 PNG，而不是隨便一張系統截圖。但它仍然是圖片：沒有訊息結構，也沒有可以當文字複製、帶語言標籤的程式碼區塊。

我們加入 PNG，是為了讓你能把 claude.ai 對話的視覺快照存成一個檔案。如果你需要分頁而不是一張長圖，請選 PDF：擴充功能會直接產生，附頁碼和目錄。PNG 仍然不限次數、不需要帳號。

PNG 和 PDF 一樣嗎？

不一樣。PNG 是圖片格式，PDF 是分頁的文件格式。Download Claude conversations 兩種都能匯出：PNG 是一張圖，PDF 是分頁文件。PNG 不限次數、不需要帳號；PDF 需要 Google 登入，每天免費 3 次。教學請見把 Claude 聊天下載成 PDF。

Claude 聊天的 PNG 匯出包含什麼？

Claude 聊天的 PNG 匯出，是 Download Claude conversations 所繪製對話內容的單一圖片。和 Markdown 或 JSON 不同，PNG 不帶有可解析的訊息結構。程式碼和表格都是像素。思考過程和 Artifact 是畫出來的，不是以文字儲存。

Messages 篩選可以限定畫出全部訊息、只有使用者，或只有助理的訊息；「Thinking」（思考過程）核取方塊決定是否加入延伸思考；「Select」（選取）可以逐一勾選訊息。中繼資料和 Artifact 版面（「Original」「Inline」「Nested」「Flat」，即原始、內嵌、巢狀、扁平）是 Dashboard（控制台）上「Export All」的選項。中繼資料在 PNG 上不會像在 JSON 裡那樣成為可選取的文字。「Copy」（複製）不適用於 PNG；PNG 一律是檔案。

如果對話很長，存成 PNG 前請先往上捲動，讓 claude.ai 載入較早的訊息。擴充功能只能繪製頁面已經載入的內容。只載入一半的對話會產生被截斷的圖片。完整的選項清單：Chrome 擴充功能特色。

在意文字內容，就留一份文字版。PNG 是快照。如果之後要用 grep 搜尋函式名稱，會找不到。另外匯出一份 Markdown 或 JSON；它和 PNG 一樣免費、不限次數。

可以批次下載成 PNG 嗎？

可以。開啟「View and Download All Conversations」，把「Chat format」（聊天格式）設為 PNG，篩選清單，再按「Export All」。你會得到一個 ZIP，每個選取的對話一張 PNG。批次匯出需要 Google 登入；免費方案中，ZIP 裡的每個聊天都會用掉每天 3 次 PDF 或批次匯出中的 1 次。Pro（每月 US$3.99 或每年 US$26.99）取消這個上限。

Dashboard 會列出 claude.ai 的對話紀錄，可依名稱搜尋、搜尋專案，提供 Chat 與 Cowork 分頁，以及 All conversations、New、Updated 和 Previously exported（所有對話、新的、已更新、先前已匯出）篩選條件。New 表示尚未用 Download Claude conversations 匯出過。「Export All」會在 ZIP 裡為每個選取的對話產生一張 PNG，不是拼貼成一張縮圖總覽，也不是合訂成 PDF。

批次額度在 UTC 午夜重設。免費方案中，如果選取數量超過今天剩下的額度，整批會被擋下，而不是只匯出一部分：少選一些，或改用 Pro。從橘色按鈕匯出的單一聊天 PNG 仍然不限次數。Anthropic 的 Settings → Privacy → Export data（若 claude.ai 設為中文，選單名稱可能會顯示為中文）仍然是延遲寄出的 JSON ZIP，不是一個裝滿圖片的資料夾。

存成 PNG 要額外付費嗎？

不用。PNG 免費、不限次數，和 Markdown、JSON、文字、XML、CSV 一樣。不需要 Google 帳號，也沒有計數。Pro（透過 Paddle 付款，每月 US$3.99 或每年 US$26.99）是為了不限次數的 PDF 和批次 ZIP，不是為了 PNG。Download Claude conversations 不會為下載 Claude 聊天為 PNG 額外收費。

只有在你需要 PDF 或「Export All」時才要登入：免費方案中兩者共用每天 3 次。在新電腦上用同一個 Google 帳號登入，Pro 就會恢復。Paddle 是正式的交易商家；我們團隊永遠看不到卡號。

擴充功能在 Chrome 的 claude.ai 上執行：聊天、Projects、Cowork 工作階段和 Claude Code 網頁版（claude.ai/code）。Claude Desktop 應用程式和本機的 Claude Code 終端機工作階段都沒有 PNG 按鈕。2026 年我們團隊沒有 iOS 或 Android App。1.16.2 版能寫出 PDF，但不會寫出 Word 或 Notion 檔案。

常見問題：下載 Claude 聊天為 PNG

這些常見問題說明 Download Claude conversations 1.16.2 中如何下載 Claude 聊天為 PNG：PDF、批次「Export All」、限制，以及圖片包含的內容。每個回答都是產品事實。頁首的 FAQPage JSON-LD 與這份清單一致。

Download Claude conversations 能匯出 PDF 嗎？

可以。在匯出面板選 PDF，就能得到分頁文件，可選擇加入頁碼和目錄。PNG 是整段對話的一張圖片。PDF 需要 Google 登入，每天免費 3 次；PNG 不限次數、不需要帳號。

可以把所有對話紀錄都下載成 PNG 嗎？

可以。Dashboard 上的「Export All」支援 PNG，會產生一個 ZIP，每個選取的對話一張圖片。批次匯出需要 Google 登入；免費方案中，ZIP 裡的每個聊天都會用掉每天 3 次 PDF 或批次匯出中的 1 次。Pro 不限次數。

PNG 是免費的，還是只有 Pro 能用？

免費且不限次數。單一聊天的 PNG 匯出不需要帳號，也沒有計數。Pro（每月 US$3.99 或每年 US$26.99）是為了不限次數的 PDF 和批次 ZIP。

可以從 Claude 聊天的 PNG 複製程式碼嗎？

沒辦法順利複製。存成 PNG 儲存的是像素。如果需要帶語言標籤的程式碼區塊，請匯出 Markdown 或 JSON。同時需要圖片和可搜尋的文字時，兩種檔案都保留。

下載 Claude 聊天為 PNG 是 Chrome 的截圖嗎？

不是。Download Claude conversations 是根據在 claude.ai 上解析的對話產生 PNG。它仍然是圖片，不是 Markdown 檔。整個視窗的系統截圖是你自己另外擷取的檔案。

PNG 能在 Claude Desktop 上使用嗎？

不能。這個 Chrome 擴充功能在 Chrome 的 claude.ai 上執行，不在 Claude Desktop 應用程式裡。Claude Desktop 永遠不會出現 PNG 選項。如果同一個對話也在 claude.ai 上，請在 Chrome 中開啟它。

PNG 匯出和 Markdown 使用同一個額度嗎？

是的，兩者都沒有額度。單一聊天的 PNG 和 Markdown 匯出都不限次數、匿名進行。唯一的上限是免費方案每天 3 次 PDF 或批次 ZIP 匯出；Pro 取消這個上限。
