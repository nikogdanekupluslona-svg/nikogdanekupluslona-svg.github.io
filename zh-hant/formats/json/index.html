如何把 Claude 對話匯出成 JSON？

在 Chrome 中開啟 claude.ai 上的對話，點訊息輸入框旁的橘色按鈕，選擇 JSON，再按「Export」。Download Claude conversations 會在本機寫出檔案。這就是在 1.16.2 版中把 Claude 對話匯出成 JSON（香港使用者常說「導出」）的方法。截至 2026 年 9 月，claude.ai 本身沒有把單一聊天另存為 JSON 的功能。

  1. 從 Chrome Web Store 安裝 Download Claude conversations。
  2. 重新整理 claude.ai，開啟一個真正的對話網址，而不是空白的輸入首頁。
  3. 點訊息輸入框右側的橘色下載按鈕。
  4. 選擇 JSON。擴充功能會記住你上次使用的格式。用「Select」（選取）只勾選你需要的訊息。
  5. 按「Export」。Chrome 會透過瀏覽器的下載 API 存下 JSON。也可以按「Copy」（複製），把 JSON 放到剪貼簿。

匯出 JSON 不需要登入。單一聊天的 JSON 匯出不限次數、匿名進行，不會傳送任何資料到我們的伺服器。只有 PDF 和批次「Export All」（全部匯出）才會要求 Google 登入。運作機制請見運作方式。

如果看不到橘色按鈕，可能是你不在對話網址上、分頁需要重新整理，或擴充功能藏在 Chrome 的拼圖選單裡。釘選 Download Claude conversations，再重新整理 claude.ai。內容腳本永遠不會注入 Claude Desktop 或 Claude Code 終端機。

一個對話或很多檔案。橘色按鈕會把目前開啟的聊天匯出成 JSON。要產出很多 JSON 檔，請開啟「View and Download All Conversations」（查看並下載所有對話），選好 JSON 後執行「Export All」：產出一個 ZIP，免費方案每天 3 個聊天，詳見批次「Export All」。

什麼時候該匯出成 JSON？

當腳本、索引工具或差異比對工具要讀取檔案時，就把對話匯出成 JSON。這個 JSON 是為訊息結構設計的，不是用來在 Obsidian 裡閱讀的。如果你要給人看的標題和程式碼區塊，請改選 Markdown。要放進試算表，請選 CSV：每則訊息一列。

從 claude.ai 複製貼上會失去傳送者結構。列印會連網頁介面一起保留。把 Claude 對話匯出成 JSON 時，Download Claude conversations 會把每一輪、傳送者和選用的思考過程保留為資料，而不是攤平成一段文字。這就是開發者選 JSON 而不選純文字的原因。

我們從頁面上已有的 claude.ai 結構寫出 JSON：傳送者、內容區塊、時間戳記、模型中繼資料，完全不上傳對話內容。這個 JSON 不是 Anthropic 的帳號 ZIP。在 1.16.2 版中，它是七種格式之一，和 PDF、CSV 並列，免費且不需要帳號。

Download Claude conversations 團隊

也有人搜尋 Claude Chat Downloader 或 Claude Conversation Downloader 找到同一個商店頁面。把對話匯出成 JSON 用的就是那個橘色按鈕，不是另一個產品。法律頁面上可能仍寫著 Claude Exporter。

JSON 匯出檔裡有什麼？

Claude 對話的 JSON 匯出檔會對應 claude.ai 上的訊息結構：傳送者、內容區塊、時間戳記和模型中繼資料。開啟相關選項時，也會包含思考區塊、網頁搜尋來源、工具／MCP 步驟和 Artifact：「Thinking」（思考過程）是匯出面板中的核取方塊，工具和來源在設定頁開啟。傳送者篩選可以讓檔案只包含全部訊息、只有使用者，或只有助理的訊息。內容不會先被轉成 Markdown 再攤平。

1.16.2 版的 Artifact 版面有「Original」「Inline」「Nested」「Flat」（原始、內嵌、巢狀、扁平）。這些版面會改變 Artifact 內容在 JSON 中的巢狀方式，和 Markdown、XML 使用的是同樣四個選項。完整清單：Chrome 擴充功能特色。需要分頁文件而不是資料時，請匯出 PDF。

對話 JSON 和 Anthropic 的 Export data 有什麼不同？

兩者都是 JSON，但結構和範圍不同。Anthropic 的 Settings → Privacy → Export data（若 claude.ai 設為中文，選單名稱可能會顯示為中文）會在一段時間後，以電子郵件寄出整個帳號的一個 ZIP。用擴充功能把 Claude 對話匯出成 JSON，則會在 Chrome 中立即拿到一個對話。ZIP 適合拿來備份。

可以批次匯出成 JSON 嗎？

可以。開啟「View and Download All Conversations」，把「Chat format」（聊天格式）設為 JSON，篩選表格，再按「Export All」。Chrome 會存下一個 ZIP，每個聊天一個 JSON 檔。免費方案用 Google 登入後每天可匯出 3 個聊天，與 PDF 共用。Pro（每月 US$3.99 或每年 US$26.99）取消批次 JSON 的這個上限。

Dashboard（控制台）會列出 claude.ai 的對話紀錄，可依名稱搜尋，提供 All conversations、New、Updated 和 Previously exported（所有對話、新的、已更新、先前已匯出）篩選條件、Chat 與 Cowork 分頁，以及專案搜尋。New 表示尚未用 Download Claude conversations 匯出過。Previously exported 會記錄你已存過的聊天。「Export All」產出的是一個 ZIP，每個聊天各一個 JSON 檔，不是混合格式的封存檔。

每日限制以帳號計算。免費方案每天 3 個聊天，與 PDF 共用。如果只剩 3 次卻選了 40 個對話，整批會被擋下，而不是只匯出一部分。少選一些，或改用 Pro。從橘色按鈕匯出的單一 JSON 仍然不限次數。

同一個 claude.ai 對話在不同時間匯出的兩個 JSON 檔，可以像比對任何 JSON 檔一樣比對差異。每次匯出都是獨立完整的檔案。對同一批聊天再執行一次「Export All」，每個聊天都會再計算一次。

匯出 JSON 需要 Pro 嗎？

不需要。單一聊天的 JSON 匯出免費、不限次數，不需要帳號，也沒有計數，和 Markdown、文字、XML、CSV、PNG 一樣。只有 PDF 和批次「Export All」有免費限制：用 Google 登入後每天 3 次。Pro 透過 Paddle 付款，每月 US$3.99 或每年 US$26.99。用 Download Claude conversations 把 Claude 對話匯出成 JSON 不會額外收費。

限制只會出現在批次 JSON。「Export All」ZIP 裡的每個聊天都會用掉每天 3 次中的 1 次，計數在 UTC 午夜重設。Pro 取消這個限制，在新電腦上用同一個 Google 帳號登入即可恢復。Paddle 是正式的交易商家；我們團隊永遠看不到卡號。

擴充功能只在 Chrome 的 claude.ai 上執行。Claude Desktop 和 Claude Code 終端機都沒有 JSON 按鈕；Claude Code 網頁版（claude.ai/code）在 claude.ai 上執行，所以能像一般聊天一樣匯出。終端機版 Claude Code 的 /export 或磁碟上的 JSONL 是另一條途徑。2026 年 9 月的 1.16.2 版仍然不會寫出 Word 或 Notion 檔案。

常見問題：Claude 對話匯出 JSON

這些常見問題說明如何在 Download Claude conversations 1.16.2 中把 Claude 對話匯出成 JSON：批次「Export All」、資料結構、費用、差異比對、Anthropic 的 ZIP、PDF 和 Desktop。每個回答都是產品事實。頁首的 FAQPage JSON-LD 與這份清單一致。

可以批次把 Claude 對話匯出成 JSON 嗎？

可以。Dashboard 上的「Export All」支援 JSON，會存成一個 ZIP，每個聊天一個 JSON 檔。免費方案用 Google 登入後每天可匯出 3 個聊天；Pro（每月 US$3.99 或每年 US$26.99）不限次數。

JSON 結構有文件說明嗎？

它對應 claude.ai 本身的訊息結構：傳送者、內容區塊、時間戳記和模型中繼資料；開啟相關選項時，也會包含 Artifact、思考區塊、網頁搜尋來源和工具／MCP 步驟。它不是 Anthropic 帳號 ZIP 的結構。

把 Claude 對話匯出成 JSON 需要 Pro 嗎？

不需要。單一聊天的 JSON 匯出不限次數、不需要帳號，除了 PDF 以外的每種格式都一樣。Pro（每月 US$3.99 或每年 US$26.99）只是取消 PDF 和批次「Export All」每天 3 次的限制。

可以比對同一個聊天的兩個 JSON 匯出檔嗎？

可以。每次把 Claude 對話匯出成 JSON，都會得到用同樣方式產生、獨立完整的檔案。比對同一個對話在不同時間的兩次匯出，就和比對其他 JSON 檔一樣。

這個 JSON 和 Anthropic 的 Export data 一樣嗎？

不一樣。Anthropic 的 Export data 是延遲寄出的整個帳號 ZIP。Download Claude conversations 會在 Chrome 中立即寫出單一聊天（或所選訊息）的 JSON 檔。兩者可能都是 JSON，但不能互相替代。

匯出成 JSON 會產生 PDF 嗎？

不會。JSON 是結構化資料。需要分頁文件時，請在同一個面板選 PDF；七種格式是 PDF、Markdown、JSON、純文字、XML、CSV 和 PNG。PDF 需要 Google 登入，在免費方案中計入每天 3 次。

JSON 匯出能在 Claude Desktop 上使用嗎？

不能。這個 Chrome 擴充功能只會注入 claude.ai。Claude Desktop 永遠不會出現 JSON 選項。如果同一個對話也在 claude.ai 上，請在 Chrome 中開啟它。
