如何把 Claude 聊天匯出成 XML？

在 Chrome 中開啟 claude.ai 上的對話，點訊息輸入框旁的橘色按鈕，選擇 XML，再按「Export」。Download Claude conversations 會在本機寫出檔案。這就是在 1.16.2 版中把 Claude 聊天匯出（香港常說「導出」）成 XML 的方法。截至 2026 年 9 月，claude.ai 本身沒有另存為 XML 的功能。

  1. 從 Chrome Web Store 安裝 Download Claude conversations。
  2. 重新整理 claude.ai，開啟一個真正的對話網址，而不是空白的輸入首頁。
  3. 點訊息輸入框右側的橘色下載按鈕。
  4. 選擇 XML。擴充功能會記住你上次使用的格式。用「Select」（選取）只勾選你需要的訊息。
  5. 按「Export」。Chrome 會透過瀏覽器的下載 API 存下 XML。也可以按「Copy」（複製），把 XML 放到剪貼簿。

匯出 XML 不需要登入。單一聊天的 XML 匯出不限次數、匿名進行，不會傳送任何資料到我們的伺服器。只有 PDF 和批次「Export All」（全部匯出）才會要求 Google 登入。運作機制請見運作方式。

如果看不到橘色按鈕，可能是你不在對話網址上、分頁需要重新整理，或擴充功能藏在 Chrome 的拼圖選單裡。釘選 Download Claude conversations，再重新整理 claude.ai。XML 匯出永遠不會出現在 Claude Desktop 或 Claude Code 終端機中。

一個檔案或很多個。橘色按鈕會把目前開啟的對話匯出成 XML。要產出很多 XML 檔，請開啟「View and Download All Conversations」（查看並下載所有對話），選好 XML 後執行「Export All」：產出一個 ZIP，免費方案每天 3 個聊天，詳見批次「Export All」。

什麼時候該匯出成 XML？

當接收端的系統、資料流程或舊有工具需要 XML 來交換結構化資料時，就把 Claude 聊天匯出成 XML。大多數開發者應該改選 JSON。Markdown 適合給人看的筆記，CSV 適合試算表，PNG 是一張圖片。選單裡之所以有 XML，是因為有些工具仍然只吃 XML、不接受 JSON。

不要把 XML 當成「比較正式」的 JSON。無論選哪一種，Download Claude conversations 的解析方式都相同。差別在於檔案的形式，而不是會神奇地多出額外欄位。如果你用的工具都不需要 XML，就跳過這個格式，改用 JSON。

我們提供 XML，是因為有些資料流程仍然需要它，而不是因為我們認為它在每種 claude.ai 匯出上都勝過 JSON。解析方式相同：訊息、傳送者、選用的思考過程和 Artifact。1.16.2 版將 XML 保留為七種格式之一，免費且不需要帳號，不是付費附加功能。

也有人搜尋 Claude Chat Downloader 或 Claude Conversation Downloader 找到同一個商店頁面。把 Claude 聊天匯出成 XML 用的就是那個橘色按鈕。法律頁面上可能仍寫著 Claude Exporter。這些名稱都是指這個產品。

XML 檔會保留哪些內容？

匯出成 XML 時，Download Claude conversations 會把對話結構（訊息、傳送者和可用的中繼資料）寫成 XML 標記。思考區塊、網頁搜尋來源、工具／MCP 步驟和 Artifact 的選項與 Markdown、JSON 相同：「Thinking」（思考過程）是匯出面板中的核取方塊，工具和來源在設定頁開啟。XML 並不是這些格式的精簡版。

1.16.2 版的 Artifact 版面有「Original」「Inline」「Nested」「Flat」（原始、內嵌、巢狀、扁平）。傳送者篩選可以讓 XML 只包含全部訊息、只有使用者，或只有助理的訊息。中繼資料（標題、時間戳記、模型）也可以一併匯出。完整的選項清單：Chrome 擴充功能特色。

如果對話很長，匯出成 XML 前請先往上捲動，讓 claude.ai 載入較早的訊息。擴充功能只能序列化頁面已經顯示的內容。只載入一半的 DOM 會產生被截斷的 XML。

匯出 Claude 聊天時，該選 XML 還是 JSON？

JSON 是開發者常見的選擇。只有下游系統需要 XML 時，才把 Claude 聊天匯出成 XML。Download Claude conversations 並不會讓 XML 比 JSON「更完整」。兩者都能包含思考過程和 Artifact，兩者也都不是 Anthropic 的帳號 ZIP。格式總覽：Claude 聊天匯出格式。

Anthropic 的 Settings → Privacy → Export data（若 claude.ai 設為中文，選單名稱可能會顯示為中文）產出的是 JSON（一個 ZIP），不是 XML。同一個面板產生的 PDF 是給人看的分頁文件，不是標記。兩者都無法取代用橘色按鈕把 Claude 聊天匯出成 XML。也不要期待這個 XML 符合 Anthropic 未公開的結構。

擴充功能只在 Chrome 的 claude.ai 上執行。Claude Desktop 和 Claude Code 終端機都沒有 XML 按鈕。Claude Code 網頁版（claude.ai/code）在 claude.ai 上執行，所以能像一般聊天一樣匯出。如果某個對話也在 claude.ai 上，請在那裡開啟再匯出成 XML。終端機版 Claude Code 的 /export 是另一條產品路徑。

可以一次把多個聊天匯出成 XML 嗎？

可以。開啟「View and Download All Conversations」，把「Chat format」（聊天格式）設為 XML，篩選表格，再按「Export All」。Chrome 會存下一個 ZIP，每個聊天一個 XML 檔。免費方案用 Google 登入後每天可匯出 3 個聊天，與 PDF 共用。Pro（每月 US$3.99 或每年 US$26.99）取消批次 XML 的這個上限。

Dashboard（控制台）會列出 claude.ai 的對話紀錄，可依名稱搜尋，提供 All conversations、New、Updated 和 Previously exported（所有對話、新的、已更新、先前已匯出）篩選條件、Chat 與 Cowork 分頁，以及專案搜尋。New 表示尚未用 Download Claude conversations 匯出過。Previously exported 會記錄你已存過的聊天。「Export All」產出的是一個 ZIP，每個聊天各一個 XML 檔，不是混合格式的封存檔。

每日限制以帳號計算。免費方案每天 3 個聊天，與 PDF 共用。如果只剩 3 次卻選了 40 個對話，整批會被擋下，而不是只匯出一部分。少選一些，或改用 Pro。從橘色按鈕匯出的單一 XML 仍然不限次數。

一次「Export All」無法同時混合 XML 和 JSON。這一輪請選 XML。如果同一個 claude.ai 對話兩種形式都需要，就再用 JSON 執行一次「Export All」；第二次執行時，每個聊天都會再計算一次。

匯出 XML 需要 Pro 嗎？

不需要。單一聊天的 XML 匯出免費、不限次數，不需要帳號，也沒有計數，和 Markdown、JSON、文字、CSV、PNG 一樣。只有 PDF 和批次「Export All」有免費限制：用 Google 登入後每天 3 次。Pro 透過 Paddle 付款，每月 US$3.99 或每年 US$26.99。Download Claude conversations 不會把 XML 當成付費限定格式。

限制只會出現在批次 XML。「Export All」ZIP 裡的每個聊天都會用掉每天 3 次中的 1 次，計數在 UTC 午夜重設。Pro 取消這個限制，在新電腦上用同一個 Google 帳號登入即可恢復。Paddle 是正式的交易商家；我們團隊永遠看不到卡號。

你不需要 Anthropic 的付費 claude.ai 方案，只需要一個能在 Chrome 中載入對話的登入帳號。2026 年 9 月的 1.16.2 版仍然不會寫出 Word 或 Notion 檔案。如果這份清單有變動，本頁會在同一天更新。

常見問題：Claude 聊天匯出 XML

這些常見問題說明如何在 Download Claude conversations 1.16.2 中把 Claude 聊天匯出成 XML：與 JSON 的比較、批次「Export All」、費用、Desktop、PDF 和 Pro。每個回答都是產品事實。頁首的 FAQPage JSON-LD 與這份清單一致。

匯出 Claude 聊天時，XML 比 JSON 好嗎？

一般來說不是。JSON 是開發者更常見的選擇。當下游系統需要 XML 來交換結構化資料時，才把 Claude 聊天匯出成 XML。從 claude.ai 解析的方式相同，只是檔案形式不同。

可以批次把 Claude 聊天匯出成 XML 嗎？

可以。Dashboard 上同樣的「Export All」流程支援 XML，會存成一個 ZIP，每個聊天一個 XML 檔。免費方案用 Google 登入後每天可匯出 3 個聊天；Pro（每月 US$3.99 或每年 US$26.99）不限次數。

XML 是付費限定格式嗎？

不是。單一聊天的 XML 匯出不限次數、不需要帳號，和 Markdown、文字、JSON、CSV、PNG 一樣。只有 PDF 和批次「Export All」有每天 3 次的免費限制。Pro 是每月 US$3.99 或每年 US$26.99。

匯出的 XML 和 Anthropic 的 ZIP 一樣嗎？

不一樣。Anthropic 的 Export data 是延遲寄出的帳號 JSON ZIP。Download Claude conversations 會在 Chrome 中立即寫出單一聊天（或所選訊息）的 XML 檔。兩者的結構不同。

匯出成 XML 會產生 PDF 嗎？

不會。XML 是標記。需要分頁文件時，請在同一個面板選 PDF；七種格式是 PDF、Markdown、JSON、純文字、XML、CSV 和 PNG。PDF 需要 Google 登入，在免費方案中計入每天 3 次。

可以在 Desktop 上把 Claude 聊天匯出成 XML 嗎？

不行。這個 Chrome 擴充功能只會注入 claude.ai。Claude Desktop 永遠不會出現 XML 選單。如果同一個對話也在 claude.ai 上，請在 Chrome 中開啟它。

只匯出一次 XML 也需要 Pro 嗎？

不需要。你完全不需要帳號。免費方案中，單一聊天的 XML 匯出不限次數。Pro（每月 US$3.99 或每年 US$26.99）只是取消批次「Export All」和 PDF 每天 3 次的限制。
