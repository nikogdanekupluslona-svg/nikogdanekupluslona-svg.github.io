How to export a Claude Desktop chat

If you searched export Claude Desktop chat, you are not on claude.ai in a browser tab. Claude Desktop is Anthropic’s standalone app. Download Claude conversations — the Claude Chat Downloader Chrome extension — only runs on claude.ai inside Chrome. It cannot inject an orange button into the Desktop window. This page maps what still works.

Claude Desktop vs claude.ai vs Claude Code

Product Where it lives This Chrome extension How to export
claude.ai Browser (claude.ai) Yes — orange button and Export All Download a chat
Claude Desktop Mac/Windows app No Open the same thread on claude.ai if it syncs; or copy-paste; or official account ZIP
Claude Code Terminal No /export or JSONL on disk

Search engines mash these together because every query contains “Claude” and “export.” The files you get are not interchangeable. A Desktop screenshot is not a Markdown export. A Code JSONL log is not a claude.ai thread.

Why the extension never appears in Claude Desktop

Chrome extensions run in Chrome (and some Chromium browsers) against pages that match their host permissions. This one is built for the claude.ai conversation page: it reads the message tree the site already rendered and writes a file on your machine. Claude Desktop is its own application. There is no extension toolbar, no content script, and no “Add to Chrome” inside that window. Installing the extension while Desktop is open does nothing to Desktop.

If you need the orange button, leave Desktop, open https://claude.ai in Chrome, and open the conversation there.

How to export a Claude Desktop conversation anyway

1. Open the same chat on claude.ai (best when the account syncs)

Many Desktop sessions are the same Claude account you use on the web. If the thread is in your web history:

  1. Open claude.ai in Chrome and find the conversation.
  2. Use Download Claude conversations for Markdown, JSON, text, XML, or PNG — one chat or bulk.
  3. If you specifically need a PDF of what you see, print to PDF from the browser, not from a format we do not offer.

If the chat exists only in Desktop and never shows on the web, skip to copy-paste or the official ZIP. We cannot pull a conversation that Chrome has never loaded.

2. Copy-paste from the Desktop window

Select the text in Desktop and paste it into a document. That is the honest fallback: no code-block fidelity, no artifacts layout, no bulk. Fine for a short answer. Painful for a long coding thread — the same reason the extension exists on claude.ai.

3. Anthropic Export data (account backup)

On the web: Settings → Privacy → Export data. Anthropic emails a link to a JSON ZIP of the account. That backup is not “export this Desktop window as Markdown,” but it is the official way to take the account with you. Details and comparison: how to export a Claude chat.

What we will not pretend

  • We do not ship a Claude Desktop plugin, menu bar app, or “export from Desktop” toggle.
  • We do not read files off your Mac/Windows Claude Desktop install.
  • We do not replace Claude Code /export. If your “desktop” meant a terminal in an IDE, that is Code, not the Desktop chat app.

The product on this site is a Chrome extension for claude.ai. If that is the surface you actually use, install it and export from the browser. If you only live in Desktop, use the three methods above until Anthropic ships a per-chat file export in the app itself.

FAQ

Can I export a Claude Desktop chat with this Chrome extension?

No. Download Claude conversations runs on claude.ai inside Chrome. The orange button never appears in the Desktop window.

How do I export a Claude Desktop conversation?

Open the same chat on claude.ai in Chrome if it syncs to your account, then use the extension or print. Otherwise copy-paste from Desktop, or use Anthropic’s Export data on the web for an account-wide JSON ZIP.

Is Claude Desktop the same as Claude Code?

No. Desktop is the chat app. Claude Code is the terminal agent with /export and JSONL transcripts.

Does official Export data include Desktop chats?

The account ZIP is tied to your Claude account. If a Desktop conversation is stored on that account, it can appear in the archive. It is still a backup ZIP, not a per-chat Markdown file from this extension.
