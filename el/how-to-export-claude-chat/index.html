Πώς να εξαγάγετε ένα chat του Claude με την επέκταση;

Για να εξαγάγετε ένα chat του Claude ως ευανάγνωστο αρχείο, χρησιμοποιήστε το πορτοκαλί κουμπί στο claude.ai. Εγκαταστήστε το Download Claude conversations, ανοίξτε τη συνομιλία, διαλέξτε PDF, Markdown, JSON, κείμενο, XML, CSV ή PNG και πατήστε «Export» (Εξαγωγή). Το αρχείο δημιουργείται στο πρόγραμμα περιήγησης και αποθηκεύεται τοπικά. Λογαριασμός χρειάζεται μόνο για PDF και μαζική εξαγωγή.

Η επέκταση είναι content script στη σελίδα που έχετε ήδη φορτώσει. Δεν ανοίγει δεύτερη συνεδρία στην Anthropic και δεν ανεβάζει τη συνομιλία για να δημιουργήσει το αρχείο. Γι’ αυτό το κουμπί εμφανίζεται μόνο σε διεύθυνση συνομιλίας, αφού η συνομιλία υπάρχει ήδη στο DOM.

  1. Εγκαταστήστε την επέκταση από το Chrome Web Store.
  2. Ανοίξτε τη συνομιλία στο claude.ai. Ανανεώστε την καρτέλα αν ήταν ανοιχτή κατά την εγκατάσταση.
  3. Κάντε κλικ στο στρογγυλό πορτοκαλί κουμπί λήψης δίπλα στο πλαίσιο μηνύματος.
  4. Ορίστε το «Messages» (Μηνύματα) σε All, Human ή Assistant (όλα, μόνο δικά σας, μόνο του Claude) και διαλέξτε PDF, Markdown, JSON, απλό κείμενο, XML, CSV ή PNG.
  5. Τσεκάρετε το «Thinking» (Σκέψη) για να συμπεριλάβετε την εκτεταμένη σκέψη. Χρησιμοποιήστε το «Select» (Επιλογή) για μεμονωμένα μηνύματα, αν χρειάζεστε μόνο μέρος της συνομιλίας. Πατήστε «Export» — ή «Copy» (Αντιγραφή) για να βάλετε Markdown, κείμενο, JSON, XML ή CSV στο πρόχειρο.

Για περισσότερες από μία συνομιλίες, ανοίξτε το «View and Download All Conversations» (Προβολή και λήψη όλων των συνομιλιών) στο αναδυόμενο παράθυρο. Κάντε αναζήτηση, φιλτράρετε με «New», «Updated» ή «Previously exported» (νέες, ενημερωμένες, ήδη εξαγμένες), αναζητήστε έργα, διαλέξτε «Chat format» και πατήστε Export All για ένα ZIP με ένα αρχείο ανά chat. Η μαζική εξαγωγή ζητά σύνδεση με Google· στο δωρεάν πρόγραμμα κάθε chat σε αυτό το ZIP χρησιμοποιεί μία από τις 3 ημερήσιες εξαγωγές, κοινές με το PDF. Αναλυτικά: μαζική εξαγωγή με Export All.

Τα chat των Team και Enterprise εξάγονται με τον ίδιο τρόπο, αρκεί να τα ανοίγετε στο Chrome. Η ανάλυση δεν ελέγχει τα ονόματα των προγραμμάτων της Anthropic. Αν ένας οργανισμός μπλοκάρει τις επεκτάσεις, πρόκειται για πολιτική IT, όχι για κάποια ρύθμιση Pro που λείπει από τη δική μας πλευρά.

Δικό μας όριο και χρήση της Anthropic. Η εξαγωγή με αυτή την επέκταση δεν καταναλώνει μηνύματα του Claude. Απλώς διαβάζει τη σελίδα. Το όριο των 3 την ημέρα για PDF και μαζική εξαγωγή είναι δικό μας· το Pro με 3,99 $ τον μήνα ή 26,99 $ τον χρόνο, με ξεχωριστή χρέωση μέσω Paddle, το καταργεί.

Βήματα για μία συνομιλία, για όσους αναζήτησαν «λήψη» αντί για «εξαγωγή»: πώς να κατεβάσετε ένα chat του Claude. Ίδιο προϊόν, ίδιο πορτοκαλί κουμπί, άλλη διατύπωση αναζήτησης.

Πώς γίνεται η εξαγωγή με το επίσημο ZIP;

Για εξαγωγή από το Claude σε επίπεδο λογαριασμού, χρησιμοποιήστε το Settings → Privacy → Export data. Η Anthropic στέλνει με email έναν σύνδεσμο που λήγει. Το ZIP περιέχει JSON για όλο τον λογαριασμό, όχι ένα ωραίο αρχείο για μία συνομιλία. Χρησιμοποιήστε το ως αντίγραφο ασφαλείας.

Το επίσημο ZIP είναι το σωστό εργαλείο όταν φεύγετε από έναν χώρο εργασίας, αρχειοθετείτε τα πάντα ή ικανοποιείτε ένα αίτημα «δώστε μου όλα τα δεδομένα μου». Είναι το λάθος εργαλείο όταν έχετε ανοιχτή μια αξιολόγηση σχεδίου και χρειάζεστε αρχείο μέσα στο επόμενο λεπτό.

Σε αυτή τη διαδικασία δεν υπάρχει φίλτρο για το αναγνωριστικό μιας συνομιλίας. Περιμένετε, κατεβάζετε το αρχείο, το αποσυμπιέζετε και βρίσκετε τη συνομιλία. Η δομή του JSON είναι σε επίπεδο λογαριασμού. Δεν είναι το JSON ανά chat που γράφει αυτή η επέκταση από την ανοιχτή σελίδα.

Αν χρειάζεστε και τα δύο, εκτελέστε μία φορά το Export data για αντίγραφο ασφαλείας και χρησιμοποιήστε το Download Claude conversations όποτε χρειάζεστε αρχείο εργασίας. Οι δύο δουλειές δεν αντικαθιστούν η μία την άλλη. Το ZIP δεν θα γίνει Markdown. Το πορτοκαλί κουμπί δεν θα σας στείλει με email κάθε ξεχασμένο chat του 2024.

Το επίσημο Export data δεν είναι ούτε εκτύπωση σε PDF. Η εκτύπωση αποτυπώνει την ιστοσελίδα. Το ZIP είναι δομημένα δεδομένα λογαριασμού. Σύγκριση εκτύπωσης και ενσωματωμένου PDF της επέκτασης: λήψη chat του Claude ως PDF.

Πώς εξάγω ένα chat του Claude σε Markdown ή JSON;

Για να εξαγάγετε ένα chat του Claude σε Markdown ή JSON, διαλέξτε τη μορφή στο αναπτυσσόμενο μενού πριν από το «Export». Το Markdown είναι για σημειώσεις και git. Το JSON είναι το δέντρο μηνυμάτων για scripts. Το απλό κείμενο αφαιρεί τη μορφοποίηση. Το CSV βάζει ένα μήνυμα ανά γραμμή. Το PNG είναι εικόνα· το PDF είναι το έγγραφο με σελίδες.

Το Markdown κρατά επικεφαλίδες, μπλοκ κώδικα με ένδειξη γλώσσας και πίνακες. Η διάταξη των artifacts μπορεί να είναι «Original», «Inline», «Nested» ή «Flat» (αρχική, ενσωματωμένη, ένθετη, επίπεδη). Τα μπλοκ σκέψης είναι προαιρετικά. Αυτό το αρχείο είναι αυτό που οι περισσότεροι εννοούν ως ευανάγνωστη εξαγωγή. Όλες οι μορφές: μορφές αρχείων.

Το JSON της επέκτασης είναι ανά συνομιλία (ή ανά μαζική επιλογή). Δεν είναι το ZIP λογαριασμού της Anthropic με άλλο όνομα. Αν γράφετε parser, χρησιμοποιήστε αυτό το JSON για μία συνομιλία και το επίσημο ZIP μόνο όταν πραγματικά χρειάζεστε κάθε συνομιλία που αποθήκευσε η Anthropic.

Μπορώ να εξαγάγω ένα chat του Claude χωρίς να πληρώσω;

Ναι. Μπορείτε να εξαγάγετε ένα chat του Claude δωρεάν σε Markdown, κείμενο, JSON, XML, CSV ή PNG, όσο συχνά θέλετε, χωρίς λογαριασμό. Το PDF και το μαζικό Export All είναι δωρεάν έως 3 την ημέρα με σύνδεση Google. Το Pro με 3,99 $ τον μήνα ή 26,99 $ τον χρόνο τα κάνει απεριόριστα.

Το μαζικό Export All και το PDF μοιράζονται αυτές τις 3 την ημέρα. Κάθε συνομιλία σε μαζικό ZIP μετρά ως μία. Αν επιλέξετε είκοσι σε δωρεάν λογαριασμό, μπλοκάρεται όλη η παρτίδα, δεν κόβεται: επιλέξτε λιγότερες, περιμένετε τον μηδενισμό στα μεσάνυχτα UTC ή αναβαθμίστε. Σχεδιάστε την επιλογή σας.

Η εκτύπωση και το Export data της Anthropic δεν χρησιμοποιούν το δικό μας όριο. Ούτε όμως σας δίνουν Markdown μίας συνομιλίας. Το «δωρεάν χωρίς επέκταση» έχει κι αυτό κόστος σε χρόνο και καθάρισμα.

Η σύνδεση με Google χρειάζεται μόνο για PDF και μαζική εξαγωγή. Η πρώτη εξαγωγή PDF ή το πρώτο Export All ζητά από τη Google να επαληθεύσει ένα email. Αν την ακυρώσετε, μοιάζει σαν να χάλασε η εξαγωγή. Ολοκληρώστε τη σύνδεση και πατήστε ξανά «Export». Για το δωρεάν πρόγραμμα δεν χρειάζεται πιστωτική κάρτα, και τα Markdown, κείμενο, JSON, XML, CSV και PNG δεν ζητούν ποτέ σύνδεση.

Η επαναφορά του Pro ακολουθεί αυτό το email της Google αν αλλάξετε υπολογιστή ή επανεγκαταστήσετε. Δεν ακολουθεί τον κωδικό της Anthropic. Συνδεθείτε με τον ίδιο λογαριασμό Google που χρησιμοποιήσατε όταν πληρώσατε.

Κρατάμε σκόπιμα το επίσημο ZIP και τη δική μας εξαγωγή ως δύο διαφορετικές δουλειές. Το JSON του λογαριασμού μέσω email είναι το αντίγραφο ασφαλείας της Anthropic. Το Markdown και το JSON ανά chat είναι αυτό που φτιάχνουμε στο πρόγραμμα περιήγησης από τη συνομιλία που έχετε ανοιχτή. Αν τα βάζαμε και τα δύο σε ένα κουμπί, θα χειροτέρευαν και τα δύο.

Εξαγωγή ή αντιγραφή-επικόλληση;

Η αντιγραφή-επικόλληση «εξάγει» ένα chat του Claude μόνο με την πιο αδύναμη έννοια: επιλέξατε κείμενο και το μετακινήσατε. Ο κώδικας χάνει τις εσοχές. Οι πίνακες διαλύονται. Μια μεγάλη συνομιλία δεν έχει όρια μεταξύ μηνυμάτων. Για δομημένο αρχείο, οι επιλογές παραμένουν η επέκταση, η εκτύπωση ή το επίσημο ZIP.

Μια ενδιάμεση λύση είναι να επιλέξετε τα πάντα και να τα επικολλήσετε σε Google Docs ή Word, διορθώνοντας τη μορφοποίηση με το χέρι. Αυτό κάνει για ένα μεμονωμένο παραδοτέο σε πελάτη, όχι για εβδομαδιαίο αρχείο. Κάθε νέο μήνυμα σημαίνει νέο καθάρισμα. Η επέκταση υπάρχει ώστε το καθάρισμα να μην ξεκινά από μια επικόλληση.

Η αντιγραφή-επικόλληση χάνει επίσης τη συμπτυγμένη σκέψη και τα artifacts που δεν ήταν ανοιγμένα. Η εκτύπωση έχει το ίδιο κενό: ό,τι είναι συμπτυγμένο στη διεπαφή λείπει από το PDF. Οι ρυθμίσεις της επέκτασης μπορούν να συμπεριλάβουν σκέψη και artifacts όταν υπάρχουν στα δεδομένα της φορτωμένης σελίδας — ένα διαφορετικό επίπεδο από το «ποια pixel φαίνονται».

Αν χρειάζεστε μόνο μία παράγραφο για το Slack, η αντιγραφή-επικόλληση είναι τίμια και πιο γρήγορη. Αν χρειάζεστε όλη την αξιολόγηση με τα μπλοκ κώδικα, εξαγάγετέ τη σε Markdown — δωρεάν, απεριόριστα, χωρίς λογαριασμό — ή χρησιμοποιήστε το κουμπί «Copy» του πάνελ για να βάλετε αυτό το Markdown στο πρόχειρο.

Πώς διαφέρει η εξαγωγή στο Claude Code και στο claude.ai;

Η εξαγωγή ενός chat στο claude.ai γίνεται με αυτή την επέκταση Chrome, και αυτό περιλαμβάνει τις συνεδρίες του Claude Code on the web στο claude.ai/code. Το Claude Desktop είναι τρίτο παράθυρο και δεν αποκτά το πορτοκαλί κουμπί.

Το /export του Claude Code γράφει μια μεταγραφή σε απλό κείμενο (στο πρόχειρο ή σε αρχείο). Η Anthropic αναφέρει ότι τα JSONL στον δίσκο είναι εσωτερική μορφή που μπορεί να αλλάξει. Προτιμήστε το /export ή τις διεπαφές scripting της για ό,τι θέλετε να κρατήσετε. Βήματα: εξαγωγή από το Claude Code.

Claude Desktop: ανοίξτε το ίδιο chat στο claude.ai αν έχει συγχρονιστεί και κάντε εκεί την εξαγωγή. Διαφορετικά, αντιγράψτε από το Desktop ή βασιστείτε στο Settings → Privacy → Export data για JSON σε επίπεδο λογαριασμού. Οδηγός: εξαγωγή chat από το Claude Desktop.

Η καταχώριση λειτουργεί μόνο στο claude.ai: το Claude Code on the web καλύπτεται, το τερματικό όχι. Αυτό το όριο είναι το ίδιο το προϊόν, όχι ένα πλαίσιο ελέγχου που λείπει.

Η εκτύπωση κρατά pixel. Τις περισσότερες φορές χάνει την καθαρή διάταξη του κώδικα. Το επίσημο ZIP κρατά ό,τι έβαλε η Anthropic στο αρχείο του λογαριασμού. Χάνει ένα ευανάγνωστο έγγραφο ανά chat. Η αντιγραφή-επικόλληση κρατά τους επιλεγμένους χαρακτήρες και χάνει τη δομή.

Φίλτρο αποστολέα: όλα τα μηνύματα, μόνο τα δικά σας ή μόνο του Claude. Χρήσιμο όταν θέλετε τα prompts χωρίς απαντήσεις ή το αντίστροφο. Η ρύθμιση μεταδεδομένων προσθέτει τίτλους, χρονοσημάνσεις και μοντέλο όταν χρειάζεστε μια γραμμή αναφοράς στο αρχείο.

Το claude.ai είχε ήδη τη συνομιλία. Αυτή είναι η πλήρης λίστα των μερών. Δεν είμαστε η Anthropic. Το Claude είναι εμπορικό σήμα της Anthropic, PBC.

Αν η εξαγωγή φαίνεται μικρή, φορτώστε περισσότερο από τη συνομιλία και εξαγάγετε ξανά. Σε Markdown, κείμενο, JSON, XML, CSV ή PNG η δεύτερη προσπάθεια είναι δωρεάν· ένα δεύτερο PDF χρησιμοποιεί άλλη μία από τις 3 της ημέρας. Βεβαιωθείτε ότι η απάντηση ολοκληρώθηκε και ότι τα παλαιότερα μηνύματα εμφανίζονται στην οθόνη πριν πατήσετε.
