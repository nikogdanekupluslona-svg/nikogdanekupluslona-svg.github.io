Η Download Claude conversations είναι ένα content script του Chrome. Διαβάζει τη συνομιλία που έχει ήδη φορτωθεί στη συνδεδεμένη σας συνεδρία στο claude.ai. Δεν καλεί κάποιο ξεχωριστό API της Anthropic με δικά της διαπιστευτήρια και δεν ανεβάζει το νήμα στους διακομιστές μας για να δημιουργήσει οποιαδήποτε μορφή, ούτε καν το PDF.

  1. Εγκαταστήστε την Download Claude conversations από το Chrome Web Store (λειτουργούν και οι browsers Chromium που φορτώνουν επεκτάσεις Chrome).
  2. Ανανεώστε το claude.ai αν η σελίδα ήταν ήδη ανοιχτή κατά την εγκατάσταση. Το Chrome δεν εισάγει τίποτα σε παλιά καρτέλα.
  3. Ανοίξτε τη διεύθυνση της συνομιλίας που θέλετε — το πορτοκαλί κουμπί εμφανίζεται μόνο σε πραγματικό νήμα, όχι στην κενή αρχική σελίδα σύνταξης.
  4. Κάντε κλικ στο στρογγυλό πορτοκαλί κουμπί λήψης δεξιά από το πλαίσιο μηνύματος. Ανοίγει ένα πάνελ με Messages (All / Human / Assistant — όλα, χρήστης, βοηθός), Format (μορφή), «Thinking» (σκέψη), «Select» (Επιλογή), «Copy» (Αντιγραφή) και «Export».

Για Markdown, Plain Text, JSON, XML, CSV ή PNG δεν χρειάζεται λογαριασμός. Αυτές οι εξαγωγές μεμονωμένων συνομιλιών είναι απεριόριστες και δωρεάν: χωρίς σύνδεση, χωρίς μετρητή. Η σύνδεση με Google εμφανίζεται μόνο όταν επιλέγετε PDF ή τρέχετε μαζικό «Export All» (Εξαγωγή όλων). Δεν είναι σύνδεση για ανάγνωση των συνομιλιών σας στο claude.ai. Το περιεχόμενο των συνομιλιών μένει στον υπολογιστή σας.

Το PDF και το μαζικό ZIP μοιράζονται ένα δωρεάν όριο 3 την ημέρα, που μηδενίζεται τα μεσάνυχτα UTC. Κάθε συνομιλία μέσα σε ένα μαζικό ZIP μετρά ως μία. Το Pro κοστίζει 3,99 $ τον μήνα ή 26,99 $ τον χρόνο και καταργεί αυτό το όριο. Τις πληρωμές Pro τις διεκπεραιώνει η Paddle. Βήματα για PDF: λήψη συνομιλίας Claude σε PDF.

Τοπικά αρχεία. Κάθε μορφή, ακόμη και το PDF, δημιουργείται στο πρόγραμμα περιήγησης και παραδίδεται στο API λήψεων του Chrome. Το κείμενο των συνομιλιών δεν ανεβαίνει ποτέ. Μόνο οι εξαγωγές PDF και οι μαζικές εξαγωγές στέλνουν έλεγχο ορίου με το email σας στο Google. Η έκδοση σε αυτή τη σελίδα είναι η 1.16.2, Σεπτέμβριος 2026.

Το ίδιο πάνελ φιλτράρει ανά αποστολέα — All, Human ή Assistant. Το πλαίσιο ελέγχου «Thinking» συμπεριλαμβάνει ή παραλείπει το extended thinking. Το «Select» σάς επιτρέπει να τσεκάρετε μεμονωμένα μηνύματα, ώστε το αρχείο να περιέχει μόνο αυτά. Το «Copy» βάζει Markdown, κείμενο, JSON, XML ή CSV στο πρόχειρο αντί να κατεβάσει αρχείο. Τα βήματα εργαλείων / MCP και οι πηγές αναζήτησης στο web ενεργοποιούνται προαιρετικά από τις ρυθμίσεις (Settings). Τα μεταδεδομένα και η διάταξη των artifacts — «Original» (αρχική), «Inline» (ενσωματωμένη), «Nested» (εμφωλευμένη) ή «Flat» (επίπεδη) — ορίζονται στον πίνακα ελέγχου (Dashboard).

Λήψη μίας συνομιλίας ή επίσημο Export data;

Η λήψη συνομιλίας με το πορτοκαλί κουμπί δίνει ένα αρχείο με όνομα για το ανοιχτό νήμα του claude.ai, αμέσως, τοπικά, και σε PDF. Το Settings → Privacy → Export data της Anthropic (οι ετικέτες μπορεί να εμφανίζονται στα ελληνικά, αν το claude.ai είναι ρυθμισμένο στα ελληνικά) είναι ένα ZIP με JSON σε επίπεδο λογαριασμού, που στέλνεται αργότερα με email. Η εκτύπωση δίνει οπτικό PDF της ιστοσελίδας. Η αντιγραφή-επικόλληση δίνει αδόμητο κείμενο. Διαλέξτε τη γραμμή που ταιριάζει στη δουλειά.

Το επίσημο Export data είναι αντίγραφο ασφαλείας ολόκληρου του λογαριασμού στην Anthropic, όχι λήψη ανά συνομιλία. Η Anthropic στέλνει με email έναν σύνδεσμο που λήγει. Το ZIP ανακατεύει συνομιλίες που είχατε ξεχάσει με όσες θέλατε να κρατήσετε. Μετά αποσυμπιέζετε μόνοι σας το JSON αν χρειάζεστε ένα νήμα ανάμεσα σε χιλιάδες. Αυτή δεν είναι η διαδρομή του πορτοκαλί κουμπιού.

Μέσω εκτύπωσης: ανοίξτε τη συνομιλία στο claude.ai, κρύψτε την πλαϊνή στήλη αν το επιτρέπει η διεπαφή, πατήστε Ctrl+P (Windows/Linux) ή Cmd+P (Mac), ορίστε ως προορισμό «Αποθήκευση ως PDF» και αποθηκεύστε. Τα μπλοκ κώδικα συχνά σπάνε ανάμεσα σε σελίδες. Στοιχεία της διεπαφής σύνταξης μπορεί να εμφανίζονται σε κάθε φύλλο. Η εκτύπωση είναι στιγμιότυπο της οθόνης, όχι Markdown. Η εξαγωγή PDF της επέκτασης παρακάμπτει αυτό το παράθυρο: συνομιλία Claude σε PDF.

Η αντιγραφή-επικόλληση είναι ένας τρίτος τρόπος χωρίς επέκταση. Επιλέγετε κείμενο στο claude.ai και το επικολλάτε σε Docs ή σε εφαρμογή σημειώσεων. Οι εσοχές στον κώδικα συνήθως χάνονται. Οι πίνακες γίνονται συνεχόμενες γραμμές. Μια συνομιλία με πολλούς γύρους γίνεται ένας αδόμητος τοίχος κειμένου. Αρκεί για μία σύντομη απάντηση. Είναι φτωχή λύση για έναν έλεγχο κώδικα που θα ψάξετε αργότερα.

Η πρώτη γραμμή είναι ακριβώς αυτό που καλύπτει αυτή η σελίδα. Το επίσημο Export data έχει ακόμη τη θέση του: αποχώρηση από εταιρεία, νομική διατήρηση δεδομένων ή ένα επιπλέον αντίγραφο ασφαλείας για σιγουριά. Και η εκτύπωση έχει τη θέση της: ένα μεμονωμένο συνημμένο που πρέπει να μοιάζει με το προϊόν. Κανένα από τα δύο δεν αντικαθιστά ένα αρχείο Markdown που θα επεξεργαστείτε την επόμενη εβδομάδα.

Το ZIP δεν είναι μία συνομιλία. Το αρχείο Export data της Anthropic είναι σε επίπεδο λογαριασμού. Η Download Claude conversations δεν ισχυρίζεται ποτέ ότι είναι αυτό το ZIP. Αν θέλετε ένα αρχείο του νήματος που βλέπετε στην οθόνη, χρησιμοποιήστε το πορτοκαλί κουμπί, όχι το Settings → Privacy.

Σε ποια μορφή να κατεβάσετε τη συνομιλία;

Για να διαλέξετε μορφή: ανοίξτε το πορτοκαλί κουμπί, επιλέξτε PDF, Markdown, JSON, κείμενο, XML, CSV ή PNG και πατήστε «Export». Το Markdown είναι το αρχείο σημειώσεων. Το JSON είναι το δέντρο μηνυμάτων για scripts. Το απλό κείμενο δεν έχει σήμανση. Το XML είναι για ανταλλαγή δεδομένων. Το CSV έχει μία γραμμή ανά μήνυμα. Το PDF είναι έγγραφο με σελίδες. Το PNG είναι εικόνα.

Το Markdown διατηρεί επικεφαλίδες, μπλοκ κώδικα με ετικέτες γλώσσας και πίνακες. Είναι η συνηθισμένη επιλογή για Obsidian, GitHub ή wiki. Το JSON διατηρεί το δέντρο που έχει ήδη φτιάξει ο αναλυτής, μαζί με artifacts και thinking όταν είναι ενεργοποιημένα. Δεν έχει την ίδια δομή με το ZIP λογαριασμού της Anthropic. Σημειώσεις για τις μορφές: όλες οι μορφές.

Το απλό κείμενο είναι η σωστή επιλογή όταν ο προορισμός αφαιρεί έτσι κι αλλιώς τη σήμανση — επικόλληση σε πεδίο ticket, σώμα email, ευρετήριο αναζήτησης που θέλει σκέτο κείμενο. Το XML είναι η εξειδικευμένη επιλογή για ανταλλαγή δεδομένων. Το CSV ανοίγει σε Excel, Google Sheets ή Numbers. Το PNG είναι για διαφάνεια ή για στιγμιότυπο του νήματος σε αναφορά σφάλματος, όχι για έναν έλεγχο σχεδίασης 40 γύρων που θα ψάξετε με grep.

Η τελευταία μορφή που χρησιμοποιήσατε απομνημονεύεται. Αν θέλατε Markdown και πήρατε JSON, η λίστα ήταν ακόμη στο JSON από την προηγούμενη εξαγωγή. Ελέγχετε τη λίστα κάθε φορά που αλλάζετε εργασία. Markdown, κείμενο, JSON, XML, CSV και PNG δεν έχουν κανένα όριο. Μόνο το PDF μετρά στο όριο των 3 την ημέρα του δωρεάν προγράμματος.

Το PNG δεν είναι PDF. Ένα PNG από την Download Claude conversations είναι μία εικόνα της συνομιλίας. Το PDF της επέκτασης είναι έγγραφο με σελίδες, με αρίθμηση σελίδων και πίνακα περιεχομένων αν τα θέλετε. Ένα PDF από το παράθυρο εκτύπωσης του Chrome είναι στιγμιότυπο της οθόνης του claude.ai. Κανένα τους δεν είναι αρχείο Markdown. Διαλέξτε τη μορφή που ταιριάζει στην επόμενη εφαρμογή, όχι στη λέξη «λήψη».

Τα τοπικά sessions τερματικού όχι: χρησιμοποιήστε /export ή αντιγράψτε το JSONL από το ~/.claude/projects (Windows: %USERPROFILE%\.claude\projects). Αυτή η επέκταση Chrome τρέχει μόνο στο claude.ai. Οδηγός: εξαγωγή Claude Code.

Σε ποιες μορφές γίνεται η λήψη συνομιλίας Claude;

Σε επτά: PDF, Markdown, JSON, απλό κείμενο, XML, CSV και PNG, στην έκδοση 1.16.2 της επέκτασης. Το PDF δημιουργείται στο πρόγραμμα περιήγησης χωρίς παράθυρο εκτύπωσης. Το CSV έχει μία γραμμή ανά μήνυμα. Το PNG είναι μια εικόνα του νήματος. Όλες οι μορφές: μορφές.
