Αρχική / Εξαγωγή από το Claude Code

Ενημέρωση: Σεπτέμβριος 2026 · Επέκταση 1.16.2

Εξαγωγή συνεδρίας Claude Code ή claude.ai: διαλέξτε τη σωστή διαδρομή

Η εξαγωγή συνεδρίας Claude Code — στα αγγλικά «claude code export» — είναι δουλειά του τερματικού. Πληκτρολογήστε /export μέσα στη συνεδρία ή αντιγράψτε τα JSONL από το ~/.claude/projects. Η λήψη μιας συνομιλίας του Claude Code από το τερματικό δεν γίνεται με το πορτοκαλί κουμπί αυτού του ιστότοπου. Το Download Claude conversations αποθηκεύει chat που ανοίγετε στο claude.ai στο Chrome — μαζί με τις συνεδρίες του Claude Code on the web στο claude.ai/code. Οι τοπικές συνεδρίες τερματικού και το Desktop είναι ξεχωριστή υπόθεση.

Τι είναι η εξαγωγή συνεδρίας Claude Code στο τερματικό;

Η εξαγωγή συνεδρίας Claude Code είναι η εντολή /export μέσα σε μια διαδραστική συνεδρία CLI. Η τεκμηρίωση της Anthropic περιγράφει ένα μενού για αντιγραφή της τρέχουσας συνομιλίας ή αποθήκευση αρχείου απλού κειμένου, με τα μηνύματα και τα αποτελέσματα εργαλείων αποδοσμένα ως ευανάγνωστο κείμενο. Αν δώσετε όνομα αρχείου, το μενού παραλείπεται και γράφεται απευθείας αυτό το αρχείο.

Αυτό δεν είναι Markdown από το claude.ai, ούτε JSON από αυτή την επέκταση Chrome, ούτε PDF. Είναι μια μεταγραφή για να τη διαβάσει άνθρωπος. Η Anthropic αναφέρει ότι το αρχείο καταγραφής JSONL στον δίσκο είναι διαφορετική, εσωτερική μορφή για το ίδιο το προϊόν, όχι δημόσιο API για εσάς.

/export

Για να παραλείψετε την ερώτηση και να γράψετε αρχείο με όνομα στον τρέχοντα κατάλογο εργασίας:

/export my-session

Η τεκμηρίωση συνεδριών της Anthropic είναι η έγκυρη πηγή για επιλογές και ονόματα αρχείων· αλλάζουν από έκδοση σε έκδοση του Claude Code. Τα blogs της κοινότητας είναι δευτερεύουσες πηγές. Αν το κείμενο του παραθύρου του /export δεν ταιριάζει με αυτό που βλέπετε, το CLI σας είναι άλλη έκδοση — χρησιμοποιήστε τη βοήθεια μέσα στο προϊόν, όχι ένα στιγμιότυπο του 2025.

Για scripts, η Anthropic προτείνει άλλες διεπαφές: claude -p με --output-format json ή stream-json, συνέχιση με αναγνωριστικό συνεδρίας, hooks που λαμβάνουν transcript_path ή το Agent SDK. Αυτά είναι εργαλεία προγραμματιστών του Claude Code. Δεν είναι η επέκταση Chrome αυτού του ιστότοπου.

Ευανάγνωστο ή δομημένο. Το /export είναι η μεταγραφή για ανθρώπους. Τα JSONL στον φάκελο projects είναι το αρχείο καταγραφής. Το JSON της επέκτασης Chrome είναι τρίτη μορφή, που δημιουργείται μόνο από σελίδα του claude.ai. Μη γράψετε έναν parser και για τα τρία.

Πώς κατεβάζω μια συνομιλία του Claude Code από τον δίσκο;

Για να πάρετε μια συνομιλία του Claude Code από τον δίσκο, αντιγράψτε το αρχείο JSONL της συνεδρίας από τον κατάλογο projects ή εκτελέστε το /export για ευανάγνωστη μεταγραφή. Η προεπιλεγμένη διαδρομή σε macOS και Linux είναι κάτω από το ~/.claude/projects/. Στα Windows είναι το %USERPROFILE%\.claude\projects. Τα ονόματα αρχείων είναι αναγνωριστικά συνεδριών.

Το όνομα του φακέλου έργου είναι ο κατάλογος εργασίας, με τους μη αλφαριθμητικούς χαρακτήρες να αντικαθίστανται από παύλες. Η Anthropic περικόπτει πολύ μεγάλα ονόματα και προσθέτει ένα hash, ώστε ο κατάλογος να μένει εντός των ορίων του συστήματος αρχείων. Αν δεν βρίσκετε τον φάκελο, ξεκινήσατε το Claude Code από άλλον κατάλογο εργασίας απ’ ό,τι νομίζετε.

Κάθε γραμμή JSONL είναι ένα αντικείμενο JSON για μήνυμα, χρήση εργαλείου ή μεταδεδομένα. Η Anthropic δηλώνει ότι αυτή η μορφή εγγραφών είναι εσωτερική και αλλάζει μεταξύ εκδόσεων. Scripts που αναλύουν αυτά τα αρχεία μπορεί να χαλάσουν σε μια νέα έκδοση του Claude Code. Προτιμήστε το /export ή τις τεκμηριωμένες διεπαφές scripting όταν χρειάζεστε κάτι σταθερό.

Η τοποθεσία αποθήκευσης μπορεί να αλλάξει. Το CLAUDE_CONFIG_DIR μεταφέρει τις ρυθμίσεις εκτός του ~/.claude. Το CLAUDE_CODE_PROJECT_DIR_NAME ορίζει το όνομα του καταλόγου έργου όταν χρησιμοποιείται μαζί με αυτόν τον κατάλογο ρυθμίσεων (Claude Code v2.1.234 ή νεότερο, σύμφωνα με την Anthropic). Το cleanupPeriodDays στο settings.json αλλάζει την προεπιλεγμένη διάρκεια διατήρησης. Καμία από αυτές τις ρυθμίσεις δεν είναι λειτουργία του Download Claude conversations.

Για αντίγραφο ασφαλείας των συνομιλιών του Claude Code, λοιπόν: αντιγράψτε τον φάκελο ή εξάγετε μεταγραφές με το /export σε τακτά διαστήματα. Αυτός ο ιστότοπος δεν θα προσθέσει κουμπί «εισαγωγή JSONL». Δεν διαβάζουμε τον προσωπικό σας κατάλογο.

Λειτουργεί η εξαγωγή του Claude Code με αυτή την επέκταση;

Όχι για συνεδρίες τερματικού. Το Download Claude conversations δεν διαβάζει τοπικές συνεδρίες του Claude Code. Η επέκταση Chrome ενεργοποιείται στο claude.ai. Δεν βλέπει το τερματικό, δεν μπορεί να εκτελέσει το /export και δεν ανοίγει JSONL. Εξαίρεση είναι το Claude Code on the web στο claude.ai/code: είναι σελίδα του claude.ai, οπότε εξάγεται όπως κάθε chat. Αν ψάξατε πώς να κατεβάσετε μια συνομιλία του Claude Code από το CLI, ακολουθήστε τα βήματα CLI αυτής της σελίδας.

Πολλοί καταλήγουν εδώ επειδή η Google ομαδοποιεί τις λέξεις «Claude» και «export». Η καταχώριση στο Web Store εξακολουθεί να αφορά μόνο το claude.ai. Η εγκατάσταση της επέκτασης δεν θα βάλει πορτοκαλί κουμπί στο iTerm, στο Ghostty, στο τερματικό του VS Code ή στο desktop περιβάλλον του Claude Code.

Αν κρατάτε και παράλληλη συνομιλία στο claude.ai για την ίδια δουλειά κώδικα, αυτό το chat του προγράμματος περιήγησης μπορεί να αποθηκευτεί με την επέκταση. Τα δύο αρχεία δεν συγχωνεύονται. Κλήσεις εργαλείων που έγιναν μόνο στο CLI δεν θα εμφανιστούν στην εξαγωγή από τον ιστό, εκτός αν τις επικολλήσατε εκεί.

Κάθε εβδομάδα λαμβάνουμε το ίδιο μήνυμα υποστήριξης: κάποιος εγκατέστησε την επέκταση Chrome και περίμενε να εμφανιστεί το /export. Εμείς αναλύουμε μόνο το claude.ai. Το Claude Code έχει ήδη το /export και τα JSONL. Ένα περιτύλιγμα για το CLI θα ήταν άλλο προϊόν, και δεν το έχουμε κυκλοφορήσει.

Η επέκταση είναι εργαλείο για το claude.ai, όχι πρόσθετο του Claude Code. Τα όριά της ισχύουν μόνο όταν εξάγετε από το claude.ai: Markdown, κείμενο, JSON, XML, CSV και PNG είναι απεριόριστα χωρίς λογαριασμό· PDF και μαζικό ZIP είναι 3 την ημέρα δωρεάν με σύνδεση Google· το Pro με 3,99 $/μήνα ή 26,99 $/χρόνο καταργεί το όριο. Τίποτα από αυτά δεν μετρά το /export.

Μπορώ να εξαγάγω συνεδρίες του Claude Code on the web;

Ναι. Το Claude Code on the web τρέχει στο claude.ai/code, οπότε το Download Claude conversations εξάγει αυτές τις συνεδρίες όπως κάθε chat του claude.ai. Ανοίξτε τη συνεδρία στο Chrome, κάντε κλικ στο πορτοκαλί κουμπί, διαλέξτε μορφή και πατήστε «Export» (Εξαγωγή). Αυτή είναι η μόνη επιφάνεια του Claude Code που καλύπτει η επέκταση.

Οι μορφές είναι οι ίδιες επτά όπως για κάθε chat: PDF, Markdown, απλό κείμενο, JSON, XML, CSV και PNG. Markdown, κείμενο, JSON, XML, CSV και PNG είναι απεριόριστα και δεν χρειάζονται λογαριασμό. Το PDF ζητά σύνδεση με Google και μοιράζεται τις 3 ημερήσιες εξαγωγές του δωρεάν προγράμματος με το μαζικό ZIP, εκτός αν έχετε Pro. Τα μπλοκ κώδικα κρατούν την ένδειξη γλώσσας. Η εκτεταμένη σκέψη είναι το πλαίσιο ελέγχου «Thinking» (Σκέψη) στο πάνελ· τα βήματα εργαλείων / MCP και οι πηγές αναζήτησης ιστού ενεργοποιούνται προαιρετικά στις ρυθμίσεις.

Η εξαγωγή από τον ιστό είναι ό,τι εμφανίζει το claude.ai/code στο πρόγραμμα περιήγησης. Δεν είναι το αρχείο καταγραφής JSONL μιας τοπικής εκτέλεσης CLI και δεν φτάνει σε συνεδρίες που έτρεξαν μόνο στο τερματικό σας. Σύμφωνα με την Anthropic, το Claude Code on the web κρατά δικό του ιστορικό συνεδριών, χωριστά από τον κατάλογο ~/.claude/projects του CLI. Για μια συνεδρία τερματικού, η διαδρομή παραμένει το /export.

Πού αποθηκεύει το Claude Code το ιστορικό συνομιλιών;

Το Claude Code αποθηκεύει το ιστορικό συνομιλιών ως μεταγραφές JSONL στον φάκελο projects του καταλόγου ρυθμίσεων. Προεπιλογή σε macOS και Linux: ~/.claude/projects/<encoded-cwd>/<session-id>.jsonl. Τα Windows χρησιμοποιούν το %USERPROFILE%\.claude\projects. Η Anthropic μπορεί να αλλάξει αυτή τη δομή· δείτε την τρέχουσα τεκμηρίωση συνεδριών αν λείπει μια διαδρομή από τον δίσκο.

Η συνέχιση είναι άλλο πράγμα από την εξαγωγή. Τα claude --continue και claude --resume φορτώνουν ξανά μια συνεδρία για να συνεχίσετε τη δουλειά. Το /export γράφει ένα αντίγραφο που μπορείτε να κρατήσετε στο git ή να στείλετε με email. Το ένα επαναφέρει το πλαίσιο. Το άλλο σας δίνει ένα αρχείο να πάρετε μαζί σας. Η σελίδα συνεδριών της Anthropic καλύπτει τη λειτουργία δικαιωμάτων κατά τη συνέχιση, το compact/summary και τη συμπεριφορά του επιλογέα — τίποτα από αυτά δεν αφορά αυτή την επέκταση.

Η εφαρμογή desktop, το Claude Code on the web και η επέκταση για VS Code διατηρούν το καθένα δικό του ιστορικό συνεδριών, σύμφωνα με την Anthropic. Οι διαδρομές αυτού του οδηγού αφορούν το CLI. Οι συνεδρίες ιστού μένουν στο claude.ai/code, όπου η επέκταση μπορεί να τις εξαγάγει. Μην υποθέσετε ότι μια μεταγραφή Cowork από το Desktop βρίσκεται στον ίδιο κατάλογο JSONL που χρησιμοποιείτε από το τερματικό.

Μη θεωρείτε το JSONL δημόσιο σχήμα. Η Anthropic λέει ότι η μορφή των γραμμών αλλάζει. Αν το αναλύετε έτσι κι αλλιώς, κλειδώστε μια έκδοση του Claude Code και να περιμένετε ότι κάτι θα χαλάσει. Το /export είναι ο σταθερός τρόπος να πάρετε μια ευανάγνωστη συνομιλία του Claude Code.

Μεταβλητές περιβάλλοντος όπως το CLAUDE_CODE_SKIP_PROMPT_HISTORY μπορούν να εμποδίσουν την εγγραφή μεταγραφών. Αν ο φάκελος projects είναι άδειος, ελέγξτε αν απενεργοποιήσατε την αποθήκευση, αν το CLAUDE_CONFIG_DIR δείχνει αλλού ή αν δεν εκτελέσατε ποτέ διαδραστική συνεδρία σε εκείνον τον κατάλογο.

Πώς κατεβάζω αντί γι’ αυτό ένα chat από το claude.ai;

Για να κατεβάσετε ένα chat του Claude από το claude.ai: εγκαταστήστε το Download Claude conversations, ανοίξτε τη συνομιλία στο Chrome, κάντε κλικ στο πορτοκαλί κουμπί και διαλέξτε PDF, Markdown, απλό κείμενο, JSON, XML, CSV ή PNG. Αυτό είναι το προϊόν για το πρόγραμμα περιήγησης και καλύπτει και τις συνεδρίες του claude.ai/code. Δεν είναι εξαγωγή του Claude Code από το τερματικό. Βήμα-βήμα: πώς να κατεβάσετε ένα chat του Claude.

Ολόκληρο το ιστορικό του claude.ai σε ξεχωριστά αρχεία γίνεται με το Export All στο Dashboard, όχι με το /export. Στο δωρεάν πρόγραμμα κάθε chat στο ZIP μετρά στις 3 την ημέρα (κοινές με το PDF, με μηδενισμό στα μεσάνυχτα UTC)· το Pro καταργεί το όριο. Οδηγός: μαζική εξαγωγή με Export All. Μορφές: μορφές αρχείων.

Για μεμονωμένα chat σε Markdown, κείμενο, JSON, XML, CSV ή PNG δεν χρειάζεται λογαριασμός — αυτές οι εξαγωγές είναι απεριόριστες. Η σύνδεση με Google εμφανίζεται μόνο για PDF, μαζικό ZIP και Pro, ώστε να μετράμε το ημερήσιο όριο και να επαναφέρουμε το Pro. Τα αρχεία δημιουργούνται τοπικά, μαζί με το PDF. Η Paddle χρεώνει το Pro 3,99 $/μήνα ή 26,99 $/χρόνο. Τίποτα από αυτά δεν ισχύει για το /export στο τερματικό.

Αν η δουλειά σας ξεκίνησε στο Claude Code και επικολλήσατε μια περίληψη στο claude.ai, κατεβάστε τη συνομιλία του ιστού για σημειώσεις και κρατήστε το /export για το πραγματικό αρχείο του CLI. Δύο αρχεία είναι καλύτερα από ένα μπερδεμένο.

Εξαγωγή από το Claude Code ή το επίσημο Export data;

Η εξαγωγή από το Claude Code (/export ή JSONL) αφορά μία συνεδρία τερματικού. Το επίσημο Export data είναι το Settings → Privacy → Export data στο claude.ai (οι ετικέτες μπορεί να εμφανίζονται στα ελληνικά αν το claude.ai είναι ρυθμισμένο στα ελληνικά): ένα ZIP με JSON του λογαριασμού στην Anthropic που φτάνει με καθυστέρηση. Δεν είναι το ίδιο αρχείο. Το ZIP δεν αντικαθιστά το /export.

Αν μια συγκεκριμένη συνεδρία του Claude Code εμφανίζεται στο ZIP του λογαριασμού εξαρτάται από το πώς αποθηκεύει η Anthropic αυτό το προϊόν, όχι από αυτή την επέκταση. Θεωρήστε το ZIP αντίγραφο ασφαλείας του λογαριασμού ιστού, εκτός αν η τρέχουσα τεκμηρίωση απορρήτου της Anthropic λέει κάτι άλλο. Εμείς δεν προσθέτουμε συνεδρίες CLI σε αυτό το ZIP.

Η εξαγωγή PDF της επέκτασης δεν εφαρμόζεται ούτε σε διεπαφή τερματικού. Δείτε τη λήψη chat του Claude ως PDF μόνο όταν η συνομιλία βρίσκεται στο claude.ai, μαζί με το claude.ai/code.

Claude Code, Desktop ή claude.ai: ποια εξαγωγή;

Claude Code, Claude Desktop και claude.ai είναι τρεις διαφορετικές επιφάνειες. Η εξαγωγή από το Claude Code χρησιμοποιεί το /export και τα JSONL. Το Desktop είναι εφαρμογή χωρίς το πορτοκαλί κουμπί αυτής της επέκτασης. Το claude.ai στο Chrome είναι το μόνο μέρος όπου τρέχει το Download Claude conversations — μαζί με το Claude Code on the web στο claude.ai/code. Όταν μπερδεύονται τα ονόματα, οι εξαγωγές αποτυγχάνουν σιωπηλά.

Claude Desktop: αν το chat συγχρονίστηκε στον ίδιο λογαριασμό Anthropic, ανοίξτε το στο claude.ai και κάντε εκεί την εξαγωγή. Αν υπάρχει μόνο στο παράθυρο του Desktop, αντιγράψτε το ή περιμένετε το επίσημο Export data. Οδηγός: εξαγωγή chat από το Claude Desktop.

Το πάνελ του Claude Code στο VS Code μοιάζει περισσότερο με το CLI παρά με το claude.ai. Μην περιμένετε το content script μας να ενεργοποιηθεί σε εκείνο το webview. Χρησιμοποιήστε το /export από τη συνεδρία που πραγματικά περιέχει τα μηνύματα.

Ανεξάρτητη επέκταση Chrome, χωρίς σχέση με την Anthropic, PBC. Το Claude είναι εμπορικό σήμα της Anthropic. Τηρείτε τους Όρους Χρήσης της. Δεν μπορούμε να δώσουμε νομικές συμβουλές για την αντιγραφή αποτελεσμάτων εργαλείων που περιέχουν ιδιόκτητο κώδικα· αυτό αφορά εσάς, τον εργοδότη σας και την Anthropic.

Συχνές ερωτήσεις: εξαγωγή από το Claude Code

Στο τερματικό του Claude Code, πληκτρολογήστε /export (προαιρετικά με όνομα αρχείου) για να αποθηκεύσετε μια αποδοσμένη μεταγραφή, ή αντιγράψτε το αρχείο JSONL από το ~/.claude/projects σε macOS/Linux ή από το %USERPROFILE%\.claude\projects στα Windows. Η τεκμηρίωση συνεδριών της Anthropic περιγράφει το τρέχον παράθυρο.

Όχι από το τερματικό. Το Download Claude conversations λειτουργεί μόνο στο claude.ai στο Chrome. Δεν διαβάζει τοπικές συνεδρίες τερματικού, μεταγραφές JSONL ή την εντολή /export. Οι συνεδρίες του Claude Code on the web στο claude.ai/code εξάγονται κανονικά, όπως κάθε chat.

Μπορώ να εξαγάγω το Claude Code on the web (claude.ai/code);

Ναι. Ανοίξτε τη συνεδρία στο claude.ai/code στο Chrome και χρησιμοποιήστε το πορτοκαλί κουμπί. Λειτουργούν όλες: PDF, Markdown, απλό κείμενο, JSON, XML, CSV και PNG. Οι έξι μορφές εκτός PDF είναι απεριόριστες χωρίς λογαριασμό· το PDF χρειάζεται σύνδεση με Google και μετρά στις 3 δωρεάν την ημέρα.

Πού αποθηκεύει το Claude Code το ιστορικό συνομιλιών;

Οι μεταγραφές συνεδριών είναι αρχεία JSONL κάτω από το ~/.claude/projects/<encoded-working-directory>/, με όνομα το αναγνωριστικό της συνεδρίας. Η ακριβής δομή μπορεί να αλλάξει. Χρησιμοποιήστε το /export όταν θέλετε ευανάγνωστο αρχείο αντί να αναλύετε JSONL. Το CLAUDE_CONFIG_DIR μπορεί να μεταφέρει τον κατάλογο.

Πώς κατεβάζω μια συνομιλία του Claude Code σε Markdown;

Το /export του Claude Code δίνει μεταγραφή σε απλό κείμενο, όχι το Markdown αυτής της επέκτασης. Αν χρειάζεστε συγκεκριμένα Markdown, εξαγάγετε μια συνεδρία του claude.ai/code ή ένα αντίγραφο της δουλειάς στο claude.ai με το Download Claude conversations, ή μετατρέψτε μόνοι σας το κείμενο του /export. Εμείς δεν μετατρέπουμε JSONL σε Markdown.

Πώς κατεβάζω αντί γι’ αυτό μια συνομιλία του Claude.ai;

Εγκαταστήστε τη δωρεάν επέκταση Chrome, ανοίξτε το chat στο claude.ai και χρησιμοποιήστε το πορτοκαλί κουμπί — ή το Export All για το ιστορικό. Δείτε το πώς να κατεβάσετε ένα chat του Claude. Markdown, κείμενο, JSON, XML, CSV και PNG είναι απεριόριστα χωρίς λογαριασμό· PDF και μαζικό ZIP είναι 3 την ημέρα δωρεάν με σύνδεση Google· το Pro κοστίζει 3,99 $/μήνα ή 26,99 $/χρόνο.

Είναι το /export το ίδιο με το επίσημο Export data;

Όχι. Το /export αφορά την τρέχουσα συνεδρία του Claude Code. Το Settings → Privacy → Export data στέλνει με email ένα ZIP με JSON του λογαριασμού στην Anthropic. Διαφορετικά προϊόντα, διαφορετικά αρχεία, διαφορετική αναμονή.

Μπορώ να αναλύσω τα JSONL του Claude Code με το jq;

Μπορείτε, με την επιφύλαξη που δημοσιεύει η Anthropic: το σχήμα των γραμμών είναι εσωτερικό και μπορεί να αλλάξει. Προτιμήστε το /export ή το claude -p --output-format json όταν χρειάζεστε σταθερή μορφή. Αν αναλύετε έτσι κι αλλιώς JSONL, κλειδώστε την έκδοση του CLI.

Λειτουργεί η εξαγωγή από το Claude Code στα Windows;

Ναι. Το /export είναι εντολή του CLI. Οι μεταγραφές στον δίσκο βρίσκονται στο %USERPROFILE%\.claude\projects, εκτός αν ορίσετε CLAUDE_CONFIG_DIR. Αυτή η επέκταση Chrome εξακολουθεί να μην τρέχει μέσα σε εκείνο το τερματικό.

Είναι το Claude Code το ίδιο με το Claude Desktop;

Όχι. Το Claude Code είναι ο πράκτορας προγραμματισμού στο τερματικό. Το Claude Desktop είναι η εφαρμογή συνομιλιών. Το claude.ai είναι ο ιστότοπος. Μόνο ο ιστότοπος, μαζί με το claude.ai/code, αποκτά αυτή την επέκταση. Σημειώσεις για εξαγωγή από το Desktop: Claude Desktop.

Θα περιτυλίξει ποτέ αυτή η επέκταση το /export;

Όχι στην έκδοση 1.16.2. Το εύρος του προϊόντος είναι το claude.ai, μαζί με το Claude Code on the web: επτά μορφές, τοπικά αρχεία, σύνδεση με Google μόνο για PDF, μαζική εξαγωγή και Pro. Αν αλλάξει αυτό το εύρος, θα το αναφέρει αυτή η σελίδα. Μέχρι τότε, χρησιμοποιήστε το CLI της Anthropic για εξαγωγή από το Claude Code στο τερματικό.

Περιλαμβάνει το /export τα αποτελέσματα εργαλείων;

Η Anthropic περιγράφει το /export ως μηνύματα και αποτελέσματα εργαλείων αποδοσμένα ως ευανάγνωστο κείμενο. Αυτή είναι η δική της μεταγραφή, όχι ο δικός μας parser. Για το ακριβές τρέχον περιεχόμενο, εκτελέστε το /export στη δική σας έκδοση και διαβάστε το αρχείο — η τεκμηρίωση μπορεί να καθυστερεί σε σχέση με μια νέα έκδοση.

Μπορώ να εξαγάγω μαζικά συνεδρίες του Claude Code;

Όχι τοπικές συνεδρίες CLI. Το Export All στο Dashboard αφορά μόνο το claude.ai. Για πολλές συνεδρίες CLI, αντιγράψτε τον φάκελο projects ή εκτελέστε το /export ανά συνεδρία. Δεν υπάρχει μαζική εξαγωγή με πορτοκαλί κουμπί για JSONL.
