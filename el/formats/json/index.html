Εξαγωγή συνομιλίας Claude σε JSON για scripts

Για εξαγωγή συνομιλίας Claude σε JSON, εγκαταστήστε το Download Claude conversations, ανοίξτε τη συνομιλία στο claude.ai, πατήστε το πορτοκαλί κουμπί, διαλέξτε JSON και πατήστε «Export» (Εξαγωγή). Το Chrome αποθηκεύει ένα αρχείο ανά συνομιλία με το δέντρο των μηνυμάτων. Αυτό το αρχείο δεν είναι το ZIP λογαριασμού της Anthropic. Στα αγγλικά αναζητείται συνήθως ως «claude export chat to json». Η εξαγωγή σε JSON είναι απεριόριστη και δωρεάν, χωρίς λογαριασμό· το Pro (3,99 $ τον μήνα ή 26,99 $ τον χρόνο) αφορά μόνο τις μαζικές εξαγωγές και το PDF.

Πώς κάνω εξαγωγή συνομιλίας Claude σε JSON;

Ανοίξτε τη συνομιλία στο claude.ai στο Chrome, πατήστε το πορτοκαλί κουμπί δίπλα στο πλαίσιο μηνύματος, διαλέξτε JSON και πατήστε «Export». Το Download Claude conversations δημιουργεί το αρχείο τοπικά. Έτσι γίνεται η εξαγωγή σε JSON στην έκδοση 1.16.2. Τον Σεπτέμβριο του 2026 το claude.ai δεν έχει δικό του κουμπί αποθήκευσης σε JSON για μία συνομιλία.

  1. Εγκαταστήστε το Download Claude conversations από το Chrome Web Store.
  2. Φορτώστε ξανά το claude.ai και ανοίξτε μια πραγματική συνομιλία, όχι την κενή αρχική σελίδα με το πλαίσιο σύνταξης.
  3. Πατήστε το πορτοκαλί κουμπί λήψης δεξιά από το πλαίσιο μηνύματος.
  4. Επιλέξτε JSON. Η τελευταία μορφή που χρησιμοποιήσατε απομνημονεύεται. Με το «Select» (Επιλογή) τσεκάρετε μόνο τα μηνύματα που θέλετε.
  5. Πατήστε «Export». Το Chrome κατεβάζει το JSON μέσω του API λήψεων του προγράμματος περιήγησης. Ή πατήστε «Copy» (Αντιγραφή) για να βάλετε το JSON στο πρόχειρο.

Για την εξαγωγή σε JSON δεν χρειάζεται σύνδεση. Οι εξαγωγές μεμονωμένων συνομιλιών σε JSON είναι απεριόριστες, ανώνυμες και δεν στέλνουν τίποτα στους διακομιστές μας. Η σύνδεση με Google ζητείται μόνο για PDF και για τη μαζική εξαγωγή «Export All» (Εξαγωγή όλων). Οι λεπτομέρειες: πώς λειτουργεί.

Αν το πορτοκαλί κουμπί λείπει, δεν βρίσκεστε σε URL συνομιλίας, η καρτέλα χρειάζεται ανανέωση ή η επέκταση είναι κρυμμένη στο μενού με το εικονίδιο του παζλ στο Chrome. Καρφιτσώστε το Download Claude conversations και ανανεώστε το claude.ai. Το script της επέκτασης δεν φορτώνεται ποτέ στο Claude Desktop ή στο τερματικό του Claude Code.

Μία συνομιλία ή πολλά αρχεία. Το πορτοκαλί κουμπί εξάγει τη συνομιλία που είναι ανοιχτή σε JSON. Για πολλά αρχεία JSON, ανοίξτε το «View and Download All Conversations» (Προβολή και λήψη όλων των συνομιλιών) και εκτελέστε «Export All» με επιλεγμένο το JSON: ένα ZIP, 3 συνομιλίες την ημέρα στο δωρεάν πρόγραμμα — δείτε τη μαζική εξαγωγή Export All.

Πότε αξίζει η εξαγωγή σε JSON;

Διαλέξτε JSON όταν το αρχείο θα το διαβάσει ένα script, ένα εργαλείο ευρετηρίασης ή ένα εργαλείο σύγκρισης (diff). Το JSON έχει σχεδιαστεί για το δέντρο των μηνυμάτων, όχι για ανάγνωση στο Obsidian. Αν θέλετε επικεφαλίδες και μπλοκ κώδικα για ανθρώπους, διαλέξτε Markdown. Για υπολογιστικό φύλλο, διαλέξτε CSV: μία γραμμή ανά μήνυμα.

Η αντιγραφή-επικόλληση από το claude.ai χάνει τη δομή των αποστολέων. Η εκτύπωση κρατά τα στοιχεία της ιστοσελίδας. Με την εξαγωγή σε JSON, το Download Claude conversations κρατά τους γύρους, τους αποστολείς και, προαιρετικά, τη σκέψη (thinking) ως δεδομένα, όχι ως μία ενιαία παράγραφο. Γι' αυτό οι προγραμματιστές προτιμούν το JSON από το απλό κείμενο.

Γράφουμε το JSON από το δέντρο του claude.ai που βρίσκεται ήδη στη σελίδα — αποστολέας, μπλοκ περιεχομένου, χρονοσημάνσεις, μεταδεδομένα μοντέλου — χωρίς να ανεβάζουμε τη συνομιλία. Αυτό το JSON δεν είναι το ZIP λογαριασμού της Anthropic. Στην έκδοση 1.16.2 είναι μία από τις επτά μορφές, δίπλα στο PDF και το CSV, και είναι δωρεάν χωρίς λογαριασμό.

Η ομάδα του Download Claude conversations

Πολλοί αναζητούν την ίδια σελίδα στο Chrome Web Store ως Claude Chat Downloader ή Claude Conversation Downloader. Η εξαγωγή σε JSON γίνεται από το ίδιο πορτοκαλί κουμπί, όχι από δεύτερο προϊόν. Οι νομικές σελίδες μπορεί ακόμα να γράφουν Claude Exporter.

Τι περιέχει μια εξαγωγή συνομιλίας Claude σε JSON;

Η εξαγωγή σε JSON αντιγράφει το δέντρο μηνυμάτων του claude.ai: αποστολέα, μπλοκ περιεχομένου, χρονοσημάνσεις και μεταδεδομένα μοντέλου. Τα μπλοκ σκέψης, οι πηγές αναζήτησης ιστού, τα βήματα εργαλείων / MCP και τα artifacts περιλαμβάνονται όταν είναι ενεργές οι αντίστοιχες επιλογές: το «Thinking» είναι πλαίσιο επιλογής στο πάνελ εξαγωγής, ενώ τα εργαλεία και οι πηγές ενεργοποιούνται στις Ρυθμίσεις. Το φίλτρο αποστολέα περιορίζει το αρχείο σε όλα τα μηνύματα, μόνο του ανθρώπου ή μόνο του βοηθού. Τίποτα δεν μετατρέπεται πρώτα σε Markdown.

Η διάταξη των artifacts στην έκδοση 1.16.2 είναι «Original», «Inline», «Nested» ή «Flat» (αρχική, ενσωματωμένη, εμφωλευμένη ή επίπεδη). Αυτές οι διατάξεις αλλάζουν τον τρόπο που εμφωλεύεται το περιεχόμενο των artifacts στο JSON — οι ίδιες τέσσερις επιλογές ισχύουν για Markdown και XML. Πλήρης λίστα: λειτουργίες της επέκτασης Chrome. Για σελίδες αντί για δεδομένα, κάντε εξαγωγή σε PDF.

Αν η συνομιλία είναι μεγάλη, κάντε κύλιση μέχρι το claude.ai να φορτώσει τα παλαιότερα μηνύματα πριν από την εξαγωγή. Η επέκταση μπορεί να μετατρέψει σε JSON μόνο ό,τι έχει εμφανίσει η σελίδα. Μια μισοφορτωμένη σελίδα δίνει ένα κομμένο αρχείο JSON.

JSON συνομιλίας ή Export data της Anthropic;

Και τα δύο είναι JSON, αλλά δεν έχουν την ίδια δομή ούτε το ίδιο εύρος. Το Settings → Privacy → Export data της Anthropic (οι ετικέτες μπορεί να εμφανίζονται μεταφρασμένες αν το claude.ai είναι ρυθμισμένο στα ελληνικά) στέλνει με email ένα ZIP ολόκληρου του λογαριασμού μετά από αναμονή. Με την εξαγωγή σε JSON από την επέκταση, παίρνετε μία συνομιλία αμέσως στο Chrome. Χρησιμοποιήστε το ZIP για αντίγραφο ασφαλείας.

Στο αίτημα ZIP της Anthropic δεν μπορείτε να διαλέξετε Markdown. Ούτε μπορείτε να χρησιμοποιήσετε το JSON αυτής της επέκτασης ως άμεσο υποκατάστατο για το σχήμα εκείνου του ZIP. Όλες οι μορφές: μορφές εξαγωγής συνομιλιών Claude. Το PDF είναι για ανάγνωση, όχι εξαγωγή σε JSON.

Το Download Claude conversations δεν συνδέεται με την Anthropic, PBC. Το script της επέκτασης χρησιμοποιεί τη σύνδεση που έχετε ήδη ανοίξει στο claude.ai. Δεν συνδέεται στην Anthropic με ξεχωριστά διαπιστευτήρια. Τηρείτε τους κανόνες της Anthropic για τον λογαριασμό σας.

Μπορώ να εξαγάγω συνομιλίες σε JSON μαζικά;

Ναι. Ανοίξτε το «View and Download All Conversations», ορίστε το «Chat format» (μορφή συνομιλίας) σε JSON, φιλτράρετε τον πίνακα και πατήστε «Export All». Το Chrome αποθηκεύει ένα ZIP με ένα αρχείο JSON ανά συνομιλία. Στο δωρεάν πρόγραμμα αυτό σημαίνει 3 συνομιλίες την ημέρα με σύνδεση Google, κοινό όριο με το PDF. Το Pro, με 3,99 $ τον μήνα ή 26,99 $ τον χρόνο, αφαιρεί το όριο για μαζικό JSON.

Ο Πίνακας ελέγχου (Dashboard) δείχνει το ιστορικό του claude.ai με αναζήτηση κατά όνομα, φίλτρα «All conversations», «New», «Updated» και «Previously exported» (όλες, νέες, ενημερωμένες, ήδη εξαγμένες), καρτέλες «Chat» και «Cowork» και αναζήτηση σε projects. «New» σημαίνει ότι η συνομιλία δεν έχει εξαχθεί ακόμα με το Download Claude conversations. Το «Previously exported» παρακολουθεί όσες έχετε ήδη αποθηκεύσει. Το «Export All» είναι ένα ZIP με αρχεία JSON ανά συνομιλία, όχι αρχείο με ανάμεικτες μορφές.

Το ημερήσιο όριο ισχύει ανά λογαριασμό. Τρεις συνομιλίες την ημέρα στο δωρεάν πρόγραμμα, κοινό όριο με το PDF. Αν επιλέξετε 40 συνομιλίες ενώ σας απομένουν 3, μπλοκάρεται ολόκληρη η παρτίδα, δεν κόβεται στη μέση. Επιλέξτε λιγότερες ή χρησιμοποιήστε το Pro. Οι μεμονωμένες εξαγωγές JSON από το πορτοκαλί κουμπί μένουν απεριόριστες.

Μπορείτε να συγκρίνετε δύο εξαγωγές JSON της ίδιας συνομιλίας στο claude.ai από διαφορετικές στιγμές, όπως θα κάνατε με οποιοδήποτε αρχείο JSON. Κάθε εξαγωγή είναι αυτόνομη. Ένα δεύτερο «Export All» των ίδιων συνομιλιών μετρά ξανά κάθε συνομιλία.

Χρειάζεται Pro η εξαγωγή σε JSON;

Όχι. Η εξαγωγή μίας συνομιλίας σε JSON είναι δωρεάν και απεριόριστη, χωρίς λογαριασμό και χωρίς μετρητή — όπως σε Markdown, κείμενο, XML, CSV και PNG. Δωρεάν όριο έχουν μόνο το PDF και το μαζικό «Export All»: 3 την ημέρα με σύνδεση Google. Το Pro κοστίζει 3,99 $ τον μήνα ή 26,99 $ τον χρόνο μέσω Paddle. Το Download Claude conversations δεν χρεώνει επιπλέον για εξαγωγή σε JSON.

Το όριο φαίνεται στο μαζικό JSON. Κάθε συνομιλία σε ένα ZIP του «Export All» μετρά ως μία από τις 3 της ημέρας, και ο μετρητής μηδενίζεται τα μεσάνυχτα UTC. Το Pro το αφαιρεί και επανέρχεται σε νέο υπολογιστή με τον ίδιο λογαριασμό Google. Η Paddle είναι ο έμπορος καταγραφής (merchant of record)· η ομάδα μας δεν βλέπει ποτέ αριθμούς καρτών.

Η επέκταση λειτουργεί μόνο στο claude.ai στο Chrome. Το Claude Desktop και το τερματικό του Claude Code δεν αποκτούν κουμπί JSON· το Claude Code στο web (claude.ai/code) τρέχει στο claude.ai, οπότε εξάγεται όπως κάθε συνομιλία. Το /export του Claude Code στο τερματικό ή τα αρχεία JSONL στον δίσκο είναι άλλη διαδρομή. Η έκδοση 1.16.2, Σεπτέμβριος 2026, εξακολουθεί να μη δημιουργεί αρχεία Word ή Notion.

Συχνές ερωτήσεις: εξαγωγή συνομιλίας Claude σε JSON

Αυτές οι ερωτήσεις καλύπτουν την εξαγωγή σε JSON στο Download Claude conversations 1.16.2: μαζικό «Export All», δομή, κόστος, συγκρίσεις, το ZIP της Anthropic, PDF και Desktop. Κάθε απάντηση είναι γεγονός για το προϊόν. Το FAQPage JSON-LD στην κεφαλίδα της σελίδας αντιστοιχεί σε αυτή τη λίστα.

Μπορώ να εξαγάγω συνομιλίες Claude σε JSON μαζικά;

Ναι. Το «Export All» στο Dashboard υποστηρίζει JSON και αποθηκεύει ένα ZIP με ένα αρχείο JSON ανά συνομιλία. Στο δωρεάν πρόγραμμα καλύπτει 3 συνομιλίες την ημέρα με σύνδεση Google· το Pro, με 3,99 $ τον μήνα ή 26,99 $ τον χρόνο, είναι απεριόριστο.

Είναι τεκμηριωμένη η δομή του JSON;

Αντιγράφει το δέντρο μηνυμάτων του ίδιου του claude.ai: αποστολέα, μπλοκ περιεχομένου, χρονοσημάνσεις και μεταδεδομένα μοντέλου, με artifacts, μπλοκ σκέψης, πηγές αναζήτησης ιστού και βήματα εργαλείων / MCP όταν ενεργοποιείτε αυτές τις επιλογές. Δεν είναι το σχήμα του ZIP λογαριασμού της Anthropic.

Χρειάζομαι Pro για εξαγωγή συνομιλίας Claude σε JSON;

Όχι. Οι εξαγωγές μεμονωμένων συνομιλιών σε JSON είναι απεριόριστες και δεν χρειάζονται λογαριασμό, όπως σε κάθε μορφή εκτός από το PDF. Το Pro, με 3,99 $ τον μήνα ή 26,99 $ τον χρόνο, αφαιρεί μόνο το όριο των 3 την ημέρα για το PDF και το μαζικό «Export All».

Μπορώ να συγκρίνω δύο εξαγωγές JSON της ίδιας συνομιλίας;

Ναι. Κάθε φορά που κάνετε εξαγωγή σε JSON, παίρνετε ένα αυτόνομο αρχείο που δημιουργείται με τον ίδιο τρόπο. Η σύγκριση δύο εξαγωγών της ίδιας συνομιλίας από διαφορετικές στιγμές γίνεται όπως με οποιοδήποτε άλλο αρχείο JSON.

Είναι αυτό το JSON το ίδιο με το Export data της Anthropic;

Όχι. Το Export data της Anthropic είναι ένα ZIP ολόκληρου του λογαριασμού που φτάνει με καθυστέρηση. Το Download Claude conversations δημιουργεί αμέσως στο Chrome ένα αρχείο JSON ανά συνομιλία (ή ανά επιλογή μηνυμάτων). Μπορεί και τα δύο να είναι JSON, αλλά δεν είναι εναλλάξιμα.

Δημιουργεί η εξαγωγή σε JSON αρχείο PDF;

Όχι. Το JSON είναι δομημένα δεδομένα. Για σελίδες, διαλέξτε PDF στο ίδιο πάνελ· οι επτά μορφές είναι PDF, Markdown, JSON, απλό κείμενο, XML, CSV και PNG. Το PDF χρειάζεται σύνδεση Google και μετρά στο όριο των 3 την ημέρα στο δωρεάν πρόγραμμα.

Λειτουργεί η εξαγωγή σε JSON στο Claude Desktop;

Όχι. Η επέκταση Chrome λειτουργεί μόνο στο claude.ai. Το Claude Desktop δεν εμφανίζει ποτέ την επιλογή JSON. Ανοίξτε την ίδια συνομιλία στο claude.ai στο Chrome, αν υπάρχει εκεί.
