Claude Chat Downloader: εξαγωγή συνομιλιών Claude

Αποθηκεύστε συνομιλίες Claude σε PDF, Markdown, JSON, κείμενο, CSV, XML ή PNG

Για την εξαγωγή συνομιλιών Claude δεν υπάρχει ενσωματωμένο κουμπί: το Claude.ai δεν κατεβάζει μεμονωμένες συνομιλίες. Η Download Claude conversations — η δωρεάν επέκταση Chrome που πολλοί λένε Claude Chat Downloader ή Claude Conversation Downloader — αποθηκεύει τη συνομιλία που έχετε ανοιχτή, ή ολόκληρο το ιστορικό σας, σε PDF, Markdown, JSON, απλό κείμενο, CSV, XML ή PNG. Στα αγγλικά την αναζητούν συνήθως ως «claude export chat» ή «claude chat export». Τα αρχεία δημιουργούνται στο πρόγραμμα περιήγησής σας και οι περισσότερες εξαγωγές δεν χρειάζονται λογαριασμό. Πώς να κατεβάσετε μια συνομιλία Claude. Χρησιμοποιείτε το Claude Code στο τερματικό; Τότε χρειάζεστε εξαγωγή Claude Code, όχι αυτή την επέκταση.

Πώς να κατεβάσετε μια συνομιλία Claude σε 3 βήματα

    Προσθέστε την επέκταση

    Εγκαταστήστε την Download Claude conversations από το Chrome Web Store και καρφιτσώστε την. Χρειάζονται περίπου δέκα δευτερόλεπτα.

    Ένα πορτοκαλί κουμπί λήψης εμφανίζεται δεξιά από το πλαίσιο μηνύματος. Για πολλές συνομιλίες, ανοίξτε το View and Download All Conversations (Προβολή και λήψη όλων των συνομιλιών).

  3. 3

    Διαλέξτε μορφή και κάντε εξαγωγή

    Επιλέξτε PDF, Markdown, JSON, κείμενο, CSV, XML ή PNG και πατήστε Export (Εξαγωγή). Δεν χρειάζεται λογαριασμός — η σύνδεση με Google ζητείται μόνο για PDF και μαζικές εξαγωγές.

6 βασικές λειτουργίες για λήψη συνομιλιών Claude

01

Εξαγωγή σε PDF, Markdown, JSON, CSV & άλλες μορφές

Κατεβάστε μια συνομιλία Claude ως πραγματικό αρχείο — όχι ως στιγμιότυπο της ιστοσελίδας. PDF για ανάγνωση και κοινοποίηση, Markdown για σημειώσεις, JSON για προγραμματιστές, CSV για υπολογιστικά φύλλα, απλό κείμενο για το πιο λιτό αρχείο, XML για ανταλλαγή δεδομένων, PNG για οπτικό στιγμιότυπο. Ή πατήστε Copy (Αντιγραφή) για να περάσει το αποτέλεσμα στο πρόχειρο.

02

Μαζική λήψη συνομιλιών Claude

Ανοίξτε το View and Download All Conversations για να δείτε το ιστορικό σας, να αναζητήσετε με βάση το όνομα, να φιλτράρετε ανά project ή Cowork, και πατήστε Export All (Εξαγωγή όλων). Ένα ZIP αντί για μία καρτέλα τη φορά — 3 συνομιλίες την ημέρα στο δωρεάν πρόγραμμα, απεριόριστες στο Pro.

03

Κώδικας, πίνακες και artifacts παραμένουν

Η μηχανή εξαγωγής αναλύει το δέντρο μηνυμάτων, ώστε τα μπλοκ κώδικα να κρατούν τις εσοχές τους, οι πίνακες να μένουν πίνακες και τα artifacts να αποθηκεύονται ως «Original» (αρχική μορφή), «Inline» (ενσωματωμένα), «Nested» (εμφωλευμένα) ή «Flat» (επίπεδα).

04

Επιλέξτε τι μπαίνει στο αρχείο

Εξαγάγετε ολόκληρο το νήμα, μόνο τα δικά σας prompts, μόνο τις απαντήσεις του Claude ή μόνο τα μηνύματα που τσεκάρετε με το Select (Επιλογή). Συμπεριλάβετε το extended thinking όταν χρειάζεστε πλήρες ίχνος ελέγχου, ή παραλείψτε το. Τίτλοι, χρονοσημάνσεις και μεταδεδομένα μοντέλου μπορούν να μπουν στο ίδιο αρχείο.

05

Αναζήτηση και φίλτρα πριν από την εξαγωγή

Περιορίστε τη βιβλιοθήκη σε νέες συνομιλίες, σε όσες έχετε ήδη εξαγάγει ή σε ένα project του Claude, και εξαγάγετε μόνο ό,τι επιλέξατε.

06

Δημιουργία τοπικά στο πρόγραμμα περιήγησης

Κάθε αρχείο, ακόμη και το PDF, συναρμολογείται στη συσκευή σας και αποθηκεύεται στον δίσκο. Οι περισσότερες εξαγωγές δεν χρειάζονται λογαριασμό. Η σύνδεση με Google απλώς μετρά τις εξαγωγές PDF και τις μαζικές εξαγωγές και συνδέει τη συνδρομή Pro — δεν ανεβάζει ποτέ κείμενο συνομιλιών στους διακομιστές μας.

Σε ποια μορφή να κατεβάσετε μια συνομιλία Claude;

PDF

Ανάγνωση, εκτύπωση ή αποστολή

Αρχείο με σελίδες, στο μέγεθος σελίδας που θέλετε, με φωτεινό ή σκούρο θέμα, γραμματοσειρά και πίνακα περιεχομένων.

 Markdown

Σημειώσεις σε Obsidian ή Notion

Επικεφαλίδες, μπλοκ κώδικα και πίνακες επικολλώνται καθαρά σε vault σημειώσεων ή σε αποθετήριο τεκμηρίωσης.

 JSON

Scripts, σύνολα δεδομένων και RAG

Δομημένα μηνύματα με ρόλους και μεταδεδομένα, έτοιμα να τα διαβάσει κώδικας.

 Απλό κείμενο

Ένα απλό αρχείο φύλαξης

Ανοίγει παντού, η αναζήτηση είναι γρήγορη και δεν χαλάει όταν αλλάζουν τα εργαλεία.

 CSV

Υπολογιστικά φύλλα και έλεγχος

Μία γραμμή ανά μήνυμα για Excel, Google Sheets ή Numbers.

 XML

Εισαγωγή σε άλλα συστήματα

Μηνύματα με ετικέτες για pipelines και εργαλεία που περιμένουν XML.

 PNG

Κοινοποίηση οπτικού στιγμιότυπου

Μία εικόνα της συνομιλίας για διαφάνεια παρουσίασης, ticket ή μήνυμα.

Συχνές ερωτήσεις

Μπορώ να κατεβάσω μια συνομιλία Claude από το claude.ai;

Όχι με ενσωματωμένο κουμπί. Εγκαταστήστε την Download Claude conversations από το Chrome Web Store, ανοίξτε τη συνομιλία και εξαγάγετε ένα αρχείο.

Είναι δωρεάν η λήψη συνομιλιών Claude;

Ναι. Οι εξαγωγές σε Markdown, απλό κείμενο, JSON, XML, CSV και PNG είναι απεριόριστες και δεν χρειάζονται λογαριασμό. Οι εξαγωγές PDF και οι μαζικές εξαγωγές ZIP ζητούν σύνδεση με Google και είναι δωρεάν έως 3 την ημέρα. Το Pro, με 3,99 $ τον μήνα ή 26,99 $ τον χρόνο, καταργεί αυτό το όριο.

Σε ποια προγράμματα περιήγησης λειτουργεί;

Στο Chrome για υπολογιστή και σε προγράμματα περιήγησης βασισμένα στο Chromium που εγκαθιστούν επεκτάσεις από το Chrome Web Store. Δεν υπάρχει εφαρμογή για κινητά και η επέκταση δεν λειτουργεί μέσα στο Claude Desktop.

Πώς ακυρώνω το Pro και μπορώ να πάρω πίσω τα χρήματά μου;

Ακυρώστε οποτεδήποτε από τη σελίδα Options της επέκτασης («Cancel subscription» — ακύρωση συνδρομής) ή μέσω Paddle. Η πρώτη σας πληρωμή καλύπτεται από εγγύηση επιστροφής χρημάτων 14 ημερών, χωρίς ερωτήσεις.

Είναι το ίδιο με το Export data του Claude;

Όχι. Η επιλογή Settings → Privacy → Export data της Anthropic (οι ετικέτες μπορεί να εμφανίζονται στα ελληνικά, αν το claude.ai είναι ρυθμισμένο στα ελληνικά) στέλνει με email ένα ZIP ολόκληρου του λογαριασμού σας (JSON). Αυτή η επέκταση κατεβάζει αμέσως την τρέχουσα συνομιλία — ή μια μαζική επιλογή — ως αναγνώσιμα αρχεία.

Αποθηκεύετε τις συνομιλίες μου με το Claude;

Όχι. Κάθε μορφή, ακόμη και το PDF, δημιουργείται στο πρόγραμμα περιήγησής σας και το κείμενο της συνομιλίας δεν φτάνει ποτέ στους διακομιστές μας. Αν συνδεθείτε με Google για PDF, μαζική εξαγωγή ή Pro, αποθηκεύουμε μόνο αυτό το email, για να μετράμε το ημερήσιο όριο και να συνδέουμε τη συνδρομή σας.

Ποια η διαφορά ανάμεσα στο «εξαγωγή συνομιλίας Claude» και στο «claude export chat»;

Είναι η ίδια εργασία, γραμμένη στα ελληνικά ή στα αγγλικά — οι περισσότεροι την αναζητούν στα αγγλικά. Και στις δύο περιπτώσεις χρησιμοποιείτε το πορτοκαλί κουμπί στο claude.ai.

Κάνει εξαγωγή σε PDF;

Ναι. Επιλέξτε PDF στο πάνελ εξαγωγής και ορίστε μέγεθος σελίδας, περιθώρια, φωτεινή ή σκούρα λειτουργία, γραμματοσειρά, αρίθμηση σελίδων και πίνακα περιεχομένων. Το PDF χρειάζεται σύνδεση με Google· το δωρεάν πρόγραμμα περιλαμβάνει 3 εξαγωγές PDF ή μαζικές εξαγωγές την ημέρα, ενώ το Pro είναι απεριόριστο. Πλήρης οδηγός: λήψη συνομιλίας Claude σε PDF.

Λειτουργεί με Claude Pro / Team;

Ναι, αρκεί να μπορείτε να ανοίξετε τη συνομιλία στο πρόγραμμα περιήγησης, στο claude.ai. Δεν είμαστε η Anthropic.

Πώς αποθηκεύω μια συνομιλία Claude;

Εγκαταστήστε τη δωρεάν επέκταση Chrome, ανοίξτε τη συνομιλία στο claude.ai, κάντε κλικ στο πορτοκαλί κουμπί, διαλέξτε μορφή και πατήστε Export. Για Markdown, κείμενο, JSON, XML, CSV ή PNG δεν χρειάζεται λογαριασμός. Έτσι αποθηκεύετε μια συνομιλία Claude ως κανονικό αρχείο. Η εκτύπωση της σελίδας και το ZIP λογαριασμού της Anthropic είναι οι άλλες δύο επιλογές — σύγκριση στον οδηγό πώς να κατεβάσετε μια συνομιλία Claude.

Κατεβάζει και συνομιλίες του Claude Code;

Μόνο όσες βρίσκονται στο claude.ai. Τα sessions του Claude Code on the web (claude.ai/code) και του Cowork εξάγονται όπως κάθε συνομιλία. Η επέκταση δεν διαβάζει τοπικά sessions τερματικού· αυτά χρησιμοποιούν το /export ή αρχεία JSONL στον δίσκο — δείτε εξαγωγή Claude Code.

Συνδέεται η Download Claude conversations με την Anthropic;

Όχι. Το Claude είναι εμπορικό σήμα της Anthropic, PBC. Πρόκειται για ανεξάρτητη επέκταση Chrome, όχι για επίσημο προϊόν της Anthropic.
