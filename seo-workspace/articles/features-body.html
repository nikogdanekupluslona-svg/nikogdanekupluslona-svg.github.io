What Chrome extension features export one chat?

The core Chrome extension features for one thread are the orange button Download Claude conversations adds next to the message box on claude.ai. Open a conversation URL, pick Markdown, JSON, text, XML, or PNG, then click Export. The file downloads immediately.

  1. Install Download Claude conversations from the Chrome Web Store (listing rated 5.0).
  2. Reload claude.ai and open a real conversation URL, not the empty composer home.
  3. Click the orange download button to the right of the message box.
  4. Choose a format. Chrome extension features remember the last format you used.
  5. Click Export. Chrome saves the file through the browser download API.

The orange button only appears on a loaded conversation. The empty composer home has nothing to parse. If the button is missing, pin the extension in the Chrome puzzle menu and refresh claude.ai. These Chrome extension features never inject on Claude Desktop or Claude Code.

Local file. Markdown, JSON, text, XML, and PNG are built in the tab. Quota checks go to our worker. Chat text does not. Mechanics: how it works.

Which Chrome extension features cover Export All?

Bulk Chrome extension features live on View and Download All Conversations: a searchable table of claude.ai history, filters All / New / Exported / Project, and Export All. Each completed file is one of the 3 free exports. Pro at $3.99/mo or $26.99/yr removes that cap.

New means not yet exported with Download Claude conversations. Exported tracks chats you already saved so a second Export All can skip them. Project matches how you group chats on claude.ai. Search is by conversation name. Full flow: bulk Export All.

Quota is account-wide. Three free exports total — not three per bulk run. Selecting 40 conversations consumes 40 exports if every file completes. Plan the selection before you click Export All, or use Pro.

Export All uses the same thinking, metadata, sender, and artifact toggles as one conversation. It is many per-chat files, not Anthropic’s delayed account ZIP. You pick one format per run. Chrome extension features do not mix Markdown and JSON in a single click.

Do Chrome extension features keep artifacts?

Yes. Chrome extension features include artifact layout: Original, Inline, Nested, or Flat. Thinking blocks are an optional toggle for research trails. Metadata can add title, timestamps, and model. Sender filter limits the file to all, human only, or assistant only.

Artifacts are part of the claude.ai thread, not a separate download. Layout changes how they sit in Markdown, JSON, XML, and text. On PNG they are drawn, not stored as markup. If thinking is off, the export omits extended thinking even when claude.ai showed it on screen.

If the thread is long, scroll until claude.ai has loaded earlier messages. Chrome extension features can only export what the page has rendered. A half-loaded DOM produces a truncated file, which looks like a missing-artifact bug and is usually an un-scrolled conversation.

How do Chrome extension features handle sign-in?

Google sign-in is required from the first export. These Chrome extension features use that sign-in to count the 3 free exports per account and to restore Pro after a reinstall. Conversation content is never part of that flow. Download Claude conversations stores a Google-verified email for quota and subscription status.

The 3 free exports do not reset when you reinstall the Chrome listing. That is the point of sign-in. Pro is $3.99 per month or $26.99 per year through Paddle. Paddle is merchant of record; this team never sees card numbers. Pro restores on a new computer from the same Google account.

You do not need Anthropic’s paid claude.ai plan. Free, Pro, Team, and Enterprise claude.ai plans work if Chrome can open the chat. If a workspace admin blocks extensions, Download Claude conversations will not inject — that is browser policy, not a missing feature on this page.
