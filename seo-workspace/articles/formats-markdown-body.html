How do I export Claude chat to Markdown?

Open the conversation on claude.ai in Chrome, click the orange button beside the message box, choose Markdown, then click Export. Download Claude conversations writes a .md file locally. That is how you export Claude chat to Markdown in version 1.13.0.

  1. Install Download Claude conversations from the Chrome Web Store (listing rated 5.0).
  2. Reload claude.ai and open a real conversation URL, not the empty composer home.
  3. Click the orange download button to the right of the message box.
  4. Select Markdown. The extension remembers the last format you used.
  5. Click Export. Chrome downloads the .md file through the browser download API.

Google sign-in is required before the first time you export Claude chat to Markdown. Download Claude conversations stores the verified email to count the 3 free exports and to restore Pro after a reinstall. Chat text is not uploaded for that sign-in. Mechanics: how it works.

Why export Claude chat to Markdown for notes?

Export Claude chat to Markdown when you will read the file in Obsidian, a GitHub wiki, or any editor that renders headings and fences. The .md file is still plain text you can search and diff. JSON is better for parsers; PNG is a picture you cannot grep.

Copy-paste from claude.ai usually drops indentation and flattens tables. Print (Ctrl/Cmd+P) keeps the sidebar and often splits a long code block across pages. When you export Claude chat to Markdown, language tags stay on fences and tables stay tables. That is the reason writers pick this format first.

We treat Markdown as the default human-readable file: headings, fenced code with language tags, and tables from the claude.ai thread. We still do not invent a PDF format — if you need a printable page, use Chrome’s print dialog after you export Claude chat to Markdown or instead of it.

Can I export Claude chat to Markdown in bulk?

Yes. Open View and Download All Conversations, set the format to Markdown, filter the table, then click Export All. Each completed .md file is one export against the same 3 free exports as a single orange-button run. Pro at $3.99/mo or $26.99/yr removes that cap for bulk Markdown.

The browse table lists claude.ai history with search by name and filters All, New, Exported, and Project. New means not yet exported with Download Claude conversations. Exported tracks chats you already saved so a second Export All can skip them. Project matches how you group chats on claude.ai.

Quota is account-wide. Three free exports total — not three Markdown files per day. Selecting 40 conversations consumes 40 exports if every .md file completes. Plan the selection before you click Export All.

Bulk Markdown uses the same thinking, metadata, sender, and artifact toggles as one conversation. Export All is not Anthropic’s delayed ZIP. It is many per-chat .md files. If you wanted one archive of the whole account, that is Settings → Privacy → Export data, which is JSON, not Markdown.
